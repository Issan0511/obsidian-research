## 1. モデルと損失（出典: [[自己項の恒等式]] §0、`src/nets.py`）

- $\hat y = \sum_j v_j a_j + c$、$a_j = \mathrm{ReLU}(z_j)$、$z_j = w_j\cdot x + b_j$ — **2層 ReLU ＋ 線形読み出し**
- 損失 $\ell = \delta^2$（**½ なし**。実装規約。外部資料では ½ 規約と明示して使い分ける）
- $\delta = \hat y - y$ … **全ユニットが共有する残差スカラー**
- $o_i = v_i a_i$ … ユニット $i$ 自身の出力（**旧 $f_i$。8/20 夕に改名** — `f` が flipping bits の本数と衝突するため）
- $\delta = o_i + \delta_{\mathrm{rest},i}$ … 残差の「自分の分／それ以外」分解
- $u_i = w_i/\lVert w_i\rVert$ … 重みの向き（単位ベクトル）
- $\mu = \mathbb{E}[x]$、$\hat\mu = \mu/\lVert\mu\rVert$ … **必ず単位ベクトル**。$\lVert\mu\rVert$ は境界で跳ぶので生の $\mu$ 内積で引用しない
- **平均入力による前活性の位置の拘束（V10）**: $\bar z_i=w_i^\top\mu+b_i$、入力ごとの中心からのずれは $w_i^\top(x-\mu)$。ここでμは生の入力平均、$\hat\mu$ は単位方向であり、区別する。「μによる硬い射影」はこの内積による平均位置の拘束を指す説明語で、ノルム上限の射影介入ではない。→ [[中心主張v10草案_0916]] §0.1
- $\mathrm{gate}_i = \mathbb{1}[z_i>0]$。**ReLU では $a_i\cdot\mathrm{gate}_i = a_i$** なので式中の gate は化粧
- $\hat p_i$ … ユニット $i$ の発火率（固定 eval バッチ上）。**8/23 以降は次の二層を区別し、修飾なしの `dead` を不可逆性の主張に使わない**
    - **凍結（`strict_dead`）**: $\hat p\equiv0$。condA では当該タスクの全 32 パターンで gate が閉じ、タスク内の勾配が恒等ゼロ。不可逆性・吸収・復活 0 を述べてよいのはこの集合だけ
    - **ほぼ消灯（`near_off`）**: $0<\hat p<0.05$。condA では量子化により $\hat p=1/32$ のみ。1 パターンでは gate が開くので勾配は恒等ゼロでない
    - **旧作業指標（`dead_0.05` / `dead_frac_0.05`）**: $\hat p<0.05$。凍結とほぼ消灯の和で、過去のログ・集計との互換用の代理指標。不可逆性の根拠には使わない。既存ファイルの修飾なし `dead` / `dead_frac` は、明示的に $\hat p=0$ と書かれていない限り原則この旧指標を指す
    - 裁定理由: $1/32=0.03125<0.05$ であり、旧 `t_death` 以降もほぼ消灯群は median $\lvert\Delta b\rvert=0.43$ 動く一方、凍結後は厳密に 0 → [[マージン恒等式と消灯点_0822]] §8(a)
- **沈下（`submerged`）**【8/30 追加・非 ReLU 腕用】: $\max_{x\in\text{全サポート}} z_i(x)\le0$。condA では 32 パターンすべてで壁座標が非正。**ReLU 腕に掛けると `strict_dead` と完全一致する**（$\hat p=0 \iff \max_x z_i\le0$）ので、ReLU では新しい情報を持たない。使うのは ELU・leaky ReLU など**ゲートが無く $\hat p$ が定義できない腕**の記述用
    - **沈下は死ではない。** ELU では $\phi'=\alpha e^{z}>0$、leaky では $\phi'=a>0$ なので勾配は流れ続け、ユニットは戻れる。`gate_dose_0830` の 5M では leaky の沈下率 0.63–0.67（ReLU 0.98–0.99）で未フィット率は ReLU の 1/240
    - **`submerged_frac` を verdict に使わない**（`strict_dead` を verdict に使わない cbp_harm 裁定と同じ理由が、より強く当てはまる）。表現型の記述にのみ使う
    - **ReLU 腕の `strict_dead` と非 ReLU 腕の `submerged_frac` を同じ列に混ぜない。** `gate_dose_0830` の `verdict.csv` は非 ReLU 腕でも `strict_dead` 列に同値を出しており、「ELU でも strict_dead 36%」と誤読される（[[現在地]] 穴 7）
    - 深さは $\bar z_i:=\mathbb E_{\text{support}}[z_i]$（**生の壁座標**。正規化量で力学を書かない）
    - 出典: [[ELU沼_spec_0830]] §4.4（定義）／[[ゲート条件付き用量結果_0830]]（実測）
- $\beta$ … **ゲートマージン**。レジーム A では $(w^\top\mu+b)/\lVert w\rVert_\Sigma$、$\mu=0$ のレジーム B では $b/\lVert w\rVert$
- $w_{\rm free}$ … **$w$ の flip bits 成分 $w[:15]$**（condA の入力 20 次元のうちタスクごとに反転しうる 15 bit に対応する部分ベクトル）。**表記は `w_free` に統一**（9/1 Issa 裁定・Q26 確認 4。`w[:15]` は実装内の添字表記としてのみ使う）。$\kappa:=\lVert w_{\rm free}\rVert_1/\lVert w_{\rm free}\rVert_2\in[1,\sqrt5]$ → [[吸収不等式の命題化_0824]]
- $\eta$ … 学習率。$c$ … 読み出しのバイアス（出力オフセット）

## 2. 力の分解（出典: [[自己項の恒等式]]、[[中和と境界窓]]）

| 記号 | 定義 | 通称 |
|---|---|---|
| $F_{\mathrm{self},i}$ | $-2\eta\, v_i^2\,\mathbb{E}[a_i\,\mathrm{gate}_i\,(x\cdot\hat\mu)]$ | **税** |
| $F_{\mathrm{rest},i}$ | 上式の $o_i \to \delta_{\mathrm{rest},i}$ | **稼ぎ**。**現行フレームではこちらが駆動** |
| $F_{\mathrm{gate},i}$ | $F_{\mathrm{self}} + F_{\mathrm{rest}} \propto \mathbb{E}[\delta\cdots]$ | 正味 |
| $G$ | $\mathbb{E}[\delta x]$。**全ユニット共通の単一ベクトル** | **潮流**（condA では $\hat\mu$ とほぼ平行、$\lvert\cos\rvert$ 0.966–0.995） |

- **「税」= $F_{\mathrm{self}}$、「稼ぎ」= $F_{\mathrm{rest}}$、「潮流」= $G$（≒ $\hat\mu$ 方向）**。全ノートでこの愛称が流通している
- $F_i^{\mathrm{ungate}} = -2\eta\,v_i\,G$ … ゲートを外した力場。$v_i$ に**線形**なので定義上 $\pm G$ の二極
- **中和** … フィット中は $F_{\mathrm{self}}+F_{\mathrm{rest}}\approx 0$（相殺比 0.005）。力の平衡ではなく「共通スカラー $\delta$ が小さいことの言い換え」
- **鏡** … $\mathrm{corr}(-F_{\mathrm{self}}, F_{\mathrm{rest}})$。中和が成立している状態＝鏡が 1.000
- **陣営** … $v_i$ の符号。二極の割り当てが $\mathrm{sign}(v_i\cdot\mathbb{E}[\delta])$ で決まることから来る言い回し

## 3. 入力条件（出典: `src/envs.py`、[[台帳（実効バイアスの縮退）]] §1）

### condA = SCR（Slowly-Changing Regression、Dohare の公式ベンチマーク）

- 入力 $x \in \{0,1\}^m$、**$m=20$、$f=15$**。$x = [\,\mathrm{flip}(15\ \mathrm{bit}) \,\Vert\, \mathrm{rnd}(5\ \mathrm{bit})\,]$
- flip ビットはタスク内で**定数**（周期 $T$ ごとに 1 ビットだけ反転）、rnd ビットは毎 step $U\{0,1\}$
- → **1 タスクのサポートは rnd 5 bit の $2^5 = \mathbf{32}$ パターン**。「$f=15$ なのになぜ 32 か」はここ。$2^{15}$ ではない
- $\mu = \mathbb{E}[x] = [\,\mathrm{flip\_state} \,\Vert\, 0.5\cdot\mathbf 1\,]$（`src/posreset.py: current_mu_A`）。**成分毎に非負** — 税の符号定理はここに乗っている
- **$n_{\mathrm{active}}$** … flip 15 ビットのうち 1 の本数。$\mathrm{Bin}(15,0.5)$ なので典型 6–10。台帳の増幅率 $1+n_{\mathrm{active}}$ に出る
- 教師は **LTU**（Linear Threshold Unit）の和。重み・バイアスは $\pm1$、閾値 $\tau = \beta(m+1)-S$（`src/envs.py: LTUTarget`）

### condB = ガウス入力・教師再サンプル

- $x \sim \mathcal N(0,\Sigma)$。異方版は $\Sigma$ に $\kappa$ スパイクを入れる（`aniso_perp_0812` の $\kappa=16$ 等）
- $\mu=0$ なので税の符号定理は**成立しない**。**台帳も存在しない**（凍結ブロックが無いため）

## 6. 現象の呼び名

- **帯** / **帯深** … dead ユニットが溜まる $\cos(u,\hat\mu)$ の値域（median −0.325）とその深さ
- **消灯点** … $\hat p$ が 0 になる $\cos(u,\hat\mu)$（実測 ≈ −0.15）。**帯深 −0.325 との差が匍匐の動機**
    - **水準の区別（8/22 追加）**: −0.15 は **seed 中央値水準**の消灯点 $\theta_\mathrm{med}$。**全サンプル水準は $\theta_\mathrm{all} = -0.55$** で、崖は $[-0.55, -0.15]$ の内部構造を持つ。**ガウス $\beta$ 近似の −0.46 と比べるときは水準を揃えること**
    - **enc 依存（8/22 追加）**: 消灯点は $\cos_\mathrm{crit} = -(b+M)/(\lVert w\rVert\lVert\mu\rVert)$ で、**分母に $\lVert\mu\rVert$ がいる**。enc=centered では $\lVert\mu\rVert$ が 3.041 → 0.117 に潰れるため $\cos$ の定義域 $[-1,1]$ の外へ出て、**消灯点が存在しなくなる**（`ratchet_centered_0822` の C1「不可比」）。**逆に $\lVert\mu\rVert$ が大きいほど壁は手前に来る**（$b+M>0$ のユニットで。$\lVert\mu\rVert$ は壁の位置と、バイアスが逃げられる割合 $1/(1+\lVert\mu\rVert^2)$ の両方を決めている）→ [[マージン恒等式と消灯点_0822]] §1.5
- **匍匐（ほふく）** … 境界で $\hat\mu$ が跳ぶ → 凍結ユニットが一瞬**再露出** → 一押しされて再凍結、を繰り返して深部へ進む描像
- **再露出率** … 凍結区間のうち $\lVert w\rVert$ が実際に動いた割合（76.5%）
- **安全角** … 力の消灯領域に入らない $\cos(u,\hat\mu)$ の範囲（方向凍結アームの設計用語）
- **新鮮エントロピー** … `dir_angle` ダイヤル実験で一定に保つ統制量（供給する方向の「新しさ」の量）。角度 $\theta$ だけを動かすための設計
- **再分類死 / 輸送死** … 境界の衝撃 $\pm w_{ik}$ 一発でゲートが閉じる死（輸送ゼロ）と、窓の中で力に運ばれて滑落する死（→ [[命題リスト]] Q16）
- **穴A** … 「税が駆動でないなら、なぜ rest が下向きに偏るのか」という未同定の機構（8/20 夕以降の最大の未解決）
- **台帳** … condA で flip 15 座標＋バイアスが 1 自由度に縮退する構造（[[台帳（実効バイアスの縮退）]]）。**次論文の素材**

## 7. 略号・固有名

- **LoP** = Loss of Plasticity（可塑性喪失）
- **LTU** = Linear Threshold Unit（condA の教師の構成単位）
- **SCR** = Slowly-Changing Regression。**Dohare の公式ベンチマーク**（condA はこれ）
- **CBP** = Continual Backprop（Dohare の手法）
- **SDE** = 確率微分方程式。8/12 の先生提案の統一フレーム（Path A / Path B）
- **Path A / Path B** = 旧 SDE フレームでの「diffusion＋吸収壁 → dead」／「drift → 低ランク整列」。現行では「同じ駆動の、吸収端とそれ以外」
- **「怪文書」** = **私的な呼称**。正式には「符号クローン仮説の解析報告文書」。**外部文書には書かない**

## 8. 番号体系の注意（**相互参照の罠**）

**`Q` と `P` は2つの体系で使われている。**

- **グローバル**: [[命題リスト]] の `Q0`–`Q16`（中心主張の足場台帳）
- **ローカル**: 各実験ノート内の事前登録 ID。**そのノート限りの番号で、命題リストとは無関係**
    - [[ロギング走の結果]]: `P1`–`P5`, `E1`
    - [[位置リセット判別]] 本走: `P4`, `P5`, `P7` ／ 追補: `Q1`–`Q8`
    - [[停止条件]]（teachw_0820）: `P1`, `P3`, `T4`

衝突例: 命題リストの `Q6`（匍匐）と位置リセット判別 追補の `Q6`（posflip の $\Delta\cos = -0.628$）は**別物**。`Q7`・`P4`・`P5` も同様。

## 9/10 追記 — 前活性の幅の 2 チャネル

第 1 層の行を $W_i = m_i\mathbf 1 + \widetilde W_i$ と分けると、ユニット内の前活性分散が厳密に 2 つに割れる（定義の正本は [[幅か沈下か_クランプ介入_結果_0909]] §4、実測は [[第1層の成長の中身_事後_0910]]）:

$$\sigma^2_{\text{within},i} \;=\; \underbrace{m_i^2 s_{11}}_{\texttt{off}} \;+\; \underbrace{2m_i\,\mathrm{Cov}(\mathbf 1^{\mathsf T}x,\ \widetilde W_i\!\cdot\!x)}_{\texttt{cross}} \;+\; \underbrace{\mathrm{Var}(\widetilde W_i\!\cdot\!x)}_{\texttt{wid}}$$

- **`off`（明度チャネル）**: 行平均 $m_i$ が総インク量 $\mathbf 1^{\mathsf T}x$ に反応する分。$s_{11} = \mathrm{Var}(\mathbf 1^{\mathsf T}x) = 1310$（プローブ実測、$\sqrt{s_{11}} = 36.2$）。**$m_i$ は「明度ゲイン」**と読む。
- **`wid`（パターンチャネル）**: 中心化重みが入力パターンに反応する分。**`wid`$/\lVert\widetilde W_i\rVert^2 = 0.065 \pm 0.002$ が 3 活性化で普遍**で、値は $\mathrm{tr}(\Sigma)/784 = 0.06664$（等方な $\widetilde W$ が受け取る分散）。
- **`star_sd`**: ユニット間の幅 $=\mathrm{sd}_i(m_i\bar S + b_i)$、$\bar S = 103.7$（プローブの平均総インク量）。沈下は $\bar z = \bar m\bar S + \bar b$。**沈下・ユニット間の幅・明度チャネルはすべて行平均ベクトル $m$ の平均・散らばり・二乗平均**である。

## 固定尺度のReLU型活性化の一般化仮説（2026-09-16）

## 押しの向きのノート 2 本の局所記号（2026-10-02）

出典: [[押しと戻りの測定_収束の鎖と模様の上限とaの梯子_1001]]・[[押しの向き_証明の進み_門の道と段ごとの格_1002]]。以下は 2 本の局所表記で、1 層の乱数ラベル MNIST の箱（784-100-10）の量。

- **傾き $g_i$・切片 $\alpha_i$・模様 $e_i(n)$・しきい値 $\tau$**: unit i の前活性を入力の明るさ $K_n=x_n^\top\mu+1$ に回帰した $z_i(n)=g_iK_n+\alpha_i+e_i(n)$ の係数と残り。$\tau=|g|\bar K/\mathrm{sd}(e)$。この $e$ は §12 の残差要求 $e_i$・µ₂ 壁の $e_2$ とは別。この τ は、証明の進みのノートの勾配流の時間 τ とも別。
- **C・G**: 乱数ラベルでの CE の分け方 CE = C + log K + G。C = 入力平均の KL(u‖p)（確信の分）、G = ラベルの分（切替時 ≈ 0、新ラベルを覚えると負）。
- **書き込み $\|\Delta e\|^2$・消去率 $\varepsilon$**: 模様の帳簿 $\Delta s^2=\|\Delta e\|^2-2\varepsilon s^2$ の 2 項。この ε は Adam の ε・$\varepsilon_{\rm act}$・$\epsilon_o$ とは別。
- **対・感度 $d_{in}$・票 $c_{in}$・門 $g_{in}$・揃い $Q_i$**: 対 = (unit i, 入力 n) の組。$d_{in}=\varphi'(z_{in})$、$c_{in}=v^c_{i,y_n}$（読み出しからクラス平均を引いたものの、入力 n の新ラベルの成分）、$g_{in}=1[z_{in}>0]$、（**門 = ほかのノートの「ゲート」の開閉**。報告では「ゲート」と書く。1003）$Q_i=\sum_n K_n g_{in}c_{in}$。門の $g_{in}$ は上の傾き $g_i$ と別、$d_{in}$ は §12 のラベル差感度 $d_i$ と別、$Q_i$ は ELU の常時点灯の量 Q と別。
- **応答 $R_{in}$・$\iota$・引きずり**: 門の道の模型（読み出し固定・感度凍結・二乗誤差）で、入力 n のラベルを $v_i$ の向きに動かしたときの $z_{in}$ の動き $R_{in}=\sum_m\Theta_{nm}d_{im}v_i^\top[F]_{mn}v_i$（$\Theta_{nm}=\tilde x_n\cdot\tilde x_m$）。m = n の項が自己項、m ≠ n の項が引きずり。$\iota$ は対の空間で 0〜1 に規格化した応答。
- **flip・$\rho_{in}$・両順で正・底・引き直し**（証明の進みのノート §12）: flip = 入力 n のラベルだけを替えて、同じ課題を同じ始点・同じバッチ順で回し直す測定。$\rho_{in}=\sum_k c_{ik}z_{in}(T;k)/\sum_k c_{ik}^2$ は票 1 あたりの z の動き（$c_{ik}$ は unit i の課題前の読み出しからクラス平均を引いたものの、クラス k の成分。上の行の票 $c_{in}$ は入力 n の新ラベルの成分で、添字の意味が違う。この ρ は、前活性と明るさの相関 ρ、$\rho_\mu$ とは別）。両順で正 = 2 通りのバッチ順の両方で $\rho_{in}>0$。底 = 課題の頭の押しで層平均の m が底を打った時点。引き直し = 同じ課題の頭・同じバッチ順で、ラベル全体を引き直して課題 1 つ分を回すこと。
- **$S^{\rm open}_i$・$\hat Q_i$・$f_i$**: $S^{\rm open}_i=\sum_{n:z_{in}>0}K_n\langle v^c_i,p_n\rangle$（押しの期待の、開いた入力の分）。$\hat Q_i=\sum_n K_n{\rm Cov}_k(c_{ik},g_{in}(T;k))$（flip で入力 n のラベルを動かしたときの、課題末の門と票の共分散の和）。$f_i$ = 引き直しで、その量が正になった引きの割合。
- **$D^W$・$D^V$**: 時間の 2 次の展開で、自分の票への応答を減らす 2 つの引きずり。$D^W$ は第 1 層の核を通る分（門の道の模型の D）、$D^V$ は読み出しと出力 bias の核（$\varphi_n\cdot\varphi_m+1$）を通る分。
- **4 つの力 L・NC・OC・RC**（押しと戻りを残差で分けるノート）: 残差を $e_y-p=(e_y-u)-\sum_k(p_k-1/K)(e_k-u)$ と割ったときの、ラベルの揃い L（$e_y-u$ の分）・新しい自信 NC（新ラベルのクラスの分）・古い自信 OC（前の課題のラベルのクラスの分。$o\ne y$ の入力）・その他の自信 RC。一様な予測を基準にした約束事。L は線形の L1・L2 正則化などの L とは別。
- **門の側・一様な側／課題前の門で割る・4 区分**（同ノート §5）: leaky の感度 $d=(1-a)1[z>0]+a$ から、m の動きを「$(1-a)\times$ その時点で開いた対の和」（門の側）と「$a\times$ 全入力の和」（一様な側）に割る。課題前の門で割る版、いまの門 × 課題前の門の 4 区分もある。どれも帳簿で、割り方で読みが変わる。
- **全データの力・ミニバッチの力・古さ**（同ノート §5.3）: m にかかる力を、その時刻の全入力で足したものと、実際の更新に使われたバッチで足したもの。古さ = 入力が最後にバッチに入ってからの更新数。ミニバッチの力の和 = 全データの力の和 ＋ 選び方の分 ＋ 抜き出しの揺らぎ。
- **ずらし $\delta$**（同ノート §6）: 課題の頭で全 unit の m を課題前の幅の $\delta$ 倍だけ $(\mu,1)$ 方向にずらす介入。ラベル差感度や §12 の $\delta$ とは別。
- **$T_i$・$\mathbf 1_{開}$・$\mathbf 1_{閉}$・逆自己項**（証明の進みのノート §13）: $T_i=\Theta\circ F_i$（成分ごとの積。半正定値）で、対の応答のベクトルは $R_i=T_id_i$。$\mathbf 1_{開}$・$\mathbf 1_{閉}$ は unit i の開いた入力・閉じた入力の指示ベクトル。逆自己項（Issa の語）= ほかの入力で、ラベル − 予測が票の向きで逆転している分。
- **容量 $\Phi$・$\pi_a$・$\pi_1$**（証明の進みのノート §14）: $\Phi=\tfrac12\log\det(\mathcal K+\lambda)$。門の道の模型で対の応答は $R_{in}=\partial\Phi/\partial d_{in}$（Jacobi の公式の型）。「容量」はこのノートだけの呼び名。$\pi_a$・$\pi_1$ は、門が 1 つだけ動く骨子で、閉じた領域・開いた領域の最小点がちょうど境界に来る配置の密度（未導出・未測定）。予測の確率や $\pi^+$ とは別。
- **票への傾き $\hat R$・揃い $G$（回し直し版）**（証明の進みのノート §15.6）: 入力 1 個のラベルを $k=1..10$ に替えて課題を回し直したときの課題末の前活性 $z_k$ について、$\hat R=\sum_k c_k z_k/\sum_k c_k^2$（$c_k$ は課題前の票）、$G=\tfrac1{10}\sum_k c_k\,1[z_k>0]$。門がラベルで動く対の 98.5% で符号が一致。
- **理想化の符号則 $D_1$**（同 §15.3）: $D_1=\bar K\,\langle 1[z>t]^\perp,(z-t)_+^\perp\rangle+\sigma_K\,\rho\,\mathrm{Var}(1[z>t]^\perp)$。$\perp$ は定数と $z$ で表せない部分。読み出しの道・$\tau\to\infty$・ガウスの前活性・ほかの unit は線形の関数だけ表す、の模型での押しの符号。第 1 項の符号は $t$ の符号（半分より多く閉じていれば正）。
- **逆・より深い複製**（同 §15.1）: 逆 = 自己項が正なのに、残りを足した合計が負。より深い複製 = 自分の開いた入力が、ほかの unit の開いた入力に含まれること（読み出しの道で実際に逆になる unit の型）。分け方の名前は 自己項／残り の 2 つに固定（1003）。
- **勾配の出どころの帳簿（自・開・閉・持）**（証明の進みのノート §16.4）: 対 $(i,n)$ の課題中の前活性の動きを、入力 $n$ 自身の勾配の分（自）、ほかの入力の勾配の分（勾配が出た時点で unit $i$ がその入力に開いていた＝開／閉じていた＝閉）、課題の頭に持ち越された 1 次モーメントの分（持）に足し分けたもの。Adam の一歩が 1 次モーメントに線形なので厳密。自己項／残り（unit 単独 対 ほかの unit）とは別の分け方。
- **A・B（m の動きの帳簿）・雑音の分・系統の分・ばらつきの分・$\Gamma_n$・腕 N0a／N2**（証明の進みのノート §16.17）: unit $i$ の $m$ にかかる力 $\sum_n K_n d_{in}\langle v_i(t),r_n\rangle$（$r_n=e_{y_n}-p_n$）を、A $=\langle v_i(0),r_n\rangle$（課題前の読み出しを通る分）と B $=\langle v_i(t)-v_i(0),r_n\rangle$（課題の中で読み出しが動いた分）に割る。読み出しの勾配を、系統 $-\bar R\bar\varphi_i$・雑音 $-\nu\bar\varphi_i$・ばらつき $-\tfrac1B\sum r_m(\varphi_{im}-\bar\varphi_i)$ に割り（$\bar\varphi_i$ = 出力の全入力平均、$\bar R$ = 全入力の平均残差、$\nu$ = バッチの平均残差 $-\bar R$）、B をその出どころで足し分けたものが 雑音の分・系統の分・ばらつきの分。$\Gamma_n=1+\sum_j\bar\varphi_j\varphi_{jn}$（雑音 $\nu$ で全 unit の読み出しと出力 bias が動いたときの、入力 $n$ の logit の動きの倍率）。雑音の分の力の期待は $-\eta^2\bar\varphi_i\,d_{in}\Gamma_n\,\mathrm{tr}(C_n\Sigma_\nu)$。N0a = 読み出しの勾配から雑音の分を抜く腕、N2 = 2 倍にする腕。単独の腕 = unit $i$ の $w_i,b_i,v_i$ だけ学習する腕。
- **$\hat d_n$（ほかの unit が当てるゲートの値）・3 因子**（証明の進みのノート §16.22）: 凍結模型（リッジ）で、対 $(i,n)$ の応答の 全体 ÷ 単独 $=(E_{nn}/E^0_{nn})\times(\kappa'_n/\kappa^0_n)\times(1-\hat d_n/d_{in})$。$E_{nn}$ = 入力 $n$ の当て残し ÷ $\lambda$（ほかの unit がいると減る）、$\kappa'_n$ = $\tilde x_n$ のうち unit 自身のほかの入力に縛られていない分（ほかの unit がいると増える）、$\hat d_n=\sum_{m\ne n}\alpha_{mn}d_{im}\Theta^Q_{nm}/\Theta^Q_{nn}$（$\alpha$ = ほかの unit だけの網が入力 $m$ から $n$ を当てる重み）。§4.4 の $d^*$ と同じ数。符号を変えられるのは第 3 因子だけ。相手が線形の道だけなら $\hat d_n=a\mathcal A_n+(1-a)\mathcal P_n$（$\mathcal P_n$ = unit の開いた入力が、入力 $n$ の当てはめに占める分）。
- **容量 $\Phi$（両方の層）・余白 $\mathcal M$・$\mathsf S$・並列和**（証明の進みのノート §16.23）: $\Phi=\tfrac12\log\det(\mathcal K+\lambda)$、$\mathcal K$ = 第 1 層と読み出しの両方の NTK。ラベルとの余白 $\mathcal M(\theta)=\sum_n\langle Y_n,f_n(\theta)\rangle$。線形化した網をリッジで当てはめた後 $E_Y[\nabla_\theta\mathcal M]=\tfrac1K\nabla_\theta\Phi$。unit の位置の向きでは左辺 = ラベルとの揃い $L_i=\sum_nK_nd_{in}c_{i,y_n}$ の期待。$\mathsf S=[\lambda(\lambda+\mathcal K_{-i})^{-1}]^{1/2}$ = ほかの unit が当て残す部分を取り出す作用素で、$\partial\Phi/\partial m_i=\partial_{m_i}\tfrac12\log\det(\lambda+\mathsf S\mathcal K_i\mathsf S)$。**並列和** $A:B=(A^{-1}+B^{-1})^{-1}$。ほかの unit がアフィン関数だけを表せるとき、unit のアフィンでない部分は $M=S_{\text{開}}:S_{\text{閉}}\preceq S/4$ で決まる。
- **$w_j$（$\hat d$ のほかの unit ごとの重み）・$\bar d_n$・$f_n$**（証明の進みのノート §16.24）: 凍結模型（読み出し 1 方向）で $\hat d_{in}=\sum_{j\ne i}w_j d_{jn}$、$w_j=\gamma_j k_i^\top(H_{\setminus n})^{-1}k_j/\kappa'_n$（$k_j$ = unit $j$ のゲートつきの、入力 $n$ との似かよい。入力 $n$ でのゲートに依らない）。$\bar d_n=a+(1-a)f_n$ は入力 $n$ でのほかの unit の平均ゲート、$f_n$ はその入力で開いているほかの unit の割合（強さの重み）。ほかの unit が入力 $n$ 以外で閉じているとき $\hat d_{in}=(\bar d_n/a)\times$（相手が強さ $a^2\sum\gamma_j$ の線形の道だけのときの $\hat d$）。$f^w$ は同じ割合を $w$ の重みで測ったもの（$\hat d=\sum_j w_j\cdot(a+(1-a)f^w)$ は恒等式）。
- **$\rho_a$・$\rho_1$・$W_a$・$W_1$・$d_{\rm crit}$・ゆっくり動かす極限**（証明の進みのノート §16.25）: $\rho_g$ = 対 $(i,n)$ のゲートを $g\in\{a,1\}$ に止めたときの凍結した応答（$\rho_g\propto g-\hat d_n$）。ゲートが 1 個だけ動く模型（終点 = 損失の最小点）で、深さについて積分した揃いは $\gamma\sigma^2(W_1\rho_1+W_a\rho_a)$、$W_1,W_a>0$。正になる条件は $\hat d_n<d_{\rm crit}$（$a$ と 1 の間の重みつき平均）。**ゆっくり動かす極限** = ラベルの大きさ $\sigma\to0$。閾値から離れた対のゲートは最小点で動かず、unit の揃いの期待は $(1-a)\gamma\sigma^2\sum_n K_n q_n(W_1\rho_1+W_a\rho_a)$（$q_n$ = unit の位置のゆらぎで入力 $n$ が閾値に来る密度）。
- **反転の恒等式・$\alpha_m$・$\beta_m$・包絡の恒等式・$\varpi_m$**（証明の進みのノート §16.26）: **反転の恒等式** = リッジの停留点の残差を、課題前のゲートの凍結模型の量と、ゲートが変わった対（反転した対）だけで書く式 $r=\lambda E_0Y-\sum_{F}\delta_{jm}[\lambda\zeta^*_{jm}E_0e_m+r_mE_0\kappa_{jm}]$（$\delta_{jm}=v_j\times$ ゲートの変化、$\zeta^*$ = 終点の前活性）。$\alpha_m=[E_0c_0]_m$ = 入力 $m$ のラベルに対する unit の位置の応答、$\beta_m=K_m-c_0\cdot E_0\kappa_{im}$ = 位置の向きと対の向きの内積のうち、当てはめに縛られない分。押しに入る量と揃いの差は $\delta[-\beta r+\lambda\alpha\zeta^*]$。**包絡の恒等式** = ゲートが 1 個動く模型で $\int dz_p\,\delta\,r^*_n=\tfrac{\lambda}{2}Y^\top(E_a-E_1)Y$（ゲートを開いたときの当て残しの減り）。$\varpi_m$ = $\hat d_n$ を unit 自身のほかの入力でのゲートの加重和 $\hat d_n=\sum_{m\ne n}\varpi_m d_{im}$ に書いたときの重み（入力 $n$ の特徴をほかの入力の特徴でリッジ回帰した係数 $\times\,\Theta_{mn}/\Theta_{nn}$）。容量は 1 個のゲートの値 $g$ について $\tfrac12\log[c_0+\gamma\kappa'(g-\hat d_n)^2]$ で、開いて増える $\iff\hat d_n<(1+a)/2$。
- **1 次元の比較原理**（同 §16.6）: $\dot z=d(z)\,c\,A(t)+B(t)$（$A>0$、$d=1$ か $a$、$B$ はラベルによらない）なら、解は票 $c$ について単調で、揃い $G\ge0$・票への傾き $\hat R\ge0$。門の動きそのものは単調性を壊さない。**自己項の向きの言い換えで（残りを仮定で外している）、中身は「対の自分の門の跳びは符号を壊さない」だけ（Issa の指摘、1003）。**
- **π_a・π_1（揃いの 1 次の式）**（同 §16.10）: 門が 1 つ動く模型で、$E[\text{揃い}]\approx\sum_{g=a,1}E[\mathrm{Var}(c)R_g J_g\mid\bar z_g=0]\,p_g(0)+\Xi_C$。$\bar z_g$ は票 0 のときの頂点、$p_g(0)$ はその密度の 0 での値、$J_g$ は門の跳び（D に接する線は ½、C に接する線は捕まる割合 $\bar h$）。$\pi_g=p_g(0)\times J_g$。境界 ½ では $g=\tfrac12H(z^*_a)+\tfrac12H(z^*_1)+(h-\tfrac12)1_C$ の恒等式。
- **閾値の感度 $d^*$・$\omega$・$P$・$\kappa$**: 対の感度だけを動かしたときの応答 $R(d_0+\epsilon)=(q+\epsilon\omega)/(1+2\epsilon q+\epsilon^2\omega)$ の零点が $d^*$。$\omega=P\kappa+q^2$、P = 当て残し ÷ λ、κ = $\tilde x_n$ のうち unit i のほかの入力に縛られていない分。この κ は二乗誤差の腕の「的の遠さ κ」・µ₂ 壁の $\kappa_2$ とは別。
