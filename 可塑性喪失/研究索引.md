## 運用ルール

- 1論点 = 1ファイル。冒頭に `親 / 状態 / 更新` を書く
- 論点が増えたらこの索引に追記し、親からもリンクを張る
- 決着した論点は Slack Canvas に昇格させる（Obsidian = 自分用の全論点、Canvas = 共同研究者に見せる決着済み）
- 破棄した主張は消さずに取り消し線で残す。理由も併記する
- **フレーム交代で死んだ論点は `過去の遺物/` へ移す**（削除しない）。移動時に **Next action は廃止と明記する**。未実施であることは残す理由にならない
- **未実施の実験を秘書システムにタスクとして起票しない。** 実験の候補は Obsidian（[[命題リスト]] の「閉じる作業」列）に置き、実際に回すと決めたものだけタスク化する
- **数値は `results/*/verdict.csv` と `summary.md` からのみ転記する。チャットの言い回しを出所にしない**（8/20 に「残差2桁増」「8.5%で止まる」の2件が会話由来の不正確な転記として発生）
- **事後追加の数値は「事後」ラベルと必ずセットで運ぶ**
- 新しいチャットを開いたら「索引と該当ファイルを読んで」と指示すればキャッチアップできる
- **実験は spec を実行前にコミットして事前登録する**（rank_int_0814 以降）。判定基準を先に凍結し、想定外の分岐に落ちたらそれ自体を記録する。**追補も同様**
- **事前登録の統計量が痩せたら、事前登録版を残したまま補遺を「事後」ラベルで足す**（8/21b、D0 → S-D0）
- **大規模な実装・実行は外部エージェント（Codex 等）に委譲してよい**。事前登録は委譲元が先に固定し、HANDOFF で背景を全部渡す。実行結果は独立に検証してから取り込む
- **計画文書（事前登録済み）は結果を見た後に書き換えない**。判定・改訂は該当論点ファイルと [[論点マップ]] に記録する
- **新しい記号・略号を導入したら [[用語と記号]] に1行足す**（8/21 追加）

## 8/22d 追記 — 訂正 1 件と、新しい主要な問い

### 訂正: 撹拌はほぼ対称だった

平均だけを見ていたのが原因。増分の分布を見ると:

- Δx の符号割合は **+ 0.4971 / − 0.5008**（タスク内・alive・Δstep=1000、n = 149,492）
- 中央値は **−0.000000**、SD 0.034220 は平均の **20 倍**
- 中央帯（−0.6〜+0.3）の +の割合は 0.478〜0.509 でほぼ 50%。偏るのは **[+0.6,∞) の 0.3952** だけ
- 生涯では **94.9% の個体が一度は +µ 側へ到達**（x_max 中央値 +0.3179、最大 +1.6226）。上向き連勝は最大 **20 回連続 = 20,000 step**

**正しい形**: 「非対称な撹拌」ではなく「**ほぼ対称な撹拌 ＋ 上側の弱い天井 × 下側の吸収**」。**整流フレームは 8/22c で書いたほど危なくない。**

→ **[[命題リスト]] Q17 の閉じ方が「対称ではなかった」から「ほぼ対称・上側に弱いバイアス」に変わる。** [[フレーム前の穴]] 後-2 も同様（未反映）。

|---|---|---|
| 何があるか | 天井（押し返す力） | 吸収（動きが消える） |

### 新しい主要な問い: 天井の正体

旧「穴A」の後継。**仮説 H**: 天井は壁ではなく**平衡点**で、`|self|/|rest| ≈ |v_i·a_i| / |r_i|`（自分の出力 ÷ 残りの残差）が 1 を跨ぐ位置。

予言 2 本が当たった。

| \|v\| | 1 を跨ぐ帯 |
|---|---|
| 低位（< 0.769） | [+0.3, +0.6)。**[−0.6,−0.1) では E[Δx] がプラス**（下から押し上げられる） |
| 高位（≥ 0.769） | [−0.1, +0.1) |

| 残差（eval_loss 中央値 0.02017） | 比のレンジ | [+0.3,+0.6) の E[Δx] |
|---|---|---|
| 小 | 0.9979〜1.0009 | **+0.000192** |
| 大 | 0.9780〜1.0245 | **−0.025329** |

**天井は残差がないと存在しない。** これは Q2b の「フィット中は 99.5% 中和」と**同一の現象**で、**中和とは平衡そのもの**。

**候補文**: 天井は外から与えられた壁ではなく、「自分がもう出しすぎている」という**自己参照的な平衡**。位置は自分の `|v|` と、他のユニットが残した残差で決まる。

### 引用禁止・要注意（追加）

- **8/22d の「天井 = 平衡」は仮説段階。** 比は 0.98〜1.03 の 5% レンジしか動かず、分子分母がほぼ相殺しているので**測定誤差に極端に敏感**。CI 未算出。**因果の向きも決まっていない**（比が 1 を超えたから押し戻されるのか、押し戻された結果 1 に張り付くのか）
- **8/22c に書いた「撹拌の対称性は棄却」を、そのまま外部へ出さないこと。** 8/22d で弱めてある

### 判別案（未起票・再学習なしで届く可能性）

比を**外から動かす**と決まる。ユニットを 1 つ消音（`v←0`）すれば他から見た残差が跳ねるので**天井が上がるはず**。[[位置リセット判別]] の `vzero` アームがその操作にあたる。
