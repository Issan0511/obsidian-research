## 0. 結論

1. **害は収束後の Adam の長い尾にある（登録）。** 箱は RL-CIFAR × MLP（leaky 0.1、std、Adam 1e−3、10 seed、50 課題）。
   - 収束後（hit999+500 以降）だけ凍結か plain SGD にすると、後期の学習の遅れは全部消える（ρ 1.00〜1.07）。
   - Adam の m, v を切替時点に戻しても効かない（AR、ρ −0.02）。害を運ぶのは重みで、状態ではない（交差 fork）。
   - **A_ce（新）**: Adam のまま SGD と同じ 3.45 e-fold だけ CE を下げて凍結すると、遅れの 90% が消える（Q7 `MATCHED_CE_HARMLESS`、ρ 0.90 [0.88, 0.94]、10 seed 全部 ≥ 0.75）。害は、SGD が届かない残りの約 2 万更新にある。この間に CE はさらに約 9 e-fold 下がり、float32 の床で暴発が起きる。
2. **最初から SGD（追補 1）では W1 は桁違いに小さい。** t50 の ‖W1‖² は IID 968、ABAB 305（Adam は 75,982）。
   - ABAB の周期の中心は伸び続けるが減速する（Q9 `SLOWING`、6.6 → 2.8/課題。Adam は 1,003 → 801）。半差は一定（Q10 `BOUNDED_DIFF`、1.7。Adam は 200）。
   - Issa の「残渣は真逆なので増えた分だけ減る」は、半差では成り立つ。中心に残るのは一歩の二乗の項だけ（§3）。
   - **SGD でも IID は遅くなる。** 覚えるのにかかる更新数が 2,970（t1–5）から 4,685（t41–50）へ 1.58 倍になった（予測 F7 は Claude・Codex とも外れ）。W1 は小さいままなので、Adam の W 増大とは別の経路。未同定。
3. **収束後の伸びの配り方（事後・新）。** SGD は 3 層に同じ量を足す（例: +20.2 / +20.07 / +20.05）。これは重みの尺度の付け替えに対する網の対称性から出る釣り合いの保存則（Du, Hu & Lee 2018）の離散版で、一歩ごとに厳密に成り立つ。Adam はこれを一次の項で破り、ほぼ全部を W1 に積む（+2,634 / +115 / +3.9）。
4. **「W 増大の必然性」はまだ言えていない。**
   - SGD では、最終層とバイアスが有界なら、W1 の長期の伸びは一歩の二乗の項の累積だけになる（Codex 検算済み）。一次の外向きは必然でない。
   - Adam の正味（収束後の押し − 切替の戻り）の符号・量・課題数に対する線形成長は、どの恒等式からも導けていない（Codex 検算で確認）。

## 3. 収束後の伸びは層にどう配られるか（事後）

課題あたりの Δ‖W_l‖²（t26–50、seed 中央値。`analysis/sgd_postfit_cifar_0923/posthoc_layers.py`）:

| 腕 | 収束後 W1 / W2 / W3 | 課題全体 W1 / W2 / W3 | t50 の ‖W3‖² |
|---|---|---|---|
| A（Adam） | +2,634 / +115 / +3.9 | +1,447 / +26 / +0.25 | 15.7 |
| A_ce | +440 / +20.7 / +1.1 | +525 / +6.1 / +0.23 | 12.7 |
| S_lo（SGD） | +2.8 / +2.82 / +2.82 | — | — |
| S_mid（SGD） | +8.0 / +7.81 / +7.79 | — | — |
| S_hi（SGD） | +24.3 / +27.1 / +23.7 | — | 267 |
| SA_iid（全部 SGD） | +20.2 / +20.07 / +20.05 | +15.9 / +2.3 / −0.25 | 148 |
| SA_abab（全部 SGD） | +2.6 / +2.63 / +2.65 | +2.9 / +1.1 / +0.25 | 71 |

**なぜ SGD は同じ量を配るか（既知の恒等式）。** leaky ReLU は正の定数倍と交換する。だから (W_l, b_l) を c 倍し W_{l+1} を 1/c 倍しても、網の出力は変わらない。これを c で微分すると、どの損失についても
⟨W_l, ∇_{W_l}L⟩ + ⟨b_l, ∇_{b_l}L⟩ = ⟨W_{l+1}, ∇_{W_{l+1}}L⟩（l = 1, 2）。
交差エントロピーでは、最終層側に M = Σ_k p_k (z_y − z_k)（softmax で重み付けした余白の平均）が現れ、
⟨W_l, −∇_{W_l}L⟩ = M + Σ_{j≥l} ⟨b_j, ∇_{b_j}L⟩。
- 正しく分類された画像では M > 0 なので、バイアスの項が小さければ、勾配はどの層も同じ量だけ外向き。
- plain SGD の一歩では一次の項が層どうしで打ち消し、Δ(‖W_l‖² + ‖b_l‖² − ‖W_{l+1}‖²) = η²(‖g_{W_l}‖² + ‖g_{b_l}‖² − ‖g_{W_{l+1}}‖²) が一歩ごとに厳密に成り立つ（Du, Hu & Lee 2018 の釣り合いの離散版。原論文の脚注 8 がバイアスへの拡張）。
- 収束後の SGD で 3 層の増分が 1% 以内で揃うのは、この式どおり（勾配が小さく二乗の項が無視できる）。S_hi の W2 だけ 1 割ずれるのは η が大きく二乗の項が見えるため。

**帰結（Codex 検算の文言に合わせた形）。** どの期間についても
Δ‖W1‖² = Δ‖W3‖² − Δ(‖b1‖² + ‖b2‖²) + Σ_t η²(‖g_{W1}‖² + ‖g_{b1}‖² + ‖g_{b2}‖² − ‖g_{W3}‖²)。
最終層と b1, b2 が有界なら、W1 の長期の伸びは二乗の項の累積と、有界な端点の項を除いて一致する。課題数で割った平均では端点の項が消える。
- SGD の最終層は課題ごとに書き直されてほぼ有界（SA_iid の課題全体 −0.25、SA_abab +0.25）。だから W1 の伸びは二乗の項だけで、当てはめの長い IID で +15.9/課題、再訪が 200 更新で済む ABAB で +2.9/課題。ABAB の中心が減速する（Q9 `SLOWING`）のも、再訪が速くなって二乗の項が減るからと読める（読み・未検証）。
- 言えないこと: 課題ごとに二乗の項だけ、二乗の項が正、学習率への依存が η² だけ、の 3 つ（端点の項と勾配の軌道が課題と η に依存する）。

**Adam はこの保存則を一次で破る。** Adam の一歩 u = η m̂ ⊘ (√v̂ + ε) の一次の項 −2⟨W_l, u_l⟩ は座標ごとの割り算で重み付けが層ごとに変わるので、層どうしで結ばれない。1 座標あたりの歩幅がほぼ η に揃うので、座標の多い層に多く積む。W1 は全パラメータの 96.5%（307,200 / 318,410）で、収束後の伸びも W1 に集中する。SGD が余白を最終層で稼ぐ（S_hi の ‖W3‖² 267 対 F 5.5）のと対照的。

## 4. Issa の問いへの答え: なぜ Adam は W を伸ばし、なぜそれが害になるか

### 4.1 何が言えて何が言えていないか

| 主張 | 格 |
|---|---|
| この箱の後期の遅れは収束後の Adam が作る | 登録（Q1–Q5、Q7） |
| 害を運ぶのは重みで、Adam の状態ではない | 登録（交差 fork） |
| 正しく分類された画像の勾配は、どの層も同じ量だけ外向き | 恒等式（既知）。バイアスが小さいときの符号。SGD 腕で 1% 以内に確認 |
| SGD では W1 は一次の項で伸びない。最終層とバイアスが有界なら、長期の平均で二乗の項だけ | 恒等式の帰結（Codex 検算済み）。全部 SGD の 2 腕と整合 |
| 収束後の Adam の更新は毎回外向き | 実測のみ（quiet_drift: 負の更新 0%、cos(−u, W1) 0.04）。符号の導出はない |
| Adam の歩幅は勾配が消えても縮まない | 近似モデル（§4.3）＋実測 |
| 暴発の 1 座標 3.16η | Adam の算術（条件付き）。実測 ‖u‖² 3.07 と一致 |
| 課題あたりの正味が正で、ほぼ一定（‖W1‖² ∝ t） | **未導出** |
| W1 が大きいと次の課題が遅くなる理由 | **未同定**（相関のみ、§4.6） |
| 最初から SGD でも遅くなる理由 | **未同定** |

Codex の監査（[[V11中心主張_沈下機構を主軸にした改稿案_0923]] §10）の「交差エントロピーに有限の最小点がなく Adam の更新ノルムが一定に近くても、それだけでは外向き成長は導けない」は正しい。外向きの符号には §3 の恒等式と「割り算とモーメンタムが符号を反転させない」ことが要る。後者は実測だけで、cos(G, G/√v̂) = 0.988 は保証にならない（小さい動径成分は小さな回転でも反転しうる。Codex）。

### 4.2 外向き: 当てはめた後の勾配は余白を広げる向き

交差エントロピーには有限の最小点がない。全部の画像を正しく分類した後も、余白を広げれば損失は下がり続ける。§3 の恒等式はこれを層ごとに言い直したもので、各層の重みを外へ伸ばす向きの成分が、どの層にも同じ量 M だけある。M は余白が広がるほど指数的に小さくなる（p_k ≈ e^{−余白}）。

### 4.3 止まらない: Adam の割り算は勾配と一緒に縮む

- **SGD**: 一歩は勾配に比例する。勾配 ∝ 損失とすると dL/dt = −ηc²L² で、L ∝ 1/t。25,000 更新で 0.9〜3.4 e-fold しか下がらず、動きは自然に止まる。
- **Adam**: 分母 √v̂ は過去の勾配の二乗の記憶で、当てはめの後は新しい勾配が小さいので、記憶が β₂ で減るだけになる。勾配と分母が同じ速さで縮むので、比 m̂/√v̂ と一歩の大きさは一定に保たれる。近似モデル（バイアス補正が飽和、ε が無視でき、モーメンタムが勾配に追従、分母を 1 つの減衰で代表、‖G‖ = cL の c が一定）では L ∝ e^{−λt}、λ = −½ ln β₂、1/λ = **1,999 更新**、‖u‖ → λ/c で一定。実測は √v̂ の時定数 1,999〜2,002、損失 1,785〜2,002、1 課題で最大約 12.4 e-fold。
  - Codex の注: 新しい勾配の二乗を永久に無視するのは自己整合的でない（t β₂^t 型の補正が入る）。これは有限期間の近似。
- **ε 域**: √v̂ が ε = 1e−8 を下回ると割り算が切れ、u ≈ (η/ε) m̂ = 10⁵ m̂ になる。これはモーメンタムの EMA に学習率 10⁵ を掛けた更新で、SGD 腕の 0.001〜0.03 より 6.5〜8 桁大きい（課題 1 の静穏期の 1 座標 0.0022η はこの域。[[RL-CIFAR第1層の漏れ検査_Adamの三つの歩幅_事後_0922]] §5.1）。
- 1 更新あたりの伸びは 2‖W1‖‖u‖cos(−u, W1)。cos は 0.04 と小さいが、‖W1‖ が大きく ‖u‖ が縮まないので、1 更新あたり約 +0.1 が 2 万更新以上続く（quiet_drift の IID 新ラベルで 0.114/更新）。これが収束後の +2,634/課題の大部分で、残りは §4.4 の暴発。

### 4.4 暴発: 1 座標 3.16η は Adam の算術

記憶 m, v が十分に減った後に勾配 g が来ると、m = (1−β₁)g、v = (1−β₂)g² なので、|u| = η(1−β₁)/√(1−β₂) = 0.1/0.0316 η = **3.16η** が g ≠ 0 のすべての座標に出る。g の大きさによらない（√(1−β₂)|g| ≫ ε のとき）。W1 では ‖u‖² = 307,200 × (3.16×10⁻³)² = **3.07** で、課題後半の暴発と切替直後の 1 歩目の実測値そのもの（[[RL-CIFAR第1層の漏れ検査_Adamの三つの歩幅_事後_0922]] §5.1、§5.3）。条件は座標ごとに |β₁ m_old| ≪ (1−β₁)|g| と β₂ v_old ≪ (1−β₂)g²（Codex）。optimizer の最初の一歩はバイアス補正で約 η に抑えられるので別物。

### 4.5 戻りと正味（押しと戻りの収支）

- 切替で新しいラベルが来ると、大半の画像が誤分類になる。M が負になれば勾配は内向き（戻り）。次の課題の最初の 300 更新で ‖W1‖² は A −1,322、A_ce −617、F −437、S_hi −101、SA_iid −22 変わる。
- ただし「誤分類なら M < 0」も「切替後の Adam の一歩が内向き」も、恒等式からは保証されない（Codex）。
- 収支の実測（A、t26–50）: 押し（収束後）+2,634、戻り（衝撃＋当てはめ）−1,265、正味 +1,447/課題。**なぜ戻りが押しの半分程度で止まり、正味がほぼ一定になるかは導けていない。** 候補は、静穏 drift と切替の侵食がともに ∝‖W‖ で打ち消し、一撃と当てはめの残りが残る、という相殺の仮説（[[RL-CIFAR第1層の漏れ検査_Adamの三つの歩幅_事後_0922]] §5.3、1 seed）。
- SGD では同じ問いに §3 で答えられる。一次の外向きは 3 層で共有され、最終層は課題ごとに書き直されるので、W1 には残らない。

### 4.6 害: 大きい W1 がなぜ遅いか（未同定、相関のみ）

- 登録で言えるのは「収束後の長い尾で積んだ重みが次の課題を遅くする」まで（A_ce・交差 fork）。
- 事後の相関（`posthoc_speed_state.py`）: A の中で、前課題末の ‖W1‖ は 62 → 261、余白の中央値は 10.2 → 15.7、次の課題の hit999 は 2,000 → 4,000 と一緒に上がる（両対数の傾き ‖W1‖ 0.69、r 0.81。余白 1.22、r 0.70）。交絡していて分けられない。
