## 1. Landing A の 3 判定基準の達成

第 18 回終了時に、audit-survivor-eta-dependency-0914 の §9-4 から抽出した 5 点値 $\bar z_{\rm width}(\eta)$（peak $\eta=0.0002$・値 7.37）を目標とし、駆動源 5 項式（audit-v1b-intra-task-drift-of-sunk-units-0909）から予言する着地点 A を設定していました。3 つの判定基準:

1. Peak position: $\eta \in [0.0002, 0.0005]$
2. Peak value: $\approx 7.37$
3. Spearman($\bar z_{\rm width}$, $\alpha_{\rm ref}$): $\geq +0.9$

第 19 回・後半で、以下の Model M4 の Monte Carlo 実装 v3i_joint が **3 判定基準すべて達成**しました。Hold-out（訓練 seed 0-4 で遷移カーネル・kon Markov 遷移行列を抽出、テスト seed 5-9 で初期状態）でも Spearman +1.000 で頑健。

| 基準            | 目標                 | v3i_joint       | 誤差    |
| ------------- | ------------------ | --------------- | ----- |
| Peak position | $[0.0002, 0.0005]$ | $\eta = 0.0002$ | ✓     |
| Peak value    | 7.37               | 7.253           | -1.6% |
| Spearman      | $\geq +0.9$        | +0.900          | ✓     |

副産物（$\overline{n_{\rm eff}}_{\rm pop}$、$N_{\rm alive}$）の予言精度も 89-102% で一致。

## 2. Model M4 の骨格

**中心命題**: 箱 A の LoP は状態変数 $(\bar z, k_{\rm on})$ の joint distribution の**離散時間 Markov process** として記述できる（$\bar z \in \mathbb R$ 連続、$k_{\rm on} \in \{0, 1, \ldots, 32\}$ 離散）。500 タスクの範囲では $\|w_i\|$ がほぼ不変（±1% 以内）で、$d_{\rm proxy} = \bar z/\|w\|$ の有界性が観察される。

$$P_{n+1}(\bar z, k_{\rm on}) = \sum_{k'} \int P_n(\bar z', k') \cdot p(\bar z, k_{\rm on} | \bar z', k'; \eta) \, d\bar z'$$

- **kon=0 branch**（stayer）: 5 項式 $\Delta \bar z = T_0 + \kappa(\eta)(-\bar z) - c(\eta) v^2 n_{\rm band}$ が per-event で R² > 0.9 で成立（V-d）→ **理論駆動可能**
- **alive branch (kon≥1)**: 5 項式は per-event R² 0.06-0.63 で不十分（V-d）→ **経験サンプリング**（$(k_{\rm on\_pre}, \bar z_{\rm pre-bin}) \to (\Delta \bar z, k_{\rm on\_next})$ の joint 分布）
- **重要な工夫**: $\Delta \bar z$ と $k_{\rm on\_next}$ を joint に sample することが本質（独立サンプリングは同じ state 遷移の効果を Δz̄ 側と kon 遷移側の両方に計上して二重計上となる、というのが最も可能性の高い診断で、実際に独立サンプリングで実装した v3g/v3h は Landing A 判定基準を達成できなかった）

**Model M4 と v3i_joint の区別**: Model M4 は上の離散時間 Markov process の理論的枠組み、v3i_joint はその一つの Monte Carlo 実装。alive branch の閉形式化は今後の課題。

## 3. V10 §0 第三文の箱 A での量的側面

V10 草案 §0 第三文（「輸送の座標は『$\rho \to 1$ かつ $\sigma \to \infty$』」）の $\bar z$ 側の有界性について、中塚くん側で箱 B（RL・ELU→ELU）で $|d| \leq 3.5$（400 タスク・[[固定尺度仮説の段階0_標準化深さと明度チャネル_事後_0916]]）を報告されていました。

**箱 A での独立確認**（走ゼロ・500 タスク × 10 seed × 100 unit の re-analysis）:

- $\|d_{\rm proxy}\|_{\max} = 2.45$（$d_{\rm proxy} = \bar z/\|w\|$）
- alive 群 $\|d_{\rm proxy}\|_{p99} \leq 1.30$（$\eta=0.000156$）→ 1.00（$\eta=0.0025$）
- 時間発展はほぼ平坦（W1: 1.64 → W5: 1.73、+5-8%）

数値順序としては箱 A の 2.45 < 箱 B の 3.5 だが、**箱・条件（RL vs SL、活性化型、タスク数）が異なるため直接比較の意義は限定的**。両者が共に V10 §0 第三文の $\bar z$ 側の有界性の量的支持となる、という位置づけが妥当と考えています。

**限定条件**: $\sigma_i$ の proxy として $\|w_i\|$ を使用。真の $\sigma_i^2 = w_i^\top \Sigma_{XX} w_i$ の測定は、5M checkpoint から $\Sigma_{XX}$ を復元して走ゼロで検証可能（未実施の残件）。

## 4. $\|w_i\|$ の時間発展の観察

- $\|w_i\|$ 中央値が 500 タスクで ±1% 以内の変動、実質不動
- alive 群 $\|w_i\|$ 中央値は W1: 4.9 → W5: 4.6（-6%）
- N_alive は劇的に減少（$\eta=0.001$ で 500 タスクで -75%）

**観察としての結論**: $\|w_i\|$ 不変性と N_alive 減少が両立している。

**仮説（要検証）**: $\sigma_i \propto \|w_i\|$ の proxy 関係を仮定すると、V10 §1 の「W 増大 → $\sigma \to \infty$」経路は箱 A では駆動されていない可能性がある。**駆動源が $w_i$ 方向変化である**という仮説を立てていますが、直接測定は未実施です（$w_i$ の方向変化の直接測定は 5M checkpoint 事後解析で可能）。

**箱 B の中塚くん観察との対比**: 中塚くんは V9 で Adam・PMNIST の箱 B で $\|\tilde W_1\| \sim \sqrt t$ を観察されており、我々の箱 A（SGD・CondA・leaky）で $\|w\|$ 不変性が確認されたことは、Adam vs SGD の縮小条件の違い（audit-v1b §5-2）を反映している可能性があります。

## 5. V10 §1.4a との対応（箱 A 版）

中塚くんが V10 §1.4a に置いた「機能的 LoP = 応答を残す (ユニット, 入力) が実効的に尽き、かつ輸送が続いてそこから戻れない状態」の $n_{\rm eff}$ を箱 A に当てはめると:

$$n_{\rm eff}(i) := \sum_{r=1}^{32} \varphi'(z_{i,r}) = 0.97 k_{\rm on,i} + 0.96$$

（leaky slope $a = 0.03$・支持点数 32）

**下限**: $k_{\rm on} = 0$ で $n_{\rm eff} = 32 \times 0.03 = 0.96$、上限は $k_{\rm on} = 32$ で $n_{\rm eff} = 32$。**微分の厳密な 0 は箱 A では起きない**（leaky が保証）。

**V-c の観察と中塚くん側の +0.89 順位相関の位置関係**: 我々の V-c は $\eta$ スキャン内（活性化型固定）での Spearman($\overline{n_{\rm eff}}_{\rm pop}$, $\alpha_{\rm ref}$) = +0.700 を観察しました（peak $\eta=0.0002$ を捉えない・$\eta$ 単調）。一方 [[機能的応答を他の箱で予測に使う_結果_0917]] で報告された +0.89 は 26 腕横断（活性化型の違いをまたぐ）の相関です。**両者は同じ $n_{\rm eff}$ の異なるスケールでの測定で（$\eta$ スキャン内 vs 活性化型の違いをまたぐ）、直接比較（V-c の +0.7 vs 26 腕横断の +0.89）はカテゴリカルに不適切**と理解しています。

## 6. 5 項式の valid 領域の確定

audit-v1b の 5 項式は状態固定 SGD の linear response で、per-task drift として使えるのは 1 タスク内で $k_{\rm on}$ が変化しない **kon=0 群のみ**であることが確定しました（V-d の per-event R² 検証）:

| $\eta$   | kon=0 R²  | kon=1 R² | kon=2 R² | kon=3-5 R² | kon≥6 R²  |
| -------- | --------- | -------- | -------- | ---------- | --------- |
| 0.000156 | **0.974** | 0.598    | 0.512    | 0.618      | 0.632     |
| 0.0002   | **0.971** | 0.552    | 0.511    | 0.496      | 0.572     |
| 0.0005   | **0.947** | 0.403    | 0.347    | 0.428      | 0.371     |
| 0.001    | **0.943** | 0.362    | 0.270    | 0.175      | 0.202     |
| 0.0025   | **0.919** | 0.198    | 0.237    | 0.155      | **0.057** |

alive 群での R² 低下は、1 タスク内で $k_{\rm on}$ が変化する crosser 群の per-task drift を状態固定 linear response では捉えきれないためと解釈しています。**alive 群の per-task drift の理論的閉形式化**が最重要の残件です。

## 7. 中塚くんに確認・議論したい点

1. **$\|w_i\|$ 不動性の観察と V10 §1 の書き方**: 箱 A で $\|w_i\|$ 中央値が 500 タスクで ±1% 以内という観察（第 4 節）は、$\sigma_i \propto \|w_i\|$ を仮定すれば $\sigma_i$ 不動性を示唆します。V10 §1 の「W 増大 → 輸送」を、駆動源が箱依存（箱 A では $w_i$ 方向変化の仮説、箱 B では W ノルム成長）である可能性を含む形に書き直す提案は妥当でしょうか。それとも V10 §1 は活性化・箱をまたぐ抽象的な命題として、駆動源の詳細は §1.4a の functional LoP に委ねる形が良いでしょうか。

2. **V10 §1.4a の $n_{\rm eff}$ の箱 A 版**: 箱 A では $n_{\rm eff}(i) = 0.97 k_{\rm on,i} + 0.96$ で下限 0.96 の連続量（第 5 節）。箱 B の「厳密な 0 に達する」functional LoP との定量的な対応は「連続量 $n_{\rm eff}$ が閾値以下」で表現するのが良いのか、それとも別の指標（例: $\|d_{\rm proxy}\|$ の高さ）で functional LoP を検出するのか、方向性を議論したいです。

3. **駆動源 5 項式の LRoff0 → LRa0p03 スケーリングの残件**: [[2026-09-15_駆動源5項式audit-v1b詳細_先生から]] §3-8 の (D2) 式で $\kappa \propto \eta a^2$ とされていますが、我々の LRa0p03 での直測（第 19 回・後半・Step Q'）は、有意な測定が $\eta=0.0025$ の 1 点のみで、この 1 点だけでは $a^2$ scaling の再推定は不可能です。ただし $\eta=0.0025$ の点の実測 6.1e-4 は LRoff0 fit × $a^2=0.09$ の予想 1.1e-4 の 5.5 倍過大で、$a^2$ scaling の妥当性に疑問があります。他 4 点の有意な測定を得るには chain 数を更に増やす（例: 4500 chain）等の追加走行が要ります。この方向性の優先度について議論したいです。

4. **箱 A の Landing A 達成の V10 §5 証拠表への追加候補**: Model M4 で予言達成は、5 項式が箱 A の LoP の量的骨格を捉えていることの支持です。証拠表に「箱 A・SGD・leaky・per-event R² > 0.9 for kon=0 群」を登録する提案。alive 群の閉形式化は残件として明記します。

5. **箱 B ([[動く場の移植_応答低下からLoPへ_結果_0917]] の PARTIAL・媒介率 0.72) と箱 A の Model M4 の関係**: 中塚くんが respdyn_ee で「押し」を外から入れると媒介率 0.47 → 0.72 になった機構と、我々の Model M4 での alive branch の joint 遷移カーネルは、どちらも「継続する輸送」を扱いますが、直接的な対応は弱いと思います（我々の alive branch は経験モデルで、respdyn_ee は機構的な仮説）。両者の統合の方向性について議論したいです。

## 8. 補足

- 500 タスク range で $\eta=0.000156$ と $\eta=0.0002$ の $\bar z_{\rm width}$ は事実上 tie（W5 で差 0.24%）。$T > 1000$ で更にシフトするか、真の定常状態か未確定（Step U 実施済み、$T > 1000$ は残件）
- 副産物予言精度は 5 $\eta$ × 3 量 = 15 数値 で ratio 0.89-1.04
- 真の $\sigma$ 版（$\Sigma_{XX}$ 復元）と $\|w_i\|$ 不動性の理論的説明が主要な残件
- V-a〜V-d の詳細・Model M4 の理論的位置・v3i_joint の実装コードは Kubo 側 Vault に整理してあり、必要なら別途共有できます
