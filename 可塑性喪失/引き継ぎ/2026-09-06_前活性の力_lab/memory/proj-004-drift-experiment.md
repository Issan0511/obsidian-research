- **Snake の前活性分布 (0904 事後・未登録・snake_lr_diag_0903 の npz を gigafile 経由で受領・sha256 20/20 OK)**。φ′=1+sin(2αz) の零点は周期 π/α の櫛。**20 seed すべてで末尾窓の中央値が零点の位相 +0.042〜+0.113**（Rayleigh R=0.996/0.991、一様なら n=10 で ~0.32）。ただし山は 1 つで櫛の複数の歯には分かれない (広がり/周期 = 0.57 と 1.24)。位相が全部わずかに **+z 側**なのは、下向きドリフトに対して罠の手前側で釣り合うため。
- **Snake の実効ゲートは sinc 平均化で決まる (0904)**: `mob = 1 + sin(2αz̄)·sinc(αW)`、W = zmax−zmin（ユニット自身の支持の広がり）。α=1 で corr(mob, 予測)=0.937・中央絶対誤差 0.075（φ′(z̄) だと 0.248）。W/周期 が 0.5→1.5 で mob 中央値は 0.34→1.00 と単調に飽和し、1 周期を超えると **φ′ の周期平均 1** になる。したがって元の「代表勾配 0.25 対 0.74」は φ′(z̄) の読みで、実効ゲートは **0.63 対 1.00**、効いているのは across-unit の広がりではなく **within-unit の span W**。[[force-field-self-rest-decomposition-caution]] と同様、平均を取る順序を間違えないこと。

- **Snake は沈まない (0904 事後・未登録)**: 中央値は t≈20 以降定常 (t=50–500 の sd 0.02)、**|w| は縮む** (0.87 倍/0.72 倍。他 4 族は 2.5–5 倍成長)、residual ≈ 1e-12 (EXACT_FIT)。機構は測れた: (i) ラチェット無し — P(Δz̄<0)=0.499・E[Δ]≈0 (ReLU 族は沈む帯で 0.55–0.6)。(ii) **零点からの位相ごとの E[Δ|位相] が周期的な復元場** — 零点 (φ の棚) が安定平衡点、φ′ 最大点が不安定平衡点。α=1 で ±0.16/task、α=3 で ±0.05/task。零点交差は位相 +0.05 で観測された中央値 +0.07/+0.10 と一致。(iii) |Δ| は mob に追随 (α=1 で下位/上位 1/3 の E|Δ| = 0.20/0.46)。位相座標では φ′ = 1−cos2πφ で両 α が同じ形になる。図: snake_vs_0904.png / snake_field_0904.png / snake_dist_0904.png / snake_law_0904.png (scratchpad)。
- **SiLU/GELU の谷底 z_c が罠にならない理由 (0904 事後・valley_0904)**: 零点の周りのドリフト場 E[Δz̄|z̄] に**符号反転が無い** — z_c の上でも下でも負 (SiLU −0.10〜−0.19、GELU −0.05〜−0.47、早期窓 t≤60・ラグ 3 でも同じ)。Snake の零点は下側で正 (+0.18)・上側で負 (−0.16) と反転して安定点になる。谷の向こう (φ′<0) を 0 に固定した Gc_b1 でも場は負のまま (−0.03〜−0.07) で z_c 横断時刻は変わらず (G 5 / Gc 4)、深さだけ 11.1→7.4 と浅くなる = 既登録の valley_clamp_0902 判定 FLIGHT_CARRIES_OVERSHOOT と整合。構造的な違い: Snake は零点の向こうでゲートが**同じ形で再開**する (φ′=1−cos2πφ で対称) ので下側から押し戻される。SiLU/GELU は零点の向こうが 負→0⁻ の死域で押し戻しが存在せず、しかも押しは浅い側 (z>0 で −0.3〜−1.2/task) から来て深さとともに単調に弱まる = ラチェット。mob は SiLU で z_c 直下から負 (−0.04〜−0.08)、GELU も同様。
