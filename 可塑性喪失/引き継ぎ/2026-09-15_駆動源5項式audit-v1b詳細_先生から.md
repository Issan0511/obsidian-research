# Audit: intra-task drift of sunk units (V1b) — the term without a formula is a $v$-independent, depth-proportional drift plus crossing dynamics, not the first-order refit

**格: C**(走ゼロ・当方の再計算・verdict.csv なし)。数値はすべて当方計算(✓ は段 0 の検算を通ったもの)。

## 0. 一行

$k_{\rm on}$=0(全点負)のユニットの「式を持たない項」は、**一次 refit $T_1=-v_i\langle\zeta,m\odot\varphi'_i\rangle$ の群 N 版ではない**。**2 つの成分に割れ、どちらも (E1) から出る**(2026-09-09 の同日中に §3-7〜§3-10 で確定):
(a) 蹴りで折れ目を跨がないユニット(77.7%): **$v_i$ の符号にも大きさにも依らず、深さに比例する上向きの drift** $\Delta\bar z=\kappa(-\bar z_i)$、$\kappa=0.0119\ [0.0109,0.0129]$／タスク。担い手は**標本雑音の $v$–$\omega$ 結合**(full-batch で 0・$v$ 凍結で 0)。小 $\eta$ では連続時間の (D2)($\kappa=\bar m\eta a^2\mathbf 1^\top\Xi^{(2)}\mathbf 1$)、lr=0.01 では離散時間の 2 次モーメント漸化式(§3-9)で書け、梯子 4 点を 13–20% で再現。
(b) 蹴りで跨ぐユニット(22.3%): **ゲート付き一次 refit** $-v_i\langle\zeta,m\odot\varphi'_i\rangle$(決定論的・full-batch でも残る)が向きを 74% で当て、符号が半々なので「戻る(−0.26)／上がる(+0.47)」に分岐。大きさは線形応答の約 1/2(飽和・未定式化)。
群平均の「+0.064」は (a) が 2/3・(b) が 1/3。

## 3. 結果

### 3-1. (E1) の $v$ 比例構造は free 重みで確認できる
厳密 stayer(区間あたり中央値 55 ユニット・200 区間)で $\Delta w^{\rm free}_i=v_i\,u_n$($u_n$ は区間共通の 5 次元ベクトル)の $R^2$ **0.86** [0.70, 0.93]($v$ をシャッフルした対照 0.01)、rank-1 エネルギー 0.89、$\operatorname{sign}(v_i)$ を付けた余弦 0.98。**ゲートが定数のユニットの重み変化は $v_i\times$共通ベクトル**。ただし free 部の $\bar z$ への寄与は **+0.003**。

### 3-2. しかし 差′ は $v_i$ に比例しない
非跨ぎユニット(24,110)で 差′ の $v_i$ への回帰(原点通過)は区間中央値 $R^2$ 0.07(対照 0.01)、傾きの符号は半々。**$v>0$: +0.0605／$v<0$: +0.0637、$|v|<0.3$: +0.062／$|v|\ge0.7$: +0.065**——符号にも大きさにも依らない。

### 3-3. 深さに比例する
非跨ぎ・終点 $k_{\rm on}$=0(23,694)で 差′ を $\bar z$ で層別: $[-8,-6)$ +0.089／$[-6,-4)$ +0.056／$[-4,-3)$ +0.039／$[-3,-2)$ +0.035。原点通過回帰で **$\kappa=0.0119$**(区間 bootstrap 95% [0.0109, 0.0129]・区間別中央値 0.0086・正の区間 91%)。同じ深さ帯では $v$ の符号・大きさで変わらない($[-6,-4)$: $v>0$ 0.0115／$v<0$ 0.0124／$|v|<0.3$ 0.0122／$|v|>0.8$ 0.0114)。

**(D2) との比較**: 線形素子($\varphi=az$・$\varphi'=a$)に (D2) の力 $-\bar m\eta(\Xi^{(2)}\varphi)\cdot\varphi'$ を当てると $\Delta\bar z\approx\bar m\eta a^2\,\mathbf 1^\top\Xi^{(2)}\mathbf 1\,(-\bar z)$。audit §16-1 の $\operatorname{tr}\Xi^{(2)}=4.118$ で係数 **0.0042**($k_{\rm on}$=0 の +0.0186 を再現)。**構造($v$ 非依存・深さ比例・上向き)は一致し、大きさは実測が 2.8 倍。**

### 3-4. 跨ぐユニットは分岐する($k_{\rm on}$=0 の 22.3%)

### 3-5. 群平均の分解($k_{\rm on}$=0・差′ +0.0748)
$0.777\times0.062+0.223\times0.119=0.048+0.027$。**「式を持たない項」の 2/3 は非跨ぎの深さ比例 drift、1/3 は跨ぎの分岐の正味。**

### 3-6. 副産物
- **オフセット項の実現平均は ≈0**($k_{\rm on}$=0 で +0.008・全体 +0.007)。$g$ は $n_{\rm active}$ だけの関数で有界なので $\Delta g$ は望遠鏡和——**定常平均は厳密に 0**。audit §16-4 の「一律の下押し −0.015」は 5M 時点の状態条件付き期待値であって、多タスクの力ではない(台帳 A28)。
- **T5($w_{\rm flip}$ 5M 固定の誤差)**: 1M→5M の drift は要素あたりタスクあたり中央値 0.0006(90% 0.0015)→ ≤49 タスクで ≤0.03〜0.07。5M までの距離で 差′ が変わらない([0,5) タスク 0.045／[15,20) 0.032)ので主因ではない。
- 蹴りの実現平均が期待値(+0.061)より小さい(+0.034)理由は未分解(台帳 C13)。

### 3-7. (F1) の結果(2026-09-09・同日)——$\kappa$ は $\eta$ とともに落ちる($\eta^{1.3}$ 程度)

lr=0.00125 の腕(3 seed・5M と 40M の末尾 50 タスク・対応する checkpoint で段 0 を通した)で同じ回帰を行った。

比 $\kappa(\eta/8)/\kappa(\eta)$＝**0.058(5M)／0.070(40M)**。$\eta^1$ なら 0.125、$\eta^2$ なら 0.016。指数に直すと $\eta^{1.3}$ 前後。

**読み**: (i) $\eta$ 非依存の機構(比 ≈1)は**棄却**。(ii) 純 $\eta^2$ も合わない。(iii) (D2) 型($\propto\eta$)に、低学習率で効く**状態の違い**(タスク終端の残差 ≈0.1 が残る・$\Xi^{(2)}$ が別物・有限 $T$ フィルタ〔穴 5〕で遅い固有モードの寄与が落ちる)が重なった、と読むのが最も自然。**「$\eta$ 依存の力」と「$\eta$ に依存する状態」の分離(穴 6)をしないと 1/8 からのずれは説明できない。** 深さ比例と $v$ 非依存は低学習率でも保たれる(40M: $v>0$ と $v<0$ が +0.0044 で一致)。

**跨ぎの分岐は $\eta$ にほとんど依らない**: 分岐率 0.53–0.56 は不変、大きさは +0.28／−0.20(lr 0.01 の +0.45／−0.26 の 0.6–0.8 倍)——$\eta$ を 1/8 にしても 0.6 倍にしか落ちない。**跨ぎ後の力は (D2) 型ではない**(別の機構)。跨ぎ率そのものは 22%→6–8% に落ちる(蹴りの大きさと帯の分布の違い・未分解)。

### 3-8. (F4) の結果(2026-09-09・同日)——drift は標本雑音の $v$–$\omega$ 結合((D2) の rescaling 経路)で、連続時間 Lyapunov は小 $\eta$ 極限

**(A) $\Xi^{(2)}$ の実測(Lyapunov・両 checkpoint・10 seed×15 flip)**。当方の機械は audit §16-1 をほぼ再現する($\nu_S$ の次数平均 1000／112／22.5／12.4／13.7／20.2、$\bar m=10.2477$、$k_{\rm on}$=0 の (D2) +0.0171 対 audit +0.0186)。線形素子の係数 $\kappa_{\rm D2}=\bar m\eta a^2\,\mathbf 1^\top\Xi^{(2)}\mathbf 1$ は **0.0039**(実測 0.0119 の 1/3)。lr=0.00125 の checkpoint では無限 $T$ の Lyapunov が発散する flip がある($\mathcal K$ の小固有値)が、**有限 $T$ フィルタ** $\Theta_T=Q\bigl[D_{ab}\tfrac{1-e^{-(\lambda_a+\lambda_b)\eta T/16}}{\lambda_a+\lambda_b}\bigr]Q^\top$(穴 5)で健全化し、$\kappa_{\rm D2}(\eta/8)=$ **0.00068**——実測 0.00072 [0.00045, 0.00099] と一致。**食い違いは lr=0.01 側にだけある。**

**(B) checkpoint からの厳密 SGD 再走(当方の numpy 実装・10 seed×15 flip＝150 本・$T=10^4$)**。前向きモデルは `eval_loss_exact` を全桁再現(段 0)。非跨ぎ・終点 $k_{\rm on}$=0 で $\kappa$ を回帰:

| 変種(状態は 5M checkpoint で固定)          | $\kappa$                | 差′ 平均   | $v>0$／$v<0$     |
| ---------------------------------- | ----------------------- | ------- | --------------- |
| SGD $\eta$=0.01                    | **0.01193**             | +0.0510 | +0.0495／+0.0525 |
| full-batch GD $\eta$=0.01          | **0.00001**             | −0.0001 |                 |
| SGD $\eta$=0.01・**$v$ 凍結**         | **−0.0022**             | −0.0107 |                 |
| SGD $\eta$=0.00125・$T=10^4$        | 0.00058                 | +0.0023 |                 |
| SGD $\eta$=0.00125・$T=8\times10^4$ | 0.00060                 | +0.0024 |                 |
| SGD $\eta$=0.0025／0.005／0.0075     | 0.00123／0.00318／0.00640 |         |                 |

- **再走は実測 $\kappa$=0.0119 を再現**する(蹴りは厳密なので T5 は無関係と確定)。
- **full-batch で消える** → 標本雑音が担い手((D2) 型)。(D1) 型の決定論的な項ではない。
- **$v$ を凍結すると消える** → 機構は $\Delta v_i$ と $\Delta\omega_i$ の相関(雑音の $v$–$\omega$ 結合)。(E1) の 2 次の交差項 $(2\eta a)^2\sum_{t'<t}\delta_t\delta_{t'}z_{i,r_{t'}}m_{r_t}\approx(2\eta a)^2\bar z_i\sum_{t'<t}\delta_t\delta_{t'}m_{r_t}$ で、標本化が作る負の時間相関 $\mathbb E[\delta_t\delta_{t'}]<0$ が $-\bar z_i$ 方向(上向き)の drift を作る。$v$ に依らず深さに比例するのはこの形のため。
- **状態固定の $\eta$ 梯子**: $\kappa/\eta$ は 0.46($\eta$=0.00125・0.0025)→0.64→0.85→**1.19**($\eta$=0.01)。小 $\eta$ 極限の 0.46 は連続時間 (D2) の 0.39 と 2 割以内で一致。**lr=0.01 での 3 倍は $\eta$ の高次(離散時間)の効果**——定数モード $\nu_0\approx10^3$ は 1〜2 step で減衰するので、雑音を白色・連続時間で扱う Lyapunov が破れる(未導出・§4 (F5))。
- 腕間の比 0.058–0.070 のうち、状態固定で 0.049 が出る。**「$\eta$ 依存の力」が主で、「$\eta$ 依存の状態」は残り(0.01〜0.02 の差)**(穴 6 への答えの一部)。

### 3-9. (F5) の結果(2026-09-09・同日)——離散時間の 2 次モーメント漸化式が梯子を再現する

**理論**($\mathcal K$ 固定・線形化・全点負ユニット・(E1) の 2 次まで)。残差ベクトル $\delta(t)\in\mathbb R^{32}$ は 1 標本更新で $\delta\leftarrow(I-2\eta\mathcal KE_r)\delta$($E_r=e_re_r^\top$・$r$ 一様)。平均は $A=I-\tfrac{2\eta}{32}\mathcal K$ で進み、2 次モーメント $M(t)=\mathbb E[\delta\delta^\top]$ は
$$M\leftarrow M-\tfrac{2\eta}{32}(\mathcal KM+M\mathcal K)+\tfrac{4\eta^2}{32}\textstyle\sum_r\mathcal K_{:r}M_{rr}\mathcal K_{r:}$$
(第 3 項が標本化の雑音注入・$\eta^2$)。$t'<t$ の履歴で条件づけると
$$\mathbb E\bigl[\Delta\bar z_i^{(2)}\bigr]=\frac{(2\eta a)^2}{32^2}\sum_{t'}g(t')^\top\Bigl[M(t')\,z_i-2\eta\,\mathcal K\operatorname{diag}(z_i)\,\operatorname{diag}M(t')\Bigr],\qquad g(t')=\sum_{n<T-t'}A^n m$$
(第 1 項は $\mathbb E[\delta(t')\langle\delta(t'),z_i\rangle]$、第 2 項は $t'$ の標本点が後の残差に残す相関)。一次項は $-2\eta a\,v_i\tfrac1{32}\sum_tm^\top A^t\delta'$。連続時間の Lyapunov(§3-8 (A))は $\eta^2$ の注入項を白色雑音で置き、$\sum_{t'}$ を積分にした極限。

**結果**(5M checkpoint・10 seed×15 flip・非跨ぎ・終点 $k_{\rm on}$=0・再走と同じ mask):

| $\eta$      | 理論 $\kappa$(離散) | 再走 $\kappa$ | 連続 Lyapunov($\propto\eta$) | ユニット別 corr |
| ----------- | --------------- | ----------- | -------------------------- | ---------- |
| 0.00125     | 0.00046         | 0.00058     | 0.00049                    | 0.69       |
| 0.0025      | 0.00107         | 0.00123     | 0.00098                    | 0.65       |
| 0.005       | 0.00276         | 0.00318     | 0.00195                    | 0.60       |
| 0.01(130 本) | **0.0135**      | **0.0115**  | 0.0039                     | 0.46       |

- **梯子は再現**(理論は小 $\eta$ で 13–20% 低め、$\eta$=0.01 で 17% 高め)。連続 Lyapunov は $\eta$=0.005 で 1.6 倍、0.01 で 3 倍外れる。**lr=0.01 での 3 倍は、標本化の雑音注入項($\eta^2$)が有限ステップで増幅される離散時間の効果**で確定。
- **$\eta$=0.01 では 150 本中 20 本(seed 3・4・7 のすべて)で凍結 $\mathcal K$ の 2 次モーメント写像が不安定**(1 標本の更新因子 $1-2\eta\mathcal K_{rr}$ が $-1.8$ に達する)。実走の網は非線形で有界に留まり、それらの seed の $\kappa$ も 0.010–0.018 と大きく違わない。**lr=0.01 は 1 標本更新の安定限界の近くにある**($\eta$=0.02 では再走が発散)——これ自体が「$\eta$ 依存の力」の高次を作る。
- ユニット別の回帰傾き obs〜pred は 0.63 前後(理論が個体を 1.6 倍過大に出す)——$\kappa$(深さへの回帰)は合うが個体の分散は合っていない。原因は未分解($z_{i,r}$ をタスク内で固定・$\mathcal K$ 固定・3 次以上の無視)。

**非跨ぎ側の結論**: 「式を持たない項」の 2/3 は **標本雑音の $v$–$\omega$ 結合による深さ比例の上向き drift** で、小 $\eta$ では連続時間の (D2)($\kappa=\bar m\eta a^2\mathbf 1^\top\Xi^{(2)}\mathbf 1$)、lr=0.01 では上の離散時間漸化式で書ける。**第 7 版の 3 項式の「未定式化」のこの部分は式を得た。**

### 3-10. 跨ぎ側の分岐(2026-09-09・同日)——担い手はゲート付き一次 refit で、決定論的

再走の 150 本で、flip 前 $k_{\rm on}$=0・flip 直後 $k_{\rm on}\ge1$ のユニット(**1,948 個**・実測の跨ぎ率と整合)を追った。

| 変種(状態固定・5M)                 | 上がる率  | 差′｜上がる | 差′｜戻る  | 差′ 平均             |
| --------------------------- | ----- | ------ | ------ | ----------------- |
| SGD $\eta$=0.01             | 0.531 | +0.469 | −0.291 | +0.113(実測 +0.119) |
| full-batch GD               | 0.668 | +0.362 | −0.198 | +0.177            |
| SGD・$v$ 凍結                  | 0.510 | +0.551 | −0.324 | +0.123            |
| SGD $\eta$=0.00125・$T=10^4$ | 0.638 | +0.336 | −0.194 | +0.144            |

- **full-batch でも $v$ 凍結でも $\eta$/8 でも分岐は残る**——標本雑音でも $v$–$\omega$ 結合でもない、**決定論的な一次の効果**。
- **向きの予言**: ゲート付き一次 refit $\Delta\bar z^{(1)}_i=-v_i\langle\zeta,m\odot\varphi'_i\rangle$($\zeta=\mathcal F(\mathcal K)\delta'$・flip 直後の $\varphi'_i$ で評価)の**符号**が「上がる／戻る」を **74–75%** で当てる($P(\text{上がる}\mid\Delta^{(1)}>0)=0.78$〜$0.90$、$P(\text{上がる}\mid\Delta^{(1)}<0)=0.27$〜$0.44$)。跨いだ点の残差だけの $\operatorname{sign}(v_i\sum_{r\in{\rm on}}\delta'_r)$ でも 70%。着地点の高さ($z_{\max}\ge0.2$)は 59%。
- **大きさ**: corr(差′, $\Delta^{(1)}$)＝0.55–0.68、回帰傾き 0.42–0.48——**一次の線形応答は向きを当て、大きさは 2 倍過大**(上がるほど残差が埋まり $\mathcal K$ が変わる飽和。未定式化・(F7))。
- **機構**: 跨いだ点で $\varphi'=1$(他は $a=0.1$)なので、その点の残差 $\delta'_r$ に対する応答が 10 倍になる。$v_i\delta'_r<0$(自分の出力を増やすと残差が減る)なら折れ目より上へ引き上げられ(採用)、$>0$ なら押し戻される(廃棄)。**跨いだ直後の $\operatorname{sign}(v_i\delta'_{\rm on})$ はほぼ半々**(995／1,948)なので分岐が 1/2 になる。実測で「大きさが $|v|$ で増える」のは $-v_i\langle\zeta,\cdot\rangle$ の $v_i$ で、$v^2$ 型(井戸・押し)ではない(§3-4 の推測を訂正)。

**跨ぎ側の結論**: 跨いだユニットの「追加移動」は**一次 refit そのもの**(T1 の群 G 版)——$k_{\rm on}$=0 では定数極 $\xi_0\approx0$ で効かなかった同じ項が、ゲートが 1 になった点を通して効く。**式は既存($-v_i\langle\zeta,m\odot\varphi'_i\rangle$)で、足りないのは飽和(傾き 0.45)だけ。**

**「式を持たない項」の全体像($k_{\rm on}$=0 群・差′ +0.075)**: 非跨ぎ 78% × 深さ比例の雑音 drift(§3-9 の離散漸化式)＋ 跨ぎ 22% × ゲート付き一次 refit(符号半々・正味 +0.11)。**両方 (E1) から出る。**

### 3-12. C16——第 5 項(雑音のゲート経由)の定義・実測則・式(2026-09-09・同日)

**定義(介入で定める)**: $T_5:=\Delta\bar z(\text{SGD}\cdot v\text{ 凍結})-\Delta\bar z(\text{GD}\cdot v\text{ 凍結})$。$v$ を凍結して $v$–$\omega$ 結合(§3-8)を切り、full-batch との差で雑音だけを取り出す。**(E1) を「凍結ゲート／ゲート変化／$v$ 変化」に代数的に分けた量($A_1,A_2,A_3$・`sim2.py`)は経路依存で相殺が大きく、SGD と GD の差が雑音を表さない**($k$=1 で $\eta$ を下げると差が増える等)——介入で定めるのが正しい(負の結果)。

**実測則(5M 状態固定・10 seed×15 flip・flip 前 $k_{\rm on}$ で群分け)**

| ------------------- | ----- | ------------------ | ------ | ------- | ---------------- |
| 0                   | 9,405 | −0.021             | −0.011 | −0.0005 | 1.8              |
| 1                   | 2,475 | −0.066             | −0.026 | −0.005  | 1.2              |

- **群 G では $T_5\propto\eta^1$**($\eta$/2 で 0.48 倍)。§3-11 の「lr/8 で 0.46 倍」は 2 つの雑音経路と決定論の混合を見ていた。
- **符号は下向きで $v$ の符号に依らない**($v>0$: −0.121／$v<0$: −0.116)。**$\propto v^2$**($v^2$ の帯で $T_5/v^2$ が −0.18〜−0.32 でほぼ一定)。**折れ目の近傍 $|z_{i,r}|<0.3$ にある支持点数 $n_{\rm band}$ に比例**($T_5/(v^2n_{\rm band})$ が −0.09〜−0.13 でほぼ一定)。原点通過で
$$T_5\approx-c\,v_i^2\,n_{{\rm band},i},\qquad c\approx0.09\text{–}0.13\ /\text{タスク}\ (\eta=0.01),\ c\propto\eta .$$
個体では散らばりが大きい($R^2$ 0.08)——帯ごとの平均で見た法則。

**式(線形化・ガウス近似・導出)**: $v$ 凍結の (E1) で $\varphi'=a+(1-a)\mathbf 1[z_r>0]$ と書くと、雑音の寄与は残差と指示関数の共分散
$$T_5=-2\eta(1-a)\,v_i\sum_t\sum_r\frac{m_r}{32}\,\operatorname{Cov}\bigl(\delta_r(t),\mathbf 1[z_{i,r}(t)>0]\bigr)\approx-2\eta(1-a)\,v_i\sum_t\sum_r\frac{m_r}{32}\,\rho_{i,r}(t)\,\operatorname{Cov}\bigl(\delta_r(t),z_{i,r}(t)\bigr),$$
$\rho_{i,r}(t)$ は $z_{i,r}(t)$ の 0 での密度。共分散は過去の同じ標本 $u$ が両方を動かすことから
$$\operatorname{Cov}\bigl(\delta_r(t),z_{i,r}(t)\bigr)=4\eta^2v_i\sum_{u<t}\frac1{32}\sum_{r'}M_{r'r'}(u)\,\mathcal K_{rr'}\,\varphi'_{i,r'}\,G_{r'r}$$
($M$ は §3-9 の 2 次モーメント・$G_{rs}=\tilde x_r\cdot\tilde x_s$)。よって
$$\boxed{\;T_5\approx-8\eta^3(1-a)\,v_i^2\sum_t\sum_r\frac{m_r}{32}\rho_{i,r}(t)\sum_{u<t}\frac1{32}\sum_{r'}M_{r'r'}(u)\mathcal K_{rr'}\varphi'_{i,r'}G_{r'r}\;}$$
- **符号**: $v_i^2(1-a)\times$(正定)$\times M\ge0$ → 下向き ✓。$v$ の符号に依らない ✓。$\propto v_i^2$ ✓。折れ目に近い点($\rho\ne0$)だけが効く ✓。
- **$\eta$ 依存**: $\eta^3\times\sum_uM\ (\propto1/\eta)\times\sum_t\rho\ (\propto$ 過渡の長さ $1/\eta)$ $=\eta^1$ ✓——ただし**帯の幅($\rho$ の幅)が雑音の広がり($\propto\eta$)でなく、決定論的な refit の振れ($\eta$ に依らず $O(0.3)$)で決まる**ことが条件。実測の $n_{\rm band}$($|z|<0.3$)比例と整合。
- これは 先生 Vault の [[kink-and-push-are-different-orders-not-the-same-term]] の角検出項(非対称核 $\mathcal A$・帯 $|\zeta|<\Lambda$)を、蹴り $\Lambda$ でなく「過渡中の残差雑音」で駆動したもの。$\varphi''$ を使わないので leaky でも書ける。
- **数値照合は未実施**: $\rho_{i,r}(t)$ に各点の平均場軌道 $\bar z_{i,r}(t)$(GD の点別軌道)が要る。当方の再走では支持平均しか保存していない。

### 3-13. (F8′) 第 5 項の式の数値照合(2026-09-09・同日)——小 $\eta$ 極限で合い、$\eta$=0.01 では 3 倍過大(ゲート応答の飽和)

§3-12 の式を実装した(`gdtraj.py`・`f8.py`)。$M(u)$ は §3-9 の離散漸化式、残差側の相関は $A^{t-u-1}$ で伝播(§3-12 の式の $\mathcal K_{rr'}$ を $[A^{t-u-1}\mathcal K]_{rr'}$ に直したもの——旧稿は減衰を落としていた)、$\rho_{i,r}(t)$ は GD($v$ 凍結)の点別軌道を平均、$z$ 側の独立標本の永久的な蹴りの分散 $\sigma^2_{i,r}(t)=4\eta^2v_i^2\sum_{u<t}\tfrac1{32}\sum_{r'}M_{r'r'}(u)\varphi'^2_{i,r'}G^2_{r'r}$ を幅とするガウス。再走の $T_5$(SGD·$v$ 凍結 − GD·$v$ 凍結)と比べた。

| $\eta$(seed 数) | flip 前 $k_{\rm on}$=1         | 2                   | 3–5                     | ≥6                      | 備考                        |
| -------------- | ----------------------------- | ------------------- | ----------------------- | ----------------------- | ------------------------- |
| 0.01(2)        | 理論 −0.167／再走 −0.072(**2.3×**) | −0.284／−0.086(3.3×) | −0.538／−0.188(2.9×)     | −0.734／−0.232(3.2×)     | $\sigma_z$ 0.5–1.6(帯より広い) |

- **小 $\eta$ 極限で式は当たる**($\eta$=0.00125・$k\ge3$ で 1.1–1.4 倍。seed 1 本なので $k$=1・2 は再走側の統計が足りない)。**$\eta$ を上げると理論が系統的に過大**(0.005 で 1.5–1.9 倍、0.01 で 2.3–3.3 倍)。
- 過大の出所は **ゲート応答の飽和**: 式は $\operatorname{Cov}(\delta_r,\mathbf 1[z_r>0])\approx\rho\,\operatorname{Cov}(\delta_r,z_r)$ という小雑音展開で、雑音の広がり $\sigma_z$ が帯($O(0.3)$)を超える $\eta$=0.01 では指示関数の応答が飽和して線形化が破れる($\sigma_z$ の列を参照)。§3-9 の $v$–$\omega$ 項では $M$ 側(雑音の生成)の離散補正で足りたが、ここでは応答側(折れ目を越える回数)の非線形が要る。
- 帯を固定幅($|z|<0.3$・一様密度)に置き換えると過大が増す(4–6 倍)ので、ガウス密度のほうが良い。
- ユニット個体の相関は 0.05–0.33 と弱い——式は群平均のためのもの。
- $\eta$ 依存は式の上で $\eta^1$ で、再走の指数(0.9–1.2)と整合するが、$\eta$=0.01 の飽和により実効指数が 1 より小さく見える方向(§3-11 の 0.46 の一部)。

**C16 の状態**: 第 5 項の式は**小 $\eta$ 極限として確定**(角検出項の雑音版・線形化ガウス)。lr=0.01 で使うには指示関数の応答の飽和(折れ目を越える確率の非線形)を入れる必要がある——(F10) として登録。
