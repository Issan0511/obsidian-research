## 4. 次の切り分け案（未登録・未実施）

ユーザーに提案済み。**この案の結果はまだ存在しない**。

### A. 画像の抽選とモデル状態の変化を分離

元の学習軌道を同じバッチ・乱数・Adam 状態で再生する。各時点で同じ画像・ラベルの診断用集合にも勾配を計算する。診断用計算ではパラメータ・Adam・SnakeのEMA/alphaを更新しない。

現ログの「現在勾配」は毎回別の学習ミニバッチなので、同じ診断集合でも反転するかを先に確認する。勾配を生成する集合と、Δzbar を評価する固定 probe は明示して区別する。診断集合は複数の固定バッチに分けて頑健性を確認する案。

比較:
1. 現在 CE × 実際の Adam 倍率
2. 現在 CE × 切替直後に固定した座標倍率
3. 素の CE 勾配を同じ平均前活性方向に射影（SGD方向）

これは Adam を替えて再学習する試験ではなく、まず同一軌道上の診断。

### B. 上押しの消失と下押しの増大を区別

同じ平均前活性への射影を、**勾配生成側の標本×第1層ユニット**まで加法的に分解して、上向き総量 U と下向き絶対総量 D を記録する。正味は U−D。

上押し U だけ減る / 下押し D だけ増える / 両方変わる、を分ける。「下向きの力が生まれた」と先に仮定しない。

さらに切替直後の z の正負で標本×ユニットの分類を固定し、どちらの群の寄与が変わったかを見る。現在時点の正負分類も副測定する。受け手側の固定正負マスクと混同しない。

### C. 勾配の四要素を前後で交換

各標本の平均化前 CE について:
\[
\partial\ell/\partial z_i
= g_i \sum_k J_{ki} r_k,\quad
g_i=\varphi'(z_i),\quad
J_{ki}=\partial\mathrm{logit}_k/\partial a_i,\quad
r_k=p_k-y_k.
\]

入力・評価 probe を固定し、以下を反転前/後の保存値で交換する:
1. 出力誤差 r
2. 下流ヤコビアン J
3. 第1層の傾き g
4. Adam の座標ごとの倍率 D

全16組を再計算し、単独交換だけでなく相互作用を見る。J が効けば、次に下流重みと第2層ゲートへ分ける。Snake の g/J には状態に依存する alpha の変化が含まれるため、必要なら z と alpha をさらに分離する。

Adam 分母は現在の勾配でも更新される。交換時は**観測済みの分母を独立の固定因子として扱う**。交換後の仮想勾配で分母を再計算した場合は別実験である。正のスカラーである bias correction は符号反転の原因にはならないが、量の比較では定義を統一する。

交換した組合せは実在するネットワーク状態とは限らない。これは勾配の代数的な寄与分解で、因果的な必要性の証明ではない。候補を絞った後、同じ checkpoint からの短い介入で確認する。

### D. 検証したい具体的な仮説

「早くフィットした標本・経路の勾配が先に消え、残る勾配が下向きに偏る」。

誤差が全標本・全クラスで一様な正の倍率で縮むだけなら、J/g/D固定下の射影の符号は変わらない。どの誤差が先に減るか、またはJ/g/Dとの対応関係の変化が必要。

優先対象は素 LR の task21..40。SNA は比較対象。測定時点・前後の対・反転の判定・seed集約・計算量は次の spec で先に決める。窓平均の符号だけを根拠に、都合のよい境界や更新を事後選択しない。必要なら20更新以降の測定点も事前指定する。

## 6. モデル条件と「現在CE」の正確な定義

- Permuted MNIST、784→100→100→10、CE。
- 入力は画素/255で非負。各タスクで全784座標を置換。
- タスク当たり10,000標本、batch16、**625 optimizer updates**。
- Adam lr=.001、β1=.9、β2=.999、eps=1e−8。タスクを跨いで状態を維持。
- LR は leaky a=.1。
- SNA は固定alphaの一般的Snakeではなく、alpha=.6/sqrt(EMA variance)、EMA β=.01、clamp .05..3 の適応型。パラメータ更新後、更新前batchのzで act.update。再生時に順序を維持。
- l2 は全W/bに `g += 2*.001*parameter` を入れる**coupled L2**。AdamWではない。
- 固定 probe は seedごとの test512標本、同じタスク内で同じ置換。
- `star_i = global_train_pixel_mean * W1[i].sum() + b1[i]`。全画素ランダム置換の平均に対応する設定点。現タスクのprobe平均とは違う。

実装上の第1層パラメータごとの現在 CE 寄与:
\[
\Delta\theta_{\rm currentCE}
= -\frac{\eta}{1-\beta_1^t}
\frac{(1-\beta_1)g_{\rm CE,t}}
{\sqrt{v_t/(1-\beta_2^t)}+\epsilon}.
\]
history は同じ係数に β1 m_(t−1) を掛けたもの。currentL2 も同様。

**過去の一次モーメントを分離した量であって、Adam非依存の生勾配ではない。** 分母v_tには現在勾配と履歴、l2腕ではL2も影響する。

平均前活性への射影:
\[
\Delta\bar z_i = \Delta W_i\cdot\mu_{\rm probe}+\Delta b_i.
\]
star の射影では mu_probe を全座標同一の global_train_pixel_mean に替える。

局所方向は −B*dL/dz（B=16）。own は同じ標本が共有W/bを動かす寄与、others は他のbatch標本の寄与である。**scalar MSEの v²φφ′「自己項」と own を同一視しない。**

## 7. 運用・避けるべき誤読

- タスク番号と更新番号を毎回書く。最初の20更新が終端の下降を代表するとは限らない。
- 切替の入力支持変更、学習内の移動、タスク終端間の累積を分ける。
- 正負入力源、正負の受け手、平均が正負のユニットを分ける。
- 局所 dL/dz の方向から実Δzや分散を推測しない。共有パラメータとAdamを通した量を測る。
- 同じ母集団での比較をする。training batchとfixed probeの条件付き平均を直接比較しない。
- median(A)+median(B)≠median(A+B)。加法恒等式はraw/境界単位で検算する。
- 「実際に下降したユニット更新」の条件付き寄与率と集団全体の正味は違う。
- 後期task101..119を「釣り合い後」「平衡」と断定しない。
