## 5 peer の SGD 橋と Adam 考察

### 5-1. SGD 橋(`1cc2f0e`・箱 B・PMNIST・α=0.6 の 5 腕)

- 層 1: peak−normal は Adam +0.118 → SGD +0.035
- 層 2: SGD −0.204(`SIGN_REVERSED`)
- **5 腕・両層で strict 縮小 0%**(`FORK_ABSENT`)
- valley V06 は SGD で `BROKEN` 7/10

### 5-2. Adam 考察(`b017db8`・事後・未登録)

**縮小条件の二項収支**:
$$\Delta \|u\|^2 = \|\Delta u\|^2 + 2\langle u, \Delta u\rangle < 0 \iff \|\Delta u\| < 2\|u\| \cos(\Delta u, -u)$$

- **SGD**: $\|\Delta u\|^2 = \eta^2 \|g\|^2$——静かな局面で自己整合的に縮小
- **Adam**: $\|\Delta u\|^2 = \eta^2 \sum_j r_j^2$($|r_j| \le 1$)——ノルムに硬い下限

**peer 主張**: 「Adam は縮小の終端(崩壊)を消し、途中の穏やかな縮小を消すのは箱の側」

## 6 (U4): 勾配からの導出

### 6-1. peer の勾配一般式(`0ba13e8`)

$$g_{u_i} = P \mathbb E[\varphi'(z_i) e_i x], \quad \langle u_i, g_{u_i}\rangle = \mathbb E[\varphi'(z_i) e_i (u_i^\top x)]$$

### 6-2. SGD の縮小条件と統合

$$\eta \|g_{u_i}\|^2 < 2 \mathbb E[\varphi'(z_i) e_i (u_i^\top x)]$$

### 6-3. 帯別閾値

- **折れ目近く**($\varphi' \approx 1$): $\eta_{\rm near}^{\rm crit} \sim 10^{-3}$
- **深部**($\varphi' \approx 0.03$): $\eta_{\rm deep}^{\rm crit} \sim 33\, \eta_{\rm near}^{\rm crit} \sim 3 \times 10^{-5}$

**深部の縮小閾値は近くの 33 倍**。

### 6-4. $\alpha(\eta)$ ピーク型の予言

3 レジーム:
- $\eta > \eta_{\rm near}^{\rm crit}$: 両方縮小 → 深部支配 → $\alpha < 0$
- $\eta_{\rm near}^{\rm crit} > \eta > \eta_{\rm deep}^{\rm crit}$: 二極化 → $\alpha > 0$ ピーク
- $\eta < \eta_{\rm deep}^{\rm crit}$: 両方成長 → $\alpha$ 左肩

**実測ピーク $\eta \in [0.0002, 0.0005]$ が予言帯 $[3 \times 10^{-5}, 10^{-3}]$ の間に入り桁で整合**。

### 6-5. Adam との対比予言

Adam で $\|\Delta u\|^2 = \eta^2 \sum_j r_j^2$ に $\varphi'$ が入らない → 帯依存が消える → **$\alpha(\eta)$ ピーク型は SGD 固有**。

**CondA×Adam 鏡像実験の予言**:
- (i) $\alpha(\eta)$ 変動幅 2.147 → **0.7 以下**
- (ii) 頂点位置が消えるか $\eta$ 大側にシフト
- (iii) $\bar z_{\rm width}$ の $\rho$ が +1.000 → **≤ 0.7**

## 7 (v2 新設) 動的機構の根源——駆動源の 5 項式

### 7-1. 出発点: 恒等式(第 7 回・先生 Vault の [[audit-v1b-intra-task-drift-of-sunk-units-0909]])

batch 1 SGD で $\bar z_i$ の 1 タスクの変位は **厳密に**:

$$\boxed{\Delta \bar z_i^{\rm task} = -2\eta \sum_{t=1}^{T} \delta_t\, v_i(t)\, \varphi'_i(z_{i,r_t}(t))\, m_{r_t}}$$

3 つの量($\delta_t$・$v_i(t)$・$\varphi'_i(t)$)がどう変わり、互いにどう相関するかで $\bar z_i$ の動きが決まる。

### 7-2. 5 項分解

$$\mathbb E[\Delta \bar z_i] = T_0 + T_1 + Y_i + T_4 + T_5$$

| 項     | 名前              | 式                                                                                                                       | 誰に効くか           | 向き                    |
| ----- | --------------- | ----------------------------------------------------------------------------------------------------------------------- | --------------- | --------------------- |
| $T_0$ | 蹴り              | $\varepsilon_{k'} w_{ik'}$                                                                                              | 全員              | 沈んだ unit は上(+0.034)   |
| $T_1$ | 一次 refit(採用/廃棄) | $-v_i \langle \zeta, m \odot \varphi'_i\rangle$                                                                         | 折れ目を跨いだ少数       | 半々                    |
| $Y_i$ | 井戸・押し           | $\frac{\bar m}{2}[(\varphi^c_i)^\top \mathsf W \varphi^c_i + v_i^2 \varphi'^\top_i (\mathsf W \odot G) \varphi'_i]$ の降下 | 跨いでいる unit      | 沈下の主役ではない             |
| $T_4$ | 雑音の浮力           | $\kappa (-\bar z_i)$                                                                                                    | 沈んだ unit        | **上向き**(+0.0119/task) |
| $T_5$ | 雑音のゲート経由        | $-c\, v_i^2\, n_{\rm band, i}$                                                                                          | **折れ目近くの unit** | **下向き(沈下の主役)**        |

**第 7 回の重要な発見**: 従来「井戸・押し」を沈下の主役と考えていたが、雑音を消した full-batch との比較で棄却。**沈下の駆動は $T_5$(batch 1 標本雑音)**。

### 7-3. $T_5$ と $T_4$ の詳細

**$T_5$(雑音のゲート経由・下向き・先生 Vault の [[audit-v1b-intra-task-drift-of-sunk-units-0909]])**:

$\varphi' = a + (1-a) \mathbf{1}[z_r > 0]$ と書くと:

$$T_5 = -2\eta (1-a) v_i \sum_t \sum_r \frac{m_r}{32} \text{Cov}(\delta_r(t), \mathbf{1}[z_{i,r}(t) > 0])$$

**実測則**: $T_5 \approx -c\, v_i^2\, n_{\rm band, i}$
- $c \approx 0.1$/タスク・$\propto \eta$
- $n_{\rm band}$ = $|z| < 0.3$ の支持点数
- 群 G の沈下の主役: $k_{\rm on}$=2 で −0.098、$\ge 3$ で −0.175/タスク
- 線形化式: $T_5 \approx -8\eta^3 (1-a) v_i^2 \sum ...$(詳細略)
- 小 $\eta$ で線形予言 1.1〜1.4 倍、$\eta$=0.01 で 2〜3 倍過大(指示関数の応答の飽和)

**$T_4$(雑音の浮力・上向き)**:

$$T_4 = \kappa (-\bar z_i)$$

- $\kappa = 0.0119\, [0.0109, 0.0129]$/タスク($\eta = 0.01$)
- 小 $\eta$ 極限: $\kappa = \bar m \eta a^2\, \mathbf{1}^T \Xi^{(2)} \mathbf{1}$(0.0039、連続時間の (D2))
- 沈んだ unit ($\bar z_i \ll 0$) ほど強い
- $v$ 非依存

### 7-4. $\bar z_{\rm width}(\eta)$ の駆動源からの予言

**帯別の動きの向き**:
- 深部($n_{\rm band} \approx 0$): $T_5 \approx 0$、$T_4$ 支配 → **上向き**
- 折れ目近く($n_{\rm band}$ 大): $T_5$ 支配 → **下向き**

**$\eta$ 依存の起源**:
- $T_5$: $c \propto \eta$(1 次)
- $T_4$: $\kappa \propto \eta^2$ の連続時間近似(2 次)
- **競合**: $T_5/T_4 \propto 1/\eta$——$\eta$ 小で $T_5$ が相対的に強い

**予言**:
- **$\eta$ 大**: $T_4$ が $T_5$ を凌駕 → 折れ目近くの unit が浮上 or $T_1$ で強く refit された少数に集約 → 深部支配(実測 $f_{\rm deep}$ 74.5%)
- **$\eta$ 中間**: $T_5$ と $T_4$ が拮抗 → 折れ目近くと深部の二極化 → $\bar z_{\rm width}$ ピーク(実測 7.37)
- **$\eta$ 小**: $T_5$ と $T_4$ が弱く、平衡到達が遅い → 分布狭くなる(実測 6.93)

**$\bar z_{\rm width}(\eta)$ ピーク型が駆動源の 5 項式の $T_5$-$T_4$ 競合から出る**。

### 7-5. 駆動源 $T_5$ と (U4) の $\varphi'$ 帯選別の関係

**両者は同じ機構の異なる表現**:

|           | 駆動源 $T_5$                | (U4) 縮小閾値                            |
| --------- | ------------------------ | ------------------------------------ |
| 主役        | 標本雑音の誤差-ゲート共分散           | $\varphi'$ の帯別値                      |
| 帯依存の起源    | $n_{\rm band}$(折れ目近くの点数) | $\varphi'$ 急変                        |
| $\eta$ 依存 | $c \propto \eta$         | $\eta_{\rm crit} \propto 1/\varphi'$ |
| 結果        | 折れ目近く unit の下向き沈下        | 折れ目近くで縮小が起こる $\eta$ が小               |

「折れ目近くで $\varphi'$ が急変する標本雑音効果」——両者が互いに補強。

### 7-6. 未接続の穴

1. **5 項式は箱 A・CondA・leaky ReLU で書かれた**——$\eta$ 系統振り 5 点への適用($c$・$\kappa$・$n_{\rm band}$ の $\eta$ 依存)は未実施
2. **1 タスクの期待変位**——260 タスク累積への外挿は未実施
3. **駆動源解析の格 C**——事前登録の実験判定を通っていない
4. **第 7 回の $T_5$ 線形化は $\eta = 0.01$ で 2〜3 倍過大**——第 14 回・第 15 回の 5 点測定はもっと小さい $\eta$ で、線形化が有効な範囲かの確認未実施

### 7-7. 駆動源との整合から出る予言

**5 点測定の $c$・$\kappa$・$n_{\rm band}$ の $\eta$ 依存を追跡すれば**:
- $\eta$ ピーク位置の予言が量で出る
- $\bar z_{\rm width}$ ピーク値の予言が量で出る
- S_a との切り分け($T_4/T_5$ の分岐を実測)
