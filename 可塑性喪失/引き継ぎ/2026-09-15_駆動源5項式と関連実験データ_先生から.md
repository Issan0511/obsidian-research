## 1 駆動源の 5 項式（第 7 回・[[audit-v1b-intra-task-drift-of-sunk-units-0909]]）

### 1-1. 出発点: 恒等式

**batch 1 SGD で $\bar z_i$ の 1 タスクの変位は厳密に**:

$$\Delta \bar z_i^{\rm task} = -2\eta \sum_{t=1}^{T} \delta_t\, v_i(t)\, \varphi'_i(z_{i,r_t}(t))\, m_{r_t}$$

- $T$ = タスク内のステップ数（当方 CondA で $10^4$）
- $\delta_t$ = ステップ $t$ の残差
- $v_i(t)$ = unit $i$ の読み出し重み
- $\varphi'_i(z_{i,r_t}(t))$ = ゲート（leaky ReLU $a=0.03$ で 1 or 0.03）
- $r_t$ = ステップ $t$ で引かれた支持点
- $m_{r_t} = \tilde x_{r_t} \cdot \tilde \mu$ = 支持点 $r_t$ の更新が $\bar z$ に与える重み

**3 つの量（$\delta_t$・$v_i(t)$・$\varphi'_i(t)$）がどう変わり、互いにどう相関するかで $\bar z_i$ の動きが決まる**。

### 1-2. 5 項分解

期待変位を 5 項に分解:

$$\mathbb E[\Delta \bar z_i] = T_0 + T_1 + Y_i + T_4 + T_5$$

| 項     | 名前              | 誰に効くか           | 向き                  | 役割              |
| ----- | --------------- | --------------- | ------------------- | --------------- |
| $T_0$ | 蹴り              | 全員              | 沈んだ unit は上（+0.034） | bit flip の瞬間の跳び |
| $T_1$ | 一次 refit（採用/廃棄） | 折れ目を跨いだ少数       | 半々                  | 跨いだ unit の分岐    |
| $Y_i$ | 井戸・押し           | 跨いでいる unit      | 沈下の主役でない            | 従来の中心だった決定論力    |
| $T_4$ | 雑音の浮力           | 沈んだ unit        | 上向き（+0.0119/task）   | 沈んだ unit を上げる   |
| $T_5$ | 雑音のゲート経由        | **折れ目近くの unit** | **下向き（沈下の主役）**      | **群 G の沈下の主駆動** |

### 1-3. 第 7 回の重要な発見

**従来「井戸・押し」を沈下の主役と考えていたが、実験（雑音を消した full-batch との比較）で棄却**。**沈下を駆動しているのは batch 1 の標本雑音（$T_5$）** だった。

### 1-4. $T_5$（雑音のゲート経由・下向き・沈下の主役）の詳細

$\varphi' = a + (1-a) \mathbf{1}[z > 0]$ と書くと:

$$T_5 = -2\eta (1-a) v_i \sum_t \sum_r \frac{m_r}{32} \text{Cov}(\delta_r(t), \mathbf{1}[z_{i,r}(t) > 0])$$

**実測則**:
$$T_5 \approx -c\, v_i^2\, n_{\rm band, i}$$

- $c \approx 0.1$/タスク
- $c \propto \eta$（学習率に 1 次で比例）
- $n_{\rm band}$ = **折れ目の $\pm 0.3$ 以内にある支持点の数**（折れ目近くの unit で大きい）
- 群 G の沈下の主役: $k_{\rm on}=2$ で −0.098、$k_{\rm on} \ge 3$ で −0.175/タスク

**線形化式** の精度: 小 $\eta$ で線形予言 1.1〜1.4 倍、$\eta = 0.01$ で 2〜3 倍過大（指示関数の応答の飽和）。

### 1-5. $T_4$（雑音の浮力・上向き）の詳細

$$T_4 = \kappa\,(-\bar z_i)$$

- $\kappa = 0.0119\,[0.0109, 0.0129]$/タスク（$\eta = 0.01$ 実測）
- 小 $\eta$ 極限: $\kappa = \bar m \eta a^2\, \mathbf{1}^T \Xi^{(2)} \mathbf{1}$（連続時間近似で $\eta^2$ の効き）
- 沈んだ unit（$\bar z_i \ll 0$）ほど強い上向きの力
- $v$ 非依存

### 1-6. $T_5$ と $T_4$ の競合

- **$T_5$ の $\eta$ 依存**: 1 次（$c \propto \eta$）
- **$T_4$ の $\eta$ 依存**: 2 次（$\kappa \propto \eta^2$ 連続時間近似）
- **$T_5/T_4 \propto 1/\eta$**——**$\eta$ が小さいほど $T_5$ が相対的に強い**

## 3 (U4) 勾配からの導出（[[u4-gradient-derivation-with-peer-shrinkage-0914]]）

### 3-1. peer の勾配一般式（[[零点復元と重み収縮_新規学習結果_0913]] §2 追補・commit `0ba13e8`）

$$g_{u_i} = P \mathbb E[\varphi'(z_i)\, e_i\, x], \quad \langle u_i, g_{u_i}\rangle = \mathbb E[\varphi'(z_i)\, e_i\, (u_i^\top x)]$$

### 3-2. peer の SGD 縮小条件（[[SGD橋_箱Bのoptimizerだけを替える_結果_0914]] Adam 考察・commit `b017db8`）

$$\Delta \|u\|^2 = \|\Delta u\|^2 + 2\langle u, \Delta u\rangle < 0 \iff \|\Delta u\| < 2\|u\| \cos(\Delta u, -u)$$

- SGD: $\|\Delta u\|^2 = \eta^2 \|g\|^2$——静かな局面で自己整合的に縮小
- Adam: $\|\Delta u\|^2 = \eta^2 \sum_j r_j^2$（$|r_j| \le 1$）——ノルムに硬い下限（$\|u\| \gtrsim 0.007$）

### 3-3. 統合式（SGD で unit $i$ の縮小条件）

$$\eta \|g_{u_i}\|^2 < 2\, \mathbb E[\varphi'(z_i)\, e_i\, (u_i^\top x)]$$

$\varphi'$ の帯別値で近似:
- **折れ目近く**（$\varphi' \approx 1$）: $\eta_{\rm near}^{\rm crit} \sim 10^{-3}$
- **深部**（$\varphi' \approx 0.03$）: $\eta_{\rm deep}^{\rm crit} \sim 33\, \eta_{\rm near}^{\rm crit} \sim 3 \times 10^{-5}$

**深部の縮小閾値は近くの 33 倍**。

### 3-4. $\alpha(\eta)$ ピーク型の予言（(U4) 骨格）

- **$\eta > \eta_{\rm near}^{\rm crit}$**: 両方縮小 → 深部支配 → $\bar z_{\rm width}$ 小 → $\alpha < 0$
- **$\eta_{\rm near}^{\rm crit} > \eta > \eta_{\rm deep}^{\rm crit}$**: 近くだけ縮小・深部成長 → 二極化 → $\bar z_{\rm width}$ ピーク → $\alpha > 0$
- **$\eta < \eta_{\rm deep}^{\rm crit}$**: 両方成長 → 分布広がるが折れ目近くの割合減 → $\alpha$ 左肩

**実測ピーク位置 $\eta \in [0.0002, 0.0005]$ が予言帯 $[3 \times 10^{-5}, 10^{-3}]$ の間に入り、桁で整合**。

### 3-5. Adam との対比予言

Adam で $\|\Delta u\|^2 = \eta^2 \sum_j r_j^2$ に $\varphi'$ が入らない → **帯依存が消える** → **$\alpha(\eta)$ ピーク型は SGD 固有**。

**CondA×Adam 鏡像実験の予言**（peer 提案 1 に対する当方の予言）:
- (i) $\alpha(\eta)$ 変動幅 2.147 → **0.7 以下**
- (ii) 頂点位置が消えるか $\eta$ 大側にシフト
- (iii) $\bar z_{\rm width}$ の $\rho$ が $+1.000$ → **$\le 0.7$**

## 4 駆動源 5 項式と (U4) の関係

**両者は同じ機構の異なる表現**:

|           | 駆動源 $T_5$                  | (U4) 縮小閾値                            |
| --------- | -------------------------- | ------------------------------------ |
| 主役        | 標本雑音の誤差-ゲート共分散             | $\varphi'$ の帯別値                      |
| 帯依存の起源    | $n_{\rm band}$（折れ目近くの支持点数） | $\varphi'(z)$ が 1 と 0.03 で切り替わる      |
| $\eta$ 依存 | $c \propto \eta$           | $\eta_{\rm crit} \propto 1/\varphi'$ |
| 結果        | 折れ目近くの unit が下向きに沈む        | 折れ目近くで縮小が起こる $\eta$ が小               |

**「折れ目近くで $\varphi'$ が急変することによる標本雑音効果」を、駆動源では $T_5$ の $n_{\rm band}$ 依存として、(U4) では $\varphi'$ の帯別縮小閾値として書いている**。両者は互いに補強する。
