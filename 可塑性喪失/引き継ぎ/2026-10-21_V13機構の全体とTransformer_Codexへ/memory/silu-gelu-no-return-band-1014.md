Issa の要望（1014 夜）「戻らないは流石に言いたい」「固定した入力雲かつある程度大きい幅で」→ 結論「1/2 へ向かう道の上では全部沈める側、浮かせる側は深い帯だけ。LoP として申し分ない」。Opus 4 体（ガウス地図・実状態・橋の読み・射影）＋ 編集役で V12 v5.9.8 に入れた（2026-10-15 未明）。所在 `obsidian-research-data/push_direction_proof_0930/review/stage4_1002/block_1003/stage17_1014_silu_return/{bridge,real,theory,projection}/`、台帳 P184、V12 §4.4・§4.5・付録 K.2 (h⁗)。

- **主張の形**: 整流型の「p < 1/2 の全域で押しが沈める側 [厳密・ガウス]」は SiLU・GELU では unit ごとに偽。言えるのは帯の形: 1 層箱の凍結状態（多クラスの核、t 3〜41 × 2 seed）で核の押し A は r > −1.75 の全 unit-状態で沈める側（548/548・429/429）、浮かせる側は 7.6%・11.5% で全部 r ≤ −1.76・開いた入力 ≤ 7・21・p ≤ 0.6%・1.8%。戻り（p < 1/2 → p > 1/2）は 2 seed × 課題 3〜1000 で 0。格は [実測（凍結状態の模型）＋ データの性質（射影の検査）＋ ガウス（参照）]。
- **浮かせる側の正体は谷の壁の項で橋ではない**: c_n = K_n φ″(z_n)γκ′E は φ″ が偶なので |z| > z* で負（両側）。壁 D₂ = [−z*, −t₀)（φ′ < 0・φ″ > 0）と行き過ぎ O₂ の項は持ち上げ無しで浮かせる [厳密]。「覆しには橋が要る」は谷のある活性化では瞬間の必要条件として偽、硬い極限（幅 ≫ z*、跳びの積分）で ReLU の条件が戻る。実状態でも A^g ≤ 0 の最も負の域は D₂（104/104・143/151）。定理 6 の補題はそのまま使え、符号条件は Cov(φ″, φ′) ≥ 0 かつ E[φ″]E[φ′] ≥ 0。第 2 項の重み 1 − T̄ は SiLU・GELU で 0.04 → 0.58（leaky 0.06〜0.08、ReLU 0.585）。
- **ガウス（K 一定）の帯**: 段 0〜2・門 1 は σ ≥ 0.94・0.57 で r < 0 全域で正。門 2 = E[φ″]E[φ′] だけはどの σ でも負の薄い帯（平滑化した活性化の最小点の直下）を持ち、上端 r_z ≈ −σ/2 − 2/σ（SiLU）・−σ − 1/(2σ)（GELU）、最大 −1.74・−1.67（p < 4〜5%）。実状態の浮かせる側の上限 −1.78・−1.76 と一致（理由は未導出）。帯の中でゲートの分が負に覆るには 1 − T̄ > 8 が要る（実測 ≤ 0.6）。平均ゲートの零点の係数は c = π²/6・1/2（私の最初の見積もり π²/12・1/4 は半分）。
- **固定した入力雲の射影**: 読み出しの分（段 1・段 2）は learned 12,000 本の 99.6% の (u, r) で σ ≥ 1.2・0.7 から 10⁴ まで正、実状態の 99.7% で正。5 量すべては言えない: p ≈ 1/2 の門 1（段 2・門 1 は鏡映 (ζ, r) → (−ζ, −r) で奇、符号は歪度で決まる）と深い帯の門 2（幅を大きくしても直らない: E[φ′] > 0 なら σ > z*/g_all で負）。崩れる値は小さい（段 1 の 2%、打ち消しの無い大きさの 2〜4%）。
- **実現した変位に持ち上げは無い**: A < 0 の unit-状態は次の課題末までに Δm −1.75（A > 0 は −1.36）、浮いた割合も帯で揃えた A > 0 より低い。

**Why:** 整流型の鎖（段 1 のチェビシェフ）が谷で使えず、1008 までは「向きまで」で止めていた。Issa は戻らないを言いたく、LoP の近くの例外は気にしない。帯の形なら実測・射影・ガウスの 3 本で支えられる。
**How to apply:** 谷のある活性化で「p < 1/2 ⇒ 沈める側」を言わない。言うなら帯の形（道の上で全部沈める側・浮かせる側の帯の位置と数）。5 量の項ごとの十分条件は p ≈ 1/2 で過剰に厳しい（鏡映の奇性）ので、押し全体は実状態の核の押しで測る。依頼文に自分で計算していない数を「確認した」と書かない（1014 に理論役へ送った「事前の粗い確認」は未計算だった。送った後に訂正）。関連 [[elu-silu-gelu-extension-1007]]・[[push-direction-proof-0930]]・[[v12-central-claim-1007]]・[[fable-role-claim-strength]]。
