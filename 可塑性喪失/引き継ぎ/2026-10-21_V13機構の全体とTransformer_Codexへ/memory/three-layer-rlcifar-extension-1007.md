/goal「RL-CIFAR の 3 層を理論的に詰める・3 種類の活性化の挙動からどうなるか」（2026-10-07）。vault `可塑性喪失/論点/V8/駆動源問題/3層RL-CIFARへの拡張_層ごとの位置の座標と壁_1007`（検証役の訂正 21 件込み。`P169_verifier_report.md`）、台帳 P169、測定 `push_direction_proof_0930/review/stage4_1002/block_1003/stage12_1007/p169_3layer.py`（45 走、各 6 秒）。

**確定した事実（実測、raw/std × LR/ELU/SILU/GELU × seed 0〜2、キメラ 7 セル）**
- 第 1 層の自己形の重みは |g_in|² K_n（g_in = W3 diag(φ2′) W2[:, i]、クラス平均で中心化）。非負なら段 1 の Cov_w(φ′, φ) ≥ 0 はそのまま [厳密]。raw の leaky・ELU で逆向き 0%。常時点灯 unit（p > 0.99）は押しが厳密 0。
- std は K_n = x̄·x_n + 1 が 36% 負 → 重みが負になり補題の前提が壊れる（符号 27〜46%）。bias だけの座標（K ≡ 1）に取り直すと 100%（登録どおりの逃げ道）。
- 第 2 層: z̄2_j = W2[j]·µ₂ + b2_j で bias は 0〜5%。W2 の µ̂₂ 成分は −0.6〜−2.4 に釘付け、‖µ₂‖ の伸び（ELU raw 27 → 601、ELU std 665 → 1209、LE 22 → 991）が z̄2 を −300〜−1000 へ。ELU raw の ‖µ₂‖ は 1〜2 個の常時点灯 unit の開いた側（z1 100〜300）が運び、閉じた側は −1 の床で √99 に飽和。µ₂ 成分の平均は負 → 正に反転。
- **raw の第 1 層は課題 1 の間に沈む**（r1 −0.13 → ELU −3.2・GELU −3.7・SiLU −3.6、全閉 51〜98%；leaky は −1.1 → 課題 5 に −2.2 の台地）。初期化は片側でない（r −0.13）。
- **std の第 1 層は 4 活性化とも 50 課題で r1 ≈ −0.1 のまま**（位置の座標が無い: ‖x̄‖₁ 330 対 raw 1454、K の mean/sd 0.40 対 3.83。bias は 50 課題で −2.8 = sd1 の 0.03 倍）。代わりに第 2 層が課題 2〜3 で死ぬ（ELU・GELU・SiLU。z2 < −16.64 が 100%）。leaky の第 2 層は r2 −1.4 で生存。
- キメラ: LE は第 2 層が課題 3 で死に、第 1 層 leaky はその間（|g|² 0.63 → 0.006）に全速で沈んで課題 5 に全閉 58%、以後凍結（0922 の「第 1 層 healthy」は p の平均 0.21 と dead_frac で見ていた）。EL は第 1 層 ELU が課題 1 で沈み、第 2 層 leaky は入力 h1 ≈ −1 定数で情報喪失（‖µ₂‖ 9.5 = 床だけ）。GE/GG/GL は第 1 層が課題 1 で死に第 2 層は z2 ≈ b2 の入力喪失（gate 0.5、沈まない）。LL だけ両層台地。

**読みの型**: 層の生死 = その層の位置の座標の大きさ（平均入力の ℓ1 と K の符号の揃い）× その層の活性化の止め役の有無。平均入力は前の層の閉じた側の値（leaky a·z1 / ELU −1 / GELU・SiLU 0）と常時点灯 unit の開いた側で決まる。入力の中心化が ReLU を救う（relu_doors）のは押しを消すのでなく押しが乗る速い座標を消すから。

**罠**: (1) 符号の統計は正規化した重みで 3 分割（正・厳密 0・負）にする。|g|² が 1e−30 まで落ちた unit や常時点灯 unit を「負」や「半々」と読まない。(2) 入力を失った層（EL の第 2 層、GE の第 2 層）の r・p・符号は意味を持たない（z2 の sd が小さい）。(3) 「死」は p の中央値で見る（平均は常時点灯 unit が作る）。(4) stats() は空配列で落ちる → isfinite で濾す。

**検証役（Fable、1007）の訂正で変わった読み**
- 「向きは壊れない」は自己形（版 (B) |g_in|² K_n／版 (A) ρ_n K_n）の文。実際の切替の押し S_i = Σ K φ′⟨g, p − 1/K⟩ は raw で 84〜97%、std で 37〜67%（bias だけの自己形 100% でも揃わない）、学べない状態で半々。3 層で加わる W3 の成長 × 初期の W2 列の項は縛れていない。
- **相対位置の壁** r ≥ −mean(K)/sd(K)（重みが平均入力に反平行のとき）。raw −3.83・std −0.40・第 2 層 std −2.0。raw の ELU/GELU/SiLU の第 1 層は課題 1 で壁に張り付き、死んだ第 2 層は壁に座る。**r の台地は止め役の印でない**（ELU std の第 2 層 −2.0 は壁で死んでいる）。生死は p・gate で読む。
- std の第 1 層は「沈まない」でなく、leaky は −0.13 → −0.33 と壁へ漂い、ELU/GELU/SiLU は第 2 層の死で凍る（|g|² 1e−6〜1e−47）。bias の道は「遅い」でなく「押しが揃わない」。
- ELU raw の第 2 層の死（課題 5）までは W2 の反平行成分 ×10 が主、‖µ₂‖ ×2.2。‖µ₂‖ ×22 は死後。LE は上流 ×16.6 が主。leaky の閉じた側 a·z1 は sd1 に比例（×1.34）、‖W1‖（×2.6）にではない。
- LE の第 1 層の沈みは第 2 層のゲートが閉じていく課題 2〜5（|g| ≫ ε）に起き、以後は残存勾配で僅か、課題 20 以降 bit 不変。「Adam が正規化して厳密 0 まで全速」は誤り。
- 常時点灯 unit は自己形の押し 0 だが実際は +x̄ へ回って押し上げられる（cos(w, x̄) 0.05 → 0.24、LE では 19 個が r −3 → +3.5）。Adam の sign 歩の偏りの読み [候補]。
- relu_doors の引用: 入力の中心化 C は無効（0.113、第 1 層の死を第 2 層へ移す）、効いたのは h1 の中心化 CH（0.987）。「入力の中心化が救う」と書かない。
- 場合分けは「止め役の有無」でなく「止め役の尺度 対 歩幅」（ELU × Adam の k* ≈ 20 は CIFAR raw の歩幅に負ける）＋「押しの源（学べているか）」＋「入力の rank」。EL の第 2 層は座標が大きくても押しの源が無く r2 が回復する。
- 罠: 零判定の尺度は中心化前の Σ|w||u||v| で（中心化後だと台が 1 入力に縮んだ unit で偽の負）。r は sd → 0 で発散するので許容値。死の閾値はエンジン依存（torch expm1-ELU −16.64、この箱の GPU 手書き e^z は −13.8156）。
