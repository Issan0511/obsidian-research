**検算（1019・Fable）**: 一次式 Δσ² ≈ −2cN Cov_n(x, φ′φ)·Cov_n(x, z)（数値一致）。等方・K 一定では Cov(z, φ′φ) > 0 で縮む。上界 |rΔσ|/|Δm| ≤ r·λ_max(Σ)·sd(φ′φ)/(K̄·E[φ′φ])。MNIST 1,200 枚（/255）: K̄ = 34.4、K_n の sd 9.4（K 一定でない）、λ_max(Σ) = 5.07、λ_max/K̄ = 0.147。自己形の一歩で σ の分は r の変化の 0.5%（r 0.18）〜4%（r 1）、r の一歩の減少は 20 seed すべてで残る。だから結論は実測・一歩の計算では生きるが、ガウス・K 一定からの導出は無い。
**残る**: 一歩の期待式 E_old[S_i] = κ(1−1/K)ΣK_n d φ [厳密な極限]。状態ごとの符号: ガウス・K 一定で r > r*₀ なら沈める側。leaky・ReLU は m ≥ 0 なら分布によらず E[φ′φ] = m + (1−a²)E[z₋] ≥ m > 0。ReLU の K_n > 0 の文。
**落ちる**: 反復の単調性・有限回の到達・r*₀ へ「向かう」「安定」。序論「約4%になるまで」、§4.1.1 の太字「沈める押しが続く」、表 D2 の群名。
**直す形の案**: 補題 1 を状態ごとの符号の命題に。有限回の越えは「位置方向の流れでは厳密」＋「実際の一歩では状態ごとの不等式 K̄E[φ′φ] > r λ_max(Σ) sd(φ′φ) で r が下がる」＋「実網は 1 回で越える [実測]」。関連: [[v12-central-claim-1007]] [[derivation-one-failure-not-impossible]] [[claims-are-outcomes-not-proof-seams-1015]]

**1019 夕・Issa「仮定を一般化できないか。実測で自己形から外れたのを見たことない」→ 仮定は 1 本に落ちた（比較 ODE の閉じ方）**: 前の「経路で比 ρ 一定」が緩さの原因。位置が大きいうちは押しが m 自身に比例して速く、ひずみが溜まるのは終盤だけなので dT/dS = q(σ₀+T)/((m₀−S)+(1−a²)(B(S)−T)) を S∈[0,m₀] で積分し B−T>0 なら閉じる（離散列も任意の歩幅で T_k ≤ T̂(S_k)、R が S・T で単調増加）。**一般化した補題 1**: 整流型（leaky・ReLU・ELU α≤1）・K 一定（H3）・自己形の列（H1）で、(i) m ≥ 0 なら ḡ = m + E[h(z₋)] > 0、h ≥ 0 は活性化ごと（leaky (1−a²)t・ReLU t・ELU t − e^{−t}(1−e^{−t})、1.125-Lipschitz）[分布によらず厳密]。(ii) 入力の幾何の比 q = λ_max(Σ)/(‖x̄‖²+1) ≤ q*(r₀, B) なら有限回で m < 0 [厳密]。途中の分布・向き・ガウス性・非ガウス残差 ε は不要。ガウス出発の q*: r₀ 0.18→0.45、0.3→0.29、0.5→0.20、1.0→0.13、1.5→0.105、2.0→0.093（leaky・ReLU 同じ）。**実状態（課題 2 末）**: MNIST q = 0.141/0.155 → 幾何だけで m≥0 の 63/69・72/80（LR）、36/47・48/61（R）、34/41・27/42（ELU）→ 生きた unit の 86〜91%（LR・R）、85〜93%（ELU）。unit の向きの q_w なら LR・R は 100%。保証される累積ひずみ T/σ₀ 中央値 0.05、β*/σ₀ 中央値 0.25。**意味**: q 小 = 核の平均モード（明るさ K̄N）が中心化モード（Nλ_max）を支配 = 論文の主張の定量形。中心化した入力（K̄≈1、q 大）では σ が m より速く縮んで r が上がり得るので補題は本当に成り立たない側で、「中心化で沈降が消える」と同じ。残る前提は既存の H1・H3 と、SiLU・GELU の符号条件（SC1）、結論 m<0（p<1/2 はガウスの読み）。
