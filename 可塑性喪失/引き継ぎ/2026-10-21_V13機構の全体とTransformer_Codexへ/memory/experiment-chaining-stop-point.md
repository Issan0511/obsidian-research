2026-09-17 夜、Issa から「ずっとループしてるように見えるけど、何が起こってるのか教えて」と聞かれた。実態は次のとおり。

- 各走の報告の最後に「次の候補」を書き、Issa がそれを依頼した。これで mucap_el → mucap_ee → l2cap → swap → escape → escneff の 6 本が連鎖した。
- 毎回同じ約 15 手順の儀式（worktree → 検査 → 登録 → 予測 → 本走 → 判定 → 検算 → 退避 → merge → vault → memory）を繰り返したので、画面上は同じことの繰り返しに見えた。

Issa に「まとめる／広げる／止める」を示すと、「まとめる」を選んだ。

**Why:** 同じ箱（RL・ELU→ELU）の中で、問いが残り 0.11 の内側へと細くなっていた。得られるものが減っていたのに、自動で次の候補を出し続けていた。

**How to apply:**
- 結果報告の末尾に、毎回決まって「次の候補」を付けない。結果ノートの「次の候補（未起票）」節は残してよい。ただし会話の締めで提案として押し出さない。
- 同じ箱での深掘りが 3 本以上続いたら、自分から止めどきを示す。選択肢は「まとめる（V10 の草案・作業リストに反映）」「広げる（他の箱へ）」「止める」で、選ぶのは Issa。
