**事実（2026-10-20、RL-CIFAR CNN、保存済み checkpoint の事後解析＋bit 一致の再生、repo `results/kappa_reload_cnn_1020/`、vault `可塑性喪失/測定/CNNの最終隠れ層で装填を測る_κの再整列・切替の押し・課題の中の戻り_結果_1020`）**
- LR（leaky 0.1、seed 10〜19、t ≤ 30）: κ_k/κ₁ 1.4〜7.0 で 10/10、cos²（head と F）0.63〜0.75、帰無分位点 1.000、補題 κ ≥ [N(log K−L)−B]/‖F‖² の破れ 0/484、κ/κ_lb 7〜22（30,000 更新で logit の広がり J ≫ D。親の「2〜5」は計算前に「2 以上」へ直して正解）。
- f2（最終隠れ層）の自分の重みを通る押し G_own は全境界 99〜100% 沈める側、実際の 1 歩 80〜95%・200 更新 84〜100% が沈む。初期化の押しは切替の 1e−4。運動量は効いていない（m=0 複製と符号全一致）。
- **覆った所**: (i) f2 の一次応答 G_full の大きさは上流項 G_up が 97〜100%（符号は G_up で決まる、G_full > 0 は 0.75〜0.94）。(ii) 課題の中で切替の沈みは t10 以降 100〜125% 戻り、f2 の集団は r ≈ −0.6 で止まる（f1・c2・c1 は沈み続ける）。unit 単位の戻り（p⁺ < 1/2 → ≥ 1/2）は LR f2 で 1,000 中 653（MLP は 4）。(iii) 適応 Snake 4 腕の κ 比は落ちる（‖F‖ が膨らむ尺度の問題、cos² は 0.5〜0.9 で保たれる）。fc の c = 3（鋭いゲート）の SNAc3・CV06FC3 は f2 の押しが半々で沈まない。
- 自己形（対角項）は S_exact の 3〜8%（MLP 13〜60%）。学習後は G_own = (1−1/K)κ_R（own 感度の旧ラベル整列）が恒等的に成り立ち、f2 で κ_R > 0 が 1.00、c1 で 0.1〜0.5。
- head を替えた固定状態の参照: 乱数 head では f2 の沈める側 0.63〜0.65、実際の head で 0.99〜1.00。クラス置換は S_exact の厳密な対称性で対照にならない。

**Why:** V13 の部品の表「CNN × 装填」の欄。Issa の予測「覆ることは無い」は LR の芯では当たり、unit 単位の不可逆と Snake の κ 比では外れた。

**How to apply:** CNN の装填は κ 比でなく cos² と Q = κ‖F‖ で書く（κ は F を a 倍・head を 1/a 倍で 1/a² 倍の非不変量）。「Keep sinking」は層で分けて書く（最終隠れ層は切替で深く沈んで課題の中で戻る、上流は沈み続ける）。Snake の再生は元の訓練と同じ 40 束でないと bit 一致しない。関連: [[kappa-reload-1020]]・[[reload-dial-1020]]・[[c1-direction-1010]]・[[sna-cnn-cause-1009]]。
