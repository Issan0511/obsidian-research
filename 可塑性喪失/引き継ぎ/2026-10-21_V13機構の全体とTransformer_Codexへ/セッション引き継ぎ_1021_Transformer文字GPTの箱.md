- 追加腕（seed 1000 の下見）: C3H・B3H・B3HB（中心化、害）、KKT1・KKT1nolo・KKT1b3・KKT1beta（Snake 族と β）、SiLU・GELU・ReLUcap・SiLUcap・GELUcap（cap 比較）、SiLU_cont・SiLUcap_cont（課題 51〜100）、2 ブロックの C3-2・SiLU-2（100 課題）。
- 罠: torch.compile × RoPE で勾配がずれる（CUDA グラフだけ）。CUDA の乱数は機種依存（系列は CPU 乱数）。走っている bash を書き換えない。provenance の git hash は開始時に。複数プロセス同時は速くならない。Vast.ai の RTX 5060 Ti は white-san とビット一致（5 腕で約 1.4 ドル）。

### 2.2 本走 10 seed（登録の判定）

C3・C4・B3 は SINKS かつ NO_LOSS（fresh gap −0.040・−0.131・−0.048）、N4 だけ LOSS（+0.358）。学習率は沈降の門ではない。Fable の事後の 3 相（課題 2〜10 → 41〜50、新品は課題 50）: C3 は 0.15 に届く更新数 546 → 879（10/10 で遅くなる）、課題末 0.041 → 0.048（10/10 で悪化）、新品を下回るのは 2〜3/10。B3・C4 も自分比 10/10 悪化、新品比 0/10。**LN のある箱では 50 課題は短い。喪失の主張は 100 課題か 2 ブロックで。**

### 2.3 seed 1000 の下見で決まったこと

- **ReLU（C3）**: L3（読み出しに隣接）が切替ごとに −0.33 沈み、μ −0.85 → −82・σ 1.7 → 27、94% が死に、課題 41〜50 で新品より遅い。**ReLU＋cap**（L3 の幅を課題 1 末で固定、縮めるとき V も直す）は止まり 3 相すべてで改善（1 seed）。cap が効く経路は φ′ でなく相対歩幅。
- **SiLU・GELU**: L3 は課題 5 に −2.8 まで沈んだ後、課題 10〜15 に正側（+1.7〜+2.2）へ出て線形化（v が相対的に小さいときの正側片側化）。50 課題では失わない。**SiLU 100 課題**: 課題 60 以降に失い（遅くなる型）、L2 が課題 70 以降に沈んで死ぬ（−0.60 → −2.37、死 29%）。L2 の沈みは上流の ȳ の変化 −0.67・自分の重み −0.28、担い手は FFN1 の共通の書き込み。Issa の鎖: L3 の重みが伸びて相対的に読み出しが小さくなり正へ飛んで線形化、L3 の重み＝L2 の読み出しが伸びて L2 が沈んで死ぬ。
- **SiLU＋cap 100 課題**: L3 の逃げを止めて L2 を守るが、L3 が 65% 死に、課題末の excess が 0.048 → 0.092（新品 0.050）＝届かない型の喪失。頭 100 更新は速い（スパイクが小さいだけ）。**GELU＋cap** は速いが課題末が GELU より少し悪い。GELU は 50 課題で失わないので「救う」とは言えない。
- **担い手**: bias の無い土台では unit のしきい値は w·ȳ しか無く、上流 FFN の共通の書き込みが原料（FFN 出力の共通成分を消すと損失 +3〜+8）。中心化の害と β の救済（KKT1b3・KKT1beta で沈みが消える、幅は止まらない）は一本。担い手は網が作り動く（上流の ȳ だけ替えると L1・L2 の戻りが出る）。L0 の担い手は注意 0 の出力平均（C3 の 4 ブロックでは課題 10 までに注意 0 が死ぬ）。
- **Δμ/σ の分解**（切替直後 100 更新 ＝ 自己形・上流・その他、課題の残り ＝ 自分・上流）: 押しは L3 に集中し L0・L1 はほぼ 0。L3 の自己形は 1〜2 割、8〜9 割は w·Δȳ。課題の中は自分の重みが沈め上流が戻す。**上流の項には上流経由の自分の信号が入る**（フォークの ρ: SGD 一次で Δm_j = 自分の重み ＋ 上流経由の自分（核 Q^{jj} ≥ 0）＋ 他人。self/other に割るには Δȳ を対角・非対角に割る。文字 GPT のセッションが実装中）。
- **KKT1（Snake、bias なし）**: 切替の押しは +0.04（上向き、理論どおり）だが課題 38〜41 に 3 層が一斉に沈む。原因は上流の共通の書き込み × 深さ（Snake のオフセットは沈むほど増え幅に比例、ブロックごとに約 2 倍）。LN の γ が幅を運ぶ。β だけで止まる（KKT1beta）。

### 2.4 2 ブロックの下見（追補 6、seed 1000、100 課題、判定外）

- 走る前に 3 条件と閾値を spec に固定（3126a878、閾値は 4 ブロック seed 1000 の参照値を同じ定義で計算し直した: 沈み −0.206、集中は一様からの超過 κ ≥ 0.380 → c ≥ 0.690、上流 0.616、喪失の δ 0.025、固定評価集合は seed だけから作る一様乱数 probe、onset_resp ≤ onset_loss + 5）。
- **C3-2 は 3 条件すべて通過**: 課題 1 末 0.075、超過損失 0.146 → 1.420（課題 55 以降に崩れ、61〜100 は学べない、新品より 1.26 悪い）。L1 の切替の押し −2.52・負 96%、onset_resp 課題 5 < onset_loss 課題 14。恒等式の残差 1.8e−14、負の量の L1 集中 0.937（κ 0.874）、上流 0.958、相殺 0.016。
- L1 の担い手の出所は課題 1〜10 は FFN0（0.90〜1.02）、課題 50〜100 は注意 1（0.49〜0.87）。**「上流 FFN の共通の書き込みが下流のしきい値を担う」は課題 1〜10 に限って言う。**
- 役割の移動は「死の移動」: L1 が課題 10 に 75% 死 → L0 が課題 25〜50 に沈み（−0.60 → −3.17）死 37 → 68 → 82% → 崩れ（課題 55〜70）は L0 の死の始まりと重なる。注意 0 は 2 ブロックでは生きている。
- SiLU-2 も失う（0.146 → 0.228、遅くなる型）。L1 は正側へ出ず両層とも閉じてゲート層なし（課題 20 以降）。
- 同じ課題列で 2 ブロックは 4 ブロックよりずっと速く深く失う（C3 の課題 41〜50: 0.354 対 0.145）。MLP（深いほど失う）とは逆。Fable の読み: 残差のある網では死んだ FFN は素通りされ深さは予備、残差の無い MLP では閉じた層が下を遮蔽（未検証）。

## 4. 次の一手（Transformer の節）

1. 本文は 2 ブロック、4 ブロックは付録。一文の案（Astra）: 「上流 FFN の共通の書き込みが下流ゲートのしきい値を担うという仮説を検証するため、両者を別々に介入できる本構成で最小の 2 ブロック Transformer を用いる。4 ブロックでの対応と、深さに伴う役割移動は付録で評価する。」
2. 節の文の候補: 「bias の無い網では上流の共通の書き込みがしきい値の原料になり、読み出しに隣接する FFN がそれに乗って沈む。ReLU は死んで戻れず、負側に傾きを持つ活性化は正側へ逃げて線形化し、押しは次のゲート層へ移る。cap は ReLU の死を止める。深さは遅らせるだけ。」喪失は 3 相で新品の同じ相と並べ、遅くなる型と届かない型を分ける。
3. 査読の反論への備え: 事後の深さ選択（採用基準を下見前に固定した、2・4 を同じ課題列で比べた、不一致も報告）、共通成分の除去は「学習に要る」の証拠で機構の証拠でない（因果は切替窓だけ上流を固定する分岐＋固定入力集合上の共通成分だけを固定する対照）、上流が大半なら 1 隠れ層の自己形の定理と多層の経験仮説を分けて書く。
