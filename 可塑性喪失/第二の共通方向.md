## レジーム分け（condA との関係）

condA（[[整流モデル]] の場）は **µ 項が Cov 項を median 4.3× で支配**し、第二方向はほぼ不可視。第二方向の判別は **condB 異方（Σ スパイク）**で行う。µ 射影を除去した**残差 inter-unit cos** と2候補の照合（task_077）が判別の道筋であることは変わらない。κ 細分スイープ（tanθ ∝ (κ−1) スケーリング、交差点 κ\* の同定）も未処理。

## 関連する留保：D → 0 と符号クローンを同一視しない

符号クローンはゲートが揃えば成立し、方向の完全一致は不要。実測 c̄ は D → 0 から遠く、その水準で症状が出ている。**D\* > 0 のままでも LoP は起きる**というのが観測事実。（**D = ユニット方向の広がり、c̄ = 平均 inter-unit cos** → [[用語と記号]] §5）

加えてポジショニング上の理由がある。D → 0 の到達先 uᵢ = ū は**置換対称性の固定点集合**であり、そこに乗ると Chen の確率的崩壊と到達先が一致して、「既存機構は構造的に適用できない」という新規性の柱が使えなくなる。

→ Phase 1 の終点は「D → 0」ではなく「**D が有限のままゲート同期が成立（符号クローン集合への進入）**」と書く。8/19 以降の言い換えでは、そもそも condA では sign_clone 帯に到達せず、唯一の安定終点は dead（[[整流モデル]]）。
