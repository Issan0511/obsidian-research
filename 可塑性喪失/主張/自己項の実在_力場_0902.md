## 0. 一行

**自己項は、分解では取り出せなかったが、除去したら系が壊れることで存在が示された。** `BL`（順 ReLU／逆 leaky）は負側で自己項だけをゼロにした腕であり、4 腕すべてが発散した。F_self / F_rest 分解が繰り返し失敗したのは自己項が無いからではなく、**大きさを割ろうとしたから**である。自己項の正体は大きさではなく**状態依存性**（$f_i=0$ へ引き戻すバネ）であり、それは介入でしか見えない。

## 1. 何が起きたか

**登録済み（`results/bwd_leak_0902/`・commit `f4cc8ca`）**

- `bwd_leaky` を使う 4 腕（`BL_933`・`BL_1216`・`BLW_933`・`BLW_1216`）が全て `NUMERIC_DIVERGENCE`。検出は 1.11M〜2.01M step、各腕 1 seed（`arm_status/*.json`）
- V1・V2 とも `INCONCLUSIVE_DIVERGENCE`
- b-WD は防がなかった（`BLW` も 2 用量とも発散）

**登録外（`results/_diag_bwd_leak_0902/`・`BL_933` seed 4 のみ・`diag_meta.json` に `"not for transcription"`）**

診断走の軌道の**形**のみ記す。**数値はここに転記しない**（[[運用ルール]] §5・診断走は endpoint ではない）。

- 発散したユニットは、発散の遥か以前から**発火率ほぼ 0 のまま潜行**していた
- 潜行中、$\bar z_i$（平均前活性）は**浮上せず単調に深くなり**、同時に $\lVert w_i\rVert$ が単調に増大した
- その間 $v_i$ は**動かない**（出力 0 なので $\delta\cdot a_i = 0$）
- 稀に 1 パターンだけ $z>0$ になった後、$v_i$・$\lVert w_i\rVert$ が桁で跳ね、非有限へ。**ただし最後の跳ねの前から $v_i$ は断続的に動いており**、跳ねは一瞬の接触ではなく §3.5 のループが可視化されたものと読める

登録走で確認したければ [[逆伝播漏れ2x2_spec_0902]] §10-2 の追走が要る。**現時点でこの形は仮説の域を出ない。**

## 3. 新しい部分 —— 税とバネは同じ項である（**Claude の読み・未登録**）

自己項 $-\eta\,v_i^2\,\mathbb E[\phi\phi']$ は「上向きの力」ではなく「$f_i \to 0$ へ引き戻す力」である。したがって**同じ 1 項が、居場所によって符号を変える**。

| ユニットの居場所                       | 自己項の向き                                   | 既存の呼び名                      |
| ------------------------------ | ---------------------------------------- | --------------------------- |
| 正側（発火している）                     | 出力を減らす ＝ **壁際まで引き寄せる（0 で消えるので壁は越えさせない）** | **自己修正税**（[[現象2主張v1_0901]]） |
| 負側（沈んでいて $\phi\ne0$、leaky・ELU） | 出力を 0 へ戻す ＝ **浮かせる**                     | **バネ**（本ノート）                |
| 負側（$\phi=0$、ReLU・`BL`）         | 存在しない                                    | ——                          |

**税は壁を越えさせない（9/2・Issa の指摘で訂正）。** 自己項は $\phi\phi'$ に比例するので、ReLU の正側では $z$ に比例して 0 へ引き、$z=0$ でゼロになる。壁を**越える**のは自己項ではなく、残差項（共通場のドリフト・µ 方向）と揺らぎである。役割分担は「**自己項が壁際に停め、揺れが落とす**」で、一行の「意味のない揺れで落ちていく」と整合する。leaky では負側でもバネが続くので、ドリフトとの釣り合いで**有限の深さに沈んだまま可動**な平衡ができる（$a^2 v_i^2 z^* \approx -F_{\rm rest}$）。`gate_dose` の leaky 沈下率 0.63–0.67 はこの平衡の姿と読める（未登録）。`BL` は負側にバネが無いので平衡が無い。

**代替勾配は 0 の方を向かない（9/2・Issa の「誤算」の中身）。** `BL` で沈んだユニットに入る力 $-\eta\alpha v_i\delta\,(x,1)$ には現在位置が入っておらず、0 の位置を知る項は自己項だけで、それが恒等的に 0 である。残るのは「点いていたら損失はどちらへ動くか」の残差項で、期待値は共通場 $-\eta\alpha v_i G$（µ 方向）、すなわち**沈めた力が同じ向きに $\alpha$ 倍で続く**。呼び戻す信号（パターンごとの $v_i\delta$ の符号）は存在するが、µ の直流成分に埋もれる。**leaky の沈んだユニットも残差項からは同じ下向きの力を受けており、戻しているのは自己項である。** `gate_dose` の leaky 0/10 を「勾配が通るから逃げられる」と読んだのが v6・Issa・Claude 共通の誤りで、正しくは「バネが張られているから戻る」。`BL` は「幻の残差項」であり、期待されていた「0 へ戻す幻の勾配」は「幻の自己項」（§6 の A）である。

**この読みが正しければ、「片道の壁」の正体は、バネが片側にしか張られていないことである。** ReLU は $\phi\ne0$ の側にしか自己項を持たないので、正側では税として壁際に停め、壁を越えた瞬間にバネが切れる。`R` は駆動も同時に切れるので凍結して止まり、`BL` は駆動だけ残るので底が抜ける。**壁と凍結が同じ機構の裏表**だという整理は、これまで別々に書いてきた。

### 3.5 `BL` の発散は「溜めた運動量の一撃」ではなく「ゲインの暴走ループ」（9/2・Issa の指摘で訂正）

当初「壁の向こうで運動量を溜め、接触した瞬間に全部渡す」と書いたが、二点で誤りである。(a) SGD に慣性は無く、溜まるのは運動量ではなく**位置**、すなわちユニットのゲイン（$\lVert w_i\rVert$・$|b_i|$）である。(b) 「全部渡す」は保存量の比喩だが、保存量は無い。実際に起きるのは正帰還である:

潜行パターンからの残差項ドリフトで $\lVert w_i\rVert$ が伸びる → $z_i$ のパターン間の広がりは $\lVert w_i\rVert$ に比例して増え、出る杭が出る → 出たパターンでの $v_i$ の勾配 $\delta\cdot z_i$ が大きい → $v_i$ が伸びる → 残差項ドリフト（$\alpha v_i\delta x$）は $v_i$ に比例して強まる → $\lVert w_i\rVert$ がさらに伸びる。診断走でも、最後の跳ねの前から $v_i$ は断続的に動いていた（§1）。比喩を換えるなら「ミュート中にゲインを上げ続けたマイク。ミュートを外した瞬間にハウリングする」。一撃ではなく、ゲイン同士の相互増幅である。

## 4. なぜ分解では出ず、介入で出たか（**Claude の読み・未登録**）

F_self / F_rest の leave-one-out 分解は、同じ残差を割るので**大きさが鏡像**になり、相殺率 99〜99.9% で独立の役割を割り当てられなかった（登録済みの行き止まり）。`BL` はそこを触っていない。**forward で経路を物理的に切り、残る項の状態依存性の違いだけを露出させた。**

- rest: 共通場との結合。ユニット自身の状態にほぼ依らない**ドリフト**
- self: 自分の出力に比例して戻す**バネ**

大きさは分けられなくても、**片方を消したときの系の安定性**は分かれる。これは「力 ≠ 変位」に続く、この系での方法論上の教訓になりうる: **相殺する 2 項は、大きさではなく状態依存性で分けよ。**

## 5. まだ言えないこと（識別性）

1. **`BL` は自己項だけを切っていない。** 同時に $v_i$ の学習と読み出しへの供給も切れている（[[逆伝播漏れ2x2_spec_0902]] §2 の表の 3 行）。したがって「バネ＝自己項」は**まだ同定されていない**
2. 発散の主因が「バネの欠如」か「深さ非依存の駆動」かは、`BL` 単独では分けられない（両方が同時に成立している）
3. §1 の軌道は 1 seed・登録外
4. §3 の「税とバネは同じ項」は代数としては自明だが、**両側で実測して符号が入れ替わることを見た測定はまだ無い**

## 6. これを閉じうる手（起案は Issa 判断・[[運用ルール]] §3）

- **A. 自己項だけ足し戻す腕**: forward は ReLU（出力 0・$v_i$ 凍結のまま）、backward は leaky、そこに leaky-forward の自己項に相当する力を解析的に加算する。安定化して `LR` と同型に振る舞えば §5-1 が閉じる。1 層・少数腕
- **B. 登録走での per-unit 診断**: `BL` は 1.3M 前後で止まるので短い。§1 の形を登録された測定にする
- **C. 減衰型代替勾配**（NeLU 型・[[SUGAR原典照合_0902]]）: 深部で駆動が消えるので発散はしないはず。ただし当方の系では「柔らかい壁のある ReLU」になり LoP は残る、と予想する（未登録）
- **D. 先生の [[ゲート硬さダイヤル_spec_0902]]** が ELU の $\alpha$ 掃引で自己項の深さ依存を 3 分する側を担う。**A は「自己項の有無」、D は「自己項の深さ依存」で、直交する**
