## 2b. 正則化論の反転 — なぜ b 限定 WD が「割に合う」のか（9/1 追加）

**格: 位置づけの論証（登録判定ではない）。実測の裏づけは C4・C5。Issa 採用 9/1（チャット `現象3_b暴走検討_0901`）・先生未承認。**

教科書的な「bias は正則化しない」の論法（例: [d2l weight-decay 章](https://d2l.ai/chapter_linear-regression/weight-decay.html) — 実装ごとに違うが多くの場合 bias は正則化しない、と明記）は、「b は 1 変数のオフセットで推定分散が小さい。0 へ引くと出力水準を失い過少適合する。分散をほぼ削れずバイアスだけ増える、割に合わない取引」。この前段は **b の推定対象が一つで動かない**（定常）ことに立っている。

SCR はこの前提を仕組みで壊す:

1. **目標が移動する。** b の仕事は動作点 $s=w\cdot\mu+b$ の閾値合わせ＝実質 $-w\cdot\mu$ の追跡であり、flip が µ を毎 $T$ ステップ動かす。b は推定でなく**追跡**の問題になり、時間方向に分散が積む（符号が振り直される成分で $\sqrt K$、C2 の無条件の税で $K$。この段は説明枠組みであり、帳簿の self/rest 分解は未測定 — [[現在地]] 穴6・Q17 系）
2. **係留する曲率がない。** 台帳（flip 重み×b の実効オフセット縮退）により損失は b 経由と flip 重み経由のオフセットを区別せず、centered では +b 方向が厳密平坦になる（C1・C3）。損失自身は b を止めない

したがって継続学習では **b が時間方向に分散の育つ側のパラメータ**になり、教科書の取引は符号が反転する:

|              | 定常（教科書）         | SCR・centered                                                       | SCR・std      |
| ------------ | --------------- | ------------------------------------------------------------------ | ------------ |
| b の分散        | ≈0（全データで 1 点推定） | **積む**                                                             | 積む           |
| 0 へ縮める導入バイアス | 大（出力水準を失う）      | **≈0**（C1: $\lVert\mu_{\rm res}\rVert\approx0.075$ → 0 がほぼタスク横断平均） | 中（平均オフセット≠0） |
| 取引           | 割に合わない          | **割に合う**                                                           | 半分           |

- 効き方は平衡式 $\lambda b^\ast=-(\tau+R)$（導出は [[現象2スコープ拡張計画_0901]]・走なし）: 復元力の下で b は有界の $b^\ast$ に止まる。C4 の「自由度の除去ではなく深さの上限」はこの $b^\ast$ のこと
- std の `INCONCLUSIVE_PARTIAL`（C5）と最適 λ の非単調の兆候（穴4）は、std では正しい縮小先がタスク平均オフセット（≠0）にあり $b^2$ ペナルティの引き先がずれる、の帰結として**整合**する（整合であって検証ではない）
- `both`（centering＋b-WD）の相性は「centering が引き先を 0 に直し、WD が分散を削る」という分業として読める

**§3 への帰結**: 「bias を WD から除外する」慣行と**矛盾しない**。慣行は定常前提の分散論法であり、本設定はその前提（b の目標が動かない）を毎 $T$ ステップ壊す側にある — 矛盾ではなく**適用範囲の外**。

## 2c. 機構の読み直し（9/2・自己項分解に依存しない形）

**格: 全体が未登録。** 恒等式は【恒】（走らせずに検算可能）、数値は committed CSV からの**事後計算**、機構の帰属は**仮説**。§1 の C1–C5 の格を書き換えるものではなく、**C2 と C3 の機構欄をどう埋めるかの候補**として置く。作成: チャット `bias_自己顧みない_0902`。

### 2c-1. 核 — 更新則に $b$ が登場しない【恒・Issa 提起】

$$b_i \leftarrow b_i - 2\eta\,\delta\,v_i\,\mathrm{gate}_i$$

右辺に $b_i$ が**読まれる場所が一箇所もない**。曲率 $H_{bb}=2v_i^2p_i$ は $b$ 自身を参照する力ではなく、$\delta$ を経由して**借りてきた錨**である。鎖（$b$ が動く → 関数が動く → $\delta$ が動く → 押し返される）のどこかが切れれば錨は消える。切断は 2 様態:

- **崖側**: gate は指示関数なので 1 サンプルあたりの更新は $b$ について区分定数。壁への近接は「更新が弱まる」ではなく「更新の頻度が下がる」でしか符号化されず、個々の更新はそれを感知できない。**勾配は壁までの距離を一切参照しない**
- **残差側**: $\delta$ が $b$ の変化を登録しない領域では押し返しの平均が厳密ゼロになる

**定常環境が耐えている理由**: batch=1 の勾配はノイズも $\delta$ に乗算的で、定常・実現可能なら $\delta\to0$ でドリフトと拡散が同時に消える。$b$ は復元平衡に達するのではなく**力学が停止した場所に置き去りにされる**。錨の不在は力学が止まっている限り試験されない。§2b の「取引の反転」を、分散論ではなく**錨の有無**として言い直したもの。

**WD の役割**: $-\lambda b_i$ は**更新則に $b$ 自身が初めて登場する項**。$\delta$ にも gate にも乗算されていないので $O(1)$ で、鎖のどこが切れても生き残る（損失由来の項は全部 $O(p)$）。C4 の「深さの上限」は、この $b$ への**固有受容**の付与として書ける。

**登録済み結果との整合**: `GATE_LOAD_BEARING`（ELU/leaky は負側で微分が消えないので借りた錨の伝達路が切断されない）と `ABSORPTION_ISOLATED`（沈下自体は錨を切らない・厳密ゼロだけが切る）を、いずれも自己項分解なしで説明する。

### 2c-3. C3 の機構候補 — centering 由来のゲージ＋飽和の正帰還【仮説】

`config` 確認済み: `cen` 腕は `centered_layers: [1, 2]` で**第2層の入力 $a^{(1)}$ も centering される**。

1. 第2層入力の centering が $b^{(1)}$ の作る直流を明示的に引き算する → $b^{(1)}$ はほぼゲージ
2. 2c-1 により、ゲージ方向では借りた錨も来ない
3. $\hat p\to1$ で ReLU が線形になると $b_i$ は $a_i$ の平均しか動かさなくなり、**ゲージが厳密になる** → 正帰還

「+b 方向が平坦」は仮説ではなく **centering の定義から出る構造**になる。初期条件を要しない点が既存の平坦化仮説との差。

**スケーリング（事後計算・未登録）**: std は指数 0.5（$\sqrt t$ ＝錨なしの拡散）、cen L2 は 0.84（線形ドリフト・IQR は 0.19 でほぼ増えない）、cen L1 は **2.11**（加速）。生存者選択は否定（`b_median_all` が `b_median_alive` とほぼ一致・cen L1 で +3.970 vs +3.973）。**共通の前提は「錨なし」（許可条件）で、速度と向きは駆動側が決める。**

### 2c-5. L1 と L2 の非対称【恒＋仮説】

|              | L1                                | L2                                                       |

### 2c-6. 主張の構造への帰結【裁定対象・§6-3】

統合は**許可条件の層だけ**（更新則に $b$ が無い）で、駆動は C2 と C3 で別物。

- **C2** → 現象1の駆動が centering で $M$ を塞がれて $b$ に出たもの。**系**
- **C3** → ここだけが新規
- **C4** → 変わらず。ただし「$b$ の病気を治す」ではなく「**塞がれた記帳先に固有受容を与える**」

§0 の「双方向の自走」は、許可条件の記述としては正しく、**機構の記述としては 2 つに割れる**。
