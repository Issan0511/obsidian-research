## 0. 一行

**現象2（b 経由の死）の正体は LoP の一種ではなく、centered regime で拘束を失った bias の双方向の自走である。** 下に流れれば痩せて死に、上に流れれば飽和して線形化しランクが潰れる。b に微小な復元力（b 限定 weight decay）を与えると両方向とも止まり、機能はむしろ改善する。この病気は std でも劣化の過半を運んでおり、b 成分を除去した残差が、初めて中心主張（µ/Σ 駆動の壁）どおりに振る舞う。

## 2. 中心主張への帰結

**脅威ではなく純化。** 「centering は治癒でなく遅延」の行はこう読み替わる: *遅延。ただし残る死と劣化は µ の病気ではなく b の自走で、微小な復元力で除去可能。除去後の残差が µ/Σ 駆動の壁の純粋なサンプルになる。* 先生側提案の「吸収域 × 2 チャネル」の書き直しは、同日中の登録 2×2 で裏打ちされた。

## 2b. 正則化論の反転 — なぜ b 限定 WD が「割に合う」のか（9/1 追加）

**格: 位置づけの論証（登録判定ではない）。実測の裏づけは C4・C5。Issa 採用 9/1（チャット `現象3_b暴走検討_0901`）・先生未承認。**

教科書的な「bias は正則化しない」の論法（例: [d2l weight-decay 章](https://d2l.ai/chapter_linear-regression/weight-decay.html) — 実装ごとに違うが多くの場合 bias は正則化しない、と明記）は、「b は 1 変数のオフセットで推定分散が小さい。0 へ引くと出力水準を失い過少適合する。分散をほぼ削れずバイアスだけ増える、割に合わない取引」。この前段は **b の推定対象が一つで動かない**（定常）ことに立っている。

SCR はこの前提を仕組みで壊す:

1. **目標が移動する。** b の仕事は動作点 $s=w\cdot\mu+b$ の閾値合わせ＝実質 $-w\cdot\mu$ の追跡であり、flip が µ を毎 $T$ ステップ動かす。b は推定でなく**追跡**の問題になり、時間方向に分散が積む（符号が振り直される成分で $\sqrt K$、C2 の無条件の税で $K$。この段は説明枠組みであり、帳簿の self/rest 分解は未測定 — [[現在地]] 穴6・Q17 系）
2. **係留する曲率がない。** 台帳（flip 重み×b の実効オフセット縮退）により損失は b 経由と flip 重み経由のオフセットを区別せず、centered では +b 方向が厳密平坦になる（C1・C3）。損失自身は b を止めない

したがって継続学習では **b が時間方向に分散の育つ側のパラメータ**になり、教科書の取引は符号が反転する:

|              | 定常（教科書）         | SCR・centered                                                       | SCR・std      |
| ------------ | --------------- | ------------------------------------------------------------------ | ------------ |
| b の分散        | ≈0（全データで 1 点推定） | **積む**                                                             | 積む           |
| 0 へ縮める導入バイアス | 大（出力水準を失う）      | **≈0**（C1: $\lVert\mu_{\rm res}\rVert\approx0.075$ → 0 がほぼタスク横断平均） | 中（平均オフセット≠0） |
| 取引           | 割に合わない          | **割に合う**                                                           | 半分           |

- 効き方は平衡式 $\lambda b^\ast=-(\tau+R)$（導出は [[現象2スコープ拡張計画_0901]]・走なし）: 復元力の下で b は有界の $b^\ast$ に止まる。C4 の「自由度の除去ではなく深さの上限」はこの $b^\ast$ のこと
- std の `INCONCLUSIVE_PARTIAL`（C5）と最適 λ の非単調の兆候（穴4）は、std では正しい縮小先がタスク平均オフセット（≠0）にあり $b^2$ ペナルティの引き先がずれる、の帰結として**整合**する（整合であって検証ではない）
- `both`（centering＋b-WD）の相性は「centering が引き先を 0 に直し、WD が分散を削る」という分業として読める

**§3 への帰結**: 「bias を WD から除外する」慣行と**矛盾しない**。慣行は定常前提の分散論法であり、本設定はその前提（b の目標が動かない）を毎 $T$ ステップ壊す側にある — 矛盾ではなく**適用範囲の外**。

## 4. 書けないこと（引用制限）

1. `BIAS_ROUTE_DECISIVE` / dead 低下を `LOP_CURED` と読み替えない（frozen で dead 0 と機能 57 倍悪化が両立した前例）
2. 「µ を消した」と書かない — EMA 中心化はタスク可識別性も同時に消す（[[論点マップ]] §20・唯一の実質的な穴）
3. 「2/3 : 1/3」の比を主張に載せない（劣加法・床効果・指標依存）
4. E-drift 単独で引かない（`CEILING_CONTAMINATED`・`LADDER_INVERTS`）。到達水準では `bwd` 単独が最良（−5.20）で順位が入れ替わる
5. 「b-WD が LoP を治す」と一般化しない。スコープ: condA・幅100・$T=10^4$・batch=1・lr=0.01・plain SGD・5M・λ=1e-3。Dohare の Permuted MNIST 等への外挿は未知 → **このスコープをどう狭める／広げるかの計画は [[現象2スコープ拡張計画_0901]]**（計画であって主張ではない。**本行の制限は計画の完了までそのまま有効**）
6. C3 の暴走機構（+b 方向の平坦化）と、深さ2オンライン SGD の稀な発散（WD 起因説はほぼ棄却・慢性/急性未判別）は未解決として引く
