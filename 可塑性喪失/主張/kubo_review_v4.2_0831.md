## 1. 提案1 — 一行を「積」から「吸収域 × 到達」へ

### 1.1 「積」が主張していること

「病理は A と B の積である」は、**どちらか一方を消せば足りる**と述べている。積は対称なので、µ を消すこととゲートを外すことは同じ価値を持つはずである。

### 1.2 実測は対称でない

| 消し方 | 5M での帰趨 | 格 |
|---|---|---|
| **ゲートを外す**（ELU / leaky） | **0/10**。固定用量 4 腕は 1M → 5M で**改善**（`E_933` −2.503 → −2.760、`LR_1216` −2.208 → −2.652） | 事前登録 |
| **µ を消す**（EMA 中心化） | `L2_Aall` B02 → B10 で **+0.3827 [0.3392, 0.4646]**（悪化）。`Aall−none` は **−0.4824 [−0.9315, +0.3418]**＝判定不能 | 事後解析の登録 |
| **µ を完全に消す**（オラクル） | **`strict_dead` 1.000・`unfit` 1.000・復活 0**・全滅到達 task 154–454（10 seed すべて） | 事前登録 |

**片方は時間とともに良くなり、もう片方は時間とともに悪くなる。積ではない。**

### 1.3 提案する構造

> **ReLU のゲートは吸収域そのものを作る。µ と b はそこへの到達を駆動する 2 本のチャネルである。**
>
> 到達を遅くしても吸収域は消えないので、**中心化は時間を買うだけである**。吸収域を消せば、到達がいくら速くても堆積は起きない。

**この形は非対称であることが結論に組み込まれている**ので、「積だが二つの消し方は対等でない」という但し書きが要らなくなる。

### 1.4 この構造は既に vault の中にある

- [[吸収不等式の命題化_0824]]（Q26・厳密）: `p̂ = 0 ⟺ s + M ≤ 0`、`s := w·µ + b`。**µ は `s` の中にしか入らない。吸収域は µ に依らず存在する**
- [[容量不足レジームの機構_0830]] §9: 「**壁はポテンシャルの壁ではなく拡散率の崖である。ゲート付きなので $z<0$ 側で拡散係数が厳密に 0**」

**拡散係数が厳密にゼロの領域は、定義により吸収域である。** §9 は物理の言葉で既に同じことを書いている。足りないのは、それを一行に上げることだけである。

### 1.5 穴12（非単調用量反応）が、この形なら導出される

**これが本提案の中心。** [[現在地]] 穴12 は最優先の未解決として立っているが、**Q19 C2 と組み合わせると予言されていたことになる。**

- **µ チャネル**: `w·µ` 経由。**µ が大きいほど速い**（Q19 C1 `FULL_PASS`）
- **b チャネル**: 税の $b$ 成分 $-2\eta v_i^2\mathbb E[a_i\,\mathrm{gate}_i]\le 0$ は**入力分布に無条件**（Q14・定理）
- **荷重の配分**: $b$ への逃走シェアは $1/(1+\lVert\mu\rVert^2)$（**Q19 C2 事前登録 PASS・傾き +0.8107 [+0.7644, +0.8556]**）

すなわち **µ を下げると µ チャネルは遅くなるが、b チャネルの荷重が上がる。** 2 本の依存が逆向きなので、**合成した到達率は µ について非単調になる。**

実測（5M・layer 1 `strict_dead`）:

| 腕 | ‖µ‖ | `strict_dead` |
|---|---|---|
| `L2_none` | 大 | 0.809 |
| `L1w100_A1`（EMA 中心化） | 中 | **0.469**（最小） |
| `L1w100_Aexact`（µ≡0） | 0 | **1.000** |

**U 字。中間で最小。** 2 チャネルが逆向きに依存する模型の予測と形が一致する。

**[[吸収不等式の命題化_0824]] §6 の予言「µ 非依存の床が残る」が「床が天井だった」になった件も、同じ枠で読める。** µ→0 で残るのは床ではなく、**b チャネルが荷重を 100% 引き受けた状態**である。

**留保**: `Aexact` はタスク可識別性も同時に消しており、[[引用禁止]] B のとおり無交絡な µ 単独介入ではない。**上の U 字は 3 点で、うち 1 点が交絡込みである。** 「非単調である」の記述に使えるが、「b チャネルが原因である」は言えない。分離には [[中心主張v5計画_0831]] §5 の **P-1（condA・centered × `freeze_bias`）**が要る。**P-1 が本提案の直接の判別実験になる。**

### 1.6 一行の案

> **LoP は、ReLU のゲートが吸収域を作り、µ と b がそこへの到達を駆動する現象である。** 吸収域を消せば到達が速くても病理は起きず（用量 12 を固定しても ELU・leaky は 5M まで 0/10）、**到達を遅くするだけでは病理は遅れるか、別チャネルに置き換わる**（EMA 中心化で 5M・2.4 倍悪化、µ≡0 で全滅）。ReLU が特殊なのは、吸収域を作る性質と到達を速める性質を同時に持つ点である。

### 1.7 得られるもの

1. **未決 8（centering の格下げをどう書くか）への回答。** 降格ではなく「**正規化は時間を買うだけで、治しているわけではない**」への置き換え。正規化が標準の実用系への警告として直接使えるので、**主張は弱くならない**
2. **未決 7（2×2 が要因計画でない）が消える。** 吸収域と到達は種類の違う量なので要因計画の対象でない。**N4 の 3 腕・約 35 分が不要になる**
3. **穴12 が「未解決の異常」から「C2 の帰結」に変わる**（§1.5）
4. **[[中心主張v5計画_0831]] 未決 2（現象2 を柱1 に畳むか独立に立てるか）への回答**: **畳める。** 現象1 と現象2 は同じ吸収域への 2 本のチャネルであり、`s = w·µ + b` の 2 項に対応する
5. **反証条件が書ける**: 「両層中心化を十分長く走らせても悪化しない」／「`freeze_bias` を掛けても µ≈0 で死ぬ」

### 1.8 弱点

- **2.4 倍悪化は事後解析**。事前登録された `log10(mean unfit)` では `A_EFFECTIVE` なので、二段構えで書く必要がある
- **0/10 は「観測しなかった」まで**（片側 95% 上限 0.2589）。吸収域が無いことは代数から言えるが、無限時間の主張はできない
- **§1.5 の U 字は 3 点**で、うち 1 点が交絡込み。**回帰ではない**

## 2. 提案2 — `dose` は「向き」を見ていない

### 2.1 [[多層Phase1結果_0829]] の未解決（指標の不整合）

`dose` は `L2_A1` のほうが低い（7.068 対 `L2_none` 7.399・`final_t500`）のに、**第2層 `strict_dead` は `L2_A1` のほうが悪い**（+0.1221 [0.0624, 0.1799]）。「偶然か、正規化の選択が誤りか」として未解決になっている。

### 2.2 `layer_stats.csv` を直読みした結果（事後）

第2層・task 500・10 seed 中央値。出所 `results/mlp2_phase1_0829/layer_stats.csv`（**`verdict.csv` / `summary.md` に無い列なので、[[運用ルール]] §5 教訓⑫に従いファイル名と窓を明記する**）。

| 腕 | `median_M`（µ 項） | `median_B`（b 項） |
|---|---|---|
| `L2_none` | **−1.079** | −1.136 |
| `L2_A1` | **−1.960** | −1.056 |

**b 項はほとんど動いていない。動いたのは µ 項で、約 1.8 倍深い。**

$M_i \approx \text{dose}\times\cos\theta_i$ と近似して逆算すると $\cos\theta$ は **−0.146 → −0.277**。すなわち

> **入力層を中心化すると ‖µ‖ は減るのに、第2層ユニットが µ と逆向きに約 1.9 倍強く整列する。**

`dose` は $\lVert\mu\rVert/\sqrt{\operatorname{tr}\Sigma/d}$ で**向きを含まない**ので、この変化を構造的に取り逃がす。これが不整合の正体である、というのが提案。

**独立な支持（ただし単点）**: 同ファイルの `wcos_mean`・第2層・**seed 0・task 500** は `L2_none` 0.279 に対し `L2_A1` 0.598。**10 seed 中央値は計算していない。** なお [[多層Phase1結果_0829]] §2.5 は `wcos_mean` を**第1層についてのみ**報告しており（0.276 → 0.183 と低下）、**第2層は逆向きである。**

### 2.3 提案

**壁の予測子を `dose` から $s_i = M_i + B_i$ の分布に替える。**

- µ 項と b 項の両方を含む（§1.5 の 2 チャネルと同じ分解）
- 向きを含む
- `exact_layer_record` が $s_i$ と $\mathbb E[z_i]/\mathrm{sd}(z_i)$ の一致を毎走照合している（S1・S2）
- **ユニット単位の `M`・`B`・`denom` が `logs/*.npz` に保存済み。新規の走は不要**

**[[中心主張v5計画_0831]] P-3（整列指標の再定義）への入力になる。** 非 ReLU では `strict_dead` が定義できないが、$s_i$ は活性化関数に依らず定義できる。

### 2.4 弱点

- $\cos\theta$ の逆算は $\sqrt{\hat w^\top\Sigma\hat w}\approx\sigma_{\rm rms}$（$\Sigma$ 等方）を仮定している。第2層入力は相関が強いので**この仮定は弱い**
- `wcos_mean` は seed 0 単点
- **先生側 Claude は当初「$\operatorname{tr}\Sigma$ が縮むので b 項が 1.5 倍深くなる」と予測し、外した。** 機構の説明は取り下げ、指標の提案だけが残る

## 3. 提案3 — 用量の「分散」と、現象3 の自前 signal

**ここは点推定の目視のみ。CI を計算していない。**

### 3.1 9 腕すべてで `off` 腕が最悪

`gate_dose_0830` の 5M 末尾窓 $\log_{10}U$ 中央値（`summary.md`）:

| 活性化 | `*_off`（用量固定なし） | `*_933` | `*_1216` |
|---|---|---|---|
| ReLU | **−0.093** | −0.215 | −0.275 |
| ELU | **−1.970** | −2.760 | −2.726 |
| leaky | **−2.275** | −2.606 | −2.652 |

`dose_const_5m_0830` の 6 腕を合わせると **9 腕すべてで例外なし**。

**平均では説明できない。** `dose_off` の ‖µ‖ は 3.20156、`dose1216` は 3.041 で **5% 差**。しかも固定腕どうしでは高用量のほうがわずかに良いので、5% 高い平均は**良くなる向き**に働く。**そして ELU・leaky では P4 の CI が 0 を含む＝平均の用量に効果が無い。**

> **平均が効かないところで、分散が効いている。**

### 3.2 現象3 の自前 signal は既にあるかもしれない

**[[中心主張v5計画_0831]] §3.5 穴1 は「非 ReLU の LoP の自前観測がゼロ」としているが、水準側には既に動きがある。**

| 腕 | 1M | 5M | 向き |
|---|---|---|---|
| `E_off` | −2.164 | −1.970 | **悪化 0.194** |
| `LR_off` | −3.245 | −2.275 | **悪化 0.970** |
| `E_933` / `E_1216` | −2.503 / −2.254 | −2.760 / −2.726 | 改善 |
| `LR_933` / `LR_1216` | −2.227 / −2.208 | −2.606 / −2.652 | 改善 |

**非 ReLU でも、用量を固定しない腕だけが 1M → 5M で悪化している。** `LR_off` は 1 桁近い。

`n_onset` が 0/10 で飽和しているために二値では見えない。**[[運用ルール]] §5 教訓⑪（二値 endpoint の飽和）そのもの。** 現象3 の存在確認の第一歩は、新しい走ではなく**既存 `gate_dose_0830` の 1M → 5M 水準変化の登録**かもしれない。

**留保**: 事後・点推定・CI なし・腕数 2。腕内の時間対比は `verdict.csv` に登録されていない。

### 3.3 判別実験（オラクル制御は実装済み・目標値を時間の関数にするだけ）

- **腕**: ‖µ‖ をタスク境界ごとに 2.333 と 3.041 で交互に振る（平均 2.687）
- **対照**: ‖µ‖ = 2.687 固定 ＝ **`dose1075`（既に走っている）**

平均が厳密に等しく分散だけ違う 1 因子比較。**ReLU と ELU の両方で回せば、「動く壁が掃いて不可逆に巻き込む」ラチェット説を判別できる**（正しければ害は ReLU でのみ大きい）。

### 3.4 弱点

- `off` 腕は分散だけでなく**オラクル介入そのものが無い**点も違う（3.3 の設計はこれを消す）
- **9 腕の点推定のみ。CI 未計算**
- `off` の ‖µ‖ は $k$ のランダムウォーク由来なので**時間相関を持つ**。単純な分散に還元できない可能性
