## §A. v4 で新しく立った作業

### A1. 柱3 spec の起票【走なし・秘書 task_118】

**目的**: 「`eval_loss` は µ/Σ に対して閾値型」を pilot から confirmation へ上げる。現状の根拠（作業5 `dose_response.csv` の `final_eval_loss_exact` 列）は committed だが事前登録の判定項目ではない。

**内容**: ‖µ‖ 2.33–3.04 の区間を刻む追加 arm を、**結果を見る前に** spec 化する。起票時に確定する設計点:

1. **用量軸**: `center_alpha`（オンライン平均の EMA 更新率）を振り、科学的な用量は実測 bulk `mu_norm`。α ∈ (0, 1e-6) の複数点（実現 ‖µ‖ が 2.4–3.0 に散るよう phase 0 で較正）
2. **endpoint**: run 末尾 1 点ではなく**末尾窓の平均**（タスク周期 T=10⁴ の整数倍）。副 endpoint に `eff_rank`（`lop_metrics_A_w100.csv` に列あり）。**既存 8 arm の窓平均・`eff_rank` は spec 確定前に見ない**
3. **判定候補**: (E1) 用量単調性（seed 別 Spearman・順序違反数）／(E2) 閾値 µ* の推定（`eval_loss` の CI が 0 を外れる最小用量、bootstrap CI つき）／(E3) 遷移幅（`eval_loss` が std 水準の 10%→90% に上がる log‖µ‖ 幅を `strict_dead` の同じ幅と比較）
4. **CI**: seed クラスタ 10 本の percentile CI は反保守的（[[天井T0b上側窓_0829]] の教訓）。studentized（bootstrap-t）を最初から使う
5. **既存 8 arm の扱い**: pilot として別枠。confirmation と合算しない（作業6 の型）
6. **Σ 不変の確認**: 実測の入力共分散（または `ŵᵀΣŵ` の代表値）が arm 間で不変であることを sanity に入れる。これで「‖µ‖ 軸 = µ/Σ 軸」と読める
7. **スコープの明記**: 「**過剰パラメータ化比 1:1（w100 × 教師 LTU 幅 100）で測った閾値である**」と spec 本文に書く（→ A6 が幅依存を判別するまで、µ* は比の関数かもしれない。[[過剰パラメータ化とスコープ条件_0829]]）

**依存**: 先生の承認（未決1・4）。**A2 の前提**。

### A4. µ 考察 §3・§5 の論証を書く【走なし・実験なし】

- **§3 µ の出所**: 正規化なしの ReLU 網では前層の非負出力が次層の µ を自己生成する（[[論点マップ]] §12）。Dohare et al. の設定がこの regime であることを示す。**多層での µ/Σ 実測は未着手**である旨も書く
- **§5 正規化との関係**: LN の置き場所で壁座標の拘束が変わる（Pre-LN は拘束しない／ゲート直前の LN は拘束する）。`b` が LN の落とした平均情報を吸収でき、`b` 駆動と µ 駆動は `1/‖w_i‖` の signature で分離可能。Lyle の LN 有効性・Abbas の CReLU/LN 結果への接続

**関連**: task_116（Q0 の線引きに Clevert bias shift 系を追加）。

### A6. 幅依存の判別 — `alive_final` は定数か比例か【第一手は走なし／第二手は走あり・秘書 task_120】

**目的**: スコープ条件「学習器が教師よりある程度複雑」（8/29 Issa・必須）を満たす測定点が現状ゼロである穴を埋める。

- **第一手（新規走なし）**: `results/coupling_fbw_0813/` の w ∈ {5,10,20,50,100} × 教師 LTU 幅 100 の committed ログから、終端 `dead_frac` の幅依存を読む。全アームが教師以下の幅なので、判別できるのは「スケールの形」まで
- **第二手（新規学習走）**: 教師を固定（H_T = 4 か 8）し、学習器幅 w ∈ {100, 300, 1000}。狙いは **A ∧ B**（学習器 ≫ 教師 かつ 残差が持続）を実際に作ること

**どちらも spec を書く前に数値を見ない。** 詳細と予言は [[過剰パラメータ化とスコープ条件_0829]]。

**A1 との連動**: (i) 絶対定数なら µ* は幅に依らず、A1 の限定は 1 行で済む。(ii) 比例なら µ* はマージン枯渇の閾値なので、A1 に幅アームを足すか、閾値の定義自体を変える。
