## 一行

**LoP は、ReLU が作り、ReLU が閉じる罠である。** ReLU の整流は隠れ層に µ/Σ を作り直し（尺度に対して不変なので重みの大小では消せない）、µ/Σ はユニットの壁座標を重みの方向に結合させて壁への到達を速め、ReLU のゲートは着いた先で勾配を消して戻れなくする。**µ/Σ だけでは無害**（ゲートが片道でなければ用量 12 でも 5M まで 0/10）、**ゲートだけでは弱い**（µ を消せば LoP はほぼ消える）。病理はこの二つの積であり、ReLU は両方を同時に持つ。

> **語の注意**: 「意味のない揺れで」は一行に戻していない（Q17 の帳簿化待ち・未決 3）。「罠」は本文の語として使う（[[用語と記号]] に登録済み）。「悪者」は本文で使わない。

## 位置づけ（v4.1 から変更）

- **正の命題として立てる**（v4 継承）。良性刈り込みへの反例は支持節へ
- **二本柱。** 柱1 = µ が壁を作る（機構・ReLU の性質 A が µ を供給する）、柱2 = 壁は片道である（動力学・ReLU の性質 B が壁を閉じる）。両者の結合は「積の構造」節で述べる。**三本目の柱は立てない**
- **µ/Σ 大は必要条件であって十分条件ではない**（v4 継承）。v4.2 では十分条件が特定された: **ゲートの片道性**。同じ µ/Σ（dose 12.16 固定）でもゲートが片道でなければ 5M まで発症しない
- **閾値を捨てる**（v4.1 継承）。用量を固定して 5M まで走らせると帯内の全用量が発症し、1M で見えた跳びは消える。用量が決めるのは発症までの時間
- **dead も沈下も経由しない。** ELU・leaky では沈下率 36–67% で未フィット率が ReLU の 1/100–1/400。**負に落ちることと LoP は別物**で、病理は「落ちた先で勾配が消えること」
- **スコープ条件**（v4 継承・必須）: 学習器が教師よりある程度複雑な場合に限る。容量は二層（パラメータ／活性部分網）あり、現状の主張は前者にしか立っていない（[[過剰パラメータ化とスコープ条件_0829]]）
- **暗黙バイアスの反証ではない**（v3 継承）
- **文献接続（要執筆）**: (i) **Clevert et al. 2015** の bias shift は「効率」の問題、本主張は「到達可能性」の問題。**差分に測定が付いた**: ELU で第2層入力の ‖µ‖ は ReLU より大きい（2.00 対 1.45）のに LoP が出ず、ゲートが無ければ用量は水準にも効かない（P4）。ELU の効果は平均活性の抑制ではなくゲートによる。(ii) **Dohare et al. 2024** の設定（正規化なし ReLU）は本主張の regime。**⚠ 同付録 B（図 B.10）は SCR で ELU・leaky ReLU にも LoP が残ると報告し（ELU は軽症だが有意）、`gate_dose` の 0/10 と緊張する。** 条件差は SCR/condA・学習器 5 ユニット/w100・深さ 3/1・ホライズン。**解けるまで「ELU / leaky は LoP を防ぐ」と一般には書かない**（[[LoP防止アーキテクチャ_0829]] §7・作業 12）。(iii) **Lyle et al.** の「independence」は共通上流の不在を示さない。(iv) **dying ReLU** 自体は既知。新しいのは、µ とゲートを分離して**ゲートだけが必要条件**であることを固定用量で示した点、**0.683 が尺度不変で入力正規化の無効を説明する**点、そして両者が ReLU の二性質として**同じ活性化関数から出ている**点

## 二本柱（v4.2）

### 柱1: µ が壁を作り、ReLU が µ を作る【機構・性質 A】

#### 1a. 単層 — µ が壁を作る（v3 から継承）

- 死は閉形式 `s + M ≤ 0`。cos 表現で `cos(u,µ̂) ≤ cos_crit = −(b+M)/(‖w‖·‖µ‖)`（[[マージン恒等式と消灯点_0822]] §1）
- ‖µ‖ は壁を **2 経路**で強くする: (i) 位置（cos_crit の分母）、(ii) b の逃走自由度 `1/(1+‖µ‖²)`（同 §1.5）
- **用量反応**（作業5、`673c338`、FULL_PASS）: 8 水準・用量比 41.35 倍。C1 PASS（壁の位置 θ は `a + b/‖µ‖`、`b = −0.2764 [−0.3515, −0.2359]`、seed 別 Spearman 中央値 0.9747）、W1 PASS（exact wall の log 傾き `−0.8613 [−0.8729, −0.8498]`）、C2 PASS（bias 逃走 share 対 `1/(1+‖µ‖²)` の傾き `+0.8107 [+0.7644, +0.8556]`）
- **µ を除去すると壁は定義域外へ出て、dead 0.947 → 0.324**（`ratchet_centered_0822`）。ただし**LoP が消えるのではなく、吸収域への到達が遅くなる**（[[容量不足レジームの機構_0830]] §10・§11）。1M・隠れ1層の w100-centered は task 1 で適合済み（raw eval ≤ 0.005）なのに dead は 0 → 0.202 → 0.294 と進み続け、5M・深さ2 の両層中心化（`L2_Aall`）は `mean(log10 unfit)` が B02 → B10 で **+0.3827 [0.3392, 0.4646]（約 2.4 倍悪化）**。w5 でも遅延は効いており（`dead ≥ 0.6` 持続到達 184k → 451k、約 2.5–2.8 倍）、final snapshot で見えないのは天井効果。残る死は b 経路（µ 考察 §4）

**格**: 用量反応は事前登録 PASS。閉形式の検証・崖位置の MC は事後計算で要昇格（v3 と同じ）。また `L2_Aall` の 5M 悪化は事後解析（`mlp2_centering_delay_posthoc_0830`）であり事前登録ではない。Aall にも第2層 dose ≈ 1.04 が残っているため、**悪化を非 µ 経路に帰属することは本データからは決まらない**（dose ≈ 1 の 5M 挙動は未測定。`dose_const_5m` が測ったのは帯 9.33–12.16 のみ）。

#### 1c. 多層 — ReLU が µ を作り直す（[[多層Phase1結果_0829]]・[[整流定数の尺度不変性_0830]]）

**主張: 壁は各層に立つ。入力層だけを中心化しても壁は消えず、下流の層へ移る。移るのは ReLU 自身が次層の µ を作り直すからで、この再生成は尺度に対して不変であり、重みの大小では逃げられない。**

- **A-1 閉形式と尺度不変性**（代数・判定に使わない）。零平均ガウス事前活性で $g_{\rm ReLU}=\mathbb E[\phi]/\mathrm{sd}(\phi)=1/\sqrt{\pi-1}=0.683$。$\mathrm{ReLU}(cz)=c\,\mathrm{ReLU}(z)$ なので平均も標準偏差も同率で伸縮し、比は $s$ を見ない。ユニット間の尺度不均一性も落ちる（$m_{1,i}=s_i a$、$v_i=s_i^2 b$ より集計比も $a/b$）。**したがって初期化スケール・学習率・ノルム成長のいずれも µ/Σ 比を動かせない。** µ を減らす介入は形を変えるもの（中心化・事前活性平均のシフト・活性化関数の変更）に限られる
- **A-2 実測**（commit 済み）:

|---|---:|---:|---:|---:|---:|---:|

| **入力層のみ中心化** | **7.18** | **+0.405** | **0.002** | **90.7%** | 65.1 | 0.0219 |
| 両層中心化 | 0.95 | （恒真） | — | 53.7% | 98.3 | 0.0092 |

入力層を中心化しても第2層の dose は **early（`early_t2_11`・task 2–11）8.108 → late（`late_t451_500`・task 451–500）7.183** で残り、第2層自身の壁が立ち上がる。第2層入力の実測比は **同じ late 窓で 0.718（中心化）・0.848（無介入）**、**`final_t500`（task 500 単点）で 0.707・0.740**。閉形式 0.683 との照合に使ってきたのは後者である。**入力正規化が隠れ層を守れないのは、性質 A が第2層の用量を作り直すから**

> **窓を混ぜない（8/30 追記・[[運用ルール]] §5 教訓⑫）。** 上の dose（early → late）と実測比（従来は task 500 単点）は**別の窓の量**で、同じ文に並べていた。窓を揃えると: **`L2_A1`（中心化）は task1 0.734 / early 0.811 / late 0.718 / final 0.707 と全窓で 0.71–0.81 に収まる**が、**`L2_none`（無介入）は 1.394 / 1.230 / 0.848 / 0.740 と単調に下がってくる**（`final_t500` の seed 範囲 0.460–1.081）。したがって「実測は閉形式 0.683 と整合」と言えるのは**中心化腕について**であり、**無介入腕については「末尾で 0.683 の近くを通過する」までしか言えない**。出所は `results/layer2_input_stats_0830/window_levels.csv`（`mlp2_phase1_0829` の保存ログの再集計。同 run の `summary.md` には late 窓しか載っていない）。
- **A-3 「無条件」の訂正**。$g$ は事前活性の標準化平均 $\lambda=\mathbb E[z]/\mathrm{sd}(z)$ の関数で、0.683 は $\lambda=0$ の値（感度 $dg/d\lambda\approx0.47$）。実測（**`final_t500` 窓の 0.707 / 0.740**）をガウス仮定で逆算すると $\lambda\approx+0.05$ / $+0.12$ で、ずれの向きは「事前活性の平均がわずかに正」と整合。**逆算値は元にした窓に依存する**ので、引用時に窓を落とさない

**格と限定**（引用時に落とさない）: スコープは condA・2 層・幅 100・batch=1・`center_alpha=0.01`。**実測比を引くときは窓を書く**（0.707 / 0.740 は `final_t500`、0.718 / 0.848 は `late_t451_500`。無介入腕は窓依存が大きい）。A-1 は代数（事前登録なし）。A-3 の $\lambda$ 逆算は二乗平均の意味での等価 $\lambda$。`L2_A2` は数値発散で未検証。「LoP を防いだ」とは書かない（署名 `NO_LOP_PREVENTION_SIGNATURE`）。eff_rank は「死」と「平均支配」を区別しない。

## 積の構造 — µ/Σ と ReLU の絡み合い

二本柱を並べると、病理が**積**であることが 2×2 で読める。LoP の表現型は末尾の未フィット率。

|                      | **片道ゲートあり（ReLU・性質 B）**                                      | **ゲートを外す（ELU / leaky）**            |
| -------------------- | ----------------------------------------------------------- | ---------------------------------- |
| **µ/Σ あり**（帯内・用量固定）  | **10/10 発症・U 0.53–0.81**（`gate_dose` R 腕・1 層）               | **0/10・U 0.002–0.011**（同 E / LR 腕） |
| **µ/Σ を層入力で消す**（中心化） | U 0.0092（`L2_Aall`・2 層両層）／eval_loss 0.0044（作業5 最低用量・1 層・1M） | U 0.0039（`E_Aall`・2 層両層）           |

**LoP が出るのは左上だけ。** 右へ動いても下へ動いても消える。どちらか一方の因子を消せば足りる、という意味で**二つの因子はどちらも必要条件**であり、病理はその積である。

ただし二つの消し方は対等ではない。

- **µ/Σ を消す側（性質 A を消す）は層ごとにしか効かない。** 入力層を中心化しても ReLU が次層に µ を作り直す（柱1 1c）。全層に入れて初めて 0.0092 で、それでも第2層の 54% は死ぬ。中心化には代金もある（[[µ維持の利得_0829]]・condA ではタスク可識別性）。そして尺度では消せない（A-1）
- **ゲートを外す側（性質 B を消す）は一度で効く。** 活性化関数を替えれば全層で壁が消える。ただし実用系で活性化関数を自由に選べるとは限らず（[[LoP防止アーキテクチャ_0829]] §7）、Dohare 付録 B との緊張が未解決

**ReLU が特殊なのは、性質 A と性質 B を同時に持つ点である。** A は「なぜ入力正規化が隠れ層を守れないか」「なぜ重みを小さくしても逃げられないか」の説明、B は「なぜ壁が病理になるか」の説明。**どちらも ReLU の形から出る。** ReLU の整流が用量を供給し、ReLU のゲートが用量を致死にする。

> **格**: 表の 4 セルは別々の走・別々の配置（1 層／2 層、固定用量／中心化）から取っており、**要因計画ではない**。左下・右下は 2 層両層中心化（`L2_Aall` / `E_Aall`）で、右上・左上は 1 層固定用量（`gate_dose`）。同一配置での 2×2 は組んでいない。「積」は 4 セルの符号の構図から読んだ言い方で、交互作用の検定ではない。多層での A と B の分離（leaky の 2 層網で第2層に用量が立ち、かつ死なないこと）は直接測っていない（`LR_A1`・未決 4）。「ReLU が悪い」という言い方は本文でしない。書くのは「A と B の両方を持つ活性化関数では」まで。

**予測（本測定の外・実測なし）**: 観測正規化＋ReLU の網では隠れ層に壁が立つ条件が整う（v4 継承）。**ELU を使う網では立たない**（`E_A1`）。rsl_rl 系の既定が ELU という聞き取りは原典未確認。Adam・幅・教師はすべて外。**予測として書き、測定と混ぜない。**

## µ 考察（v4.1 から更新）

1. **無次元用量の定義**【定義・継承】
2. **用量反応と率**【柱1 1b へ】: 壁の位置（graded）と LoP（率）。閾値は 1M の見かけ
3. **µ の出所と多層での連鎖**【柱1 1c へ】: 正斉次な整流は次層の µ を定数比で自己生成し、尺度では消せない。ELU で沈んだユニットは定数 $-\alpha$ を出し Σ には効かず µ にだけ効く経路があるが、2 層で沈下率 6% では量が足りず dose は減少。**この節の役割は「入力正規化が隠れ層を守れない理由」に限定**
4. **µ→0 でも残る経路（b 経路）**【継承】
5. **正規化との関係**【追加測定あり】: 活性化関数の変更が正規化より強い（`E_A1` 0.0028 対 `L2_Aall` 0.0092）。ELU では第2層の中心化はわずかに悪化させ（+0.128 [+0.087, +0.180]）、第1層の沈下率を 6% → 39% に上げる（機構未解明）。LN は未測定
6. **Clevert bias shift との差分**【測定つき】: 位置づけ節 (i)
7. **収束速度とのトレードオフ**【論点・未検証・継承】
8. **過剰パラメータ化とスコープ条件**【継承】
9. **活性化関数の役割**【積の構造へ】: ELU 沼で立てた「µ が大きいと ELU でも $e^{z}$ の沼に落ちる」仮説は沈下率 1.5%・ドリフト正で空振り。`gate_dose` の Q2 は全腕揺れ支配だが可動度スケーリングは合わず、可動度の絵は主張に使わない
