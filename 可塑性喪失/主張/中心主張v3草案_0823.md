## 位置づけ: 暗黙バイアスの反証ではない。「良性刈り込みへの反例」は再裁定

- **LoP は暗黙バイアスである。** タスク内で µ ブロックは実効閾値 `b_eff` の 1 自由度に縮退し、残る 14 次元は厳密零空間。零空間の中で SGD がどの方向を選ぶかを µ（潮流）が決めている — 教科書的な暗黙バイアスの構造そのもの
- **直接機能量と凍結結果には保護的関連がある。** exact `p_count × pre_max` 層別後も高 `ΔL` 群の `strict_dead` 率が23.5ポイント低い。したがって「学習内容を一切参照しない選抜」は売りにしない
- **ただし容量残存は消えない。** 落とされた W を固定したままスイッチと bias を修復すると失われた損失の93.6%が回復する（柱3）。これは dead unit 単体の価値ではなく、表現全体のオラクル容量診断である
- 主張の型は「暗黙バイアス理論の反証」では**ない**。本系は補間点に達していない（unfit ≈ 0.14）ので、補間点上の選択則を反証することは論理的に不可能。「良性刈り込みへの反例」という旧位置づけも、作業6後は O 単独で支えられるか先生再裁定が必要
- 文献接続: 零損失多様体上のドリフト（[[命題リスト]] §3-1 の正典 Blanc+ / Li+）に対し、**不可逆な容量ロックを伴う事例**を与える

## 三本柱

### 柱1: µ が壁を作る【機構】

- 死は閉形式 `s + M ≤ 0`。cos 表現で `cos(u,µ̂) ≤ cos_crit = −(b+M)/(‖w‖·‖µ‖)`（[[マージン恒等式と消灯点_0822]] §1）
- ‖µ‖ は壁を **2 経路**で強くする: (i) 位置（cos_crit の分母）、(ii) b の逃走自由度 `1/(1+‖µ‖²)`（同 §1.5）
- µ を除去すると壁は定義域外へ出て、dead 0.947 → 0.324（同 §3）
- 崖の位置 −0.15 は初期化則と入力統計だけのゼロパラメータ MC で予言が当たる（同 §2）
- `β ≤ −r` は PB-5 の有界入力版の解析定理（同 §1.3）

**格**: centered 本走は **commit 済**（`ratchet_centered_0822`）。閉形式の検証・2 経路・MC は事後計算で要昇格。β≤−r は走なしで命題化できる。
**残る穴**: 2 経路の寄与分離（µ タイトレーション未実施、同 §9-6）。

### 柱2: 揺れはほぼ対称、境界が非対称（整流）【動力学】

- 撹拌の符号は 49.7 : 50.1、94.9% の個体が +µ 側を訪問、終端で +側に残るのは 0（[[xr分解と生存機構_0822]] §19）
- 上端 = **可逆な天井**（残差依存・自己参照平衡）、下端 = **不可逆な吸収**（勾配恒等ゼロ、16,475,293 ペアで復活 0、同 §14・§20）
- 境界あたりハザードは一定 0.099–0.186（時間依存なし、下げ止まりなし。[[マージン恒等式と消灯点_0822]] §7）
- 「行きは自由、帰りは無い」だけで、時間とともに全員が下端に堆積する
- 揺れの大きさは残差に比例（|Δx| ∝ eval_loss、窓相関 ≈0.96）— **揺れは学習の副産物であり、方向情報を持たない**

**格**: `ratchet_log_0819` の走は事前登録済だが、上記の解析は 8/22–23 事後計算で**要昇格**。
**前提作業**: `p̂ < 0.05` 作業定義の裁定（[[マージン恒等式と消灯点_0822]] §8a。「勾配恒等ゼロ」は p̂≡0 でのみ正しい）。

### 柱3: 容量残存と機能選択性【意義・再裁定】

良性刈り込み仮説（「LoP は不要なユニットを落としているだけ」）を検討する3点。作業6後は、**直接機能量と凍結結果の保護的関連**と**凍結を含む学習済み W 全体の容量残存**を分けて扱う:

1. **強い機能盲目性は否定側**: 独立20系列で、現在タスクの `utility_nmse` high−low の同一タスク末尾 `strict_dead` 調整RDは **−0.2353 [−0.2812, −0.2325]**、事前規則で **PROTECTIVE**。exact `p_count` と `pre_max` 五分位を揃えてもセル内高 `ΔL` 群が死ににくい。観察的関連であり、因果介入とは呼ばない（[[直接機能量による選抜確認_0823]]）
2. **機能代理 r の旧 H は未決着のまま**: any-hit は天井効果、非天井endpointは **INCONCLUSIVE**。直接 `ΔL` の独立確認で置換せず、「代理指標では決着しなかった」という履歴として残す（[[機能盲目性_0823]]）
3. **落とされた W には修復可能な容量が残る**: `dead_0.05` を閾値上へ蹴り上げ、W・vを固定して全 bias + c だけ再最適化すると、seed平均 NMSEは **0.143367 → 0.009148（93.619%回復）**。学習済 W は3破壊対照より良い。ただしdead unit単体の有用性や動的な修復持続は示さない

**機構と結果の区別**: 壁の閉形式に `ΔL` は現れない。しかし、壁が機能量を明示参照しないことから、凍結結果まで機能盲目だとは言えない。作業6では後者が明確に否定された。

**格**: 1 は独立confirmation（結果 commit `ac29d87`、C-S1〜C-S8 PASS、CLI再実行byte一致）。2・3は `function_blind_0823` の再現解析（結果 `4493a14`）で、既知の事後概数を見た後の再現。pilotとconfirmationは合算していない。
