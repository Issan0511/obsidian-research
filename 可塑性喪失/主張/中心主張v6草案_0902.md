## 3. なぜ「ReLU で研究しても意味ない」の形を採らないか（Claude の整理・9/2）

9/2 チャットで最初に出た形は「継続学習界隈は ReLU を使っていたから悪かっただけ」だった。同じ内容を一行の形に置き直した理由は 3 つ。

1. **否定形の主張は等価限界を要求する。** 「意味ない」は (iii) の強い形「非 ReLU では LoP が無い」を含意する。当方が持つのは「CI がゼロをまたぐ」＝判定不能であって、タイトなヌルではない（[[運用ルール]] §5 教訓・等価帯の事前登録）。一行は「観測されない」を**同じ条件**に限定することでこの要求を回避している
2. **跳ね返りがある。** GELU の負側微分は $z\to-\infty$ でガウス裾（$z\phi(z)$ の速さ）で 0 へ落ち、ELU の $e^z$ より速い（**閉形式からの帰結・実験出力ではない**）。つまり現代の主流活性化は「ゲートが無い」のではなく「軟らかいゲート」であり、深く沈めば実質 ReLU に近づく。もし「GELU でも同じ壁に落ちている」なら、ReLU は**極限ケース**であって ReLU で研究する意味はむしろ**ある**。「意味ない」はこの一般化の芽を自分で切る
3. **新規性が薄い。** 「活性化を変えると LoP が減る」は Abbas et al. 2023（CReLU）と Lillo & Cheney 2026（ICLR）が既に言っている。当方が新しいのは「なぜか」（用量固定の介入・沈下と LoP の分離・厳密列挙）であって、主軸を「ReLU 悪い」に置くと新しい部分が脇に落ちる

**「硬さが速度を決める」の形で得るもの**: (a) 肯定形の予言で反証可能、(b) Q21 と同型（ダイヤル → 時間）なので**論文内で構造が揃う**、(c) GELU・SiLU を排除せず硬さ軸上に置ける。

## 4. 「硬さ」の操作的定義（Claude 提案・**未登録**・§9-2 の裁定対象）

一行の (ii) は「硬さ」が測れて初めて命題になる。候補:

$$m^-_i := \mathbb E\big[\varphi'(z_i)\,\big|\,z_i<0\big]$$

**沈下したユニットの残余可動度**。[[現象3指標再定義_P3_0901]] の 3 軸のうち**可動度軸 $m_i=\mathbb E[\varphi']$ を負側に条件付けたもの**なので、新しい指標ではなく既存軸の制限である。

| 活性化             | $m^-$                      | 性質                      |
| --------------- | -------------------------- | ----------------------- |
| ReLU            | 0                          | 定数・最硬                   |
| leaky（傾き $a$）   | $a$                        | **定数**・$a$ が硬さのダイヤルそのもの |
| ELU（$\alpha$=1） | $\mathbb E[e^{z}\mid z<0]$ | **状態依存**（沈下が深いほど硬い）     |
| GELU / SiLU     | ガウス裾                       | **状態依存**・ELU より速く 0 へ   |
| 線形（$a$=1）       | 1                          | 最軟＝ゲート無し                |

**★ 設計上の注意（重要）**: 滑らかな活性化では硬さが**活性化の定数ではなく沈下の深さの関数**になる。すると「硬さが速度を決める」は自己参照的になり得る（沈むほど硬くなり、硬いほど速く沈む → 正のフィードバック）。これは主張の欠陥ではなく、**(ii) を書くときに「硬さ = 活性化の性質 × 沈下の深さ」と宣言する**必要があるということ。leaky だけが硬さを定数として与えるので、**(ii) の一次検証は leaky の $a$ ダイヤルで行うのが筋**（§5 H-1）。
