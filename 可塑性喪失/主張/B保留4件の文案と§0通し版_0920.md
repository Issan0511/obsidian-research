### 1.2 何が問題か

- **B2 の保留理由**: ReLU の話しか書いておらず、負側に傾きを残す類似活性化（leaky・ELU・GELU・SiLU・適応尺度）で駆動と戻りがどうなるかが無い。登録した実測は、その類似活性化のほうで意外な結果を出している（erosion_race M2 `MORE_UPWARD`: leaky .1 と適応 Snake は GELU より**下向きも上向きも大きく**、正味の下向きが小さい）。
- **B8 の分離要求**: 「落ちた入力の自分への勾配は 0」は負側の傾きが厳密に 0 の ReLU にだけ成り立つ恒等式で、類似活性化ではそのまま使えない。厳密に成り立つ範囲と、類似活性化での弱い形を分けて書く。
- **「上回ると」**: 元の文は下向きと上向きの力比べを一文で決めてしまう。実測では両方が大きい腕（leaky・Snake）があり、正味だけを見ると「押していない」と読み違える。正味が下向きであることと、下向きの力が強いことを分ける。
- **格**: 「正味が下向き」の登録は課題 1 の最初の 750 更新・第 1 層だけ（M1）。課題をまたぐ向きは A2 が本走中で、まだ無い。文は A2 の結果を待たずに成り立つ形（条件文）にし、A2 の結果は §0.4 の格の行で受ける（§1.7）。

**群 A — 駆動（活性化によらない部分・4 文）**

> 課題への誤差修正の更新は、共有重みを通じて、修正対象以外の入力の前活性にも及ぶ。入力が非負なら、一つの更新はすべての入力の前活性を同じ向きに動かし、共通位置もその向きに動く。下向きの更新と上向きの更新は同じ経路で伝わり、その正味が下向きのとき、正側に届く入力が侵食され、負側への輸送が進む。正味が下向きであることは、下向きの力が強いことと同じではなく、上向きの更新がどれだけ保たれるかにも依る。

**群 B — 戻る経路（ReLU の厳密な範囲と、類似活性化の弱い形・8 文）**

> 落ちた入力が戻る経路は、活性化で異なる。負側の傾きが厳密に 0 の ReLU では、正側から落ちた入力は自分の誤差から自分の重みへの勾配を失う。戻る経路は他の入力からの共有重みの更新と上流の変化だけになり、侵食は入力ごとに片方向になる。この片方向性が厳密に成り立つのは、負側の傾きが 0 の活性化に限る。負側に非ゼロの傾きを残す活性化では、落ちた入力からの勾配は消えず、傾きの大きさの分だけ弱まる。傾きが指数的に減衰する裾では、深く運ばれるほど戻りは実効的に失われ、片方向性に近づく。実装の訓練の微分が厳密に 0 になる深さでは、経路は ReLU と同じく閉じる。負側に固定の傾きを持つ活性化や、曲がる領域を分布の幅に追随させる活性化では、落ちた入力からの戻りが残る。

次の既存文「有界な入力支持では、…明確な消灯境界が存在する。ReLU はこの境界に達すると…必要ない。」はそのまま続ける。

### 1.5 残す意味と限定

- **書けるもの**: 更新が共有重みで全入力に及ぶこと（恒等式）。非負入力で同符号（一標本 SGD の恒等式。Adam は座標ごとの正規化で大きさが変わり、構造は同じ）。課題 1 初期の正味が下向きであること（登録）。ReLU の片方向性（恒等式）。類似活性化で戻りが傾きの分だけ残ること（恒等式）と、裾で実効的に失われること（条件付き導出）と、厳密 0 で閉じること（登録）。
- **言わないこと**: 「誤差修正が駆動源だと導いた」。「下向きの力が活性化で違うから生き残る」（M2 が否定: 下向きは leaky・Snake のほうが大きい）。速度・崩壊時刻。「負側に傾きがあれば戻れる」（上向きの前活性移動は機能の回復ではない。leaky には幅の経路の劣化が残る）。「谷を持つ GELU・SiLU では自分の勾配が逆向きに働く」を本文で言うこと（§12 の条件付きの読みで、登録した実測がない。書くなら考察）。課題をまたぐ向きを A2 の前に登録として書くこと。
- **PM の蹴り** $w_i^\top\Delta\mu$ は §0.5 の第 2 項に残す。群 A は自己更新の経路だけを書き、上流の経路は群 B の「上流の変化」と §0.3 で受ける。
- **B8 の分離**: 群 B の 2〜4 文目が ReLU の厳密な範囲、5 文目以降が類似活性化。ReLU のラチェットを類似活性化に持ち込まず、類似活性化の弱い形を ReLU に持ち込まない。

**案（三段の形・§0.1 の該当箇所の置き換え・4 文・B8 を 1 句に畳む）**:

> 課題への誤差修正の更新は、共有重みを通じて、修正対象以外の入力の前活性にも及び、入力が非負なら同じ向きに動かす。この作用が正味で下向きに揃うのは課題の切替直後で、誤差が大きい間に限られる。誤差が小さくなると、縮める更新も伸ばす更新も小さくなり、切替で動いた分はそのまま残る。落ちた入力は自分の誤差からは戻れず（ReLU では厳密に、負側に傾きを残す活性化では傾きの分だけ弱く）、課題の間に沈降を運ぶのは上流の入力平均と重みの成長である。

格: 1 文目は恒等式。2 文目は登録（課題 1 の M1、課題間の M3x 5/5）。3 文目は A2 の後続 S（記述・4/5 正・数%）と §12.7（一歩の下降から正味は出ない）。4 文目の前半は恒等式（φ′=0）と §1.3a、後半は登録（A2 の U 5/5 負・A6 補助窓・S5 `RESCUED`）。PM の蹴り $w_i^\top\Delta\mu$ は「切替の衝撃」の別の形として §0.5 に残る。**言わないこと**: 「残りは直せ圧が勝つ」（この箱では逆）、「上流が単独で運ぶ」（A6 主窓は交差 60%）、「条件の頻度 = 移動量」。

この案を採るなら §0.3 の「押し戻され続けること」（戻れないの 2 つ目の意味）は「切替のたびに押されること」に言い換える候補になる（MNIST の respdyn の「押しの持続」は課題内の一様な沈みで、CIFAR の A2 とは形が違う。両方の箱を見てから）。

#### 1.8b 正負の非対称を入れた案 v2（2026-09-21・Issa「正負の勾配の非対称は言わなくていいの？」）

§1.8 の案は「いつ下がるか」（切替直後）だけ書いて「なぜ下向きか」を書いていない。理由は二つの非対称で、[[駆動源問題_0909]] に既にある。

- **誤差の大きさの非対称（CE）**: 誤差修正の要求は間違えている標本で大きく、合っている標本ではほぼ消える。[[なぜ下がるか_活性化誤差の分解_事後_0910]] §1: 誤答標本は 11〜13% しかないのに正側の平均誤差が 10 倍（+1.9e−3 対 −2.1e−4）で正答標本の「増やせ」と釣り合う。切替直後（更新 1–20）は誤答 77%。CE の勾配が確信した誤答で大きいのは損失の性質（導出）、比の数字は PM-MNIST 箱 B の事後。
- **折れ目の両側の非対称（ゲート）**: 正側で応答している入力への「縮めろ」は傾き 1 で重みに届くが、負側にある入力への「伸ばせ」はその入力での傾き φ′ を通してしか届かない（恒等式・連鎖律）。ReLU では通らず、leaky では a 倍、裾では指数的に弱く、帯を幅に追随させる活性化では通る。同 §1 の 4: 切替直後の負側の「増やせ」は生で −12780、ゲート（a=0.1）後で −1278、正側の「減らせ」+2740 が勝って正味が下げ。[[駆動源の力の曲線_事後_0910]] §B: 負側の押し返しの比は leaky 0.25・ELU 0.84・Snake 0.93（事後）。Adam は負側ゲートの大きさを部分的に正規化する（浮きは a^0.3・同 §I）。

この二つで、切替直後の下向きの揃い（登録: M1 `CONF_NEGATIVE_DOMINANT`・A2 M3x `BOUNDARY_ENRICHED`）と、leaky・適応 Snake が GELU より上向きの移動が大きいこと（登録: erosion_race M2 `MORE_UPWARD`・上向き 351 / 548 対 75、正味 68 / 12 対 78）が同じ機構で読める。**これが B2 に欠けていた「ReLU 以外の類似活性化の説明」**で、戻る経路（§1.8 案の 4 文目）とは同じ恒等式の別の役割（切替時に既に負側にいる入力への「伸ばせ」が通るか、落ちた入力が自分の誤差で戻れるか）。

**案 v2（§0.1 の該当箇所の置き換え・8 文）**:

> 課題への誤差修正の更新は、共有重みを通じて、修正対象以外の入力の前活性にも及び、入力が非負なら同じ向きに動かす。この要求には二つの非対称がある。誤差修正の要求は間違えている標本で大きく、合っている標本ではほぼ消える。また、正側で応答している入力への「縮めろ」は傾き 1 で重みに届くが、負側にある入力への「伸ばせ」はその入力での傾きを通してしか届かない。課題の切替直後はほとんどの標本を間違えるので、正側で応答している入力への「縮めろ」が揃い、共通位置は下向きに動く。負側に傾きを残す活性化では「伸ばせ」の一部が通るので上向きの更新が大きくなり、正味の沈みが減る。誤差が小さくなると、縮める要求も伸ばす要求も小さくなり、切替で動いた分はそのまま残る。落ちた入力は自分の誤差からは戻れず（ReLU では厳密に、負側に傾きを残す活性化では傾きの分だけ弱く）、課題の間に沈降を運ぶのは上流の入力平均と重みの成長である。

格: 1 恒等式／2–3 CE の性質（導出）＋比は事後（MNIST）／4 恒等式／5 登録（M1・M3x）＋導出 §12.1／6 登録（M2・raw RL-CIFAR・課題 1 の 750 更新・第 1 層・leaky .1 と適応 Snake 対 GELU）、機構の読みは事後（ゲート比）／7 A2 後続 S（記述）＋ §12.7／8 恒等式＋ §1.3a＋登録（A2 U・A6 補助窓・S5）。

**言わないこと**: 「誤答の勾配は 10 倍」を CIFAR に持ち込む（PM-MNIST の事後）。「Snake は押しが弱い」（下向きも大きい・M2）。「谷の奥では自分の勾配が逆向き」を本文で言う（§12 の条件付きの読み・考察行き）。「負側に傾きがあれば戻れる」（上向きの移動は機能の回復ではない）。「上流が単独で運ぶ」（A6 主窓は交差 60%）。

B8 の分離はこの版では: 4 文目と 8 文目の括弧が ReLU の厳密な範囲（φ′=0 で通らない・戻れない）、6 文目と 8 文目の「傾きの分だけ」が類似活性化の弱い形。§0.2 の B5 採用文（裾で局所応答が消える）と §0.3 の三つの意味（厳密 0 で自力で戻れない）はそのまま。

### 2.2 文案 A — 中心化の系譜（「効率」から「配置」へ）

> 層入力の平均をゼロに寄せることは、収束を速める工夫として古くから知られている。LeCun らは、入力変数の平均をゼロに近づけると収束が速くなり、隠れ層の出力も次層の入力として同じ扱いを受けると述べた。Clevert らは、重みの更新でユニットの平均出力が動くことを bias shift と呼び、平均をゼロに寄せる活性化（ELU）がこれを減らして学習を速めるとした。Salimans と Kingma は、ミニバッチ平均だけを引いて分散で割らない mean-only batch normalization を提案した。これらはいずれも最適化の効率の議論であり、可塑性喪失には結びつけていない。本研究は同じ操作を、重みの更新が入力平均への投影を通じて前活性の共通位置を動かすという幾何に置き直し、その経路を中間層で遮断すると、乱数ラベル CIFAR の ReLU MLP で再学習能力が保たれること（bias の減衰と併せて 200 課題まで）を示す。

### 2.3 文案 B — 可塑性喪失の文献での正規化と活性化

> 可塑性喪失の文献では、正規化層は介入の一つとして扱われてきた。Kumar らは Layer Norm が喪失の一部しか防がないことを乱数ラベル MNIST（Baseline 0.16・LN 0.54・L2 Init 0.86）と 5+1 CIFAR（LN 0.51・L2 Init 0.67）で示し、Lewandowski らは乱数ラベル MNIST の MLP で LN を入れると水準は上がるが課題が進むにつれ単調に下がることを図で示している。Lyle らは正規化層を平均の減算と分散での再尺度化に分け、利得の大半は後者に帰属すると結論した。同じ論文の付録は二段で、MLP は batch 軸の平均減算が無いと訓練が苦しいこと、その利得の大半が入力の中心化で再現したことを報告する。本研究の結果は前半と同じ向きで、後半とは異なる（入力の中心化だけでは第 2 層が沈む）。差の候補は箱にある（彼らは L2 1e−5・50,000 更新・100 反復、本研究は WD なし・30,000 更新 × 50 課題で、raw の入力平均が 3 桁大きい）。姉妹論文の付録は中心化が飽和への頑健さに目立った効果を持たないとするが、その足場は訓練した網ではなく等方ガウスのランダムウォークである。
>
> 活性化については、Dohare らが Slowly-Changing Regression で ELU の喪失は軽いが有意に残ると報告し、Lillo と Cheney は 17 種の活性化を 5 つのベンチマークで比べ、死んだユニットの割合と精度の相関（r = −0.51）と、負側に実効的な非ゼロの傾きを持つ群が生き残りやすいことを示した。彼らは負側の傾きに 0.6–0.9 の帯があるとしつつ、規則ではなく活性化と設定で変わりうると但し書きしている。本研究はこの括りを既知として引き、その群が自然な学習でいつ裾に届くか（輸送の担い手と介入）、届いたらなぜ戻れないか（条件付き導出と押しの持続）、どう機能的に死ぬか（訓練の微分と両方向の介入）を足す。さらに、曲がる領域を分布の幅に追随させる第三の枝（kunekune・適応 Snake）は、照合した範囲では乱数ラベル CIFAR の MLP で誰も回していない。Snake は Ziyin らの周期活性化、Deep Fourier は Lewandowski らの sin と cos の連結、CReLU は Shang らの提案を Abbas らが可塑性に用いたもので、本研究はこれらを同じ箱の対照として置く。

### 2.4 文案 C — 手法比較（L2 Init との並べ方）

> Kumar らの L2 Init（初期重みへの L2）は 5+1 CIFAR で他手法を大きく上回る（0.67）。本研究の 5+1 CIFAR × MLP では、原典の λ = 1e−2 の L2 Init は ReLU の喪失を消すが適応 Snake に 20 seed 中 19 で負け（kunekune は適応 Snake と 20 seed で同等）、箱で最良の λ = 1e−3 を与えると ±0.5 pt で同等だった。活性化側は 3 箱とも既定値のままである。書けるのは「原典の λ には勝ち、調整した λ とは同等。正則化項なし・箱ごとの再調整なしで同じ水準」までで、「活性化が L2 Init に勝つ」とは書かない。原典は CNN で、MLP に移すと順位は移らない（Deep Fourier は 16 腕中 15 位。Lillo と Cheney は L2 Init が Deep Fourier を 72.29 から 20.40 に壊すと報告している）。

### 3.1 文案

## 4. §0 の通し版

### 4.1 三段落（通し・【 】なし・B2＋B8 の群 A・B を入れた形）

> 本研究は、可塑性喪失のうち、負側の飽和を介する経路を対象とする。

**第一段落 — μ の幾何と中心化**

> 飽和型可塑性喪失の土台には、入力平均への投影が前活性分布の共通位置の重み側の成分を厳密に決める幾何がある。各層の前活性は、共通位置 $w_i^\top\mu+b_i$ と入力ごとの揺らぎ $w_i^\top(x-\mu)$ に分かれる。特徴を学ぶ同じ重みの更新が、その μ 方向成分を通じて共通位置にも作用するという「硬い」投影関係が存在する。bias は投影を介さずに共通位置を動かすもう一つのレバーである。ReLU型活性化は、正側の出力を通す一方で、負側の出力を切り捨てたり圧縮したりする。この正負非対称性は、前活性の平均がゼロであっても出力の正負の釣合いを崩し、次層に非ゼロの入力平均を生みやすい。そのため、入力平均を介して重みの更新が前活性の共通位置にも作用するという配置の問題は、外部データの偏りに限らず、ネットワーク内部の整流によっても再形成される。課題への誤差修正の更新は、共有重みを通じて、修正対象以外の入力の前活性にも及ぶ。入力が非負なら、一つの更新はすべての入力の前活性を同じ向きに動かし、共通位置もその向きに動く。下向きの更新と上向きの更新は同じ経路で伝わり、その正味が下向きのとき、正側に届く入力が侵食され、負側への輸送が進む。正味が下向きであることは、下向きの力が強いことと同じではなく、上向きの更新がどれだけ保たれるかにも依る。落ちた入力が戻る経路は、活性化で異なる。負側の傾きが厳密に 0 の ReLU では、正側から落ちた入力は自分の誤差から自分の重みへの勾配を失う。戻る経路は他の入力からの共有重みの更新と上流の変化だけになり、侵食は入力ごとに片方向になる。この片方向性が厳密に成り立つのは、負側の傾きが 0 の活性化に限る。負側に非ゼロの傾きを残す活性化では、落ちた入力からの勾配は消えず、傾きの大きさの分だけ弱まる。傾きが指数的に減衰する裾では、深く運ばれるほど戻りは実効的に失われ、片方向性に近づく。実装の訓練の微分が厳密に 0 になる深さでは、経路は ReLU と同じく閉じる。負側に固定の傾きを持つ活性化や、曲がる領域を分布の幅に追随させる活性化では、落ちた入力からの戻りが残る。有界な入力支持では、共通位置から入力ごとの揺らぎが最も上に届いても正側へ出られなくなる、明確な消灯境界が存在する。ReLU はこの境界に達すると対象の全入力への局所応答を失い、その死亡に重みの発散や深い負側への輸送は必要ない。
>
> 層入力の中心化は、重みの更新が入力平均への投影を介して前活性の共通位置を動かす経路を取り除く。ただし、bias はこの投影を介さずに共通位置を動かすため、その経路は残る。実際、中間層まで中心化した条件では50タスクまでは学習能力が保たれた一方、より長い200タスクではbiasの成長に伴って10 seed中7 seedが崩壊した。これに対しbiasにも減衰を加えると、200タスクまで10 seedすべてで学習能力が保たれた。したがって、中心化が遮断するのは共通位置を動かすすべての経路ではなく、重みと入力平均の投影を介する経路である。

**第二段落 — 駆動・進行・活性化の分岐**

> この駆動に重みの成長や上流入力の変化が重なり、前活性が負側へ際限なく運ばれ続けると、正側で傾きを保ち、負側では傾きがゼロへ漸近する固定尺度のReLU型活性化は、その種類によらず、運ばれた入力への局所応答を維持できない。さらに、負側の傾きの大きさが指数的以上に減衰し、下流からの修正要求と層入力の大きさが深さに対して多項式程度にしか増大しないなら、その入力に由来する重みの勾配もゼロへ向かう。一方、負側に非ゼロの傾きを保つ活性化では、同じ負側への輸送によって局所応答が消失することはない。ただし折れ目が固定されていれば、輸送は入力ごとの傾きの切替を奪う（片側化）。曲がる領域を分布の幅に追随させる活性化では、共通位置が帯の中にある限り入力ごとの傾きの違いが残り、帯の外では傾き 1 の直線が応答を保つ。

**第三段落 — 再学習能力への接続**

> 局所応答が弱まっても、他の入力からの共有重みの更新や上流層の変化によって、輸送は続き得る。輸送によって課題に必要な応答が失われ、その再形成や他のユニット・層による補償でも埋め合わせられなくなると、新しい課題を学ぶ能力が低下する。戻れないことには三つの意味がある。訓練の微分が厳密に 0 になって自力で戻れないこと、押し戻され続けること、成長の下で微分の担い手を保てないこと。本研究は、入力平均を介した配置、誤差修正による駆動、重み成長による進行、活性化による応答の分岐を結び、課題に必要な応答が失われ、その回復や維持も妨げられる過程として、飽和型可塑性喪失を説明する。
