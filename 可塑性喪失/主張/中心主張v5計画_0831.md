### 1.1 「今までは 1/3」の精密化（Claude の整理・未登録）

**現象1 と現象2 は同じ吸収域・同じ片道ゲートを共有しており、違うのは輸送チャネルだけ**である。消灯条件は [[吸収不等式の命題化_0824]]（Q26）の一本で、

```
p̂ = 0  ⟺  s + M ≤ 0  ⟺  β ≤ −κ ,   s := w·µ + b ,  κ := ‖w_free‖₁/‖w_free‖₂ ∈ [1, √5]
```

µ は $s$ の中にしか入らない。したがって

- **柱2（壁は片道で、片道が病理を作る）は現象1・2 の両方を覆う。** ゲート交換実験 `gate_dose_0830`（用量を帯内に固定し活性化だけを替える介入）の `GATE_LOAD_BEARING` は µ の水準に依存しない主張
- **縮んだのは柱1 だけ。** しかも柱1 は 8/31 の非単調用量反応（§2.2）で既に書き直しを要求されている

**よって「1/3 に縮んだ」ではなく「柱1 が µ の三役のうち一役しか見ていなかった」が正確**、というのが現時点の読み（**未登録・Issa/先生の裁定対象**）。

## 2. 現象2（b 経由の死）— 骨格は定理級、決定打がない

### 2.1 理論として確立していること

1. **吸収域は µ に依らず存在する**（Q26・**厳密**。ただし Issa 未確認 4 点が残る）。$\lVert\mu\rVert\to0$ では $s\to b$ となり吸収域は $D\to\{b+M\le0\}$ に**退化するだけで消えない**。消えるのは cos 側の壁（$\cos_{\rm crit}$ が定義域 $[-1,1]$ の外へ退場）のみ
2. **$b$ を沈める力は入力分布に無条件**（Q14・[[自己項の恒等式]]・**定理**）。税（自己項 $=\nabla\mathbb E[o_i^2]$）の $b$ 成分 $-2\eta v_i^2\mathbb E[a_i\,\mathrm{gate}_i]\le0$ は µ も condA も要らない。$v$ 成分（$\lvert v\rvert$ の乗法減衰）も無条件
3. **µ は三役を持ち、向きが揃っていない**（Claude 解釈・**未登録**）:
	(i) 壁の位置と輸送（Q19 C1 FULL_PASS）→ µ 大で死ぬ／
	(ii) $b$ の勾配分担 $1/(1+\lVert\mu\rVert^2)$（Q19 C2・傾き +0.8107 [+0.7644, +0.8556]）→ µ 小で $b$ が荷重を全部負う
	(iii) 境界ごとの吸収域の引き直し＝唯一の脱出路 → µ≡0 で復活 0

### 2.3 何が言えて何が言えないか

**言える**: $b$ 経路の死は実在する。押し下げ力は理論的に無条件。吸収域とゲート片道性は現象1 と共通。µ=0 側でも十分な時間（5M）で機能劣化まで進む。

**言えない**:

- **「Dead は確立、LoP は未確立」。** condB では dead と機能が解離（PB-7・G0）。condA 5M で初めて機能劣化が出たが交絡が 2 本（`L2_Aall` に残る第2層 dose ≈1.04、`Aexact` のタスク可識別性）
- 「µ が保護的」「centering を完全にすれば防げる」はどちらも書けない（[[引用禁止]] B に登録済み）

### 2.4 穴

## 3. 現象3（整列・ゲート非依存）— 力は埋まっている、状態はゼロ

### 3.1 理論

1. **共通場モデル**（`theory_v2` 8/11・作業仮説）: 整列力の正体は Kuramoto 型の相互引力ではなく**共通外場**（相互作用項の係数は $v_iv_j$ に比例し、同符号なら反発）。µ 項の係数は $v_i$ に比例するので**力場は厳密二極**（Q1・**力場レベル限定**）
2. **$\lambda_{\rm align}$ と $\lambda_{\rm lock}$ の分離**: $1/D^\star=\alpha+\beta\lVert\mu\rVert^2$。$\alpha$ 側（$\lambda_{\rm align}$）が **µ 非依存の整列力**であり、**µ=0 でも整列は残る**という予言 — **現象3 の理論的な種はここにある**
3. **整列は学習の帰結ではなく構造的に最初から存在する**（怪文書検証・恒等式 $\mathbb E[g_{W_i}]=2v_i\mathbb E[\delta\cdot\mathrm{gate}\cdot x]$ を相対誤差 1.5e-6 で確認）
4. **穴 B-1（最重要）**: 力場の整列 → **生存者**の整列 → ランク低下、という橋は**未導出**。8/21 にこの橋を中心主張から外し、ランク低下は dead 経由（Q9b）で立て直した経緯がある。**現行の中心主張に「整列」の行は無い**
5. 恒等式の成立条件（Q13）は**ユニット加法性（1 隠れ層＋線形読み出し）＋二乗損失**。多層・非 ReLU での理論は未整備

### 4.2 ★ 設計上の縮退（先に潰さないと仮説が検証できない）

**condA では rnd 5 bit だけが分散を持つので、「$r$ 側」と「$\Sigma$ のサポート」は同一の 5 座標である。** したがって「$r$ が効く」説と「$\Sigma$ が効く」説は**このベンチマーク上で原理的に区別できない**。分けるには condB か、$\Sigma$ を独立に動かす新設計が要る。これは [[論点マップ]] §20 の可識別性交絡と**同型の、しかし別の**縮退。

### 4.3 仮説の翻訳案（Claude・未登録）

既存記録と整合させると、仮説は「$r$・$\Sigma$ が殺す」ではなく次の形に置き直すのが自然に見える。

> **現象3 ＝ 保護装置（$r$ 側のスパン・配置・成長）の故障であり、故障を駆動するのは $\Sigma$ 上の残差誘起力である。**

この形なら既存の 3 つのアンカーに直接載る: 候補2 後半（同本数でも到達可能な損失より 0.25–0.34 悪く、$v$ の最小二乗 refit で埋まらない＝**配置の質**の破壊）／候補7（w100 は初期特徴だけで rank 32 完全補間、w5 は rank 3–5・NMSE 0.926＝**スパン冗長性が幅の保護**）／候補5（cross-moment 力の再生）。

**留保**: 3 つとも**事後・ReLU 腕**。非 ReLU では一度も測っていない。
