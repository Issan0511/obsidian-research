## 1. v6 か v6.0 か → **v6.0 を v4.2 の後継とし、v6 は予言ノートとして残す**

[[中心主張v6.0草案_0902]] §6 の案を採る。**理由を 1 つ足す。**

### ★ v6 の一行は内部で不整合である

v6 の一行は (ii) で「**硬さは連続量**」と言いながら、(iii) で「**硬いゲートを持たない活性化**」と二値で切っている。v6 §4 自身が「滑らかな活性化では硬さが状態依存になる」と気づいているが、**それなら (iii) の主語が壊れている。**

U4 の再集計がこれを裏づけた。沈んだユニットの可動度 $\varphi'$ は

| 活性化             | 沈んだユニットの $\varphi'$                                |
| --------------- | -------------------------------------------------- |
| ReLU            | $0$                                                |
| leaky（$a$=0.1）  | **一律 $0.1$**（深さ非依存）                                |
| ELU（$\alpha$=1） | 深さ 6–22 で $2.5\times10^{-3}$ 〜 $2.7\times10^{-10}$ |

**1.6 〜 8.6 桁違う。「硬いゲートを持たない」というカテゴリに ELU と leaky を同居させられない。**

### そのほかの理由 3 つ

1. **格の混在。** v6 の一行は「確立（i）」「予言（ii）」「スコープ限定の観測（iii）」を 1 文に混ぜている。H-1 が外れると一行ごと倒れる。v6.0 は全行が committed
2. **(ii) の新規性が束 1 で削れた。** 「多様化 ↔ 勾配の残り」のトレードオフの存在自体は Joudaki 2025（rank–plasticity tension）に先行がある。差分は「ELU について恒等式である」ことだけ
3. **埋まるまでの距離が違う。** v6.0 の未完は行 12（順逆分離）だけで **15 分級**（`bwd_leak_0902` 段 1）。v6 の (ii) は `gate_dial_0902` で **2.2 時間**

### ★ ただし v6 を捨てない

「硬さダイヤル → 発症時間」は**肯定形で反証可能**であり、Q21（用量ダイヤル → 時間）と構造が揃う。論文は「**解剖（v6.0）＋ 予言（v6）**」の 2 段構えが強い。

### ★ ただし「硬さ」を 1 つのスカラーにしようとするのは無理

U4 で分かったのは、**視野によって効く量が違う**ことである。

- **短い視野**: 可動度 $\varphi'$（瞬間量）。v6 §4 の $m^-=\mathbb E[\varphi'\mid z<0]$ がこれ
- **長い視野**: 自己項 $\varphi\varphi'$ の深さ依存（脱出）。[[帯拘束ゲートとELU実効吸収_0902]] §6-1 の 3 分類がこれ

**別の量なので、視野が違えば別の順序を与えうる。** 単一スカラーに畳もうとすると 2 つが混ざる。

**この裁定は [[ゲート硬さダイヤル_spec_0902]] §5.4 の V3 で下すのが正しい。** 同 spec が「どの予測子（$m^-$／$u_{\rm fr}$／凍結＋谷率）が並べるか」を表で見せ、**ラベルを置かない**設計にしているのは適切である。

## 2. 一行の文言 → **「帰着する」は強すぎる**

消去法が示したのは「**試した範囲で**単独では病理を作らない」までである。[[中心主張v6.0草案_0902]] §5-4 が自認するとおり**試していない性質**（正側の非有界性・線形性）が残り、行 12 が未走なので**一行の名詞「勾配」に証拠がない**。

**対案:**

> **ReLU の LoP は、片道ゲートと押し下げ力（µ または b）が組んだときにだけ、同じ条件で観測される。沈下・非滑らかさ・正斉次性・用量の大きさは、それぞれ単独では病理を作らない。**

「帰着」も「必要条件」も使わず、**全行が committed** で、**「同じ条件で」を運べる**。

## ★ 訂正 1（2026-09-02・同日）—— §4 の「checkpoint が無い」は誤り

**§4 の「`results/gate_dose_0830/` の出力は 8 ファイルだけで `logs/` も checkpoint も無い」は誤りである。**

`bwd_leak_0902` の結果ノート §4.3 が **`ckpts/R_*_step5000000.pt`** を実際に使っている。**checkpoint は存在する。** 同ノートは `results/gate_dose_0830/logs/*.npz` も使っており、**`logs/` も存在する。**

**原因**: 使用したディレクトリ一覧ツールが**ディレクトリを表示しない**（再帰指定でも同じ 8 ファイルしか返らなかった）。**ファイルだけを見て「無い」と断定した。** §6 の引用上の注意に「`logs/` が別の場所にある可能性は排除していない」と留保は書いたが、**留保を書いたうえで §4 で断定したこと自体が誤り**である。

### 撤回するもの

- **「`u_esc` の probe（U1）は再走が要る（ELU・leaky 各 12 分＋probe）」を撤回する。** 再走が要るとは限らない
- [[帯拘束ゲートとELU実効吸収_0902]] §6-6 の「U1 に要る checkpoint が `gate_dose_0830` に残っているかは**未確認**（`results/` 直下には見当たらない）」も、**同じ観察に基づくので同時に解消する**（あちらは断定していないので撤回は要らないが、**存在が確認された**）

### 撤回しないもの

**§4 の結論（U1 を先に置かない）は変えない。** 理由は checkpoint の有無と独立である —— [[ゲート硬さダイヤル_spec_0902]] の新規ロガー `layer1_mob` $=\mathbb E_x[\varphi'(z_i)]$ が、短い視野の予言の中核量（沈んだユニットの可動度）を**直接与える**。probe はその差を見てからでよい。

### 残る確認

- **`ckpts/` にどの step の checkpoint が何腕分あるか。** 結果ノートが使ったのは `R_*` の 5M 時点のみで、**ELU・leaky 腕にもあるかは未確認**
- `logs/*.npz` にユニット別 $v_i$ が無いことは結果ノート §4.3 が明記している（だから checkpoint 経由を使った）

### 一般化した教訓

**「ファイルが無い」を一覧ツール 1 本で断定しない。** 一覧が何を表示しないか（ディレクトリ・隠しファイル・再帰の挙動）を確認するか、**それを使っている他の文書から逆に存在を確かめる**。今回は後者（相手の結果ノートが実際にパスを使っていた）で判明した。
