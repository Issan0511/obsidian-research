## 0. 一行

**非 ReLU の LoP（現象3）は「現象1 の押し下げ ＋ 活性化固有の戻り道」に分解できる。** 沈下までは 20 腕すべてで同じ数字（$w\cdot\mu$ 9 割・$b$ 1 割）で、活性化が決めるのは沈んだ後の戻り道だけ。戻り道は **凍結（ReLU）／線形復元（leaky）／指数復元（ELU）／反転＝逃走（SiLU・GELU）** の 4 型で、**戻り道が押し下げに負ければ、硬いゲートを持たない活性化でも同じ条件で LoP が出る**（V6 (iii) の否定）。逃走型は谷の向こうで自分から沈むため ReLU を追い越し、**谷を埋める介入でその成分だけが消える**（`FLIGHT_CARRIES_OVERSHOOT`）。

## 2. 中心主張への帰結（提案・裁定待ち）

1. **V6 硬さ版 (iii) は否定された。** 「硬いゲートを持たない活性化では同じ条件で LoP が観測されない」は標準 GELU（C4）で反例。書き直すなら「ELU α=1・leaky a=0.1 の 2 点では観測されなかった」まで（[[ゲート硬さダイヤル結果_0902]] §9 と同じ）
2. **現象3 の定義の書き換え（提案）**: 「ゲート非依存の LoP」ではなく「**戻り道依存の LoP**」。現象1・2 が「押し下げ × 厳密吸収」なら、現象3 は「同じ押し下げ × 活性化ごとの戻り道」で、**3 現象は同じ押し下げを共有し、吸収の側だけが違う**（[[中心主張v5計画_0831]] §1.1 の「同一吸収域への 2 チャネル」を非 ReLU まで延長した形）
3. **V6 (ii)「硬さが速度を決める」**: ELU で坂として支持、leaky は崖、滑らかなゲートは追い越し。**硬さはスカラーではない**（[[v6分岐の裁定_0902]] §1 と整合）。単一スカラーの代わりに「戻り道の型」で書くほうが予言力がある
4. **v6.0 解剖表への行**: 行 13（硬さ）は本ノート C2–C5 で埋まる。「沈下 ≠ 病理」（行 1）に **同じ凍結率 0.9 で $U$ が 1.0 と 0.3**（C5）を足せる
5. **沈下率・凍結率は損傷量ではない**（[[ゲート硬さダイヤル結果_0902]] §6.5 の介入版）。損傷を決めるのは**凍結の深さ**（再露出できるか）

## 4. 書けないこと（引用制限）

1. **「非 ReLU は LoP しない」と書かない。** leaky 0.1・ELU 1 の 0/10 は「5M までに観測しなかった」（片側 95% 上限 0.2589）
2. **C1・C2・C6 の数値は事後・未登録**（seed 中央値・CI なし）。判定に使わない。登録判定は C3 の対比・C4 の P3′・C5 の 1 つだけ
3. **4 型は「タスク内増分の符号と深さ依存」の記述であって力の分解ではない。** 自己項／rest の言葉に翻訳しない（[[命題リスト]] Q2b・Q12・[[論点マップ]] §14）
4. **churn の頻度差で ReLU と SiLU・GELU を分けない**（崩壊腕は ≈650–750/走で同じ）。分けるのは深さ
5. `gelu_clamp`／`silu_clamp` は**本走のための合成活性化**。処方箋として一般化しない
6. スコープ: condA・1 層・幅 100・用量 12.16・$T=10^4$・batch 1・lr 0.01・5M（延長は 15M）・float32。lr スイープ・2 層・condB・他用量は未走
7. **`S_b1`・`S_b0p3`・`G_b0p3` の $n_{\rm onset}$ は `CAPACITY_UNDEFINED`**。発症数として引かない（水準・深さ・凍結は引ける）
8. **K=1 の上界（$u_{\rm fr}$）は予測子として無力**（[[ゲート硬さダイヤル結果_0902]] §6.6）。「凍結深さ 13.8」と測定値のように書かない
9. **境界増分は跳びと直後の押しの混合**。「境界で押される」を跳び単独の性質として引かない
10. 生ログは未添付（`gate_dial_0902` 2.2 GB・`valley_clamp_0902` 380 MB・延長走は約 3 GB）。判定は `seed_values.csv`／`verdict.csv` から再計算できる
11. C7 は走行中。**結果が出るまで「平衡」「対数成長」を事実として引かない**

## 5. 開いている穴
