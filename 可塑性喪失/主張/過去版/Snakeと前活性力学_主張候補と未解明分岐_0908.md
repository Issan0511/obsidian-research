> **目的**: 「Snake がどれくらい効くか」と「前活性分布の変位を何が駆動するか」について、既存結果から言えることと、未解明点の答え次第で言えるようになることを分ける。主張の採用・研究の主軸は Issa が決める。
> **資料の範囲**: main の結果ノートと追補を照合した内部整理。生ログ・実験 repo の出力の再計算、結果 commit の公開確認、先行研究の新規性調査はしていない。測定の数値表は転記せず、出典の節へ案内する。下の「登録」はノートが報告する登録判定であり、今回の独立再検証を意味しない。
> **最も大きい更新**: 有効性の比較は既に主張候補になる。力学は、変位の収支と候補機構への制約が進んだが、符号・速度・長時間挙動を導く理論はまだ閉じていない。両者を結ぶ「この力学だから Snake が効く」は検証途上。

## 1. 最初に区別する対象

| 対象          | この整理で問うこと                   | それだけでは答えないこと          |
| ----------- | --------------------------- | --------------------- |
| タスクへの適合     | 与えた学習予算でどこまで当てるか            | 長期訓練による可塑性の喪失         |
| 可塑性         | 訓練後半の新タスクを、初期と比べてどれだけ学べるか   | 過去タスクの保持              |
| 保持と savings | 過去タスクの精度が残るか／再学習が初期化からより速いか | 新タスクへの適応との同一視         |
| 前活性分布の力学    | ユニットごとの中心・幅・端点がどう動くか        | 平均の沈下だけによる機能障害の認定     |
| 機構          | 更新則から、なぜその符号・速度・位置になるか      | 収支の恒等式や観察的な相関だけでの説明完了 |

Snake の固定 α と、走行統計で α を更新する適応版 SNA は分ける。SNA の勝ちを「活性化関数を交換するだけで勝つ」とは書かない。合成箱の半幅、実データのユニット内標準偏差、全ユニットを混ぜた分布の標準偏差も交換しない。

## 2. Snakeについて、既存結果で成立する主張候補

### 2.1 有効性は条件を付ければ言える

| 主張候補                                                          | 現在の根拠と格                                                                                     | 限定・まだ言えないこと                                                                       |
| ------------------------------------------------------------- | ------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| **前活性の広がりに α を追随させる方法は、検証した Permuted MNIST の二設定で leaky を上回る** | [[PermutedMNIST_適応α結果_0905]] §1–3。Q3 は両設定で成立                                                | 同ノート Q4 では SNA 単体が ReLU+l2init／cbp に負ける。Snake の普遍的優位ではない                          |
| **Random Label MNIST では、正則化下でも適応 Snake の優位が残る**               | [[RandomLabelMNIST結果_0906]] §1。対 ReLU+WD と対 ReLU+l2init は登録判定。対 leaky+WD も優位だが §5b の REPORT | その課題・学習予算・正則化条件での比較。「既存手法全体で最強」「Snake 固有の唯一の性質」にはならない                             |
| **活性化と正則化の組み合わせの順位は、評価した課題間で変わる**                             | Permuted の WD 追加診断と Random Label の §5b。Snake への WD の効果の符号も逆                                 | 課題差に加えタスク数・学習予算が違う。「記憶課題だから」という原因の同定は未了                                           |
| **新タスクの学習・保持・再学習の速さを一つの性能に畳めない**                              | [[PermutedMNIST_追加診断_0905]] §13–14。SNA の後半新タスク学習、BWT、savings で順位が違う                         | 同箱では正則化なしで可塑性上の利点があるが、WD 下では新タスク学習速度の優位が明確でない。Random Label の memo は過去タスク保持の証拠ではない |

**採用可能な文の候補**:

「前活性の広がりに合わせた適応 Snake は、調べた継続学習課題で leaky を上回り、Random Label MNIST では正則化を施した ReLU との比較でも優位を示した。ただし、優位の大きさと正則化の効果は課題・学習予算に依存し、保持や再学習の優位を意味しない。」

これは比較結果の主張として成立する候補。一般化の根拠や機構が未完成でも、この限定した比較自体は残る。

### 2.2 「なぜ効くか」について言える範囲

1. **α の生値だけでなく、前活性分布に対する相対的な周期の細かさを見る必要がある。** 適応 α の介入は検証した条件で有効だった。ただし「最適な無次元量を発見した」は強すぎる。$\alpha_i=c/W_i$ なら、同じ $W_i$ を使う限り $2\alpha_iW_i=2c$ は構成上の等式であり、その値への一致自体は独立の発見ではない。性能が保たれること、実測ゲートの挙動、他の c に対する頑健性が別々の検証対象。c の普遍的最適性は未検証。出所: [[PermutedMNIST_適応α結果_0905]] §1・§5。

2. **局所的な分布の留まり方と、非線形な適合能力は区別できる。** [[Snake反転結果_0906]] §1–4 では、一葉版が幅の大きい合成系で近い局所力学を示す一方、容量不足系で適合が悪い。§8 の事後のパラメータ調整でも差は残る。したがって「周期の後半は何もしていない」は採れない。ただし幅の異なる二設定を使うため、同一系内の完全な因果分離でも、実データの性能差の説明でもない。

3. **ゲートが開いていることだけでは十分でない。** 浅い反転の腕ではゲートが開いたまま読み出しの小さいユニットが増え、適合も悪化する。Permuted でも SNA に可塑性喪失は残る。これはゲート単独の説明への制約であり、「残りの原因はすべてノルム」と確定するものではない。出所: [[Snake反転結果_0906]] §2・§6、[[PermutedMNIST_追加診断_0905]] §11・§14。

**一段強いが未確定の候補**:

「Snake は、前活性分布が局所的に留まれる形と、分布全体で非線形な適合を担える形を併せ持つ。この二つの両立が、有効性に寄与する。」

合成系では根拠があるが、実データまで結ぶには、固定点・分布幅・ゲート・読み出しの変化が後半の学習性能にどう効くかの橋渡しが要る。

## 3. 前活性分布の力学について、既存結果で言えること

### 3.1 収支はかなり見えた。駆動則はまだ閉じない

[[境界密記録_結果_0907]] §1–3 の到達点は、合成 condA の測定した沈下区間で、

- タスク内の学習が前活性平均を下げる。
- タスク切替による入力支持の変更が、その一部を上へ戻す。
- バイアスだけでなく、タスク方向の重みの変化が大きな寄与を持つ。
- full-batch でも正味の沈下が残る。

という収支を測れたこと。

同ノートの $N=J+B+A$ は、$J$ が入力支持の切替、$B$ がバイアス更新、$A$ が固定されたタスク方向への重み更新による寄与。**J は勾配の力ではない。A と B は独立な殺し屋でもない。** タスク中の固定入力成分には同じ勾配のスカラーが入り、配分の大きさは入力のノルムに依存する。

したがって「どの経路が運んだか」は進んだが、**なぜタスク内の適応と切替の戻りが相殺されず、下向きの残りが生まれるのか**は未解明。収支をもう一度書くだけでは、力の符号を予言したことにならない。a を変えると収支が弱まる理由もここに含む。

**採用可能な文の候補**:

「測定した合成系では、前活性の沈下はタスク内適応と入力支持の切替の収支として生じ、ミニバッチ標本雑音を除いても残る。重み経路とバイアス経路は同じ更新の配分として理解できるが、正味の符号と速度を決める法則は未導出である。」

full-batch でもタスク列の変化は残る。「あらゆる雑音が不要」「静的な単一タスクでも同じ」とは言わない。また、ここでいう一次の勾配による運動と、サイクル変位を摂動量で展開したときの次数は別。

### 3.2 位置・幅・局所応答・長期移動を分ける

| --------------------------------------------- | ------------------------------------------------- | ------------------------------------------------ |

**現状に合う理論の単位は、前活性平均だけの一変数モデルより、中心・幅・読み出し・残差とタスク位相の結合系。** これはモデル化の候補であって、十分な状態変数を同定したという結論ではない。

### 3.3 旧ノートの強い言い回しをそのまま主張にしない

- **「c は v 経由でしか効かない」**: 結果ノートの解釈だが、一般の二乗誤差では $\partial L/\partial b_i=2\delta v_i\phi'(z_i)$ の残差 $\delta$ にも c が入る。導関数に明示的な c が無いことと、総勾配が c に依存しないことは別。出力バイアスが定数差をどう吸収するか、初期化・過渡・v 凍結下の対応を指定して初めて「v の適応だけ」の命題になる。現状は「v の適応との結合を支持する」までとする。これは今回の式上の点検であり、実装上の補償条件の確認は未実施。
- **「支持の幅と平均の連動＝上端に引く力の同定」**: 上端と幅の関係は幾何。状態で条件付けた変位には平均回帰も混ざる。[[vとwの成長_0907]] §8 の棄却と、後継の境界密記録を併読する。
- **「滑らかにしたのでラチェットが消えた」**: [[折れ目を滑らかに_結果_0907]] では小さな平滑化で運動はほぼ残り、大きな平滑化では適合・幅・読み出しも変わる。鋭い折れ目を一歩ごとに跨ぐ弁の説明は支持しにくいが、非対称な学習収支一般の棄却ではない。登録の DELTA_SCALE と効果量の読みも区別する。
- **「初期値を忘れる＝唯一の平衡点」**: [[命題1-5_上端則結果_0905]] の登録は未決や MEAN_DEPENDENT を含む。事後の初期値依存の弱さは使えるが、上側初期化の発散・未定着を飛ばして大域的安定性を主張しない。

## 4. 未解明点が解けると、主張はどう分岐するか

以下は実験の実施計画ではなく、主張の依存関係。未知が残っても右端の限定主張は失われない。

| 未解明点                          | 支持する答えが出た場合                | 別の答え・反例が出た場合            | 今のままでも残るもの                    |
| ----------------------------- | -------------------------- | ----------------------- | ----------------------------- |
| Snake の優位は課題構造によるか、予算・調整差によるか | 課題の性質に応じて活性化と正則化を選ぶ条件付き原理へ | 特定予算・設定の有効な方法という位置付けへ   | 測定済み比較での優位                    |
| 適応 α の定数 c に広い有効範囲があるか        | 前活性幅に基づく頑健な調整則へ            | c 自体の調整が必要な方法へ          | 検証した c の方法が有効だったこと            |
| 同程度のゲート量でも Snake の差が残るか       | 周期的な表現、分布形状、勾配の構造まで主張に必要   | 分布で平均したゲートが実用上の十分な説明候補へ | 「非ゼロの傾き床の有無だけでは順位を説明しない」という制約 |
| 長期でも Random Label の優位が続くか     | 長期の可塑性維持として主張を強められる        | 発症遅延・短中期の適応上の利点へ        | 観測窓内の性能                       |
| タスク内適応と切替の差がなぜ負になるか           | 更新則から沈下の符号・速度を予言する機構論へ     | 教師・タスク構造に依存する経験的収支として限定 | N=J+B+A の測定結果                 |
| 中心・幅・v の結合から端点と着座を導けるか        | 活性化ごとの分布運動を予測する理論へ         | 条件付きの位置予測と、速度を決める別の機構へ  | 枝の零点との対応、幅と平均の連動              |
| 長時間の絶対位置は本当に定着するか             | 条件付き平衡・安定性の主張へ             | 緩慢な移動や準定常の理論へ           | 有限時間の軌道と介入差                   |
| v 凍結・オフセット効果を残差補償込みで説明できるか    | v 適応を介した位置選択という機構へ         | 出力バイアス・残差・過渡を含む結合系へ     | オフセットが分布を変える介入結果              |
| 分布の安定化を変えると後半の新タスク学習も変わるか     | 力学が Snake の有効性を説明する一体の主張へ  | 力学研究と有効性研究を別の貢献として提示    | 二本それぞれの結果                     |

**優先度の高い未解明点**は、力学側では「収支の符号を生む理由」と「定着か遅い移動か」、接続側では「分布運動が機能にどう効くか」。この三つは、主張が記述に留まるか予測理論になるかを変える。一方、未測定の全課題を埋めることは、限定した有効性主張の成立条件ではない。

## 5. 二本を結ぶ場合に必要な橋

現時点の接続候補は、

**活性化の形と入力分布 → 学習中の分布・読み出しの運動 → 使える非線形な応答 → 後半の新タスク学習**

という順序。

最初の矢印は合成系の介入で材料が増えている。最後の性能差は実データで測れている。**中間の矢印が、両者を同じ理論にするための不足部分**。平均の沈下が少ない、ゲートが開いている、ある固定点に留まる、のどれか一つから性能を結論しない。

二本を一つにまとめる場合の未確定候補:

「継続学習で有効な活性化には、ゲートを開けることに加えて、前活性分布と読み出しが非線形な適応能力を失わないような力学が必要であり、Snake はその一つの実現である。」

これは今の材料が向かう方向として書けるが、必要条件・十分条件としての証明はなく、中心主張としての採用はまだ別の判断。

## 7. 先に解消すべきノート間の食い違い

1. **Permuted の SNA 単体と SNA+WD の比較相手が混ざっている。** [[RandomLabelMNIST結果_0906]] §4・引用制限の対 ReLU+l2init の Permuted 値は、[[PermutedMNIST_適応α結果_0905]] Q4 の SNA 単体の値。SNA+WD の比較は同ノート §4 および [[PermutedMNIST_追加診断_0905]] §11 を使う。負ける向きは同じでも差の大きさが違う。本整理は正しい腕の組を区別した。
2. **A9 は未回答ではない。** [[駆動源_追伸A9_lrと着座深さ_0906]] 冒頭の状態は未着手だが、§5 に回答済み。残るのは解釈表の符号の食い違い。低 lr が深いという古い末尾比較をそのまま使わない。
3. **境界密記録の b が一歩で動き切るという記述は訂正済み。** [[境界密記録_結果_0907]] §3-2 は「急降下後に部分的に戻る」形に修正されている。[[現在地]] の一歩の記述は古い。

### 10.1 現時点の中心仮説（仮置き）

**正則化なしの Adam では、FRESH なタスク列ではほぼ直交する更新の堆積、同じタスクの反復では既存方向への自己膨張という二経路で中心化重みが伸びる。FRESH 列では $\lVert\widetilde W_1\rVert\approx\sqrt t$ となる。新しいタスクでは、過去に形成されたフィルタの不要な応答を損失が抑え、その更新は傾きの大きい側へ強く流れる。幅が広いほどこの下向き成分が大きくなり、負側の戻しが弱い leaky／ELU ではタスクごとの残差が積み上がる。検証した SNA では負側のゲートが残るため、開始時の下向き力はあっても途中で反転し、深さのラチェットが弱い。L2 は二つの幅成長経路をともに止める。**

この仮説で分けておくべきもの:

- **幅の成長**: Adam 下の FRESH 列での直交堆積と、反復タスクでの自己膨張。新規タスクだけに依存せず、Snake でも止まらない。→ [[置換循環_幅成長の反実仮想_結果_0909]]
- **幅から深さへの変換**: 高傾き側に偏った応答抑制と、低傾き側の弱い戻し。
- **深さから可塑性喪失への接続**: 活性化・読み出し・有効 step・表現の SNR に依存し、まだ単一の因果として閉じていない。
