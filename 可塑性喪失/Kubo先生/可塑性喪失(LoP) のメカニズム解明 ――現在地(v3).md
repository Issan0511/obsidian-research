

## 0 記号と用語の定義(先に全て)
先に用語を全部定義します。以降の議論でこれらを使います。

### 0-1. ニューラルネットワーク (NN)の基本
* **NN**: 入力を受けて出力を返す関数を、多数の 「unit (ユニット・素子)」の組み合わせで作る仕組み
* **weight (重み・パラメータ)**: NNが学習で調整する数値。第1層のunit $i$ の重みは行ベクトル $w_{i}$
* **入力**: NNに入れるデータ (当方の CondAでは5次元の±1 ベクトル、32通りの支持点)
* **前活性 $z_{i}(x)=w_{i}^{\top}x$**: unit $i$ が入力を受けて計算する内積
* **活性化関数 $\varphi(z)$**: 前活性を受けて unit の出力 $\varphi(z)$ を作る非線形関数

### 0-2. 当方が使う活性化関数 (leaky ReLU $\alpha=0.03$)
$$
\varphi(z)=\begin{cases}z&(z>0)\\ 0.03~z&(z\le0)\end{cases}
$$
* **折れ目(kink)**: $z=0$ の点。ここで傾きが1から0.03へ不連続に変わる
* **$\varphi^{\prime}(z)$**: $z>0$ で1(「オン」)、$z<0$で0.03 (「ほぼオフ」)

### 0-3. 学習の仕組み
* **損失 L**: NN の出力が正解からどれだけずれているか
* **学習率 $\eta$**: 1回の更新でどれだけ weight を動かすか
* **勾配 $g$**: 損失を weight で微分した値
* **SGD**: 1 ステップの更新 $\Delta w=-\eta g$
* **Adam**: 座標ごとに正規化して更新する別の学習法
* **batch 1 SGD**: 1 サンプルずつ勾配を取って更新する SGD (当方の設定はこれ)。サンプルごとにばらつき (標本雑音)が生じる

### 0-4. unit の状態
* **unit $i$ の位置 $\overline{z}_{i}$**: 前活性の期待値 $\overline{z}_{i}=\mathbb{E}_{x}[z_{i}]$
* **$k_{on}(i)$**: unit $i$ がタスク内で「オン」になった頻度
* **生存者**: $k_{on}(i)>0$ の unit
* **死者**: $k_{on}(i)=0$ の unit
* **群G**: 折れ目を跨いでいる生存者 ($k_{on}\ge1$ で $\overline{z}_{i}\le0$ のunit)

### 0-5. 生存者の分布を測る量
生存者を $\overline{z}_{i}$ で3帯に分ける:
* **折れ目近く (near)**: $\overline{z}_{i}>-0.5$ の生存者の割合 $f_{near}$
* **中間 (mid)**: $-2.5<\overline{z}_{i}\le-0.5$ の割合 $f_{mid}$
* **深部 (deep)**: $\overline{z}_{i}\le-2.5$ の割合 $f_{deep}$

分布の広がり:
* **$\overline{z}_{width}=q_{90}-q_{10}$**: 生存者の $\overline{z}_{i}$ 値の90パーセンタイルと10パーセンタイルの差
* **危険率 $h(u)$**: 「タスク $t$ で生きていた unit がタスク $t+1$ で死ぬ確率」

### 0-6. 駆動源解析の追加記号(第7回・audit-v1b-intra-task-drift-of-sunk-units-0909)
* **タスク**: 260個のタスクを順に学習。1タスク=1万ステップの学習
* **flip (反転)**: タスクの切り替え。入力の1ビットが反転
* **1 サイクル**: flip 1回 + 1万ステップの学習
* **$v_{i}$**: unit $i$ の読み出し重み(出力層への weight)
* **$n_{band,i}$**: unit $i$ の32支持点のうち、折れ目の0.3以内にある点の数
* **駆動源**: 「1サイクルで $\overline{z}_{i}$ の期待変位はどこから来るか」を勾配式から分解した理論

### 0-7. 実験設定
* **箱A (久保先生)**: 1層 100 unit・SGD・MSE 損失・CondA (5 bit)・260 タスク・10 seed
* **箱B (中塚くん)**: 隠れ3層・Adam・CE損失・PMNIST

### 0-8. 診断量 $\alpha(\eta)$
$$
\alpha(\eta)=\frac{\partial \log~L}{\partial \log~W}
$$
「重み Wを大きくする介入をしたとき、損失Lがどれだけ動くか」の傾き。実測は維持型介入を3腕 (0.5, 1, 2)で振り、末尾窓のlog-log 傾きから得る。
* **$\alpha>0$**: LoP 発症(W大→L大)
* **$\alpha<0$**: refit 完了(W大→L小・健全)

### 0-9. 学習過程の2つの力
* **refit**: 学習で既存パターンを思い出す力
* **拡散**: 学習が乱される力

## 7 なぜ相関するか――2段構造の理論的説明
上流( $\eta$ で分布幅が変わる)と下流(折れ目近くが多いと $\alpha$ が大きい)の2段で、どちらも $\varphi^{\prime}$ の帯依存が主役。

### 7-1. 下流: 折れ目近くがW介入に敏感な理由
* **深部 $(\varphi^{\prime}\approx0.03)$**: W介入は入力の3%しか届かない → 損失に効かない
* **折れ目近く( $z$ が符号を跨ぐ)**: $\varphi^{\prime}$ が1と0.03 で急変 → 強い非線形性 → W大で refit がノイズに埋もれる → 損失増
* $f_{near}$ 高 → $\alpha$ 高。

### 7-2. 上流: SGD の縮小条件が帯依存な理由
peer の勾配一般式と縮小条件から:
* **折れ目近くの縮小閾値**: $\eta_{near}^{crit}\sim10^{-3}$
* **深部の縮小閾値**: $\eta_{deep}^{crit}\sim33~\eta_{near}^{crit}\sim3\times10^{-5}$

3 レジーム:
* **$\eta$ 大**: 両方縮小 → 深部支配・$\overline{z}_{width}$ 小
* **$\eta$ 中間**: 近くだけ縮小・深部成長 → 二極化 → $\overline{z}_{width}$ 最大
* **$\eta$ 小**: 両方成長 → 分布広がるが折れ目近くの割合減 → $\overline{z}_{width}$ 左肩

### 7-3. 2段構造の帰結
「$\varphi^{\prime}$ が折れ目近くで急変する」という1つの性質が上流と下流の両方を作る → 両者が同じ $\eta$ で大きくなる。

## 8 なぜ SGD 特有か
Adam では座標正規化で $\varphi^{\prime}$ が消える → 帯依存が消える $\overline{z}_{width} \rightarrow \alpha(\eta)$ ピーク型は SGD 固有。
中塚くん V9 (Adam・3層・PMNIST) の $\alpha=+1.25$ と当方 (SGD・1層・CondA)の $\alpha=+0.607$ の2倍差別機構:
* **箱AのLoP**: SGD の $\varphi^{\prime}$ 帯選別(S_b)
* **箱BのLoP**: Adam の $\| W_1 \|$ 蓄積 (V9)

## 9 動的機構の根源――駆動源の5項式
### 9-1. 駆動源とは
「1タスクの間にユニットの $\overline{z}_{i}$ がなぜどれだけ動くか」をSGD の恒等式から分解した理論(第7回・audit-v1b-intra-task-drift-of-sunk-units-0909)。
中心の恒等式: batch 1 SGDでの1タスクの変位は、$10^{4}$ ステップの誤差 × 読み出し重み × $\varphi^{\prime}$ × 入力の重ね合わせで厳密に書ける:
$$
\Delta\overline{z}_{i}^{task}=-2\eta\sum_{t=1}^{10^{4}}\delta_{t}v_{i}(t)\varphi^{\prime}(z_{i,r_{t}}(t))m_{r_{t}}
$$
これを5項に分解: $\Delta\overline{z}_{i} = T_0 + T_1 + Y + T_4 + T_5$

### 9-2. 5つの力の役割

| 項       | 力の名前     | 誰に効くか       | 向き           |
| ------- | -------- | ----------- | ------------ |
| $T_{0}$ | 蹴り       | 全員          | 沈んだ unit は上へ |
| $T_{1}$ | 採用/廃棄    | 折れ目を跨いだ少数   | 半々           |
| $Y_{i}$ | 井戸・押し    | 跨いでいる unit  | 沈下の主役ではなかった  |
| $T_{4}$ | 雑音の浮力    | 沈んだ unit    | 上向き          |
| $T_{5}$ | 雑音のゲート経由 | 折れ目近くの unit | 下向き(沈下の主役)   |

第7回の発見: 従来「井戸・押し」を沈下の主役と考えていたが、実験(雑音を消した full-batch との比較)で棄却。沈下を駆動しているのは batch 1の標本雑音 $(T_{5})$ だった。

### 9-3. 特に重要な2項
**$T_{5}$ (雑音のゲート経由)** ――群Gの沈下の主役:
$$
T_{5}\approx-c~v_{i}^{2}n_{band,i}
$$
* $c\approx0.1/$ タスク
* $c\propto\eta$ (学習率に比例)
* $n_{band}$ = 折れ目 $0\pm0.3$ 以内にある支持点の数 (折れ目近くのunit で大きい)
* 下向きに沈める力・$v^{2}$ に比例

**$T_{4}$ (雑音の浮力)** ――沈んだ unit を上げる:
$$
T_{4}=\kappa(-\overline{z}_{i})
$$
* $\kappa\approx0.0119/$ タスク
* $\kappa\propto\eta^{2}$ の相当(連続時間近似)
* 上向き・深さに比例・沈んだ unit ほど強い

### 9-4. $\overline{z}_{width}(\eta)$ ピーク型を駆動源から導く
**動的機構**: $\overline{z}_{i}(t+1)=\overline{z}_{i}(t)+T_{0}+T_{1}+Y+T_{4}+T_{5}$。260 タスク後の分布は5項の釣り合いで決まる。

**帯別の動きの向き**:
* **深部 $(n_{band}\approx0)$**: $T_{5}\approx0$、$T_{4}$ が支配 → 上向き
* **折れ目近く $(n_{band}\gg0)$**: $T_{5}$ が支配 → 下向き
* **中間**: 両方が弱く働く

**$\eta$ 依存の起源**:
* **$T_{5}$ の $\eta$ 依存**: $c\propto\eta$ → $\eta$ 大で1 unit あたり強い
* **$T_{4}$ の $\eta$ 依存**: $\kappa\propto\eta^{2}$ → $\eta$ 大でさらに強い
* **競合**: $T_{5}$ は $\eta$ の1次、$T_{4}$ は $\eta$ の2次 → $\eta$ が小さいほど $T_{5}$ が相対的に強い

**生存者分布の $\eta$ 依存の予言**:
* **$\eta$ 大**: $T_{4}$ が $T_{5}$ に勝ち、生存者は上 (浅い側) へ集まるか、$T_{1}$ で強く refit された少数と深部の集約 → 深部支配(実測74.5%)
* **$\eta$ 中間**: $T_{5}$ が $T_{4}$ に相対的に強く、折れ目近くを沈める。しかし $T_{4}$ もある程度立つので、折れ目近くと深部の二極化 → $\overline{z}_{width}$ ピーク (実測 7.37)
* **$\eta$ 小**: 両方弱く、平衡到達が遅い → 分布が狭くなる(実測 6.93)

$\overline{z}_{width}(\eta)$ ピーク型が駆動源の5項式の釣り合いから出る。

### 9-5. (U4)の $\varphi^{\prime}$ 帯選別と駆動源 $T_{5}$ の関係
(U4) の $\varphi^{\prime}$ 帯選別と駆動源の $T_{5}$ は同じ機構の異なる表現:

| | 駆動源 $T_5$ | (U4) の縮小閾値 |
|---|---|---|
| 主役 | 標本雑音による誤差-ゲート共分散 | $\eta$ の帯別値 |
| 帯依存の起源 | $n_{band}$ (折れ目近くの点数) | $\varphi^{\prime}(z)$が1と0.03 で切り替わる |
| $\eta$ 依存 | $c\propto\eta$ | $\eta_{crit}$ が帯別 |
| 結果 | 折れ目近くの unit が下向きに沈む | 折れ目近くで縮小が起こるが $\eta$ 小さい |

「折れ目近くで $\varphi^{\prime}$ が急変することによる標本雑音の効果」として、駆動源では $T_{5}$ の $n_{band}$ 依存と書き、(U4)では $\eta$ の帯別縮小閾値として書いている。両者は互いに補強する。
