# 実験設定と記号

> **役割**: 以降のノートが参照する実験設定と記号の定義集。定義以外の主張は含まない。

## 1. 箱 (環境): CondA

### 1.1 入力空間

入力は 20 次元 binary ベクトルに scalar shift $g$ を加えた:
$$\tilde x_r = X_r - g \cdot \mathbf 1_{20}, \quad X_r \in \{0, 1\}^{20}$$

20 dim は 2 subspace に分かれる:
- **Fixed subspace** (index 0-14, 15 dim): task 内で固定される bit・seed 依存 (`fs` と表記)
- **Free subspace** (index 15-19, 5 dim): 32 パターン全てが支持点として登場

### 1.2 32 支持点

支持点集合 $\{X_r\}_{r=1}^{32}$ は次で構成:

$$X_r = (\underbrace{fs_0, fs_1, \ldots, fs_{14}}_{\text{fixed}}, \underbrace{\mathrm{FREE}[r, 0], \ldots, \mathrm{FREE}[r, 4]}_{\text{free}})$$

ここで $\mathrm{FREE} \in \{0,1\}^{32 \times 5}$ は 5-bit binary の全 32 パターンを列挙した行列 (`itertools.product([0,1], repeat=5)` で生成)。

`fs` = fixed subspace の bit configuration・seed 依存・task 内で固定・task 切替時に **1 bit だけ flip**。

### 1.3 oracle_g

$g$ は seed の $n_{\rm fixed} = \sum_j fs_j$ (fixed subspace の 1 の数) に応じて解析的に決まる:

$$g(n) = \frac{(n + 2.5) - \sqrt{(n + 2.5)^2 - 20(n + 1.25 - \mu_2^2)}}{20}, \quad \mu_2 = 3.041$$

これは $\mathbb E_r[\|\tilde x_r\|^2] = \mu_2^2 = 9.248$ を保つように選ばれている ($\mu_2$ は target dose の平方根)。

### 1.4 支持点行列と Σ_XX

支持点を行としてまとめた centered 行列:
$$X_c \in \mathbb R^{32 \times 20}, \quad X_c[r, k] = X_r[k] - g$$

**Σ_XX の解析的表現** (第 20 回で導出・詳細は [[02_V-a真の版_有界性_0918]]):

Fixed subspace の各行は task 内で定数 ($X_c[r, k<15] = fs_k - g$ が全 $r$ で同じ) なので、centered 分散 ($r$ について) はゼロ:
$$\mathrm{Var}_r[X_c[\cdot, k]] = 0 \quad (k = 0, \ldots, 14)$$

Free subspace は 5-bit binary で $\{0, 1\}^5$ を等頻度で覆う。centered 分散:
$$\mathrm{Var}_r[X_c[\cdot, k]] = 0.25 \quad (k = 15, \ldots, 19)$$

したがって centered covariance matrix は
$$\boxed{\Sigma_{XX} = 0.25 \cdot \mathrm{diag}(0_{15}, 1_5)}$$

**uncentered second moment matrix** (支持点で平均):
$$\Sigma^{(2)}_{XX} = \frac{1}{32} X_c^\top X_c$$

diagonal:
- $k \le 6$ で $fs_k = 1$: $(1 - g)^2 \approx 1.10$ (seed 0 例)
- $k \in [7, 14]$ で $fs_k = 0$: $g^2 \approx 0.0025$
- $k \in [15, 19]$ (free): $0.25 + (0.5 - g)^2 = 0.55$

## 2. 網 (net)

### 2.1 構造

1 層 hidden・スカラー出力:
$$\hat y(x) = \sum_{i=1}^{H} v_i \varphi(z_i) + c, \quad z_i = w_i \cdot x + b_i$$

- $H = 100$ (hidden unit 数)
- $x \in \mathbb R^{20}$ (入力)
- $w_i \in \mathbb R^{20}$ (unit $i$ の重み)
- $b_i \in \mathbb R$ (unit $i$ の bias)
- $v_i \in \mathbb R$ (unit $i$ の読み出し)
- $c \in \mathbb R$ (全体 bias)

### 2.2 活性化: leaky ReLU

$$\varphi(z) = \begin{cases} z & (z > 0) \\ a z & (z \le 0) \end{cases}, \quad a = 0.03$$

微分:
$$\varphi'(z) = \begin{cases} 1 & (z > 0) \\ a & (z \le 0) \end{cases}$$

**leaky ReLU の恒等式** ([[04_Term_I_II分解と3レジーム_0918]] で本質的):
$$\varphi'(z) \cdot z = \varphi(z)$$

証明: $z > 0$ で $\varphi'(z) z = z = \varphi(z)$、$z \le 0$ で $\varphi'(z) z = a z = \varphi(z)$。

### 2.3 学習 (SGD)

**Adam ではなく SGD** で学習する。1 step の更新は task 内でランダムに $r \in \{1, \ldots, 32\}$ を選び、centered 支持点 $\tilde x_r = X_r - g \mathbf 1_{20}$ (§1.1) を net に投入:

$$\Delta w_i = -\eta \cdot \delta \cdot v_i \cdot \varphi'(z_i(\tilde x_r)) \cdot \tilde x_r$$
$$\Delta b_i = -\eta \cdot \delta \cdot v_i \cdot \varphi'(z_i(\tilde x_r))$$
$$\Delta v_i = -\eta \cdot \delta \cdot \varphi(z_i(\tilde x_r))$$
$$\Delta c = -\eta \cdot \delta$$

ここで $z_i(\tilde x_r) = w_i \cdot \tilde x_r + b_i$ (§6.3)・$\delta = \hat y(\tilde x_r) - y(\tilde x_r)$ は残差・$y$ は teacher output。batch size = 1。実装は centered 支持点で行う (`sim_act.load_ck()` と `mtM_v2.py` の実装通り・turn 9-2 追記)。

### 2.4 損失関数

MSE:
$$L = \tfrac{1}{2} (\hat y(x) - y(x))^2$$

## 3. 教師 (teacher)

### 3.1 teacher 出力

CondA では teacher output は fixed subspace の bit configuration に依存する (固定形の関数)。具体的には:

$$y(x) = f_{\rm teacher}(x; \theta)$$

ここで $\theta$ は task ごとに固定される。詳細な形は本ノート群の中心的主張には影響しないため省略 (`~/project/Nakatsuka/claude/hole1_scripts/model.py` を参照)。

### 3.2 task 切替 (bit-flip kick)

各 task 開始時に:
1. Fixed subspace の 15 bit のうち **1 bit をランダムに選んで flip**
2. `fs` を更新
3. $g = g(n_{\rm fixed})$ を再計算
4. 支持点行列 $X_c$ を再構成
5. teacher output $y$ が新しい支持点上で変わる

この bit-flip kick は、student の $\bar z_i$ に幾何 kick + offset を与える (詳細は [[07_駆動源5項式のper-event検証_0918]] の $T_0$)。

## 4. task と event

- **task**: SGD の 10⁴ step の連続実行
- **event**: 1 task の (task, seed, unit_i) の三つ組
- **task 0**: 5M step で pretrained された初期状態
- **task 1 - task 500**: continual learning の 500 task

## 5. arm と seed

### 5.1 5 arm

学習率 $\eta$ の 5 値:

| tag    | $\eta$                | 数値       |
| ------ | --------------------- | -------- |
| lr0156 | $1.56 \times 10^{-4}$ | 0.000156 |
| lr02   | $2.0 \times 10^{-4}$  | 0.0002   |

### 5.2 seed

各 arm で 10 seed (seed = 0, 1, ..., 9) を実行。5 arm × 10 seed = 50 走行。

## 6. 記号定義表

以下、本ノート群で使用する全記号を集約する。

### 6.1 基本量

| 記号     | 定義                         | 単位・型    |
| ------ | -------------------------- | ------- |
| $\eta$ | 学習率                        | scalar  |
| $T$    | 1 task の SGD step 数 = 10⁴  | integer |
| $H$    | hidden unit 数 = 100        | integer |
| $R$    | 支持点数 = 32                  | integer |
| $a$    | leaky ReLU 負側 slope = 0.03 | scalar  |

### 6.2 支持点と入力

| 記号                                                    | 定義                                              |
| ----------------------------------------------------- | ----------------------------------------------- |
| $X \in \{0,1\}^{20}$                                  | binary 入力                                       |
| $\tilde x_r = X_r - g \mathbf 1$                      | centered 支持点                                    |
| $g$                                                   | oracle shift ($g(n_{\rm fixed})$)               |
| $n_{\rm fixed} = \sum_j fs_j$                         | fixed subspace の 1 の数                           |
| $fs$                                                  | fixed subspace bit configuration・seed & task 依存 |
| $\mathrm{FREE}$                                       | 5-bit binary 32 パターン                            |
| $\mu_2 = 3.041$                                       | target dose 平方根                                 |
| $\tilde\mu$                                           | $\mathbb E_r[\tilde x_r]$ (centered 支持点の平均)     |
| $\Sigma_{XX} = 0.25 \cdot \mathrm{diag}(0_{15}, 1_5)$ | centered 共分散行列                                  |
| $\Sigma^{(2)}_{XX} = X_c^\top X_c / 32$               | uncentered second moment                        |

### 6.3 網の量

| 記号                                  | 定義                   |
| ----------------------------------- | -------------------- |
| $w_i \in \mathbb R^{20}$            | unit $i$ の重み         |
| $b_i \in \mathbb R$                 | unit $i$ の bias      |
| $v_i \in \mathbb R$                 | unit $i$ の読み出し       |
| $c \in \mathbb R$                   | 出力 bias              |
| $W \in \mathbb R^{H \times 20}$     | 重み行列 (行が $w_i^\top$) |
| $z_i(x) = w_i \cdot x + b_i$        | unit $i$ の前活性        |
| $a_i(x) = \varphi(z_i(x))$          | unit $i$ の活性化        |
| $\hat y(x) = \sum_i v_i a_i(x) + c$ | 出力                   |
| $\delta = \hat y - y$               | 残差                   |

### 6.4 task 内の集計量 (per-task per-unit)

| 記号                                             | 定義                                                    |
| ---------------------------------------------- | ----------------------------------------------------- |
| $\bar z_i = \mathbb E_r[z_i(x_r)]$             | unit $i$ の 32 支持点上での前活性平均                             |
| $\sigma_i = \sqrt{\mathrm{Var}_r[z_i(x_r)]}$   | unit $i$ の前活性標準偏差                                     |
| $k_{\rm on, i}$                                | $\|\{r: z_i(x_r) > 0\}\|$ (unit $i$ が正の gate を持つ支持点数) |
| $\mathrm{on}(i) = \{r: z_i(x_r) > 0\}$         | unit $i$ の正 gate 支持点集合                                |
| $n_{\rm band, i}$                              | audit-v1b で定義される「帯」の指数                                |
| $d_i = \Delta \sigma_i / \sigma_{i, \rm kick}$ | per-task per-unit の diagnosis                         |

### 6.5 K spectrum (第 20 回発見・詳細 [[05_K_spectrumとF_K_decay_0918]])

| 記号                                                       | 定義                             |
| -------------------------------------------------------- | ------------------------------ |
| $\mathcal K = X_c X_c^\top / 32$                         | 支持点分光行列 (32 × 32)              |
| $\lambda_k$                                              | $\mathcal K$ の非零固有値 (rank = 6) |
| $u_k$                                                    | 対応する固有ベクトル                     |
| $\lambda_{\max} = 9.29 = \|\tilde\mu\|^2$                | bias mode の固有値                 |
| $u_1 = \tilde\mu / \|\tilde\mu\|$                        | bias mode 方向                   |
| $\mathcal F(\mathcal K) = \exp(-\eta T \mathcal K / 16)$ | 演算子応答 (連続時間極限)                 |

### 6.6 駆動源 5 項式の各項

| 記号                                                 | 定義                                                   |
| -------------------------------------------------- | ---------------------------------------------------- |
| $T_0$                                              | 幾何 kick + offset (task 切替時の直接効果)                     |
| $T_1$                                              | 一次 refit (crosser の押し)                               |
| $T_1^{\rm true}$                                   | 演算子応答 $\mathcal F(\mathcal K) \delta'$ を使った実効的 $T_1$ |
| $T_1^{\rm 0th}$                                    | 0 次近似 $\zeta = \delta'$ を使った $T_1$                   |
| $T_1^{\rm 0th, bias\text{-}mode}$                  | $T_1^{\rm 0th}$ の bias mode 成分                       |
| $T_4 = \kappa(\eta) \cdot (-\bar z_i)$             | 雑音の浮力                                                |
| $T_5 = -c(\eta) \cdot v_i^2 \cdot n_{\rm band, i}$ | 雑音ゲート経由                                              |
| $Y_i$                                              | 井戸・押し項 (kp $\ge 1$ で non-zero)                       |
| $\delta'$                                          | flip 直後の残差 (SGD 開始前の $\hat y - y$ at 32 支持点)         |
| $\zeta$                                            | 演算子応答後の residual (0 次近似で $\zeta = \delta'$)          |
| $m_r = \tilde x_r \cdot \tilde\mu$                 | 支持点重み                                                |
| $\bar m_r = \mathbb E_r[m_r] = \|\tilde\mu\|^2$    | 支持点重みの平均                                             |
