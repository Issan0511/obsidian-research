## 3. 棄却済み仮説 (Y_i の閉形式選定)

### 3.1 Y_i の 6 関数形 (form (i)-(vi)) の比較

Claude Code session 21 Step E で 6 関数形を比較し、form (v) 以外の 5 候補を棄却 (詳細 [[08_Y_i閉形式_step_E_0918]] §4-5):

| form    | 関数形                                 | kp6+ R²   | 棄却理由      |
| ------- | ----------------------------------- | --------- | --------- |
| (i)     | $v^2 \cdot z_{\max}$                | 0.213     | R² < 0.3  |
| (ii)    | $\|v\|$                             | 0.086     | R² < 0.1  |
| (iii)   | $v^2 \cdot \mathrm{sgn}(\bar z)$    | 0.135     | R² < 0.2  |
| (iv)    | $v^2 \cdot \bar z$                  | 0.302     | R² < 0.4  |
| **(v)** | **$v \cdot \sum_{\rm on} \delta'$** | **0.996** | **採用**    |
| (vi)    | $v^2$                               | 0.028     | R² < 0.05 |

**Form (vi) の詳細**: 第 20 回の Chat preliminary で $Y_i$ を $v_i^2$ 単体でモデル化した試みは R² < 0.03 で棄却された (詳細 [[07_駆動源5項式のper-event検証_0918]] §6.3)。これが Claude Code session 21 Step E での form (vi) と同じ結論。

### 3.2 棄却の意味

- **$v^2$ 系** (form (i), (iii), (iv), (vi)): $v_i^2$ の符号は常に正なので、$Y_i$ の符号を state で反転できない → alive unit の $\bar z_i$ が下降するタイミングを表現できない
- **form (v) $v \cdot \sum \delta'$**: $v_i$ の 1 乗と $\delta'_r$ の符号で $Y_i$ の符号が自然に決まる → alive dynamics を正しく表現
- **Form (ii) $\|v\|$**: state 依存が最小 → R² 最低

物理的な picture として、Form (v) は「正 gate 支持点で unit $i$ が受ける残差の総和」で、これが SGD で $\bar z_i$ を動かす原因という直観に整合する。

## 4. Kubo 段 0 で決着した factor 1 と Claude Code report の古い factor 3 記述

**turn 8-b・9・9-2 修正**: 本 §4 は memory summary ベースで「段 0 で訂正済み」と記述したのを turn 8-b で両論併記に緩和し、turn 9 で subsection の tone を両論併記に統一したが、turn 9-2 で先生の指示「Kubo 段 0 で決着・Claude Code の記述が古い」に従い、Kubo 決着 (factor 1) を主・Claude Code report (factor 3) を段 0 実施前の古い記述として位置付け直した。詳細な物理的正当性の根拠と Claude Code 記述の棄却理由は [[09_Y_iの物理的正体_bias_mode_cancellation_0918]] §5-6 を参照。

### 4.1 Claude Code session 21 report の記述 (段 0 実施前の暫定)

Claude Code session 21 は Y_i の閉形式 $c(\eta)$ を「$3 \times (2\eta T / 32) \bar m_{\rm on}$」と解釈し、その根拠として:

- $\bar m_{\rm on} \approx 3.5$ を「alive unit の on 支持点の $m_r$ 平均」として計算
- 実測 $c(\eta)^{\rm fit} \approx 3 \cdot (2\eta T / 32) \cdot 3.5$
- **「factor 3」の解釈**を出力

### 4.2 Kubo 段 0 分析による決着

第 20 回終了時に Chat で Kubo (先生) が実施した段 0 分析 ([[09_Y_iの物理的正体_bias_mode_cancellation_0918]] §5) で、Y_i の閉形式の正しい理論値が同定された:

- 正しい理論値: $c(\eta)^{\rm theory} = (2\eta T / 32) \cdot \|\tilde\mu\|^2 = (2\eta T / 32) \cdot 9.24$
- $\|\tilde\mu\|^2 \approx 9.24$ は bias mode の magnitude ([[05_K_spectrumとF_K_decay_0918]] §5.1)・全 32 支持点の projection weight・support 空間の spectral property
- ratio $c^{\rm fit} / c^{\rm theory} = 1.008 \pm 0.009$ (5 arm・narrow band で 1 に集中・arm 依存性 < 1%)

Kubo 段 0 分析による決着: **正しい理論値 $\|\tilde\mu\|^2 = 9.24$ を使えば ratio 1.008 の narrow band 一致**。Claude Code session 21 report の「factor 3× ずれ」は $\bar m_{\rm on} = 3.5$ を bias mode magnitude と誤解した artifact ($9.24 / 3.5 \approx 2.64 \approx 3$) で、段 0 の同定時点で 4 つの独立根拠 (代数・実測・categorical・物理整合性・詳細 [[09_Y_iの物理的正体_bias_mode_cancellation_0918]] §6.3) で棄却が確定する。

### 4.3 factor 3 の起源 (Claude Code report の誤解)

Kubo 段 0 で正しい理論値 ($\|\tilde\mu\|^2 = 9.24$) と Claude Code report の誤解 ($\bar m_{\rm on} = 3.5$) の 2.64 倍差が「factor 3× ずれ」の起源:

- **正しい (Kubo 段 0)**: bias mode magnitude は $\mathcal K = X_c X_c^\top / 32$ の最大固有値 $\lambda_{\max} = \|\tilde\mu\|^2 = 9.24$ — 全 32 支持点にわたる projection weight・support 空間の spectral property
- **Claude Code report の誤解 (段 0 実施前)**: on-support (alive unit の gate 応答 = 1) 上の $m_r$ 平均 $\bar m_{\rm on} \approx 3.5$ — unit 依存量・bias mode magnitude ではない

$9.24 / 3.5 \approx 2.64 \approx 3$ が「factor 3× ずれ」の起源で、Claude Code は K spectrum の解析を経ずに empirical fit を解釈したため $\bar m_{\rm on}$ を bias mode magnitude と誤解した artifact。詳細は [[09_Y_iの物理的正体_bias_mode_cancellation_0918]] §6.1 参照。

### 4.4 Kubo 決着の Landing A 判定への意義

- **判定 1 (Model M4 v3i_joint 3 判定)**: Kubo 段 0・Claude Code 記述のどちらの解釈にも影響されない (v3i_joint は $c(\eta)$ の解釈に依存しない・alive branch は経験 Markov chain)
- **判定 5 (Y_i の物理的解明)**: Kubo 段 0 分析で「bias mode cancellation」として同定・ratio 1.008 で narrow band 一致で決着。Claude Code report の「factor 3× ずれ」記述は $\bar m_{\rm on}$ の誤解による artifact として棄却

Landing A 完全達成 ([[00_概要と5判定基準_0918]]) の宣言は Kubo 段 0 分析の narrow band 一致を判定 5 の後半達成として採用する (詳細 [[09_Y_iの物理的正体_bias_mode_cancellation_0918]] §5-6)。Landing B の Step 0 では Kubo 決着の精度確認 (他 seed の $\|\tilde\mu\|^2$ verification 等・詳細 §2.8) を実施する。

### 4.5 教訓

**関連する量の identifiable な計算方法を先に固定する** — K spectrum の解剖を経ずに empirical fit の解釈を行うと、簡単に $\bar m_{\rm on}$ (unit 依存の経験平均) と bias mode magnitude ($\|\tilde\mu\|^2$・spectral property) を混同する ($9.24$ vs $3.5$ の 2.64 倍差)。第 20 回終了時に段 0 を実施し narrow band 一致を確認したことで、Claude Code report の $\bar m_{\rm on}$ 使用が誤解の artifact だと同定できた。Kubo 決着の精度確認は Landing B の Step 0 で追加予定 (詳細 [[09_Y_iの物理的正体_bias_mode_cancellation_0918]] §6.4)。

## 5. Model M4-B 発散から Model M4-C への課題移行

### 5.1 Model M4-B の 3 大欠陥 (詳細 [[11_Model_M4-B発散の3大欠陥_0918]])

1. $T_1^{\rm true}$ 項の欠落 → free subspace restoring 不在
2. $Y_i$ を独立 Gaussian random walk として扱った → $\sqrt{N_{\rm task}}$ 発散
3. $\delta'$ を state 条件付けなしの IID Gaussian でモデル化 → bias mode cancellation 不成立

### 5.2 Model M4-C の設計指針 (Landing B の future work)

3 欠陥を解消:

1. **$T_1^{\rm true}$ の追加**: 演算子応答 $\mathcal F(\mathcal K) \delta'$ から計算
2. **$Y_i$ の閉形式使用**: form (v) を直接使う
3. **$\delta'$ の state 条件付き統計モデル**: 前 task の refit 履歴を反映

これらを解消すれば bias mode cancellation ([[09_Y_iの物理的正体_bias_mode_cancellation_0918]]) が自動的に成立し、Model M4-C は 3 判定を維持したまま完全理論駆動化される (予想)。

### 5.3 Landing A の完成度

Landing A の 5 判定基準 (詳細 [[00_概要と5判定基準_0918]]) は達成されている。ただし完全性の観点で以下が open:

- Alive branch の理論駆動化 (Landing B)

これらは Landing A の判定を反証しないが、Landing A → Landing B → Landing C → Landing D の系統的な作業として認識される。
