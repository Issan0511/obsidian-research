# V-a 真の版・有界性

親: [[00_概要と5判定基準_0918]] / 状態: **決着** / 更新: 2026-09-18

## 1. 主張

**|d_true|_max ≈ 7.4 (proxy 版 2.45 の 3 倍) だが p99 (all) ≤ 4.24・alive p99 ≤ 2.84・dead p99 ≤ 5.83 で有界。V-a 判定 (発散しない) 成立。**

これは Landing A の判定基準 2 ([[00_概要と5判定基準_0918]] 参照)。

## 2. 反証条件

以下のいずれかが観測されたら V-a 判定は棄却される:

1. 他 seed 群 (seed = 10-19 等) で $|d_{\rm true}|$ の **p99 が 10 を超える** arm が現れる
2. 他 arm ($\eta$ を [$10^{-5}, 10^{-2}$] の中で任意に変えた場合) で **p99 が発散** (無限大に発散する) 傾向を示す
3. $\Sigma_{XX}$ の解析的導出に数値検算で machine precision 以上の乖離 (0.25 の相対誤差 > $10^{-10}$) が観測される
4. σ_i = 0.5 · ‖w_i[15:20]‖ の per-unit 式が、他 seed または他 task で相対誤差 > $10^{-6}$ で成立しない

## 3. Σ_XX の解析的導出 (完全形)

### 3.1 定義

支持点行列 $X_c \in \mathbb R^{32 \times 20}$ は [[01_実験設定と記号_0918]] の §1.4 で定義される:

$$X_c[r, k] = X_r[k] - g$$

centered covariance matrix:

$$\Sigma_{XX}[j, k] = \frac{1}{32} \sum_{r=1}^{32} (X_c[r, j] - \bar X_c[\cdot, j]) (X_c[r, k] - \bar X_c[\cdot, k])$$

ここで $\bar X_c[\cdot, k] = (1/32) \sum_r X_c[r, k]$ は列 $k$ の平均。

### 3.2 Fixed subspace の分解

Fixed subspace ($k \in \{0, \ldots, 14\}$) では、支持点 $X_r[k] = fs_k$ が全 $r$ で **同じ値** (task 内で固定):

$$X_c[r, k] = fs_k - g \quad \text{for all } r$$

したがって:
- 平均: $\bar X_c[\cdot, k] = fs_k - g$
- 各項の centered 値: $X_c[r, k] - \bar X_c[\cdot, k] = 0$
- 分散: $\Sigma_{XX}[k, k] = 0$
- 他 fixed 列との共分散: $\Sigma_{XX}[j, k] = 0$ (両者が定数なので)

結論: **fixed subspace の 15 × 15 ブロックはすべて 0**。

### 3.3 Free subspace の分解

Free subspace ($k \in \{15, \ldots, 19\}$) では、$X_r[k] = \mathrm{FREE}[r, k-15]$ が 32 パターンで $\{0, 1\}$ を等頻度 (各 16 回) で覆う:

$$\sum_r X_r[k] = 16, \quad \sum_r X_r[k]^2 = 16$$

したがって:
- 平均: $\bar X_c[\cdot, k] = (1/32)(16 - 32 g) = 0.5 - g$
- 分散:
  $$\Sigma_{XX}[k, k] = \frac{1}{32} \sum_r (X_c[r, k] - \bar X_c[\cdot, k])^2 = \frac{1}{32} \sum_r (X_r[k] - 0.5)^2$$
  $$= \frac{1}{32} \left[ 16 \cdot (1 - 0.5)^2 + 16 \cdot (0 - 0.5)^2 \right] = \frac{1}{32} \cdot 32 \cdot 0.25 = 0.25$$

### 3.4 Free-free の cross terms

$k \ne k'$ で共に free subspace の場合、$\mathrm{FREE}[r, k-15]$ と $\mathrm{FREE}[r, k'-15]$ は **独立に $\{0,1\}$ を全パターン列挙** している (5-bit binary の直積構造):

$$\sum_r \mathrm{FREE}[r, k-15] \cdot \mathrm{FREE}[r, k'-15] = 8$$

(両方が 1 のパターン数 = $2^3 = 8$)

したがって:
$$\Sigma_{XX}[k, k'] = \frac{1}{32} \sum_r (X_r[k] - 0.5)(X_r[k'] - 0.5) = \frac{1}{32}(8 - 8 - 8 + 8) = 0$$

### 3.5 Fixed-free の cross terms

$k < 15$, $k' \ge 15$ の場合、$X_r[k] = fs_k$ (定数) と $X_r[k']$ (変数):

$$\Sigma_{XX}[k, k'] = \frac{1}{32} \sum_r (fs_k - g - (fs_k - g))(X_r[k'] - 0.5) = 0$$

### 3.6 結論

$$\boxed{\Sigma_{XX} = 0.25 \cdot \mathrm{diag}(\underbrace{0, 0, \ldots, 0}_{15}, \underbrace{1, 1, 1, 1, 1}_{5})}$$

### 3.7 数値検証 (第 20 回)

5M ckpt (seed 0 n_fixed=7) で数値計算した結果:

| entry                             | 理論   | 実測                      | 相対誤差              |
| --------------------------------- | ---- | ----------------------- | ----------------- |
| $\Sigma_{XX}[0, 0]$ (fixed)       | 0    | $3.47 \times 10^{-18}$  | machine precision |
| $\Sigma_{XX}[7, 7]$ (fixed)       | 0    | $2.90 \times 10^{-18}$  | machine precision |
| $\Sigma_{XX}[15, 15]$ (free)      | 0.25 | 0.2500                  | $< 10^{-15}$      |
| $\Sigma_{XX}[15, 16]$ (free-free) | 0    | $-1.11 \times 10^{-16}$ | machine precision |

$\Sigma_{XX} = 0.25 \cdot \mathrm{diag}(0_{15}, 1_5)$ の解析形は machine precision で確認された。

## 4. σ_i の per-unit 式

### 4.1 導出

$\sigma_i$ は unit $i$ の 32 支持点上での前活性 $z_i(x_r) = w_i \cdot x_r + b_i$ の標準偏差:

$$\sigma_i^2 = \mathrm{Var}_r[z_i(x_r)] = \mathrm{Var}_r[w_i \cdot x_r]$$

(bias $b_i$ は $r$ 非依存なので分散に寄与しない)

$$= \mathrm{Var}_r[w_i \cdot \tilde x_r] = w_i^\top \Sigma_{XX} w_i$$

(centered support $\tilde x_r$ を使えば同じ結果・shift は分散に寄与しない)

$\Sigma_{XX}$ の diag 形を代入:

$$\sigma_i^2 = w_i^\top \cdot 0.25 \cdot \mathrm{diag}(0_{15}, 1_5) \cdot w_i = 0.25 \cdot \sum_{k=15}^{19} w_{i,k}^2 = 0.25 \cdot \|w_i[15:20]\|_2^2$$

したがって:

$$\boxed{\sigma_i = 0.5 \cdot \|w_i[15:20]\|_2}$$

### 4.2 意味

$\sigma_i$ は **free subspace への重みの射影**でのみ決まる。fixed subspace への重み $w_i[0:15]$ は $\bar z_i$ (中心) に効くが $\sigma_i$ には効かない。これは V-b ([[03_V-b真の版_wnorm不動性_0918]]) の中央値変化差の起源。

## 5. |d_true| の定義

per-task per-unit の diagnosis:

$$d_i = \frac{\sigma_i^{\rm post\text{-}task} - \sigma_i^{\rm kick}}{\sigma_i^{\rm kick}}$$

ここで:
- $\sigma_i^{\rm kick}$: task 開始時 (flip 直後・SGD 前) の $\sigma_i$
- $\sigma_i^{\rm post\text{-}task}$: task 終了時 (SGD の $10^4$ step 後) の $\sigma_i$

$|d_i|$ は「1 task の SGD で $\sigma_i$ がどの程度動くか」の相対量。

## 6. 実測結果 (5 arm × 10 seed × 500 tasks)

### 6.1 σ/‖w‖ の task 0 での 5 arm 比較

Task 0 (5M ckpt・500 tasks 開始時) での per-unit の σ_i / ‖w_i‖ の median (proxy との対応):

| arm    | median | CV  | cos(w, free-subspace) median |
| ------ | ------ | --- | ---------------------------- |
| lr0156 | 0.4442 | 7%  | 0.888                        |
| lr02   | 0.4438 | 7%  | 0.888                        |
| lr05   | 0.4497 | 7%  | 0.899                        |
| lr10   | 0.4483 | 7%  | 0.897                        |
| lr25   | 0.4507 | 9%  | 0.901                        |

σ/‖w‖ ≈ 0.5 × cos(w, free) と整合。cos が 0.88-0.90 で high であることが、proxy 版 (‖w‖ を σ の代替として使う) が **近似的に成立** する根拠。

### 6.2 |d_true| の 5 arm × 全 event 統計

500 tasks × 10 seed × 100 unit = 500,000 event の統計:

| arm    | max      | p99 (all) | p99 (alive) | p99 (dead) | mean |
| ------ | -------- | --------- | ----------- | ---------- | ---- |
| lr0156 | 3.05     | 1.82      | 1.85        | 3.12       | 0.12 |
| lr02   | 3.51     | 1.98      | 2.01        | 3.36       | 0.13 |
| lr05   | 5.20     | 2.78      | 2.44        | 4.22       | 0.17 |
| lr10   | 6.87     | 3.42      | 2.77        | 4.84       | 0.20 |
| lr25   | **7.42** | **4.24**  | **2.84**    | **5.83**   | 0.25 |

- **max = 7.42** (η=2.5e-3 arm の isolated event, task 46-279 の range で発生)
- **alive p99 ≤ 2.84** (5 arm)
- **dead p99 ≤ 5.83** — dead の tail が alive より重い

### 6.3 max event の解剖

$|d_{\rm true}|_{\max} = 7.42$ の event を追跡:

- arm: lr25 ($\eta = 2.5 \times 10^{-3}$)
- task: 152
- unit: 43
- kick 時 $\sigma_i^{\rm kick} \approx 0.045$ (低支持)
- post-task $\sigma_i \approx 0.379$
- $|d_i| = |0.379 - 0.045| / 0.045 \approx 7.42$
- 特徴: **low-support crossing** — $\sigma_i^{\rm kick}$ が小さい (support が薄い) unit で、$\sigma$ が SGD で回復した rare event

これは isolated peak であって、分布全体の tail は heavy でない。p99 (alive) が 2.84 で有界であることが V-a 判定を保つ。

### 6.4 proxy 版との比較

第 19 回で使われた **proxy 版**の $|d_{\rm proxy}| = |\Delta \|w_i\|| / \|w_i\|^{\rm kick}$:

| arm    | proxy max | true max | ratio |
| ------ | --------- | -------- | ----- |
| lr0156 | 0.99      | 3.05     | 3.08  |
| lr02   | 1.20      | 3.51     | 2.93  |
| lr05   | 1.62      | 5.20     | 3.21  |
| lr10   | 2.03      | 6.87     | 3.38  |
| lr25   | 2.45      | 7.42     | 3.03  |

**true 版は proxy 版の約 3 倍**。これは σ_i が w_i の free subspace 5 dim だけに依存するのに対し、‖w_i‖ は 20 dim 全体を含むためのスケール差。5 dim / 20 dim の全空間比 = 0.25 で、それに合わせて $\sigma$ の変動が拡大される。
