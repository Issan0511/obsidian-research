# Model M4-A / M4-B 発散の 3 大欠陥

親: [[00_概要と5判定基準_0918]] / 状態: **決着** (欠陥同定完了・Model M4-C は future work) / 更新: 2026-09-18 (turn 8-a 訂正)

## 1. 主張

**Claude Code session 21 Step G で試みた Model M4 の完全理論駆動化 (M4-A・M4-B の 2 実装) は 3 判定基準を達成できず、M4-A は Spearman = −1.0 (逆順)、M4-B は width = 170 (η=2.5e-3・target 7.37 の 23 倍) に発散した。M4-A の失敗の主因は「state feedback の欠如」($k_{\rm on}^{\rm kick}$ と R を η-marginal からサンプリング・state 条件付けなし)、M4-B の発散は「3 大欠陥」($T_1^{\rm true}$ 欠落・$Y_i$ IID Gaussian random walk・$\delta'$ state 独立 IID) に起因する。**

## 2. 反証条件

以下のいずれかが観測されたら本主張は棄却される:

1. **M4-A の Spearman −1.0** が state-conditional な R sampling を追加しても改善しない
2. **M4-B の発散が 3 大欠陥のいずれかを解消しても改善しない**
3. Model M4-B の std 見積り (η=2.5e-3 で M4-B width ≈ 170) が同じ実装で再現しない
4. Session 21 step_G_model_m4_theory_driven.py の実装で本ノートが記述する M4-A / M4-B の update rule と異なる更新が行われる

## 3. Model M4-A: empirical R bootstrap + Markov marginal

### 3.1 実装 (`step_G_model_m4_theory_driven.py::simulate_theory_driven`)

各 task で各 unit について:

1. $T_4 = \kappa(\eta) \cdot (-\bar z_i)$ を計算 ($\kappa$ は Step Q' の `step_Q_LRa0p03_coefficients.csv` から load)
2. $T_5 = -c_v(\eta) \cdot v_i^2 \cdot n_{\rm band}(\bar z_i)$ ($c_v$ は Step R から・$n_{\rm band}(\bar z_i) = A \exp(-B \bar z_i^2)$)
3. $T_0$ を Step T の joint 分布から load
4. **$k_{\rm on,i}^{\rm kick}$ を Step F の η-marginal $p(k^{\rm kick} \mid \eta)$ からサンプリング** (state 独立)
5. **R を per $(η, k^{\rm kick})$ の empirical distribution からブートストラップ** (session 20 v2 500-tasks npz の task 100-500 から抽出)
6. $\Delta \bar z_i = T_0 + T_4 + T_5 + R$
7. $\bar z_i \leftarrow \bar z_i + \Delta \bar z_i$

260 tasks 走行 (WARMUP 200 後の tail 60 tasks で判定)。

### 3.2 結果 (5 arm・M4-A)

Session 21 report §Step G の実測:

| $\eta$   | M4-A $\bar z_{\rm width}$ | 実測 v2 npz | v3i_joint (Chat) | §9-4 target |
| -------- | ------------------------- | --------- | ---------------- | ----------- |
| 0.000156 | 5.16                      | 6.08      | 7.30             | 6.93        |
| 0.0002   | 4.00                      | 6.09      | **7.40**         | **7.37**    |
| 0.0005   | 4.95                      | 5.67      | 5.75             | 7.37        |
| 0.001    | 5.83                      | 4.68      | 5.29             | 6.15        |
| 0.0025   | 6.06                      | 3.48      | 2.81             | 5.13        |

**3 判定基準の M4-A 到達度**:
- Peak position: η = 0.0025 (target [0.0002, 0.0005] を外す) → **NG**
- Peak value: 6.06 (target 7.37 近傍だが peak position が違う) → NG
- **Spearman(width, α_ref) = −1.000** (完全逆順) → **NG**

### 3.3 失敗の主因: state feedback の欠如

M4-A の update rule は各 unit の $\bar z$ を保持しつつ update するが、$k_{\rm on,i}^{\rm kick}$ と $R$ を **η-marginal 分布** から独立サンプリング。これにより:

- 実際の $k_{\rm on,i}^{\rm kick}$ は unit の状態 ($v_i^2$・prev $\bar z_i$・prev $k_{\rm on,i}$) に依存するが、marginal 独立サンプリングでは相関を無視
- 実際の $R$ は state 依存 ($v_i^2$・$\bar z_i$・$k_{\rm on,i}$ の bin) だが、M4-A は per $(η, k_{\rm on,i}^{\rm kick})$ empirical のみ (v・$\bar z$ 依存を捨てる)
- **state feedback がない** → 各 unit の $\bar z$ dynamics が η arm 間で本質的に交換される → Spearman が逆順

Session 21 report §Step G の直接引用 (証拠):

> v3i_joint (Chat) が Landing A を達成しているのは、R を state-conditional (v²・z̄・kon の bin) でサンプリングするため。Step G の unconditional bootstrap は state feedback が抜けている。

## 4. Model M4-B: closed form Y_i + IID Gaussian δ'

### 4.1 実装 (`step_G_model_m4_theory_driven.py::simulate_theory_driven_v2`)

各 task で各 unit について:

1. $T_0, T_4, T_5$ は M4-A と同じ (empirical から load)
2. $k_{\rm on,i}^{\rm kick}$ を Step F marginal からサンプリング (M4-A と同じ・state 独立)
3. kp 群ごとに $n_{\rm on}$ の代表値 (kp1→1, kp2→2, kp3-5→4, kp6+→8) を取り、**$\sum_{r \in \mathrm{on}} \delta'_r$ を $\mathcal N(0, \delta_{\rm amp} \sqrt{n_{\rm on}})$ で IID Gaussian サンプリング** ($\delta_{\rm amp} = 0.9$)
4. $Y_i = c(\eta) \cdot v_i \cdot \sum \delta'_r$ (Step E の閉形式)
5. $c(\eta) = C_0 \cdot \eta$ ($C_0 = 6800$ を代表値として使用)
6. $\Delta \bar z_i = T_0 + T_4 + T_5 + Y_i$ (kp0 では $Y_i = 0$)
7. $\bar z_i \leftarrow \bar z_i + \Delta \bar z_i$

### 4.2 結果 (5 arm・M4-B)

Session 21 report §Step G の実測:

| $\eta$   | M4-B $\bar z_{\rm width}$ | 実測 v2 npz |
| -------- | ------------------------- | --------- |
| 0.000156 | 12.67                     | 6.08      |
| 0.0002   | 21.58                     | 6.09      |
| 0.0005   | 66.38                     | 5.67      |
| 0.001    | 90.65                     | 4.68      |
| 0.0025   | **170.10**                | 3.48      |

- **全 arm で実測を大幅に上回る** (最大 lr25 で target 5.13 の 33 倍)
- **width が η と共に単調増加** — 実測は η と共に単調減少 (完全逆傾向)
- **典型的な発散パターン**

## 5. Model M4-B 発散の 3 大欠陥

### 5.1 欠陥 1: $T_1^{\rm true}$ 項の欠落

Model M4-B の update rule:
$$\Delta \bar z_i = T_0 + T_4 + T_5 + Y_i$$

$T_1^{\rm true}$ (演算子応答 $\mathcal F(\mathcal K) \delta'$) が **欠落**。

問題:
- $T_1^{\rm true}$ は free subspace modes の contribution を含む (詳細 [[09_Y_iの物理的正体_bias_mode_cancellation_0918]] §7)
- Alive unit で $T_1^{\rm true}$ が **restoring 力** (unit を $\bar z$ 上に refit)
- $T_1^{\rm true}$ 欠落で unit が free subspace 方向に自由に動きすぎる → $\bar z_{\rm width}$ が過大

### 5.2 欠陥 2: $Y_i$ を独立 Gaussian random walk として扱った

M4-B の $Y_i$ 実装は各 task で $\sum \delta'_r \sim \mathcal N(0, \delta_{\rm amp} \sqrt{n_{\rm on}})$ の IID Gaussian サンプリング。

問題:
- 実測の $\delta'_r$ は前 task の SGD 結果 + 新 task の teacher 変更から生じる **state 依存量**
- IID Gaussian は state 相関を無視 → 各 task で独立にサンプリング
- $Y_i$ が独立増分の random walk として累積 → $\sigma \cdot \sqrt{N_{\rm task}}$ に発散

具体的な数値見積り (η=2.5e-3・M4-B):
- $c(\eta) = 6800 \times 2.5 \times 10^{-3} = 17$
- $|v_i| \approx 0.7$・$\delta_{\rm amp} = 0.9$・$\sqrt{n_{\rm on}} = 2$ (kp 群平均で $n_{\rm on} = 4$ 代表)
- Single-task $|Y_i|$ std ≈ $17 \cdot 0.7 \cdot 0.9 \cdot 2 = 21.4$
- 260 tasks 累積 (independent increments・random walk): std ≈ $21.4 \cdot \sqrt{260} \approx 345$

実測 M4-B width 170 は集団の interquantile-based 量 (q90 − q10) なので個別 std $\sim 345$ の半分程度で order 一致。

### 5.3 欠陥 3: $\delta'_r$ の state 条件付けなし IID Gaussian

M4-B では $\delta'_r$ の各支持点間の相関を無視し、bit-flip 後の全 32 支持点で独立サンプリング。

問題:
- 実測の $\delta'_r$ は前 task の SGD 結果として **32 支持点間に相関** を持つ
- 特に **bias mode 方向の $\delta'$** は前 task で refit されているので、新 task の $\delta'$ の bias mode 成分は小さい (階段状 pattern)
- IID Gaussian ではこの状態相関を無視 → bias mode 成分が過大
- **bias mode cancellation ([[09_Y_iの物理的正体_bias_mode_cancellation_0918]]) が働かない** → 実質的に $T_1^{0\text{th, bias-mode}}$ が過大に効く (欠陥 1 と結合)

### 5.4 3 大欠陥の複合効果

3 欠陥が独立に効くわけではなく、複合効果で発散する:

- 欠陥 1 ($T_1^{\rm true}$ 欠落): free subspace restoring 不在
- 欠陥 2 ($Y_i$ IID random walk): 各 task 独立で累積 $\sqrt{N}$ 発散
- 欠陥 3 ($\delta'$ IID Gaussian): bias mode cancellation 失敗

3 欠陥全部を解消しないと Model M4-B の発散は止まらない (単独解消では発散源が残る)。

## 6. M4-A と M4-B の共通の失敗: state feedback の欠如

M4-A と M4-B は両者とも **state feedback の欠如** を共有する:

- **M4-A**: $R$ を per (η, $k_{\rm on}^{\rm kick}$) の marginal から取り、v・$\bar z$ 依存を捨てる
- **M4-B**: $\delta'$ を IID Gaussian で取り、前 task の refit 履歴 (state) を無視

両者とも 「unit の state ($v$・$\bar z$・prev $k_{\rm on}$) が次 task の driver に反映されない」 のが本質的欠陥。v3i_joint (Chat) は R を state-conditional (v²・$\bar z$・$k_{\rm on}$ の bin) でサンプリングしたため、この欠陥を回避して 3 判定達成。

## 7. Model M4-C の設計指針 (Landing B の future work)

3 欠陥と state feedback 欠如を全て解消:

### 7.1 欠陥 1 の解消: $T_1^{\rm true}$ 項の追加

$$\Delta \bar z_i = T_0 + T_1^{\rm true} + T_4 + T_5 + Y_i$$

$T_1^{\rm true}$ は演算子応答 $\mathcal F(\mathcal K) \delta'$ から計算 (詳細 [[05_K_spectrumとF_K_decay_0918]] の $\mathcal K$ 対角化と Step C の実装)。

### 7.2 欠陥 2 の解消: $Y_i$ の閉形式使用

$$Y_i = c(\eta) \cdot v_i \cdot \sum_{r \in \mathrm{on}(i)} \delta'_r$$

Form (v) の閉形式 (詳細 [[08_Y_i閉形式_step_E_0918]]) を直接使う。

### 7.3 欠陥 3 の解消: $\delta'_r$ の state 条件付き統計モデル

$\delta'_r$ を state (前 task の $\bar z_i$・$k_{\rm on,i}$・$v_i^2$) に条件付けた統計モデル (v3i_joint 型の bin-based sampling を $\delta'$ に拡張):
$$\delta'_r \sim p(\delta'_r \mid v_i^2, \bar z_i, k_{\rm on,i}^{\rm kick})$$

Bias mode 成分は前 task で refit されている (階段 pattern) → 新 task の $\delta'$ の bias mode 成分を小さく設定。

### 7.4 3 欠陥解消後の予想

3 欠陥解消後は [[09_Y_iの物理的正体_bias_mode_cancellation_0918]] の bias mode cancellation ($Y_i \approx -T_1^{0\text{th, bias-mode}}$) が **自動的に成立** → $\bar z_i$ の発散が止まる。3 判定を維持したまま完全理論駆動化される (Chat 側の予想)。

## 8. Landing A の中での位置

Landing A の判定達成は v3i_joint 版 (Chat container 実装) で成立 ([[06_Model_M4_v3i_joint_3判定_0918]]) しているので、Model M4-A / M4-B の失敗は Landing A の判定を反証しない。しかし:

- **Landing A の完全理論駆動化は達成できていない** (alive branch は経験駆動・v3i_joint も empirical bin table を使用)
- **Model M4-C は Landing B の future work**
- 本ノートの 3 欠陥分析と state feedback 欠如の同定は Model M4-C の設計指針を与える

Session 21 report の判定 (原文引用): 「**Landing A 判定**: **部分達成**。Y_i の closed form (中核発見) は確立。ただし closed form の Model M4 統合には δ' の**状態依存**モデル (feedback loop) が必要。」

つまり Kubo 側 (Chat) の v3i_joint での 3 判定達成と、Claude Code 側の Model M4-A / M4-B での「部分達成」は視点が異なる:
- Kubo 側: v3i_joint (state-conditional empirical) で 3 判定達成 → 判定達成
- Claude Code 側: 完全理論駆動 (M4-A / M4-B) では未達 → 部分達成

両者は矛盾せず、Model M4-C (完全理論駆動 + state-conditional δ') を目指す共通の future work として整合。
