## 1. なぜ気になったか（Kubo 側の勘定・間違っていれば (1) で潰れます）

タスク長が 10,000 step 固定なら、$\eta\cdot$step を揃えたとき**サイクル数は揃わない**:

|                 | `LRoff0` | `LRoff0_lr0p00125` |
| --------------- | -------- | ------------------ |
| lr              | 0.01     | 0.00125            |
| step            | 5M       | 40M                |
| $\eta\cdot$step | 50,000   | 50,000（揃えた）        |
| **タスク数**        | **500**  | **4,000**          |
| $\bar z$        | −3.598   | −4.888             |

つまり「8 倍のタスク数で 1.36 倍深い」。**これは (a) まだ定着しておらずタスク数とともに深くなり続けている、(b) lr が平衡そのものを動かしている、のどちらでも起こる。** 同じことが [[命題1-5_上端則結果_0905]] 5-d にもあるので、1 回限りの偶然ではないと思う。

Kubo 側のモデルでは、この違いは意味が大きい。1 サイクルの期待変位のうち **lr に依らない項**（跳びの 2 次の項と、蹴りが折れ目を横切ることで出る一次の項）と **lr に比例する項**（過渡の雑音由来・Issa の R はその対角）を分けているが、
- (a) なら**すべての 5M 腕の末尾値は途中経過**で、腕どうしの比較は「同じタスク数どうし」に限られる。
- (b) なら lr は 2 つの入口を持つ（drift そのものと、暗黙正則化 $\propto\eta$ が決める**平衡スケール**）。実測の $\lvert v\rvert$ 0.604 → 1.268・$\lVert w\rVert$ 4.03 → 4.42 は後者の向き。

なお、**Kubo 側の理屈では「lr が小さいほど雑音由来の沈下が弱くなるので浅くなる」が出る**ので、観測（深い）を雑音の項だけで説明することはできない。

## 2. 聞きたいこと（3 行・既存ログのみ）

1. **タスク長は 10,000 step 固定か**（5M = 500 タスク・40M = 4,000 タスクという勘定で合っているか）。違えば以下は無効。
2. **`LRoff0_lr0p00125` の $\bar z$ 中央値を、タスク 451–500 の窓で**（＝ `LRoff0` と同じタスク数の時点で）読んだ値。ALIVE 規則・seed 中央値は末尾窓と同じ扱いで。
3. **`act_offset_0906` の settle 3 窓の判定は、$\Delta$（$c$ 腕 − $c{=}0$ 腕）に掛けたか、腕ごとの絶対値に掛けたか。** $\Delta$ だけなら、両腕に共通のゆっくりした drift は差で消えるので「定着」は共通 drift を排除しない——という理解で合っているか。

## 3. 答えで何が変わるか

| (2) の値                   | 読み                                                                                       |
| ------------------------ | ---------------------------------------------------------------------------------------- |
| **≈ −3.6**（`LRoff0` と同じ） | 深さはタスク数だけの関数。lr は 1 サイクルあたりの変位に効いていない（lr 非依存の項が主役であることの強い確認でもある）。**ただし 5M の末尾値は途中経過**になる |
| **`LRoff0` より深い**        | 同じタスク数でも小さい lr が深い。lr は平衡スケール（$v$・$\lVert w\rVert$）経由で設定点を動かしている                         |
| **`LRoff0` より浅い**        | Kubo 側の符号の読み（雑音は沈める向き）が間違っている                                                            |

**Kubo の事前予測（値を見る前）**: 1 番目（≈−3.6）に 55%、2 番目に 35%、3 番目に 10%。

余力があれば: `LRoff0_lr0p00125` の $\bar z$ を**タスク数の対数に対して**引いた図（500 → 4,000）。直線なら 1 番目、500 付近で頭打ちなら 2 番目。ただし (2) の 1 点だけでもだいぶ分かる。
