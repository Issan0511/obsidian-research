V3/V4 の「µ が壁を作る」と、V8–V10 の「W 増大」を、**同じ式の二つの成分**として書く座標系。数値は第1層・400タスク（PM）の事後集計で、出所は段階0の結果ノート。

## 1. 分解

重みを置換不変な方向とそれ以外に割る。

$$w_i = m_i\mathbf 1 + \widetilde W_i, \qquad z_i(x) = m_i\,S(x) + \widetilde W_i^\top x + b_i$$

- $m_i$ = 行平均（$w_i$ の全1方向成分）
- $S(x)=\mathbf 1^\top x$ = 画素和（**明るさ**）。PM ではタスクごとの画素置換で不変なので、タスクをまたいで蓄積できる唯一の入力方向
- $\widetilde W_i$ = 中心化重み（**模様**）。置換で毎回スクランブルされる

前活性の平均と分散（[[前活性分散の厳密分解_事後_0910]] と同じ恒等式）:

$$\bar z_i \approx m_i\bar S + b_i, \qquad \sigma_i^2 = \kappa_\Sigma\|\widetilde W_i\|^2 + \mathrm{Var}(S)\,m_i^2$$

**明度支配率** $\rho_i$ を第2項の割合と定義する:

$$\rho_i = \frac{\mathrm{Var}(S)\,m_i^2}{\kappa_\Sigma\|\widetilde W_i\|^2 + \mathrm{Var}(S)\,m_i^2}\in[0,1]$$

分子が $m$、分母が $\widetilde W$。**$\rho\to1$ とは「$m$ の成長が $\widetilde W$ の成長を追い越すこと」**。

## 2. 二つのデータ定数

**釘付け値** $c$（標準化深さの下限）: $\rho_i\to1$ のとき $m$ が約分されて

$$d_i=\frac{\bar z_i}{\sigma_i}\to \mathrm{sign}(m_i)\frac{\bar S}{\mathrm{sd}(S)}=\mp c, \qquad \text{一般に } d_i\approx-c\sqrt{\rho_i}$$

**吸収線** $\kappa$（上側の到達距離。V3 の Q26 の $\kappa=\operatorname{ess\,sup}(w\cdot\delta)/\sigma$ をこの方向で測ったもの）:

$$\kappa=\frac{\bar S-S_{\min}}{\mathrm{sd}(S)}$$

| 箱            | 壁の方向             | $c$      | $\kappa$ | 由来                                                                    |
| ------------ | ---------------- | -------- | -------- | --------------------------------------------------------------------- |
| **PM**（画素置換） | 全1方向 $\mathbf 1$ | **3.03** | **2.39** | $\bar S=103.9$, $\mathrm{sd}(S)=34.3$, $S_{\min}=21.9$（MNIST test 全体） |
| **RL**（画素固定） | $\hat\mu$（平均画像）  | **3.44** | **2.55** | $\|\mu\|=6.041$, $\mathrm{sd}(\hat\mu^\top x)=1.758$, $\min=1.560$    |

RL は画素を置換しないので置換不変な方向が $\mu$ 全体に広がる。壁の方向も定数もそのぶん変わる。

**記号の衝突に注意**: $\kappa_\Sigma=\mathrm{tr}(\Sigma)/784=0.0656$（分散分解の係数、0910 由来）と、吸収線 $\kappa$（V3 の Q26 由来）は別物。本ノートでは前者に $\Sigma$ の添字を付けた。[[用語と記号]] の統一は未対応。

## 3. 飽和条件が非負性に還元される

全入力が負側に入る（$\sup_x z_i<0$）のは $d_i+\kappa<0$、つまり $c>\kappa$ のとき。ところが

$$c>\kappa \iff \bar S>\bar S-S_{\min} \iff S_{\min}>0$$

**$\mathrm{sd}(S)$ も $\bar S$ も消え、入力の非負性だけが残る。** 画素が非負である限り、明度支配ユニットでは吸収が自動的に成立する。PM で余裕は $(3.03-2.39)\sigma=0.64\sigma$、RL で $0.89\sigma$。

一方、模様チャネル $\widetilde W^\top x$ は中心化されていて $c=0$。$\kappa>0$ なので $c>\kappa$ は絶対に満たされない。**$\|\widetilde W\|$ をどれだけ伸ばしても正側の裾が残る。**

これが [[固定尺度のReLU型活性化の飽和不可避性_仮説_0916]] §3.2 の条件（$\sup_x z\to-\infty$）が満たされる仕組みで、同 §4 の Issa の反例（$-3s$ と $+s$ の二点。$d=-1/2$, 上側到達 $+1$）は $\rho<1$ 側に整理される。反例は仮説の反証ではなく、**適用外の領域を示していた**。

## 3.5 極座標 — V3 の閉形式を代入すると吸収域は円錐になる

平面を張る（単位は前活性の標準偏差）:

$$A_i=|m_i|\,\mathrm{sd}(S)\ \ (\text{明度チャネル}),\qquad B_i=\sqrt{\kappa_\Sigma}\,\|\widetilde W_i\|\ \ (\text{模様チャネル}),\qquad \sigma_i^2=A_i^2+B_i^2$$

| 極座標                      | 中身                     | どの世代の主軸                  |
| ------------------------ | ---------------------- | ------------------------ |
| **半径** $r=\sigma$        | 前活性の幅                  | V8–V10（W 増大。§41・§42・§43） |
| **角度** $\theta$（$A$ 軸から） | $\cos\theta=\sqrt\rho$ | V3/V4（µ の壁。柱1・Q26）       |

V3 の死の閉形式 $s+M\le0$（$s=w\cdot\mu+b$、$M=\operatorname{ess\,sup}(w\cdot\delta)$）に、$w\cdot\mu\approx m\bar S=-cA$（$m<0$）と $M=\kappa r$ を代入すると

$$-cA+b+\kappa r\le0 \iff \boxed{\ \cos\theta\ \ge\ \frac{\kappa}{c}+\frac{b}{c\,r}\ }$$

**吸収域は $A$ 軸まわりの円錐（扇形）**。$b=0$ の半角は $\theta_{\rm crit}=\arccos(\kappa/c)$ = **37.9°（PM）/ 42.1°（RL）**。

- 左辺 $\cos\theta=\sqrt\rho$ は V3 の $\cos(u,\hat\mu)$、Q26 の $-\beta/c$ と同じ量。V3 は $\cos_{\rm crit}=-(b+M)/(\|w\|\|\mu\|)$ とユークリッドノルムで割っていたが、**$\sigma$（Σ ノルム）で割ると $c$ がデータだけの定数になり、条件が尺度不変になる**
- $\kappa/c$ = 現象1（µ の壁の位置）。データ定数
- $b/(cr)$ = **現象2（b 経路）が「円錐を広げる項」として同じ式に入る**。$r$ に反比例するので、半径が伸びると効かなくなる

**角速度は成長指数の差**: $\tan\theta=B/A\propto t^{\,b_{\widetilde W}-b_m}$。$b_{\widetilde W}>b_m$ なら円錐から離れ（生存）、$b_{\widetilde W}<b_m$ なら円錐へ回り込む（吸収）。§5 の指数表がそのまま角速度の表になる。

## 4. V3/V4 の µ の壁との対応

| V3/V4 の量                            | 本ノートの量                                                        | 備考                                               |
| ----------------------------------- | ------------------------------------------------------------- | ------------------------------------------------ |
| $s=w\cdot\mu+b$（周期内定数部）             | $\bar z=m\bar S+b$                                            | $\bar S=\mathbf 1^\top\mu$。µ の置換不変成分             |
| $\sigma=\|w\|_\Sigma$               | $\sigma^2=\kappa_\Sigma\|\widetilde W\|^2+\mathrm{Var}(S)m^2$ | 同じ量を2成分に割っただけ                                    |
| $\beta=s/\sigma$（ゲートマージン）           | $d=\bar z/\sigma$（標準化深さ）                                      | **同一の量**                                         |
| $\cos(u,\hat\mu)\le\cos_{\rm crit}$ | $\sqrt\rho$、$d=-c\sqrt\rho$                                   | $\sqrt\rho$ は $\Sigma$ 重み付きの $\cos(w,\mathbf 1)$ |
| Q26: 消灯 $\iff\beta\le-\kappa$       | $d\le-\kappa$、極座標で $\cos\theta\ge\kappa/c+b/(cr)$             | 全1方向での $\kappa$ が 2.39（PM）/ 2.55（RL）。§3.5        |
| 「µ を除去すると壁は定義域外」                    | $\bar S=0$ なら釘付け値も 0                                          | condA のオラクル中心化                                   |

**V3 の柱1「µ が壁を作る」は座標系として正しかった**。V8–V10 で W 増大へ主軸を移したのも正しい。段階0が言うのは、その二つが $w=m\mathbf 1+\widetilde W$ の二成分だということ。

- $m$ の成長 = 壁への接近（毒。$z_{\max}=-(c-\kappa)\sigma$ が深くなる）
- $\widetilde W$ の成長 = 壁からの防御（薬。$z_{\max}=+(\kappa-c\sqrt\rho)\sigma$ が正側へ伸びる）

**同じ「W が増える」でも成分によって符号が逆**。V9/V10 が幹に置いた $\|\widetilde W_1\|$ は薬の側の量で、V3 の壁は毒の側の量。Q26 の「有界入力では吸収域が正の測度で実在する」は、この方向では「必ず実在する」に強まる。

## 6. 開いている問い

1. **なぜ一部のユニットで $m$ の復元力が切れるのか。** ELU の t21–120 で整列項が正転する理由、なぜ10%だけか、なぜその窓か。$\varphi'$ が消えると正側からの復元勾配も消える（自己制限が自己強化に変わる）という読みは立つが未導出。→ [[駆動源問題_0909]] は「$m$ の復元力が消える条件は何か」に言い換わる
2. **$m$ の収支を更新則から出す。** [[W増大メカニズム_0909]] の二項収支は $\widetilde W$ 側だけで、$m$ の収支が書かれていない。駆動源問題 §11 の行平均除去の補正項がまさに $m$ の項
3. **多層での $\rho$。** 第2層の崩壊は $d\approx-3.0$〜$-3.5$ で、上流の飽和で入力の共通成分が支配的になり全ユニットが $\rho\to1$ に押し込まれる、という読み。ただし $S_2=\mathbf 1^\top a_1$ の統計は保存されておらず**未検証**
4. **谷型は別経路。** GELU/SILU は $\rho$ が減るのに吸収線越えが増える（PM で 22→75% / 30→54%）。$b$（負バイアス）経由で、現象2 の再登場。$\rho$ ではこれを説明できない

## 7. 限定

- 恒等式（§1–§3）は導出済みだが、$\bar z\approx m\bar S+b$ は $\widetilde W^\top\bar x_c$ を落とした近似（相関 0.95–0.995）。$\rho$ は test 全体の $\mathrm{Var}(S)$ を使う
- §5 は全て事後（`registered=0`, `analysis_grade=posthoc_not_preregistered`）・第1層・PM・Adam・400タスクに限る
- 混合ユニット（$\rho<1$）では $\kappa$ は方向依存なので $-2.39$ は厳密な吸収線ではない。$\sup_x z$ の直接確認は入力別 $z$ が未保存のためできていない
- 「$m$ が毒・$\widetilde W$ が薬」は $\rho$ と $\sigma$ の恒等式からの帰結であって、介入の効果を主張するものではない。中心化 $\widetilde W$ のみの減衰が $\rho$ を上げる（飽和型に害）という読みは未検証の候補
- §3.5 の $\theta_{\rm eff}$ 対 吸収線越えの対応は、中央値ユニットで要約した**腕あたり1点の粗い比較**（6点、ELU と R の順が逆転）。予測として登録したものではない。$\cos\theta\ge\kappa/c+b/(cr)$ の導出は $w\cdot\mu\approx m\bar S$（$\widetilde W^\top\mu\approx0$）の近似を含み、RL では $\hat\mu$ 方向で置き直す必要がある
