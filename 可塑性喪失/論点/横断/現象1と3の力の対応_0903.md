## 0. 一行

**問いの直観は正しく、しかも既に測られている。** $x>0$ で自己項（税）の相手をしている「押し」は正で活性化に比例し、その正体は $F_{\rm rest}$ である（8/22 §4・本ノート §3）。ただし「負けている」のではなく**フィットの定義により厳密に釣り合っている**。パズルの解は、**$F_{\rm rest}$ という同じ記号が、ユニットが出力を持つ（結合）か持たない（非結合）かで物理的に別物になる**こと: 結合ユニットの $F_{\rm rest}$ は「他のユニットが自分の出力を吸収した結果」（$\delta_{\rm rest}\approx-o_i$、鏡像）、`BL` の $F_{\rm rest}$ は「自分抜きで他が残した残差場」（$o_i\equiv0$ ゆえ $\delta_{\rm rest}=\delta$、外場）。**現象1 で凄まじい負の力が見えないのは、税がユニット自身の出力パワー $\mathbb E[o_i^2]$ の勾配であり、損失がそれを最小化している以上、鏡像で打ち消されるからである。`BL` にはその井戸が無い。**

「何度も否定された」のは**大きさで役割を割る**こと（Q2b・Q12）であって、代数（$F_{\rm gate}=F_{\rm self}+F_{\rm rest}$・$F_{\rm self}\le0$）ではない。そして**線形応答（バネ定数）は自己項だけから来て、大きさの割り算なしに同定できる**（§4）。これが「状態依存性で分けよ」（[[自己項の実在_力場_0902]] §4）の定量版になる。

## 2. 代数（厳密・1 層・二乗損失）

$\hat y=\sum_j v_j\varphi(z_j)+c$、$\ell=\delta^2$、$\delta=o_i+\delta_{\rm rest,i}$。$\theta_i\in\{w_i,b_i\}$ への力は

$$F_{\theta_i}=-2\eta\,v_i\,\mathbb E\bigl[\delta\,\varphi'_{\rm bwd}(z_i)\,\partial_{\theta_i}z_i\bigr]
=\underbrace{-2\eta v_i^2\,\mathbb E[\varphi_{\rm fwd}\varphi'_{\rm bwd}\,\partial z_i]}_{F_{\rm self}}
+\underbrace{-2\eta v_i\,\mathbb E[\delta_{\rm rest,i}\,\varphi'_{\rm bwd}\,\partial z_i]}_{F_{\rm rest}}$$

（順逆を分ける腕のために $\varphi_{\rm fwd}$・$\varphi'_{\rm bwd}$ と書き分ける。標準腕では同じ $\varphi$）。

- **結合ユニット**（$o_i\not\equiv0$・$\varphi'_{\rm bwd}\ne0$）: 損失は $\theta_i$ について井戸を持ち、フィット点で $F_{\rm gate}=0$。したがって $F_{\rm rest}=-F_{\rm self}$ が**フィットの帰結として**成り立つ。$F_{\rm self}=-\eta\nabla_{\theta_i}\mathbb E[o_i^2]$（[[自己項の恒等式]] §1）は自分の出力パワーの勾配なので、大きさは $v_i^2\times$活性化に比例する。**$x>0$ の税が巨大なら、鏡像の $F_{\rm rest}$ も同じだけ巨大で正**。これは 8/22 §4 の「中和率 0.99–0.999・self と rest が同率で伸びる」の代数的理由
- **`BL`**（$\varphi_{\rm fwd}\equiv0$・$\varphi'_{\rm bwd}=a$）: $\mathbb E[o_i^2]\equiv0$ なので井戸が無い。$F_{\rm self}\equiv0$、$F_{\rm rest}=-2\eta a v_i\mathbb E[\delta\,(x,1)]$ で $\delta$ は $\theta_i$ に依らない ＝ **他のユニットが決めた外場**。$v_i$ も凍結（$g_v=2\delta\varphi=0$）。動いても何も戻ってこない
- **`R`**: 両方 0。**`FL`**: $\varphi'_{\rm bwd}=0$ で両方 0（$v$ だけ学習）

これが [[順逆分離2x2結果_0902]] §2.1・先生 ★訂正 2 の 2×2 と同じ表で、**現象3 の「自己項＋押し」は代数的には $F_{\rm self}+F_{\rm rest}$ そのもの**。禁じられているのは翻訳ではなく、この 2 項の**大きさ**から役割を割ること（§4 参照）。

## 4. 同定できる量 — バネ定数は自己項だけから来る（厳密）

他のユニットを固定して $\theta_i$ を $\varepsilon$ だけ動かすと、$\delta$ は $v_i\varphi'_{\rm fwd}(z_i)\,\partial z_i\,\varepsilon$ だけ動く。よって $b_i$ 成分の線形応答は（**区分線形で $\varphi''=0$ のときに限り**。ELU・SiLU・GELU はこの条件を満たさないので下の一般形を使うこと — §4b・§4c）

$$k_i:=-\frac{\partial F_{b_i}}{\partial b_i}=2\eta\,v_i^2\,\mathbb E\bigl[\varphi'_{\rm fwd}(z_i)\,\varphi'_{\rm bwd}(z_i)\bigr]\qquad(w_i \text{ 成分は } \mathbb E[\varphi'_{\rm fwd}\varphi'_{\rm bwd}\,xx^\top])$$

## 4b. ★訂正 1 — ELU の $k_i$ は消えるのではなく**負になる**

Issa の問い（9/3・チャット `ELUバネ符号_0903`）「ELU 本当にバネが消えるの？」への答え。**消えない。符号が変わる。**

§4 冒頭の $k_i=2\eta v^2\mathbb E[\varphi'_{\rm fwd}\varphi'_{\rm bwd}]$ は区分線形（$\varphi''=0$）専用の式で、ELU には使えない。使うべきは同じ節が括弧で書いている一般形

$$k_i=2\eta v^2\,\mathbb E\bigl[\varphi'^2+\varphi\varphi''\bigr]=\eta v^2\,\mathbb E\bigl[(\varphi^2)''\bigr]$$

すなわち**自己ポテンシャル $U=\eta v^2\varphi^2$ の曲率**。ELU（$z\le0$・$\varphi=\alpha(e^z-1)$・$\varphi'=\varphi''=\alpha e^z$）で計算すると

$$\varphi'^2+\varphi\varphi''=\alpha^2\bigl(2e^{2z}-e^{z}\bigr),\qquad\text{符号は }2e^{z}-1$$

- $z>-\ln 2=-0.6931$ で $k_i>0$（バネ）／$z=-\ln 2$ でちょうど 0／**$z<-\ln 2$ で $k_i<0$**
- 深部では $e^{2z}\ll e^{z}$ なので $k_i\simeq-2\eta v^2\alpha^2e^{z}<0$。落ちていた $\varphi\varphi''$ 項の方が支配的（$\alpha$=1・$z=-3$ で $\varphi'^2=2.48\times10^{-3}$ に対し $\varphi\varphi''=-4.73\times10^{-2}$）
- 数値（$\alpha$=1・$k_i/2\eta v^2$）: $z=-1$ で $-0.0972$、$z=-3$ で $-0.0448$、$z=-8$ で $-3.35\times10^{-4}$。$F=-2\eta v^2\varphi\varphi'$ の中心差分と一致を確認

**力の向きは反転しない。** $F_{\rm self,b}=-2\eta v^2\alpha^2(e^{2z}-e^{z})>0$ は $z<0$ の全域で帯へ向かう。反転するのは剛性の側で、理由は $U=\eta v^2\alpha^2(e^z-1)^2$ が $z\to-\infty$ で $\alpha^2\eta v^2$ に**飽和する台地**だから。井戸ではなく、平らになっていく斜面の外側にいる。leaky の $U=\eta v^2a^2z^2$（放物線・$k_i=2\eta v^2a^2$ 一定・深いほど強い）との対比がここに立つ。

台地は測ってもいる: [[ELU可動度の深さ座標結果_0903]] の「$\varphi/\alpha$ が $-1$ に貼り付く（帯間の振れ 3.0〜8.5%・leaky は 78〜518%）」が $U$ の飽和そのもの。交差点 $-\ln 2$ は沈下分布のほぼ最浅端にあり、`E_1216`@15M の $\max_x z$ 帯では深さ 0–1 が 1.62M / 4.94M ＝ 33%（中央値 0.48）、**残り 67% はすべて $k_i<0$ 側**。

**`BL` の非有界とは別物。** `BL` は $k_i=0$ かつ外場が残る組み合わせだが、ELU は $k_i$ も外場も同じ $e^{z}$ で一緒に消えるので、暴走ではなく台地の上で指数的に遅くなる。§6 の書き直し案の「ELU の深部で凍結」は結論としては変わらないが、理由は「$\varphi'_{\rm fwd}\varphi'_{\rm bwd}\to0$」ではなく「$U$ が台地になり $k_i<0$、力も $\to0$」。

格: **代数・導出のみ・未測定**（$k_i$ 自体は §7-3 のとおり未測定）。数値は初等関数の評価で、走を伴わない。

## 6. 現象3 の文の書き直し案（裁定は Issa・先生）

「復元力と押しの綱引きで押しが勝つと LoP」は、結合腕では**綱引きとして測れない**（鏡像）。$k_i$ の言葉で書くと:

> 非 ReLU の LoP は、ユニットが井戸から外れること — $\varphi'_{\rm fwd}\varphi'_{\rm bwd}\to0$（ELU の深部・ReLU・`FL`）で凍結、$\varphi'_{\rm fwd}=0$ かつ $\varphi'_{\rm bwd}\ne0$（`BL` 族）で暴走、$\varphi^2$ の分水嶺越え（SiLU・GELU）で自己平衡点の $-\infty$ への移動 — として起き、井戸に居る間（leaky・浅い ELU）は深さがフィットで決まり LoP しない。

現象1 との対応: 同じ井戸（税 ＝ 鏡像の rest）に居て、ReLU は壁を越えた瞬間に $k_i\to0$ かつ外場 $\to0$ で凍る。**3 現象は「井戸から外れる 3 つの型」**。

## 8. 追記（同日・チャット `現象1x3横断_0903`）— 「揺れも壁で消える」は議論されていたか

> **Issa の問い**: $x>0$ で起きたランダムな揺れは、0 を潜ったら消える。これはそもそも議論していたか。

**半分だけ。** 「壁の下で勾配が開集合上で恒等ゼロ」（[[自己項の恒等式]] §1 系・[[吸収不等式の命題化_0824]]）は力についても揺れについても同じ文なので、**揺れが消えること自体は定義として織り込まれていた**。しかし v3 柱2「ほぼ対称な揺れ × 片側吸収」の「揺れ」は勾配由来の揺れ（フィット中のジッタ）と読める書き方で、**その揺れは壁に近づくほどゲートで細り、壁の下では消える**ので壁を割る担い手にはなりにくい、という帰結は 8/31 の E3 `BOUNDARY_CARRIES_DESCENT` と 9/2 の [[負に押す力の正体_0902]] §1（flip ＝ ゲートされない入力側の OU 浴・$-2/15$）まで明文化されていなかった。**「揺れ」には 2 種類あり、片方だけがゲートされる**、と一か所に書いた文は vault に無かった。

| 揺れの種類                                             | 経路     | ゲート                                        | 壁の下で                    |
| ------------------------------------------------- | ------ | ------------------------------------------ | ----------------------- |
| フィット中の SGD ジッタ $-2\eta v\delta_t\varphi'(z_i)x_t$ | 勾配     | **される**（$\propto\varphi'$、ReLU では発火パターンのみ） | 消える                     |
| refit 過渡（flip 直後・$\delta$ 大）                      | 勾配     | される（ただし $\delta$ が大きいので細る前に効く）             | 消える                     |
| 境界の跳び $\pm w_k$・$\gamma(k)$ の引き直し                 | **入力** | **されない**                                   | 続く（OU 浴・沈下ユニットで −0.143） |

**補足（導出・ReLU は区分線形なので §4 の式がそのまま使える）**: ゲートされる揺れは壁際で消えるが、バネ定数 $k_i=2\eta v^2\hat p$ も同じ $\hat p$ で消えるので、揺らぎ散逸の比 $\text{noise}^2/k\propto\eta\,\mathbb E[\delta^2]/v^2$ は $\hat p$ に依らない。**壁際のユニットは「守られている」のではなく「遅くなっている」だけ**（臨界減速）で、振幅は落ちない。それでもゲートされた揺れは発火パターンにしか当たらず全 32 パターンを同時に沈めにくいので、最後の一押しは入力側（flip）か $\delta$ の大きい過渡が担う。

**検算（事後・`ratchet_log_0819` seed 0・未登録）**: $\hat p>0\to0$ の遷移 910 件を直前の flip からの距離で切ると、**flip 当該 step 116・2〜100 step 453・101〜1000 step 256・1000 step 超 85**。1 step あたりの率に直すと flip 直後 100 step が ≈4.6/step、101〜1000 が ≈0.28/step、以降 ≈0.009/step で **フィット領域の 500 倍**。恒久死 94 件も 9／55／19／11 で 68% が flip 後 100 step 以内。**復活 847 件は全件が flip 当該 step**（タスク内 0・[[順逆分離2x2結果_0902]] §4.1 の `R` within-task 0 と整合）＝ **壁の下でユニットを動かすのは入力側の跳びだけ**、の直接の姿。バルク記録は 1000 step 刻みなので 101 以降の 2 区分は粗い。

**帰結**: 一行の「意味のない揺れで落ちていく」の「揺れ」は、**フィット中のジッタではなく flip（と直後の refit 過渡）**と書くべきで、それはゲートされないからこそ壁を割れる。Issa の違和感は正しく、v3 の文はこの区別を欠いていた。
