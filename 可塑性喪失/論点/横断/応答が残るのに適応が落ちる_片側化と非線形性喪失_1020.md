# 応答が残るのに適応が落ちる — 片側化と非線形性喪失

更新: 2026-10-20 / 作成: Codex
依頼: Issa「ReDoのノートとは別にLeakも片側化で精度低下してるので『そういう応答低下死じゃない奴ら』をまとめるノート作って」。
役割: **死亡率や平均応答だけでは捉えきれない適応低下の入口**。主例はLeakとReDo、補助例は固定Snake。各走の結果正本を置き換えず、新規実験・V13本文の改稿は含まない。

## 1. ここでまとめたいこと

**活性化の微分が消える死亡を防いでも、十分に学び直せるとは限らない。** Leakでは負側にも微分が残るが、負側への片側化と成績低下が観測されている。ReDo後のReLUでは、正側に寄って微分がほぼ1のまま、折れ目を使わなくなるユニットが増える。

両者をつなぐのは、**入力が変わってもほぼ同じ側の直線部分を通り、そのユニットが入力ごとに傾きを切り替えなくなること**である。正へ寄るか負へ寄るかと、微分がゼロになるかは別の軸になる。

ただしLeakでは、正側の傾き1から負側の小さい傾きへ移ることで、平均応答も下がりうる。したがって、この群を「応答低下が全くない」とは定義しない。ここで分けるのは、**応答の消失・極小化**と、**応答を残した片側化・非線形性の喪失**である。両経路は同じユニットで併存しうる。

## 2. 何が同じで、何が違うか

下表は一つのユニットについて、その層への入力集合上で考える。$p=P_x(z(x)>0)$、Leakの負側の傾きを $0<\alpha<1$ とする。

| 状態                   | 前活性の配置   | 残る局所応答          | 折れ目の利用 |
| -------------------- | -------- | --------------- | ------ |
| ReLUの負側死亡            | 全入力が負側   | 微分0             | 失う     |
| ReLUの正側片側化（ReDoでの主例） | ほぼ全入力が正側 | 微分ほぼ1           | ほぼ失う   |
| Leakの負側片側化           | ほぼ全入力が負側 | 微分ほぼ $\alpha>0$ | ほぼ失う   |
| Leakの正側片側化           | ほぼ全入力が正側 | 微分ほぼ1           | ほぼ失う   |

Leakの微分を $g(x)=\varphi'(z(x))$ とすると、

$$
g(x)=\alpha+(1-\alpha)\mathbf1[z(x)>0],
$$

$$
\mathbb E_x[g]=\alpha+(1-\alpha)p,\qquad
\mathbb E_x[g^2]=\alpha^2+(1-\alpha^2)p,
$$

$$
\operatorname{Var}_x(g)=(1-\alpha)^2p(1-p).
$$

**応答の大きさと、入力による傾きの違いは別の量である。** 正側の $p\to1$ では応答が1へ近づいても、傾きの分散は0へ近づく。負側の $p\to0$ では応答は $\alpha$ に残り、やはり分散は0へ近づく。ReLUは上式の $\alpha=0$ に対応する。

これは**同じユニットに違う入力を入れたとき**の変化であり、ユニット同士がクローンになるという意味ではない。異なる重みを持つユニットが、それぞれ別の線形特徴を表すことはできる。

厳密に同じ枝に留まるなら、そのユニットの出力はその層への入力 $h$ に対して $c(w^\top h+b)$ というアフィン関数になる。ただし、ほぼ片側という測定だけから近似誤差の小ささまでは保証されず、前段が非線形ならネットワーク全体も直ちに線形にはならない。特徴rankが必ず下がる、片側化したら必ず精度が下がる、という命題もここからは出ない。

## 3. Leak — 非ゼロの床を残した負側片側化

根拠: [[RL-CIFARのMLPで13の活性化をバトル_kunekune_結果_0918]]。**乱数ラベルCIFAR-10**のMLP（3072–100–100–10）、Adam $10^{-3}$、50課題、seed 0–9。実ラベル5+1のReDoとは設定が異なる。

### 成績の低下は10 seedの結果

| Leak 0.1 | 後期online精度 | 早期から後期への低下 |
| -------- | ---------: | ---------: |
| raw入力    |     72.64% |   4.93ポイント |
| std入力    |     96.55% |   1.39ポイント |

後期onlineはt31–50、低下は各seedでの(t1–10)−(t41–50)。表はそれぞれのseed中央値であり、窓の違う値から引き算し直さない。数値正本は `results/rlcifar_mlp_battle_0918/summary.md`。

### 片側化の内部測定は事後・seed 0

第1層のLeak 0.1・rawでは、ほぼ片側のユニット割合がt1で38%、t10で55%、t50で43%だった。t10・t50で該当した個体は負側である。stdのt1・t50では0%。判定は各個体の $\min(p,1-p)<0.01$、すなわち入力の99%超が同じ側にあること。

Leak 0.01・rawでは、t10・t50の全個体がこの「ほぼ負側」の基準に入った。**旧記述の「全個体が厳密にアフィン」は強すぎる。** 少数の正側標本が残る個体があり、出力表の丸められた0や、ゲート変動の個体間中央値0を、全個体で厳密に0と読んではいけない。1020に保存された前活性配列と指標実装を再照合した。

この内部測定を10 seedの成績集計と同じ反復数の証拠として扱わない。また片側割合は38→55→43%で単調増加しておらず、「片側率が増え続けるから成績が落ち続ける」とは読めない。Leak 0.3では片側率0%の観測でもraw/stdの成績差が残るため、この閾値一つで全ての性能差は説明できない。

**確かめたこと**は、非ゼロ微分を残した時間劣化と負側片側化の存在である。**片側化がその精度低下を媒介したことは未検証**。傾きを変える比較やraw/std比較は、初期特徴、応答の大きさ、入力の幾何なども変える。解釈の正本は [[RL-CIFARの入力平均と非線形領域_V10とkunekuneの考察_0919]] §10・§13と [[V11監査訂正の反映_0923]]。

## 4. ReDo — 救済後の正側片側化

詳細は [[ReDoのvリセットと正の片側化_因果対照とFable検証_1019]] に置く。ここでは共通論点に必要な結果だけを引く。

**実ラベルCIFAR-100の5+1・ReLU MLP、初回リセット後の第3課題、20 paired seed**。交換対象・新しい入力重み・データ順を揃え、交換した第2層ユニットの出力重み初期化を変えた。

| 出力重みの初期化     | 50更新後のほぼ全開個体割合 | 第3課題online |
| ------------ | -------------: | ---------: |
| 元のReDo（zero） |         88.14% |     62.94% |
| 非ゼロのrand10   |         28.49% |     65.90% |

ほぼ全開は各個体の $p\ge0.99$。第3課題の全2500学習画像で測り、固定した初回交換群の割合をseed内で計算してから20 seedを等重み平均した。全層の死亡率でも、全ユニットの平均開口率でもない。

出力ゼロ化がその後の正側片側化を強めることと、非ゼロ化が次課題成績を改善することは、対応介入で支持された。一方、中心化とランダムな座標変更の対照では、片側化をより減らした腕の成績が高いとは限らなかった。**片側化が成績差を媒介した寄与は分離されていない。**

ここで微分がほぼ1というのは、交換ユニットの活性化の性質である。小さい読み出し $v$、逆伝播される誤差、入力の構造によって実際の勾配は小さくなりうる。「全開だから十分に更新される」とは言わない。また、初回交換の成績差から長期のReDo全体を否定しない。

## 5. 補助例 — 固定Snakeは平均応答が高くても劣化する

[[5p1MLPに固定Snakeを足す_結果_1019]] は、同じ大きな論点に属する別の例である。**片側化の例としては数えない。**

実ラベル5+1 CIFAR-100・MLP、seed 0–9。後期窓はhard課題21・23・25・27・29、値はseed中央値。

| 腕                 | 第2層の平均応答指標mob | 後期online | fresh gap |
| ----------------- | ------------: | -------: | --------: |
| SNA               |         0.804 |   67.10% |  3.21ポイント |
| 固定Snake 0.6（SN06） |         0.988 |   60.43% | 11.29ポイント |
| 固定Snake 3（SN3）    |         0.995 |   54.05% |  7.05ポイント |

mobの基礎量は、各個体の入力平均微分を個体間で中央値にした指標である。層内の全入力・個体を一括した単純平均ではない。表は元走の後期集約値のseed中央値。

SN06・SN3はともにSNAに10/10 seedで劣り、登録した対応検定でも差が出た。平均応答はほぼ1に残るが、課題に合わせ直す能力は十分に保たれなかった。

この走では固定尺度の下で位相幅 $2\alpha W$ の増加も観測された。ただし、周期との尺度不整合が成績差を媒介したとまでは同定していない。**平均応答が大きいだけで健全とは判定できない**という補助証拠として使う。Snakeには入力による傾きの変動が残りうるので、Leak/ReDoの片側化と同じ原因にまとめない。

## 6. 一つの量に戻さないための読み方

既存の [[ゲート被覆か非線形性か_結果_0911]] でも、平均応答・支持内の非線形性・性能の関係は、活性化の族をまたぐ比較と、同じ腕への介入で一致しなかった。平均応答を上げる介入の効果が小さく、平均応答が下がる介入で大きく改善する場合もある。「平均応答が全て」を「傾き分散が全て」に置き換えない。

整理すると、見る対象は次のように分かれる。

| 見る対象              | 分かること          | それだけでは分からないこと         |
| ----------------- | -------------- | --------------------- |
| 微分0の個体・入力の割合      | 活性化のゲートによる勾配遮断 | 応答を残す個体が十分学べるか        |
| 微分の平均・二乗平均        | 局所応答の量         | 入力に応じて傾きが切り替わるか       |
| 個体別のp分布・微分の入力間分散  | 片側化と折れ目の利用     | 成績差の媒介寄与、ユニット間の特徴rank |
| 読み出しを含む勾配・実更新     | どの入力側パラメータが動くか | 更新が新課題に役立つか           |
| online・freshとの差など | 学び直しの成績と喪失     | どの内部経路が原因か            |

**層全体の平均開口率だけでは片側化を判定できない。** 平均が0.5でも、各個体が半分ずつ開く場合と、全開個体・全閉個体が半々の場合がある。

このノートに含める中心例は、応答を残した片側化である。ELU・SiLU・GELUが深い負側で極小応答や数値的なゼロに至る例は、厳密な死がまだ無い時点でも、応答低下の経路として別に読む。

## 7. 先行研究と、論文で言える位置

正側でReLUが恒等写像になるzombie unitと線形化の問題は、[Lyle et al., Disentangling the Causes of Plasticity Loss in Neural Networks](https://proceedings.mlr.press/v274/lyle25a.html) に先行がある。最終版§3.2・付録F.8は線形化と学習停滞、付録Dは全体が線形化した条件でのNTK rankの制約を扱う。既知の一般機構を今回の片側化の読みへ接続できる。一方、個々の実験での性能媒介の証明まで置き換えるものではない。

ReDoへの既存批判・非ゼロ出力初期化の先行は [[ReDoのvリセットと正の片側化_因果対照とFable検証_1019]] §7を参照する。「死亡が少ないのに性能が悪い」「非ゼロ初期化が良いことがある」だけを新規性にしない。

本ノートから使える主張は次の形になる。

> 活性化の局所応答を残すことは、適応維持の十分条件ではない。Leaky ReLUの負側片側化と、ReDoで再生したReLUの正側片側化は、応答を残したまま入力に応じた傾きの切替を失う例として捉えられる。Leakでは片側化と時間劣化を観測し、ReDoでは出力ゼロ化が片側化を促進することを介入で示した。固定Snakeの劣化も含め、平均応答と学び直し能力を同一視できない。各例の性能低下をどの経路がどれだけ媒介するかは、証拠の範囲を分けて述べる。
