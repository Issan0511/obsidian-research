## 0. 記号（[[用語と記号]] に従う。本ノートで追加する呼び名は 3 つだけ）

- $z_i=w_i\cdot x+b_i$、$\bar z_i=\mathbb E_{\rm support}[z_i]$（深さ・生の壁座標）、$z_{\max,i}=\max_{\rm support}z_i$（上端）、$z_{\min,i}$（下端）。支持は rnd 5 bit の 32 パターン。

- 蹴り: flip で bit $k$ が反転すると $z_i$ が全支持点で $\pm w_{ik}$ だけ跳ぶ（§5 の「flip の蹴り」）。

- 残差 $\delta=\hat y-y$。refit＝タスク内で残差を消す SGD。
- **本ノートの呼び名（3 つ）**: 定数極・殻極・角検出項。定義は §1。

### (3) spec B（殻極）に対する当方の事前予言 — 大きさは言えない・格 C

当方の殻極は parity 残差の 2 次の効果（残差の parity 成分を消す refit で $v$ と $w$ が動く量の 2 乗）です。固定教師に $\pm\varepsilon\,u_{\rm parity}$ を入れる設計は、この「2 次の効果」を偶応答で取り出す形になっていて、当方の枠組みと噛み合っています。

- (a) **$P>0$**（K1 で下・K31 で上）。spec の候補予測と同じ。
- (b) **$P\propto\varepsilon^2$**（$\varepsilon/Y$ = 0.01／0.03／0.10 で 1 : 9 : 100）。refit が線形な範囲で。$\varepsilon=0.10Y$ は非線形に入る可能性があります。**spec の振幅感度（REPORT_ONLY）がそのまま当方の検定になります。**
- (c) 平均成分の偶応答 $D_{\rm mean}$ は定数極の応答で、K1 で**上**・K31 で**下**。bit 成分（次数 1）については当方は予言を持ちません。

**弱点**: (i) 殻極の係数（残差の parity 固有値）を当方は持っていないので、大きさは出せません。(ii) 殻極が立つのは「折れ目を跨ぐユニット」だけで、$b$ だけで作る鏡像構成は K1・K31 とも跨いでいるのでこの条件は満たされますが、自然状態の K1 と $w$・$v$ が同じで $b$ だけ違う人工状態なので、自然な沈下への外挿は別です。(iii) 1000 更新で refit が終わらなければ（MSE 比 > 0.1）、(b) の比は「途中」の値になります。

### (4) spec C（角検出項）に対する当方の事前予言 — 格 C

当方の角検出項は「折れ目を横切った点の可動度が $1\leftrightarrow a$ で変わり、戻りが非対称になる分」で、蹴りの 1 乗・下向き・$\propto(1-a)v_i^2$・**横切った点の数に比例**。

- (a) **CROSSING_DOWN_CONTRAST**（$C<0$）。$G(h_{\rm below})\approx0$、$G(h_{\rm cross})<0$。
- (b) $\lvert G(h_{\rm multi})\rvert>\lvert G(h_{\rm cross})\rvert$。**横切った点の数で割ると腕をまたいで揃う**のが当方の形。
- (c) K1 側と K31 側で同符号（下）。K31 側は横断が off→on 1 点分で弱い。

**弱点**: (i) 当方の式は蹴りが $w_{\rm flip}$ 経由（入力の切替）で、$b$ の蹴りには $\Delta w_{ik}=u_k\Delta b_i$ の寄与がありません。$\bar z$ の並進としては同じですが、幅の変化が伴わない分だけ違います。(ii) $v$ は更新されるので $v_i^2$ の係数は時間で動きます。(iii) LIVE と PRE_GATE の 0+ の出力差（$v_i\times$ 折れ目の余り）が主応答と比例するなら「1 更新目の非対称」で説明がつき、比例しなければ再適応の経路が要ります——spec §7 の検算がそのまま当方の予言の検定になります。

### (5) 記号の書き分け（当方側で対応・用語集の変更は求めない）

spec の $h$（蹴りの振幅）・$G$（ゲート介入差）・$u_{\rm mode}$（誤差モード）・$D$（偶応答）は、当方のノートの $h_i$（on 指示関数）・$G$（支持点の入力グラム）・$u_k$（flip bit の実効入力）・(D1)(D2) と衝突するので、当方側では $h_{\rm kick}$・$G_{\rm gate}$・$u^{\rm err}_{\rm mode}$・$D^{\rm even}$ と書き分けます。spec の表記は変えないでください。

## 4. 依頼 — `drift_law` の表を online と full-batch で同じビンに並べる（走ゼロ・再集計 1 回）

対象: [[前活性1次元のdrift則_結果_0907]] §5 の表（$\bar p^{(8)}_{\rm up}$ ビン × 1 タスク drift）。

**依頼**: 同じ表を **full-batch の腕**（`offset_grid_0906` の `FBLRoff0_1216`。あれば `boundary_dense_0907` の full-batch 腕も）について、online と同じビン境界・同じ条件付け（両端を除く 8 タスク平均）で出していただけないでしょうか。既存ログの再集計だけで、新しい走は要りません。

**見たいのは 2 つ**:

1. **full-batch だけで $p^\ast$ が残るか。** 残れば「タスク切替の残差の 2 次で立つ井戸」が実在、消えれば線形域ではその係数が検出限界以下。
2. **online − full-batch の差**（ビンごと）。ミニバッチ雑音が運ぶ成分の drift 場。`offset_grid_0906` の正本で、online と full-batch の $\bar z$ の差は $c=-0.5$ で +0.56（上）・$c=+0.5$ で −0.60（下）——雑音は両方向とも「平均活性がゼロになる点」へ向けて運んでいるように見えるので、それを drift 場として確かめたい。

**当方の側の誠実さのために書いておくこと**:

- 当方の枠組みでは、井戸はタスク切替の残差の 2 次で立つので **full-batch でも残ると予言します**。したがって 1 で $p^\ast\to0$ が出れば、当方に不利な結果です（構造の反証ではなく係数の問題、と読みますが、それは結果を見てから書きます）。
- ミニバッチ雑音の成分は当方の枠組みでは「refit 過渡の雑音 drift」に当たり、井戸と同じ向きの加速器と置いています。現在の当方の中心の式にはその重みを入れていないので、2 の差が出ればそれを足します。
- `offset_grid_0906` の「上群 10.2%／0%／0%」の表は、Kramers 型（決定論の井戸＋雑音で障壁越え）と Chen 型（井戸へ運ぶ drift 自体が雑音の項）を分けないので、決め手にはしていません。1 と 2 で初めて分かれます。

**費用**: online 側は §5 の表が既にあるので、full-batch 側の再集計 1 回。
