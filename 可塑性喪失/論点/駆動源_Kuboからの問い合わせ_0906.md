## 0. 記号（[[用語と記号]] に従う。本ノートで追加する呼び名は 3 つだけ）

- $z_i=w_i\cdot x+b_i$、$\bar z_i=\mathbb E_{\rm support}[z_i]$（深さ・生の壁座標）、$z_{\max,i}=\max_{\rm support}z_i$（上端）、$z_{\min,i}$（下端）。支持は rnd 5 bit の 32 パターン。
- $\phi$ は活性化関数。leaky の負側傾きは $a$、ELU の $\alpha$。可動度 $=\mathbb E[\phi']$（`mob`）。
- 蹴り: flip で bit $k$ が反転すると $z_i$ が全支持点で $\pm w_{ik}$ だけ跳ぶ（§5 の「flip の蹴り」）。
- $\hat p_i$: 発火率。leaky では $\hat p=(\text{mob}-a)/(1-a)$ で復元できる（[[引用禁止]] B「mobility は $\hat p$ の一次関数」）。$\hat p=1/32$ は `near_off`。
- **alive／dead は §10.3 と同じ $\lvert v_i\rvert>0.05$／$\le0.05$**（$\hat p$ ではなく読み出しの大きさ）。
- 残差 $\delta=\hat y-y$。refit＝タスク内で残差を消す SGD。
- **本ノートの呼び名（3 つ）**: 定数極・殻極・角検出項。定義は §1。

## 1. 背景: 上端則と復元場を作る 3 つの力（Kubo 側の読み・裁定は求めない）

出所は共通で、**refit の暗黙正則化**（Blanc 型: 残差を消すときに $v$ と $w$ が動く量の 2 次の効果）と、**蹴りがゲートを変える効果**の 2 つ。

| 呼び名      | 出所（一言）                                                                                                                                                                 | 向き（上端で）                                                                            | $v$ 依存                                 | 誰に働くか                                     | Issa 側の対応物                                                                                                                                         |
| -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- | -------------------------------------- | ----------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| **定数極**  | 残差の**平均成分**を消す refit。零点はユニットの平均活性 $\mathbb E_{\rm support}[\phi(z_i)]=0$ の点（線形なら $\bar z=0$、leaky なら折れ目の少し下、$\phi\to\phi+c$ なら $\overline{\phi+c}=0$ ＝ 支持が負側なら $-c/a$） | **上へ**（強さ $\propto a$）                                                             | **依らない**（$v$ の勾配が出所なので $v\to0$ でも消えない） | 全ユニット                                     | **§10.3 の復元場**（dead でも引き戻す・固定点が $a$ とともに 0 へ）と、**`act_offset_0906` の候補 1**（$\lvert\phi\rvert$ の偏り・$v$ 経由・「$E[(\phi+c)^2]$ を下る」）。R が「位置」を当てる範囲も同じ向き |

`act_offset_0906`（`OFFSET_SIGNED_B`・△）は定数極の直接の観測に見える: c>0 の着座 $-c/a$（−5.015／−19.65）は $\overline{\phi+c}=0$ の点で、$\phi'$ に目印の無い位置。**c<0 が底（+0.5／+2）に届かず −2.1〜−2.4 で止まるのは、定数極と「下向きの項」の釣り合い**——Issa の §4-2「両方要る」と同じ絵で、**B1 はその下向きの項が角検出項（$v^2$・蹴りの 1 乗）か殻極（$v^0$・parity）かを割る**。

**1 点 on の上端では 3 つとも「下」を予測する**ので、そこだけ見ても割れない。割れるのは:
1. **1 点 off のユニット（$\hat p=31/32$）**: 殻極だけが「上」。定数極は下、角検出項は 32 点中 1 点分の非対称で弱い下。
2. **dead（$\lvert v\rvert\le0.05$）**: 角検出項だけが消える。
3. **$a$ 依存の形**（`scale_attractor_b_0906` の 10 水準）: 殻極 $(1-a)^2$、角検出項 $(1-a)$（設定点）または $(1-a)/a$（§5 の時間平均の言い方）。

**復元場との関係（B1 の (c)）**: §10.3 の固定点 $z^\ast$（$a=0.1\ldots1.0$ で −3.47 → 0.00・△）は、定数極の零点 $\mathbb E_{\rm support}[\phi(z_i)]=0$ を「支持の広さ」で解いたものと同じ形になる。支持 32 点を等大の 2 項分布（$z=\bar z+w(k-2.5)$、$k=0..5$、重み $\binom5k/32$、$w=(z_{\max}-\bar z)/2.5$）で近似すると $z^\ast/w$ は $a=0.1\ldots1.0$ で −1.05／−0.71／−0.51／−0.40／−0.31／−0.23／−0.17／−0.10／−0.05／0（Kubo の手計算）。dead の固定点が浅いのは、線形化で $\lVert w\rVert$ が縮んで支持が狭まる（$z^\ast\propto w$）で読める。**§10.3 の機構候補 (ii)「冗長パラメータの暗黙正則化」は定数極と同じ対象**。

## B1. 上端ユニットの回帰（走ゼロ・§10.3 `restore_field_0906` の拡張）

**目的**: 定数極・殻極・角検出項を既存 npz の再集計だけで割る。

**集団**（`mob` から $\hat p$ を復元、$k_{\rm on}=32\hat p$）:
- **K1**: $k_{\rm on}=1$（`near_off`・上端がぶら下がる）
- **K31**: $k_{\rm on}=31$（下端がぶら下がる）
- **K2**: $k_{\rm on}=2$（任意・殻極はここを「力ゼロの棚」と予測する）
- **alive／dead 別**に出す。

**窓と条件**: 後半窓（§10.3 と同じ後半 3M）。初期降下（`posthoc_bshare_0903` の $t_{\rm sub}$ 中央値 34k–61k・△）は含めない。§10.3 と同じく条件は 2 タスク前（$t-2$）、変位は $\bar z(t+1)-\bar z(t)$（平均への回帰を除く）。境界は [[引用禁止]] C のマスク。

**回帰**:
- (a) K1: $\Delta\bar z$ を $z_{\max}(t-2)$ に回帰。傾き $\beta_1$・切片 $\beta_0$（seed ごと → 中央値・percentile bootstrap）。
- (b) **K31（主判定）**: $\Delta\bar z$ を $\lvert z_{\min}\rvert$ に回帰。$z_{\min}$ が npz に無ければ等大近似の代理 $\lvert2\bar z-z_{\max}\rvert$ を使う。傾き $\beta'_1$。
- (c) 各ユニットで $w=(z_{\max}-\bar z)/2.5$ を取り、$\mathbb E_{\rm support}[\phi(z_i)]=0$ の等大 2 項解 $z^\ast_{\rm pred}$（§1 の表）の腕中央値を、§10.3 の固定点 $z^\ast(a)$ と並べる（alive／dead 別）。
- (d) $a$ 掃引 10 腕で (a) の $\beta_1(a)$ を $c(1-a)^2$・$c(1-a)$・$c(1-a)/a$ で別々にフィットし、残差を比べる。
- (f) K2 の $\Delta\bar z$ の中央値が K1 より 0 に近いか。
- 率で出す（総和でなく境界あたり・教訓⑰）。K1 滞在の打ち切りを記録。

**判定ラベル（案。閾値の数値は Issa が凍結前に決めてよい——Kubo 側に根拠は無い）**:

| 検定        | ラベル                                                          | 条件（案）                                                         |
| --------- | ------------------------------------------------------------ | ------------------------------------------------------------- |
| (b)       | `MIRROR_UP`                                                  | $\beta'_1>0$・95% CI が 0 を含まない・`R_1216` と `LR_1216` の両方        |
| (b)       | `MIRROR_NULL` / `MIRROR_DOWN`                                | CI が 0 を含む／$\beta'_1<0$                                       |
| (a) alive | `EDGE_LINEAR_DOWN`                                           | $\beta_1<0$・CI 除 0                                            |

| (d)       | `A_SHAPE_SHELL` / `A_SHAPE_RATCHET` / `A_SHAPE_INCONCLUSIVE` | 残差比 2 倍以上／逆／それ以外                                              |
| (c)       | `WELL_ZERO_MATCH` / `MISMATCH`                               | 10 水準中 8 以上で $\lvert z^\ast_{\rm pred}-z^\ast\rvert<0.3$／それ以外 |

**帰結**: `MIRROR_UP` かつ `DEAD_PUSH_PRESENT` → 殻極が主。`MIRROR_NULL` かつ `DEAD_PUSH_ABSENT` かつ `A_SHAPE_RATCHET` → 角検出項（Issa のラチェット）が主。`MIRROR_DOWN` → 定数極が K31 でも勝ち、殻極は劣位。(c) は独立で、`MATCH` なら §10.3 の復元場＝定数極。

**S 検査**: S1 $32\hat p$ が整数（$<10^{-6}$）／S2 境界イベント 499／seed（教訓⑭）／S3 線形腕（$a=1$）で (a)(b) の傾きが 0（3 者とも力ゼロ）／S4 条件を $t$ に置いた版との差（REPORT）／S5 K1・K31 の個体数と滞在長。
