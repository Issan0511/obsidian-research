## 1. 問いと答え

**問い（Issa）**: 自己項がここまで優勢なら、なぜ訓練は自己項に長期間逆らう配置（留め置き）を作れないのか。非増加の保存量のような概念は無いか。

**答え**: 保存量ではなく、入力側の占有が unit の位置に従うこと（鏡像の注釈で、押しの向きの条件ではない。追記 4）と、幾何で尺度の決まった相関の幅。負の位置の unit の余白の和が正の位置の unit の超過を上回り（負の偏り。全 unit で m_k < 0 はその特別な場合で、相 2 の余白は unit の 5〜9 割分、a0.5 で 3〜4 割分。追記 3）、全入力の明るさが正（K_n ≥ 1、ゆえに cot θ_n > 0）なので、位置の沈降はどの入力の占有の期待も 1/2 の下に押さえ、残る占有は平均入力から離れた入力（cot θ 小）に集まる。留め置きの材料は候補の模様どうしの正の相関だが、その幅の尺度はデータの実効次元が決め（等方の帰無 0.170、実測 leaky 0.148〜0.159・ELU 0.182）、訓練はその 1 割前後しか動かさない。橋の数は「標的の配置と各 unit の位置・幅を実測から与え、候補の向きだけを等方に引き直す」模型のモンテカルロが leaky で 1.5 倍以内に近似し（帯の基準では棄却）、ELU は訓練が作る 1 本の共通の模様を実測から足して同じ精度になる。模型の同時刻平均と n_β を状態ごとに Cantelli に入れた留め置きの割合の期待値の上界は 0.002〜0.016 で、実測の橋の数を使わない。模型の前提（模様の向きの等方性）は訓練後の重みそのものでは破れており（等方性の指標 0.38 対 初期 0.97）、誘導された模様の統計の近似としてだけ使える（追記 6 で仮定から外した: 文は恒等式と測った統計量の帯で述べ、等方・独立は初期化が与える参照）。

模型の流れ（Φ の降下）には非増加の量 Φ があるが、留め置きはその停留点なので単調性は何も禁じない（P155・P157）。実訓練で留め置きを壊すのは Φ 降下でない部分（課題ごとのラベル依存の当てはめ）で、そこに単調な量は無い。この部分は本ノートの外（[[瞬間の逆向き状態は長続きしない_H4の厳密化_1007]] §1-6）。

## 追記 1014: 「橋の材料はデータが用意する」の格の割り方

§0 の答えの「幅の尺度はデータの実効次元が決め、訓練はその 1 割前後しか動かさない」は、格の違う 2 文に割れる。

- **幅の既定値がデータの定数であること [恒等式＋模型 M′・主要項]。** 模様は u⊥_kn = x̃^⊥_n · w_k なので、入力の上で測った 2 unit の模様の相関は、正規化した向き ĝ_k・ĝ_l を Σ⊥ で挟んだ値で、データは Σ⊥ だけを介して入る [恒等式]。向きが Σ⊥ の固有基底に対して等方なら E ρ² = tr(Σ⊥²)/tr(Σ⊥)² = 1/PR [模型・主要項]（PR 31.1 で sd 0.179、29.9 で 0.183。合わせる定数なし）。初期化は座標が iid 零平均なので t = 0 では等方の仮定も要らない（分母のゆらぎ、相対 sd 0.25 の分だけ主要項。検証役の等方指標 0.97 と整合）。
- **訓練がその既定値の近くに留まること [実測]。** 訓練後の幅は leaky −7〜−13%・ELU +6%、相関の平均は訓練が作る（a0.1 0.01 → 0.08、ELU 0.15〜0.18）。データは幅を強制しない（向きを揃えれば 1、Σ⊥ で直交させれば 0 まで動かせる）。重み空間では訓練後の向きは等方でない（0.38）。模型 M′ に訓練の力学は入っておらず、「訓練でなく」の部分は実測だけ。ELU の共通成分も実測の ū⊥ を条件にしただけ。
- **導出にするなら示す文**: 更新 Δw_k ∝ Σ_n δ_kn x̃_n はデータの張る空間に居て δ はラベル乱数で駆動される、そこから向きの分布が Σ⊥ の固有基底で等方から 1 割以内に留まること [未導出]。cobirth_1013 の cos(v^c) × ω はこの相関の部分への最初の試みで、運び手としては落ちた。

言い方: 「材料の桁 0.17 はデータの定数（導出）、訓練がそれを保つこと（実測）」。「訓練でなくデータが用意する」とだけ書かない。

## 追記 1014（Issa「これ前から言われてたことじゃない？ 仮定に入れられてなかった？」）: 位置の沈降と分水嶺のうち既知だった部分

## 追記 3（1014 夜、Issa「m < 0 に等号が無いのは結構まずい」）: 命題 2 の全か無かの前提を符号つきの余白に替えた

旧命題 2 の前提「全 unit で m_k < 0」は、縁 m_k = 0 に余白の無い全か無かの文で、しかも「入力側のハブが消える時点」はその縁の上にある。実際、課題 2 末には 12 ファイル中 7 で m ≥ 0 の unit が 1〜5 個残り、a0.5 の相 2 では 90 状態中 24・26 で 1〜2 個いる。旧前提はそこで何も言わない。

直し方: λ_k = (−m_k/s⊥_k)√tr(Σ⊥)/|x̄| を符号つきに取ると、どの符号でも F(n) − 1/2 = mean_k [Φ̄(λ_k cot θ_n) − 1/2] = −(D₋(n) − D₊(n))/H。D₋ は負の位置の unit の余白の和、D₊ は正の位置の unit の超過の和（≤ H₊/2）、m_k = 0 は 0 を足す。F < 1/2 ⟺ D₋ > D₊ [厳密・模型、期待値]。D₋ は cot θ の増加関数なので最悪の入力は cot θ 最小の入力で、H_crit/H = 2 D₋(n_min)/H が「最悪の入力で F が 1/2 に届くまで許される常時点灯 unit の割合」。

数（12 ファイル、`analysis/xbar_arrangement_1014/fable_graded_prop2.py`）: 初期化 H_crit/H 0.13（m ≥ 0 の unit 46〜48、D₋ ≈ D₊、F の最大 0.48〜0.50。縁の上なので実現値の f ≥ 1/2 は 187・600 入力に散る）。課題 1 末 0.00〜0.04（m ≥ 0 の unit 41〜92、D₊ ≫ D₋。模型の F ≥ 1/2 は leaky で全 1,200 入力、実現値 643〜1,190）。課題 2 末 0.22〜0.36（m ≥ 0 の unit 0〜5 個でも D₊ ≤ 0.3 対 D₋ 11〜18。模型の F ≥ 1/2 は 0、実現値 0〜1）。相 2 0.52〜0.86、a0.5 は 0.28〜0.40（D₊ は余白の 1% 未満）。

注意 2 つ。(i) unit 側の変数は位置 m_k で、開いた割合 p_k ではない。位置のずれは K_n に比例するので m_k < 0 かつ p_k ≥ 1/2 の unit がある（課題 1 末 leaky 1〜3・ELU 8〜9、相 2 は a0.5 の 1・3 状態に 1 個）。段 2 の分水嶺 p = 1/2 と命題 2′ の m = 0 は unit ごとには別の線。(ii) 模型の F は共通成分を含まないので、相 2 の実現値の f ≥ 1/2（a0.5 35・6 状態、ELU s1 1 状態）は命題 2′ でも説明されず、§4 の共通成分による。

主張は変わらない。前提が「全か無か」から「余白の差」に弱まり、縁の上の時点でも文が出るようになった。V12 v5.9.4 に反映。

## 追記 4（1014 夜 2、Issa「開いた側に偏っていても自己項に従って閉じる側に行くでしょう普通に考えて」）: 位置の条件は模型の残りの限界で、押しの向きの条件ではない

## 追記 5（1014 夜 2、Issa「開くと閉じるという概念が納得いかない」）: 「開く」の約束

ELU の「開く」は z > 0 と置いた約束で、φ′ = e^z は連続なので 2 値のゲートではない。ELU の占有・橋の数・共通成分の数はこの約束の上の値（leaky・ReLU では φ′ ∈ {a, 1}・{0, 1} なので約束ではない）。 2 値を使う文（k・p・f_n・橋・1/2・段 2 の折れ目）は leaky・ReLU の特殊化で、使わない文（自己形 Σ K φ′φ の符号、位置と模様の分解と cot θ、留め置きの定義 A ≤ 0 < 自己項）は活性化に依らない。V12 の (l6) の ELU の数もこの約束の上にあり、未注記。
