## 1. 何を置き換えたか

H4-S と P161 の「n* 本が同時にある確率 ≈ λ^{n*}/n*!」は新生の独立（Poisson）を仮定していた。長期の形に要るのは ρ_R < 14〜32% だけなので、独立なしの片側 Chebyshev（Cantelli）P(N_i ≥ n*) ≤ σ²/(σ² + (n* − μ)²) [厳密] で足りる。縛るべきは 2 次モーメント σ²。

## 2. 導出で立ったもの [厳密／厳密・模型]

1. 状態を固定し新ラベルで 1 歩動かすと、2 つの unit j・k の前活性の変化のラベルの分の共分散は Cov = (η²/(N²K)) ⟨v_j^c, v_k^c⟩ Σ_m Θ_nm Θ_n′m d_jm d_km [厳密・全データ GD 1 歩]。同じ入力での相関は cos(v_j^c, v_k^c) × ω、ω ∈ (0, 1]（Cauchy–Schwarz、等号は同じゲート模様）[厳密]。異なる unit は同じラベル雑音を別の読み出しの向きに射影する。
2. 希な閾値越えは相関を増幅する: 2 変量正規で Cov(1[X>a],1[Y>b]) ≤ ρ/(2π√(1−ρ²))·exp(−(a²+b²)/(2(1+ρ)))（Plackett）、独立に対する相対超過は p = 0.003 で ρ 0.05・0.15・0.3 に対し 0.7・3.9・17 [厳密]。
3. 模型 G（課題を通した雑音を 1 の形の正規とし係数を頭で凍結）で F_i ≤ 1 + μ_i · mean R(ρ_jk)、Cantelli で ρ_R [厳密・模型 G]。
検証役が別 3 状態・autograd のモンテカルロで比 0.94〜0.98、Plackett は 1e−7 で確認。cos × ω の因数分解と Plackett → Fano → Cantelli の鎖は vault・BRIDGE_CONDITION・H4 報告に無く新規。

## 3. 反証で分かったこと [実測]

- **模型 G は共誕の記述として a0.1・a0.3 で破れる。** 状態を固定しラベルを引き直す測度（bit 一致、R 300）で N_i の Fano は 1.30・1.53・1.13、模型 G を候補ごとの周辺で評価した上界 1.10・1.36・1.55 を 81%・75%・1% の標的が超える。
- 課題末の累積の unit 間相関は 1 歩の cos·ω の 1/4〜1/10、累積の分散はラベル項の独立和の 600 倍。不等式 |ρ| ≤ |cos| は保たれるが内容は空。**ラベル雑音の候補どうしの共動は共誕を運んでいない。**
- この箱では ω は a² の床と幅で 93〜99% 決まり、開いた集合の重なりは入らない（寄与 ≤ 1.5%）。|cos|・|ρ| は共在・共誕の超過を並べず（Spearman ≈ 0）、|cos| > 0.5 の組は共在に濃縮されない（13.4% 対 基準 13.3%）。
- **共誕の出どころは標的の閾値のプール C_i**（標的の閾値 3 入力の 2 つ以上で開いている unit の数、N_i ≤ C_i）。C_i を与えると残りの Fano は 0.85〜1.02（引き直し）・0.64〜0.94（時系列）。過分散は候補どうしの相関でなく、標的の実現した閾値の入力が混んでいるかという共通原因を通る。C_i 自身の Fano は 1.5〜1.9（帰無 1.0）。
- 時系列の Fano（90 課題）は 1.39・1.64・1.33（最大 3.4・6.3・2.3）。候補ごとの系列を独立にずらす帰無は 0.93〜1.01、幅で層別した帰無は 1.10〜1.28。標的間の μ_i の不均一は Fano 単位 0.02〜0.04 → H4_stoch §(5)「過分散は標的ごとの λ_i の不均一」は否定。
- 占有は暗い入力（K_n 小）に偏り、入力の幾何のハブはこの箱に無い。N ≥ 10 の 4 件は 1 つの閾値の入力で開いた広い unit の集まりで、その入力を抜くと 0〜2 本。持ち上げ役は標的より広い（99.7〜100%）。

## 4. 着地点

- 独立なしの Cantelli に実測の μ_i・F_i・n_β を入れると **全標的で ρ_R ≤ 1.5%**（最大 0.0145・0.0048・0.0089）、閾値 14〜32% を超える標的 0/100。引き直しの測度でも経験の裾が Cantelli を超える標的 0。ただし独立（F = 1）の Cantelli との差は ×1.5〜3.6 で、小ささは (n* − μ)² ≫ μF による。独立を外した対価は Poisson の裾 → Cantelli の 3〜12 桁。
- H4 に置ける文（[[瞬間の逆向き状態は長続きしない_H4の厳密化_1007]] §1-4・§5-5、総まとめ G7b、cumulative_push §3 の「新生の独立」に替えて）: **(B′)** N_i の Fano 因子は F̄ を超えない [仮定つき・実測 F̄: 引き直し最大 3.0、時系列最大 6.3] ＋ **(N*′)** n*_i − μ_i ≥ 3.5 [実測] → ρ_R ≤ 2.8%（F̄ = 3）・5.8%（F̄ = 6.4）、閾値 14% の内側。これは結論の変数の 2 次モーメントについての仮定で、素な量（cos・ω・幅）の仮定には書けない。
- 撤回: 「独立の仮定を cos × ω に置き換えた」「新生はラベルの分が運ぶ」「縛りが消えるのは複製だけ」「材料は状態から計算できる」。「緩い署名で数えた N は保守的」は「署名が持ち上げの必要条件」（H4 L1′、未導出）の下だけ。
