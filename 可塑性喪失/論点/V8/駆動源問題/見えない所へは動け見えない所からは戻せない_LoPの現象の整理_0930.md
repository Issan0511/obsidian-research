**言葉。**
- **見える／見えない**: 見える = 損失の勾配が、その方向・その入力に応える。見えない = 応えない（勾配が 0 か、無視できる）。「無視できる」は Adam の箱では次の 2 段に分けて使う（理由は §1.2）。
  - **座標の段**: ある重みの座標全体の勾配が、厳密に 0・Adam の ε の下・数値の床のどれかにある。Adam でも動かない。
  - **入力の段**: 1 つの重みの勾配は、多くの入力の寄与の和。その中で、ある入力の寄与が他の入力の寄与に埋もれている。Adam は座標の歩の大きさを変えるだけで、この割合は変えない。
- **値に見えない／門が閉じている**（facts §9 の分け方）: 値に見えない = 損失の値そのものが、その量に依らない（補空間・softmax のゲージ）。門が閉じている = 損失の値は依るが、勾配の感度 φ′ がほぼ 0（閉じた入力・裾の外・数値の床・ε の下）。
- **切替** = 課題（乱数ラベル）の入れ替え。**押し** = 切替直後の m の変位（窓は 200 更新。再生の集計は 450 更新）。**戻り** = その後、課題末までの m の変位。
- **m** = unit の前活性の入力平均。**s** = 前活性の入力についての標準偏差（幅）。**上端** = unit の前活性の最大値。**相対位置** = m/s（幅を目盛りにした位置）。
- **開いた入力** = z > 0 の入力。**k** = unit の開いた入力の数。**p⁺** = k/N。**全閉** = k = 0（上端 ≤ 0）。
- **μ₊** = 開いた入力を持つ unit が、次の課題末に全閉になる率。**μ₋** = 全閉の unit が、次の課題末に開く率。
- **被覆** = その入力を開いている unit の数。**被覆 0** = どの unit にも開かれていない入力。
- **a・w⊥・v_top**: μ̂ = 入力平均の向き。a = w·μ̂（平均方向の成分）。w⊥ = w − aμ̂（直交成分）。上端の入力 x_top について px = μ̂·x_top、v_top = w⊥·x_top。c⊥ = v_top/‖w⊥‖。
- **可動度** = unit の |φ′(z)| の入力についての平均。facts の値は z ~ N(m, s²) の正規近似 [近似]。
- **裾** = φ′ と φ が 0 でない深さの範囲。SiLU は |z|e^z、GELU は e^{−z²/2} で消える。
- **要求と変位**: 要求 = 勾配の符号が指す向き（その入力の z をどちらへ動かしたいか）。変位 = 実際の動き。別の量として書く。
- **P・R・−R/P**: P = 押しの窓での Σm の変化（生の力の比では、バッチで当たった勾配の和）。R = 戻りの窓での同じ量。−R/P が比。
- **床**: 3 つの意味で出るので、毎回どれかを書く。傾きの床 = 負側の傾きの下限（leaky の a。ELU・GELU・SiLU・ReLU には無い）。数値の床 = float32 で微分が厳密に 0 になる深さ。出力の下限 = ELU の −1、ReLU の 0。正答率が偶然と同じことは「偶然の水準」と書く。
- **比**: 戻り ÷ |押し|。3 系統を区別する（§2.4 の表）。**登録の比** = 切替時に開いた unit の、中央値どうしの比（fork2）。**全 unit の比** = 全 unit の和どうしの比。**再生の比** = 保存状態から再生した Σm の比（生の力の比と変位の比がある）。
- **v̂・ε 域**: v̂ = Adam が持つ、勾配の二乗の移動平均。一歩は m̂/(√v̂ + ε)。ε 域 = √v̂ ≪ ε の座標。そこでは Adam は歩幅 η/ε の SGD になる。
- **λ** = 入力の共分散の固有値（方向ごとの入力の分散）。方向の見えやすさの目盛りに使う。
- **online** = 課題の学習中の正答率の、課題の中での平均。課題末の正答率とは別の量。
- **fork2** = 登録走 sink_roots_0930 を回した別セッション。**本体** = すり合わせノートを書いたセッション。

## 0. 一枚で

**構造の一文（Issa・[候補]）。** 損失の勾配が応えない方向・入力（見えない所）へは、損失に咎められずに動ける。いったんそこへ入った量は、勾配では戻らない。

**この文の格は 2 つに割れる。**
- [厳密] 勾配が厳密に 0 の方向には、抵抗も復元力も無い。SGD ではその成分が保存される。
- [候補] 勾配が小さいだけの所でも戻らない。Adam の箱では、小さいが 0 でない勾配は等身大の歩に戻ることがある（負側の勾配を 10⁻²・10⁻⁴ 倍にしても p⁺ は戻る。§1.2）。「戻らない」が言えるかは、座標の段か入力の段かで変わる。

**厳密に見えない所に入った量は、喪失を作れない [厳密・丸めを除く]。** softmax のゲージと、入力が固定の箱の補空間では、入った量は関数にも学習の軌道にも効かない（§2.8）。積もるのは大きさ（‖W‖²・生の |v|）だけ。この構造が LoP に中身を持つのは、「いまの勾配にはほぼ見えないが、前向きの出力か後の課題の学習には効く」量に限られる。

**中身があるのは次の 3 点で、現象ごとに格が違う。**
1. 何がそこへ運ぶか（§3）。
2. 入った量が、前向きの出力か次の課題の学習にどう効くか。
3. なぜ一方向に積もるか（入る速さが戻る速さを上回るか）。1 次元（m）で戻りが片側に不足する理由は、構造の一文からは出ない（§3.4）。定常の沈降は「負の相対位置 × 幅の伸び」で書ける。W 増大から沈降を言うのに要る前提は、相対位置が保たれることの 1 つで、釣り合いの位置は活性化ごとに別の問いになる（ELU は開いた入力の数 k がなぜ約 19 か、leaky は相対位置がなぜ約 −2.0 か）。どちらも [未導出]（§3.5）。

### 1.2 Adam の箱では「見えない」が 2 段に分かれる

- **SGD**: 変位は勾配の大きさに比例する。見えにくい所へは入りにくく、そこからも戻りにくい。入る側にも戻る側にも同じ勾配の因子が掛かる（入る量と戻る量が等しい、という意味ではない）。
- **Adam の尺度不変は、座標ごとの性質 [厳密、[[ELUの生存と死の理論_1層Adamと2層_0929]] §2.4]。** ε が無視できる間、ある座標の勾配の履歴に共通の倍率を掛けても、一歩は変わらない。
- **座標の段。** 座標全体の勾配が小さい場合（全閉の unit の重みなど）。
  - 小さいが 0 でなく、v̂ の古い記憶が抜けていれば、Adam は等身大の歩に戻す。ここは「見えない」に入らない。
    - 箱 M1 の ELU で、課題 51 から負側の勾配を 10⁻²・10⁻⁴ 倍にすると、生きた割合はいったん 0.84・0.59 まで落ち、課題 151〜200 には 1.00・0.96 まで戻る。10⁻⁶ 倍では 200 課題でも戻る途中（0.31 → 0.53）。0 にしたときだけ全滅する [介入・2 seed、[[ELUの生存と死の理論_1層Adamと2層_0929]] §3.4・[[ELUが沈降しない事件_総まとめ_0929]] §2.4]。
    - −16.64 の床が無いエンジンでは、全閉の ELU unit は止まらずに下へ動き続ける。箱 M2 の層別キメラ（6,000 更新/課題・GPU の手書きの逆伝播）で、t50 の第 2 層の前活性の平均は −153、−0.90/課題でまだ動いている [事後・メモリの要約、[[層別キメラでELU崩壊の所在を決める_結果_0914]]]。これは「見えない」ではなく「見えていて下へ動く」。
  - Adam でも動かないのは 3 つ: 厳密な 0、ε の下（√v̂ ≪ ε）、数値の床。
- **入力の段。** 1 つの重みの勾配は、入力ごとの寄与の和（∂L/∂w_i = Σ_n (v_i·e_n) φ′(z_in) x_n）。Adam は座標の歩の大きさを変えるが、座標の中での入力ごとの寄与の割合は変えない [厳密・勾配の式]。開いた入力を持つ unit では、深く閉じた入力の寄与（ELU で e^z 倍）は、開いた入力の寄与に埋もれたまま残る。現象 3・4 の「見えない」はこの段。
- **「Adam は入る側も戻る側も速くする」は、座標の段の、小さいが 0 でない場合に限る [厳密: 尺度不変。戻ることは上の介入]。** 一方向に積もる場所は 3 つある。
  - (i) 座標の段の 3 つ（厳密な 0・ε の下・数値の床）。
  - (ii) 入力の段。
  - (iii) 新しい変位が前の変位を辿り直さない所。理由は [未導出]（§4）。
- 注意: 「閉じた unit は Adam で全速で戻る」とは書けない。v̂ に古い大きい勾配が残っている間、一歩は小さい（満額の約 1% 以下。[[ELUの生存と死の理論_1層Adamと2層_0929]] §3.4・§9）。

### 1.3 「見える集合が固定なら沈まない」側の文

**(a) 線形の固定特徴模型では、押しと戻りは相殺する [厳密・模型]。**

  - 記号: φᵢ は Φ の第 i 列。Θ = ΦΦᵀ + 11ᵀ（1 は全成分 1 のベクトル。出力 bias の分）。bᵢ の第 n 成分は (x_n·μ + 1)·φ′(z_in)。出典はこの (x_n·μ + 1) を K_n と書く。クラス数の K とは別の量。

### 1.4 機能が落ちているのに、なぜ戻れないか（Issa の問い・0930 午後。facts §9）

Issa の問い: 「見えないから戻れない」のは分かるが、機能の低下（誤差が大きい）が起きているのに、なぜなお戻れないのか。

- **「見えない」は損失の値ではなく、勾配について言う [厳密・勾配の式]。** 第 1 層の重みへの勾配は「誤差 × 感度」の和（∂L/∂w_i = Σ_n (v_i·e_n) φ′(z_in) x_n）。誤差 e_n が大きくても、感度 φ′(z_in) がほぼ 0 なら、その誤差は W を動かさない。
- **見えない所は 2 種類ある。**
  - 値に見えない: 損失の値そのものが依らない（補空間・softmax のゲージ）。機能は落ちない。積もるのは大きさだけで、学習の軌道にも効かない [厳密・丸めを除く、§2.8]。
  - 門が閉じている: 損失の値は依るが、感度が無い（閉じた入力・裾の外・数値の床・ε の下）。機能が落ちても力が出ない。Issa の問いはこちら。
- **被覆 0 の入力の誤差が届くのは、読み出しと出力 bias だけ**（∂out/∂v_i = φ ≈ −1）。これらの入力は隠れ層の出力がほぼ同じなので、読み出しは共通の予測しか変えられず、定数の予測に落ち着く（正答率 0.10、|h − 平均| の中央値 0.93 対 6.6）。誤差は大きいまま、勾配はほぼ 0 の停留点 [実測＋勾配の式]。
- **ただし、門の大きさだけでは分かれない [実測]。** 被覆 0 の入力のうち、いちばん浅い unit での z が −1〜0 のもの（その unit では φ′ = e^z ≥ 0.37）も、正答率は 0.10（課題 29）。門が残る入力には力が出ている。それでも当てはまらない。
  - 理由の候補: 乱数ラベルでは、入力ごとに力の向きが割れる [候補]。
  - k が 12〜20 で下げ止まるのを、切替の押し（全部同じ向き）と拾い直し（向きが割れる）の釣り合いと読む案も [候補]。釣り合いの位置は [未導出]。ELU では、入力の数 N を 300〜2,400 に変えても、この k は 18〜20.5 で保たれる（§3.5 の N の梯子。生きた unit・切替時の中央値）。なぜその数かは [未導出]。
- **機能が落ちても、戻す力は増えない [事後の読み]。** 力の上限は門の大きさで決まり、誤差の大きさでは決まらない。落ちると沈みは浅くなる（切替時に読み出しを ×0.5 にすると、沈みの深さは 0.76〜0.82 倍。fork2 F2 [登録]。深さは谷までの量で、200 更新の押しとは別）。戻らないが、悪化も止まる。課題 50 以降に LoP が進まないことと合う。止まるのは相対位置 m/s と正答率で、m の沈みそのものは幅の伸びの分だけ続く（ELU は課題 151〜200 でも −0.13〜−0.17/課題。§3.4）。
- **良い解は存在するが、勾配の下り坂の先に無い [登録・介入]。** 第 1 層の初期化で 0.97／0.95（R5・課題 50／200 から分岐）。行を縮めて 0.985〜0.987（G1(c)）。bias で中心化して 0.82／0.65（R5）。
- **効いた対処は、どれも勾配に頼らない操作 [自前の走]。** 重み減衰・初期値への L2（leaky の RL-MNIST で、W̃ だけの減衰が LoP の 98% を除く。l2split_rlmnist_0914、メモリの要約）、行ノルムの上限、縮小、初期化のやり直し、中間層の中心化（箱 C・raw の ReLU で 0.113 → 0.987。relu_doors_0919）。文献の shrink & perturb・CBP・L2 Init も同じ型、という並べ方は facts §9 のもので、文献との照合はしていない。

### 2.3 ELU の本体の沈み（G3）

**何が起きるか。** 箱 M1・ELU・3 seed・全 unit の平均・1 課題あたり [恒等式＋実測・事後、すり合わせノート §1.3]。
- 恒等式: 上端の入力で z_top = b + a·px + v_top。差を取ると Δ(m − b) = (‖μ‖/px)[Δ(上端 − b) − Δv_top − a·Δpx] [恒等式]。
- 課題 10〜30 で、Δ(上端 − b) +0.03〜+0.11、Δv_top +0.36〜+0.66、Δ(m − b) −0.42〜−0.77。上端はほぼ戻り、v_top が伸び、本体が沈む。

**この構造での読み [候補]。**
- 「上端を保ったまま a を下げ、v_top を上げる」動きは、上端の入力の z を変えない。動くのは、上端より下の入力だけ。
- ELU では、深く閉じた入力は出力 ≈ −1・φ′ ≈ e^z で、損失にほぼ見えない（入力の段）。だからこの動きに抵抗が無く、下がった分を戻す勾配も小さい。

- ただし、この読みが説明するのは沈みの速さまで。沈むこと自体は、閉じた入力が見える leaky でも起きる（§3.4）。leaky で測れている「抵抗」は、c⊥ が下がって v_top が伸びにくいことで、沈みが止まることではない。

- 比 < 1 は「課題の正味 < 0」の言い換え [恒等式] で、原因ではない。正味がなぜ負の側に決まるかは §3.4。
- 比が小さいことは、喪失が大きいことと同じではない [実測・事後、すり合わせノート §1.3b]。
  - 腕の間で比を動かすのは幅の伸びの速さで、正答率が追うのは相対位置 m/s。§3.4 の分け方（沈み = 相対位置 × 幅の伸び）と同じ向き。
  - β₂ 0.9 の腕は全 unit の比 0.55（基準 0.80）なのに、正答率は基準より高い（0.50 対 0.41）。
  - 課題 50 以降は全 unit の比 0.95 が残るのに、LoP は進まない。
- 登録の比・全 unit の比・再生の比は、母集団も窓も違う。値を直接並べない。

### 2.7 第 2 層の死と床

**何が起きるか。**
- 箱 M2（層別キメラ・3 seed・50 課題・GPU の手書きの逆伝播）: 後期の online は ELU→ELU 0.104、ELU→leaky 0.319、leaky→ELU 0.108、leaky→leaky 0.475。第 2 層に傾きの床が無い腕だけが、偶然の水準に落ちる [登録・メモリの要約、[[層別キメラでELU崩壊の所在を決める_結果_0914]]]。
- 箱 C・raw（層別キメラ・10 seed）: 窓の正答率は leaky→leaky 0.728、ELU→leaky 0.140、leaky→ELU 0.100、ELU→ELU 0.101。生存は両層に傾きの床がある腕だけ [登録・メモリの要約、[[層別キメラをRL-CIFARへ_S-A_結果_0922]]]。

**この構造での読み。**
- 入る側: 第 2 層の中心は m₂ = W₂μ₂ + b₂。上流の平均 μ₂ が伸びれば、W₂ が動かなくても沈む [恒等式]。箱 M2 で z̄₂ の沈みの 7 割以上は上流 [事後、[[第2層のµ₂壁_崩壊層の釘付けと切替衝撃_事後_0916]]]。箱 C の ELU/std の帳簿は、t1 → t50 で上流 −752・自己 −102・交差 −113 [事後・判定しない量、[[CIFAR層別成長制限_S5_結果_0920]]]。
- 戻せない側: 消去（古い書き込みを消す力）は Jacobian W₃ diag φ′(z₂) W₂ diag φ′(z₁) を通るので、各層の φ′ を因子に持つ [厳密・構造]。傾きの床が無いと、沈んだ層でこの因子が小さくなる。箱 C の std 9 腕で、消す割合は平均ゲートに追随する（順位相関 0.96）。leaky の傾き 0.3・0.1・0.01 で 0.185・0.113・0.016（検査役の照合では t41〜50 の seed 中央値）[事後・走ゼロ、[[先生の導出をELU_GELU_SiLUへ拡張_床が排水口を決める_走ゼロ_0924]]]。
- 「勾配が無いから戻れない」と書けるのは、微分が厳密に 0 になる深さまで沈んだ走だけ。
  - CPU の expm1 の自動微分の系統では、z < −16.64 で微分が厳密に 0 になり、凍結はそこで始まる [登録・メモリの要約、[[εの再判定_float32の床を入れて読み直す_結果_0917]]]。
  - 上の 2 つのキメラの走（箱 M2 の GPU・箱 C）には、−16.64 の床が無い（§1.1）。箱 M2 では、全閉の ELU unit は止まらずに下へ動き続ける（§1.2）。ここで沈んだ層が戻らない理由は、この構造の「勾配が無い」では書けない。
  - 箱 C の std で両層に傾きの床が無い腕は、第 2 層が全閉になった後、課題末の W₁ が bit 一致で止まる [事後・メモリの要約、[[先生の導出をELU_GELU_SiLUへ拡張_床が排水口を決める_走ゼロ_0924]]]。どの深さで微分が 0 になったかは、このノートでは確かめていない。

**対照。**
- leaky の第 2 層は、切替ごとの一時的な全閉から毎課題回復する。ELU は回復しきれず、課題 8〜12 から残る [事後・箱 M2]。
- 両層の上限（cap12）。片方の層だけでは足りない。

**言えないこと。**
- 箱 C の ELU/std で、当てはめた後の更新を止めても崩壊は 1〜2 課題遅れるだけ（R7。10/10 seed が偶然の水準）[登録]。「当てはめ後の Adam が見えない所へ運ぶ」だけでは、この崩壊は説明できない。

### 2.8 softmax のゲージ

**何が起きるか。**
- 交差エントロピーは、unit の読み出し v に全クラス共通の定数を足しても変わらない。勾配のクラス和は厳密に 0。SGD はこの向きに動かない。Adam は座標ごとの分母が違うので動く [厳密、[[ELUの生存と死の理論_1層Adamと2層_0929]] §2.2]。
- 箱 C・leaky/std: t50 で logit の共通のずれは Adam で |中央値| 159、‖W3‖² の 57%。全部 SGD は 0.2 で、初期値のまま厳密に保存 [恒等式＋事後・メモリの要約、[[RL-CIFAR第3層のlogitの変化_押しは関数では消える_事後_0923]]]。
- 箱 M1・ELU・seed 0: 課題 10・50・100・200 で、機能する |v^c| は 1.62・1.29・0.65・0.41、生の |v| は 1.6・1.3・0.8・2.0 [実測、[[ELUの生存と死の理論_1層Adamと2層_0929]] §2.2]。

**この構造での読み。** 入る側と戻せない側は、構造のいちばんきれいな例。入るのは Adam だけで、戻す勾配は厳密に無い。ただし入った量は何もしない（下）。

**ゲージは学習の軌道に効かない [厳密・丸めを除く]。**
- 読み出しに全クラス共通の g_i を足しても、隠れ層への逆伝播 Σ_c (p_c − y_c) v_ic は変わらない（g_i·Σ_c (p_c − y_c) = 0）。logit の共通のずれは softmax を変えない。だから全パラメータの勾配は、ゲージの値に依らない。
- Adam の一歩は、各座標の勾配の履歴だけで決まる。帰納的に、関数と学習の軌道はゲージの値に依らない。
- 補空間も同じ。入力 1,200 枚が固定の箱では、補空間の成分はどの入力の z も変えず、どの勾配もこの成分に依らない。入力が課題ごとに替わる箱（PM など）では、この議論は当てはまらない。
- 効くのは測り方だけ。‖W‖² と生の |v| は、この成分を含んで膨らむ。読み出しの大きさは、クラス平均を引いた v^c で読む。
- つまり、厳密に見えない所に入った量は喪失を作れない。「共通のずれを 0 に戻して次の課題の速さを比べる」介入は、回さなくても結果が出る（速さは変わらない）。

**対照。** SGD（厳密に保存）。

**言えないこと。**
- 上は実数の演算での話。float32 の丸めを通して大きなずれ（t50 で 159）が効くかは測っていない。
- ゲージ成分の符号（ELU は負、GELU は正）は [未導出]。

## 3. この構造だけでは足りないもの

### 3.1 動かす側が要る（切替の押し）

- **見えないだけでは動かない [介入]。** 同じラベルを 30 課題続けた腕（G2）では、行ノルムは伸びるのに本体は沈まない（Δ(m − b) −0.29/−0.05/0.00、基準 −17。箱 M1・ELU・課題 5→30）。
- **介入で言えるのは 2 つ [介入]。** 直交成分に上限を掛けると、本体は沈まない（課題 5〜30 の正答率 0.97〜0.98）。同じラベルでは、重みが伸びても沈まない。
  - 「沈みには成長と押しの両方が要る」は、この 2 つからの読み [事後]。上限は、伸び以外の経路（上端の高さなど）で効いている可能性が残る。
  - 平均方向だけの上限（par）でも、正答率は 0.91〜0.93 まで戻る。「成分別の上限で因果の向きが決まった」とは書けない（すり合わせノート §8）。
- **押しの向きは、この構造からは出ない。**
  - unit 自身の寄与を取り消す分（自己項。基準は出力の下限: ELU は −1、ReLU は 0）は、出力に下限のある単調な活性化で必ず下向き [厳密・自己項の補題、メモリの要約]。ただしこれは帳簿の分け方で、残りの分が鏡像に動きうる。「自己項が下向きだから押しは下向き」とは書けない。
  - 他の unit との兼ね合いで決まる分は、部分回帰係数の符号（Gram の逆行列の非対角）で決まり、[未導出]。
