## 0. 結論

- **証明つき**: 押しの恒等式（多クラス・両方の層・有限の強さ）。通り道 ② と多クラスはその中に入る。ゲートの分 = 自己項の形の分 MF − 並びの分 Fl。ρ > r^↑ なら、並びによらず A^g > 0。
- **条件つき**: MF > 0 は (A_c; θ)（unit の状態）と (W_T; θ)（残り）から。読み出しの分の符号は 1 出力で十分条件つき、多クラスは未導出。確率の文は弱い unit の極限だけ。
- **実測**: 実状態の生きた unit 282 個は、形 (β) で全部 ρ > 1、読み出しの分も全部正。作った反例 3 型は ρ > r^↑ を満たさない。
- **渡す量**: T̄_c − 1、並びの相関 r（または ϑ）、読み出しの側の ε_K・O^r_i・Λ^g_i（§9）。

## 1. 模型と記号

- 入力: x̃_n ∈ R^{P+1}（成分 ≥ 0、最後は定数 1）、n = 1..N。Θ := X̃X̃ᵀ。x̄ := 入力の平均。**明るさ** K_n := x̃_n·x̄ > 0。
- unit j: 前活性 z_nj := x̃_n·w_j。**ゲート** d_nj := a + (1 − a)σ(z_nj/τ_j) ∈ (a, 1)（0 < a < 1。硬いゲートは τ → 0）。活性 φ_nj（φ′ = d）。**開き具合** s_nj := (d_nj − a)/(1 − a)。**生きた unit** := z > 0 の入力が 1 個以上ある unit。
- unit i の量は添字 i を省く。**模様** := ベクトル (s_m)_m。**開いた割合** p := s の全入力平均。**平均ゲート** ḡ := a + (1 − a)p。D := diag(d)。
- 読み出し: v_j ∈ R^{K′}、γ_j := ‖v_j‖²、v̂_j := v_j/‖v_j‖。
- 核: 𝒦 := Σ_j (v_jv_jᵀ)⊗(D_jΘD_j) + I⊗(FFᵀ + 11ᵀ)。第 1 項が **ゲートの道**、FFᵀ が **読み出しの道**（F := (φ_nj)）、11ᵀ が出力の bias。
- 逆行列: E := (λ + 𝒦)⁻¹、Ē := Σ_c E_cc。行 r := (v̂_i, n)。
- **押し**: 二乗誤差・リッジ λ・（クラス, 入力）ごとに独立なガウスのラベル・当てはめが済む極限で、unit i の位置（w_i → w_i + t·x̄）への押しの期待は A_i := ∂Φ/∂t に比例する（Φ := ½ log det(λ + 𝒦) = 容量）。**A_i > 0 が沈める向き**、A_i < 0 が浮かせる向き。この比例は模型の前提で、ここでは証明しない。
- **自己項** := unit 単独の核 (v_iv_iᵀ)⊗(DΘD) + I⊗(φφᵀ + 11ᵀ) での押し。閉じた側の a 倍の分と自分の読み出しの道の分は自己項に入る。後者が浮かせる向きのとき **浮力** と呼ぶ。**残り** := 全体 − 単独。
- 残りの通り道: ① := ほかの unit のゲートの道。② := ほかの unit の読み出しの特徴 φ_jφ_jᵀ。
- e′_n := K_n·∂d_n/∂z > 0、u_n := K_n d_n > 0。**閾値の近くの入力** := e′_n の大きい入力（実測では、大きい順に e′ の合計の 90% を占める入力）。
- (A) := p < 1/2（半分より多く開いていない）。
- **弱い unit の極限**（このノートでの意味）:= 逆行列を P⁰_i（unit i の両方の道を除いた核）に置き換えた形。両方の層の核では γ → 0 の極限そのものではない（γ → 0 で残るのは P^B_i。§10.2 の 3）。**有限の強さ** := そうしない実際の場合。**遮り** := 有限の強さの値 ÷ 弱い unit の極限の値。
- **粗い仮定** := これまでの反例探しで置いた規制の組（§16.35〜§16.37）。作った反例 3 型（浅い 50 個・深い 15 個・多クラスの 3 個）は全部これを満たす。

## 2. 定理 1: 押しの恒等式（→ (U2) の通り道 ② と (U3)）

**定理 1** [厳密]【両方の層・多クラス・有限の強さ・滑らかなゲート。使うのは λ > 0 と γ > 0 だけ】

1. **和**: A_i = A^g + A^r。ゲートの分 A^g := γ·e′ᵀ(Θ∘P_i)d。読み出しの分 A^r := uᵀĒφ。
2. **放物線**: φ を固定して入力 n のゲートの値だけを g にすると 1/E_rr(g) = c_0 + γκ′_n(g − d̂_n)²（κ′_n > 0、c_0 ≥ λ）。よって **A^g = Σ_n c_n(d_n − d̂_n)、c_n := e′_n·γκ′_n·E_rr > 0**。
3. **ゲートの道を除いた核の重みで書く形（版 R）**: 𝒦 = B + G_i（G_i := unit i のゲートの道、B := それ以外の全部。unit i 自身の読み出しの特徴も B に入る）と割る。π^B_nm := −P^B_i[n,m]/P^B_i[n,n]（m ≠ n。π^B_nn := 0。B だけで行 r をほかの全部の行にリッジ回帰した重みの (v̂_i, m) 成分）。予測 x̂_n := Σ_m π^B_nm x̃_m、x̂^d_n := Σ_m π^B_nm d_m x̃_m、ζ_n := Σ_m π^B_nm (s_m − p) x̃_m。計量 Q_n := (I + γX̃ᵀD·P^{B∖}_i·DX̃)⁻¹（0 ≺ Q_n ⪯ I。P^{B∖}_i := P^B_i − P^B_i e_n e_nᵀ P^B_i/P^B_i[n,n]）、⟨x, y⟩_{Q_n} := xᵀQ_n y。このとき
   - 1/E_rr(g) = 1/P^B_i[n,n] + γ‖g·x̃_n − x̂^d_n‖²_{Q_n}。κ′_n = ‖x̃_n‖²_{Q_n}。d̂_n = ⟨x̃_n, x̂^d_n⟩_{Q_n}/κ′_n。
   - **d̂_n = T^B_n·ḡ + (1 − a)·C^B_n**。T^B_n := ⟨x̃_n, x̂_n⟩_{Q_n}/κ′_n。C^B_n := ⟨x̃_n, ζ_n⟩_{Q_n}/κ′_n。
   - **上界**: |C^B_n| ≤ ε_n := ‖ζ_n‖/√κ′_n。|1 − T^B_n| ≤ θ_n := ‖x̃_n − x̂_n‖/√κ′_n。よって d_n − d̂_n ≥ (1 − a)(s_n − p) − ḡθ_n − (1 − a)ε_n。
   - unit の水準: A^g = γ·e′ᵀ(Θ^Q∘P^B_i)d、Θ^Q := X̃QX̃ᵀ、Q := (I + γX̃ᵀDP^B_iDX̃)⁻¹。
4. **多クラス（系 M）**: クラスの基底の第 1 軸を v̂_i に取り、B を v̂_i のブロック「1」とそれ以外「⊥」に割る。B^eff_i := B_11 − B_1⊥(λ + B_⊥⊥)⁻¹B_⊥1 ⪰ 0 とすると P^B_i = (λ + B^eff_i)⁻¹、P_i = (λ + B^eff_i + γDΘD)⁻¹。ゲートの分の量（A^g・d̂_n・κ′_n・c_n・Q_n・π^B・T^B_n・C^B_n）は「1 出力・核 B^eff_i・強さ γ」の系の量に一致する。

証明の要点（全文は a1 §2〜§6）。
- 1: ∂Φ/∂t = ½ tr(E·∂𝒦/∂t)。t に依るのは unit i の 2 項だけ。∂D/∂t = diag(e′) と ∂φ/∂t = u を入れる。

## 3. 定理 2: ゲートの分 = 自己項の形の分 − 並びの分（→ (U4) の決定論の文）

定義（**行で正規化した形** := 正の係数 c_n と重みの行 ϖ_n（ϖ_nn = 0）の組で A^g = Σ_n c_n(d_n − Σ_m ϖ_nm d_m) となるもの。§2 の版はどれもこの形）。
- **重みの合計** T_n := Σ_m ϖ_nm。C_n := Σ_m ϖ_nm (s_m − p)。d̂_n = T_n ḡ + (1 − a)C_n。
- ω := Σ_n c_n ϖ_n（入力の上のベクトル）。ω^⊥ := ω − （ω の平均）。
- **自己項の形の分** MF := Σ_n c_n(d_n − T_n ḡ)（§16.38 の「平均ゲートの分」）。**並びの分** Fl := (1 − a)⟨ω, s − p⟩。
- **並び** := 模様の値の集合を保ったまま、どの入力にどの値が乗るか。
- **並びの相関** r := ⟨ω^⊥, s − p⟩/(‖ω^⊥‖‖s − p‖)。**必要な相関** ρ := MF/((1 − a)‖ω^⊥‖‖s − p‖)。
- **最悪の並びの相関** r^↑ := Σ_j ω^⊥_(j)(s − p)_(j)/(‖ω^⊥‖‖s − p‖)（ω^⊥ と s − p を、符号つきの値の小さい順にそれぞれ並べた組。絶対値の順ではない。並べ替え全部の中の r の最大）。
- **並びの割合** ϑ := Σ_n c_n C_n / Σ_n c_n(s_n − p)。
- **実測での和の範囲**: §8 の MF・Fl・ω・T̄_c・T_max・ρ・r・r^↑・ϑ は、n の和を J（e′ の 90% を占める入力）に限った値。「ρ > r」は A_J := Σ_{n∈J} c_n(d_n − d̂_n) > 0 と同じで、A^g > 0 とは別の文。実状態では J の外の分は A^g の 1%・4%・5%（中央値。最大 6%・7%・10%）で、全入力の A^g も生きた unit の全部で正 [実測 P147]。作った反例には A_J > 0 > A^g の例がある（§8.2）。J の取り方（90%）への依存は未測定。

**定理 2** [厳密]【どの核・どの強さ・どの版でも。ω^⊥ ≠ 0、s は定数でない】
- (2a) [恒等式] A^g = MF − Fl = MF·(1 − r/ρ)（MF ≠ 0）。
- (2b) r ≤ r^↑ ≤ 1。
- (2c) **ρ > r^↑ なら A^g > 0**。とくに ρ > 1 なら A^g > 0。
- (2d) [恒等式] A^g = ḡ·Σ_n c_n(1 − T_n) + (1 − a)(1 − ϑ)·Σ_n c_n(s_n − p)。

証明。(2a)(2d) は d̂_n = T_n ḡ + (1 − a)C_n の代入。(2b) は並べ替えの不等式とコーシー・シュワルツ。(2c) は A^g = (1 − a)‖ω^⊥‖‖s − p‖(ρ − r) と (2b)。∎（a3 §6.1）

注意。
- (2c) の「並びによらず」は、ω を実現値に固定した勘定。有限の強さでは、模様を並べ替えると ω・T・κ′・c も動く（§5）。文字どおりの意味になるのは弱い unit の極限。
- **版は先に固定する**。行で正規化した形には定数の行 ϖ_nm := d̂_n/Σ_{k≠n} d_k も入り、この版では「ρ > r^↑」が A^g > 0 の言い換えになる [数値: 監査の検算]。条件が検査 ① を通るのは、重みを d̂_n を使わずに決める版（(β)・(γ)・(δ)・(W)）に固定したときだけ。

## 5. 定理 4: 確率の文（→ (U4)）

前提。**並べ替える** := unit i の前活性の値 z_n の、入力への割り当てを替える。s・d・e′/K・φ は z の関数なので一緒に動く。残りと K_n は入力に付けたまま。
- 並べ替えた模様は、N > rank[X̃] では一般にどの重み w でも実現できない（実状態 a 0.3 は N = 1,200、rank[X̃] = 599）。以下の確率は模様の集合の上の基準の測度で、網の状態の分布ではない。
- 弱い unit の極限 (W): M^W := Θ∘P⁰_i、A^{g,W} := γ·e′ᵀM^W d。M^W は unit i に v̂_i を通してだけ依り、模様にはよらない。

**補題** [厳密]（a3 L1〜L5）ベクトル h の成分を一様に並べ替えた h_ψ と固定のベクトル f について E⟨f, h_ψ⟩ = N·f̄·h̄、Var⟨f, h_ψ⟩ = ‖f^⊥‖²‖h^⊥‖²/(N − 1)。相関 r(ψ) は平均 0・分散 1/(N − 1)・最大 r^↑。
- 裾: L := ⟨f^⊥, s_ψ⟩（s ∈ [0, 1]^N。平均 0、分散 𝔙）について Cantelli の P(L ≥ t) ≤ 𝔙/(𝔙 + t²)。Bernstein 型 P(L ≥ t) ≤ exp(−t²/(2(k*σ_f² + f_max·t/3)))（k* := ⌈Σ_m s_m⌉、σ_f² := ‖f^⊥‖²/N、f_max := max_m f^⊥_m）。
- 証明: 交換可能性から Cov(h_ψ) = (‖h^⊥‖²/(N − 1))(I − 11ᵀ/N)。裾は Hoeffding (1963) 定理 4（非復元抽出の和の凸関数の期待値 ≤ 復元抽出）と、開き具合が [0, 1] の値のときを硬いゲートに帰着する補題 L4。∎

**定理 4** [厳密]【弱い unit の極限。ゲートの道だけ／両方の層、1 出力／多クラスのどれでも】J := 閾値の近くの入力の集合（任意に固定）。J の外の入力の数 N_c ≥ 2。
- **(4a) 値の並べ替え**（a3 定理 4）: J の中の z を固定し、J の外で z の値を一様に並べ替える。A_J := Σ_{n∈J} c_n(d_n − d̂_n) は A_J(ψ) = MF^J − Fl^{JJ} − Fl^{Jc}(ψ)。
  - MF^J := Σ_{n∈J} c_n(d_n − T_n ḡ)。ω^J := Σ_{n∈J} c_n ϖ_n。ω̄_c・p_c := J の外での ω^J・s の平均。ω^{J⊥} := J の外で中心化した ω^J。
  - Fl^{JJ} := (1 − a)Σ_{m∈J}(ω^J_m − ω̄_c)(s_m − p)。閾値の近くの入力どうしの分で、並べ替えで動かない。
  - Fl^{Jc}(ψ) := (1 − a)Σ_{m∉J}(ω^J_m − ω̄_c)(s_ψ(m) − p_c)。**平均 0、分散 (σ^J)² := (1 − a)²‖ω^{J⊥}‖²·Σ_{m∉J}(s_m − p_c)²/(N_c − 1)**。

  - A^{g,W}(ψ) = A_J(ψ) + R_J(ψ)。R_J は J の外の入力の e′ の分。その上界は粗い [数値 a3 chk3: 実際の最大の約 50〜500 倍]。
- **(4b) 符号の並べ替え**（a3 定理 5。余りなし）: J の外で z の符号だけを並べ替える（|z_m| は入力に付けたまま）。e′ は全入力で不変。η := γM^W e′、h_m := η_m(1 − a)|s_m − ½|、k₊ := J の外で z > 0 の入力の数として A^{g,W}(ψ) = 𝔐 + 2Σ_{m∈O_ψ} h^⊥_m（O_ψ は J の外の一様な k₊ 元部分集合）。

## 6. 定理 5: 読み出しの分（→ (U2)）
