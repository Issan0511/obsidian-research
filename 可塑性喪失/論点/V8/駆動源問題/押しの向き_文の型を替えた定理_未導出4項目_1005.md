## 0. 結論

- **主の文（並びの期待値。§12）**: 残りがどんなものでも、unit の開いた模様の並びについての期待値では、ゲートの分は「閾値でのゲートと平均ゲートの共分散」の正の倍数 ＋ 0 以上の項 [厳密]。正になる条件は unit 自身の ⟨s⟩_{e′} > p だけ（硬いゲートで (A)）。残りへの仮定は要らない。実状態では期待値は全 unit で正で、実際の値は期待値の 0.2〜0.6 倍・同じ符号 [実測 P149]。個々の配置で覆る反例は、この文と両立する。
- **証明つき**: 押しの恒等式（多クラス・両方の層・有限の強さ）。通り道 ② と多クラスはその中に入る。ゲートの分 = 自己項の形の分 MF − 並びの分 Fl。ρ > r^↑ なら、並びによらず A^g > 0。
- **条件つき**: MF > 0 は (A_c; θ)（unit の状態）と (W_T; θ)（残り）から。読み出しの分の符号は 1 出力で十分条件つき、多クラスは未導出。確率の文は弱い unit の極限だけ。
- **実測**: 実状態の生きた unit 282 個は、全部 A^g > 0・A^r > 0、どの版でも T̄_c < T_max と ρ > r。**ρ > r^↑（並びによらない）は版に依る**: 形 (β) で 100%、頂点の版で 100%・99%・89%、実際の版 (δ) で 88%・98%・83%（§11）。作った反例 3 型は ρ > r^↑ を満たさない。
- **重みの条件（別チャット CF17 の結果。§11）**: T の側は素な条件「選択性の比較」まで。並びの側と読み出しの分の符号は、素な重みの条件では閉じなかった（規制の中の敵対例つき）。
- **渡す量**: T̄_c − 1、並びの相関 r（または ϑ）、読み出しの側の ε_K・O^r_i・Λ^g_i（§9）。

## 1. 模型と記号

- 入力: x̃_n ∈ R^{P+1}（成分 ≥ 0、最後は定数 1）、n = 1..N。Θ := X̃X̃ᵀ。x̄ := 入力の平均。**明るさ** K_n := x̃_n·x̄ > 0。
- unit j: 前活性 z_nj := x̃_n·w_j。**ゲート** d_nj := a + (1 − a)σ(z_nj/τ_j) ∈ (a, 1)（0 < a < 1。硬いゲートは τ → 0）。活性 φ_nj（φ′ = d）。**開き具合** s_nj := (d_nj − a)/(1 − a)。**生きた unit** := z > 0 の入力が 1 個以上ある unit。
- unit i の量は添字 i を省く。**模様** := ベクトル (s_m)_m。**開いた割合** p := s の全入力平均。**平均ゲート** ḡ := a + (1 − a)p。D := diag(d)。
- 読み出し: v_j ∈ R^{K′}、γ_j := ‖v_j‖²、v̂_j := v_j/‖v_j‖。
- 核: 𝒦 := Σ_j (v_jv_jᵀ)⊗(D_jΘD_j) + I⊗(FFᵀ + 11ᵀ)。第 1 項が **ゲートの道**、FFᵀ が **読み出しの道**（F := (φ_nj)）、11ᵀ が出力の bias。
- 逆行列: E := (λ + 𝒦)⁻¹、Ē := Σ_c E_cc。行 r := (v̂_i, n)。
- **押し**: 二乗誤差・リッジ λ・（クラス, 入力）ごとに独立なガウスのラベル・当てはめが済む極限で、unit i の位置（w_i → w_i + t·x̄）への押しの期待は A_i := ∂Φ/∂t に比例する（Φ := ½ log det(λ + 𝒦) = 容量）。**A_i > 0 が沈める向き**、A_i < 0 が浮かせる向き。この比例は模型の前提で、ここでは証明しない。
- **自己項** := unit 単独の核 (v_iv_iᵀ)⊗(DΘD) + I⊗(φφᵀ + 11ᵀ) での押し。閉じた側の a 倍の分と自分の読み出しの道の分は自己項に入る。後者が浮かせる向きのとき **浮力** と呼ぶ。**残り** := 全体 − 単独。
- 残りの通り道: ① := ほかの unit のゲートの道。② := ほかの unit の読み出しの特徴 φ_jφ_jᵀ。
- e′_n := K_n·∂d_n/∂z > 0、u_n := K_n d_n > 0。**閾値の近くの入力** := e′_n の大きい入力（実測では、大きい順に e′ の合計の 90% を占める入力）。
- (A) := p < 1/2（半分より多く開いていない）。
- **弱い unit の極限**（このノートでの意味）:= 逆行列を P⁰_i（unit i の両方の道を除いた核）に置き換えた形。両方の層の核では γ → 0 の極限そのものではない（γ → 0 で残るのは P^B_i。§10.2 の 3）。**有限の強さ** := そうしない実際の場合。**遮り** := 有限の強さの値 ÷ 弱い unit の極限の値。
- **粗い仮定** := これまでの反例探しで置いた規制の組（§16.35〜§16.37）。作った反例 3 型（浅い 50 個・深い 15 個・多クラスの 3 個）は全部これを満たす。

## 2. 定理 1: 押しの恒等式（→ (U2) の通り道 ② と (U3)）

**定理 1** [厳密]【両方の層・多クラス・有限の強さ・滑らかなゲート。使うのは λ > 0 と γ > 0 だけ】

1. **和**: A_i = A^g + A^r。ゲートの分 A^g := γ·e′ᵀ(Θ∘P_i)d。読み出しの分 A^r := uᵀĒφ。
2. **放物線**: φ を固定して入力 n のゲートの値だけを g にすると 1/E_rr(g) = c_0 + γκ′_n(g − d̂_n)²（κ′_n > 0、c_0 ≥ λ）。よって **A^g = Σ_n c_n(d_n − d̂_n)、c_n := e′_n·γκ′_n·E_rr > 0**。
3. **ゲートの道を除いた核の重みで書く形（版 R）**: 𝒦 = B + G_i（G_i := unit i のゲートの道、B := それ以外の全部。unit i 自身の読み出しの特徴も B に入る）と割る。π^B_nm := −P^B_i[n,m]/P^B_i[n,n]（m ≠ n。π^B_nn := 0。B だけで行 r をほかの全部の行にリッジ回帰した重みの (v̂_i, m) 成分）。予測 x̂_n := Σ_m π^B_nm x̃_m、x̂^d_n := Σ_m π^B_nm d_m x̃_m、ζ_n := Σ_m π^B_nm (s_m − p) x̃_m。計量 Q_n := (I + γX̃ᵀD·P^{B∖}_i·DX̃)⁻¹（0 ≺ Q_n ⪯ I。P^{B∖}_i := P^B_i − P^B_i e_n e_nᵀ P^B_i/P^B_i[n,n]）、⟨x, y⟩_{Q_n} := xᵀQ_n y。このとき
   - 1/E_rr(g) = 1/P^B_i[n,n] + γ‖g·x̃_n − x̂^d_n‖²_{Q_n}。κ′_n = ‖x̃_n‖²_{Q_n}。d̂_n = ⟨x̃_n, x̂^d_n⟩_{Q_n}/κ′_n。
   - **d̂_n = T^B_n·ḡ + (1 − a)·C^B_n**。T^B_n := ⟨x̃_n, x̂_n⟩_{Q_n}/κ′_n。C^B_n := ⟨x̃_n, ζ_n⟩_{Q_n}/κ′_n。
   - **上界**: |C^B_n| ≤ ε_n := ‖ζ_n‖/√κ′_n。|1 − T^B_n| ≤ θ_n := ‖x̃_n − x̂_n‖/√κ′_n。よって d_n − d̂_n ≥ (1 − a)(s_n − p) − ḡθ_n − (1 − a)ε_n。
   - unit の水準: A^g = γ·e′ᵀ(Θ^Q∘P^B_i)d、Θ^Q := X̃QX̃ᵀ、Q := (I + γX̃ᵀDP^B_iDX̃)⁻¹。

## 3. 定理 2: ゲートの分 = 自己項の形の分 − 並びの分（→ (U4) の決定論の文）

定義（**行で正規化した形** := 正の係数 c_n と重みの行 ϖ_n（ϖ_nn = 0）の組で A^g = Σ_n c_n(d_n − Σ_m ϖ_nm d_m) となるもの。§2 の版はどれもこの形）。
- **重みの合計** T_n := Σ_m ϖ_nm。C_n := Σ_m ϖ_nm (s_m − p)。d̂_n = T_n ḡ + (1 − a)C_n。
- ω := Σ_n c_n ϖ_n（入力の上のベクトル）。ω^⊥ := ω − （ω の平均）。
- **自己項の形の分** MF := Σ_n c_n(d_n − T_n ḡ)（§16.38 の「平均ゲートの分」）。**並びの分** Fl := (1 − a)⟨ω, s − p⟩。
- **並び** := 模様の値の集合を保ったまま、どの入力にどの値が乗るか。
- **並びの相関** r := ⟨ω^⊥, s − p⟩/(‖ω^⊥‖‖s − p‖)。**必要な相関** ρ := MF/((1 − a)‖ω^⊥‖‖s − p‖)。
- **最悪の並びの相関** r^↑ := Σ_j ω^⊥_(j)(s − p)_(j)/(‖ω^⊥‖‖s − p‖)（ω^⊥ と s − p を、符号つきの値の小さい順にそれぞれ並べた組。絶対値の順ではない。並べ替え全部の中の r の最大）。
- **並びの割合** ϑ := Σ_n c_n C_n / Σ_n c_n(s_n − p)。
- **実測での和の範囲**: §8 の MF・Fl・ω・T̄_c・T_max・ρ・r・r^↑・ϑ は、n の和を J（e′ の 90% を占める入力）に限った値。「ρ > r」は A_J := Σ_{n∈J} c_n(d_n − d̂_n) > 0 と同じで、A^g > 0 とは別の文。実状態では J の外の分は A^g の 1%・4%・5%（中央値。最大 6%・7%・10%）で、全入力の A^g も生きた unit の全部で正 [実測 P147]。作った反例には A_J > 0 > A^g の例がある（§8.2）。J の取り方（90%）への依存は未測定。

**定理 2** [厳密]【どの核・どの強さ・どの版でも。ω^⊥ ≠ 0、s は定数でない】

- (2b) r ≤ r^↑ ≤ 1。
- (2c) **ρ > r^↑ なら A^g > 0**。とくに ρ > 1 なら A^g > 0。

証明。(2a)(2d) は d̂_n = T_n ḡ + (1 − a)C_n の代入。(2b) は並べ替えの不等式とコーシー・シュワルツ。(2c) は A^g = (1 − a)‖ω^⊥‖‖s − p‖(ρ − r) と (2b)。∎（a3 §6.1）

## 5. 定理 4: 確率の文（→ (U4)）

前提。**並べ替える** := unit i の前活性の値 z_n の、入力への割り当てを替える。s・d・e′/K・φ は z の関数なので一緒に動く。残りと K_n は入力に付けたまま。
- 並べ替えた模様は、N > rank[X̃] では一般にどの重み w でも実現できない（実状態 a 0.3 は N = 1,200、rank[X̃] = 599）。以下の確率は模様の集合の上の基準の測度で、網の状態の分布ではない。
- 弱い unit の極限 (W): M^W := Θ∘P⁰_i、A^{g,W} := γ·e′ᵀM^W d。M^W は unit i に v̂_i を通してだけ依り、模様にはよらない。

**補題** [厳密]（a3 L1〜L5）ベクトル h の成分を一様に並べ替えた h_ψ と固定のベクトル f について E⟨f, h_ψ⟩ = N·f̄·h̄、Var⟨f, h_ψ⟩ = ‖f^⊥‖²‖h^⊥‖²/(N − 1)。相関 r(ψ) は平均 0・分散 1/(N − 1)・最大 r^↑。
- 裾: L := ⟨f^⊥, s_ψ⟩（s ∈ [0, 1]^N。平均 0、分散 𝔙）について Cantelli の P(L ≥ t) ≤ 𝔙/(𝔙 + t²)。Bernstein 型 P(L ≥ t) ≤ exp(−t²/(2(k*σ_f² + f_max·t/3)))（k* := ⌈Σ_m s_m⌉、σ_f² := ‖f^⊥‖²/N、f_max := max_m f^⊥_m）。
- 証明: 交換可能性から Cov(h_ψ) = (‖h^⊥‖²/(N − 1))(I − 11ᵀ/N)。裾は Hoeffding (1963) 定理 4（非復元抽出の和の凸関数の期待値 ≤ 復元抽出）と、開き具合が [0, 1] の値のときを硬いゲートに帰着する補題 L4。∎

**定理 4** [厳密]【弱い unit の極限。ゲートの道だけ／両方の層、1 出力／多クラスのどれでも】J := 閾値の近くの入力の集合（任意に固定）。J の外の入力の数 N_c ≥ 2。
- **(4a) 値の並べ替え**（a3 定理 4）: J の中の z を固定し、J の外で z の値を一様に並べ替える。A_J := Σ_{n∈J} c_n(d_n − d̂_n) は A_J(ψ) = MF^J − Fl^{JJ} − Fl^{Jc}(ψ)。
  - MF^J := Σ_{n∈J} c_n(d_n − T_n ḡ)。ω^J := Σ_{n∈J} c_n ϖ_n。ω̄_c・p_c := J の外での ω^J・s の平均。ω^{J⊥} := J の外で中心化した ω^J。
  - Fl^{JJ} := (1 − a)Σ_{m∈J}(ω^J_m − ω̄_c)(s_m − p)。閾値の近くの入力どうしの分で、並べ替えで動かない。
  - Fl^{Jc}(ψ) := (1 − a)Σ_{m∉J}(ω^J_m − ω̄_c)(s_ψ(m) − p_c)。**平均 0、分散 (σ^J)² := (1 − a)²‖ω^{J⊥}‖²·Σ_{m∉J}(s_m − p_c)²/(N_c − 1)**。
  - MF^J > Fl^{JJ} のとき **P(A_J(ψ) ≤ 0) ≤ 1/(1 + (m^J)²)**、m^J := (MF^J − Fl^{JJ})/σ^J。Bernstein 型も付く。
  - A^{g,W}(ψ) = A_J(ψ) + R_J(ψ)。R_J は J の外の入力の e′ の分。その上界は粗い [数値 a3 chk3: 実際の最大の約 50〜500 倍]。
- **(4b) 符号の並べ替え**（a3 定理 5。余りなし）: J の外で z の符号だけを並べ替える（|z_m| は入力に付けたまま）。e′ は全入力で不変。η := γM^W e′、h_m := η_m(1 − a)|s_m − ½|、k₊ := J の外で z > 0 の入力の数として A^{g,W}(ψ) = 𝔐 + 2Σ_{m∈O_ψ} h^⊥_m（O_ψ は J の外の一様な k₊ 元部分集合）。
  - 平均 𝔐 := Σ_{m∈J} η_m d_m + ((1 + a)/2)Σ_{m∉J} η_m + (2k₊ − N_c)h̄。分散 𝔙 := 4k₊(N_c − k₊)‖h^⊥‖²/(N_c(N_c − 1))。
  - 𝔐 > 0 のとき P(A^{g,W} ≤ 0) ≤ 𝔙/(𝔙 + 𝔐²)。
  - 最小値 𝔐 − 2·(−h^⊥ の上位 k₊ 個の和) が正なら、J の外の開閉をどう並べ替えても A^{g,W} > 0。
- **(4c) 対の水準**（a3 定理 1）: 入力 n を固定してほかの z を並べ替えると、C_n に当たる量は平均 0、分散 ‖ϖ_n^⊥‖²·Σ_{m≠n}(s_m − p′)²/(N − 2)（p′ := n 以外での s の平均）。

証明の要点。(W) では n ∈ J の c_n と ϖ_n が並びによらないので、並びの分が 1 次の統計量になる。そこに補題を当てる。(4b) は s ↦ 1 − s で e′ が変わらないことを使う。∎（a3 §5・§6.2）

**有限の強さでは、係数を固定した式は確率の文にならない（有限の強さの確率の文は未導出）** [反例・数値 a3 chk4]【ゲートの道だけ・1 出力・N = 40】

## 6. 定理 5: 読み出しの分（→ (U2)）

## 14. 悪い配置は自壊する: 無作為では確率が小さく、学習で持続するには釣り合いの微調整が要る（1006。Issa の案。P136・P137・P151・別チャット CF13）

- 「ピンポイント」は「押しの流れの吸引点ではない」の意味で、測度 0 の証明ではない。釣り合いの点は存在する（深い反例）。

### 15.1 対の水準の定理（検証役が直した形）

[厳密・ゲートの道だけ・1 出力・λ > 0・強さ任意]。unit j の入力 n での谷底を、ほかの unit の n でのゲートで書く（(D1)、unit ごとの primal の形）: d̂_jn = Σ_l w_l d_ln = T⁺(a + (1−a) f⁺) − T⁻(a + (1−a) f⁻)。T± = Σ w±（重みの正の部分と負の部分の合計）、f± = その重みのうち n で開いている unit に乗る割合。
- 開いている unit j（d_jn = 1）が n で**閉じる向きに押される十分条件は T + (1−a)T⁻ < 1**（w ≥ 0 なら T ≤ 1。等号は f = 1 かつ T = 1 だけ）。w ≥ 0 は落とせない（T ≤ 1 でも T⁺ > 1 なら覆り得る）。実状態の T⁻/Σ|w| は中央値 0.2〜1.1%・90% 点 3〜5% なので補正は ≤ 0.04。
- 硬いゲートは落とせる: f を重みつき平均の開き具合 s̄^w に替え、右辺を d_jn にする。
- 両方の層: 硬いゲート・1 出力なら同じ形（bias は「どこでも開いた unit」として T と f に入る。自分の読み出しは自己項の中）。滑らかなゲート・多クラスでは自分の読み出しの項と bias の項が符号なしで足され、条件は T + r + β ≤ 1 に替わる [仮定つき]。P151 の 100% はこの形の実測。
- **T は版で違う数** [blocker]。(D1) の primal T^{(j)}_n = Σ_l w_l（ほかの unit を n で全部開いたときの谷底）と、§3 の双対 T_n = Σ_m ϖ_nm（unit 自身の n 以外を全部開いたときの谷底）は別の数（小さい系で 1.313 対 1.023）。§14 の「T ≤ 1 が 85〜99%」は双対の数で、primal では Σw ≤ 1 が 90・65・60%（a 0.1・0.3・0.5）、f^w < f* は 100%（§16.24 (7)）。**P152a**: 双対 (δ) の重みは負の部分が正の 0.6〜0.7 倍あり、正の部分で作った必要条件は空虚（234/462・1,238/1,367 の対で満たされる）。縛りになるのは unit ごとの primal。
- 等号条件は正しい。S1 は φ を固定してゲートだけ動かす微分（A^g の対の項）の話。

### 15.2 母集団の恒等式（新・厳密）

[厳密・ゲートの道だけ・1 出力・λ > 0・強さ任意] 入力 n を固定して全 unit で足すと
- Σ_l γ_l κ′_l d_ln (d_ln − d̂_ln) = 1/E_nn − λ > 0
- Σ_l γ_l κ′_l (1 − T^{(l)}_n) = Var(S_n | y_∖n) > 0

帰結: (a) 入力 n で全 unit が開いていれば、必ず誰かは閉じる向き（純粋な共点灯は全員は持ち上がれない）。(b) n で開いた unit を全部持ち上げるには、n で閉じた unit が d̂ < a で払う必要がある。(c) T > 1 の unit は同じ入力の T < 1 の unit で相殺される。相互持ち上げ（n で開いた全 unit が d̂ > 1）は無作為 3,000 例で 0、不可能かは [未導出]。

### 15.3 §14 の誤り: 複製は持ち上げない。持ち上げは非対称

[厳密・同] 同じ模様の相手の重みは w = γ_j q/(Θ_nn − γ_i q) < 1、複製の組だけなら T < 1（§16.29 (4″)「ぴったりの複製は 2 個で 1 個として沈む」と整合）。**複製は持ち上げない。** 持ち上がる配置は非対称で、[厳密・相手 1 個・弱い極限・λ→0・ϖ⁰ ≥ 0] T^{(j)} = Σ_m ϖ⁰_nm d_jm/d_km ≤ R² max_m(d_jm/d_km): 相手 k は n で開き n の言い換えの入力では閉じ（狭い）、持ち上がる j は言い換えの入力でも開いている（広い）。検証役の数値: 広い j の d̂ ≥ 1 が 285/300、同じ系で狭い k の d̂ は 0.79（閉じる向き）。§14 の「孤立した共点灯・複製に近い組」は向きが逆だった（取り下げ）。

### 15.4 対から unit へは出ない（循環）

持ち上げ役 k は n の対では閉じる向きだが、持ち上がる j が開いている言い換えの入力 m では d̂_km > a で**開く向き**に引かれる（閉じている方が浮く。§16.29 (4″)）。A_k > 0（沈む）を置けば主定理と循環する。言えるのは [仮定つき]「持ち上げ役に n 以外の閾値近傍の入力が無く、読み出しの分が符号を変えないなら沈んで持ち上げは終わる」まで。「自壊の定理」は名乗れない。

### 15.5 位置の流れの終点: 持ち上げ役は沈むが、底で釘付けになって持ち上げは残る（P152c・d）

作った深い反例 15 本（1 出力・両方の層・N 60・H 25）を、全 unit が動く位置の流れに 20,000 歩乗せた（P137 と同じ・終点を保存）。
- 標的が上で止まった 11 本で、**始点の持ち上げ役 69 個のうち 56 個（81%）が 1 幅以上沈んだ**。作った配置そのものは自壊する。
- しかし標的は上に残る（+0.5〜+4 幅・自己項 +2〜+44 に対して全体 ≈ 0）。終点の持ち上げ役 50 個は、位置 −3〜−13 幅・開いた入力 2〜18%（多くは 2〜5%）の**ほぼ死んだ unit** で、標的の閾値の入力 n だけが開いたまま残っている。62%（31/50）は n で自分の谷底より上（閉じる向き）だが、|A_j| < 0.05|自己項| が 48/50 で動かない。
- 読み: 押しは遷移域のゲートだけが運ぶ。沈む unit は弱い入力から閉じ、いちばん強い入力を最後まで開いたまま、底の近くで押しが消えて止まる。標的の閾値の入力が持ち上げ役の最上位の入力なら（作った例では構成上そう）、持ち上げは微調整なしに自動で残る。**持続の条件は「d̂_jn ≥ 1（開く向きの押し）」でも「釣り合い」でもなく、「標的の閾値の入力 = 持ち上げ役の最上位の入力」という一致**。沈んだ 4 本では標的も持ち上げ役も底。

### 15.6 いま言えること

1. [厳密] 開いている持ち上げ役は、その入力で閉じる向きに押される（T + (1−a)T⁻ < 1 のとき。実状態は primal で Σw ≤ 1 が 60〜90%、f^w < f* が 100%、両方の層・多クラスで 100%）。
2. [厳密] 母集団の恒等式: 同じ入力で全員は持ち上がれない。複製は持ち上げない。持ち上げは狭い相手が広い unit に与える。
3. [実測・流れ] 作った悪い配置は自壊する（持ち上げ役の 81% が沈む）。
4. [実測・流れ] 持続には微調整は要らない: 底で釘付けになった持ち上げ役の最上位の入力が標的の閾値の入力なら残る（作った 15 本中 11 本）。実状態でこの一致がどれだけあるかは未測定。
5. [未導出] 対の押しから unit の沈み。相互持ち上げの不可能性。多 unit・有限の強さでの T > 1 の配置の必要条件。

**§14 の「持続には釣り合いの微調整が要る」は取り下げる。** 残るのは「作った配置は自壊する [実測] ＋ 持続は一致の有無で決まる [実測・模型]」。

### 15.8 訂正: 持ち上げを払うのは、沈んだ unit の閉じた側（1006 昼。P152c 追記 2）

§15.5・§15.7 で「代償は持ち上げ役の死（圧力が持ち上げ役に移る）」と書いたが、終点の帳簿で見ると正確ではない。入力 n でのゲートの勾配は全 unit で足すと Σ_l d_ln ∂Φ/∂d_ln = (E𝒦_gate)_nn（両方の層。1 出力・ゲートの道だけなら 1 − λE_nn）で、正の数に固定される。上で止まった 11 本の標的の最上位 e′ 入力では、標的の項が 8/11 で負（開く向き）、正の側は 24 個中 22 個の unit が担い、その大半は **n で閉じている底近くの unit**（開いた入力 0〜3 個、n はその unit の順位 30 位台）。n で開いている unit の分は正の和の 0〜0.37。つまり持ち上げを払っているのは、沈んだ元の持ち上げ役の**閉じた側（a 倍の線形の道）**で、飽和している（e′ ≈ 0）ので動かない。**持ち上げが続くのは、払い手が応答できないから。** 持ち上げの中身は「線形の道が n と標的のほかの開いた入力を結び付け、標的のゲートが n でもそろって開く向きが容量を下げる」こと（§16.23 (5) の線形の道と同じ型）。

## 16. 崩壊を理論的に言う: 留め置きは橋 unit だけが作り、訓練は橋を作らない（1006 午後。Issa「実状態で初期化作れないかな」「無理なら何が本質的にダメなのか調べて、それから崩壊を理論的に言ってください」。P154〜P156）

### 16.1 実状態で留め置き（新しい初期化）は作れるか

- **位置だけでは作れない** [P154]: 実状態（a0.1 課題 40・a0.3 課題 100、N 1,200、H 100）で、ほかの unit の位置を最急降下の向き（ヘッセ行列 ∂A_i/∂pos_j）に最大 8 幅動かしても、A_i は 0.80・0.92 倍にしか下がらない（0/82・0/100）。位置の移動は z を入力によらず一様にずらすので、死んだ unit の閉じた側の変化は定数で bias に吸われ、生きた unit は狭い（開いた入力 0.6〜5.6%）ので動かせるゲートが少ない。
- **既存 unit の強さの付け替えでも作れない** [P156]: 99 個全部の強さを 10 倍まで自由にしても 0/5・0/5。
- **模様を設計すれば作れる** [P155]: 補助 unit を足して重みを自由にすると、強さを実 unit の中央値以下に縛っても 10〜30 個で全標的が留め置きに届き（1 出力）、多クラスの核でも 10/14 が残る（外れも 99% は消えている）。強さ 10 倍なら 3 個で足りる（多クラスで 5/11）。
- **設計された unit の署名 = 橋**: 標的の閾値の入力（e′ の上位 3）で開き（被覆 0.5〜0.67）、**かつ標的の開いた入力でも開く**（被覆 0.50〜0.64）、n に似ていて標的が閉じている入力では閉じている。狭くても広くても同じ署名。これを**橋 unit**（標的の閾値の入力と開いた入力をまたいで開く unit = 開いた集合の部分的な写し）と呼ぶ。

### 16.2 何が本質的にダメか

実網に無いのは橋である。閾値の入力を共有する実 unit は、標的の開いた集合の被覆が 0.17〜0.18 しかない（橋には 0.5〜0.64）。1 標的の閾値の入力の 2 個以上で開く unit は中央値 0〜2 個。強さは一様（最大/中央値 1.6〜1.9）で、狭い unit も広い unit も同じ強さなので強さで補えない（P156 のとおり補っても届かない）。

橋が生じない理由:
- [厳密・位置の流れ] 位置の押しは z を一様にずらすだけで、unit の中の入力の順序を変えない。各 unit の開いた集合は自分の最上位の入力へ単調に縮む。橋は「標的の開いた入力と閾値の入力を含む」という他 unit との関係で決まるので、流れは橋を壊す（縮むと標的の開いた入力を失う）ことはあっても作らない。
- [実測] 模様が変わる実際の訓練でも、開いた集合が重なる組は無く（Jaccard 最大 0.34）、100 課題で増えない（§16.29 (4‴)）。写し（クローン化）への引力は模型にあるが、重みの傾きのずれで本物の極小点に止まる（[[クローン化_複製に重なる動きの観測まとめ_1004]]）。
- [実測] Adam の下で強さは一様（max/median < 2）なので、少数の強い橋も生じない。

つまり、問題の初めから置いていた仮定 (B)「複製が無い」が、研ぎ澄ました形で本体だった: **留め置きの唯一の経路は部分的な写し（橋）であり、訓練はそれを作らない。**

### 16.4 橋があれば LoP は解消するか（1006 午後。Issa の問い）

答え: **1 個の unit の沈下は止まるが、網の可塑性喪失は解消しない。** 理由は 3 つ。
1. [構成の数] 橋は 1 unit あたり 10〜30 個（自然な強さ）で、橋は標的の部分的な写しなので unit を消費する。全 unit を持つ橋は網の unit 数を超える。
2. [模型・実測 P152c] 橋も unit で自己項を持ち、自分の最上位の入力（標的の近傍）だけ残して沈む（始点の持ち上げ役の 81% が 1 幅以上沈む）。1 個を生かすために 10〜30 個を死なせる。
3. [模型 P153] 持たれた unit は、容量 Φ のその unit の座標での**極小**に止まっている（流れは容量の降下で、蹴ると戻る = 極小）。持たれるのは、橋が標的の特徴を写していて、その位置で標的が最も冗長だから。ゲートの勾配は生きているが、網の容量（この模型での可塑性）には寄与が小さい。

母集団の恒等式のとおり、各入力の沈める圧力の総量 (E𝒦_gate)_nn は配置では変わらない。橋は圧力を配り直すだけで、流れの向き（押し = −∇Φ）は変えない。LoP を変える介入は圧力の総量を変えるもの（正規化・活性化の形・中心化・W の上限など、これまでに効いたもの）で、配置ではない。
未検証: 設計した相互の橋（全員が全員の部分的な写し）で生きた unit の割合を保てるか。無作為な重なりでは期待値の定理により不可。

### 16.5 橋も沈むので、期待値の定理は再帰で言える（1006 午後。Issa「橋が沈むんだったら期待値で理論を言えるようになるんじゃないの？」「一回では無理でも沈んで行くんじゃないの？」。P157）

**実測（位置の流れ・実状態 + 設計した橋 10 個）**: 橋は 5,000 歩で 19 幅沈み、架けている入力の被覆は 0.60 → 0.43・0.54 → 0.25。標的の押しは ≤ 0 から正に戻り、軌道に沿って被覆の単調関数（相関 −0.99）。向きは Issa のとおり「沈んでいく」。ただし被覆の一部は残り（平均入力と直交に近い入力は位置の向きで動かない）、押しの 92〜95% は打ち消されたままで、沈み直しは自然の 1/20〜1/12 の速さ。

**再帰の定理（位置の流れ。格つき）**
1. [厳密・定理 6] どの unit も、並びの期待値では押しは自己項の形の正の倍数（沈める向き）。
2. [厳密・必要条件] 特定の並びで持たれる unit があるなら、持ち上げ役は橋（その unit の閾値の入力と開いた入力で開く unit）で、持ち上げは橋の「架けている入力の被覆」の単調関数（実測では相関 −0.99）。
3. [厳密・位置の流れ] 橋は unit なので 1 が適用され、期待値では沈む。沈むと開いた集合は単調に縮み（入力の順序は不変）、被覆は非増加。
4. [帰結・仮定つき] よって持ち上げは期待値では減り、標的は沈み直す。例外は被覆が守られる並び: (i) 架けている入力が橋の最上位（釘付け）、(ii) 平均入力と直交に近い入力（位置の向きに免疫）。どちらも並びの一致で、無作為な模様では確率が小さい [見積もり・未導出]。
5. [実測] 設計した橋でも (ii) の残りが 0.25〜0.43 あり、位置の流れでは沈み直しが遅い。(ii) は重みが全方向に動く実際の訓練では守られないはず [未検証]。(i) は実際の訓練でも残る。

定理として閉じるのに要るもの: 守られた被覆の残り（(i)(ii)）の確率を、模様の統計で縛ること。位置の流れでなく全方向の流れ（容量の降下は写しを引き寄せる側なので、別の問題が出る。[[クローン化_複製に重なる動きの観測まとめ_1004]]）での再検討。

### 16.6 守られた被覆の確率を縛る（1006 午後。Issa「縛りましょう！」。P158）

**例外 (ii)（平均入力と直交）は実状態に無い** [実測]。生きた unit の閾値の入力の K_n/K̄ は中央値 0.96・1.30、0.3 未満は 0%。P157 で残った被覆は直交でなく余裕の大きいゲート（z/τ 中央値 46・13 = 釘付けの型）。容量の全勾配 ∂Φ/∂w_j は x̄ 方向が支配的で、全方向の流れでの架けている入力の向きは位置の流れと同じ（閉じる割合が一致）。よって縛るべき例外は **(i) 釘付けの橋** だけ。

**例外 (i) の縛り（3 段）**。橋 = 標的 i の閾値の入力 T_i（上位 3）の 2 個以上と開いた入力 O_i の半分以上で開く unit。持つには設計した橋で ≥ 10 個（自然な強さ。自然な橋は設計より弱く、P156 で 5 個を 10× にしても持てない）。
1. [厳密・仮定: unit ごとの入力の順位が独立な一様置換] 対 (i, j) が橋である確率は、j の最上位 m_j 個が T_i ∪ O_i の 2 + ⌈|O_i|/2⌉ 個以上を覆う超幾何の裾。標的ごとの期待数 λ_i は最大 0.03（a0.1）・0.06（a0.3）、P(≥10) ≤ λ_i^10/10! ≤ 10^−22・10^−19。
2. [実測] 仮定は破れている: 実状態の橋の対の率は 4.2e−3・2.0e−3 で、一様の期待数の 110 倍・34 倍。相関の源は模様の写しではなく（Jaccard 0.03〜0.04）**幅**: 広い unit（開いた入力 48〜232）が狭い標的（2〜11）の入力を含む。実測の率を独立な対に入れた二項の縛りは P(≥10) ≤ 10^−10.6・10^−13.8。観測の倍率で λ_i を較正すると、最も狭い標的で 10^−1.6・10^−3.4（数 % 以下）。
3. [実測・仮定なし] 直接の数え上げ: 1 標的あたりの橋は最大 5、≥10 は 0/182、≥3 は 3/182。要る数の半分に届かない。

**時間の側**: 位置の流れは順序を変えず開いた集合を縮めるので橋を作らない [厳密]。実際の訓練でも 100 課題で重なりは増えない [実測]。

**縛りの文**: 実状態の模様の統計（幅の分布と対の率）の下で、どの生きた unit も留め置きに要る橋の半分以下しか持たず、要る数に届く確率は 10^−10 以下（独立な対）〜数 % 以下（最も狭い標的・較正つき）。よって再帰の定理（§16.5）の例外は実状態では起きず、**全ての生きた unit は期待値でも実際にも沈む**。残る未導出: 幅による相関を入れた厳密な確率（較正でなく導出）、実際の訓練で橋が生じないことの導出。
