## 1. 一言で

**ReLU（leaky の a = 0）の鎖**
- 押しは沈める側。格は段ごとに付く。
  - 相 1 は H1（勾配で育った読み出し・予測が当たっている）のもとで、生きた unit の全部で沈める側 [厳密な極限 ＋ H1 ＋ K > 0]。
  - 段 1 は重みつきで値まで出る: (1 − p_w)E_w[relu z] ≥ 0 [厳密・分布によらず]。実 K の段 1 は素な十分条件つき [厳密]。
  - 段 2 はガウスの母集団で p < 1/2 ⟺ 沈める側 [厳密（Codex の証明）]。任意の分布では必要十分条件 (1 − p)μ₊σ₋² > p|μ₋|σ₊² つき [恒等式]。
- 戻す項が無い。同定済みの 3 項（閉じた側の浮力・両方の層の容量の浮力・§16.17 の雑音の項）は ReLU で 0 か沈める側 [厳密・項ごと]。全ての項について無いことは [未導出]。
- 死んでいる間は勾配が厳密に 0 [厳密]（入力が固定の層）。
- 死ねば学べない。永久に死んだ unit は関数と全部の勾配から消え、全部死ねば出力は定数 [厳密・実網]。両方の層の容量の最小は全部死んだ状態 [厳密・模型]。
- 条件つきの 2 段。
  - 生きた unit が死に着くことは、(S1) 漂流が正でない を仮定した確率 1 の文 [確率・仮定つき]。(S1) は [未導出]。
  - 死が永久になるのは Adam の残りが開き直さないとき [厳密・条件つき]。開き直す実例がある（Codex C5）。開き直すかは状態ごとに判定する。残りは最後の更新の 9.05 倍（ε → 0・t₀ が大きいとき）。この判定は P172 の課題の中の死で 295/299 が実際と一致した [実測]。
- 照合（P172、1 層 RL-MNIST）。
  - 第 1 層は課題 15・15・13（Adam）、14・15（SGD）で全滅する [実測]。
  - 上端の余白の 1 課題の平均の変化は、開いた入力の数のどの区分でも負（Adam）[実測]。
  - 生き返りは 0 [実測]。
  - 3 層の第 2 層へ容量の定理を移植すると（P176）、R std（相 1 の t1〜t2 だけ判定できる）で条件 Cov(e′, d) > 0 の内側の覆しは 0/467 [実測]。

**くねくね（KKT1・KKA）・適応 Snake（SNA）**
- 向きは同じ。向きを選ぶのは偶の部分 sin²(αz)/α ≥ 0 [厳密: 鏡像 ＋ ガウス]。

### 2.2 段 0 と相 1

- **R1（段 0）[厳密]**: K_n ≥ 0 が全 n なら Σ_n K_n φ′(z_n)φ(z_n) = Σ_{n∈O} K_n z_n ≥ 0（φ′φ = φ）。等号は O の上で K_n = 0 のときだけ（死んだ unit を含む）。
- 段 0 の釣り合い r*₀ は無い。ガウス・K 一定で σ[ϕ(r) + rΦ(r)] > 0 が全 r（r < 0 はミルズの不等式から）[ガウス]。r = −12 でも 1.5e−34 > 0 [数値]。leaky の r*₀ は a → 0 で −∞ へ行く。
- **R1′（相 1 の切替の押し）[厳密な極限 ＋ H1 ＋ K > 0]**: E_y[S_i] = c·Σ_{n∈O_i} K_n z_in、**c = κ(1 − 1/K)**。
  - 原典の c = κ(1/K)(1 − 1/K) は類で平均した内積のときの値（検証役の訂正 5。定理ノート §16.8 (3)(a) から引き継いだ）。符号には影響しない。
  - 検証役のモンテカルロ（4 万ラベル）: K = 3 で 0.247 対 κ(1 − 1/K) = 0.247、K = 10 で 0.335 対 0.333。

### 2.10 LoP — 死の分は戻らず、狭さが階数の天井になる

- **R9 [厳密・実網]**: 永久に死んだ unit は網の関数からも全部の勾配からも消え、残りの学習は「生きた部分網 ＋ 出力 bias」の学習そのものになる。全部死ねば f ≡ b2 で、一様な乱数ラベルの正答率は argmax の類の割合（≈ 1/K）。
- **R10（核の単調性・容量の最小）[厳密・模型]**:
  - 𝒦 = Σ_{j∈A}𝒦_j + I_{K′}⊗11ᵀ（A = 生きた unit。死んだ unit の寄与は厳密に 0）。
  - 𝒦 ⪯ 𝒦′ なら Φ ≤ Φ′。リッジの当て残しと、線形化した勾配降下の T 歩の当て残しは 𝒦 の側が大きい（η ≤ 1/λ_max(𝒦′)）。Weyl の固有値の単調性だけで出る。
  - 両方の層の容量の最小は全部死んだ状態と一致する。どの配置でも 𝒦 ⪰ I⊗11ᵀ で、等号は全部死んだときだけ。両方の層・多クラス・どの λ でも成り立つ。
  - leaky では閉じた unit の浮力で、両方の層の最小は有限の深さ（ちょうど閉じた点）にあった。1002 §16.31 の「最小 = 全部閉じた状態」はゲートの道だけの容量に限られていた。
  - 乱数の ReLU 網 400 個で死んだ unit の寄与 0・単調性の破れ 0。核の式は自動微分の JJᵀ と 8.9e−16 で一致。検証役の 200 網でも破れ 0 [数値]。
- **R11（狭さと階数）[厳密・模型]**: rank 𝒦 ≤ Σ_{j∈A} min(k_j, rank X̃) + K′(|A| + 1)。
  - 当てはまらないラベルの向きは NK′ − rank 𝒦 以上（リッジ λ → 0 でも、線形化した勾配降下のどの T でも）。

  - leaky では全 unit で rank(D_jX̃) = rank X̃（ゲート ≥ a）なので、狭さは階数を減らさず固有値を a² 倍に縮めるだけ。ReLU では沈下（狭さ）そのものが階数の天井になる。
