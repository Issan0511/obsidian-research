## 1. 言いたい文と、いま言える形

**言いたい文（Issa）**: 瞬間だけを見たときに沈降と逆の動きをする状態は長続きしない。

**いま言える形**（4 段。(i)(ii) は厳密、(iii)(iv) は揺らぎの仮定つきの確率の文）:
1. **作られない [厳密・T ≤ 1・w ≥ 0]**: 多数決の入力が無い状態（M = ∅）では、位置の流れはどの入力でも閉じた側のゲートを開いた側へ渡さない。逆向き状態の必要条件（橋 = 標的の閾値の入力で開く unit）は、流れでは新しく満たされない。
2. **あっても減る [厳密・位置の流れ]**: 逆向き状態を作っている橋も unit なので、並びの期待値では沈み（定理 6、(A) のもと）、位置の流れは入力の順序を変えないので橋の開いた集合は単調に縮み、架けている入力の被覆は非増加。持ち上げは被覆の単調関数なので減る。
3. **残るのは釘付けだけで、釘付けは揺らぎで解ける [確率 1・揺らぎの仮定]**: 位置の流れだけでは、架けている入力が橋の最上位の入力である配置（釘付け）は被覆を保つ。ゲートの余裕 M_gap を越える揺らぎが積もれば解け、0 平均・分散 σ² の揺らぎのもとで越える時刻はほぼ確実に有限（期待 ≈ (M_gap/σ)² 課題）。
4. **再生には多数決の逆転が要る [大偏差・仮定つき]**: 解けた後に逆向き状態が再び立つには、どれかの入力で説明する重みの半分より多くが同時に開く必要があり、揺らぎが独立なら確率は指数的に小さい。実測では新生の橋の寿命は 1 課題（92〜94%）、同時に 10 個は 2e−12/課題/標的。

結論の格: **「長続きしない」は、位置の流れでは (i)(ii) の厳密な文、揺らぎを入れた過程では「寿命はほぼ確実に有限で、再生は指数的に稀」という確率の文。決定論の流れだけでは釘付けの逆向き状態が持続する（P157・P153）ので、確率の仮定なしには言えない。** これは中心主張の「期待値での必然」と同じ格。

## 3. 導出の案（入力の水準の不変性）

**命題 A（多数決の不在は流れで保たれる）** [厳密・T ≤ 1・w ≥ 0・谷底の重みを準静的に扱う]。
位置の流れのもとで、時刻 τ₀ に M(τ₀) = ∅（全入力で f_n < 1/2）なら、τ ≥ τ₀ でどの入力でも閉じた側のゲート（s < 1/2）は開いた側（s > 1/2）へ渡らない。
- 証明の筋: L2 の一般形で、入力 n のゲートは f_n < s なら閉じる側、f_n > s なら開く側に押されるが、開く側に押されたゲートは谷底 d̂_n ≤ T(a + (1−a) f_n) < (1+a)/2 で止まる（谷底は放物線の頂点 = 安定な釣り合い）。よって閾値 s = 1/2 を下から越えるゲートは無い。開いた側のゲート（s > 1/2 > f_n）は全部閉じる側に押される。したがって各入力で開いている unit の集合は非増加。
- 残る段: f_n の重み w（谷底の重み。H⁻¹ 計量で決まる）は配置とともに動く。開いている unit の集合が縮むだけなら f_n は非増加だが、重みの再配分で f_n が 1/2 を越える可能性を縛る必要がある。候補: (a) 重みを課題の中で凍結する準静的の仮定、(b) 重みの和 T ≤ 1 と各重みの上界から f_n の変化を縛る。[未導出]

**命題 B（unit の水準）** [厳密 ＋ 期待値]。
M = ∅ なら、どの unit も新しく橋になれない（L1 の必要条件が流れでは新しく満たされない: 命題 A ＋ L3）。既にある橋は L7 で被覆が非増加。よって留め置きの集合は位置の流れで非増加（新しく入らず、出るだけ）。
- 注意: unit の位置の押し A_i は全入力の和なので、閉じた側のゲートが谷底へ向かう分（開く側）が和の符号を変えることは命題 A では排除されない。unit の水準の符号は L5（並びの期待値）に委ねる。瞬間・unit ごとの符号を素な仮定から言うのは反例で閉じた道（総まとめ §6）。

**命題 C（釘付けの寿命）** [確率 1・仮定: 課題ごとの位置の揺らぎが 0 平均・分散 σ² > 0 で独立]。
釘付けの橋の被覆が保たれる条件は、架けている入力のゲートが開いたままであること。位置の揺らぎが余裕 M_gap（架けている入力の z をゲートの幅 τ で割った量）を下に越えれば被覆は減る。独立な揺らぎの和は任意の有界な帯をほぼ確実に有限時間で出るので、寿命は有限（期待 ≈ (M_gap/σ)² 課題）。解けた後は命題 A で再生されない（揺らぎによる再生は命題 D）。
- 実状態の釘付けの余裕は z/τ 中央値 46・13（P157）。揺らぎの σ は実測が要る（§5 の走 3）。P153 の数値（walk 0.01 で 11/11 持続、拡散が 3τ を越えてから落ちる）はこの命題の数値版。

**命題 D（再生の確率）** [大偏差・仮定つき]。
M = ∅ の状態から揺らぎで多数決の入力を作るには、入力 n を説明する重みの半分より多くの unit が同じ課題に n で開く必要がある。開く事象が unit ごとに独立で確率 q なら、重みの数 k の入力で多数が開く確率は exp(−k·D(1/2‖q)) の桁。実測の新生（0.2〜0.3 組/課題/標的）と寿命 1 課題から、同時に 10 個は 2e−12/課題/標的（P161）。

**文の形（案）**: 位置の流れ（期待の押し）は逆向き状態を作らず（命題 A）、ある逆向き状態の被覆を減らし（L7）、残る釘付けは揺らぎでほぼ確実に有限時間で解け（命題 C）、揺らぎによる再生は指数的に稀（命題 D）。よって逆向き状態の寿命はほぼ確実に有限で、長い時間の中で逆向きの状態にある割合は 0 へ向かう [厳密 ＋ 確率・仮定つき]。

## 4. 足りない段

1. 命題 A の重みの動き（谷底の重み w の再配分で f_n が 1/2 を越えないこと）。準静的の仮定を置くか、T ≤ 1 から縛る。
2. 命題 B で、unit の位置の符号は並びの期待値のまま。瞬間の符号は言わない（文の型どおり）。
3. 命題 C の揺らぎの模型（独立・0 平均・分散 σ²）と、実網の揺らぎの大きさの較正。
4. 命題 D の独立性（新生の独立）。実測では相関の源は幅（広い unit が狭い標的を含む）で、帰無の 6.4 倍（a0.1）。
5. T ≤ 1 の割合: 実状態の primal Σw ≤ 1 は 90・65・60%（a 0.1・0.3・0.5）。T > 1 の unit では命題 A の閾値が f_n < (1/T − a)/(1−a) に下がる（より厳しい条件）。
6. 相 1（課題 < 10）は M ≠ ∅（課題 2 で 69〜85% の入力が f_n ≥ 1/2）なので命題 A の外。相 1 は切替の押しが運ぶ（G8）。

## 5. 検証の走（既存の checkpoint・走ゼロ）

1. **逆向き状態の寿命**（P170 として登録）: 実際の訓練の checkpoint（a0.1 課題 2〜101、a0.3・a0.5 課題 2〜101）で、unit ごとに模型の押し A_i の符号を課題ごとに出し、A_i ≤ 0（自己項 > 0）の連続する課題数（寿命）の分布を数える。予測: 相 2 の留め置きの unit-task は 0〜数%、寿命は 1〜2 課題が 9 割以上、3 課題以上は無い。
2. **多数決の入力の時系列**: f_n ≥ 1/2 の入力の数を課題ごとに（相 1 で多く、相 2 で 0 のまま戻らない）。P161 の f_n の集計を全課題へ。
3. **揺らぎの較正**: 課題ごとの位置の変位 Δm_i の標準偏差を τ（ゲートの幅）で割り、釘付けの余裕 z/τ（46・13）と比べて命題 C の期待寿命を出す。
