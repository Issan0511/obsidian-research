## 1. 言いたい文と、いま言える形

**言いたい文（Issa）**: 瞬間だけを見たときに沈降と逆の動きをする状態は長続きしない。

**いま言える形（4 つ。格を分ける）**:
1. **瞬間の障壁 [厳密]**: 閾値にあるゲート (j, n) が M の外（谷底が閾値より下）なら、その項は unit j の位置の押しに閉じる側で入る（定理 A1）。両方の層の谷底には読み出し・bias の項 w_r が付き、十分条件は a·T + (1−a)·W^open + w_r < (1+a)/2（T = primal の重みの和、W^open = n で開いている unit に乗る重みの和）。
2. **硬いゲートの極限では閾値は上向きに跳べない障壁 [厳密・極限]**: ゲートの幅 τ → 0 で閾値の項が 1/τ で他を圧倒し、閉じたゲートが M の外で下から閾値に達すると unit は沈める側に押される（定理 A2。容量は開く所で ΔΦ > 0 ⟺ d̂ < (1+a)/2 だけ跳び、降下の流れは上へは跳べない）。重みを凍結すれば M の外は保たれ、閉じたゲートは開かない（定理 A3）。この極限 ＋ M の外では**ゲートの道を通る留め置きはどの瞬間にも無い**（閾値にゲートのある unit は A^g ≥ 0、無い unit は A^g = 0）。残るのは読み出しの分が負になる型（悪 4）と、なめらかなゲート・重みが動く流れ [未導出]。
3. **位置の流れでは逆向きの符号は続かない [厳密]、続きうるのは打ち消し [実測]**: 位置の流れは下に有界な Φ の勾配降下なので押しは 0 へ向かう。P157 の標的の押しは ≤ 0 から正に戻り（−0.002 → +0.105、−0.015 → +0.39）、P152c の終点は |A|/自己項 ≤ 0.04 で符号は正 8・負 7（雑音）。決定論の流れで持続するのは「押しの打ち消し（持ち上げられた位置に留まる）」= 留め置きの終点であり、逆向きの符号ではない。
4. **実際の訓練 [実測]**: 留め置きは相 1 の課題 2 にしか無く（41・42・45 個、全部 p > 1/2 の unit。橋型でも釘付け型でもない）、課題 3 で全部解け、相 2 の 276 checkpoint で 0/8,255・0/9,190・0/9,200。余裕 A/自己項の最小は 0.024〜0.15 で 0 へ向かわない。位置の揺らぎは 1 課題 4〜5 τ だが増分は反相関で 8〜9 τ で頭打ち（r が r* に留まる）、解けるのは模様の脱相関（最上位の入力が毎課題 57〜63% 入れ替わる）で、釘付けの対象そのものが実網に無い。橋は釘付けでも 1 課題で消える（94.8・91.9・87.3%）。

**結論の格**: 「長続きしない」は、(a) 符号の文としては位置の流れで [厳密]（押し → 0）、(b) 留め置き（打ち消し）としては決定論の流れでは持続しうる [実測 P152c]、(c) 硬いゲートの極限 ＋ M の外ではゲートの道の留め置きは無い [厳密・極限]、(d) 実際の訓練では相 1 の 1 課題だけで相 2 では生じない [実測]。揺らぎで解けることの一般の定理は、位置の拡散でなく模様の脱相関の模型が要り [未導出]。定理 6 の期待（並びの一様な並べ替え）と課題列の揺らぎは別の測度で、一方から他方は出ない。中心主張の「期待値での必然」と「同じ格」とは書かない。

## 3. 反例・限界（初版の命題 A〜D がどこで破れたか）

- (a) **ゲート 1 個の降下と位置の流れの混同**（初版 命題 A の筋）。「開く側に押されたゲートは谷底で止まる」はゲート 1 個・他を全部止めた場合だけ正しく（Φ(g) は d̂ で唯一の極小）、位置の流れでは unit の全ゲートが同じ Δt·K_n で動くのでゲートは個別に止まれない。谷底が動く流れ（補題 G の逆）では T → 1 で f < 1/2 のまま閉じた集団が揃って開く（合意の持ち上げ）。実状態でゲートの流れを解くと、閾値の近くの閉じた対のうち合意の定常値が閾値を越えるのは a0.1 で 0〜2/748、a0.3 で 7〜31/2,227、a0.5 で 266〜338/4,159、ρ(W_CC) は 0.65〜0.83 [実測]。
- (b) **測った f^γ_n < 1/2 は留め置きを排除しない。** P152c の留め置きの反例 15 本は始点・終点とも f^γ が全入力で < 1/2（最大 0.30〜0.47）のまま持たれている。補題の f_jn（primal）はそこで 0.00〜0.75、強さ重みの f^γ は 0.09〜0.28 [実測]。初版の「M = ∅ ⇒ 作られない」は結論（全 unit で A_j ≥ 0）を仮定した文だった。
- (c) **浮力の釘付け = 長続きする逆向き状態。** 硬い極限で閾値にゲートの無い unit は −A^r_j だけで動き、深い unit は両方の層の容量の底（§16.34）で A^r < 0 となって浮き、最初の閉じたゲートの閾値で障壁に当たって止まる（A2）。これは A < 0 の逆向き状態だが留め置き（自己項 > 0）ではなく、障壁で止まった安定な状態で長続きする [厳密・極限]。実状態では A^r ≤ 0 は a0.1 の生きた unit に 1〜4 個、A は全 unit で正 [実測]。初版の「逆向き状態 = A_i < 0」のままでは「長続きしない」は偽で、文は留め置きに限る。
- (d) **浮かせる側の項（なめらかな模型）。** 閉じた対のうち谷底の下（開く側）にある対は 32・46・65%、閾値の近くでは 1.7・6.6・16%、e′ の取り分は 9・19・27%。unit ごとの 負の項の和 ÷ 正の項の和 は中央値 0.008・0.04・0.11、最大 0.12・0.17・0.46。A^g ≤ 0 の unit は 0 だが実測で、素な仮定からは出ない [実測・未導出]。
- (e) **厳密な M は実状態で空ではない。** 閉じた対の M は a0.1 で 0〜4、a0.3 で 12〜40、a0.5 で 159〜208（56〜59 unit）。越えさせているのは開いた unit の多数（W^open 中央値 0.3）ではなく aT と w_r で、a0.3・a0.5 では w_r 無しには 1 対も越えない。これらは閾値から遠く（s 中央値 0.2〜0.3）、unit は全部沈める側 [実測]。w_r は閾値の 3.5・11・12%（中央値）、90% 点で 5・18・23%。
- (f) **実際の訓練では重みの方が動く。** 課題 t → t+1 の谷底の変化を「ゲートの分」と「重みの分」に分けると |重みの分| ÷ |ゲートの分| は中央値 1.9〜2.8。閾値の近くの閉じた対の 0〜6% が課題ごとに M に入るが、ほぼ全部（17/21、278/306、766/856）はそのゲート自身が揺らぎで同時に開いた対で、M にいることは次の課題で開く確率を上げない（M の外と同率）[実測]。準静的の仮定 (a) は量的に成り立たない。模型の一歩（全 unit を 0.5τ 沈める／−A_j で動かす）では M への流入は 3 状態とも 0 で、M は 12〜15% 縮む [実測]。
- (g) **揺らぎの模型。** 初版の「独立・0 平均の位置の拡散、期待 (M/σ)²」は数で破れる: 片側の越えの期待値は無限（中央値 2.2(M/σ)²）、実網の増分は lag-1 −0.2〜−0.25 で反相関、位置の h 課題変位は 8〜9 τ で頭打ち（a0.5 は 6 τ）。固定した入力の相対ゲート z_n − m は 1 課題 3.8〜4.2 τ、h^0.3 で伸び続け、模様の相関は 32 課題で 0.3〜0.6 に落ちる。実状態の生きた unit の最上位の入力の余裕は z/τ 中央値 14・21・29（初版の 46・13 は P157 で足した設計の橋の数）。初通過の直接測定: 余裕 20〜40 τ で閉じるまで中央 3・7・12 課題、≥ 40 τ で 8・9・14 課題 [実測]。
- (h) **再生に多数決は要らない。** 留め置きに要るのは橋（構成では ≥ 10）で多数決の入力ではない（P161: f^γ ≥ 1/2 が 0% のまま橋は毎課題 17・34 組）。縛りは P161 の Poisson（新生の独立を仮定）2e−12 のまま。緩い基準の橋 ≥ 10 は相 2 の 276 checkpoint で 4 標的-課題（a0.3 で 14・11・10 本、a0.5 で 10 本）にあるが A/自己項 ≥ +0.24 で、緩い基準の数は P155 の設計した橋の「10 本で持たれる」には移らない。P159 の「1 標的あたり ≤ 5」は 5 checkpoint の値で、全 92 では最大 7・14・10 [実測]。
