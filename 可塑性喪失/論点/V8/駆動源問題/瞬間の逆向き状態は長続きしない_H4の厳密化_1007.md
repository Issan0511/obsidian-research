## 1. 言いたい文と、言える形（第 3 版）

**言いたい文（Issa）**: 瞬間だけを見たときに沈降と逆の動きをする状態は長続きしない。配置が良いから防げるのか、普通に学習を続けていれば普通に防げるのか。

**答え**: 「配置が良いから」ではなく、(A) 学習が作る状態では留め置きが生じず（瞬間の定理 ＋ 障壁 ＋ 狭さ）、(B) 人為的に入れても学習が壊す（標的自身の動き。P171）。ただし一般の定理としては偽で（§1 の 3）、言える形は次の 6 つ。

1. **瞬間の定理（なめらかなゲート）[厳密・条件つき]**。「谷底が閾値より下（M = ∅）」だけでは unit の水準の符号は出ない: 余裕 δ = 0 の下界は A^g_j ≥ (1−a)·C_j·(⟨s⟩_c,j − ½) で、沈んだ unit（⟨s⟩_c < ½）では負、対称な密度では厳密に 0（定理 H-2 の δ = 0。実状態 282 unit で 0 が成立）。要るのは余裕 δ か、入力ごと・両側の形: 全入力で谷底が閾値の下に余裕 δ をもてば十分条件は ⟨s⟩_c,j > ½ − δ/(1−a)（定理 H-2）；入力ごとに閉じた側の谷底 B^cl_n と開いた側の B^op_n を取れば、十分条件は C^cl_j(⟨s⟩^cl_c − ⟨σ^cl⟩_c) + C^op_j(⟨s⟩^op_c − ⟨σ^op⟩_c) > 0（定理 H-3。unit j の入力の開き具合の分布と入力ごとの谷底だけの条件で j の重みを使わない）。実状態で H-3 を満たす unit は a0.1 で 80/82、a0.3 で 72/100、a0.5 で 0/100（標的ごとの上界 B⁺ なら 82・100・98）。満たさない unit も含め A^g ≤ 0 は 0/282。ガウスでは ⟨s⟩_e′ = (1 + rε)/2（ε = τ/σ）なので条件は r > −2δ/((1−a)ε)、要る余裕は δ = (1−a)|r|ε/2（r = −2・ε = 0.1 で 0.09・0.07・0.05）。
2. **障壁 [厳密・極限]**。硬いゲートの極限で、閾値のゲート (j, n) ∉ M の項は閉じる側（A1）、閉じたゲートが下から閾値に達すると unit は沈める側に押され、容量は上へ跳べない（A2。ΔΦ > 0 ⟺ d̂ < (1+a)/2）。凍結した正の重みで上界 B⁺_jn = aT⁺ + (1−a)S⁺ + w_r⁺ は非増加（A3・H-4）。この極限 ＋ M の外では**ゲートの道の留め置きはどの瞬間にも無い**。
3. **位置の流れでは逆向きの符号は続かず、持続しうるのは打ち消し [厳密 ＋ 実測]**。流れは下に有界な Φ の勾配降下なので押しは 0 へ向かう（P157 の標的は正に戻り、P152c の終点は |A|/自己項 ≤ 0.04 で符号は雑音）。持続するのは「持たれた位置に留まること」= 留め置きの終点で、これは流れの本物の停留点。**一般の定理が偽なのはこの意味**: 設計した橋 10 個で作れる（P155）。
4. **持続の確率の縛り（実際の訓練）[厳密・仮定つき]**（定理 H4-S）。橋型の留め置きに持ち上げ役の条件が n* 個同時に要り、標的の実現した状態を与えたとき各持ち上げ役の条件の生存が独立（実測の相関 c ≤ 1.1）で新生が Poisson(λ_i) に支配されるなら、1 課題続く確率は P(S + B ≥ n*) ≤ C(n_t, n*)·q̄^{n*}、T 課題は q_hold^T、期待寿命 ≤ 1/(1 − q_hold)。実測の核（条件の一歩の持続 0.064・0.083・0.129）で、観測した状態の範囲で q_hold ≤ 1.7e−9・2.7e−8・1.4e−4（新生を Poisson(3) にしても ≤ 1.5e−2・4.7e−3・6.6e−2）。**形成は縛らない。** 測度は課題列で、定理 6 の並びの期待値とは別。
5. **必要数の下界 [厳密]**（定理 1〜4）。1 入力で m_n > w*_n / max_k Δ_k(n)、unit で m ≥ need_c/(被覆 × 最大の持ち上げ)。持ち上げの静的な上界はグラム行列 ⪯ diag(Θ_nn I, I) から出て、1 unit の持ち上げは強さについて一様に有界（P156 の「強くしても持てない」の理由）。**(B)（R̃ < 1）だけから出る数は 1 で空。** 「≥ 10」は実状態の |cos_G| が 0.03〜0.2 で持ち上げが上界の 1/4〜1/15 で止まることの実測で、unit で最小 3.6・12.8・20.0（中央値 33〜35）。
6. **実際の訓練 [実測]**。留め置きは相 1 の課題 2 にしか無く（41・42・45 個、全部 p > 1/2 の unit。橋型でも釘付け型でもない）、課題 3 で全部解け、相 2 の 276 checkpoint で 0/8,255・0/9,190・0/9,200（P170）。人為的に入れた留め置き（P155 の橋 10 個）は 1 出力の核で 1〜10 更新、多クラスの核で 50〜4,000 更新で解ける（P171）。壊すのは橋のゲートの揺らぎでなく**標的自身が動くこと**（寄与 88〜99.8%。1 更新で 0.2〜0.3 τ₀、1 課題で 5〜14 τ₀）。橋の配置は 5 課題後も元の標的に対して 98〜99% 効いたままで（P157 の「流れでは壊れない」は橋の側では実際の訓練でも成り立つ）、標的が留まらないので極小点としては持たない。

**結論の格**。「長続きしない」は、(a) 符号の文としては位置の流れで [厳密]、(b) 留め置き（打ち消し）としては決定論の流れでは持続しうる [実測 P152c・P157]、(c) 硬い極限 ＋ M の外ではゲートの道の留め置きは無い [厳密・極限]、(d) なめらかなゲートでは入力ごとの谷底と unit の開き具合の密度の条件で [厳密・条件つき]（a0.1・a0.3 の大半、a0.5 は標的ごとの形）、(e) 実際の訓練では持続は q_hold^T で縛られ [確率・仮定つき]、形成は実測（相 2 で 0）、(f) 入れても標的が動いて壊れる [実測]。一般の定理は無い。未導出は §5。

## 3. 反例・限界（どこで破れるか）

- (a) **一般の定理は偽**。設計した橋 10〜30 個で留め置きが作れ（P155）、位置の流れでは橋が釘付けになって打ち消し 92〜95% が残る（P157）。持たれた標的 ＋ 釘付けの橋は流れの停留点。
- (b) **「谷底 < 閾値」だけでは unit の符号は出ない**（初版 命題 A の誤り）。ゲート 1 個の降下（谷底で止まる）を位置の流れ（unit の全ゲートが一緒に動く）に移す段が無く、δ = 0 の下界は沈んだ unit で負。測った f^γ_n < 1/2 も留め置きを排除しない（P152c の反例 15 本は f^γ < 1/2 のまま持たれる）。
- (c) **浮力の釘付け = 長続きする逆向き状態**。硬い極限で深い unit は A^r < 0 で浮き、最初の閉じたゲートの閾値で障壁に当たって止まる。留め置きではない（自己項も浮かせる側）。文は留め置きに限る。
- (d) **浮かせる側の項**。閉じた対で谷底の下にある対は 32・46・65%、e′ の取り分 9・19・27%、unit ごとの 負÷正 は中央値 0.008・0.04・0.11（最大 0.46）。A^g ≤ 0 は 0 だが、素な仮定からは出ない。
- (e) **厳密な M は実状態で空ではない**。閉じた対 0〜4・12〜40・159〜208（56〜59 unit）。越えさせるのは aT（閉じた他 unit の床の和）と他 unit の読み出しの項の和で、開いた unit の多数ではない（a0.1 の唯一の閉じた M の対だけが本物の多数決 W^open 0.64）。これらは閾値から遠く（s 0.2〜0.3）、unit は全部沈める側。
- (f) **実際の訓練では重みの方が動く**。課題 t → t+1 で |重みの分| ÷ |ゲートの分| は中央値 1.9〜2.8。閾値の近くの閉じた対の 0〜6% が課題ごとに M に入るが、ほぼ全部はゲート自身が揺らぎで開いた対で、M にいることは次の課題で開く確率を上げない。模型の一歩では M への流入 0、M は 12〜15% 縮む。
- (g) **揺らぎは位置の拡散ではない**。位置の増分は反相関（lag-1 −0.2〜−0.25）で 8〜9 τ で頭打ち。解けるのは模様の脱相関（相対ゲート z_n − m の一歩 3.8〜4.2 τ、h^0.3 で伸び、最上位の入力が毎課題 57〜63% 入れ替わる）。正しい一歩の核はゲートの probit q_g(M) = Φ((M − μ)/σ)（(μ, σ) = (8.3, 8.8)・(4.7, 8.0)・(2.4, 7.1) τ。μ > 0 は余裕に比例する平均への回帰）＋ unit 内の位置の共有（分散の 0.31）＋ unit 間の独立（入力内の生存比 1.003〜1.017）。これで橋の寿命の分布 P(L ≥ 2〜5) が 0.95〜1.3 倍、最大 4〜5 まで再現される。
- (h) **再生に多数決は要らない**。要るのは橋の同時の新生。緩い基準の橋 ≥ 10 は相 2 の 276 checkpoint で 4 標的-課題にあるが A/自己項 ≥ +0.24。形成率は P161 の Poisson(0.2〜0.3) より標的の不均一さで大きい（狭い標的に新生が集中、n_t ≥ 1 で平均 0.48・最大 11）。
- (i) **橋の経路は読み出しの項が主**（P155 の自然な強さの橋で持ち上げの 57〜94%、f_h と k_i の G 計量の cos 0.24〜0.60）。10 倍の強さではゲートの項（cos_G 0.41〜0.89）。「閾値の入力と開いた入力をまたいで開く」は署名であって経路ではない。
- (j) **強さでは補えない**。一様 ×10・×100 でも 1 unit の持ち上げは ×0.5〜2.9、供給/必要量は 0.31・0.76 止まり。A が減るのは c_in ∝ E_nn の縮み。
- (k) **注入した留め置きは標的が動いて解ける**（P171）。標的は沈まずに上がる（23 で +13.6 τ₀、99 で +6.1 τ₀。注入が旧ラベルの関数を壊した分の修復の勾配）。まず位置（更新 1〜20）、次に模様（更新 50 以降）。1 出力の相殺は 99.7〜99.95% と薄く、多クラスで余裕 −2.7% の標的 23 は 50 更新持った。余裕を持たせた設計は未走。
