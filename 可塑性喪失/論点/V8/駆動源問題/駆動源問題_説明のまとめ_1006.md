## 1. 一言で

**問い**: 継続学習（乱数ラベルの課題列）で第 1 層の unit の前活性が負へ沈み、ゲートが閉じて可塑性を失う。沈める力の源は何で、なぜ他の unit がそれを覆さないか。土台（Issa）は「沈みは幅に従う・押しは自己項の向き・相対位置は活性化 × 最適化器」。このうち「押しは自己項の向き」の証明が、0930 から今日までの本体。

**答え（2 相）**:
- **相 1（初期・広い・課題 < 10）**: 自信のある分類器（p_max 0.96）に対する切替の押し S_i = Σ_n K_n d_in ⟨v_i, p_n − 1/K⟩ が、全 unit の位置をほぼ一様に沈める（向き 90〜97%、実際 99〜100%）。幅の伸びはブレーキ。容量の押しは冗長性の割引で小さく（A/自己項 0.1）、運ばない。
- **相 2（狭い・課題 ≥ 10）**: 相対位置 r = m/sd は r*（−2.2・−1.6）に止まり、沈降は幅の伸びの速さで進む（m = r*·sd）。押しの向きは自己項（容量の押し、全 unit で沈める向き）。残りは並びの期待値では自己項の正の倍率でしかなく、覆すには橋が ≥ 10 個要るが、実状態は最大 5、訓練は橋を壊す側、確率は 10^−7 以下。

## 3. 平文の説明

1. 押しは容量の傾き。unit が沈むのは、沈む向きに動くと網の容量（新しい乱数ラベルを当てる力）が減るから — 切替のたびに古い当てはめを消す動きの期待が、ちょうど容量の勾配になる（G1）。
2. unit 1 個だけなら、沈める向きは自明（自己項、G2）。問題は他の unit。他の unit は、各入力で「この unit のゲートがここまで開いていれば十分」という谷底を決め、ゲートが谷底より上なら閉じる向き、下なら開く向きに押す（G3）。
3. 谷底をゲートより上に持ち上げられる unit は限られる: その入力で開いていて、しかも標的が開いている入力でも開いている unit = 標的の部分的な写し = 橋。橋が無ければ覆らない。並びを無作為に取れば、残りは自己項を縮めるだけで向きは変えない（G3・G4）。
4. 実網に橋は無い。橋を作るには 10〜30 個の写しが要るが、訓練された unit は狭く、互いの開いた集合を写さない。位置を動かしても強さを変えても作れず、模様を設計して初めて作れる（G5）。
5. 橋があっても長くは続かない: 橋も沈み、架けている入力を失う。残るのは余裕の大きいゲートだけ。その確率は、実際の入力の幾何の中で向きが無作為なら 10^−7 以下で、訓練はむしろ橋を壊す（G6・G7）。
6. ただし初期は別。初期の広い unit はみな互いの緩い橋で、容量の押しは消えている。それでも崩壊するのは、CE で自信のある分類器を次の課題で消す切替の押しが、各 unit の「自分が予測を支えた分」に比例して全員を沈めるから。リッジの当てはめと違い、実際の読み出しは整合していないので打ち消しが無い（G8）。
7. 狭くなった後は、相対位置が止まり、沈降は幅の伸び（W 増大）の速さで進む。向きは自己項、覆す橋は無い（G9）。

## 4′. 活性化の一般化（1007）

ELU・SiLU・GELU への拡張は [[ELU・SiLU・GELUへの拡張_負の偏りと死_1007]]。向き（負に偏る）は 3 つとも閉じた（ELU は leaky と同じ補題で厳密・分布によらず、SiLU・GELU はガウスの数値 ＋ 実測 98〜100%）。幅が際限なく伸びたとき p⁺ → 0 かは、模型（段 1 以上）では leaky を含め 4 つとも釣り合いが無く答えられず、止め役の有無が分ける: leaky は §16.17（σ に比例 → r* 不変）、ELU × Adam は −1 ＋ Adam の守り（k* ≈ 20 一定 → r* −2.1 不変、幅 9 → 71）、ELU × SGD は壁で死ぬ、SiLU・GELU は φ̄ → 0 で止め役なく死ぬ。
