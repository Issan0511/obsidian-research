- **自己項の向き** = unit が自分の寄与を打ち消す向き（土台 §1-3）。式にすると、各入力で unit の出力 φ を基準 c₀ に近づける向きの要求で、m の向きとしてはその和の向き。鏡像の活性化では逆になる（§1(d)）ので、向きそのものに上下の性質は無い。**向きは c₀ の取り方で変わる**（状態ごとに c₀ を φ の最大より上に置けば、単調な活性化でも全入力で m を上げる向きになる）。だから「押しは自己項の向きに働く」の中身は c₀ を決めて初めて決まる。材料にある読みは 2 つで、このノートでは書き分ける。

  - **平均出力基準**（c₀ = unit の平均出力 φ̄_i、q を定数と置く）: φ > φ̄ の入力（開いた入力はここに入る）は m を下げる向き、φ < φ̄ の入力は上げる向きを要求し、和は中心化した記憶の押し M_c = Σ_n K_n φ′_in(φ_in − φ̄_i) = C1 + C2 そのもの（sign result §3.3）。「開いた入力の自己項が強い」の厳密な形は C1 ≥ 0（チェビシェフ）で、例外は反平行 (A) の unit（§1(e)）。記憶の模型の自然な基準は学習の長さで決まり、1 歩で 0、5〜30 歩で平均出力で、床ではない（§1(e)）。
  - 土台 §1-3 は「開いた入力の自己項が強い」と平均出力基準の言い方で説明し、§2 の段 3 では床基準の補題を根拠に置いている。どちらの基準で読むかは Issa の判断待ち。
- **床基準** = c₀ を活性化の床に取ること。自己項と残りの分け方は c₀ で変わり、和だけが c₀ によらない。
- **反平行**。2 つの定義があり、同じではない。(A) 記憶の模型の反平行: 明るい入力ほど活動が低い unit（Cov_n(K_n, φ_in) < 0）。(B) 重みの反平行: w_i·μ < 0（2 層の第 2 層では W₂ᵢ·μ₂ < 0 ⟺ m₂ᵢ < b₂ᵢ）。§1(e) と §2 は (A)。
- **k** = 切替時の unit の開いた入力（z > 0）の数。**全閉** = k = 0。

## 0. 一枚で

**問い。** 切替の押しは、なぜ自己項の向き（この箱では m を下げる向き）になるのか。全 unit について言えるか。言えないなら、集団（割合・和）で言えるか。その前に、自己項の向きの基準 c₀（床か平均出力か）を決める必要がある。c₀ で向きの中身が変わる（「言葉」）。

**いま言えること。**
1. 帳簿の上で、床基準の自己項の分は、どの状態・どのバッチ・どの歩でも、m を下げる向きか 0 [厳密。仮定: 最終隠れ層・床のある単調な活性化・その層の入力が非負・c₀ = 床・交差エントロピー（二乗誤差でも同じ向き）。変位については §1(c) の「分」の定義で、窓の始めの旧モーメントの分は入らない]。帳簿の分け方で、因果の根拠にはならない（[[引用禁止]] A 節の 8/20 の撤回、Issa 0902 の注意）。活性化を鏡に映すと押しの向きも映る [厳密]。向きの出どころが活性化の形（床のある側）であることは、鏡像の定理だけで言える。
2. 押しの期待は「unit が切替時の予測に入れている票」S で書け、(μ, 1) 方向に停留していれば「旧ラベルへの票 − 新ラベルへの票」になる [厳密・全データ SGD の 1 歩・新ラベルが状態と独立で一様]。
3. 記憶の模型で、4 つの仮定（記憶が中心化されている。これは合成の実測で 5〜30 歩の記憶が平均出力の基準に移ることからの近似で、F_τ から導いてはいない／共線の抑制 C3 を入れない／φ と φ′ が非減少（ReLU・leaky・ELU）／K_n > 0）の下で、m を上げる向きになれるのは反平行 (A) の unit だけ [厳密・模型]。C3 を入れると平行の unit でも逆になりうる（§2.2b）。旧ラベル整列 S^oh が m を下げる向きの割合は確率の式でパラメタなしに当たる（1 層 105 状態で平均絶対誤差 0.067）[式は厳密（仮定: 2 変量正規）、一致は実測・事後]。
4. 新ラベルが切替前の状態と独立な乱数ラベルの箱（1 層・2 層 MNIST）で、Snake と大きい α の ELU を除く活性化では、測った範囲で集団は逆転していない [実測]。
   - 期待の場（要求）が m を下げる向きの unit: 1 層・K 10・切替 5〜30・3 seed で ELU 0.98〜0.99・GELU 0.97・SiLU 0.94〜0.95・leaky 0.70。1 層・K 2（seed 0）で ELU・GELU・SiLU 0.82〜0.92・leaky 0.71。2 層の第 2 層の期待 T（seed 0・1）は 0.72〜0.99（ELU の切替 2〜4 は 0.75〜0.79）。
   - 実際に m が下がった unit（200 更新）: 1 層（同じ窓・3 seed）で ELU 0.95〜0.96・GELU 0.84〜0.86・SiLU 0.87〜0.88・leaky 0.84。2 層の第 2 層（seed 0・1）で 0.92〜1.00。facts §10 の別の数え方では ELU 0.92・leaky 0.73・SiLU 0.72・GELU 0.56 で、定義を照合できていない（§3.3）。
   - 2 層では期待の場も自己項も向きを説明しておらず（床基準の自己項は期待の押しの 1%）、支えは変位だけ。1 層でも、期待の場と変位の unit ごとの符号の一致は偶然の水準とほぼ同じ（leaky だけ +0.06〜+0.07）[事後]。 【注 1003 夕 → [[押しの向き_証明の進み_門の道と段ごとの格_1002]] §16.18 の 10。床基準の割合は基準の取り方で動く。言えるのは「床基準の補題は向きを説明しない」まで】
   - 逆転した箱もある。実ラベルの 5+1 CIFAR の第 2 層で、押しの中央値が負の課題は ReLU 0.37・KKT1 0.31（ReLU の第 2 層は床基準の補題の仮定を満たす層）。Snake α = 1 固定の変位は 0.39 まで下がる（§4）。RL-CIFAR（ReLU の第 2 層）は別の量しか無く、課題全体では m を上げる向きの十分条件の方が多い（§3.1）。範囲をこう限ったのは結果を見てから [事後]。
5. これまでに見つかった例外は §4 の 8 型 [実測・事後]: 鏡像（逆になる）、床の無い・ほぼ線形の活性化（Snake・大きい α の ELU。半々）、谷の下の入力 1 つずつ、開いた入力の少ない unit（m が上がる）、γ < τ（試せていない）、実ラベルで入力も替わる箱の第 2 層（課題の種類で割れる）、二乗誤差で長く当てはめる玩具。

**言えないこと。**
1. 他の unit と出力 bias の分の符号。部分回帰係数（Gram の逆行列の非対角）で決まり、抑え役の unit では自己項の向きと逆になる（入力 3 枚・Ĝ 正則の例 §2.2b、Ĝ が特異な 2 入力の例 §2.2）[厳密・模型の例]。全 unit の定理は無い。
2. 集団の割合の下限を、測った量を使わずに出すこと。2 層で S2 > 0 がほぼ 1 になる理由 [未導出]。
3. 自己項の補題を向きの説明に使うこと。帳簿の分け方で、残りが逆に動きうる（2 層の初期の切替では床基準の自己項は期待の押しの 1%。5+1 CIFAR の ReLU の第 2 層は補題が成り立つ層なのに、過半の課題で m が上がった）。
4. 早い窓の変位の向きが、unit ごとに期待の場の向きに帰着すること（1 層でも符号の一致は偶然の水準と区別できない）。

## 1. 厳密に言えること

### (a) 新ラベルについての期待の式 [厳密]

- 仮定: 新ラベルが切替前の状態と独立で一様（E[y_new | 状態] = u）。全データ SGD の 1 歩、η の 1 次。最終隠れ層の unit の自分の重みと bias の経路（2 層の上流の経路はこの式の外）。入力どうしの独立は要らない。
- 式: **E[Δm_i] = −(η/N) S_i**、S_i = Σ_n K_n φ′_in v^c_i·p_n。どの活性化でも成り立つ。w·μ̂ についての同じ形が 0925 §1.5-1。予測 p が one-hot でなくても、E[y_new | 状態] = u だけで厳密。
- 旧ラベルを残す箱（E[y_new | 状態] = π_n）では E[Δm_i] = −(η/N) Σ_n K_n φ′_in v^c_i·(p_n − π_n)。旧ラベルを確率 τ で残すなら π_n = (1 − τ)u + τ e_{y_old(n)} で、−(η/N)(S_i − τ S^oh_i)（fork2 R11a の事後の場と同じ形）。
- 整列の仮定なしに言えるのは、切替の 1 歩目の期待勾配が予測を一様にする勾配で、出力層（と斉次な活性化なら隠れ層）のノルムを一次で縮めることまで [厳密・0925 §1.3]。m の向きはこの中に入っていない。
- 出どころ: [[切替の押しの符号とp⁺の単調減少_理論検証と1層の走_0925]] §1.2・§1.3・§1.5（Codex の独立レビュー）、`derivations_round1/sign/derivation.md` §1・§2.1。

### (b) 課題末に釣り合っていれば、押しはラベルの差だけで書ける [厳密]

- 1 歩の変位は **Δm_i = −(η/N)[S_i(p) − S_i(y)]**、S_i(q) := Σ_n K_n φ′_in v^c_i·q_n（y は学んでいるラベル）[恒等式・全データ SGD・η の 1 次]。切替の直後は第 2 項の期待が 0 [厳密・新ラベルが状態と独立で一様]。p が y に近づくと第 2 項が第 1 項を打ち消す（p = y なら 0 [恒等式]）。課題の後半の戻りをこの第 2 項の育ちで読むのは [事後。すり合わせ §1.5]。すり合わせ §1.5 の D = S − A と同じ式。
- 旧課題で (μ, 1) 方向に停留していれば（旧課題の損失の勾配の (μ, 1) 成分が 0）、S_i(p) = S^oh_i なので、切替の 1 歩は
  **Δm_i = −(η/N) Σ_n K_n φ′_in (v^c_{i,y_old(n)} − v^c_{i,y_new(n)})**
  で、予測を含まない。押し = 「unit が旧ラベルに入れていた票 − 新ラベルに入れる票」を K φ′ で重み付けた和。期待は S^oh_i。
- 一般には S_i = S^oh_i + N (μ, 1)·∇_{(w_i, b_i)} L_old [厳密]。ELU・GELU・SiLU は停留に近い（S と S^oh の unit 間の順位相関 0.97〜0.99、3 seed・切替 5〜30）が、leaky は崩れる（順位相関 0.63。切替 8〜12 で S > 0 が 0.66〜0.79、S^oh > 0 が 0.80〜0.84）[実測・事後]。
- 保持率 τ の箱で停留を置くと、期待は −(η/N)(1 − τ)S^oh_i で、τ < 1 なら符号は S^oh と同じ（このノートで足した 1 行。(a) の式に S_i = S^oh_i を入れただけ）。0925 の (γ − τ) の式は、予測を旧ラベルと一様の混ぜ合わせ p = (1 − γ)u + γ e_{y_old} と置いた近似から出る（§4 の 6）。
- 出どころ: `derivation.md` P1.1、`derivations_round1/sign/final/result.md` §3.5。

### (c) 自己項の補題 [厳密]

- 恒等式（状態ごと。ラベルを含まない）: **v^c_i·p_n = q_in(φ_in − c₀) + v^c_i·p_n^{(i→c₀)}**、q_in ≥ 0。p^{(i→c₀)} は unit i の出力を c₀ に置いたときの予測。よって入力ごとの誤差の場は
  δ_in = φ′_in q_in (φ_in − c₀) ＋ φ′_in v^c_i·p_n^{(i→c₀)} − φ′_in v^c_{i,y_n}
  と分かれ、第 1 項が自己項。
- 自己項の向き: φ′(φ − c₀) = d/dz[(φ − c₀)²/2] なので、自己項は各入力で φ を c₀ に近づける向きに z を動かすことを要求する（このノートで足した言い換え）。これは要求で、変位ではない。重みは入力のあいだで共有されているので、入力 n′ の実際の Δz は、全入力の自己項を核（SGD では x̃_n·x̃_n′、Adam では x̃_n′ᵀΛx̃_n）で重み付けた和で決まる。全入力の z が要求どおりに動くことが保証されるのは、入力ごとの符号がそろう場合（床基準で、その層の入力が非負）で、そのとき自己項の分の一歩は全座標が同符号なので全入力の z を同じ向きに動かす（twolayer §0-7 と同じ形）。平均出力基準や谷の下では、要求の向きと z の動きは一致しない。
- **床のある単調な活性化で c₀ = 床**（ReLU 0、ELU −1。α·ELU(z/α) の −α と softplus の 0 はこのノートで当てはめた。式は同じ）なら φ′ ≥ 0・φ − c₀ ≥ 0 で、自己項は全入力で ≥ 0（m を下げる向き）。q_in は softmax の下の分散なので、この形は交差エントロピーの損失についてのもの。二乗誤差では自己項は φ′|v_i|²(φ − c₀) で、向きは同じ（§4 の 8）。
- **期待値でなく実際の勾配でも毎歩成り立つ**（`derivations_round1/adam/final/result.md` §4.1 の A7′）。範囲を正確に書く。
  - 成り立つもの: どの状態・どのバッチ・どのラベルの引き・どの歩でも、自己項の勾配 (1/B)Σ_n φ′q(φ − c₀) x̃_n は、その層への入力が非負なら全座標で ≥ 0。
  - 変位について: 自己項の勾配だけを別のモーメントに流し、分母は実際の Adam のままにした変位を「自己項の分」と定義すると（Adam は非線形なので、この定義を置かないと「分」が決まらない）、Adam の窓の変位のうち自己項の分は、どの窓でも m を下げる向きか 0。要るのは Adam の核 κ_r(n) = kᵀΛ_r x̃_n ≥ 0（k = (μ, 1)。入力が非負なら自動）。窓の恒等式の旧モーメントの項（窓の始めのモーメント M₀ から来る分）は「自己項の分」に入らない。窓を学習の始めから取れば M₀ = 0 で、全部が分けられる。

  - 成り立たないもの: leaky（有限の床が無い）。GELU・SiLU（φ′ < 0 の域があり、どの c₀ でも全入力で符号がそろわない。開いた入力と帯 (z_c, 0) の入力には c₀ ≤ φ(z)、谷の下の入力には c₀ ≥ φ(z) が要る。与えられた状態でそろう基準はありうる）。Snake（床が無い）。最終隠れ層でない層（2 層の第 1 層、5+1 CIFAR の第 1 層）。入力に負を含む層（RL-CIFAR の std では K < 0 の入力が 35〜38%）。
  - 2 層の第 2 層: 第 2 層だけを動かす own 腕は 1 層問題と同じ形 [厳密・構成] だが、入力 a₁ が ELU では負になりうるので、K2 と κ の符号を別に要る（κ < 0 の (入力, unit) は 0〜0.14% [実測]）。対の核 a₁(x)·a₁(x′) + 1 ≥ 0 は「全入力で m を下げる向き」の十分条件にすぎず、SGD の 1 歩（床基準）の変位で測ると、切替の瞬間に m を上げる向きの (入力, unit) が ELU の切替 2 で 3.9%・12.9%、切替 3〜4 で 0.4% 以下。Adam の核では切替 6 で 0.25〜0.70% [実測・事後・seed 0・1。twolayer §2.4]。
- 検算: ランダムな ELU の網（非負の入力）で補題の誤差 2.7e−15、自己項と φ − 床 の符号の不一致 0 / 199,963（softmax が飽和して q < 1e−13 になる 37 件は float64 の丸めの域として除いた）。任意の残り（自己項の鏡像を含む）を足した Adam の窓 200 本で、自己項の分は全部 m を下げる向き（最大 −0.073）。
- **限界。**
  1. 分け方は c₀ で変わる。和だけが c₀ によらない。自己項の向きも c₀ で変わる（「言葉」）。この補題は床基準についてのもの。
  2. 残りは自己項を打ち消す向きに動きうる（鏡像）。この「自己項＋残り」の分解は、過去に何度も因果の根拠として棄却されている（Issa 0902 の注意。メモリの要約）。「非対称性の出所は自己項」は 8/20 に撤回されている（[[引用禁止]] A 節）。自己項は独立の駆動力でない、は [[三理論の統合_駆動源5項式とV10とφ′射影_0918]] の合意。言えるのは「帳簿の上で、床基準の自己項の分は常に m を下げる向き」まで。
  3. 大きさ: 1 層の箱（ELU・切替 5〜30・3 seed）で、自己項 ÷ S の unit 中央値は基準 0 なら 0.59〜0.60、床基準 1.17〜1.23、平均出力基準 1.08〜1.13 [実測・事後]。2 層の第 2 層（ELU・切替 2〜4・seed 0・1）では、床基準の自己項（上流の対角で戻る分を含む）は期待の押しの 0.01 で、0.66〜0.67 が他の unit の要求（上流の非対角）から来る [実測・事後]。

### (d) 鏡像で向きが逆になる [厳密]

- 仮定: ψ(z) = −φ(−z)。対象層の (w, b) と次の層の読み出しを符号反転、出力 bias はそのまま（2 層で両層に ψ を使うなら写像 (−W₁, −b₁, W₂, −b₂, −W₃, b₃)）。同じデータ・ラベル・バッチ順。最適化器が座標ごとの符号反転に同変（SGD・Adam はそう: 一次モーメントは反転、二次モーメントは不変）。初期値を写像で対応させる。
- 主張: 関数は同じで、全時刻で z′ = −z。押しも自己項も残りも符号が逆（c₀ → −c₀。床は天井になり、自己項は φ を天井に近づける向き）。
- 帰結: 押しの向きの出どころは、データや最適化器ではなく活性化の形（床のある側）。奇関数の φ では、初期値の分布が符号反転で変わらなければ、初期値の集団についての期待の沈みは全時刻で 0。ただし奇関数性は向きを選ばない（ある偶部がどちら向きを与えるかは、状態とデータの積分で決まる）。
- 検算: 合成網で float64 の不一致 0。登録済みの S-mirror（edge_law_0905 の命題 1）と整合。
- 出どころ: `derivation.md` §3.1、`refutation.md` §2.1、すり合わせ §1.7。

### (e) 中心化した記憶の模型での符号の定理 [厳密・模型]

- 記憶の模型: 特徴（隠れ層の活動 Φ、N × H）を固定し、読み出しと出力 bias を二乗誤差の勾配流で学習の長さ τ だけ学ぶ。初期値はラベルと独立。旧ラベルは一様・独立。このとき
  **E[S^oh_i] = (1 − 1/K)·b_iᵀ F_τ φ_i**、F_τ = Θ⁺(I − e^{−τΘ})、Θ = ΦΦᵀ + 11ᵀ [厳密・模型]。
  τ → 0 で生の記憶（∝ Σ_n b_in φ_in）、τ → ∞ で FWL（§2.1）。合成の Monte Carlo と 1.87 SE 以内。基準は学習の長さで決まり、1 歩の記憶は基準 0、5〜30 歩で unit の平均出力に移る（出力 bias を固定しても同じ）[実測・合成]。
- 中心化した記憶（票の期待 ∝ φ_in − φ̄_i）では、押しの期待は M_c = Σ_n K_n φ′_in(φ_in − φ̄_i) = C1 + C2（sign result §3.3）。これは平均出力基準（q を定数と置く）の自己項の和と同じ形（「言葉」）。
  - C1 = (ΣK)·Cov_π(φ′, φ)（π_n = K_n/ΣK）。**φ と φ′ がともに非減少（ReLU・leaky・ELU）なら C1 ≥ 0**（チェビシェフの和の不等式）。
  - C2 = (Cov_n(K, φ)/K̄)·Σ_n K_n φ′_in。**反平行 (A) の unit でだけ負。**
  - だから **m を上げる向きになれるのは反平行 (A) の unit だけ**で、|C2| > C1 のとき。
- 仮定: 記憶が中心化されている（合成の実測 S1b で、5〜30 歩の記憶の基準が平均出力に移ることからの近似。F_τ から導いてはいない）。共線の抑制（§2.1 の C3）を入れない。K_n > 0。C1 ≥ 0 にはさらに φ と φ′ が非減少であること。C3 を入れると、平行の unit でも m を上げる向きになりうる（§2.2b）。
- 活性化ごと: leaky は C1 = (ΣK)(1 − a)π⁺(1 − π⁺)(h̄₊ + a d̄₋) で開いた割合 π⁺ とともに消え、C2 ≈ a²·ΣK·Cov_n(K, z)/K̄ は沈んでも残る [厳密・模型]。ただし、これを自然な走の leaky の「m が上がる unit の 3 割」の説明に使うことは撤回されている（変位については、同じ k なら leaky と ELU で m が上がった割合はほぼ同じ。§3.2・§7）。期待の場で leaky の約 3 割が m を上げる向きなのも k の分布で説明がつくか（上げる向きの unit が k の小さい unit か）は確かめていない。ReLU は M_c = Σ_開 K(z − p⁺h̄₊) でほぼ常に正。GELU・SiLU・Snake はチェビシェフの保証の外（実状態で C1 < 0 の unit は GELU・SiLU で 0、Snake で 0.02〜0.53）。

- 出どころ: `final/result.md` §3.1・§3.3、すり合わせ §1.1、fork2 追補 2。

- 仮定: (e) の模型。旧ラベルの揺らぎと記憶を押しの重みで集めた量が 2 変量正規（標本についての中心極限による近似）。

## 2. 導出できないことと、その理由

### 2.1 他の unit との兼ね合いは、部分回帰係数で入る

- 記憶の模型で τ → ∞ にすると、**E[S^oh_i] = (1 − 1/K)⟨b_i, φ_i^⊥⟩/‖φ_i^⊥‖²**（φ_i^⊥ = unit i の活動を、他の unit の活動と定数で回帰した残り）[厳密・模型]。これは b_i を全 unit の活動と定数に回帰したときの φ_i の係数 c^{(i)}_i（部分回帰係数、FWL の added-variable の傾き）の (1 − 1/K) 倍。
- 分けると ⟨b_i, φ_i^⊥⟩ = C1 + C2 + C3。C1・C2 は §1(e) と同じで、**C3 = −⟨b_i, P_{−i}φ̃_i⟩**（P_{−i} は他の unit の中心化した活動が張る空間への射影）が共線の抑制 [厳密・模型]。C3 の符号は決まらない。
- 係数で書くと c^{(i)}_i = Σ_j (Ĝ⁻¹)_ij ⟨φ̂_j, b_i⟩（Φ̂ = [Φ, 1]、Ĝ = Φ̂ᵀΦ̂）。**他の unit の分は Gram の逆行列の非対角 (Ĝ⁻¹)_ij（j ≠ i）を通る。** その符号は unit どうしの活動の重なり方で決まり、活性化の形だけからは決まらない。これが「他 unit の分は [未導出]」の中身。
- 途中の τ でも同じ形に書ける: **E[S^oh_i] = (1 − 1/K)·Σ_j c^{(i)}_j [I − e^{−τĜ}]_{ji}**（Ĝ が正則のとき。このノートで足した書き換え。F_τΦ̂ = Φ̂Ĝ⁻¹(I − e^{−τĜ}) から出る。数値で確認 §8）。τ → 0 で τ⟨b_i, φ_i⟩（生の記憶）、τ → ∞ で c^{(i)}_i。学習が進むほど、他の unit の係数 c^{(i)}_j が混ざる。
- 実状態（1 層 ELU 2 seed × 切替 2・3・5・8・12、GELU seed 0 × 切替 2・3）: C1 > 0 と C3 < 0 が 12 状態すべて。切替 2 では ⟨b, φ^⊥⟩ を 1 として C1 ≈ 17〜19、C3 ≈ −17〜−18 でほぼ打ち消し合い、切替 12 で 1.4 と −0.4。FWL の符号は 98〜100% の unit で m を下げる向きだが、大きさは実際の S と合わない（unit 間の順位相関 −0.37〜+0.18）。実際の網は共線の抑制を十分には受けていない（途中の τ にいる）[実測・事後]。
- 出どころ: `derivation.md` P1.4、`final/result.md` §3.1。

### 2.2 例: 2 unit・2 入力で、抑え役の unit は自己項の向きと逆になる [厳密・模型の例。Ĝ が特異な退化した例。検算済み]

**設定。** 入力 2 枚、明るさ K = (3, 2)。ReLU の unit 2 つが、どちらの入力でも開いている（φ′ = 1 なので b = K）。unit 1 の活動 φ_1 = (3, 1)、unit 2 の活動 φ_2 = (4, 2)。どちらも明るい入力で強く点く（平行。C2 > 0、C1 = 0）。自己項（床基準）は両方の入力で m を下げる向き。読み出しと出力 bias を旧ラベル（乱数）に二乗誤差の勾配流で当てる（入力が 2 枚なので当て切れる。τ → ∞ は最小ノルムの当てはめ）。

| | unit 1 だけ（＋出力 bias） | unit 1 と unit 2（＋出力 bias） |
|---|---|---|
| Θ = ΦΦᵀ + 11ᵀ | `((10, 4), (4, 2))` | `((26, 12), (12, 6))` |
| unit 1 の記憶 Θ⁻¹φ_1（入力ごとの票の期待の形） | (+0.5, −0.5) | (+0.5, −0.83) |
| b·Θ⁻¹φ_1（E[S^oh_1] はこの (1 − 1/K) 倍） | **+0.5（m を下げる向き）** | **−1/6（m を上げる向き）** |

**なぜ逆になるか。**
- b = (3, 2) は、2 枚に共通の部分 2.5·(1, 1) が大きく、差の部分 0.5·(1, −1) が小さい。
- unit 1 だけなら、2 枚が同じラベルのときは出力 bias が受け持つので、unit 1 の票の共通部分は 0。押しは差の部分だけで、2 × 0.5 × 0.5 = +0.5。
- unit 2 がいると、最小ノルムの当てはめは、2 枚が同じラベルのとき unit 2 にも票を持たせ（+1/3。出力 bias は 1 → 2/3）、そのせいで出る 2 枚の差を unit 1 の逆票（−1/3）で消す。unit 1 は抑え役になり、記憶の共通部分が負になる: Θ⁻¹φ_1 = −(1/6)·(1, 1) + (2/3)·(1, −1)。
- 共通部分の大きい b と掛かって、共通の分 2 × 2.5 × (−1/6) = −5/6 が差の分 2 × 0.5 × (2/3) = +2/3 に勝ち、和は −1/6。
- **この例は §2.1 の式の適用域の外。** 2 枚では、unit 1 と unit 2 の中心化した活動が同じ (1, −1) になり、φ_1^⊥ = 0。Φ̂ = [φ_1, φ_2, 1] は 2 × 3 で階数 2 なので Ĝ = Φ̂ᵀΦ̂ は特異で、FWL の式 ⟨b, φ^⊥⟩/‖φ^⊥‖²（0/0）も Ĝ⁻¹ の式も使えない。τ → ∞ の −1/6 は最小ノルムの補間（Θ⁻¹）から出た値で、C3 が C1 + C2 に勝つことから出た値ではない。Ĝ が正則な例は §2.2b。

**学習の長さで見ると**（b·F_τφ_1）: τ = 0.1 で +0.32、τ = 1 で +0.19、**τ ≈ 3.0 で符号が変わり**、τ = 10 で −0.15、τ → ∞ で −1/6。unit 1 だけなら、どの τ でも正（τ = 1 で +0.82、→ +0.5）。生の記憶（τ → 0 の傾き）は b·φ_1 = 11 > 0。Θ の固有値は 31.6（おおよそ 2 枚に共通の向き。固有ベクトルは (1, 0.47) 方向）と 0.38（おおよそ差の向き。(−0.47, 1) 方向）で、共通の向きは τ ≈ 0.03 で当てはまるがそこではまだ正、符号が変わるのは差の向きまで当てはまったとき（τ × 0.38 ≈ 1.1）。

## 5. 前提としての置き方

**本流の文**（土台 §1-3 のまま）: 切替の押しは「自己項の向き」（unit が自分の寄与を打ち消す向き）に働く。整流型の活性化では開いた入力の自己項が強いので、m を下げる向きになる。これを前提として置き、証明は Issa が別に粘る。

**読むときに決めること。** 自己項の向きの基準 c₀（「言葉」）。床基準なら、前提の中身は「m が下がる」の言い換えで、鏡像の定理以上の中身は無い。平均出力基準なら、「開いた入力の自己項が強い」の厳密な形は C1 ≥ 0 で、反平行 (A) の unit は最初から例外に入る。土台の文は説明に平均出力基準の言い方を使い、根拠（土台 §2 の段 3）に床基準の補題を置いている。

> **Issa の読み（0930 夜。判断待ちは解消）。** 「自己項」は言い方が悪い。押しは、unit の出力を下げる力の合計で駆動される、と読む。式では Δm ∝ Σ_n K_n φ′_in ×（入力 n で出力に掛かる力 −∂L/∂φ_in）[恒等式・全データ SGD の 1 歩] で、基準 c₀ は要らない。c₀ が要るのは、この力を unit 自身の分と他の unit の分に割るときだけ。切替の期待では、出力を下げる力 = 切替時の予測への票 v^c_i·p_n（§1(a)）。平均出力基準の形（票 ∝ φ − φ̄、M_c = Σ K φ′(φ − φ̄)）がこの読みに当たる: 開いた入力では下げる力、閉じた入力では上げる力で、感度 φ′ の大きい側が勝つ。leaky は閉じた側に重み a が残るので勝ち方が弱い（期待の場 0.70 対 ELU 0.98 と向きが合う [事後]）。未導出なのは、票が (φ − φ̄) に正の係数で比例することを unit ごとに言うこと（抑え役の unit では負になりうる、§2.2b）。以下、このノートの「自己項の向き」はこの意味で読む。

**置くときに添える範囲**（このノートの提案。結果を見てから置いた [事後]。R11b の登録の予測（Claude、確信 0.6）は範囲を限っていなかった）。
- 対象: 新ラベルが切替前の状態と独立に引かれる箱の、切替時に開いた入力を持つ unit。
- 水準: 集団（割合・中央値）。unit ごとには例外がある（開いた入力の少ない unit、反平行 (A) の unit、抑え役の unit）。
- 量: 期待の場の向きか、早い窓（数十〜数百更新）の変位の向きかを書き分ける。
- 土台 §1-1 の定常の議論（相対位置 × 幅）に要るのは、集団の相対位置が負に保たれることで、この狭めた前提（開いた入力の少ない unit は上がる。k ≤ 2 が leaky 24%・ELU 9%）で足りるかは [未導出]。

**根拠 3 つ。**
1. **鏡像の定理** [厳密]: 活性化を鏡に映せば押しの向きも映る（§1(d)）。向きの出どころが活性化の形（床のある側）であることは、これだけで言える。
2. **記憶の模型** [厳密・模型]: 4 つの仮定（記憶が中心化されている。これは合成の実測からの近似で、F_τ から導いてはいない／共線の抑制 C3 を入れない／φ と φ′ が非減少（ReLU・leaky・ELU）／K_n > 0）の下で、m を上げる向きになれるのは反平行 (A) の unit だけ（チェビシェフ）。C3 を入れると平行の unit でも逆になりうる（§2.2b）。旧ラベル整列 S^oh が m を下げる向きの割合は、確率の式でパラメタなしに当たる（1 層 105 状態で誤差 0.067）[一致は実測・事後]。
3. **実測** [実測]: 新ラベルが状態と独立な乱数ラベルの箱（1 層・2 層 MNIST）で、Snake と大きい α の ELU を除けば、集団では逆転していない（§3.1）。1 層・K 10 で期待の場（m 版）ELU 0.98〜0.99・GELU 0.97・SiLU 0.94〜0.95・leaky 0.70、変位 0.84〜0.96。2 層の第 2 層では期待 T 0.72〜0.99、変位 0.92〜1.00 で、支えは変位だけ（期待の場も自己項も向きを説明していない）。変位の割合には facts §10 の別の数え方（0.56〜0.92）もあり、照合できていない（§3.3）。逆転した箱: 実ラベルの 5+1 CIFAR の第 2 層（押しの中央値が負の課題は ReLU 0.37・KKT1 0.31）、Snake の変位 0.39 の切替。

### (i) 重なりの上限を仮定に置く道

- **考え方。** §2.1 で、他の unit の分は「他の unit が unit i の活動をどれだけ表せるか」で効く。表せる割合に上限を置けば、自分の分が勝つ。
- **τ → ∞ の模型での十分条件**（このノートで足した 1 行。Cauchy–Schwarz）: ⟨b_i, φ_i^⊥⟩ = ⟨b̃_i, φ̃_i⟩ − ⟨P_{−i}b̃_i, P_{−i}φ̃_i⟩ なので、
  **cos(b̃_i, φ̃_i) > R_b,i · R_φ,i ⇒ E[S^oh_i] > 0（m を下げる向き）**。
  R_φ,i = ‖P_{−i}φ̃_i‖/‖φ̃_i‖（unit i の中心化した活動のうち、他の unit で表せる割合。重相関）、R_b,i は押しの重みについて同じ量。b̃・φ̃ は入力について中心化したもの。§2.2 の例は Ĝ が特異（φ^⊥ = 0）で、この式の適用域の外。§2.2b の例は R_b·R_φ = 0.990 > cos 0.982 で条件が外れ、実際に逆になる場合。
- **要る仮定。** 記憶の模型、τ が十分長い。実際の網は途中の τ にいる（§2.1）。途中の τ への拡張は、射影 P_{−i} を §2.1 の I − e^{−τĜ} の形に置き換えた「F_τ の計量での重なり」になるはずだが [未導出]。
- **既にある検算。** 実状態（1 層 ELU 2 seed・GELU seed 0、12 状態）では、切替 2 で C1 と C3 がほぼ打ち消し合う（17〜19 対 −17〜−18）が、FWL の符号は 12 状態全体で 98〜100% の unit で m を下げる向きだった（derivation P1.4）。R_φ・R_b は測っていないので、この十分条件がどれだけの unit を覆うかは分からない（C3 が大きいことから R_φ ≈ 1 は出ない。R_b が大きくても同じになる）。
- **測れば進む量。** 保存状態での unit ごとの R_φ、R_b、cos(b̃, φ̃) の分布と、十分条件が覆う unit の割合。非対角の割合 |C3|/(C1 + C2) の分布（切替・活性化ごと）。期待の場が m を上げる向きの unit の k の分布（leaky 対 ELU、k をそろえた割合。§1(e) の leaky の 3 割が k の分布で説明できるか）。自然な τ での「他の unit の係数の分」Σ_{j≠i} c^{(i)}_j [I − e^{−τĜ}]_{ji} と自分の分 c^{(i)}_i [I − e^{−τĜ}]_{ii} の比。保存状態は `sink_roots_0930/round1/sign_states/` に 1 層 6 状態と 2 層 24 状態。§1(f) の 105 状態は、このデータのフォルダには見当たらない（作り直しが要るかもしれない）。

### (ii) 集団の和 Σ_i で言う道

- **層の和の恒等式** [厳密]: Σ_i S_i = Σ_n K_n J_n·(p_n − u) = K Σ_n K_n Cov_k(p_nk, J_nk)、J_n = Σ_i φ′_in v_i（層の全 unit の前活性をそろって s だけ上げたときの出力の変化 ∂f_n/∂s）。各入力で J_n と f_n のクラスの順序がそろえば（同順）Σ_i S_i ≥ 0（チェビシェフ）[厳密]。ReLU で開いた unit の高さがそろい、出力 bias のクラス差が小さければ同順 [候補]。読み: d/ds KL(u‖p_n) = (p_n − u)·J_n なので Σ_i S_i = Σ_n K_n d/ds KL(u‖p_n) [恒等式]。層全体の押しが m を下げる向き ⟺ 層をそろって持ち上げると、K で重みを付けた Σ_n K_n KL(u‖p_n) が増える。これは土台 §4-1 で外れた「戻りの不足を自信で読む」とは別の量。
