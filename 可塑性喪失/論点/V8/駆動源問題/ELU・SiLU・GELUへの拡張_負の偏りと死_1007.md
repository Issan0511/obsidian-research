## 1. 一言で

- **負に偏る（向き）**: 3 つとも閉じた。ELU は leaky と同じ補題で [厳密・K 一定・α ≤ 1・分布によらず]（φ′ 単調非減少・φ 増加 → 段 1 の Cov(φ′, φ) > 0）。SiLU・GELU は谷（φ′ < 0 の領域）があるので補題は使えないが、段 1・段 2 の押しは実状態の範囲（σ ≥ 1・r ∈ [−4, 0]）で正 [ガウス]、1 層箱の実測で 98〜100% [実測]。（1008: 状態ごとの十分条件 SC1・SC2 [厳密・K 一定・分布によらず] とガウスの閾値 σ ≥ 0.87・0.53 に格を上げた。段 2 は r = 0 で 0 なので「r ∈ [−4, 0] で正」は「非負」。H5 だけでは分布によらず閉じない。§7）
- **幅が際限なく伸びるなら p⁺ → 0 か**: 模型の中でこれを言えるのは**段 0（他の unit も bias も無い自己形）だけ**。そこでは leaky の釣り合い r* = −1.72 は σ によらず、ELU の釣り合いは r* ≈ −0.7σ で σ とともに深くなり（σ ≳ 6 で釣り合いの開いた入力は 1 個未満）、SiLU・GELU には σ ≥ 1 で無い [ガウス]。しかし**段 1 以上（bias か他の unit がいる）では leaky を含む 4 つとも模型に釣り合いが無く、止まる位置は 4 つとも模型の外**（leaky の鎖と同じ）。
- **生きるか死ぬかを分けるのは、模型の外の止め役の有無とその幅への依存**（§4）: leaky は §16.17 の項（正斉次なので σ に比例 → r* は幅によらない）。ELU × Adam は別の守り（−1 の床 ＋ Adam の正規化 → 開いた入力 k* ≈ 20 を幅によらず保つ → r* = Φ⁻¹(k*/N) ≈ −2.1。幅 9 → 71 で不変）。ELU × SGD は止め役が無く深さの壁で死ぬ。SiLU・GELU は φ̄ → 0 で止め役が無く死ぬ。
- **答え**: 「幅が際限なく伸びるなら p⁺ → 0」は、SiLU・GELU と ELU × SGD で成り立ち [実測 ＋ 止め役の不在の論理]、ELU × Adam では成り立たない（p⁺ = k*/N、N → ∞ で 0）[実測 2,000 課題]。活性化は (i) 向き（3 つとも沈める）と (ii) 止め役の有無・尺度 の 2 か所で入る。

## 3. 幅の尺度: 閉じた側は有界、開いた側は σ に比例（段 0 の性質）

標準化した位置 ζ = z/σ < 0 を固定して σ → ∞ とすると、閉じた側のゲート φ′(σζ) は leaky で a（不変）、ELU で αe^{σζ} → 0、SiLU で ≈ −σ|ζ|e^{σζ} → 0、GELU で ≈ −σ|ζ|ϕ(σζ) → 0。閉じた側の出力は leaky で aσζ（σ に比例）、ELU で → −α、SiLU・GELU で → 0 [厳密]。これは土台 §1 点 4「幅が増すと負の側の φ′ が相対的に小さくなる」の厳密形（drive_recon の N1 と同じ）。

## 6. 言えないこと

- 相対位置の時間の形（1 層 Adam で ρ(t) ≈ −c ln t、c = ELU 0.57・SiLU 0.43・GELU 0.4）の導出。

## 7. 幅と谷（1008・Codex 導出・Opus 反証）

> Issa の問い: 幅が伸びること（H5）を仮定しているなら、SiLU・GELU の向きの条件「σ ≥ 1」は外せるか。

**答え**: ガウスと 1 層箱の実状態では外せる（標準化した分布を固定すれば各分布ごとにも外せる）。分布によらない一様な σ の閾値は無い。§1・§2・§5 E2 の旧い言い方（σ ≥ 1・r ∈ [−4, 0]・98〜100%）はこの節で読み替える。

- **段 1 の十分条件 SC1** [厳密・K 一定・分布によらず]。ψ = φ − relu、q = φ′ − 1[z > 0]、p = P(z > 0)、µ = E[z₊] と置くと、Cov(φ′, φ) は Cov(1[z > 0], relu) = (1 − p)µ（厳密）と 3 つの補正に分かれ、
  (1 − p)µ > min{A·p(1 − p), √(p(1 − p)Var ψ)} + D·P(0 < z < t₀) + µ(E q)₊ + √(Var q·Var ψ)
  なら Cov(φ′, φ) > 0。定数は SiLU・GELU の順に A = sup|ψ| ≈ 0.2785・0.1700、D = sup_{0<z<t₀}(−zq) ≈ 0.1310・0.0812、t₀ ≈ 1.2785・0.7518（−t₀ が φ の最小点）。分布の形を仮定せず、unit の状態ごとに測って判定できる。
- **段 2 の十分条件 SC2** [厳密・K 一定・分布によらず]。P⊥ を {1, z} の直交補への射影、H = 1[z > 0]、R = relu として ⟨P⊥H, P⊥R⟩ > ‖P⊥H‖‖P⊥ψ‖ + ‖P⊥q‖‖P⊥R‖ + ‖P⊥q‖‖P⊥ψ‖ なら段 2 は沈める向き。r = 0 の対称分布では φ(z) − φ(−z) = z・φ′(z) + φ′(−z) = 1 なので段 2 は全 σ で厳密に 0。§2・E2 の「段 1・段 2 とも r ∈ [−4, 0] で正」の段 2 の端点は「非負（r = 0 で 0）」。
- **ガウス** z ~ N(rσ, σ²) [数値]: 段 1 の真の境界の最大は r ∈ [−8, 0]（0.01 刻み）で SiLU 0.8685（r ≈ −2.98）・GELU 0.5231（r ≈ −2.80）。σ ≥ 0.87・0.53 なら段 1 は正（探索域 σ ∈ [10⁻³, 10⁴] で負を検出せず。解析的な全域証明ではない）。σ ≤ 0.5 の深い r に負例が残る。段 2 は GELU の r = −4・−3.75 の σ ≈ 0.5 に小さい負の楔（真の境界 0.5563・0.5586）。
- **各固定分布** [厳密]: 標準化した分布 ζ（E ζ ≤ 0、sd 1、E ζ₊ > 0）を固定して σ → ∞ とすれば SC1 はいずれ成り立つ。ただし σ₀ は分布全体に依存し、平均と sd だけでは一様にできない。
- **H5 だけでは閉じない** [反例]: 質量 0.001 を z = +2、0.2 を −0.5、0.799 を −L に置く生きた三点分布は、r ≈ −2.0 のまま L = 10²〜10⁵（σ 40〜40,075）で Cov(φ′, φ) = −5.98 × 10⁻³（SiLU）・−1.17 × 10⁻³（GELU）。浅い負点と遠い負点の死んだ二点分布も大 σ で負。p と E[z₊]/σ の「下限」だけでも足りない三点分布もある。
- **一様定理** [厳密]: p ≤ p̄ < 1/(1 + 2a₊)（a₊ = sup_{z>0} q₊ ≈ 0.0998・0.1289）と E[z₊] ≥ ρσ を族の全分布に置けば、σ > σ₀(p̄, ρ) で一様に正（p ≤ 1/2 なら σ > 1.023/ρ・0.677/ρ）。ただし課題 1〜200 の実状態で覆うのは SiLU 40/5,611（0.7%）・GELU 208/4,511（4.6%）、課題 300〜1000 は 0 件。ρ = E[z₊]/σ が幅とともに落ちる（SiLU の中央値で課題 10 → 200 に 1.4 × 10⁻³ → 1.4 × 10⁻⁴）ので、H5 の幅の伸びからはこの仮定が出ない。
- **実状態**（1 層 RL-MNIST 784–100–10、1,200 入力、seed 0–1。K 一定の符号統計）[実測]: 課題 1〜200 の生きた unit-state で Cov(φ′, φ) > 0 は SiLU 99.84%（5,602/5,611）・GELU 99.80%（4,502/4,511）、SC1 合格は 90.59%・97.05%。課題 300〜1000 は Cov > 0 が 695/695・216/216、SC1 合格 621/695・200/216。SC1 合格率は幅とともに上がらない。負の 18 件は全部 p = 1/1200（開いた入力 1 個）で、その値は t₀ よりずっと浅い（SiLU 0.012〜0.117・GELU 0.012〜0.202）。
- **同じ平均・sd の敵対分布** [数値]: 2〜4 点分布の探索は、ガウスの σ₀ より上でも、代表 r ∈ [−4, 0] の全点で Cov(φ′, φ) < 0 の分布を見つけた。ガウスの閾値は任意の分布へ移せない。
- **検算** [数値]: 1 活性化あたり 36,201 分布（2〜4 点・混合ガウス・歪んだ経験分布）で「SC1 成立なのに Cov ≤ 0」は 0 件。SC1 の µ(E q)₊ の係数を 1/2 にした変異対照には偽陽性（SiLU 1・GELU 7）が出る。
- まとめ: 実状態で効いている分布によらない根拠は、状態ごとに測った SC1（と SC2）である。H5 は沈降（m = r·s）を運ぶ仮定で、SiLU・GELU の向きを分布によらず閉じる仮定ではない。
