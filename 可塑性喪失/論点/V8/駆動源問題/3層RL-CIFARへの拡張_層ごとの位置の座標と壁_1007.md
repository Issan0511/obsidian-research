## 1. 一言で

- **自己形の向きは 3 層でも壊れない [厳密]。** 第 1 層の自己形の重みは入力依存（版 (B): |g_in|² K_n、版 (A): ρ_n K_n、ρ_n = Σ_j φ2′(z2_nj)² |W3c[:, j]|²）になるが非負のままなので、段 1 の補題（非負の重みの共分散 ≥ 0）はそのまま通る。実測: raw の leaky・ELU の両層で、生きた unit の段 1 の押しは沈める向きか厳密 0（常時点灯 unit）で、逆向き 0%。
- **押しそのものは自己形の文より弱い [実測]。** 3 層では ⟨g_in, p_n − 1/K⟩ の期待に W3 の成長 × 初期の W2 列を通る項が加わり、補題では縛れない。実際の切替の押し S_i = Σ_n K_n φ1′(z1_in)⟨g_in, p_n − 1/K⟩ が沈める向きなのは、確信のある古い関数がある raw で 84〜97%（leaky）・84〜94%（ELU 課題 1〜3）、**std では 37〜67%**（LR std は p_max 1.00 なのに揃わない）、学べなくなった状態（p_max 0.12〜0.14）では半々。
- **相対位置には壁がある [厳密・b = 0]。** x̄ の方向で届く r の下限は −mean(K_n)/sd(K_n)（重みが x̄ に反平行のとき）。raw は −3.83、std は −0.40。raw の ELU・SiLU・GELU の第 1 層は課題 1 の間に壁へ張り付く（r1 −3.6〜−3.75）。std では x̄ の道でどの unit も閉じられない（Φ(−0.4) = 0.34）。第 2 層の壁は −1/cv(K2)（std で −2.0）で、死んだ第 2 層はそこに座る。**r の台地は止め役の印ではない**（壁で死んでいることがある）。生死は p・gate で読む。
- **第 2 層は「入力が h1、平均入力が µ₂」の 2 層の理論と同じ構造 [恒等式 ＋ 但し書き 3 つ]。** z̄2_j = W2[j]·µ₂ + b2_j で bias は 0〜5%。但し (a) K2_n ≥ 0 は保証されない（EL の情報を持つ入力で負）、(b) 2 層に無い上流の項 W2·Δµ₂ がある、(c) µ̂₂ は床の共通成分（ELU の −1、leaky の a·z1）が支配。死（課題 3〜5）までの沈みは W2 の反平行成分の成長が主（ELU raw: W2·µ̂₂ ×10、‖µ₂‖ ×2.2）で、LE だけ上流が主（×7.6 対 ×16.6）。‖µ₂‖ の ×22 は死後。
- **どの層が沈むかは、その層の位置の座標の揃い（壁の深さ）と押しの源で決まる [読み・実測]。** raw は第 1 層（壁 −3.8）が課題 1 に沈む。std は第 1 層に深い壁が無く（−0.4）、leaky は −0.13 → −0.33 と壁へ漂い、ELU・GELU・SiLU は第 2 層の死で凍る（|g|² 1e−6〜1e−47）。第 2 層の入力 h1 は中心化されていないので（‖µ₂‖ 50 → 400〜1200）std でも第 2 層には座標があり、止め役の無い活性化の第 2 層は課題 2〜5 で死ぬ。これが「死ぬのは第 2 層」（cifar5p1・cap_cifar_ee）と、relu_doors で**入力の中心化が無効（0.113、死が第 2 層へ移るだけ）で h1 の中心化が救う（0.987）**理由。
- **活性化は 3 か所で入る**: (i) その層の止め役の尺度 対 歩幅（leaky は §16.17 で r* ≈ −2 に止まる。ELU × Adam の k* ≈ 20 の守りは CIFAR raw の歩幅に負けて課題 1 で壁まで落ちる。SiLU・GELU は止め役なし）、(ii) 次の層の µ₂ の担い手（閉じた側 a·z1 / −1 / 0、開いた側は開いた入力を持つ unit の z1 の尺度）、(iii) 死後に第 1 層の読み出し g_in を float32 の訓練微分で厳密 0 にして bit で凍らせるか（第 2 層の全死の後に W1 が bit で止まるのは ReLU と GELU std だけ。ELU std・SiLU std・LE は bit では止まらない。P173 §F・§2.4 の注）。

## 2. 第 1 層: 自己形の向きは不変、押しそのものは別

### 2.1 重みつきの補題 [厳密]

線形化した softmax の「古い出力を消す一歩」で、f_n のうち unit i の分を g_in h1_in と置く（版 (B)）と、自己の部分は Σ_n w_in φ′(z_in) φ(z_in)、w_in = |g_in|² K_n。§16.8 (3)(a) の経路（W2[:, i] がラベルで育つ）で同じ計算をすると重みは ρ_n K_n で i によらない（版 (A)）。vault の 2 層版の自己形 Σ K_n φ′φ には |v|² の因子は無い。どちらの版も非負。
- 段 1（他の unit が定数を作れる理想化）: 押し = Cov_w(φ′, φ) = ½ Σ_{n,m} w̃_n w̃_m (φ′_n − φ′_m)(φ_n − φ_m)。**非負の重みなら、φ′ が単調非減少・φ が増加のとき各項が非負で ≥ 0**。leaky・ELU α ≤ 1（0 で φ′ が下に跳ばない）で成立。等号は重みの台の上で φ′ が定数のときに限る: leaky なら台が片側に揃うとき、ELU なら台が全部開いた側のとき（閉じた側は e^z が狭義増加なので 2 点あれば正）。**常時点灯 unit（p = 1、leaky・ELU）の自己形は厳密 0**。SiLU・GELU は開いた側でも φ′ が動くので 0 でない。
- 重みが負になるのは K_n < 0（std の 36% の入力）のとき。bias だけの座標（K ≡ 1）に取り直せば非負に戻るが、それは自己形の文で、押しの文ではない（§2.3）。
- 「定数を作れる」の定数が w の重みつき平均と一致するときだけ Cov_w の形になる。3 層では b2 が吸う定数の重みは未指定 [仮定つき]。

S_i = Σ_n K_n φ1′(z1_in) ⟨g_in, p_n − 1/K⟩（課題末の softmax p_n = 古い関数。沈める向き = 正）。生きた unit の正の割合と、古い関数の確信 p_max の平均:

### 2.4 第 1 層の押しの測度は第 2 層のゲートが決める [実測]

w_in の入力にわたる有効数 N_eff/N と |g_in|² の平均: LR raw 0.55 → 0.48・4.4 → 3.1（課題 5 → 50）。ELU raw 0.54 → 0.001・0.76 → 0.007。LE 0.001・6e−23 → 1e−29。ELU std 0.005 → 0.001・4e−4 → 1e−6。第 2 層が閉じた入力では φ2′ ≈ 0 で g_in ≈ 0。**第 2 層が死ぬと第 1 層の押しは（自己形の向きを保ったまま）測度を失って凍る**（[[先生の導出をELU・GELU・SiLUへ拡張_teacher_ledger_act_0924]] の「床なしは蛇口も排水口も閉じて凍結」の 3 層版）。注: script の g2 は float64 なので |g|² 1e−23〜1e−47 は訓練の勾配そのものではない。訓練の微分が float32 で厳密 0 になって第 2 層の全死の後に W1 が bit で止まるのは ReLU と GELU std だけで、ELU std・SiLU std は bit では止まらない（P173 §F）。LE の W1 も課題 21〜50 に毎課題 1〜46 行が動く（相対 2e−8 以下。b1 は bit 不変。1008 の検算: `layer_chimera_cifar_0921` の LE の snap、seed 0〜2）。

## 3. 壁: 相対位置の下限は入力の幾何で決まる [厳密・実測]

bias を除けば z_in = w·x_n。w を x̄ に反平行にすると z_in = −c·(x̄·x_n) で、r = mean z / sd z = −mean(K)/sd(K)。これより下には x̄ の道では行けない（他の方向は分散を増やすだけ）。
| 層・条件 | 壁 −mean(K)/sd(K) | Adam の sign 歩で見た壁 −mean/sd(x_n·sign(x̄)) | 実測の r（中央値） |
|---|---|---|---|
| 第 1 層 raw | −3.83 | −3.85 | ELU −3.62・SiLU −3.67・GELU −3.74・EE −3.65・EL −3.63・LE −3.44（死・凍結: 壁に張り付く）。leaky −2.2（壁の内側: 止め役） |
| 第 1 層 std | −0.40 | −0.37 | LR −0.13 → −0.33（壁へ漂う）。ELU・GELU・SiLU −0.10（凍結） |
| 第 2 層 std（K2 の cv 0.49〜0.50） | −2.0 | — | ELU −1.99・SiLU −2.01・GELU −2.08（死。gate 1e−5 以下・z2 < −13.8 が 100%）、leaky −1.36（内側・生存） |
| 第 2 層 raw | LL・LR −3.5〜−4.2、LE −3.7、ELU −2.6 → −20（K2 の cv が縮む） | — | LL・LR −1.9（内側・生存）。LE −3.7・ELU −18（壁で死） |
- 「幅が伸びて沈む」の上限が壁。死んだ層は壁に座り、生きた leaky の層は壁の内側で止まる。**r の台地だけでは「止まった」と「壁で死んだ」を区別できない**（ELU std の第 2 層 −2.0 は壁）。
- raw の第 1 層の「課題 1 の間の沈み」は壁までの落下で、速さは歩幅（‖x‖₁ × 更新数）。ELU × Adam の守り（k* ≈ 20）は 1 層・2 層箱では効くが、CIFAR raw の歩幅に負ける（inventory: lr₁/16 で全閉 74〜87% → 5〜12%）。場合分けは「止め役の有無」でなく**止め役の尺度 対 歩幅**。
- bias の道が効かない理由は「1 パラメータで遅い」ではない（上限は η × 30,000 更新 = 30/課題）。b1 の実測は −0.06〜−2.8（sd1 85〜200）で r1 への寄与 ≤ 0.03。効かないのは押しが揃わないから（§2.3 の std 28〜58%）。

## 4. 第 2 層: µ₂ の 2 層理論と上流の項

µ₂ = 閉じた側 ＋ 常時点灯 unit の開いた側 ＋ それ以外の開いた側（課題 50、ノルム。座標が重なるので直交分解ではない）:

## 8. 言えないこと・未導出

- **3 層で leaky の第 1 層に §16.17 の項が同じ形で効くか** [未導出]: 雑音は W2[:, i] → φ2′ → W3 を通る。Γ_n > 0 の対応物が要る。LL の r1 −2.2 は 2 層と同じ数だが導出ではない。
- **課題 1 の落下の速さ**: raw の floor-less の第 1 層が課題 1 の間に壁まで落ちるのは歩幅（‖x‖₁ × 更新数）の事件で、模型の期待の押し（課題の終点の形）ではない [未導出]。向きだけが模型の文。
- **押しそのものの向き（std）**: 自己形は 100% でも実際の S は 28〜58%。W3 の成長 × 初期の W2 列の項の符号は縛れていない [未導出]。
- **常時点灯 unit が +x̄ へ回る**（ELU raw・EE・LE）: 自己形の押し 0 では予測されず、Adam の sign 歩の偏りの読み [候補]。なぜ 1〜2 個（raw）か 18 個（LE）かは言えない。
- **GE/GG の b2 が 0 へ縮む**理由 [未導出]（候補: h1 ≡ 定数で第 2 層の出力は定数、損失への効きは logit の平均だけで b3 が吸う）。
- **壁の値そのもの**は入力の幾何（raw の全画素正、std の K の cv、第 2 層の床の共通成分）で、理論の外から与えられる量。
- 死の閾値: script の z2 < −16.64 は torch の expm1-ELU の値で、この箱のエンジン（battle・キメラ）は F.elu（訓練の微分は e^z。出力 + 1 の形ではないので −16.64 で 0 にはならない。`src/layer_chimera_cifar_0921.py`）。S-A の ELU −13.8156・GELU −5.395 は |φ′| < 10⁻⁶ の閾値（`specs/spec_layer_chimera_cifar_0921.md` の Q。ln 10⁻⁶ = −13.8155）で、訓練微分の厳密 0 の閾値ではない。両方の列を出し、結論（100%）は変わらない。
