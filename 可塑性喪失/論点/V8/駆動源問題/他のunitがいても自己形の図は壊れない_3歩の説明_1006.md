# 他の unit がいても自己形の図は壊れない — 3 歩の説明（1006。3 歩目は 1006 夜に訂正）

親: [[駆動源問題_説明のまとめ_1006]] / 長い版: [[駆動源問題_Issaへの説明_1006]] §2⁗ / 土台: [[駆動源の土台_Issaの流れ_0930]] / 作成: 2026-10-06 / 状態: **説明（Issa「やっぱまだ全然わかんなくて助けて」→「Vault にしてください」）**

> 読み方。「容量」「谷底」「橋」の語を使わず、Issa の自己形の図だけから、他の unit がいるときの押しの向きと相対位置を 3 歩で出す。容量（log det）は 2 歩目の引き算を全 unit 分まとめて書いた名前にすぎない。
> 格: [厳密]・[計算]・[実測]・[候補]。模型 = 切替の最初の一歩の、古いラベルについての期待。実状態 = a0.1 課題 40・a0.3 課題 100（台帳 P162〜P165）。

## 0. 出発点: 自己形の図（Issa）

- 切替の押しは「古い出力を消す一歩」。新しいラベルは乱数で平均 0 なので、新しい課題の勾配のうち毎回同じ向きに効くのは「古い出力を小さくせよ」だけ。
- unit 1 個にとって「自分の出力を小さくする」とは:
  - 開いた入力（z > 0）では出力は z。z を下げる → **下げる力**。
  - 閉じた入力（z < 0）では出力は a·z（小さい負）。0 に近づけるには z を上げる → **上げる力（浮力）**。出力が a 倍・勾配も a 倍なので効き目は a²。
- 合わせると自己形 Σ_n K_n φ′(z_n)φ(z_n) = 下げる力 − 浮力（K_n = x̄·x_n > 0）。これは「自分の出力の二乗 ½Σφ² の位置についての傾き」[厳密]。
- 沈むと開いた入力が減って下げる力が弱まり、閉じた入力が増えて浮力が強まる。釣り合いは z ~ N(m, σ²)・相対位置 r = m/σ で φ(r) + rΦ(r) = a²[φ(r) − rΦ(−r)]（φ, Φ は標準正規の密度・分布）[厳密・ガウス]。

a = 0.1（幅 = 1 の単位）:

| r | 開いた入力 | 下げる力 | 浮力（× a²） |
|---|---|---|---|
| 0 | 50% | 0.40 | 0.004 |
| −1 | 16% | 0.083 | 0.011 |
| −1.72 | 4.3% | 0.017 | 0.017 ← 釣り合い |
| −2.5 | 0.6% | 0.002 | 0.025 |

r* は a = 0.1 で −1.72、0.3 で −0.94、0.5 で −0.55。ReLU（a = 0）は浮力が無く止まらない（死ぬ）。

**問い**: 古い出力は全 unit の合計なのに、この図は unit 1 個の話。他の unit がいても同じ結論か。

## 1 歩目: 他の unit がいると、消されるのは全体の出力

古い出力 f = Σ_j v_j φ_j（φ_j = unit j の出力を入力について並べたベクトル、v_j = 読み出し）。unit 1 の位置を動かしたとき unit 1 の出力が動く向きを u₁ = (K_n φ′(z_1n))_n と書くと、出力は v₁u₁ の向きに動くので

　押し₁ = v₁⟨u₁, f⟩ = v₁²⟨u₁, φ₁⟩ ＋ Σ_{j≠1} v₁v_j⟨u₁, φ_j⟩

第 1 項が図そのもの（⟨u₁, φ₁⟩ = 自己形）。第 2 項は「他の unit の出力」を unit 1 が消しにいく分で、符号は v₁v_j 次第。これが逆向きに大きければ図は壊れる。

## 2 歩目: 読み出しは一緒に当てはめられたので、他で作れる分が引かれる

v は全 unit で同じラベル Y を当てた結果。読み出しだけで当てはめる最小二乗（当てはめが済む極限）なら、|Y − Φv|² を最小にする条件 ΦᵀΦv = ΦᵀY から v = (ΦᵀΦ)⁻¹ΦᵀY = MY（**v はラベルの 1 次式**）、f = Φv。期待値は古い課題の乱数ラベルについて取る:
- E[v] = M·E[Y] = 0。読み出しの向き自体は課題ごとにでたらめ。
- しかし押し v₁⟨u₁, f⟩ = v₁ Σ_j v_j⟨u₁, φ_j⟩ は v の 2 次式なので、平均は 0 にならない。要るのは積の平均で、ラベルが入力ごとに独立・同じ分散（E[YYᵀ] = σ²I）なら

　E[v vᵀ] = M E[YYᵀ] Mᵀ = σ² M Mᵀ = σ²(ΦᵀΦ)⁻¹

**具体例**（入力 2 個・unit 2 個）。unit 1 は両方の入力で開く φ₁ = (1, 1)、unit 2 は入力 1 だけ φ₂ = (1, 0)。ラベル y₁, y₂ は独立。当てはめると、入力 2 は unit 1 しか担えないので v₁ = y₂、入力 1 は v₁ + v₂ = y₁ なので v₂ = y₁ − y₂。E[v₁v₂] = E[y₂(y₁ − y₂)] = −σ²（負）。式でも ΦᵀΦ = [[2, 1], [1, 1]]、逆行列 [[1, −1], [−1, 2]] で一致。unit 1 への押しの期待は E[v₁⟨u₁, Y⟩] = σ²·u₁₂ で、**入力 2（unit 1 だけが担う入力）の分だけが効く**。入力 1 の分は unit 2 が消すので、unit 1 には来ない。φ₁⊥ = (1, 1) − (1, 0) = (0, 1) とも一致する。

unit が 2 個なら非対角は −σ²⟨φ₁, φ₂⟩/det で、**似た 2 個の読み出しは負に相関する**（同じ仕事を分け合うので、片方が正に振れればもう片方は負に振れる）。
- なぜ負か（Issa「なんで」）: G = [[A, B], [B, C]]（A = |φ₁|²、B = ⟨φ₁, φ₂⟩、C = |φ₂|²）の逆行列は (1/det)[[C, −B], [−B, A]]、det = AC − B² > 0（コーシー・シュワルツ）。非対角は −B/det で、B と逆の符号 [厳密]。意味は二重取りの防止: v = G⁻¹(ΦᵀY) で、ΦᵀY は各 unit とラベルの相関。unit 1 がラベルと相関すると似た unit 2 も相関して見えるが、その分は unit 1 がもう説明しているので、v₂ は下げられる。
- unit が多いとき: 非対角の符号は生の内積でなく、他の全 unit で説明できる分を両方から引いた残りどうしの相関（偏相関）と逆 [厳密: [G⁻¹]_{ij} = −ρ_{ij·他} √([G⁻¹]_{ii}[G⁻¹]_{jj})]。「他を除いても似ている」組だけが負に相関する。2 歩目の結論 E[押し₁] = σ²⟨u₁, φ₁⊥⟩/|φ₁⊥|² は、この符号に関係なく成り立つ。
- なぜ符号に関係ないか（Issa「解説」）: E[押し₁] = σ²⟨u₁, ψ₁⟩、ψ₁ = Σ_j [G⁻¹]_{1j}φ_j。G⁻¹G = I から ⟨ψ₁, φ_k⟩ = δ_{1k}: ψ₁ は φ たちの組み合わせで、他の全 unit と直交し、φ₁ との内積が 1。そういうベクトルは φ₁⊥/|φ₁⊥|² しかない [厳密。使ったのは G⁻¹G = I だけ]。非対角は「他の unit で φ₁ をいちばんよく作る組み合わせ Σ c_jφ_j（重回帰）」のレシピで、[G⁻¹]_{11} = 1/|φ₁⊥|²、[G⁻¹]_{1j} = −c_j/|φ₁⊥|²。φ_j を足して使うなら（c_j > 0）負、引いて使うなら（c_j < 0）正。どちらでも ψ₁ =（φ₁ − いちばんよい再現）/|φ₁⊥|² = 残り。
- 例（入力 3 個・unit 3 個）: φ₁ = (1, 1, 0)、φ₂ = (1, 1, 1)、φ₃ = (1, 0, 1)。⟨φ₁, φ₃⟩ = 1 > 0（似ている）なのに、いちばんよい再現は φ₁ ≈ φ₂ − 0.5φ₃（φ₃ は引いて使う）で、[G⁻¹]_{1·} = (2, −2, +1)、非対角の 1 つが正。それでも Σ_j [G⁻¹]_{1j}φ_j = (1, 0, −1) = φ₁⊥/|φ₁⊥|²（φ₁⊥ = (0.5, 0, −0.5)）[検算済み]。押しは σ²(u₁₁ − u₁₃): 他では作れない「入力 1 にあって入力 3 に無い」形だけが効く。これを 1 歩目に入れると

　**E[押し₁] = σ² ⟨u₁, φ₁⊥⟩ / |φ₁⊥|²**　[厳密。乱数の小さい系で検算: モンテカルロ 0.2710 対 式 0.2702]

φ₁⊥ = φ₁ から「他の全 unit の出力の組み合わせで作れる分」を引いた残り。**図の「自分の出力 φ₁」を「他では作れない残り φ₁⊥」に置き換えたものになる。** 他の unit と重なっている分は、その unit たちが消すので、自分は消しにいかなくてよい。他の unit の効き方はこれだけ。

- unit 1 個なら φ₁⊥ = φ₁ で、図に戻る。
- **記号の注意**: このノートの Φ は unit の出力を並べた行列（列が φ_j）。他のノートで容量を Φ と書いているのとは別物で、ここでは容量を C と書く: C = ½ log det(λ + ΦᵀΦ)（読み出しの道だけの場合）。出力ベクトルが張る平行体の体積の対数。
- **容量が出てくる場所**（Issa「ここで容量の Φ が登場するわけね」）: G = ΦᵀΦ + λ（出力どうしの内積の表）とおくと、log det の微分は d log det G = tr(G⁻¹dG) なので ∂C/∂t₁ = Σ_j [G⁻¹]_{1j}⟨φ_j, u₁⟩。一方、読み出しのラベルとの相関は E[vYᵀ] = σ²G⁻¹Φᵀ（リッジ v = G⁻¹ΦᵀY）なので、ラベルの分を消す押しの期待は E[v₁⟨u₁, Y⟩] = σ²Σ_j [G⁻¹]_{1j}⟨φ_j, u₁⟩。**同じ逆行列 G⁻¹ が両方に出るので、E[押し] = σ² ∂C/∂t₁** [厳密・どの λ でも]。λ → 0 では傾きは ⟨u₁, φ₁⊥⟩/|φ₁⊥|²（体積 = 底辺 × 高さ、高さ = φ₁⊥）。「押し = 容量を下げる向き」はこの一致のこと。
- λ > 0 での正確な位置: G⁻¹ がそのまま出るのは E[vYᵀ]（ラベルとの相関）の方で、E[v vᵀ] 自体は σ²G⁻¹ΦᵀΦG⁻¹。消す相手を当てはめた出力 f = Φv にすると、ラベルとの差（当て残し）の分だけ ∂C からずれる（[[駆動源問題_Issaへの説明_1006]] §2″）。λ → 0 で両者は一致する。
- 仮定: 読み出しだけで当てはめる（隠れ層の学習は 3 歩目の注で）・当てはめが済む・ラベルは入力ごとに独立。逆に、古い出力は当てはめ済み（f ≈ Y。隠れ層も使って当てた）で、読み出しだけが各 unit の相関で育った（v_i ∝ ⟨φ_i, Y⟩、[[押しの向き_文の型を替えた定理_未導出4項目_1005]] §16.8 の仮定）なら、E[押し₁] ∝ ⟨u₁, φ₁⟩ で引き算は起きず、押しは図のまま。実際の訓練はこの 2 つの間にある [候補]。

## 2.5 歩目: E[押し] がなぜ自己項の向き（沈む向き）になるか（Issa「E[押し] は理解しました。これが自己項の向きになるのはなんで？」）

E[押し₁] ∝ ⟨u₁, φ₁⊥⟩。u₁ = K × ゲート（開いた入力で 1、閉じた入力で a）、φ₁⊥ = 自分の出力のうち他で作れない部分。**沈む ⟺ 「他で作れない自分の形」がゲートの開いた所で正。** 他の unit が何を作れるかで 3 段に分かれる。

1. **unit 1 個（他で作れるのは定数 = bias だけ）**: ⟨u, φ − φ̄⟩ = ゲートと出力の共分散（K ≈ 一定のとき）。ゲートも出力も z の増加関数なので、共分散は必ず ≥ 0（チェビシェフの和の不等式）[厳密]。**開き具合によらず必ず沈む。これが「自己項の向き」。**
2. **他の unit が入力の 1 次式を作れる（leaky の線形の道）**: φ⊥ から 1 次式が引かれて折れ目の形 relu(z)⊥ だけが残り、u の a·K の部分（1 次式）は効かなくなる。押し ∝ (1 − a)² ⟨1_開⊥, relu(z)⊥⟩（1 次式を引いた後の「ゲート」と「折れ目」の共分散）。符号は開き具合で決まる [厳密: [[押しの向き_証明の進み_門の道と段ごとの格_1002]] §16.23 (5)、正 ⟺ (1 − p)μ₊σ₋² > p|μ₋|σ₊²。ガウスでは p < 1/2]:

| 開いた割合 | 0.02 | 0.16 | 0.31 | 0.46 | 0.54 | 0.69 | 0.84 |
|---|---|---|---|---|---|---|---|
| unit 1 個 | + | + | + | + | + | + | + |
| 1 次式を他が作れる | + | + | + | + | − | − | − |

（z ~ N(m, 1)、20 万点の数値。1006）

   なぜ半分が境目か: 少ししか開いていない unit の relu(z) は開いた入力の上の「こぶ」で、1 次式ではほとんど近似できないので、残りは開いた所で正 → ゲートと重なる → 沈む。ほとんど開いている unit の relu(z) はほぼ直線 z で、1 次式を引くと残りは「閉じた側の欠け」（閉じた入力の上で正、開いた入力ではわずかに負）→ ゲートと逆 → 浮いてさらに開く（§16.23 (5) の山の開いた側）。**実網の unit は 0.6〜6% しか開いていないので正。これが前提 (A)「半分より多く開いていない」の中身。**
   **折れ目の形をもう一段かみくだく**（Issa「1 次式が引かれて折れ目が残る、があんまり分かってない。もしかして下に凸なのがいいのかな」）:
   - 「1 次式が引かれる」= 他の unit が、自分の出力のいちばんよい 1 次式の近似を肩代わりする。a·z はそのまま 1 次式なので全部持っていかれる。relu(z) は 1 次式でないので、近似の直線の分だけ持っていかれ、残りが**折れ目**。
   - relu(z) をいちばんよく近似する直線の**傾きはちょうど開いた割合 p**（z がガウスなら Cov(z, relu(z)) = p·Var(z) で厳密）。折れ目 = relu(z) − p·z − 定数 [厳密・数値で確認]。
   - 押し = 折れ目（入力のいる所で重みをつけたもの）の**開いた側の面積**。ゲートの a の部分と定数の部分は 1 次式なので折れ目と直交して効かず、残るのは「開いた入力で 1」の部分だけだから。値は (1 − 2p)φ(m) + m·p(1 − p)（z ~ N(m, 1)）[厳密・数値で確認]。
   - p が小さい: 直線はほぼ水平 → 折れ目 ≈ 開いた側のこぶ → 開いた側の面積が正 → 沈む。p が大きい: 直線の傾き ≈ 1 → 折れ目 ≈ relu(z) − z = 閉じた側の欠け → 開いた側の面積が負 → 浮く。p = 1/2 で 0。
   - **下に凸について**: 半分正しい。折れ目ができるのは relu が下に凸（閾値で傾きが上がる）だから。unit 1 個なら、下に凸 ⇒ ゲート（= 傾き）が z とともに増える ⇒ ゲートと出力の共分散 ≥ 0 ⇒ どの p でも沈む（1 の段）。しかし 1 次式を他が持っていくと、relu(z) と relu(−z) は直線 z の分しか違わないので折れ目は同じになり、折れ目は「どちらが開いた側か」を区別しない。決めるのは折れ目の重さがどちらに乗るか = 少数派の側。**下に凸 ＋ 入力の大半が曲がり目より下（開いているのは少数）⇒ 沈む。** 上に凸の活性化なら 1 の段の符号から逆になる。

3. **他の unit が自分の折れ目の一部まで作れる（開いた入力が重なる unit がいる）**: 並びを無作為にすれば、押しは 2 の値の正の倍率に縮むだけ（[[押しの向き_文の型を替えた定理_未導出4項目_1005]] 定理 6）[厳密]。逆にするには、自分の閾値の入力と開いた入力をまたいで開く unit（橋）が 10 個以上要り、実網には無い（最大 5、できても 1 課題で壊れる）[実測]。

実測（後期）: 容量の読み出しの分で沈める向きの unit は 99〜100%。

## 3 歩目: leaky では、残るのは少数派の側の折れ目（1006 夜に訂正）

**分解は一通りではない**（Issa「分解で正のほうが残るのがわからないの？なんで負じゃないの？」）:

　leaky(z) = a·z ＋ (1 − a)·relu(z) = z ＋ (1 − a)·relu(−z)

前者は「傾き a の直線 ＋ 正の側だけの足し分」、後者は「傾き 1 の直線 ＋ 負の側だけの足し分」。どちらも正しい（前者: z > 0 で a·z ＋ (1 − a)·z = z、z < 0 で a·z。後者: z > 0 で z、z < 0 で z ＋ (1 − a)·(−z) = a·z）。だから「どちらの側が残るか」は分け方からは決まらない。1006 夕にこの節で「浮力は全部 a·z の側に乗っているので、a·z を他の unit が持っていくと浮力が消え、下げる力は 9 割残る」と書いたのは前者の分け方に依っていた（撤回）。

**一意に決まるもの**: 他の unit が作れるのは入力の 1 次式。持っていかれるのは「φ をいちばんよく近似する 1 次式」で、これはどう書いても同じ。残り（折れ目）= φ − その近似、も同じ（2 つの書き方の差は直線 z だけ）。自分の z だけで近似する理想化（[[押しの向き_証明の進み_門の道と段ごとの格_1002]] §16.23 (5)）では:
- いちばんよい直線の傾き = a ＋ (1 − a)p（p = 開いた割合。z がガウスなら厳密。実状態でも a0.1 の後期で 0.109 対 0.106、a0.3 で 0.339 対 0.334 などと一致）。
- 直線は入力の多い側に合わせて引かれるので、外れて残るのは少数派の側。p が小さい → 傾き ≈ a（閉じた側に合う）→ 残りは開いた側のこぶ。p が大きい → 傾き ≈ 1（開いた側に合う）→ 残りは閉じた側の欠け。
- 押し = (1 − a)² ×（残りの、入力のいる所で重みをつけた開いた側の面積）（2.5 歩目）。p < 1/2 で正（沈む）、p > 1/2 で負（浮く）。

**正の側が残るのは、開いた入力が少数派だから**で、分け方のせいではない。実網は p = 0.6〜6%。

**実測**（後期、両方の層の核の E）: 1 次式 a·z は relu(z) の 0.012（a0.1）・0.022（a0.3）倍しか残らない — E が 1 次式を消すことの裏付け。容量の読み出しの分で沈める向きの unit は 99〜100%（自己形のままでは 5〜13%）[実測 P163・P164]。

注: 両方の層の模型（隠れ層も当てはめに使う）では、2 歩目の式は逆行列 (λ + 𝒦)⁻¹ を使った形になり、leaky では自分の重みの道が自分の出力と同じ向きを含むので、λ → 0 のきれいな射影にはならない。だから 3 歩目は実測で確かめている。

## だから

1. **向き**: 他の unit が直線を持っていくと、残るのは少数派の側の折れ目。開いた入力が半分より少なければそれは開いた側で、押しは沈める向き。これが「押しは自己項の向き」。
2. **相対位置**: 自分の z の直線を全部持っていかれると、p < 1/2 では押しは常に正で、釣り合いの点が無い（止まらない）。実測 −2.20（a0.1）・−1.60（a0.3）は図だけの −1.72・−0.94 より深く、「一部だけ分担されている」と読める [候補・未導出]。1006 夕に載せた括り −2.99・−2.13 は「持っていかれるのがちょうど a·z」と置いた計算で、分け方に依っていたので取り下げる。
3. **自分にしか作れない出力**: 1006 夕に「relu の部分の割合が 10 課題で 0.80 → 0.04」と書いたのも分け方の産物（撤回）。一意な量（自分の z のいちばんよい直線で説明できない出力の分散の割合）で測り直すと、課題 2 → 3 → 5 → 10 → 40 → 100 で a0.1 は 0.17 → 0.36 → 0.36 → 0.17 → 0.18 → 0.20、a0.3 は 0.08 → 0.13 → 0.09 → 0.06 → 0.07 → 0.09 で、0 には向かわない。「LoP = 出力が 1 次式に近づくこと」も撤回。

## 補足

- 初期（課題 2、全 unit が広く開いている）は逆に relu の部分どうしが重なっている（1 次式より relu の側が多く引かれる）。それでも沈める向き（容量の読み出しの分 100%）で、初期の崩壊は図の下げる力がそのまま運ぶ（[[押しの向き_文の型を替えた定理_未導出4項目_1005]] §16.8）。
- 他の unit がこの向きを逆にできるか、のもう 1 つの道（ゲートの道の分。谷底・橋）は [[駆動源問題_Issaへの説明_1006]] §3〜§7。実網では起きない。この説明には要らない。
- 1006 の会話で、2 歩目の式を一度 E[v_i v_j] = σ²[(ΦᵀΦ + λ)⁻¹]_{ij} と書いたが、λ > 0 では正しくは σ²G⁻¹ΦᵀΦG⁻¹（G = ΦᵀΦ + λ）。ここでは当てはめが済む極限（λ → 0）で書いた。
