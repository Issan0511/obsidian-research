## 0. 一言で

- ゴール（Issa）: 「分布が負に偏る（unit が沈む）ことを厳密に言う」。
- **「どの unit も、今、沈む向きに押される」は定理にならない。** 反例は、似ていない unit どうし、実データの特徴を仮定に置いた系にもある [反例・模型]。
- **代わりに「行き先」は言えた。** 押しの期待は容量を下げる向き。ゲートの道だけの容量の谷底は「全部の unit が完全に閉じた状態」だけ [厳密・模型]。読み出しの道（自己項の浮力）を入れると、unit 1 個を動かしたときの谷底は「全部の入力が 0 のすぐ下」の有限の深さになる。a 0.1 の実状態で m/幅 ≈ −3 [厳密＋数値・模型]。
- **反例の正体は、ほぼ 1 つにまとまった。** leaky の閉じた側はどの unit も「a × 入力の 1 次式」なので、ほかの unit の閉じた側は全部まとめて線形の道になる。その道が強いと、自己項の保証の前提（明るさ K_n > 0 = 平均入力が効く）が打ち消される。
- 実状態は、今の押しが全 unit で沈める向き。谷底（−3）より上（−2.2）にいる。この差は、ミニバッチの揺らぎの持ち上げ（§16.19）と向きが合う [実測・模型]。
- 反例を除く素な仮定は、まだ見つかっていない。

## 1. 言葉と模型

- 模型: 1 層の網。第 1 層だけ当てる。読み出しは固定（1 方向。unit の強さ γ_i = 読み出しの 2 乗）。二乗誤差・リッジ λ・ガウスのラベル。「当てはめが済む極限」は λ → 0。
- **押し**: 課題の切替の最初の一歩で、unit の位置（重みの、平均入力の向きの成分）が動く量の期待。正 = 沈める向き。
- **揃い**: 押しの式で、網が当てた値の代わりにラベルそのものを使った量。当てはめが済めば押しと一致する。
- **容量** Φ = ½ log det(λ + 核): 網がラベルに従える度合い。当てはめが済む極限では、押しの期待はちょうど容量を下げる向き [厳密・模型]。
- **ゲートの道**: 第 1 層の重みがゲートを通して出力を動かす道。**読み出しの道**: 読み出しの重みが活性を通して出力を動かす道。
- **自己項** = unit 単独（閉じた側の a 倍の分 = 浮力を含む）。**残り** = 全体 − 単独。
- **当て残し**: 課題の終わりに網が当てられていないラベルの部分（模型ではリッジ λ で表す）。
- 仮定 (A) = 半分より多く開いていない。(B) = 複製（ゲートの模様がほぼ同じ unit の組）がいない。

## 3. 反例でわかったこと（定理にならないもの）

| 言いたかった文 | 何が破るか | 格 |
|---|---|---|
| 当てはめが途中でも、ほかの unit がいても沈める向き | unit が極端に弱い（強さの比 4,900）。平均入力が強くても（cos ≥ 0.9）ほかの unit がいると逆 | 反例（Codex） |
| 全部の unit の押しの和は沈める向き | 複製の組・数個の unit の集団で逆 | 反例（Codex・別セッション） |
| 近い重みが無ければ（開いた入力の重なりが小さければ）よい | 明るい入力 1 個を共有する 2 個（重なり 1/6）で、今の模様の容量 < 完全に閉じた模様 | 反例（Codex。整数の計算で確認） |
| 開いた入力を 1 個も共有せず、重みの向きも逆ならよい | a > 0 では全部で逆の例（型 C）。穏当な系でも押しが逆の系は a 0.1 で 0.09%、0.3 で 1.7%、0.5 で 5.9% | 反例（検証役） |
| 押しはいつも、あるポテンシャルを下げる | ちょうど下るポテンシャルは無い（固有値を全部上げる状態がある）。近似は「Φ ＋ θ × 当て残しの項」で、無作為な対の符号の 99.6% が合う | 反例＋数値 |
| 実データの特徴（非負・平均入力が強い・明るさがそろう・多く高次元）と (A)・(B) を仮定に置けばよい | ゲートの道の模型では全部の符号に反例。読み出しの道を入れると 3 分の 2 以上は消えるが、14〜34% は残る | 反例・模型 |

- 逆向きは **unit 1 個では起きない**（押しの大部分を持つ unit だけ残すと、70 状態すべてで正）。残り（ほかの unit）が共有の核を通して作る [数値・検証役]。
- 状態の量で反例を除く候補（組の相対の容量 μβ_max、強さに依らない比 ρ、各入力で開いている unit の強さの割合 < ½）は、どれも実状態と反例を分けられなかった [数値]。

## 4. 型 C の正体（/goal）

- 型 C: 入力 1 次元・unit 2 個・向きが逆・開いた入力を共有しない、のに押しが逆（a 0.3・0.5）。
- 説明（既存の道具だけ）:
  1. 閉じた側はどの unit も a × 1 次式なので、相手の閉じた側が線形の道になる [恒等式]。
  2. 線形の道が強いと、容量は 2 次モーメントの並列和の山になり、「半分」は開いた数でなく 2 次モーメントで測る（§16.23 (5)）[厳密・模型]。
  3. 逆を向く unit は、開いた数では 30% だが、明るい入力を開いているので 2 次モーメントでは 69%。山の開いた側にいる [数値]。
  4. ほかの unit を線形の道 1 本に替えても逆のまま（別セッションの介入）。
- a 依存の決め手は閉じた側の強さ（a² × ほかの unit の強さ ÷ リッジ）。
- 読み出しの道を入れると、型 C で残る逆向きは a 0.5 の 1 個（−0.37）だけ。
- 未導出: なぜ重みの和が 1 を超えるのか（必要条件「相手の開いた入力に乗る正味の重みが負」と、別セッションの言い換え「unit の前活性と全部開いたときの出力が事後で負に相関する」まで）。
- 【訂正】反例を「浮力の差の道」と「開いた分の道」に分ける二分は、割り方次第だった。型の区別は介入でしか付けられない。

## 5. 当て残し（②）は、実状態でなぜ無害だったか（/goal）

- 悪さの式は 2 の 10。悪さをするのは「β/K_n」と「K_n𝒰/E[L]」の積が 1 に届くとき。既知の反例 38 個のうち 34 個がこの型。
- 実状態では、その積の最大は 0.54。小さい 2 項は揃いの 3.5% 以下。E[L] > 0 の対で押しが逆なのは 26,108 対中 1 対だけ。unit ごとの和は全部正 [実測・模型]。
- **なぜ積が小さいのかは未導出**（測定だけ）。
- 厳密な十分条件は 3 つ（unit 単独・弱い unit の極限・4 条件の組）。どれも、ほかの unit がいる実状態の大半を覆う素な条件ではない。

## 6. 負の偏りについて、今言えること

| 段 | 言えること | 格 |
|---|---|---|
| 行き先（ゲートの道だけの容量） | 全部の unit が完全に閉じた状態が唯一の谷底。深さは決めない | 厳密・模型 |
| 行き先（両方の層の容量、unit 1 個を位置の向きに動かす） | 谷底は「全部の入力が 0 のすぐ下」。a 0.1 の実状態で 82/82 unit、m/幅 −2.97。a 0.3・0.5 では開いた入力 1〜2 個の所にずれる unit がいる | 厳密（深さが有限）＋数値・模型 |
| 今の向き | 実状態は全 unit で沈める向き（両方の層の容量でも 99〜100%） | 実測・模型。定理ではない |
| 釣り合いの位置 | 実網は m/幅 −2.2（a 0.1）。揺らぎを抜いた網は −2.9 で止まり、上の谷底と分布の水準で重なる | 実測 |
| 全部の重みを動かすと | 容量を下らせると重みの大きさが 0 に縮む（形は「数個の入力が 0、残りは負」） | 数値・模型 |

- 注意（検証役）: 揺らぎを抜いた網でも、完全に閉じた unit が浮き上がる様子は見えない。深さが合うのは「開いた入力が無くなると沈める力が消える」でも説明でき、浮力の証拠ではない。
- 実網が容量を下る（Adam・CE・ミニバッチ）ことは示していない。

## 7. クローン化について

- 複製（クローン化）は谷底ではなく、谷底へ行く途中の段（谷底の定理）。
- ぴったり同じ 2 個は、強さが等しくないと保たれない [厳密・模型]。実網の強さは unit ごとに 4〜6 倍違う。
- 重みが近くない組でも、小さい方の開いた入力の 3 割以上が相手に含まれていれば、そろうことがある（別セッション CF10b）。
- 実網には、似た組はいない（重みつきの似かたでも 0.8 以上は 0%）。

## 8. 今晩の訂正・撤回

- 「1（押しそのものの符号）は簡単」→ 有限の当てはめで反例（Codex）。
- 「両方の応答が 0 以上・0 ≤ β ≤ K_n なら、ほかの unit がいても逆にならない」→ 反例 A（無作為な探索で 0 だっただけ）。
- 「全体で見れば残りは打ち消す」→ 複製の組で全体も逆（Codex）。
- 「複製は容量を下げる」→ ぴったりの複製には下げる余地が無い。逆に動くのは、なりかけの組が引き寄せ合う間だけ（Issa の指摘）。
- 「谷底は全部沈んだ状態 1 つ」→ ゲートの道だけの容量の話。読み出しの道を入れると深い所は谷底でない（Issa の指摘「自己項の浮力を忘れていないか」）。
- 「半分より多く開いた unit は全開へ走る」（別セッション）→ 取り下げ（踊り場だった）。
- 「反例は浮力の差の道と開いた分の道に分かれる」→ 割り方次第（監査役）。
- 「Σw > (1 + a)/(2a)」を仕組みとして書いた → 閉じた入力では逆向きの定義の言い換え。
- 「実データの強さの比 5〜33」→ 代用の模型の重みの比だった。読み出しの大きさそのものでは 6 倍以内。
- 「unit が多く強さの比 ≤ 10 なら全体の逆は見つからない」（探索役）→ 検証役が unit 40〜100 個の反例を作って否定。

## 9. 残っている穴

1. 実状態と反例を分ける素な仮定。検証役の見立てでは、全体の符号を決めているのは「ほかの unit がどれだけ閾値の近くにいるか」。結論の言い換えに近いので、そのままは置けない。
2. 型 C の閉じた対で、なぜ重みの和が 1 を超えるか。
3. 当て残しの積が、実状態でなぜ小さいか。
4. 実網が両方の層の容量を下るか。揺らぎの持ち上げ（§16.19）と、読み出し v の動き（Adam のブレーキ）を理論に入れること。
5. 多クラス・CE・Adam。何課題もかけて偏る過程。
