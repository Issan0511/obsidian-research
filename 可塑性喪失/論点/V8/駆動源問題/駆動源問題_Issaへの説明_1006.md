## 0. 語

| 語 | 中身 |
|---|---|
| 前活性 z_in | unit i に入力 n を入れたときの z = w_i·x_n |
| ゲート d_in | φ′(z_in)。leaky なら開いて 1、閉じて a。unit i が入力 n で「学べる度合い」 |
| 位置 t_i（m_i） | 重み w_i を平均入力 x̄ の向きに動かす量。m = w_i·x̄。全部の z_in が t·K_n（K_n = x̄·x_n > 0）だけ一緒にずれる。沈む = t が減る = ゲートが閾値の近い入力から順に閉じる |
| 核 𝒦 | 両方の層の NTK。N 個の訓練入力の上の N×N 行列（多クラスでは 9N×9N）。重みを少し動かしたとき出力がどう動けるかの「動ける向きの一覧」 |

## 1. 容量とは何か

線形化した網の出力は f = f₀ + J·δθ（J = ヤコビ行列、δθ = 重みの小さな変化）。乱数ラベル Y をリッジで当てはめると δθ = Jᵀ(𝒦 + λ)⁻¹Y、𝒦 = JJᵀ。当て残る損失の期待は λ·tr(𝒦 + λ)⁻¹ で、核の固有値が大きい向きほどよく当たる。**容量 Φ = ½ Σ log(λ + 固有値)** は「当てられる向きがどれだけあるか」を 1 つの数にしたもの（log det = 動ける向きの体積の対数）。

unit i は核に 2 種類の向きを足している:
- **読み出しの道**: v_i を動かすと出力が φ_i = (φ(z_i1), …, φ(z_iN)) の向きに動く。unit の出力の模様そのもの。
- **ゲートの道**: w_i を動かすと出力が v_i·φ′(z_in)·x_n の向きに動く。unit が入力 n で開いていれば（φ′ = 1）、その入力の上で出力を自由に動かせる。閉じていれば a 倍しか動かせない。

ゲートが閉じるほど、その unit が足せる向きが減る。**可塑性喪失 = 容量の減少**で、これは log det の降下として 1 つの数で測れる。

## 2. 押しは容量の降下

課題の切替で、網は古いラベルへの当てはめを消しながら新しい乱数ラベルに向かう。最初の更新の期待（新しいラベルについて平均）は −η∇U、U = 古い関数の自信。これを古いラベルについても平均すると **−η(1/K)∇Φ**（§16.23 (1)。導出は 1 行: E_Y[Yᵀ(∂J)JᵀEY] = tr((∂J)JᵀE) = ∂Φ）。

つまり**切替のたびに、重みは容量が減る向きに期待値で動く**。古い当てはめを消す = 当てはめに使った向きを縮める = 当てられる向きを減らす。

unit i の位置 t_i について書けば、押し A_i = ∂Φ/∂t_i。A_i > 0 なら「t を上げると容量が増える」ので、降下の流れは t を下げる = 沈める。だから **A > 0 = 沈める向き**。

**自己項**: unit i だけを核に入れて同じ量を測ったもの。unit 1 個なら、ゲートが開くほど（S_開 に x_nx_nᵀ が足されるほど）容量は必ず増えるので、自己項は必ず A > 0 = 沈める向き。これが「押しは自己項の向き」の自己項の側。問題は**残り**（ほかの unit がいることで自己項がどう変わるか）だった。

### 2′. なぜ容量を下げる向きに動くのか（Issa の問い）

1. **切替の最初の一歩は「古い出力を消す一歩」。** 新しい損失 ½‖Y′ − f‖² の勾配は −Jᵀ(Y′ − f)。新しいラベル Y′ の平均は 0 なので、期待は −η Jᵀ f_old = −η ∇U（U = ½‖f‖²、古い出力の大きさ）。古い出力を小さくする向き。
2. **出力は「読み出し × 特徴」の積で、消す一歩は両方を縮める。** unit の特徴の強さは、ゲートの道ではゲートの開き（開いた入力でだけ出力を動かせる）。縮める = 閉じる = 沈む。1 変数の玩具: 出力 f = s·c（s = 特徴の強さ、c = 読み出し）、ラベル Y を c で当てる（c = sY/(s² + λ)）と U = ½ s⁴Y²/(s² + λ)²、∂U/∂s = 2λ s³Y²/(s² + λ)³ > 0。消す一歩は s を小さくする。
3. **古いラベルについて平均すると、残るのは容量の勾配。** 消す一歩 −η J(θ*)ᵀ f(θ*) で、J(θ*) = J₀ + (∂J)δθ、f = 𝒦EY ≈ Y、δθ = JᵀEY。J₀ᵀY の部分（当てはめをそのまま戻す部分）は Y の 1 次で ± で消える。残る (∂_uJ)δθ の部分は Y の 2 次: E_Y[Yᵀ(∂_uJ)JᵀEY] = σ² tr((∂_uJ)JᵀE) = σ² ∂_u ½ log det(𝒦 + λ) = σ² ∂_uΦ。つまり E[一歩] = −ησ² ∇Φ。
4. **意味**: 余白 𝓜 = ⟨Y, f⟩ は、当てはめた点では「表せる空間への Y の射影の大きさ」。容量が増える向きに θ を動かすと表せる空間が広がり、f が Y をもっと捉えて余白が増える。だから期待値で ∇𝓜 ∝ ∇Φ。学ぶ向き（余白を増やす）は容量を増やす向きで、切替で消す向きはその逆。
5. 言わないこと: 押しそのものが Φ の勾配であること（(3) に当て残しの項が残る）。言えるのは「古いラベルの期待で、当てはめが済んでいれば」。

### 2″. 当て残しが無い理想化は適切か（Issa「当て残しが生じた時点で LoP ではあるか」）

- 相 1（課題 2、p_max 0.96）では当たり、相 2（p_max 0.4）では外れ。Issa のとおり、当て残しがある = 新しいラベルを当てられない = LoP そのもの。
- 当て残しを入れても形は保てる [厳密・線形化・リッジ]: f_old = 𝒦EY（𝒦E = 当てられた割合の行列）とすると E[一歩] = −ησ² tr((∂_uJ)Jᵀ E𝒦E) = −(ησ²/2) ∂_uΨ、Ψ = log det(𝒦 + λ) + λ tr(𝒦 + λ)⁻¹（§16.23 (3) の Ψ。実際はこれに勾配の形にならない小さい項が足される）。当てはめが済めば（λ → 0）∂Φ、全く当たらなければ 0。**消せるのは学んだ分だけ。**
- だから当て残しは押しのブレーキ。LoP が進むほど切替の押しは弱まる。相 2 で切替の押しの向きの一致が 60〜70% に落ち、1 課題の変位が揺らぎ優位になり、沈降（0.04/課題）を運ぶのが押しでなく幅の伸び（m = r*·sd）になるのはこれ。
- それでも理想化した容量の押しが相 2 の変位を最もよく予測する（向き 100%・順位 ρ 0.45〜0.6）のは、当て残しの効き方が主に倍率（Ψ 対 Φ）で、向きと順位をほぼ変えないから。
- 格: 当て残し 0 は「向き」の理論には適切、「速さ」には不適切（速さは当て残しで縮んだ押しと幅の伸びの釣り合い）。

## 3. 谷底: ゲート 1 個について容量は放物線

unit i と入力 n を固定し、その 1 個のゲートの値 g = d_in だけを動かして（ほかは全部固定）容量を見ると

　Φ(g) = ½ log( c₀ + γ_i κ′_n (g − d̂_in)² ) + 定数

という形になる [厳密]。g の 2 次式の対数で、**g = d̂_in で最小**。この最小点が**谷底**。ゲート 1 個についての押しは c (d_in − d̂_in)（c > 0）で、

- ゲートが谷底より上（d_in > d̂_in）→ 閉じる向きに押される
- ゲートが谷底より下（d_in < d̂_in）→ 開く向きに押される

位置の押し A_i は、これを全入力について足したもの（A^g = Σ_n c_n (d_in − d̂_in)、閾値の近くの入力ほど重い）。

**unit 1 個なら谷底は床より下**（d̂ < a）。開くほど容量が増えるので、最小は「いちばん閉じた所」のさらに下にある。全部のゲートが谷底より上 → 全部閉じる向き → 沈む。

## 4. 残りは谷底を動かすことでだけ効く

ほかの unit が居ると、谷底は

　**d̂_in = Σ_{j≠i} w_j d_jn**　（(D1)、§16.24）

**ほかの unit の「同じ入力 n でのゲート」の重みつき平均**になる。重み w_j は「unit j の模様が unit i の模様にどれだけ似ているか」で、正確には、n 以外の入力の上で、j のゲートの模様 (d_jm Θ_mn) と i のそれとの内積を、残り全体の核で割り引いた計量（H⁻¹）で測ったもの。**i と似た所で開いている unit ほど重い。** 閉じた unit（d_jn = a）は a 倍しか効かない。

意味: 「i と似た unit たちが入力 n でどのくらい開いているか」が、i のゲートの行き先。似た unit が n で開いていれば、i も n で開いた方が「模様がそろって冗長になり、容量が下がる」ので、降下の流れは i を n で開く向きに押す（谷底が上がる）。似た unit が n で閉じていれば、i も閉じた方が容量が下がる（谷底が下がる）。

**「谷底をゲートより上に持ち上げる」** = i と似た unit たちが、i が閾値にいる入力 n で開いていて、重みつき平均 Σ w_j d_jn が i の今のゲート（閾値なら (1+a)/2 ≈ 0.55）を超えること。そのとき i はその入力で開く向きに押され、閾値の近くの入力でそれが起きれば、位置の押し A_i が負（沈まない）になりうる。これが「残りが自己項を覆す」の唯一の道 [厳密: 残りは谷底を通してだけ入る]。

**並びの期待値（定理 6）**: i の模様を入力の上で無作為に並べ替えて平均すると、Σ w_j d_jn の効き方は自己項の形の正の倍率に落ちる。つまり**特定の並び**（i の閾値の入力に、i に似た開いた unit が並んでいること）が無ければ、残りは自己項を縮めるだけで向きは変えない。

## 5. 橋

谷底を持ち上げる unit j に要る性質が 2 つ:
1. i の閾値の入力 n で**開いている**（d_jn = 1。平均の中で 1 を足す）
2. i の**開いた入力でも開いている**（模様が似ている → 重み w_j が大きい。似ていなければ w_j ≈ 0 で、n で開いていても平均に効かない）

1 と 2 を両方持つ unit を**橋**と呼ぶ: i の開いた集合から i の閾値の入力へ、開いたまま架かっている unit。**i の部分的な写し**。

- 完全な写し（i と同じ模様）は持ち上げない: 重み w < 1 で、しかも n で i と同じゲートなので、平均は i の今のゲートに戻るだけ [厳密 §15.3]。持ち上げるのは「i より広い」写し。
- 橋 1 個の重みは 1 未満（写しの重みの上界）で、自然な強さでは 0.05〜0.1。谷底を 0.55 以上にするには **橋が 10〜30 個**要る [構成 P155]。実状態に設計した橋を足すとどの標的も沈まなくなり、多クラスの核でも 10/14 が残る。
- 実状態の unit は橋ではない: 閾値の入力を共有する unit でも、標的の開いた集合の被覆は 0.17（橋には 0.5 以上）。訓練された unit は狭く（開いた入力 0.6〜6%）、互いの開いた集合を写さない。1 標的あたり最大 5 個 [実測]。

## 6. 払い手: 持ち上げはただではない

入力 n でのゲートの押しを全 unit で足すと

　Σ_l d_ln ∂Φ/∂d_ln = (E𝒦_gate)_nn > 0　[厳密]

右辺は正の定数（n が核で説明される割合）。**1 つの unit が n で開く向きに押される（負）なら、ほかの unit の閉じる向きの和がその分だけ大きい。** 持ち上げは同じ入力のほかの unit の閉じる圧力として払われる。作った反例の流れの終点では、払っているのは沈んだ unit の閉じた側（a 倍の線形の道）で、飽和して動けないから持ち上げが続いていた（§15.8）。

## 7. 橋はできかけで壊れる

橋になるには、ほかの unit の閾値の入力 n で開かなければならない。しかし**新しく開きかけたゲートは自分の谷底より上**（相 2 では、どの入力 n でも開いている unit が 1〜5 個/100 しか無く、谷底 ≤ T(a + (1−a)f_n) は f_n < 1/2 なら閾値より下 [厳密・補題 §16.9]）。だから閉じ戻される。実際の訓練でも、橋（緩い基準）は毎課題 17〜34 組できるが 92〜94% は 1 課題で壊れ、1 標的に ≥ 10 個が同時に揃う確率は 10^−12 [実測＋仮定つき]。

無作為な向きの unit なら橋 ≥ 10 の確率は 10^−7 以下 [厳密・仮定つき、入力の幾何込み]。

## 8. 相 1 は容量でなく「自信のある分類器を消す押し」

初期の広い unit（開いた割合 0.56）はみな互いの緩い橋で、容量の押しは 9 割打ち消されている（A/自己項 0.1、20 個が持たれる）。それでも 8 課題で開いた割合が 1/80 になるのは、**実際の古い関数**（CE で自信のある分類器、p_max 0.96）を消す切替の押し

　S_i = Σ_n K_n d_in ⟨v_i, p_n − 1/K⟩ ≈ Σ_n K_n d_in (v_{i,ŷ_n} − v̄_i)

が運ぶから。「unit の開いた入力の上で、予測された類への読み出しが平均を上回る量」。読み出しが勾配で育ったものなら E_y[S_i] ∝ Σ_n K_n φ′(z_n)φ(z_n) > 0（自己形。unit 間の打ち消しなし）[厳密・仮定つき §16.8]。容量の押しはリッジの整合した当てはめの期待なので、冗長な広い unit の間で打ち消しが出るが、実際の読み出しは整合していない。

## 9. 相対位置が負に偏る理由（Issa の機構）

自己形 Σ K φ′φ を開いた側と閉じた側に分けると、開いた側は z > 0（下向き）、閉じた側は φ′φ = a·(a z) = a² z < 0（上向き）。**上向きの自己項 = 負の側の微分 × 負の側の値**。a が小さいほど小さい。釣り合いは φ(r) + rΦ(r) = a²[φ(r) − rΦ(−r)] で r*(0.1) = −1.72、(0.3) = −0.94、(0.5) = −0.55、ReLU で −∞。実測 −2.2・−1.6・−0.9: 符号・順序・6〜7 割 [§16.10]。残りの 0.4〜0.9 は、容量型の押し（下）・自己形の閉じた側（上）・幅の伸び（上）の釣り合いで、幅の伸びは W 増大の章。

## 10. 一枚の絵

1. 切替のたびに、重みは古い当てはめを消す向きに動く。期待値では容量の降下（§2）。
2. unit 1 個なら、ゲートが閉じるほど容量が減るので、必ず沈む（自己項、§3）。
3. ほかの unit は、各入力での「似た unit たちの開き具合」= 谷底を動かすことでだけ効く（§4）。
4. 谷底をゲートより上に押し上げるには橋（部分的な写し）が 10 個以上要り、実網には無く、できかけで壊れる（§5〜§7）。
5. だから相 2 では全 unit が自己項の向きに沈み、相対位置は閉じた側の小さな上向きの自己項と釣り合う負の位置に止まる（§9）。
6. 初期の崩壊だけは、容量の押しでなく、自信のある分類器を消す押しが運ぶ（§8）。
