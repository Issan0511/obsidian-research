## 1. 段 3〜5 のつなぎ方

- 課題末の揃いを、門と読み出しを課題前／課題末で入れ替えて分ける: Q(門, 読み出し) = Σ_n K_n g_in v^c_{i,y_n}。新ラベルは課題前の状態と独立なので、E[Q(課題前の門, 課題前の読み出し)] = 0 [厳密]。課題末の揃いは、門の変化の分 Σ_n K_n (g^末 − g^前) c_in と、読み出しの変化の分から成る。
- 門の変化の分が正になるには、「票が正の対ほど開き、票が負の対ほど閉じる」ことが要る。これは「z_in が自分の票の向きに動く」（段 4）から出る。線形応答で Δz_in = R_in·c_in + (y_n によらない項) と書けるなら、R_in ≥ 0 のとき任意の閾値 θ で E[c_in·1[z_in(T) > θ]] ≥ 0 [厳密・模型。§4.1 の (c)]。
- ただし門が動くと模型の核そのものが変わるので、このつなぎが厳密なのは「その入力で感度が 0 でない unit が 1 つだけ」の場合まで（段 5 の穴）。

## 4. 門の道の模型で厳密に言えること [厳密・模型]

### 4.1 和の正値性と反例

- (a) unit ごと: Σ_n d_in R_in ≥ 0。(b) 入力ごと: unit についての感度つきの和は tr_K[I − e^{−τ𝒦}]_nn ≥ 0。どちらも線形化した網のハット行列の対角で、標準的な事実。
- (c) 入力 n で感度が 0 でない unit が i だけなら、Δz_in は票の正の倍 ＋ y_n によらない項で、任意の閾値で E[c·1[z_T > θ]] ≥ 0（先生の定理 6.2 と同じ型）。
- **反例**: 入力を複数の unit が共有すると、対ごとの符号は保証されない（3 unit が共有する入力で Cov = −0.196。無作為な小さい箱では感度 1 の対の 0.6% が負）。
- (b) が非負にするのは感度つきの Cov(票, Δz) で、押しに要る Σ_n K_n Cov(票, 1[z(T) > 0]) ではない。

### 4.2 橋の定理 [厳密・模型・プロジェクト内で新規]

感度を 0/1 に置いた模型を、対の空間で書く。W = Q⁻¹Γ（Q⁻¹ = unit ごとの、見えている入力の Gram。Γ = 入力ごとの、開いた unit の読み出しの Gram）。対 p = (i, n) の応答を 0〜1 に規格化したもの（1 = 入力 n の v_i 向きの変化を全部その対が運ぶ）は、勾配流で ι_p(τ) = 1 − [e^{−τW}]_pp、リッジで ι_p(λ) = (β − λχ)/(λα + β − 2λχ)。分母は正で、符号は β − λχ。β は「入力 n のほかの unit が吸えない分」、χ は「unit i のほかの入力」と「入力 n のほかの unit」が残りの網を通してつながる強さ（閉路の結合）。

- **定理**: 見える対を辺とする unit–入力の二部グラフで、辺 p が橋（p を通る閉路が無い）なら、全 τ・全 λ で 0 ≤ ι_p ≤ 1。ほかの場所の閉路は構わない。4.1 の (c) の一般化。
- 証明の骨子: 橋なら χ = 0 で、リッジの解は α/(λα + β)。α は Stieltjes 関数、β は完全 Bernstein 関数で、完全単調な関数の積と Bernstein の定理から勾配流でも出る。Θ の部分行列が特異な場合は Θ + εI と連続性で補う。
- 検証: 無作為な橋の対 45,237 個と最適化による反例探しで違反 0（float64 の見かけの違反 31 件は 90 桁の計算で消える）。
- 範囲: unit ごとの固定の前処理（分母を凍結した Adam）と、CE のヘッセ行列を入れても成り立つ。**読み出しも学ばせると成り立たない**（森でも (対, τ) の 0.7% で負）。純粋な 4 閉路・6 閉路だけでは負は出ず、枝が付くと出る。
- **どんなグラフでも** (1 − √V_p)/2 ≤ ι_p ≤ (1 + √V_p)/2（V_p = 入力側と読み出し側の分散拡大係数の小さい方。等号まで届く）。実状態では V の中央値が 1.15〜2.95 で、この界だけでは正は出ない。
- 一般的な性質だけから閉路の結合を抑える不等式は無い（合成の箱では負がふつうに出る）。

### 4.4 閾値の式（本物の感度を入れる）[厳密・模型（リッジ）]

対 (i, n) の感度だけを動かす。基点の感度 d₀ での応答を q、ずれを ε とすると

 R(d₀ + ε) = (q + εω)/(1 + 2εq + ε²ω)、ω = P·κ + q² > 0

P = 入力 n の v_i 向きの当て残し ÷ λ、κ = x̃_n のうち unit i のほかの入力に縛られていない分（どちらも基点で測る）。階数 2 の更新の式で、どの基点からでも同じ形になる。道具は先生の Session 43 定理 4.3（門 1 つの反転）と同じ型で、新しいのは量（自分のラベルへの z の応答）・リッジ版・下の閾値の形と界。

- 基点を「対を消した状態」（d₀ = 0、応答 R⁰）に取ると、R⁰ < 0 のとき **感度が閾値 d* = −R⁰/ω を超える対だけが票の向きに動く**。開いた対（感度 1）と閉じた対（leaky a、ELU e^z）が同じ式に乗る。
- **界**: d* ≤ 1/(2√(Pκ))。Pκ > 1/4 なら、感度 1 の対は閉路の有無によらず票の向き。
- **恒等式**: 実際の状態では d_in − d*_in = R_in/ω_in。d* は R(d) の零点なので、どの基点から計算しても同じ数。
- 検証: 合成 1,800 例で重み空間の直接解と 6.5e−8、実状態 9 個で全体の核から逆にたどった値と 1e−15〜5e−13。閉じた形はリッジ専用（勾配流には無い）。

実状態 9 個（ELU 5・leaky a 0.1 が 3・leaky a 0.3 が 1。課題前か底）[実測・模型]:
- 開いた対は本物の感度で 100% 票の向き（リッジ 6 点・勾配流 3 点）。対を消したときの応答 R⁰ は 91〜100% が負（引きずりはほぼ必ず押しのける向き）。
- d* は ELU で中央値 0.000〜0.028・最大 0.03〜0.49。界だけで覆える開いた対は、λ/λmax ≤ 1e−3（当てはまりの割合 約 1 割以上）で ELU 96〜100%・leaky（a 0.1）98〜100%、1e−2 で 66〜100%、0.1 で 0〜94%。
- 閉じた対・ELU: 模型の応答が正の割合は深さとともに落ちる（λ/λmax = 1e−4、課題前の状態で、深さ 0〜−2 は 1.00、−2〜−4 は 0.96〜0.99、−4〜−6 は 0.78〜0.92、−6〜−8 は 0.58〜0.77、−8〜−12 は 0.36〜0.43、それより下は 0.2〜0.3）。
- 閉じた対・leaky: d* は a のすぐ下に出る（d*/a が 0.65 → 0.998）。これは余裕ではない。恒等式のとおり、ω が当てはめとともに膨らむ（1.4 → 1,300 倍）ことの言い換えで、符号の情報は無い。基点を「対を消した状態」に取っても同じく縮退している（a·R⁰ の中央値は a 0.1 で −0.94・a 0.3 で −0.63 と −1 に寄り、分母は 0 に寄る）。応答そのものは開いた対の 0.08〜0.31 倍で 0 から離れている。
- λ（当てはめの進み）と実際の更新数の対応は決まっていない。結論は λ で動く。

### 4.5 線形の網と leaky の 2 項 [厳密・模型]

- 門が無い網（全部の感度が等しい）では R_in ≥ 0（Θ と (a²μΘ + λ)⁻¹ が交換する。P32 に既出）。
- leaky では R_in = a·A_in + (1 − a)·B_in と厳密に割れる。A = 全入力に一様な重みの分（線形の背景）、B = unit の開いた入力から来る分（引きずり）。
- [実測・模型] leaky a 0.1（課題 40、開いた入力は生きた unit あたり平均 17〜19 個・中央値 7.5〜8）: a·A は「開いた対を全部閉じた純粋な線形の網」の応答と中央値で同じ（1.02〜1.18 倍。対ごとの順位相関は 0.96 → 0.67〜0.70）で、閉じた対の 97〜100% が正。leaky a 0.3（課題 100、unit あたり平均 86 個・中央値 67）: 当てはめを進めると B が浅い対で a·A を上回り、合計が負になる（正の割合 0.98 → 0.53。小さい λ では純粋な線形の網との順位相関は −0.09）。

## 5. 課題の頭 [厳密・実網・時間の 1 次]

- 課題の頭では残差がまだ変わっていないので、Δz_in の自分の票への傾きは自己項だけ = 感度 × Θ^{(i)}_nn × 時間。Θ^{(i)} は Adam の成分ごとの歩幅を入れた内積で、対角の前処理なので正。ほかの入力のラベルは独立なので、1 次では傾きに入らない。読み出しの学習は 2 次で入る。
- 「時間展開の 1 次が自己項、2 次が引きずり」は既知（P30・P31 の式、0930 §1(c) の核の話）。足したのは実測との照合（§6.2）と 2 次の形:
- **2 次まで** [厳密。門凍結・読み出し固定・勾配流]: R(τ) = τ·S − (τ²/2)·D + O(τ³)。S = d_in Θ_nn |v_i^c|²（自己項。CE と、的の遠さ κ = 1 の二乗誤差で同じ）、D = Σ_m d_im Θ_mn² Σ_j d_jm d_jn (v_iᵀ H_m v_j)(v_i^c·v_j^c)。二乗誤差では H_m は中心化の射影で D ≥ 0（引きずりは 2 次で必ず逆向き）。CE では H_m = diag(p_m) − p_m p_mᵀ で、固有値は 1/2 以下、予測の自信が高いほど小さい。CE では D の符号は保証されない。
- 課題前の値で評価すると、D_CE/D_二乗誤差 の中央値は leaky a 0.3 で 0.05〜0.13、a 0.1 で 0.24〜0.34（負の対は無し）[実測・検証役]。課題全体では [未導出]。

### 12.7 理論 [格は項目ごと。置き場 `review/stage4_1002/THEORY.md`]

- **ラベルを 1 つ替えることは、票の向きの力を足すこと** [恒等式]。入力 n のラベルが k の損失は L^{(k)} = L̄ − (e_k^c)ᵀf_n。足される項の勾配は 3 か所にかかる: 第 1 層には unit j ごとに −c_jk·d_jn·x̃_n（自己項）、読み出しには −e_k^c φ_nᵀ、出力 bias には −e_k^c。門の道の模型（読み出し固定）は後の 2 つを持たない。
- **時間の 2 次まで** [厳密。感度凍結・全データの勾配流・読み出しも学習。検証役が合成 300 例で確認]:
  ρ_in(τ) = τ·d_in Θ_nn + (τ²/2)·[ φ_in·ż_in^u + Θ_nn d_in c_iᵀv̇_i^u − D^V − D^W ]/|c_i|²。
  D^W は §5 の第 1 層の引きずり。**D^V = Σ_m Θ_nm d_im (φ_n·φ_m + 1) v_iᵀH_m v_i^c は読み出しと出力 bias の引きずり**（読み出しが入力 n のラベルを覚えると、活性の似た入力の logit も動き、その残差の変化が unit i を票と逆向きに押す。unit i の感度のある入力で φ_n·φ_m + 1 ≥ 0 なら必ず逆向き）。残りの 2 項は、読み出しが動くことによる自分の票の変化。実状態の課題の頭（勾配流での目安）では、leaky は全部の対で D^V > D^W（3〜20 倍）。それなのに読み出しを凍結しても逆向きの対が 2〜3 割しか減らない理由は [未導出]（Adam の歩幅か、高次の項か）。
- **反例: 本物の CE では、門が無い 1 unit の網でも途中の時刻で逆向きになる** [数値で頑健。検証役が積分器 5 種と 30 桁の計算で再現]。1 unit・K = 2・非負の 2 次元の入力（= ロジスティック回帰）の勾配流で、ラベルを替えた入力の z の差が +1.93 まで上がったあと −0.41 になり、終わりは +0.067。同じ入力で曲率が一定（二乗誤差）なら全時刻で正。橋の定理（§4.2）は「CE のヘッセ行列を固定して入れれば成り立つ」まで言えていたが、曲率が時間で変わる本物の CE では 1 unit（橋の特別な場合）でも成り立たない。負が出たのは、途中で曲率が増える入力があり、そのノルムが先に効いている入力の 5 倍以上で、調べる入力が両者の間にある配置（必要条件かは示せていない）。無作為な 7,500 例（うち 1,500 例は課題切り替えの形）では負は 0。
- **補題: 曲率が増えない間は、入力ごとの感度つきの和は非負** [厳密・模型]。2 つのラベルの流れの差は δ̇ = b − Ã(t)δ（Ã は 2 本の流れの間で平均した曲率。線形化なし）で、dÃ/dt ⪯ 0 の間は bᵀδ ≥ ½δᵀÃδ ≥ 0。入力 n で感度のある unit が 1 つなら対ごとの文。曲率が増える区間のあとは使えない（その後に曲率が減っても、言えるのは「増えた区間の終わりの値より下がらない」だけ）。実際の課題では、曲率（1 − Σp² の平均）は課題の頭 0.60〜0.72 → 更新 400〜800 で 0.75〜0.85 → 課題末 0.61〜0.74 と前半に増えるので、補題は課題全体には届かない。
- **入力ごとの和の恒等式** [恒等式。実網・どんな学習でも]: Σ_i Cov_k(c_ik, φ_in(T;k)) ＋ 読み出しの変化の項 ＋ bias の項 = log K − mean_k CE_n(T;k) ＋ mean_k KL(u‖p_n(T;k))。[[押しと戻りの測定_収束の鎖と模様の上限とaの梯子_1001]] の CE = C + log K + G と同じ恒等式を、ラベルを替えた K 通りに当てたもの。実測では違反 0（8 状態 × 2 順 × 144 入力）、第 1 層の項が合計の 0.83〜0.94（入力ごとの比の中央値。ELU の課題 100 だけ 0.15〜0.22 で、第 1 層の項が正の入力も 64〜67%）。
- **経路分けの注意** [厳密なのは線形応答]: 力の合計は logit を変える向きだけを向くが、第 1 層の分・読み出しの分は、それぞれ「どの入力の logit も変えない向き」の成分を逆符号で持つ。片方ずつかけると、その成分の応答が積み上がる（引数 2 つの最小の例で、片方ずつは ±t に比例、和は頭打ち）。経路ごとの大きさと符号は、仕組みの量として読めない。
- 帰結: 「実網の課題全体で、対ごとに票の向き」は、仮定なしの定理にはならない（模型の閉路の反例に加えて、CE の反例）。実網で厳密なのは、課題の頭の 1 次と、入力ごとの和の恒等式。2 次の形と補題は模型の中（感度凍結・全データの勾配流）。対ごとの文は §12.2 の測定。補題と反例は初等的で、既出の可能性が高い（文献は照合していない）。
