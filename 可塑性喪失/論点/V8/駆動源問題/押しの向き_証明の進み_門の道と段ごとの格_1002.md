## 1. 段 3〜5 のつなぎ方

- 課題末の揃いを、門と読み出しを課題前／課題末で入れ替えて分ける: Q(門, 読み出し) = Σ_n K_n g_in v^c_{i,y_n}。新ラベルは課題前の状態と独立なので、E[Q(課題前の門, 課題前の読み出し)] = 0 [厳密]。課題末の揃いは、門の変化の分 Σ_n K_n (g^末 − g^前) c_in と、読み出しの変化の分から成る。
- 門の変化の分が正になるには、「票が正の対ほど開き、票が負の対ほど閉じる」ことが要る。これは「z_in が自分の票の向きに動く」（段 4）から出る。線形応答で Δz_in = R_in·c_in + (y_n によらない項) と書けるなら、R_in ≥ 0 のとき任意の閾値 θ で E[c_in·1[z_in(T) > θ]] ≥ 0 [厳密・模型。§4.1 の (c)]。
- ただし門が動くと模型の核そのものが変わるので、このつなぎが厳密なのは「その入力で感度が 0 でない unit が 1 つだけ」の場合まで（段 5 の穴）。

## 4. 門の道の模型で厳密に言えること [厳密・模型]

### 4.1 和の正値性と反例

- (a) unit ごと: Σ_n d_in R_in ≥ 0。(b) 入力ごと: unit についての感度つきの和は tr_K[I − e^{−τ𝒦}]_nn ≥ 0。どちらも線形化した網のハット行列の対角で、標準的な事実。
- (c) 入力 n で感度が 0 でない unit が i だけなら、Δz_in は票の正の倍 ＋ y_n によらない項で、任意の閾値で E[c·1[z_T > θ]] ≥ 0（先生の定理 6.2 と同じ型）。
- **反例**: 入力を複数の unit が共有すると、対ごとの符号は保証されない（3 unit が共有する入力で Cov = −0.196。無作為な小さい箱では感度 1 の対の 0.6% が負）。
- (b) が非負にするのは感度つきの Cov(票, Δz) で、押しに要る Σ_n K_n Cov(票, 1[z(T) > 0]) ではない。

### 4.2 橋の定理 [厳密・模型・プロジェクト内で新規]

感度を 0/1 に置いた模型を、対の空間で書く。W = Q⁻¹Γ（Q⁻¹ = unit ごとの、見えている入力の Gram。Γ = 入力ごとの、開いた unit の読み出しの Gram）。対 p = (i, n) の応答を 0〜1 に規格化したもの（1 = 入力 n の v_i 向きの変化を全部その対が運ぶ）は、勾配流で ι_p(τ) = 1 − [e^{−τW}]_pp、リッジで ι_p(λ) = (β − λχ)/(λα + β − 2λχ)。分母は正で、符号は β − λχ。β は「入力 n のほかの unit が吸えない分」、χ は「unit i のほかの入力」と「入力 n のほかの unit」が残りの網を通してつながる強さ（閉路の結合）。

- **定理**: 見える対を辺とする unit–入力の二部グラフで、辺 p が橋（p を通る閉路が無い）なら、全 τ・全 λ で 0 ≤ ι_p ≤ 1。ほかの場所の閉路は構わない。4.1 の (c) の一般化。
- 証明の骨子: 橋なら χ = 0 で、リッジの解は α/(λα + β)。α は Stieltjes 関数、β は完全 Bernstein 関数で、完全単調な関数の積と Bernstein の定理から勾配流でも出る。Θ の部分行列が特異な場合は Θ + εI と連続性で補う。
- 検証: 無作為な橋の対 45,237 個と最適化による反例探しで違反 0（float64 の見かけの違反 31 件は 90 桁の計算で消える）。
- 範囲: unit ごとの固定の前処理（分母を凍結した Adam）と、CE のヘッセ行列を入れても成り立つ。**読み出しも学ばせると成り立たない**（森でも (対, τ) の 0.7% で負）。純粋な 4 閉路・6 閉路だけでは負は出ず、枝が付くと出る。
- **どんなグラフでも** (1 − √V_p)/2 ≤ ι_p ≤ (1 + √V_p)/2（V_p = 入力側と読み出し側の分散拡大係数の小さい方。等号まで届く）。実状態では V の中央値が 1.15〜2.95 で、この界だけでは正は出ない。
- 一般的な性質だけから閉路の結合を抑える不等式は無い（合成の箱では負がふつうに出る）。

### 4.3 実状態の開いた対（感度を 0/1 に置いた版）[実測・模型]

- 閉路の結合 max_λ λχ/β は、普通の走で中央値 0.000〜0.025・最大 0.06〜0.40、収束した状態で中央値 0.02〜0.08・最大 0.65（ELU）・0.81（leaky）。
- 橋の対は ELU 11〜15%、leaky（a 0.1）23〜32%、leaky（a 0.3）1.6%。定理が保証するのはこの分だけで、残りが正なのは測定。

### 4.4 閾値の式（本物の感度を入れる）[厳密・模型（リッジ）]

対 (i, n) の感度だけを動かす。基点の感度 d₀ での応答を q、ずれを ε とすると

 R(d₀ + ε) = (q + εω)/(1 + 2εq + ε²ω)、ω = P·κ + q² > 0

P = 入力 n の v_i 向きの当て残し ÷ λ、κ = x̃_n のうち unit i のほかの入力に縛られていない分（どちらも基点で測る）。階数 2 の更新の式で、どの基点からでも同じ形になる。道具は先生の Session 43 定理 4.3（門 1 つの反転）と同じ型で、新しいのは量（自分のラベルへの z の応答）・リッジ版・下の閾値の形と界。

- 基点を「対を消した状態」（d₀ = 0、応答 R⁰）に取ると、R⁰ < 0 のとき **感度が閾値 d* = −R⁰/ω を超える対だけが票の向きに動く**。開いた対（感度 1）と閉じた対（leaky a、ELU e^z）が同じ式に乗る。
- **界**: d* ≤ 1/(2√(Pκ))。Pκ > 1/4 なら、感度 1 の対は閉路の有無によらず票の向き。
- **恒等式**: 実際の状態では d_in − d*_in = R_in/ω_in。d* は R(d) の零点なので、どの基点から計算しても同じ数。
- 検証: 合成 1,800 例で重み空間の直接解と 6.5e−8、実状態 9 個で全体の核から逆にたどった値と 1e−15〜5e−13。閉じた形はリッジ専用（勾配流には無い）。

実状態 9 個（ELU 5・leaky a 0.1 が 3・leaky a 0.3 が 1。課題前か底）[実測・模型]:
- 開いた対は本物の感度で 100% 票の向き（リッジ 6 点・勾配流 3 点）。対を消したときの応答 R⁰ は 91〜100% が負（引きずりはほぼ必ず押しのける向き）。
- d* は ELU で中央値 0.000〜0.028・最大 0.03〜0.49。界だけで覆える開いた対は、λ/λmax ≤ 1e−3（当てはまりの割合 約 1 割以上）で ELU 96〜100%・leaky（a 0.1）98〜100%、1e−2 で 66〜100%、0.1 で 0〜94%。
- 閉じた対・ELU: 模型の応答が正の割合は深さとともに落ちる（λ/λmax = 1e−4、課題前の状態で、深さ 0〜−2 は 1.00、−2〜−4 は 0.96〜0.99、−4〜−6 は 0.78〜0.92、−6〜−8 は 0.58〜0.77、−8〜−12 は 0.36〜0.43、それより下は 0.2〜0.3）。
- 閉じた対・leaky: d* は a のすぐ下に出る（d*/a が 0.65 → 0.998）。これは余裕ではない。恒等式のとおり、ω が当てはめとともに膨らむ（1.4 → 1,300 倍）ことの言い換えで、符号の情報は無い。基点を「対を消した状態」に取っても同じく縮退している（a·R⁰ の中央値は a 0.1 で −0.94・a 0.3 で −0.63 と −1 に寄り、分母は 0 に寄る）。応答そのものは開いた対の 0.08〜0.31 倍で 0 から離れている。
- λ（当てはめの進み）と実際の更新数の対応は決まっていない。結論は λ で動く。

### 4.5 線形の網と leaky の 2 項 [厳密・模型]

- 門が無い網（全部の感度が等しい）では R_in ≥ 0（Θ と (a²μΘ + λ)⁻¹ が交換する。P32 に既出）。
- leaky では R_in = a·A_in + (1 − a)·B_in と厳密に割れる。A = 全入力に一様な重みの分（線形の背景）、B = unit の開いた入力から来る分（引きずり）。
- [実測・模型] leaky a 0.1（課題 40、開いた入力は生きた unit あたり平均 17〜19 個・中央値 7.5〜8）: a·A は「開いた対を全部閉じた純粋な線形の網」の応答と中央値で同じ（1.02〜1.18 倍。対ごとの順位相関は 0.96 → 0.67〜0.70）で、閉じた対の 97〜100% が正。leaky a 0.3（課題 100、unit あたり平均 86 個・中央値 67）: 当てはめを進めると B が浅い対で a·A を上回り、合計が負になる（正の割合 0.98 → 0.53。小さい λ では純粋な線形の網との順位相関は −0.09）。

## 5. 課題の頭 [厳密・実網・時間の 1 次]

- 課題の頭では残差がまだ変わっていないので、Δz_in の自分の票への傾きは自己項だけ = 感度 × Θ^{(i)}_nn × 時間。Θ^{(i)} は Adam の成分ごとの歩幅を入れた内積で、対角の前処理なので正。ほかの入力のラベルは独立なので、1 次では傾きに入らない。読み出しの学習は 2 次で入る。
- 「時間展開の 1 次が自己項、2 次が引きずり」は既知（P30・P31 の式、0930 §1(c) の核の話）。足したのは実測との照合（§6.2）と 2 次の形:
- **2 次まで** [厳密。門凍結・読み出し固定・勾配流]: R(τ) = τ·S − (τ²/2)·D + O(τ³)。S = d_in Θ_nn |v_i^c|²（自己項。CE と、的の遠さ κ = 1 の二乗誤差で同じ）、D = Σ_m d_im Θ_mn² Σ_j d_jm d_jn (v_iᵀ H_m v_j)(v_i^c·v_j^c)。二乗誤差では H_m は中心化の射影で D ≥ 0（引きずりは 2 次で必ず逆向き）。CE では H_m = diag(p_m) − p_m p_mᵀ で、固有値は 1/2 以下、予測の自信が高いほど小さい。CE では D の符号は保証されない。
- 課題前の値で評価すると、D_CE/D_二乗誤差 の中央値は leaky a 0.3 で 0.05〜0.13、a 0.1 で 0.24〜0.34（負の対は無し）[実測・検証役]。課題全体では [未導出]。

### 12.1 測り方

これまでの実測は、対をまたいだ回帰の傾き（集団の量）だった。段 4 の文は対ごとなので、対ごとに測った。

- **flip**: 保存済みの走を bit 一致で再生して課題の頭の状態（重みと Adam の状態）を取り、入力 n のラベルだけを k = 0〜9 に替えて、同じ課題を同じバッチ順で 10 通り回し直す。ほかの入力のラベルは実際の値のまま。対 (i, n) の応答は ρ_in = Σ_k c_ik z_in(T;k) / Σ_k c_ik²（票 1 あたりの z の動き。c は課題前の読み出しの票）。ρ > 0 が「票の向き」。
- 入力は無作為に 144 個。状態は leaky a 0.1（課題 40・100）、leaky a 0.3（課題 100）、ELU（課題 40・100）で、課題 40 と a 0.3 は seed 0・1、計 8 状態。バッチ順は 2 通り（順 A = 実際の順、順 B = 引き直し）で、「両順で正」「両順で負」を数える。1 状態あたり課題約 2,600 回分の学習。
- **底** = 課題の頭の押しで層平均の m が底を打った時点（保存済みの重み）。課題前に開いていた対のうち、底でも開いているのは 0.30〜0.55。
- **引き直し** = 同じ課題の頭の状態から、ラベル全体を引き直して課題 1 つ分を回す（60 回）。unit ごとの揃いと S^open の、引きについての分布を取る（§12.6）。

### 12.7 理論 [格は項目ごと。置き場 `review/stage4_1002/THEORY.md`]

- **ラベルを 1 つ替えることは、票の向きの力を足すこと** [恒等式]。入力 n のラベルが k の損失は L^{(k)} = L̄ − (e_k^c)ᵀf_n。足される項の勾配は 3 か所にかかる: 第 1 層には unit j ごとに −c_jk·d_jn·x̃_n（自己項）、読み出しには −e_k^c φ_nᵀ、出力 bias には −e_k^c。門の道の模型（読み出し固定）は後の 2 つを持たない。
- **時間の 2 次まで** [厳密。感度凍結・全データの勾配流・読み出しも学習。検証役が合成 300 例で確認]:
  ρ_in(τ) = τ·d_in Θ_nn + (τ²/2)·[ φ_in·ż_in^u + Θ_nn d_in c_iᵀv̇_i^u − D^V − D^W ]/|c_i|²。
  D^W は §5 の第 1 層の引きずり。**D^V = Σ_m Θ_nm d_im (φ_n·φ_m + 1) v_iᵀH_m v_i^c は読み出しと出力 bias の引きずり**（読み出しが入力 n のラベルを覚えると、活性の似た入力の logit も動き、その残差の変化が unit i を票と逆向きに押す。unit i の感度のある入力で φ_n·φ_m + 1 ≥ 0 なら必ず逆向き）。残りの 2 項は、読み出しが動くことによる自分の票の変化。実状態の課題の頭（勾配流での目安）では、leaky は全部の対で D^V > D^W（3〜20 倍）。それなのに読み出しを凍結しても逆向きの対が 2〜3 割しか減らない理由は [未導出]（Adam の歩幅か、高次の項か）。
- **反例: 本物の CE では、門が無い 1 unit の網でも途中の時刻で逆向きになる** [数値で頑健。検証役が積分器 5 種と 30 桁の計算で再現]。1 unit・K = 2・非負の 2 次元の入力（= ロジスティック回帰）の勾配流で、ラベルを替えた入力の z の差が +1.93 まで上がったあと −0.41 になり、終わりは +0.067。同じ入力で曲率が一定（二乗誤差）なら全時刻で正。橋の定理（§4.2）は「CE のヘッセ行列を固定して入れれば成り立つ」まで言えていたが、曲率が時間で変わる本物の CE では 1 unit（橋の特別な場合）でも成り立たない。負が出たのは、途中で曲率が増える入力があり、そのノルムが先に効いている入力の 5 倍以上で、調べる入力が両者の間にある配置（必要条件かは示せていない）。無作為な 7,500 例（うち 1,500 例は課題切り替えの形）では負は 0。
- **補題: 曲率が増えない間は、入力ごとの感度つきの和は非負** [厳密・模型]。2 つのラベルの流れの差は δ̇ = b − Ã(t)δ（Ã は 2 本の流れの間で平均した曲率。線形化なし）で、dÃ/dt ⪯ 0 の間は bᵀδ ≥ ½δᵀÃδ ≥ 0。入力 n で感度のある unit が 1 つなら対ごとの文。曲率が増える区間のあとは使えない（その後に曲率が減っても、言えるのは「増えた区間の終わりの値より下がらない」だけ）。実際の課題では、曲率（1 − Σp² の平均）は課題の頭 0.60〜0.72 → 更新 400〜800 で 0.75〜0.85 → 課題末 0.61〜0.74 と前半に増えるので、補題は課題全体には届かない。
- **入力ごとの和の恒等式** [恒等式。実網・どんな学習でも]: Σ_i Cov_k(c_ik, φ_in(T;k)) ＋ 読み出しの変化の項 ＋ bias の項 = log K − mean_k CE_n(T;k) ＋ mean_k KL(u‖p_n(T;k))。[[押しと戻りの測定_収束の鎖と模様の上限とaの梯子_1001]] の CE = C + log K + G と同じ恒等式を、ラベルを替えた K 通りに当てたもの。実測では違反 0（8 状態 × 2 順 × 144 入力）、第 1 層の項が合計の 0.83〜0.94（入力ごとの比の中央値。ELU の課題 100 だけ 0.15〜0.22 で、第 1 層の項が正の入力も 64〜67%）。
- **経路分けの注意** [厳密なのは線形応答]: 力の合計は logit を変える向きだけを向くが、第 1 層の分・読み出しの分は、それぞれ「どの入力の logit も変えない向き」の成分を逆符号で持つ。片方ずつかけると、その成分の応答が積み上がる（引数 2 つの最小の例で、片方ずつは ±t に比例、和は頭打ち）。経路ごとの大きさと符号は、仕組みの量として読めない。
- 帰結: 「実網の課題全体で、対ごとに票の向き」は、仮定なしの定理にはならない（模型の閉路の反例に加えて、CE の反例）。実網で厳密なのは、課題の頭の 1 次と、入力ごとの和の恒等式。2 次の形と補題は模型の中（感度凍結・全データの勾配流）。対ごとの文は §12.2 の測定。補題と反例は初等的で、既出の可能性が高い（文献は照合していない）。

### 13.2 対の応答の書き直し（P44）と、その読みの訂正 [厳密・模型＋実測・模型。検証役が導出と数字を確認し、反例を足した]

**最初の版（P44、予測固定）。** 門の道の模型（リッジ）で、対の応答を「全部の感度が 1 の仮の unit の応答 A_in」と「感度の差 × 入力 n のラベルが入力 m の残差に出る分」に書き直した: R_in = d_in·A_in + Σ_{m≠n} W_nm (d_in − d_im)。A ≥ 0・W ≥ 0 なら開いた対は必ず正、という道。実状態では、A は当てはめを進めると開いた対のほぼ全部で負になり（正の割合 0.997 → 0.74 → 0.16 → 0。P44a ×）、「この道では届かない」と読んだ。

**Issa の指摘**（1002 夜）。「だから a × 閉じた入力からの引きずりは別にそれも『自己項』だから良いんだって。出力を減らす方向やん」「もしかしてまた同じ過ちを犯そうとしてた？」。

**訂正。** 最初の版の誤りは、基準を「全部の入力の感度が 1」に置いたこと。その基準では閉じた側が 1 倍の強さで A に入り、大きな敵に見える。閉じた側は同じ unit の自分の項の弱い側（a 倍）で、1001 に T₄（閉じた側の浮力）を自己項と別物に扱ったのと同じ型の誤り。説明に使った「A = 門が無いときの応答」「門が無ければ票と逆に動く」も誤りで、A は足し方だけを変えた帳簿の量（門の無い網の応答は ≥ 0。§4.5）。

**組み替えた形** [厳密・模型]。§4.5 の R = a·A + (1 − a)·B（A = T·1、B = T·1_開）の組み替えで、新しい量ではない。
- unit i の対の応答のベクトルは R_i = T_i d_i。T_i = Θ ∘ F_i（成分ごとの積。F_i は応答の行列を v_i の向きに射影した N × N）は、半正定値どうしの成分ごとの積なので半正定値（Schur の積定理）。d_i は感度のベクトル。
- leaky では d = 1_開 + a·1_閉（開いた入力・閉じた入力の指示ベクトル）で、開いた対の応答 = (T 1_開)_n + a·(T 1_閉)_n（開いた側だけの分 ＋ a × 閉じた側の分）。unit ごとに Σ_開 R = 1_開ᵀT 1_開 + a·1_開ᵀT 1_閉 = ½[dᵀT d + 1_開ᵀT 1_開 − a²·1_閉ᵀT 1_閉]。3 つの 2 次形式はどれも ≥ 0。
- unit が 1 個だけなら、どの対も応答 ≥ 0（d_n R_n = [M(M + λ)⁻¹]_nn。自分の入力を通る引きずりは縮めるだけで逆向きにしない）。§4.1 と同じ内容。unit が複数のとき保証されるのは、unit ごとの和 tr(M_i F_i) ≥ 0 と入力ごとの和（§4.1 の (a)・(b)）だけ。

**実状態** [実測・模型。leaky a 0.1 の 3 状態と a 0.3 の 1 状態 × λ 6 通り]。
- 開いた側だけの分 (T 1_開)_n は、開いた対の 100.00% で正（§4.3 の感度 0/1 版の結果に近い）。
- a × 閉じた側の分は負で、大きさは開いた側の分の 0.05〜0.19 倍（a 0.1）・0.13〜0.39 倍（a 0.3）（中央値どうし）。
- unit ごとの Σ_開 R > 0 は全 unit。Σ_閉 R > 0 は a 0.1 で全 unit、a 0.3 で 0.78〜1.00。
- コーシー・シュワルツ（|1_開ᵀT 1_閉| ≤ √(1_開ᵀT 1_開 · 1_閉ᵀT 1_閉)）から出る十分条件 a²·1_閉ᵀT 1_閉 ≤ 1_開ᵀT 1_開 は、a 0.1 で 52〜99%、a 0.3 で 18〜48% の unit で破れる。それでも開いた側の和は全 unit で正なので、この不等式だけでは説明にならない。

**反例**（検証役）[数値で頑健]。「交差の項が開いた側の強さより小さい」は、模型の中でも一般には偽。悪い向きへの局所探索で Σ_開 R ÷ 1_開ᵀT 1_開 = −2.06（a 0.1）・−3.37（a 0.3）の例がある（N 7・H 3・K 2・開いた入力 1 個。逆行列の残差 5e−13、Woodbury の形・リッジの直接解・50 桁の計算で同じ値）。無作為な例（3,000 例・4,152 unit と、別の 2,607 例）では一度も出ない。

**結論。** P44 の道は「届かなかった」でも「残りは交差の項の上界だけ」でもなく、「典型では成り立つが、仮定なしの定理にはならない。開いた入力の数・λ・入力の配置についての条件が要る」。§0 の残る穴 3（閉路）と同じ場所に戻る。

### 13.3 逆向きの対の中身 [事後。検証役が数字を再現し、読みを訂正]

## 15. 残りが自己項を覆すのに何が要るか: 反例の本質・理想化の符号則・閾値の段（1003。予測固定 P48・P49・P51、検証役 verify5・verify6）

Issa（1003）「反例は超少数で恣意的に作っているのだから、自己項の向きにならない本質をつかめるのでは」「反例の前提を壊すのが仮定として置く一番良い手。反例を思いついた経緯の逆が理論となるのでは」。この節は、その方針で反例ごとに「反例が要る状態」を素な量で特定した記録。

**語。** この節から、分け方の名前を **自己項／残り** の 2 つに固定する。読み出しの道では、自己項 = unit 単独（＋定数）のときの値 ⟨b̃, φ̃⟩（0930 §1(e) の C1 + C2 = M_c）、残り = ほかの unit の分 −⟨Pb̃, Pφ̃⟩（C3）。門の道では、自己項 = 自分の入力の項（m = n）、残り = ほかの入力を通る項（m ≠ n。冒頭の「言葉」の「引きずり」と同じもの）。**逆** = 自己項が正なのに、残りを足した合計が負。

### 15.1 反例と、反例が要る状態と、そうでない状態で言える文

### 15.2 読み出しの道: 逆になる本質 [数値で頑健。検証役 verify5 が自前の実装で再現し、読みを直した]

- **入力の数は本質でない。** 合成（入力の次元 50、unit 2〜100 個）で逆の割合は N = H + 1 の一点に山（H 20 で 0.19〜0.27、H 100 で 0.22〜0.38）、N ≥ 3H で 0.010 以下。この山は、偏相関を N − H 次元の残差で推定するときの標本のぶれ（補間の閾値）で、母集団の偏相関 ρ⊥ から合わせ込みなしの式 P(逆) = ∫₀^{arccos ρ⊥} sin^{d−1} ÷ ∫₀^π sin^{d−1}（d = N − H）で当たる（予言 0.246・0.312・0.211・0.280、実測 0.251・0.294・0.178・0.240）。自然な τ（ηT/(NK)）では、実状態の入力を 100 枚に間引いても逆は 0。山は当てはめ切った極限で評価することの性質。
- **入力を増やした極限の逆の割合 = 母集団で偏相関が負の unit の割合。** これが 0 でない型が 2 つ。
  1. 線形に近い unit。合成（leaky・開いた側の重み）で、開いた割合 p⁺ 0.7〜0.85 の unit の 0.22、0.85〜0.95 の 0.40 が逆。全部開いた ReLU の unit 2 つ（0930 §2.2b）は N = 10〜10,000 で D∞ = −1 のまま。逆の unit の p⁺ の中央値は leaky 0.85・ELU 0.70、逆でない unit は 0.39・0.26。
  2. 複製。重みを少しずらした写しがあると、N ≫ H でも 33〜57/60 組で逆。
- **残りは押しを小さくするとは限らない。** 分子どうしの比 \|残り\| ÷ 自己項 は H 100 で 0.62〜0.92 だが、分母 ‖φ⊥‖² も同じだけ縮む。押しそのもの（D∞ ÷ unit 単独の値 − 1）で比べると、ほかの unit の効きは合成で −52%〜+16%、実状態で +80%（leaky a 0.1）・−1%（ELU）・+35%（leaky a 0.3）。式は b̃ = cφ̃ + e（e ⊥ φ̃）と分けて D∞ = c − ⟨e, Pφ̃⟩/‖φ⊥‖²。
- **ポテンシャルの形** [恒等式。b = Kφ′ のとき]: ⟨b, φ⊥⟩ = \|x̄\|² ∂/∂m ½‖φ⊥‖²（中央差分と相対 6e−8）。読み: 押しが自己項の向き ⟺ unit を開くと、出力のうちほかの unit が表せない部分が増える。開いた側だけの b では成り立たない。
- 重みが開いた側なら、N ≥ 2H でどの τ でも逆は 0（実状態もどの τ でも 0）。重みが全体のとき「どこかの τ で負」が 0.4〜0.7 と高いのは、unit 単独でも同じ割合で負（生の内積 b·φ < 0）で、残りではなく自己項の基準の話。

### 15.3 理想化の符号則 [厳密・理想化の模型。検証役 verify6 が求積（差 5e−14）とモンテカルロで確認]

**置き方。** 前活性 z ~ N(0,1)、閾値 t（開いた割合 p⁺ = P(z > t)）、ReLU、押しの重み b = K·1[z > t]、明るさ K = K̄ + σ_K(ρz + √(1−ρ²)w)（w は z と独立）、ほかの unit が表せるのは定数と線形の関数だけ（山は表せない）、読み出しの道の τ → ∞。

**式。** ⊥ を「定数と z で表せない部分」として

D₁ = K̄·⟨1[z>t]⊥, (z−t)₊⊥⟩ + σ_K·ρ·Var(1[z>t]⊥)、Var(1[z>t]⊥) = Q(1−Q) − φ_G(t)²（Q = p⁺、φ_G は標準正規の密度）。

- 第 1 項 = −(K̄/2)·∂_t Var((z−t)₊⊥)。(z−t)₊⊥ = ½\|z−t\|⊥ なので、この分散は t の偶関数で t = 0 が最大。符号は t の符号: **半分より多く閉じていれば正（自己項の向き）、半分より多く開いていれば負。**
- 第 2 項は、明るい入力ほど閉じている（ρ < 0）と常に負。K のうち z と相関しない部分は式に入らない。
- 境目（合計が 0 になる p⁺。K̄/σ_K = 3.5）: ρ 0 で 0.500、−0.3 で 0.454、−0.6（実状態の値）で 0.406、−0.8 で 0.371。
- 線形の部分を割合 q だけ表せる場合は (1−q)·自己項 + q·D₁（凸結合）。両方が正の深さでは、どの q でも正。最悪の取り方でも境目は 0.406 → 0.389。
- unit 単独の自己項は ρ = 0 ならどの t でも正。つまり「unit 単独では正、ほかの unit が線形の部分を取ると、半分より多く開いた unit で逆」。

**leaky** [恒等式。入力の分布の仮定なし]: 明るさ K と前活性 z の両方をほかの unit が表せれば、押しの期待はちょうど (1 − a)² × ReLU の値（実の z・K で 2.6e−15）。

**ELU**: 境目は c = 幅 ÷ α に依る。

| | ρ 0 | ρ −0.6 |
|---|---|---|
| c 1・重みは全体（b = Kφ′） | 0.248 | 0.126 |
| c 1・重みは開いた側 | 0.636 | 0.552 |
| c 25（実の ELU は 15〜25）・全体 | 0.484 | 0.390 |
| c 25・開いた側 | 0.519 | 0.426 |
| c ≤ 0.3・全体 | 正の領域なし | 正の領域なし |

**限界。** (1) 深い側（p⁺ 2e−8〜8e−4）に 2 つ目のゼロがある。ガウスの K が負になる所で、実の K（最小 ÷ sd = 1.22）には無い。(2) 大きさは合わない（unit ごとの t・ρ を入れた値は実の値の 0.28〜0.91 倍。符号は合う）。(3) 0930 §2.2b（全部開いた unit 2 つ）はこの型の端ではない（φ⊥ = 0 で、係数 −1 は完全な共線から来る別の仕組み）。(4) 大きい α の ELU で押しの符号が半々になること（α 梯子、0925〜29）はこの式では説明できない（式の予言は系統的な逆）。

**仮定の形の検査**（§14.6 の 3 つ。検証役）: 「unit は境目より多く閉じている・自分より深い複製が無い」は、結論の移項ではなく（検査 1 ○）、押しの重み b を見ずに測れる（検査 2 ○）。検査 3（条件の外に破れる例が落ちるか）は 2 点を直して通る: 境目を活性化と重みごとに取ること（合成の ELU c 1・全体の重みは p⁺ 0.30〜0.41 で 35% が逆）、複製を「より深い複製」に限ること（同じ向きで閾値だけ違う写しは、深い方が 20/20 で逆、浅い方は 0。分散した部分的な写しは、30 unit・山の R² 0.63 まで逆にならない）。十分条件としては粗い（実の特徴の反実仮想では p⁺ 0.7 まで逆 0）。

### 15.5 門の道の模型で、閾値の両側を合わせた unit ごとの正味 [実測・模型。予測固定 P49。検証役の確認は未]

- 正の unit は全部の組で 0.978〜1.000。開いた側だけの和は全部の組で 1.000。閉じた側だけの和が正の unit は a 0.1 で 0.95〜1.00、a 0.3・λ/λmax ≤ 1e−4 で 0.11〜0.71。

### 15.7 言えること・言えないこと

言える:
1. [厳密・理想化の模型] 読み出しの道（τ → ∞）で、ほかの unit が線形の関数を全部表し、前活性がガウスなら、押しの符号は §15.3 の D₁ の符号。ReLU では、開くと「線形で表せない部分」が増えるのは半分より多く閉じているときだけ。明るさとの逆相関が境目を 0.41 に動かす。
2. [恒等式] leaky で K と z をほかの unit が表せれば、押しの期待は (1 − a)² × ReLU の値。保存した実の特徴では、閉じた側の項は開いた側の 0〜3.5%（τ → ∞、中央値）。
3. [数値] 読み出しの道で実際に逆になる unit は「より深い複製」（開いた入力 1〜2 個で、開いた集合がほかの unit に含まれる）。
4. [数値・反実仮想] 実の特徴で逆が出始めるのは p⁺ 0.7 より上。

言えない（検証役が落とした文）:
1. 「p⁺ < 0.41 なら、実網で押しは自己項の向き」。模型の中の十分条件で、α が幅に近い ELU では成り立たず、学習の始め（p⁺ ≈ 1/2）を覆わない。
2. 「線形の背景の自己項は、実網ではほかの unit に取られて消える」。中央値についてだけ。unit ごとには、実の閉じた側の項は符号が半々で、模型の値との順位相関は −0.25〜+0.10。
3. 「uniform_self の 98% の打ち消しはこの符号則で説明できる」。理由は「K が層で表せる（R² 0.97〜0.996）＋読み出しがほぼ定常」（残差の 98% 以上が読み出しの非定常）。unit ごとの打ち消しは 80〜90%。
4. 「leaky の恒等式が位置の式を与える」。言えるのは M_c のゼロ点が止まり点でないこと（全 unit を閉じる向きに 1.5 sd までずらすと M_c > 0 は 0.18〜0.48、ほかの unit 込みの押しは 0.87〜1.00 で正）までで、位置の落ち着き先は言わない。
5. 「同じ文が門の道でも言える」。読み出しの道の記憶は回帰係数（N > H + 1）で、ほかの unit が表せる成分の係数は 0 になる。門の道の応答は unit ごとの第 1 層の配分（重みの数 ≫ 制約の数）で、重なる向きは除かれずに分け合われ、自分の対角は常に正。門の道では線形の背景は閉じた対の 97〜100% で正（守る側）で、符号を壊すのは山の側（共有する開いた入力と閉路。§4.2・§4.5）。役が読み出しの道と逆。

### 16.4 勾配の出どころの帳簿 [実測・帳簿・P53。課題末の前活性は既存の回し直しと bit 一致（144/144 入力）、集計は別実装で 408 セル一致]

**作り方。** Adam の一歩は 1 次モーメントに線形なので、実際の分母（2 次モーメント）をそのまま使えば、重みの動きを勾配の出どころごとに厳密に足し分けられる（[[押しと戻りを残差で分ける_古い自信の消え方と揃いの育ち方_1002]] の帳簿と同じ型）。対 (i, n) の課題中の前活性の動きを 4 つに分ける: **自分の入力の分**（入力 n 自身の勾配が第 1 層を動かした分を x̃_n に当てたもの）、**ほかの入力の分**を 2 つ（勾配が出た時点で unit i がその入力に開いていた／閉じていた）、課題の頭に持ち越された 1 次モーメントの分（どの対でも 1e−6 以下）。それぞれを票に回帰した傾きが R̂ の内訳。4 つの和と実際の動きの差は最大 6e−4（float32 の丸めを別に積んで足すと 3.5e−13）。走は leaky a 0.1・a 0.3・ELU の課題 100（seed 0）× 48 入力 × ラベル 10 通り × 順 A。

**これは帳簿の分け方で、自己項／残り（unit 単独 対 ほかの unit）ではない。** 「ほかの入力の分」のラベル依存が unit 自身の動きから来たのか、ほかの unit の動きから来たのかは、この帳簿では分けられない。反実仮想の説明は付けない。

### 16.6 1 次元の比較原理 [厳密。対の前活性が下の形に従う場合]

対の前活性が ż = d(z)·c·A(t) + B(t) に従うとする。d(z) = 1（z > 0）・a（z < 0）、0 < a ≤ 1、A(t) > 0、B(t) は任意（ラベルによらない）。閾値の上は Filippov の意味で解く。

- **主張**: 同じ始点から出た解は、票 c について単調（c > c′ なら全部の時刻で z(t; c) ≥ z(t; c′)）。
- 理由: 2 つの解が同じ値で出会った時点では感度が同じなので、速度の差は d·(c − c′)·A > 0。閾値の上で出会った場合も、開いた側の速度 cA + B と閉じた側の速度 a·cA + B の両方が c について増加なので、c の解が止まる（閉じた側から上へ・開いた側から下へ押される）とき c′ の解は止まるか下がり、c′ の解が上がるとき c の解も上がる。
- 帰結: 課題末の門 1[z > 0] も c について単調なので、Σ_k c_k = 0 から揃い G = (1/K)Σ_k c_k g_k ≥ 0、票への傾き R̂ ≥ 0。**門がどう動いても（閾値で止まる場合・途中で越える場合を含めて）、門の動きそのものは単調性を壊さない。**
- 壊しうるのは、A と B がラベルに依る分（ラベルに依る項がほかの入力の勾配を通って入る分。§16.4 の「ほかの入力の分」）だけ。

### 16.7 門の道で言えること・未証明の中身（1003 時点）

言える:
1. [厳密・模型] 線形だけの網（全部の感度が等しい）なら対の応答は ≥ 0（§4.5）。開いた対は、開いた入力を共有する unit の閉路が無ければ ≥ 0（§4.2）。弱い対は閾値の式（§4.4）。
2. [厳密] 対の前活性が「自分の入力の押し ＋ ラベルによらない動き」なら、門がどう動いても票について単調（§16.6）。
3. [実測] 実網で票への傾きが正の対は、開いた対 96.5〜98.3%、leaky の閉じた対 96.1〜98.5%。門がラベルで動く対の揃いの符号は 98.5% で票への傾きの符号（§15.6）。unit ごとの正味は 1,277/1,279 で正。
4. [実測・帳簿] 応答は「自分の入力 ＋ 閉じた入力を通る分」（99.4〜100% の対で正）と「unit の開いた入力を通る分」（負に寄る）の 2 項で、合計が負になるのは後者が大きい対（§16.4）。模型の 2 項と同じ形。
5. [実測] leaky では、票が負のラベルの対は閾値で止まる（§16.2）。

未証明の中身（条件の形にしないで、素な量で書く）:
- unit の開いた入力を通る分が、線形の背景の分を上回らないこと。実測では、この分は閉じた対で合計の 3〜16%（中央値）、開いた対で 6〜9 割。上回る対は 2〜5% で、その半分はバッチ順の揺れ。課題前の量（浅さ・開いた入力への近さ・開いた入力の数）は AUC 0.64〜0.73 でしか分けない。
- 「自分の入力 ＋ 閉じた入力を通る分 ≥ 0」は、線形だけの網では厳密だが、開いた入力のある網での不等式は無い（実測 99.4〜100%）。
- CE と Adam のもとでの時間の形（自分の分もほかの分も課題末まで増え続ける。閉じた対の合計が a によらない理由）。

置かない条件: 「ほかの入力の分が自分の入力の分より小さい」は R̂ > 0 の移項（§14.6 の検査 1）。帳簿は余裕の大きさの記述にだけ使う。
