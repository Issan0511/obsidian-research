# 累積の期待押しを直接扱う — 3 つの押し・凍結/適応の分解・反例が累積に効く量（1013）

## 1. 「押し」を 3 つに分ける [定義]

| 量 | 中身 | 何についての期待 |
|---|---|---|
| (i) 実変位 D_t | m_i(θ_t) − m_i(θ_{t+1}) | 累積は恒等式 (6)（検算済み） |
| (ii) 切替の押し S_i(θ) | Σ_n K_n d_in⟨v_i, p_n − u⟩（実 softmax） | 新ラベルについての最初の一歩の期待 [厳密]。模型なし |
| (iii) 容量の押し A_i(θ) | ∂Φ/∂t_i（凍結核・リッジ・古いラベルの期待） | (ii) の模型平均。瞬間の反例 A ≤ 0 < 自己項 はここ |

Codex の README の「累積の期待押し」は (iii) の Σ_t A_i(θ_t)。Issa の「長期的期待値での押し」は (ii)(iii) の時間平均と (i) の累積のどれにも読める。**3 つとも実測では累積が全 unit で沈める側（§4）。正味の沈降の符号を決めるのは (i) の課題内の釣り合いで、(ii)(iii) の符号ではない。**

## 2. 厳密に言えたこと

1. **CE の勾配の分解** [厳密]: L_Y = L_U − G_Y、L_U = (1/N)Σ KL(u‖p_n) + log K、G_Y = (1/N)Σ⟨e_{Y_n} − u, f_n⟩。各入力のラベルの周辺が一様なら、どの θ でも E_Y∇G_Y = 0（入力間の独立性は不要）。位置の力は F^Y = F^U − F^{G,Y}、全データなら F^U = S_i/N。
2. **一課題の力の経路積分の分解** [恒等式]: Adam の実軌道に沿った位置勾配の経路積分 G = Σ_s F_i(s) について、(a) G = G^U − G^G（確信／ラベル。課題末に向けて同じ大きさで打ち消し合い |G| の 20〜100 倍）、(b) **G = G0 ＋ Gad**（係数 d_in v_i を課題の頭で凍結した分 ＋ 適応の分）。
3. **凍結の分の期待** [厳密]: E_Y[G0 | θ_t] = Σ_s S^{B_s}[θ_t; p̄(s)]、p̄_n(s) = E_Y[p_n(θ_s)]（ラベル平均した予測の経路）。古い自信が消えていく間、凍結した unit が受け続ける切替の押しの積算。p̄ が縮むだけなら τ_n で重みづけた切替の押し [仮定つき]。
4. **鎖の恒等式** [恒等式]: 課題末のラベルの力 = 次の切替の押し/N − 課題末の当て残しの位置勾配。この箱では当て残しは次の押しと同じ桁で符号は半々（正答率 0.60〜0.75）。
5. **読み出しの適応は散逸** [厳密・模型（読み出しの勾配流・特徴凍結）]: ∫(1/N)Σφ_in⟨Δv_i, r_n⟩ = −½|Δv_i(T)|² ≤ 0。位置の適応 Gad は重みが K_n d_in なのでこの恒等式そのものではない。
6. **反例が累積に効く量** [恒等式]: Σ_t a_t > 0 ⟺ 反例の課題の |a| の和 < 残りの和。「生成が解消を上回らない」の正しい形は「反例にいる課題の割合 × 大きさ < 平均の押し」。実測の平均 A/自己項 0.23〜0.46 では、累積を 0 以下にするには課題の 14〜32% で反例が要る（反例の大きさを自己項の 1〜2.8 倍として。P171 の注入は ≤ 2.8）。
7. **Adam の最初の一歩の期待** [厳密]: 有限ラベルの 16 重畳み込みで有限。線形領域（新しい勾配 ≪ √v₀）では切替の押しの K_n を前処理した明るさ K̃_n = Σ_j x̄̃_j x̃_nj/√v₀_j に替えた形 ＋ 運動量の持ち越し。飽和領域では画素ごとの符号の投票で、SGD と符号が一致するのは第 1 バッチの c_n が同符号のとき。

## 3. 言えないこと [未導出]

(a) 累積の相殺率 Σ(自己項 − A)/Σ 自己項 が 1 未満に留まる機構（実測 0.54〜0.77 で安定。定理 6 は無作為な並びの基準で、実際の並びは 2〜5 倍不利な側）。(b) G0 − Gad > 0（課題内の釣り合い = r*。P167 で問わない）。(c) 反例の課題の割合 ρ_R = 0 の導出（H4 の寿命・新生は実測）。(d) Adam の 2 歩目以降の期待。

読み [実測]:
- (i)(ii)(iii) とも累積は全 unit で沈める側。(iii) の相殺率 0.54〜0.77 は unit 間でも時間でも動かず、瞬間の反例は 1 つも無い。(ii) は課題ごとには 6 割しか沈める側でないが累積では全 unit。
- 正味の沈みは押しの累積の 1〜7%。1 課題の変位は揺らぎ優位（Δm/s の 10〜90% は ±0.6、Δr の sd は |r| の 2 割）。2 点分解では幅の伸びが沈みの大半（G0「沈みは幅に従う」）。課題ごとの和の分解 Σ r_tΔs_t は r_t と Δs_t の負の共分散でほぼ消えるので 2 点で読む。
- **符号が unit を通して揃うのは凍結／適応の分解だけ。** 凍結した係数で受ける力は全 unit が沈める側、適応で生じる力は全 unit が浮かせる側、正味はその 1〜7% の差。確信／ラベルの分解は課題末で同じ大きさで打ち消し合い（|G| の 20〜100 倍）、残差のクラスやゲートで割る 1002 の帳簿は割り方で読みが変わる。
- Adam の実変位は勾配の経路積分と符号が 9 割以上一致するが大きさは SGD の 90〜170 倍。Adam の最初の一歩は線形領域で、押しの部分は SGD の切替の押しと符号 98% 一致（`adam_stationary_b16` 型の反転は実状態では起きない）。ただし一歩は押しの 0.03%。
- 課題末は当てはまっておらず（正答率 0.60〜0.75）、凍結の分は時間に比例して積もり続け、適応の分がそれを追う。鎖の恒等式の当て残しは次の押しと同じ桁。
