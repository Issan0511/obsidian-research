## 0. 答え

**先に言葉（詳しくは §1）。**
- 全閉 = unit の全入力で z ≤ 0。死 = 切替の時点で全閉。
- 床 = この CPU の float32 で ELU の微分が厳密に 0 になる深さ（z < −16.6355）。凍結 = unit の z の最大値が床より下にあること。
- 閉じた回 = unit が全閉になってから、開き直るか凍結するまでの一続き。着地 = その最初の課題末の深さ。
- 溜まり = 床の手前の深さ約 15。閉じた unit がほとんど動かなくなる所。
- 第 1 層だけ ×m = 第 1 層の lr だけを m 倍した腕。全層 ×m、α 梯子とは別の箱（§1）。
- online = 課題中の正答率の平均。
- 切替 = 課題（乱数ラベル）の入れ替え。押し = 切替から 500 更新までの動き。
- k = unit の開いた入力（z > 0）の数。N = 入力の数（1,200）。p⁺ = k/N。k* = k の釣り合いの値。
- 読み出し = 第 1 層の unit から次の層への重み（1 層では出力層の列 v_i、2 層では W2 の列）。
- 管 = 深く閉じた入力の出力 −1 を通って、ミニバッチ誤差の和が読み出しの勾配に入る経路。
- lr₁ = 第 1 層の lr。expm1 の微分 = ELU の微分を「出力 + 1」で作る自動微分（この CPU で床を作る）。

### 0.1 学習率の閾値に見えた件

- **不連続な閾値は無い [実測]。** 第 1 層だけ ×m の腕で、課題 200 の凍結の割合は m 1・4・6・8・11・16 で 0・0.075・0.215・0.35・0.565・0.76（2 seed 平均）と滑らかに増える。半分に達するのは課題 200 で m ≈ 10、課題 50 では m ≈ 12。
- **凍結の割合は 2 つの量の積に等しい [厳密、§4.1]。** unit あたりの閉じた回の数と、閉じた回が凍結で終わる割合。m 4 から 16 では、閉じた回の数は増えない（10.2 → 4.4。死んだ unit はもう閉じないので減る）。増えるのは凍結で終わる割合で、0.7% → 17% と 23 倍になる [実測]。
- **S 字に見える理由 [条件付き、§4.5]。** 死で打ち切られなければ起きたはずの閉じた回の数は、m 4〜11 で 10.5〜11.8、m 16 で 8.3 とほぼ一定。凍結で終わる割合だけが 23 倍になり、1 − exp(−回数 × 割合) が飽和する。
- **閉じた回が溜まりまで沈む確率は、閉じた unit の酔歩の模型で書ける [条件付き、§4.2]。** 閉じた unit は課題ごとに少しずつ沈み、ときどき開き直る。式と実測の比は、新しい腕（m 6・8・11）で 1.24・1.13・1.09。
- **以前「×4 と ×8 の間の閾値」に見えた理由 [実測]。** (a) α 梯子は、第 1 層の lr のほかに第 1 層の初期値と ε、出力層の初期値・lr・ε も写す。そのため同じ ×8・×16 で凍結が 12〜14 pt 多い（α = 1/8 で 0.49、第 1 層だけ ×8 で 0.35）。どの写像が差を作るかは分けていない。(b) 課題 200 で切った S 字の急な部分を見ていた。
- **「死ぬのは 1 回の切替の押しが床を越えるとき」（元ノート §8.5・§8.10）は撤回する。** 第 1 層だけ ×8 の probe 走（最初の 30 課題・2 seed・到着 32 件）では、床への到着の 66% が閉じたまま課題ごとに沈んで着いたもので、切替での落下は 0。×16（120 件）でも切替での落下は 20% にとどまる [実測、§4.6]。
- **式が無いもの [未導出]。** 開き直りの率・着地の深さ・閉じた回の数が lr でどう変わるか。溜まりに届いた回が凍結で終わる割合が lr で上がること（第 1 層だけ ×4 → ×16 で 0.42 → 0.77。凍結で終わる割合の 23 倍のうち約 1.8 倍はこれで、酔歩の模型の外）。

### 0.2 ELU→leaky が崩壊した件

- **RL-MNIST の 2 層 ELU→leaky では、第 1 層は死なない [実測]。** W2 の列（第 1 層の unit の読み出し）は課題 50 で 6.5〜7.6 倍に育つが、凍結は 0。第 1 層の状態は 1 層の箱と同じ程度（課題 50 で、2 層は k 12・18・全閉 0.02・0.03、1 層は k 8・11・全閉 0.05・0.02）。
- **RL-CIFAR の第 1 層の死は、歩幅の尺度が主因 [介入]。** 生 CIFAR の入力の ‖x‖₁ は MNIST の 14.2 倍で、1 更新の z の歩幅で比べると lr 1e−3 は MNIST の第 1 層だけ ×14 に当たる。第 1 層の lr を 1/16 にすると、課題 50 の全閉は 74〜87% → 5〜12% に下がる（CPU 再現、seed 0・1）。
- **Issa の「W2 が育ったから」は、半分当たっている [介入・MNIST]。** 第 1 層だけ ×16 のとき、W2 の列を初期値のまま育てないと、課題 50 の凍結は 0.63 → 0.10 と 8 割以上減る。列を 0.2 まで抑えると 0.02 になる。一方、×1 では列が 3.7 まで育っても凍結は 0（育つだけでは凍結しない。ただし列を 1.0 に抑えた ×1 の腕と比べると、押しで全閉になる率は約 7 倍になる。0.027 対 0.004）。×16 では育てなくても 7〜13% が凍結する。
- **CIFAR では W2 を止める介入をしていない。** CIFAR で言えるのは、lr₁ を 1/16 にすると W2 はむしろ大きく育つ（‖W2‖ 24 → 73〜77）のに第 1 層が死ななくなる、まで [介入]。
- **CIFAR のエンジンには expm1 の床が無い [実測]。** 第 1 層の微分は手書きの e^z。ここでの死は課題末の全閉で、§4 の床での吸収とは別の量。床の代わりに何が戻りを止めているかは測っていない [未導出]。
- **CIFAR の崩壊の残り半分は死ではない [介入]。** 全閉を 5〜12% まで減らしても、online は 0.36〜0.44 に留まる（lr₁ を揃えた leaky→leaky は 0.66）。第 1 層を課題 5 で凍結しても 0.40 なので、第 1 層が学べなくなることによる。機構は [未導出]。

## 1. 箱・腕・言葉

**箱。** 1 層は 784-100-10、生 MNIST/255、N 1,200、K 10 の乱数ラベル、バッチ 16、4,000 更新/課題、Adam（lr 1e−3、β 0.9/0.999、ε 1e−8）、float32、ELU の微分は expm1 の自動微分。断りが無ければ 2 seed（seed 0・1）。2 層は RL-MNIST 784-100-100-10 と RL-CIFAR 3072-100-100-10。

**腕の 3 種類。** 同じ「×m」でも箱が違うので、必ず区別して書く。
- **第 1 層だけ ×m**: 第 1 層の lr だけを m 倍する。m = 4・6・8・11・16。今夜の腕（6・8・11）と既存の腕（4・16）。
- **全層 ×m**: 両層の lr を m 倍する。m = 1/4・1/2・1・2・4。m = 1 は基準の腕で、第 1 層だけ ×1 と同じ走。
- **α 梯子**: α·ELU(z/α)。第 1 層の初期値と lr を 1/α 倍・ε を α 倍し、出力層の初期値と lr を α 倍・ε を 1/α 倍した標準 ELU と同値（§2.5）。第 1 層だけ ×(1/α) とは同値でない。課題 200 の凍結は α = 1/4・1/8・1/16 で 0.085・0.49・0.88、第 1 層だけ ×4・×8・×16 で 0.075・0.35・0.76 [実測]。

**言葉。**
- 開いている: 入力 n が unit i で z_in > 0。k = unit の開いた入力の数。p⁺ = k/N。
- 全閉: k = 0。死 = 切替の時点で全閉（課題 151〜200 の平均で数える）。
- 上端 = unit の z の最大値。本体 = unit の z の入力についての中央値。幅 s = z の入力についての標準偏差。
- 深さ y = −上端（全閉の unit）。
- 凍結 = 上端 < −16.6355。expm1 の微分の腕では戻らない（§4.1）。厳密な微分の腕では深さの目印にすぎない。
- 押し = 切替から 500 更新までの動き。持ち上げ = 課題の残りの動き。
- 読み出し v_i = 出力層の i 列（K 次元）。v_i^c = v_i からクラス平均を引いたもの。大きさは |v^c| で読む（§2.2）。
- 管 = 深い閉じた入力の出力 −1 を通って、ミニバッチ誤差の和が読み出しの勾配に入る経路（§2.1）。
- ブレーキ = 管の揺らぎで Adam の分母が膨らみ、読み出しの当てはめの一歩が縮むこと（§3.1）。
- 閉じた回 = unit が開いた状態から全閉になり、開き直るか凍結するまでの一続き。開いた unit が 1 課題で床の下まで落ちた場合も、1 回と数える。着地 = 閉じた回の最初の課題末の深さ。
- 溜まり = 床の手前の深さ約 15。ここでは閉じた unit の課題ごとの沈みの中央値がほぼ 0 で、揺れ（四分位幅）も 0.2（深さ 4〜7 では中央値 1.8・四分位幅 1.9。第 1 層だけ ×4）。
- 眠り = 閉じた直後、Adam の v̂ が開いていた頃の大きい勾配を覚えていて、一歩が小さい期間。
- 行き過ぎ = 1 回の大きな動きで床を越えること。起き抜けの蹴りと、開いた unit の切替での落下の 2 種類（§4.6）。

**酔歩の記号。**
- r = 閉じた unit が次の課題末までに開く確率。ρ = −ln(1 − r)（開き直りの率）。
- δ = 開かなかった課題の沈みの平均。σ = 沈みの揺れ（四分位から求めた頑健な幅、IQR/1.349）。
- θ = (√(δ² + 2σ²ρ) − δ)/σ²（深さあたりの減衰の定数）。
- n_閉 = unit あたりに実際に起きた閉じた回の数。Λ = 死で打ち切られなければ起きたはずの回数。
- q_溜 = 閉じた回が溜まり（y ≥ 15）に届く確率。π_床 = 溜まりに届いた回が凍結で終わる割合。q_床 = π_床 × q_溜 = 閉じた回が凍結で終わる割合。

## 2. 厳密な部品

**2.1 逆伝播の形と管の恒等式 [厳密]。** g_{z_in} = φ′(z_in)(v_i·e_n)、g_{v_i} = ⟨φ(z_in) e_n⟩（e_n は出力の誤差、⟨ ⟩ はバッチ平均）。z の力は必ず φ′ を背負い、v の力は φ だけを背負う。任意の定数 a で g_{v_i} = a g_c + ⟨(φ(z_in) − a) e_n⟩（g_c = ⟨e_n⟩ は出力バイアスの勾配）。ELU で a = −1 と置くと、深い入力は第 2 項に e^z しか入らない。第 1 項は全 unit に共通で、ミニバッチの誤差の和そのもの。

**2.2 ゲージ [厳密]。** 交差エントロピーは v_i → v_i + λ·1 で変わらない。Σ_k e_nk = 0 なので、SGD はこの向きに動かない。Adam は座標ごとの分母が違うので動く。生の |v| はこの成分を含む。機能するのは v^c で、ELU では時間とともに縮む（seed 0 の課題 10・50・100・200 で |v^c| 1.62・1.29・0.65・0.41、同じ時点の生の |v| は 1.6・1.3・0.8・2.0）[実測、並走]。ゲージ成分（出力層 v の全要素の平均）の符号は腕で違い、ELU では負（課題 200 で −0.67）、GELU/GELU では正（+13.2）[実測、並走、seed 0。理由は未導出]。

**2.3 ELU の微分と数値の床 [厳密・実装依存]。** φ′(z) = e^z（z ≤ 0）。expm1 の自動微分は「出力 + 1」で微分を作る。この CPU の float32 では z < −16.6355 で微分が厳密に 0 になる。CUDA の自動微分では −16.98、手書きの e^z では −103.97（flush_denormal の下では −87.3）まで 0 にならない。§5 の GPU のキメラと RL-CIFAR のエンジンは手書きの e^z で、−16.6355 の床が無い。

**2.4 Adam。**
- [厳密] ε = 0 なら、ある座標の勾配の履歴に共通の正の倍率を掛けても、一歩は変わらない。ε があるときは、倍率 c を掛けることは ε を ε/c に替えることと同じ。
- [厳密: g = 0 で、更新数 t ≫ 1/(1 − β₂) のとき。g² ≪ v̂ なら近似] ln v̂ は 1 更新あたり ln β₂ = −1.0005×10⁻³ ずつ変わる。閉じた unit の実測の傾きは、第 1 層だけ ×8・×16 で −1.000×10⁻³、基準で −0.976×10⁻³（probe 走・seed 0）。
- [厳密] √v̂ ≪ ε の座標では、Adam は歩幅 η/ε の SGD になる。条件は今の |g| ではなく √v̂ にかかる。v̂ に古い大きい勾配が残っている間は、|g| ≪ ε でも ε はほとんど効かない。閉じた unit の深さ 14〜16.6 で、ε による一歩の縮みは第 1 層だけ ×16 で 4%、×8 で 25% [実測、probe 走・seed 0・最初の 30 課題]。
- [条件付き: 足す揺らぎが元の勾配と負に相関しない、時間的にほぼ無相関、m̂ と v̂ の共分散が小さい、ε が無視できる、状態が β₂ の窓で定常] 同じ座標に入る平均 0 の揺らぎは √v̂ を膨らませ、平均の一歩を縮める。一歩 ≈ −η ḡ/√(ḡ² + σ_g²)（ḡ は勾配の平均、σ_g は揺らぎ。並走 THEORY_v2 の式 (4)）。定理ではない。共分散が負なら分散は逆に減り（箱では課題 1・2）、時間相関が強いと符号まで外れる反例がある。SGD では平均 0 の揺らぎは 1 歩の平均を変えない。

**2.5 α の写像 [厳密]。** α·ELU(z/α) の網は、第 1 層の初期値と lr を 1/α 倍・ε を α 倍し、出力層の初期値と lr を α 倍・ε を 1/α 倍した標準 ELU と同じ軌道を通る。α が 2 のべきなら float32 でもビット一致する（元ノート §8.4 の腕 D）。第 1 層の lr だけを 1/α 倍した網は同値ではない。

**2.6 数の恒等式と不等式。**
- [厳密] 平均の p⁺ = ū/H。ū は、入力 1 つを開いている unit の数の、入力についての平均。
- [厳密・分布によらない] Cantelli の不等式から、z の入力についての平均 z̄ と幅 s について z̄/s ≤ √(p⁺/(1 − p⁺))。p⁺ = 0.02 なら z̄/s ≤ 0.14。平均が折れ目から大きく上に出ることはできない、という上限だけを与える。
- [条件付き: unit の z の塊がほぼ正規分布] 本体/s = Φ⁻¹(p⁺)。
- [条件付き: 全閉の割合が時間で一定で、吸収が無い] 開いた unit が全閉になる割合を μ₊、全閉の unit が開く割合を μ₋ とすると、全閉の割合 = μ₊/(μ₊ + μ₋)（先生の定理 7.1 の形）。基準の lr の、前向き/逆向きを入れ替えた 5 腕（ELU/ELU・GELU/ELU・ReLU/ELU・ELU/GELU・GELU/GELU、課題 51〜200）で、実測と 0.01 以内 [実測]。凍結が起きる lr では吸収があるので使えない。

**2.7 管の割合はバッチによらない [厳密・パラメータを止めたとき]。** 管の揺らぎも当てはめの信号の揺らぎも、同じミニバッチの平均なので、同じ有限母集団の因子 (N − B)/(B(N − 1)) を持つ。読み出しの揺らぎに占める管の割合はバッチの大きさ B によらない。B = N でだけ両方が 0 になる。

**2.8 深さは ε の倍率（元ノートの命題 E）[条件付き]。** 条件は 4 つ。全閉であること。v̂ の記憶が抜けていること。下げた状態が β₂ の窓（約 1,000 更新）より長く続くこと。前向きの出力の変化による誤差の変化を無視できること。このとき、全閉の unit の全入力の z を Δ だけ下げると、φ′ が e^{−Δ} 倍になり、その unit の第 1 層の勾配が e^{−Δ} 倍になる。§2.4 の 1 つめから、これは ε を e^{Δ} 倍にすることと同じ。閉じた unit の勾配の RMS は e^{上端} に比例する（状態をまたいだ傾き 0.94〜1.04、unit の中の傾きの中央値 0.92〜1.10）[実測]。

## 3. 生きている unit の理論（保持）

### 3.1 ブレーキ

**管がある [厳密、§2.1]。** 基準の腕では、unit あたり約 1,150 個の入力が深く閉じている。その出力 −1 が、ミニバッチの誤差の和を全 unit の読み出しの勾配に入れる。

| 窓 | 消える割合 | 一歩の比（管なし ÷ 管あり） |

**ブレーキを外すと崩れる [介入・基準の腕]。**

### 3.2 読み出しが小さいと、開いた入力が高い

- [条件付き: 各入力の、床から測った出力 v·(ELU(z) + 1) を止め、logit を固定したとき] 出力を変えない動きは、開いた側で (z + 1) を 1/v 倍、閉じた側で z を log(1/v) ずらす形になる（二群模型、元ノート §8.44）。logit を固定した走では、閉じた側のずれが ±0.1 まで合う。RL の箱では出力そのものが v とともに変わるので、この条件は破れる。言えるのは向きまで。

### 3.3 押しは読み出しの大きさによらない

- [条件付き: v_i の向きが同じ、|v_i| が β₂ の窓より長く一定、ε が無視できる、各歩の誤差と φ′ が同じ] unit i の第 1 層の勾配のすべての寄与に |v_i| が共通の倍率として掛かり、Adam の正規化で消える（§2.4 の 1 つめ、並走 THEORY_v2 §3）。

### 3.5 開いた入力の数 k*

- [実測] k は N によらない。N 300・600・1,200・2,400 で 20.8・19.3・19.1・18.0（2 seed 平均、課題 151〜200）、log-log の傾き −0.06。K（2〜20）への傾きは −0.13。H には弱くよる（H^0.3）。
- [厳密] 深い閉じた入力が第 1 層の勾配に入る量には e^z が掛かる（z ≤ −8 で 3.4×10⁻⁴ 以下、z < −16.6355 で厳密に 0）。
- [介入] 深い入力に勾配を持たせると、k は N とともに増える。逆向きに下限 0.1 を置くと傾き +0.51、leaky 0.1 では +0.66。k* が N によらないことには、深い入力が第 1 層の勾配にほとんど寄与しないことが要る。
- [未導出] 深い入力が寄与しないことから、k* が一定になるまでの道筋（数の出入りの係数が N によらない理由）。
- 読み出しとの関係は 2 通りに出る。自然な走で N・K を変えた腕の間では、|v^c| が 0.13〜0.80 と動いても k は動かない [実測]。読み出しを凍結して大きさだけ変えると、k は 13・7.5・2.8（0.1・1・10 倍）と減る [介入。読み出しの学習も止めた腕]。k* が読み出しによらないとは言えない。
- 帰結:
  - p⁺ = k*/N（定義）。p⁺ の N への傾き −1.05 は、k の傾き −0.06 の言い換え。
  - mob = (k + Σ_閉 e^z)/N。閉じた側の和 Σ_閉 e^z は 1.7〜2.2 で N によらない [実測] ので、mob ≈ (k* + 2)/N（傾き −1.08）。
  - [条件付き: 塊がほぼ正規] 本体/s ≈ Φ⁻¹(k*/N)。実測 −1.47・−1.84・−2.06・−2.28、式 −1.49・−1.86・−2.14・−2.43（N 300・600・1,200・2,400）。大きい N で少し浅いのは、右の裾が正規より重いため。
  - 元の命題「p⁺ → 0・mob → 0」は、時間 t → ∞ では成り立たない（k* は課題 2,000 で 23〜25 とむしろ少し増える）。k* が N 2,400 より先でも N によらないなら、N → ∞ で成り立つ [条件付き・外挿]。

### 3.6 k* の会計 [実測の係数からの導出]

課題ごとに、押しで閉じる入力の数を a_p k + c_p、持ち上げで開く数を a_g k_中 + c_g と直線で書く（k_中 は押しの後の数）。1 課題の写像は k′ = (1 + a_g)((1 − a_p)k − c_p) + c_g で、不動点は

k* = (c_g − (1 + a_g)c_p) / (1 − (1 − a_p)(1 + a_g))。

- 係数は実測（課題 51〜200）。基準の腕で a_p 0.49・c_p −2.74・a_g 0.31・c_g 3.1、不動点 20.3。不動点は切替時の k の中央値（15〜17）の 1.2〜1.4 倍。
- 不動点の分子 c_g − (1 + a_g)c_p = 3.1 + 3.6 では、押しの切片 c_p の寄与が、持ち上げの切片 c_g と同じくらい大きい。
- 係数は N ではほとんど変わらない（N 300〜2,400 で a_p 0.44〜0.51、不動点は seed ごとに 20.2〜27.5。N 1,200 の基準は 19.1・21.5）。H では持ち上げの傾き a_g が 0.20〜0.29（H 25）から 0.38〜0.39（H 400）に増え、不動点も 13 → 38〜39 と動く（k の H^0.3 と同じ向き）。
- 全層の lr の梯子（×1/4〜×4）では、不動点は 50.8・31.3・20.3・13.7・7.0（∝ lr^−0.7）。実測の k（45・28・18・11・5、課題 101〜200）は ∝ lr^−0.8。押しの直線だけを ×1 のものに替えると、不動点は 26.6・21.2・20.3・21.7・22.1 とほぼ平らになる。lr 依存を担うのは、押しで閉じる割合 a_p（0.33 → 0.67）。
- 第 1 層だけの腕では、k（生きた unit の中央値、課題 151〜200、2 seed 平均）は m 1・4・6・8・11・16 で 19.1・6.7・4.0・2.3・1.05・1.0。m 4 までは m^−0.8 に沿い、その先は速く落ちる。m ≥ 4 では unit が死に始めるので、生きた unit だけの k には選別がかかる。
- [未導出] a_p が lr で増える理由、c_g と c_p の値の理由。元ノート §8.45 は k の lr 依存を開いた組の高さに帰していて、この会計とはまだ突き合わせていない。

## 4. 死の理論

### 4.1 会計

**恒等式 [厳密・expm1 の微分の腕]。** expm1 の腕では凍結は戻らない（次段）。凍結した unit は、凍結で終わった閉じた回をちょうど 1 つ持つ。よって

凍結の割合 = n_閉 × q_床。

厳密な微分の腕では、床の深さを通っても戻るので、この恒等式は成り立たない（第 1 層だけ ×8 で n_閉 × q_床 0.39 に対して凍結 0.20）。

**床のある腕では凍結は戻らない [厳密＋実測]。** 上端が −16.6355 より下なら全入力の微分が厳密に 0 で、第 1 層の重みに勾配が入らない。凍結が一度でも出た expm1 の走 16 本で、戻った unit は 0。厳密な微分の腕では、上端が −16.6355 を下回った unit の多くが戻る（第 1 層だけ ×8 で 78 個中 54 個）。

|---|---|---|---|---|---|---|
| 基準（×1） | 4.0 | 0（0/807） | – | 0 | 0 | – |

### 4.2 閉じた unit の酔歩の模型

**模型の仮定。**
1. 閉じた unit の深さは、課題ごとのマルコフ過程。
2. 開き直りの確率 r は深さによらない。中間の深さ（y が 3〜13）の値を使う。
3. 開かなかった課題の沈みは、深さによらない正規分布（平均 δ、幅 σ）。
4. 閉じた回は互いに独立。
5. 溜まりの深さは 15。

**式 [模型の中で厳密]。** 沈み δ・分散 σ² のブラウン運動を率 ρ で殺したときの、距離 d への初到達のラプラス変換から

q_溜 = ⟨exp(−θ (15 − y0)⁺)⟩、θ = (√(δ² + 2σ²ρ) − δ)/σ²。

⟨ ⟩ は着地 y0 の実測の分布での平均。

**仮定の破れ [実測]。**
- 仮定 2 は破れている。開き直りの確率は深さとともに下がる。第 1 層だけ ×4 で深さ 0・8・12・14 のとき 0.62・0.47・0.36・0.18。×16 では 0.73 → 0.13。中間の深さの r を全体に使うのは近似。
- 仮定 3 も破れている。開かなかった課題の沈みの平均は深さとともに下がる（第 1 層だけ ×4 で深さ 3〜4 の 2.8、8〜9 の 0.9、11〜12 の 0.3。×16 でも 3.9 → 0.4）。δ は中間の深さ（3〜13）の平均。裾も重い（標準偏差 2.0 に対して頑健な幅 1.5）ので、σ には頑健な幅を使う。
- 深いほど沈みが遅いこと（届く確率を下げる向き）と、深いほど開き直りが減ること（上げる向き）が一部打ち消し合って、比 1.0〜1.3 が出ている可能性がある [候補]。
- 仮定 1 は眠りの記憶のために近似にとどまる。深く着地した unit は、最初の課題でほとんど動かない（§4.6）。

**式と実測の比 [実測]。** 各腕の r・δ・σ・着地の分布を入れた式と、実測の q_溜 の比。式に当てはめの定数は無い。

- σ に頑健な幅を使ったときの値。ふつうの標準偏差を使うと、上の 4 腕の比は 1.1〜3.0 に開く。

### 4.5 なぜ閾値に見えたか [条件付き: §4.1 の近似と §4.2 の模型]

- Λ q_床 は観測した凍結から逆算した量なので、「Λ q_床 が上がるから S 字になる」だけでは言い換えにすぎない。中身は次の 2 点。
- **Λ はほぼ一定。** 第 1 層だけ ×4〜×11 で 10.5〜11.8、×16 で 8.3。
- **q_床 が 23 倍になる。** 内訳は q_溜 が約 12 倍、π_床 が約 1.8 倍。q_溜 は e^{−θd} の形で増える（d は着地から溜まりまでの距離）。π_床 に式は無い。θ も d も lr とともに縮む。指数の肩は、基準・全層 ×2・第 1 層だけ ×4・×8・×16 で 9.9・7.4・3.9・2.9・1.9。
- 倍ごとの肩の縮みは 2.6（基準 → 全層 ×2）・3.4（全層 ×2 → 第 1 層だけ ×4。全層 ×4 なら 3.2）・1.1（×4 → ×8）・0.9（×8 → ×16）。届く確率が最も急に変わるのは全層 ×2 から ×4 の段（行き先が第 1 層だけ ×4 でも全層 ×4 でも）で、そこでは凍結がまだ小さい（全層 ×2 までは 0、全層 ×4 で 0.035、第 1 層だけ ×4 で 0.075）。
- 凍結が見える第 1 層だけ ×4 → ×16 では、届く確率の増え方は緩く、1 − exp(−Λ q_床) の飽和が効いて S 字になる。半分の点は Λ q_床 = ln 2 で、課題 200 では m ≈ 10（模型 B 8.9〜9.8、模型 A 10.1〜11.7）。
- 半分の点は時点で動く（課題 50 で m ≈ 12）。課題を無限に続けたときに本当の閾値が現れるかは、高い m で閉じた回の数が頭打ちになるか次第で、確かめていない。基準の lr では、課題 400 以降は閉じなくなる（元ノート §8.7）。

### 4.6 床・ε の壁・眠り・行き過ぎ

**床は到着を吸収に変えるだけ [実測・α 梯子]。** 厳密な微分でも、閉じた回が深さ 16.64 に届く頻度はほぼ同じ（α = 1/8 で 0.041 対 0.044、1/16 で 0.133 対 0.133。1/4 は 0.0062 対 0.0097 で 17 件対 26 件）。床が無いと、深さ 20 より浅い通過者はほぼ全部 3〜5 課題で戻る。深さ 26 より先からは戻らない（83 件中 0）。
- 死のうち床が要る割合は、数え方で変わる。戻らない死で数えると α = 1/4・1/8・1/16 で 76%・61%・26%。課題 200 の死の数で数えると 32%・57%・21%。
- 第 1 層だけ ×8 では、厳密な微分にすると死（課題 151〜200）は 0.33・0.42 → 0.24・0.22（約 4 割減）[介入]。

**ε の壁 [条件付き（§2.8）＋実測]。**
- 基準の lr で、閉じた unit が一課題で戻れなくなる深さ（次の課題末までに開く確率が 0.25 になる深さ）は、ε 1e−6・1e−5・1e−4 で 9.65・7.48・5.27。直線の傾きは ε 1 桁あたり 2.19（確率 0.10 の深さで測ると 2.10）。§2.8 の理論値 ln 10 = 2.30 より小さいのは、戻りの最後の部分が Adam 域を通るから、と読める [候補]。
- 釣り合った Adam の状態と、上端の入力の勾配の向きが一課題変わらないことを仮定して計算した壁は、ε 1e−8 の基準の lr で深さ 13.4〜13.7、第 1 層だけ ×8 で 16.2〜16.8、×16 で 16.9〜17.6。床（16.64）と重なる。
- 第 1 層だけ ×8 で ε を 1e−10 にしても、死と凍結は減らなかった（死 0.33・0.42 → 0.42・0.45、凍結 0.31・0.39 → 0.41・0.44）[実測]。1e−10 と 1e−6 の 4 つの比較はどれも死が増える向きだが、seed 1 の増え方（+0.03）は基準の seed 間の差（0.09）や 100 unit の二項の揺れ（約 0.05）より小さい。2 seed で言えるのは「減らない」まで。中間の深さの開き直り（0.43 対 0.43）と、溜まりに届く確率（0.066 対 0.070）はほぼ変わっていない。
- ε を 1e−6 にすると、閉じた unit は床に着く前に遅くなる。中間の深さの開き直りは 0.43 → 0.28、沈みは 1.46 → 0.72 に落ちる。凍結は 0.14・0.19 に減るが、死（切替時の全閉、課題 151〜200）は 0.40・0.45 で、こちらも減らない。課題 200 に死んでいた unit の 59% は、深さ 10〜16.64 に留まる [実測・事後]。ε の壁は硬い吸収点ではなく、閉じた unit を遅くする。

**眠り [probe 走・seed 0・最初の 30 課題]。**
- [厳密＋実測] 閉じた間、ln v̂ は 1 更新あたり ln β₂ で減る（§2.4）。
- [実測] 閉じた時の記憶 ln(v̂/g²_閉) は lr とともに大きい。基準・第 1 層だけ ×8・×16 の中央値で 3.5・6.7・9.7（300 更新以上続いた閉じた回）。
- [条件付き: 閉じた勾配が一定] 記憶が抜けるまでの時間は 記憶/(1 − β₂)。
- [実測] 記憶が抜けて起きるのを観測できたのは、眠った回の 7/75・26/357・20/328 だけ。その回の予測の中央値は 3,900・7,300・20,800 更新で、観測との比の中央値は 1.24・1.92・1.05（10〜90% の範囲は 0.4〜4.6 倍）。
- [外れた予言] 眠りの間、正規化された一歩が e^{5×10⁻⁴τ} で育つという予言は外れた。実測の傾きの中央値は −1.6×10⁻⁴・−3.2×10⁻⁵・+6.7×10⁻⁵/更新。
- [外れた予言] 閉じた unit の沈みは課題あたり 2.0 を超えない、という導出も外れた。4,000 更新の窓の 25〜60% が 2.0 より深く沈む。
- 多くの閉じた unit は、記憶が残ったまま開き直る。「記憶が大きい閉じた回ほど長く眠る」は、閉じた回ごとには確かめられていない [候補]。
- [実測・200 課題の走] 深さ 8 より深く着地した unit は、最初の課題でほとんど動かない（第 1 層だけ ×4・×16 で動きの中央値 0.16・0.11）。浅く着地した unit に動かない期間は無い。

**床への着き方 [実測]。** 最初の 30 課題の probe 走（第 1 層だけの腕）で、10 更新ごとに追った。

| 腕 | 到着の数 | 閉じたまま沈む | 起き抜けの蹴り | 切替での落下 | その他 |
|---|---|---|---|---|---|
| 第 1 層だけ ×8（2 seed） | 32 | 66% | 28% | 0% | 6% |
| 第 1 層だけ ×16（2 seed） | 120 | 36% | 38% | 20% | 6% |

課題ごとの記録（200 課題）で見ると、α = 1/4（17 件）・第 1 層だけ ×4（15 件）・全層 ×4（7 件）の到着は、どれもすべて、切替の時点でも切替の少し後（α 梯子は +200 更新、ほかは +500 更新）でも閉じていた unit から来た。開いた unit が切替で落ちたものは 0 件。α = 1/8 では、到着の 90% がこの分類。ただしこの記録では、閉じたまま沈んだものと、その後に起きて蹴られたものを分けられない。

- **起き抜けの蹴り [実測・×16・seed 0 の 4 例]。** 眠った unit の √v̂ が 6×10⁻⁹〜3×10⁻⁶ まで縮んだ後に、上端の入力がバッチに来る。正規化された一歩が大きく、上端が +14〜+24 跳ねて開く。直後に逆向きの勾配で 25〜45 落ち、30 更新ほどで深さ 19〜30 に達する。×16 の起き抜けの蹴り全体では、床を越えて 500 更新後の深さの中央値は seed 0 で 22.5（24 件）、seed 1 で 20.9（22 件）。
- 蹴りの大きさは、Adam の一歩の形から η₁ × 上端の入力の画素の和に比例すると読める [条件付き。lr をまたいだ比例は測っていない]。
- **切るとどうなるか [介入・seed 0・30 課題]。** 第 1 層の 1 更新を座標ごとに η₁ 以下に切る（Adam の状態は変えない）。×16 の凍結は課題 10 で 0.23 → 0.05、課題 30 で 0.59 → 0.42。閉じた回が床に着く割合は 0.183 → 0.120。蹴りは 24 → 10 件、落下は 14 → 3 件に減り、閉じたまま沈む到着は 18 → 28 件に増える。×1 では効果が無い。

### 4.7 読み出しの大きさと閉じる頻度

### 4.8 SGD・ReLU との違い、先行研究

- **SGD [実測]。** モーメンタムなしの η 0.01〜0.1 と、モーメンタム 0.9 つきの 0.003・0.01 で、p⁺ は保たれず死が積もる。Adam と比べて μ₊ が 12〜30 倍（0.19〜0.48 対 0.016）、μ₋ が 5〜13 分の 1（0.06〜0.15 対 0.77）。閉じた unit は戻るが遅い。どちらが主かは分けていない。当てはめの悪さのせいではない（元ノート §8.22）。
- **ε の向き [候補・未検証]。** ReLU では ε を大きくすると死が減るという報告がある（Dufort-Labbé ら 2025、Lyle ら 2023）。ε には 2 つの向きがあると読める。閉じた unit の戻り（§3.4）を遅くする向きと、v̂ が縮んだ後の大きな一歩（この箱では起き抜けの蹴り）を抑える向き。ReLU の報告は後者を、この箱の基準の lr の μ₋ は前者を見ている。測っている量も違う（死の割合と戻る速さ）。
- **先行研究 [文献・検索は約 30 件の範囲]。**
  - 近いのは、ReLU の死を吸収的なブラウン運動として扱う Dufort-Labbé ら 2025（lr が大きいほど速く死ぬ。SGD の雑音で、数値の床は無い）。
  - lr と雑音の積に閾値があり、越えると unit が入出力の重み 0 の不変集合に引き込まれることは、Chen ら 2023（SGD・ラベル雑音の単一ニューロン模型）。この箱の凍結は、Adam の下で負側の数値の床に吸収されるもので、lr に対して滑らかな S 字。
  - 管の部品は Schraudolph 1998（中心化されていない活動 × 誤差の雑音が、外向きの重みに雑音を入れる）。揺らぎで Adam の一歩が縮むことは Balles & Hennig 2018。
  - 眠りの鏡像は Lyle ら 2023・Ellis ら 2024（収束後の古い小さい v̂ が、切替で大きな一歩を生む）。
  - float32 の微分の床の表は TeLU（Fernández ら 2025。exp の実装で −103.98）。
  - −1 の管をブレーキと読むもの、閉じた後の v̂ の記憶による眠り、N によらない k* は見つからなかった。

### 5.5 lr₁ と読み出しの積 [候補・事後・一部は反証]

- 2 層の 6 腕で、課題 50 の凍結は「第 1 層の lr の倍率 × W2 の列の大きさ」とともにほぼ増える。積 1.0・3.2・3.7・9.2・16・33 で 0.00・0.02・0.00・0.10・0.36・0.63。

- W3 が補って育つので、W3 を含む実効の読み出しは測っていない。W3 の列を掛けた粗い代理では、並びが崩れる（2.2・3.1・5.6・5.8・6.3・13.7 に対して凍結 0.00・0.00・0.10・0.02・0.36・0.63）。

## 9. 書けない文

- 「ELU が沈降しない理由を全部解明した」。言えるのは「この箱で機構の鎖を同定し、閉じた unit の酔歩の材料（開き直り・着地・床に着く割合）を、新しい腕で事前に当てた」まで。凍結の割合そのものは、両端の腕の内挿でも当たる。
- 「学習率に死の閾値がある」（不連続の意味で）。
- 「死ぬのは 1 回の押しが床を越えるとき」。
- 「ε が死を止めている」「ε は死に関係ない」。どちらも書けない。ε は閉じた unit が休む深さと戻りの速さを変える。第 1 層だけ ×8 では、ε を 1e−10 にしても 1e−6 にしても死は減らなかった（4 つの比較はどれも +0.03〜+0.09 の増える向きで、平均 0.375 → 0.43。seed 1 の増え方は seed 間の差より小さい）。
- 「W2 が育ったことだけで ELU→leaky が崩れた」「W2 は関係ない」。どちらも書けない。
- 「RL-CIFAR の第 1 層は床に吸収されて死ぬ」。CIFAR のエンジンに −16.64 の床は無い。
- 「閉じた unit は Adam で全速で戻る」。
- 「開いた入力の高さは読み出しに反比例する」。
- 「読み出しが小さければ unit は守られる」を、箱を書かずに言うこと。
- 「床が unit を守る」を、損失と最適化器を書かずに言うこと。
- 生の |v| で読み出しの大きさを語ること。
- 第 1 層だけの腕・全層の腕・α 梯子を、同じ「×m」で呼ぶこと。
