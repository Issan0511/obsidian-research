- **m** = unit の前活性の入力平均（m = w·μ + b、μ は入力の平均）。**切替** = 課題（乱数ラベル）の入れ替え。**押し** = 切替から 200 更新までの m の変位。**戻り** = 200 更新から課題末までの m の変位。**比** = 戻り ÷ |押し|。登録の比（fork2）は、切替時に開いた入力を持つ unit での −(戻りの中央値)/(押しの中央値)。**正味** = 課題末の m − 切替時の m。
- **期待の押しの場** S_i = ⟨K_n φ′(z_in) v^c_i·p_n⟩（⟨⟩ は全入力の平均、K_n = x_n·μ + 1）。切替時の状態で計算した、全データ SGD の 1 歩の期待の変位の向き（S > 0 が下向き）。**旧ラベル整列** S^oh_i = ⟨K_n φ′ v^c_{i,y_old(n)}⟩（旧ラベルに当てはまっていれば S に近い）。どちらも要求の側の量で、押し（実際の変位）とは別の数として書く。
- **生き残り** = 切替時にも課題末にも開いた入力を持つ unit。**閉じる unit** = 切替時に開いた入力を持ち、課題末に全閉になる unit。
- **開いた入力** = z > 0 の入力。**k** = unit の開いた入力の数。**p⁺** = k/N。**上端** = unit の z の最大値。**全閉** = k = 0。**幅 s** = z の入力についての標準偏差。**κ** = (上端 − m)/s。
- **読み出し v_i** = unit i から出力層への重み（K 次元）。**v^c** = v_i からクラス平均を引いたもの。**票** = v^c_{i,y}（unit i の読み出しがクラス y に入れる重み）。
- **要求** = 入力 n での誤差の場 δ_in = φ′(z_in)·v_i·(p_n − y_n)。その入力の z をどちらへ動かしたいかを表す。**変位** = z の実際の変化。変位は、共有の重みを通して全入力の要求を重ねたもの。**要求の向きと変位の向きは別の量**として書く。
- **自己 unit 項** = 要求のうち、unit i 自身の出力を基準 c₀ まで取り消す分。大きさが基準で変わるので、割合には必ず基準を書く（**床基準** = ELU では −1、ReLU では 0）。核の対角（入力 n 自身の要求が n を動かす分）は **自己標本項** と呼んで分ける。

## 1. 7 件

### 1.1 (1) 押しの向きのうち、他の unit との兼ね合いで決まる分

**要点。**
- 部分残差の類推で使えたのは、収束した部分残差（FWL・added-variable）ではなく、途中で止めた boosting（L2Boost のスペクトルフィルタ）の形。「他の unit との兼ね合い」は、他の unit と出力 bias が共有方向を先に吸い取る量として式に入る [厳密・線形模型]。
- 1 層では、旧ラベル整列（期待の押しの場の近似）が下向きの unit の割合をパラメタなしに当てた [実測・事後]。実際の 200 更新の変位の割合とは別の数。2 層では当たらない。全 unit の保証は出ない。中心化した記憶の模型で φ と φ′ が非減少なら、上向きの期待の押しは反平行の unit にしか生じない [厳密・模型]。

**導出できたこと。**
- **記憶のフィルタ** [厳密・線形模型]。仮定: 二乗誤差。特徴 Φ（隠れ層の活動、N×H）はラベルによらず固定。読み出し V と出力 bias を全データの勾配流で学習の長さ τ だけ学ぶ。初期値はラベルと独立。旧ラベルは一様で独立。このとき旧ラベル整列の期待は
  E[S^oh_i] = (1 − 1/K)·b_iᵀ F_τ φ_i、F_τ = Θ⁺(I − e^{−τΘ})、Θ = ΦΦᵀ + 11ᵀ。
  b_in = K_n φ′(z_in) は押しの重み（K_n = x_n·μ + 1）、φ_i は unit i の活動の列。τ → 0 で生の記憶、τ → ∞ で FWL（共線の抑制つき）。合成データの Monte Carlo と 1.87 SE 以内。
- **基準は学習の長さで決まる** [実測・合成]。1 歩の記憶は基準 0（最大 2.78 SE）。5〜30 歩では unit の平均出力に移る。出力 bias を固定しても同じ。前の「基準 c₀ は恣意的」という反証は、これで「基準は τ の関数」に置き換わった。
- **下向きの確率** [厳密: Ã・B̃（旧ラベルの揺らぎと記憶を押しの重みで集めた量）が 2 変量正規なら。実際は標本についての中心極限による近似]。P(S^oh_i > 0) = ∫₀^{π−arccos ρ} sin^{K−2}θ dθ ／ ∫₀^π sin^{K−2}θ dθ、ρ = cos(b_i, F_τφ_i)（標本について中心化しない余弦）。K = 2 で ½ + arcsin(ρ)/π、K = 3 で (1+ρ)/2。K とともに 1 に近づく。合成で式と Monte Carlo の差は最大 0.009。
- **中心化した記憶での符号定理** [厳密・模型の中: 記憶が中心化されている、共線の抑制を入れない、K_n > 0]。押しの期待 M_c = C1 + C2。C1 = (ΣK)·Cov_π(φ′, φ) は φ と φ′ がともに非減少（ReLU・leaky・ELU）なら ≥ 0（チェビシェフの和の不等式）。C2 = (Cov_n(K, φ)/K̄)·ΣKφ′ は反平行の unit（明るい入力ほど活動が低い unit、Cov_n(K, φ) < 0）でだけ負。**φ と φ′ がともに非減少なら、上向きの unit は必ず反平行。** GELU・SiLU・Snake ではチェビシェフの保証が外れる。leaky では C1 は開いた割合 π⁺ とともに消え、C2 ≈ a²·ΣK·Cov_n(K, z)/K̄ は沈んでも残る。
- **期待の押しの場が旧ラベル整列に等しくなる条件** [厳密・全データ SGD の 1 歩・η の 1 次。Adam 版ではない]。S_i = S^oh_i + N·(μ,1)·∇_{(w_i,b_i)}L_old。旧課題の損失が (μ,1) 方向で停留していれば、S = S^oh。leaky ではこれが崩れる（切替 8〜12 で S > 0 が 0.66〜0.79、S^oh > 0 が 0.80〜0.84）。

**実測（1 層の箱・事後）。** ここの「実際」は、保存した実状態で計算した期待の場（S^oh・S）の割合で、変位ではない。

### 1.2 (2) Adam での実際の変位

**要点。**
- 窓の変位は勾配の列で閉じた恒等式に書ける [厳密]。切替後の数十更新では、一歩は「揺らぎの標準偏差で割った SGD」になる [条件付き]。1 層で 50 更新の大きさを当て、実変位との符号の一致率は SGD の形と同じだった（差 ≤ 0.02。unit ごとに符号が同じかは示していない）。
- 押しの深さ（谷まで）は式から出ない [未導出]。深さは旧予測の logit の散らばりと腕の間で同じ向きに並ぶ [実測・事後・相関]。

**導出できたこと。**
- **窓の恒等式** [厳密: 通常の Adam。減衰・AMSGrad なし]。窓の始めのモーメントを M₀ として
  Δθ(τ) = −η[Σ_{s≤τ} β₁ˢ D̃_s M₀ + Σ_{r≤τ} Λ_r g_r]、Λ_r = (1−β₁)Σ_{s=r}^{τ} β₁^{s−r} D̃_s。
  D̃_s は s 歩目の分母の逆数 1/(√v̂_s + ε) を 1 − β₁ᵗ で割ったもの。float64 の Adam と差 2〜8e−15。
- **読み替えの限界** [厳密]。入力が非負なら、Adam は「正で時間とともに変わる核の SGD ＋ 旧モーメントの残り」と書ける。ただし核は g_r 自身と未来の勾配とラベルに依る。SGD の期待値の符号は、この読み替えだけでは Adam に移らない。
- **分母の記憶の積分** [条件付き: g² の期待が窓で一定・v̂ の揺らぎを無視・ε ≪ √v̂・連続近似。この仮定の下での計算は厳密]。Σ G/√v̂_s ≈ I(τ;ρ) = (1/λ)ln[(1+y_τ)|1−y₀|/(|1−y_τ|(1+y₀))]、y₀ = √ρ、y_τ = √(1+(ρ−1)e^{−λτ})、λ = −ln β₂、ρ = 窓の始めの v̂ ÷ 窓の中の g² の期待。直接和と 0.2〜0.4%。
- **初期の変位** [条件付き: (i) 期待勾配と分散が切替時の値のまま、(ii) 旧 m・旧 v が新しい勾配の分散より小さい、(iii) 全座標で信号対雑音 ≪ 1。1 層の閉じた形にはさらに (iv) E_y[δ_ni²] と x_nd² が標本について分離すること。sign 組の result.md では (A1)〜(A4)]。Δθ_d ≈ −η c_T ḡ_d/s_d、c_T = Σ_{t≤T}(1−β₁ᵗ)/√(1−β₂ᵗ)（c_50 = 278、c_200 = 737）。ḡ_d は座標 d の期待勾配、s_d はミニバッチ平均の標準偏差。1 層では Δm_i ≈ −η c_T √B′·S̃_i/(Nσ_i) まで閉じる（S̃ は画素ごとに rms で割った明るさで重みを付けた押し、σ_i は unit の誤差の rms、B′ = B(N−1)/(N−B)）。符号は S̃ の符号で、S の符号とほとんど同じ。大きさは unit ごとに誤差の rms で割られる（勾配の小さい unit も同じだけ動く）。仮定の「信号対雑音 > 1 の座標」は全状態・全層で 0.00〜0.04。
- **まれで大きい勾配での符号の逆転** [条件付き: 事象の間隔が指数分布、p ≪ λ、大きい一歩の頭打ち]。E g > 0 でも、e^{−p n_c}(1 + 2p/λ) > p/√λ なら Adam の平均の一歩は逆向き（p は事象の率、n_c = ln(λL²/s²)/λ）。17 例すべてで逆転の有無が当たる。箱の開いた入力 1 個がバッチに入る率（16/1,200 ≈ 13λ）はこの域の外で、箱は平均場の域にある。
- **自己 unit 項は、Adam の実際の勾配でも毎歩・全座標で非負** [厳密]。仮定: 最終隠れ層。床のある単調な活性化（ReLU・ELU）。基準 c₀ = 床。勾配の成分の符号には、その層への入力が非負であること（1 層の生の画素）。変位の符号には、Adam の核 κ_r(n) = kᵀΛ_r x̃_n ≥ 0。期待値もラベルの独立も使わない。**分け方の定義**: 自己 unit 項の勾配だけを別のモーメントに流し、分母は実際の Adam のままにしたときの変位を「自己 unit 項の分」と呼ぶ（Adam は非線形なので、この定義を置かないと「分」が決まらない）。この定義で、窓の変位のうち自己 unit 項の分は、どの窓・どの引きでも下向きか 0。**これは帳簿の分け方で、因果の根拠にはならない。** 残りが自己 unit 項の鏡像に動きうる（この型の分解は過去に何度も棄却されている）。GELU・SiLU（φ′ < 0 の域がある）と leaky（有限の床が無い）には使えない。

### 1.3 (3) 戻りが押しより小さい理由

**要点。**
- 比 < 1 は、unit ごと（または平均どうしの比）では「課題末の m が下がる」ことと同じ [厳密・恒等式]。駆動が弱いことが比を決めるのは、戻りが課題の途中で打ち切られる場合だけ。
- 生き残りでは、正味の沈みは恒等式で κ × 幅の伸びと言い換えられ、実測でほぼ尽きる [恒等式＋実測]。因果の向きはこの恒等式からは決まらない。押しは墨の多い入力ほど深く下げるので、幅を広げる [条件付き・母集団の水準で実測と一致]。
- 活性化の順は戻りの側で出る。谷の逆向きの微分が戻りを削る [登録・介入]。

**導出できたこと。**
- **比の恒等式** [厳密・恒等式: unit ごと、または平均どうしの比について]。unit ごとに、比 = 1 − |正味|/|押し|（押しと正味が負のとき）。平均どうしの比 −E[戻り]/E[押し] は、課題末の m の分布が課題をまたいで定常なら 1。登録の比（切替時に開いた unit の、中央値どうしの比）と全 unit の正味には、そのまま移らない。leaky で登録の比 0.73〜0.84 と全 unit の課題の正味 +0.00 が並ぶのは、母集団（切替時に開いた unit 対 全 unit）と統計量（中央値どうしの比）が違うため。
- **正味の恒等式** [厳密・恒等式]。正味 = Δ上端 − κ₀Δs − s_TΔκ（添字 0 は切替時、T は課題末）。生き残りでは上端がほぼ戻るので正味 ≈ −κΔs になる。これは幅の伸び（W 増大）への言い換えで、機構の導出ではない。幅が沈みを作るのか、上端が固定されたまま沈むと幅が広がるのかは、恒等式からは決まらない（反証役 P3-2）。
- **押しの幅の 1 次の式** [条件付き: 押しの変位が窓の中で向きの固定した形 Δz_n = −λ(u·x_n + u_b) を取る、λ の 1 次、Adam の揃った窓で u ≈ sign(ḡ)]。a_P = Δs_P/|Δm_P| = −ρ(z, u·x)·CV(u·x)。ρ(z, u·x) は前活性と「押しの向きで測った墨の量」の入力をまたぐ相関、CV は墨の量の変動係数。入力は非負で、Adam はほぼ全画素を同じ向きに約 η ずつ動かすので、墨の多い入力ほど大きく下がる。沈んだ unit はもともと墨の多い入力で低い（ρ ≈ −0.3）ので、押しは下の裾を伸ばす。

### 1.4 (4) 谷（GELU・SiLU）

**範囲。** 1 層の箱だけ。軌道は GELU 6 本・SiLU 6 本・200 課題。6 本は seed 2 × 実装 3（chim = 0928 のキメラのエンジン、v4 = α 梯子のエンジン、v3long = 0925 の長い走のエンジン。SiLU は chim の代わりに general_force_0929 のエンジン）で、同じ seed の 3 実装は課題 10 前後で分かれるだけなので、独立な 6 seed ではない。ε の壁は Adam の性質なので、SGD の箱には移らない。

**要点。**
- 谷底は、1 入力・ε 域の外（√V̂ ≫ ε）の Adam では壁にならない [厳密]。箱では、谷底のすぐ下の帯から毎課題 10〜16% が開く [実測]。閉じた GELU unit を止めているのは Adam の ε で、ε を変えると止まる深さが予言どおり動いた [介入・未登録の集計]。

**導出できたこと。**

### 1.5 (5) 切替直後と課題の残りを 1 つの式で

**要点。**
- 1 本の式は書けた。入力ごとの誤差 δ_n = φ′v^c·(p_n − y_n) は、予測の側と正解の側の 2 項に分かれる。全データ SGD の自分の経路で集めると D = S − A = v^c·[(P − U) − (Y − U)] [厳密]。全データの SGD の 1 歩で Δm = −ηD。切替の瞬間の期待の駆動は S（E[A] = 0）で、課題の残りで A が育つ。
- 式は勾配を書き直しただけで、反転の時刻も課題の後半の向きも出ない。p が y に届かなくても、停留点では D = 0 [厳密]。
- 反転の時刻は切替時の CE とともに遅れるが、CE だけでは決まらない [実測]。

**導出できたこと。**
- **1 本の式** [厳密: 1 隠れ層（または最終隠れ層の自分の重みの経路）、交差エントロピー]。D_i = ∂L/∂w_i·μ + ∂L/∂b_i = ⟨K φ′_i v_i·(p − y)⟩ = S_i − A_i。S_i = v^c_i·P_i（予測の側、P_ik = ⟨K φ′ p_k⟩）、A_i = v^c_i·Y_i（正解の側、Y_ik = ⟨K φ′ y_k⟩）。⟨⟩ は入力の平均、K_n = x_n·μ + 1。v^c·u = 0 なので D = v^c·[(P − U) − (Y − U)] と書ける。m は (w, b) の 1 次式なので、全データ SGD の 1 歩で Δm = −ηD は η² の項なしで厳密。実走で |S − A − D| ≤ 2.4×10⁻⁷。
- **切替** [厳密: 新ラベルが切替前の状態と独立で一様に引かれる]。E[Y − U] = 0 なので E[D] = S（旧予測を unit の票で測った量）。これが切替の瞬間の期待の駆動（全データ SGD の 1 歩の期待）で、200 更新の押し（実変位）とは別の量。E[A] = 0 は切替の瞬間だけで、その後の状態は新ラベルに依る。
- **停留点** [厳密]。D = 0 は p_y < 1 のままでも起こる。「交差エントロピーでは p が y に届かないので持ち上げが残る」は定理ではない（撤回）。
- **課題の後半の向き** [条件付き: m の向き μ̃ = (μ, 1) に沿った損失が単峰]。直線上の位置を ℓ、その上の最小点を ℓ* とすると、D の符号 = (ℓ − ℓ*) の符号（ℓ は幅 s とは別の記号）。後半の向きは「押しが最小点を行き過ぎたか（上向き）、手前で止まったか（下向き）」で決まる。どちらになるかは決めない。
- **Adam では** D をそのまま使えない。Adam の窓の恒等式（§1.6）が核に通すのは D ではなく入力ごとの δ_n（上流の経路では他の unit の誤差の和）で、核は入力ごとに違う。だから Adam の変位は D の関数にならない。符号の意味（S と A のどちらが勝っているか）だけが移る。実測では、全データの駆動 ÷ √v̂ と実際の一歩の差 b が、戻りの窓でほぼ一定の下向きの足し算として入る（§1.3）。

**実測。**
- 反転の時刻（開いた unit の平均 D が 0 を横切る時刻、fork2 の 5 腕 × 3 seed、ELU）: logit の締め付け 107〜117、課題長 1,000 で 212〜216（どちらも切替時の CE 2.82）、ラベル平滑化 305〜335（CE 4.05）、基準 620〜658（5.36）、課題長 16,000 で 2,882〜2,959（13.0）。
- 同じ CE 2.82 でも、200 更新の押しは −1.27（課題長 1,000）対 −2.44（締め付け）で違う。自信は「押しの続く時間」と「古い v̂ に対する新しい勾配の大きさ」の 2 つの経路で入る [候補]。
- 戻りの時間の形（fork2 R3・3 seed、−R(s)/P）: ELU 基準で 500 更新 −0.09〜−0.11、2,000 更新 0.14〜0.22、4,000 更新 0.62〜0.70。16,000 の課題では 1,000 更新 −0.57〜−0.63、8,000 更新 −0.10〜−0.15、16,000 更新 0.62〜0.63。

**仮定として残ること。** 単峰性（確かめていない）。最小点 ℓ* が時間とともに動くこと。

**まだ解明・導出が要ること。**
1. S の減り方と A の育ち方の動学。反転の時刻と大きさの閉じた式 [未導出]。
2. 課題の後半の向きが箱で違う理由（RL-CIFAR の ReLU は上向き、condA と置換 MNIST の leaky は下向き）[未解明]。上の条件付きの式は向きの意味を与えるだけ。

**要点。**
