## 0. 一言で

ゲートの模様（どの入力で開いているか）がほぼ同じ 2 つの unit は、切替の押しの期待だけで動かすと、**引き寄せ合って同じ模様になる**（クローン化）。重なったあとは、**2 個で 1 個の unit としてそろって沈む**。引き寄せ合う間は、閉じている方の unit が開く向き（沈むのと逆）に動く。「押しは自己項の向き」を破る反例として何度も出てきた「複製」の型は、この動きの途中の姿だった。実網（a 0.1・0.3・0.5、seed 0、100 課題）には模様がほぼ同じ unit の組が無く、クローン化は起きていない。

| 文 | 格 |
|---|---|
| 同じ模様の unit は、強さを足した 1 個の unit と同じ | [厳密・模型]（§16.24 のまとめる補題） |
| 切替の押しの期待は、容量を下げる向き | [厳密・模型]（線形化・二乗誤差・当てはめが済む極限。§16.23） |
| 対のゲートの値について容量は谷の形で、複製がいると谷底は相手のゲートの値のすぐ手前 | [恒等式]（§1.2。合成 300 系で 3e−11） |
| ぴったり同じ 2 個は両方とも沈む向き。少し違う 2 個は引き寄せ合う | [数値・模型・1 つの系] |
| 動かすと、重なってからそろって沈む | [数値・模型・1 つの系・3 つの始点] |
| 1 つの始点では、そろって沈む途中で分かれて止まる。理由は 2 個の重みの傾きがずれること | [数値・模型・1 つの系。傾きをずらさない動かし方では起きない] |
| 実網には、模様がほぼ同じ unit の組が無い | [実測・3 走] |

## 1. 言葉・模型・使った系

### 1.1 言葉

- **ゲート**: 対（unit、入力）ごとの活性化の傾き。leaky では開（1）か閉（a）。**ゲートの模様**: その unit が、どの入力で開いているか。
- **複製（クローン）**: ゲートの模様が同じ unit の組。**なりかけ**: 模様がほぼ同じで、少しだけ違う組。**クローン化**: なりかけの組が、同じ模様になっていく動き。
- **容量** Φ = ½ log det(G + λ)（G = 第 1 層の核）: 網が 1 つの課題の中でラベルに従える広さ。
- **押し**: 課題の切替の、最初の一歩の期待。**傾き** A_i = ∂Φ/∂m_i（m_i = unit i の位置 = 平均入力に対する前活性）。A_i が正なら、押しは unit i を沈める（閉じる）向き。
- **自己項／残り**: unit 単独の分／ほかの unit がいることで変わる分（全体 − 単独）。

### 1.2 模型と、土台になる 3 つの文

模型は、線形化した網のゲートの道（読み出し固定・1 出力）・二乗誤差・リッジ λ・滑らかな leaky（ゲートの幅は前活性の単位で固定）。動かすのは各 unit の位置だけ（重みを平均入力の向きに足す）。

1. **押しの期待 = 容量の勾配降下** [厳密・模型。§16.23]。当てはめが済む極限で、切替の一歩の期待は −∇Φ に比例する。課題で使った区別ほど、切替で削られる。
2. **同じ模様の unit は 1 個と同じ** [厳密・模型。§16.24 (D2)]。強さ γ_0・γ_1 の 2 個は、強さ γ_0 + γ_1 の 1 個と同じ核を作る。
3. **谷底は相手のゲートの値のすぐ手前** [恒等式。予測固定 P99a]。対 (unit 0, 入力 n) のゲートの値 g について、容量は Φ(g) = 定数 + ½ log[c_0 + γ_0κ′(g − d̂)²]（§16.26 (8)）。入力 n 以外で同じ模様の unit 1 だけがいるとき

　**d̂ = d_1n × γ_1(Θ_nn − κ_Γ) ÷ (γ_1Θ_nn + γ_0κ_Γ)**

（d_1n = 相手の入力 n でのゲート、κ_Γ = 2 個をまとめた 1 個の unit で、入力 n がほかの入力から言い換えられない分。0 < κ_Γ ≤ Θ_nn）。d̂ は相手のゲートの値より必ず小さく、当てはめが重いほど相手の値に近づく（合成 300 系で d̂ ÷ d_1n の中央値 0.91、最大 1.0000）。押しはゲートを谷底へ寄せるので、**unit のゲートは相手のゲートの値へ寄っていく**。

### 1.3 観測に使った系

Codex が §16.29 の反例として出した系。入力 5 個・1 次元（x = 1.7・2.0・2.1｜5.7・6.3 と定数 1）。unit 2 個（同じ向き。閾値より上の入力で開く）。読み出し 0.54・0.58、a 0.1、λ/λmax 1.1e−4、ゲートの幅 0.2。反例の位置は閾値 5.1（unit 0）・3.9（unit 1）で、**2 個とも入力 5.7 と 6.3 だけを開いている**（unit 0 は入力 5.7 がほぼ開、ゲート 0.957）。

## 3. 力の形: ぴったり同じなら沈む・少し違えば引き寄せ合う

§1.3 の入力で、2 つの unit の閾値を入力 5.7 の近くに置いたときの傾き（正 = 沈む向き）。

| 2 つの unit の閾値 | 入力 5.7 でのゲート | 傾き（unit 0・unit 1） | 和 | 従えるラベルの向きの数 |
|---|---|---|---|---|
| 5.4・5.4（ぴったり同じ） | 0.835・0.835 | +4.0・+4.6 | +8.6 | 1.69 |
| 5.4・5.41 | 0.835・0.828 | +52・−45 | +7.1 | 1.71 |
| 5.4・5.45 | 0.835・0.799 | +161・−179 | −18 | 2.07 |
| 5.4・5.5 | 0.835・0.757 | +141・−179 | −39 | 2.41 |
| 5.4・5.8 | 0.835・0.440 | +37・−46 | −9.5 | 2.63 |
| 5.4・6.0（大きく違う） | 0.835・0.265 | +27・−2.8 | +24 | 2.64 |

- ぴったり同じ 2 個は、両方とも沈む向き。2 個で 1 個の unit（§1.2 の 2）として、自己項の向きに動く。
- 少し違う 2 個は、開いている方が沈む向き、閉じている方が浮く向き。**互いのゲートの値へ寄る**（§1.2 の 3）。
- 引き寄せ合う力は、そろって沈む動きの 10〜40 倍。
- 違いが大きいほど、従えるラベルの向きの数（tr G(G + λ)⁻¹）が多い。少し違う間は、その違いが入力の区別に使われている。

## 5. 動かして見たこと

押しの期待だけ（容量の勾配降下。位置だけ）で 2 つの unit を動かした。歩幅は、容量が必ず下がるように毎歩決めた。t は勾配流の時間（歩幅の和）。

### 5.1 3 つの始点

| 始点（閾値） | 重なるまで | 重なった所のゲート（入力 5.7） | そのあと | 終点 |
|---|---|---|---|---|
| 5.4・5.5（少し違う） | 14 歩（t 1.7e−5） | 0.801・0.802 | 差 0.003 以下のままそろって下がる | 2 個とも完全に閉（Φ −10.445） |
| 5.4・5.8（違う） | 24 歩（t 1.2e−4） | 0.679・0.679 | 差 0.022 以下のままそろって下がる | 2 個とも完全に閉（Φ −10.445） |
| 5.1・3.9（反例） | 35 歩（t 4.2e−3） | 0.995・1.000 | そろって下がるが、途中で分かれる | 極小点で止まる（Φ −8.654） |

- 重なり方は 2 通り。5.4・5.5 と 5.4・5.8 では、開いている方が下がり、閉じている方が上がって、間で出会う。反例では、閉じている方（unit 0）だけが上がって、開ききった相手に重なる。

- **重なる**: unit 0 のゲート（5.7）が 0.957 → 0.995 に上がる。unit 0 は開く向き（沈むのと逆）に動く。
- **待つ**: 重なった直後は 2 個ともゲートがほぼ 1 で、傾きが小さい。そろって沈み始めるまでが長い（t 0.004 → 1.16）。この間に、開ききっていた unit 1 の閾値が 3.90 → 4.91 に上がる。
- **そろって沈む**: ゲート（5.7）が 0.96 → 0.50 まで、差 0.04 以下で下がる。
- **分かれて止まる**: 止まった所は本物の極小点（傾きの大きさ 1.5e−5、位置 2 個についての 2 階微分の固有値は +4.3e3・+6.2e4）。完全に閉じた状態（Φ −10.445）より容量が高い。unit 0 は「6.3 が開・5.7 がほぼ閉」、unit 1 は「6.3 が半開き」で、2 個は違う模様になっている。

### 5.3 分かれる理由

- 重みを平均入力の向きに動かすと、位置だけでなく重みの傾き（入力の向きの成分）も変わる。unit 1 は閾値 3.9 → 6.29 と長く動いたので、傾きが 1.00 → 0.64 に下がった。unit 0 は 0.86。
- ゲートの幅は前活性の単位で固定なので、入力の単位での幅が 2 個で違ってくる（0.23 と 0.31）。閾値をそろえても、2 つの入力でのゲートが同時にはそろわない。
- **bias だけを動かす**（重みの傾きは 1 のまま）と、同じ始点から 59 歩で重なり、差 0.016 以下のままそろって沈んで、完全に閉じた。分かれなかった [数値・予測固定 P99b]。
- 5.4・5.5 と 5.4・5.8 の始点では、平均入力の向きに動かしても 2 個の傾きの差は 0.07 以下のままで（終盤 0.82〜0.88）、分かれなかった。

## 6. 実網では

保存してある重み（a 0.1・0.3・0.5、seed 0、課題 2〜100 の末。開いた入力が 5 個以上の unit）で、unit どうしの開いた入力の重なり（共通 ÷ 和集合）を測った [実測・予測固定 P97]。

| | a 0.1 | a 0.3 | a 0.5 |
|---|---|---|---|
| いちばん似た相手との重なりの平均（課題 10 → 100） | 0.14 → 0.12 | 0.15 → 0.15 | 0.23 → 0.23 |
| 課題 100 での最大 | 0.27 | 0.25 | 0.34 |
| 重なり 0.8 以上の相手がいる unit（測った 7 時点とも） | 0% | 0% | 0% |
| ほかの unit にほぼ丸ごと含まれる unit（課題 100） | 1.5% | 0% | 0% |
| 基準（入力ごとの開きやすさだけ保って、独立に引いた場合の平均） | 0.09 | 0.10 | 0.17 |

- 模様がほぼ同じ unit の組は、100 課題のどの時点にも無い。似かたは課題を重ねても増えていない。
- 引き寄せ合う力が働くのは、ほぼ同じ模様の組がいるときだけなので、実網はその配置に入っていない。力そのものが実網にあるかは、似た組が無いので測れていない。
- 対の水準では、同じ仕組みの弱い形が実測されている（§16.11）。実網で票と逆に動く閉じた対（a 0.1 で 224 対、a 0.3 で 559 対）の割合は、「読み出しの重なる unit がその入力で開いていて、unit の開いた入力がその入力に似ている」配置で 0.06% → 1.24%（20 倍）、0.21% → 4.75%（22 倍）に上がる。

## 7. 複製が反例として出た所

「押しは自己項の向き」を破る型として、複製はこのセッションで 6 か所に出た。どれも、いまの見方では「なりかけの組の、閉じている方」。

| どこ | 形 |
|---|---|
| 0930 のノート §2.2・§2.2b | 読み出しの道。平行の unit が、ほかの unit のせいで逆になる（2 入力・3 入力の例） |
| §15.1・§15.2・§15.4 | 読み出しの道。自分より深い複製。重みを少しずらした写しがあると 33〜57/60 組で逆。実状態（凍結模型）の逆 8/1,497 は全部この型 |
| §16.12 | ゲートの道。開いた入力の塊を分け合う unit |
| §16.22 | ゲートの道。同じ入力で開いた、もっと強い unit |
| §16.26 (8) | ほかの unit が n で開いて、周りで閉じる（2 入力の例） |
| §16.29 | 全部の unit の押しを足しても逆になる |

- 毎回出る理由: 複製がいると、自己項と残りの区別がデータから付かない（観測 2）。「自己項が残りに勝つ」は、複製に対しては定義できていない。
- 仮定 (B)「複製がいない」は、証明の都合ではなく、「なりかけの組が引き寄せ合っている最中でない」という状態の条件。

## 8. 範囲と、まだ測っていないこと

- 動きの観測は 1 つの系（入力 5 個・1 次元・unit 2 個・同じ向き）だけ。入力が多次元の系、unit が多い系、向きが違う unit では動かしていない。
- 動かしたのは押しの期待だけ。課題の中の当てはめ・ミニバッチの揺らぎ・Adam・交差エントロピー・幅の伸びは入っていない。ゲートの幅と λ は固定。
- 押しの期待 = 容量の勾配降下 は、線形化した模型の、当てはめが済む極限の文。有限の当てはめでは、押しは純粋な勾配にならない（§16.23 (3)・§16.26）。
- 独立の検算: 反例そのもの（観測 1・2）は Codex と親で一致。観測 3〜10 は親の計算だけ。
- 「沈む」と「複製に重なる」のどちらも可塑性を失う向き、という読みは未検証（容量が下がることまでは模型の中で厳密）。
- まだ測っていないこと: 実網で似た組を人為的に作り（重みを写す）、切替の押しが引き寄せ合う向きになるか。ほかの seed・ほかの箱で似た組があるか。大きい系でクローン化が起きる条件。
