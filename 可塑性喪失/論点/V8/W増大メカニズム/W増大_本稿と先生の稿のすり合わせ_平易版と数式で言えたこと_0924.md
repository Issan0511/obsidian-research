## 1. 本稿の主張

Issa が「一番伝えたいこと」（[[V11骨組みの決定メモ_Issa_0923]]）に書いたのは次の 3 点。

- ReLU 型の活性化では、入力に平均があるかぎり沈下が起きる。
- 重みが伸びて前活性の幅が広がるほど、ELU・GELU・SiLU は働かなくなっていく。これらは負側で微分が 0 に近づくので、負側に微分があるから安心とは言えない。
- kunekune は負側でも傾きが残り、曲がる範囲を幅に合わせて動かすので、この問題を避けられる。

論文ではこれを 3 つの問いに分けている。

1. **なぜ沈むか。** 課題が切り替わった直後、網は古い予測を消そうとして大きく動く。その動きが入力の平均を通して、前活性全体を下へずらす。
2. **なぜ伸びるか。** §2。
3. **それでなぜ学べなくなるか。** 沈下が進むと、第 2 層の折れ目が分布の上端に来て、ほとんどの入力が負側に入る。その位置のまま幅が伸びるので、負側の入力はどんどん深くなる。ELU や GELU は深い負側で微分がほぼ 0 なので戻れない。leaky は同じ位置でも微分が残るので学び続ける。第 2 層の応答を人工的に入れ替える実験では、学べる網が学べなくなり、学べない網が学べるようになった。両層の伸びに上限を置くと、崩壊は止まった。

## 2. ②を浴槽でたとえる

「幅」は、第 1 層の各ユニットの出力が画像ごとにどれだけばらつくかの大きさ。重みのノルムとは違い、網が実際に使っている部分だけを数える。この幅を浴槽の水位と考える。

- **蛇口。** 課題ごとに、網は新しいラベルを覚えるために重みを書き換える。これが流入。
- **排水。** 次の課題以降が、前の書き込みの一部を消す。
- **水位。** 1 課題の流入と、書いたものが残る平均課題数の積になる。これは恒等式で決まる。

本稿の実験で分かったこと。

- 書き込みの 95% は後の課題が消し、5% が残る。この割合は、Adam でも SGD でも、隠れ層の幅を大きく変えても同じだった。
- 流入の大部分は、課題を覚え切った後も Adam が動き続ける分だった。覚えた後だけ SGD か凍結に替えると、伸びの大半と、後の課題ほど遅くなる現象がほぼ全部消えた。事前登録した実験で、leaky の網で確かめた。
- 調べた範囲では、水位は止まらなかった。

未解決だったのは「なぜ 5% 残るのか」。

## 3. 先生の稿が言っていること

先生の網と設定は本稿の背骨の実験とまったく同じで、数値も本稿の Adam の対照とほぼ一致する。先生の答えは「排水口がだんだん細くなり、蛇口がだんだん開く」。

- **排水口が細くなる。** 新しいラベルは乱数なので、勾配を平均すると「今の予測を一様に戻す」力だけが残る。今の予測を支えているのは直前の課題の書き込みなので、それは強く消される。古い書き込みは今の予測を支えていないので、弱い力でしか消されない。だから書き込みは古くなるほど消えにくい。しかも入力の分散が小さい方向ほど消えにくく、水はだんだんそちらへ溜まる。
- **蛇口が開く。** Adam の 1 歩の大きさは、重みの大きさに依らない。幅が大きいと 1 歩が相対的に小さくなり、同じ向きに進む時間が長くなる。その結果、1 課題の書き込みは幅の平方根くらいで増える。
- **だから止まらない。** 釣り合う水位そのものが上がり続けるうえ、遅い方向が埋まるまでにとても長くかかる。
- **幅が大きいと遅くなる理由も同じ。** Adam の 1 歩が相対的に小さくなるからで、幅を早期の値に戻すと遅れがほとんど消えた。学習率を上げるだけでも同じ効果が出た。

二つの稿の分担:

| 問い | 本稿 | 先生 |
|---|---|---|
| 誰が水を入れているか | 覚えた後の Adam。止める実験あり | 覚えた後の動きの形を数式で |
| なぜ 5% 残るか | 未解決 | 古い書き込みほど消されにくい |
| 幅が大きいとなぜ遅いか | 未解決 | Adam の 1 歩が相対的に小さくなる |
| SGD や隠れ層の幅を変えても同じか | 調べた | 無し |
| 伸びた幅が ELU や GELU を崩壊させるか | 調べた | 無し。先生の網は leaky で崩壊しない |

先生の稿は②の中身を埋める。本稿は、②の入口と、②から③へつなぐ部分を持つ。

**まだつながっていない所。** 「覚えた後の Adam が水を入れる」は leaky の網で確かめたこと。崩壊するのは ELU の網で、ELU の網でも同じ介入で崩壊が止まるかはまだ走らせていない。これが 1 本あれば、①から③までが同じ網でつながる。止まらなかった場合は、ELU の崩壊は切り替え直後の動きで決まる、と書く。

## 4. 数式で何が言えたか

先生の稿で数式として厳密に言えたのは、収支の帳簿と、Adam の対称性と、乱数ラベルでの勾配の平均の 3 系統。「幅が伸び続ける」は定理になっていない。帳簿に実験で測った値を入れると伸び方を再現できる、というところまで。

### 4.1 仮定なしで成り立つこと

1. **収支の恒等式。**
   ```
   V_t = (1 − a_t)² V_{t−1} + q_t
   ```
   V は幅の二乗、a は前の蓄えを消した割合、q は新しい書き込みの大きさの二乗。前の蓄えの残りと、それと直交する新しい書き込みを三平方で足しただけの式。a と q が一定なら、V は `q / (a(2 − a))` に近づく。weight decay 付きの網の平衡と同じ形で、減衰の代わりに次の課題の消去が入っている。本稿の `ΔV = Q + 2X` と釣り合い比 0.95 も、同じ恒等式の別の書き方。帳簿なので、a と q がどう動くかについては何も言っていない。

2. **Adam の尺度対称性。** leaky は正の定数倍と交換する。そのため第 1 層を 1/k 倍し、第 2 層を k 倍しても出力は変わらない。このとき ε を無視すれば、Adam の 1 歩は変わらない。つまり Adam の 1 歩の大きさは幅に依らない。幅が効くのは「1 歩が相対的にどれだけ小さいか」、つまり相対速度 `η / σ` を通してだけ。

3. **変位の分解。** 1 課題の変位の二乗は、歩数と、1 歩の大きさの二乗と、向きが揃っている長さの積。2 と合わせると、幅は「向きが揃っている長さ」を通してしか書き込みに効かない。

4. **ラベル平均の勾配。**
   ```
   E_y[∇L] = (1/N) Σ_n J_nᵀ (p_n − 1/C)
   ```
   ラベルが乱数なら、平均して残る力は「予測を一様に戻す」力だけ。ラベルに比例する部分は平均が 0 で、これが新しい書き込みになる。「今の予測を支えている書き込みだけが強く消される」という話は、この式が土台。

5. **線形回帰では積もらない。** 隠れ層がない線形回帰で毎課題を解き直すと、データで測ったノルムは前の重みに依らず、毎課題リセットされる。積もる原因は、隠れ層があることと出力の次元が低いことにある、という対比。

本稿側にも厳密な式が 1 つある。SGD では、隣り合う層の重みの二乗の差が、一歩ごとに二乗の項の分しか変わらない（Du・Hu・Lee 2018 の釣り合いの離散版）。だから SGD では第 1 層は一次の項で伸びない。Adam はこの保存則を一次の項で破り、伸びを第 1 層に積む（[[収束後だけSGDに替える_sgd_postfit_cifar_0923_結果_0923]] §3）。

### 4.2 仮定を置いて導いたこと

- **覚えた後の局面の速さと長さ。** 勾配が損失に比例し、その向きがゆっくり変わると仮定すると、Adam の 2 次モーメントの平方根と損失は、どちらも同じ速さ `(1 − β₂)/2` で減る。損失を e 分の 1 にするあいだの変位は、学習率にも β₂ にも依らない。この局面は、損失が float32 の丸めの床に着くまで約 9 回分続く。事前固定の検定を通っている。本稿の「覚えた後の漂流の速さは β₂ が決める」（[[IIDの静かな漂流が大きい理由_Adamの向きのずれ_事後_0923]]）と同じ内容。
- **書き込みの弾性が ½ になること。** 動きを拡散と見なすと、1 課題の書き込みは `√(η σ)` に比例する。実測は 0.53〜0.57 で、½ との差は導けていない。
- **消去の 2 項。** ある書き込みの振幅にかかる力をテイラー展開すると、2 つの項が出る。1 次の項は「今の予測を支えている度合い」に比例し、2 次の項は「出力をどれだけ動かすか」と振幅の積。直前の課題の書き込みは 1 次の項で強く消され、古い書き込みは 2 次の項でしか消されない。振幅が小さいときの展開。
- **釣り合う幅。** 恒等式に「書き込みは幅の β 乗」を代入すると、釣り合う幅は `(A² τ)^{1/(2(1−β))}`。β が約 0.53 なら、滞在時間 τ のほぼ 1 乗、書き込みの係数 A のほぼ 2 乗。代入しただけなので新しい仮定は入っていない。

### 4.3 導けていないこと

「伸び続ける」ことそのものは、上の式に測った値を入れて再現しただけ。

- 古い書き込みほど消去の割合が下がる量は、事後の当てはめ。下がった先の値がなぜ約 0.035 になるのかも、上位の方向の古い書き込みがほぼ消えない理由も、機構はまだ決まっていない。
- 方向ごとの消去率が入力の分散の 0.45 乗になるという関係は、観測の記述。
- 弾性 0.57 と ½ の差。
- 幅から当てはめにかかる時間を出す式は、最初の版が外れた。
- 全部 SGD の網でも弾性が 0.55 前後になる理由（本稿の走ゼロ）。2 の対称性は Adam のものなので、先生の導出の範囲外。
- 成長が必然だということ。

論文に数式として置けるのは、仮定なしの 5 つと SGD の保存則。仮定を置いて導いた 4 つは、条件を書けば置ける。成長率の機構を先生の稿の参照にするか（決定 9b の (e)）は、先生の確認のあと。
