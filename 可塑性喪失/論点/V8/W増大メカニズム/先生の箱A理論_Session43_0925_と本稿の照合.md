### 2.2 こちらから足す 4 件

1. **c↓ ∝ η の η 依存が未導出。** 押し下げの源（定理 6.2）は SGD 雑音と門の共分散なので、素朴には η²（揺れの分散）か η^{3/2}（OU 定常で揺れの幅 ∝ √η）。実測は c↓ = 24〜42 η で **η¹**。命題 6.5（Stein＋線形応答）は大きさを 1.2〜2.9 倍で当てるが η のべきを陽に出しておらず、Smith らの陰的正則化（η²TL）も合わないと先生も書いている。本稿の [[命題1-5_上端則結果_0905]]（leaky 0.1・5-d）では揺らぎが **η に依らなかった**（flip 浴: 折れ目の反転直後の残差パルスが源で Σδ² ∝ 1/η）。先生の箱でも揺れの源が同じなら「雑音の分散 ∝ η² × 相関時間 ∝ 1/η」で η¹ が出る可能性がある（候補・未導出）。
2. **「雑音は w 側に偏る（n_w > n_v）」は 1 行で厳密にできる。** leaky では φ(z) = φ′(z)z なので、補題 2.2 の η² 項は
   $$\Delta B_i=n_v-n_w=-4\eta^2d^2\,\varphi'(z_{i\ell})^2\,\lVert\tilde x_\ell\rVert^2\,\lVert w_i\rVert^2\big(\gamma_i^2-\cos^2\angle(w_i,\tilde x_\ell)\big)$$
   （z=0 では n_v 項が 0 で n_w 項だけ残る）。つまり **B が負へ動く（γ*² < 1）⟺ γ_i² > cos²∠(w_i, x̃_ℓ) の d²φ′²‖x̃‖² 重み平均**。[実測] だった「n_w > n_v が続く」が、γ が上がった後は自動的に成り立つ条件になる。帰結（仮定つき・未検証）: 幅の伸びが止まった後（Δ₁ ≈ 0）、|B| は γ² > ⟨cos²⟩ の間だけ伸び、γ² = 1 − |B|/‖w‖² は **⟨cos²⟩ へ落ちる**（引力点）。η=1e−2 後半で γ̄² が 0.16 → 0.052 に落ちるのは「γ の大きい unit から死ぬ選択」だけでなくこの引力でも説明できるかもしれない（初期化の cos² は 0.1·10.5/(2·10.5) ≈ 0.05、x̄ に揃った unit は 9.25/10.5 ≈ 0.88 まで上がる）。先生の fulltraj（per-unit v, w）で 1 行で検算できる。
3. **段 3 → 4（γ ↑ → 押し下げ ↑）は介入で確かめていない。** 根拠は腕またぎの時間平均の比例（μ₊ ≈ c↓γ̄²）と v² の因子（定理 6.2）で、腕の中の窓比は 0.33〜0.52（10⁻²）と一定でない。先生の §II.12-10 は B≈0 の初期化を提案しているが、もっと鋭い介入がある: **尺度の方向 ζ_i は出力を変えない（補題 2.1 ii）ので、γ_i を関数を変えずに毎課題リセットできる**（v_i → v_i/λ、w_i → λw_i）。γ を初期値 0.07 に釘付けた腕で死と A の低下が止まれば段 3 → 4 は因果、止まらなければ押しているのは幅そのもの（か雑音の総量 η²TL）。本稿の [[幅か沈下か_クランプ介入_結果_0909]] と同型の走で、1 腕 500 課題は CPU で数分。こちらの harness でも回せる（同じ箱）。
4. **(1−a) 因子の a 依存と本稿の ± 蹴りが逆向きのまま。** 定理 6.2 の自己整流は ∝ (1−a)v² で a が小さいほど強い。本稿では折れ目 unit への対称 ± 蹴りの対平均が **a=0.7 でだけ負**（a=0.1 では戻り対称・[[φ′収縮の局所式と全網の補償_結果_0918]] §3.5）。観測量が違う（自然な SGD の drift／蹴りへの応答）ので矛盾ではないが、先生の走は a=0.03 の 1 点。[[三理論の統合_駆動源5項式とV10とφ′射影_0918]] §3.5 の判別走（full-batch 対 SGD・± 蹴り反復）に a の梯子を足せば一度に決まる。
