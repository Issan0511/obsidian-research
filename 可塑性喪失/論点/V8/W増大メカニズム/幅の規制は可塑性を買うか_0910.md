## 0. 問い

$\lVert\widetilde W_1\rVert$ の増大が LoP の**原因**なら、成長だけを止めれば可塑性が戻るはずである。単なる相関なら、止めても精度は変わらないか、制約のぶん下がる。

これまで W 増大と LoP の関係は**相関**でしか見ていない（[[W増大メカニズム_0909]] §5.5・§D-8）。L2 は幅を止めるが同時に沈下も精度も全部変えるので、幅だけを止めた対照になっていない。

|---|---|---|---|---|---|
| leaky | 0.923 / 0.918 / 0.925 | 0.906 / 0.906 / 0.903 | **0.918 / 0.919 / 0.920** | −1.7 / −1.2 / −2.1 pt | **−0.5 / +0.1 / −0.5 pt** |

**正しい言い方は「精度が上がる」ではなく「目減りがほぼ止まる」。** クランプ腕は t20 の水準を 80 タスク保つ。差は ref 比で leaky +1.26/+1.33/+1.63 pt、Snake +0.47/+0.79/+0.66、ELU +1.08/+1.05/+1.29。**9 腕seed すべてで正**、80 タスク中 ref を上回った割合は leaky 0.91–0.95・Snake 0.81–0.85・ELU 0.94–0.99。

対応のある設計（同 seed・同ストリーム・bit 一致の t20 状態から 4 分岐）なので、seed 間分散は差し引かれている。

**同方向の傍証**:
- `mclamp`（設定点の散らばりを固定）と `dclamp`（沈下を固定）は精度を上げない（leaky で −0.1〜+0.5 pt）。**効くのは $\widetilde W$ の固定だけ。**
- [[ゲートなし線形網の幅成長_結果_0910]]: 幅が leaky の 85% までしか伸びない LIN の精度低下は −0.6 pt、leaky は −2.9 pt。
- [[第1層の成長の中身_事後_0910]]: `wclamp` は占有率 $p^+$ をほとんど動かさない（Δ −0.005〜−0.015）。**「ゲートが開いたから精度が戻った」ではない。**

## 1b. p⁺ ではなく ‖W̃‖ が lever（0910 夜）

同じ走で p⁺ を 0.12〜0.39 まで動かしても（mclamp / dclamp）精度は ±0.4 pt しか動かず、‖W̃‖ を止めた腕だけが +0.7〜+1.3 pt 戻る（表は [[駆動源問題_0909]] §10）。ELU では wclamp でも σ_inv が参照の 89% 残るのに精度が戻る。**効いているのはゲート占有率でも前活性幅でもなく、中心化重みのノルムが運ぶ何か。** これが本論点を LoP の主軸に接続する根拠。

## 1c. 400 タスクでも順序は ‖W̃‖（0910・[[長い地平線でのleakyとELUの分岐_結果_0910]]）

t400 の累積精度損失は leaky −4.3 / ELU −3.1 / Snake −0.9 pt で、‖W̃‖ の 15.2 / 13.7 / 9.0 と同順（n=3・相関）。死亡数（0 / 9 / 0）・飽和（0 / 0.62 / 0.15）・p⁺（0.10 / 0.23 / 0.30）では順序が付かない。3 腕とも late 傾きは −0.3〜−0.6 pt/100task に収束し、1/√t（−1.0）より速く減速する。**減速の理由は未導出** — 強度ダイヤルで「幅を止めると減速が消えるか」が §4 に足す判定候補。

## 1c′. 訂正（0910 夜）: 幅は腕の**中**の lever であって、腕の**間**の順序は付けない

§1c の「順序は ‖W̃‖（n=3）」は偶然だった。`gate_scale_invariance_0909` の 8 腕（t120）で幅と損失は **Spearman +0.07・Pearson +0.01**。Snake 族は幅 6.0–7.0 で損失 0.1–3.4 pt（SN02 対 SN06 は seed 対で 3.3/2.6/1.7 pt とすべて正）。幅 7.4 に抑えた leaky（`wcap2`）は幅 8.7 の Snake より 1 pt 悪い。**loss ≈ c_act · g(‖W̃‖)**: 各腕の中では g（§1d の介入）、腕の間は c_act。**§3-1「なぜ目減りが止まるのか」は c_act の同定と同じ問い。** 候補: 支持上の実効非線形性（SN02・LIN の「ほぼ線形」が小さい）。

## 1d. t400 の登録走で「lever は ‖W̃‖」が決まった（0910・[[長い地平線で沈下と幅を分ける_結果_0910]]）

## 2. なぜ論点として立てるか

1. **因果の向き**: W 増大 → LoP の**介入的**証拠の 1 点目。これまでは相関と、L2 という交絡だらけの対照しかなかった。
2. **既存手法との関係**: `wclamp` は Nero 型の射影制約（[[文献照合_W増大メカニズム_0909]] §6）。ただし文献の射影は最適化器の一部として最初から掛けるもので、**「途中から、第 1 層の中心化部分だけ、行平均と bias は自由なまま固定する」腕は見当たらない**。新規性の線引きは §4 の走の後。
3. **実用**: LoP 緩和策として測れる形になっている。

## 3. まだ言えないこと（＝論点の中身）

1. **なぜ目減りが止まるのか。** $p^+$ は動いていないのでゲートではない。実効ランク・条件数・第 2 層の追随・勾配の SNR — どれも未測定。
2. **開始点と強度に 1 水準しかない。** t20 で凍結・κ=1 のみ。t1 から掛けたら？緩い制約（κ>1 で伸ばす余地を残す）なら？**単調性が出なければ「たまたま t20 が良い動作点だった」で終わる。**
3. **天井効果の可能性。** t20 の 0.923 を保っているだけで、それを超えてはいない。「可塑性を買った」のか「初期状態を保存しただけ」かは、**より長い地平線（t200 以降）**か**より強い制約**でしか分けられない。
4. **保持（後ろ向き）は未測定。** 現タスク精度だけ。幅を止めると過去タスクの保持が悪化する可能性は残る。
5. **L2 との同走比較が無い。** 「幅だけ止める」対「幅も深さも止める」の直接対照。
6. **1 アーキテクチャ・1 データセット**（784→100→100→10・pmnist・100 ユニット）。CNN・RandomLabel 系では未確認。
7. **第 1 層のみ。** W2・W3 も同時に伸びている（[[幅か沈下か_クランプ介入_結果_0909]] §7 の w2col）。第 1 層を止めれば十分なのか、他層が代償するのかは未測定。

## 4. 閉じ方（案・未登録）

| 走 | 何を決めるか |
|---|---|
| **強度ダイヤル** $\lVert\widetilde W_i\rVert \leftarrow \kappa c_i$、κ ∈ {0.7, 1, 1.4, 2, ∞(=ref)} | 精度が κ に単調か。単調なら「幅が LoP を作る」、非単調なら「t20 が良い動作点」 |
| **開始点** t1 / t20 / t50 から | 初期状態の保存なのか、成長そのものが害なのか |
| **L2 同走** | 幅だけ止める 対 幅も深さも止める |
| **保持測定** | 過去タスクの再評価（[[保持測定結果_0829]] の枠を流用） |
| **機能量の相乗り** | 実効ランク・条件数・第 2 層列ノルム・勾配 SNR を毎タスク記録（[[9月運用_0901]] §2「ロガーを盛ってから回す」） |
| **他層クランプ** | W2 も同時に固定した腕 |

**優先**: 強度ダイヤルと開始点は同じ runner の腕追加で済む（1 継続 216 s、9 腕seed で 35 分）。保持測定と機能量は相乗りで足せる。**L2 同走を必ず同じ走に入れる**（別走の L2 と比べると seed とストリームが変わる）。

## 6. この論点が閉じたときの含意

- **単調に効くなら**: [[中心主張v8草案_0909]] の段階 0（履歴の蓄積）が段階 3（機能的 LoP）の原因であることの介入的証拠になり、V8 の時間順が因果順であると言えるようになる。
- **非単調・保存だけなら**: W 増大は LoP の**随伴現象**で、原因は別（沈下・ゲート・読み出し）。§41 の位置づけを「上流状態」から「共変量」へ下げる必要がある。

どちらでも V8 の構造に効くので、§D-8 を「未着手」のまま置かない。
