## 3 矛盾と和解

### 3.1 勾配が縮むことと、押しの零点が無いこと

Shvetsov の停止（§1 l.345「gradients diminish, the drift stabilizes」、§2 の knee）は、通常訓練で勾配の大きさが落ちて漂いが鈍るという説明で、有限位置の安定平衡の定理ではない [原典]。本稿の補題 2 は、凍結模型の期待の押しが条件内で正だという主張で、正の一様な下界は言わない [原典]。押しがゼロへ近づくことも、更新の累積が有限なら変位が有限に収まることも許す。両立する。
課題の中で誤差が消えれば勾配は小さくなり、切替で新ラベルが来れば旧課題を学んだ読み出しを通って C.3 の押しが現れる。「装填し直す」はこの意味で両立する。ただし C.3 は H1 を仮定しており、各課題で κ が十分に育ち直すことを定理では示していない [読み]。相 1 と相 2 の時間的な接続を定理にするには、両模型が使える時刻と持続の条件が要る。

### 3.2 任意の深さと、入力層・CNN の例外

Shvetsov §1 は「weights at every layer」と書き、最初の隠れ層も含む [原典 l.442]。しかし前活性の勾配と重みの更新は別で、∂ℓ/∂W_ik = (∂ℓ/∂p_i)·x_k。隠れ ReLU の出力は x_k ≥ 0 だが、原入力は符号つき（G.1 の標準化画像、G.2 の正規乱数）。§0 の 3 の反例のとおり、入力層では追加条件が要る。
本稿の CNN c1 の結果は、学習後の状態で新ラベルについて平均した押しで、主対象は leaky と Snake 族。Shvetsov の定理（初期化時・ReLU・乱数読み出し）への反例ではないし、その定理を理由に c1 の逸脱を無視することもできない。C.11 と CNN ノート §4 の適用限界は残す。初期化時の c1 の押しは測っていない（保存済みの初期値で計算できる）。

### 3.3 重みの漂いと位置の漂いは別の量。Shvetsov の証明の記載上の問題

Δm = x̄ᵀΔw + Δb（上流が動く層では wᵀΔx̄ + ΔwᵀΔx̄ が加わる）。重み平均が負へ動くことだけでは内積の符号は決まらない。平均活性 Eφ(z) の低下から m の低下も逆算できない。一定学習率の GD では E[Δw] = −η E[g_w] だが、Adam では過去のモーメントと座標ごとの分母が入り、勾配の平均の符号だけでは更新の符号は決まらない。Shvetsov C.2 の MP-SENet（GELU/SiLU で勾配は正のまま重み平均が正へ）はこの区別を要する観測 [原典 l.507]。本稿の期待値の定理も GD の一歩の文で、Adam の下の符号は主張しない。引くときは「GD の一歩」と限定する。
Shvetsov の証明の記載上の問題（Astra §4.9。本稿との矛盾ではなく、援用する前の確認事項）: 定理 1.1 は有効行列の行の内積を述べるが付録 A は列の内積に使う。行の Gram から列の交差項の非負は一般には出ない（a, b, c を √2 w.p. 1/3、−1/√2 w.p. 2/3 の iid、d = 1{a+b>0}、V = (cda, cdb) で E[V₁V₂] = −2/9 < 0 [厳密・Fable も手計算で確認]）。定理 1.1 の第 2 証明は零平均 iid から回転不変を使う。定理 1.2/1.3 の下流ゲートと p^(l) の独立は追加仮定。B.1 の CE は高次剰余の符号を制御していない。Remark B.2 の奇数項の消滅は符号反転対称性を要る。

### 3.4 中心化は軸と配置と bias を指定して引く

本稿の中心化は入力間の各座標の平均を 0 にする操作で、そのとき K_n = 1、bias が学習されれば経路が残る。Shvetsov G.1 の線形層・畳込層は bias を省く [原典 l.2454]。LayerNorm は各標本内の特徴を中心化する操作で、x̄ = 0 を意味しない。表 1 の MLP+LayerNorm は ReLU でも負の前活性率 68.6% [原典 l.620]。Shvetsov が中心化の例として直接挙げるのは BN を持つ ResNet（43.6%）。「LayerNorm があれば漂いは消える」とは書けないし、「先行が CHB と同じ介入を検証した」とも書けない。bias の無い網では K̄ = ‖x̄‖² が 0 に近く、補題 1′ の q の定義が退化する。bias 無しの網での補題 1′ の形は未導出。

### 3.5 SiLU・GELU は「弱い」のか「全閉まで下がる」のか

彼らの比較は単一課題の初期（1,000 step・5 epoch）の重みの変化の速さと訓練後の負の割合（MLP で ReLU 70.8%、GELU 63.6%、SiLU 61.0%）。本稿は多数の切替の後の到達点（1 層の箱で SiLU・GELU は止め役が無く r ≈ −2.5 の全閉、leaky は −2.2 で止まる）。別の量。本稿の模型でも正側の自己の項は SiLU・GELU で小さく（g ≥ z/4、ReLU は g = z）、一歩が弱いことと整合する。到達の深さは止め役の有無（H6）で決まる。

### 4.2 強化: SiLU・GELU は全実数で φφ′ ≥ z/4 [厳密]

φ(z) = z·A(z)、A = σ（SiLU）または Φ（GELU）、g = φφ′ = z·A·(A + zA′)。z > 0 では A ≥ 1/2 かつ A + zA′ ≥ A なので A(A + zA′) ≥ 1/4。z < 0 では A ≤ 1/2 かつ A + zA′ ≤ A なので A(A + zA′) ≤ 1/4。負の z を掛けて不等号が戻り、全実数で g(z) ≥ z/4、z ≠ 0 で狭義。よって E[g(Z)] ≥ m/4 で、m ≥ 0・P(Z ≠ 0) > 0 なら E[g(Z)] > 0。
数値の確認（Fable、格子 [−60, 60]・480 万点）: g − z/4 の最小は z = 0 の 0、|z| > 10⁻³ では全点で正。
使える範囲: 一定の正の担い手（H3）の下の相 1 の符号。可変の K_n ≥ 0 なら Σ K_n g(z_n) ≥ (1/4) Σ K_n z_n。負の K_n があるときは点ごとに掛けられない。相 2 の残差化した共分散とゲートの φ″ の項には使えない。パッチ §3 の SiLU・GELU の条件は、この場面ではこの不等式に置き換えられる。
