## 2. Issa の判断（2026-09-20・1 と 3 は決定、2 は確認中）

1. **Lyle E.9 の書き方（1b）— 採用（両方書く）。** 原文は 2 段で、(i) MLP は batch 軸の平均減算が無いと訓練できない、(ii) それは入力中心化で大半が代替できた、と言う。当方は (i) と同じ向き（H が効く）、(ii) と逆（D1 は `TIE`）。**両方を書く**のが誠実で、差の候補は箱（彼らは L2 1e−5 あり・50,000 step・100 反復、当方は WD なし・30,000 更新・50 タスク・raw の μ が 3 桁大きい）。「Lyle と逆向き」とだけ書かない。
2. **L&C の「WD なし」（3g）— リポジトリで確認中（0920・サブエージェント）。結果が出るまで本文で「WD なし」と書かない。** 原文に weight decay の記載が無い。「Adam・CL 介入なし（vanilla）」までにするか、リポジトリの設定で確かめるか。リポジトリは `lute47lillo/activations_plasticity`（0917 に main を取得済み、論文の走と同じ版かは不明）。
3. **Goldilocks 0.6–0.9（3c）— 採用（但し書きごと引く）。** 5+1 spec は LK07 の根拠に使ったが、原文は「規則ではない」と但し書き。5+1 で LK07 が負けたことを書くとき、彼らの但し書きも一緒に引く。

## 3. 直しが要らなかったもの

数字はすべて原文と一致した（Kumar Fig. 2 の 8 値、L&C Table 2 の 5+1 列 12 値と RL 列 7 値、Table 4 の lr/λ、Salimans の誤り率、Ziyin の式、Abbas の定義、LeCun の節）。当方の丸め（84.2 ← 84.23 など）は小数 1 桁。
