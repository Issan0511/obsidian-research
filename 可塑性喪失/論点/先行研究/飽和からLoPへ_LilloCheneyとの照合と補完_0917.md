## 0. 一行

**「ReLU 以外でもユニットが実質的に死ぬ」ことは新しくない。** 最も近い Lillo & Cheney は、負側の微分が裾で 0 へ減衰する活性化（ELU・CELU・SELU・GELU・Swish）を「実効的な非ゼロ床」として一つの群にまとめ、厳密な非ゼロ床を持つ活性化を勧める。これは V10 §0 第三文のクラスと同じ括りなので、**クラス分けそのものに新規性はない。** ただし同論文の「飽和 → LoP」は、相関（r = −0.51）と、自分のデータで支持されなかった仮説（付録 D.4）で支えられている。押し込みは仮定と人工の衝撃で与えていて、観測していない。V10 が補完するのは、**押し込みの観測と担い手の特定・介入、飽和から LoP への介入、機能的な死の定義、裾の定理**。

## 1. 先行文献（非 ReLU のユニットの死・飽和）

## 2. Lillo & Cheney の精読

出典: arXiv 2509.22562 v4（2026-04-30）、リポジトリ `lute47lillo/activations_plasticity` の main（2026-09-17 取得。論文の走と同じ版かは不明）。

### 2.1 Random Label MNIST の設定は、私たちの箱とほぼ同じ

| | Lillo & Cheney（付録 E・表 E1・E2） | 私たち（resp_ee 系） |
|---|---|---|
| 網 | 784–100–100–10 の MLP（`bench_models.py`） | 同じ |
| データ | 1200 枚固定・タスクごとに新しい乱数ラベル | 同じ |
| 最適化 | Adam・batch 16 | 同じ |
| 1 タスク | **400 epoch = 30,000 更新 × 50 タスク** | 80 epoch = 6,000 更新 × 22〜150 タスク |
| 学習率・形 | **活性化ごとに調整**。ELU は **α = 3.6・lr 1e−4**、GELU は β = 0.8・lr 1e−3、Swish は β = 0.01・lr 1e−3、CELU は α = 3.6・lr 1e−4、ReLU は lr 1e−4 | α = 1・lr 1e−3 |
| 主量 | 全 50 タスクの online 精度の平均（更新前のバッチ精度） | 次のタスクの online 精度、適合率 F |

表 2 の Random Label MNIST（%・5 seed）: ReLU 20.0、GELU 38.8、CELU 37.2、Swish 67.7、SELU 80.0、ELU 84.2、leaky 91.5、Rand. Smooth-Leaky 93.3。

読みの注意:

- **ELU の 84.2 は lr 1e−4 の値。** 学習率は輸送の速さに効くので、「ELU は生き残る」は「この学習率では 50 タスクのうちに裾へ届かなかった」の可能性がある。同じ 400 epoch × 50 タスクの箱を lr 1e−3・α = 1 で回した act_chimera_0913（[[層別キメラでELU崩壊の所在を決める_結果_0914]] §5 の凍結の表の出所・[[εの再判定_float32の床を入れて読み直す_結果_0917]] の L3）では、ELU は 3/3 seed で偶然水準に落ち、t18–30 で凍結した。
- **ただし学習率だけでは説明しきれない。** CELU は同じ α = 3.6・lr 1e−4 で 37.2。CELU の負側の微分は $e^{z/3.6}$ で、ELU(3.6) の $3.6e^{z}$ より裾でずっと大きいのに成績は悪い。0 付近の傾き（CELU は 1、ELU(3.6) は負側で 3.6）など、裾以外の違いが効いている。
- Swish の β = 0.01 は、通常の前活性の範囲ではほぼ線形。クラスの中の関数として比べる対象になっていない。
- 主量が全タスクの平均なので、後半の崩壊と中程度の劣化を区別できない。
- 5 seed・活性化ごとに調整した 1 設定ずつ。

### 2.2 「飽和 → LoP」について言っていることと、その格

| 箇所 | 主張 | 格 |
|---|---|---|
| §3・付録 C.1 | 負側の傾きの掃引で、dead unit の割合と最終精度が負に相関（r = −0.51）。8% 未満なら精度 27〜33%、25% 超なら 20% 以下。勾配ノルムとの相関は弱い（r = −0.11）ので、dead unit の増加（勾配の飢餓）の方が LoP の直接の指標だとする | **相関**。活性化の形を変える掃引なので、dead unit と一緒に曲率なども変わる。本人たちも、dead unit だけでは分散を説明しきれず、傾きが大きい側では曲率が失敗を決めると書く |
| §4 冒頭 | 分布のずれの後、前活性が裾の奥へ押し込まれ得る。脱飽和にかかる時間が適応の遅れを決める、と仮説を置く | **仮説** |
| §4・付録 D.2–D.3 | 前活性を γ 倍する衝撃で、厳密な非ゼロ床を持つ活性化は飽和から最もよく戻る。実効的な非ゼロ床の群は、戻るときは速いが戻らない割合が高い。|φ′| < 1e−3 となる入力範囲の幅が、戻らない割合を予測する（r = 0.84） | **飽和の指標どうしの関係**（性能ではない） |
| 付録 D.4 | 衝撃後の性能の回復時間 τ95 は、ほぼ全員 1〜2 epoch（非回復 1.1%）。γ = 2 では両側飽和型（sigmoid・tanh）が最速、厳密な床を持つ群が最も遅い | **§4 の仮説と逆向き**。本人たちは「当面のタスクの回復であり、長期の可塑性は全体の精度で見るべき」と退く |
| §8 | 脱飽和の上界などの理論は今後の課題 | — |

**「飽和 → LoP」は、この論文で最も弱い環。** 飽和を動かして LoP が動くかを見た実験は無い。

### 2.3 押し込みの出どころ — 観測ではない

1. **仮定。** §4 は「押し込まれ得る」という言い方で、引用も図も無い。序論の Lyle et al. の「前活性の分布のずれ」からの借用と読める。
2. **§3 の dead unit の割合を傍証にしている。** ただしこれはタスク終端の状態の数で、時間的な動きではない。しかも判定は出力値によるので、裾にいるかを見ていない（§2.4）。
3. **§4 では人工的に作っている。** 10 epoch ごとに 1 epoch だけ、全層の前活性を γ 倍（1.5・0.5・0.25・2.0 を順に）して、すぐ戻す（付録 D.1）。何が押すかは問いの外。
4. コード（`dead_units.py`）は層ごとの前活性の平均も記録しているが、論文にはその推移の図が無い。

### 2.4 dead unit の判定はコードで見ると出力値の大きさ

`utils/dead_units.py` の `analyze_activations_streaming`（現行 main）:

| 活性化 | 「dead／saturated」と数える条件（(ユニット, 入力) ごと） |
|---|---|
| sigmoid | a < 0.02 または a > 0.98 |
| tanh | \|a\| > 0.98 |
| ReLU | \|a\| < 1e−5 |
| leaky | \|a\| < max(0.05σ, 10·傾き·σ)（σ はそのバッチの出力の標準偏差） |
| **GELU・SiLU・Swish** | **\|a\| < 0.05σ** |
| **ELU・CELU** | a < −α + 0.02、**または \|a\| < 0.05σ** |

- GELU・SiLU は φ(0) = 0 なので、**z ≈ 0 にいて微分が約 0.5 ある元気な入力も dead に数えられる。** ELU も z ≈ 0（微分 1）が入る。この割合は「裾の奥にいる」と「0 のそばにいる」を区別できない。
- 衝撃の実験の飽和割合（SF）は解析的な微分 |φ′(z)| < 1e−3 で数えていて、こちらは微分に基づく。ただし訓練で使われる微分ではない（[[εの再判定_float32の床を入れて読み直す_結果_0917]] の 3 系統の話は、彼らの実装には未確認）。
- **出力の判定では原理的に見えない例が、私たちの手元にある。** resp_ee の移植腕は、分岐点の前向きの値が自然な網と bit 一致するように作ってある（検査 S3）。したがって出力で数える dead unit の割合は、崩壊した t10 の網（E 0.14）と t2 の場を戻した網（E 0.90）で同じ値になる。学習能力を分けたのは微分の側だった。

### 2.5 付録 D.4 は、V10 の「押しの持続」と整合する

γ 倍は前活性の一様な拡大で、層の重みと bias を γ 倍するのと同じ前向きになる。つまり**「W 増大の一回版」を 1 epoch で元に戻している。** 押しが続かないので、ユニットは戻れ、性能も戻る。

- 押しが一回きりなら戻れる: resp_ee の固定した場では、移植先のユニットが自力で登り直した（+4.9）。
- 押しが続くと戻れない: 動く場（切替直後の一様な沈み）で、媒介率が 0.47 → 0.72 に上がった（[[動く場の移植_応答低下からLoPへ_結果_0917]]）。
- 押しを止めると戻り始める: 崩壊した ref の網も t10 で成長を止めると登り返し、+0.053 学べるようになった（[[cap12とrefの網で第2層の場を入れ替える_結果_0917]]）。

したがって D.4 の「性能は戻る」は、V10 から見ると予測どおりで、§4 の仮説の反証ではない。ただし彼らの衝撃は健康な網への一回きり・課題の途中で、私たちの結果とは条件が違う。同じ衝撃を私たちの箱で、戻す・戻さないで比べる走は設計案の C2。

## 4. 補完の候補（未実行）

- **C1 判定の混同（再解析・走ゼロ）**: 私たちの保存状態に、彼らの出力の判定と訓練の微分の判定を並べて当て、彼らの「dead」のうち元気な入力がどれだけ混ざるかと、どちらが再学習と並ぶかを測る。
- **C2 押しの持続（彼らの衝撃を私たちの箱へ）**: 同じ γ 倍の衝撃を、1 epoch で戻す・戻さない・切替直後に当てる、で比べる。
- **C3 学習率と α（彼らのプロトコルで）**: 400 epoch × 50 タスクで、lr {1e−3, 1e−4} × α {1, 3.6}。ELU の 84.2 が「輸送が届かなかった」で説明できるか。
- **C4 理論（未導出）**: 一回きりの押しからの回復時間の上界と、押しが続くときの釣り合い。彼らが今後の課題にした「脱飽和の上界」に当たる。

## 5. 新規性の書き方

- **V10 §0 第三文（クラス命題）**: Lillo & Cheney の「実効的な非ゼロ床」の群を引用し、括り自体は既知とする。V10 の貢献は、その群が自然な学習でいつ裾に届くか（輸送の担い手と介入）、届いたらなぜ戻れないか（定理と押しの持続）、どう機能的に死ぬか（訓練の微分と実効数・両方向の介入）。
- **「厳密な非ゼロ床を持て」の限界**: leaky には幅の経路の劣化が残る（V9、[[幅の規制は可塑性を買うか_0910]]）。床は到達後の分岐を外すだけで、上流の輸送は止めない。
- **言わないこと**: 「非 ReLU の死を初めて示した」「飽和 → LoP を初めて示した」。言えるのは「飽和 → LoP を、応答の場への両方向の介入で示した」。
