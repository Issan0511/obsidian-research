## 一行

**condA では、消灯（p̂ = 0）はゲートマージンの閉不等式 `β ≤ −κ`（κ = ‖w_free‖₁/‖w_free‖₂ ∈ [1, √5]）と厳密に同値であり、この集合はタスク内 SGD の不変集合である。ガウス入力の PB-5「Φ(β) > 0 なので絶対吸収は起きない」に対し、有界入力では吸収域が正の測度で実在する — その但し書き解除を、初めて閾値つきの式にする。**

## 1. 設定と記号（既存定義の再掲のみ）

[[用語と記号]] §1・§3 に従う。condA・1 タスク内・ユニット 1 本（添字 i 省略）。

- 入力 `x = [flip ‖ rnd] ∈ {0,1}²⁰`。flip 15 bit はタスク内定数、rnd 5 bit は毎 step iid Bern(1/2)。サポートは rnd の **2⁵ = 32 パターン**（等確率）
- `µ = E[x] = [flip ‖ 0.5·1₅]`、揺らぎ `δ_x := x − µ`（flip 座標で 0、rnd 座標で ±1/2）
- `w = (w_flip, w_free) ∈ ℝ¹⁵ × ℝ⁵`（**表記ゆれの申し送りを継承**: §9 系は `w[:15]` 等。正は未決）
- 前活性 `z = w·x + b = s + w·δ_x`、`s := w·µ + b`（周期内定数部）
- `gate = 1[z > 0]`、`a = ReLU(z)`、`p̂ := (1/32) Σ_パターン 1[z > 0]`（[[マージン恒等式と消灯点_0822]] §1.4 で記録値との完全一致を確認済み）
- `M := max_δ (w·δ_x) = ‖w_free‖₁ / 2`（最大は δ_x = ½·sign(w_free) で達成され、これはサポート内の 1 パターン）
- `σ := ‖w‖_Σ = √(wᵀΣw) = ‖w_free‖₂ / 2`（Σ = Cov(x)、rnd ブロックのみ分散 1/4）
- `β := s / σ`（[[用語と記号]] §1 のゲートマージン、レジーム A 定義そのまま。**w_free ≠ 0 を要する**）

## 2. 命題（消灯の閉不等式・正規化形）

**命題 1.** condA の 1 タスク内で、`w_free ≠ 0` のとき

```
p̂ = 0  ⟺  s + M ≤ 0  ⟺  β ≤ −κ ,   κ := ‖w_free‖₁ / ‖w_free‖₂ ∈ [1, √5]
```

`w_free = 0` の退化では σ = 0 で β は未定義だが、第一の同値 `p̂ = 0 ⟺ s ≤ 0` はそのまま成立する（M = 0、z ≡ s）。

**証明.** サポート上の z の最大値は `max z = s + max(w·δ_x) = s + M` で、最大化パターンはサポートに含まれる。ゲートがどこかで開く ⟺ max z > 0 ⟺ s + M > 0。対偶を取り、σ > 0 で割ると `s/σ ≤ −M/σ`、ここで `M/σ = ‖w_free‖₁/‖w_free‖₂ = κ`。κ の範囲は ℝ⁵ のノルム同値（‖·‖₂ ≤ ‖·‖₁ ≤ √5‖·‖₂）。∎

**注（同一代数の別座標）.** `s + M = b_eff + reach`（`b_eff := flip·w_flip + b`、`reach := Σ_{j∈rnd} max(w_j, 0)`）。恒等式は `0.5Σw_j + 0.5Σ|w_j| = Σ max(w_j, 0)`。したがって本命題は [[xr分解と生存機構_0822]] §9 の閉形式・[[マージン恒等式と消灯点_0822]] §1.2 の cos 表現と**同一の判定条件の第三の座標**であり、二重記帳しない。新規なのは (i) β という無次元量での表現、(ii) 閾値 −κ の明示、(iii) 下記の二分法と不変性である。

**注（スケール不変性）.** (w, b) → λ(w, b)（λ > 0）で β も κ も不変。判定条件は方向のみの関数である。[[引用禁止]]「正規化量（cos, β）で力学を書かない」は**時間発展**への警告であり、本命題は**静的な判定条件**なので抵触しない（[[マージン恒等式と消灯点_0822]] §1.3 の注意を継承。引用時に一言添えること）。

## 3. 系 1（力学的吸収 — タスク内不変性は定理）

**系 1.** `D := {(w, b) : s + M ≤ 0}` 上では、サポート全 32 パターンで `gate = 0`・`a = 0`。よって当該タスクから引いた**任意のバッチ・任意の学習率**に対し

```
∂ℓ/∂w = 2δ·v·gate·x = 0 ,  ∂ℓ/∂b = 2δ·v·gate = 0 ,  ∂ℓ/∂v = 2δ·a = 0
```

が**恒等的に**成立し（ReLU の劣勾配規約 ReLU′(0)=0、実装準拠）、ユニットの座標 (w, b, v) はタスク内で厳密に不動。D は**開集合上で勾配が消える真の平坦域**（[[自己項の恒等式]] §1 系・§2 等号条件の明示版）であり、到達すれば**タスク内では**出られない。

- 格: 系そのものは定理。実測アンカー「タスク内 p̂=0 ペア **16,475,293 件**で復活 0・`max|Δcos| = max|Δ‖w‖| = 0`」は**事後計算**（[[xr分解と生存機構_0822]] §14、作業4で昇格予定）
- 吸収は**タスクごと**: 境界で flip が変わると s がジャンプし D が引き直される。恒久死は全変種の D の共通部分（[[命題リスト]] Q11。同 8/22c 注記により列挙不要の閉形式で書ける）
- `strict_dead`（p̂ = 0）にのみ適用する。`near_off`（p̂ = 1/32）は 1 パターンで開き勾配が残る（8/23 裁定、[[用語と記号]] §1）

## 4. 系 2（PB-5 の二分法 — 吸収の存在条件）

揺らぎ δ_x を平均 0 の任意の分布に置き換え、`ρ(w) := ess sup(w·δ_x) / σ ∈ (0, ∞]` とおくと、同じ証明で

```
p̂ = 0  ⟺  β ≤ −ρ(w)
```

- **ガウス入力**: `w_free ≠ 0` なら ess sup = ∞、よって ρ = ∞ で吸収域 {β ≤ −ρ} は**空**。これが PB-5「Φ(β) > 0 なので絶対吸収は起きない」の言い換え（p̂ = P(z>0) = Φ(β) > 0）
- **有界入力**: ρ(w) は有限で、吸収域は**正の測度で実在**する。condA では ρ = κ ∈ [1, √5]

**二分法**: 文字通りの吸収が存在するか否かは、w 方向の揺らぎの**片側有界性**（ess sup の有限性）と厳密に同値。[[整流モデル]] 部品2 の「condA の有界入力では文字通りの吸収が実在」・[[用語と記号]] §5 PB-5 の「但し書きは有界サポートでは解除される」が、閾値 −ρ(w) つきの定理になる。

## 5. 系 3（κ の幾何 — 実効自由ビット数）

`κ² = (Σ|w_j|)² / Σw_j²` は w_free の **participation ratio**。k 本の等大成分なら κ² = k（チャット内検算で k = 1..5 一致、未コミット）。

- **κ = 1**（1-sparse）: 吸収閾値 β = −1 が最も浅い。自由ビット 1 本しか使わないユニットは、正規化マージン −1 で既に凍る
- **κ = √5**（5 本等大）: 閾値 −√5 が最も深い。**自由ビットを広く使うユニットほど、同じ σ に対して最良パターンの持ち上げ M = κσ が大きく、凍りにくい**
- 実測 κ ∈ [1.19, 2.24] は**事後**（[[マージン恒等式と消灯点_0822]] §1.3）

**xr分解との関係（混同注意）.** [[xr分解と生存機構_0822]] の `reach`・`r` は「背の高さ」＝どれだけ持ち上げられるかの**絶対量**。κ はそれを ‖w_free‖₂ で割った**形状量**で、「背を何本の自由ビットに載せているか」を測る。両者は独立に動きうる（同じ `r` でも κ は 1〜√5 の幅を持つ）。「入力に応答する重みが育つと死から遠ざかる」（[[ノルム増大と不可逆性]] §(4)）は前者の話で、κ はそこに**形状という第二の自由度**を足す。

## 6. µ 依存と Q8（Feller・task_080）への予言 — **字義の修正提案あり**

µ は s = w·µ + b を通じてのみ入る。cos 表現との等価（[[マージン恒等式と消灯点_0822]] §1.2）:

```
β ≤ −κ  ⟺  cos(u, µ̂) ≤ cos_crit = −(b + M)/(‖w‖·‖µ‖)
```

1. **吸収性（系 1）は µ に依らない。** D に入れば出られない、はどの µ でも定理。µ が決めるのは**吸収域の位置と、そこへの輸送**である
2. ‖µ‖ → 0 で cos_crit は（b + M > 0 のユニットで）発散し、壁は cos の定義域 [−1, 1] の外へ出る。実測: `ratchet_centered_0822` C1 不可比 ＝ 崖の消失、`mu_titration_0823` C1 ＝ 低用量 2 点の**左打ち切り**（格: FULL_PASS。正本 commit `38aff23` は **8/24 時点で未 push**）
3. ただし **D 自体は消えない**。‖µ‖ → 0 では s → b で `D → {b + M ≤ 0}` に退化する。実測もこれと整合: centered では `b + M ≤ 0` と p̂ = 0 の一致率 98.9%（std は 7.0%、事後）、centered final dead 0.324（commit 済）、titration 最低用量の strict_dead 0.245（正本未 push）

**予言の精密化（本 note の提案）**: 作業リスト・[[マージン恒等式と消灯点_0822]] §9-1 の字義「µ → 0 の極限で吸収境界でなくなるはず」は、**そのままでは上記 3 と衝突する**（吸収域は残る）。task_080 で分類すべきは境界の存在ではなく**到達可能性**であり、予言は次の形に直すことを提案する:

> ‖µ‖ → 0 で、**x 座標（cos 側）経由の到達経路は閉じる**（潮流 G ∥ µ̂ の輸送が消え、壁が定義域外へ退場する）一方、**b 座標経由の到達経路は残る**（Q14: 税の b 成分は入力分布に無条件で沈黙方向）。したがって dead は 0 に落ちず、µ 非依存の床（b 経路）が残る。

これなら `ratchet_centered_0822`（0.324）とも titration P1 の**低用量反騰**（0.105 → 0.134 → 0.245、単調でない）とも矛盾しない。字義のままだと自分のデータに反証される。

- 留保: centered の「死亡」の 53% は 1e6 時点で復活しており（[[マージン恒等式と消灯点_0822]] §8(d)、未適用）、低 µ レジームの死は std と同じ語で呼べない可能性がある。到達経路の分類はこの点も含めて task_080 の対象
