# ノルム増大と不可逆性

親: [[新理論の構築]] / 状態: 検証中 / 更新: 2026-08-21

Lyle (CoLLAs 2025) が供給するのは「継続学習で ‖W‖ は増大する」というマクロ事実のみ。そこから病理への橋を架ける論点。記号は [[用語と記号]] を参照。

## ‖w‖ の二役

**チャネル (a)：力の増幅**

自己項が ‖w‖ に比例するので、ē·µ も Cov(e,x) も ‖w‖ に線形にスケールする。整列力の**両方**に ‖w‖ が乗る。

**チャネル (b)：操舵の切断 ← 不可逆性の本体（の候補だった）**

方向の更新を書き下すと

    Δu ∝ −η[ σ(uᵀx) − (f_t(x)+ξ)/‖w‖ ]·P x·1{uᵀx>0}

自己誤差由来の第1項は ‖w‖ に依存しない O(1)、**タスク項だけが 1/‖w‖ で減衰する**。ガウス入力なら残る自律場は

    u̇ ∝ −P[ s(u)·µ + p(u)·Σu ]     ( s(u)=E[(uᵀx)₊] ≥ 0, p(u)=P(uᵀx>0) )

> **不可逆性の正体は「壁」ではなく「ハンドルが切れること」。** 新しいタスクが f_t を通じて方向を操舵する権限が 1/‖w‖ で消え、方向は入力統計（µ と Σ）だけが決める共通の流れに乗る。脱出が塞がれるのではなく、脱出しようとする力がタスクから届かなくなる。

## 新規性の線引き

「ノルムが大きいと角度更新が 1/‖w‖ で遅くなる」こと自体は有効学習率の文献（LayerNorm 系）で既知。本研究の差分は**減速（等方的）ではなく、タスクから切断されたまま入力統計の決める共通方向へ異方的に集団流動すること**。減速は現象、切断＋自律流が病理。

## 未解決：不可逆性はまだ理論から出ていない

D\* の平衡は**ゆらぎ続けている定常状態**であって、抜け出せない罠ではない。Ḋ は線形の縮約なので行き着く先は D\* > 0 の平衡。脱出確率が指数的に小さいと主張するには、ReLU ゲートが 0 を跨ぐ境界での議論（Nagumo 型の内向き条件）が別途必要。

さらに重要な帰結として、**このモデル自身が「µ を事後に除去すれば整列は解ける」と予測してしまう**（λ_lock → 0 で広がりが σ²/(2λ_align) に戻る）。真に不可逆なのは全入力でゲートが閉じた死ユニットのみ。ここを曖昧にすると 8/21 で先生の Phase 2 の記述と食い違ったまま進む。

## チャネル(b) への実験的反証（E1、2026-08-19）

[[位置リセット判別]] の posonly アーム（‖w‖ を初期値へ縮めて操舵権限 1/‖w‖ を戻す操作、方向・µ は不変）は、チャネル(b) の予測どおりなら**「操舵が戻って u が +µ̂ 半空間へ回る」二段回復**を示すはずだった。実測は逆:

- **本走 P7**: posonly-treated の median Δcos(u, µ̂) = **−0.033**、CI [−0.054, −0.007]。予測と逆符号
- **追補 Q7**: 同じ v←0 の共通床のみを与える vzero（w・b は不変、posonly と違って ‖w‖ もそのまま）では Δcos ≈ **−0.002**、CI [−0.025, 0.024]（ほぼゼロ）

Q7 ≈ 0 は「v←0 による勾配窒息だけでは posonly の負符号は説明できない」ことを示す。つまり **posonly に固有の何か（‖w‖ を縮めたこと自体？）が Δcos を負に振っている**——チャネル(b) が予言する「操舵権限が戻って µ̂ 側へ回る」効果は、この実験では**観測されないどころか、わずかに逆に働いている**。

**解釈上の注意**: これはチャネル(b) の完全否定ではない。posonly は「操舵権限を戻す」と同時に「方向 u はそのまま・ノルムだけ縮む」という操作であり、u̇ の自律項 `−P[s(u)·µ + p(u)·Σu]` 自体はノルムに依存しないので、u が µ̂ に近ければ近いほど回転の余地は小さい（すでに整列側にいるユニットは動きようがない）——という代替説明も排除できていない。次の一手は、posonly-treated ユニットを介入直前の cos(u,µ̂) で層別し、初期整列度と Δcos の関係を見ること。

## 整流モデルとの接続（2026-08-19）

[[整流モデル]] により、**condA での不可逆性の実測上の描像**が更新された:

- **停止は「力の消灯」**: 滑落速度は p̂<0.05 で ≈0（力の釣り合いでも壁への衝突でもない）。ゲートの O(p) 同時消失（bias_margin PB-5 の機構）の**方向版**が実測された形
- **condA の有界入力では文字通りの吸収が存在**: 経験ゲート曲線は cos < −0.15 で p̂ = 0.000（ガウス近似の −0.46 で 5% より遥かに急峻）。「絶対吸収は有限バッチで検証不能」の但し書きは、**有界サポートでは解除される**（ガウス入力の主張と峻別すること）
- **輸送が前景**: posflip の往復（+0.325 → −0.300、原初帯 −0.325 とほぼ一致）は、1/‖w‖ の等方的減速や静的な壁ではなく「**場が方向を特定の帯へ輸送する**」動力学を示す。不可逆性の記述は「凍結」より「アトラクタ帯への回帰」が実測に近い
- **‖w‖ と死の符号問題**: E1 では alive ‖w‖ 3.30 > dead 2.44 と**生存側の方が大ノルム**。β̇ = ḃ/‖w‖ − β·d(ln‖w‖)/dt（canvas_review_0818 §4）の「ノルム成長は沈んだ β を薄める**復元項**」と符号整合。ノルムの正味効果は高次で決まり、**Path A 側では「ノルム＝悪玉」と単純に言えない**。µ≠0 では ‖w‖→∞ 極限で β → ŵᵀµ/‖ŵ‖_Σ（b の寄与消失）＝「b 経由の死」から「方向経由の死」への主導権移行
- 匍匐仮説（消灯点 −0.15 → 堆積帯 −0.325 への切替駆動の匍匐）が通れば、「深さ」は時間でなく**切替回数**の関数になる → [[整流モデル]]

## ノルム増大 → 境界衝撃の増大 の筋は棄却（8/20 夕）

台帳（[[台帳（実効バイアスの縮退）]] §4）の測定で、**境界衝撃の担い手である凍結ノルム |w_flip| は育たない**（0.2702 → 0.2548、100k step で微減）ことが分かった。育つのは構造側（|w_rnd| 0.273 → 0.448、|v| 0.088 → 0.563）。

→ **衝撃サイズは初期化スケールのまま据え置きで、攪乱は自己強化しない。** 「ノルムが増える → 境界の衝撃が増える → 崩壊が加速」という正のフィードバックの筋は消えた。

## 8/22 の測定による訂正（[[xr分解と生存機構_0822]]）

**本ファイルの中心的な問い「‖w‖ は増大するのか、それが病理か」に、直接の測定が入った。すべて事後計算・未事前登録・spec 未起票。**

### (1) ‖w‖ は増大している。ただし全体平均では見えない

死んだユニットは ‖w‖ が死亡時点で凍結するので、全体中央値は「増大が止まった」ように見える。コホートを分けると別物になる。

| task | 全体 | 終端死者 | **その時点で生きている個体** | n_alive |
|---|---|---|---|---|
| 0 | 1.418 | 1.420 | 1.415 | 77.8 |
| 30 | 2.132 | 2.151 | **3.143** | 15.9 |
| 100 | 2.956 | 2.860 | **4.221** | 7.4 |

`E[Δ‖w‖ | alive] = +0.009135` [+0.007526, +0.011038]、step 区間別でも全部正で後半も減衰しない。**Lyle のマクロ事実「継続学習で ‖W‖ は増大する」は、この設定でも成立する。**

### (2) ただし増大しているのは µ̂ 方向ではない

現 alive の内訳（x = w·µ̂、r = µ̂ 直交成分）:

| task | x² | r² | x² の割合 |
|---|---|---|---|
| 0 | 0.0285 | 1.9247 | 0.0146 |
| 100 | 0.3718 | 17.6644 | 0.0206 |

**成長の 98% は µ̂ 直交方向。** 割合は 100 タスク通してほぼ一定（1.5〜2.1%）で、**等方基準 1/20 = 5% よりむしろ痩せている**。checkpoint 500k でも µ̂ 方向のエネルギー割合は alive **0.0247** / dead 0.1124（等方 0.050）。

→ **「ノルムが増大して操舵が 1/‖w‖ で切れる」というチャネル(b) の 1 次元的な描像に対し、実測は「舵の軸だけ痩せたまま、無関係な 19 次元が膨らむ」。** 増大は起きているが、増大しているものが違う。P7/Q7 の反証寄りの観測（Δcos が予測と逆符号）と同じ方向を向いている。

### (3) 復元項は座標変換の項だが、無害ではない

本ファイルの `β̇ = ḃ/‖w‖ − β·d(ln‖w‖)/dt` の第二項（「ノルム成長は沈んだ β を薄める復元項」）について:

- **力ではない。** `x = w·µ̂` の座標で見れば復元力は存在せず、w は同じように動いている。正規化したから戻って見えるだけ
- **しかし無害な見かけでもない。** 分母を育てているのは `r` で、`r` の大小は生存と強く相関する（alive 4.161 / dead 2.632、+0.97 SD）。**この座標変換には選択がかかっている**

同型の誤りが [[不偏ウォーク仮説]] の検定 A（cos 基準の保存則テスト）にもあった。**正規化量で力学を書くと、分母の成長が力に化ける。** 今後は `x = w·µ̂` の生の座標で測ること（`cos × w_norm` で復元可）。

### (4) 「‖w‖ ＝ 悪玉と単純に言えない」の理由が具体化した

本ファイルは「E1 では alive 3.30 > dead 2.44 で生存側が大ノルム」と書き、Path A 側で悪玉と言えないとしていた。8/22 の分解でその中身が出た。

condA のタスク内では、死の条件が閉形式 1 本で書ける（[[xr分解と生存機構_0822]] §9・§17）:

```
生きている ⟺ b_eff + reach > 0
   b_eff = flip·w[:15] + b            （実効バイアス ≒ x 座標）
   reach = Σ_{j∈rnd} max(w_j, 0)      （最良入力での上乗せ ≒ r 座標）
```

**`reach` はノルムの µ̂ 直交成分そのもの**なので、**ノルムが育つことは死から遠ざかることと機械的に同義**。alive/dead 差は `reach` で +0.83 SD、`b_eff` で +0.57 SD。

つまり「ノルム＝悪玉」が成り立たないのは高次の打ち消しではなく、**死の条件式にノルムが分子として直接入っている**から。

> **8/20 夕の「ノルム増大 → 境界衝撃の増大の筋は棄却」（凍結ノルム |w_flip| は育たない）とも整合する。** 育たないのは flip 側で、育つのは rnd 側。8/22 の測定でも成長の 91.2%（alive）が rnd 側に入っている。台帳の観測と x/r 分解は**同じ構造を別の座標で見ている**。
