## 1. 定義と現象1 との関係

| | 定義 | v4.2 での扱い |
|---|---|---|
| **現象1**（µ 経由の死） | µ が大きく、$w\cdot\hat\mu$（cos）経由でゲートが閉じ `strict_dead`（$\hat p=0$）に落ちる | 二本柱はここ |
| **現象2**（b 経由の死） | µ$\approx$0 でも bias $b$ の沈下で同じ消灯域に到達して Dead → LoP | 柱2 の射程内・**柱1 は要書き直し** |

消灯条件は [[吸収不等式の命題化_0824]]（Q26）の一本しかない。

```
p̂ = 0  ⟺  s + M ≤ 0  ⟺  β ≤ −κ ,   s := w·µ + b ,  κ := ‖w_free‖₁/‖w_free‖₂ ∈ [1, √5]
```

**µ は $s$ の中にしか入らない。** したがって現象1 と現象2 は**同じ吸収域・同じ片道ゲートを共有しており、違うのは輸送チャネルだけ**である（Claude の整理・**未登録**）。

- **柱2 は µ の水準に依存しない主張。** `gate_dose_0830` の `GATE_LOAD_BEARING`（用量を帯内に固定し活性化だけを替える介入）は現象1・2 の両方に効く
- **縮んだのは柱1 だけ。** しかも柱1 は §3 の非単調用量反応で既に書き直しを要求されている

→ したがって「LoP の理解は 1/3 に縮んだ」ではなく「**柱1 が µ の三役のうち一役しか見ていなかった**」が正確、というのが現時点の読み（**未登録・Issa／先生の裁定対象** = [[中心主張v5計画_0831]] 未決 2）。

## 2. 理論として確立していること

1. **吸収域は µ に依らず存在する**（Q26・**厳密**。ただし Issa 未確認 4 点が残る）。$\lVert\mu\rVert\to0$ では $s\to b$ となり吸収域は $D\to\{b+M\le0\}$ に**退化するだけで消えない**。消えるのは cos 側の壁（$\cos_{\rm crit}$ が定義域 $[-1,1]$ の外へ退場）のみ
2. **$b$ を沈める力は入力分布に無条件**（Q14・[[自己項の恒等式]]・**定理**）。税（自己項 $=\nabla\mathbb E[o_i^2]$）の $b$ 成分 $-2\eta v_i^2\mathbb E[a_i\,\mathrm{gate}_i]\le0$ は µ も condA も要らない。$v$ 成分（$\lvert v\rvert$ の乗法減衰）も無条件
3. **µ は三役を持ち、向きが揃っていない**（Claude 解釈・**未登録**）
   - (i) 壁の位置と輸送（Q19 C1 `FULL_PASS`）→ **µ 大で死ぬ**
   - (ii) $b$ の勾配分担 $1/(1+\lVert\mu\rVert^2)$（Q19 C2・傾き **+0.8107 [+0.7644, +0.8556]**・事前登録 PASS）→ **µ 小で $b$ が荷重を全部負う**
   - (iii) 境界ごとの吸収域の引き直し ＝ 唯一の脱出路 → **µ≡0 で復活 0**

**(i) と (ii) が µ について逆向き**であることが、§3 の非単調用量反応の候補説明になっている（→ §5）。

## 4. 何が言えて何が言えないか

**言える**

- $b$ 経路の死は実在する
- condA・EMA centered の終盤死には学習可能な $b$ が必要（P-1 `BIAS_ROUTE_DECISIVE`）
- 押し下げ力は理論的に無条件（Q14）
- 吸収域とゲート片道性は現象1 と共通（Q26）
- µ=0 側でも十分な時間（5M）で機能劣化まで進む

**言えない**

- **「Dead は確立、LoP は未確立」。** condB では dead と機能が解離（PB-7・G0）。condA 5M で初めて機能劣化が出たが交絡が 2 本 —— `L2_Aall` に残る第2層 dose ≈ 1.04 と、`Aexact` のタスク可識別性
- **P-1 を治療効果と読めない。** b 凍結は dead を消したが `unfit` を悪化させた。bias 表現力を欠く別の仮説クラスであり、dead の機能コストは同定しない
- 「µ が保護的」「centering を完全にすれば防げる」は**どちらも書けない**（[[引用禁止]] B に登録済み）
- **`center_oracle_0831` の $R_{499}=0.5167$ を単独で引かない**（打ち切りを受けている。生存中 1 境界あたりに直すと符号関係が反転 → [[運用ルール]] §5 教訓⑰）
