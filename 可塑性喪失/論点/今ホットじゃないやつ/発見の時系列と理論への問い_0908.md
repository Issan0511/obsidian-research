## 第 2 部 — 理論側で解明してほしいこと（優先順）

**採点の仕方**: 各項目を「第一原理から予言できるか／矛盾しないか」で。数値を出せるものは出す。

### 最優先 — 2αW 則の由来

**T0（新・2026-09-09）. ゲートはどの層で効くのか。** CIFAR CNN で `SN3` は深い 3 サイトの 2αW が 4.4/36.5/75.3・mobility 1.02/0.99/0.97 と**ゲートが完全に消えているのに適応 α に 10/10 で勝つ**。conv1 だけが 2αW = 1.27 で帯にいる。**「効くゲートは入力に近い層だけ」なら 2αW 則は層ごとではなく第 1 層について読むべきで、適応 α の設計（全層で c/W）は過剰**ということになる。ただし MLP の Permuted では層 2 の mobility も精度と相関していたので普遍ではない。**理論は「ゲートの寄与が深さでどう減衰するか」を出せるか。**

**T1. なぜ 2αW ≈ 1.2 か。** 適応 α は 3 箱（Permuted SGD・Permuted Adam・CIFAR CNN の 3 サイト）で **1.20** に落ち、固定 α の勝ち帯は 0.57–1.26、負けは 4.70 以上。同じ α=3 が 2αW=14.2 で最下位・0.99 で最強。**候補**: E[φ′] = 1 + sin(2αz̄)·exp(−2α²W²) の e 折り点は 2αW = 1.41 で、その少し下。しかし **閉形式は水準を 7 桁外す**（α=3 で予測 1.7e−10・実測 |1−mob| は 1e−3 で床）。**床の由来**（ユニット間の W の不均一・非ガウス・[[前活性の力学_事後_0904]] の sinc 平均化則 mob = 1+sin(2αz̄)·sinc(αW) との整合）を含めて。

**T2. なぜ 1.2 が「勝つ」のか — mobility の最適値の理論。** mobility 1.0（線形）でも 0.0（死）でもなく **0.55–0.85** が最良。ゲートが開きすぎると何を失うか（Permuted の忘却 BWT・記憶課題の容量との関係）。「非線形性の取り分」（Permuted 4.6 pt・Random Label 87 pt）が箱で 20 倍違うことと接続してほしい。

**T3. 適応 α の固定点の安定性。** α ↓ → W ↑ → α ↓↓ の正帰還があるのに暴走しない（MNIST で clip 0%・CNN で 3 サイト追随）。W(α) の非単調性（2.86→2.09→2.37）と合わせて、**c/W_i = α_i の不動点が安定である条件**。conv1 だけ c/W > 3 になる理由（W=0.165 — 重み共有と小さい fan_in 25·C_in で分散が小さい？）。

### 層間の膨張

**T4. なぜ Snake だけ深さとともに W が増えるか。** MLP で L2/L1 = 1.33、CNN で **0.17 → 1.05 → 7.6 → 19.6**（4 サイト・100 倍）。ReLU 族・恒等は全部 ≤ 1.0。**候補**: φ(z) = z + sin²(αz)/α の周期項の振幅は 1/α = **W/c で W に比例** — 適応 α はゲートの位相を正規化するが**出力の振幅は正規化しない**。W が大きいほど大きい瘤を次の層へ送り、次の層の W がさらに大きくなる正帰還。整流の有無（層あたり rms 比 Snake 1.0–1.16 対 ReLU 0.65–0.82）と合わせて、**深さ d での W_d の漸化式**を出してほしい。**それが出れば「最適 α が層で違う」（MNIST L1 0.30 / L2 0.19・CNN 3.0/0.56/0.08/0.03）は帰結になる。**

**T5. 正規化との関係。** 入力を正規化（z/W）してから固定 α を当てれば位相も振幅も揃う → T4 の正帰還が切れるはず。**理論は「適応 α ⊂ 前活性正規化」の包含関係を書けるか。** ただし Kumar の表で Layer Norm 単体は Random Label MNIST 0.54 と弱い — 正規化だけでは足りず開いたゲートと組む必要がある、という予言になるか。

### WD と ‖w‖

**T6. なぜ WD は Snake を「縮小」し ReLU を「転向」させるか。** z̄/‖w‖ が Snake は WD で不変（−0.169 対 −0.147）、ReLU は 1〜3 桁変わる（−0.512 → −0.001）。**候補**: ReLU の沈下は自己増強的（負に入る → 死ぬ → その方向の勾配が消える → 訂正されないまま μ との整列が固定 → さらに深く）で WD がループを切る。Snake は死なないので整列は損失が要求する分だけ＝受動的。**そして `LIN` は ‖w‖ 8.35× でも整列を作らない**（z̄/‖w‖ = −0.001）→ 整列はゲートの帰結。**理論は「整列の速度 d(w·μ̂)/dt がゲートの閉じ方に比例する」を出せるか。** 注意: これは正規化量なので [[引用禁止]] に触れる。ユニット別 w·μ̂ の生の測定で裏取りが要る。

**T7. なぜ ‖w‖ 成長は普遍で、死だけが止めるか。** 42 セルで例外なし。**候補**: cross-entropy は分離可能／記憶可能データで有限の最小点を持たず、‖w‖ → ∞ がマージン最大化（Soudry et al. 2018）。止めるものは (1) 飽和・死 (2) 明示的制約 (3) スケール不変化（正規化・止めるのではなく無害化）の 3 つだけ。**理論は「LoP の経路 (b) は損失の性質で活性化と独立」を確認し、活性化が (a) だけを担うことの帰結を書いてほしい。**

**T8. λ の谷が鋭い理由。** CNN で λ=1e−4 が 0.877、1e−3 が 0.114。1e−5 は LoP（劣化中）、1e−3 は即死。**弱すぎると経路 (b)、強すぎると信号消失、その間が 1 桁。** MLP（3072 次元）では谷が無い（全 λ で死）。**理論は λ の許容幅を fan_in・重み共有・batch で書けるか。**

### 箱依存

**T9. なぜ記憶課題には開いたゲートが要り、置換入力の適合には要らないか。** `SNA+l2` − `R+l2` が Permuted +0.0023 → Random Label MNIST +0.0233 → CIFAR CNN（暫定）+0.58。**候補**: 記憶は入力ごとに別のユニット部分集合を使うので生きたユニット数が容量そのもの・置換は線形で足りる（`LIN` が 0.887）。**理論は「課題の線形可解性」と「活性化の効き」の関係を定量化できるか。** Kumar の表（L2 と L2 Init の差 0.01 / 0.15 / 0.21）と同じ順序。

**T10. WD の符号は 3 箱で ＋ − ＋（2026-09-08 に書き換え）。** `SNA+l2` − `SNA` は Permuted **+0.0185**・Random Label MNIST **−0.0217**・**Random Label CIFAR CNN +0.0343**（各 6/6 以上）。**「記憶課題では縮小＝容量削減」という当初の読みは崩れた** — 後ろ 2 つは同じ乱数ラベル記憶なのに符号が逆。残る差は入力次元（784 対 3072）・重み共有・λ（1e−3 対 1e−4）・アーキテクチャ。**理論は「WD が助ける条件」を課題の側だけでは書けない。**

**T11. `R+l2` の遅い崩壊（CNN）。** 10 タスクまでは 0.93、窓 31–50 で 0.406。MNIST の `R+l2` は 50 タスク持つ。**何が 10 タスク後に起きるか**（‖w‖ の緩い成長が閾値を越える？ conv2 の暴走？）。段 0 のガードが見えない時間スケール。

### 忘却

**T12. 開いたゲート ⇒ 速い忘却。** BWT `SNA+l2` −0.72 対 `R+l2` −0.58、死んだ `R` −0.22。**「学ぶ速さと忘れる速さは同じゲートで決まる」なら、可塑性と安定性のトレードオフが mobility 1 本で書ける**はず。`l2init` の「保持なき savings」（θ₀ 近傍に留まることで初速だけ残る）と合わせて。

### CNN 固有（暫定・確定後に格上げ）

**T13. `mob_pool` > `mob`。** max pool が選ぶ位置で φ′ が**大きい**。予測（pool は大きい活性を選ぶ・Snake では φ′ が大きい位置とは限らない）の逆。**Snake で φ(z) が大きい位置は φ′ = 1+sin(2αz) も大きい傾向**（z の上り坂）が理由か。

**T14. `R` の conv2 だけが −854 まで暴走する理由。** conv1 は ±5 に収まる。層で崩落の形が違う。

### 未測定の予言（理論が先に数字を出せば検証できる）

- **深さ 3–4 の MLP** で層間膨張は累積するか（T4 の漸化式の直接検定）
- **固定 α=3 対 適応 α（CNN・走行中）**: T4 が正しければ `SN3` は深いサイトで 2αW = 6.3 / 45.6 / 117.9 になりゲートが消える → `SNA` > `SN3` 9/10
- **c の最適値は箱に依らないか**（0.6 の 1 点。T1 が 1.2 を出せば c = 0.6 は帰結）
- **Random Label MNIST を 200 タスク**（T10 の交絡分離・素の `SNA` の ‖w‖ 5.4× が爆発するか）
- **前活性正規化 × 固定 α**（T5）: `SNA` を超え、L2/L1 < 1 に戻るか
- **‖w‖ を固定した ReLU**（重み正規化）で LoP はどれだけ残るか — 経路 (a) 単独の大きさ
- **5+1 CIFAR**: Lillo & Cheney が「l2init が強い活性化を壊す」を見つけた唯一の箱。`SNA` 対 `l2init` の構図が反転する可能性
