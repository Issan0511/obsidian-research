## 1. 実験の順序と、それぞれが答える問い

| ID  | 正本                          | 問い                                      | 証拠の範囲                      |
| --- | --------------------------- | --------------------------------------- | -------------------------- |
| A   | [[駆動源_鏡像と読み出し層別_spec_0908]] | 自然な学習軌道に K1 の下降・K31 の上昇、小さい読み出しでの変位があるか | 既存ログの事後解析。観測的な特徴           |
| B   | [[殻極_parity再適応_spec_0908]]  | 入力の蹴りを与えず、parity の誤差への再適応だけで跨ぎを解く運動が出るか | 同じ checkpoint から作る診断条件での介入 |
| C   | [[角検出項_対称キック_spec_0908]]    | 対称な蹴りに対する戻りの偏りが、ゲート切替を許すかで変わるか          | 同じ checkpoint から作る診断条件での介入 |

A のデータ在庫確認を先に行い、新しい実験は B → C の順。A が個体不足でも B/C は実施可能。B と C を「相互排他的な二説の勝負」にしない。両方、相互作用、どちらも未解決がありうる。

## 2. 前の会話案から具体化した点

1. **自然な K31 が少なくても鏡像予測を試せるようにする。** B/C の主実験は、同じユニットの重み・読み出しを保ち、バイアスだけで K1 と K31 を作る。自然状態の解析 A とは格を分ける。
2. **角検出の対照には、支持点ごとに切替前の枝を延長するモデルを置く。** 順伝播と逆伝播を整合させる。逆伝播のゲートだけ差し替える実験ではない。
3. **1 更新目の正負対称性と v² 依存は、独立な機構の証拠にしない。** 更新式で決まる部分は実装検査に使い、主 endpoint は 1000 更新後。
4. **CI が 0 を含むことと、効果が小さいことを区別する。** 全 spec に実用上の判定幅と NOT_DETERMINED を置く。
5. 生の平均前活性を主量とし、幅や読み出しは別列で追う。動く幅で割った増分を「力」と呼ばない。

## 3. 共通の初期状態・記号

対象は condA、入力 20 次元、自由 5 bit の厳密な 32 点支持、隠れ 1 層・幅 100、leaky の負側傾き a=0.1、活性化の加算オフセットなし。ReLU/Snake/多層は今回の主実験に混ぜない。

- 入力の raw bit ID と、モデルへ入る変換後の実数 X を別々に保存する。
- flip 成分は W[:, :15]、自由 5 bit 成分は W[:, 15:20]。[[駆動源_追伸A9_lrと着座深さ_0906]] §5(6) と実装 src/edge_law_0905.py の FREE_SLICE に従う。古い用語集の逆の添字を使わない。
- 平均前活性 zbar_i = mean_r z_i(X_r)、幅 W_i = (max_r z_i-min_r z_i)/2。端点も 32 点から直接計算する。
- K1/K31 は、初期状態で z>0 がそれぞれ 1 点/31 点。small_v は |v|≤0.05 という読み出しの区分であり、ゲート閉鎖・不可逆な死を意味しない。
- parity q_r=(-1)^(自由 raw bit の 1 の個数)。入力中心化後の数値から偶奇を計算しない。

### checkpoint の選択

B/C の第一候補は act_offset_0906 の LRoff0_1216、step 1,000,000、元の独立 10 seed。共有の記録は A9 §5 にあるが、この spec 作成では checkpoint の実ファイル・全 seed の復元を再検証していない。所在は availability.json に絶対パス・SHA256・arm・seed・step として記録する。

別の腕、5M checkpoint、別設定で穴埋めしない。第一候補が復元できなければ NOT_RUN_INPUT_MISSING とし、代替は追補で先に固定する。追加の長時間学習で checkpoint を作ることはこの spec に含めない。

B/C はパラメータを float64 へ複製し、X と入力変換を固定する。EMA、教師更新、タスク切替、乱数によるデータ抽出を止める。**元の軌道の再開ではなく、固定状態への診断**である。

## 4. B/C の鏡像状態の作り方

各 seed の全ユニットについて初期 z の 32 点を昇順 z_(1)≤…≤z_(32) に並べる。

- K1 側: 対象ユニットの b に −(z_(31)+z_(32))/2 を加える。
- K31 側: 対象ユニットの b に −(z_(1)+z_(2))/2 を加える。
- 各枝は元 checkpoint から別々に作る。他ユニット、対象の w と v は変更しない。
- 端の隙間 z_(32)−z_(31) と z_(2)−z_(1) がともに 10^-6 を超えるユニットを適格とする。適格性は介入後の動きを見ずに決める。
- seed ごとに適格 unit ID を固定乱数 rng(20260908+seed_index) で並べ、先頭 2 ユニットを選ぶ。1 個しかなければその 1 個、0 個なら欠測。選抜 ID と全候補の除外理由を保存する。
- 1 seed×2 target×2 sides で最大 4 個、全体で最大 40 個の初期世界を作る。
- 各世界の全ネットワークの初期出力 f0(X) を保存し、その世界専用の診断教師の基準にする。教師は学習中に再計算しない。

これにより同じ w・v・幅・入力支持で両端を比較できる。ただし b と f0 は違う。これは自然軌道上の K1/K31 の対応ペアではない。元の b からの移動量、元の K、自然状態との違いを必ず出す。

## 5. 共通の更新・時間・統計

- 全 32 点の平均二乗誤差 L=mean_r(f(X_r)−y_r)^2。**1/2 は付けない**。
- 通常の全パラメータ同時勾配降下、学習率 η=0.001、momentum=0、weight decay=0、clipping なし、optimizer 履歴なし。W、b、v、出力バイアスを更新する。
- 主 endpoint: 1000 更新後。途中記録: pre、介入直後で更新前の 0+、1、2、5、10、20、50、100、200、500、1000。ゲート変化のカウンタは毎更新。
- 1000 更新は「完全に refit した時点」という定義ではない。残差比を併記し、適応が進まなければその機構の否定に使わない。
- 同じ specimen の条件差を先に取り、target 間は seed 内算術平均、最後に seed 等重みの算術平均。ユニット中央値への差し替え・有意な枝だけのプールはしない。
- CI は元学習 seed 単位の percentile bootstrap 10,000 回、rng(20260908)。target、正負枝、鏡像側、時刻を独立標本として水増ししない。主判定には適格 seed≥8、各 seed≥1 target が必要。
- 主 endpoint の生 z 変位の判定幅 δ_z=10^-5。これは理論の予測値でも検出力保証でもなく、今回の診断で区別する最小幅として起草側が固定する値。CI 全体が帯 [−δ_z,+δ_z] 内なら WITHIN_BAND、帯の上/下に完全に出れば POSITIVE/NEGATIVE、その他は NOT_DETERMINED。
- B/C の主比較には各 97.5% CI（2 本の主比較に対する保守的な同時評価）、補助には 95% CI。多数の補助指標は REPORT_ONLY で、主判定を差し替えない。
- 非有限値・破綻は該当ペアを NUMERIC_FAILURE とし成功枝だけ残さない。原因を直すときは結果から条件を選ばず、同じ比較集合を再実行する。欠測・失敗で有効 seed<8 なら主判定は NOT_DETERMINED。

## 6. 必須の記録と前検査

全実験: source commit、spec の hash、実装/config の hash、seed、checkpoint hash、タスク位相、支持点順序、解析窓、除外理由。

B/C: 対象ユニットの z の 32 点、zbar、min/max、W、b、w_flip/w_free、v、平均活性、活性の parity 係数、残差の平均/parity 係数、MSE、初期比、対象/他ユニット別のゲート切替数、初期状態からのパラメータ差。全ネットワークの開始・終了パラメータも保存する。

前検査は 1 seed×1 target、20 更新とし、精度・配管・実行時間・メモリだけ確認する。本 endpoint や帰結ラベルを選ぶ用途にしない。

- 初期正負枝の同一性、対照のゼロ誤差、32 点の直交性、勾配規約、支持固定を検査。
- 介入なし・ゼロ誤差では状態が許容誤差 10^-10 以内で不変。
- 勾配の検算は折れ目から離れた点で中心差分と比較し、相対誤差≤10^-5、絶対誤差≤10^-8 を許容する。
- 意図的に誤った parity の並べ替え、片枝のみ異なる初期値、固定ゲートの逆伝播だけの差し替えを検出できる検査を用意する。恒真な式だけの検査で済ませない。
- 経路・データ欠落は欠落として出す。未確認の既存結果・データ所在を補完して書かない。

## 7. 計算量と成果物

B は最大 40 世界×11 枝×1000=440,000 full-support 更新、C は最大 40 世界×14 枝×1000=560,000 更新。合わせて最大 32,000,000 支持点提示。枝のベクトル化が可能だが、壁時計時間・GPU メモリは前検査で測る。単に「短い枝だから安い」とは扱わない。追加の自然状態・学習率・読み出し介入は今回の必須腕に含めない。

実装先は lop_analysis、vault は spec と結果ノートのみ。予定出力:
- results/drive_mirror_0908/
- results/shell_parity_0908/
- results/corner_kick_0908/

各々 manifest.json、availability.json、preflight.json、unit_endpoints.csv、seed_summary.csv、verdict.csv、summary.md、図、必要な短時間生ログを置く。未実装のパスであり、存在確認済み出力ではない。

実行前に本 spec 群と config を commit し、その hash を manifest に固定する。今回の保存は実験結果の事前登録完了を意味しない。A は既存データの事後解析なので、手続きの先行固定後も posthoc の格を保つ。

## 8. 結果から言えることの上限

- A の一致だけ: 自然軌道に予測と整合する特徴がある。
- B の一致だけ: 制御した parity 再適応で、跨ぎを解く向きの応答が生じる。
- C の一致だけ: 制御した蹴りへの応答に、対象ユニットのゲート切替が寄与する。
- B/C とも一致: それぞれの介入効果がある。変位を「殻極+角検出項」に一意に足し分けたことにはならない。
- 自然な教師の flip 応答・残差に当該成分があり、自然な境界の変位まで量的に説明できて初めて、元の沈下の駆動源として格上げできる。この橋渡しは A の残差成分測定で足場を作るが、今回の 3 本で寄与率を確定しない。
- LoP の機能量や Snake の性能改善はこの 3 本の endpoint ではない。ここから直接「LoP を防ぐ機構が解明された」とは書かない。
