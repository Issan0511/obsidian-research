## 0. 方針を一文で

> **正負で応答の強さが違うため、学習で必要な寄与を分担するとき、弱い負側は人数・前活性の深さ・分布の幅・読み出し重みでその弱さを補う。その分担がタスクごとに組み直されることが、下降と回復を生むのではないか。**

Issa の直感は「負側は leak で活性化が小さいため、釣り合うだけの寄与を出すには遠くまで行く必要がある」。これは**深い配置が選ばれる理由**の候補である。次に説明したいのは、そこへ向かう**更新の符号・速さ・タスクごとの収支**。

現時点の到達点は「式で表せる補償関係と、それに対応する分布がある」まで。中心主張の採用や、下降の駆動源が判明したという宣言にはしない。

## 1. 何と何が釣り合うのか

「少数の正側」には二つの意味がある。

| 対象            | 正側の少数              | 負側の多数              | 問う量                     |
| ------------- | ------------------ | ------------------ | ----------------------- |
| 一つのユニットの内部    | そのユニットを正側に置く入力パターン | 同じユニットを負側に置く入力パターン | 入力ごとの残差、活性化、傾き、更新への寄与   |
| ネットワーク内のユニット群 | 正側の井戸付近に残るユニットなど   | 平均前活性が負のユニット群      | 符号付き出力の和、読み出し、他群の適応への影響 |

前活性平均が負でも、正側の入力が残る。逆に、全入力が負でも leaky の出力・勾配はゼロではない。

以下の三つは同じ条件ではない。

1. **出力が合う**: $\sum_i v_i\phi_i(x)+c_{\rm out}=y(x)$。
2. **自己二乗の傾きがゼロ**: $\mathbb E_x[\phi_i\phi_i']=0$。
3. **実際の前活性の更新が止まる**: 重み・バイアス・入力の変化を含む $\Delta\bar z_i=0$。

少数・多数のモーメントを足して近い値になることは、1 や 3 を示さない。

## 2. 式で言えること

対象はまず単層・二乗損失・通常の SGD。$\phi(z)=\operatorname{LeakyReLU}(z;a)+c$、$a>0$。$c$ は活性化へのオフセット、$c_{\rm out}$ はネットワークの出力バイアス。

### 2.1 同じ活性化を担う距離は 1/a

負枝で必要な活性化を $q$ とすれば、

$$az+c=q,\qquad z=\frac{q-c}{a}\quad(q-c<0).$$

$q-c$ を固定すると距離は $1/a$。必要なユニット出力を $o$、$v\ne0$ とすれば $q=o/v$ なので、$v$ も条件に入る。

**この式だけでは「深くなるしかない」とは言えない。** 実際には $v$、寄与するユニット数、出力の分担も変えられる。負側へ要求される寄与自体も、学習の結果として決まる。

他ユニットを瞬時に固定したときの残りの出力要求は $q_i^{\rm out}(x)=y(x)-c_{\rm out}-\sum_{j\ne i}v_j\phi_j(x)$ と書ける。ただしこれは部分残差の恒等式であり、独立に与えられた需要ではない。これがなぜ負側の深さを要求するように変化するかが研究対象。

### 2.2 自己二乗のモーメントでは負側が a² で弱くなる

$c=0$ とし、

$$Z_i^+=\mathbb E_x[\max(z_i,0)],\qquad Z_i^-=\mathbb E_x[\max(-z_i,0)]$$

と置く（会話と集計 JSON の $P,N$ に対応）。

$$\mathbb E_x[\phi_i]=Z_i^+-aZ_i^-,$$
$$\frac12\partial_{b_i}\mathbb E_x[\phi_i^2]
=\mathbb E_x[\phi_i\phi_i']=Z_i^+-a^2Z_i^-.$$

負側では活性化と傾きの両方に $a$ が掛かる。自己二乗だけの平衡条件は $Z_i^+=a^2Z_i^-$。$a=0.1$ なら負側は前活性量として正側の 100 倍必要になる。

正側割合 $p_i$、正側の条件付き距離 $d_i^+$、負側の条件付き距離 $d_i^-$ なら、

$$p_i d_i^+=a^2(1-p_i)d_i^-.$$

**$1/a^2$ の距離則には $p_i,d_i^+$ などを固定する前提がある。** $p_i$ や幅が動く学習腕で、深さだけが必ず $a^{-2}$ に従うとは予測しない。この条件は実損失の平衡条件ではない。

$c\ne0$ では、

$$\mathbb E_x[\phi_i\phi_i']
=Z_i^+-a^2Z_i^-+c\{p_i+a(1-p_i)\}.$$

$c=0$ の条件をそのままオフセット腕へ当てない。

### 2.3 実際の下降を決めるのは残差を含む更新

$\delta=\hat y-y$、$\ell=\delta^2$ とすれば、

$$\Delta b_i=-2\eta v_i\mathbb E_B[\delta\phi_i'],\qquad
\Delta w_i=-2\eta v_i\mathbb E_B[\delta\phi_i'x],$$
$$\Delta v_i=-2\eta\mathbb E_B[\delta\phi_i].$$

$\mathbb E_B$ はその更新で使うミニバッチ平均。入力分布が固定され、$\mu=\mathbb E_x[x]$ なら、

$$\Delta\bar z_i
=\Delta b_i+\mu^\top\Delta w_i
=-2\eta v_i\mathbb E_B[\delta\phi_i'(1+\mu^\top x)].$$

バイアスだけの式で前活性平均全体を説明しない。期待更新を測る場合は、実際のミニバッチ更新と全支持平均を別に記録する。

入力の正負で分けたバイアス更新は、

$$\Delta b_i=-2\eta v_i\left(
\mathbb E_B[\delta\,1_{\{z_i>0\}}]
+a\mathbb E_B[\delta\,1_{\{z_i\le0\}}]\right).$$

こちらで必要なのは**残差の符号を含む釣り合い**。$\mathbb E[\phi\phi']$ の形だけでは置き換えられない。

全入力が負の $c=0$ ユニットでは自己項は上向きになる。それでも下降するなら、残差との結合、他パラメータの適応、入力の切替を含めた説明が必要。self/rest の大きさの比を駆動の寄与率にする道には戻らない（[[現象1と3の力の対応_0903]] §9・[[引用禁止]]）。

## 3. データが言っていること

今回の直接集計の正本は [[Leak距離補償_モーメント事後集計_0908]]。事後・未登録であり、独立な検証データではない。

### 3.1 c=0：少数の正側と、多数かつ深い負側

LRoff0_1216・$a=0.1$・10 seed・末尾50タスク終端（4.51M–5M）、100ユニット×32入力。

| 量               |            正側 |               負側 |
| --------------- | ------------: | ---------------: |
| 入力×ユニット×時点での割合  |        4.124% |          95.876% |
| 各側の条件付き前活性絶対値平均 |         1.099 |            3.785 |
| 活性化の量           | $Z^+=0.04531$ |   $aZ^-=0.36288$ |
| 傾きも掛けたモーメント     | $Z^+=0.04531$ | $a^2Z^-=0.03629$ |

活性化量は釣り合わず、モーメントの大きさは同程度。正／負モーメント比は **1.249**、イベントごとに $v_i^2$ を掛けて集計すると **1.317**。**一致した平衡とは書かない。**

集団平均をほどくと、全イベントの **77.24%** では自己項の $b$ 方向は上向き。跨ぎユニットだけのモーメント比は **4.600**、全点負のユニットでは正側項がゼロ。集団の比 1.249 は各ユニットの釣り合いを意味しない。

### 3.2 c=-0.5：正側の井戸に残る群は読み出しが小さい

5M 単点・10 seed×100ユニットでは、全点正 **10.2%**、跨ぎ **53.6%**、全点負 **36.2%**。全点正群は $\bar z$ 中央値 **+0.498**、$|v|$ 中央値 **0.0012**。跨ぎ群・全点負群の $|v|$ は **0.467 / 0.559**。

「井戸付近に残った少数ユニットが出力を主に担う」という読みは支持しにくい。ただし、この群の存在や適応が他群の下降に必要かは、分布だけでは決まらない。**井戸付近のユニット群と、負の平均を持つユニット内の正側入力点を区別する。**

### 3.3 既存結果との対応と限界

- **零点に座る場合の距離補償**: $c=+0.5$ の下群は $a=0.2,0.3,0.5,0.7$ で $\bar z=-2.48,-1.66,-1.00,-0.71$。$-c/a$ と対応する。[[前活性オフセット格子結果_0906]] §2・§3。数値の読みは事後、ブロックの登録ラベルは NOT_DETERMINED。$c\le0$ の下降の駆動を説明した結果ではない。
- **下降と回復の時間構造**: [[境界密記録_結果_0907]] の参照腕では、学習による $b$ と重み射影の変位が約200更新で最も負になり、その後タスク終端までに約2/3が戻る。200更新は指数時定数ではない。入力切替そのものの跳びと分けて扱う。古い $J$ 定義には最初の更新の混入があるため、純粋な入力効果の寄与率には使わない。
- **単純な二乗井戸では足りない**: [[井戸の剛性_0907]] で実効的な応答の強さは単純な $a^2$ 則に揃わなかった。静的な自己二乗だけで全運動を閉じる仮説には制約がある。
- **殻極・角検出項の既存検証**: parity の主予測は未確定、ゲート切替介入の有限時間応答は鏡像側で符号が異なった。[[殻極_parity再適応_結果_0908]]／[[角検出項_対称キック_結果_0908]]。今回の補償仮説がどちらかの証明になったわけではなく、自然な切替後の下降との接続が残る。

## 4. いま想定する運動と、残る疑問

想定する流れは次のもの。ただし、矢印はまだ検証対象。

**タスク切替 → 残差と各ユニットの寄与の関係が変化 → 弱い負側が深さ・幅・読み出しで補う → 再適応で要求が変わり回復 → 回復しない分が蓄積。**

| 残る疑問                                | 答えがないと何が言えないか                  |
| ----------------------------------- | ------------------------------ |
| 何が釣り合うのか。出力、自己モーメント、残差を重み付けした更新のどれか | 分布のモーメントから静止点を決められない           |
| 正側の少数は、ユニット群か、各ユニットの入力点か            | 「少数が多数を押す」という群間の説明を立てられない      |
| なぜ $v$ の増加や別ユニットへの分担より、深さ・幅が選ばれるのか  | 弱い leak から実際の沈下を導けない           |
| 切替後の最初の約200更新で、何が下向きに揃うのか           | 急降下の符号と大きさが説明できない              |
| その後、何が変わって上向きになるのか                  | 残差が小さくなるだけで回復の符号反転を説明できない      |
| なぜタスク終端で元に戻りきらないのか                  | 長期の沈下率が導けない                    |
| 止まっているのは平均、上端、比率、各ユニットのどれか          | 動く分布を静的平衡と呼んでしまう               |
| この配置が可塑性をどの経路で損なうのか                 | 深い配置の説明から LoP や Snake の優位へ進めない |

## 5. 追加で必要な測定：優先順

既存データの記述的再解析 → 自然なタスク境界の更新記録 → 因果介入、の順。以下は測定候補であり、主 endpoint・効果量の帯・標本数・計算量を凍結した実行 spec は別途作る。

### 優先1：既存ログで、誰が何を補っているかを追う

**閉じる疑問**: 集団平均の近さが、個々のユニットの配置や運動と結び付くか。

- 同じユニットをタスク間で追い、$\bar z_i$、分布の標準偏差 $\sigma_i$、$z_{\min},z_{\max}$、$p_i$、$v_i$、$Z_i^\pm$、$\mathbb E[\phi_i]$、$\mathbb E[\phi_i\phi_i']$ を並べる。$v_i$ は符号付きと絶対値の両方を保持する。
- 正負モーメントは生の分子・分母を先に出し、比を補助表示する。分母が小さい例も人数とともに残す。
- ユニット内部の入力分担と、ユニット群の分担を別集計する。群別出力は $\sum_{i\in G}v_i\phi_i(x)$ を符号付きで足す。各出力の二乗和をネット出力の二乗に置き換えない。
- 初期・沈下中・後半、全点正・跨ぎ・全点負、$|v|$ の層別を出す。軌道比較の群は観測区間の前に固定する。現在位置で群を選んだ下降を因果的な力と読まない。
- $a$ を変えた既存腕では、深さだけでなく $p_i,\sigma_i,v_i$ の変化を併記し、補償がどこへ配分されたかを見る。タスク数・更新数・学習率を混同しない。
- 実際の将来変位への予測を、開始時の $\bar z,\sigma,p,v$ だけの基準モデルと比較する。自己モーメントを足した説明が別 seed・別タスク窓でも改善するかを確認する。時点の恒等式が成立することは予測の成功に数えない。

**既存データの範囲**: logs_tail の $w_{\rm free}$ から32点を再構成できるのは、その記録ステップとの共通時点。全ログの1000更新記録にはモーメント等があるが、最初の200更新は解像できない。未記録の密な軌道を補間して観測したことにしない。

**分岐**: 個々の将来変位まで説明できれば配置と運動の接続が進む。集団平均だけで近ければ、現状は集計上の配置の記述に留める。

### 優先2：切替直後に、残差と正味更新を同時に密記録する

**最優先の新規記録。閉じる疑問**: 急降下・回復の符号が、どの入力のどの残差から生じるか。

- 同じ自然なタスク切替を、旧支持・更新前 $0^-$、新支持・更新前 $0^+$、その後 $1,2,5,10,20,50,100,200,500,1000,2000,5000,10000$ 更新で記録する。最初の初期学習をタスク切替に混ぜない。
- 対応する32入力について $x,y,\hat y,\delta,z_i,\phi_i,\phi_i',v_i$ を記録する。切替時の入力変化と教師変化を区別する。
- 各実更新の $\Delta b_i,\Delta w_i,\Delta v_i$ を積算し、正側入力と負側入力からの更新寄与を記録する。$\mu^\top\Delta w_i$ を含め、積算が実際の $\Delta\bar z_i$ と合うかを確認する。
- 全支持で計算した期待更新と、オンラインの実現した更新を分ける。全支持で検算できたことを標本雑音の機構解明には数えない。
- 同時に $Z_i^\pm,p_i,\sigma_i,v_i$ を追い、**下がり始める前に何が変わり、底を打つ前に何が反転するか**を見る。残差の大きさだけでなく、$v_i\delta\phi_i'$ の符号を読む。

**支持する観測**: 負側の必要な寄与の変化を独立に測ったとき、それに続く深さ・幅・読み出しの更新と、後の回復を同じ条件付きの式で予測できる。

**不利な観測**: モーメントは配置と一緒に動くが更新の向きを予測しない、または「需要の増加」が下降後にしか現れない。その場合、距離補償は運動の結果を記述している可能性が高い。

### 優先3：傾きを変えたとき、補償先がどう変わるか

**閉じる疑問**: 小さい $a$ が深さを必要とさせるのか。$v$ や幅で代替できるのか。

既存の $a$ 梯子で、深さ・幅・読み出し・入力の正側割合を同時に比較する。その後、同じ checkpoint・固定支持・同じ新課題への応答で、$a$ と $v$ の適応を操作する候補を設計する。初期予測・初期残差が違う場合は、その差による再適応を切り分ける。

**非自明な判定にする条件**: 全点負ユニットについて $a$ 変更時に $W,b$ を $a/a'$ 倍して出力を保てば、初期深さの $1/a$ 則は構成上成立する。その初期値を発見に数えない。比較対象は、その後の追加変位・出力回復・補償の配分。

$1/a$ と $1/a^2$ を結果に合わせて選ばない。必要出力・読み出し・正側割合・距離の何を固定した予測なのかを先に定める。既存の $v$ 凍結腕は状態も適合度も違うため、単独で経路の必要性を断定しない。

### 優先4：正側の少数の「適応」が負側の運動に必要か

**閉じる疑問**: 正側に残るユニット群、または各ユニットの正側入力が、他の運動を作っているか。

- ユニット群については、介入前に群を定義し、出力への寄与を維持したままその群のパラメータ適応を凍結する対照を候補にする。負側群の下降・回復の差を見る。
- これは**適応への参加**の検査であり、その群が存在しなくてもよいという証明ではない。単純な削除は予測誤差を変えるため、削除が作った残差を区別する対照が必要。
- 入力点の正側ゲートについては既存 [[角検出項_対称キック_結果_0908]] を先に照合する。その有限時間・人工キックの結果を自然な切替へそのまま移さず、優先2で観測した条件に沿った対照を作る。

### 優先5：Snake と可塑性へ接続する

**閉じる疑問**: 距離補償の構造が LoP の差を説明するか。

固定 $\alpha$ の Snake は $\phi(z)=z+\sin^2(\alpha z)/\alpha$ で、大域的には線形成分を持ち、負半直線全体が小さい一定傾きになる形ではない。したがって「負側の寄与を担うための深さ・幅の負担」が leaky と異なる、という条件付き予測が候補になる。

比較では前活性の分布だけでなく、符号付き出力、読み出し、$\phi'$ の分布、新しい残差への適応速度を測る。Snake の局所的な傾きゼロや周期も含める。固定 $\alpha$ と適応 $\alpha$ は分け、適応則で固定される $2\alpha\sigma$ 自体を検証結果にはしない。

「深くならない」だけで LoP を説明せず、深さが増えても新しい課題へ適応できる場合を扱える理論にする。

## 6. 主張へ進める条件

| 検証が進んだ段階                | その段階で言えること                      |
| ----------------------- | ------------------------------- |
| 現在：代数と末尾の記述統計           | 弱い負側を人数・距離で補う配置が、データと対応する候補になった |
| 同一ユニットの予測が通る            | 配置の変化と更新の間に、再現する条件付きの関係がある      |
| 自然な切替の符号・反転・収支が予測できる    | タスク再適応が下降と回復を作る力学を説明できる         |
