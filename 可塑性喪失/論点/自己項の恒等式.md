## 0. 記号と規約（係数 2 の混乱をここで殺す）

実装（`nets.py`）に合わせる。

- モデル: $\hat y = \sum_j v_j a_j + c$、$a_j = \sigma(z_j)$、$z_j = w_j\cdot x + b_j$、$\sigma = \mathrm{ReLU}$
- 損失: $\ell = \delta^2$（**½ なし**）、$\delta = \hat y - y$。よって勾配は係数 2 込み
- 更新: $\theta \leftarrow \theta - \eta\, g$
- ユニット自身の出力: $o_i := \delta_{\mathrm{self},i} = v_i a_i$、残差分解 $\delta = o_i + \delta_{\mathrm{rest},i}$
- 記録量: $\hat\mu$ は**単位**ベクトル $\mu/\lVert\mu\rVert$（$\lVert\mu\rVert$ は境界で跳ぶため）、$\mu = \mathbb{E}[x] = [\,\text{flip\_state} \,\Vert\, 0.5\cdot\mathbf{1}\,]$

$$F_{\mathrm{self},i} = -2\eta\, v_i\, \mathbb{E}\big[o_i\,\mathrm{gate}_i\,(x\cdot\hat\mu)\big], \qquad F_{\mathrm{rest},i} = \big(o_i \to \delta_{\mathrm{rest},i}\big), \qquad F_{\mathrm{gate},i} = \big(o_i \to \delta\big)$$

| 主張の形 | ½ 規約（$\ell = \tfrac12\delta^2$） | 実装規約（$\ell = \delta^2$） |
|---|---|---|
| 恒等式 | self 部分の $\nabla\tfrac12\mathbb{E}[\delta^2] = \nabla\tfrac12\mathbb{E}[o_i^2]$ | self 部分の $\nabla\mathbb{E}[\delta^2] = \nabla\mathbb{E}[o_i^2]$ |
| 力 | $-\eta'\nabla\tfrac12\mathbb{E}[o_i^2]$（$\eta' = 2\eta$） | $F_{\mathrm{self},i} = -2\eta\, v_i^2\, \mathbb{E}[a_i\,\mathrm{gate}_i\,(x\cdot\hat\mu)]$ |

`context_0820` §7 の「$\nabla\tfrac12\mathbb{E}[o_i^2]$」と canvas の「$-2\eta v_i^2\mathbb{E}[\cdots]$」は**同じ命題**。外部資料ではどちらの規約か明示する。

## 1. 主張A（恒等式）と導出

> $\theta_i \in \{w_i, b_i, v_i\}$ の各成分について、per-sample 勾配の self 部分は**すべての $x$ で点毎に** $\partial(o_i^2)/\partial\theta_i$ に等しい。したがって
> $$\text{self 部分の } \nabla_{\theta_i}\mathbb{E}[\delta^2] \;=\; \nabla_{\theta_i}\mathbb{E}\big[o_i^2\big]$$

**Step 1（ユニット加法性 — 議論の要）**。$\hat y = o_i + \sum_{j\neq i} o_j + c$ で後ろ2項は $\theta_i$ に依存しないので $\partial\hat y/\partial\theta_i = \partial o_i/\partial\theta_i$。**これが恒等式の存在条件**で、重み共有・正規化層・後段の非線形合成があると崩れる。1 隠れ層＋線形読み出しだから成立している、と明示すること（多層拡張は `blindspot_0820` §6 / §10）。

**Step 2（分解）**。$g_{\theta_i} = 2\delta\,\partial o_i/\partial\theta_i$ に $\delta = o_i + \delta_{\mathrm{rest},i}$ を代入して

$$g_{\theta_i} = \underbrace{2 o_i \frac{\partial o_i}{\partial \theta_i}}_{g^{\mathrm{self}}} + \underbrace{2 \delta_{\mathrm{rest},i} \frac{\partial o_i}{\partial \theta_i}}_{g^{\mathrm{rest}}}$$

`exact_record` の `d_self` / `d_rest` と項ごとに一致。取りこぼしが無いことは autograd と機械精度で確認（I2: 4.2e-16）。

**Step 3（連鎖律）**。$2o_i\,\partial o_i/\partial\theta = \partial(o_i^2)/\partial\theta$ を成分ごとに確認する。

- $v_i$: $2(v_ia_i)a_i = 2v_ia_i^2 = \partial(v_i^2a_i^2)/\partial v_i$（$a_i$ は $v_i$ に依らない）
- $w_i$: $o_i^2 = v_i^2\sigma(z_i)^2$ で、補題より $\partial(o_i^2)/\partial w_i = 2v_i^2 a_i\,\mathrm{gate}_i\,x$
- $b_i$: 同上で $x \to 1$

> **補題（角の処理）**: $h(z) := \sigma(z)^2$ は ReLU の角 $z=0$ でも微分可能で $h'(z) = 2\sigma(z)\mathbb{1}[z>0]$。
> 右側 $\frac{h(\varepsilon)-h(0)}{\varepsilon} = \varepsilon \to 0$、左側 $0$。よって $h'(0) = 0$。
> **$\sigma'$ が跳ぶ点で $\sigma$ 自身が消えるので、劣勾配規約（`>0` か `≥0` か）に恒等式は依存しない。** 実際 $a_i\,\mathrm{gate}_i = \sigma(z)\mathbb{1}[z>0] = a_i$ なので式中の gate は化粧（数値確認 K2: 両規約の差は厳密に 0）。

**Step 4（期待値との交換）**。condA の $\mathbb{E}$ は 32 パターンの有限一様和（`full_support_ro`）なので $\nabla\mathbb{E} = \mathbb{E}\nabla$ は自明。解析的な条件は一切不要。

### 系: 自己ポテンシャルは滑らかで、死領域では平坦

$\mathbb{E}[o_i^2] = \frac{v_i^2}{P}\sum_p h(z_i(x_p))$ は $h \in C^1$ より **$(w_i,b_i)$ について $C^1$**。損失自体は角を持つのに自己ポテンシャルは角を持たない。さらに全パターンで $z_i < 0$ なら近傍で $\mathbb{E}[o_i^2] \equiv 0$、よって**勾配も高階微分も恒等ゼロ**。

→ [[整流モデル]] 部品2 の「力の消灯」は、self 成分については点で釣り合っているのではなく**開集合上で勾配が恒等ゼロ**（吸収的プラトー）。Q8（漸近吸収性）に効く。**8/20 夕: 税の主たる貢献はここだと判明した**（§5-bis）。

### 3成分の力（税は3座標を同時に沈黙へ向ける）

| 成分 | ドリフト | 符号 |
|---|---|---|
| $w_i$ の $\hat\mu$ 射影 | $-2\eta v_i^2\,\mathbb{E}[a_i\,\mathrm{gate}_i\,(x\cdot\hat\mu)]$ | $\le 0$ に condA が要る（§2） |
| $b_i$ | $-2\eta v_i^2\,\mathbb{E}[a_i\,\mathrm{gate}_i]$ | **$\le 0$ が無条件**（入力分布に依らない） |
| $v_i$ | $-2\eta v_i\,\mathbb{E}[a_i^2]$ | $\lvert v_i\rvert$ を縮める乗法的減衰・**無条件** |

税は「向きを傾ける力」ではなく、**ゲートを閉じ・読み出しを消し・$\hat\mu$ から離す、沈黙への3方向同時押し**。$b$ と $v$ の無条件性は未使用のカード（→ [[命題リスト]] Q14）。

## 2. 主張B（condA 符号）: 点毎に $\le 0$ ⇒ 任意バッチで決定論

> condA・enc=std では、任意のパラメータ・任意のバッチ・任意の時刻で $F_{\mathrm{self},i} \le 0$。

**補題（入力の非負性）**: $x \in \{0,1\}^m$（`envs.py` の `randint{0,1}`）なので $\mu = \mathbb{E}[x] = [\,\text{flip}\,\Vert\,0.5\cdot\mathbf 1\,] \ge 0$、よって $\hat\mu \ge 0$ 成分毎。したがって**すべてのサポートパターンで** $x\cdot\hat\mu \ge 0$。

**証明**: 点毎スカラー $s_i(x) := a_i\,\mathrm{gate}_i\,(x\cdot\hat\mu)$ は非負3因子の積で $\ge 0$。非負重みの任意の平均（32 パターン厳密期待値・任意サイズのミニバッチ・単一サンプル）でも $\mathrm{avg}[s_i] \ge 0$。$\eta > 0$、$v_i^2 \ge 0$ より

$$F_{\mathrm{self},i} = -2\eta\, v_i^2\, \mathrm{avg}[s_i] \;\le\; 0 \qquad \blacksquare$$

$v_i$ が二乗で入るのは、$\delta_{\mathrm{self},i} = v_ia_i$ の $v_i$ と勾配側 $-2\eta v_i$ が掛かるため。**陣営（$v_i$ の符号）に依存しないのは代数的事実**で、$F_i = -2\eta v_i G$（$v_i$ に線形＝二極）との対比が効く。

**等号の特徴づけ**: flip_state $\neq 0$ なら全パターンで $x\cdot\hat\mu \ge \lVert\text{flip}\rVert_1/\lVert\mu\rVert > 0$ だから

$$F_{\mathrm{self},i} = 0 \iff v_i = 0 \ \ \text{または}\ \ a_i \equiv 0\ (\text{全 32 パターン} = \text{dead}, \hat p_i = 0)$$

つまり **alive なら厳密に $< 0$、dead でちょうど $0$**。税は片側であるだけでなく**自己消灯的**（行き先で消える。overshoot する力ではない）。flip_state $= 0$ の縁ケース（タスクあたり $2^{-15}$）でも符号 $\le 0$ は不変で、等号条件が緩むだけ。

> **8/20 夕の注意**: この自己消灯性は「吸収的で良い性質」であると同時に、**税が輸送の主役になれない理由**でもある（§5-bis）。両面性を必ずセットで運ぶこと。

### 系: 符号安定率 1.0000 の格上げ

E1 の「10 seed × 20901 記録点で一度も正にならない」は、この定理の下では**確率 1 の事象**。実測は定理の実装確認として読む。float64 では非負積の和なので丸めでも負側から漏れない。

→ **将来この量が一度でも正になったらそれは物理ではなくバグ。**

## 3. スコープ: 何が証明を担っているか

1. $\eta > 0$（自明）
2. **$\sigma\sigma' \ge 0$**: ReLU は $\sigma \ge 0$ かつ $\sigma' \ge 0$。これは ReLU 固有ではなく**非負・単調非減少な活性なら成立**（sigmoid で数値確認）。ReLU 固有なのは §1 の系（真の吸収プラトー）だけ
3. **$x\cdot\hat\mu \ge 0$ が点毎**: これが condA の担う部分。ただし本体は「$x \ge 0$」ではなく**内積の点毎非負性**

| 変更 | 恒等式 | 符号 | 数値 |
|---|---|---|---|
| condB（ガウス入力） | 成立 | **壊れる** | 正符号率 0.485 |
| enc=centered | 成立 | **壊れる**（$x-\mathbb{E}[x]$ が負成分、$\mu$ が退化） | `ratchet_log.py` が `NotImplementedError` で落とす＝実装都合であると同時に**理論のスコープ境界** |
| LeakyReLU $\alpha>0$ | 成立（2.1e-16） | **壊れる**（$z<0$ で $\sigma\sigma' = \alpha^2 z < 0$） | 正符号率 0.212 |
| sigmoid | 成立 | 保たれる | max $-6.1\times10^{-9} \le 0$ |
| $\pm1$ 再符号化 condA | 成立 | 保たれる | $x\cdot\hat\mu = \sqrt{n_{\mathrm{flip}}}$ の**正定数**（点毎に一定）。監査の実測 min **2.646 = √7** → **そのケースの flip ビット数は 7**。**condA 本番（f=15、√15 ≈ 3.873）とは別のトイ設定**〔下記 注〕 |

> **導出**: ±1 再符号化では flip 座標が $\pm1$ の定数、rnd 座標は平均 0 なので
> $\mu=[\pm1\ (n_{\mathrm{flip}}\ \text{個})\,\Vert\,0]$、$\lVert\mu\rVert=\sqrt{n_{\mathrm{flip}}}$、
> $x\cdot\mu = n_{\mathrm{flip}}$、よって $x\cdot\hat\mu = \sqrt{n_{\mathrm{flip}}}$（全サポートで一定）。
> $2.646=\sqrt7$ から **その監査ケースは $n_{\mathrm{flip}}=7$** と読める。

## 5-bis. 訂正: 税は駆動ではない（8/20 夕・[[中和と境界窓]]）

恒等式の直後に「では税は実際に何を運んでいるのか」を測ったところ、**税は正味の輸送をほとんど担っていない**ことがスモークで判明した。

- $F_{\mathrm{self}} + F_{\mathrm{rest}} = F_{\mathrm{gate}} \propto \mathbb{E}[\delta\cdots]$ なので、和には残差しか残らない。**フィット中は税が 99.5% 中和される**（相殺比 0.005）
- 境界窓に絞っても中和は解けない（窓内で正味は税の 1.3%、下向きは 57% ≈ コイン投げ）
- 台帳テスト: 死亡個体の沈下のうち**税が説明するのは中央値 24.5%**、残り 3/4 は rest。死亡個体の 53.8% は稼ぎ自体が負

**理由は定理の中にある**。$F_{\mathrm{self}} \propto v_i^2\,\mathbb{E}[a_i\cdots]$ は自分の出力パワーに比例するので、**死に近づいた個体には掛かる税がもう無い**（§2 の自己消灯性）。うるさい個体には大きく掛かるが、そういう個体は稼ぎも大きくて完全中和されている。**吸収性を保証する性質が、同時に税をとどめの一撃から失格させている。**

→ 役割の書き換え: **税 = 罠の構造（なぜ落ちた先から出られないか）。駆動 = rest（$v_i$ に線形の二極の揺らぎ）。**

定理部（§1–§4）は無傷で、むしろ「罠の吸収性の証明」として位置づけが明確になった。数値は全て R=8 スモークなので、**本番 npz での確認が必要**（[[中和と境界窓]] §8）。

5. $\hat\mu$ 射影は**単位ベクトル**への射影。生の $\mu$ 内積で引用しない

## 7. 引用文（½ 規約・外部資料用）

> 2 層 ReLU 回帰の SGD において、ユニット $i$ のパラメータに掛かる勾配のうち残差の自己寄与分は、恒等的に $\nabla_{\theta_i}\tfrac12\mathbb{E}[o_i^2]$（ユニット自身の二乗出力の勾配）に等しい。非負入力かつ $\mathbb{E}[x]$ 非負の下では、その $w_i$ 成分の $\mathbb{E}[x]$ 方向射影は**サンプル点毎に**非正であり、したがって任意のミニバッチで非正が決定論的に成立する。

「構造的に片側」は **self 成分の主張**であって、駆動全体（$F_{\mathrm{gate}}$）の主張ではない。**そして 8/20 夕以降、この片側性が正味の輸送を説明するとは主張しない。**
