## 2. 理論 — µ 非依存の整列力

1. **共通場モデル**（`theory_v2` 8/11・作業仮説）: 整列力の正体は Kuramoto 型の相互引力ではなく**共通外場**（相互作用項の係数は $v_iv_j$ に比例し、同符号なら反発）。µ 項の係数は $v_i$ に比例するので**力場は厳密二極**（Q1・**力場レベル限定**）
2. **$\lambda_{\rm align}$ と $\lambda_{\rm lock}$ の分離**: $1/D^\star=\alpha+\beta\lVert\mu\rVert^2$。$\alpha$ 側（$\lambda_{\rm align}$）が **µ 非依存の整列力**であり、**µ=0 でも整列は残る**という予言 —— **現象3 の理論的な種はここにある**
3. **整列は学習の帰結ではなく構造的に最初から存在する**（怪文書検証・恒等式 $\mathbb E[g_{W_i}]=2v_i\mathbb E[\delta\cdot\mathrm{gate}\cdot x]$ を相対誤差 1.5e-6 で確認）
4. **★穴 B-1（最重要）**: 力場の整列 → **生存者**の整列 → ランク低下、という橋は**未導出**。8/21 にこの橋を中心主張から外し、ランク低下は dead 経由（Q9b）で立て直した経緯がある。**現行の中心主張に「整列」の行は無い**
5. 恒等式の成立条件（Q13）は**ユニット加法性（1 隠れ層＋線形読み出し）＋二乗損失**。**多層・非 ReLU での理論は未整備**

## 6. $r$ と $\Sigma$ の位置づけ（Issa 仮説・8/31）

**仮説（Issa）**: 現象3 には xr 分解の $r$ 側（$\hat\mu$ 直交成分）と入力共分散 $\Sigma$ が大きく関わる。

### 6.1 既存の記録は $r$・$\Sigma$ を「殺す側」ではなく「守る側」に置いている

| $r$ 側 | 出所・格 |
|---|---|
| 生存条件の正項が $r$ 側そのもの: 生きている $\iff b_{\rm eff}+\text{reach}>0$、$\text{reach}=\sum_{j\in\rm rnd}\max(w_j,0)$ | **閉形式**・32 パターン厳密一致 |
| 生存者は $r$ が大きく（4.161 対 死者 2.632、+0.97 SD）、$\lvert x\rvert$ はむしろ小さい（0.564 対 1.017） | 8/22c・**事後** |
| ノルム成長の **98% が $\hat\mu$ 直交方向**（$x^2$ 割合 1.5–2.1%、等方基準 5% より痩せる）。$r$ の成長には正のフィードバック（太い個体は $\mathbb E[\Delta(r^2)]$ が 7 倍） | 同・**事後** |
| 死は「$b_{\rm eff}$ の沈下と reach の成長の競争」＝ **$r$ 側が伸び負けた個体から死ぬ** | 同・**事後**・機構文の候補 |
| 生存者の低ランクの起源は整列でなく**入力スパンの狭さ** | 同・**事後** |

| $\Sigma$ 側 | 出所・格 |
|---|---|
| 病理のダイヤル自体が $\text{dose}=\lVert\mu\rVert/\sqrt{\operatorname{tr}\Sigma/d}$ で **$\Sigma$ は分母**。ゲートマージンも $\beta=s/\sigma$、$\sigma=\lVert w\rVert_\Sigma$ | **定義** |
| µ が上げる曲率は $(\mu,1)$ 方向だけで、**情報を運ぶ方向の固有値は $\Sigma$ のまま** | [[µ維持の利得_0829]]・**論証** |
| µ=0 では共通場が $\operatorname{Cov}(\delta,x)$ に縮退し $\Sigma$ 主軸を向く（$\lvert\cos\rvert=0.907$）。**ただし実体はタスク依存で符号反転する誤差フィードバック**（符号安定率 6.1%）で片道の潮流ではない | `center_selfcov_0814` |
| w5・centered の step 10k（全員 alive）で平均力は **3.15 倍 [1.44, 5.62]**、その **92% が $\operatorname{Cov}(\delta,x_{\rm in})$** ＝ **center しても残差が $\Sigma$ 経由で平均力を作り直す**。ただし方向コヒーレンスは w5 が **0.275 倍**で、大部分は「残差が大きいから力も大きい」で説明できる | 候補5・**事後** |
| condB 異方で $\Sigma$ 支配軸への吸引を実測（$\lvert\cos\rvert$ 0.63–0.74、符号は run 内でも ± に割れる） | `aniso_perp_0812` |

### 6.2 ★ 設計上の縮退（先に潰さないと仮説が検証できない）

**condA では rnd 5 bit だけが分散を持つので、「$r$ 側」と「$\Sigma$ のサポート」は同一の 5 座標である。** したがって「$r$ が効く」説と「$\Sigma$ が効く」説は**このベンチマーク上で原理的に区別できない**。分けるには condB か、$\Sigma$ を独立に動かす新設計が要る。これは [[論点マップ]] §20 の可識別性交絡と**同型の、しかし別の**縮退。

### 6.3 仮説の翻訳案（Claude・**未登録**）

既存記録と整合させると、仮説は「$r$・$\Sigma$ が殺す」ではなく次の形に置き直すのが自然に見える。

> **現象3 ＝ 保護装置（$r$ 側のスパン・配置・成長）の故障であり、故障を駆動するのは $\Sigma$ 上の残差誘起力である。**

この形なら既存の 3 つのアンカーに直接載る —— 候補2 後半（同本数でも到達可能な損失より 0.25–0.34 悪く、$v$ の最小二乗 refit で埋まらない ＝ **配置の質**の破壊）／候補7（w100 は初期特徴だけで rank 32 完全補間、w5 は rank 3–5・NMSE 0.926 ＝ **スパン冗長性が幅の保護**）／候補5（cross-moment 力の再生）。

**留保**: 3 つとも**事後・ReLU 腕**。非 ReLU では一度も測っていない。
