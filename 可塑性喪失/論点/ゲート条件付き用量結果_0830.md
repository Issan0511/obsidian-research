## 3. 読み

### 3.1 沈下と LoP が切れた（副予測が外れたことが本走で一番重要）

当初の説明は「ゲートを外せば沈まないので LoP が起きない」だった。実際は「**沈む数はほとんど変わらないのに LoP が起きない**」。leaky では 100 中 63–67 が全 32 パターンで負にいる（ReLU の 98 に迫る）のに、未フィット率は ReLU の 1/240。沈下率が一緒に下がっていたら「沈下が減ったから」という交絡が残った。高いまま LoP だけ消えたので、**沈下と LoP を分離した実験**になった。

LoP を作っているのは「負に落ちること」ではなく「**落ちた先で勾配が消えること**」。可動度が 0.1 でも残れば戻れる。

### 3.2 滑らかさは要らない

leaky（折れ目あり・可動度定数 0.1）が ELU（滑らか・$e^z$）と同等かやや良い。`SMOOTHNESS_REQUIRED` は排除。**片道でないことだけが効く。**

### 3.3 ゲートが無ければ用量は効かない

P4 が両活性化で 0 を含み、全 seed 同符号ですらない。**Clevert の効率経路（ゲートが無くても平均のずれが学習を遅らせる）は、この系では検出されなかった。** $J$ も平坦。

### 3.4 揺れが支配的（汚染なしの初測定）

隠れ 1 層なので $\Delta\bar z_i$ に上流の学習が混ざらない。全 6 腕で ρ ≤ 0.08、駆動はほぼ無い。沈下は揺れで起きている。**中心主張の「揺れ」側を、ゲートを外した配置で初めて直接測った。** ただし ReLU 腕では沈下ユニットが凍結して増分が測れないので、**ReLU の駆動については Q17（MATERIAL_REST_ASYMMETRY）の帳簿が残る**。

### 3.5 可動度の絵は部分的にしか合わない

ELU の β は 2 層（[[ELU沼結果_0830]]、−0.27）から**符号が反転して正**になり、上流混入を除いた効果が出た。だが 1 には届かない（0.4–0.6）。leaky の β が有意に負なのは可動度定数では説明できず、深いユニットほど ‖w‖ や $|v_i|$ が小さいといった交絡が候補（**測っていない**）。
