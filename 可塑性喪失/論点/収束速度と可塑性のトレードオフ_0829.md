# 収束速度と可塑性のトレードオフ（ReLU + 大きい µ は速いのか）

親: [[論点マップ]] §18 / 状態: **論点・未検証・主張に入れない** / 作成: 2026-08-29（チャット `v4_init`、Issa 提起） / 関連: [[中心主張v4草案_0829]] µ 考察 §7、[[マージン恒等式と消灯点_0822]] §1、[[停止条件]]、[[命題リスト]] Q0

> **格**: 本ノートは仮説の置き場である。数値は既存の committed 出力から**言える範囲だけ**を引き、仮説に有利な新しい計算はしていない（pilot を回す前に spec を書く）。

## 論点

**前提（スコープ条件・8/29 Issa）**: 本仮説も「学習器が教師よりある程度複雑」な場合に限る。そうでないと速度差は容量不足と混ざり、比較にならない（→ [[過剰パラメータ化とスコープ条件_0829]]）。速度指標を µ 別に比べるときは、**過剰パラメータ化比を固定する**か、比を交絡として明示的に切る。

**仮説（Issa・8/29）**: ReLU + µ/Σ 大の regime では、**可塑性と引き換えに学習の収束が速くなる**のではないか。µ は壁の強さ（柱1）と LoP の閾値（柱3）を決めるダイヤルだが、同じダイヤルが**初期の収束速度を上げる側にも効いている**なら、LoP は「速さの代償」として述べられる。

これが立てば、µ/Σ 主軸の論文にとって大きい。「µ 大は病理」（否定形）が「µ 大は速さと引き換えの病理」（トレードオフ）になり、正規化や中心化が**何を捨てて可塑性を買っているか**まで言えるようになる。

## 先行研究との関係（逆向きの予測）

Clevert et al. 2015（ELU、arXiv 1511.07289）は、前層の非ゼロ平均活性が次層への **bias shift** として働き、これが学習を**遅らせる**と論じた（勾配が自然勾配からずれる、という効率の議論）。ELU が平均活性をゼロへ寄せることで学習が速くなる、という報告である。

本仮説はこれと**逆向き**の予測を立てる。ただし条件が違う。

| | Clevert et al. | 本系 |
|---|---|---|
| 深さ | 深い網（層間の bias shift が累積） | 1 隠れ層・固定入力平均 |
| µ の出所 | 前層の活性平均（学習で動く） | 入力統計（固定。EMA 中心化で外から振れる） |
| 活性 | ELU vs ReLU の比較 | ReLU のみ、µ を振る |
| 主張の型 | 効率（勾配方向） | 到達可能性（壁）＋速度（本仮説） |

したがって「Clevert と矛盾する」とは言えず、**「Clevert の効率の議論が支配する regime と、壁と速度が支配する regime は別かもしれない」**という形で置く。[[命題リスト]] Q0 の Clevert 線引き（効率 vs 到達可能性）に、速度の軸が一本増える。

## 既知の事実で言えること・言えないこと

**言えること**（committed）:

- µ を変えても**関数クラスは変わらない**。学習器入力は `x − m_t` で、シフトは `b_i ← b_i − w_i·m_t` に吸収できる。したがって µ 水準間の差は表現力の差ではなく**最適化力学の差**である（初期の実効バイアス `w_i·µ` の分布と、勾配のスケール）
- std（‖µ‖ ≈ 3.04）でも初期の当てはめは速い側にある: `teachw_0820` で t = 100k では全 H 水準が高精度にフィットし、未フィット率は**時間とともに上昇**する（[[論点マップ]] §0c）。「µ 大だと最初から学べない」ではない
- µ 大 → 最終 `eval_loss` 大は柱3 の表（作業5、`673c338`）。トレードオフの「可塑性側」はここにある
- 作業5 の 8 arm には `online_loss_A_w100.csv`（step, run_id, loss）と `lop_metrics_A_w100.csv`（`eval_loss`・`eff_rank` ほか）が保存されており、入力列は arm 間でビット同一（S6a）。**速度側の pilot は新規走なしで計算できる**

**言えないこと**（未測定）:

- µ 水準ごとの**初期収束速度**そのもの。作業5 の online loss を µ 別に比べた記録は vault に無い。**spec を書く前に見ない**
- 「速い」の定義（第 1 タスクの steps-to-threshold か、序盤 k タスクのタスク内適応速度か、序盤の eval_loss 曲線下面積か）
- 速度差が µ の効果か、単なる**スケール交絡**か（下記）

## 候補機構（Claude 案・未検証・主張に入れない）

柱1 の閉形式から素直に出る絵。µ/Σ が大きいと、初期化時点で前活性は `w_i·µ = ‖w_i‖‖µ‖cosθ_i` に支配され、ユニットは三つに割れる。

1. `cosθ_i < cos_crit` — 全入力で消灯（初期から死）
2. `cosθ_i ≫ 0` — 全入力で点灯（**入力に依らず線形に振る舞う**）
3. `|w_i·µ| ≲ ‖w_i‖√(ŵ_iᵀΣŵ_i)` の薄い殻 — 入力依存のゲート（非線形容量はここにしかない）

2 が多いと網は**ほぼ線形モデル**として動くので、線形成分の当てはめは速い（凸に近い）。一方 3 の殻は**壁のすぐ近くにいる集団そのもの**で、壁に吸収される。速さは 2 から、可塑性の喪失は 3 の消失から来る、という分業になる。**これが正しければ「速さの代償」は比喩ではなく、同じ幾何の二つの面**である。

反証されうる点: 2 の線形部分が速くても、教師（LTU 幅 H）の非線形成分を当てるには 3 が要る。**速度の利得は線形成分の大きさで決まる**はずで、教師の非線形性が強いほど利得は消えると予言する。`teachw_0820` の H 軸で速度を層別すれば、この予言は既存ログで叩ける。

## 判別のスケッチ（起票前）

**pilot（新規走なし・spec 起票後に見る）**: 作業5 の 8 arm × 10 seed で、序盤の速度指標を µ 別に出す。候補指標は (a) 第 1 タスク（step 0–10⁴）の online loss が std 終端水準の 10% を切る step、(b) 序盤 k タスクの各タスク内 steps-to-threshold の中央値、(c) 序盤 eval_loss 曲線下面積。**µ に対する単調性**と、柱3 の最終 eval_loss との**トレードオフ曲線**を描く。

**confirmation（新規走）**: スケール交絡を切るため、実効学習率を揃えた arm（下記）で再走。柱3 spec（task_118）の追加 arm と**同じ走の別 endpoint** にできるなら相乗り可能だが、endpoint の追加は結果を見る前に spec へ書く。

## 交絡（速度比較で必ず切るもの）

1. **スケール**: 入力二次モーメントは `E‖x‖² = ‖µ‖² + tr Σ` で、µ 大ほど同じ η でも実効ステップが大きい。速度差の一部は単に学習率が上がっただけかもしれない。`‖µ‖² + tr Σ` で η を割る、または勾配ノルムで正規化した時間で比べる
2. **初期の生存数**: µ 大は初期化時点の消灯（候補機構の 1）を増やす。速度を「生存ユニットあたり」で見るか全体で見るかで結論が変わる
3. **教師の非線形性**: 上記の H 層別。線形成分の利得だけなら「速い」は自明に近い
4. **中心化の過渡**: EMA 中心化は境界直後に `m_t` が遅れるので、タスク内適応速度は中心化の時定数 `1/α` と混ざる。第 1 タスクの指標は影響が小さく、序盤 k タスクの指標は影響を受ける

## 主張へ昇格する条件

- pilot で速度指標が µ に対して単調で、かつ柱3 の最終 eval_loss と逆向き（トレードオフ曲線が単調）
- confirmation で**スケールを揃えても**速度差が残る
- 候補機構の予言（教師の非線形性が強いほど利得が消える）が H 層別で当たる

三つ揃うまでは µ 考察 §7 の**論点**に留め、一行・柱には入れない。
