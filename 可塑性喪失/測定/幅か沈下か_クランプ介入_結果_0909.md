## 0. 設計

第 1 層の行を **W_i = m̄·1 + (m_i − m̄)·1 + W̃_i** と直交分解し、毎更新（Adam 更新の直後）に 1 成分ずつ t20 の値へ射影する。

| 腕 | 固定するもの | 厳密に触らないもの |
|---|---|---|
| `ref` | — | — |
| `wclamp` | ‖W̃ᵢ‖（中心化ノルム） | m_i 全部・bias・W2・W3・Adam・Snake V |
| `mclamp` | sd_i(m_i)（設定点の散らばり） | W̃ᵢ・m̄・以下同じ |
| `dclamp` | m̄（設定点の水準＝沈下の実体） | W̃ᵢ・sd_i(m_i)・以下同じ |

init から t1–100 を学習。t1–20 は共通の前置きを 1 本だけ回し、そこから 4 分岐（4 腕が bit 一致の t20 状態から出る）。LR/SNA/ELU1 × seed 0–2 × 4 腕 = 36 継続、1 継続 216–236 s。
**`dclamp` を b でなく m̄ でやる理由**: 沈下の 92% は行平均が運ぶ。b で観測量 z̄ だけ押さえると m̄ は沈み続け、off = s11·E[m²] 経由で幅を伸ばしてしまう。

## 4. 読み — 深さは「幅を運んでいる方のチャネル」に従う

前活性の分散は 2 つのチャネルに厳密に分かれる（参照 perm 下・追補 3 の恒等式で検算済み）:

$$\sigma^2_{\text{within},i} \;=\; \underbrace{m_i^2\,s_{11}}_{\texttt{off}:\ \text{行平均}\times\text{明度}} \;+\; \underbrace{2m_i\,\mathrm{Cov}(1^{\mathsf T}x,\ \widetilde W_i\!\cdot\!x)}_{\texttt{cross}} \;+\; \underbrace{\mathrm{Var}(\widetilde W_i\!\cdot\!x)}_{\texttt{wid}:\ \text{中心化重み}}$$

t100・seed0 の内訳（σ² = off / wid）:

| 腕 | ref | `wclamp`（‖W̃‖ 固定） |
|---|---|---|
| LR | 6.52 = 2.67 (41%) / 3.85 (59%) | **1.84** = 0.93 / 0.89 |
| ELU1 | 19.76 = **15.95 (81%)** / 3.85 (20%) | **19.74** = 18.84 / 0.90 |
| SNA | 2.45 = 0.29 (12%) / **2.19 (89%)** | 0.91 = 0.26 / 0.64 |

1. **leaky は中心化重みが幅を運ぶ。** `wclamp` で ‖W̃‖ を止めると σ² が 6.52 → 1.84 に落ち、m̄ と sd(m) も t20 付近で止まり、**沈下が 1/4〜1/2 に落ちる**（R_w 0.23–0.57）。一方 `mclamp` で設定点の散らばりだけ止めても ‖W̃‖ は伸び続け、**沈下は止まらない**（R_m 1.02–1.68、むしろ深い）。
2. **ELU は行平均が幅を運ぶ。** ref で off が 81%。`wclamp` で ‖W̃‖ を止めても **σ² は 19.76 → 19.74 とほとんど変わらず**（行平均チャネルが引き継ぐ）、沈下も止まらない（R_w 0.96–1.59）。逆に `mclamp` で設定点の散らばりを止めると off が 15.95 → 3.49、σ² が 7.60 に落ち、**沈下が半分以下になる**（R_m 0.23–0.66）。
3. **どちらの活性化でも、幅を運ぶ側を止めれば沈下が止まり、運んでいない側を止めても止まらない。** これは「幅が先」の一方向性を、**どの幅かまで指定した形**で支持する。
   チャネルの並び（leaky = 中心化重み、ELU = 行平均、Snake = 中心化重み）は h(z) = zφ′−φ の大小（leaky 0、ELU ≥0 で有界、Snake 振動）と**対応して見える**が、**因果として主張しない**。同日の [[ゲートの尺度不変性と指数_結果_0909]] は「ゲートの尺度不変性が**指数**を決める」を 4 判定とも外して棄却しており、h だけで説明が付く段階ではない。本走が言えるのは**どのチャネルが幅を運ぶかと、深さがそれに従うこと**だけである。
4. **深さを止めても幅は伸びる。** G_within は LR 0.75–0.97（ほぼ完全に伸び続ける）、ELU 0.29–0.66。
5. **中心化ノルムを固定すると精度が上がる。** LR 0.906 → 0.918–0.920、ELU 0.911 → 0.922–0.923（late 窓の中央値、3 seed とも）。Nero 型の射影制約は LoP を軽くする方向に働く。

## 5. 上端の張り付きは servo ではない — これが本走の主結果

**深さを止めると上端が上がる。** `dclamp` の Δp⁺ は LR +0.091〜+0.113、ELU +0.173〜+0.222 で、**両腕とも 3/3 で `EDGE_LIFTS`**。seed0・t100 の生の値では LR の p⁺ が 0.158 → 0.288、ELU が 0.202 → 0.447。

占有率 p⁺ を一定に保つ復元力があるなら、深さを固定した分だけ幅が縮むか、少なくとも p⁺ が元へ戻るはずだが、そうならない。**p⁺ ≈ 一定は、幅と深さが同じ駆動源で一緒に動くことの帰結であって、制御されている量ではない。** [[上端の張り付き_事後_0909]] で見つけた「4 活性化で 80 タスク ±10%」は法則ではなく、共通の上流（第 1 層の成長）が両方を動かしている副産物である。

逆に `wclamp`（LR）と `mclamp`（LR・ELU）では Δp⁺ が −0.005〜−0.045 と小さい。**幅を止めると上端は保たれる。** これは 4 と同じことを上端の側から言っている。

## 6. 事前予測の帰趨

- **Issa「幅が先」**: **支持**。ただし「どの幅か」は活性化で違い（leaky = ‖W̃‖、ELU = 設定点の散らばり）、単一のラベルにはならなかった。
- **Issa「B 腕の上端は `EDGE_HELD`（深さを固定しても p⁺ は保たれる）または判定不能」**: **外れ**。LR・ELU1 とも 3/3 で `EDGE_LIFTS`。SNA だけ `MIXED`（+0.021/+0.040/+0.053）。
- **Claude**: A の「`SINK_STOPS_W` かつ `SINK_STOPS_M`」は**外れ**（LR は M が SURVIVES、ELU は W が SURVIVES）。B の `WIDTH_GROWS_REGARDLESS` も**外れ**（LR `MIXED`、ELU `WIDTH_PARTIAL`）。**唯一の分岐点だった `EDGE_LIFTS` は当たり。**
- 分岐点は Claude 側に落ちたが、**A 側は両者とも「どちらの軸を止めても同じ」と思っていた点で外れており**、活性化ごとにチャネルが違うという構造は事前にどちらも予測していない。

## 7. 各クランプがどれだけ軸を分離できたか

- `wclamp` の ‖W̃ᵢ‖ は毎ステップ厳密に固定（相対 ≤ 3.0e−8）。W̃ᵢ の**向きは自由**なので回転で σ が伸びうるが、LR では回転由来の σ_inv の伸びは +9〜13%（参照は +104〜105%）で**ノルムが支配的**。ELU では σ_inv が参照の 85〜97% で、これは回転ではなく**行平均チャネルが引き継いだ**ため（§4 の表）。
- `mclamp` は off = s11·E[m²] 経由で σ_within をわずかに下げる。追補 2 B3 の見積り −5.5% に対し LR 実測 −2.7〜−5.0%。ELU では sd(m) が幅の主役なので「わずか」では済まない（設計どおり）。
- **3 クランプはパラメータ空間では厳密に直交するが、効果は直交しない。** LR の `wclamp` は ‖W̃‖ を止めるだけで m̄ と sd(m) も止まった（設定点の漂流が ‖W̃‖ 成長の下流にある）。これは欠陥ではなく結果だが、`SINK_*_W` は「ユニット内の幅だけを止めた」判定ではない。

## 8. 限界

- t20 の一点・幅 100 の 2 層 MLP・100 タスク・CPU 学習。`ref` は committed 軌道の再現であって独立な再現ではない。
- SNA は late 窓でほとんど沈まないので A・B の比が不可検定。上端だけが判定できた。
- クランプは関数を保存しない。精度は全腕で報告した（G3 は全腕seed PASS、`wclamp` はむしろ改善）。
- `MIXED` 5 件のうち 3 件は閾値をかすめている（§3）。
- 本走は「クランプすれば止まる」ことを示すが、**なぜその軸が伸びるのか**（[[W増大メカニズム_0909]]）には答えていない。
