> **結論**: 現在タスク32入力上の単独消音損失 `ΔL` が大きいユニットほど、同じ `p̂` と壁マージンを層別した後も同一タスク末尾で `strict_dead` になりにくかった。主判定は **PROTECTIVE**。作業6の操作的定義では、強い「選抜は機能を見ない」仮説は**否定側**である。

作業2の H は機能代理 `r` を使い、any-hit は天井効果、非天井 endpoint は **INCONCLUSIVE** だった。そこで、ユニットが現在の予測へ実際に寄与する量を新規走で直接記録した。

- 主リスク集合: t0で `p_hat>=0.05`。主転帰: t1で `strict_dead := p_hat=0`

## 2. 直接機能量と主解析

現タスクの32入力を全列挙し、ユニット `i` の出力寄与を `q_i`、残差を `δ=yhat-y` として

`delta_mse_i = E[(δ-q_i)^2]-E[δ^2] = E[q_i^2-2δq_i]`

`utility_nmse_i = delta_mse_i / Var(y)`

を記録した。正なら、その時点・その現タスクでユニットを単独消音すると損失が増える。

主解析は、t0のリスク曝露をまず **`t0 × p_count`**（`p_count=round(32*p_hat)`）で完全層別し、その中で `pre_max` を五分位化した。各 `t0 × p_count × margin5` セル内で `utility_nmse` を三分位化し、high−low の凍結率差を `min(n_high,n_low)` で重み付けした。CIは20 seedのブロックbootstrap 10,000回（RNG `20260831`）。群とセルはbootstrap前に固定した。

判定境界は±0.05。CI上端が−0.05未満なら **PROTECTIVE** と事前固定した。

## 5. 柱3への含意

**言ってよい**

- この条件・この現在タスク `ΔL`・この層別の範囲では、セル内で相対的に `ΔL` が高いユニットほど凍結しにくい
- 壁の式そのものに機能量が現れないことと、集団としての凍結結果が機能に無関係であることは別。後者は支持されなかった
- 作業2 O の「学習済み W に修復可能な容量が残る」は別の容量診断として維持される

**言わない**

- `ΔL` がユニットの普遍的価値・将来タスク価値・Shapley値である
- 層別で交絡が完全に消えた、または機能が凍結を因果的に防いだ
- condB、他幅、他教師、長期将来へ一般化できる
- Oまで否定された、または逆に O だけで「病理的刈り込み」が確定した

したがって、柱3を「機能盲目性」として売るのは止める。残る事実は、**直接機能量と凍結結果には保護的関連が見える一方、学習済み W 全体にもオラクル修復可能な容量が残る**という二層構造である。v3の「良性刈り込みへの反例」という位置づけは、この分解を踏まえて先生再裁定が必要。

## 7. r 差し替え解析（2026-08-27・`r_swap_0824`）

spec: [[r差し替え解析spec_0824]]（事前登録 commit `3e22b6b`）/ 実装 `6e3e4d9` / 結果 `d357779`（**push 済み・リモート確認済み**）/ 正本: `results/r_swap_0824/summary.md`, `verdict.csv`, `sanity.csv`

**問い**: 作業6 の `ΔL` 効果は、`r`（µ̂ 直交成分＝背の高さ）の言い換えではないのか。既存 `exposures.csv`（`ac29d87`）の再解析のみで、**新規学習走ゼロ**。

### 7.1 判定

| # | 内容 | 結果 | 判定 |
|---|---|---:|---|
| **R1（主）** | `ΔL` high−low を `cell_id × r_half` で層別 | **−0.3114 [−0.3577, −0.2895]** | **SPECIFIC** |
| **R2（副）** | `r` high−low を `cell_id × u_half` で層別 | **+0.0311 [−0.0003, +0.0721]** | **INCONCLUSIVE** |

検出力ガードは**両方とも不発**: G1 曝露保持率 low 2639/5023 = 0.5254 / high 2537/4431 = 0.5726（閾値 0.40）、G2 CI 半幅 0.0341（閾値 0.10）。層は 8,841（有効 1,664）。副次転帰 `end_dead_0_05` も同方向（R1 −0.3299 [−0.3710, −0.3109]、R2 +0.0248 [−0.0039, +0.0657]）。

### 7.2 言ってよいこと

- **査読の反論「`ΔL` 効果は `r` の言い換えでは」は否定される。** `r` の中央値分割で条件付けても、`ΔL` high−low の調整 RD は CI ごと 0 から離れたまま、事前登録の SPECIFIC 閾値（点推定 ≤ −0.15）を大きく超える
- **`r` と `ΔL` は弱くしか相関していない**（seed 中央値 +0.198、pooled +0.206）。`xr分解と生存機構_0822` §17 の `Spearman(reach, r) = +0.73` から素朴に期待されるほど `ΔL` は `r` に乗っていない。R1 が生き残った理由はここにある
- **`r` 自体に保護効果は見えない。** R2 は点推定が **+**（保護と逆符号）で、周辺 RD も +0.0165。ただし CI が 0 と等価域の双方を跨ぐので **INCONCLUSIVE**（= null の証拠でもない）

### 7.3 言わないこと（重要）

- **「`r` で条件付けると効果が強まる（−0.2353 → −0.3114）」を機構の主張にしない。** この 2 数値は**推定対象の重み付けが違う**。層別を細かくすると有効セル集合と曝露集合が変わる（2,839 セル・5,023/4,431 曝露 → 1,664 層・2,639/2,537 曝露）ので、増分には (a) `r` による条件付け と (b) 母集団のシフト が**未分解のまま混ざっている**。事前登録にも like-for-like の対照は無い。**SPECIFIC の判定自体はこの比較に依存しない**（CI が 0 を除外し点推定が閾値を超えたか、だけで決まる）
- **R2 INCONCLUSIVE を「`r` は効かない」と読まない。** 「保護効果の証拠が無い」までで、等価域に収まっていないので null は主張できない
- 作業2 H の null を本結果で説明し切ったとも書かない。H の天井（追跡窓 30 倍）は別要因として残る
- スコープは作業6 と同一（condA・w100・T=10,000・std・`generator_offset = 20260830` の 20 系列、**層別後の観察的関連であり因果介入ではない**）

### 7.4 サニティと、spec の穴 2 件

S1 / S2 / S3 / S4 / S6 PASS、S5 は REPORT。**S2 は作業6 の登録値と float 完全一致**（`rd = −0.23527554781786336`、`ci = [−0.28122021273155479, −0.23246969586791047]`、`n_low=5023 / n_high=4431 / n_cell=2839`）＝ハーネスが作業6 を再現している。4 CSV は CLI 独立再実行でも byte 一致。

実行後に判明した**空虚な検査が 2 件**。どちらも判定に使っていないので結論には影響しないが、記録しておく。

- **S4（`p̂ == 0 ⇔ pre_max <= 0`）は空虚に真**。リスク集合が `p̂ >= 0.05` なので `p̂ == 0` の曝露が 0 件。両辺 0 件で成立する
- **S5（中央値分割の群サイズ偏り）は構造的にトートロジー**。同値を上位側へ送る中央値分割では上位側サイズが常に `ceil(n/2)` になるので、少数側シェアは**セルの大きさ `n` だけで決まり、どの変数で切っても同一**。実測でも `r_half` と `u_half` の分布が全 6,002 セルで完全一致した。少数側 < 1/4 の 3,163 セルは全て n=1 のセル（作業6 でも無効セルとして除外済み）。**分割の質を何も検査していない**

→ `ratchet_log_0819` P4・`cell4_0821` P1 と同型。**「事前登録の検査が測定対象の一部で恒真になっていないか」は、判定基準だけでなくサニティ側にも掛けること**（[[論点マップ]] §9 の教訓②の適用範囲を拡張）。

### 7.5 柱3 への含意

作業6 の PROTECTIVE は**代理変数への還元では説明されない**ことが確定した。「選抜は機能を見ない」の強い形は、`ΔL` でも `r` 統制後の `ΔL` でも否定側で一貫する。§5 の二層構造（直接機能量と凍結結果には保護的関連／学習済み W 全体にはオラクル修復可能な容量が残る）はそのまま維持され、**先生再裁定に出す材料が 1 本増えた**という位置づけ。
