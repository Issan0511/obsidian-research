# 残滓は「要る」のではなく「溶接されている」 — 当てはめの前なら外せて、しかも速くなる（事後・0923）

**要旨。** Issa の問い「増やせるならなんで消せないのか」。0922 の答え（「新しい解が残滓の存在を前提に書かれ、後から外すと損失が上がる」）を、古い分と当課題の書き込みを**分ける**検査で確かめた。**(1) 課題 50 の更新 ΔW は解ではなく差分で、top 帯で ΔW だけを残すと帯ごとゼロにするより悪い**（−60.8 pt 対 −53.9 pt）。**(2) 収束点は残滓の量に対して極小**で、消す側にも足す側にも損失が上がる（10/10 seed）。ただし一次の押し返しは分解能以下で、私の「単調に上り坂」は言い過ぎだった。**(3) 決め手: 当てはめの前に抜けば無料どころか速い。** mid2+低帯（ノルムの 57%）を課題 50 の開始前に抜いても、精度 1.0 到達は 5,400/4,800/4,800 更新（対照 5,300/5,600/5,900）で、抜いた帯は 1 課題では再建されない（V_mid2 3.23e4 → 694）。**残滓は課題に必要ではない。固定を作っているのは残滓の中身ではなく、当てはめという手続き。**
**(4) 0922 に引いた −31 pt は古い残滓の担い手性の証拠にならなかった。** 古い分だけ抜くと **−16.2 pt**。半分は当課題自身の書き込みの寄与だった（ノルムでは 2% しかないのに）。

関連: [[RL-CIFAR第1層の幅を広げる者_消し残りと収束後の増幅_事後_0922]]（前段・§3 の PC 別侵食率）・[[RL-CIFAR第1層の漏れ検査_Adamの三つの歩幅_事後_0922]]・[[RL-CIFAR第1層の帯別帳簿_事後_0922]]。

## 0. 問い

0922 に私がこう書いた。

> 一番の理由は、新しい解が残滓の存在を前提に書かれること。top が先に出力を合わせ切ると、残滓の出力への効果は新しい解に織り込まれ、その時点で残滓を消すとむしろ損失が上がる。損失にとって残滓は「無視されている」のではなく「固定されている」。証拠は抜き取り検査で、古い残滓の帯である mid2＋low を抜くと −31 pt。

証拠の穴: t=50 で mid2+low を抜くと、**古い残滓と課題 50 自身がその帯に書いた分の両方**が消える。分けていない。

## 1. 道具

W49 = 課題 50 が始まる前の第1層、W50 = 課題 50 の終わり、ΔW = W50 − W49、P_b = 帯 b への射影（PCA 基底 Q は seed ごとの 1200 枚の中心化共分散）。評価は**課題 50 のラベル**・1200 枚・LR std・seed 0–9。W2/W3/bias は一切触らない。float64（float32 の snapshot は厳密に広がる）。`full` は acc 1.0・損失 8.1e−5。補空間の除去は Δacc 厳密 0（射影の較正点）。

- **A 事後の抜き取り**: 帯ごと（W50 − P_b(W50)）／古い分だけ（W50 − P_b(W49)、残るのは ΔW の塊）／新しい分だけ（W50 − P_b(ΔW)、残るのは W49 の塊）。ノルムを揃え直す対照つき。
- **B 向きの特異性**: 古い塊を帯の中で乱数直交回転して戻す／同ノルムのガウス行列を戻す。
- **C 損失の形**: L(s) = loss(W50 − s·P_b(W49))、s ∈ [−0.25, 1]、および自動微分の厳密勾配との内積。
- **D 決定的**: 課題 50 を「残滓を抜いた W49」から学習し直す（Adam 状態ゼロ、対照も同条件、6,000 更新上限、精度 0.999 到達＋500 更新で停止）。
- 予測は計算前に固定（`_mine/PREDICTIONS_weld.md`、sha256 6aafde11…）。判定は ○6 △1 ×4。

## 2. 結果 A: 古い分だけ抜く（Δacc、pt、seed 中央値 [min, max]）

| 帯 | 古い分の割合（ノルム） | 帯ごとゼロ | **古い分だけ抜く** | 新しい分だけ抜く |
|---|---|---|---|---|
| top 1–10 | 0.99 | −53.88 [−55.0, −50.8] | **−60.79 [−63.0, −55.7]** | −44.46 |
| mid1 11–100 | 0.99 | −67.17 | −58.12 [−61.3, −56.3] | −29.29 |
| mid2 101–439 | 0.98 | −27.54 | −14.88 | −4.33 |
| low 440–1199 | 0.98 | +0.00 | +0.00 | +0.00 |
| mid2+low | 0.98 | −31.00 | **−16.17 [−17.8, −15.3]** | −6.54 |
| 補空間 | 0.98 | +0.00 | +0.00（厳密） | +0.00 |
| W49 を全部（W1 := ΔW） | | | **−81.33**（acc 0.187） | |

- **ΔW は解ではなく差分**。top 帯で ΔW の塊だけを残すと（−60.8）、帯をゼロにする（−53.9）より**悪い**。課題 50 の更新は top 帯では大半が「前の解を消す」成分（侵食率 −0.93）なので、単独では前の解の負の像になる。**新しい書き込みが古い塊を前提にしている**ことの直接の証拠。予測 A2（古い分だけの方が軽い、−25〜−45）は符号ごと外れ。
- **0922 の −31 pt は使えない**。古い分だけなら −16.2。ノルムでは 2% しかない当課題の書き込みが残り半分を担う。しかも足し算にならない（−16.2 と −6.5 で別々、両方で −31.0）。予測 A1（−26〜−36）は外れ。
- W49 を全部抜くと acc 0.187。ノルムを元に戻しても 0.185（予測 A3 ○）。残滓は「ただ乗っているだけ」ではない。
- ノルムを揃え直す対照で Δacc は最大 0.21 pt しか動かない → **効いているのは大きさでなく向き**。

## 4. 結果 C: 収束点は残滓の量に対して極小

|---|---|---|---|---|
| top | 8.1e−5 | 0.103 | 17.1 | 分解能以下・符号は seed で割れる |
| mid1 | | 0.057 | 8.07 | 同上 |
| mid2 | | 1.1e−3 | 1.08 | 同上 |
| low | | 8.8e−5 | 3.2e−4 | 同上 |
| **補空間** | | 変化なし | **変化なし** | **厳密 0（1e−19）** |

- **L(±0.05) > L(0) が top・mid1・mid2 で両側・10/10 seed**。つまり今の残滓の量は損失の極小で、**消す側にも足す側にも上り坂**。「量に合わせて書かれている」（予測 C3 ○）。
- ただし**一次の押し返しは無い**（勾配は 1.3e−4、内積の cos は ±0.005 以内、符号は seed で割れる）。予測 C1「s=0 から単調に増える」は**外れ**。収束点なので当然で、正しい言い方は「押し返される」ではなく「**極小に嵌っている**」。
- 補空間は両方の測り方で厳密 0（予測 C2 ○）。「本当に無視されている」の較正点。

## 5. 結果 D（決定的）: 当てはめの前なら外せる、しかも速い

課題 50 を、開始前に残滓を抜いた重みから学習し直す（seed 0/1/2）。

| 開始点 | 精度 0.999 まで | 課題末 σ | 課題末 V_mid2 / V_mid1 | ‖W1‖² 開始 → 末 |
|---|---|---|---|---|
| 対照（W49 のまま） | 5,300 / 5,600 / 5,900 | 83.6 / 84.0 / 82.5 | 3.23e4 / 2.97e5 | 7.60e4 → 7.47e4 |
| mid2+低帯を抜く | **5,400 / 4,800 / 4,800** | 81.3 / 80.3 / 77.4 | **694** / 2.97e5 | 3.37e4 → 3.30e4 |
| mid1 を抜く | **4,200 / 4,500 / 5,000** | 59.6 / 55.0 / 59.2 | 3.19e4 / **1.09e4** | 4.56e4 → 4.56e4 |
| 第1層だけ初期値 | 2,600 / 4,200 / 2,600 | 12.0 / 15.7 / 12.1 | | 33 → 600〜1,000 |

- **残滓は課題 50 に必要ではない**（予測 D1 ○、しかも予測より強い）。抜いても届くどころか、固定更新数での精度は全区間で抜いた側が上（例 3,000 更新: 対照 .838/.852/.795、mid1 抜き .955/.982/.954）。
- **抜いた帯は 1 課題では再建されない**（V_mid2 3.23e4 → 694、V_low 651 → 8.9、V_mid1 2.97e5 → 1.09e4）。当てはめは「あれば使うが、無ければ作らない」。
- ‖W1‖² も戻らない（予測 D3 ○）。幅は mid1 を抜くと 29〜35% 減、mid2+低帯では 3〜6% 減（予測 D2 は mid1 のみ的中）。**幅の担い手は mid1、ノルムの担い手は mid2**という 0922 の分業と整合。
- **網ごと初期値が 3 倍速い**（1,767 対 5,600 更新）。これが LoP そのもの。残滓を部分的に抜くとその中間に入る。

## 6. 読み

- **「固定」は残滓の性質ではなく当てはめの産物**。同じ重みが、当てはめの前なら無料で外せ（D）、当てはめの後なら外すと −16〜−61 pt（A）。間にあるのは 5,000 更新の当てはめだけ。
- **なぜ消えないか**の正しい言い方: 損失には原点を向く項が無く、古い成分を押し下げる力は「それがいま出力を間違えさせている間」だけ働く。当てはめが終わるとその力は消え、残滓は解の座標として極小に嵌る。一次の力で守られているのではなく、**動かす理由が無くなる**。WD はこの欠けた項に当たる。
- **ΔW は解ではなく差分**（A の top）。「前の解を消して書き直す」（帯別帳簿の「考え直し」）は、消し切れなかった分だけ次の当てはめの土台になり、その土台の上でしか意味を持たない更新が書かれる。これが世代を重ねる。
- **V11 への含意**: 「W 増大 → LoP」の鎖で、増えた重みは**能力の担い手ではない**（抜いても学べる・むしろ速い）。介入としての cap/L2 が効く理由もここにある（[[cap-cifar-ee-0920]] [[l2split-rlmnist-0914]]）。ただし「抜けば速い」は 1 課題・3 seed の再学習であって、連続学習の腕としては未登録。

## 7. 未検査・限界

- seed 0–2（D）・0–9（A・C）、LR std のみ。raw・SNA・他活性化は未見。
- D は Adam 状態ゼロからの再学習（対照も同条件）。走そのものの課題内軌道ではない。対照 seed 1・2 は 6,000 更新の上限に当たり acc 0.9992 で停止（0.999 到達更新数は影響なし）。mid1 抜き seed 0 は 4,200 で 0.999 到達後 0.926 へ落ちる非単調。
- 「抜いても速い」を連続学習の腕にしたらどうなるか（毎課題 mid2+低帯を落とす腕）は未実施。cap/L2 との関係もそこで見るべき。
- B の対照は摂動が大きく、「向きが効く」までしか言えない。
- 一次の押し返しが無いこと（C）は「収束点だから」で説明できるが、当てはめの途中（損失 0.1 前後）での押し返しは測っていない。
