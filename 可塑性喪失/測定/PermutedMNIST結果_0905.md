## 0. 一行

**段 0 の足切りは通り**（ReLU が「精度 −0.029・dead +0.123・w_norm 7.78」で `MECHANISM_PRESENT`）、**Snake α=1 は leaky に勝つ**が、**既存の LoP 対策 4 手法すべてに負ける**。機構の主判定 C1 は `NEITHER_ORDERS` で、[[前活性の力学_事後_0904]] §8 の「ゲート量が損害を順序づける」は**実データで支持されなかった**。

## 1. 段 0（M0）

`MECHANISM_PRESENT`（lr 0.1・ReLU・10 seed 中央値）。3 条件すべて成立。

| §5.1 条件 | 閾値 | 実測 |
|---|---|---|
| タスク 1 からの精度低下 | ≥0.02 | **+0.029** |
| `dead_frac` 上昇 | ≥0.10 | **+0.123** |
| `w_norm` 比 | ≥1.2 | **7.78** |

**LoP の大きさは lr に単調**（peak−final が lr 0.005 で +0.002 → lr 0.1 で +0.054）。低 lr では失うものが小さい。

**対照だけで言えることが 2 つある（Snake を入れる前）。**
1. **ノルム成長は機構ではない。** `LIN`(恒等)は w_norm が 5.9 倍に育つのに 0.015 しか失わない
2. **沈下の深さは損害を順序づけない。** lr 0.05 で leaky は ReLU より**深く沈み**（zbar −2.41 対 −2.14）**損失は小さい**（0.033 対 0.038）。合成箱の幅 5（[[前活性の力学_事後_0904]] §8.5）と同じ像が実データの対照腕で再現した

## 2. 段 2（主判定）

**P2 = `SNAKE_WORSE`。登録どおりでは Issa・Claude の両予測が外れる。**

主判定腕は `SN3`（α=3）で、`SN1`（α=1）は REPORT_ONLY だった（[[PermutedMNIST_spec_0905]] §5.3・§5.4）。

| 腕 | lr 0.01 | 0.02 | 0.05 | 0.1 | 最良 lr |
|---|---|---|---|---|---|
| `SN1`（REPORT_ONLY） | 0.9017 | **0.9066** | 0.8975 | 0.8661 | 0.02 |
| `SN3`（**主判定腕**） | 0.8919 | 0.8806 | 0.8763 | 0.8483 | 0.01 |
| `LR` | 0.8885 | 0.8899 | 0.8870 | 0.8862 | 0.02 |

`SN3` は lr 0.02/0.05/0.1 で `LR` に 0/10 の負け。**登録した判定は `SNAKE_WORSE`。**

| | P2 の予測 | 結果 |
|---|---|---|
| Issa | `SNAKE_RETAINS_BETTER` | **外れ** |
| Claude | `SINKING_NOT_BINDING` | **外れ** |

**α=1 を主判定腕にしていれば当たっていた、とは書けない。** α=3 を選んだ理由は「合成箱の 3 設定すべてを生き残った唯一の α」で、実データでは発散しないので選定理由が効いていない。**spec 設計のミス**（[[引用禁止]] に追加）。

### 2.1 REPORT_ONLY の `SN1`

`SN1` は lr 0.01・0.02・0.05 で `LR` に **10/10・p=0.002**（+0.011〜+0.016）。lr 0.1 でのみ 0/10 で負ける。

**ただし勝ちの大半は「保つ」ではなく「よく学習する」。** lr 0.02 で final 差 +0.0174 のうちピーク差が +0.0122。下落量（peak−final）で有意に勝つのは 4 lr 中 1 つだけ（lr 0.02・9/10・p=0.022）で、lr 0.1 では 0/10 で負ける。**可塑性の主張としては立たない。**

## 3. 既存 LoP 手法との比較（`pmnist_lopcmp_0905`）

実装は [[PermutedMNIST_既存手法比較_spec_0905]] §5 の擬似コードであって**原論文の再現ではない**。検査（`none` が宿主と bit 一致・各手法を無効値で回すと `none` と bit 一致・CBP の置換回数 124/125）は全通過。

**当初 lr 0.1 でしか回しておらず、それは全腕にとって最良でなかった**（Issa の指摘・9/5）。lr 0.01/0.02/0.05 を追加し、**各腕を自分の最良 lr で**並べ直した。

| 腕 | 最良 lr | 精度 |
|---|---|---|
| **`R`+`l2init` (λ=1e-3)** | 0.05 | **0.9216** |
| `R`+`l2` (λ=1e-3) | 0.05 | 0.9149 |
| `R`+`cbp` (ρ=1e-4) | 0.05 | 0.9129 |
| `R`+`snp` (p=0.9,σ=0.01) | 0.05 | 0.9125 |
| **`SN1`** | 0.02 | **0.9066** |
| `SN3` | 0.01 | 0.8919 |
| `LR` | 0.02 | 0.8899 |
| `R`（介入なし） | 0.02 | 0.8898 |
| `LIN` | 0.05 | 0.8853 |

**`SNAKE_BELOW_INTERVENTIONS`。** `SN1`@0.02 は最良の介入 `l2init`@0.05 に **0/10・p=0.002**（−0.0153）で負ける。介入 4 つすべてが Snake を上回る。lr を公平にしても順位は変わらない。

### 3.1 機構の判定 = `NEITHER_ORDERS`

| | Spearman（10 セル・lr 0.1） | 順列 p |
|---|---|---|
| acc と `mobility` | −0.539 | 0.115 |
| acc と `w_norm` 比 | −0.576 | 0.089 |

**どちらも有意でなく、mobility のほうが弱い。** C1（mobility が順序づけ w_norm は関係ない）は**外れ**。

理由は **`mobility` が非単調**だから。0.008（`R` 介入なし）は悪いが **1.000（`LIN`・`SN3`）も悪い**。良いのは 0.13〜0.28 の中間帯（介入 4 つ）。「ゲートが開いているほど良い」ではない。

| 予測 | 結果 |
|---|---|
| C1 mobility が順序づける | **外れ**（`NEITHER_ORDERS`） |
| C2 `l2` が介入 4 つで最下位 | **当たり**（ただし差は小さい） |
| C3 `SN1` は `R` より上・`R`+`cbp` より下 | **半分外れ**（lr 0.1 では `R` にも負ける） |
| C4 `SN1`+`cbp` > `SN1` | **外れ**（差 0.0002・5/10・p=1.0） |

C4 の外れ方が示唆的で、**CBP は Snake に何もしない**。Snake は `dead_frac` が恒等的に 0 なので置換対象が無い。

### 3.2 spec の欠陥 2 つ（実装側が発見）

- **P1 が到達不能**。`dead_frac` を `|φ′|<1e-6` と定義したので床のある腕（`LR`・`SN1`・`SN3`・`LIN`）は全部恒等的に 0。0 対 0 の符号検定は 9/10 に届かない。**`mobility` を使うべきだった**（§8.6 で自分でそう書いておきながら spec で `dead_frac` を使った不整合）
- **§5.1 の錨**。「タスク 1 からの低下」は lr が小さいとタスク 1 がウォームアップ中で、失ったものでなく「タスク 1 が何点だったか」を測る。ピーク基準なら lr 0.05 でも `MECHANISM_PRESENT`

## 4. 引用制限

- **主判定腕は `SN3` で、それは負けた。** 「Permuted MNIST で Snake が勝った」と書かない。α=1 の勝ちは REPORT_ONLY 枠
- **`SN1` の勝ちを可塑性の証拠にしない。** 大半はピーク差（よく学習する）で、下落量で有意なのは 4 lr 中 1 つ
- **実装は原論文の再現ではない。** 「CBP に勝った/負けた」ではなく「本 spec の CBP 実装に対して」
- **`NEITHER_ORDERS` を「w_norm が効く」と読み替えない。** w_norm も有意ではない
- つまみは介入側だけ最良点を取っている（Snake に不利な設計）。それでも Snake が負けた、という向きでのみ読む
