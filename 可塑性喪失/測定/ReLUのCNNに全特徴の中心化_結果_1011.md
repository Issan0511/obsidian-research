## 0. 何を測ったか

P181 の事後の機構: CH（色のチャネル平均の C ＋ pool 出力のチャネル平均・fc のユニット平均の H）は、f1 の入力（c2 の pool 出力 16 チャネル × 8×8 位置 = 1,024 特徴）の**位置ごとの平均**を残し、f1 がそれを通る µ 経路で沈んだ。MLP の H は次の層に渡る各スカラー特徴を中心化するので、CNN での厳密な対応は (チャネル × 位置) ごとの中心化になる。

- **H′**: conv の pool 出力から (チャネル × 位置) ごとの EMA 平均を引く（c1 の後 4,096・c2 の後 1,024 特徴、β 0.01・勾配なし・訓練と評価で同じ m）。fc（f1・f2）はユニットごと（P181 の H と同じ）。
- **CH′**（主、repo では `CHf`）: C（P181 と同じ色のチャネル平均）＋ H′。**H′**（`Hf`）単独。Kumar らの CNN・RL-CIFAR・ReLU・seed 10–19・30 課題・主窓 t21–30。
- 主張の範囲: 「隠れ層の入力の全特徴の中心化 ＋ 入力の色の中心化」。入力層 c1 の入力は位置ごとには中心化しない（MLP の C の厳密な移植ではない）。
- 対照: **Hs**（seed 10。H′ と同じ m を、位置の固定の並べ替え（不動点なし）で引く。チャネルの平均は消え、位置ごとの平均は消えない）と **CHs**（C ＋ 同じ並べ替え。親が追加を採用）。
- ref・C・H・CH は P181 の走を再利用した（このエンジンで R = 10・課題 1 を回し直すと per_task・t0・curves・40 本のチェックポイントが P181 と bit 一致）。
- 判定は P181 の規則（主窓 online ≥ 0.5 の seed が 9/10 以上で RESCUED、1/10 以下で FAIL）。要約 FEATURE_DOOR: CH′ が RESCUED なら `FEATURE_CENTERING_SUFFICES`、CH′ と H′ がともに FAIL なら `CENTERING_NOT_A_DOOR_IN_CNN`、他 `FEATURE_CENTERING_PARTIAL`。扉の記録の条件は「課題 1 の中で EMA が更新された」だけにした（P181 の穴: 95〜99% が死んだ層で m が float32 の非正規数の不動点に止まるのを免除していなかった）。
- 検査 20 項目 all_pass（変異 46/46）。

## 2. 機構（事後・報告のみ。単位中央値の seed 中央値）

- **装置は位置ごとの平均を消した**: f1 の入力の位置ごとの平均（rms 偏差で割る）は課題 1 末で、扉の前 0.13〜0.14 → 扉の後 0.009（比 0.06）。c2 の入力では比 0.01〜0.03。Hs・CHs では逆に ×1.40〜1.51（別の位置の平均を引くので √2 倍に増える）。H・CH は 0.16〜2.3 のまま。
- **µ 経路は 4 層すべてで閉じたが、4 層とも b 経路で沈む**: CH′ の初期値 → t30 の b の取り分は 4 層とも 1.00。Δb は c1 −1.04・c2 −10.5・f1 −6.5・f2 −6.0、t30 の死亡率は c1 0.78・c2 0.88・f1 0.77・f2 0.86。H′ では c1 だけが生の入力の平均の経路（µ 経路）で沈む。
- **沈む場所が fc から上流の conv へ移る**（CH′ 対 CH、層の機能の低下の時刻の seed 中央値）: f1 は 5.5 → 19・f2 は 12 → 24 と守られたが、c1 は 12 → 5.5、c2 は 24.5 → 8.5（10/10 で早い）。t30 の死亡率は c1 0.28 → 0.78、c2 0.41 → 0.88。H′ 対 H も同じ向き。仮説（検証していない）: P181 の CH では f1 が早く死んで上流への勾配を止め、c1・c2 を凍らせて守っていた。f1 が生き残ると上流の conv が b 経路で押され続ける。
- **尺度の育ちは止まらない**: 課題 1 末の logit の SD は CH′ 3,089・H′ 9,701（ref 15、CH 626、H 2,019）。位置ごとの平均の帰還を消しても前活性の尺度は育つ。
- 扉の記録（報告のみ）: H′ の f1 で 91 件（c2 が死んで f1 の入力が定数になり、m が動かなくなった）、CH′ で 8 件、すべて T_f の後。P181 の規則なら H′ は INAPPLICABLE になっていた。

## 3. 読み

- **「標準の CNN（ReLU）でも、各層の入力の全特徴の中心化は喪失を防ぐ」は言えない。** この箱では、MLP の H の厳密な対応（次層に渡る全特徴の中心化）に色の中心化を足しても、30 課題の主窓で 9/10 seed が床の近くへ落ちる。チャネル平均だけの CH より主窓では高い（9/1）が、機能の低下の時刻は区別できない。
- CNN では、中心化（平均の経路 µ を閉じる扉）だけでは **b 経路の沈降が残り**、4 層とも bias が下がって閉じる。P181 で f1 を沈めた位置ごとの平均の経路は H′ で消えた（Hs が H の側を通ったので、H′ の効き = f1 を守ることは位置ごとの平均を消すことから来る、と読める。1 seed・1 つの並べ替えに限る）が、沈む場所が c1・c2 に移った。
- MLP との対応: MLP の CH は 50 課題を保った（V12 §3.3）。CNN の CH′ は µ 経路を閉じても b 経路で落ちる。違いの理由（MLP で b 経路が救命を妨げない理由、max-pool や重み共有の役割）は分からない。
- 言えないこと: bias への扉（b 経路を止める扉。MLP の CHB に当たるもの）を足せば救えるか。50 課題。「f1 の早い死が上流を守った」という読み（仮説）。
