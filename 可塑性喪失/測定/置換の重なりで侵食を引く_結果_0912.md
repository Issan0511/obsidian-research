# 置換の重なりで侵食 c を引く（perm_overlap_0912）

spec `spec_perm_overlap_0912`（事前登録 repo `d9aa0ef`、追補 1）／結果 `88a5318`。タスク境界で 784 画素のうち割合 k だけを入れ替え直す。k ∈ {0, 0.1, 0.25, 0.5, 1} × {leaky 0.1, Snake 0.6} × 3 seed = **30 走 × 120 タスク**。k=1 が標準の Permuted MNIST で、宿主と同じ経路を通るので **G1 42 点 maxabs 0.0** と `gradient_factors_0910` の `LR` 再現 **0.0** がそのまま効く。

## 問い

帳簿 Δ‖W̃‖² = D² − 2cDN のうち D 側は誤差 e2 が並べる（[[勾配の因子分解と斉次性の破れ_結果_0912]]）。残る c は 19 の活性化腕で **0.024–0.050** に揃う一方、CYCLE1 で符号反転・WD で 10 倍と活性化以外では大きく動く。**c はタスク側の変数か。**

## 判定（Claude 1/6）

| | ラベル | 予測 | 実測 |
|---|---|---|---|
| V1 c は k で反転するか | **`SIGN_FLIPS`** ✓ | `SIGN_FLIPS` | c(k=0) −0.0285 / c(k=1) +0.0421 |
| V2 2 活性化で同じ曲線か | **`DIFFERENT`** | `SAME_CURVE` | \|Δc\| 最大 **0.0522** |
| V3 切替ショックが媒介か | **`WEAK`** | `MEDIATES` | Spearman +0.60（leaky 単独なら **+1.000**） |
| V4 c<0 で成長則 | **`SUB_SQRT`** | `SUPER_SQRT` | p_late(k=0) 0.435 |
| V5 帳簿の再現 | **`FAILS`** | `HOLDS` | 最大相対誤差 17.1%（順序は Spearman +0.94） |
| V6 幅が LoP を並べるか | **`NO`** | `WIDTH_TRACKS` | (N120, 低下) +0.15 対 **(k, 低下) +0.74** |

## 主結果 — c は活性化で機構が違う

| k | 切替 CE (LR/SN) | **c (leaky)** | **c (Snake)** | 差 |
|---:|---|---:|---:|---:|
| 0 | 0.015 / 0.053 | **−0.0285** | +0.0036 | +0.0321 |
| 0.1 | 0.198 / 0.228 | −0.0099 | **+0.0423** | **+0.0522** |
| 0.25 | 0.635 / 0.594 | +0.0137 | +0.0472 | +0.0336 |
| 0.5 | 1.716 / 1.574 | +0.0295 | +0.0466 | +0.0171 |
| 1 | 3.949 / 4.597 | +0.0421 | +0.0445 | **+0.0025** |

**2 活性化が一致するのは k=1 だけ。** 離れると最大 0.052 開き、これは 19 腕の全幅（0.026）の 2 倍。

> **「活性化 19 腕で c が揃う」は、k=1 でしか測っていなかったことの産物だった。**

- **leaky**: 切替ショックが c を完全に媒介（Spearman(切替CE, c) = **+1.000**）。k を下げると単調に下がり k=0.25–0.1 で**符号反転**して自己膨張に入る。[[なぜ下がるか_活性化誤差の分解_事後_0910]] §6 の「誤答標本が既存パターンを縮める」はこちらでは支持。
- **Snake**: **飽和**。c(k=0.1)/c(k=1) = **0.95**。切替 CE 0.23（k=1 の 1/20）で満額の侵食が立ち、k=0 以外では常に最大。

**事後の読み（未検定）**: Snake のゲート 1+sin(2αz) は零交差が周期的に並ぶので、画素を 1 割入れ替えるだけで応答ユニットの集合が大きく入れ替わる。leaky は sign(z) しか見ないので 1 割では反転しにくい。これは「ゲートは Adam に消される」と矛盾しない——消えるのはユニットごとの**定数倍 g2** であって、**どのユニットが応答するかという配置**は消えない。

## その他

- **c<0 でも暴走しない**（V4）。`K000_LR` は固定点が消えるのに p_late 0.435。D が 1.165 → 0.374 と 1/3 に落ちるため。帳簿はこのセルで 17.1% 過小（V5）。
- **この軸では幅が LoP を並べない**（V6）。`K000_LR` は幅 6.98 で精度が **改善**（−0.52 pt）、`K000_SN06` は幅 4.57 で +0.82 pt 低下。ただし **k<1 は Permuted MNIST の外側**なので V9 の「幹は幅」への反証としては読めない。
- **e2 は 4 データ目でも生存**: 10 セルで Spearman(e2, ρ) = +0.915（D² とは +0.939）。

## 限界
spec §6 で宣言したとおり k は c だけを動かさない（D² が 1.36 → 0.14）。ゲート零交差の読みは事後・未検定（α を振れば検定可）。活性化 2 種・k 5 水準。k=0 は継続学習ではない。
