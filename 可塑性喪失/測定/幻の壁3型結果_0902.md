## 3. `RWw` は「w-WD が弱かった」腕ではない（**本走で一番効いた発見**）

§4.1 は $\lambda_w=10^{-4}$ を「対照が**効かない**側にいてくれないと Xw の 0/10 を幻に帰属できない」という理由で選び、§7.3 (ii) は「`RWw` が 0 なら w-WD が強すぎ」を疑い先に挙げていた。**実測はどちらの想定にも当たらない。**

$\|w\|$ の中央値（**登録外の診断・転記対象ではない**）:

| step | 0 | 500k | 1M | 2M | 3M | 5M |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 実測 | 1.433 | 1.862 | 1.341 | 0.524 | 0.193 | **0.026** |
| 純粋な減衰 $\exp(-\eta\lambda_w t)$ | 1.41 | — | 0.519 | — | 0.070 | 0.0095 |

減衰時定数は $1/(\eta\lambda_w)=10^6$ ステップで、**5M はちょうど 5 時定数**。1M 以降は 1M ごとに $\times0.37\approx e^{-1}$ で進み、**勾配が減衰に対抗しなくなっている**。5M 末尾窓（`verdict.csv` より）: `strict_dead` **1.000**・`submerged` **1.000**・$\|w\|$ **0.0257**・`eval_loss_exact` 1.397・$U=1.0$（9/10 seed）。

P7（登録・verdict 不使用・全ユニット系列の paired Δ）:

| 対比 | `median_M` | `median_B` | `median_s` |
| --- | --- | --- | --- |
| `RWw` − `R` | **+0.3242** [+0.279, +0.367] | **−44.47** [−46.77, −42.71] | **−44.21** [−45.67, −42.49] |

$\|w\|\to0$ で $\mathrm{denom}=\sqrt{w^\top\Sigma w}\to0$ になるため $B=b/\mathrm{denom}$ が発散している。**これは「w-WD が b チャネルを動かした」ではなく「分母が消えた」** —— 正規化量だけで力学を書かない、の実例（[[引用禁止]] C）。

**帰結**: `RWw` は「w-WD 単独では止まらない」の対照として**使えない**。ネットが壊れているので 10/10 は自明である。したがって §4.1 が設計した「Xw の 0/10 を幻に帰属する」論法は、そもそも成立する条件になかった。ただし**幻 6 腕が全部発散したので Xw の 0/10 は 1 つも出ておらず、この論法は使う場面が来なかった**。

## 5. spec 自身の代数も外れた（[[自己項の実在_力場_0902]] へ返す材料）

repo spec §10.1（本走前に記録・予測は据え置いた）はこう検算していた:

- 恒等式 $\nabla_{w_i}=(\lvert F\rvert+\gamma\lvert S\rvert)\bar g+(1-\gamma)\sum_F a_p$ は **[[自己項の実在_力場_0902]] に存在しない**（grep で `gamma` 0 件・`a_p` 0 件・「反転」0 件）。本 spec 初出の未登録の代数である
- 完全沈下ユニット（$\lvert F\rvert=0$）では $\sum_F a_p=0$（空和）なので $\nabla=\gamma\cdot32\,\bar g$。`BL` は $+3.2\,\bar g$（壁と同じ向き＝実測の発散と整合）、**`BLR` は $-3.2\,\bar g$ ＝ 復元ドリフト**
- したがって代数は `BLR` について Issa 側（RESCUES / NEEDS_SPRING）を支持し、Claude の `PHANTOM_DEAF` を否定する

**実測はこの代数も否定した。** 符号を反転させると安定するどころか **2.8–3.4 倍速く壊れる**（`BLR` 411k・`BLQ` 501k 対 `BL` 1,398k）。

**さらに強い否定が `BLP` から出ている。** spec §0 は「µ の壁の力が壁の向こうでも同じ向きに続くため発散した」と書き、`BLP` は**まさにその µ 成分だけを抜いた**腕だった（$w$ の幻勾配から $\hat\mu$ 射影を抜き、$b$ の幻勾配は 0）。前提が正しければ止まるはずが、**1.09M で発散し `BL` の 1.40M より早い**。

→ **µ チャネルの壁の力は発散の駆動源ではない。** 抜いても止まらず、反転すると悪化する。残る候補は揺らぎ項 $\sum_F a_p$ の側か、$v_i$ 凍結によるゲイン正帰還（親走の診断走 [[順逆分離2x2結果_0902]] §2.2 で見えたラチェット）。

$a_Q$ が $a$ の 1/10 なのに `BLQ` の発散が `BLR` とほぼ同時（501k 対 411k）だったことも効く。浅い側の押し戻しの強さでは説明がつかない（$\lvert\gamma_{BLQ}\rvert$ が $\lvert\gamma_{BLR}\rvert$ を超えるのは $z<-10$）。

## 7. S-refl の降格（**登録の変更**・9/2 Issa 裁定 A）

§6 の **S-refl は登録時「必須」だったが、本走前に REPORT_ONLY へ降格した**（repo spec §10.3 追補 13）。理由は 2 つ: (i) 実装の検査ではなく**本走の主 endpoint と同じ物理の主張**を検査するゲートだった、(ii) 30k では登録された署名（`BLR` の $\bar z$ が `BL` と逆向き）が観測できず、沈下ユニットの定義 3 通り・窓 4 通りのいずれでも符号が反転しなかった。

`registered_expectation_met`: **False**（REPORT_ONLY・本走は止めていない）。実装側のゲートは **19 本すべて PASS**（S-cross・S-limit ×4・S-bwd・S-proj・S-wd-w・S-pair・S-dose・S-taut・S-ref・S6・S-CI）。とくに S-proj の float64 射影残差は **9.5e-18**（登録許容 1e-12）で、`BLP` の射影は設計どおり動いている。

なお S-refl が観測できなかった理由の見当（**µ の向きがタスク境界ごとに回るので $\bar g$ の µ 成分に固定符号が無い**）は、§5 の「µ チャネルは駆動源ではない」と同じ方向を指している。

## 9. ここから（裁定待ち・[[運用ルール]] §3）

起草側の所見:

1. **「幻の壁」の路線は 3 型とも閉じた。** 負側に何を入れても（$+a$・$-a$・$a_Q z$・µ 射影抜き）5M に届かない。**追走するなら幻の形ではなく、[[SUGAR原典照合_0902]] の減衰型（NeLU 型 $2\alpha x/(1+x^2)^2$・深い負側で 0 に戻る）**。本走の 3 型はどれも深い側でゲートが 0 に戻らない（`BLQ` に至っては深いほど強い）
2. **µ チャネル説は `BLP` で否定された。** [[自己項の実在_力場_0902]] §3 に書き戻す材料になる（作業表 #5）。次に疑うのは揺らぎ項か $v_i$ 凍結のゲイン正帰還
3. **$\lambda_w$ の較正が要る。** $1/(\eta\lambda_w)$ を走の長さより十分長く取る（5M なら $\lambda_w \lesssim 10^{-6}$ が目安）。今回の $10^{-4}$ は 5 時定数で、W を溶かす設定だった
4. `RWw` をやり直さないと「w-WD 単独は LoP を止めるか」は未解決のまま残る
