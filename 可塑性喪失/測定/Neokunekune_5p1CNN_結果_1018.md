> **結論**: 実ラベルの 5+1 CIFAR の CNN では、損失ゲート（NEO）は通常の適応 SNA と区別できなかった。課題 1 末で固定した Snake には 1.17 ポイント負けた。登録判定は D1 `INCONCLUSIVE`、D2 `INFERIOR_TO_FREEZE`。ゲートは設計どおり動いていた。この箱の Snake 3 腕は、そもそも可塑性を失っていない。RC CNN で損失ゲートが直した劣化が、ここには最初から無かった。

## 1. 何を問うたか

RC CNN（乱数ラベル）では、損失ゲートが SNA に +1.18 ポイント勝った（[[損失で尺度適応を遅くするSnake_CNN結果_1018]]）。今回はそれを実ラベルの 5+1 CIFAR の CNN へ移した。

- (a) 通常の適応 SNA より再学習が速いか。
- (b) 課題 1 末で固定した Snake に対して、0.5 ポイント幅の非劣性を保つか。

RC 版からの事前指定の変更は、基準損失の窓だけである。hard 課題は約 10 epoch しかないので、「最後の 10 epoch」を「課題 1 の最後の 78 更新（全体の 10%）」に替えた（spec §3.1）。

## 2. 箱と腕

| 項目   | 固定値                                                                              |
| ---- | -------------------------------------------------------------------------------- |
| データ  | CIFAR-100 の fine label、チャネル標準化、augmentation なし                                   |
| 課題列  | 30 課題、奇数が hard（5 クラス × 500 枚）、偶数が easy（1 クラス × 500 枚）、90 クラスを再訪なしで消費             |
| 出力   | 100 次元、課題内の付け直しも出力の mask もなし                                                     |
| 網    | RC CNN（conv 5×5 16 → pool → conv 5×5 16 → pool → fc 100 → fc 100 → 100）、全層に bias |
| 学習   | Adam lr 1e−4、batch 32、780 更新／課題、課題間で重み・Adam・活性化の状態を継続                            |
| seed | 2000〜2009（10 本）                                                                  |
| 計算   | float32、TF32 なし（matmul・畳み込みとも）、決定的アルゴリズム、4 腕を 1 つの束で同じカーネルに通す                    |

| 腕       | 中身                                                                                   |
| ------- | ------------------------------------------------------------------------------------ |
| R       | ReLU                                                                                 |
| SNA     | 通常の適応 Snake。α = clip(0.6/√V, 0.005, 3)、V はバッチ分散の EMA（β = 0.01）                       |
| SNAfrz1 | 課題 1 は SNA。課題 1 の最後の更新の後で α と V を unit・channel ごとに固定                                 |
| NEO     | 課題 1 は SNA。課題 2 以降は V の更新速度を β·g にする。g = min(1, Lref / max(L, 1e−4))、L は更新前のミニバッチ CE |

## 6. 制御と幅（事後の記述・`descriptive_posthoc.json`）

**基準損失**: NEO の Lref は 0.41〜0.79（seed 平均 0.57）で、10 run とも下限 1e−4 に届かなかった。RC 版では全 run が下限に張り付いていた。

**ゲートの形**: hard 課題（課題 3〜29）の NEO の g を、10 更新ごとの区間の平均で並べる。

| 区間（更新） |  1–10 | 11–20 | 21–30 | 41–50 | 71–80 | 91–100 | 191–200 | 391–400 | 771–780 |
| ------ | ----: | ----: | ----: | ----: | ----: | -----: | ------: | ------: | ------: |
| g      | 0.054 | 0.137 | 0.187 | 0.364 | 0.518 |  0.581 |   0.706 |   0.840 |   0.927 |

- 平均の β_eff/β は hard 課題で 0.76、easy 課題で 0.98 だった。
- NEO は「序盤で強く抑え、課題の終わりまでに戻す」型だった。ほぼ固定でも、通常の適応そのままでもない。

**α と実測の幅**（課題 30 末、unit・channel の中央値の seed 平均。幅 s は固定 probe 2,000 枚での前活性の母 SD）:

| site | α: SNA / SNAfrz1 / NEO | 2αs: SNA / SNAfrz1 / NEO | s（課題 2 → 30）: SNA / SNAfrz1 / NEO |
| ---- | ---------------------- | ------------------------ | --------------------------------- |
| c1   | 1.45 / 0.96 / 1.47     | 1.24 / 0.96 / 1.24       | 0.58→0.44 / 0.58→0.46 / 0.58→0.44 |
| c2   | 0.57 / 0.70 / 0.57     | 1.24 / 1.63 / 1.21       | 0.80→1.11 / 0.80→1.17 / 0.80→1.10 |
| f1   | 0.26 / 0.38 / 0.28     | 1.45 / 2.10 / 1.44       | 1.30→2.86 / 1.40→2.78 / 1.30→2.71 |
| f2   | 0.31 / 0.43 / 0.33     | 1.47 / 2.00 / 1.44       | 1.10→2.43 / 1.21→2.33 / 1.10→2.33 |

- fc の幅は Snake 3 腕とも課題 2 → 30 で約 1.9〜2.2 倍に伸びた（固定腕が 1.9〜2.0 倍で最も小さい）。課題 30 末の幅そのものは 3 腕でほぼ同じである。
- NEO の α は SNA に遅れて追いつき、課題 30 末ではほぼ同じ値だった。
- 固定腕だけ、伸びた幅に対して α が据え置かれる。その結果 fc の 2αs が 2 前後まで育つ。
- **読み（事後・未検証）**: 固定腕が勝つのは、幅が伸びて 2αs が育ち、ゲートの谷が「洗われる」からかもしれない。これは RC CNN の [[適応SnakeがCNNで固定αに負ける原因_結果_1009]] で見た向き（課題 1 末の凍結は W の成長で 2αW が育つから効く）と同じである。NEO は α を遅れて追うだけなので、2αs は SNA と同じ 1.2〜1.5 に留まる。

## 7. 言えること・言えないこと

**言える**: この固定設定（lr 1e−4、30 課題、10 seed）の実ラベル 5+1 CIFAR の CNN で、損失ゲートは通常の適応 SNA への改善を検出できなかった。課題 1 末固定に対しては、登録した 0.5 ポイント幅の非劣性を満たさず、固定が 1.17 ポイント上だった。

**言えない**:
- 「損失ゲートは実ラベルでは無効」という一般化。lr・箱・課題数・seed の範囲の外は測っていない。
- NEO と SNA が「同等」。同等性の検定は登録していない。
- 既存手法に対する順位。共通の lr 1e−4 だけで、手法ごとの較正をしていない。
- RC 版の機構の否定。この箱には RC 版で直した劣化が無かった。
- §6 の「洗われる」読みは、介入で確かめていない。

## 8. 次

Codex から、追加 8 腕で計 12 腕にする案が出た（Issa 経由）。中身は固定 Snake α 0.6・3、従来 kunekune（KKT1）、ELU、Leaky 0.4、Randomized Smooth-Leaky、ReLU + ReDo、ReLU + L2 Init である。
- 今回の 4 腕は「ゲートの効果」の検証として閉じ、追加腕は「手法としての競争力」の検証として別 spec・別 run id で行う。
- 共通の lr だけでは調整済み手法への優越を言えないので、手法ごとに lr と形を較正 seed で選んでから評価 seed で比べる。較正格子の中心には先行の推奨値を置く。Lillo & Cheney v4 の表 E2（5+1 CIFAR の CNN）は Leaky 0.4・ELU α 3.6・RSL (0.5, 0.5, 0.673, 2.673) で、いずれも lr 1e−3。Kumar ら 2024 の表 4 は L2 Init λ 1e−2・ReDo 周期 1560・閾値 0 で、どちらも lr 1e−3。
- 今回の結果からは、比べる相手の筆頭は NEO ではなく SNAfrz1 になる。spec 案の登録と起動は Issa の判断待ち。
