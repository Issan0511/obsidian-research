## 2. 判定の脚が 1 本しか立っていない

`LOP_ABSENT` の登録条件は「`dU` の CI が 0 を含む」**かつ**「late 未フィット率 < 0.05」。

- 前者: CI は `[-0.00149, 91.94]`。**studentized bootstrap が退化している**（early 未フィット率 ≈ 8.6e-12 で seed 間 SE が 0 に潰れ、t 型 pivot が発散）。0 を含むのは幅が壊れているからであって、効果が無い証拠ではない
- また `dU = 0.00608679` は `late_unfit = 0.00608679` と 8 桁一致する（early ≈ 0 なので）。**`dU` は late 水準の言い換えで独立な情報を持たない**

したがって **`LOP_ABSENT` は実質「late 未フィット率 < 0.05」の一本で決まっている**。トレンドの腕は推論を一切出していない。

**教訓①の 5 例目**（事前登録の判定基準が仮説の一方に依存していると、その一方が崩れたとき基準ごと無意味になる）。今回崩れたのは「未フィット率が 0 から離れている」という暗黙の前提。

### 3.4 seed 分布 — 1 本は既に発症している

L2 の late 未フィット率は seed 間で **2e-14 〜 5.7e-2（14 桁）**。中央値 1.31e-06、平均 0.00609。

- **seed4 は 0.0572 で閾値 0.05 を単独で越えている**（dead 0.827 / alive 17.3 / eff_rank 10.0）
- committed の `late_unfit = 0.00608679` は**ほぼ seed4 単独で作られた数字**

「10 seed 中 1 本が発症済み」が正確な記述。

### 3.5 予測2 は時間で逆転していた

副次スカラー dose = $\|\boldsymbol\mu^{(\ell)}\|/\sqrt{\operatorname{tr}\Sigma^{(\ell)}/d_\ell}$:

| 窓 | 第1層 | 第2層 |
|---|---:|---:|
| early | 11.37 | **12.30** |
| late | 11.80 | **8.50** |

**初期は予測どおり第2層が強く、後期に逆転する。** 中身は $\|\boldsymbol\mu^{(2)}\|$ が 2.780 → 1.906 と縮む一方、$\sigma_{\rm rms}$ は 0.2296 → 0.2277 とほぼ動かないこと。

これは §7-2 に登録した「外れ方の想定」（第1層が凍結すると $\mathbf a^{(1)}$ がゼロに寄って $\boldsymbol\mu^{(2)}$ と $\Sigma^{(2)}$ が同時に縮む）が起きたもので、**しかも非対称**だった — µ だけ縮み、Σ は生存者が支えるので縮まない。

## 4. 予測の帰趨

| # | 予測 | 帰趨 |
|---|---|---|
| 1 | `LOP_PRESENT` | **外れ**（ただし §2 のとおり判定の脚は 1 本） |
| 2 | 第2層の M > 第1層 | **登録比較（最終タスク末尾）では外れ**。early 窓では当たり、時間で逆転（§3.5） |
| 3 | 第2層の M は増える | **判定不能**（符号の指定漏れ ＋ CI 退化） |
| 4 | 外れたら $\Sigma^{(2)}$ の退化を第一に疑う | **その容疑者は棄却**（NA = 0）。実装差も S0 PASS で棄却 |

§7-4 の順に潰すと、(第一) $\Sigma^{(2)}$ 退化 → 棄却、(a) 第1層凍結による $\mathbf a^{(1)}$ 消失 → **部分的に起きている**（§3.5 の µ 縮小はこれ）、(b) 実装差 → 棄却。**「3 つ全部空振りなら µ 考察 §3 を疑う」には至っていない**（(a) が生きているため）。

## 5. 現時点の読みと、その格

**読み（仮説・未検証）**: 深さ2 では死の進行が遅く、生存者数が必要ランクを割る手前で 1M step が尽きた。壁が無いのではなく、まだ届いていない。

- 支持: 死は 0.65 まで進行中で頭打ちしていない、$M$ は深まり続けている、alive↔未フィット率の関係が深さ非依存に見える（§3.3）、seed4 は既に閾値超え（§3.4）
- **競合仮説**: 深さではなく**容量・表現力**が効いている。深さ2 は補間点に達しており（§3.1）、幅を広げた深さ1 でも同じことが起きるかもしれない。**本走ではこの 2 つを分離していない**
- 未検証。[[多層Phase0b_spec_0829]] がこの分離とホライズン延長を担う
