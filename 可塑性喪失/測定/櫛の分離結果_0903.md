## 5. `CB1f` の軌跡 —— 厳密補間から ReLU 水準への崩壊

`CB1f` は **1M で ReLU より 9.20 dex 低い**（P3′ 1M −9.200 [−10.730, −7.818]・10:0）のに、5M では ReLU と区別できない（+0.125）。途中経過は

- $k^\ast$ 中央値 **304**・横断 **10/10**・横断していた窓の割合 **0.401**・$U^{(10)}_{500}$ **0.631**
- 末尾窓の深さ中央値 **8.236**（井戸 $\pi$=3.14 のはるか先）・`at_well` **0.0025**
- **`frozen_abs` 0.977** —— ユニット記録の 97.7% が $\mathbb E_x\lvert\varphi'\rvert<10^{-6}$

**井戸はユニットを留めない。** `CB1f` の沈下ユニットは葉を出て、その先の平坦域で ReLU と同じように凍った。[[櫛の分離_spec_0903]] §7.2 (ii) が想定した「`CB1f` が 0/10 → 沈下ユニットが葉の中に留まっている」の**逆**が起きた。

対照的に `CB1l` の `frozen_abs` は **0.000**。葉の先に傾き $a$=0.1 があるだけで、凍結は 1 記録も出ない。

## 7. 段 B —— 深さ 2 で発散

`CB_A1`（`comb_binf`・α=1・幅 [100,100]・第 1 層のみ中心化）は **step 2,091,000（タスク 210 / 500）で seed 2** が非有限。非有限になったのは**両層の $W$・$b$ と読み出し $v$・$c$ の全部**。登録どおり腕ごと停止、部分ログ破棄。**V7 = `INCONCLUSIVE_DIVERGENCE`。深さ 2 について本走は何も言えない。**

**★ 段 A で同じ `comb_binf`（1 層・α=1）は 5M を完走している。** 発散は活性化そのものではなく**深さ 2 との組み合わせ**で出た。config に書いた見込み「負側が有界（$\lvert\varphi\rvert\le1$）なので深さ 2 でも第 2 層入力が発散しない」は**外れた**。

## 8. 錨（Snake）—— 失って、別の軸で取り戻した

### 8-1. 登録走（lr 0.01・α=1）は発散

step 1,000 の最初の probe で **seed 3 だけ**非有限（0.19 秒）。登録どおり当該腕だけ落とした（spec §6「`SN` は発散を許容する腕（錨）」）。**判定腕ではないので V5・V6 に影響しない。**

診断走（判定に不使用）: **step 25 未満で NaN**。step 0 は ‖W‖=44.71 で正常、同じ init の `CB1l` は 400 step 後も ‖W‖=44.20 で安定。活性化は S-fd 2.2e−9・S-num $[-200,200]$・恒等極限とも PASS なので、**実装の誤りではなく登録設定での学習発散**。

### 8-2. なぜ強かったか（step 0 の利得・**事後・診断**）

| 活性化                     | 平均 $\varphi'$ | $E[\varphi^2]/E[z^2]$ |
| ----------------------- | ------------- | --------------------- |
| `relu`                  | 0.449         | 0.405                 |
| `leaky_relu` (0.1)      | 0.504         | 0.411                 |
| `elu`                   | 0.713         | 0.561                 |
| `comb_binf` / `comb1_*` | 0.693         | 0.569                 |
| **`snake`**             | **0.956**     | **1.181**             |

**Snake だけ前向き比が 1 を超える。** ReLU 系は入ってきた分散の 6 割を捨てているが、Snake は捨てない。`kaiming_mlp_params` の `sqrt(6/d)` は **gain √2 を織り込んだ ReLU 用**の目盛りなので、「半分死ぬ」前提の init に「何も捨てない活性化」を載せたことになる。後ろ向きも ReLU の 2.13 倍。**ゲートは非線形性だけでなく安定余裕も買っていた。**

### 8-3. lr の梯子（**未登録診断**・100k step ＝ タスク 10 個）

lr 0.01 で 1/10 が非有限、**0.007 / 0.005 / 0.002 はいずれも 0/10 で通過**。生き残った seed の ‖W‖ は 14.4 → 16.0 で、同じ lr 0.01 の `CB1l`（14.4 → 17.6）より穏やか。**「壊れている」のではなく「登録 lr が Snake には僅かに大きい」。**

lr 0.005・α=1 で 5M 完走（診断 A）: 発症 **0/10**・横断 **0/10**・`frozen_abs` **0.0**・median log₁₀U (5M) −11.82。**ただし `EXACT_FIT` が立つ**（1M 窓 2.14e−11）ので `CB_a1` と同じ交絡に戻る。**lr が違うので水準の比較には使わない。**

### 8-4. ★ `act_alpha` の梯子 —— 登録 α=1 が最悪点だった（**未登録診断**）

$\varphi'=1+\sin(2\alpha z)$ の値域は $[0,2]$ で **$\alpha$ に依らない**。動くのは前向きで、足す項の振幅が $1/\alpha$ なので **$\alpha=1$ がちょうど山の頂上**。

| $\alpha$              | 0.1   | 0.3   | **1**     | 3     | 10    | 30    |
| --------------------- | ----- | ----- | --------- | ----- | ----- | ----- |
| $E[\varphi^2]/E[z^2]$ | 1.040 | 1.230 | **1.352** | 1.051 | 1.007 | 1.001 |
| 100k step の非有限        | 0/10  | 0/10  | **1/10**  | 0/10  | 0/10  | 0/10  |

**登録した $\alpha$=1 は安定性の梯子の最悪点だった。** lr を触るより **dial を振るほうが筋**である（`act_alpha` は既存の腕フィールドで、`LR_a0p01` 対 `LR_1216` と同じ格の操作）。

### 8-6. ★ ユニットは漣のどこに居たか —— $\alpha$=1 は自前のゲートを作り、$\alpha$=3 は作れない（**事後・未登録・引用不可**）

$\varphi(z)=z+\sin^2(\alpha z)/\alpha$、$\varphi'(z)=1+\sin(2\alpha z)$。

> **★ 周期の取り違えに注意。** $\sin^2(\alpha z)=\tfrac{1-\cos(2\alpha z)}{2}$ なので、**漣の周期は $\sin(\alpha z)$ の $2\pi/\alpha$ ではなく半分の $T=\pi/\alpha$** である（$\varphi$ も $\varphi'$ も同じ $T$）。$\alpha$=3 で $T$=1.047、$\alpha$=1 で $T$=3.142。**$2\pi/\alpha$ で割ると下の span/$T$ が半分になり、結論が逆になる。**

位相は $\theta:=(2\alpha\bar z)\bmod 2\pi$ で測る（$\varphi'=1+\sin\theta$。谷は $\theta=3\pi/2$ で $\varphi'=0$、山は $\theta=\pi/2$ で $\varphi'=2$）。末尾窓・10 seed・10,000 ユニット記録。

|                                           | $\alpha$=1（lr 0.005）            | **$\alpha$=3（lr 0.01）**   |
| ----------------------------------------- | ------------------------------- | ------------------------- |
| 周期 $T=\pi/\alpha$                         | 3.142                           | 1.047                     |
| span 中央値                                  | 2.045                           | 1.406                     |
| **span / $T$**                            | **0.651**                       | **1.343**                 |
| span > $T$ の割合                            | 0.219                           | **0.936**                 |
| $\mathbb E_x[\varphi']$ 中央値               | **0.634**（5–95% [0.135, 1.099]） | **0.998**（[0.860, 1.056]） |
| $\lvert\mathbb E_x[\varphi']-1\rvert$ 中央値 | 0.372                           | **0.0147**                |

**$\alpha$=3 では 93.6% のユニットが 1 周期より広い支持を持つ**ので、各ユニットは漣を丸ごとまたいで平均してしまい、**位相が定義できない**。$\mathbb E_x[\varphi']$ は全ユニットで 1 に張り付く。位相ヒストグラムもほぼ平坦（$0$–$\pi/2$ 0.218／$\pi/2$–$\pi$ 0.170／$\pi$–$3\pi/2$ 0.269／$3\pi/2$–$2\pi$ 0.344）。

**$\alpha$=1 は逆で、78% が 1 周期未満**——位相が意味を持ち、しかも**谷に偏る**。

| 位相 4 分割（$\alpha$=1・末尾窓）       | 割合        |
| ----------------------------- | --------- |
| $0$–$\pi/2$（$\varphi'$ が 1→2） | 0.089     |
| $\pi/2$–$\pi$（2→1）            | 0.048     |
| $\pi$–$3\pi/2$（1→0）           | 0.288     |
| **$3\pi/2$–$2\pi$（0→1）**      | **0.575** |

$\varphi'<1$ の下半分（$\pi$〜$2\pi$）に **86.3%**。**しかも学習で深まる**:

| 窓           | $\varphi'(\bar z)$ 中央値（$\alpha$=1） | $\varphi'(\bar z)<0.5$ の割合 | $\alpha$=3 の $\varphi'(\bar z)$ 中央値 |
| ----------- | ---------------------------------- | -------------------------- | ----------------------------------- |
| early（2–11） | 0.411                              | 0.548                      | 0.757                               |
| 1M（91–100）  | 0.294                              | 0.636                      | 0.757                               |
| 末尾（491–500） | **0.250**                          | 0.684                      | 0.739                               |

**何周目か**: 両者とも $-1$ 周目（$\bar z\in[-T,0)$）に集中（$\alpha$=1 で 88.8%、$\alpha$=3 で 69.7%）。原点のすぐ下、漣 1 つぶん沈んだところで、遠くへは行っていない。

**読み（事後・登録の外）**: 初期は $\alpha$ に依らず平均 $\varphi'\approx1.00$（§8-2）なのに、**$\alpha$=1 のネットワークは自分で漣の低利得の位相へ降りていき、その場の利得を 1 → 0.25 まで落とす**。$\mathbb E_x[\varphi']$ が 0.634 で止まるのは支持が 0.65 周期ぶん広いためで、**この値は ReLU の 0.449・leaky の 0.504 とそう遠くない**（§8-2）。壁を持たない活性化が**自前のゲートを作っている**ように見える。

対して **$\alpha$=3 は支持が周期より広いので、どこへ動いても利得が 1 から動かない**（$\mathbb E_x[\varphi']$ が early から末尾まで 0.997 → 0.998）。ゲートを作る自由度が無い。**それでも LoP を出さず、$U$ を $4\times10^{-5}$ まで下げた**（§8-5）。

§8-2 の「ゲートは減衰も買っていた」の続きになる —— **減衰は活性化が与えるとは限らず、ネットワークが位相を選んで自作することもある。ただし自作できるのは支持が周期を分解できるときだけ。** これは登録された量ではなく、**格を上げるなら別に登録すること**（$\varphi'(\bar z)$ も位相も本走の登録集計に無い量である）。

## 11. 事前登録 spec の字義訂正

[[運用ルール]] §2 により事前登録済みの spec 本文は書き換えないので、ここに記録する（repo 側 `specs/spec_comb_isolate_0903.md` §10 にも入れてある）。

1. **S-limit の区間。** spec §6 は「`comb1_*` は $z\ge-\pi$ で `comb_binf` と bit 一致」と書くが、**閉区間では成り立たない**。float64 で $\sin(-\pi)=-1.2246\times10^{-16}$ なので `comb_binf` は端点で $\varphi=-1.4998\times10^{-32}$・$\varphi'=-2.4493\times10^{-16}$ を返す。**一致は開区間 $(-\pi,\infty)$ で見る**（端点は測度 0・S-fd も折れ目 $\pm10^{-3}$ を除外している）
2. **`snake` の S-limit の $\alpha$。** spec は「$\alpha\to$ 極小」で数値を書いていない。$\lvert z\rvert\le30$ で相対 1e−4 を満たすには $\alpha\le3\times10^{-6}$ が要る（1e−3 では 3.0e−2）。**登録値を $\alpha=10^{-6}$・相対許容 1e−4 とした**
3. **S-dial の井戸の定義。** `weird_act_0903._s_dial` の極小探索は `comb1_flat` に使えない（葉の端より深い側で $\varphi^2\equiv0$ なので狭義の極小が無い）。spec §2 の定義（葉の端 ＝ $\varphi$ の負側の零点）で照合し、$\varphi'=0$ かは REPORT に落とした
4. **深さ 2 の見込み。** config のコメント「負側が有界なので深さ 2 でも第 2 層入力が発散しない見込み」は**外れた**（§7）
5. **`SN` の安定性。** spec は `SN` を「発散を許容する腕」としか書いていないが、**発散するのは $\alpha$=1 という登録値の選び方のため**であって Snake 一般の性質ではない（§8-4）
6. `band_leaky_dpi` は新しい分岐を書かずに `BAND_WIDTH` の 1 エントリだけで通る（追補として実装に反映済み）
