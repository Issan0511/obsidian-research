## 2. 事後・未登録 — 操作チェックの機構を読み違えていた

§0 で読んだ 3 腕の範囲で、**E0 の閾値の根拠にした機械的予測が間違っていた**ことが分かる。記録として先に書く（予測の採点は spec §5 のまま、外れとして残す）。

**spec §5 の予測**: ノイズは $\hat v\to\hat v(1+c^2)$ にするので正規化後の歩幅 κ2 は $1/(1+c^2)$ 倍、つまり κ2(N2)/κ2(N0) ≈ 0.45。

**実測（N0 / N05 / N1・seed 中央値）**: κ2 = 0.0623 / 0.0597 / 0.0570。c=1 でも **8.5% しか落ちない**。

**なぜか**: ノイズは $\hat v$ だけでなく $\hat m$ にも入る。$\hat m$ は $\beta_1=0.9$ の EMA なのでノイズは約 10 歩ぶん平均されるが消えはせず、分散の寄与は $\frac{1-\beta_1}{1+\beta_1}c^2\sigma^2 = 0.053\,c^2\sigma^2$ 残る。したがって
$$\frac{\kappa_2(c)}{\kappa_2(0)}\;\approx\;\frac{\kappa_2(0)+0.053\,c^2}{\kappa_2(0)\,(1+c^2)}$$
$\kappa_2(0)=0.062$ を入れると c=0.5 で 0.97、c=1 で 0.92、c=2 で 0.88。実測の 0.96 / 0.92 と合う。**私の予測が外れた原因は、分母の膨張だけを数えて分子の膨張を数えなかったこと。**

**これ自体が 1 つの所見**: $\kappa_2(0)=0.062$ は $\hat m/\sqrt{\hat v}$ の RMS が **0.25** ということで、**第 1 層の勾配はもともと歩ごとにほとんど揃っていない**。だから外からノイズを足しても歩幅は動かない。動くのは**向き**のほうで、タスク内の経路持続 ρ は 51.9 / 46.7 / 38.2 と **c=1 で 26% 落ちている**。

**実験としては、これはむしろ都合がよい**（事後の読み）: 歩幅がほぼ動かないまま向きだけが乱れるので、§3 の E5（揃いか歩幅か）で分けたかった 2 つが、ノイズ自身によってほぼ分離されている。ただし**登録した E0 は κ2 で書いてあるので、ラベルは登録どおりに落とす。** ρ を操作チェックに使う版は、この開示のあとに書いた事後の読みであり、登録判定として引かない。
