## 結論

1. **切替の後の沈みは、読み出しの整列でなく大きさで決まる。** 各ユニットの読み出しの成分をクラスの間で入れ替えて整列だけを壊しても（ノルムは同じ）、200 更新で沈むユニットの割合は変わらなかった（整列が要る割合 ρ_align −0.05〜0.12）[実測・10 seed]。向きを保って大きさだけ初期化の時点へ縮めると、沈みの 37〜85% が消えた [実測]。保存状態の事後の計算（一歩の期待の勾配）と同じ向きで、学習の動きでも成り立った。
2. **喪失も、読み出しの大きさを毎回戻すと消える。** 全ての切替で出力層を 0 にする・初期化し直す・初期化のノルムへ縮める軌道は、5 活性化とも課題 21〜30 の不足を 2〜31% に減らした [実測]。整列だけを毎回壊す軌道は 74〜104% を残した [実測]。
3. **隠れ層の Adam の状態だけでは、沈みも喪失も説明できない。** 隠れ層の Adam の状態だけを捨てても、不足はほぼ減らなかった（一回の切替で −5〜+3%、毎回でも 70〜104% が残る）[実測]。V13 の付録 D.6 の H0A（不足が消える）は、出力層を 0 にすることとの組み合わせだった。
4. **SGD でも沈みは起きる。喪失は活性化で分かれる。** 学習率を較正した SGD では、5 活性化とも切替の後に 74〜99% のユニットが沈み、整列はここでも要らなかった [実測]。課題 21〜30 の不足は ReLU 0.20・ELU 0.28 で、leaky ReLU・SiLU・GELU には無かった [実測]。
5. **課題 1 の途中では、整列が一歩の期待の押しを運ぶが、実の沈みはそれほど変わらない。** 訓練精度 20〜50% の時点で整列を壊すと、一歩の期待の押しは 0.07〜0.42 倍になったが、200 更新で沈む割合は 6〜18 ポイントしか下がらなかった [実測・2 seed]。

## 1 何をしたか

箱は `push_direction_proof_0930/gen_states.py` の engine（784-100-10・乱数ラベル MNIST 1,200 枚・Adam 1e-3・batch 16・4,000 更新/課題・30 課題）。5 活性化 × seed 0〜9。本線は保存済みの 2 seed と全 30 課題で bit 一致した。

**一回の切替の腕（課題 t の頭で一度だけ介入し、課題 t を回す）**

| 腕 | 介入 |
|---|---|
| P0 | 全ユニットで同じクラスの並べ替え（ラベルの付け替えと同じ・帰無） |
| P | ユニットごとに独立なクラスの並べ替え（整列だけ壊す・大きさは同じ） |
| Q | 向きを保って大きさを初期化の時点へ縮める |
| R | 出力層を初期化し直す |
| H0 | 出力層を 0 にする（出力層の Adam も捨てる） |
| A0 | 隠れ層の Adam の状態だけ捨てる |
| F200 | 最初の 200 更新は隠れ層を動かさない |

**毎回の介入の軌道（T）**: 同じ介入を全ての切替で施しながら 30 課題を回す（H0all・Qall・Rall・Pall・A0all・F200all）。

**最適化器**: 既定の Adam（B1）・SGD（B2。学習率を 30 課題の平均精度で較正: leaky ReLU 0.3・ReLU 0.01・ELU 0.03・SiLU 0.01・GELU 0.01。ReLU・SiLU・GELU は格子の端）・Lyle ら 2023 の Adam（β2 = 0.9・内側の ε = 1e-3、B3）。

## 6 V13 への含意 [提案・Issa の判断待ち]

- 段 ① は「学んだ整列が源」より「課題を重ねて育つ読み出しの大きさが源」と書くほうが、測った物に合う。整列は補題 1 の下界と命題 1 の模型の中の量として残る。
- 喪失の介入として、「切替ごとに読み出しの大きさを初期化の時点へ戻す」（Qall）が、この箱では出力層を 0 にするのと同じだけ効いた。手法としての比べ（L2 Init など）はしていない。
- 隠れ層の Adam の状態による説明（Lyle 2023）は、この箱では喪失の担い手でない。ただし Lyle の Adam は喪失を一部減らした。
- 限り: 一隠れ層・乱数ラベル MNIST の一つの箱。CNN・実ラベル・Kumar らの列では回していない。
