### 2.5 読み（記述・登録外）

- 死 l2 は .342 から .399 で、減らない。
- 読み: ReLU の閉じ方は、0 より下かどうか（符号）だけで決まり、深さによらない。bias を除けば、上限が縮めるのは z̄ と sd の両方で、開いた入力の数を決める r は動かない。

## 8. V12 への意味（柱ごと）

1. **μ の配置と中心化**: 3 箱で登録になった（RL-CIFAR は `relu_doors_0919`・`relu_doors_h_ref_0920`、5+1 は `cifar5p1_mlp_0920` 追補 4、RL-MNIST は `doors_rlmnist_1007`）。平均を除くレバーは 3 箱とも効いた。どの扉で足りるかは箱で違う（RL-CIFAR raw ReLU は CH、5+1 std ReLU は H、RL-MNIST ELU は H で `RESCUED`・水準には CH）。「先に沈む層で決まる」は読み（§5.9）。RL-MNIST の H・CH は 100 課題の終わりでもまだ下がっており、bias（b₂）が残りの経路になった。
2. **駆動源の向き**: 3 箱で登録になった（RL-CIFAR は A2、5+1 は `drive_cifar5p1_1007`、RL-MNIST は `drive_rlmnist_1007`）。
   - 共通 1: 上流（入力の平均の変化）が、第 2 層を沈める側に運ぶ。U の総和は 3 箱とも 5/5 負（A2、5+1 の D2 `UPSTREAM_DOWN`、RL-MNIST の M4x）。
   - 共通 2: 自己の押しは切替直後に集中する。RL-CIFAR（A2 の M3x）と RL-MNIST（M3x）で `BOUNDARY_ENRICHED` を登録した。5+1 は、切替直後の bin 1 で S が 5/5・両種で負という記述（D1 は窓が無く `NOT_JUDGED`）。
   - 箱で逆: 課題全体の頻度の主ラベル（RL-CIFAR C 腕 ReLU は `NOT_SUPPORTED`、RL-MNIST ELU は `HOLDS`）。5+1 は旧ラベルが無く、この条件を定義できない。
   - 撤回: 5+1 の「easy 課題が第 2 層を殺す」は、課題の中の移動としては支持されない（D3 `HARD_SINKS` 5/5）。
   - 量の注（記述）: 「上流が運ぶ」を量で言えるのは 5+1（Δm 総和のほぼ全部が U）。RL-MNIST の課題 2–5 では S が U の 2.6〜32 倍で、U が S を上回るのは課題 6–10（REPORT_ONLY）。本文で量を言うときは箱を限る。
3. **W 増大 → 進行**: 重みの伸びが進行に効くのは、深さで応答が細る ELU の経路（ユニットの死を待たない機能低下）として 2 箱で登録した（`RESCUED`: RL-CIFAR の S5 `cap_cifar_ee_0920` cap12、RL-MNIST の `l2cap_ee_0917` cap12）。符号で死ぬ ReLU では、上限は相対位置を変えず、効かない。これは 5+1 で登録した（陰性。cap12 `WORSE`・cap2 `NO_EFFECT`。相対位置が −1.49〜−1.58 で変わらないことは記述）。RL-MNIST でも、別の形の上限（ユニット別の中心化ノルムを初期値の 2 倍で止める）は効かなかった（`wcap_rlmnist_0914` の R cap2 `SIZE_NOT_LEVER`。ただし操作が task 1 で第 1 層の 57% を殺しており、副作用の可能性がある）。違いは、ラベルの種類ではなく活性化として書く。読み: 理論の「沈みの深さ = 相対位置 × 幅」で読むと、ReLU の機能は相対位置（開閉）だけで決まり、ELU の機能は深さでも細る。違いは訓練の勾配が止まる場所で、ReLU は 0 を下回った所、ELU は float32 の限界の深さ。事後集計（1008）: 5+1 ReLU の全画像で閉じたユニットの自己移動は開いたユニットの 0.9〜4.7%、MNIST ELU は 37%。MNIST ELU の ref は、全画像で微分が 0 のユニットが出る前（課題 7 まで 0）に適合率が半分を割った（課題 7）。V12 §5（vault `70b4537`）。5+1 の上限なしの ELU 腕は、重みが ReLU 以上に伸びたが、相対位置は −0.54 で、喪失はほぼ無い（fresh gap +.010・事後）。ELU が浅く留まる理由は未調査。
4. **活性化 → 応答**: 既に 3 箱で登録（変更なし）。
5. **応答 → 再学習能力**: 3 箱で `RESPONSE_BOTH_WAYS`（RL-CIFAR は S4 `resp_cifar_ee_0920`、RL-MNIST は `resp_ee_0917`、5+1 は `resp_cifar5p1_1007`）。復元と沈降の大きさの比は、箱で違う（記述）。5+1 は復元 +21.3 pt・沈降 +6.0 pt（ρ1 .91・ρ2 .22）。RL-MNIST は +76 / +26 pt（ρ1 1.18・ρ2 .47）。RL-CIFAR は +47 / +68 pt（ρ1 .57・ρ2 .78）。どの箱も P1 は Adam 継続同士、P2 は reset 同士で条件が違うので、この比は登録した非対称ではない。

要旨の「各接続を三設定すべてで検証したとは主張しない」を置き換える文案（3 文）:

> 主な対象は二隠れ層 MLP・Adam の三つの課題設定であり、五つの接続はいずれも三設定すべてで事前登録の走を持つ。ただし重みの成長が進行を運ぶことは ELU の二設定に限られ、実ラベルの ReLU では成長の上限は喪失を減らさなかった。活性化・入力の前処理・層は設定ごとに異なり、駆動源の向きの課題全体での主ラベルは乱数ラベルの二箱で逆である。
