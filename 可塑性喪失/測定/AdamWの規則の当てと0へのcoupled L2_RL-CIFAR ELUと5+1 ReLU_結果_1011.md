## 0. 何を測ったか

- **A1（主）**: RL-CIFAR × ELU→ELU・std（cap_cifar_ee_0920 の箱。3072–100–100–10・native `F.elu`・Adam 1e−3・batch 16・30,000 更新/課題・50 課題・seed 0–9 を R = 10 で束ねる）。AdamW（decoupled、全 6 テンソル。各更新で θ を fl₃₂(1 − ηλ) 倍してから宿主の Adam の 1 歩）を、cap_cifar_ee の task 1 の共通の接頭部から分岐して task 2 から入れた。λ = 0.03・0.1・1（τ = 1.11・0.33・0.033 課題）。ref は cap_cifar_ee の記録を再利用した（λ = 0 の経路が task 1–10 で bit 一致: S0）。
- **規則**（`analysis/adamw_dose2_1011/rule.py`、spec と同じ commit で登録）: 止まる第 2 層の幅 s2 = κ1κ2·ρ1·f·‖w1‖*‖w2‖*（‖w‖* は回転平衡 η√(d/2(1 − c))、κ 1.6〜2.3 は P180 の観測、ρ1 4.48〜9.61・f 0.67〜1.16 は cap_cifar_ee の記録）、深さ m = r·s2（r −1.85〜−1.95 は無介入の ref の値）を訓練の微分の零点と比べる。λ は、規則が「救わない（幅は止まるが深い）」「際どい」「救う」を 1 つずつ出すように選んだ。二値の当ては 0.03 FAIL・0.1 FAIL・1 SAVE。
- **この箱の零点は −103.97**: native `F.elu` の負側の微分は e^z で、float32 で厳密に 0 になるのは z < ln 2⁻¹⁵⁰ = −103.97 だけ（起動の直前に CUDA で実測して launch_record に記録）。P180 の −16.64 は MNIST の宿主の「出力 + 1」形の微分の零点で、この箱には当てはまらない。Z は e^z の零率で、上流の dy を掛けた dy·e^z の零率ではない（dy = 10⁻⁴ なら零点は −94.76）。出力が −1 に貼り付く線は −16.98（CUDA）。
- **判定**: λ ごとのラベルは cap_cifar_ee の登録規則（主窓 t31–50、E1 は online、E2 は第 2 層の訓練の微分）。主判定 RULE_PREDICTED は、当て SAVE と「救った」（RESCUED かつ ¬IMPAIRED_EARLY）の一致の数（3/3 HOLDS・2/3 PARTIAL・≤1 FAILS）。副判定 RULE_DEPTH は DEPTH_ABOVE_LINE の側の一致の数。「規則が立った」と書けるのは、機能が 3/3 一致し、救った λ で DEPTH_ABOVE_LINE が真のときだけ（§14.1。Codex の監査の後に親の指示で直した定義）。
- **A2**: 5+1 CIFAR × MLP × ReLU（std・Adam 1e−4・30 課題 × 780 更新・seed 0–9）。coupled L2（勾配に 2λθ を足して Adam に通す・0 へ・全 6 テンソル。宿主の `iv='l2'` と同じ演算）を λ = 10⁻²（L2 Init と同じ λ、主）と 5×10⁻³。2×2 で見ると、L2 Init は（初期値へ, coupled）、P180 の AdamW は（0 へ, decoupled）、本走は（0 へ, coupled）。読みは回復の割合 ρ = (W − R)/(L2 Init − R) の 95% 区間で決める: ≥ 3/4 なら NORM_MATTERS（Adam の正規化を通すことが効く）、≤ 1/4 なら TARGET_MATTERS（引く先が効く）、間なら BOTH、帯の境をまたげば READING_UNRESOLVED（§14.3）。R と L2 Init は committed の記録を bit 照合して再利用した。
- 検査は 17 項目すべて PASS で、列挙した変異 48/48 を検出した（`14d42ef8`）。変異対照: 読み出しだけの WD（λ = 1、seed 100）は隠れ層の幅を止めなかった（task 4 の s1 102・s2 306。ref は 115・282、全テンソルの WD は 6.3・1.25。S-ctrl）。L2 を Adam の後に足す形は decoupled と丸めの帯の中で一致し（最悪比 0.27）、coupled は要素の 99.99% で帯の外だった（S-mut）。

## 2. 読み

- **救う λ を走る前に規則で当てることは、この箱ではできなかった（`RULE_FAILS`）。** 規則は 0.03 と 0.1 を「救わない」としたが、3 水準とも救った。V12 に「救う λ は走る前に当てられる」とは書けない。
- **外れたのは、規則に外から持ち込んだ 2 つの因子。** 止まった第 2 層の幅 s2 は 26.1・8.1・1.3 で、規則の帯の浅い端（70.7・21.2・2.1）の 0.37〜0.62 倍だった。(a) 行ノルムは回転平衡の ×0.78〜1.48 で、P180（MNIST、6,000 更新/課題）の ×1.6〜2.3 より内側に留まった。(b) WD の下の第 2 層の相対位置 r2 は −1.09・−0.56・+1.51 で、規則が使った無介入の ref の −1.85〜−1.95 よりずっと浅い（λ = 1 では第 2 層の対の 93% が開く）。ρ1（4.6〜5.2）と f（0.64〜0.83）は帯の中か、その近く。実測の s2 と r2 を同じ式に入れると、深さ m = −28.5・−4.6・+1.9 はどれも零点の上で、Φ(z₀/s2 − r) ≈ 0.002・0・0（実測 Z 0.023・8×10⁻⁶・0）。深さと零点を結ぶ算術はこの 3 腕で合い、外れたのは外挿した入力（κ と r）である。事前の警告は検査 S-ctrl にあった（λ = 1 の s2 1.25 が帯の下。spec §14.5 で開示し、当ては変えなかった）。
- **言えること**: この箱で AdamW（全 6 テンソル・task 2 から）は、試した λ = 0.03〜1（τ ≤ 1.1 課題）のすべてで崩壊を防いだ。主窓で online は下がらず（課題 10 → 50 で 0.902 → 0.911・0.948 → 0.948・0.866 → 0.866）、幅は止まり、戻りの事象は無い。救った 3 腕とも、止まった深さは零点の上だった。これは「零点より上で止まれば救う」と矛盾しないが、零点の下で止まった腕がこの走に無いので、逆向き（下で止まれば救わない）は試せていない。λ = 0.03 は cap12 に近い所に止まった（行ノルム 5.6・1.1 対 3.67・1.01、s2 26 対 14、r2 −1.09 対 −1.09、online 0.904 対 0.860）。
- **箱の違いは、規則が言った向きと逆に出た**（報告の格）。規則は「CIFAR は射影の広がりが大きいので MNIST より大きな λ が要る」と言った（MNIST で救ったのは 0.1 だけ）。実際は CIFAR では 0.03 でも救った。違いを生んだのは r2 と κ で、どちらも走る前には分からなかった。
- **用量の頂点**: λ = 1 では第 2 層がほぼ線形になり（r2 +1.5、局所微分の平均 G2 0.97）、水準が 0.08 下がった（`DOSE_PEAKED`）。
- **報告のみ**: λ = 0.03 では、第 2 層の対の 64%（主窓）が出力の線 −16.98 の下（出力が −1 に貼り付く）にいながら、online 0.90 で学んだ（cap12 と同じ）。この箱では、その線は救う・救わないを分けなかった。
- **A2: 0 への coupled L2 は第 2 層の死を全部消したが、水準は R のままだった。** 死 l2 0.342 → 0（両腕 10/10）、開いた対 0.14 → 0.94、相対位置 −1.57 → +1.72。一方で第 2 層の階数 eff_rank は 9.6 → 5.4（10⁻²）・8.4（5×10⁻³）に落ち、W3 の行ノルムは 2.79 → 0.09 に縮んだ。同じ λ・同じ coupled で初期値へ引く L2 Init は 0.656。**この箱の ReLU では、主の λ で効いたのは引く先（初期値）だった**（読み `TARGET_MATTERS`）。Adam の正規化を通して 0 へ引くと、死んだ unit は戻るが水準は戻らない。ReDo が死を消しても後期窓は R から適応 Snake までの差の 43% しか戻さなかった `baselines_cifar5p1_1008`（V12 通し稿の標準手法との比較）と同じ形。λ = 5×10⁻³ は 19% 戻し、読みは決まらなかった。
- 名目の強さで揃えた P180 の AdamW（0 へ・decoupled）よりは良い（+0.087・+0.120、10/10）。ただし揃えは全座標の √v̂ の中央値での名目の対応で、層ごとの実効の強さは違う（W2 で 3.1・1.6 倍、W3 で 62・31 倍。spec §14.6）。「通し方（coupled か decoupled か）の効果」とは言わない。

## 4. 限界

- A1 は RL-CIFAR × ELU→ELU・std・この 3 水準・task 2 からの減衰・50 課題、A2 は 5+1 CIFAR × ReLU/std・λ ∈ {5×10⁻³, 10⁻²} の範囲。SiLU・GELU・他の箱は測っていない。RL-MNIST の ReLU で coupled L2（λ 10⁻³）が時間劣化の 98.9% を除いた結果とは、箱・λ・測り方が違う。
- 規則の外れは「登録した外挿の規則」（κ を MNIST から、r を無介入の ref から持ち込んだもの）の外れで、深さと零点の関係そのものの反証ではない。零点の下で止まった腕が無いので、その関係を支える証拠にもならない（矛盾しないだけ）。WD の下の相対位置 r を導けていないことが穴として残る。
- RESCUED は「この箱の 50 課題で床に落ちなかった」の意味で、無限時間の非崩壊ではない。online は学ぶ速さで、到達点ではない。零点 −103.97 はこの箱の実装（native `F.elu`・CUDA）の性質。
- 釣り合いの式は既知で、新規性は主張しない。V12 本文は未変更。
