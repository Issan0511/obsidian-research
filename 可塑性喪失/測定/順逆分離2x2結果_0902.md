### 2.1 機構（恒等式・登録外の解析）

負側ユニットの $b_i$ への勾配は厳密に 2 つに割れる（$\delta = v_i\sigma_i + G_i$）:

$$g_{b_i} = \underbrace{2v_i^2\,\sigma_i\sigma_i'}_{\text{self（復元力）}} + \underbrace{2v_i\sigma_i'\,G_i}_{\text{rest（駆動）}}$$

| 腕 | $\sigma_i$ | $\sigma_i'$ | self | rest | $g_{v_i}$ | |
| --- | ---: | ---: | ---: | ---: | ---: | --- |
| `R` | 0 | 0 | 0 | 0 | 0 | 凍結。吸収だが**安全** |
| `LR` | $az$ | $a$ | $2v^2a^2z<0$ | ≠0 | ≠0 | 復元力あり。**安全** |
| `BL` | **0** | $a$ | **0** | ≠0 | **0** | **駆動だけ残り減衰が無い** |
| `FL` | $az$ | **0** | 0 | 0 | ≠0 | $w,b$ 凍結。**安全** |

`BL` だけが「rest ≠ 0 かつ self = 0」。しかも `LR` の self は $2v^2a^2z$ で**沈むほど強い復元バネ**なのに対し、`BL` は $\sigma_i \equiv 0$ なのでどれだけ沈んでも self が立たず、rest $=2v_ia G_i$ には $z_i$ が入らないので**深さに依らない一定サイズの駆動が押し返す力ゼロで掛かり続ける**。加えて $g_{v_i}=0$ でゲインが凍結する。

- **$v_i$ は沈下中だけ厳密に凍結** — 沈下区間 225 本での $v$ 変化の中央値は厳密に 0.000e+00。稀に浮上したときだけ更新され、0.096 → −2.72（28 倍）まで育つ**ラチェット**
- **ランダムウォークではなく加速する暴走** — $d\log\|w\|/d\log t$ が区間ごとに 0.94 → 1.25 → 4.26 → 3.00（拘束のない拡散なら 0.5）

## 7. ここから

**裁定待ち（Issa）。** 起草側の所見として:

1. **★穴 1 は半分埋まった。** `FL` ≈ `R`（10/10・水準も区別つかず・固定特徴の $|v|$ も同じ）なので、**出力チャネル単独は担い手ではない**。`LR` が 0/10 で `R` が 10/10 である以上、差は backward 側か順逆の結合にある。ただし `BL` が測れていないので **`GRADIENT_CARRIES` を主張することはできない**（`BOTH_REQUIRED` を排除できていない）
2. **勾配側を測り直すなら定数傾きでは無理。** [[SUGAR原典照合_0902]] が提案する**減衰型代替勾配**（NeLU: $\mathrm{d}/\mathrm{d}x = 2\alpha x/(1+x^2)^2$、深い負側で 0 に戻る）なら、§2.1 の「深さに依らない駆動」が消えるので安定するはず。SUGAR 自身も定数傾き（LeakyReLU 型）は振るわず減衰型が効くと報告している。**追走を起案するかは Issa 判断**（[[運用ルール]] §3）
3. **C4 のスコープを [[現象2主張v1_0901]] に書き戻す必要がある。** `RW` 10/10 は「b-WD による治療」が **2 層・centered 限定**であることの直接証拠。P7c が示すのは「b チャネルの係留は効くが µ チャネルが相殺する」で、機構の説明もついている
4. `channel_2x2_0901` 型の seed 隔離ポリシーへの移行は、**本件では救いにならない**（§2.2）。ただし他の走のために検討する価値はある
