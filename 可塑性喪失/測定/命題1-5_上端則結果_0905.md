## 4. 命題ごとの読み

### 命題 1（線形は対称）— **当たり。しかも 0 に釘付け**

`LIN_1216` 全 1000 ユニット（末尾窓）: median z̄ **−0.0000**、\|z̄\| 中央値 **0.0075**、p95 0.033、**全ユニットが ±0.084 の中**、P(z̄>0) = 0.500、歪度 +0.27（範囲 ±0.08 の分布の歪度は雑音）。‖w‖ 1.42 → 0.46、\|v\| → 0.020。定理どおりの対称に加えて、**線形ユニットは平均を自分で消す**（LIN100 の事後値と同じ）。

`TH_1216`（tanh・奇関数）: 対称（P(z̄>0) 0.529・歪度 −0.07）だが**釘付けではない**: \|z̄\| 中央値 2.65 の二峰（飽和域へ出る）。**0 に釘付けになるのは線形だけ**。

### 命題 2（曲率の反対へ）— **Issa の読み A（初期分布の周りの曲率）が正しかった**

### 命題 3（初期平均に依らない）— **当たり。スケールにも依らない**

| 腕 | 摂動 | 末尾 zmax（参照 0.112） | 登録 | 読み |

| `LRbm5` 15M | b −5 | **0.078〜0.094**（差 0.02〜0.03）・保持率 **0.4%** | `MEAN_DEPENDENT` | 指数フィットの z∞ = −0.094 が参照を外した。実測の高原は +0.08〜0.09（タスク 100/300/500/1500 で 0.026/0.106/0.078/0.094）で、**フィットが初期のオーバーシュートに引かれた手続きの問題** |

### 命題 4（同位置・同傾きなら一致）— 括弧書きが全部だった

局所性半径 **d\* = 2**（単調）: z ≥ −2 で一致する活性化は末尾で一致する。ただしそれは**到達する支持が狭い（半幅 0.30）から**で、沈んだユニットの支持は 3.8（leaky）〜6.5（ELU）に広がり、そこでは谷の向こうまで効く（`valley_clamp`）。「合わせるべき局所」の幅は**レジームが決める**。Issa が括弧で書いた「周りの分布が変わったら平均も変わる」が本体。

## 5. 力場について今言えること（本走で確定した性質）

| 性質 | 証拠 |
|---|---|
| 一次の力である | full-batch でも沈む（§4 命題 5） |
| 奇関数には存在しない | 定理＋`LIN` 全ユニット ±0.084・S-mirror 不一致 0 |
| 向きは「到達できる支持の上での傾きの非対称」が決める | softplus −11 / 棚の梯子（d≥2 は永久に見つけない） |
| v の学習と結合している | v 凍結で 2.9 浅い・κ ×16 で 2.2 深い |
| 落ち着き先は初期の平均にもスケールにも依らない | b −5 から 99.6% 戻る・×0.5/×2 で差 0.005/−0.057 |

condA では z̄ に働く力は厳密に 2 成分: (1) **タスク内の降下**（15 本の flip 重みと b は 1 本のスカラー ∂L/∂z̄ で一斉に動く）、(2) **flip の蹴り ±w_k**（対称・回帰率 2/15）。ラチェット＝蹴りは対称・降下速度は可動度 E[φ′] に比例して非対称 → 時間平均が降下の目標点より下に座る。非対称は支持が折れ目をまたぐ間だけ働くので、上端が折れ目にぶら下がる（leaky で zmax ≈ 0.1 が κ・a・初期値に依らない）。**滑らかな φ での釣り合いの深さ・v との結合の符号構造は未導出。**

## 7. 方法論の教訓（次の spec に持ち込む）

1. **進捗ゲートは「‖w‖ の比」で書かない。** 線形族は縮み、tanh/softplus は 3〜4 倍に育つ。「初期から状態が動いたか」を ‖Δw‖ か軌跡で見る。scale 腕は初期から帯の中にいるので別扱い。
2. **b オフセット ±5/±4 は lr 0.01 で step 1,000 に発散する。** 批評 S7 が「±2 では分解能がない」と広げた副作用。次は +2（発散しない側）で 15M。
3. **後処理スクリプトは runner の実際の出力名で数える。** `_done.json` の `status` を読む（`_diverged.json` は存在しない）。
4. **5-g (ii) は設計ミス。** 記録 1 本（1000 step）の dz̄ と −ηG は 6 桁違う。二次ドリフトを直接見るなら 100 タスク級の時間平均で。
5. **5-b の `OUTSIDE_1.0` が else 枝になっていた。** `Enull` の CI [−0.23, −0.05] は ±1 の中なのに `NOT_SETTLED` を理由に `OUTSIDE` と出た。ラベルの網羅性検査（レビュー SPE6）を通り抜けた例。
6. **3-b の指数フィットは初期オーバーシュートに引かれる。** z∞ = −0.09 対 実測高原 +0.08。同等性は末尾窓の中央値差で見るべきだった。
7. **ALIVE 規則（`denom` > 0.25）は線形ユニットを 93% 落とす。** 副次規則との食い違いを §3.5 の REPORT が拾ったのは設計どおり。
8. 空虚な S 検査が実装段階で 3 件また入っていた（自分自身との比較に退化しうる S-hook-noop・テストゼロの S-vfreeze・定数と比べる columns）。**変異テスト（47 変異）が全部拾った。** 新しい S 検査には必ず「変異を入れたら落ちる」対照を書く。
