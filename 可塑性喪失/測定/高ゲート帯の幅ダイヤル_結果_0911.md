## 2. 読み

1. **帯幅は c_act を動かす。** τ=1 → 3 で ‖W̃‖ は 7.97 → 8.06 と変わらないのに損失は 1.86 → 0.65 pt。[[長い地平線で沈下と幅を分ける_結果_0910]] の「腕の中では幅が lever」に対し、**同じ幅で活性化の形だけを変えると損失が 1.2 pt 動く**。V9 §3-5 の loss ≈ c_act·g(‖W̃‖) の c_act 側を、初めて介入で動かした。
2. **動いた量は被覆（と深さ）で、支持内の非線形性ではない。** Cov 0.71 → 0.28、Ḡ 0.26 → 0.56、z̄ −6.6 → −2.4、σ 4.4 → 2.5。一方 NL_x は 0.080 → 0.070 でほぼ不変、NL_u も 0.076 → 0.059。姉妹 spec [[ゲート被覆か非線形性か_結果_0911]] の相関（Cov が `ORDERS`、NL_x は逆向き）と同じ向き。
3. **τ=0.3 は ReLU 側に寄る。** hard-dead 14 個（e^{z/0.3} は z < −4.1 で 1e−6 未満）、N は −14%。「幅が小さいほど損失が小さい」の幅 lever なら CELU03 は**良く**なるはずだが、最悪。ここでも c_act が勝つ。
4. **床は少し助ける。** ELUF は CELU1 より 0.5〜1.0 pt 良い（3/3 で −0.5 を切らないので登録ラベルは `FLOOR_NEUTRAL`）。深部の弱さ（e^z → 0）を消すだけでも効くが、帯を広げる（τ=3）ほうが 2 倍効く。Issa の「浅い帯が深部の弱さを補う」は、**浅い帯を広げるほうが深部の床より効く**という形で立つ。
5. **注意（spec §7）**: τ は帯幅と同時に負側の飽和値 −τ と復元力を変える。CELU3 は沈下も浅い（z̄ −2.4）。「被覆だけ」の介入ではなく「負側でゲートを保つ活性化」への介入。`dclamp`（深さだけを浅く保つ）が ELU で効かなかったこと（ρ 0.03–0.09）と合わせると、**効いているのは深さそのものではなく、活性化が負側で持つゲートの量**と読む。
