## 0. 一行

4 ブロックの文字 GPT では、切替の 1 歩で FFN の位置を動かすのは主に同じ層の他の unit の信号（③a）で、自分の信号（①＋②）は 1〜2 割にとどまる。SiLU の L2 が課題 70〜100 に沈むとき、自分の項は浮かせる側にあり、沈めたのは他人の信号だった [測定]。

## 1. 何を測ったか

- 依頼：Issa（Neokunekune の fork 経由、1020 夜と 1021 未明）。結果は Issa の指示で Codex のスレッドへ送った。
- FFN の unit j の位置 m_j = w_j·ȳ の 1 歩の動きを、誰の誤差信号かで 4 つに割る。どれも連鎖律の恒等式。
  - ① 自分の重みを通る自分の信号
  - ② 上流の重みを通る自分の信号
  - ③a 上流を通る、同じ層の他の unit の信号
  - ③b 上流を通る、その FFN を通らない経路の信号（残差の直通・後のブロック・読み出し）
- ρ = |① + ②| / |③|。計量は SGD の内積（A）と、Adam の分母で重みづけた内積（D）。
- 状態は切替の瞬間（課題 k の末）と、新しい課題の更新 100。
- 窓：C3 は課題 2〜10 と 40〜50。SiLU はそれに加えて 11〜15 と 60〜100（5 課題おき）。
- κ_R,j は kappa_reload_cnn_1020（main 05c00725）の定義に、網の全経路の感度を入れたもの。κ_R > 0 が沈める側。
- 検査は 4 つ通った。恒等式（1e−15）、2 つの計算法の一致（C3 4e−15・SiLU 5e−6）、行と列を入れ替える変異の検出、誤差の符号の反転。

## 2. 答え

| 問い | 答え |
| -- | -- |
| C3 の L3 の切替の押しは自分の信号の移動か、他人か | 他人（③a）。沈む unit の押しの 84〜90% |
| SiLU の L3 が課題 11〜15 に正側へ出たとき、上向きを運んだのは | ③a。③b は逆向き。自分の項も上向き |
| SiLU の L2 が課題 70〜100 に沈むとき | 自分の項 ①② は平均で上向き。沈めたのは他人（平均は ③b、沈む unit では ③a が 7 割） |
| 伸びと回転 | C3 の L3 の沈みは伸びが 7 割。SiLU の L3 の上向き（課題 11〜15）は回転が 9 割 |

- 自分の信号は、自分の重み（①）と上流（②）にほぼ半分ずつ分かれる。符号は生きた unit の 9 割で一致する。
- ③a は平均が小さく、unit ごとに散らばって配り直す。③b は全 unit を共通に動かす。

## 3. unit ごとの κ_R（SiLU）

- L3 で κ_R < 0（自分の信号が浮かせる側）の unit の割合は、課題 2〜10 の 2〜3 割から、課題 50 の 7 割、課題 100 の 9 割へ増えた。L3 が正側へ出て線形になる時期と並ぶ。
- L3 の非線形の残り（出力を入力の線形写像で当てた残差の割合）は、課題 15 で 0.13、課題 20 で 0.06、課題 100 で 0.004。
- L2 の読み出しは、課題 11 以降 L3 経由が直通を上回り、課題 100 では 16 倍になった。
- L2 の κ_R を割ると、直通は沈める側、L3 経由は浮かせる側で、L3 経由が勝つ。

## 5. 言わないこと

- 1 歩の絵は、実際の 100 更新の窓より自分の重みの割合を小さく見積もる。C3 の L3 では、1 歩の ① は 3〜5% だが、実際の窓の自分の重みは 23%。実際の窓の上流を ② と ③ に割る帳簿は作っていない。
- 課題の中で起きる沈みは、この分割に入っていない。
- seed 1000 の 1 本。
