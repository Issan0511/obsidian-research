## 0. 何を測ったか

RL-CIFAR CNN（Kumar の CNN）の leaky 0.1 で、入力から CIFAR-10 訓練集合のチャネル平均 (0.491, 0.482, 0.447) を引くだけの腕 LRc（標準偏差では割らない）を、基準の LR（生の入力、cnn_drive_verify_1009）と同じエンジン・seed 10–19・30 課題 × 400 epoch で回した。
- 中心化で平均パッチのノルムは 3.78 → 0.02〜0.05。内側のパッチの共分散は不変（相対 1e−8）。ゼロ埋めの意味が変わるので全位置の共分散は 16% 変わる（開示）。
- 検査 5 本 all_pass。腕 "LR" で回すと基準の課題 1 を bit 一致で再現。

問い: 入力層 c1 の沈降は非負の入力の平均方向（DC 経路: 重みの平均パッチ方向の成分が伸びると、平均は幅の 2.2 倍の速さで沈む）を通るのか。中心化で止まるか、bias が肩代わりするか。

## 1. 登録判定

| 判定 | ラベル | 内容 |
|---|---|---|
| Q（c1 の沈降、初期値 → t30） | **C1_PARTIAL** | LR −2.70 → LRc −0.92、ρ = 0.34（10/10 seed で沈む） |
| 経路 | — | LRc では W1 の DC 成分は 0 のまま（Δ⟨W, m⟩ = −0.001）、**沈降は全部 bias**（Δb −0.86）。LR は DC −2.53・bias −0.23 |
| Q_c2 | **C2_SINKS** | 両腕とも c2 の 100% が沈む。LRc のほうが深い（−5.8 対 −4.3） |
| Q_plast | **LESS_LOSS** | online の低下 0.077 → 0.031（10/10）。水準 0.967 → 0.975、t30 で 0.889 → 0.943 |

相対位置 z̄/sd（c1、t30）は −1.92 → −1.33。c1 の z>0 の割合は t30 で LR 0.01・LRc 0.10、実効ランクは 5.9 対 13.0。c2・fc のゲートは両腕でほぼ同じ。

## 2. 読み

- 非負の入力の平均方向（DC 経路）は、入力層の沈降の約 2/3 を運ぶ。中心化してそれを塞いでも、平均を下げる駆動は残り、bias 経路で 1/3 が沈む。**駆動は入力の幾何に依らず存在し、入力の幾何がそれを約 3 倍に増幅する。**
- 深い層 c2 は入力の中心化に関わらず沈む（自己項の駆動、谷の則・自己形と整合）。
- 入力の中心化で可塑性の喪失は 60% 小さくなり、生の入力で起きる c1 のほぼ全面的な負側への沈み込み（線形化・実効ランクの崩れ）が防がれる。ただし、中心化は縁の埋め方と初期のゲートの割合も変えるので、可塑性の改善が c1 の沈降の減少によるとはこの 1 腕では言えない。

会議向けの 3 文の 3 つ目（入力層は別の経路）は、「入力の非中心性が入力層の沈降を約 3 倍に増幅し、平均を引くだけで 2/3 が消え、可塑性の喪失も 6 割減る（10/10）」という予言つきの主張になった。止まりきらない 1/3 は bias 経路の駆動で、その項は未導出。

## 3. 予測の採点（Claude）

Q STOPS 0.55 ✗（PARTIAL 0.30）・C2_SINKS 0.75 ○・|r1| 半分 0.55 ✗・可塑性 最頻 SAME 0.40 ✗（LESS 0.35）・水準が上 0.60 ○。中心化の効きを、入力層の沈降については過大に、可塑性については過小に見積もった。
