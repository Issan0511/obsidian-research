## 0. 一行

読み出しに隣接する L1 は、有効な読み出しを縮めると 1 課題で生き返った。逆に、L1 自身の書き込みが最終 LN の分母を膨らませる経路を塞ぐと、15 課題たっても生き返らなかった [測定]。

## 1. 問いと走

- 問い：C3-2（2 ブロック、ReLU）では、課題 40〜50 に L1 の死が 0.96 から 0.06 へ下がる。何が L1 を生き返らせるのか。
- 出発：元の走の課題 40 の末と課題 25 の末（重みと Adam の状態）。同じデータ列で再生した。
- 対照は 2 本とも、元の走の各更新の損失とビット一致した（課題 41〜55、26〜40）。
- 予測は走る前に commit した（lop_analysis b73352a3、`results/chargpt_cl_1019/quicklook/M2/intervene/PREDICTIONS.md`）。

| 腕 | 出発 | 介入 |
| -- | -- | -- |
| 対照 | 課題 40・25 | なし |
| 分母を定数に固定 | 課題 40 | 最終 LN の分母を課題 40 の平均の定数にする |
| 分母から FFN1 を除く | 課題 40 | 最終 LN の分母を、FFN1 の出力を除いた残差から取る |
| 共通成分を除く | 課題 40 | FFN1 の出力から、バッチのトークン平均を引く |
| L0 凍結 | 課題 40 | FFN0 の重みと LN2₀ の γ を固定する |
| γ を 0.3 倍 | 課題 25 | 最終 LN の γ を 0.3 倍にする（学習で戻れる） |
| γ を 0.3 倍で固定 | 課題 25 | 最終 LN の γ を 0.3 倍にして固定する |

## 2. 結果

### 2.1 課題 40 から（L1 の死）

| 課題 | 対照 | 分母から FFN1 を除く | 共通成分を除く | 分母を定数に固定 | L0 凍結 |
| -- | -- | -- | -- | -- | -- |
| 43 | 0.80 | 0.99 | 0.97 | 1.00 | 0.23 |
| 46 | 0.51 | 0.98 | 0.95 | 0.99 | 0.28 |
| 50 | **0.06** | 0.99 | 0.97 | 1.00 | 0.77 |
| 55 | 0.32 | 0.99 | 0.99 | 1.00 | 0.80 |
| 課題 51〜55 の最後の 1,000 更新の超過損失 | **0.19** | 0.77 | 1.04 | 0.68 | 0.75 |

- 帰還を塞いだ 3 本では、L1 は最後まで生き返らなかった。損失は対照の 4〜5 倍悪い。
- 塞いだ腕では、L1 の有効な読み出しが 1.2 から 1.6〜2.3 へ伸びた。対照では 1.0〜1.2 にとどまった。
- L0 凍結では、L1 は早く生き返ったが（課題 43 で 0.23）、課題 47 以降にまた死んだ。FFN0 を止めても、L0 の死は対照と同じように増えた（0.18 → 0.6）。L0 は埋め込みと注意 0 を通じて沈むので、この腕は「L0 の沈みを止める」介入になっていない。

### 2.2 課題 25 から（十分性）

| 課題 | 対照の L1 の死 | γ を 0.3 倍 | γ を 0.3 倍で固定 | 固定の腕の有効な読み出し |
| -- | -- | -- | -- | -- |
| 25（介入の直後） | 0.99 | 0.99 | 0.99 | 0.29 |
| 26 | 1.00 | **0.32** | **0.03** | 0.49 |
| 27 | 0.99 | 0.76 | 0.54 | 0.71 |
| 28 | 1.00 | 0.96 | 0.71 | 0.76 |
| 31 | 1.00 | 1.00 | 0.98 | 0.67 |

- 読み出しを縮めると、L1 は 1 課題でほぼ全部生き返った。
- 読み出しが戻ると、L1 はまた死んだ。γ が戻れる腕では γ の再成長で 2 課題、固定の腕では W_down と埋め込みの成長で 5 課題かかった。
- 固定の腕は対照より損失が良かった（課題 36〜40 の最後の 1,000 更新で 0.095 対 0.104）。L0 も死ななかった（課題 40 で 0.00 対 0.18）。

## 3. 読み

- 各腕の中では、L1 の死は有効な読み出しの大きさと一緒に動く。読み出しが小さくなると生き返り、大きくなると死ぬ。ただし、腕をまたいだ一本のしきい値は無い（固定の腕は 0.7〜0.8 で死に、対照は 1.0 前後で生き返った）[測定]。
- 元の走での生き返りは、帰還の形に合う。生き返った L1 の書き込みが最終 LN の分母を膨らませ、読み出しの伸びを打ち消し、さらに生き返る。この経路を塞ぐと、読み出しは伸び、L1 は死んだままだった [読み]。
- 最初のきっかけ（課題 42〜43 に FFN1 の出力が伸び始める理由）は、この介入では分かっていない。

## 4. 訂正

- 下見と 10 seed のノート（§3.3）で「生き返る時期に L1 の有効な読み出しが半分以下に縮んだ」と書いた。これは最終 LN の入力の rms で割った値だった。
- LN が実際に割る、トークンごとの特徴の標準偏差で測ると、課題 40 → 50 の縮みは 1.19 → 0.96（約 2 割）だった。分母は 2.5 倍に膨らんだが、W_down の列も伸びて大半が打ち消された。
- 残る言い方は「分母の膨らみが読み出しの伸びを打ち消した」で、「読み出しが半分に縮んだ」ではない。

## 6. 言わないこと

- seed 1000 の 1 本の事後の介入。10 seed の判定ではない。
- 分母を変える介入は forward の関数そのものを変える。読み出しの大きさだけを動かしたとは言えない。
- γ を縮める介入は、L1 の読み出しだけでなく網全体の出力と勾配を変える。「L1 の有効な読み出しだけを縮めた十分性」とは言わない。言えるのは「生き返りを誘発できる操作が得られた」まで（Codex の指摘、1021）。
- 言えるのは、生き返りを支える帰還の経路と、生き返りを誘発する操作が得られたところまで。自然の軌道で最初に生き返りを始める原因は未同定。
