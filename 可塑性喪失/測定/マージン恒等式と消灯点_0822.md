## 1. マージン恒等式（**[[xr分解と生存機構_0822]] §9 と同一の代数**）

### 1.1 既存との関係（先に書く）

[[xr分解と生存機構_0822]] §9 が既に閉形式を出している:

```
dead(flip) ⟺ flip·w[:15] + b + Σ_{j∈rnd} max(w_j, 0) ≤ 0
```

本節の `s + M ≤ 0` は **µ = [flip ‖ 0.5·1] を代入すると代数的に同一**（`flip·w[:15] + b + 0.5Σw_j + 0.5Σ|w_j| = flip·w[:15] + b + Σ max(w_j,0)`）。**新規なのは以下の 3 点だけで、閉形式そのものは二重記帳しない。**

> **表記ゆれの申し送り**: §9 は `w[1:15]`、§17 と [[blindspot_0820]] §5 は `w[:15]`。本ファイルは `w_flip`（flip 15 座標）/ `w_free`（rnd 5 座標）と書く。どれを正とするか未決。

### 1.2 新規 1: cos 表現

`s := w·µ + b`（周期内で定数の部分）、`M := max_δ(w·δ) = ‖w_free‖₁/2` として

```
p̂ = 0  ⟺  s + M ≤ 0  ⟺  cos(u,µ̂) ≤ cos_crit := −(b + M)/(‖w‖·‖µ‖)
```

**消灯点がユニットごとの量として書ける。** ゲート曲線の崖は cos_crit の分布の反映であり、θ_med（seed 中央値水準）は median(cos_crit) の、θ_all（全サンプル水準）は min(cos_crit) の交差点。**θ_all < θ_med という順序が定義から従う。**

### 1.3 新規 2: 正規化形（**PB-5 の有界入力版**）

```
p̂ = 0  ⟺  β ≤ −r ,   r := ‖w_free‖₁ / ‖w_free‖₂ ∈ [1, √5]
```

β は [[用語と記号]] §1 と同一定義（condA では √(wᵀΣw) = ‖w_free‖₂/2）。実測 r ∈ [1.19, 2.24]。

**これが一番価値がある。** [[用語と記号]] §5 の `PB-5`「ガウス入力では Φ(β)>0 なので絶対吸収は起きない」に対する**有界入力版の厳密な対応物**であり、[[整流モデル]] 部品2 と [[ノルム増大と不可逆性]] の「condA の有界入力では文字通りの吸収が存在／但し書きは有界サポートでは解除される」という定性的主張を、初めて閉じた式にしている。

> **注意**: [[引用禁止]]「正規化量（cos, β）で力学を書かない。分母の成長が力に化ける」と字面が衝突する。**あちらは力学（時間発展）の話で、本節は静的な判定条件**。引用時に一言添えること。

[[自己項の恒等式]] §2 の等号条件「`F_self,i = 0 ⟺ v_i = 0 または a_i ≡ 0`（全 32 パターン = dead）」の後半に、明示的な不等式を与える。**税の消灯条件 = マージン条件**の橋渡し。

### 1.4 新規 3: 検証（独立）

step 0 と 1M の checkpoint から full W を取り、per-unit で照合:

- **不一致 0 件**（両 arm × 両時点 × 10 seed × 100 unit = 4,000 unit）。`max|pre_max − (s+M)| ≤ 2.2e-16`
- **p̂ そのものの再構成**が step 0 で記録済みと完全一致（2,000/2,000、`max|Δp̂| = 0`）→ µ/δ/p̂ の定義理解が確定
- 記録ログのみで検証できる必要条件 3 本を **41,802,000 サンプル**で回して違反 0 件
- running_mean は µ と x_in の両方に同じだけ入るので **δ から相殺**。std / centered で δ も M も同一

### 1.5 µ は壁を強くする（2 つの経路）

`cos_crit = −(b+M)/(‖w‖·‖µ‖)` の分母に ‖µ‖ がいることの帰結。**入力平均の大きさが、罠の強さそのものを決めている。**

**経路 1: 壁の位置を手前に引き寄せる**

死の条件は `‖w‖·‖µ‖·cos + b + M ≤ 0`。`b + M > 0` のユニット（cos = 0 で発火するもの）では cos_crit < 0 で、**‖µ‖ が大きいほど cos_crit が 0 に近づき、死の領域 `cos ≤ cos_crit` が広がる。**

> **条件つきであることに注意。** `b + M ≤ 0`（cos = 0 でも既に消灯）のユニットでは cos_crit ≥ 0 になり符号が逆転する（‖µ‖ を大きくすると生存側が広がる）。**std ではこちらは少数派**で、`b + M ≤ 0` と p̂=0 の一致率は **7.0%** しかなく、median `|w·µ|/|b+M|` = **1.56**。**std の死は cos 項が担っている。** centered は逆で一致率 **98.9%**・median 0.044 とこちらのレジームに入る（→ §4.2・§8）。

**経路 2: 逃げる手段を奪う**

§4.2 の `b が動かせる s の割合 = 1/(1 + ‖µ‖²)`。**`x·µ ≥ 0` から無条件で単調**（経路 1 と違って条件が要らない）。‖µ‖ が大きいほど、バイアスが壁から逃げるために使える自由度が減る。

**2 つの経路はどちらも ‖µ‖ でスケールする。µ は壁を手前に引き寄せると同時に、逃げる手段も奪う。** centered（‖µ‖ 3.041 → 0.117）で dead_frac が 0.947 → 0.324 に落ちるのは、この両方が同時に緩むため（→ §3.1・§4.2）。

> **未検証**: 2 経路の寄与を分離していない。‖µ‖ を連続的に振る介入（部分センタリング / center_alpha スイープ）があれば θ(‖µ‖) のスケーリングとして直接測れる。→ §9-6

## 2. 消灯点 −0.15 は初期化則と入力統計から予言できる（**[[フレーム前の穴]] §6(c) の問いへの答え**）

§6(c)「−0.15 が入力統計から予言できるのか、この設定固有の値かが未確認」に対し、**走なしで答えが出た**。

初期化則（`w_j ~ U(±√(6/20))`、`b=0`）と入力統計（flip ~ Bern(1/2)¹⁵）だけの MC。**フィットゼロ・パラメータ 0 個**、20,921,000 unit:

| | 予測 | 観測 |
|---|---|---|
| **θ_med** | **−0.15** | **−0.15** |
| θ_all | −0.50 | −0.55（1 ビン差） |

cos_crit 中央値 −0.166。θ_all の 1 ビン差は最小値統計＋観測プールの強い自己相関（実効標本数が違う）で、交絡込みの比較。

**ただし「凍っているから当たった」のではない。** 学習中に κ := M/‖w‖ が 0.488 → 0.854 と上がり、b/‖w‖ が 0 → −0.15 と下がる。この 2 つが**逆向きで部分的に打ち消し合う**。checkpoint の cos_crit 中央値自体は −0.172 → −0.221 と動いている。

> 時間プール側の予測（κ 近似）で θ_med = −0.15 を再現した推定量は**観測を見た後の事後選択**で、予測の格はない（単一 checkpoint の κ では step0 → −0.10、1M → −0.20 と観測を挟む）。**格があるのは上の step-0 MC だけ。**

**§3 の「新規の学習走が要るのは 前-1 の一部のみ」という記述の更新対象**（走なしで埋まった）。

### 3.1 C1「不可比」の正体（事後計算）

`cos_crit = −(b+M)/(‖w‖·‖µ‖)` の**分母に ‖µ‖ がいる**。

- ‖µ‖ 中央値（全記録点プール）: std **3.041** → centered **0.117**（比 **26.0**）
- 1M の cos_crit 中央値 **−3.14**、**|cos_crit| > 1 が 88.1%**（≤ −1 が 69.2%、≥ +1 が 18.9% ＝ 常時消灯）
- → 崖が cos の定義域 [−1, 1] の**外へ出る**。「動いた」のではなく「盤から落ちた」
- κ（分子側）は 0.488 → 0.577 とあまり動かない。**効いているのは分母**

centered で µ が潰れる理由: EMA の時定数 1/α = 100 step に対し周期は 10,000 step なので、周期の最初の 1% で平均は引かれ切り、あとは自由 5 ビットのサンプリング雑音だけが残る（理論値 `0.5·√(α/(2−α))·√5 = 0.079`、実測 offset 0 で 0.073）。境界では 1 ビット分の残差が立って ‖µ̂‖ ≈ 1（実測 +1 で 0.993）、+100 で 0.375（実測 0.373）。

[[自己項の恒等式]] §3 の enc=centered 行「µ が退化」に **3.04 → 0.117** という数字が入る（ただし §3 の主題は F_self の符号、本節はゲート条件なので別量として並べること）。**同表の「`ratchet_log.py` が `NotImplementedError` で落とす」は centered 走が回った以上すでに古い**（`a08645c` でガード撤去済み）。

## 4. なぜバイアスは µ を打ち消せないのか（**[[台帳（実効バイアスの縮退）]] §1・§2 と同一構造**）

### 4.1 既存との関係（先に書く）

[[台帳（実効バイアスの縮退）]] §1 が既に出している:

```
g_{w_ik} = 2δ·v_i·gate_i·x_k = flip_k · g_{b_i}      §2: Δb_eff = Δb·(1 + n_active)
```

本節の `gW = gb ⊗ x_in` は**この式の全座標版**、`Δs = Δb·(1 + x_in·µ)` は**同じ量を µ 座標で書いたもの**（flip 座標で読むと `flip·Δw_flip = Δb·n_active`）。[[xr分解と生存機構_0822]] §17 が「同じ構造を独立に掘り当てた」と書いているのと同じ事情。

> **スコープ分離の線に触れる（要判断）**: [[論文スコープ分離]] は Q15（台帳）を次論文に振り、「現論文の文書に台帳・二速修理・Glorot を書かない。現論文が台帳から受け取るのは境界衝撃 ±w_ik と再分類死の存在の 2 点のみで、**縮退の導出は書かない**」としている。**本節を現論文の機構節に置くとこの線を跨ぐ。** [[命題リスト]] 8/22c 表の Q15 行が既に予告済み。

### 4.2 新規: 支配率 1/(1+‖µ‖²)

1 step で厳密に `Δ(w·µ) = Δb·(x_in·µ)`、`Δs = Δb·(1 + x_in·µ)`。std は x ∈ {0,1}²⁰・µ ≥ 0 なので **x·µ ≥ 0 が常に成立**、しかも `E[x·µ] = µ·µ = ‖µ‖²`。したがって

```
b が動かせる s の割合 = 1 / (1 + ‖µ‖²)
```

- **std**: ‖µ‖² ≈ 8.75 → **約 10%**。実測 同符号率 **1.0000**（922,467 ペア、逆符号 0 step）、比の中央値 **8.00**（5–95% で [5.0, 11.5]）、b が担える |Δs| 中央値 **11%**
- **centered**: ‖µ̂‖² ≈ 0.014 → **約 99%**

**「w·µ はそのままで b だけ動かす」動きが更新則に存在しない。** 自由度は 1 本で、その向きを決めるのは損失であってユニットの生死ではない。s を守る復元力はどこにもない。

**centering の効能は 2 つある**: (i) 分母 ‖µ‖ が潰れて崖が定義域外へ出る（§3.1）、(ii) **b の自由度が戻る**。後者は既存記述ゼロ。**この 2 つは µ を増やす向きに読めば「µ が壁を強くする 2 つの経路」で、§1.5 にまとめてある。**

実測（std alive, 1e6 近傍）: `w·µ = −0.99`、`b = −0.25`、`s = −1.32`。**両項とも負で、和は両者より深い**（打ち消しどころか強め合い）。全記録点で median `|w·µ|/|b|` = 5.46。

### 4.3 s は 0 に寄らない

`s/M = 0` ⟺ p̂ ≈ 0.5（δ の ± 対称性から厳密）。

| | s/‖w‖ 中央値 | s/M̂ 中央値 | p̂ 中央値（κ 非依存） |
|---|---|---|---|
| std alive | −0.225 | −0.395 | **0.250** |
| centered alive | −0.147 | −0.289 | 0.312 |

alive の 25% しか s > 0 でない。M̂ の κ 近似への依存は 3 経路（κ̂ 感度 −0.29〜−0.51 / 消灯遷移点での挟み込み −0.31 / checkpoint の順序統計から p̂=8/32 を逆算 −0.35）で否定。**能力の問題であって時間の問題ではない**: 組成を固定した final_survivor コホートでも s は −0.19 → −1.32 と離れ続ける。

[[命題リスト]] Q14（税の b・v 成分は無条件で沈黙方向）と同方向。b の負ドリフトの 8 割超が「発火している最中」に稼がれるのは、`a_i·gate_i = a_i` が発火時のみ非ゼロであることから構造的に従う（Q14 の実測確認）。**per-unit の drift であり selection ではない**（全 unit が b(0)=0 から出発するので低 b 選択は原理的に不可能）。ただし母集団値 −0.20 の水準は composition が主役（最終 alive 5.3% の b/‖w‖ は −0.062、低 p̂ 帯 94.7% が −0.211）。

## 5. 死は境界に集中する

死亡判定は `src/figures_ratchet_log.py: death_events` を import してそのまま使用（TAU=0.05、`death_recover_periods=1`）。

| | 死亡数 | offset +1..+100 の割合 | 率比（生） | 率比（検出バイアス補正後） | offset +1 ちょうど |
|---|---|---|---|---|---|
| **std** | 995 | **69.9%** | 233× | **206×** | **28.2%**（補正後率比 3519×） |
| **centered** | 693 | 51.4% | 106× | 9.5× | 25.5%（補正後 310×） |

時間占有は 0.99%。補正は `−99..−1`（物理的にはバルク時間だが密グリッド）の率比を検出バイアス推定値として使用。seed 間ばらつき std 0.63–0.74 / centered 0.40–0.55。恒久的な死だけに絞っても不変（70.1% / 53.7%）。

- 余裕との関係: P(+1 で消灯) は序数 k=1 で std 19.9% → k=17–32 で 0.36% と単調減少。下向きジャンプ幅の五分位でも単調（std 0.8% → 30.4%）
- ジャンプの構造: `‖µ‖² = Σflip + 1.25` が全 209,010 記録点で float32 精度成立、境界ごとに `Δ‖µ‖² = ±1` → **flip は毎回ちょうど 1 ビット**、`Δ(w·µ)` は実質 ±w_j
- 境界 1 step: median `|Δ(w·µ)|` = **0.283** に対し median `|Δb|` = **0**（mean 比 66:1）

> **[[死の二経路]] が 8/22 に「出所が無い」として削除した数値と一致する。** 削除リスト (b) の「死亡イベント全体では 281/995 = 0.282」は、本節の 995 件・28.2% と n も割合も一致。**独立計算で復活した形**。削除の判断自体は運用メモに従った正しい処理だったので、書き戻すなら経緯を上書きせず訂正記録に追記する形にすること（§8-c）。
>
> **別量との混同注意**: [[ロギング走の結果]] P4 の `BC_w` = 0.315（時間占有 2.01% に対し 15.7 倍の濃縮）は**凍結ユニットの ‖w‖ 変位**の集中で、本節の**死亡イベント**の集中とは別量。
>
> **`|Δx|` の食い違い（未解決）**: [[xr分解と生存機構_0822]] §2 は境界ペアで `median |Δx| = 0.0872`（発火中のみ 0.0980）。本節の 0.283 と 3 倍違う。**母集団の条件付けが違う可能性が高い**（全ユニット vs 死亡個体）。揃えるか、別量と明記するかは未処理。

## 6. 境界後の回復は std では起きない

κ フリー指標 `gap(o) = median_up(Δs) − median_down(Δs)`（共通ドリフトが消える）で測定。

| arm | gap(+1) | 9000 step 後 | 半減 | 時定数 | 回復の担い手 |
|---|---|---|---|---|---|
| **std** | 0.566 | **91% 残存** | 1 周期内に存在しない | 微細窓 2.8e3 / バルク **3.8e5 step ≈ 38 周期** | — （b の寄与は gap の **2.7%**）|
| **centered** | — | — | **77 step** | **112 step ≈ 1/α** | **running_mean**（b ではない。残差 gap は b 側で符号は反回復）|

**std では w も b も新しい µ に合わせ直さない。** centered の回復は centering 機構そのものが担っており、ネットワークの適応ではない。

> [[中和と境界窓]] §2 の「境界で壊れ 1–2k step で再建」は残差 δ の中和比の回復で**別対象**（矛盾ではない）。ただし同節は出所注記で「倍率と時定数の数値は未検証（スモーク由来）」とされており、**唯一の回復時定数の記述がそれである以上、本節は留保を足す材料になる**。[[論文スコープ分離]]「回復に 1–2k step かかる（スモーク）／なぜ 1–2k step なのかは書かない」も同じ数値に依存している。
