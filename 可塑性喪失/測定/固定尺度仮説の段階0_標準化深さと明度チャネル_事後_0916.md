## 0. 一行

**標準化深さ $d_i=\bar z_i/\sigma_i$（平均前活性を前活性の標準偏差で割ったもの）は 400 タスクでも有界（$|d|\le 3.5$）で、$-\infty$ へは行かない。** 負側へ走り続けるのは、前活性分散が**明度チャネル**（行平均 $m_i$ × 画像の画素和 $S(x)=\mathbf 1^\top x$）に支配された少数ユニットで、その $d$ は $-\bar S/\mathrm{sd}(S)=-3.03$（MNIST test の明度の変動係数の逆数）に収束する。この値は最も暗い画像の z 得点 $-2.39$ より深いので、**絶対尺度 $\sigma_i$ が伸びる限り、裾（暗い画像）を含む支持全体が負側へ運ばれる**。逆に模様チャネル $\kappa\|\widetilde W_i\|^2$ が支配するユニットは $d\approx-0.2\sim-1.9$ に留まり、$\sigma$ が伸びても正側の裾（入力の 3–40%）は残る。

したがって仮説の実体は「$m/\sigma\to-\infty$」ではなく **「そのユニットの分散が明度支配（$\rho_i\to1$）になるか」** であり、第1層では明度支配ユニットの割合は 400 タスクで増えない（9–14%）。第2層の全滅は、上流層の飽和で入力 $a_1$ の共通成分が支配的になり全ユニットが明度支配に入る事象として読める。

- **標準化深さ** $d_i=\bar z_i/\sigma_i$。
- **明度支配率** $\rho_i=\mathrm{Var}(S)\,m_i^2/\sigma_i^2$（[[前活性分散の厳密分解_事後_0910]] の $\sigma^2=\kappa\|\widetilde W\|^2+\mathrm{Var}(S)m^2$ の第2項の割合）。$\mathrm{Var}(S)=34.3^2$, $\bar S=103.9$ は MNIST test 全体（probe の値と数%差）。

- **Adam ε 域**: `tinygate`>0.5（probe の過半で $|\varphi'|<\varepsilon$）。

### 2.3 走り続けるユニットの速度と Adam の ε（箱 A）

- **ELU1 の $\rho\approx1$ ユニット**（seed あたり 4–5 個）は t100 −38 → t400 −42〜−46 で**減速**し、log 当てはめ（R² 0.87–0.99）が線形（0.58–0.93）に勝つ。速度 −0.01〜−0.02/タスク。$\bar z\approx-45$, $\sigma\approx12$ なら最も暗い画像でも $z\approx-45+2.4\cdot12\approx-16$、$\varphi'=e^{-16}\approx10^{-7}$。勾配が ε=1e-8 に近づいて Adam の正規化が外れる **ε ブレーキ**の位置と読める。
- **GELU・SILU・LR の走り出しユニット**は t400 で $\bar z=-15\sim-22$、まだ線形（−0.02〜−0.09/タスク）。ε 域には未到達。
- 深さ別平均速度（5 タスク平滑・5 タスク差）: 全腕で $\bar z\in[-2,2]$ は下向き（−0.09〜−0.12/タスク）、$[-16,-6]$ は上向き（復元）、**ELU1 の $[-32,-18]$ だけ −0.3〜−0.5/タスク**で、$|\Delta\bar z|$ は浅い帯（0.23）より大きい。$\varphi'\approx e^{-25}$ でも止まらないのは Adam の座標正規化のため（SGD 型の自己制動 $\propto\varphi'$ ではない）。※ 回帰効果の偏りを含む。

### 2.5 同日追記 — 「低応答」と「吸収」を分ける／吸収線越えの推移／m の収支

**用語**: 本ノートの「飽和」は **吸収**（$\sup_x z_i(x)<0$、正側の入力がゼロ）を指す。応答量 $\mathbb E_x\varphi'$ が小さいだけの状態は **低応答（侵食）** と呼び分ける。RL の ELU 第1層は後者（t150 で gate_mean 中央 0.073、$d$ 中央 −1.56、吸収線 −2.39 越え 12%、−3 到達 0%）で、吸収されているのは第2層（100%、$d\approx-3.5$）。層別キメラ EL 腕（ELU 第1層 $\bar z=-32.7$, gate 0.015, $d=-2.06$）が 0.31 で学べるのは、第1層に 2% の裾が残り leaky 第2層がそれを使うため。

**同日再訂正（Issa 指摘）**: 上の RL ELU 第1層の数値は、第2層が t11–16 で死んだ後の凍結状態（‖W̃₁‖ が t20 の 11.9 から t150 の 13.8 までしか伸びない）であり、ELU 第1層の力学の判定に使えない。RL で ELU 第1層を生きた下流の下で見ている走は層別キメラ EL 腕（ELU 第1層・leaky 第2層）だけで、そこでは t5→50 に $\bar z_1$ −3.7→−32.6、$\|\widetilde W_1\|$ 7.2→28.4、$d_1$ −1.08→−2.07（t40–50 で減速）。RL は画素を置換しないので壁の方向は $\hat\mu$ 全体で、定数は $c_\mu=\|\mu\|/\mathrm{sd}(\hat\mu^\top x)=3.44$、吸収線 $\kappa_\mu=2.55$（MNIST test）。EL の −2.07 は吸収線の手前（裾 ≈2%、EL の 0.31 と整合）。RL の leaky 第1層は t10–150 で $d_1=-1.96$ に釘付け（$\|\widetilde W_1\|$ 7→43）。**「ELU 第1層が吸収されるか」は RL では未決**（EL 50 タスクのみ）。PM 400 タスクでは吸収されない。

## 3. 読み（事後・仮説ノートへの含意）

**座標系としての整理は [[明度チャネルρとµの壁_0916]]（論点マップ §47）に分離した**（V3 柱1・Q26 との対応、$c$ と $\kappa$ の定義と箱依存、$m$ 対 $\widetilde W$ の成分競争）。以下は本走の結果から直接言えること。

1. **§3.2 の「一様輸送」は標準化ではなく絶対尺度で書く。** 命題候補: $\rho_i\to1$（明度支配）かつ $\sigma_i\to\infty$ ならば $\sup_x z_i(x)\to-\infty$（$S(x)>0$ が全画像で成り立つため、負の明度ゲインは最も暗い画像も運ぶ）。$\rho_i<1$ なら $d_i>-3.03\sqrt{\rho_i}$ で、正側の裾が残る。§4 の反例（$m/\sigma=-1/2$）は $\rho<1$ の場合に当たる。
2. **飽和の「不可避性」は「$\rho_i\to1$ になるユニットが増えるか」に還元される。** 第1層では増えない（400 タスク）。増える条件は上流の飽和で入力の共通成分が支配的になる場合（第2層）。これは「$W$ 増大」ではなく「行平均 $m$ と $\widetilde W$ の競争」であり、[[W増大メカニズム_0909]] の中心化補正項 $C_l$ と [[駆動源問題_0909]] §11 の μ 輸送式に直接つながる。
3. **ブレーキは二段**: Adam の正規化域では深さに依らず定速（ELU −32〜−18 で 0.3–0.5/タスク）、$|g|\lesssim\varepsilon$ で log 時間へ（ELU 第1層は $\bar z\approx-45$）。GELU/SILU/LR は t400 でまだ前者。

## 4. 限定

- 事後・未登録。$\hat R$ はガウス近似（入力分布はガウスでない。特に R では粗い）。$\rho$ は test 全体の $\mathrm{Var}(S)$ を使う近似で、$\bar z\approx m\bar S+b$ は $\widetilde W_i\cdot\bar x_c$ の寄与を落としている（相関 0.95–0.995 はこの近似の確認を含む）。
- 深さ別速度は回帰効果の偏りを含む（5 タスク平滑で軽減のみ）。ELU の深い帯の負の速度は偏りの向きと逆なので頑健。
- 「$\rho>0.7$ が増えない」は第1層・400 タスク・Adam・**PM-MNIST** に限る。第2層・RL・他 optimizer では未確認（RL の ELU 第1層では吸収線越えが 0→7→12% と増える。§2.5）。
- $S_2$ の統計と第2層の −3.3 の対応は未検証。

## 5. 次

- 段階1（走ゼロ）: $d$ の漸近値 $-\bar S/\mathrm{sd}(S)$ と $\rho$ の力学を、$\widetilde W$ と $m$ の更新式から出す。第2層版は $S_2$ を定義して同じ形にする。
- 段階2（登録走の候補）: 主判定を $\rho_i$ の時間発展と $\sigma_i$ の成長則に置き、活性化 × optimizer（Adam/SGD）で ε ブレーキの位置（$\bar z_\varepsilon$）を事前に予測する。飽和型（ELU/GELU/SILU）と leaky・適応αSnake の差は $\rho$ ではなく応答の残り方に出るはず。
