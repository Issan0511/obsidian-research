## 3. 読み

1. **ELU は落ちない。** 死亡ユニットは t400 でも硬い定義で 3〜9、緩い定義で 10〜14 に**頭打ち**し、飽和対は 62% に達しているのに、精度は leaky と同じか少し良い。**ゲートの 62% が 0.05 以下でも精度は同じ** — [[駆動源問題_0909]] §10 の「p⁺ は LoP の lever でない」を長い地平線で再確認した形。「沈下 → 死 → LoP」は ELU では 400 タスクで**成立していない**。死ぬのは 1 割で止まる。
2. **leaky は「LoP しない」でも「1/√t で落ち続ける」でもなく、強く減速する。** 傾きは early −1.9〜−2.5 → late −0.3〜−0.6 pt/100task。1/√t なら −0.95 のはずで、それより速く減速している。Issa の「頭打ち」に近いが、3 seed とも負のまま（累積 −4.3 pt）。
3. **3 腕は同じ緩い低下に収束する**（late 傾き −0.3〜−0.6・Snake は −0.4〜+0.0）。分けるのは**累積損失の順序**で、それは ‖W̃‖ の順: leaky 15.2 / −4.3 pt、ELU 13.7 / −3.1 pt、Snake 9.0 / −0.9 pt（n=3・相関）。死亡数（0 / 9 / 0）でも飽和（0 / 0.62 / 0.15）でも p⁺（0.10 / 0.23 / 0.30）でも順序は付かない。**§42 の「lever は ‖W̃‖」と整合。**
4. **√t は 400 タスクまで続く。** leaky の ‖W̃‖ 8.4 → 15.2 は比 1.81 で √(400/120) = 1.83 と一致。ELU は 1.65 で sub-√t（指数 0.43 と整合）。沈下も続き、両腕とも z̄ ≈ −8 に達する。
5. **leaky の p⁺ は 0.16 → 0.10 へ緩く滑る。** 「p⁺ 一定」は 80 タスクでは ±10% だったが 400 タスクでは 4 割落ちる。力の曲線の閾値（参照 perm ガウス近似で 0.05）に集団がゆっくり近づいている読み。ELU は逆に 0.19 → 0.23 へ上がる（死んだユニットの分だけ生きているユニットが浅い側に分布する）。

## 4. 予測の帰趨

- **Issa**: A `ELU_DIVERGES` 外れ。B は `LEAKY_PLATEAUS` に**惜しい**（seed2 の −0.60 が閾値 −0.5 を割った。減速の方向は当たり）。
- **Claude**: A・B・C・D の 4 つとも外れ。特に B は「1/√t で −1.0」と予測して実測 −0.44 — **減速は尺度則より速い**。ELU の死と加速の予測は完全に外れ。
- **どちらも予測していなかったこと**: ELU が leaky より良い、死が 1 割で飽和する、3 腕が同じ傾きに収束する。

## 5. V8 への含意（要 Issa 確認）

- [[駆動源問題_0909]] §10 の「ReLU は沈下 → 死、非 ReLU は幅 → 未同定の経路」のうち、**ELU を「死ぬ側」に入れる読みは撤回**。ELU の死は 1 割で止まり、精度に効かない。非 ReLU は 3 腕とも「幅に順序付けられた緩い共通の低下」。
- **「沈下」が V8 の故障過程の主役である読みは弱まる。** 沈下は 400 タスク続き z̄ = −8 に達するが、それが精度を削っている証拠は無い（ELU の飽和 62% で精度不変）。故障の主役候補は ‖W̃‖（§42）で、経路は未同定。
- 減速が 1/√t より速い理由は未導出。候補: 第 2 層の追随、logit 尺度の飽和、タスク難度の床。
