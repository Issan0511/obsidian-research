**幅 5 で現象3 は再現しなかった。** 主判定 `PHENOMENON3_NOT_REPRODUCED`。leaky と ELU は末尾窓で **`LIN5` より悪くなるどころか、ほぼ全 seed で良い側**に落ちた（`LR5` 0/20・`E5` 1/20）。ReLU だけが 13/20 で **`R5_INCONCLUSIVE_WIDE`**（n=20 では届かない）。事前予測は登録 6 項がすべて外れ、うち `LR5` は**向きごと逆**だった。

## 3. G0（単独の主判定・末尾窓 task 491–500・Clopper–Pearson 95%）

$k_A$ = 同 seed の `LIN5` より `unfit` が大きい seed 数。除外 seed は 3 腕とも 0（S-lin-ref `n_valid`=20）。

| 腕     | $k_A$/20 | CP95               | status                      |
| ----- | -------: | ------------------ | --------------------------- |
| `R5`  |   **13** | [0.4078, 0.8461]   | **`R5_INCONCLUSIVE_WIDE`**  |
| `LR5` |    **0** | [0.0000, 0.1684]   | **`LR5_BELOW_LINEAR`**      |
| `E5`  |    **1** | [0.0013, 0.2487]   | **`E5_BELOW_LINEAR`**       |

`LR5`・`E5` がともに `BELOW_LINEAR` なので **`PHENOMENON3_NOT_REPRODUCED`**。

**`R5` は主判定に入らない。** spec §5 の主判定規則は `LR5` と `E5` だけを読む設計（現象3 は「ゲートが無くても起きるか」の問いなので ReLU 腕は対照）。$k_{R5}$=13 は spec §5 が事前計算していた到達可能性（`ABOVE` に $k\ge15$・`BELOW` に $k\le5$・`TIGHT` は $k\in\{9,10,11\}$）のどれにも入らない中間で、**n=20 では原理的に決着しない位置**である。

> **事後・設計用（登録判定ではない）**: 観測率 0.65 を保ったまま CP95 下限を 0.5 より上へ出すには **n≈44**（$k$=29 で [0.5008, 0.7951]）が要る。n=40 でもまだ下限 0.4832 で届かない。`R5` を決着させたいなら seed を倍以上に増やす設計が要る。
