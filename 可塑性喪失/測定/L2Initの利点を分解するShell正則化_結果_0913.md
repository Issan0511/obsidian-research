## 0. 一行

**L2-Init の罰則を半径の項だけにした Shell 正則化は、どちらの活性化でも方向効果を同定できなかった（両方 D）。** R では shell は l2 と区別できず l2init より 0.017 低いが、norm-match ガードが W3 で 0.0025 差で外れたので方向の価値とは読まない。SNA では shell > l2init > l2（10/10）だが L2-Init の利得 +0.0028 が帯に対して小さすぎる。**λ=1e−3 ではどの正則化もノルムを初期値に保っておらず（W1・W2 で約 2 倍）、分解の前提そのものが弱い。**

## 5. 読み（spec §9 の範囲内）

- **R（性能比較のみ）**: shell は l2 と区別できず、l2init より 0.017 低い。L2-Init の利得 +0.0169 を性能の上ではまったく取り戻していない（取り戻し割合 f = −0.01・95% CI [−0.09, +0.07]・REPORT）。**ガード FAIL なので、これを初期方向アンカーの価値（B）とは書かない**
- **SNA**: shell は l2init を 10/10 で上回るが差 +0.0014 は帯の中。L2-Init の利得 +0.0028 が 0.010 に届かないので、A（半径で利得の大部分を説明）とも言えない。**この箱と帯では SNA の分解は原理的に解像できない**
- 0906（CUDA）の同名 6 腕とは窓平均が 0.0003 以内（R `none` のみ 0.114 対 0.122）。bit 一致は求めていない・主判定に使っていない

## 6. 重みテンソルの大きさ（**事後・REPORT_ONLY**・Issa の依頼で 2026-09-14 に追加）

窓内（seed × タスク 31–50 = 200 値）の ‖W‖/‖W0‖ の中央値。初期値 ‖W0‖ は W1 5.77・W2 5.78・W3 1.82（U(±1/√fan_in) なので ‖W0‖² の期待値は 出力ユニット数/3）。

| act | reg      | W1                   | W2                | W3            |
| --- | -------- | -------------------- | ----------------- | ------------- |
| R   | l2       | ×1.99                | ×1.58             | ×4.95         |
| R   | l2init   | ×2.19                | ×1.89             | ×5.05         |
| R   | shell    | ×2.22                | ×1.88             | ×4.54         |
| SNA | l2       | ×2.19                | ×1.63             | ×3.81         |
| SNA | l2init   | ×2.43                | ×2.09             | ×4.17         |
| SNA | shell    | ×2.48                | ×2.02             | ×3.76         |
| SNA | **none** | **×27.9**（24.0–31.4） | **×8.4**（7.6–9.2） | ×4.1（3.3–4.9） |

- **λ=1e−3 ではどの正則化もノルムを初期値に保っていない。** shell も「初期半径の維持」を名目どおりには実現しておらず、ガードは初期の約 2 倍の半径どうしを比べた。**分解の前提（shell = 半径を初期値に保つ）がこの λ では弱い**
- cos(p, p0) の窓内中央値は shell と l2 で |cos| < 0.05（初期方向をほぼ完全に失う）、l2init は 0.33–0.92
- **SNA `none`**: W1 は止まらず成長（中央値 ×5.5 @t1 → ×17 @t10 → ×25 @t30 → ×30 @t50）、W2 もゆっくり成長（×5.7 @t10 → ×8.9 @t50）、**W3 だけは t10 の ×5.3 を頂点に ×4.1 へ縮み、正則化ありとほぼ同じ大きさ**。それでも窓の `online_acc` 0.986・`memo_acc` 1.000 で全腕最高（50 タスクの範囲で）
- **W3 の倍率が大きいのは半分は見かけ**: 出発点が 1/3 なので、‖W‖ そのものは正則化 3 腕で W3 6.8–9.2 が 3 本の中で最小（W1 11.5–14.3・W2 9.1–12.1）。ただし入力数が同じ W2 と比べると 1 要素あたりの大きさは W3 が約 2.5 倍（0.22–0.29 対 0.09–0.12）で、**出力層が隠れ層より育つのは本物**
- W3 は正則化腕では**タスク 1 のうちに今の大きさに達して以後ほぼ一定**（R l2: ×4.76 @t1 → ×4.94 @t50）。タスクを重ねて溜まる成長ではなく、1 タスク内の釣り合い
- **読み（事後・未検証の仮説）**: ランダムラベルの丸暗記にはロジットの大きな開きが要り、ロジット = W3·h + b3 なので W3 が最も直接のレバー。W3 は誤差を直接受け、タスクごとにクラス対応が全部入れ替わるので強い勾配が続く。W1 の勾配は入力で薄まる（1200 枚で 1 枚あたり非 0 画素は約 19%、全画像で常に 0 の画素が約 22%。**seed 0・1 のその場計算で commit 済み出力ではない**）。Adam＋coupled L2 では勾配が大きく揃う要素ほど釣り合いの位置が大きい。検証には層ごとの CE 勾配の記録か、W3 だけ λ を変える走が要る（未登録）
- **未解決**: shell は同じノルムなら l2 より引き戻しが弱いはずなのに W3 が最も小さい（R ×4.54 対 l2 ×4.95）理由は、今の記録からは説明できない。これが R のガード FAIL の場所

## 7. 未解決

1. shell がノルムを初期値に保てていない（§6）。「半径の維持」を本当に切り分けるには強い λ か、半径を拘束する hard projection が要る（spec の範囲外）
2. ガードは両活性化とも W3 で閾値の近く（R は 0.0025 差で FAIL、SNA は 0.001 差で PASS）。seed や λ で判定が動きうる
3. SNA は L2-Init の利得そのものが帯より小さい
4. tensor 単位のノルムしか記録していない（行ごと・要素ごとの分布は無い・重みを保存して走り直す必要がある）
