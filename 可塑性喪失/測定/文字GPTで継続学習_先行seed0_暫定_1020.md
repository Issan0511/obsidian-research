## 一行

LN 付きの文字 GPT は、Adam の継続学習で課題を重ねるたびに FFN の前活性が沈んだ。lr 1e−4 でも沈みは遅れるだけで、止まらなかった。学ぶ力は終盤で落ちるが、課題 50 でもまだ新品より速く学ぶ。いずれも seed 0 だけの結果である。

## 何をしているか

- 4 層の文字 GPT（pre-LN、RoPE、ReLU の FFN、約 80 万パラメータ）に、50 個の課題を順に学ばせる。
- 課題は、65 個の記号でできた乱数の 2 次マルコフ言語である。直前 2 記号で次の記号の確率が決まり、規則は課題ごとに作り直す。α = 0.01 なので、次の記号はかなり決定的である。
- 1 課題は 10,000 更新（batch 32 × 128 トークン）。Adam は課題をまたいで持ち越し、weight decay はかけない。
- 見るのは 2 つ。一つは、FFN の ReLU の手前の値（前活性）が負に偏るか（沈むか）。もう一つは、新しい課題を学ぶ力が落ちるかである。どんな入力でも前活性が 0 以下の unit を「死んだ unit」と呼ぶ。

## 分かったこと（seed 0）

### 1. LN があっても沈む

負の割合（前活性が負のトークン×unit の割合）と平均が負の unit の割合（どちらも 4 層の平均、課題末）：

| 腕 | 課題 1 | 課題 10 | 課題 25 | 課題 50 |
| -- | -- | -- | -- | -- |
| C3 | 0.75 / 0.90 | 0.91 / 0.90 | 0.78 / 0.75 | 0.82 / 0.92 |
| C4 | 0.57 / 0.68 | 0.77 / 0.93 | 0.83 / 0.92 | 0.83 / 0.93 |
| B3 | 0.77 / 0.94 | 0.91 / 1.00 | 0.84 / 0.98 | 0.78 / 0.92 |

- 学習前は 0.50 / 0.50 である。
- 3 腕とも、課題 10 の末で Q1 の沈降の閾値（0.65・0.8）を超えた。

### 2. 学習率を下げても、沈みは遅れるだけで止まらない

- C4（lr 1e−4）は課題 1 の末で 0.57 で、ほとんど沈んでいない。パイロットの B（lr 1e−4・1,200 反復で 0.54）とほぼ同じである。
- それでも課題を重ねるごとに沈み、課題 10 の末で 0.77 になった。
- spec の予測 4（学習率が沈みを止める `LR_GATES_SINKING`、確信 中）とは逆の向きである。ViT（Adam 1e−4）で沈まなかったのは、課題の数か更新数が足りなかっただけかもしれない。判定は 10 seed で出す。

### 3. 沈み方は層によって違う

- 深い層（第 2・3 層）は沈み続け、unit が死ぬ。C3 の第 3 層の死んだ unit は、課題 10 で 31%、課題 25 で 66%、課題 50 で 28% だった。C4 でも課題 50 で 53% が死んだ。
- 浅い層は、一度沈んでも戻ることがある。C3 の第 1 層の μ/σ の中央値は、課題 10 で −2.16、課題 25 で −0.01 だった。
- B3 は死ぬ unit が少ない（第 3 層で課題 10 に 34%、課題 50 に 8%）。

### 4. 学ぶ力は終盤で落ちるが、新品にはまだ勝つ

| 腕 | オンラインの超過損失 序盤（課題 1〜10） | 終盤（課題 41〜50） | fresh gap 課題 10 / 25 / 50 |
| -- | -- | -- | -- |
| C3 | 0.098 | 0.143 | −0.055 / +0.023 / −0.042 |
| C4 | 0.143 | 0.174 | −0.173 / −0.153 / −0.129 |
| B3 | 0.095 | 0.107 | −0.069 / −0.065 / −0.057 |

- 超過損失は「交差エントロピー − その言語のエントロピー率」（nat）で、小さいほどよく学んでいる。オンラインは更新前のバッチで測る。
- fresh gap は「継続の網 − 同じ課題を新品の網で学んだとき」の超過損失である。正なら継続の網が劣る。
- 3 腕とも、終盤のほうが新しい課題を学ぶ損失が大きい。
- それでも課題 50 では、継続の網のほうが新品より速く学ぶ（fresh gap が負）。spec の Q3 の定義では、これは喪失に数えない。C4 の fresh gap が大きく負なのは、lr 1e−4 の新品が 1 課題の中で学び切れないためである。
- bias と β がある B3 は、終盤の悪化が小さい。

### 5. 重みは √t で伸び続け、前活性の幅もそれに比例して広がる

FFN の up 行列のノルム（4 層をまとめた値）：

| 腕 | 初期 | 課題 1 | 課題 10 | 課題 25 | 課題 50 |
| -- | -- | -- | -- | -- | -- |
| C3 | 26 | 49 | 164 | 247 | 353 |
| C4 | 26 | 27 | 32 | 39 | 49 |
| B3 | 26 | 50 | 166 | 270 | 395 |

最終層の前活性の幅 σ と平均 μ（unit の中央値、課題 1 / 10 / 50）：

| 腕 | 幅 σ | 平均 μ |
| -- | -- | -- |
| C3 | 1.7 / 7.4 / 14.7 | −0.8 / −19.1 / −29.8 |
| C4 | 0.69 / 0.84 / 1.43 | 0.0 / −1.3 / −4.9 |
| B3 | 1.7 / 7.6 / 32.1 | −0.9 / −17.1 / −52.8 |

- 重みは課題 50 まで止まらずに伸びる。C3 は課題 10 → 50（更新 5 倍）で 2.15 倍で、更新数の平方根（√5 = 2.24）に近い。C4 も、初期からの増分が同じ形で伸びる。weight decay のない Adam の歩きとして知られている形である。
- 前活性の幅は、行ノルムとほぼ比例して広がる。LN が入力の大きさをそろえるので、幅は行ノルムと LN の γ で決まる。
- 平均も幅と一緒に深くなる。幅を単位にした沈み（μ/σ）は深い層で −2〜−3.5 で、絶対値の深さはこの相対位置に幅を掛けたものになっている。MLP の箱で見た「沈みの深さを幅の伸びが運ぶ」形と同じに見えるが、1 seed なのでそこまでは言わない。
- 第 0 層だけは、行ノルムが伸びても幅は課題 30 ごろまで 0.2 前後と小さい。

### 6. B3 で平均のずれを運ぶのは主に β の経路

前活性の平均は μᵢ = wᵢ·(γ ⊙ m̂) ＋ wᵢ·β ＋ bᵢ に分けられる（m̂ は LN の正規化後の出力のトークン平均）。B3 の課題 50 の末の unit 中央値：

- 線形層の bias の分（|bᵢ|/|μᵢ|）は、第 0〜2 層で 0.09〜0.12、第 3 層で 0.02。パイロットの 0.08〜0.10 と同じくらいである。
- β を通る項の大きさ（|wᵢ·β|/|μᵢ|）は 0.55〜1.07 で、大きい。1 を超える層は、β の項と残りの項が一部打ち消し合っている。

### 7. N4（LN なし・lr 1e−4）は、はじめ浮いてから沈み、大量に死んで学ぶ力を失う（03:04 に完走して追記）

| 課題末 | 負の割合 / 平均が負の unit | 死んだ unit（第 0〜3 層） |
| -- | -- | -- |
| 1 | 0.21 / 0.06 | 0% / 0% / 0% / 0% |
| 10 | 0.56 / 0.53 | 0% / 5% / 1% / 0% |
| 25 | 0.82 / 0.81 | 10% / 86% / 57% / 40% |
| 50 | 0.83 / 0.82 | 79% / 78% / 51% / 38% |

- LN が無いと、はじめは前活性が正の側にいる（課題 1 の末で μ/σ の中央値が +0.3〜+1.4）。そこから課題 10〜25 で沈み、浅い層まで大量に死ぬ。LN のある C4（同じ lr）の死は最大 53% で、最終層に限られた。
- 学ぶ力ははっきり落ちる。オンラインの超過損失は序盤 0.56 → 終盤 1.49 で、課題 50 の fresh gap は +0.41（継続の網が新品に負ける）。4 腕のうち、Q3 の定義で喪失に当たるのはこれだけである。
- 凍結した Q1 の基準（課題 10 の末）では、N4 は 0.56 で「沈まない」側、C4 は 0.77 で「沈む」側に入る。spec の Q5 が想定した組み合わせのどれにも当たらない（1 seed）。
- up のノルムは 26 → 73 で、C4（26 → 49）より速く伸びる。

## 事後解析 1：担い手を測る（1020 未明・事後・未登録）

Neokunekune のセッションの見立て（Transformer の残差ストリームの共通の向きが担い手で、トークンごとの正規化はそれを消せない）を、seed 0 の C3・C4・B3 の checkpoint で確かめた。スクリプトは repo の `src/chargpt_cl_1019_posthoc_carrier.py`、出力は `results/chargpt_cl_1019/posthoc_carrier_white-san/`（commit 72edbe69）。

**記号。** FFN の入力 y_n（LN の affine の後）、probe のトークン平均 ȳ、担い手 K_n = ȳ·y_n（bias がある腕は +1）。期待の押し S^E_i = Σ_n K_n δ^E_in で、δ^E は新ラベルを一様と置いた交差エントロピーの勾配を前活性まで逆伝播したもの。S > 0 が沈める側。状態は課題 1・10・25 の末（課題 2・11・26 への切替の時点）で、実測は課題 t+1 の更新 0 → 100 の μ_i の変位（Adam・全パラメータ）。

**検算。** checkpoint と probe から作り直した μ_i は、保存値と最大 2.5e−6 で一致した（μ の大きさは 0.007〜40）。

**分かったこと。**

1. **担い手 K_n は、ほぼ全トークンで正である。** 3 腕・4 層・初期と課題 1・10・25・50 の末で、K_n > 0 のトークンの割合は 1.000 だった。例外は C3 の第 0 層の課題 10・25（0.81・0.66）だけ。K_n の中央値は ‖ȳ‖² にほぼ等しく、担い手は入力にあまり依らない。
2. **ただし「m̂ が大きい」とまでは言えない。** ‖ȳ‖ と全体のばらつきの比は 0.15〜1.2、トークンで共有する成分のエネルギーの割合は 0.04〜0.6 だった。K_n が正になるのは、ȳ の向きに沿ったばらつきが小さいからである（128 次元のうち 1 方向）。
3. **期待の押しは最終層で沈める側を向き、中間層ではほぼ半々である。**

   | 腕 | 最終層：沈める側の unit（期待の押し） | 最終層：実測で沈んだ unit | 最終層：符号の一致 | 中間層：符号の一致 |
   | -- | -- | -- | -- | -- |
   | C3 | 65〜77% | 89〜99% | 66〜75% | 47〜69% |
   | C4 | 58〜81% | 54〜100% | 57〜80% | 54〜59% |
   | B3 | 69〜77% | 67〜90% | 61〜76% | 48〜62% |

   最終層ほど一致が高いのは、中間層の unit の実効読み出しが入力に依るからと読める（MLP の 3 層の第 1 層と同じ構図、Neokunekune のセッションの予想どおり）。
4. **κ は正だが、読み出しのごく一部しか説明しない。** 最終層の実効読み出し（W_head diag(γ_f) J̄_LN W_down、クラスで中心化）を v⁰ + κF に最小二乗で当てると、9 通りすべてで κ > 0 だった。ただし説明できる割合（R²）は 0.01〜0.19 である。
5. **自己形の符号の一致は、この箱では空の検査になる。** ReLU では φ′φ = φ ≥ 0 なので、κ > 0 かつ K_n > 0 なら、自己形はすべての生きた unit で沈める側を指す。自己形と実測の一致は、実測の沈んだ割合と同じ数になった。中身のある主張は「κ > 0 かつ K_n > 0」の部分である。
6. **常に開いている unit は一つも無い。** q ≤ 0.05（ほぼ全トークンで開く）の unit は、3 腕・4 層・課題 1・10・50 のどこにも無かった。unit は「常に閉じる」（q ≥ 0.95）か中間に分かれる。offset があると always-on か never-on になる、という二択のうち、閉じる側だけが出ている。

**格。** seed 0 の 1 本ずつで、事後・未登録。押しは全バッチ GD の一歩で置いた（checkpoint に Adam の状態が無いため）。C.11 の重みつきの形 Cov_ω(φ′, φ) ≥ 0 はまだ測っていない。

## 事後解析 2：中心化の腕はなぜ学ぶ力を落とすか（1020 早朝・事後・未登録）

担い手を塞ぐ追加腕（[[文字GPTで継続学習_担い手を塞ぐ追加腕_spec案_1020]]）の seed 0 で、中心化した 3 腕はそろって学ぶ力を落とした。Neokunekune のセッションの読み「この箱では unit ごとのオフセット（閾値）が課題を学ぶのに要り、中心化はそれを禁じる」を、保存済みの記録と checkpoint で調べた。スクリプトは repo の `src/chargpt_cl_1019_posthoc_offsets.py`、出力は `results/chargpt_cl_1019/posthoc_offsets_seed0/`。5 腕（C3・B3・C3H・B3H・B3HB）の seed 0。

1. **中心化の腕には、まばらな検出器が無い。** 開く割合 p（= 1 − q）が 0.05〜0.3 の unit を「まばらな検出器」と呼ぶ。C3・B3 では 4 層平均で unit の 40〜80% がこれに当たる（課題 1・10・25・50 の末）。C3H と B3HB では課題 10 以降 0% で、全 unit が 0.3〜0.7（半分くらい開く）に集まる。B3H は主に第 0 層に 18〜54% 残る（bias がオフセットを作る）。読みと合う。
2. **差は、課題の頭の学び直しの速さに出る。** どの腕も、課題の最後の 1,000 更新では超過損失 0.04〜0.07 まで学び切る。後半の課題（26〜50）で、更新 100〜1,000 の超過損失は C3H 0.63・B3H 0.69・B3HB 1.04 で、C3 0.55・B3 0.27 より遅い。C3H は課題 11〜25 ではむしろ C3 より速い。C3H の遅れは終盤（課題 41〜50）に集まっている。
3. **実効階数は潰れていない。幅は 5〜7 倍に伸びる。** FFN 隠れ層の実効階数は、中心化の腕で 100〜170 と安定している。潰れるのはむしろ C3 の深い層である（課題 25 で 44〜110）。一方、深い層の前活性の幅 σ（unit の中央値）は、課題 50 の第 1〜3 層で C3H 48・76・105、B3HB 37・74・85、B3H 39・46・66 になる。C3 は 8・16・15、B3 は 11・16・32 である。up のノルムはほぼ同じ（C3H 358 対 C3 353）なので、重みが入力のばらつきの大きい向きにそろったか、LN の γ が伸びたかのどちらかで、まだ分けていない。幅が大きいと、Adam の一定の歩幅では位置が動きにくい。課題の頭の学び直しが遅いことと合わせて、「幅の害」の読みが立つ。
4. **担い手の壁 c は、中心化で 1 以下に潰れる。** c = mean(K)/sd(K)（K_n = ȳ·y_n、y は up が実際に受け取る入力）は、ȳ の向きにそろった unit の μ/σ である。土台の腕では学習後も 0.6〜10、中心化の腕では 0.3〜1.1 だった。bias の無い unit の |μ/σ| の厳密な上限（マハラノビス √(ȳᵀΣ⁻¹ȳ)）は、中心化しても 6〜160 と大きい。つまり上限そのものが縛っているのではなく、unit が平均の残りの向きにそろわない。B3H では、課題 10 の第 0〜2 層で 75〜88% の unit が −c より深い（bias がそれを許す）。
5. **c が大きいのは網の作りによる。データの単純さではない。** 初期値の網で c を測ると、マルコフの系列・本物の文章（Tiny Shakespeare）・一様乱数の記号列で、ほぼ同じ値だった（C3 で 3〜17、2 seed）。LN の無い N4 では 1.1〜3.2 と小さい。第 0 層では、埋め込みに LN をかけただけだと c = 1.6 で、注意を通すと 3.3 に上がる。初期値で注意がトークンをほぼ一様に平均することが、共通の向きを作っていると読める（パイロットの checkpoint は保存されていないので、初期値で代えた）。

**読み（仮）。** 中心化は、沈降と死を止めるが、オフセットで作るまばらな検出器も禁じる。網は代わりに幅を伸ばして課題を学ぶが、伸びた幅は後半の課題の学び直しを遅くする。EMA の非定常性の読みとは、まだ分けていない（追補 4 の案 C3P が分ける）。

**格。** seed 0 の 1 本ずつで、事後・未登録。

## 実際の言語・乱数ラベルとしての妥当性（Claude の見立て）

測ったのはパイロット（本物の文章で 1 課題）の部分だけで、ほかは見立てである。

**実際の言語モデルとして近いところ**
- 網の形（因果 Transformer、pre-LN、RoPE、共有の埋め込み、次トークンの交差エントロピー、Adam）が同じ系統である。
- 沈みを測る場所（FFN の活性化の手前）は、Li ら 2022・Shvetsov ら 2026 が本物の言語モデルで沈みを報告した場所と同じである。
- 本物の文章（Tiny Shakespeare）の 1 課題でも、lr 1e−3 で同じくらい沈んだ（パイロット、0.72〜0.75）。GELU でも沈んだ。

**実際の言語モデルとして遠いところ**
- データに長い文脈も文法の階層も語の頻度の偏りもない。注意は直前 2 個で足り、FFN は 4,225 文脈 × 65 記号の表を覚える役になる。
- 課題ごとに規則が独立で、持ち越せる構造がない。実際の継続学習（分野や言語の切り替え）では文法などが残る。
- weight decay がない。実際の大規模学習は AdamW と学習率の減衰で回すので、√t の伸びは釣り合いの大きさで止まるはずである。これが一番大きな違いだと思う。
- 規模（80 万パラメータ）と活性化（実物は GELU・SwiGLU が多い）も違う。

**乱数ラベルとして近いところ**
- 文脈の集合は全課題で同じで、正解の分布だけが入れ替わる。表を毎回覚え直させる点が乱数ラベルに近い。α 0.01 で正解はかなり決定的である。

**乱数ラベルとして遠いところ**
- 入力の系列も新しい規則から作るので、入力の分布も課題ごとに変わる。乱数ラベル MNIST は入力を固定して正解だけを替える。
- データは無限で（毎回新しい系列）、固定した 1,200 枚を覚え込む「記憶」とは違う。正解には消せない乱れ（0.7 nat）が残る。
- 乱数ラベル MNIST の ReLU は可塑性をはっきり失ったが、ここの C3 は課題 50 でもまだ新品に勝つ。

**妥当性を上げるなら**
- 乱数ラベル寄り：spec §2.4 の中間案 M′（Shakespeare の本文を入力に固定し、正解を直前 2 文字 → 乱数表で課題ごとに付け替える）。
- 実際の言語寄り：本物の文章の分野を順に切り替え、AdamW と学習率の減衰で回す。weight decay があっても沈むかが、実物への橋になる。

## 言わないこと

- これは seed 0 の 1 本ずつで、spec §5 の判定ではない。予測 4 と逆向きに見えるのも、10 seed の判定までは「1 seed でそう見えた」にとどめる。
- 「実際の言語モデルでも同じ」「乱数ラベルと同じ」とは書かない（上の妥当性の節）。

## 追記（1020 朝・Fable）：5+1 MLP の 10 倍予算との対照

[[5p1MLP_10倍予算_中心化の反転を幅と検出器で診断_結果_1020]]: 5+1 CIFAR MLP（入力が課題で変わる箱）の 10 倍予算では、中心化した腕（CH・CHB0）は課題を重ねても落ちず、CHB0 は自分の新品とほぼ同じだった（fresh gap +0.006、R は +0.094）。後期窓の水準は R が上だが、それは課題 1 からの一定の差で、可塑性の差ではない。中心化で幅は縮み、実効階数は半分以下になった。この箱の中心化の腕が自分の新品に負け課題を重ねて落ちるのとは逆で、「入力分布が変わるから中心化が害」という読みは外れた。違いの候補は Transformer の作り（pre-LN の後の中心化、残差、幅の伸び）。
