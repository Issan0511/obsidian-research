## 2. 事後の読み（Q1–Q4 は登録上 `NOT_TESTABLE`）

### 2-1. 帯は対を割らない

| 対 | ΔL（seed 別） | ω 比 | 長さ比 | **浅い帯 比** |
|---|---|---:|---:|---:|
| **E1h 対 E2（遅い対・ω が揃っている）** | −0.12 / −0.20 / +0.05 | **1.096** | 0.50 | **2.22** |
| E1d 対 E05（速い対・ω が揃っていない） | +0.83 / +0.96 / +0.89 | 0.721 | 2.00 | 0.28 |
| 参考 leaky の遅い対 | +0.09 / −0.10 / +0.39 | 1.03 | 0.50 | 帯は 0.000 |

**ω が 10% 以内で揃い、長さが 2 倍違い、浅い帯が 2.22 倍違う対で、目減りの差は 0.12 pt。** leaky の同じ対（+0.09 pt）と区別がつかない。**帯が 2 倍違っても損失は動かない。**
速い対は ω が 28% ずれているので対の検定には使えない（ΔL 0.89 pt のうち ω だけで 0.50 pt 説明がつく）。

### 2-2. ELU の傾きは leaky と同じだった

クランプ 5 腕 × 3 seed = 15 点で当てはめると **−1.00 pt/octave**（Spearman −0.87）。

| 測り方 | 傾き |
|---|---:|
| leaky（κ と lr を振る・[[回る速さが幅の正体か_結果_0912]]） | −1.06 |
| **ELU（同じく κ と lr を振る・本走）** | **−1.00** |
| ELU（τ ダイヤル・[[飽和は回る速さを通すか_結果_0912]]） | −1.59 |

**τ ダイヤルの −1.59 は、帯と ω が束になって動いていた見かけだった。** 同じ設計で測れば活性化によらず約 −1.0 pt/octave。**ω の効き方は活性化に依らない。**

### 2-3. 帯は ω の下流

- ω の当てはめ残差と log(浅い帯) の Spearman **−0.27**（|≤0.3| = 何も足さない）。帯そのものと L の相関も −0.28 と弱い。
- 帯は κ でも lr でも動く（κ×2 で 0.69 倍、κ×0.5 で 1.61 倍、lr×0.5 で 1.53 倍、**lr×2 で 0.45 倍**）。**lr のほうが κ より大きく動かす。** つまり帯は「長さの従属変数」ですらなく、**学習の進み方が決めている**。
- **Issa の観察は正しい**（leaky 0.000 対 ELU 0.094〜0.240）。**ただし帯は原因ではなく、ω と同じものを別の端から見た姿。** §0 の負のフィードバックも、帯が独立に効くのではなく **ω を作る側に回り込んでいる**ことを示す。

### 2-4. c_act は切片で、約 −0.9 pt

同じ ω で ELU と leaky を比べる（どちらも幅クランプ・κ=1）:

| | ω | L |
|---|---:|---:|
| leaky | 1.38e−3 | +0.60 |
| **ELU** | **1.12e−3**（遅い） | **0.00** |

傾き −1.0 で leaky を ELU の ω まで外挿すると 0.90 pt。実測 0.00 なので **ELU の有利は約 −0.9 pt の切片**。これは [[飽和は回る速さを通すか_結果_0912]] の M4 が独立に出した **δ = −0.93 pt** と一致する。**別の走・別の設計で同じ数が出た。**

**主軸 B の現状**:
$$L \;\approx\; -1.0\cdot\log_2\omega \;+\; c_{\rm act}, \qquad c_{\rm act}(\text{ELU}) - c_{\rm act}(\text{leaky}) \approx -0.9\ \text{pt}$$
**傾きは活性化に依らない。残るのは切片 1 個。** 浅い帯・ドリフト・経路持続・ゲート被覆はいずれも切片を説明しない（帯は本走、ドリフトは [[勾配の床か揃いか_結果_0911]]、ρ は [[幅クランプはドリフトを上げるか_結果_0912]]）。

## 訂正（2026-09-12 夜・[[回転を買い戻せるか_結果_0912]] の事後解析による）

**§2-2・§2-4 の「主軸 B は $L \approx -1.0\log_2\omega + c_{\rm act}$ に収束した」は撤回する。** ω（1 更新あたりの回転）は、**全腕が 625 更新だったから**損失を並べていた。更新数の違う腕を混ぜると Spearman(ω, L) は **+0.00** になる。正しい変数は **Θ（1 タスクで実際に回った角度）** で、その上に**更新数そのもの**の項が乗る（9 腕 × 3 seed = 27 点）:

$$L \approx 2.89 \;-\; 1.25\cdot\log_2\Theta \;-\; 0.49\cdot\log_2 N \qquad(\text{残差 sd } 0.48\ \text{pt})$$

ω = Θ/N と書けば、625 更新固定のときは log ω と log Θ が同じものなので、本ノートの傾き −1.00 は Θ の係数 −1.25 に更新数の効き −0.49 が混ざったものだった。**傾きが活性化に依らない（leaky −1.06・ELU −1.00）という結論は、625 更新固定の範囲では生きている。**
