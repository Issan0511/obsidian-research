## 箱と量
- 箱 M1（1 層 RL-MNIST・784-100-10・Adam 1e−3・N 1,200・float32）。W₁ を入力の非中心 PCA 基底で読むだけ。帯: u₁（平均の向き）／u₂–₁₀／u₁₁–₁₀₀／u₁₀₁–₄₀₀／u₄₀₁–₅₉₇／データが張らない向き u₅₉₈–₇₈₄。
- 延長の走は課題 1〜(t−1) を元どおり 4,000 更新ずつ学習し、課題 t だけ 64,000 更新まで続ける。最初の 4,000 更新は元の走とビット一致。
- 1,000 課題の走は学習が wtrace_pca_1002 と課題 1〜200 でビット一致（m・s・p⁺・b₁・CE・正答率）。データが張らない 187 次元の基底の取り方だけが違う（固有値がほぼ 0 で重なるため）。帯の部分空間は完全一致、帯の長さの差は 1e−8。
- 帳簿 [恒等式]: ‖W_b(t)‖² − ‖W_b(t−1)‖² = D + E、D = ‖Δ_b‖²（課題の変位の二乗、足される分）、E = 2⟨W_b, Δ_b⟩ = 2 cos ‖W_b‖‖Δ_b‖（cos < 0 なら消す分）。定常には cos = −‖Δ_b‖ / (2‖W_b‖) が要る。収束の判定はこの式ではなく、実測の伸びの傾きと cos の推移で行う。

## 0. 答え
1. **u₁ 以外の向きが W を育てる。** 長くした課題の中で ‖W₁‖ は 22〜79% 伸び、4,000 更新以降の増分の 99〜104% が u₂ 以降（u₁ の列はむしろ縮む）。1,000 課題では ‖W₁‖ が ELU 1,130〜1,150・leaky 900〜930 になり、‖W₁‖² の 98%（ELU）・99.9%（leaky）が u₂ 以降。[実測]
2. **課題の中では、当てはめが終われば止まる。** 64,000 更新まで延ばすと全データの CE は 1e−7〜3e−5、正答率 1.0。Adam の一歩は 5〜40 分の 1 になり、どの帯の変位もほとんど伸びなくなる（ELU 課題 20 の u₁₀₁–₅₉₇ で 16,000→64,000 の傾き 0.22）。標準の 4,000 更新では当てはめが終わる前に課題が切り替わる（課題 20 の CE 1.2〜1.4）ので、前段で「課題末まで止まらない」と見えたのは止まる前に切られていたため。CE の下限 0 は無限遠でしか届かないので、厳密に止まることはない [厳密]。量は [実測]。
3. **課題をまたぐと、帯と活性化で分かれる**（1,000 課題、2 seed）。
   - ELU の u₁・u₂–₁₀ は定常に近づく。毎課題に足された分の 86〜97% を消し、cos は定常に要る値にほぼ届いている（u₂–₁₀ で −0.065 対 −0.064）。伸びの傾きは 0.23〜0.35 で下がっている。
   - **ELU の u₁₁ 以降とデータが張らない向きは収束しない。** cos が課題とともに負から正へ上がり（u₁₀₁–₄₀₀ で −0.11 → +0.018、データが張らない向きで −0.06 → +0.031）、課題の変位が今ある W の向きを向く。消す代わりに上乗せになり（E/D = +1.3〜+3.1）、伸びの傾きは課題 200〜500 の 0.44〜0.54 から 500〜1,000 の 0.53〜0.63 へ加速。cos が正のままなら定常は無い。
   - leaky はどの帯も cos が負（消す側）。u₁ は収束（課題 500→1,000 で列が縮む、傾き −0.08）、u₂–₁₀₀ は 95〜100% を消して定常に近い。u₄₀₁–₅₉₇ とデータが張らない向きは消し込みが足りず（cos −0.007〜−0.013 に対し定常に要るのは −0.017〜−0.021）伸び続けるが、傾きは 0.30〜0.39 に下がってきている。
4. ELU の m/s は課題 100〜1,000 で −2.1 のまま（沈みは幅に比例）。leaky の m/s は −2.1 → −1.7 に上がる。[実測]

## 4. 読みと残る問い
- [事後] W を育てるのは当てはめそのもので、u₁ 以外の向きは「足された分が消されない」ことで育つ。上位の向きは新しいラベルの当てはめが古い模様と食い違うので毎課題消され、定常に近づく。
- [未導出] ELU の下位の向きで cos が正へ上がる理由（課題の変位が今ある W の向きを向く）。候補: 当てはめの「太り」（マージンを広げる向き＝今ある行を伸ばす向き）が、Adam の座標ごとの割り算を通して、損失の効かない向きにも今ある向きの伸びとして漏れる。データが張らない向きでも cos が正（+0.03）なので、少なくともそこは損失の勾配ではなく Adam の一歩の形から来ている [厳密: 張らない向きの勾配は 0]。
- [未確認] SGD なら下位の向きと張らない向きは育たないはず（勾配の大きさが入力の分散に比例し、張らない向きは厳密に 0）。同じ記録の SGD の走は未実施。
