## 4. 読み（事後）

1. **c>0 の着座点は井戸の底 −c/a に一致する。** leaky a=0.1 で |φ+c| = 0 になるのは z = −c/a。c=+0.5 → −5.0 に対し実測 **−5.015**、c=+2 → −20 に対し **−19.65**（復元場の零点も −4.99 / −19.29）。単に「動いた」ではなく**予測された場所へ動いている**。しかもそこは支持全体が折れ目より下（zmax −3.9 / −16.5）で、φ′ = a の一定域。φ′ には何の目印も無い位置に座っている。
2. **c<0 は井戸の底に届かず、途中で止まる。** 底は +0.5（A）/ +2（B）なのに着座は −2.09 / −2.39。上へ行くほど φ′ のラチェット（候補 2 の機構）が押し返すので、着座点は**井戸とラチェットの釣り合い**。**両方要る**、が正しい絵。挙げられていた「証拠は 2 寄り」（棚で折れ目が初期支持の外だと押しが消える）は無傷で、更新は「2 は必要だが十分でない」。
3. **効き方は v 経由でしかあり得ない（式の上で）。** c は ∂L/∂b にも ∂L/∂w にも入らず（どちらも φ′ しか見ない）、∂L/∂v = φ + c だけに入る。残差のずれは c_out が吸収する。R の「井戸の勾配が b に直接乗る」版（ノイズ誘起ドリフト）は [[命題1-5_上端則結果_0905]] で棄却済み。実測もそれと整合: c>0 の腕は **|v| が 0.60→0.06（A）/ 1.27→0.15（B）に落ち、線形化率が 0.01→0.47 / 0.00→0.17** に跳ねる。z = −c/a はユニットの出力 v(φ+c) がちょうど 0 になる点で、**ユニットは自分の出力を消す位置に滑り込んでいる**。E[(φ+c)²] を下るとはそういうことで、spec が最初から H-v を置き §8-2 で併記を要求していた穴が、そのまま機構の本体だった。
4. **ラダー B の参照は A より深い**（−4.89 対 −3.60・lr が 8 分の 1）。edge_law 5-d「小さい lr ほど深い」と同じ向き。水準比較はしない（追補 1 §9）が記録する。
5. **c=±2 の発散（副産物）**: ŷ = Σ vᵢ(φᵢ + c) + c_out で同じ定数が全ユニットに乗るため、v 空間の一様方向 (1,…,1) に **λ ≈ 2hc²**（h=100・c=2 で 800）のコヒーレントな曲率が立ち、lr < 2/λ = 0.0025 を破る。未登録診断: lr 0.005 で 1 seed 発散・0.0025 と 0.00125 で完走。edge_law の b オフセット ±5/±4 の即発散と同型。**一様な定数を全ユニットに入れる介入は、設計時に λ ≈ 2hc² で lr の上限を先に見積もること。**

## 6. 引用上の注意

1. 登録ラベルは §2 の 2 つ（A `NOT_DETERMINED`・B `OFFSET_SIGNED_B`）。**畳んで 1 つにしない。** §3–§4 は事後。

4. 「井戸が z̄ を引く」と書かない。**c が z̄ を動かす経路は v だけ**（§4-3）。「候補 1 が正しい」は「|φ| の偏りが着座点に効く（v 経由で）」まで。
5. 「c>0 で −c/a に一致」は 2 点（c=+0.5, +2）の事後の読み。登録量ではない。
6. λ ≈ 2hc² は設計のための見積りであって測定値ではない（追補 1 §9-4）。
7. ELU 2 腕は判定に入れない（φ′ も |φ| も非対称・c=0 の ELU 腕が無い）。
8. 力場分解（self/rest）は使っていない。
