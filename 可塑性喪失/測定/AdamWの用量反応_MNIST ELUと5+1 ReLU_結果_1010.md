## 0. 何を測ったか

AdamW（decoupled weight decay）を全 6 テンソル（両隠れ層と読み出しの重みと bias）に入れた。各更新で θ を fl₃₂(1 − ηλ) 倍してから宿主の Adam の 1 歩を引く。勾配には何も足さない。時間定数は τ = 1/(ηλ) 更新で、減衰は task 1 の最初の更新から入る。

- **箱 1（主）**: 乱数ラベル MNIST × ELU→ELU（l2cap_ee_0917 の ref と同じ箱。784–100–100–10・Adam 1e−3・6,000 更新/課題・100 課題・seed 0–9）。λ = 10⁻³・10⁻²・3×10⁻²・10⁻¹（τ = 164・16.6・5.6・1.7 課題）。判定の規則は doors_rlmnist_1007 と同じで、主窓は課題 51–100、E1 は online、E2 は第 2 層の訓練の微分、床は F + 3s/√50。効く水準の 3×10⁻²・10⁻¹ は 97.5%。
- **箱 2（否定対照）**: 5+1 CIFAR × MLP × ReLU（std・Adam 1e−4・30 課題・R = 10 の束ね）。λ = 5・10（τ = 2.6・1.3 課題）。R と L2 Init（λ 1e−2）の committed の記録を bit 照合して再利用した。判定は後期窓（hard 21–29）で、R と L2 Init の中点との符号検定に Holm をかける。
- 検査は 16 項目すべて PASS で、列挙した変異 48/48 を検出した。λ = 0 の経路は l2cap の ref と bit 一致（S0）。勾配 0 の座標は 1 歩で fl₃₂(p·c) と bit 一致し、coupled L2 とは違う（S-wd）。torch.optim.AdamW との差は登録した丸めの帯の 0.07 倍（箱 1）・0.10 倍（箱 2）で、coupled の Adam は帯の外（S-torch）。走の中でも、死んだ画素の W1 が全課題で c の反復と bit 一致した（S-deadpix・(C)）。読み出しだけの WD では、隠れ層の幅が ref と同じく伸びる（S-ctrl。σ2 38.8 対 ref 20.5、全テンソルの WD は 0.62）。

## 2. 読み

- **救ったのは λ = 10⁻¹ だけ**。spec §5.7 により、V12 の WD の文は「λ = 10⁻¹（τ = 1.7 課題）だけで」と限定する。登録の「τ ≤ 走/10 なら救う」は、2 水準のうち 1 つしか立たず支えられない。λ = 3×10⁻² は機能を床の上に保ったが、第 2 層の応答を守れなかった。T1_LOWER が立った 2 腕では「可塑性を守った」と書かない。水準を併記すると、λ = 10⁻¹ の主窓 0.817 は自分の task 1（0.778）とも ref の task 1（0.797）とも同じか上である。
- **幅は止まったが、止まった場所が生死を分けた**。効く 2 水準とも幅は止まった。行ノルムは回転平衡（Kosson 2024 の AdamW の釣り合い）の 1.6〜2.3 倍で、乱歩だけの値より大きい。課題ごとに揃った押しが乗ったと読める（報告の格）。止まった第 2 層の幅と相対位置は、λ = 10⁻¹ で σ2 0.60・d2 +0.59、λ = 3×10⁻² で σ2 12.3・d2 −1.82 だった。後者は float32 の零点 z = −16.64 の線を越え、厳密に 0 の対が 65% になった（正規近似 Φ(−(16.64/σ2 + d2)) は 68%）。spec の中心の見積もり σ2 2.3 が外れたのは、第 1 層の幅（σ1 3.0）とともに r2 = σ2/‖w2‖ が 4.8 まで伸びたため。**幅を止めるだけでは足りず、零点の線より手前で止まる必要がある。** [[H5とWD_幅成長による応答消失を防ぐ条件_1010]] の言う「幅の有界化」は、どちらの水準でも実測で成り立った。ただし第 2 層の応答が実際に残った（厳密に 0 の対が 0%）のは λ = 10⁻¹ だけ。λ = 3×10⁻² では幅は有界でも、対の 65% が零点の線の下にあった（有界であることと、床から離れていることは別）。
- **報告のみ**: λ = 3×10⁻² は崩れかけてから戻った（T½ は課題 10〜16。そのあと適合率 1/2 を上回る課題が来る「戻り」が 8/10 seed）。λ = 10⁻² に戻りは無かった。λ = 10⁻³ は崩れた後、死んだ重みが減衰で縮むだけ（第 2 層の行ノルムは 3.85 → 2.58）。
- **箱 2 では、原点への縮めはゲートを動かしたが、水準は戻らなかった**。第 2 層の相対位置は −1.57 → −0.54・−0.38、開いた（画像, unit）の対の割合は 0.14 → 0.43・0.46 に上がった。死んだ unit の割合は R と差を示せない（0.27・0.39 対 0.34）。階数 eff_rank l2 は 9.6 → 4.2・3.6 に落ち、W2 の行ノルムは 0.69 → 0.07・0.05 に縮んだ。早期窓から R より 0.13・0.16 低い（IMPAIRED）。早期 → 後期の低下（0.12・0.10）は R の 0.17 より小さいが、水準は全期間で R の下にある。t29 では、同じ AdamW の新しい網のほうが 0.25 よく学ぶ。spec §2.5 の「全層を縮めると bias の比重が上がり、階数が下がる」と同じ形（報告のみ）。「WD は ReLU の閉じたゲートを開けられない」とは書かない。
- C-snp: 較正 seed 100–109 で、adamw10 − S&P（ε 1e−3・σ 1e−4、≈ λ 10 の AdamW）= −0.029 [−0.046, −0.017]。S&P の縮めだけのセルは AdamW の近い代わりだが、同じではない。
- spec §1.3 が引く「RL-MNIST の coupled L2 が ReLU を 98.9% 救った」は、元の per_task.csv から ρ = 0.9887（A(31–50) 94.02 対 ref 12.55、seed 0.984〜0.992）で一致した。98.9% は時間劣化の除去率で、L2 の腕は task 1 から 94.97（ref 97.00）と低い所から始まる。箱 2 の結果は decoupled WD についてのもので、coupled L2 には広げない。

## 4. 限界

- 2 箱・この λ・この予算の範囲の結果。乱数ラベル MNIST の ELU→ELU（6,000 更新/課題・100 課題）と、5+1 CIFAR の ReLU/std（lr 1e−4・30 課題）だけ。SiLU・GELU は測っていない。
- RESCUED は「この箱の 100 課題で床に落ちなかった」の意味で、無限時間の非崩壊ではない。online は学ぶ速さで、到達点ではない。
- 箱 2 は λ ∈ {5, 10} だけ（λ < 4.27 は走っていない）。中心化との比較は範囲外。釣り合いの式は既知で、新規性は主張しない。独立監査なし。
