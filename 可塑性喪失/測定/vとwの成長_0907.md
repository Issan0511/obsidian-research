## 1. v も増える。しかも先に増えて止まる

`LRoff0_1216`（a=0.1・c=0・lr 0.01・5M）の中央値:

|---|---|---|---|---|---|---|

| 100k（10 タスク） | −1.164 | 1.152 | **−1.010** | 0.533 | 1.677 | 0.894 |

| 5M | −3.728 | 3.798 | **−0.982** | 0.600 | 4.035 | 2.422 |

- **v は最初の 10 タスクで ×6.3 に跳ね、そこで止まる**（以後 0.53 → 0.70 → 0.60 と横ばい〜微減）。

- **両方増えているので、ゲージ（W,b を s 倍・v を 1/s 倍しても leaky なら関数は不変）だけの漂流ではない。** ただし **1M 以降は w ×1.25・v ×0.89・積 ×1.10** で、後半はほぼゲージ方向。

## 2. 「押し下げ」と「太り」は同じ運動

**z̄/半幅 は 10 タスクで −1.0 に固定され、残り 490 タスクで z̄ が 3.2 倍・半幅が 3.3 倍になる間ずっと −0.96〜−1.01 のまま。** z̄ = −半幅 は **zmax ≈ 0**、つまり**支持の上端が折れ目に釘付け**であることと同じ（実測 zmax 中央値 +0.11）。

→ **`offset_grid` §3-3 で「未解明」としていた幅の成長は、押し下げと独立な現象ではない。** 1 つの運動（上端を折れ目に留めたまま支持が下へ伸びる）を、z̄ で見るか幅で見るかの違い。[[命題1-5_上端則結果_0905]] の上端則がその運動の保存量。

lr 1/8（40M）では比が **−1.24 に固定**（zmax ≈ −0.93）。full-batch は zmax −0.52、online lr 0.01 は +0.11。**雑音の量が上端の座る位置を決め、比はそのあと一定に保たれる。**

## 4. 訂正

`act_offset` の読みで「c>0 で \|v\| 0.60 → 0.06」と書いたのは**腕どうしの末尾比較**（c=0 の腕の 0.60 と c=+0.5 の腕の 0.06）であって時間発展ではない。時間発展で見ると c=+0.5 の \|v\| は 0.085 → 0.115（**×1.35 しか育たない**）。正しい言い方は「**v が潰れる**」ではなく「**v が育たない**」。井戸の底に座る腕では、読み出しが最初から伸びない。

## 5. 次

1. **z̄/半幅 = 一定（上端釘付け）を登録判定にする** spec。「幅の成長」を主題にした spec（[[前活性オフセット格子結果_0906]] §8-2）は、この比の保存を主判定にすれば 1 本で書ける。
2. 比が固定される値（−1.0 / −1.24 / full-batch）が雑音の量で決まる法則。`edge_law` の上端則と接続する。
3. 後半がほぼゲージ方向という観察は、**「太り」を関数空間の量（積 \|v\|·‖w‖ や実効ゲート mob）で測り直す**必要を示す。

## 6. v は抑えられている——抑えているのは雑音（Issa「v が爆発するのは復元力で抑えられるべきじゃね」）

ユニットの出力パワー v²·E_支持[φ²] とその全ユニット和で見る（`m_phi2` は実測列）:

| 腕 | step | ユニット中央値 v²E[φ²] | Σ_i v²E[φ²] | unfit |
|---|---|---|---|---|
| **online lr 0.01** | 0 → 100k → 500k → 2.5M → 5M | 0.0004 → 0.0090 → 0.0425 → 0.0792 → **0.0722** | 0.53 → 6.4 → 15.1 → 17.1 → **14.0** | 1.006 → 0.0002 → 0.0005 → 0.0001 → 0.0012 |
| **full-batch（雑音ゼロ）** | 同 | 0.0004 → 0.0121 → 0.0700 → 0.3608 → **0.5901** | 0.53 → 10.3 → 19.2 → 70.0 → **100.0** | 1.006 → 0 → 0 → 0 → **0** |
| **c=+0.5（底が届く）** | 同 | 0.0031 → 0.0047 → 0.0001 → 0.0001 → **0.0001** | 1.19 → 6.2 → 0.32 → 0.36 → **0.22** | 1.006 → 0.168 → 0.406 → 0.522 → **0.520** |

- **online では出力パワーが 500k で頭打ちになり、その後は微減**（15.1 → 14.0）。fit は 1e-3 のまま。**v は爆発していない。**
- **雑音を消すと同じ箱で ×190 まで伸び、5M でもまだ伸びている**（fit は厳密に 0）。**止めているのは fit ではなく雑音。**
- \|v\| の init→tail 比を雑音の量で並べると **full-batch ×19.4 > lr 1/8 ×14.7 > lr 0.01 ×7.07** で単調。**雑音が多いほど v が育たない。**
- **c=+0.5（各ユニットの零点が手の届く所にある腕）では復元力が勝ち切る**: 出力パワーはピークから ×28 潰れ、fit は 400 倍悪化（0.0012 → 0.52）。**「出力を消す力」は実在し、零点が届けば fit を犠牲にしてでも通る。**

**読み**: 復元力は v そのものではなく**ユニットの出力 v·φ に効く**。c=0 では出力を消す道が v→0 しかなく、fit がそれを止めるので**頭打ち**になる。c>0 では z を下げるだけで出力が消えるので、fit を壊してでも**潰れる**。そして頭打ちを作っているのは雑音誘起のドリフト（[[前活性オフセット格子結果_0906]] §3-2 の Chen 型と同じ向き）。

**幅との対比が効く**: ‖w_free‖ の成長は雑音に依らない（×5.05 / ×5.34 / ×4.68 = lr 0.01 / lr 1/8 / full-batch・一次）のに、**v の成長は雑音で 3 倍近く変わる**。**w は決定論的に育ち、v は雑音に抑えられる**——別々の機構。

**次**: 雑音量 × 出力パワーの梯子（lr と full-batch の間を埋める）を登録判定にすれば、「雑音が v を抑える」を主判定 1 本で書ける。効果量の下限を必ず併記すること（[[折れ目を滑らかに_結果_0907]] §4-1）。

## 7. c<0 の「謎の釣り合い」の正体（Issa のアニメーション観察）

> Issa: 「c がプラスのときは分布が全部 leak した方へ行く単純な動き。c がマイナスだと −c 近傍は中心に縮むのに、折れ目を超えて leak した人達はそのまま下に押されていって、**折れ目が裾に来るような謎の釣り合い**で安定する」

支持 32 点のうち**折れ目より上にある割合**を時系列で取ると、これは正確に測れる:

| 腕 | step | z̄ | 半幅 | z̄/半幅 | **折れ目より上の割合** |
|---|---|---|---|---|---|
| c=0 | 100k → 5M | −1.16 → −3.73 | 1.15 → 3.80 | −1.010 → −0.982 | **0/32 → 0/32** |
| **c=−0.5** | 100k → 5M | −0.70 → −2.06 | 1.20 → 2.68 | −0.585 → **−0.769（500k で固定）** | 4/32 → **1/32（500k 以降ずっと）** |
| c=+0.5 | 100k → 5M | −2.39 → −4.99 | 0.98 → 1.05 | −2.44 → **−4.77** | 0/32 → 0/32 |

**c=−0.5 の釣り合いは「支持 32 点のうちちょうど 1 点だけが折れ目の上に残る」**。500k 以降 4.5M step にわたって 1/32 のまま動かない。Issa の「折れ目が裾に来る」はこれ。

### 機構（事後の読み・登録なし）

1. **ラチェットは支持が折れ目を跨いでいる間だけ働く**（3 分割の作動条件・線形域は釘付け [[命題1-5_上端則結果_0905]]）。
2. だから**押し下げは自分の成功で止まる**——下がるほど跨ぎが減り、跨ぎが尽きると力が消える。
3. 一方で**幅は決定論的に育つ**（雑音に依らず ×4.7〜5.3）ので、上端 zmax = z̄ + 半幅 を押し上げ**跨ぎを作り直す**。
4. 釣り合うのは **zmax ≈ 一定**（＝ z̄ の下降速度と半幅の成長速度が等しい）ところ。実測: 100k → 5M で **Δz̄ = −2.564、Δ半幅 = +2.646（差 3%）**。
   → **これが上端則の中身。押し下げは幅の成長のサーボであって、独立な現象ではない。**
5. **c の効果はこの釣り合い点をずらすだけ**:
   - **c<0**: **下枝に零点は無い**（φ+c = az+c の形式的な零点 +|c|/a は z>0 側で、下枝の定義域の外）。下枝では (az−|c|)² が z について**単調減少＝極小の無い坂**で、力は **2a(|c| − a z)** と**上向き**。**本物の井戸は ReLU 側（上枝）の z = −c = +|c|** にあり、そこに届いた「上」群は a を振っても +0.50 ちょうどに座る（[[前活性オフセット格子結果_0906]] §3-1）。折れ目での引きは下枝が上枝の **a 倍（=1/10）** しかないので、leak した人達は井戸へ戻れず、**弱い坂とラチェットの釣り合い**で 1/32 の足がかりを残す位置に止まる（比 −0.77）。着座点での上向きの力は c=0 が 2a²|z̄| = 0.075、c=−0.5 が 2a(|c|+a|z̄|) = 0.141 で **2 倍強い方が 1.7 倍浅い所で止まる**（整合）。
     **（2026-09-07 訂正: 初出で「下枝の零点 +|c|/a の井戸が引く」と書いたのは誤り。定義域の外の点で、「底が支持と同じ線形域にあるときだけ座る」という登録済みの法則に自分で反していた。Issa の指摘。）**
   - **c=0**: 下枝に零点が無い（φ = a z）ので上向きの引きが無く、**上端がちょうど折れ目に貼りつく**（比 −0.98・0/32）。
   - **c>0**: 下枝の零点 −c/a が**手の届く所**にあるので、ユニットは折れ目を捨てて底へ落ちる（比 −4.8）。しかも E[(az+c)²] = (a z̄+c)² + a²E[u²] は**幅そのものも罰する**ので半幅が育たない（×1.58・c=0 の ×5.05 に対して）。Issa の言う「全部 leak した方へ行く単純な動き」。
6. **v を凍らせるとこの釣り合いは壊れる**（上 +12.8 / 下 −11.8 の二峰・半幅 9.9）。上端則は v の適応込みの現象。

**次**: 「Δz̄ = −Δ半幅（zmax 一定）」を主判定にした spec。効果量の下限つきで（[[折れ目を滑らかに_結果_0907]] §4-1）。c を振ると釣り合い点が 0/32 → 1/32 → 折れ目を捨てる、と動くので、**c を「跨ぎの足がかりの数」で読む**のが自然。

### 7-2. 訂正 2（Issa「引きが弱いでは説明できない・山の頂上が折れ目から遠い」）

§7 の「弱い坂とラチェットの釣り合いで止まる」は、**力の大きさが位置を決めているように読めるので誤り**。跨ぐ群の上端を c ごとに測ると:

| c | 上/跨/下 | z̄(跨) | **zmax(跨)** | 半幅(跨) |
|---|---|---|---|---|
| 0 | 0/59/41% | −3.39 | **+0.44** | 3.97 |
| −0.25 | 0/77/23% | −2.73 | **+0.46** | 3.28 |
| −0.5 | 10/84/6% | −2.04 | **+0.65** | 2.76 |

**上端は c を振っても +0.2 しか動かないのに、山は 1.35 動く。** 山の位置 = 上端 − 半幅 で、山が折れ目から遠いのは幅が広いから。

**機構は bang-bang**: ラチェットは跨いでいる間だけ ON なので、zmax = 0 が ON/OFF の切り替え面。跨いでいれば下へ、跨ぎが尽きれば坂だけで上へ → **系は切り替え面に貼りつく**。位置は力の大きさに依らず、順序（跨ぎ中はラチェット > 坂）だけで決まる。

c<0 の坂の役割は位置決めではなく、(1) ラチェットより弱いこと（強いと上端が折れ目を越えて支持全体が ReLU 側に入り、ラチェットが切れて +|c| の井戸に捕まる＝c=−0.5 の「上」群 10%）、(2) 沈み切るのを防ぐ床（下群 41% → 6%・跨ぐ群 59% → 84%）。**何人を切り替え面に留めるかを決める。**

外れた仮説: 「上端が上枝の零点 +|c| に座る」→ zmax の c=0 からのずれは +0.02 / +0.21 で |c| = 0.25 / 0.5 に乗らない。棄却。

## 8. 「上端に下向きの力」の微視的な理由 —— 候補（戻りの非対称）は棄却、機構は未解明（Issa の問い）

**厳密に言えること**: b の勾配は ∂L/∂b = 2v[a·E[δ] + (1−a)·E[δ·1{z>0}]]。c_out が E[δ] を消すので、**ユニットの位置は折れ目より上の点の残差だけで操舵される**。制御変数が山でなく上端なのはこのため。

**候補の機構（対称な蹴り × 非対称な戻り）を末尾 20 タスクの密記録で検査** → **棄却**。
蹴り K′ = z̄(境界+1000) − z̄(境界)、タスク内の戻り R = z̄(境界+10000) − z̄(境界+1000)、正味 T = K′+R（`flip_state` は行 10000k で旧・10000k+1000 で新）:

| 腕 | E[K′] | E[R] | E[T] | R/K′（上蹴り / 下蹴り） | \|K′\|（上 / 下） |
|---|---|---|---|---|---|
| a=0.1 | **−0.027 ± 0.005** | **+0.025 ± 0.001** | −0.002 ± 0.005 | +0.085 / +0.013（跨ぐ） | 0.60 / 0.70（跨ぐ）|
| a=0.7 | −0.010 | +0.010 | −0.001 | −0.15 / −0.22（両側とも部分的に戻る） | 0.095 / 0.105 |
| v 凍結 | +0.005 ± 0.011 | −0.003 | +0.002 ± 0.015 | +0.25 / +0.27 | 1.21 / 1.26 |
| full-batch | −0.006 | +0.002 | −0.004 ± 0.003 | +0.03 / +0.03 | 0.48 / 0.50 |

1. **蹴りはタスク内でまったく戻されない**（a=0.1 で R/K′ ≈ 0.01〜0.09・むしろ蹴りの向きに少し進む）。a=0.7 は両側とも 15〜22% 戻るが**上下で対称**。「上蹴りは速く戻り下蹴りは戻らない」は成り立たない。→ **戻りの非対称というラチェット像は棄却**（1000-step 分解能で）。
2. 末尾は**定常の鋸歯**: タスク内の学習が z̄ を +0.025/タスク 上げ（w_flip が現タスクの反転パターンに揃う＝現支持での z̄ が上がる）、反転がそれを −0.027/タスク 失わせる。差し引き 0 ＝ 定着。
3. **「跨いでいるユニットは下へ動く（−0.21/タスク）」は力ではなく平均への回帰**。蹴り前に跨ぐ群は \|K′\| が 上 0.60 / 下 0.70 で下寄り、跨がない群は 上 0.39 / 下 0.27 で上寄り。z̄ = b + w_flip·x_flip の x_flip 越しの揺らぎ（±0.5）を状態で条件付けているだけ（[[peak-final-max-selection-bias]] と同じ罠）。**これを「上端に下向きの力」と読んではいけない。**
4. **v 凍結は鋸歯が無い**（E[K′] ≈ E[R] ≈ 0・蹴りは ±1.2 で対称・R/K′ は両側 +0.25 で蹴りを増幅）。サーボが壊れて ±12 へ走るのはこの「増幅・回帰なし」の姿。

**結論**: 走の前半（100k→5M で −2.56）の沈下を作る微視的機構は**まだ分かっていない**。末尾の密記録は定着後なので機構が見えない。**決定実験**: 沈下中（100k〜2M）に、反転直後を 10 step 刻み・以後 100 step 刻みで記録し、蹴りと戻りを中心が動いている最中に分ける。`edge_law` の recorder に「境界密」モードを足すだけで済む。
