# 恒等式11.1で幅の収縮閾値を検証 — 0916

依頼: Issa。親: [[駆動源問題_0909]] §11.1、[[φφ′積分と幅の侵食_事後検証_0916]] §8。既知の結果を踏まえた事後検証。新しい長期学習ではなく既存軌道の再生・計測。

## 結論

**収支の閾値は実更新と整合するが、Leakyの傾き0.6自体が普遍的な収縮閾値だとは確認できなかった。** 同じaでも学習時点で収支が変わり、層の平均分散と典型個体の幅で結論が分かれる。

さらに、今回のCondAではタスク内の時間順序が想定と逆だった。**切替後の最初の1000更新は縮み、残り9000更新で広がる。** a=.55/.60、初期・後期の両窓、全重みノルム・行平均除去ノルム・前活性分散の全てについて、10タスク平均をとった各seedで10/10。個々のタスクや更新が全て同じ符号という意味ではない。PM/Adamに広げない。

## 測定範囲・再現

- CondA/SGD、lr=.01、batch=1、7傾き(.35,.4,.45,.55,.6,.65,.8)×10seed。
- step0と1Mの既存checkpointから各100000更新（task1–10、101–110）。
- 入力生成乱数列を復元し、元のWノルム・vを1000更新ごと、自由5重みを10000更新ごとにbit一致確認。14窓、合計1414照合時点、各10seed。
- 二乗ノルム帳簿の一更新誤差最大1.95e−14、窓積算誤差最大1.89e−12。S+H−B−Cと勾配射影の相対差最大1.21e−7（float32演算）。
- 一致は恒等式と計測の検算であり、未来予測や機構の独立な証明ではない。前のBA50.9%は開始時のφφ′だけで次タスクを当てた別の検査。

## 収支比

各更新の実際の増分をUとし、−2w·Uが正の分の和を侵食E、2w·Uが正の分の和を回復R、||U||²の和を増分Jとする。正味変化はR+J−E。

$$K_i=\frac{E_i-R_i}{J_i},\qquad K_i>1\iff\text{個体iの幅が収縮}.$$

ここで回復は外向きの更新成分の名称であり、性能回復ではない。CondAの前活性分散は||w_free||²/4なので、その座標で帳簿を取る。タスク正味増分を一回の更新とみなさず、各更新の内積を積算した。

傾きa=.6の個体中央値→seed中央値:

| 測定窓         | 個体ごとの収支比Kの中央値 | 前活性標準偏差の終/始比 | 収縮する個体の割合 |
| ----------- | ------------- | ------------ | --------- |
| task1–10    | 0.591         | 1.296        | 34.0%     |
| task101–110 | 1.070         | 0.962        | 53.5%     |

後期は個体中央値で8/10seedが縮小。一方、層全体の平均分散は6/10seedで増加し、層の合計から作る収支比のseed中央値は0.963。少数の大きな増加が多数の小さな減少を上回る。個体別の閾値と、層の合計の閾値を混ぜない。

a=.55の個体収支比は初期0.416→後期1.111、標準偏差の終/始比は1.451→0.925。今回の窓では.55と.60の間で普遍的に成長→収縮を挟むという結果にはならなかった。

## φφ′を含む自己項は何をしているか

MSEで残差をv_iφ_i+R_iと置いた自己項を、読み出しv_i²と入力の幅方向で重み付けて積算した。φφ′の単純和ではない。

a=.6・task101–110の自由入力分散への寄与（各個体平均→全seed平均、10タスク積算）:

| 項         | 分散への寄与    |
| --------- | --------- |
| φφ′を含む自己項 | −27.32281 |
| その他の勾配項   | +26.99193 |
| 各更新の二乗増分  | +0.33430  |
| 実際の正味変化   | +0.00341  |

浮動小数の微小な残差は別に記録。大きな自己項と残りの項が相殺し、**回復後にも残る内向きの差約0.331と、二乗増分約0.334が競合**していた。増分は切替直後に一度だけ入るものではなく、学習中の各更新にある。この成分の帳簿から因果的な除去効果の割合は算出しない。

## 時間帯の実測

a=.6・task101–110、各seed内で10タスクと個体を平均した分散変化、そのseed中央値:

| 切替後の更新区間   | 分散変化      | 符号を共有するseed |
| ---------- | --------- | ----------- |
| 0–20       | −0.001184 | 収縮10/10     |
| 20–100     | −0.002936 | 収縮10/10     |
| 100–1000   | −0.010086 | 収縮10/10     |
| 1000–10000 | +0.014511 | 拡大10/10     |

区間ごとの変化量であり、長さの違う区間の学習速度をそのまま比較しない。中央値どうしは加法的でないため、全区間の正味との閉包はseed別CSVで確認した。

## 限界・残る問い

元の5M初期/最終比では、a=.6の典型個体の幅は0.809倍。今回の短い窓の符号だけでその全履歴を説明したとはしない。初期10タスクでは同じa=.6でも1.296倍だった。

この検証で分かったのは、単純なφφ′合計の閾値では取り落とす相殺、継続的な二乗増分、個体と層の集約差、タスク内の時間構造である。なぜ学習された状態がその収支を作るのか、なぜ長期の最終/初期比が.6付近で1をまたぐのかは、恒等式の閉包だけでは導出しきれない。Adamの長期比較は今回は行っていない。
