# 小さい読み出しで上端が伸びる理由 — 正解対応と沈下を分離

親: [[出力を上げる需要と読み出し縮小_勾配と実更新の分岐_結果_1111]]・[[ELUが沈降しない事件_総まとめ_0929]] / 状態: **検証中**（この一層ELUでの方向・介入対照は完了。長期の全媒介割合は未同定） / 更新: 2026-11-11

Issa の問い: 「読み出し縮小だと、なぜユニットの出力を上げようとするのか。沈下は別に止まっていない。その原因を検証してほしい」。前の説明のうち、上昇を主に『最初の沈下を弱めて応答を残したから』で説明する部分を、この対照で補う。

数値の正本は `lop_analysis/results/readout_lift_1111/summary.md`・`verdict.csv`、追加対照は `followup_summary.md`・`followup_verdict.csv`。同一状態の交差比較は `mechanism_summary.md`。コード・仕様・失敗した対照も保存。原稿本文は変更していない。

## 1. この検証で分かったこと

**上向きの駆動源は、新しい正解との対応を学ぶ更新である。読み出しを小さく固定しても、負側本体を対照と同じ時系列で沈ませても、正解に役立つ入力への応答は大きく育った。固定された入力と正解の対応をなくすと、その成長は消えた。**

これは「縮めると全入力の上向き勾配が強くなる」という説明ではない。上向き・下向きの要求の両方が弱まり得る。その釣り合い、予測確率、およびどの入力に強く反応するかが学習中に変わる。全体の沈下と、特定入力への応答の成長は両立する。

## 2. どの入力を上げたいのか

活動 $a_i=\phi(z_i)$ に届く勾配は

$$D_i=\sum_c p_cV_{ci}-V_{yi}.$$

$D_i<0$ が活動を上げる要求である。あるユニットの読み出しが正解クラスを最も強く支持していれば、

$$D_i=-\sum_{c\ne y}p_c(V_{yi}-V_{ci})\le0.$$

その入力には上向きの要求がある。一方、同じユニットでも別の正解を持つ入力には下向きの要求があり得る。全入力に同じ指示が出るわけではない。

一様ラベル期待 $u_c=1/10$ を使うと、厳密に

$$D_i=\underbrace{v_i^\top(p-u)}_{D_i^U}+\underbrace{v_i^\top(u-y)}_{D_i^Y}.$$

$D^U$ は一様な予測を目指す損失の勾配、$D^Y$ は固定された正解との対応を含む項である。これは勾配の分解であり、両項をそれぞれ長期的な『原因割合』と呼んではいけない。特に $D^Y$ だけの損失は下に有界でないため、単独学習を正常な最適解の証明には使っていない。

**小さい読み出しでは、活動が同じでも予測確率 $p$ が変わり、二項の釣り合いが変わる。** 正解に沿う活動を増やす要求が、より大きな活動まで残り得る。大きさだけの逆伝播倍率では符号は変わらない。

この点を、既に学んだ同じ活動に対して直接確かめた。Vを0.1倍で固定した枝の課題10末、現在の上位5%入力群、3seed平均。前向きのV倍率変更では、その時点のクラス別平均logitを保つよう出力biasを補正する。

| 同じ状態への仮想操作                |  群の平均 $D$ |
| ------------------------- | --------: |
| 小さい読み出しのまま                | −0.010214 |
| 予測を固定し、逆伝播のVだけ10倍         | −0.102138 |
| Vはそのまま、予測確率だけ10倍Vで得たものへ交換 | +0.001713 |
| Vと予測をともに10倍時へ変更           | +0.017135 |

予測を固定した倍率変更は符号を保ち、予測確率の変更で平均要求が下向きへ反転した。課題25でも同じ向きで、両課題とも各3seedで成り立った。これは現在の同じ群での局所対照であり、全入力が同じ符号へ変わるという意味ではない。出典: `mechanism_summary.md`・`frozen_cross_end.csv`（arm=V01, step=4000, group=current_top）。

## 3. 本体の沈下を同じにしても上端は伸びる

介入前に $z\le-3$ だった入力を各ユニットの固定本体 $B_i$ とした。全6状態で100ユニットすべてが30入力以上を持つ。元の大きい読み出しを固定した軌道から、各更新時刻の本体平均 $m_i^{ref}(t)$ を保存した。

追加対照では、前活性を

$$z_{ni}=w_i^\top(x_n-\bar x_{B_i})+m_i^{ref}(t)$$

と置き、**全腕で本体の平均位置を毎更新同じにした**。勾配もこの式を微分したものを使う。新しい座標に合わせ、WのAdamは全4腕で同じように初期化した。読み出しVは固定し、出力biasは学習を続ける。

以下の上端は『各ユニットの最大前活性を取り、その100ユニット中央値』。正側ではELUの活動と一致する。負の値をそのままELU出力とは読まない。4,000更新後、3seed平均。

| 条件                         |    課題10の上端 |    課題25の上端 | 課題10の訓練精度 |
| -------------------------- | ---------: | ---------: | --------: |
| 元の大きい読み出し固定・新しい正解を学ぶ C1    |      7.857 |      9.247 |    66.14% |
| 読み出し0.1倍固定・同じ正解を学ぶ C01     | **18.257** | **22.149** |    62.28% |
| 0.1倍固定・正解を毎回ランダムに引き直す C01R |      3.164 |      3.391 |    10.78% |
| 0.1倍固定・一様な確率を目標とする C01U    |     −1.165 |     −0.964 |    10.72% |

開始時の上端は課題10で8.380、課題25で9.508。本体平均の開始から末尾への変位は**すべての腕で**課題10 −1.253、課題25 −0.887。本体の時系列の最大不一致は9.54×10⁻⁷だった。C01で同じユニットの『本体が0.1以上下がり、上端が0.1以上上がる』割合は66.3%／44.7%だった。

小Vと大V、小Vと一様目標、小Vと毎回ラベルの全対照が、両課題・各3seedで登録方向だった。一様目標の損失も安定し、課題末は両課題とも約log(10)。出典: `followup_summary.md`・`followup_verdict.csv`、窓は0→4000。

本体軌道は課題内で一度沈んで戻る部分を含み、4,000更新のあいだ単調に沈み続けるという意味ではない。図を見た後の事後確認では、200→500の窓で本体平均がさらに下がり、上端が上がることも全6状態で起きた（`mechanism_summary.md`、明示的に事後）。

## 4. 自然な軌道の上向き更新と、入力の入れ替わり

本体への外力を入れない対照でも、Vを0.1倍で固定すると上端は課題10で8.380→14.277、課題25で9.508→17.693へ上がった。一様目標では末尾1.431／1.291、毎回ラベルでは2.478／2.716であり、安定した入力と正解の対応を消すと上昇は再現しなかった（`summary.md`、V01/V01U/V01R）。Vは全期間で厳密に固定されているため、Vの再成長はこの上昇に必須ではない。

実際のAdam一歩を、当初の一次moment・一様目標の勾配履歴・正解対応の勾配履歴に分けた。課題10、最初に上位5%だった固定入力群、200/500/1000/2000の4probeを各seed内で平均してから3seed平均すると:

| 読み出し        |   正解対応の寄与 |   一様目標の寄与 |  合計の前活性変位 |
| ----------- | --------: | --------: | --------: |
| 元の大きさを固定 V1 | +0.018730 | −0.019622 | −0.000892 |
| 0.1倍で固定 V01 | +0.004124 | −0.003891 | +0.000233 |

**上向きの寄与自体は小さくなっているが、下向きとの釣り合いが変わっている。** この分解は実測された同じAdam分母での会計であり、項を消したときの軌道や因果割合ではない。課題25でも固定上位群への正解対応の寄与は全3seedで正だった（`late_sources.csv`・`mechanism_summary.md`、P5）。

さらに、Vが固定なら $D^Y(x,i)$ は入力ごとに時間不変である。それでも**現在の上位5%群**の平均 $D^Y$ は、課題10のV01で開始時 +0.000427→末尾 −0.026130へ変わった。上端を占める入力が、新しい正解に役立つ方へ入れ替わったためである。最初の上位群に固定すると $D^Y$ は変わらない（登録済み `demand.csv` の group=upper/current_top）。

事後の入力選択監査でも、V01の現在上位5%に元の上位5%が残る割合は46.5%、読み出しの最大クラスと正解が一致する割合は9.82%→18.47%。追加対照C01でも、同じ沈下の下で読み出しの正解支持度が上位群で増え、一様・毎回ラベルの対照では増えなかった（`selectivity_posthoc.md`。これは事後診断で、追加の独立反復ではない）。

## 5. 失敗した対照を残す

最初の位置合わせは、普通のAdam更新の後にhidden biasだけを補正する方式だった。正解学習では本体が同じ深さでも上端が伸びたが、一様目標の腕でも上端が暴走し、課題10のCEは50.66、精度9.56%になった。これは有用な表現の成長の証拠ではなく、**外部のbias補正が更新を押し返す副作用**を含む。元の登録P4の『正解学習が一様目標より上端を伸ばす』は不支持のまま保持する。

この結果を見た後に、追加仕様 `98cde383` を登録して、位置制約を含む損失の正しい勾配へ変更した。追加対照はその修正後の別モデルであり、当初から予測していた結果のようには扱わない。WのAdam初期化も全腕に共通する変更である。自然なQの改善のうち何割が各機構によるかは、この対照からは出さない。

## 6. 既存の長期走との範囲の違い

9月のvfreezeを事後再集計した。課題151–200・各課題開始時に開口があるユニットを選び、unit中央値→課題平均→2seed平均。元のbodyは各unitの全入力の**中央値**であり、今回の固定深部平均とは異なる。

V0.1固定でも0→500のbody変位は−2.254。500→4000には上端が+2.414戻り、課題全体0→4000ではbody −1.465・上端 −1.200だった。従って『小Vなら上端が毎課題を通して必ず増え続ける』とは言えない。課題内の戻りと、切替を重ねる長期の沈下を区別する（`old_vfreeze_posthoc.md`）。
