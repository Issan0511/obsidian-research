# 第1層の増幅器は Adam か — RL-CIFAR LE への ε 介入（le_eps_cifar_0922）

## 問い

S-A の LE（leaky→ELU, raw）で第2層が t2–t5 に死ぬのと同時に、第1層の正側ユニットが a₁ rms 4 → 88、‖µ₂‖ 48 → 847 まで伸びる。Issa の仮説（12:4x）: 第2層が −1 に張り付き W₂ が µ₂ に反平行なら、要求される修正 δh を届けるには δz = δh·e^{|z₂|} が要り、その指数的な要求が第1層に伝わって伸ばす。Claude の位置づけ: 逆伝播は e^{z₂} 倍に**減衰**させ、戻すのは Adam の正規化。ならば ε を上げれば伸びは消える。

## 読み

1. **Adam の正規化は増幅器の速さで、存在ではない。** 伸びは ε で単調に 4〜5 分の 1 に縮むが LL には戻らず、t5 以降も伸び続ける（e3: a₁ rms 15 → 23、‖µ₂‖ 142 → 220、z̄₂ −104 → −194）。√v ≪ ε の域は SGD（実効 lr = lr/ε = 1）で、そこでも同じ形（向きは −∇ に cos +0.5〜0.8、行は x̄ に 0.6〜0.7）。
2. **ラチェットは最適化器によらない。** どの ε でも z̄₂ ≈ w₂·µ₂、W₂ の µ₂ への反平行は −0.25〜−0.30 で共通。e3 では W₂ が凍らない（2.26 → 3.05）が向きは変わらず、沈みの担い手は三腕とも ‖µ₂‖。
3. **扉が閉じる速さだけ変わり、死ぬ時刻は変わらない。** 勾配を運ぶ画像は t5 で 0 / 16 / 333、t50 で 0 / 3 / 7。online t3 は 0.12 / 0.18 / 0.36、T_A は 3。
4. **Issa の仮説の位置。** 「指数的な要求が第1層に伝わる」は最適化器を SGD 寄りにしても残ったので、要求の伝達は Adam の産物ではない。私の「増幅は Adam が実現する」は速度と扉の閉じる速さの差まで。骨格（少数対の要求 → ±x̄ に揃う一歩 → 反平行の W₂ 経由で残りが沈む）は ε に依らない。
5. **健康側**: LL の窓は変わらないが t1 の a₁ rms 4.5 → 3.3、‖µ₂‖ 23 → 18 で健康な成長も 2 割鈍る。

## 未検査

SGD そのもの（lr 掃引）。e3 の t5 以降の伸びが実効 lr=1 の SGD として量的に合うか。MNIST（EE）で同じ ε 介入。

## 検査

S1 `--eps 1e-8` は S-A LE と rows・snapshots bit 一致。S2 ε=1e−3 は 10/10 slot の t1 行が変わり、同 ε の torch.optim.Adam replica と 3.7e−8 で一致（ε=1e−8 replica とは 0.029 差）。S3 別 ε での resume 拒否。S4 provenance に adam_eps。生データ 3.64 GB は `obsidian-research-data/le_eps_cifar_0922/`。

## 追補（事後・登録外）: なぜ W₂ の反平行が保たれるか（Claude, 0922 15:xx）

Issa の問い。二つの候補を既存スナップショットで照らした（10 seed 中央値、δ₂ = ∂L/∂z₂、正 = 下げろ）。

1. **「開いた対は自信を持って間違えているから縮めろ」は課題末では外れ。** 課題末（t の状態に t のラベル）の開いた対の |δ₂| 重みつき符号は −0.2〜−1.0（上げろ）、z₂>0 の対で下げろは 0.31〜0.42。残っている要求は反平行を弱める向き。
2. **切替の瞬間（t−1 の状態に t のラベル）は逆で、下げろが揃う。** 重みつき符号 +0.12〜+0.25（t2–t3）→ +0.6〜+0.99（対が減るほど）。W₂ の降下方向の µ̂₂ 成分は切替で負（LE_e8 −0.39, LE_e3 −0.43, LL_e8 −0.30）、課題末では 0.000。つまり **反平行は毎回の切替の衝撃で更新される**（一層の理論を第2層に当てたもの、LL でも起きる）。
3. **床のある層では戻らない。** LL は課題の中で戻す（cos −0.13〜−0.18 で安定）。LE では飽和した 99.8% に勾配が無く、残った「上げろ」の要求は開いた画像 = h₁ が µ̂₂ 成分を最も持たない画像に集中するので µ̂₂ 成分を持たない（proj 0.000）。切替ごとの押しだけが積もり、e3 では w·µ̂₂ が −0.45（t2）→ −0.74（t3）→ −0.91（t50）と 50 回の切替で深まり続ける。e8 は t4 で厳密 0 になって凍る。
4. **l2_wall の「壁定数 −c₂ に釘付け」の読み直し。** 定数ではなく「切替の押しの累積 − 課題内の戻し」で、e8 の一定値は凍結。ε に依らないのは切替の勾配が大きく √v ≫ ε だから。
5. **訂正（15:xx）: ‖µ₂‖ の伸びも切替の「下げろ」が作る。** 平均 h₁ の降下方向 −mean_i W₂ᵀδ₂(i) と µ̂₂ の cos は、切替の瞬間 +0.63 / +0.42 / +0.55（LE_e8 t3 / LE_e3 t3 / LL_e8 t3、以後も +0.3〜+0.45）、課題末 −0.2 / −0.2 / −0.03。δ₂ > 0（下げろ）が反平行な w_j を通ると −δ₂ w_j は +µ̂₂ 成分を持つ。課題末の「上げろ」は逆に ‖µ₂‖ を縮める向きで、ΔW₁ は切替時の勾配と cos 0.3・課題末とは 0 なので、伸びは切替の分。前段の「課題末の上げろが第1層へ届く」は誤り。
   - **一つの要求・二つの径路。** 切替の「下げろ」を満たす径路は (i) W₂ の行を −(µ₂+ξ) へ（反平行を深める）と (ii) h₁ を +µ̂₂ へ（正 unit を伸ばす = 上流の経路）。どちらも z̄₂ = w₂·µ₂ を全画像で深め、飽和した多数は勾配が無く反対しない。LL では正 unit が無く (ii) を傾斜 0.1 の負 unit が運ぶ（cos の正 unit 分 +0.06 対 LE +0.24）ので、‖µ₂‖ 23 → 40・z̄₁ −7 → −40 の「順当な沈下」になる。LE では傾斜 1 の正 unit が運び、床で戻らず、数百まで伸びる。
