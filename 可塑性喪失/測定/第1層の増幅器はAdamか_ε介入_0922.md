# 第1層の増幅器は Adam か — RL-CIFAR LE への ε 介入（le_eps_cifar_0922）

Claude, 2026-09-22。spec `specs/spec_le_eps_cifar_0922.md`、結果 `results/le_eps_cifar_0922/`（main 統合済み）。親は [[層別キメラをRL-CIFARへ_S-A_結果_0922]]。

## 問い

S-A の LE（leaky→ELU, raw）で第2層が t2–t5 に死ぬのと同時に、第1層の正側ユニットが a₁ rms 4 → 88、‖µ₂‖ 48 → 847 まで伸びる。Issa の仮説（12:4x）: 第2層が −1 に張り付き W₂ が µ₂ に反平行なら、要求される修正 δh を届けるには δz = δh·e^{|z₂|} が要り、その指数的な要求が第1層に伝わって伸ばす。Claude の位置づけ: 逆伝播は e^{z₂} 倍に**減衰**させ、戻すのは Adam の正規化。ならば ε を上げれば伸びは消える。

## 読み

1. **Adam の正規化は増幅器の速さで、存在ではない。** 伸びは ε で単調に 4〜5 分の 1 に縮むが LL には戻らず、t5 以降も伸び続ける（e3: a₁ rms 15 → 23、‖µ₂‖ 142 → 220、z̄₂ −104 → −194）。√v ≪ ε の域は SGD（実効 lr = lr/ε = 1）で、そこでも同じ形（向きは −∇ に cos +0.5〜0.8、行は x̄ に 0.6〜0.7）。
2. **ラチェットは最適化器によらない。** どの ε でも z̄₂ ≈ w₂·µ₂、W₂ の µ₂ への反平行は −0.25〜−0.30 で共通。e3 では W₂ が凍らない（2.26 → 3.05）が向きは変わらず、沈みの担い手は三腕とも ‖µ₂‖。
3. **扉が閉じる速さだけ変わり、死ぬ時刻は変わらない。** 勾配を運ぶ画像は t5 で 0 / 16 / 333、t50 で 0 / 3 / 7。online t3 は 0.12 / 0.18 / 0.36、T_A は 3。
4. **Issa の仮説の位置。** 「指数的な要求が第1層に伝わる」は最適化器を SGD 寄りにしても残ったので、要求の伝達は Adam の産物ではない。私の「増幅は Adam が実現する」は速度と扉の閉じる速さの差まで。骨格（少数対の要求 → ±x̄ に揃う一歩 → 反平行の W₂ 経由で残りが沈む）は ε に依らない。
5. **健康側**: LL の窓は変わらないが t1 の a₁ rms 4.5 → 3.3、‖µ₂‖ 23 → 18 で健康な成長も 2 割鈍る。

## 未検査

SGD そのもの（lr 掃引）。e3 の t5 以降の伸びが実効 lr=1 の SGD として量的に合うか。MNIST（EE）で同じ ε 介入。

## 検査

S1 `--eps 1e-8` は S-A LE と rows・snapshots bit 一致。S2 ε=1e−3 は 10/10 slot の t1 行が変わり、同 ε の torch.optim.Adam replica と 3.7e−8 で一致（ε=1e−8 replica とは 0.029 差）。S3 別 ε での resume 拒否。S4 provenance に adam_eps。生データ 3.64 GB は `obsidian-research-data/le_eps_cifar_0922/`。
