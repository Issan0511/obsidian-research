## 2. 読み

### 2-1. τ の効果は半々に割れる

$$\underbrace{2.02}_{\text{τ の効果}} = \underbrace{0.90}_{\text{幅を経由}} + \underbrace{1.12}_{\text{幅の外}}\ \text{[pt]}$$

**幅クランプはどの τ でも 0.90〜1.86 pt を取り去る。** 飽和が深くても浅くても幅の害は立つ。飽和は幅の害を免除しないし、作りもしない。

### 2-2. 残った分は回る速さで説明がつく

| | ω の比（τ 0.3 → 3） | ω からの予測 | 実測 |
|---|---:|---:|---:|
| クランプなし（[[飽和は回る速さを通すか_結果_0912]]） | 1.48 倍 | 0.60 pt | **2.02 pt**（不足 1.4） |
| **幅クランプあり（本走）** | **1.86 倍** | **0.94 pt** | **1.12 pt**（不足 0.18） |

**幅を釘付けにすると ω の説明力が戻る。** 前走で「ω では 3 割」と出たのは、幅が自由だったために ω の変域が圧縮され、かつ効果の半分が幅経由だったからである。**[[飽和は回る速さを通すか_結果_0912]] §2-4 の「残り 7 割は更新の力学の外」は、本走で半分が回収された**（0.90 pt は幅経由＝力学の中、1.12 pt は ω で説明）。

本走 6 腕（3 τ × 2 クランプ）を ω で並べると Spearman **−0.94**、当てはめは **L = −15.43 − 1.59·log₂ω**。**傾きは leaky の −1.06 より急**（残差は −0.67〜+0.45 pt）。ELU は ω 1 オクターブあたり leaky より 0.5 pt 多く損をする。**c_act はここに残っている**（[[飽和は回る速さを通すか_結果_0912]] M4 の `OFFSET` 寄りと整合）。

### 2-3. 「ELU は飽和しても平気」は τ=1 固有の偶然

幅を止めた後に残る損失は **0.87 / 0.00 / −0.25 pt**。**τ=1 はちょうどゼロを横切る点**である。[[ゲート被覆か非線形性か_結果_0911]] の 13 腕表で ELU1 の残差が 0.08 と出て、そこから私は「ELU 族は幅を止めれば全部治る」と読んだが、**族の性質ではなく 1 点の偶然**だった。
なお本走の S(1) = 0.00 は 9/11 の R_c(ELU1) = 0.08 と、S(leaky) = 0.60（[[回る速さが幅の正体か_結果_0912]] の `W1`）は R_c(LR) = 0.49 と整合する。**別走・別窓で同じ量が再現している。**

### 2-4. 死んだユニットは幅クランプで戻らない

τ=0.3 の hard-dead は t20 で 0 → t120 で 14（無クランプ）／**15**（クランプ）。**幅を止めても死者は減らない。むしろ seed 0 では 13 → 18 に増える。** S(0.3) = 0.87 pt にはこの床が含まれており、**「飽和の害」と「死の害」は本走でも分離できていない**（spec §7 に登録済み）。分離には死の起きない条件での対照が要る。

### 2-5. 主軸 B の現状（9/12 午後）

$$L \;\approx\; f(\omega) \;+\; c_{\rm act}, \qquad f\ \text{の傾きは leaky で } -1.06,\ \text{ELU で } -1.59\ \text{pt/octave}$$

- **幅の害は ω で 1 次元**（[[回る速さが幅の正体か_結果_0912]]）。本走でも幅クランプは ω を 1.8〜2.3 倍にして 0.90〜1.86 pt を消す。
- **飽和の害も半分は ω 経由**、残り半分は幅経由。**飽和は「回る速さを下げる」と「幅の害を増やす」の両方で効く。**
- **c_act は ω の傾きの差として残っている**（leaky −1.06 対 ELU −1.59）。単なる切片ではなく**傾きの差**なので、次はここを測るのが筋。**ELU で ω を独立に振る**（`turn_rate_0912` の設計をそのまま ELU で）と 6 走で決まる。

## 3. 限界

- t120・3 seed・τ は 3 水準・クランプは κ=1 の 1 水準。
- **死んだユニットと飽和の分離は未了**（§2-4）。τ=0.3 の S には死の床が入る。
- τ=1 は別走（`elu_turn_0912`）からの持ち込み。同じ計装・窓・錨規約だが同一走ではない。
- ω の傾き −1.59 は 6 腕・ω の変域 3.4 倍の当てはめ。leaky の −1.06 とは腕の作り方（κ と lr 対 τ とクランプ）が違うので、**傾きの差が活性化の差か介入の差かは本走では決まらない**。
- N3 のラベルは幅で消えた分が [1.80, 1.86, 0.90] で単調でないことによる。τ=0.3 と 1 がほぼ同じなのは、τ=0.3 の死者 15 個が幅経由の利得を食っている可能性がある（事後の読み）。

## 4. 開示

**量の名前が 9/11 のノートと逆になっていた。** [[ゲート被覆か非線形性か_結果_0911]] の $R_c$ は「幅を止めても**残る**分」だが、本走の spec §2 では $R_c$ を「幅を止めて**消える**分」と定義し、残る分を $S$ とした。**本ノートの表では「幅で消えた分」「L（幅クランプ）」と日本語で書いて衝突を避けている。** 9/11 の $R_c$ に対応するのは本走の $S$ である（§2-3 で数値の整合を確認）。次の spec からは「消えた分」を $\Delta_c$、「残る分」を $R_c$ に統一する。
