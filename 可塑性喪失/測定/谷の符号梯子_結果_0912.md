## 1. 腕（箱 B・pmnist・Adam・400 タスク・seed 0–2）

| 腕 | φ′(z), z<z_c | φ(z), z<z_c |
|---|---|---|
| `GELU` | φ′(z) < 0 | → 0 |
| `GELUF` | 0 | φ(z_c) = −0.16997 |
| `GELUA` | \|φ′(z)\| > 0 | 2φ(z_c) − φ(z) → −0.33994 |

`GELUA` の \|ゲート\| は**全 z で GELU と bit 一致**なので、GELU との差は符号以外に無い。

## 4. 読み（事後・登録の外）

- **`GELUF` と `GELUA` がほぼ同値**（4.70 対 4.62）。深部の挙動は全く違う（平坦で凍る 対 有界で正の傾き）のに同じ損失。共通するのは「反転が無い」ことだけなので、spec §5.1 が疑えと書いた「GELUA は ELU 化しただけ」は**否定**される（ELU 帯 4.0–4.3 にも着地していない）。
- **介入は幅と深さも動かす**: z̄(t400) −6.89 → −4.47 / −3.67、sd 3.31 → 4.15 / 4.25、cnorm 9.13 → 13.24 / 14.25。反転を消すと沈まず・広くなる。媒介（反転 → 可動性 → 損失 なのか、反転 → 幅 → 損失 なのか）は本走では分離していない。
- **[[turn_rate_0912]] の ω 則との照合（暫定・cnorm(t400) を ‖W̃‖ に代用）**: L = −9.11 − 1.05·log2(ω) の予測は GELU 4.70・GELUF 5.27・GELUA 5.38。**残差は GELUF −0.57・GELUA −0.76 に対し GELU だけ +2.98**。ω 則は非谷 2 腕をよく当て、**谷だけがその上に約 3 pt 上乗せする**。反転は ω が見ていない加法的なチャネルに見える。ω の定義を turn_rate の spec に合わせて取り直す必要がある。
- **0910 の「吸収は lever ではない」は修正が要る**。あの読みは wclamp が「嵌まったユニットを増やしながら精度を上げる」ことに依っていたが、腕をまたぐ介入では反転そのものが 3 pt を持っていた。クランプ間で順序が壊れるのは媒介が幅を経由するからかもしれない。

## 5. 走の中で潰した罠

**float32 の符号跨ぎで 1 回目を中断（追補 1・追補 2 blocker と同型で 2 例目）。** GELU の φ′ は z_c で符号を変えるので、float32 では **z ≥ z_c なのに φ′ < 0 になる点**がある（[−1.2,−0.3] の 2e6 点格子で 1 点・float64 では 0 点）。`where(z >= ZC, d, -d)` がそれをそのまま出し、`GELUA` seed 1 が「非谷腕のゲートは負にならない」で落ちた（51200 標本中 1 点）。`GELUF` も同じ穴を持ち、通ったのは標本が落ちなかっただけ。直しは関数を変えず `GELUA.dphi = |φ′|`・`GELUF.dphi = clamp(φ′,min=0)`。G2 が構成上真になる分、自己検査に **float32 の検査と変異対照**（生の GELU が float32 で実際に跨ぐこと）を足した。

**開示**: 1 回目の完了行で acc(t400) を GELU 3 seed・GELUF 3 seed・GELUA s0 について見た。閾値・ラベル・記名予測は変更せず、9 走とも破棄して再走した（追補 1 に記録）。

### 読み

- **私の差分商（閉形式）は損失の水準を予言しない。** 反転の総量 \|φ_min\| は SiLU が GELU の 1.64 倍で、谷底 3 下のゲートは 36 倍（−0.0440 対 −0.0012）なのに、ΔL は逆に 0.81 倍。ゲートの「量」は損失の量にならない。[[前活性の力学_事後_0904]] の sinc 則と同じで、**差分商はゲートを当てるが損失は当てない**（[[ゲート被覆か非線形性か_結果_0911]] の mob が SN02/SN06 を逆に間違えたのと同型・2 例目）。
- **可動性は損失を「並べる」が「比例しない」。** 6 腕で Spearman −1.00（Pearson −0.88）なのに、可動性欠損に比例する B は 2 倍外した。
- `SILUA` の 4.38 は leaky の 4.36 と同値で、この梯子の最良腕。ゲート 0（F）より正（A）がわずかに良いのは GELU（4.70 対 4.62）でも SiLU（4.63 対 4.38）でも同じ向きで、SiLU のほうが差が大きい（0.25 対 0.08）。
