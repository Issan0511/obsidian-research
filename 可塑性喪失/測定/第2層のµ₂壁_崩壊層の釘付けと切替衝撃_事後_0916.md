## 0. 一行

**第2層の壁は全1方向ではなく、第1層出力の平均 µ₂ の方向にある。崩壊した第2層はどの箱でも ρ_µ≈1・b₂/σ₂≈0 で、d₂ は µ₂ 方向の壁定数 −c₂（−3.0〜−3.7）にそのまま乗る。** 崩壊はラベル切替ごとの一時吸収から始まる。切替直後の 75 更新で第1層出力の平均が跳ね、第2層の過半のユニットが全標本で負になる。leaky の第2層は毎タスク回復するが、ELU は跳ねが育つにつれて回復しきれなくなり、t8–t12 から吸収がタスク終端でも残る。第2層の平均前活性を運んだのは、t5 までは W₂ 自身と共変、その後は主に上流（µ₂ の伸び）。

## 1. 座標

第2層の入力を u（通常は a₁）、$e_2=\mu_2/\|\mu_2\|$、$w_2=q_2e_2+v_2$ とすると厳密に

$$\bar z_2=q_2\|\mu_2\|+b_2,\qquad \sigma_2^2=q_2^2\,\mathrm{Var}(e_2^\top u)+\mathrm{Var}(v_2^\top u)+2q_2\,\mathrm{Cov}(e_2^\top u,\,v_2^\top u)$$

$$\rho_\mu=\frac{q_2^2\,\mathrm{Var}(e_2^\top u)}{\sigma_2^2},\qquad d_2=\mathrm{sign}(q_2)\,c_2\sqrt{\rho_\mu}+\frac{b_2}{\sigma_2},\qquad c_2=\frac{\|\mu_2\|}{\mathrm{sd}(e_2^\top u)},\quad \kappa_2=\frac{\|\mu_2\|-\min_x e_2^\top u}{\mathrm{sd}(e_2^\top u)}$$

[[明度チャネルρとµの壁_0916]] の第1層と同じ形。違いは、定数 $c_2,\kappa_2$ が第1層の状態で毎タスク動くこと。$c_2>\kappa_2\iff\min_x e_2^\top u>0$（µ₂ 方向の片側性）。共分散項は落とさない（ρ_µ は 1 を少し超えうる）。恒等式は固定 1200 枚上で float64 で再計算し、許容誤差の 1e−5 倍以下で閉じた（変異対照 8 種はすべて検出）。

## 4. 誰が運ぶか — ベクトル帳簿と Shapley

$\Delta\bar z_2=(\Delta W_2)\mu_2+W_2\Delta\mu_2+\Delta W_2\,\Delta\mu_2+\Delta b_2$（自己・上流・交差・bias。連続する診断点の旧状態で評価）。上流項は $\|\mu_2\|$ の伸びと $e_2$ の回転に対称差分で割る。$d_2,\rho_\mu$ は（W₂,b₂）・µ₂・Σ₂ の 3 因子、σ₂ は（W₂）・Σ₂ の 2 因子に Shapley で割る（`windows.csv`、中央ユニットと平均）。

- **z̄₂ の沈みの 7 割以上は上流が運んだ**（ELU→ELU 73–76%、leaky→ELU 82–85%、150 タスクの RL ELU 82–85%、PM GELU 92%）。上流項のほとんどは ‖µ₂‖ の伸びで、回転は小さく逆向き。bias はどの箱でも 1% 程度以下。
- **ε 域に入った後は上流だけ**。ELU→ELU の ε 域 → t50 で上流 −39〜−68、自己 −4〜−6。止まった W₂ のまま、第1層の動きで z̄₂ が沈み続ける（[[層別キメラでELU崩壊の所在を決める_結果_0914]] §5 の「ε 域でも降下が続く」の中身）。
- **d₂ を下げたのは「平均の伸びが広がりの伸びを上回った分」**。RL では µ₂ の寄与が −6.5〜−11、Σ₂ の寄与が +3.3〜+7.1 で打ち消し合い、正味 −3.1〜−3.8。W₂ 自身はキメラの ELU→ELU で −1.9〜−2.7（正味の 3 分の 2）、150 タスク箱の ELU で −0.9〜−1.5、leaky→ELU と SiLU ではほぼ 0 か正。
- **ρ_µ→1 を押したのは主に入力の共分散**（ELU→ELU で Σ₂ +0.5〜+0.8、W₂ +0.3〜+0.4）。µ₂ 方向の分散割合は t1 の 0.02 から t50 の 0.82–0.86 へ。第1層出力の共通成分支配が ρ_µ を 1 に寄せた。σ₂ の伸びも主に上流（ELU→ELU で Σ₂ +31〜+37、W₂ +9〜+12）。
- **帰属は代数的**。上流の変化そのものも第2層を通る勾配で起きているので、「上流」は「第1層が独立に動いた」という意味ではない。

## 7. 開いていた 6 項目のいま

1. **円錐への入り方** → 閉じた（§3・§4）。一時吸収は t2 から、終端での持続は t8–t12。入れたのは主に第1層出力の共通成分（Σ₂）と W₂ の整列。
2. **早期窓の帳簿** → ベクトルで閉包し、25 更新刻みで交差を半分にした（§4b）。早期は W₂ 自身、中盤以降は上流。
3. **LE の壁定数** → 閉じた（§2）。
4. **PM GELU/SiLU の崩壊層** → 閉じた。釘付けで、b 経路ではない。
5. **釘付けと ε ブレーキ** → 観察では順序が決まった（§3）。介入の結果は [[第2層のµ₂壁にεとLayerNormを当てる_結果_0916]]。
6. **第2層の W 成長抑制（cap1/cap2）** → 未着手。[[H2_W成長抑制と負側輸送_設計案_0916]] §10.4 は mucap_el_0916 の結果を見て判断すると決めている。本ノートの帳簿は「崩壊期の後半は W₂ が止まっても上流の伸びで沈む」ことを示唆するので、設計では第1層側（µ₂ の伸び）の操作か LN と並べる必要がある。
