## 0. 一行

**resp_ee の自然軌道で作った「$n_{\rm eff}$ → 次のタスクを学べる度合い F」の曲線は、同じ箱の新しい seed では完全に当たり（15/15、崩れる時刻も 3 seed とも一致）、外の 3 箱ではすべて外れた。** 登録判定は **`BOX_SPECIFIC`**。RL の GELU は第2層の $n_{\rm eff}$ が 0.9 以上のまま F が 0.15 まで落ち（尽きているのは第1層）、PM の GELU と ELU→leaky は曲線が言うより低い $n_{\rm eff}$ で学べた。**$n_{\rm eff}$ の値そのものは箱をまたがない。**

## 1. 何をしたか

- **予測子**: 逆伝播が実際に掛けている微分 g について、ユニットごとに $n_{\rm eff}=(\sum_x|g|)^2/(N\sum_x g^2)$、層のユニット平均（resp_ee の `neffT` と同じ量。GELU の負の微分は |g| で数える）。分岐 t の値は、タスク t+1 の入力を入れて重みを動かす前に読んだ。
- **F**: $F=\mathrm{clip}\big((E-0.1)/(E_0-0.1),0,1\big)$。E = 次のタスクの online 正解率、$E_0$ = 同じ seed の t2 の E。
- **較正（resp_ee の中だけで閉じる）**: 自然軌道の t = 2–21 × seed 0–9 の 200 点を、$\log_{10}n_{\rm eff}$ のロジスティック（2 パラメータ）で fit。**半減点 $n_{\rm eff}$ = 0.119**、帯（Mondrian conformal 95%）は当てはめ値の区分ごとに ±0.078 / ±0.191 / ±0.089。seed 抜きの検証 39/40。
- **箱**（すべて介入なしの自然軌道。Adam を引き継ぐ分岐は、自然軌道の次のタスクそのもの）:

| 箱 | 実装 | 主の層 | 分岐点 |
|---|---|---|---|
| RL_EE_cpu | resp_ee の CPU 箱（expm1 の微分）、**seed 10–12** | 第2層 | t2, 5, 10, 20, 50 |
| RL_GELU | relu_gelu_silu の GPU エンジン（ext150 と t1–150 が bit 一致） | 第2層 | 同上 |
| PM_GELU | 同上 | 第2層 | 同上 ＋ t100 |
| RL_EL | layer_chimera の GPU エンジン（t1–50 が bit 一致）、ELU→leaky | 第1層 | t2, 5, 10, 20, 50 |

主の層 = 固定尺度のクラス（ELU・ReLU・GELU・SiLU）に入る最も深い隠れ層（設計案の選び方を規則にしたもの）。同じ GPU 走に乗った ReLU・SiLU・GPU 版 ELU→ELU・leaky→ELU・leaky→leaky と、それぞれの PM は副の箱。

**設計案からの変更**（登録時に spec に明記）: (1) 較正を「26 腕の 10 seed 平均」から自然軌道の 200 点に替えた。26 腕には、同じ $n_{\rm eff}$ で E が 0.3 高い移植腕（S2_10r 0.464 対 N10 0.137）が混ざり、同じ手順で作ると帯が ±0.48 になって検定にならない。(2) 分岐の継続は自然軌道の次のタスクで読んだ（量は同じ）。(3) F を [0, 1] に clip した。(4) ラベルに `PREDICTS_NOT_BEST` を足した。

## 5. 読み（事後・未登録）

1. **$n_{\rm eff}$ は「箱の中での進み具合」の指標で、箱をまたぐ尺度ではない。** 同じ箱・同じ活性化・同じ層なら、新しい seed でも崩れる時刻まで一致する。PM では同じ値で RL より学べ、ELU→leaky では曲線と平行にずれる。健康な値で正規化すると ELU→leaky は通るが、PM は通らない。
2. **どの層が先に尽きるかは箱で違う。層を 1 つに固定した指標は外れる。** RL の EE では第2層、RL の GELU・ELU→leaky・ReLU では第1層が先に尽きる。ただし第1層だけが尽きた網は読み出しと第2層で F 0.15–0.35 まで学べるので、「最も尽きた層」を第2層の曲線に当てると、今度は学習能力を過小に見る。
3. **応答が残っているのに学べない網（RL の GELU の第2層）は、「応答喪失を経ない LoP」の例ではない。** その網は第1層の応答を失っている。「喪失した層が第2層でない」例として読む。
4. **陰性対照（leaky→leaky）では $n_{\rm eff}$ は劣化を映さない。** 固定尺度のクラスの外の劣化（V9 の幅の経路）がこの定義の外にあることと合う。

## 6. V10 に対して言えること

- [[中心主張v10草案_0916]] §1.4a の「尽きるまで学べる（効くのは大きさでなく実効数）」の行: **登録した予測で「同じ箱の中では再現する（新しい seed で 15/15・崩れる時刻が一致）」まで上がった。「箱をまたぐ定義」としては外れた（`BOX_SPECIFIC`）。** 「応答を残す (ユニット, 入力) が実効的に尽きる」を $n_{\rm eff}$ の絶対値の閾値で書くことはできない。書くなら、その箱の健康な状態からの相対値か、箱ごとの較正を条件にする。どの層で尽きたかも明記が要る。
- [[命題リスト]] Q35「機能的な応答は微分の平均でなく実効数で測る」: 箱の外の 48 点では $n_{\rm eff}$（+0.08）が微分の平均（+0.28）にも厳密な 0 の割合（+0.53）にも負けた。箱の中では両者はほぼ同じ順（RL_EE +0.81 対 +0.81）。**「平均より実効数」を支えているのは、resp_ee の 26 腕（人工の腕を含む）だけ。**
- [[中心主張v10作業リスト_0916]] H4 の格上げの計画の (4)「$n_{\rm eff}$ の外の箱」は実行済み。「1 箱」の限定は外れなかった。同じ行の後半（PM GELU での移植）は未着手。

## 7. 範囲

- 較正は 1 箱・1 活性化・200 点。帯の被覆は seed 内の相関を無視した近似（LOSO 39/40）。
- GPU の箱は、較正の箱と乱数の流れ・逆伝播の実装が違う（ELU の微分は $e^z$）。箱をまたぐ比較にはその違いも混ざる。ただし GPU 版の ELU→ELU は 15/15 なので、実装の差だけでは外れていない。
- F は $E_0$（t2 の E）で正規化するので、t2 で既に崩れている箱（RL の ReLU）では弱い。
- §4 の副の結果と §5 の読みはすべて事後。副の箱は登録判定に入らない。
- 費用: GPU 1 本 48 分（他セッションの CNN 5 本と共有）、CPU 3 本 各 4 分。検査は 1 回 約 10 分 × 3 回。実装中に、resp_ee の import 連鎖（`elu_growth_0909` → `boundary_gradient_0908` → `boundary_groups_0908` の 6 行目、モジュール直下の `torch.set_num_threads(1)`）が torch のスレッド数を 1 に戻す副作用を見つけた（検査 S6 の変異で発覚。本走は 1 スレッドなので数値には効かない）。
