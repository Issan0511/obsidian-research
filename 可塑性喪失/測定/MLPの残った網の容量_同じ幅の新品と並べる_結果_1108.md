# MLP の残った網の容量 — 同じ幅の新品と並べる（結果、1108）

依頼: [[V14主張の流れ_残った網の容量_1108]] の切れ目 1（G4「学び直しが削れるのは、切り落とされた残りの網の容量が課題を下回ったとき」が読みのまま）。[[MLPのhead0対照_⑤は体の側か装填費用か_結果_1108]] の H0A（head と全 Adam を 0 にして体の重みだけ引き継ぐ）で戻る割合が、切替時に生きている unit の割合と順位一致していたのを、数で言えるかを確かめた。
箱: 同じ 1 隠れ層の乱数ラベル MNIST（784-100-10、Adam 1e-3・batch 16・4,000 更新/課題）、課題 21〜30、活性化 5 × seed 0・1。
やったこと: 切替時に生きている unit の数 k_start（p⁺ ≥ 0.005）と H0A の課題末に開いている数 k_end を数え、幅 k の新品 784-k-10（k = 3・6・13・25・45・74・100 と k_start・k_end、取り直し 2 本）を同じラベル・同じミニバッチ順で回し、H0A の漸近と同じ精度になる新品の幅 k_equiv を曲線から読んだ。判定は k_equiv が [k_start, k_end]（取り直しのばらつき分の幅つき）に入るか。
記録: lop_analysis `specs/spec_head0_mlp_1108.md` 追補 A、`results/head0_mlp_1108/cap/`（summary_cap.md・judge_cap.md・curve.md・図 fig_cap.png）。

## 結論（3 行）

1. φ′ ≈ 0 で切り落とす活性化では、残った網は生きている数と同じ幅の新品にほぼ並ぶ。ReLU は k = 0（偶然）で一致、SiLU は k_equiv 11 対 k_start 12〜13、GELU は 5 対 5〜5.5（判定のラベルは「割れ」。帯の幅が 1〜2 unit しかなく、課題ごとの k_start がその両側に散る）。
2. ELU は下。生きている unit 73 個の網が、新品 47 個分の漸近にしかならない。生きていても開いている入力が少ない（p⁺ ≥ 0.05 は 4 個、開いている入力の有効数 Σp⁺ は 1.9）。
3. leaky は上端で一致。閉じた unit が全部開き直す（k_end 100）ので、H0A は幅 100 の新品と同じ漸近に着く（k_equiv 88〜93）。沈みは可逆。

## 予測の採点

送り手（Vit振り返り、Fable）: |Δ| ≤ 0.05 は ReLU だけ当たり。leaky k45 ≥ 0.95 は外れ（0.93）、SiLU k13 0.5〜0.6 は外れ（0.61）、GELU k6 0.3〜0.4 は外れ（0.43）。
受け手（このセッション、Fable）: J A1 は leaky・ReLU・ELU（下）当たり、SiLU・GELU 外れ（割れ）。k_equiv の見込みは leaky・ReLU・ELU 当たり、SiLU 外れ、GELU 割れ。

## 段 G4 への材料（置き方は Issa の判断）

- φ′ ≈ 0 の活性化では「残った網 = 生きている数の新品」が 1〜2 unit の幅で成り立つ。生きている数は、新品の曲線を通して漸近の精度を予測する。
- ELU は unit の数では容量を過大に数える（開いている入力が少ない）。容量を数えるなら「開いている入力の数」の側に手掛かりがある（記録。定義し直しはしない）。
- leaky は切り落としが無く、容量は幅 100 の新品と同じ。
- 言わないこと: 容量を p⁺ の閾値で定義し直さない。曲線を他の箱の幅に当てない。H0A を手法として語らない。
