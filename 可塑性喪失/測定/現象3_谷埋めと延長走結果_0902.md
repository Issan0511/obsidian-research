### 1.4 読み（未登録）

- **追い越しには逃走が要る（必要条件側）**ことは介入で決着した。谷の手前を一切変えず、谷の向こうの $\varphi'<0$ を 0 に置き換えただけで水準が 0.5 dex 戻る。凍結率は 0.98→0.88・0.94→0.93 でほぼ変わらず —— **凍結の量ではなく凍結の深さ（と再露出）**が効く（[[現象3_非ReLU戻り道の対応づけ_0902]] §4）
- **読みの限定**: 介入は $\varphi'<0$ の除去と同時に (i) 床の出力を 0⁻ から定数 $\varphi(z_c)$=−0.170／−0.093 に変えている（凍結ユニットの $v_i$ は $2\delta\,\varphi(z_c)$ の勾配を受け続けるので ReLU の床と同型ではない）、(ii) 沈下ユニットの $\lvert v\rvert$ 中央値を 8.05→1.32・7.59→1.35 に下げている（`seed_values.csv` `absv_sub_med`）。対立判定 `OVERSHOOT_NOT_FLIGHT` は水準不変の場合しか捕まえないので、床の値・$\lvert v\rvert$ 経路との分離には床ゼロの谷埋め（[[現象3主張v1_0902]] §7 行 0）が要る
- clamp 腕が ReLU より良い理由（候補・未検証）: 床が $-u^\ast$ にあって表層との距離が 0.4–0.75 しかなく、再露出されたユニットが谷の手前の滑らかな勾配（0 → 1）で戻りやすい。ReLU は床が 0 で再露出即 φ'=1 だが深さ 4–5 に沈む。**境界復活 2.5 倍**がこの読みの唯一の材料で、方向の主張はしない
- **沈下率・凍結率は損傷量ではない**（[[ゲート硬さダイヤル結果_0902]] §6.5）の介入版: 同じ 0.9 の凍結率で $U$ が 1.0 と 0.3

### 2.3 読み（未登録）

- **(b) 時間軸の答え**: 標準パラメータの leaky（0.1）・ELU（1）は **3 倍の時間でも動かない平衡**にある（沈下率・深さとも ±0.1 の範囲で不動、unfit は横ばい〜改善）。「学習時間・データ量のスケールアップで ReLU に近づく」は**この 2 つには起きない**（15M・用量 12.16 の範囲で）
- **逃走は減速する。** 5M ごとの深さ増分は S_b1 +4.8 → +2.7、G_b0p3 +3.5 → +1.2、S_b0p3 +2.6 → +0.8 と縮み、凍結率の伸びは S_b1 +0.41 → +0.23、G_b0p3 +0.10 → +0.11。**深さは時間の対数、凍結率はほぼ線形**。事前登録の「凍結時刻 ∝ 1/β」（論点ノート §4・β≥1 の 3 点からの目視外挿）は **β=0.3 に外挿できなかった**: 逃走速度は $\lvert\varphi'(\beta z)\rvert$ だけでなく残差と $\lvert v\rvert$ にも比例し、G_b0p3 はまだフィットしている（$U$ 0.13）ので正帰還が弱い。S_b1 は $\lvert v\rvert$ 7.5 → 10.1 と育ちながら崩壊を続けている（$U$ 0.18 → 0.45、ReLU の 0.53 に迫る）
- **標準 SiLU（β=1）は 15M で凍結 0.81・$U$ 0.45 ＝ ReLU の水準に達した。** 「時間のスケールアップで標準の滑らかな活性化が ReLU の regime に入る」は **SiLU β=1 については 15M で実測**。GELU β=1 は 5M で既にそうなっていた（[[ゲート硬さダイヤル結果_0902]]）
- 教訓候補: **β をまたぐ外挿に 1/β 則を使わない**（残差の正帰還を含まない）。登録閾値（凍結 ≥0.8）は β≥1 の腕から置いたもので、β=0.3 には厳しすぎた —— ただし閾値を後から動かさない（判定は `FLIGHT_STALLS` のまま）
