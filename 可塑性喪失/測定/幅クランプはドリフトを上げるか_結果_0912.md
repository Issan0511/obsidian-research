## 2. 読み

### 2-1. 2×2 で見ると幅が桁で大きい

目減り L（seed 中央値）:

| | クランプ無し | クランプ | クランプの効果 |
|---|---:|---:|---:|
| ノイズ無し | 2.28 | **0.60** | **−1.68** |
| ノイズ c=1 | 2.62 | **0.69** | **−1.93** |
| ノイズの効果 | +0.17 | **−0.04** | |

**幅クランプは 1.7–1.9 pt、ノイズは 0.17 pt。** さらに**クランプはノイズの害も吸収する**（クランプ下でノイズの効果は −0.04 pt）。9/11 の `grad_coherence_0911` E4 が「損傷が床に届かず `NOT_TESTABLE`」で出せなかった形が、ここでは 2×2 として出た。

### 2-2. 幅クランプは一歩を何も変えない

N0w ÷ N0（late 窓・seed 中央値）:

| 動かさない量 | 比 | 動かす量 | 比 |
|---|---:|---|---:|
| ドリフト drift2_net | 0.94 | **‖W̃ᵢ‖** | **0.46** |
| 直交成分 diff2_net | 0.95 | 前活性の幅 σ | 0.54 |
| 正規化歩幅 κ2 | 0.95 | 沈下 z̄ | 0.62 |
| 歩幅の予算 S² | 0.94 | **生勾配 graw²** | **2.18** |
| ‖W2‖ | 1.03 | 経路持続 ρ | 0.74 |
| ゲート mob | 0.91 | | |

**射影が消しているのはほぼ純粋に動径（成長）方向で、勾配方向は 0.5%**（J3）。つまりクランプは**学習の向きにも歩幅にも触れず、成長ぶんだけを毎更新削っている**。それで目減りが 3 分の 1 になり、絶対精度が 1.6 pt 上がる。

**生勾配が 2.18 倍になるのに κ2 が 0.95 倍**というのが要点で、Adam が増えた勾配を正規化で吸収している。V9 §3 が候補に挙げた「重み増大に伴う実効 step の縮小」は、**勾配の側では起きているが、一歩の側では起きていない**。

### 2-3. ドリフトはノイズ側の量としては生きている

ρ が分けられなかった対（N0w の ρ 38.4・L 0.60 対 N1 の ρ 38.1・L 2.62）を、drift2 は 1.85 倍で分ける（12.52 対 6.86）。**ρ は死に、drift2 はノイズ側で生き残った。** ただし J1・J4 のとおり、drift2 は幅クランプの効き方を説明せず、4 腕を並べもしない（Spearman +0.00）。

### 2-4. したがって主軸 B の現状

- **幹は幅**（1.7–1.9 pt）。これは [[長い地平線で沈下と幅を分ける_結果_0910]] の t400 登録走と同じ向きで、今回は「一歩を何も変えずに効く」まで絞れた。
- **ドリフトは第 2 のレバー**（0.17–0.5 pt）。勾配を汚す側の摂動でだけ効く。
- **幅の経路は依然として未同定。** 今回の走で**新たに外れた候補**: 一歩の大きさ（κ2・S²）、一歩の向き（drift2・diff2）、第 2 層のノルム（‖W2‖）。[[長い地平線で沈下と幅を分ける_結果_0910]] で既に外れていたもの: σ・p⁺・沈下・死。
- **残るのは「重みが何を表しているか」の側**（実効ランク・条件数・読み出しの分離度）で、**更新の力学ではない**。次はそこを測る。

## 3. 限界

- t120・3 seed・leaky・c=1 の 1 用量・クランプは t21 開始で κ=1 の 1 水準。
- σ はここでは 0.54 倍に**下がる**が、[[長い地平線で沈下と幅を分ける_結果_0910]] の t400 では wclamp のほうが**広かった**（5.78 対 5.65）。地平線で符号が変わるので、σ を幅の経路の候補から外す根拠には使わない。
- drift2 は各腕の lr² で割った相対量。$\hat g_i$ はその更新のミニバッチ勾配の向きで、タスク平均ではない。
- J4 は n=4 で弱い。
