## 0. 何を問うたか

- **Issa が貼った別チャットの読み**: LN は線形層の入力の全1方向（明度チャネル）を厳密に 0 にするので、残る吸収は b 経由になる。affine の β は b 型の経路を足す。leaky と ELU も GELU と同じ b 経路で死ぬ。
- **観察側の幾何**（[[第2層のµ₂壁_崩壊層の釘付けと切替衝撃_事後_0916]] §5）: LN が消すのは全1方向だけ。崩壊層の壁（µ₂ 方向）は残り、LN 後は c が 40 倍になる。
- **ε**: 崩壊層では ρ_µ≈1 の釘付けと Adam の ε ブレーキが同じ状態で共存していた。ε が深さを決めているかを介入で問う。

## 1. 箱と腕

層別キメラの箱（1200 枚固定・784–100–100–10・batch 16・Adam lr 1e−3・6000 更新/タスク・50 タスク・seed 0–2・乱数ストリームは親と同じ）。1 本のエンジンに 132 モデル。

| 腕 | 内容 | 組 |
|---|---|---|
| `none` | LN なし・ε 1e−8（ε の対照を兼ねる） | ELU→ELU・ELU→leaky・leaky→ELU・leaky→leaky × RL/PM |
| `inLN` | 各隠れ層の線形変換の入力（x と a₁）に LN・affine なし | 同上 |
| `inLN_a` | 同上、a₁ 側だけ affine（γ, β を学習） | 同上 |
| `preLN` | 各隠れ非線形性の直前に LN・affine なし | 同上 |
| `preLN_a` | 同上・affine あり（Lyle et al. の配置） | 同上 |
| `eps1e-6`・`eps1e-30` | LN なし・Adam の ε だけ替える | ELU→ELU・leaky→ELU × RL |

LN(t) = (t − mean)/sqrt(var + 1e−5)（サンプルごと・特徴軸）。γ, β は本体と同じ Adam で学習し、affine なしの腕では勾配 0 で動かない。

活性化前 LN の腕では非線形性の入力が LN 後の値なので、線形出力 z₂ の d₂・c₂ は壁の読みに使わない（非線形性の入力の中央値は −4.8〜+0.1、全標本負は上の列）。

- **入力 LN（affine なし）は µ₂ の伸びを止めた**。‖µ₂‖ は上限 √n=10 の手前（8.6–8.9）で止まり、z̄₂ の沈みは 1/6（−24 対 −154）。µ₂ 方向の壁は片側のまま（min e₂ᵀu +2.3〜+4.6、c₂ > κ₂）だが、c₂ が 8–12 に上がって釘付け −c₂ が遠のき、d₂ は −2.9 で止まった（全標本負 19–31%）。
- **切替衝撃そのものは残る**。入力 LN でも切替 75 更新後の全標本負は 57–88%。違いは回復で、t20 まで終端の全標本負 0–4%。ただし平均 φ′ は 0.77 → 0.03（t50）と下がり続けており、50 タスクより先の生死は分からない。
- **affine を付けると崩れた（報告のみの腕）**。γ が尺度を戻して ‖µ₂‖ は 38–44 まで伸び、β が W₂β = −13〜−21 の定数項を作った。ELU→ELU は 2/3 seed、leaky→ELU は 3/3 seed が床。沈みのうち β 項は 27–28%、残りは µ₂ 方向。**貼られた読みの「β が b 型の経路を足す」はこの腕で当たった**が、主経路は µ₂ 方向のまま。
- **活性化前 LN は切替衝撃を小さくした**。切替直後の全標本負 15–40%、終端は常に 0、平均 φ′ は 0.76 で一定（affine なし）。affine ありでは β₂ の中央値が −3.9 まで負に動いたが、LN がどのサンプルでも 8% 前後以上のユニットを正に保ち、online 0.73 と RL ELU→ELU で最良。
- **leaky 第2層では入力 LN が精度を下げた**（ELU→leaky 0.31 → 0.20、leaky→leaky 0.49 → 0.39）。活性化前 LN は ELU→leaky を 0.45–0.69 に上げ、leaky→leaky は 0.45–0.50 で変わらない。**PM は全腕 0.98–0.99 で天井**。

## 6. 読み（事後）

1. **LN が RL の ELU 崩壊を防いだ主因は、全1方向を消したことではなく、µ₂ の伸び（上流の輸送）を止めて釘付けを遠ざけたことに見える**。根拠: affine なしの入力 LN では µ₂ 方向の壁が片側のまま残るのに崩壊せず、γ で尺度が戻る affine ありでは崩壊する。観察側の帳簿（沈みの 7 割以上が ‖µ₂‖ の伸び）とも合う。
2. **[[明度チャネルρとµの壁_0916]] の極座標で言えば、壁（角度）より半径が効いていた**。第2層では、半径を止めると角度が壁の内側でも全標本負に届かない。
3. **先行研究の配置（活性化前・affine あり）が最も強かった**。層全体の吸収を構造的に禁じる制約が効いたと読めるが、LN の尺度不変性で重みノルムの増大が実効学習率の低下に置き換わる効果（Lyle et al., NeurIPS 2024, [arXiv:2407.01800](https://arxiv.org/abs/2407.01800)）などとは分けていない。
4. **ε は崩壊を運ぶ量ではなく、到達後の運動を決める量**。[[層別キメラでELU崩壊の所在を決める_結果_0914]] §5 の「旅を止めるのは ε」は、「釘付けの位置は壁定数、そこで止まるかどうかは ε」と言い直せる。

## 7. 限定

- 3 seed・1 箱・50 タスク。入力 LN の腕は平均 φ′ が下がり続けており、長い地平線での生死は未確認。
- LN の実装は 1 つ（eps 1e−5・画素側は affine なし・b₁, b₂ を残す）。LN 一般の性質とは書かない。
- `inLN_a` の床は報告のみ。登録した C1 は affine なしの腕。
- Part B の δ は対照の揺れから導いたが、釘付け後の揺れが小さいため厳しい判定になった。`MIXED` を「ε が深さを決める」とは読まない。
- ε=1e−30 は float32 の非正規化数域に入る。非有限は 0。
