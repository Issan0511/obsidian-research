## 0. 一行

担い手の交代の前半は支持、後半は修正。読み出しに隣接する L1 が死んでいる間（課題末 39〜50）は L0 が課題を担い（FFN0 を切ると CE が 8 nats 悪化、FFN1 を切っても 0.1）、L1 が戻る後期（89〜100）には L1 が担いと残差への書き込みを支配する（切ると 17 nats、書き込みの比 1.1）。しかし L0 の死（84%）と位置の沈み（r −1.3 → −3.5）は L1 が閉じている間ではなく、L1 が戻る時期に進む（seed ごとの相関 10/10 で負）。cap の網でも L1 の死と戻りの周期は同じに起きるが、L0 は死なない。喪失を決めるのは L0 が沈めるかどうかで、L1 の周期ではない。

## 4. 読み

- 前半は支持。L1 が死んでいる 39〜50 では L0 が課題を担い（担い 8 対 0.1）、L1 が戻る 89〜100 では L1 が担い（17）と書き込み（比 1.1）を支配する。cap でも同じ周期（L1 の死 0.86 → 0.00、担い 0.24 → 10.4）。
- 後半は修正。L0 は L1 が閉じている間には 10% しか死なず、死 84% と r −3.5 への沈みは L1 が戻る時期に進む。seed ごとの相関は 10/10 で負、lnex1 で L1 を戻らせないと L0 はわずかに沈まない。「L1 が閉じている間に L0 が使い潰される」ではなく、「L1 が戻る（大きなノルムで書き始める）のと同時に L0 が沈んで死ぬ」。L1 の戻りが L0 を沈めるのか、共通の原因（head と重みの成長）が両方を動かすのかは、この記述では分けられない。
- ReLUcap では L0 が死なず r も −0.8 のまま。L1 の周期は喪失の原因ではなく、L0 が沈めるか（up 行の上限）が喪失を決める。ELR（L0 だけの射影）が救うことと整合。
- P1c の外れ: cap でも早期・中期は L0 の担いが L1 の 5〜25 倍で、「同程度」は読みの誤り。FFN0 は最初から主担い手で、FFN1 は読み出しの隣で薄く担う。
- P2 前半の外れ: C3 の FFN0 の書き込みの比は早期から 0.87 で、39〜50 で増えない（既に支配的）。cap では増える（9/10）。

## 5. 言わないこと

切除は forward を変える介入で、担いは「外したときの CE の悪化」であり寄与率ではない。carry0 と carry1 の和は両方を切った値に一致しない。書き込みの比は大きさで情報ではない。検査 4 は 31 対の記述で因果の向きを言わない。検査 3 は byakko の再生で元の走とビット一致しない。2 ブロック・合成 2 次マルコフ・この Adam と lr・seed 0〜9 の外へ一般化しない。
