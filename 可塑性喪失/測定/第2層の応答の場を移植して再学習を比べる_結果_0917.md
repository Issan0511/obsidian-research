## 0. 一行

**この箱では、第2層の応答の場が、同じ重み・同じ特徴・同じ Adam 状態の網が次のタスクを学べるかを両方向に決める。** 崩壊した t10 の網に t2 の応答の場を戻すと次のタスクを 0.90 で学び（自然継続は 0.14）、健康な t2 の網に t10 の場を渡すと 0.72 から 0.46 に落ちる。登録判定は **`RESPONSE_BOTH_WAYS`**。

## 1. 何をしたか

Random Label MNIST（1200 枚固定）、784–100–100–10、**両隠れ層 ELU**、Adam lr 1e−3、6000 更新/タスク、seed 0–9。mucap_ee_0917 の ref と同じ箱で、**全 10 seed の自然軌道が ref の記録と task 1–22 で一致**した。

自然軌道を task 2・5・7・10・15・20 の終端で分岐させ、第2層（一部の腕は第1層）が訓練で使う応答だけを入れ替えて、新しいラベルを 2 タスク学ばせた。分岐点の特徴・logit・損失・重み・Adam 履歴は自然な網と 1 bit も変えない（検査 S3）。

$$
a_i(x)=\phi\big(z^0_i(x)\big)+\Big[\phi\big(z_i(x)+d_i(x)\big)-\phi\big(z^0_i(x)+d_i(x)\big)\Big]
$$

$z^0$ は分岐点で凍結した網の前活性。括弧は分岐点で厳密に 0 で、訓練の微分は $\phi'(z+d)$ になる（S4）。

- **場の移植**: $d=z^{(\rm src)}-z^{(\rm 分岐)}$。ユニットは画像ごとに時刻 src の応答を返す。
- **一様シフト**: $d=-\Delta$。応答の形を保ったまま大きさだけを下げる。

主量 E は継続 1 タスク目の online 正解率。

### 4.2 読み（事後・未登録）

1. **崩壊した網の再学習を止めているのは、第2層の応答の場。** t5〜t20 のどの崩壊段階でも、t2 の場を戻すと 0.82〜0.92 で学ぶ。重み・特徴・W3・Adam 状態は崩壊後のまま。Adam を初期化するだけでは戻らない（N10r − N10 = +0.03）。
2. **ただし、場の喪失は自然な劣化の半分弱しか説明しない。** t10 の場を t2 の網に渡しても 0.46 までしか落ちず、自然な t10（0.17、Adam 初期化）より 0.30 高い。自然な網は継続中も沈み続けるが（実効引数 −8.9）、移植した腕のユニットは上へ動く（+4.9）。t2 の網の他の状態（特徴・重み）も効いている可能性がある。
3. **効くのは応答の大きさより形。** 一様シフトは Δ = 15 まで F̄ 0.86 を保つ。Δ = 20 では分岐点で (ユニット, 画像) の 96% の微分が厳密に 0 で、W2 座標の 69% が ε を下回るのに、F̄ は 0.74 ある。残った 4% の勾配でユニットが上へ動き（+2.0）、0 の割合は終端で 0.55 まで下がる。t10 の場は同じくらい 0 が多いうえに、全画像で 0 のユニット（5%）と、画像間の広がりの大きい場を持ち、上へ動いても 0 の割合は 0.85 に留まる。
4. **腕をまたぐ順位相関**（26 腕）: 訓練の微分を運ぶ実効的な画像数 $n_{\rm eff}$ が +0.89 で最も強い。微分の平均は +0.72、厳密な 0 の割合は −0.84、ε を下回る座標の割合は −0.79。「機能的な応答」の候補は、微分の大きさより $n_{\rm eff}$。
5. **ε は主犯でない。** Δ = 20 で W2 の 69% が ε を下回っても学べた。完全に止まったのは、第2層の勾配が厳密に 0 になった Δ = 30 だけ。t2 の Adam 履歴を残したまま t10 の場を渡すと、さらに 0.08 下がる（古い v の人工物）。
6. **復元した網は自然な t2 より学ぶ**（R2_10 0.897 対 N2 0.779、Adam 初期化どうしでも 0.911 対 0.724）。理由は未同定。固定補正 $\phi(z^0)$ が画像ごとの定数の特徴を残すこと、崩壊後の網の重みが大きいことの両方があり得る。
7. **復元は持続しない兆候がある。** t20 から戻した腕は 1 タスクで実効引数が −13 動き、0 の割合が 0.37 まで戻る（E は 0.82 → 0.76）。

## 5. 実装中に見つけたこと: この箱の ELU の訓練中の微分は float32 で z < −16.64 のとき厳密に 0

プロジェクトの ELU は `where(z > 0, z, expm1(min(z, 0)))`。PyTorch は expm1 の逆伝播を「出力 + 1」で計算する。white-san の float32 の expm1 カーネルは $e^z<2^{-24}$ で −1 を返すので、**オプティマイザが受け取る微分は z < ln 2⁻²⁴ = −16.64 で厳密に 0** になり、その上では $2^{-24}$ 刻みに量子化される。境界はカーネルの性質で、計算機に依存する。`F.elu` にはこの性質が無い。

- 既存の診断（`gate`・`dphi`・`gate_mean`）は解析的な $e^z$ で、訓練で使われた微分ではない。t10 の第2層では $e^z$ の平均が 0.003〜0.01 あるが、(ユニット, 画像) の 91〜96% は訓練の微分が厳密に 0。**訓練の上では、崩壊した ELU の第2層はほとんど ReLU の死と同じ状態にある。**
- 過去の読みのうち「ELU の微分は厳密に 0 にならない」「凍結を止めたのは Adam の ε」（[[層別キメラでELU崩壊の所在を決める_結果_0914]] の事後の読み）と、[[第2層のµ₂壁にεとLayerNormを当てる_結果_0916]] の ε 介入の読みは、この性質を入れて読み直す必要がある。**本走ではその再判定をしていない**（別作業として提案済み）。
- 固定尺度の命題（[[中心主張v10草案_0916]] §1.3a）の「ELU の負側の微分は $e^{-D}$ のオーダー」は、この実装・float32 では D > 16.64 で 0 に置き換わる。命題の結論（局所応答と生勾配が消える）はむしろ早く成り立つ。
- **09/17 補足（系統）**: この床は autograd で expm1 を微分する走（mucap/resp_ee/l2cap・act_chimera の VM）の性質で、white-san の CUDA では −16.98。GPU で逆伝播を手書きした走（elu_environment・layer_chimera・relu_gelu_silu・l2_wall）は微分に $e^z$ をそのまま使うので、床は float32 の exp の下溢れ −103.97 → [[εの再判定_float32の床を入れて読み直す_結果_0917]]

## 6. H4 に対して言えること

- 作業リスト H4 の閉じる条件のうち「**応答への介入が再学習の低下を変える**」は、RL・ELU→ELU・固定 1200 枚・6000 更新の箱で、両方向に満たした。
- 同じ箱の上流（[[第1層の成分上限をELU→ELUに当てる_結果_0917]]）では、第1層の成分上限は第2層の崩壊を遅らせただけで防げなかった。**この箱で「W の成長 → 第2層の輸送」を介入でつなぐ部分は、まだ閉じていない。** 下流（応答 → 再学習）はこの走で閉じ、上流の担い手は第2層自身の重みの成長が候補に残る。
- 「機能的な応答」の定義は、平均の $e^z$ でなく、訓練の微分（float32 の 0 を含む）と、その微分を運ぶ実効的な画像数で書くのがよい（§4.2-4）。
