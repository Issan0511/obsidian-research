## 2. 読み

1. **低ゲートは「くすぶる」。Adam は補償しない。** 生勾配（ρ_g 0.9）だけでなく、Adam が正規化した歩幅 κ2 も歩幅の予算 S² もタスク増分 D² も、ゲートの順に並ぶ（leaky +0.63・ELU +0.86・Snake +0.55）。座標ごとの正規化は勾配の**尺度**を消すが、低ゲートユニットの勾配は少数の入力（折れ目の正側にいる標本）だけが作るので **m̂/√v̂（符号の揃い）が小さく**、正規化後の一歩も短い。9/10 夜の「深い leaky ユニットは利得 0.1 の線形ユニットとして更新され続ける」は、‖W̃ᵢ‖² の正味増分（[[低ゲート個体の滞留_結果_0911]] §2-5: 下位 10% が +0.69 対 +0.55）だけを見た読みで、**歩幅は小さいが向きが動径（成長）方向に揃っている**と直すべき。
2. **ELU の固定の芯は貢献ゼロ。** 7–9 個の芯（e^z が消えた個体）は平均置換しても損失が 1e−3 も動かない（活性化が定数 −1）。[[低ゲート個体の滞留_結果_0911]] C4（芯があっても余分な損失なし）と整合。「動かないが有用な特徴を保持している」でもない。**芯は死んでいて、死は無害**（ELU の損失 ≤ leaky）。
3. **幅を止めて動くのは、ゲートでも歩幅でも参加数でもなく、第 1 層の生勾配と経路持続。** wclamp で graw² は 1.7 倍（9/9）、ρ は 0.83 倍（9/9）、S² と κ2 は不変。つまり **Adam の歩幅は同じまま、勾配が大きい状態に保たれる**（‖W̃‖ が伸びるほど第 1 層の勾配が縮む、の逆）。V9 §3 が「残る候補」に挙げた**「重み増大に伴う実効 step の縮小」**の直接の署名で、ゲート（p⁺・Ḡ・Cov）と参加数・W2 列は外れる。ρ の低下は、射影が動径成分（成長方向の持続）を削っていることの表れ。
4. **主軸 B の経路候補の絞り込み**: 残るのは「勾配の尺度（実効 step）」と「経路持続」。次は wclamp と ref の間で **勾配尺度を直接操作**する腕（第 1 層だけ lr を ‖W̃‖ に比例させる／Adam の ε を動かす）か、graw² が ρ と同じ順で並ぶかを Snake 梯子・τ 梯子（[[高ゲート帯の幅ダイヤル_結果_0911]]）で見ること。

## 5. 追記（2026-09-11・**事後・未登録**）— B1 の交絡を 3 つ潰した

「低ゲートのユニットは歩幅も短い」（B1）が、ゲート**そのもの**の効果か、ユニットの幅や深さの副産物かを、偏 Spearman（順位の線形残差）で見た。late 窓 t61–100・3 seed・hard-dead 除外・タスク中央値。

| 腕 | ρ(ḡ, S²) | ‖W̃ᵢ‖ を制御 | z̄ᵢ を制御 | **graw²ᵢ を制御** |
|---|---:|---:|---:|---:|
| LR | +0.63 | +0.64 | +0.52 | **+0.13** |
| ELU1 | +0.85 | +0.85 | +0.36 | **+0.21** |
| SNA | +0.56 | +0.55 | +0.33 | **+0.22** |

- **ユニットの幅では説明されない**（制御しても値が動かない）。深さを制御すると弱まるが残る（ゲートは深さを超えて効く）。
- **生勾配を制御すると消える。** 経路は **ゲート → 生勾配 → 実現した歩幅** の 1 本で、Adam の正規化はこの鎖を切らない。ρ(ḡ, κ2) も同じ値（+0.63 / +0.85 / +0.54、幅を制御しても不変）なので、効いているのは勾配の**大きさ**ではなく **m̂/√v̂（符号の揃い）** である。低ゲートのユニットは少数の標本しか勾配を出さないので、座標ごとに正規化しても一歩が伸びない。
- これは [[ゲートの尺度不変性と指数_結果_0909]] §6 の未登録仮説「β は勾配の一貫性」と同じ向きで、§3 の「Adam は行方向を優遇しない」（[[第1層の成長の中身_事後_0910]]）とも矛盾しない（あちらは**方向**の話、こちらは**ユニット間の順序**）。

**B3 との非対称**（同じ事後の読み）: 腕の中のユニット間ではゲート → 歩幅が通るのに、`ref` → `wclamp` の population 全体では生勾配が +70% でも歩幅 S² は不変（`STATIC`）。Adam は**一様な尺度変化は吸収し、ユニットごとの断続性は吸収しない**。これは正規化の定義どおりで、2 つの結果は整合する。あわせて、wclamp の ρ −17% は [[タスク内経路の持続_結果_0910|step_persistence_0910]] の実測則 ρ ∝ ‖∇W₁‖^−0.81 に生勾配 ×1.7 を入れた予測 −19% と 2 pt で一致する（事後の検算・登録予測ではない）。
