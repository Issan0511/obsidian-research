## 2. 読み

### 2-1. 飽和は一歩を縮める。向きは合っていた。量が足りない

τ を 0.3 → 3 にすると一歩が 1.54 倍、ω が 1.48 倍。**「帯が広いほど多くの標本が勾配を出し、符号が揃って一歩が伸びる」は成立**。しかし ω の 1.48 倍は leaky の傾きで 0.60 pt にしかならず、τ の効果 2.0 pt の **3 割**。**残り 1.4 pt は回る速さでは説明できない。**

### 2-2. ELU は同じ ω で leaky より良い。帯が広いほど、幅を止めるほど差が開く

M4 の残差は CELU03 −0.02 → CELU1 −0.57 → CELU3 −1.43 と単調。同じ計装で走らせた leaky の残差は +0.16 なので、2 走の較正はずれていない。**ELU 腕は leaky の線より下にあり、その差は τ とともに広がる。** 幅を止めた ELU（`CELU1w`）は目減り 0.00 pt・絶対水準 0.9222 で、leaky の同じクランプ腕（0.60 pt・0.9159）より良い。**ω は ELU クランプのほうが遅い（1.12e−3 対 1.38e−3）。**

したがって **L ≈ f(ω) + c_act** で、c_act は ELU で負（有利）、帯が広いほど大きく負になり、**ω の外にある**。

### 2-3. M3 は検出力がなかった（開示）

腕の中でユニットの長さは p10–p90 で **1.1〜1.2 倍**しか散らばらず、ゲートは **4〜30000 倍**散らばる。長さ側に効くかどうかを見る検定として無効で、`GATE_ONLY` は「腕の中では長さがほぼ一定」の言い換えにすぎない。長さの効果は腕をまたいで 4 倍振った [[回る速さが幅の正体か_結果_0912]] で決まっている。**M3 の設計ミスで、spec を書いた時点で気づくべきだった。**
副産物: 腕の中では**長いユニットほど回るのが速い**（ρ(ω_i, ‖W̃ᵢ‖) +0.09〜+0.38）。長いユニットは一歩も大きく（+0.15〜+0.41）、ゲートも高い（ELU で +0.13〜+0.48）。「長いユニットは深く沈む」という直感は腕の中では成り立たない。

### 2-4. 残り 7 割は何か

回る速さ（M2）は 3 割。ドリフト（一歩のうち勾配方向の成分）は τ で 10.0 → 13.2 と上がるが、[[勾配の床か揃いか_結果_0911]] の尺度（13.3 → 3.2 で +0.5〜0.7 pt）では 0.2 pt 程度で、これも足りない。**更新の力学側の 1 次元量は、ゲートの害に対しては 2 つとも測って不足と出た。**

残る候補は表現の側: τ=0.3 では hard-dead が **14 個**（他は 0）で Cov 0.78、使えるユニットが減っている。τ=1 → 3 は dead 0 のまま 1.2 pt 差があるので、dead の数だけでもない。**ゲートの形が「読み出しから見てユニットが何を運んでいるか」を変えている**、という方向。これは Issa が避けたかった多次元の話で、私も 9/12 に一度早まって口にしたが、**今回は 1 次元の候補を 2 つ実際に測って不足と確認したうえで**そこに戻る。

### 2-5. 主軸 B の現状（9/12 昼）

- **幅の害は ω で 1 次元に落ちた**（[[回る速さが幅の正体か_結果_0912]]）。本走でも ω は活性化をまたいで効き（11 腕 −0.83）、幅を止めた ELU は ω が上がって目減りが 0 になる。
- **ゲート（c_act）の害は ω では 3 割。** 残りは更新の力学の外。
- 主軸 B は **「損失 ≈ f(ω) + c_act」** まで来た。f は 1.05 pt/octave、c_act は ELU で −0.6〜−1.4 pt（帯が広いほど大）。**次は c_act の機構で、候補は表現の側。**

## 3. 限界

- t120・3 seed・τ は 3 水準・ELU のクランプは 1 水準。
- $b$ = 1.05 は leaky の当てはめ。ELU に持ち込む仮定を M2 で検定し、**外れた**。ELU の傾きが同じかは本走では決まらない（ELU で ω を独立に振っていない）。
- M4 の leaky 直線は ω の範囲 4 倍・ELU 側は 2.5 倍。外挿は不可。
- ḡᵢ は探針 512 枚での入力平均。
- `CELU1w` の錨は t100 まで。

## 4. 開示

- **M3 の設計**（§2-3）: 腕の中で長さがほぼ一定なので検定として無効。
- **角度の主式**（走る前・spec §4 に記載）: arccos は θ ≈ 1e−6 rad で相対 1e−4 の誤差を出す。正規化後の弦を主にし、arccos との突合は θ > 1e−4 の行だけ。**この修正が要った理由がまさに「飽和したユニットは回らない」で、CELU03 では (ユニット, 更新) の 40% が 1e−4 rad 未満**。
- 予測の根拠の誤り（§1）: ELU1 の ω が leaky より速いと読んだが、遅かった。
