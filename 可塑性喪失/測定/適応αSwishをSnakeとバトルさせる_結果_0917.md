## 0. 何を測ったか

適応 α Swish（$\alpha_j=\mathrm{clip}(c/W_j,10^{-3},10^3)$、$W_j=\sqrt{\mathrm{EMA}[\mathrm{Var}\,z_j]}$）が、適応 α Snake と同じ箱で LoP を防ぐか。Swish も尺度共変（$\phi_{\alpha/s}(sz)=s\phi_\alpha(z)$）なので、$\alpha=c/W$ ならゲート $\phi'$ は $u=z/W$ だけの関数になる。これは [[中心主張v10作業リスト_0916]] H6（スケール対照）の「尺度が追随する活性化」の 2 例目にあたる。

- 箱 `mlp`: 784-100-100-10・MNIST 1200 枚・Random Label・50 タスク・Adam 1e−3・batch 16・seed 0–9（CPU）
- 箱 `cnn`: Kumar の CNN・CIFAR-10 1200 枚・同条件（GPU、参照 5 腕は `rlcifar_cnn_0908` を bit 一致で再利用）
- 腕: `SW1`（α=1 ＝ SiLU）・`SW3`・`SWA1`・`SWA3`（適応、c=1・3）・`SNAc3`（Snake を c=3 で）・参照 `SNA`・`SN06`・`SN3`・`LR`・`R`

## 1. 登録判定

`verdict_mlp.json` の `labels`:

| 判定         | ラベル          | 意味                                        |
| ---------- | ------------ | ----------------------------------------- |
| B_c1       | `TIE`        | c=1 では適応 α Swish は固定 α Swish と区別できない      |
| B_c3       | `ADAPT_WINS` | c=3 では適応が固定に勝つ（SWA3 − SW3 = +0.565・10/10） |
| C_swa_best | `SWA3`       | 適応 Swish の最良腕                             |
| C_vs_SNA   | `SWA_BELOW`  | 最良の適応 Swish でも適応 Snake に届かない（−0.232・0/10） |
| C_vs_LR    | `TIE`        | leaky とは差が付かない（−0.051・7/10・p 0.34）        |

`verdict_cnn_A.json`: `SNAc3` は **`C_VALUE`**（q = 0.880、SNAc3 − SNA = +0.0157・10/10）。CNN で SNA が固定 α に負けていたのは c の値の問題だったという前ターンの診断と整合する（この判定は Swish ではなく Snake の c ダイヤルについてのもの）。
