# ゲートの単調性が侵食の符号を決める（gate_rearrangement_0912）

spec `spec_gate_rearrangement_0912`（事前登録 repo `08da078`、追補 1–2）／結果 `46b2b71`。活性化 7 種 × 置換の重なり k ∈ {0, 0.1, 1} × 3 seed = **63 走 × 120 タスク**。

## 問い

[[置換の重なりで侵食を引く_結果_0912]] で、侵食 c の飽和が leaky と Snake で違った。**事後の読み**「Snake のゲート 1+sin(2αz) は零点が周期的に並ぶので、画素を 1 割入れ替えるだけで応答ユニットが大きく入れ替わる」を潰す。**活性化形状の検定は 5 回目**（φ″・gcorr・RMS φ′・h の 4 連敗のあと）。

## 判定（Claude 2/5）

| | ラベル | 予測 | 実測 |
|---|---|---|---|
| V1 組み換え量が飽和を並べるか | **`FAILS`** | `EXPLAINS` | Spearman(gate_corr, S) **−0.36** |
| V2 Snake 族で α に単調か | **`NOT`** | `MONOTONE` | S = 0.23 / **0.95** / 0.83（SN06 > SN15） |
| V3 傾き族は飽和しないか | **`NO_SATURATION`** ✓ | 同 | S = −0.20 / −0.24 / −0.06 |
| V4 ELU はどちら側か | **`LIKE_LEAKY`** ✓ | 同 | S(ELU1) −0.18 |
| V5 c を並べるのは | **`TIE`** | `GATE_WINS` | gate_corr −0.73 対 **切替CE +0.84** |

## 残ったもの — 二値の分離は 7 腕で例外なし

飽和比 $S = c(k{=}0.1)/c(k{=}1)$:

| 群 | 活性化 | S |
|---|---|---|
| **1 交差** | LR001・LR・LR03・ELU1 | **−0.20 / −0.24 / −0.06 / −0.18**（全部負） |
| **周期** | SN02・SN06・SN15 | **+0.23 / +0.95 / +0.83**（全部正） |

leak を 100 倍（0.01→0.3）振っても、折れ目を平滑（ELU）にしても 1 交差なら S ≈ −0.2 に揃う。**量（組み換えの大きさ・α の値）は並ばないが、単調か周期かの二値は完全に分離する。**

## 決定的 — 機構は「境界での組み換え」ではない

**k=0 では境界で置換が変わらない**（`gate_corr` ≡ 1.0、`gate_l1` ≡ 0）。組み換えはゼロ。それでも:

| 活性化 | c(k=0) |
|---|---:|
| ELU1 / LR03 / LR001 / LR | −0.042 / −0.036 / −0.033 / −0.029（**自己膨張**） |
| SN02 / SN06 / SN15 | −0.001 / +0.004 / **+0.012**（α に単調増） |

**何も組み変わっていないのに族で符号が分かれる。** よって §0 の事後読みは、二分の部分だけ正しく、機構の帰属を誤っていた。残る候補は**タスク内でゲートが動くこと自体**。

## `gate_corr` は何を測っていたか
k=1 では Snake の `gate_corr` が 0.003–0.06（LR001 0.50・ELU1 0.39 に対し）まで落ちるので、大きな摂動では確かに激しく組み変わる。しかし飽和が起きる k=0.1 では SN02 が **0.916** と最も組み換えが小さいのに S は正。`gate_corr` は φ′ の**値の分布**に支配され（leaky は 2 値、Snake は連続）、配置の指標として不適切だった可能性が高い。

## 限界
V2 は n=3。S は比で c(k=1) が小さい SN15（0.031）で不安定（生値併記）。k<1 は Permuted MNIST の外側。初回本走は `p4` の許容 1e−12 が厳しすぎ 63/63 が最後の検査で落ちた（追補 2、28 分の損）——検査を訓練の後ろに置いた設計の失敗。
