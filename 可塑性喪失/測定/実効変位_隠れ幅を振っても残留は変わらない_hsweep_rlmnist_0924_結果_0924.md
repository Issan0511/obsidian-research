## 0. 一言で

## 2. 読み

- **残留は容量で決まっていない。** 当てはまる腕（h = 64, 100, 300）で f_10 は .556 / .566 / .599、当てはまらない腕でも .51〜.54。読み出しが全部を読む h=8 でも半分残る。h に対する単調な上昇（+.09、h=8 → 300）はあるが、仮説が要る大きさ（.5 → .1）の 1/5 以下。
- **削りは lag 1 に集中し、その大きさは読まれる分担に追随する。** 1 課題目の削りは h=300 の 18% から h=8 の 33% へ増え、読まれる部分の f_1 は .59〜.67、読まれない部分は .81〜.86 で h によらない。しかし 10 課題後には読まれる部分も読まれない部分も同じ .5 前後に落ち着く。**読まれるかどうかは「いつ削られるか」を決め、「どれだけ残るか」は決めない。** Codex の事前の指摘「W3·W2 の直交補は損失の零空間ではない」と整合する。
- **幅は止まらない。** B は .89〜.95、log-log の傾きは .6〜1.9、P2 は全腕 0/5。小さい網は 1 課題の書き換えの割合が大きく（ρ .42 → .63）削りも深い（c −.19 → −.29）が、比は同じ（B ≈ 2|c|/ρ ≈ .9）。
- **小さい網ほど 1 ユニットの幅が大きい。** V_Σ は h に対して劣線形（8 → 300 で 5.4 倍、ユニット数は 37.5 倍）。当てはまらない網でも幅は伸び続ける（h=8 で +40/課題）。

## 4. 残る問い

残留の半分は、容量でも読みやすさでもない。候補は二つ。**最適化器**（同じ h=100 で全部 SGD の ABAB は往復 cos −.93、Adam は −.40）と、**損失の「勝てば十分」**（新ラベルが勝った時点で古い関数を抑える圧力が消え、読まれる残りも許される）。分ける走は、同じ MNIST 固定入力・h=100 で最適化器を SGD（lr .01）にして f_10 を測ること。最適化器なら f_10 が .1〜.2 に落ち、損失側なら Adam と同じ .5 前後のはず。走ゼロで先に見られるのは CIFAR の sgd_postfit の SA_iid 腕（crossover fork の保存点、26 GB の退避先）。

## 5. 訂正（完走後、Claude）: f_10 の判定は恒等式の言い換えだった

残留 f_∞ は定常なら 1 − B/2（f_k = 1 + Σ cos_j、B ≈ −2 Σ cos_j）。B が .89〜.95 なら f_∞ は .52〜.55 で、h によらず「半分残る」のは幅がほぼ釣り合っていることの言い換え。登録した「最小の当てはまる h で f_10 ≤ .3」は B ≥ 1.4（幅が急速に縮む）に相当し、定常では起こり得ない条件だった。**効いた判定は B と P2**（全 h で B .89〜.95、P2 0/5、頭打ちなし）で、結論「容量は幅の伸びを止めない」は変わらない。h による差は削りの**時期**（f_1: h=300 .82 → h=8 .67）だけ。

§4 の SGD の走は判別にならない。CIFAR の全部 SGD 腕（SA_iid）の B は .952 で Adam A の .952 と同じ、F .958、S_hi .963。残り 5% は最適化器の性質ではなく、差は尺度（Q が 57 倍）。残る問いは「なぜ B が 1 に届かないか」で、D ∝ R^0.7・|c| ∝ R^−0.26（MNIST 150 課題）という現象論より先は未導出。
