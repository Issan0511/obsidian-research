## 1. 併記（spec §5 の必須）— 「両側とも下」ではない

| D_PRE_GATE(h_cross) | +7.06e-3 | [+3.5e-3, +1.18e-2] |

読み:

1. **G(h_below) は機械精度でゼロ**（1e-16）。横断しない振幅では LIVE と PRE_GATE が同じモデルになるという §8-2 の要請が実測で立っている。主 C はほぼ G(h_cross) そのもの。
2. **符号は鏡像側で逆**。K1（上端に 1 点だけ出ている側）では −5.1e-2、K31（1 点だけ下にある側）では **+1.4e-2**。**「両側とも下」とは書けない**。主 C が負なのは K1 側の大きさが K31 側の 3.6 倍あるため。
3. **正負平均の応答自体は両モデルとも正**（D_LIVE = +2.1e-2、D_PRE_GATE = +7.1e-3）。ゲート切替は「上向きの偶応答を 3 分の 1 に減らす」向きに効いていて、単独で下向きの変位を作っているのではない。この区別は G が差であることから来る。
4. 振幅を上げる（h_multi）と G は両側とも約 2 倍になる。3 振幅から普遍的なべき指数は主張しない（spec §7）。

## 2. 1 更新目の独立検算（§7・機構の発見には数えない）

LIVE / PRE_GATE の両モデル、全振幅・両符号で、実装が返した変位と代数式
R(h,1) = −2η v² mean_r{[φ(z_ref+h)−φ(z_ref)] φ′(z_ref+h) [1+X_r·µ_X]}
が **最大誤差 6e-16** で一致（`first_step_check.csv`）。**この式の v² は代数的に決まるので、v² 機構の発見ではない。**

PRE_GATE では ±h の 1 更新目が厳密に反対符号、LIVE では横断振幅でだけ非対称、という予定通りの形も確認した。

## 3. 適応量 — 読みを縛る条件

**`FIT_LIMITED`。** 1000 更新後の MSE/MSE(0+) の中央値は 0.20、比 ≤0.1 を満たす target は 2/20。`NO_FIT_SIGNAL`（蹴りが出力に効かない）は無し。

→ **C が正の値を持つことは示せたが、「十分に戻した後の非対称」ではない。** 5 分の 1 まで誤差を消した時点での介入差である。逆向きに言えば、小さい C を否定に使えないという §6 の注意はここでは効かない（C は帯を超えている）。

学習中の横断: LIVE は中央値 0 回（蹴りで移った先のゲートに留まる）、PRE_GATE は z の符号変化が中央値 1 回（傾きは固定のまま）。h_below では両モデルとも横断 0。

## 4. 実装検査（18 本 PASS・`src/test_mirror_0908.py`）

蹴りは b だけ（W 不変・0+ の zbar 変化が厳密に ±h）／φ(z+h)−φ(z)−s_ref h が非横断点で厳密 0・横断点で非 0／横断しない人工例で LIVE と PRE_GATE の短時間全パラメータ軌道が一致／**参照枝をずらした変異では順伝播の出力自体が変わる（逆伝播だけの改変ではないことの検出）**／支持点を並べ替えても対応を保てば同じ結果／**a=1 の人工例で G が 1e-12 以下**（D_LIVE 自体は 0 と要求しない）。

## 5. 主張の上限

- 言えるのは「**対象のゲート切替を許すと、対称な蹴りへの有限時間応答が変わる**」まで。差の向きは鏡像側に依存する。
- 自然なタスク境界の沈下を説明したことにはならない。これは b だけの並進であり、実際の flip は入力平均・入力変換・教師出力・全ユニットを同時に動かす。
- ここで測った C を、[[殻極_parity再適応_結果_0908]] の P と足し引きして寄与率にしない（親 §8）。
- **差の向きは 1 更新目には決まっていない。** G(h_cross) は両側とも step 1 で負（K1 −1.7e-4 / K31 −1.7e-4）で始まり、K31 は step 50–100 の間に符号を変えて最終的に +1.4e-2 になる。K1 は単調に −5.1e-2 まで伸びる。**鏡像側の符号の違いは、蹴りの瞬間ではなく後続の再適応が作っている。**
