## 一行

「タスク内で安定 → 境界で反転」は**棄却**。駆動符号は τ ≈ 5–10 step で自己脱相関する高速ゆらぎで、タスク周期 10⁴ とは 3 桁違う。ただし**境界イベント自体は 1 step で符号を完全再ランダム化する**（同ラグ対照で確認）。死亡は単調輸送、匍匐は amended 指標で支持、下向き正味の正体は構造的に負の自己項（**ただしその含意は 8/20 夕に訂正 → [[中和と境界窓]]**）。

## 設計

condA・w100・T=1e4・batch=1・lr 0.01・10 seed・1M step（**`w100` は学習器の幅** → [[用語と記号]] §4）。**境界 [−100,+100] は毎 step、バルクは 1000 step ごと**に記録（21,000 点/run）。全量が 32 パターン全サポート上の**厳密期待値**（サンプリング誤差ゼロ）。判定基準は実行前に commit。

実現 flip は 100 境界のうち **99**（`range(start, total)` で t=total は実行されない）。

## 核心: 時間構造【ラグを揃えると絵が反転する】

| ペア | 一致率 |
|---|---|
| バルク 1000 step 隣接（P1） | 0.497 [0.487, 0.507] |
| 1 step 隣接（一般・flip 跨ぎ除外） | **0.797** [0.783, 0.808] |
| **1 step 隣接・flip を跨ぐ** | **0.496** [0.460, 0.532] |
| flip 直前 1 step | 0.785 |
| flip 直後 1 step | 0.821 |

paired 差（generic − straddle）= **+0.301 [+0.268, +0.332]**。

- **P1 の FAIL は本物**（粒度アーティファクトではない）。1 step で 0.797 → 1000 step で 0.497 まで落ちるので、相関時間は数〜10 step。タスク周期の 1/1000
- **P2 の字義 FAIL は基準の作り方の問題**。事前登録した「A_within − A_boundary の下端 > 0.2」は within が安定であることを前提にしていたため、within が崩れた時点で自動的に落ちる。**予測内容（境界で符号がコイン化する）は成立している**

> **監査で検出した誤り**: 実験 summary の総合判定「A_within 0.503 ≈ A_boundary 0.496 で差が無い → 境界は駆動符号にとって特別な瞬間ではない」は、**ラグ 1000 step の量とラグ 1 step の量を比較している**。両方が 0.5 なのは別々の理由による。同ラグ対照では境界は明確に特別。**8/20 以降はこの文を引用しない**。

## P3: 死亡は輸送

死亡ユニットの**経路効率 PE = |正味変位| / Σ|増分|**（1 に近いほど輸送、0 に近いほど拡散）の中央値 0.396、符号置換帰無の 95%点 0.218（帰無中央値 0.205）。766 窓。独自定義（粗グリッド）での再計算では 0.705 と定義依存だが、**輸送方向の結論は同じ**。拡散到着ではなく、方向のそろった輸送で −帯に運ばれている。

**留保（8/20 追加）**: 死亡個体に**再分類死と輸送死が混在**している（[[命題リスト]] Q16）。分離前の PE を機構の証拠として引かない。

## P4: 匍匐【事前登録指標が無効だった】

- **事前登録 BC(cos) はトートロジー**: p̂=0 のユニットは勾配が恒等的に 0 で w が動かない。すると cos(u,µ̂) が動くのは µ̂ が動く時＝境界だけなので、**BC(cos)→1 が機構と無関係に成立**する（バルク変位が実測で厳密に 0.000）。0.924 という値は証拠にならない
- **amended 指標 BC_w**（µ̂ 非依存・‖w‖ ベース）: 0.315 [0.300, 0.331]。時間占有率 2.01% に対し **15.7 倍の濃縮**。独自再計算（等解像度 1000 grid）でも 0.639 vs 帰無 0.2 = 3.2 倍で同方向
- **再露出率**: 凍結区間の 76.5% [74.7, 78.3] で ‖w‖ が実際に動いている＝「押されている」こと自体を確認

→ 匍匐仮説（境界で µ̂ が跳ぶ → 凍結ユニットが一瞬再露出 → 一押し → 再凍結）は**支持**。ただし amended 扱い（rank_int の width プールと同じ格）。**BC(cos) 単独では引用しない**。機構の説明は [[台帳（実効バイアスの縮退）]] §4（再露出＝凍結座標の記帳が b_eff に復帰）。

## P5: 判定保留

切替回数と経過 step の相関 **0.9999**（切替は period ごとに決定的に起きるので同じ量の 1/period 倍）。「step を追加しても符号維持」は共線下で自動的に満たされ、**字義 PASS は証拠にならない**。→ **T スイープ（T ∈ {1e4, 3e4}）を Phase 2 に起案**。

## E1: 下向き正味の正体は自己項【探索的・**含意は 8/20 夕に訂正**】

- **self 成分は一度も正にならない**（10 seed × 20,901 記録点、符号安定率 1.000）。独自再計算でも全 seed で「正の割合 0.0」
- **解析的に構造化**: F_self,i = −2η·v_i²·E[a_i·gate_i·(x·µ̂)]。condA は入力もµ̂も非負なので全因子非負 → **恒等的に ≤ 0**。偶然ではない（→ [[自己項の恒等式]] で定理化、点毎に成立）
- rest 成分の符号安定率 0.806、大きさ比 self/rest = 0.6176

→ 8/19 canvas で未分離だった「(a) v² 比例の自己項 か (b) 整流残差 か」は **(a) 寄りで決着**…**とした読みは 8/20 夕に撤回**。税は 99.5% 中和されて正味を運んでおらず、**駆動は rest** に差し替わった（[[中和と境界窓]]、[[命題リスト]] Q2b）。self の片側性は定理として残り、役割は**罠の吸収性**へ移った。

> **引用上の限定**: **rest の符号安定率 0.806 は「死亡ユニットの降下窓」限定**（`figures_ratchet_log.py` L303–326、`descent_windows`）。死んだ個体に条件付ければ下向き持続が出るのは P3 の言い換えに近く、**駆動の偏りの証拠としては使えない**。

## サニティ

- **S2（無擾乱）**: probe あり/なしで 100k step 後の全 state ハッシュが bit 一致。probe は軌道に一切影響しない
- **S3**: 厳密 p̂ と経験 p̂（N=2000）が二項ゆらぎ内。退化ユニットは厳密一致（誤差 0.0）
- **S4**: flip イベントが t ≡ 0 (mod 10⁴) に厳密一致、99 遷移
- **恒等式**: G の相対誤差 0.0、F_gate 4e-16（float64 マシンイプシロン）

## 実装上の逸脱（記録）

1. `full_support()` は内部で `maybe_flip()` を呼び軌道を進める → probe から呼ぶと S2 違反。**`full_support_ro()` を新設**（スペック §2 の設計ミス）
2. スペック §2/§4.1 が指す `posreset_posthoc.py` に G / F_i 実装は無い → 本番勾配コード `nets.VecMLP.grads_batch` との突き合わせに変更
3. **旧・部品3 の 0.567 は再現不能**。値がリポジトリに無く、60 遷移を作る run 部分集合も復元できず、`followup_Eg` npz は G=E[δx] ではなくゲート済み `Eg_W` しか持たない。**以後は本実験の値のみ引用**
4. S3 の字義「全ユニット max ±3σ」は約 3000 検定になり真に無擾乱でもほぼ確実に落ちる → median|z| + 二項上側検定に置換（bias_margin_0814 の教訓）
5. F_self/F_rest は float32 の和で桁落ちするため `F_gate` を別途保存
