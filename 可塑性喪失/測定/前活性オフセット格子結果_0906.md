## 3. 読み（事後）

### 3-1. 井戸の底の法則は a に依らない

「下」群は 4 つの a すべてで −c/a に**小数 2 桁で**座る（−2.48/−2.50、−1.66/−1.67、−1.00/−1.00、−0.71/−0.71）。a=0.7 も例外ではない（予測「上の枝の底 −0.5 と融合して −0.6 前後」は外れ・底は下の枝にしか無い）。c=−0.5 の「上」群も 4 つの a すべてで **+0.50** ちょうど（底 −c）。**井戸の底に座るという法則は、a・c・lr（ラダー B の c=+1 → −9.89 対 −10）にわたって成り立つ。**

### 3-2. c<0 の「上」への脱出は雑音誘起（Chen 型）

事前に登録した読み規則（spec Log）: c=−0.5 の「上」群の割合を 3 条件で比べ、一次なら ≈10% で不変、Chen 型（Itô ドリフト ∝ η）なら雑音 0 で ≈0・雑音 1/8 で数 %。

| 条件 | 上の割合 | z̄ ALL |
|---|---|---|
| online lr 0.01（act_offset） | **10.2%** | −2.01 |
| online lr 0.00125（雑音 1/8・η·step 一致） | **0.0%** | −4.48 |
| full-batch lr 0.01（雑音 0） | **0.0%** | −2.57 |

→ **Chen 型の署名**。Issa の直感（「c=−2 の上群は Chen の GELU が 0 に引き込まれる話に似る」）が当たり、形式上の予測（Issa・Claude とも「一次 65%」）は外れ。ただし **c=−2 では lr 0.00125 でも 51% が抜ける**ので、絵は「浅い井戸（|c| 小）では折れ目の壁を越えるのに雑音の蹴りが要り、深い井戸（|c| 大）では一次の引きだけで越える」＝**Kramers 型の障壁越え**が最も素直。雑音が要るのは**脱出**であって、井戸の存在ではない（雑音ゼロでも Δz̄(c) は +1.10／−0.82 と動く）。

### 3-3. 幅（‖w_free‖）は雑音でも lr でも決まらず、v が抑えている

| 条件（c=0・a=0.1） | ‖w_free‖ 比 |
|---|---|
| online lr 0.01 | ×5.05 |
| online lr 0.00125 | ×5.34 |
| full-batch | ×4.68 |
| **v 凍結** | **×13.6** |

幅の成長は雑音にも lr にも依らない（一次）。**v を凍らせると 2.7 倍余計に育つ**——v の学習が幅を抑えている。a の梯子（c=0）は ×3.39 / 2.61 / 1.76 / 0.23（a=0.2/0.3/0.5/0.7）で、1 を切るのは 0.5–0.7 の間（scale_attractor の転移 a≈0.52–0.6 と整合）。**井戸の底に座ると幅は潰れる**（c=+0.5 で ×0.75 / 0.19 / 0.03 / 0.08）——E[(φ+c)²] の最小は支持の幅 0 なので、着座と支持の崩壊は同じ運動。

### 3-4. v 凍結の世界

v を初期値で凍らせると、c に依らず同じ 3 分割（上 17–20% / 跨 50% / 下 29–32%）になり、「上」群は +12.8、「下」群は −11.8 と両側へ飛ぶ（半幅 9.9）。c の効果は消える（Δz̄ +0.1〜+0.3・帯内）。**v が動かないと井戸が働かない**、という act_offset §4-3 の読み（c は ∂L/∂v にしか入らない）と整合する。ただし CI が広く登録の帯を越えたので、ラベルは `INCONCLUSIVE`。

### 3-5. 小さい c は母集団を割る

c=+0.25（底 −2.5 は c=0 の着座 −3.6 より上）: ALL 中央値は動かない（Δz̄ −0.10）が、**67% が −2.56 へ上がり**（底 −2.5）、33% が −4.35 へ沈む。「着座点が上がる」という予測は中央値では外れ、機構（底が届く範囲にあれば座る）では当たり。c=−0.25: 脱出 0%、Δz̄ +0.75。

### 3-6. ラダー B（lr 0.00125・7 点）

| c | −2 | −1 | −0.5 | 0 | +0.5 | +1 | +2 |

c>0 は底を追う（−5.14 / −9.89 / −19.65）。c<0 は −2 だけが脱出し、−1・−0.5 は跨いだまま押し戻される。

### 3-7. full-batch 500 タスク

c=0: z̄ −3.68（online −3.60 ✔）、**zmax −0.52**（online +0.11 ✘・雑音が無いと上端は折れ目の 0.5 下に座る）、幅 ×4.68。settle は −3.22 → −3.50 → −3.68 で**まだ下降中**（雑音は加速器、edge_law の読みどおり）。c=+0.5: −4.42 で下降中（底 −5.0 に向かうかは 500 タスクでは決まらない）。

### 3-8. ELU（参照 `Eoff0` を得て Δ が読めた）

Δz̄(+1) = −2.82 [−3.31, −2.48]、Δz̄(−1) = +1.92 [+0.79, +3.08]。leaky と同じ符号の型。`Eoffm1` は **84% が +1.00 に座る**（底 −c）——ELU でも法則は同じ。

## 6. 方法論の教訓

1. **settle 判定は判定統計量そのものに掛け、CI 幅を絶対下限つきで書く。** ブロック 1 は判定量（「下」群の中央値）ではなく ALIVE 全体の z̄ で settle を測り、CI 幅 0.001 に対して 0.02 のドリフトで `NOT_DETERMINED` を出した。edge_law の G1 誤射と同型（精度が高すぎる量にゲートを掛けると必ず落ちる）。
2. 一様な定数を全ユニットに足す介入（c・b オフセット）は λ ≈ 2hc² の曲率を作る。**b+2 も落ちた**ので、edge_law の ±5/±4 の即発散は「大きすぎた」のではなく機構的。
3. 「上」群の割合は ALL ユニットで読む。ALIVE 規則は潰れたユニット＝見たいユニットを落とす。
4. 予測を「中央値」で書くと二峰で外れる。母集団が割れる走では「群の割合と群の位置」で予測を書く。
