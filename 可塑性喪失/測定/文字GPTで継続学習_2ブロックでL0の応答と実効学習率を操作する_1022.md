## 0. 一行

読み出しの一つ手前の FFN（L0）について、局所の応答だけを戻す操作でも、実効学習率だけを保つ操作でも、2 ブロックの C3-2 の学び直しは戻った。応答の操作では部分的（C3-2 と cap の差の 4〜7 割）、実効学習率を保つ ELR では cap 並みだった。ELR では、読み出しに隣接する L1 が課題 100 まで 9 割以上閉じたままの seed でも、学び直しは生き返った seed とほぼ同じだった [測定]。

## 1. 問い

- 追補 7 では、両方の FFN に幅の上限 cap をかけると、C3-2 の可塑性の喪失が 10 seed すべてで救われた。cap なしでは L0 が課題 25〜100 に閉じて死に、cap ありでは死ななかった。
- cap は、幅・相対歩幅・担い手への感度を同時に変える。L0 の局所応答（ゲートと局所微分の場）だけを操作したとき、学び直しは変わるか（9.A）。
- 実効学習率（lr / ‖w‖）だけを保つと、学び直しは変わるか（9.C）。
- 依頼は Issa（「① しきい値の持ち上げと ② 応答場の交換の両方を設計して回して」「実効学習率だけを保つ腕を足して」）。設計は V13 セッション（Opus 5.5）が書き、Astra（gpt-6-astra）が登録前に批評した。確定と実行はこのセッション。

## 2. 走（9.A：L0 の応答の操作）

### 2.1 操作の形

受け手の L0 の ReLU に入る活動を、次の形に置き換える。

ã = φ(r₀) + {φ(base + (z − r₀)) − φ(base)}

- z は受け手の今の L0 の前活性。r₀ は、受け手の出発点を凍結した写しの前活性。
- 凍結した写しは、自分の埋め込み・注意 0・LN を通して、各 forward でその入力について毎回計算する。勾配は流さず、optimizer にも入れない。
- 開始時（z = r₀）の活動は自然網とまったく同じになる。変わるのは、受け手の z に対する局所微分（実効ゲート 1[base + z − r₀ > 0]）だけ。

| 腕 | 受け手 | base | 役割 |
| -- | -- | -- | -- |
| C3-self | C3-2 | r₀ | 対照（同じ演算経路） |
| cap-self | ReLUcap-2 | r₀ | 逆向きの対照（cap は続ける） |
| β-FA | C3-2 | r₀ + β | ほぼ開かない unit のしきい値を持ち上げる |
| F-swap | C3-2 | d₀ | 同じ seed の cap 網の L0 の場を移す |
| F-rev | ReLUcap-2 | d₀ | C3-2 の場を cap 網へ移す（逆向き） |
| F-swap-scale | C3-2 | c ⊙ d₀ | 移す場の幅を受け手にそろえる |
| β-F（報告のみ） | C3-2 | — | 自然な固定 bias（ã = φ(z + β)） |

d₀ は供与者の出発点を凍結した写しの前活性。主は課題 90 末 → 課題 91〜100、副は課題 50 末 → 課題 51〜60（C3-self・cap-self・β-FA・F-swap）。

### 2.2 走る前に確定した数（spec 9.B）

- p* = 0.3321（課題 10 末の C3-2 で、L0 の unit ごとの開く割合の中央値を seed ごとに取り、その中央値）。
- 較正集合と検証集合は、課題 t₀+1 の鎖から別の乱数ストリームで作った（それぞれ 64 系列 × 128 位置）。
- D = 較正集合で開く割合 p < 0.005 の unit。D の unit の β は、開く割合がちょうど p* になる値にした。課題 90 末の C3-2 の D は 0〜490 unit で、seed 4・8 は空（無介入の seed として残した）。
- F-swap-scale の倍率 c は、受け手と供与者の前活性の幅の比で、seed ごとの中央値は 35〜61。安全規則に当たった unit は 0 個。

### 2.3 実装の検査と監査

- 非自己の場で、実効の活動を独立な式と照合した（誤差 3×10⁻¹⁶）。実効ゲートも照合した（厳密に一致）。
- 受け手の勾配は有限差分と照合した（相対 3×10⁻⁶ 以内）。この勾配は自然網の勾配と 3 倍以上違うので、自明な一致ではない。
- ほかに確かめたこと：場の入れ替え、参照網の不変と勾配なし、復元後の Adam の 1 歩を手で書いた式と照合（相対 7.5×10⁻⁵）、ELR の射影と倍率。8 項目すべて合格した。
- 自己の腕は、元の走と最初の 10 更新では 10⁻⁶〜5×10⁻⁵ 以内で一致した。そのあとは丸め誤差が混沌的に増幅して、課題平均で最大 2% ずれた。spec の「丸め誤差の範囲で一致」は字面どおりには満たしていない。比較の対照は再走した自己の腕なので、判定には影響しない。
- 別の Astra に実装を監査させた。学習の式・較正・参照網・cap の継続・ELR は仕様どおりと判定された。ただし、検査の不備（Adam の復元の検査が自明に通る作り）など 7 点の指摘があり、すべて直した。直したあとの再監査は受けていない。
- 走った場所：手元の white-san と Vast の RTX 5060 Ti 4 台。各台の同じ短い走は、手元とビット一致した。

## 3. 判定（確認的な族）

主指標は、課題 91〜100 の seed 内平均 E1000（更新 951〜1,050 の超過損失）。両側 exact 符号検定に Holm（family α = 0.05）をかけた。

| 比較 | 予測方向の seed | p | Holm 後 | 平均の差（区間） | ラベル |
| -- | -- | -- | -- | -- | -- |
| C3-self − β-FA | 8/8（D が空の 2 seed は差 0 で除外） | 0.0078 | 0.0078 | +0.48（+0.24〜+0.73） | 予測方向の効果を検出 |
| C3-self − F-swap | 10/10 | 0.0020 | 0.0078 | +0.69（+0.51〜+0.89） | 予測方向の効果を検出 |
| C3-self − F-swap-scale | 10/10 | 0.0020 | 0.0078 | +0.86（+0.66〜+1.10） | 予測方向の効果を検出 |

区間は seed の bootstrap（20,000 回）。4 比較すべてで、予測した方向の効果を検出した [測定]。

## 4. 操作の成立

- 更新 0：補償つきの 6 腕は、同じ入力で自然網と残差・ロジット・損失・L1 のゲート・最終 LN の分母がすべて完全に一致した。自然な bias の β-F だけが、開始時に残差を 1.45 倍の大きさで揺らし、損失を +6.3 上げた。
- β-FA：D が空でない 8 seed すべてで、検証集合で D の unit がほぼ全部 p*/2 以上で開いた（開く割合の平均 0.33）。
- F-swap・F-rev・F-swap-scale：10/10 seed で、実効ゲートの開く割合が供与者側へ動いた（C3-2 の自然 0.085 → 0.196、F-rev は逆）。
- 持続：β-FA で持ち上げた unit のうち p*/2 以上で開いている割合は、課題 91〜95 の末で 1.00、課題 100 の末で 0.91。

## 6. ELR（9.C：実効学習率だけを保つ腕）

- 受け手は C3-2。課題 1 末から課題 2〜100 を学習した。手を入れたのは L0 だけ。
  - 各 Adam の更新のあと、L0 の W_up の各行を課題 1 末のノルムに射影し直す。これで lr / ‖w‖ が課題 1 の値に保たれる。
  - L0 の前活性に、学習しない倍率 k_i(t)（同じ seed の C3-2 の行ノルムの推移）を掛ける。出力の尺度を C3-2 にそろえる狙い。
  - L1 は素のままで、cap は無し。
- 判定は `ELR_RESCUES` [測定]。課題 91〜100 の 3 相すべてで、10/10 seed が C3-2 より良かった（どの相も p = 0.002）。

| 相 | ELR − C3-2 の中央値 | ELR − ReLUcap-2 の中央値 |
| -- | -- | -- |
| T015（更新数） | −8,832 | +147 |
| E1000 | −1.13 | +0.010 |
| ELast | −0.27 | −0.018 |

- 課題 100 の L0 の死は 0.00〜0.01。
- L1 は手を入れていない。課題 50 までは 10 seed とも 9 割以上閉じていた（0.90〜0.98）。課題 100 では seed ごとに分かれた。

| 課題 100 の L1 の死 | seed | 課題 91〜100 の E1000 |
| -- | -- | -- |
| 0.94〜0.99（閉じたまま） | 0・5・6・9 | 0.154〜0.168 |
| 0.86 | 4 | 0.158 |
| 0.40〜0.50 | 2・3 | 0.162〜0.167 |
| 0.00（生き返った） | 1・7・8 | 0.132〜0.147 |

- L1 が閉じたままの seed でも、学び直しは生き返った seed とほぼ同じで、cap 並みだった（生き返った seed のほうがわずかに良い）。
- 操作の成立は半分だった。
  - 回転（課題ごとの 1 − cos）が C3-2 の 10 倍以上：10/10 で成立（中央 28 倍）。
  - L0 の出力の RMS が C3-2 の ±20% 以内：0/10 で不成立。ELR の L0 の出力は C3-2 の 1.7 倍（課題 40〜50）、3.1 倍（課題 90〜100）だった。行ノルムは k でそろえたが、L0 が開いたままなので出力は大きくなった。

- L0 の ‖w‖ の中央値は、課題 1 末の 1.9・4.5・10.9・22.7・46.7・97.6・194・397・766 倍（課題 2〜10）、課題 20 で 8.4 × 10⁴ 倍になった。

## 9. 読み

- C3-2 の L0 で、応答（実効ゲートの場）を操作すると、学び直しは部分的に戻った。幅を受け手にそろえた場の移植が最も効いた [測定]。
- L0 の実効学習率（回転）を課題 1 の水準に保つと、学び直しは cap 並みに戻った。L0 の出力が C3-2 より大きいままでも救われたので、「出力の尺度が小さいこと」は救済に要らない [測定]。ただし出力の尺度は登録どおりにそろわなかったので、「実効学習率だけで救える」とまでは言わない。
- 読み出しに隣接する L1 の生死は、学び直しに必須ではなかった。ELR で L1 が課題 100 まで 9 割以上閉じたままの 4 seed も、cap 並みに学び直した [測定]。
- 逆向きの F-rev は、L0 の実効ゲートの大半を閉じても悪化が小さかった。cap 網の文脈では、L0 の応答の喪失だけでは崩れに足りない [読み]。

## 10. 言わないこと

- 回復比 G は媒介率ではない。cap の履歴を保ったまま媒介変数だけを入れ替える、自然な反実仮想ではない。
- 救済は、この受け手・課題 90 と 50 からの修復・10 課題での操作の効果。L0 の応答の喪失が、喪失の十分条件・必要条件だとは言わない。
- 学びが変わっても、平均応答の量だけの効果とは言わない（ゲートの配置・入力への依存・後段の適応を含む）。
- 同じ seed・同じ unit 番号の対応は初期の対応で、90 課題後の特徴の意味がそろっている保証はない。
- 2 ブロック・合成 2 次マルコフ・この lr と Adam・seed 0〜9 を超えて一般化しない。
