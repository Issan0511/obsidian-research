# leaky .001〜.01：必要な学習更新数の桁とφ′

2026-11-11。Issaの「.001と.01の間で、何桁の学習が必要か」「φ′はどうなっているか」に対する新規実験。元のCondA図の再現とは区別する。実験名：leaky_order_1111。

**今回の6課題後では、必要時間は約1万〜4万更新の範囲だった。a=.001はa=.01の同じseedに対して2.05〜2.88倍で、10倍ではなかった。75条件すべてで90%の連続到達を確認した。** ただしaの中間点は単調でなく、逆比例則や鋭い臨界点はこの結果からは決められない。

## 何を測ったか

乱数ラベルMNISTの固定1,200例、784–100–100–10、2層ともleaky ReLU、Adam（学習率.001、eps1e-8）、バッチ16。1更新は16例のミニバッチ更新で、75更新が1エポック。aは初期化時から一定。a=.001,.002,.003,.005,.01、seed3〜7。seed内で初期重み・入力・課題ラベル・バッチ順を対応させた。

旧課題を各6,000更新ずつ学習した「新品／3課題後／6課題後」から、同じ独立した新しい乱数ラベル課題を与え続けた。課題・Adam状態を途中でリセットしない。a=.003の源状態は前実験のSHA256照合済み保存から再利用し、独立反復としては数えていない。他のaは新しく20本の履歴を作り、全75プローブを今回のコードで実行した。a間では学習済み状態も変わるため、同じ重みにaだけを変える介入ではない。

主指標T90_sustainedは「75更新おきの4回連続で学習データ正答率90%以上になった区間の先頭」。確認は225更新後。最初の1回のT90も別途保存した。最低24,000更新、必要なら最大1,536,000更新という事前固定の停止規則。今回は全例到達し、最も遅い先頭が39,900、確認が40,125更新だった。90%は永続的な安定や汎化を意味しない。

## φ′：層・seedを分けると落ち込みが見える

以下は実験完了後の追加質問に対する保存済みログの解析。新しい学習や除外は行っていない。

今回のleaky ReLUは

\[
\phi'(z)=\begin{cases}1&z>0\\a&z\le0,\end{cases}
\qquad
\langle\phi'\rangle=a+(1-a)\Pr(z>0).
\]

したがってaは負側の傾きで、平均φ′そのものではない。ここでの平均は各層の1,200入力×100ユニット上の平均であり、パラメータ勾配の平均ではない。この恒等式は保存した全測定点で照合し、最大絶対誤差2.24e-10だった。

6課題後からの再学習750更新時点。各seedで層内平均を計算し、下表ではその**5seed中央値**を示す。

| ---: | ---------------: | ---------------: |
| .001 |          .083967 |          .001416 |
| .002 |          .026709 |          .052815 |
| .003 |          .112230 |          .003432 |
| .005 |          .097634 |          .005473 |
|  .01 |          .059021 |          .010602 |

a=.001ではseed3,4,6,7のどちらかの層が.00119〜.00142まで落ちていた。seed4では第1層、seed3,6,7では第2層が小さい。seed5は別で、第1層.01594、第2層.24031。全例が同じ経路で遅くなっていると見なさない。

**全seedを平均すると、この偏りが隠れる。** 再学習開始直後の第2層のseed平均はa=.001で.14636、.01で.07218だが、a=.001 seed4は第1層.003239／第2層.428172で、必要時間39,900更新。750更新後には第1層.001300／第2層.420389となる。第2層平均が大きいことと、両層を通る学習が速いことは同じではない。

## 追補：第1層×第2層の積ならどうか（1111・事後）

Issa「大体1層の値×2層の値では？」を受けて、同じseed内で \(P=\mu_1\mu_2\)、\(\mu_l=\langle\phi'_l\rangle\) を計算した。**前回答は層を別々に比較しており、積での説明を確かめていなかった。この比較は不十分だった。開始時の積は必要時間とかなり対応する。** 新しい学習は行わず、既存75例のログだけを解析した。全て事後解析で、事前登録の主結果とは区別する。

第1層への逆伝播は \(D_1W_2^\top D_2W_3^\top e\)（\(D_l=\operatorname{diag}(\phi'_l)\)、eは出力誤差）なので、経路上で両層のφ′が掛かる。したがって平均の積は自然な近似候補。ただし重み・符号・同じ入力上のゲートの組合せ・誤差方向を平均の積は保持しない。時間がその逆数になるかは別途確かめる必要がある。[逆伝播の連鎖律の出典：Deep Learning 第6章](https://www.deeplearningbook.org/contents/mlp.html)。

### 再学習開始時の積

6課題後・更新0で、各seedの積を計算してから5seedの中央値を取った。以前の表の「層ごとのseed中央値」を後から掛ける操作とは異なる。

|    a | 開始時の平均φ′の積P：seed中央値 | 90%連続到達まで：seed中央値 |
| ---: | ------------------: | ----------------: |
| .001 |           .00305325 |            21,075 |
| .002 |           .00268451 |            28,575 |
| .003 |           .00466017 |            11,775 |
| .005 |           .00570870 |             8,925 |
|  .01 |           .00609536 |             9,900 |

6課題後の25条件に対する事後の両対数当てはめは **\(T\propto P^{-0.9645}\)、両対数R²=.5959**。1/Pと時間のSpearman相関は.7805。傾きを−1に固定すると \(T\approx64.65/P\)、当てはめ内の幾何RMS誤差倍率1.36。実測／当てはめ値の範囲は.61〜2.64なので、粗い尺度としての対応であり精密な予測ではない。25点は5seed×5aの対応ありデータで、独立25反復としてのp値や信頼区間は主張しない。

3課題後の開始時でも指数−1.1484、R²=.7455。ただし傾き−1の比例定数は245.02で、6課題後の64.65とは違う。新品では積も時間もほぼ変わらず、当てはめ傾きは約0で、有用なスケーリング範囲がない。課題年齢を跨ぐ共通の逆比例則とはいえない。

### 750更新後の値では対応が崩れる

前回答の表が示した750更新時点の積を使うと、6課題後では指数が+0.1799、R²=.1389、Spearman(1/P,T)=−.2485となる。開始時の対応が学習途中にもそのまま残るわけではない。時点0と750の両方、および6課題後の1500・3000・6000更新も保存した。都合の良い時点だけを選んで一般則とはしない。

**修正後の読み：層別の平均だけより、両層の積を先に調べるべきだった。開始時にはおおむね逆比例に近い対応がある。一方、積は学習中に変わり、この一つの値だけで全過程や課題年齢間の時間差を説明できたわけではない。**
