## 0. 何を測ったか

## 2. 読み（機構）

1. **負けは可塑性の喪失**。t1 は SNA 0.977 > SNAc3 0.972（SNA のほうが速く覚える）、t4–5 で逆転、t50 で 0.939 対 0.965。
2. **切り替えの瞬間に fc(c=0.6) は平らな点に座って黙る**（t10 からの epoch 記録: 新ラベルの最初の 1 epoch で f2 のゲート平均 0.66 → 0.07、座席は谷底 −π/2、CE 33 → 2.5）。これは古い自信を 1 epoch で消す**速いリセット**で、損の原因ではない（QF: 塞ぐと切り替え時の CE が 450 に膨らみ覚え直しが 10 倍遅い）。c=3 の fc はゲート 0.99 のまま読み出しが動いて自信を消す。
3. **壊れ方は 2 つ**で、それぞれ介入で止まる。
   - **M2（尺度の錨）**: 入力層 c1 の適応 α が上限 3 に張り付いているあいだは固定 Snake として尺度の錨になる。c1 の幅が c/3 を超えて α が上限から外れ、fc の黙らせ（ブレーキ）も無いと、fc の幅と logit が暴走する（CV06FC3 は t25 から 0.973 → 0.885、fcamp0.7 単独は t10 から、F30 の fc→3 fork は t36 から。暴走時は α_c1 が 1.2〜1.7 まで落ちる）。c1 を固定 α=3 にすると止まる（QD1）。
   - **M1（谷の深さと鋭いゲートの追随）**: 錨がある状態で fc の平らな点を持ち上げると損が消える（QD2）。α を課題 1 末で凍結しても消える（Q2′: 凍結した α は t1 の値に留まり、W が育つと 2αW が 1.2 から 5 前後へ育ってゲートが洗われる）。つまり劣化を作るのは **2αW = 1.2 を保ち続ける追随**で、座席が谷へ沈む間もゲートの鋭さが保たれることが覚え直しを遅くする。
4. **進行性の劣化には c2・f1・f2 の 3 つのゲートが全部鋭いまま（2αW=1.2）であることが要る。** どれか 1 層を c=3 にする（conv: CV3FC06 は 50 課題で SNAc3 と同水準、t30 での conv→3 の fork は直後に全回復。fc の片方: F1ONLY/F2ONLY は平ら）か、α を凍結するか、平らな点を持ち上げる（c1 の錨つき）と、劣化は消えて固定 α=3 より上（0.969〜0.975 対 SNAc3 0.965）に出る。ただし沈んだ状態から fc の c を一気に 3 にする介入（F30 の fc→3・CV3FC06→SNAc3）は壊れる: c=0.6 の fc は損であると同時に尺度のブレーキでもあり、両方の fc を一度に洗うとブレーキが無くなる。
5. 分解（登録外、1 課題の fork）: conv を凍結すると fc だけの覚え直しは t10 でも online 0.989（0.99 到達は 11 → 18 epoch に遅れる）。conv と fc の共同の覚え直しの損は fc=0.6 の腕で t1→t10 に倍増（1.1 → 2.1 pt）、fc=3 は 1.3 → 1.4。課題中に α を固定すると全腕 +0.4 pt（fc=0.6 固有ではない）。c2 の位置間分散は pooled の 13%（α にして 7%）で、チャネル単位の分散の問題ではない。

**一文**: 適応 Snake が固定 Snake に負けるのは適応そのものの罰ではなく、(i) c2・f1・f2 の 3 層すべてで 2αW=1.2 の鋭いゲートを谷に沈んだまま保ち続けること（M1、どれか 1 層を洗えば消える）、(ii) 鋭いゲートの fc が 1 層も残らず入力層 c1 の α が上限から外れると尺度の錨を失うこと（M2）、の 2 つの設計の帰結である。c1 を固定 α=3 にし fc の平らな点を少し持ち上げるだけで、固定 α=3 を上回る。
