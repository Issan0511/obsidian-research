## 0. 一行

**崩壊した ELU の層を止めたのは、optimizer に渡った微分が厳密に 0 になったこと（float32 の expm1 の床）で、Adam の ε ではない。** 0914 §5 の「止めたのは Adam の ε」は撤回する。ただしこれは autograd の expm1 で微分を作る実装（L1・L3）の話で、手書きの exp で微分を作る実装（L2、L3 の SMINH）には 50 タスクで届く床が無く、ε が効く範囲に入っても凍結しない。

## 1. 設計案の前提を直した — 「この箱の ELU」は 3 系統ある

設計案は、過去の走がすべて autograd の expm1 で微分を作ると仮定していた。コードを読むと系統が 3 つあり、**GPU で回した走（layer_chimera・l2_wall など）は逆伝播を手書きしていて、ELU の微分に $e^{z}$ をそのまま使っている**。

| 系統 | 走 | 計算機 | 訓練の微分 | 厳密に 0 |
|---|---|---|---|---|
| **L1** | mucap_el_0916・mucap_ee_0917・resp_ee_0917・l2cap_ee_0917 | white-san CPU | autograd: $\mathrm{expm1}(z)+1$ | $z\le-16.635534$ |
| **L2** | elu_environment_0913・layer_chimera_rl_0914・relu_gelu_silu_rl_0914（ext150 含む）・l2_wall_0916 | white-san GPU | 手書き: $e^{z}$ | $z<-103.97$ |
| **L3** | act_chimera_0913 の RL 400 epoch 箱（**0914 §5 の凍結の表の出所**） | GCP の AMD CPU（削除済み） | ELU1: autograd $\mathrm{expm1}(z)+1$／SMINH: $e^{z}$ | ELU1: $-17.33$ 以上（カーネルは測れない）／SMINH: $-103.97$ |

- 0914 §5 は、L2 の「80 epoch 箱は t50 でもまだ走る」と L3 の「400 epoch 箱は t24 で凍る・6.09e−34」をつないだ読みだった。
- 設計案の「L2 の `tinygate` は厳密 0 の下界」「l2_wall の `MIXED` は ZERO と整合」は、L2 に −16.64 の床が無いので成り立たない。取り下げた。
- 境界の実測（white-san）: CPU の autograd の係数は −16.635534 以下で 0、その次の float32 で $2^{-24}$。**CUDA の autograd は −16.982107**（CPU と別の丸め）。float32 の exp は −103.97 未満で 0（CPU で flush ありなら −87.34 未満）。
- **Adam の moment の丸め残り**（float32・勾配 0）: flush なしでは $m$ は 834 更新で $4\cdot2^{-149}$ に止まって 0 にならず、$v$ は $500\cdot2^{-149}$ に止まる。flush ありなら $m$ は 698 更新、$v$ は 59,677 更新（約 10 タスク）で厳密に 0。
- L3 は白さんでは bit 再現しない（task 1 の online が 0.9550625 対 0.9543625）。VM が残した readout だけで読んだ。

## 2. L3 — 0914 §5 の出所（VM の readout）

| 腕 | seed | 凍結の開始 | 第2層の全 (ユニット, 画像) が床の下に入った終端 | 分類 | 凍結中の第2層の m |
|---|---|---|---|---|---|
| ELU1 | 0 | t24 | t23（どの丸めでも） | `ZERO_R` | $4\cdot2^{-149}$ |
| ELU1 | 1 | t18 | t17（どの丸めでも） | `ZERO_R` | $4\cdot2^{-149}$ |
| ELU1 | 2 | t30 | t29（white-san と同じ切り捨てなら） | `ZERO_T` | $4\cdot2^{-149}$ |
| SMINH | 0–2 | **なし**（t50 でも動く） | — | **`TRAVEL`** 3/3 | — |

「床の下に入った」は、ユニットごとの解析的な平均ゲート $\bar g$ から作った上界 $\ln(1200\,\bar g)\ge\max_x z$ で判定した（L1 の 30 万件で上界と下界がともに成り立つことを確かめた）。**ELU1 の行は登録前に見ていた記述で、予測ではない。**

1. **凍結は、第2層の最後の (ユニット, 画像) が float32 の床の下に入った次のタスクに始まる**（3/3 seed）。その後の訓練の微分は厳密に 0 で、第1層にも勾配が来ない。
2. 凍結時の「ゲート 6.09e−34」は、**解析的な $e^{z}$ のユニット中央値で、訓練では使われていない**。「float32 の最小値より 11 桁上だから ε」という推論は、比べる床を取り違えていた（効くのは exp の下溢れ 1.4e−45 ではなく、expm1 の −1 付近の刻み $2^{-24}$ ≈ 6e−8）。
3. 凍結中の Adam の $m$ は、勾配ではなく float32 の丸め残り $4\cdot2^{-149}$ そのもの（`adam_ratio`×ε で 3 seed とも 4.0 量子）。一歩は約 5.6e−40 で、ε を外しても $v$ の残りがあるので 1e−25 以下（算術）。**ε は凍結を作っていないし、外しても解けない。**
4. **同じ VM・同じ Adam・同じ ε で、深部の微分を $e^{z}$ で作る SMINH は 50 タスク凍結しない。** 第2層のゲートの中央値は t12–18 から ε を下回り、第2層の行ごとの $\sqrt{\hat v}<10\varepsilon$ の割合も中央値 1.0 になるのに、隠れ層は動き続ける。t50 に $\ln\bar g>-70$ のユニット（exp で微分を作れば 0 にならない画像を持つ）は SMINH で 25–28 個、凍結した ELU1 でも 28–56 個ある。違うのは、その画像での訓練の微分が厳密に 0 かどうかだけ（ほかに 0 付近の傾きも 0.1 と 1 で違う）。
5. **P4 は外れ**: 私は SMINH が「ε と重みの分解能で止まる」（`EPS_REAL`・45%）に張った。ε だけで止まる例は、この箱の 50 タスクには無かった。

## 3. L1 — mucap_ee / resp_ee の箱（white-san CPU・flush あり）

### 3.1 凍結の時刻（mucap_ee の 4 腕 × 10 seed × 100 タスク）

| 腕 | 判定 | 内訳 | 第1層の $\sqrt{\hat v}<\varepsilon$ |
|---|---|---|---|
| ref | **`ZERO_NOT_EPS`** | 10/10 seed で、第2層が全滅したタスク（t31–62）の 1 タスク後（1 seed は 2 タスク後）に凍結 | **`HISTORY_DECAY`**（10/10） |
| cap_perp | `ZERO_NOT_EPS` | 9/10（s6 は t100 でも 1 ユニット生存） | `PARTIAL`（9/10） |
| cap_par | `ZERO_NOT_EPS` | 8/10（2 seed は全滅せず） | `PARTIAL`（8/10） |
| cap_both | `ZERO_NOT_EPS` | 8/10（2 seed は全滅せず） | `PARTIAL`（8/10） |

- 「生きた画像があるのに凍った」は 40 run で 0 回、「全滅したのに動いた」も 0 回。
- **旅は各ユニットの最上位の画像が床を越えたところで止まる。** ref の凍結時の第2層の最大前活性は −16.64〜−18.63（8/10 seed で −16.64〜−16.78）で、そのときユニット平均 $\bar z_2$ は −127〜−175。深さの到達点を決めているのは平均ではなく上端。
- mucap_ee の「t100 の第1層で $\sqrt{\hat v}<\varepsilon$ がほぼ全座標」は、第2層が全滅した 2 タスク後から第1層の $m$ が全ユニット厳密に 0 になった結果（第2層が全滅すると第1層への勾配は厳密に 0、flush ありなので $m$ も $v$ も 0 に落ちる）。**ε のブレーキではなく履歴の減衰。**

### 3.2 分岐点から 1 エポック（resp_ee の t2〜t20 × 10 seed・ε=1e−8 と 1e−30 を並べた）

各状態から次のタスクを自然に走らせ（60/60 状態で終端のハッシュが resp_ee の記録と一致）、座標を「動いた（M）」「勾配も m も厳密に 0 で止まった（Z）」「ε を外すと動く（E）」「ε に依らず止まった（Q）」に分けた。

| t | 層 | 動いた | 止まった | 止まった中の Z | Q | **E** | 判定 |
|---|---|---|---|---|---|---|---|
| 10 | 第2層 | 0.886 | 0.114 | 0.367 | 0.574 | **0.059** | `ZERO_NOT_EPS` |
| **15** | **第2層** | 0.464 | 0.536 | 0.862 | 0.128 | **0.011** | **`ZERO_NOT_EPS`** |
| **20** | **第2層** | 0.222 | 0.778 | 0.931 | 0.060 | **0.009** | **`ZERO_NOT_EPS`** |
| 15 | 第1層 | 0.681 | 0.319 | 0.821 | 0.141 | 0.037 | `ZERO_NOT_EPS` |
| 20 | 第1層 | 0.562 | 0.438 | 0.803 | 0.171 | 0.026 | `ZERO_NOT_EPS` |

- **止まった第2層の座標のうち、ε が止めていたのは t15・t20 で 1% 前後。** 残りは勾配が厳密に 0（Z）か、勾配が止まった後に m が 0 へ落ちきる途中（Q の大半）。
- 逆に、分岐点で $\sqrt{\hat v}<\varepsilon$ だったのに 1 エポックで動いた第2層の座標が t20 で 2432 個ある。**ε 域に入っていることは止まることを意味しない**（resp_ee の Δ=20 と同じ）。
- 第2層の微分だけを解析的な $e^{z}$ に替えると（検査 S2b）、Z は 4800→0・7100→0 になる。Z は expm1 の床から来ている。

## 4. L2 — l2_wall の ε 腕

- **`L2_NO_FLOOR`**: t50 に全画像で exp ゲートが 0 になったユニットは、18 モデル中 15 モデルで 0 個、ε=1e−30 の ELU→ELU 3 モデルで各 1 個。**L2 の ε 介入は 0 でない勾配に働いていた。** −16.64 の床の話は L2 には当てはまらず、l2_wall Part B の読み（「釘付けの位置は壁定数、ε が変えるのは到達後の動き方」）は L2 の実装の中でそのまま残る。
- 事後: L2 の ε=1e−30 腕の記録には $\sqrt{\hat v}=0$ の座標は無く、一歩の大きさも Adam の範囲だった（下の L1 の暴発は L2 には出ていない）。

## 5. 報告のみ

- **t50 までの平均の深さは両系統でほぼ同じで、違うのは止まるかどうか**（両系統は微分の実装のほかに装置と乱数の流れも違う。seed 数も 10 と 3）。ユニット平均 $\bar z_2$ は L1 ref が t10/20/30/40/50 で −50.9/−107.9/−134.0/−146.1/−151.7（t100 −152.9）、L2 の EE が −43.3/−103.4/−126.4/−145.9/−154.1。L1 は t32–63 に凍り、L2 は t50 でも −0.83/タスクで動く。
- **ε=1e−30 で 1 タスク通すと（L1）、崩壊は救えない**（online の差 −0.004〜+0.009）。30 状態のうち 12 状態で Adam では出ない大きさ（>1e−2）の一歩が出た。flush ありの float32 では $v$ が 0 に落ちて $m$ が残る座標ができ、そこに $m/10^{-30}$ の一歩が出る。死んだユニットが大きく戻った 8 状態はすべてこの 12 状態の中にあった。**人工物として読み、「ε を外すと戻る」とは書かない。** ε を小さくする介入を float32 で行うときは、$\sqrt{\hat v}=0$ の座標を数えること。

## 7. 対象ノートの書き換え

- **0914 §5 の 2**「止めたのは活性化でも float32 でもなく Adam の ε」→ **「止めたのは float32 の expm1 の床（訓練の微分が厳密に 0）。凍結は第2層の最後の画像が床を越えた次のタスクに始まり、6.09e−34 は訓練では使われていない解析値。凍結中の m は丸め残りで、ε を外しても解けない」**。同じ §5 の「80 epoch 箱は t50 でも走る」は L2（手書きの exp）の性質。**含意の「到達深さは optimizer の定数で決まる」は、「凍結（旅の終わり）は微分の実装の床で決まる。t50 までの平均の深さは両系統でほぼ同じ（報告のみ）」に直す。**
- **l2_wall Part B**: L2 は手書きの exp ゲートで −16.64 の床は無く、ε 介入は 0 でない勾配に働いていた。読みはそのまま。設計案の「`MIXED` は ZERO と整合」は取り下げ。
- **mucap_ee の範囲**: t100 の第1層の $\sqrt{\hat v}<\varepsilon$ は第2層全滅後の履歴の減衰（ref 10/10、上限腕は全滅した seed で同じ）。
- **V10 作業リスト H4 の ε の段落・仮説 §3.4**: 「このプロジェクトの ELU は −16.64 で微分 0」は **autograd の系統（L1・L3）**の話。GPU の手書き系統（L2）は $e^{z}$ で、この床は無い。ε を停止機構として本文に入れる必要は無くなった。

## 8. 範囲

- L3 の ELU1 の境界は VM が消えていて測れない。s2 は「白さんと同じ切り捨てなら」の条件付き（上界 −16.65 は最近接丸めの境界 −17.33 より上）。
- L3・L2 は保存された量（タスク終端）だけで読んだ。タスクの途中の動きは見ていない。
- SMINH と ELU1 は 0 付近の傾き（0.1 と 1）も違う。SMINH の `TRAVEL` を「微分の床だけの効果」とは書かない。
- 「ε が止めたか」は ELU の微分の実装（expm1 か exp か）と Adam の実装（flush の有無で moment の残りが違う）の両方に依る。Adam 一般の性質とは書かない。
- L1 の「全滅」は 1200 枚の行列積の $z$ で判定した。学習のミニバッチの $z$ と bit が違いうるユニット（境界の ±1e−4）は分岐点に 0 個だった。
