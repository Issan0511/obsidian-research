## 0. 一行

**Permuted MNIST で「WD が活性化の差を吸収する」（`SNA+l2` − `R+l2` = +0.0023）と出した同じ 7 腕を、WD が失敗すると報告されている箱（概念シフト）に置くと差は 10 倍に開き（+0.0233・10/10・p=0.002）、しかも既存最強の l2init を上回った（+0.0062・10/10）。活性化の吸収は箱固有だった。**

## 5. 未登録の観察

- **`LR` の ‖w‖ は 16.9 倍。** 正則化なしで記憶を続けると leaky はノルムが暴走する（`SNA` 5.3 倍・`R` 1.35 倍＝死んで止まった）
- **アンカーは Snake でも小さく効く**: `SNA+l2` − `SNA+l2init` = −0.0025・0/10。Permuted では無差だった
- **WD は `SNA` を下げる**: `SNA+l2` − `SNA` = −0.0217・0/10。素の `SNA`（0.986）が全腕最高で、正則化は記憶課題では**害**。`R` には +0.827 の救命
- `memo_acc` は正則化腕で 0.985–0.994 と 1.0 を割る（400 epoch でも完全記憶に届かない）

## 5b. 追加腕 `LR+l2` と 素の `SNA` の位置（2026-09-07・未登録 REPORT_ONLY・n=10・発散 0）

### 5b-1. Q1 は Snake 固有（穴を埋めた）

§引用制限で自ら挙げた穴（比較相手が ReLU だけ）を `LR+l2`（leaky に WD・λ=1e−3・同 seed/init/ラベル列）で埋めた。予測は `results/pmnist_rlmnist_0906/PREDICTION_lr_l2.md`（走らせる前）。

| 対応差 | 値 | |
|---|---|---|
| **`SNA+l2` − `LR+l2`** | **+0.0149 ± 0.0002・10/10・p=0.002** | **Q1 は Snake 固有** |
| `LR+l2` − `R+l2` | +0.0084・10/10 | WD の下でも床は効く（が足りない） |
| `LR+l2` − `LR` | +0.1429・10/10 | WD は leaky も救う（0.808 → 0.950・‖w‖ 16.9 → 0.99 倍） |

**mobility と精度が単調に並ぶ**: `R+l2` 0.233 → 0.9412、`LR+l2` 0.393 → 0.9497、`SNA+l2` 0.824 → 0.9644。**記憶課題では「非ゼロ床があるか」ではなく「どれだけ開いているか」が効く。** 予測は 1 ○（0.9497 は 0.950–0.962 の下端）・2 ○（差 +0.0149 は +0.005〜+0.015 の上端・10/10）・3 ×（mob 0.393・素の `LR` の 0.114 の 3.4 倍に上がった。WD が z̄ を浅くするので床の外のユニットが増える）・4 ○（0.99 倍）。

### 5b-2. 素の `SNA` が全腕最高 — 正則化は記憶課題では容量税

素の `SNA`（0.9859）は**正則化腕を含む全腕に 10/10・p=0.002 で勝つ**: 対 `SNA+l2` +0.0217・対 `SNA+l2init` +0.0192・**対 `R+l2init` +0.0278**・対 `R+l2` +0.0450・対 `LR` +0.1795・対 `R` +0.8720。**階級 A が階級 C を上回る。**

機構は記憶完了率に出る: 素の `SNA` は memo_acc **1.0000**（1200 枚を完全記憶）、正則化腕は 0.985–0.994 で 1.0 を割る。**重みを縮める操作は容量の削減そのもの。** `R` は WD で +0.827 救われ（死んでいた）、`LR` は +0.143、**`SNA` は救助を必要としないので税だけ払う**。

**時限爆弾は 50 タスクでは爆発していない。** `SNA` の ‖w‖ は t10/30/50 で 3.0/4.5/5.4 倍と伸び続けるが、窓 31–50 の傾きは **+0.0009/50 タスク**（横ばい）。**ただし 50 タスクしか見ていない**（Permuted の 200 タスクでは同じ `SNA` が劣化した）。

### 5b-3. 正則化の符号が箱で反転する

| 箱 | `SNA+l2` − `SNA` | |
|---|---|---|
| Permuted MNIST（200 タスク・入力シフト） | **+0.0185・10/10・p=0.002** | WD は Snake を**助ける** |
| Random Label MNIST（50 タスク・概念シフト） | **−0.0217・0/10・p=0.002** | WD は Snake を**害する** |

同じ活性化・同じ λ・同じ最適化器で符号が逆。読みは「入力シフトでは損傷（ノルム成長）の抑制が効き、概念シフトでは容量の確保が優先される」だが、**Permuted 200 タスク 対 Random Label 50 タスクの時間スケール交絡が残る**（`SNA` を Random Label で 200 タスク回せば分離できる・未実施）。

### 5b-4. Snake だけ第 2 層の広がりが第 1 層を超える（Issa がアニメーションから指摘・seed 1 本）

`results/_diag_rlhist_0907/`（前活性分布のタスク別キャプチャ・7 腕 × 50 タスク・seed 0・本走とタスク 1 の `memo_acc` が 7 腕とも一致）。プール前活性の広がり sd の**層比 L2/L1**:

| 腕 | 比 t1 | 比 t50 | L1 sd t50 | L2 sd t50 | L2 のユニット平均 min/max t50 |
|---|---|---|---|---|---|
| `R` | 0.89 | **0.15** | 4.86 | 0.75 | −2.5 / −0.0 |
| `LR` | 0.89 | 1.00 | 4.39 | 4.39 | −22.0 / −3.3 |
| **`SNA`** | **1.49** | **1.33** | 4.95 | **6.59** | **−33.8 / +2.4** |
| `R+l2` | 0.62 | 0.45 | 0.97 | 0.44 | −0.1 / +1.0 |
| `LR+l2` | 0.48 | 0.48 | 0.72 | 0.34 | −0.0 / +0.5 |
| **`SNA+l2`** | 0.58 | **1.29** | 1.76 | **2.26** | **−5.9 / +1.9** |
| `R+l2init` | 0.55 | 0.54 | 0.91 | 0.49 | −0.6 / +1.4 |

**Snake 2 腕だけが L2/L1 > 1。** 他 5 腕は 0.15–1.00 で第 2 層のほうが狭い。**`SNA+l2` では WD が第 1 層を 1.76 に抑えているのに第 2 層は 2.26 と第 1 層を超える（比 0.58 → 1.29）— 正則化は層間の膨張を止めない。**

機構候補: Snake は整流しないので 1 層あたりの出力/入力 rms 比が 1.0–1.16（[[前活性の力学_事後_0904]] §8.2・ReLU 族は 0.65–0.82）。**ReLU 族は層を通るたびに信号を縮め、Snake は縮めない**ので深さとともに広がりが積み上がる。`R` の 0.15 は逆で、第 1 層の死んだユニットが多く第 2 層へ届く信号が痩せている。

**含意（未検証）**: W が層で 1.3 倍違うなら最適 α も層で違う。実測の α_med は L1 0.30 / L2 0.19（[[PermutedMNIST_適応α結果_0905]] 箱 A）で、適応 α は層ごとに正しく調整していた。**適応 α が固定 α に勝った理由の一部は、この層間の膨張を吸収したことかもしれない**（固定 α では L1 か L2 のどちらかが必ず外れる）。深さ 3–4 で膨張が累積すれば適応 α の優位は広がるはずだが、**深さを変えた走は無い**。

**限定**: seed 1 本・層 2 つ・1 箱。sd はプール分布のもの（ユニット内 W とユニット間の散らばりの和）で、ゲートの平均化に効くユニット内 W とは別量。

## 引用制限

- **§5b-4 の層比を「深さで悪化する」と書かない。** 層 2 つ・seed 1 本の観察で、深さ 3 以上は未測定。プール sd はユニット内 W とは別量
- **素の `SNA` の全腕最高（0.9859）を「Snake は正則化不要」と一般化しない。** 記憶課題で WD が容量税になるのが理由で、Permuted では逆に WD が Snake を +0.0185 助ける（§5b-3）。50 タスクしか見ていない（‖w‖ は 5.4 倍まで伸び続けている）
- **「Snake が既存手法に勝った」を無条件に書かない。** Random Label MNIST・λ=1e−3・階級 B+C 対 C の 1 点。**Permuted MNIST では同じ比較で負けている**（−0.0198）。両方書く
- **素の `SNA` が全腕最高（0.986）を「Snake は正則化不要」と読まない。** 記憶課題で WD が害になるのは `R` 以外の全腕に共通の可能性（`LR+l2` 未測定）
- **`R` のタスク 3 崩落を Lillo & Cheney の 20.03% の再現と書かない**（彼らは 5 ベンチの平均的設定・当方は 1 箱・λ も最適化器も別）
- **online と `memo_acc` を混ぜない**（Kumar と比べるのは online）
- 効果量は **+2.3 pt**。「桁で開いた」は Permuted 比の話であって絶対量ではない
