# 前活性分散の厳密分解（事後・0910）

[[W増大メカニズム_0909]] §D-0b（並走セッション・同日朝）が「パターン側は普遍定数 0.065、腕差は明度チャネル」で穴 5 を閉じた。本ノートは同じ分解を **恒等式として導出し、5 腕（LIN を含む）・変異対照つきで再検証した**もの。結論は §D-0b と一致し、定数と読みを 2 点訂正する。

## 1. 恒等式（置換の期待値で厳密）
$z_i = W_i\cdot Px + b_i$、$W_i = m_i\mathbf 1 + \widetilde W_i$（$\Sigma_j \widetilde W_{ij}=0$）。置換 $P$ の期待値で
$$\sigma_i^2 = \kappa\,\lVert\widetilde W_i\rVert^2 + \mathrm{Var}(S)\,m_i^2,\qquad \kappa=\bar v-\bar c,\quad S(x)=\textstyle\sum_j x_j$$
$\bar v$ = 画素分散の平均、$\bar c$ = 画素間共分散の平均、$S$ = 総インク。cross 項 $2m_i\,\mathrm{Cov}(S,\widetilde W_i\cdot Px)$ は $\Sigma\widetilde W=0$ で消える。**自由パラメータなし。**
MNIST test: $\bar v$ 0.06741、$\bar c$ 0.00183、**$\kappa$ = 0.0656**、E[S] 103.9、sd(S) 34.3、Var(S)/E[S]² = 0.109。

## 2. 検証
- **checkpoint（LR/SNA t100 × 3 seed・8 参照置換・test 1 万）**: 幅/‖W̃‖² = 0.0657–0.0667（単位別 sd 0.005）、オフセット/(m²E[S]²) = 0.109 厳密、cross ±1%。変異対照（参照置換を恒等 1 本）: 単位別 sd が 3 倍（0.016–0.019）、cross 最大 +4%。
- **記録済み単位別データ（LIN/LR/ELU03/ELU1/SNA・t≥20・sd_i² ~ a‖W̃_i‖² + g z̄_i²）**: a = 0.065/0.066/0.069/0.069/0.066、g = 0.09–0.10（z̄_i に bias 5% 混入で理論 0.109 より小さめ）。R² 当てはめ 0.97–0.999、**0 パラメータ理論で 0.91–0.97**。変異対照（z̄_i を単位間で入替）: R² 0.48/0.59/−0.07/−0.11/0.02。

## 4. §D-0b への訂正・補足
1. **定数は tr(Σ)/784 = $\bar v$ = 0.0666 ではなく $\bar v-\bar c$ = 0.0656**。$\Sigma\widetilde W=0$ が共分散平均を差し引く。差は 1.5% で実測（0.0657–0.0664）は後者に乗る。
2. **置換平均の σ_inv では κ の普遍性は恒等式であって証拠ではない**。任意の中心化ベクトルで成り立つ。「$\widetilde W$ が Σ の主軸に乗らない」という幾何の主張は、単一置換での係数（変異対照: 平均 0.063–0.071、sd 0.017）からしか言えない。その範囲では確かに乗っていない。
3. 「z̄ = −1.7σ の直線」の σ にはオフセット項が混入していた。z̄ = m·E[S]、σ_off = |m|·sd(S) なので z̄/σ_off = −3.03 は機械的。深さは σ_w で言い直すべきで、その値は LR −2.0、ELU1 −3.2、SNA −0.9、LIN 0。[[幅と沈下の介入_結果_0909]] は $\widetilde W$ だけを掛けたので結論は影響を受けない。

## 5. 一文
**W → σ の写像は活性化に依らない（κ はデータ定数）。活性化が変えるのは W の成分（‖W̃‖ と m）で、σ の腕差は沈下 m の副産物である。**
