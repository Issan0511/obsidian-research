## 4. 読み

1. **罠の機構は Issa の言うとおり「最初の曲率反転」**。1 葉だけの `snake1` で幅 100 の力学（固定点・占有・符号反転）が Snake と一致し、零点のない `snake_amp` でも符号反転がある。周期の 2 本目以降は罠に関与しない。
2. **ただし罠は変曲点には固定されない**。固定点は **z\* ≈ −0.6·A**（4 腕で z\*/A = −0.57〜−0.66）。A → 0 で 0 に向かう＝線形網の「0 への釘付け」に連続的につながる。読みとしては、反転が作る「変曲点へ引く力」（∝ A）と、線形ユニットが持つ「平均を 0 に消す力」（A に依らない・[[命題1-5_上端則結果_0905]] §4 命題 1）の釣り合い。A=1 でも −0.59 で止まり −0.785 に届かないのは後者のため。
3. **反転が浅いと線形化する**。死亡率 0.18 → 0.32 → 0.57 で、死んだユニットは ‖w‖・\|v\| が線形網の極限に落ちる。ゲートは開いたまま（mob 0.94〜0.99）なので ReLU 族の「沈んで閉じる」とは別の失敗 — **読み出しが消える**。
4. **周期は適合の担い手**。幅 5 では支持幅 W ≈ 12 が 3.8 周期を覆い、その波が LTU 教師を当てる。1 葉しか無い `snake1` は葉の外（W の大半）で線形なので 3 倍悪い（lr を揃えても 2.4 倍）。ゲート／沈下と適合は**別の問題**で、前者は最初の反転が、後者は周期の波が担う。
5. **Snake の α の下限（[[前活性の力学_事後_0904]] §8 と本走の対応）**: 「変曲点が初期支持（\|z\| ≲ 1.7）の中にある」= α ≳ 0.5。上限は非線形振幅 1/α の消失。本走はここに「A（反転の深さ）が浅いと線形化する」を足す — 零点まで落ちる A=1 が、線形化と沈下の間で一番深く罠を掘る。

## 7. 次

- **A の連続掃引**（A ∈ {0.75, 1, 1.25}・A>1 は φ′<0 の谷が出る）で z\*(A) の線形性と、線形化率が A のどこで立ち上がるかを取る。
- **線形化 = 読み出しの消失**を LoP の第 3 の型として [[論点マップ]] に置くか（ReLU 族「沈んで閉じる」／SiLU・GELU「逃走」／弱い非線形「線形化」）。
