# ε を上げると実効変位と幅の水準が落ちるか — Issa の「微量な成分を Adam が拡張する」の検定（eps_width_cifar_0923・結果）

Claude (Fable 5.1), 2026-09-23 夜。依頼: Issa「今すぐ検証して。一旦 c は定数ということにしましょう」「なぜ Adam の実効変位が SGD の 7 倍かは、しょうもない微量な成分を Adam が拡張するからでは」「Codex Astra とか使っていいよ」。
予測: Claude と Codex gpt-6-astra が走る前（Codex は課題 1 の結果が出る前）に固定（lop_analysis `results/eps_width_cifar_0923/PREDICTIONS_*`、sha256）。前段: [[W増大の接続面_0923夜の棚卸し_どこまで言えたか]] §8–9（幅の水準 = 実効変位 ÷ 2|c_S|、5 腕で 96〜97%）。

## 0. 結論

1. **向きは成立。** Adam の ε を 1e−8 → 1e−6 → 1e−4 → 1e−3 と上げると、1 課題の実効変位 ‖D‖_S（入力分散で重み付けした W1 の変位）は 343 → 254 → 250 → 192 と単調に減り、幅 σ の水準は釣り合いの式 ‖D‖_S ÷ 2|c_S| に従って 56 → 34 → 35 → 26 と落ちる（実測 ÷ 式 0.94〜0.95）。
2. **量は半分。** ε = 1e−3 で消えるのは Adam の実効変位の 44%。全部 SGD（50）との差の 52% は残る。残りは勾配が 1e−3 より大きい当てはめの区間の変位で、ε では止まらない。
3. **段差の形。** e6 と e4 が同じで、e3 で一段落ちる。収束後の押し（√v̂ ≪ 1e−6 の域）は e6 で消え、当てはめ中の小さい成分は e3 でようやく削られる。
4. **c は ε をまたぐと動く。** −0.25（e8）→ −0.35（e6 以上）。ε が大きいと次の当てはめの削りが深い（S_hi の −0.35 と同じ）。幅の比 0.46 が実効変位の比 0.56 より小さいのはこのため。「c は定数」は同じ ε の中では成り立つ。
5. 当てはめは損なわれない。課題中の online_acc は e8 0.974 → e3 0.983 で、ε を上げるほど高い。
6. 検査: LL_e8（chimera エンジン）の snapshot は sgd_postfit の A（battle エンジン、LR_iid）と byte 単位で一致（同じ箱・同じ乱数列）。LL_e6 の seed 0 課題 3 は課題末に暴発（memo 0.45）、判定窓 t11–20 には無し。

## 4. 読み

- Issa の仮説は「Adam の実効変位のうち、ε で止まる微量な成分の分」について正しい。ただしそれは差の半分で、残り半分は当てはめ中の勾配 1e−3 以上の成分が Adam の正規化で等身大に動く分。これは ε では止まらず、SGD にしないと止まらない（S_hi の 155、全部 SGD の 56）。
- 幅の水準が釣り合いの式に従うことは ε をまたいでも成り立つ（0.94〜0.95）。c は ε で 4 割動くので、幅の水準を「実効変位だけ」で書くと 2 割ずれる。
- 次の候補: ε = 1e−2 と、当てはめ中だけ SGD にする腕（収束後だけ SGD の逆）で、残り半分がどちらで消えるかを分ける。
