## 5. §8-6 の順に潰す

**(i) `W*` の較正失敗 — 完全には潰せていない。**

- `W* = 600` は `abs_log10_difference = 1.98083` で、許容 2 の**ぎりぎり内側**
- しかも **600 はグリッドの上端**（`fallback_width` と同値）。より広い幅が必要だったかは分からない
- 較正の探索は **3 seed で非単調**（150 → 2.74e-07、200 → 1.58e-06、300 → 5.89e-10、450 → 2.39e-09、600 → 2.87e-11）。ノイズが大きい

**(ii) 幅の変更が死の速度を変えた交絡 — 起きている。** L1w100 の strict_dead 0.990 に対し L1wide は 0.995。幅を 6 倍にして死亡率は**下がっていない**。1 ユニットあたりの勾配が薄まる効果は、少なくとも終端では見えない。

**(iii) 深さ自体が効いている。** (i) が未解像なので断定はできないが、腕効果の符号がそれを示唆する（§6-3）。

## 6. 読み

### 6-1【設計の教訓】二値化した endpoint が飽和した

`n_onset` は 3 腕とも 9–10 で飽和し、**判別情報を持たなかった**。判別している量は水準側（未フィット率 0.856 / 0.269 / 0.069）と生存者数（1 / 3 / 14.5）にあった。「発症したか」を数える設計は Phase 0 の失敗（seed 平均が 1 本に支配される）を直したが、今度は天井に張り付いた。

### 6-2【設計の教訓】regime ラベルの閾値が判別しなかった

G-pre は 3 腕すべてを `INTERPOLATING` にした。**canonical な v4 の腕（L1w100）まで「v4 の適用外」と分類される**のは明らかに誤り。原因は、v4 の「本系は補間点に達していない（unfit ≈ 0.14）」が**定常状態**の値なのに、G-pre を**初期窓**（タスク 2–11）で測ったこと。初期窓では LoP がまだ進んでおらず、どの腕も小さい。**閾値は「比較したい両側が別ラベルになる」ことを確認してから凍結すべきだった。**

→ `INTERPOLATING` ラベルを根拠に「v4 の反証として引かない」という §9 の規則は、**本走については発動させない**（発動させると L1w100 の結果まで引けなくなる）。

### 6-3【本走の実質的な結果】深さには残差効果がある。幅の符号は検閲の産物の疑いが濃い

**8/29 追記・訂正**: 初稿は「深さと幅が逆符号」と書いたが、committed の `layer_stats.csv` を eff_rank でビン分けして直接見ると**幅の符号は再現しない**。訂正する。

`log10(eff_rank)` で条件付けたときの回帰係数は

- **L2 − L1w100 = −0.654**（深さ2 の方が未フィット率が低い）
- **L1wide − L1w100 = +0.641**（幅600 の方が高い）

だが、同じデータを eff_rank ビンごとの未フィット率中央値（読み出し直前の層）で並べると:

| eff_rank | L1w100 | L1wide | L2 |
|---|---:|---:|---:|
| [3,5) | 0.2467 | 0.2060 | **0.1450** |
| [5,8) | 0.09778 | 0.07429 | **0.04609** |
| [8,12) | 0.01289 | 0.01210 | **4.923e-05** |
| [12,18) | 2.202e-05 | 2.455e-05 | **1e-12（床）** |
| [18,30) | 8.494e-08 | 8.152e-12 | **1e-12（床）** |

- **L2 は全ビンで最良**。回帰係数 −0.654 と整合し、**深さの効果は頑健**
- **L1wide は L1w100 と同等かむしろ良い。** 回帰係数 +0.641 とは**逆**

原因は**床による左検閲**。`unfit_floor = 1e-12` にかかった点の割合は **L1w100 0.3% / L1wide 10.4% / L2 22.5%** と腕でまったく違う。検閲は真値を持ち上げるので、検閲率の高い腕ほど係数が**悪い側へ偏る**。

- L1wide（10.4%）は L1w100（0.3%）より検閲が強い → **+0.641 は検閲だけで作れる**
- L2（22.5%）は最も検閲が強いのに **−0.654**（良い側）→ **深さの効果は検閲バイアスに逆らって残っている**

加えて、真の関係は log-log で線形ではない（eff_rank 1→20 で未フィット率が 12 桁落ちて床に張り付く急峻な形）。腕ごとに x 軸上の分布も大きく違う（eff_rank 中央値 1.91 / 8.56 / 9.35）ので、線形当てはめは腕ごとに別の部分を見ている。

**したがって読める形はこうなる**:

- **幅（容量）は eff_rank を通してのみ効いている**（残差効果は確認できない）。ここは「原因は容量」という立場と整合
- **深さは eff_rank で条件付けてもなお有利**。ここが立場と食い違う

**未解像**: (i) 較正がぎりぎりなので `L1wide` が `L2` と同じ表現力水準にあったかが確定していない。(ii) 検閲と非線形性を扱った推定（Tobit 型、または床を上げる／床にかからない窓に限定する）をやり直すまで、係数の絶対値を機構の主張に使わない。

### 6-4 v4 への跳ね返り

- **µ 考察 §3 の書き直しは確定的に必要**。自己生成 µ は前層の LoP に食われて減衰し、late で dose 8.16（第1層 12.81 の 6 割）。ただし µ 優勢の目安（‖µ‖/σ ≳ 2.33）の約 3.5 倍で、**床は regime の中にある**
- **第2層の壁トレンドだけが符号検定を通らない**（p = 0.754）。第2層では壁が深まっていない。第2層の死（0.900）は自層の壁ではなく**前層の崩壊による入力の劣化**で説明される可能性がある。**未検証**
- 「補間点に達していない」というスコープ条件は、**主張の適用範囲を切る線ではなく発症までの時間を延ばす要因**だった、という Phase 0b §8-2 の含意は支持された

## 7. 引用上の注意

- **§1・§2 以外は事後計算**
- **腕間はペアではない**。同一個体の主張として読まない
- **`n_onset` は飽和した endpoint**。3 腕の差の根拠に使わない（§6-1）
- **`INTERPOLATING` ラベルは本走では判別していない**（§6-2）。このラベルを理由に結果を割り引かない
- **L2 の `n_onset = 10` は閾値 0.05 依存**（§3.3）
- **腕効果の符号を機構の主張に使う前に、較正のやり直しと検閲の処理が要る**（§6-3 の未解像）。**とくに幅の係数 +0.641 は床検閲の産物の疑いが濃く、ビン別中央値では再現しない。単独で引かない**
- 壁トレンドの `increase = 0` は CI 退化による。**トレンドの向きについて本走は判定していない**（点推定は 4 つとも正、符号検定は L2 第2層のみ非有意）
- スコープは condA・T=10⁴・batch=1・std
