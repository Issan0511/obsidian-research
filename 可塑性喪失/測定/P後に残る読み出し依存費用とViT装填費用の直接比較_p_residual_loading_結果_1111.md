# P後に残る読み出し依存費用とViT装填費用の直接比較

2026-11-11 / p_residual_loading_1111 / Codex

**後期ELUでは、P後にも読み出しをゼロにすると軽くなる適応費用が残った。一方ViTではP後の効果が弱まり、Adamの扱い・介入時点に依存した。P後の残り方まで同種だと確認するには至らなかった。**

事前登録に基づく判定は **unresolved（未確定）**。同じ微視的機構を証明した研究ではない。

## 問いと比較方法

Issaの問いは「P後に残った遅れのうち、読み出しを外すと消える部分は、ViTの装填費用と同種なのか」。

Pは読み出し行列の各列でクラス方向の要素を独立に並べ替え、平均logitを保つようbiasを補償する。特定の整列を壊す操作であり、古い情報をすべて消す操作ではない。

同じbody parametersとbody Adamから分岐して、読み出しのweight/biasとhead Adamをそれぞれ保持・消去する4条件を比較した。bodyは分岐後も学習する。

| 条件  | 読み出しweight/bias | head Adam |
| --- | --------------- | --------- |
| KK  | 保持              | 保持        |
| KC  | 保持              | 消去        |
| ZK  | ゼロ              | 保持        |
| ZC  | ゼロ              | 消去        |

主比較は **KC−ZC**。両群でhead Adamを空にそろえることで、読み出しパラメータを消す効果を比較した。head Adamの消去には一次・二次momentとstep counterを含む。weightとbiasそれぞれの寄与は分離していない。

主指標Uは固定学習集合の精度不足（1−accuracy）を残り区間で台形積分し、期間で割った値。以下は `100 × [U(KC)−U(ZC)]`。正値は読み出しゼロ化による期間平均精度の改善、単位はpercentage points（pp）。更新数・効果量が異なるモデルで等価だとは検定していない。

![[補助データ/p_residual_loading_1111/contrast_pattern.png]]

後期ELUはP後にもSと近い大きさの除去効果が残った。P/S比は **1.036 [0.990, 1.086]**。ViTではSの除去効果は明瞭だが、P後は **0.200 [−0.156, 0.544]** に弱まり、主比較の区間は0をまたいだ。ViTのP直後KC−ZCが正だったのは5seed中2seed。

この比は読み出し除去という操作の効果比であり、全遅れの因果的残存率ではない。「Pで遅れの80%が取り除かれた」とは読めない。

## Adamと介入時点への依存

ViTでもhead Adamを保持した比較 **KK−ZKは +6.52 [+1.96, +11.07] pp** だった。したがって「ViTにはP後の読み出し依存成分がない」とは言えない。

ViTのP直後で、Adam保持の差はhead保持時KK−KCが +1.13 [−0.20, +2.46] pp、headゼロ時ZK−ZCが −3.10 [−3.98, −2.18] pp。後者ではAdamを残す方が有利であり、「古いAdamが遅れの主因」とも結論できない。

Pから25更新後の介入では、後期ELUの除去効果は正のままだったが、ViTは全5seedで負に反転した。τ25ではP-KKの最初の25更新から同じ状態で分岐し、同じbatch列の続きを同じ絶対終点まで学習した。ただしゼロ化はこの25更新で新しく学んだ読み出しも消す。符号反転は介入効果の変化であって、初期費用が完全に消えた証拠ではない。Sのτ25対照は実施していない。

## 「遅れが消える」の範囲

ELU通常履歴・課題10末・P直後では、終点精度はKC 69.99% → ZC 96.39%。4000更新内の90%到達はKC 0/10seed、ZC 10/10seed（平均3220更新）。

Pall履歴でも終点精度は34.93% → 70.91%へ改善したが、全4条件・全10seedが4000更新内に90%未到達だった。**読み出し依存の残差は軽くなるが、全残差は除かれていない。**

ViT P直後では両群とも全5seedが90%に到達。初回到達の平均はKC 705、ZC 675更新だが、差の区間は0をまたぐ。持続的な到達時点では方向も反転するため、「30更新の共通費用」とは扱わない。

![[補助データ/p_residual_loading_1111/focus_curves.png]]

一般化にも限界がある。初期MLP（R/ELU/SiLU、課題1末）は読み出しを残す方が有利。後期R/SiLUのτ0では小さい除去利益があるが全条件が90%未到達。後期SiLUのτ25は期間平均と終点で優劣が異なり、曲線が後半に交差した。

- **820論理曲線、690本の実行、130本の厳密な同一曲線共有**。共有は独立した反復として数えていない。
- 全41ジョブ正常終了。欠測・除外seedなし。全80入力archiveのSHA256を照合。
- 既存MLPの190固有曲線（250論理比較）を完全再現。通常履歴の300課題末weight/labelを完全照合。
- Pall再生290課題の既存測定9項目を完全照合。Pallには保存済み末端weightがないため、独立したweightのビット一致とは主張しない。
- 各factorialの分岐時body parameters/body Adamのhash一致を確認。
- CIは対応seed bootstrap10000回の百分位95%、多重比較未調整。MLP条件選択は先行データを参照しており、新規の独立検証だけで構成された研究ではない。
- 未到達T90は欠測として保持し、上限値を到達時刻に代入しなかった。

先行の[[ViTの装填費用とMLP段①の照合_loading_bridge_結果_1111]]では回復時に全Adamをリセットしていた。今回はbody Adamを保持しているため、結果を混ぜて推定していない。

## 結論

読み出し依存の適応費用という広い共通点はある。しかし、**Pで整列を壊した後に、その費用がどう残るかはELUとViTで異なった**。登録した主比較では、ELUに残る費用をViTの装填費用と同種と確認する条件を満たさず、判定は未確定。
