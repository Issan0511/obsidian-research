## 1. 道具

- 堆積 d_b(t) = ‖P_b ΔW_t‖²、侵食 e_b(t) = 2⟨P_b W_{t−1}, P_b ΔW_t⟩、恒等式 N_b(t) − N_b(t−1) = d_b + e_b（残差 max 5.5e−11・相対 2e−15。N と d, e は別々の射影から出るので実の検査）

## 4. 読み（二つの主張の判定）

1. **「毎回考え直している」は支持。** 上位 10 方向に積まれた堆積の 92〜99% が後の課題で消される（r_top 0.05〜0.11。時刻 t に書いた上位成分は t50 までに 7〜9 割消える）。登録した P5 の課題ごとの cos が −0.26〜−0.43 で閾値に届かないのは、増分に「前の解の除去」と「新しい解」が同居し、cos が薄まるからで、積分量（侵食率・累積比・q）が正しい道具だった。Codex の一次の定理（線形化 f = Jθ・独立ラベルで E⟨θ, δθ⟩ = −η‖Jθ‖² ≤ 0）は課題開始時の unlearning を与え、「毎課題が同じ解写像で置き換わる」極限では連続増分の相関 −1/2・累積比 1/T。実測は相関 −0.16〜−0.26・r_top 0.05〜0.11（1/T = 0.022）で、**部分的な置き換え**。
2. **「損失が二度と戻しに来ない成分」は支持。ただし 0/1 ではなく連続。** 侵食率は top −0.93 → mid1 −0.68 → mid2 −0.40 → low −0.19 → comp −0.05 と、その方向が出力に効く度合いの順に並ぶ。LR std の low は q −0.03 で「以後ほぼ触られない」。raw の low は −0.34 で触られ、SNA の low は逆に +0.14 で補強される。
3. **「Adam の正規化が、関係の薄さに見合わない η の歩幅を与える」は本走では識別できない。** Codex の線形代用モデル: 1 歩の SGD は帯の係数変化が ∝ λ_j、課題を完全に当てはめる増分は ∝ 1/λ_j（低分散方向を通して出力を動かすには大きな係数が要る）。つまり低帯にノルムが溜まるのは「当てはめ」自体からも出るので、スナップショットだけでは Adam の再重み付けと区別できない（画素座標の Adam は PCA 座標の Adam ではない）。同日の [[第1層の増幅器はAdamか_ε介入_0922]] も LE の伸びで「Adam は速さを決め、存在は決めない」。**Adam 固有と言えるのは補空間への堆積だけ**（§5）。
4. **「二乗が足し算になって √t」は帳簿としては成立、機構としての「定数堆積 × 直交」は不成立。** 堆積は t5–14 → t41–50 で ×1.56（‖W‖ ≈ 3 倍に対し D² ∝ N^0.4、PM の D ∝ N^0.2 と同じ）、侵食も同じ速さで増え、**差の正味がほぼ一定**（−17%）なので ‖W‖² が t に線形に見える。0910 の PM（「堆積も侵食も t100 で大きくなるが差は変わらない」）と同じ形。Codex の検算では、定数 D・c の現象論（dN²/dt = D² − 2cDN、局所指数 1/2 − x/6、x = N/N*）に PM の c = 0.05・N(120)/N* = 0.67・指数 0.46–0.48 を同時に入れると矛盾する（x = 0.67 なら局所指数 0.32）。**[[W増大メカニズム_0909]] §C の固定点 N* = D/2c は D 一定を仮定しており、書き直しが要る。**
5. **Snake の指数 0.35 は、堆積が増えないのに侵食が増えて正味が落ちる（691 → 380）から。** leaky が 0.5 を保つのは堆積が ×1.56 に増えて侵食の増加を埋めるから。「Snake は堆積が少ない」（PM の SNA 0.465 対 LR 1.005）と同じ向き。なぜ leaky の堆積が N とともに増えるかは未解明（候補: 課題を学ぶのに要る更新数が伸びる＝LoP の帰還。Codex も「学習曲線の長さ・活性座標数・時間的整合の増加」を挙げる）。

## 5. 予測を外した 2 点は機構の情報

- **P6: Adam は勾配の張る空間の外へ重みを出す。** 勾配 Σ_k e_k φ′ x_k は必ず画像の張る空間にあるが、Adam の m̂/(√v̂ + ε) は座標ごとの非線形なので更新はその外へ出る（Codex の反例: 張る空間 span(1,2)・勾配 (1,2) → Adam の 1 歩 ∝ (1,1)）。実測: comp のノルム 20 → 221（LR std）・343（raw）・769（ELU std）、堆積の 1e−3（等方の 250〜800 分の 1）だが float 丸め（1e−14）の 11 桁上。**comp は 1200 枚すべてで前活性に厳密に 0 しか足さない＝損失が厳密に見えない方向**で、侵食率 −0.05 の純粋なランダムウォーク（p 0.39）。主張の「戻しに来ない成分」の最も純粋な例で、かつ Adam 固有（SGD・momentum は張る空間を保つ）。ノルムの 0.3% なので成長則の担い手ではない。凍った ELU では後期堆積の 44% が comp（勾配が微小になると画素ごとの正規化の不均一が向きを支配する）。
- **μ⊥ 方向は弾道的。** μ⊥ は中心化データに直交するので w·μ⊥ は 1200 枚すべてに同じ定数を足す（bias と同じ働き）。この方向は r 7.9（std）〜18.6（SNA std）、指数 0.84〜0.94、後の課題が積み増す（q +1.3）。勾配のこの成分は bias 勾配 × ‖μ⊥‖² に等しいので、bias の沈みと同じ符号で毎課題積む。ノルム比は 2e−4 で成長則には効かないが、**輸送（Δz̄ = ΔW·μ）の第 1 層側の担い手の一部**として記録する。

## 6. 引用の訂正（0922 昼のチャットの発言を直す）

- 「WD なし Adam の √t は Kosson 2024 §5.1 にある」は誤り。Kosson et al. 2024（arXiv:2305.17212）§5.1・Fig. 14 は WD を切るとノルムが増える**観測**と「WD を切るのは η_r に指数減衰を掛けるのと同じ」の一文だけ。同論文の Eq. 15（Q_{t+1} = (1 − ηλ)² Q_t + η² C）は λ = 0 で線形成長を含意するが本文では述べない。
- **明記した先行は Kosson, Welborn, Liu, Jaggi & Chen 2025, "Weight Decay may matter more than µP for LR Transfer in Practice"（OPT 2025 workshop）付録 F.2 式 (37): ρ_t² = ρ_0² + t·η²**（定数 η・λ = 0・「simplified model」＝毎歩の更新ノルム bη で重みに直交、の仮定）。相対更新が t^−0.5 で減る、と書いている。原文 PDF で確認済み（`opt-ml.org/papers/2025/paper41.pdf` p.28）。
- Merrill et al. 2021 の √t（付録 E.2）は ‖δ_t‖ ∝ η_t‖θ_t‖ と T5 の 1/√t スケジュールから出るもので、定数 η では指数成長を与える別の機構。
- したがって V11 が「定数堆積 × 直交 → √t」を自分の導出として書く余地は無い。書けるのは、帯別の帳簿（どこが消され、どこが残るか）と、定数堆積の簡約モデルが実測（堆積が増え、侵食も増える）と合わないこと。

- **Q1 恒等式**: |e|/d ≈ N/N* は推定量の定義から従う近似恒等式（R = r[1 + (f/2)(1−r) + O(f²)]）。上の表の「到達度」列は侵食率の言い換えで独立の情報は無い（同一点で計算すると 0.963/0.795/0.487/0.222/0.067）。`budget.py` は窓平均の S, f から N* を作り窓末の N と比べているので単一課題の恒等式とは少しずれる（値は同じ結論）。モデルの検証可能な中身は「f と S が一定に留まるか」だけで、top は留まり mid2 は留まらない。
- **Q2 機構**: 線形代用（方向 j が率 a_j = 1 − e^{−kλ_j} で目標へ緩和・課題ごとに iid 目標）の定常値は **N*_j = (σ²/λ_j)·tanh(kλ_j/2)**。弱い裾では平坦 kσ²/2、強く当てはまる方向では σ²/λ_j へ落ちる → **top の PC あたりの水準が mid1 より低い（266 対 336、山が PC 20–30）ことは説明できる**。しかし mid2 → low → comp の減衰（N*/PC 394 → 189 → 45 → 1.5）は説明できない。溶接（共通の T_top）も堆積 ∝ λ^0.8 も、両方合わせても弱い裾は λ^0 〜 λ^{−0.2}。減衰を出すには **消す割合 f_j ∝ λ^x で x < 0.8（消す側の λ 選択性が堆積より弱い）** が要り、N* ∝ λ^{0.8−x}。梯子 1/(2f) = 3.6 → 141 を 5 桁の λ に当てると x ≈ 0.32（例示。帯は加重平均なので PC ごとの f_j と λ_j の対で測り直すのが筋。comp は λ = 0 なので梯子に入れてはいけない）。学習率だけを a_j ∝ λ^x にしても S ∝ λ^{2x−1} で堆積 0.8 には x = 0.9 が要り N* ∝ λ^{−0.1} でやはり違う。
- **Q3 逃げる定常値**: N* の 3.7 倍のうち、堆積の増加 ×1.41 より **f の低下 ×2.78 が主**。動径 drift γ = √(1+ΔN_drift/N) − 1 は課題 1 で 0.12、課題 50 で 0.019 と**減る**ので、共通の drift が侵食を隠す仮説（上の追記の候補）は向きが逆で不成立。当てはめが長くなること自体は f を上げる側。**消す力学そのものが弱まっている（未同定）**。S ∝ N^0.4 で f 一定でも f ∝ N^{−1/2} でも漸近は有限の定常（p → 0）で、t30–50 の局所指数 1.0〜1.1 は途中の傾き。「drift ∝ ‖W‖」は γ ∝ N^{−1/2} を意味するが f ∝ N^{−1/2} は別の仮説。
- 私の候補（未検査・Codex の外）: 消しているのが切替の一撃で歩幅が固定（全座標 3η）なら、侵食の絶対量は N に依らず f ∝ 1/‖W‖。早期→後期の N 比の平方根 top 1.4・mid1 1.7・mid2 1.95・low 2.05・comp 1.7 に対し f の低下 1.3・1.6・2.7・3.8・2.0（top・mid1・comp は合い、mid2 は粗く、low は合わない）。50 課題連結の再生で切替 200 更新の e を帯別に出せば決まる（漏れ検査 §9 の相殺検査と同じ走）。
- **指摘 2 点**: comp は λ = 0 で可視度モデルの外（f ≠ 0 は Adam の漏れ）。「収束点で力ゼロ」は CE では言い過ぎ（Soudry ら 2018: 分離可能なら極小は無限遠で余裕は伸び続ける）。正しくは「残滓方向への復元力が無い」で、top の釣り合いも「極小に居る」証拠ではない。溶接ノート §4 の測定（勾配 1.3e−4・cos ±0.005）はこの言い方と整合。
