## 3. PM で GELU が崩れる（事後・登録外・最大の驚き）

spec の PM は「学習できる活性化か」の報告欄だった。150 タスクでは:

| 腕 | seed | t50 | t70 | t90 | t110 | t150 | 最初に床 |
|---|---|---:|---:|---:|---:|---:|---:|
| **GELU** | 0 | 0.925 | **0.200** | 0.117 | 0.118 | 0.117 | t68 |
| **GELU** | 1 | 0.907 | 0.867 | 0.778 | **0.179** | 0.114 | t117 |
| **GELU** | 2 | 0.925 | **0.116** | 0.116 | 0.116 | 0.116 | t66 |
| SiLU | 0 / 1 / 2 | 0.98 / 0.98 / 0.91 | | | | 0.20 / **0.92** / 0.29 | — |
| R | 0–2 | 0.90–0.95 | | | | 0.62–0.85 | — |
| LR / ELU1 | 0–2 | 0.98–0.99 | | | | 0.95–0.97 | — |

- **GELU の PM は 3 seed とも偶然水準（0.114–0.117）**。登録規則は s1 を `ABOVE_FLOOR` と出すが、PM はラベルが毎タスク同じで s = 0 になり閾値 = F そのもの（s1 は late 0.1142 と閾値 0.1142 が紙一重）。規則の縮退で、軌道は明らかに床。
- **反転域に入ってから死ぬ**: t50 で第 2 層の φ′<0 が 0.43–0.73、その後 median z̄₂ −64〜−76 まで沈み |φ′|<1e−8 が 1.00。第 1 層も t150 で φ′<0 が 0.65–0.81。
- **RL と PM で死ぬ活性化が入れ替わる**: ELU は RL で死に PM で生きる。GELU は RL で床の上に残り PM で死ぬ。SiLU は PM で 2/3 が大きく崩れる（0.20・0.29）。
- 箱 B（pmnist・625 更新/タスク）では GELU の谷の向こうは復元域で釣り合い −7 だった。この箱（1200 枚・6000 更新/タスク）の PM では −75 まで沈んで凍る。**反転域が復元になるかは箱に依る**。

## 4. 引用制限

- 「GELU は RL-MNIST で崩壊しない」と書かない。150 タスクで床の上、精度は減速しているが反転域の占有は増え続けている。
- PM の崩壊は**登録外**。「GELU は PMNIST で崩壊する」と書くなら、この箱（1200 枚固定・80 epoch/タスク）での事後観察と明記し、登録走での確認が要る。
- PM に親と同じ床規則を当てると s = 0 で縮退する。PM の床判定を登録するなら規則を作り直す。
