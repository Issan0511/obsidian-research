## 0. 一行

**登録判定は主 `ZETA_CLOSURE` = `NOT_DETERMINED`・第 2 `PSTAR_INVARIANT` = `NOT_DETERMINED`。落としたのは現象でなく床の設計。** 事後に読むと、**位置の場は ζ では閉じない**（零点が W とともに 4.1 倍動く・傾き β ≈ −1.5）が、**ζ/W でも完全には閉じない**（B ≈ 2.0）。

## 1. 登録判定と、落ちた理由

`drift_ok`（効果量の床 2）が **8 腕すべてで False**。1 度も通らないのは効果が弱い署名ではなく、**床の書き方が間違っている**署名。

**誤り 1: 床を「最初と最後のビン」に掛けた。** 十分位の両端は一番雑音が大きい。`LRoff0` 第 1 三分位:

```
ζ:    -2.761 -2.433 -2.228 -2.047 -1.876 -1.706 -1.525 -1.327 -1.092 -0.716
E[N]: +.0154 +.0282 +.0236 +.0162 +.0148 +.0026 -.0020 -.0018 +.0064 +.0024
```

ζ = −1.60 で明確に符号を変えているのに、最後のビンが +0.0024 に**戻る**ので「両端が逆符号」が偽になる。**床はプロファイルの振れ幅に掛けるべきだった。**

**誤り 2: W の三分位が広すぎた。** 第 3 三分位（W̃ = 4.03）は帯の中で W がまだ大きく動くので、ζ を固定しても W が混ざって符号が揺れる（符号列 `+--+------` ＝ + → − の交差が 2 本 → nan）。**ζ で条件付けるのに帯の中で W が動く**という、この検定が解消するはずだった混同そのもの。

**誤り 3: 床が「3 三分位すべてで」の AND。** 複合 AND が判定を殺したのは [[井戸の剛性_0907]] に続いて **3 回目**。

## 2. 事後の読み（登録ラベルではない）

### 2-1. ζ では閉じない

| 腕 | a | ζ\*/W̃（三分位順） | A = max/min &#124;ζ\*&#124; | ζ\* = α + βW の β |
|---|---|---|---|---|
| `LRoff0` | 0.1 | −0.987 / −0.897 / — | — | **−0.79** |
| `LRa0p2_off0` | 0.2 | −0.497 / −0.754 / −0.998 | **4.11** | **−1.47** |
| `LRa0p3_off0` | 0.3 | −0.372 / −0.617 / — | — | **−1.10** |
| `LRoffm0p5` | 0.1 | −0.563 / −0.813 / −1.106 | **4.56** | **−1.49** |

零点は W とともに大きく動く（a=0.2 で ζ\* が 4.1 倍）。**β は 0 から遠い。**

### 2-2. ζ/W でも閉じない

B = 2.01（a=0.2）・1.97（c=−0.5）。A の半分だが 1 ではない。**ζ\*/W は幅が広いユニットほど −1 に近づく**（−0.50 → −0.75 → −1.00）。a=0.1 だけは 2 点とも −0.99 / −0.90 で上端則にほぼ乗る。

→ 読みとしては「**ζ/W は ζ より 2 倍うまく畳めるが、どちらでも閉じない。affine 則 ζ\* = α + βW（α > 0・β ≈ −1.5）のほうが合う**」。**2〜3 点の当てはめなのでこれ以上は言えない。**

### 2-3. p_up の量子化 — [[前活性1次元のdrift則_結果_0907]] に効く

**p_up は 1/32 = 0.03125 の倍数しか取れない**（支持が 32 点）。前回の p\* を刻みに照らすと:

| a | p\* | 位置 |
|---|---|---|
| **0.1** | **0.012** | **0/32 と 1/32 の間 ＝ 最初の刻みの中** |
| 0.2 | 0.040 | 1/32 と 2/32 の間 |
| 0.3 | 0.081 | 2/32 と 3/32 の間 |
| 0.5 | 0.234 | 7/32 と 8/32 の間 |

**a = 0.1 の p\* は p_up = 0 と 1/32 の 2 点の内挿だけで決まっており、分解できていない。** a ≥ 0.2 は別々の水準を跨ぐので本物。

→ **`p* ≈ a²` は a ≥ 0.2 で支持され、a = 0.1 では分解限界以下、と読み替える。**
今回 `PSTAR_INVARIANT` が C = 2.09 で落ちたのも（p\* = 0.0180 / 0.0184 / 0.0088・前 2 つは見事に一致）この量子化を強く疑う。

## 4. 方法論（登録設計のミス 5 回目）

**床は「判定量が意味を持つ範囲」に掛ける。両端のビンのような一番雑音の大きい場所に掛けない。**
これまでの型:
1. `offset_grid`: settle 誤射
2. `well_stiffness`: 未登録の畳み込み ＋ 複合 AND
3. `smooth_kink`: 効果量の床が無い
4. `drift_law`: 符号が変わる量に log–log
5. **`zeta_field`: 床を最も雑音の大きい両端ビンに掛けた ＋ 複合 AND（AND は 3 回目）**

良かった点: 検査が**識別力**を人工データで実測していた（ζ で閉じる世界と ζ/W で閉じる世界を別ラベルに振り分ける・追補 1 §8-3）。判定器そのものは効く。落ちたのは床。
