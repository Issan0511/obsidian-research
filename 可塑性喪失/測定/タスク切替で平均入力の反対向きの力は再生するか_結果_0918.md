## 結論

**切替直後の押し下げと、長期に残る沈下を分ける必要がある。** CondA leaky a=0.1 では、切替直後に平均入力の反対向きへの力が生じる。ただし全15通りを平均した瞬間の力の記述的95%区間が負に収まったのは20・100タスク状態で、500タスク状態では0を跨いだ。実際に1タスク学習すると、切替なし対照より下がる効果が登録した100更新・10000更新の両方で残ったのは20タスク状態だけ。他の条件は未分解（UNRESOLVED）で、効果ゼロの証明ではない。

その20タスク状態では、押し下げの大部分が **現在のwに直交する更新** から来る。一方、入力だけの切替で前活性は上がっており、学習はその上昇をほぼ打ち消す。**負向きの学習があることと、タスク境界を跨いで前活性が毎回さらに沈むことは別。** この1タスクの検証で500タスクの長期則は閉じていない。

## 1. 条件・登録

- CondA、20入力・100 hidden・scalar出力、MSE（1/2なし）、通常SGD lr=0.005。W/b/v/出力biasを同時更新。
- leaky a=0.1 / 0.7、学習済み20・100・500タスクのcheckpoint、各10 seed。初期状態は主解析に含めない。
- 固定状態の検査: 15通りのbit切替を全列挙、各32支持点。切替は教師の変更ではなく入力bitの変更で、固定教師の出す正解と用量固定offsetがそれに応じて変わる。
- 入力旧/新 × 正解旧/新の4条件を固定パラメータで比較。交差条件は診断用の反実仮想。入力・正解の効果は交互作用を保ち、順序を対称化したShapley配分も記録。
- 実学習: seedごとに一つのbitを乱数で選び、切替あり/なしを同じrandom 5bit列で10000更新。float64とnative float32。元の5M学習の乱数列の再生ではない。
- 両軌道を同じ新タスクの平均入力μ_newで評価する。主endpointはunit平均したW輸送のseed内差、100・10000更新、2腕×3時点×2窓の12比較。seedを独立単位として両側t区間、Bonferroni family α=.05。支持点・unit・15個のflipを独立標本数に数えない。

登録: [spec・355529e](https://github.com/Issan0511/lop_analysis/blob/355529e/specs/spec_switch_force_0918.md)。本走コード e5644e3、結果 [summary.md・8fa064b](https://github.com/Issan0511/lop_analysis/blob/8fa064b/results/switch_force_0918/summary.md) / [verdict.csv](https://github.com/Issan0511/lop_analysis/blob/8fa064b/results/switch_force_0918/verdict.csv)。以下の数値はsummaryの表から転記。

## 2. 切替直後に何が崩れるか（分解は記述的）

一更新の平均入力へのW応答変化。新μを共通の基準として、全15flip・32入力・100unitをseed内で平均後、10seed平均。

| a=0.1・学習済み |     切替前の総力 |     切替後の総力 | 自己項 前→後                 | 残り 前→後                  |
| ---------- | ---------: | ---------: | ----------------------- | ----------------------- |
| 20タスク      | +0.0000123 | −0.0010661 | −0.0040972 → −0.0047247 | +0.0041095 → +0.0036586 |
| 100タスク     | −0.0001078 | −0.0008357 | −0.0004155 → −0.0004651 | +0.0003077 → −0.0003706 |
| 500タスク     | +0.0000185 | −0.0002143 | −0.0003409 → −0.0003528 | +0.0003594 → +0.0001385 |

20タスクでは自己項の押しが強まり、残りの押し戻しも弱まる。100タスクでは残りの項が符号を変え、500タスクでは自己項の変化は小さく残りの押し戻しが弱まる。「一定の自己項だけが露出する」という一つの説明では揃わない。

正解だけを入れ替え、入力とパラメータを固定した場合、自己項は厳密に不変。自然なCondA切替では入力も変わるため、自己項自体も変わる。入力変化と正解変化の両方が、a=0.1の3時点の負向きの変化に寄与する。残差変化、gate変化、両者の交互作用、入力ベクトル変化の積展開も全て閉じた。**φ′の大小だけでは符号は決まらない。**

## 3. 実学習で押し下げは残るか

以下は切替直後を起点とし、新μに対する重みだけの応答変化。入力だけのジャンプとbiasを含めない。unit/seed平均、float64。

| 学習済み   | a=0.1・100更新 | a=0.1・10000更新 | 10000更新の対照との差と調整済み区間             |
| ------ | ----------: | ------------: | -------------------------------- |
| 20タスク  |   −0.040719 |     −0.045406 | −0.045761 [−0.088560, −0.002962] |
| 100タスク |   −0.015027 |     −0.001526 | −0.002981 [−0.027004, +0.021042] |
| 500タスク |   −0.020817 |     −0.003485 | −0.006895 [−0.057720, +0.043929] |

20タスクの2窓が **SWITCH_ADDS_DOWNWARD**。a=0.7の全6比較と、a=0.1の残り4比較は **UNRESOLVED**。native float32でも主判定の12ラベルは同じ。

100・500タスク状態では、初期に下がった後かなり戻る。a=0.7では末尾のW輸送の平均値が正になる条件もある。初期100更新の押しだけを積み上げて長期沈下を予測できない。

## 4. 回転方向と、入力だけのジャンプ

**a=0.1・20タスク状態から10000更新**。

- W輸送 −0.045406 = 各歩のwに平行な寄与 −0.004110 + 直交する寄与 −0.041296。
- 端点の厳密な対称分解では、長さ変化 −0.001036 + 方向変化 −0.044370。
- W輸送が負のunitは50.5%。集団の負平均を、全unitが同じ方向へ動くことと読まない。
- 同じタスクで中心化Wの二乗ノルムは平均として増えている（全6条件とも）。

入力だけの切替を含めた前活性の収支は、

$$
\bar z_{\rm end,new}-\bar z_{\rm start,old}
=\underbrace{w_0^\top(\mu_{\rm new}-\mu_{\rm old})}_{\text{入力だけのジャンプ}}
+\underbrace{(w_{\rm end}-w_0)^\top\mu_{\rm new}}_{\text{重み更新}}
+\Delta b.
$$

|      入力だけ |      重み更新 |    bias更新 |            全体 |
| --------: | --------: | --------: | ------------: |
| +0.049354 | −0.045406 | −0.004759 | **−0.000811** |

この例の学習中の負向き輸送は、切替による上昇をほぼ打ち消している。500タスク状態では同じ全体の変化は +0.033320。どちらも、学習中の押し下げだけから境界を跨ぐ沈下を推論してはいけないことを示す。

## 5. 自己項の巨大な量を、総力と混ぜない

a=0.1・20タスク状態の1タスク合計:

| 寄与     |         値 |
| ------ | --------: |
| 自己項・正側 | −53.93953 |
| 自己項・負側 |  +9.47116 |
| 残り・正側  | +53.88975 |
| 残り・負側  |  −9.46678 |
| 正側の総寄与 |  −0.04978 |
| 負側の総寄与 |  +0.00437 |
| 総W輸送   |  −0.04541 |

学習が進むと自己項と残りは強く相殺する。総力に残るのはその差であり、初期状態で自己項が支配的だったことを1タスク全体へ延長できない。自己項/残りの分解は恒等的な帳簿で、独立の物理的な力を除去する介入ではない。
