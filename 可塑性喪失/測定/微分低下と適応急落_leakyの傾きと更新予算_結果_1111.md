# 微分低下と適応急落：leakyの傾きと更新予算（1111）

2026-11-11。新規実験 `leaky_cliff_1111`。ユーザーの「平均微分0.1程度では動けたが、その後急落した」という記憶はCondAまで遡る可能性がある。元図は未同定。このノートは、新しく回した**乱数ラベルMNIST**の結果であり、CondAの再現と扱わない。

今回の条件では、小さい正のleakで適応が大幅に遅くなる。しかし、20課題を終えた同じ網に同じ新課題を長く与えると、自然継続でも精度が54.4%から99.4%へ回復した。逆伝播の微分だけを強める効果は小さく、Adamだけのリセットでは回復しない。出力層をゼロにしてAdamもリセットすると、短い予算で97.4%まで回復する。**固定更新数で見える成績低下と、学習不能・固定した容量上限を区別する必要がある。**

## 設計と完了

事前登録は [spec（73338cd8）](https://github.com/Issan0511/lop_analysis/blob/73338cd8/specs/spec_leaky_cliff_1111.md)。実験コードは `18b4681fec66d42617da7814ae625852d3ca108d`。結果は [保存コミット（048b848f）](https://github.com/Issan0511/lop_analysis/tree/048b848fa43b4fa452b14bdb496d8439d1eb1ea5/results/leaky_cliff_1111)、main統合は `23986ee4342d40441504c3e0e685cc0194d58191`。

固定1200枚のMNIST画像、入力を255で割る。各課題で独立な10クラス乱数ラベル。784–100–100–10の2隠れ層、両層で同じleaky傾きa、batch16、Adam lr=.001、eps=1e-8、weight decayなし。1課題6000更新×20課題。初期値・画像部分集合・ラベル・バッチ順をseed内でa間に揃えた。float32、CPU、最大5プロセス、各1thread。GPUは使用していない。

探索は a={0,.003,.01,.03,.1,.3,1}×3seed。正の非線形aの隣接区間で、後半online精度差が最大の区間を選ぶ登録規則により .03／.1を選択。差が.15以上だったため幾何平均 .0547723も加え、独立seed3〜7で確認した。学習率のa別調整はしていない。

36系列の自然経過と60本の分岐、計96本がすべて完了。B−Nが.15未満のため、登録条件付きのB1／B2追加実験は実施していない。主実行は約12.5分。途中失敗の系列を除外した平均ではない。

online精度は6000回の更新前ミニバッチ精度の平均、課題末精度はちょうど6000更新後の固定1200枚全体での精度。両者を混同しない。**すべて訓練・記憶精度であり、未知画像の汎化精度ではない。**

## 何が効いたか

Bは現在のパラメータに対する自然forwardを常に保ち、backwardだけを変更する。Xは各入力について凍結した元の網の値を用い、各層で
\[
h_X(z)=\phi_{.03}(z_0)+\phi_{.1}(z)-\phi_{.1}(z_0)
\]
とする。開始時は隠れ表現・logitが元とbitwise一致するが、その後のforwardは変わる。固定した入力依存オフセットを持つため、Xは通常のleaky網と同じ関数クラスでもない。Aは開始時のforwardから変わる。

| ---- | ---------: | -------------- |
| B−N  |  +6.12ポイント | [3.67,8.56]    |
| X−N  | +36.12ポイント | [32.23,40.01]  |
| O−N  |  −0.65ポイント | [−2.15,0.85]   |
| H−O  | +43.63ポイント | [39.86,47.41]  |
| BO−O |  +2.95ポイント | [0.99,4.91]    |
| BO−B |  −3.82ポイント | [−5.06,−2.57]  |

逆向きも別のa=.1学習済み状態から実施。自然継続83.68%に対して、backwardだけ.03にした分岐64.23%、初期出力を保つXreverse63.42%。backward逆変更の差は−19.45ポイント [−21.05,−17.85]。逆向き3条件は登録通り6000更新のみで、90%未到達は右打ち切りとして記録した。

**逆伝播だけを弱める害は大きいが、強める救済は小さいという非対称性**が出た。「正向きBの改善15ポイント以上、逆向きBの悪化15ポイント以上」という登録した両方向基準は満たさない。Bの正の効果自体は全5seedで見える。Xの大きな回復をそのままbackwardだけの効果や自然a差の媒介率としない。

Adamリセット単独では回復しなかった。一方、Adamをリセットした条件で出力層もゼロにする効果は大きい。Hではその後のbodyも学習し、第2層の平均微分や入力上の開きも大きく増えた。**凍結したbodyの容量を測った実験ではなく、headだけをリセットしてAdamを保持する対照も今回はない。**「headが作る再学習開始状態が強く効く」までが直接の結果。

既存の [[MLPのhead0対照_⑤は体の側か装填費用か_結果_1108]] は1隠れ層・4000更新など条件が違う。そのH0Aも、specに照らすと各境界でSから一度だけ分岐する対照であり、毎課題の予防リセット軌道ではない。今回も一度の回復と予防を分ける。

## 平均微分0.1をどう読むか

ここでaは負側の傾きであり、平均微分そのものではない。各unitで入力上の正側確率をpとすると、
\[
\bar g=a+(1-a)p,\qquad
\overline{g^2}=a^2+(1-a^2)p,\qquad
\mathrm{Var}_x(g)=(1-a)^2p(1-p).
\]
入力平均の後にunit平均を取る。2層は別々に報告する。この3量はleakyでは代数的に結ばれるため、独立な3つの証拠ではない。

a=.1で平均微分が.1に近いなら、入力のほぼ全部が負側にある。全入力への弱い応答と、一部入力への強い応答では関数の変わり方が違う。探索の課題20では、ほぼ片側のunit比率はa=.03で第1層83.3%／第2層84.0%、a=.1で43.3%／24.0%、a=.3で2.0%／0.67%。正のleakでは片側化はゼロ微分による文字通りの死ではない。片側化の相関だけで因果媒介を確定しない。

登録した「同じtask・seedで、両層の平均微分差.02以内、精度差20ポイント超」という自然経過の反例基準は**未達**。該当29ペアの最大差は18.33ポイントだった。これを成功した反証として書かない。

一方、予算を延長したNに対する**事後集計**では、以下の3seedは両層の平均微分が.1未満のまま90%を超えた。これは文字通りの一律停止境界とは両立しないが、上記の登録比較とは別物。

| seed |   更新数 |     精度 | 第1層平均微分 | 第2層平均微分 |
| ---- | ----: | -----: | ------: | ------: |
| 3    | 18000 | 92.08% |  .05988 |  .06234 |
| 5    | 17250 | 91.17% |  .06740 |  .06793 |
| 6    | 14250 | 91.50% |  .06609 |  .08325 |

また、従来の微分participationは
\[
n_{\rm eff}(p,a)=
\frac{[a+(1-a)p]^2}{a^2+(1-a^2)p},
\quad
\min_p n_{\rm eff}=\frac{4a}{(1+a)^2}.
\]
a>0では全負側p=0でも1へ戻る。a=.1の最小値は.33058なので、ELUから校正した.119をそのままleaky .1へ持ち込むことは数学的にできない。「全て同じ弱い応答だからparticipationが高い」と「非線形な表現能力が高い」は異なる。[[機能的応答を他の箱で予測に使う_結果_0917]] の最終判定BOX_SPECIFICと整合する。

## Adamと実際の機能変位

Nの6000更新時の第1層パラメータ実変位ノルムは平均.0531、Bでは.0518。平均微分が低くても重みの移動は止まっていない。意図したAdam step、float32で実現したstep、真のforwardヤコビアンによるJΔ、実際のlogit変化、誤差方向との内積、全体CE変化を別々に保存した。

全履歴を同じ正数cで縮める場合のAdamは、
\[
\Delta\theta_c
=-\eta\frac{c\hat m}{c\sqrt{\hat v}+\epsilon}
=-\eta\frac{\hat m}{\sqrt{\hat v}+\epsilon/c}.
\]
εが十分小さく、履歴・方向も実際に同じ比率で変わるときに限ってcがほぼ相殺される。突然aを変えると例・unitごとに変化が異なり、既存のmomentも残るため、この相殺を無条件に使えない。[Adam原論文のAlgorithm1と§2](https://arxiv.org/pdf/1412.6980)に基づく式で、今回のa介入への当てはめは別途検証が必要。

task21の初回勾配を一律.01倍にするshadow比較で、第1層stepノルムの元に対する比は、履歴も整合して縮小すると.9919、新しいmomentなら.9954、古いmomentを保持すると.5978だった。SGDなら瞬間的な同じ勾配の一律縮小にstepが比例するが、**SGDでの学習実験を回したわけではない**。

Nの6000更新では第2層・headのε支配座標比率は0。第1層の約20.9%はほぼ全て、この1200枚で常に黒い画素への接続。これを除いた残りの座標での比率は最大.153%。広範なε支配による停止は支持しない。[[εの再判定_float32の床を入れて読み直す_結果_0917]] のELU実装依存のゼロ微分とは区別する。

機能変位の局所近似も万能ではない。Xの最初のstepでは平均の線形予測CE減少は+.08355だが、実際のCEは.01727増加した。有限stepの曲率効果等があるため、JΔの誤差方向投影だけで一回のCE減少や全学習速度を断定しない。各分岐は残差の大きさや学習段階も異なり、記録点の指標を単純順位化しただけでは全曲線を説明しきれない。

固定カーネル・二乗損失のモデルでは誤差モードがexp(−ηλt)で減衰し、限られた更新数での達成率はηλ×予算に依存する。[Jacotらの§5](https://arxiv.org/pdf/1806.07572)はその理論例。ただし今回の有限幅・Adam・CEで固有値や誤差投影を同定したわけではなく、今回の急落をその式で説明済みとはしない。

## 1111補記：急落の境界を直接比較した結果

本実験の後期状態からの回復だけでは、境界での急な力学変化と連続的な遅延を区別できない。追加の新規実験 [[適応急落の境界_相転移か時間切れか_結果_1111]] では、a=.003・独立5seedの急落前後から同一の新課題を学習させ、実際の経路の1/4刻みも比較した。T90平均は3585→7905更新で6000更新の制限をまたぎ、登録した時間伸縮一致は5/5、急変条件は0/5。学び直し中の第2層ゲートの入力依存性低下と、開始時ゲートを固定した対照の大きな高速化も観測した。ただし単一の平均微分や正側unitなし比率では例外seedを説明できない。旧結果の回復可能性と、新実験の境界機構の証拠は分けて読む。
