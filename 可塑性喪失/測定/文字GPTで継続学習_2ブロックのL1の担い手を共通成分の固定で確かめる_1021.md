# 文字 GPT で継続学習：2 ブロックの L1 の担い手を、上流の共通成分の固定で確かめる（追補 8）

親：[[文字GPTで継続学習_2ブロックの幅の上限cap_10seed_結果_1021]] / 状態：事後・未登録（10 seed の介入、定義と予測は走る前に commit） / 更新：2026-10-22、Claude（文字 GPT 継続学習のセッション）
関連：[[文字GPTで継続学習_2ブロックのL1の生き返りを介入で分ける_1021]]、[[文字GPTで継続学習_位置の動きを誰の信号かで割る_ρとκR_事後_1021]]、[[V13機構の部品表_1021]]（部品 1、脚注 T1）

## 0. 一行

FFN0 の共通の書き込みを切替の 100 更新だけ固定すると、読み出しに隣接する L1 の沈みは課題 2〜10 で約半分減り、課題 41〜50 では 8/10 seed で浮く向きに反転した。注意 1 の共通の書き込みを固定すると、課題 41〜50 ではかえって大きく沈んだ（9/10）[測定]。

## 1. 問いと走

- 依頼：Issa（「行 1（担い手）を 2 ブロックで閉じておいて」、V13 セッション経由）。spec 追補 8（lop_analysis d182c3ed）。
- 箱：追補 7 の C3-2（2 ブロック、ReLU、bias なし）、seed 0〜9。
- 課題 t−1 の末（重み＋Adam）から、課題 t の最初の 100 更新を同じデータ列で再生した。t は 2・3・5・10・41・45・50。
- 腕は 3 つ。

| 腕 | 介入 |
| -- | -- |
| 対照 | なし |
| FFN0 固定 | FFN0 の出力 f を、各 forward で f − mean(f) + c に置き換える |
| 注意 1 固定 | 注意 1 の出力を同じ形で置き換える |

- mean はそのバッチの全トークン平均（共通の書き込み）。c は窓の始まりの網で、課題 t の probe に対して取ったトークン平均。
- 置き換えは測定の forward にも入れた。probe 上の共通成分は、窓の末でも c と一致した（相対 4×10⁻⁷ 以内）。
- 測るのは L1 の位置の変化 Δμ/σ（両端とも課題 t の probe）。これを自分の重みの分と上流の分（上流の平均の動き＋交差）に割った。
- 集計の主は「対照で沈む unit」の平均。減りは 1 − 介入 / 対照（seed ごと）。

## 2. 検査

- 対照 70 本は、元の走の各更新の損失と、保存済みの更新 100 の重みの両方にビット一致した。
- 位置の分解の恒等式の残差は最大 4.4×10⁻¹⁵。
- 1 回目の並列実行で、10 本同時に GPU のメモリが足りなくなった。7 seed は 4 本ずつ回し直した。

## 3. 結果

### 3.1 課題ごと（対照で沈む unit の平均、10 seed の中央値）

| 課題 | 対照 上流の分 / 合計 | FFN0 固定（減り） | 注意 1 固定（減り） |
| -- | -- | -- | -- |
| 2 | −0.25 / −0.29 | 0.65 / 0.58 | 0.15 / 0.13 |
| 3 | −0.48 / −0.51 | 0.94 / 0.88 | 0.22 / 0.20 |
| 5 | −1.16 / −1.27 | 0.50 / 0.46 | −0.15 / −0.13 |
| 10 | −3.86 / −3.90 | 0.59 / 0.59 | −0.06 / −0.06 |
| 41 | −1.37 / −1.37 | 1.52 / 1.30 | −1.29 / −1.29 |
| 45 | −0.92 / −0.92 | 1.50 / 1.50 | −1.74 / −1.74 |
| 50 | −0.23 / −0.25 | 1.45 / 1.44 | −0.60 / −0.60 |

減りの欄は「上流の分 / 合計」。1 を超える減りは、沈む変位が浮く向きに反転したということ。負の減りは、固定するとかえって大きく沈むということ。

### 3.2 seed ごとの塊（課題 2〜10 は t = 2・3・5・10、課題 41〜50 は t = 41・45・50 の平均）

- FFN0 固定：課題 2〜10 の減りは、上流の分で 0.38〜0.67（中央 0.55）、合計で 0.37〜0.66（中央 0.53）。課題 41〜50 では **8/10 seed で 1 を超えて反転した**（seed 5・9 は 0.48・0.88）。
- 注意 1 固定：課題 2〜10 の減りは −0.08〜0.10。課題 41〜50 では 9/10 seed で負。
- (seed 7, 課題 45) は対照で沈む unit が 0 個だったので、欠測にした。塊の平均はその課題を除いて取った。この扱いは spec に無く、走ったあとで決めた。
- 窓の末の損失：FFN0 固定は、課題 3〜50 で対照より 0.15〜0.55 良かった（課題 2 だけ +0.11）。

### 3.3 予測との照合（V13 セッションの予測、8/10 以上で当たり）

| 予測 | 結果 |
| -- | -- |
| P-C1 FFN0 固定で、課題 2〜10 の上流の分が 5 割以上減る | 外れ（6/10） |
| P-C2 同じく、合計が 4 割以上減る | 当たり（9/10） |
| P-C3a FFN0 固定の減りは、課題 41〜50 で 3 割未満 | 外れ（0/10。逆に反転した） |
| P-C3b 注意 1 固定の減りは、課題 41〜50 のほうが大きい | 外れ（1/10） |

このセッションの予測は P-C1 ○・P-C2 ○・P-C3a ×・P-C3b ○ で、当たりは P-C2 と P-C3a の 2 つ。

## 4. 読み

- 早い課題では、FFN0 の共通の書き込みを固定すると、L1 の切替の沈みが約半分減った [測定]。残りの半分には、FFN0 の変動成分やほかの経路が関わっている [読み]。
- 遅い課題でも、担い手は FFN0 のままだった。seed 1000 の分解で見えた「課題 50〜100 は注意 1 が担い手の出所」は、静的な射影の割合であり、この介入の向きとは合わなかった [測定]。
- 注意 1 の共通成分は、遅い課題では L1 を浮かせる側に働き、FFN0 の沈める押しの一部を打ち消していた [読み]。

## 5. 訂正

- Codex と V13 セッションへの最初の報告で、「FFN0 固定の後期の反転は 9/10」と書いた。正しくは 8/10（注意 1 の 9/10 と取り違えた）。Codex は主集計から 8/10 を確認して部品表に入れている。

## 6. 言わないこと

- 共通成分を固定すると、そのあとの上流と後段の学習も変わる。減りを「担い手の寄与の割合」とは呼ばない。
- 2 つの固定の効果は足し算にならない。
- 100 更新の窓の話で、課題の中の沈みは測っていない。
