## 何をしたか

実ラベル 5+1 CIFAR-100 の CNN（c1 c2 f1 f2、全層 bias、Adam lr 3e−4、30 課題）で、乱数ラベル CNN を救った CH′＋B（c1・c2・f1・f2 の出力から EMA 平均を引き、bias を ±0.2 × 幅へ射影）を ReLU と ELU α3.6 に当てた。予算は 780 と 7800 更新/課題。土台の R・ELU は同じ束で計算し直し、前段の予算延長の走とビットで一致した（S-reuse PASS）。

## 結論

1. **CH′＋B は 4 セルのうち 3 セルで土台より悪く、残る 1 セルは引き分けだった。** 主判定の差 D（後期 hard の最初の 780 更新の online、中心化 − 土台）は ReLU・780 −9.0 pt、ELU・780 −42.8 pt、ELU・7800 −45.3 pt（`CENTER_LOWER`）、ReLU・7800 +17.4 pt（`TIE`、7/10）[登録]。
2. **中心化した網は課題をほとんど学べなくなり、自分の新品にも大きく負ける。** 後期 hard の課題全体の online は、中心化の腕が 39〜41%、土台の ELU は 84%（780）・98%（7800）。課題 29 の新品との差（新品 − 継続）は ECB が +28.7 pt（780）・+51.1 pt（7800）、ELU は −6.4・−0.7 pt [記述]。5+1 MLP の中心化（課題を重ねて落ちず、新品とほぼ同じ）とは逆で、文字 GPT の中心化と同じ側である。
3. **中心化した網では FC2 の幅が 100〜350 倍に伸びる。** FC2 の幅（unit 中央値）は ECB 2,394（780）・1,690（7800）、RCB 871・536、土台は ELU 6.7・31.6、R 10.1・87.0 [記述]。文字 GPT の中心化の腕（5〜7 倍）と同じ向きで、桁が大きい。5+1 MLP の中心化では幅が縮んだ。
4. **ReLU・7800 の引き分けは、土台の R が先に壊れたためである。** R は 7800 で FC2 の 94% が死に、後期の最初の 780 更新は 18.9%、新品との差は +55.8 pt。RCB は死なずに 36〜39% を保つ。中心化は ReLU の深い死を防ぐが、網そのものの学ぶ力は低い。

## 三つの箱を並べた読み

| 箱                                                | 入力     | 中心化の結果                          | 中心化での幅         |
| ------------------------------------------------ | ------ | ------------------------------- | -------------- |
| 乱数ラベル CIFAR の CNN（CH′＋B、`cnn_chprime_bias_1018`） | 固定     | 救う（`RESCUED`、課題 21〜30 で 94%）    | 未比較            |
| 5+1 CIFAR MLP、10 倍予算（CH・CHB0）                    | 課題で変わる | 課題を重ねて落ちない。新品とほぼ同じ。水準は課題 1 から低い | 縮む（30 → 13〜14） |
| 5+1 CIFAR CNN（CH′＋B）                             | 課題で変わる | 学べなくなり、新品に大きく負ける                | 100〜350 倍      |
| 文字 GPT（C3H・B3H・B3HB）                             | 課題で変わる | 課題を重ねて落ち、新品に負ける                 | 5〜7 倍          |

- 中心化が害になる箱には、幅が大きく伸びるという共通の印がある。害にならない箱（5+1 MLP）では幅が縮む。入力が課題で変わるかどうかでは分かれない（5+1 MLP も変わる）[読み]。
- 幅が伸びる理由は分かっていない。候補は、切替の直後の EMA の遅れ（CNN では 0.3〜1.0 と大きい）が中心化の後の値に毎回大きなずれを残し、下の層の重みがそれを追って伸びること。文字 GPT の遅れは 0.02〜0.08 と小さいので、遅れだけでは説明しきれない [読み・未検証]。
- 機構への含意。担い手を EMA 中心化で塞ぐ介入は、入力固定の箱と 5+1 MLP では機構の予測どおりに効き、CNN と Transformer の実ラベル・言語の箱では介入そのものが幅の暴走という別の壊れ方を起こす。だから後者の結果は「経路を塞いでも保たれない」ではなく「この塞ぎ方は使えない」である。介入の限界として書き、機構の反証には数えない [読み]。

## 言わないこと

- 「CNN では担い手を塞いでも学び直しは保たれない」とは書かない。壊れたのは EMA 中心化という塞ぎ方の側である（上の読み）。
- 幅の暴走の原因は割り当てない。
- 乱数ラベル CNN の `RESCUED` と同じ処方とは書かない。こちらは入力の C を外し（標準化済みの入力で恒等に近い）、lr 3e−4・CIFAR-100・5+1 の課題列で、RC の処方とは箱が違う。


## 追記（1020 昼・Fable）: 幅の暴走の分解

保存済みの checkpoint（重み）と probe の unit 統計から、課題 30 末の各層で、幅 s、出力の入力間のばらつき osd（前活性をガウスと置いて ReLU／ELU を通した標準偏差）、重みの行ノルム ‖w‖、層の利得 gain = s_l / osd_{l−1}、そろいの係数 align = gain / (‖w‖√fan-in) を出した。script は `obsidian-research-data/cnn_center_budget_1020/analysis_width_decomposition_1020.py`。

**1. 幅の暴走は重みの伸びではなく、層をまたぐ出力のばらつきの掛け算である。** 780 更新・課題 30 末:

| 腕   | 層            |                幅 s |      出力のばらつき osd |              osd/s |                ‖w‖ |     利得 gain |              align |
| --- | ------------ | -----------------: | ---------------: | -----------------: | -----------------: | ----------: | -----------------: |
| R   | c2 / f1 / f2 |   2.9 / 9.5 / 10.1 |  0.7 / 2.0 / 1.0 | 0.26 / 0.21 / 0.10 | 1.44 / 2.36 / 0.89 | 10 / 13 / 5 | 0.35 / 0.17 / 0.58 |
| RCB | c2 / f1 / f2 |     38 / 811 / 872 |   24 / 423 / 486 | 0.65 / 0.52 / 0.56 | 4.75 / 4.39 / 0.95 | 33 / 33 / 2 | 0.35 / 0.24 / 0.22 |
| ELU | c2 / f1 / f2 |   2.5 / 11.1 / 6.7 |  2.5 / 5.7 / 4.6 | 1.03 / 0.51 / 0.69 | 1.17 / 1.81 / 0.85 |   2 / 4 / 1 | 0.09 / 0.08 / 0.14 |
| ECB | c2 / f1 / f2 | 68 / 1,360 / 2,394 | 40 / 755 / 1,281 | 0.58 / 0.55 / 0.53 | 3.37 / 4.92 / 1.00 | 23 / 34 / 3 | 0.34 / 0.22 / 0.32 |

- 重みは中心化の腕でも c2・f1 で 2〜3 倍、f2 は同じ（0.95〜1.00 対 0.85〜0.89）。100〜350 倍の幅は重みから出ない。
- 違うのは osd/s である。中心化の腕は全層で 0.5〜0.65（半分開いた unit の出力はそのまま揺れる）。沈む腕の ReLU は c2 0.26 → f1 0.21 → f2 0.10 と層ごとに下がり（7800 更新では f2 で 0.03）、閉じた unit の出力は 0 で揺れない。ELU も沈むと出力が床 −α に張りつき、揺れは消える。
- 利得は ‖w‖ × √fan-in × align × (前の層の osd/s)。align は ReLU の土台と中心化で同じ（0.35 / 0.17〜0.24）で、ELU では中心化の方が高い（0.09 → 0.34、実効階数の 33 → 8〜11 の低下と対応）。
- したがって幅_f2 ∝ Π_l ‖w_l‖ × Π_l (osd/s)_l。中心化は (osd/s) を各層 0.5〜0.6 に保ち、c2 → f1 → f2 の 3 段で 20〜130 倍ずつ掛かる。沈降は (osd/s) を 0.1〜0.3 に落として、この掛け算を切る。**沈降は、正規化層の無い深い経路で前向きの尺度を抑える唯一のブレーキとして働いていた**。中心化はそのブレーキだけを外す。

**2. 学べないのは logit が爆発するためである。** 課題の最初の更新の訓練 CE（seed 平均、nat）:

| 課題       |    R |  RCB |  ELU |  ECB |
| -------- | ---: | ---: | ---: | ---: |
| 1（780）   |  4.6 |  4.6 |  4.8 |  4.8 |
| 21（780）  |   54 |  170 |   22 |  230 |
| 29（780）  |   77 |  223 |   23 |  368 |
| 21（7800） |   43 |  757 |   39 |  567 |
| 29（7800） |   33 |  755 |   54 |  798 |

中心化の腕は、課題末でも CE が 12〜178 nat に留まり（土台は 0〜2）、softmax が飽和したまま課題を当てはめられない。最大値は 10³〜10⁴ nat に達する。

**3. 同じ暴走は乱数ラベル CNN の CH′＋B（`RESCUED`）でも起きていた。** Codex の worktree の `results/cnn_chprime_bias_1018/CHf_B/units.npz`（読むだけ）: f2 の幅は課題 1 で 5,300、課題 10〜20 で 200,000、課題 30 で 129,000。それでも後期 online は 94% である。CH′ だけの CHf は幅が 36,000 まで伸びたあと沈んで 6 に落ち（m/s −33、死）、49.5%。つまり中心化による幅の暴走は、EMA 中心化をかけた CNN に共通で、ラベルの種類によらない。乱数ラベルの箱で学べたのは、1 課題 30,000 更新・lr 1e−3 で、固定した画像の表を覚える課題だったからで、5+1 の 780〜7800 更新と新しい画像への般化では間に合わない。`RESCUED` は幅の暴走の中で得られた結果だった、と注記が要る。

**4. 5+1 MLP で暴走しなかった理由は、担い手を塞ぎ切っていなかったからである。** MLP の扉 C は seed の 1,200 枚の平均画像を引く固定の中心化で、課題ごとのクラスの平均を追わない。だから第 1 層の位置は課題の平均とともに動き、CHB0 でも課題 30 末の第 1 層の平均は −2.3（R は −2.0）で、開く割合 0.12〜0.38 のまばらさが残る。EMA で中心化した隠れ層は 1 つだけで、掛け算の段が無い。MLP の「落ちない・新品と同じ」は、第 1 層の沈降というブレーキを残したまま第 2 層だけ塞いだ結果として読む。

**含意。** 担い手を塞ぐ介入は、尺度のブレーキを別に持つ箱でしか使えない。正規化層の無い深い経路では、沈降そのものがブレーキなので、EMA 中心化は幅を暴走させる。乱数ラベル MLP（1 隠れ層、入力固定）と 5+1 MLP（第 1 層は沈んだまま）では害が出ず、CNN では出る。文字 GPT は pre-LN が各 block で尺度を戻すので掛け算は起きないはずで、5〜7 倍の伸びは別の経路（LN の γ か向きのそろい）として残る。機構の文「経路を塞ぐか応答を保てば学び直しは保たれる」は、「塞ぐ」に尺度の制御を伴うことを条件に書く。
