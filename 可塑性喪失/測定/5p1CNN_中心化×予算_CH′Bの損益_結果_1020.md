## 何をしたか

実ラベル 5+1 CIFAR-100 の CNN（c1 c2 f1 f2、全層 bias、Adam lr 3e−4、30 課題）で、乱数ラベル CNN を救った CH′＋B（c1・c2・f1・f2 の出力から EMA 平均を引き、bias を ±0.2 × 幅へ射影）を ReLU と ELU α3.6 に当てた。予算は 780 と 7800 更新/課題。土台の R・ELU は同じ束で計算し直し、前段の予算延長の走とビットで一致した（S-reuse PASS）。

## 結論

1. **CH′＋B は 4 セルのうち 3 セルで土台より悪く、残る 1 セルは引き分けだった。** 主判定の差 D（後期 hard の最初の 780 更新の online、中心化 − 土台）は ReLU・780 −9.0 pt、ELU・780 −42.8 pt、ELU・7800 −45.3 pt（`CENTER_LOWER`）、ReLU・7800 +17.4 pt（`TIE`、7/10）[登録]。
2. **中心化した網は課題をほとんど学べなくなり、自分の新品にも大きく負ける。** 後期 hard の課題全体の online は、中心化の腕が 39〜41%、土台の ELU は 84%（780）・98%（7800）。課題 29 の新品との差（新品 − 継続）は ECB が +28.7 pt（780）・+51.1 pt（7800）、ELU は −6.4・−0.7 pt [記述]。5+1 MLP の中心化（課題を重ねて落ちず、新品とほぼ同じ）とは逆で、文字 GPT の中心化と同じ側である。
3. **中心化した網では FC2 の幅が 100〜350 倍に伸びる。** FC2 の幅（unit 中央値）は ECB 2,394（780）・1,690（7800）、RCB 871・536、土台は ELU 6.7・31.6、R 10.1・87.0 [記述]。文字 GPT の中心化の腕（5〜7 倍）と同じ向きで、桁が大きい。5+1 MLP の中心化では幅が縮んだ。
4. **ReLU・7800 の引き分けは、土台の R が先に壊れたためである。** R は 7800 で FC2 の 94% が死に、後期の最初の 780 更新は 18.9%、新品との差は +55.8 pt。RCB は死なずに 36〜39% を保つ。中心化は ReLU の深い死を防ぐが、網そのものの学ぶ力は低い。

## 三つの箱を並べた読み

| 箱                                                | 入力     | 中心化の結果                          | 中心化での幅         |
| ------------------------------------------------ | ------ | ------------------------------- | -------------- |
| 乱数ラベル CIFAR の CNN（CH′＋B、`cnn_chprime_bias_1018`） | 固定     | 救う（`RESCUED`、課題 21〜30 で 94%）    | 未比較            |
| 5+1 CIFAR MLP、10 倍予算（CH・CHB0）                    | 課題で変わる | 課題を重ねて落ちない。新品とほぼ同じ。水準は課題 1 から低い | 縮む（30 → 13〜14） |
| 5+1 CIFAR CNN（CH′＋B）                             | 課題で変わる | 学べなくなり、新品に大きく負ける                | 100〜350 倍      |
| 文字 GPT（C3H・B3H・B3HB）                             | 課題で変わる | 課題を重ねて落ち、新品に負ける                 | 5〜7 倍          |

- 中心化が害になる箱には、幅が大きく伸びるという共通の印がある。害にならない箱（5+1 MLP）では幅が縮む。入力が課題で変わるかどうかでは分かれない（5+1 MLP も変わる）[読み]。
- 幅が伸びる理由は分かっていない。候補は、切替の直後の EMA の遅れ（CNN では 0.3〜1.0 と大きい）が中心化の後の値に毎回大きなずれを残し、下の層の重みがそれを追って伸びること。文字 GPT の遅れは 0.02〜0.08 と小さいので、遅れだけでは説明しきれない [読み・未検証]。
- 機構への含意。担い手を EMA 中心化で塞ぐ介入は、入力固定の箱と 5+1 MLP では機構の予測どおりに効き、CNN と Transformer の実ラベル・言語の箱では介入そのものが幅の暴走という別の壊れ方を起こす。だから後者の結果は「経路を塞いでも保たれない」ではなく「この塞ぎ方は使えない」である。介入の限界として書き、機構の反証には数えない [読み]。

## 言わないこと

- 「CNN では担い手を塞いでも学び直しは保たれない」とは書かない。壊れたのは EMA 中心化という塞ぎ方の側である（上の読み）。
- 幅の暴走の原因は割り当てない。
- 乱数ラベル CNN の `RESCUED` と同じ処方とは書かない。こちらは入力の C を外し（標準化済みの入力で恒等に近い）、lr 3e−4・CIFAR-100・5+1 の課題列で、RC の処方とは箱が違う。
