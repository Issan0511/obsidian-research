## 2. 一行

**座標の取り違えは、指数の食い違いの源ではなかった。** $\bar z$ を $\max_x z$ に替えても対応は良くならない。

だが「増分と可動度が対応しない」は雑すぎる読みで、**落ちているのは増分の「正味」だけである**:

| 何を測るか | 深さ指数は可動度の指数と一致するか |
| --- | --- |
| §2(c) の**前件**（$\varphi$ が飽和するか） | **ELU では成り立つ** —— $\varphi/\alpha$ の帯間の振れは 3.0〜8.5%（§4） |
| 増分の**大きさ**（sd・IQR・MAD） | **深い帯では一致する** —— sd で深い 10 対中 8 対が許容帯 0.3 の中（§5） |
| 増分の**正味**（中央値・登録された P2） | **一致しない** —— 0/15 対（§6） |

つまり $\varphi'$ は「揺れの大きさ」の深さ依存はまるごと担っているが、「どちらへ正味で動くか」の深さ依存は担っていない。**§2(c) が言い当てているのは前者で、[[現象3主張v1_0902]] C2 が問うている増分の指数は後者である。**

## 3. D / P1 —— 恒等式は成り立つ

沈下 ELU では `act_grad` が厳密に $\alpha e^z$（`nets.VecMLPL.act_grad` の `alpha_exp` 分岐・`S-grad` で相対誤差 0）なので、$\ln(\mathbb E_x[\varphi']/\alpha)-\max_x z$ は $[-\ln32,\,0]$ に入るはずである。**入る。**

| `E_1216`@15M（α=1） | 4,937,633 | −3.4277 | −3.076 | −0.0001 | 0 | 1.48 |

（`E_1216`@5M の 1,666,944 行は 15M 窓の**部分集合**なので合計に足さない。独立な合計 **17.0M 行**。spec §4 D の「全記録」より、タスク内増分の手前の記録点に限っている分だけ 1/10 少ない。）

$n_{\rm eff}=32\exp(\text{残差})=\sum_p e^{z_p-\max_x z}$ は $\mathbb E_x[\varphi']$ を担っている実効パターン数。**★ 読みの限定**: α=1 の 1.48 は「最浅の 1 パターンが $\mathbb E_x[\varphi']$ の **68%** を担う」であって「最浅の 1 個だけが決めている」ではない。しかも **α=1 の腕だけの数字**で、α≤0.1 の 3 腕では 3.4〜4.0（最浅の寄与 25〜30%）。**α は走・窓と交絡しているので α 依存として読んではいけない。**

**P1 が通ったこと自体は情報を持たない**（spec §7）が、**P1 は配管の検査としては歯がある**: 独立監査は、`mob` を 1 記録ずらすと 2.65% が帯外、`zmax` を $\bar z$ に取り違えると 99.7% が帯外になることを実演した。

## 5. ★★ 増分の**大きさ**は可動度に追随する

§2(c) の代数が言っているのは勾配の**大きさ**が $\varphi'$ に比例するということである。同じ帯・同じ横軸（帯の深さ中央値。§8-3）で、中央値でなく大きさの指数を取る:

| 統計量 | 通過（全対） | 通過（浅い帯 0–1 を含まない対だけ） |
| --- | --- | --- |
| 中央値（登録どおりの P2） | 0/3 | 0/2 |
| IQR | 6/14 | 6/10 |
| **標準偏差** | 8/14 | **8/10** |
| MAD | 6/14 | 6/10 |

`E_1216`@15M の例（$\kappa_\text{可動度}$ は恒等式どおり ≈1）:

| 対 | $\kappa_\text{可動度}$ | $\kappa_\text{sd}$ | 差 | $\kappa_\text{IQR}$ | 差 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 0–1→1–3 | +0.971 | +0.145 | −0.827 | +0.311 | −0.660 |
| 1–3→3–6 | +0.989 | +0.637 | −0.352 | +0.679 | −0.311 |
| **3–6→6–10** | +1.008 | +0.934 | **−0.075** | +0.874 | **−0.134** |
| **6–10→>10** | +1.020 | +0.891 | **−0.129** | +1.157 | **+0.137** |

同一ユニットを深さで追跡した within-unit の指数でも同じ向きに出る（`E_1216`・各帯 200 記録以上のユニット・$\kappa_\text{IQR}$ − $\kappa_\text{可動度}$ = −0.60／−0.38／−0.31／+0.12、いっぽう $\kappa_\text{中央値}$ − $\kappa_\text{可動度}$ = +0.93／−0.78／−0.69）。**帯間比較と within-unit が一致するので、これは深さ帯ごとに別集団を並べたことの産物ではない。**

浅い帯 0–1 を含む対だけが外れる。この帯は $\max_x z$ が 0 のすぐ下＝**帯へ戻る直前の集団**で、他の帯と性質が違う。

## 7. C —— `z̄` 座標と、タスク内位置を固定した版

**C（`z̄` 座標）**: `E_1216`@15M で $\kappa_\text{増分}/\kappa_\text{可動度}$ = 0.98/0.52・0.49/0.35・0.91/0.72（差 +0.46・+0.15・+0.19）。差の向きは `zmax` と同じで大きさだけ 1 桁小さい。通ったのは深い 2 対だけ。$z̄$ 帯 0–1 は深さ中央 0.01・n=27k と薄く、「沈下しているが $\bar z$ はほぼ 0」という浮上直前の特殊な集団である。**§10-4 の「1–3 で 0.98」も隣の 16k 行の帯に乗っており、§3 が挙げた 0.37〜0.98 の振れの少なくとも一部は薄い帯の中央値の振れである。**

**位置固定**: タスク内増分は定常量ではなく、**同じ 1 タスクの中で記録位置 o=1→9 に 2〜3 桁減衰する**（`E_1216` の `zmax` 帯 0–1 で +1.23e−2 → +2.3e−5）。9 位置をプールした中央値は後半の静かな位置で決まる。位置を o∈{1,2,3} に固定して同じ判定をすると ELU 4 腕・`zmax` で **45 対中 通過 3 対**、ラベルは同じ。ただし報告の書き方は変わる:

- `E_1216` の 0–1→1–3 の差はプールの +2.16 に対し **o=1 で +0.36**・o=2 で +1.05・o=3 で +1.58。**どの位置でも許容帯 0.3 を超えるが、プール版はずれを誇張していた。**
- `E_1216` の 3–6→6–10 は位置固定だと 3 位置とも通る。**「全対で外れる」はプール版だけの言い方である。**

## 8. 監査で訂正した点

**8-1. 初稿の「leaky 対照」は §2(c) の前件を取り違えていた（格下げ）。** 初稿は「leaky は $\varphi'\equiv a$ で厳密に一定なのだから、§2(c) が正しければ増分は深さに依らないはず」と書き、$\lvert\kappa_\text{増分}\rvert>0.3$ が 15 対中 8 対あることを「§2(c) の反証」として提示した。**これは誤り。** §2(c) が括弧の深さ非依存を導くのは $\varphi$ の**飽和**からで、leaky は $\varphi=az$ が伸び続ける（§4 で 78〜518%）。同じ代数が leaky に与える向きは「深いほど増分が大きい」であり、実測の $\kappa_\text{増分}<0$ はその向きどおりである。**残る意味は「配管が増分の深さ依存を実際に検出できる」という感度の確認だけ。** §2(c) を同じ配管で対照検査したいなら、飽和する族（他の α、あるいは SiLU/GELU の谷底より深い領域＝`valley_clamp` 系）を使うしかない。

**8-2. P4 は恒真で、配管を検査していない。** `zmax` 座標では帯そのものが $\max_x z<0$ を再賦課するので、沈下 leaky の `mob` は $a$ の float32 値ちょうど 1 種類になり、$\ln(\text{mob}/a)$ は全行同じ定数である。独立監査は、**沈下フィルタを丸ごと外しても・$\hat p=0$ に替えても・`mob` を 1 記録ずらしても $\kappa_\text{可動度}$ が厳密に 0 のまま**であることを実演した。spec §5 が「P1・P4 が通っている下で」と置いたゲートのうち、**P4 は 0 ビットしか持たない**。配管を実際に検査しているのは P1（§3）と、`S-repro`（§10-4 の 4 つの中央値を再現）・`S-sub`（`zmax`≤0 と $\hat p=0$ が全腕・全 seed・全記録で一致＝第一容疑 (1)）・`S-bnd`（除くべき増分が `flip_state` 基準の index 10,20,… であり `step//period` 基準の 9,19,… ではない＝第一容疑 (2)）の 3 本である。

**8-3. 登録された「帯の中点」の横軸は偏っている。** 恒等式より `zmax` 座標の $\kappa_\text{可動度}$ は 1 のはずだが、帯の中点を横軸にすると 0.65〜1.75 に散る。縦軸が帯の中央値なのに横軸だけ中点にしたための偏りで、**最大 0.42 と許容帯 0.3 より大きい**。帯の深さ中央値に替えると 0.85〜1.22（大半は 0.96〜1.10）。ラベルはどちらでも 0/15 だが、**個々の $\kappa_\text{可動度}$ は深さ中央値版を読むこと。**

**8-4. 増分はロガーの `layer1_dzbar` を使う。** 初稿は §10-4 を逐語継承して float32 の `layer1_zbar` の差から作り直していたが、`EluRecorder` の docstring は「$\bar z$ を float32 に落としてから引くと深い沈下域が丸めに沈む」と明示的に警告している。ロガーの float64 差分に差し替えた。**判定を担う浅い帯では差は無視できる**（`E_1216` の 0–1 は完全一致、1–3 は 4.678e−6 対 4.768e−6）。効くのは厳密 0 が出ていた深い帯（6–10 が 0 → +5.7e−8）。**つまり「量子化の床で落ちていた」という筋は、判定を担う対についてはそもそも成り立っていなかった。**

**8-5. `zmax` 座標の限界。** $\kappa_\text{可動度}$ がほぼ 1 に固定されるということは、**`zmax` 座標の P2 は事実上「増分の指数が 1 か」を聞いているのと同じ**である。spec §5 は「指数が 1 かではなく可動度の指数と一致するか」を問うと区別したが、その 2 つは `zmax` 座標では恒等式によって同じ問いに潰れる。座標を替えて落ちるのは $\ln32$ のオフセットだけで、問いの中身は元の Q2 に戻っている。

## 9. これで何が動くか

## 10. 引用上の注意・弱点

- **走はゼロ。** 生ログは 4.8 GB で repo に入らないので `provenance.json` の `input_sha256`（70 本）で同一性を固定してある。`git_hash` は出力を作ったコードの commit（`831cbee`）を指す。
- スコープ: condA・1 層・幅 100・用量 12.16・$T=10^4$・batch 1・lr 0.01・float32・seed 0–9。ELU は α 4 点、leaky は $a$ 3 点。**多層・他用量・他 lr には広げていない。**
- **窓は腕で違う**（`E_1216`・`LR_1216` は 15M、他は 5M）。spec §4 の「A・B・C は同一の走・同一の窓・同一の帯」は**腕の中では**守っている。腕をまたぐ比較は窓が違う。`E_1216` は 5M 打ち切り版も出してあり判定は両方で同じだが、**`z̄` 座標の対の合否は窓で動く**。
- **深い帯は薄い。** `E_1216` の `zmax` 6–10 は 88k 行・>10 は 4.3k 行、`E_a0p1` の >10 は 9 行しかない。判定の根拠にしたのは各腕の最も厚い対（0–1→1–3）だけである。
- **P2 の「0/15」の内訳**: 指数が有限値を持つのは 3 対で、残り 13 対は深い側の帯の増分中央値が 0 以下で対数が取れない。**これは「測れなかった」ではなく「正である §2(c) の予測に対して中央値が 0 か負」**だが、「15 対すべてで不一致が観測された」とは読まないこと。実体は 2σ 表の 5 対である。
- **P5 は時間方向のプールを含む**。断面（1 記録点）で切ると ELU の符号は保たない。**向きだけの副次予測**として読むこと。
- $\max_x z$ は生の量（[[引用禁止]]「正規化量で力学を書かない」に抵触しない）。外部文献は引いていない。
- **[[用語と記号]] の「深さ = $\bar z$」の定義変更は提案しない。** `zmax` に替えても良くならなかったので替える理由がない。
