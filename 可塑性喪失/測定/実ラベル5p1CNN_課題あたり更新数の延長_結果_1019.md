# 実ラベル5p1CNN_課題あたり更新数の延長_結果_1019

状態: **決着** / 更新: 2026-10-19 / 親: [[現在地]] / 前段: [[Neokunekune_手法比較12腕_5p1CNN_結果_1018]]
run id: `cifar5p1_cnn_budget_1019`（lop_analysis main `825c75b9`）

## 一行

課題あたりの更新数を 780 から 2340・7800 に延ばすと、4 腕とも FC2 の幅が伸びた。生きている腕のうち、沈降と応答の低下を伴ったのは ELU だけで、ELU は 7800 回で学び直しが 1.17 pt 落ちた。Snake の 2 腕は幅が伸びても φ′ を 0.9 前後に保ち、学び直しは 780 回より良いか同じだった。

## 何をしたか

- **依頼**: Issa の意向「実ラベル CNN で幅が成長する条件を調べ、沈降・応答低下・可塑性喪失の関係を追う」（Codex 経由、2026-10-19）。
- **箱**: 12 腕と同じ実ラベル 5+1 CIFAR の CNN。seed 2000〜2009、30 課題。
- **腕**: ReLU・ELU α = 3.6・KKT1・SNAfrz1。lr は全腕 3e−4（12 腕の較正で選ばれた値）。予算ごとの再較正はしない。
- **予算**: 課題あたり 780・2340・7800 更新。hard と easy の両方を延ばす。短い予算の batch 列は長い予算の先頭と同じになるように作った。
- **測るもの**: 固定 probe 2,000 枚の上で、4 層の各 unit の平均 m、幅 s、相対位置 r = m/s、φ′ の入力平均、正側占有率 p⁺、死、低応答（φ′ < 0.1）、出力 0、実効ランク。初期状態と各課題の末（境界 0〜30）で取った。主に見る層は FC2。
- **性能**: 後期 hard 課題（21・23・25・27・29）の更新前 online を、最初の 100 更新・最初の 780 更新・課題全体に分けた。課題末の test と、課題 9・19・29 の fresh 対照も取った。
- **判定**: 予算 − 780 の seed 対応差を、seed の bootstrap と Bonferroni 8 で読む（族 F1〜F4）。
- **commit**: spec `c2597606`、実装 `4dde42d9`、検査と smoke `defacbc3`、結果 `b0bb0129`、退避 `825c75b9`。

## 読み（spec §6 の規則）

- **① 幅の継続成長**は、8 つの (腕, 予算) すべてで成り立つ。
- **② 負側への位置変化と応答低下**は、ELU の 2340 と 7800 だけで成り立つ。
- **「ELU は幅の成長後も健全」は成り立たない。** 落ちた条件は F1 だけである（7800 で −1.17 pt、正の seed 3/10）。課題 29 の fresh − 継続の 95% 区間は [−0.89, −0.43] で 0 より下、FC2 の死は 0 だった。
- **次の介入の候補**（登録規則）: ReLU の 2340・7800、ELU の 2340・7800、KKT1 の 7800、SNAfrz1 の 7800。
- **幅の因果効果はこの走では立たない。** 予算延長は幅だけを動かす介入ではない。

## 但し書き

- **KKT1 と SNAfrz1 の 7800 が候補に入ったのは、F3 が `HIGHER` だったからだけである。** 課題全体の online は fresh も継続も 98% 前後に張り付くので、差が 0 に寄るぶんには天井の効果が入る。最初の 780 更新で比べると、継続は fresh より大きく良いままである。

| 腕       | 最初の 780 更新の fresh − 継続・780 | 同・2340 | 同・7800 |
| ------- | -------------------------: | -----: | -----: |
| ELU     |                      −6.44 |  −6.32 |  −4.89 |
| KKT1    |                      −4.60 |  −9.68 |  −9.33 |
| SNAfrz1 |                      −7.40 | −10.97 |  −8.37 |

- **780 予算は 12 腕と同じ軌道である。** S-reuse-780 は `PASS` で、per_task の 1,200 行 × 41 列が 12 腕の本走とビットで一致した。新しい seed での追試ではない。

## 次の介入に使える条件

- **いちばんきれいなのは ELU の 7800。** 幅の成長、負側への位置変化、応答の低下、学び直しの低下が同居し、死んだ unit はまだ無い。cap や応答の交換を試す出発点になる。
- **checkpoint** は各予算で、境界 0・1・8・9・18・19・28・29・30 の完全な状態（重み・Adam・更新番号・α・V・固定の有無）を保存した。置き場は `obsidian-research-data/cifar5p1_cnn_budget_1019/b<予算>/checkpoints/`。
