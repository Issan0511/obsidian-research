## 2. 張り付いていないもの

- **絶対的な上端は伸びる**: mean_i(z̄ᵢ + 2σᵢ) は +1.40 (t20) → +1.76 (t100)、その 90% 点は +4.5 → +6.0。max や p99 で「上端」を定義すると張り付きは消える。
- 標準化位置も厳密には一定でない: −mean/σ_within は 1.15 → 1.36（+18%）、−mean/sd_between は 1.31 → 1.20（−8%）。late 窓の seed 内 CV は r_W 0.035・r_B 0.058・p⁺(ガウス近似) 0.065、対して mean 0.107・sd_between 0.127・σ_within 0.094。**形（分位点・占有率）は 1 割前後で保たれ、尺度（平均・幅）は 2 倍動く。**

→ 張り付きの正しい定義は **「折れ目より上の占有率（または z̄ᵢ の 90% 点）」** であって最大値ではない。エンドポイントに使うなら p⁺（現 perm）か frac(z̄ᵢ>0)。

## 4. 読み

1. **占有率が調節されている変数で、深さと幅はその従属変数のように見える。** ただし観測だけでは「幅が伸びて占有率が上がりそうになるから沈む」と「沈んで占有率が下がりそうになるから伸びる」と「二つが同じ √t 則で偶然同期している」を分けられない。
2. **占有率の調節には 2 つの時間尺度がある**: 1 タスクで戻る速い成分（現 perm の整列・W̃ の向き）と、10〜20 タスクかかる遅い成分（z̄ の水準）。深さの漂流が説明すべきなのは遅いほう。
3. 既存の一発介入は占有率を揺らしていないので、**自然な漂流の駆動を止める検定は未実施** → [[幅か沈下か_クランプ介入_spec_0909]]。
4. **z̄_inv,i は star_i と等しくない。** 厳密には z̄_{r,i} = m_i·S̄ + b_i + W̃_i·x̄_r で、8 本平均でも W̃ 由来の残差 ε が残る（t20 の素 leaky で max|ε| = 0.70、ユニット間 sd は z̄_inv 1.428 対 star 1.374、相関 0.988）。μ（訓練平均画素）と S̄（probe の平均総輝度）も別物。**本ノート §1–§2 の数値は params だけから決まる `star` か、実測の `pos_frac`／`zmean` を使っており、この等式には依存していない。**
5. leaky では折れ目シフト ≡ bias シフト（φ(z−c) は b−c と同一モデル）なので、「折れ目を動かす」腕は bplus/bminus と同じもの。新設しない。
