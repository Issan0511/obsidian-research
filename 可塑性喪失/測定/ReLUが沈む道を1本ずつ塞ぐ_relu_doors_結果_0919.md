## 0. 何を測ったか

RL-CIFAR × MLP（3072-100-100-10、1200 枚固定・毎タスク乱数ラベル・50 タスク × 30,000 step・Adam 1e−3・WD なし・正規化層なし）で、**ReLU だけ**を使い、**前活性の中心を押し下げる道を 1 本ずつ塞いで、どれが効くか**を決める。入力は全腕 **raw 固定**（尺度は動かさない）。

| 扉 | 定義 |
|---|---|
| **C** | 入力の中心化。x ← x − x̄（seed の 1200 枚の平均、走る前に一度）。**割らない**。r = ‖x̄‖/rms‖x−x̄‖ が 1.911 → 0.121 |
| **H** | 中間層の中心化。a ← a − m、m は**ユニットごと・画像方向**の EMA（β=0.01、φ(z) の平均を追う）。**勾配を通さない定数**で訓練と評価で同じ値。分散正規化も affine も無い |
| **B** | **b₁ を持たない**（恒等的に 0）＋ b₂ に decoupled WD（λ = 0.1713 は未使用 seed の probe から導出）。b₃ は自由 |

追補 1 の対照 2 腕:

| 腕 | 定義 |
|---|---|
| **CS** | 扉 H の**正確な裏返し**。同じ軸の**スケール側**（v ← (1−β)v + β·mean_batch(φ(z)²)、出力 φ(z)/√v）。中心化なし・affine なし（RMSNorm 相当） |
| **LN** | **素の LayerNorm**。**標本ごとに特徴方向**で正規化、学習可能な γ・β あり、線形写像の後・非線形の前 |

## 3. 読み

### 3.1 効くのは「中心化」だけで、しかも中間層でだけ

**素の ReLU 0.113 → 0.987（10/10 seed）、50 タスク通して低下 −0.010（＝下がらずに上がり続ける）。**この箱で ReLU は「WD なしでも t1 で全滅」が定説だったので、それが**扉 2 枚**で消えた。

そして**どの扉かが極端に限定される**:

- **入力の中心化（`C`）は完全に無効**。窓 0.1133 は `ref` の 0.1132 と実質同一。**第 1 層の死亡は確かに防げている**（t1 の死亡率 0.985 → 0.000、R1 = `L1_SAVED`）のに成績が動かない。
- **分散だけの正規化（`CS`）も完全に無効**。窓 0.1132 で `ref` と数値まで同じ。
- **素の LayerNorm（`LN`）も救わない**（0.206）。
- **bias は関係ない**（D3・D4 とも `TIE`）。`B_ROUTE` = `BIAS_TAKES_OVER` で b₂ は実際に 90 倍働き出すのに、塞いでも成績は変わらない。**「扉は引き継がれるが、その扉はもう成績に関係ない」。**

### 3.2 三つの死に方（そして `CH` だけが折れ目の上に留まる）

t50 の第 2 層の状態:

| 腕 | z̄₂/sd₂ | P(z₂>0) | φ′ が厳密 0 | 実効ランク | 死に方 |
|---|---|---|---|---|---|
| `C` / `CS` | **−2.0 / −2.3** | ≈0 | **1.000** | — | **負側へ沈んで死ぬ**（ゲートが閉じる） |
| **`LN`** | **+2.0** | **1.000** | **0.000** | **63 → 0.0** | **正側へ行って線形になる**（ゲートは開きっぱなし） |
| **`CH`** | **−0.19** | ≈0.5 | 0.566 | 61 | **0 をまたいだまま** |

**LN の死に方は他と正反対**である。ユニットは 1 本も死なず（`dead_frac` は 50 タスクを通して 0.000、φ′ が厳密 0 の割合も 0.000）、**全画像・全ユニットが正側に載って ReLU が恒等写像になり**、実効ランクが 63 → 6.2 → **0.000** と潰れて崩れる。memo は t30 まで 1.000 を保ち、そこから落ちる。

したがって統一的な読みは「**死なせないこと**」でも「**飽和させないこと**」でもなく、**折れ目の上に居続けること**である。負に振っても正に振っても失う。

### 3.3 `CS` が効かない理由は事前に導ける

`CS` はユニットごとの定数 s で割るだけなので、**ā₁ も広がりも同じだけ縮み、第 2 層の入力の直流成分 r_a1 を原理的に消せない**。実測でも `CS` の r_a1 は 50 タスク通して **0.67 で一定**、`CH` は **0.003**。走らせる前にこの機構に気づいていれば、Claude の Q1（CS は救う 0.70）は置かなかった（§10.6 に開示のうえ、予測は動かさず採点した）。

## 5. 先行研究との位置（原典で照合・2026-09-19）

- **Lyle ら, arXiv 2402.18762 付録 D.2 / Figure 8**（"Isolating features of normalization layers"、凡例 `subtract mean` / `divide by std` / `both`、BN・LN × CNN・MLP）。**同じアブレーション軸が既にある。**結論は逐語 "We find that **most of the performance gain from normalization layers can be attributed to the second mechanism**"（分散で割るほう）。**この箱の結果は逆**（`CS` は `ref` と数値まで同じ、`CH` だけが救う）。
- 姉妹論文 **arXiv 2407.01800 付録 A.4**: "**centering does not have noticeable effects on the network's robustness to unit saturation.**" ただしその足場（付録 C.4 / Fig. 11）は**訓練した網でなく等方ガウス勾配のランダムウォーク・シミュレーション**、Figure 8 がどの箱かは本文に記載が無い。
- **同 付録 E.9**: "…the MLP struggles in the absence of mean subtraction from batch normalization. In the case of the MLP, … **most of the benefits of the mean subtraction from batch normalization seen here were replicated by input centering.**" 前半は D2 と一致、**後半は D1（`C` 単独が完全に無効）と衝突する**。図も数値も手順も無い一文。
- **Kumar ら, arXiv 2308.11958 (CoLLAs 2024)** は箱がほぼ同型（MNIST 1200 枚・400 epoch・50 タスク・batch 16・Adam・MLP 2×100）。Fig. 2 の数値: RL-MNIST で Baseline **0.16** / **Layer Norm 0.54** / L2 Init 0.86 / Concat ReLU 0.95。総括 "**Layer Norm mitigates only some plasticity loss.**"
- **Lewandowski ら, arXiv 2406.06811 Fig. 12**（RL-MNIST × 4×256 MLP）: 素の ReLU が LayerNorm で ≈0.11 → ≈0.62・≈0.16 → ≈0.755、**いずれも単調低下**（図からの読み取り）。
- 照合した 5 本のいずれにも **RMSNorm の腕も affine 無しのアブレーションも無い**。**RL-CIFAR × MLP に正規化を入れた数値は存在しない。**

### 5.1 箱の比較可能性（この箱のほうが厳しい）

上の 2 本（Kumar ら・Lewandowski ら）の MLP 箱は **RL-MNIST** で、この箱は **RL-CIFAR**。そのまま数値を並べることはできないが、**効くと示した軸そのもので測ると、この箱のほうが厳しい側にある**:

| 箱 | r = ‖x̄‖/rms‖x−x̄‖ | 画素の平均 / sd |
|---|---|---|
| **RL-CIFAR raw（この箱）** | **1.895** | 0.467 / 0.249 |
| RL-MNIST raw（Kumar ら・Lewandowski らの MLP 箱） | **0.814** | 0.131 / 0.308 |

**MNIST は背景が黒いので、生のままでも直流成分が偏差より小さく、膝（r ≈ 1）の下にある。CIFAR は上にある。**
Kumar らのベースラインが 0.16（チャンス 0.10 より上）で、この箱の `ref` が 0.113（チャンスちょうど）なのもこれと整合する。
指標も、こちらは t31–50 の窓、彼らは全タスク平均で、こちらのほうが厳しい取り方である。
そもそも **RL-CIFAR は通常 CNN で回すタスク**で、素の MLP で回すこの箱が「簡単」ということはない（Issa の指摘。走る前の spec §10.1 でこの疑いを理由に対照を足すと書いたのは誤りで、訂正は spec §10.7）。

**この箱の `LN` = 0.206・低下 +0.859（t28 まで保ってから崩れる）は、上の「LayerNorm は一部しか緩和しない」と同じ向き・同じ程度**で、彼らの知見を CIFAR × MLP で再現した形になる。
`LN` 腕の役割は「この箱が簡単でないことを示す」ことではなく、**公表されている介入をこの箱の中で自分の手で測った基準点として置く**ことである。そのうえで **LayerNorm より弱い介入（中心化だけ・分散正規化なし・affine なし）が 0.987 で完全に救う。**
なお実際の収穫は基準点ですらなく、**§3.2 の「LN は正側で線形化してランクが潰れる」という別の死に方**のほうだった。

したがって新しいのは「正規化が効く」ことではなく、**(a) 分散正規化も affine も無い最小の介入で足りること、(b) 入力の中心化は無効で中間層だけが効くこと、(c) `CS` が完全に無効で Lyle らの結論と逆向きであること、(d) LN の死に方が「線形化＋ランク潰れ」で他と正反対であること**の 4 点に絞られる。

## 6. 検査（12 本・変異対照つき・`all_pass`）

`results/_checks_relu_doors_0919/checks.json`。閾値はすべて算術から導いた。

- **S-off**: 扉を全部開けると**親エンジン（`rlcifar_mlp_battle_0918` の `R` raw）と 16 列 bit 一致**。複製して編集したことで無関係な経路が変わっていないことの保証。
- **S-pin**: `CHB`/`CHB0` で \|z̄₁\| = 6.5e−7、Cauchy-Schwarz の上限 2.7e−6 の 24%。
- **S-LN**: torch の `F.layer_norm` と 4.8e−7 で一致（上限 1.9e−6）、γ/β が実際に動く。
- **S-resume が実害のあるバグを捕まえた**: 扉 H の EMA が ckpt に保存されておらず（保存が `act.adaptive` で条件分岐していた）、**再開すると EMA が 0 から数え直し**になっていた。launcher は失敗時に自動再開するので本走を静かに壊すところだった。
- Claude が書く途中で**「float32 の丸めが出る場所に厳密等号を要求する」誤りを 2 回**踏み（S-C・S-H）、どちらも 2·eps·max\|値\| の上限に導き直した（実測は上限の 12–25%）。変異対照の閾値も 1 か所「1e6 倍」という無茶を置いて直した → [[検査の閾値は算術から導く]]

## 7. 限界

- **1 箱・ReLU のみ・10 seed。**他の活性化（leaky・snake 系）や他の箱（PMNIST・CNN）で同じかは未測定。`CH` が leaky や snake も押し上げるのか、ReLU 固有の話なのかは分からない。
- **扉 H の β（=0.01）は振っていない。**λ は probe から導いたが β は適応 α と同じ値をそのまま使った。
- **`LN` の置き方は 1 通りだけ**（線形写像の後・非線形の前、affine あり）。置き場所や affine の有無は振っていない。Kumar らの LayerNorm の実装詳細（挿入位置・affine の有無）は原論文に記載が無く、直接比較はできない。
