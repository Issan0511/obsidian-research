## 2. 決定的な読み: ラベルと蹴りの 2×2（事後）

k=784 と前走の PM は**ラベルだけ**が違う（乱数 対 正）。late online（t141–150・3 seed 平均）:

| 活性化 | 乱数ラベル・蹴りなし（k=0） | 乱数ラベル・全置換（k=784） | 正ラベル・全置換（PM） |
|---|---:|---:|---:|
| LR | 0.453 | 0.451 | 0.969 |
| ELU1 | **0.101** | **0.100** | **0.961** |
| R | **0.114** | **0.114** | **0.741** |
| GELU | **0.171** | **0.114** | **0.116** |
| SiLU | 0.153 | 0.115 | 0.458 |

- **ELU・ReLU の PM での生存は、蹴りではなくラベルによる。** 蹴りを全開にしても乱数ラベルなら死ぬ。蹴りは死を遅らせるだけ（最初に床を割るタスク: ELU t11–16 → t20–30、ReLU t5 → t8–38）。
- **GELU の PM での死は、蹴りによる。** 乱数ラベルのまま蹴りだけ入れると死ぬ（0.171 → 0.114）。ラベルを正しくしても救われない（0.116）。
- つまり **RL と PM で ELU と GELU の運命が入れ替わるのは、二つの別の変数が効いているから**。ELU/ReLU を殺すのは乱数ラベルの圧、GELU を殺すのは入力の蹴り。
- Issa の「μ が存在するかどうか」は、**GELU については正しく**（蹴り＝μ のリセットが GELU を殺す）、**ELU/ReLU の救済については足りない**（リセットがあっても乱数ラベルなら死ぬ）。

## 3. 機構（報告のみ）

- **ReLU の復活**は蹴りとともに増える（第 1 層 0 → 2.6%/タスク、第 2 層 0 → 8.9%/タスク）。RL（k=0）は 44,019 件で 0。ただし乱数ラベルの下では足りず、t141–150 では全 k で床。PM（正ラベル）の第 1 層復活は 12–16%/タスク。
- **GELU は蹴りで深く沈んで凍る**: k=270・784 で第 2 層の median z̄₂ が −120 / −49、|φ′|<1e−8 が 1.00（t150）。k=0 では z̄₂ −0.10・凍結 0.00。φ′<0 の占有は t150 で 0.00 だが、これは谷の向こうを通り越して φ′ が float32 で +0.0 に潰れる深さまで行ったため。
- SiLU の k=270 が 3/3 生存（late 0.21・第 2 層は φ′<0 が 0.98 で反転域に居座るが凍結 0.00）は、3 seed の非単調な 1 セルなので主張に使わない。

## 4. 引用制限

- 「蹴りは死んだユニットを救う」と書かない。復活は起きるが、乱数ラベルの下では生存に届かない。
- 「PM と RL の違いは μ の有無」と一般に書かない。GELU の死については成り立ち、ELU/ReLU の生存については成り立たない（ラベルが要る）。
- 生存数は 3 seed の数えで、中間水準の非単調（GELU 3/2/3、SiLU 1/0/2/3）は荒い。主張は端点（k=0 と k=784）と PM との比較に限る。
- ダイヤルの中間は算術の目標どおりには並ばなかった（G2 の比 0.23/0.29/0.61）。

## 7. 蹴りはなぜ GELU を殺すか（事後・per-unit 再集計・repo `results/perm_dial_rl_0915/posthoc_why_kick_kills_0915.md`）

Issa の問い「谷の奥に蹴り飛ばされて谷から離れた負まで行ってしまうから？」への答え。第 2 層・凍結線 −6.2（|φ′| < Adam の ε）。

| 段 | 何が起きるか | 数字 |
|---|---|---|
| 1 | 蹴りは零平均・sd ≈ 1.7/タスク | k=784 の LR |Δz̄₂| 2.3 対 k=0 の 1.6 |
| 2 | RL の GELU 第 2 層は水面に駐車 | z̄₂ −0.1〜−0.3・|Δ| 0.03/タスク・最深 −2.3。LR は同じ RL で −1.6/タスク沈む |
| 3 | 蹴りで −2 より下に出ると −1/タスクで沈む。**谷の勾配ではなくラベルの押し込み** | 無条件に [−4,−2) で GELU −0.99 対 **LR −1.12**、[−6.2,−4) で −1.11 対 −1.06 |
| 4 | −6.2 は 79% が蹴り一発で跨ぐ | −4.3 → −8.3・直前の典型の 5.7 倍・t_f 中央 11 |
| 5 | その後の −50〜−120 は引きずり | z̄₂ と zstd₂ が同倍率（corr 0.94〜0.97）・倍率 5.7〜13.5 = 第 1 層の生き残り 3〜8 個の z̄₁ が 6.4→40 / 4.9→68 に育つ倍率 |
| 6 | 復活は線の近くでのみ | 98〜248/300 が一度は解凍・最後の解凍 t≈11〜60・t150 は 300/300 凍結・距離は動きの 30 倍 |

直感との照合: 「蹴り飛ばされて」○、「谷の奥へ引かれて」×（LR 対照）、「谷から離れた負へ」○だが凍った後の引きずり、「生き返れない」線の近くでは戻るが運ばれる。
残る交絡: 段 2 の駐車が谷の復元か第 1 層の凍結（a₁ 固定）か。第 1 層だけ leaky の EL 型で GELU 第 2 層が RL で駐車するかを見れば分かる。

**§7 の訂正（同日・再分解）**: Δz̄₂ を引きずり分（z̄₂ × zstd₂ の伸び）と学習分に割ると、段 3 の「LR と同じ速さ＝ラベルの押し込み」は中身が違った。[−4,−2) で LR は −1.12 = **−0.79 学習** − 0.33 引きずり、蹴られた GELU は −0.99 = −0.29 学習 **−0.69 引きずり**。段 2 の駐車は、RL の GELU の第 1 層が t10 で凍結 100/100・正側ユニット 0 になり、第 2 層に入力の変化が来ないこと（学習 −0.01・引きずり 0.00）で大部分説明できる。**蹴りの作用点は第 1 層**で、第 1 層を生かし（t10 の凍結 21/100）、育つ a₁（正側 z̄₁ 4.5 → t50 で 35）が第 2 層を上では学習で押し（[1,3) で −1.79）、下では引きずる。~~同じ水面の駐車が ReLU では死・GELU では生なのは、z̄₂ ≈ 0⁻ のゲートが ReLU 0、GELU ≈ 0.4 だから。~~ **撤回（Issa の指摘）**: 差は第 1 層にある。ReLU の第 1 層は全標本でゲート 0 で a₁ ≡ 0、第 2 層は zstd 0.000 の定数なので第 2 層のゲートに依らず床。GELU の第 1 層は標本の 18% → 1% を通し続け、第 2 層は zstd 0.28 → 0.96 で入力の違いを運ぶ。ただし GELU も train 精度 0.55 → 0.20（LR 0.73）で「生」は言い過ぎ。「第 2 層に入力の変化がほとんど来ない」も「LR の 1/7 しか来ない」に直す。
