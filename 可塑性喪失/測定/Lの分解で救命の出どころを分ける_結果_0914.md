## 0. 一行

**L2 の罰則を同じ λ のまま「中心化した W̃ の減衰（l2wt）」と「行平均・bias・W3 の減衰（l2rest）」に厳密に割った。**
- **leaky では l2wt だけで LoP の 98% が消え（税 −0.8 pt）、l2rest だけでは参照より悪化する（`WT_SUFFICES`）。**
- **ReLU ではどちらの半分も単独では救命しない（`MIXED`）。** l2wt は死んだユニットの重みを消して崩落を早める副作用がある（HARMFUL）。l2rest は崩落を t5–t10 まで遅らせるだけ。

「W の大きさを soft に規制すれば LoP は消える」は leaky では成り立ち、ReLU では L2 の両方の半分がそろって初めて成り立つ。

## 1. 分解

W_i = W̃_i + m_i·1、W̃_i ⊥ 1 なので、λΣ‖θ‖² ＝ **λΣ‖W̃_i‖²**（l2wt） ＋ **λ[Σ d·m_i² ＋ ‖b‖² ＋ ‖W3‖² ＋ ‖b3‖²]**（l2rest）。

勾配は l2wt が W1・W2 に 2λ(W − m·1)、l2rest が W1・W2 に 2λm·1、bias・W3・b3 に 2λp。和は l2 の 2λθ に一致する（検査 S2）。{ref, l2wt, l2rest, l2} が 2×2 になる。

- **R l2wt は死んだユニットの W̃ を消す**。
  - 死んだユニットには CE の勾配が来ないので、結合型の減衰（Adam の座標ごとの正規化を通る）が W̃ を 0 に引く。
  - bias と行平均は自由なので、死んだまま戻らない。L2 は bias と行平均も縮めるので、この組み合わせにならない。
  - [[Wの蓄積を止めれば時間劣化は消えるか_結果_0914]] の R cap2（task 1 に 57% 死亡）と同じ向き。
- **l2rest では規模が隠れ層の W̃ へ逃げる**。
  - W3・bias・行平均を小さく保つと、W̃1 が参照より速く伸びる（R ×6・LR ×15）。
  - 行平均と bias がほぼ 0 なのに、前活性は参照より深く沈む（z̄1 −30〜−34）。この沈下は明度チャネル m·Σx ではなく、W̃ そのもの（平均画像への射影）を通っていると読める（未検定）。
- **LR l2wt は ‖W3‖ が 147 まで伸び、第 2 層が負側に入っても（mob2 0.10）劣化しない**。前の走で上限腕の残りの劣化と同時に見えた「W3 の成長・第 2 層の沈下」は、それだけでは劣化を起こさない。

## 5. 読み（spec §5.2 の型の表の範囲内）

1. **leaky（`WT_SUFFICES`）**: L2 の LoP 除去は、**中心化した W̃ の soft な減衰**で足りる。行平均・bias・W3 の減衰は不要で、それだけを掛けると W̃ の伸びが速まって LoP が悪化する。
   - 硬い上限 cap2（ρ 0.93・A(1) が l2 より −3.9 pt）より除去が多く、税は小さい（−0.8 pt）。前の走の cap2 の税と残りの一部は、射影そのものの副作用だったと読める（腕をまたいだ比較）。
   - **前の走の Q1（蓄積停止 ρ 0.79）と合わせると、leaky の時間劣化は主に隠れ層 W̃ の大きさを通っており、L2 もそこを通して効いている**（2 つの走を合わせた読み）。
2. **ReLU（`MIXED`）**: この λ では、どちらの半分も単独で L2 の救命を再現しない。
   - l2wt は HARMFUL なので、「ReLU では W̃ の大きさはレバーでない」とは読まない（spec §5.1）。
   - l2rest は崩落を t5–t10 まで遅らせるが、救わない。L2 の救命は、2 つの半分の組み合わせ（W̃ の減衰と bias・行平均の減衰が同時にあること）から来ている可能性が高いが、登録した型では BOTH_NEEDED に当たらない（l2rest が PARTIAL のため）。

## 6. 事前予測（spec §7・Claude）の照合

| 項目 | 予測 | 結果 |
|---|---|---|
| R の型 | REST_SUFFICES 40%（MIXED 20%） | × MIXED |
| R l2wt | NOT_LEVER 45% | ○（ただし +HARMFUL） |
| R l2rest | SUFFICIENT 50% | × PARTIAL |
| LR の型 | MIXED 40%／WT_SUFFICES 35% | △ WT_SUFFICES |
| LR l2wt | SUFFICIENT 55% | ○ |
| LR l2rest | PARTIAL 50% | × NOT_LEVER（ρ < 0） |
| l2wt の副作用ガード通過（両 act） | 85% | × R で HARMFUL |
| REUSE_OK | 90% | ○ |

R の予測の根拠（「R の崩落は bias・行平均の沈下が運ぶので l2rest が救う」）は外れた。沈下は bias・行平均を 0 に保っても W̃ を通って起きた。

## 7. 引用の限定

- **「L2 は W̃ の減衰で効く」を活性化を跨いで書かない。** leaky は WT_SUFFICES、ReLU は MIXED。
- **R l2wt の NOT_LEVER は HARMFUL つき。** 「ReLU では大きさはレバーでない」と書かない。
- §4 の機序（W̃ の消去・W̃ を通る沈下・規模の逃げ）は事後の同時変化。
- 限定: Random Label MNIST・784–100–100–10・Adam lr=1e−3・λ=1e−3（結合型）・400 epoch・50 タスク・seed 0–9・white-san CPU。G は画像固定による正の転移を含む正味。

## 8. 未解決（自動では起案しない）

1. ReLU で救命に要る最小の組み合わせ。候補は「W̃ の減衰 ＋ bias の減衰だけ」と、W3 の寄与。
2. l2wt の副作用は結合型 L2 に固有か。decoupled weight decay（AdamW 型）で W̃ だけ減衰させる腕で分けられる。
3. λ 依存と、50 タスクより先。
4. l2rest の沈下が W̃ の平均画像方向の成分で起きているかの直接測定。
