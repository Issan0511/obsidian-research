## 0. 一行

同じ seed・同じ課題列で 10 本の網を比べた。ReLU（C3）と SiLU の網で、沈んで死ぬのは読み出しに最も近いゲート層（第 3 層）だった。SiLU ではその層が正の側へ逃げ、沈降は 1 つ手前の第 2 層へ移った。SiLU の網は 50 課題では学ぶ力を保ち、課題 60〜100 で第 2 層が死ぬのと同時に失った [測定・1 seed]。

言葉の約束：μ/σ は unit の前活性の平均を幅で割った値（相対位置）。φ′ は活性化の傾き（局所応答）。担い手は FFN の入力のトークン平均 ȳ（全トークンに共通な向き）。fresh gap は本体 − 新品のオンライン超過損失で、負なら本体のほうが学べている。

## 4. 機構（測ったこと）

### 4.1 共通の書き込みは bias の代わり

β も bias も無い土台では、unit のしきい値は μ_i = w_i·ȳ しかない [恒等式]。網は、上流の FFN が書いた全トークン共通のベクトルを原料にしてしきい値を作っていた。FFN の出力から共通成分だけを消す（計算はそのまま）と、損失が壊れる [測定]。

| 共通成分だけ消したときの損失の増え方（課題 50） | FFN0 | FFN1 | FFN2 | FFN3 |
| -- | -- | -- | -- | -- |
| SiLU | +3.6 | +0.6 | +8.2 | +0.7 |
| C3 | +7.0 | +2.0 | +6.9 | +0.6 |
| KKT1 | +5.8 | +4.2 | +2.4 | +0.2 |

中心化の腕（C3H など）が学ぶ力を落としたこと、β の腕で沈みが消えたことは、どちらもこの原料で説明がつく [読み]。中心化は原料を取り上げ、β は原料を要らなくする。

### 4.2 担い手は網が作るので、固定ではない

μ/σ の変化を、自分の重み・上流の平均 ȳ・上流の分散だけを替えた計算に割った（入れ替え）。

| 区間 | 実際の動き | 重みだけ替える | 上流の平均だけ | 上流の分散だけ |
| -- | -- | -- | -- | -- |
| C3 第 1 層 課題 10 → 25 | −1.71 → −0.80 | −1.50 | **−1.03** | −1.76 |
| C3 第 2 層 課題 10 → 25 | −1.22 → −0.24 | −0.83 | **−0.24** | −1.21 |
| SiLU 第 3 層 課題 10 → 25 | −1.03 → +0.60 | −0.16 | **+0.11** | −1.12 |

C3 の第 1・2 層が戻ったのも、SiLU の第 3 層が正へ渡ったのも、上流の平均の変化がいちばん大きく運んだ [測定]。上流の分散の低下では説明できない。中央値は足し算にならないので、それぞれの値は向きと大きさの目安である。

### 4.3 第 0 層の担い手は注意 0 の出力

| -- | -- | -- |
| 注意 0 の出力の平均の大きさ | 0.59 → 10.0 | 0.53 → 0.00 → 0.01 |
| 第 0 層の入力の共通成分のうち注意 0 の分 | 74% → 85% | 89% → 0% → 0% |
| LN1（注意の前）の γ | 0.61 → 0.18 | 0.48 → 0.015 → 0.013 |

- SiLU の第 0 層の μ/σ は、LN 後の共通成分の大きさに追随して −0.9〜−1.9 を動いた [測定]。
- C3 ではブロック 0 の注意が課題 10 までに死に、第 0 層には担い手が無い。だから沈めず、μ/σ ≈ 0・幅 0.3 で屈曲点のまわりを動く [測定]。それでも FFN0 は最も重い仕事をしている（計算を消すと +7.0）。ReLU の網がなぜブロック 0 の注意を捨てるのかは分からない。
- SiLU の第 0 層は、課題 45 に 93% の unit が φ′ < 0.1 になっても死んでいない。開くトークンの割合 2〜30% の検出器で、（前の文字, 今の文字）の組に選択的に反応する（上位 5 組の割合 0.13〜0.32、全トークンでは 0.02）。仕事の全部がこの群にある（群ごとに消すと +3.3・+6.7）[測定]。
- 第 0 層の沈みは、課題 1 の更新 200〜400（損失が急に下がる時期）に重みと注意 0 の共同で始まる（別セッションの解析、課題 1 の最初の 500 更新をビット一致で再生。repo の 78890e83）。

### 4.5 第 3 層の線形化と第 2 層の死（SiLU）

| 課題（切替直後の網） | 10 | 25 | 50 | 100 |
| -- | -- | -- | -- | -- |
| FFN3 の出力の平均の大きさ（共通成分の割合） | 119（0.33） | — | 19,433（0.93） | 78,072（0.98） |
| 最終 LN の入力の rms | 31 | 349 | 1,841 | 7,076 |
| 第 3 層の実効の読み出しの利得 | 11.7 | 3.5 | 1.7 | **1.0** |
| 第 3 層に届く誤差の rms | 4.8e−6 | 1.3e−6 | 6.2e−7 | 3.7e−7 |
| 第 2 層に届く誤差の、FFN3 経路あり ÷ 切る | 1.4 倍 | — | 8.2 倍 | **14.8 倍** |

実効の読み出しの利得は、埋め込みの行の大きさ × 最終 LN の γ × ‖W_down3‖ ÷ 最終 LN の入力の rms で測った。

- **第 3 層が正に留まる理由**：正に出た unit は SiLU のほぼ恒等の側で働き、FFN3 は全トークン共通の巨大な定数を書く。最終 LN はそれで割るので、第 3 層が見る実効の読み出しは 12 分の 1 になり、戻す押しが消える [測定]。生の重み（埋め込み・W_down3・最終 LN の γ）は育っているが、分母がもっと速く育つ。
- **第 2 層が死ぬ理由**：線形化した FFN3 は、第 2 層への誤差を増幅する。課題 100 では、FFN3 を通る経路を切ると第 2 層に届く誤差は 15 分の 1 になる。第 2 層への誤差は第 3 層自身への誤差より 13 倍大きい [測定]。同時に第 2 層の担い手も育った（壁 c 4.9 → 12.3、共通成分の割合 0.36 → 0.84、原料は FFN1 の共通の書き込みで、消したときの損失 +0.6 → +6.6）。課題 50 → 100 の第 2 層の沈み −1.77 のうち、上流の平均の分が −0.67、自分の重みの分が −0.28 だった。
- **切替の押しの向きが変わった**：課題 50 の末から課題 51 を 1,500 更新再生すると、第 2 層は切替直後に +0.05（上流 +0.04）浮いて戻った。課題 100 の末から課題 101 を再生すると、−2.41 → −2.70 と沈み（平均の内訳は上流 −0.11）、1,500 更新後も −2.50 のままだった [測定]。
- まとめると、沈降が次のゲート層へ移る機構は「前の層の線形化が、次の層の読み出しを育てる」である [読み]。MLP の深さの登録走でも、2 層の網で第 2 層が正側へ逃げたあと第 1 層が閉じる、同じ並びが出ている（[[深さを変えたSiLU_MLP_層ごとの沈みと担い手_結果_1020]] §4b）。

### 4.6 KKT1 の幅の爆発は LN の γ が運ぶ

- 前活性の幅を ‖w‖ × γ × 揃い に分けると、差を運ぶのは γ だった。深い層の γ は KKT1 で 9.8〜12.2、C3（seed 0）で 2.2〜2.5 [測定]。
- γ は KKT1 で課題数に比例して伸びた（第 2 層で 2.0 → 4.9 → 9.8）。符号がでたらめなら ‖γ‖² は観測の 0.3% 以下にしかならない。
- 課題 25 の末から再生すると、切替直後 100〜300 更新で深い層の γ の座標の 72〜75% が外向きに動いた。切替なしでは 0.50〜0.53 で、α を凍結しても変わらなかった [測定]。
- 読みは「新しい課題で出力の尺度を上げると古い残差の内容を上書きでき、それ自体が損失を下げるので尺度の勾配の符号がそろう。Adam はそれを lr の歩幅で積み、収束後に戻す力は無い」である。導出は尺度の勾配の符号まで、残りは読み。

### 4.7 β の役（KKT1b3・KKT1beta）

- β は共通入力を打ち消さず、負のしきい値として使われた。課題 50 の第 2 層で、w·β は −0.48σ、w·(γ⊙m̂) は −0.25σ で同じ向き [測定]。
- 残差の共通成分の割合は 0.04 / 0.14（第 2・3 層の入力）で、KKT1 の 0.30 / 0.31 より小さい。
- 幅は止まらない。第 2 層の幅の中央値は 163（KKT1b3）・155（KKT1beta）で、KKT1 の 98 以上。幅の積み上がりそのものは学ぶ力を落とさず、落としていたのは課題 40 の一斉の沈みだった [読み]。

### 4.8 cap は ReLU を救い、φ′ を保たない

- ReLUcap は第 3 層が死なず（φ′ 0.61、μ/σ +0.32）、代わりに第 0・1 層がまばらな形になった。学ぶ力は 6 腕で最良の側 [測定]。
- SiLUcap・GELUcap は、幅が課題 1 の値に固定されたまま μ が負に進み、μ/σ は SiLUcap の第 3 層で −4.0、GELUcap の第 0 層で −8.9 まで深くなった。φ′ はほぼ 0（SiLU は負の傾きの領域に入り平均が −0.02）。それでも学ぶ力は保たれた [測定]。
- cap が効く経路は、応答の維持ではない。

## 6. cap の定義と検査

- unit ごとの幅 s_i = √V_i。V は前活性のバッチ分散の EMA（β 0.01、kune 腕と同じ追跡）。上限 cap_i は課題 1 末の s_i。
- 課題 2 以降、各更新のあとで s_i > cap_i なら up の行 w_i を cap_i/s_i 倍に縮め、V_i も (cap_i/s_i)² 倍に直す。Adam の状態・down・γ には触らない。CUDA グラフの中で行う。
- 検査 6 項目は全部通った（`src/chargpt_cl_1019_cap_checks.py`）。SiLU の φ′ は自動微分と一致、C3 はこのモジュールを通しても本走とビット一致、課題 1 は SiLUcap と SiLU がビット一致、課題 2・3 で s/cap ≤ 1 + 1e−7、cap なしの変異は 1.2 cap を超える、√V と probe の幅の比は 0.91〜0.98。

## 7. 分からないこと

- SiLU の第 3 層が課題 10〜25 に正の側へ渡った理由。運び手（上流の平均の回転と重み）は分かったが、導出は無い。
- ReLU の網がブロック 0 の注意を捨てる理由。
- SiLU の第 2 層が課題 100 以降に正へ逃げるのか、死に切るのか。
- GELU・ReLUcap・GELUcap は 50 課題しか回していない。SiLU と同じ遅れがあるかは不明。
- すべて 1 seed。本走の 10 seed では C3 の Q2 が `MIXED` で、層ごとの戻りは seed で分かれる。
