[[台帳（実効バイアスの縮退）]] §3 の台帳半減期 35 step が正しければ τ=96 で台帳寄与は消えているはずだが、ℓ=2 は −0.24 → −0.16 と **1/3 縮むだけ**。時定数による窓分離が意図どおり働いた証拠は無い。

→ **「主窓の値＝構造側だけの保持」という読みは本走の証拠では支持されない。** spec §4-2（窓の選択は間接的分離であって代数的分離ではない）がそのまま効いた。**R1 が読んでいるものの内訳は未確定。**

## 6. ℓ≥3 は判定に使えない【Claude 監査で追加】

ℓ≥3 は **τ 全域の 3 % でしか CI が 0 を外れない**（ℓ=2 は 97 %）。τ=96–100 の −0.114 は曲線のギザギザの一点で、隣接する τ=81–95 では −0.006。

→ 「ℓ≥3 でも保持がある」「保持は ℓ に依存しない」のいずれも**読めない**。n=26 の問題で、spec §4-5 の予告どおり。R2 の CI も 0 を跨ぐ。**ℓ 依存性は未決。**

## 7. 言えること / 言えないこと

**言える**: condA・std アーム・ℓ=2 において、以前 10⁴ step 占有したタスクへ復帰すると、到達直後の損失が LoP 進行分を補正してなお約 7 % 低い。置換 null（R5）は 0 を中心とし、推定量にバイアスは無い。

**言えない**:

- 内訳（台帳の復元 vs 構造の保持）— §5。スカラー損失では原理的に割れない（`eval_loss_exact` にパターン別残差が無い）
- ℓ 依存性 — §6
- µ との関係 — **単一アームなので µ 水準間比較は原理的に不可**（spec §8）
- [[µ維持の利得_0829]] §4（休眠による保護）— centered アームが要る
