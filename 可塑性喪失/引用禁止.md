## C. 測り方・書き方の禁止

- **「p̂ < 0.05 = dead」は condA では gate が開いたユニットを含む**（`1/32 = 0.031 < 0.05`）。**凍結を主張するときは `p̂ ≡ 0` を使う**
- **正規化量（cos, β）で力学を書かない。** 分母の成長が力に化ける。**生の `x = w·µ̂` で測る**（静的な判定条件は例外 → [[吸収不等式の命題化_0824]] §2）
- **`E[F_gate]` と `E[Δx]` は同じ量ではない。** F 系列を Δ 系列の説明に使わない → [[論点マップ]] §14
- **解析のマスク**: 境界ペアは `(s % T == 0) & (gap == 1) & (s > 0)`。**`s // T` ではタスクが分かれない**
- **µ̂ が動く点（境界）を跨いで cos の増分を比較しない**
- **絶対値の損失をレベル間で比較しない**（無次元化する）
- **A2（`xr_recheck_0827`）の符号は 1000 step 積分の符号**。1 step の増分が対称であることを意味しない
- **A3 は snapshot 走、A1/A2/A4/A5/A6 は logs 走で別 run。** 同一個体の主張として読まない
- **A3（動的修復走）は破壊対照**（G4 発火）。「同大の無方向摂動では改善しない」の対照に使わない
- **A1（動的修復走）はオラクルであって学習手法ではない。** PERSISTENT でも「手法」と書かない
- **A2（動的修復走）は one-shot であり CBP の継続適用ではない**
