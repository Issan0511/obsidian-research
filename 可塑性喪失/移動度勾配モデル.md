>
> **(1) 主予言が「不要」になりました。** 本モデルは「平均力ゼロでも σσ′ で輸送が出る」という筋でしたが、同日の測定で **平均力そのものが位置依存で下向き**であることが分かりました（[[xr分解と生存機構_0822]] §3。最上位帯 −0.02585 対 最下位帯 −0.00039、**66 倍・CI 非重複**）。σσ′ を持ち出す必要がありません。**棄却ではなく不要**。
>
> **(2) §3 の主証拠にヤコビアン交絡があります。** 降下速度 −0.028 / −0.034 / +0.004 は **Δcos の単位**で測られています。`Δcos = [(1 − cos²)/‖w‖]·Δx` で、前の係数は測定量ではなく座標変換のヤコビアン。`(1−cos²)` は当該レンジで 0.91〜0.98 とほぼ平坦ですが `1/‖w‖` は平坦ではなく、[[フレーム前の穴]] §6(b) のとおり ‖w‖ は p̂ と相関します。**発火率の高いユニットほど ‖w‖ が大きければ、同じ `Δx` でも `Δcos` は小さく出る。** −0.028 と −0.034 の差（21%）はこれだけで説明されえます。
>
> **(3) §4「分水嶺の描像が成り立たない」を撤回します。** ゲート前の力に `cos` が入らないのは正しいのですが、`p̂` と `|v|` が位置と相関する以上、**ゲート後の実効ドリフトは位置の関数**です。実測がそれを示しました。位置依存の力は実在します。

## 4. 「分水嶺」の描像について【前半は撤回・後半は維持】

### 撤回した部分

~~恒等式 `F_i^ungate = −2η·v_i·G` の右辺に cos が入らないので、位置の関数として力の符号が決まることはない~~

→ ゲート前の代数としては正しいが、**ゲート後の実効ドリフトは位置の関数**（[[xr分解と生存機構_0822]] §3）。「分水嶺は成り立たない」は誤り。

なお当時挙げた傍証（sign(v) と極の一致率 **0.527**、A2 のラベル差 **≤0.06**、下方クロスの **91–92% が再点灯**・クロス回数**中央値 11 回**）は、「**ユニットを恒久的に二群に分けるラベルは存在しない**」ことの証拠としては有効です。位置依存の力があることとは両立します。

### 維持する部分 — 分水嶺は「振幅の側」に実在する

**cos ≈ −0.20 が線**。ただし「そこから下は下向きに引かれる」ではなく「**そこから下は動けない**」。上下を分ける線ではなく、**動ける領域と動けない領域を分ける線**。

### 語への含意（後-3。**維持**）

「二極」は引力中心を含意するが、ここに引力中心はない。恒等式が言っているのは

> 力場は**ユニット横断で rank-1**（全ユニットの力が一本の線上にある）

で、二極性は「その線の向きが二つある」以上の意味を持たない。**「二極」を「rank-1」と言い換えると、撤回済みの状態レベル二極と読まれる余地が消える。** [[フレーム前の穴]] **後-3** は、書き分けではなく**語の差し替え**で済む可能性がある。

## 5. [[不偏ウォーク仮説]] との判別【両者とも落ちた】

判別に置いていた「保存則テスト」は、cos 基準では成立しません（伊藤項で cos は必ず 0 へ寄る）。`x` 基準に直した測定が [[xr分解と生存機構_0822]] §3 で、結果は両者の共通前提を落としました。
