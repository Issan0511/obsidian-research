## 一行

**平均力がゼロでも輸送は出る。** 歩幅 σ が位置依存なら、駆動雑音が色付き（相関時間 τ を持つ）である限り Stratonovich 側に落ち、`σσ′` に比例した**実在の下向きドリフト**が生じる。向きは移動度が下がる側、つまり −µ̂ 側。

これは「フィット中 99.5% 中和」（[[中和と境界窓]]。ただし §4 は 8/22 に使用停止）と正面から噛み合う。**中和されて平均力が消えていても、輸送は説明できる。**

## 1. 死の機構候補の三択

| | 機構 | 降下速度の p̂ 依存 | 要求するもの |
|---|---|---|---|
| (i) 吸収壁 | 対称ウォーク＋下端で吸収 | 内部では正味ゼロ | 何も |
| (ii) 偏った駆動 | 平均力が下向き × 移動度 | **p̂ に単調増加** | 穴A（rest の偏り）の同定 |
| (iii) **移動度勾配（本ファイル）** | 平均力ゼロ、振幅が位置依存 | **中間 p̂ で最大** | 何も（既存値だけで立つ） |

(i) は P3（単調輸送）と合わない。壁は内部に方向性を作らないため。
(ii) は穴A / 後-1 を主張の前提に抱え込む。

## 2. 成分

1. **平均力はゼロ**（[[不偏ウォーク仮説]] と共通の前提）
2. **歩幅は位置依存** σ(cos) ∝ p̂(cos)。力はゲート越しにしか効かない
3. **駆動雑音は色付き**。相関時間 τ ≈ 5–10 step（[[ロギング走の結果]]・事前登録）が、位置 cos の変化時間尺度（10⁴–10⁵ step）より十分短い

3 が成り立つと Wong–Zakai の意味で Stratonovich 規約が選ばれ、伊藤形に直したときに `½·σσ′` のドリフト項が現れる。σ′ > 0（下に行くほど歩幅が減る）なので**ドリフトは下向き**。

**要点**: これは見かけの効果ではなく実在のドリフトで、**平均力ゼロと両立する**。

## 3. 主予言 — 降下速度は非単調

σσ′ が最大になるのは σ が最も急に変化する帯、つまり**ゲート曲線が最も急な cos ∈ [−0.15, 0) 付近**。

ゲート曲線（[[フレーム前の穴]] §6(a)。`ratchet_log_0819` npz・seed 束ねブートストラップ・**事後計算・未事前登録**）:

| cos 区間 | p̂ 中央値 | 95% CI |
|---|---|---|
| [−0.25, −0.20) | 0.0000 | [0.0000, 0.0000] |
| [−0.20, −0.15) | 0.0031 | [0.0000, 0.0094] |
| [−0.15, −0.10) | 0.0625 | [0.0625, 0.0625] |
| [−0.05, +0.00) | 0.3313 | [0.3219, 0.3406] |
| [+0.15, +0.30) | 0.9125 | [0.8969, 0.9281] |

実測の降下速度（[[整流モデル]] 部品2。Δcos/10k median・**誤差棒なし**）:

| p̂ | 降下速度 |
|---|---|
| p̂ > 0.5 | −0.028 |
| 0.05 < p̂ < 0.5 | **−0.034** |
| p̂ < 0.05 | +0.004 ≈ 0 |

**単調ではなく中間帯が最速。** (ii) なら力 × 移動度なので p̂ > 0.5 が最速のはず。(iii) の予言と向きが合う。

**ただし 3 行に誤差棒が無く、−0.028 と −0.034 の差が有意かは未確認。** [[不偏ウォーク仮説]] §9 の検定 D で同時に付く。

## 4. 「分水嶺」の描像が成り立たない理由（この節はフレーム後-3 に効く）

チャットで出た直感「どこかを境に向かう方向が二分される」は、**位置 cos の関数として平均力の符号が決まる**ことを要求する。しかし恒等式

```
F_i^ungate = −2η · v_i · G
```

の右辺に **cos_i が入っていない**。向きを決めるのは `sign(v_i · G·µ̂)` だけで位置は無関係。cos = +0.8 のユニットと cos = −0.1 のユニットは同じ時刻に同じ向きへ押される。位置が効くのは**ゲートを通した大きさだけ**。

裏づけ:

- sign(v) と極の一致率 **0.527**（偶然水準。[[整流モデル]] 棄却済みリスト）
- A2 のラベル差 **≤0.06** — 早期の極ラベルは最終位置を予言しない
- 生の下方クロスの **91–92% が再点灯**、終端死までのクロス回数**中央値 11 回**（[[死の二経路]] §5）

最後の行が決定的で、**分水嶺があるなら境界を割った個体は吸引域に入って戻れないはず**が、実際には 11 回出入りしている。

### ただし分水嶺は「振幅の側」に実在する

**cos ≈ −0.20 が線**。ただし「そこから下は下向きに引かれる」ではなく「**そこから下は動けない**」。上下を分ける線ではなく、**動ける領域と動けない領域を分ける線**。

→ 直感は当たっていて、分けている量が**力ではなく移動度**だった、という位置関係になる。

### 語への含意

「二極」は引力中心を含意するが、ここに引力中心はない。恒等式が言っているのは

> 力場は**ユニット横断で rank-1**（全ユニットの力が一本の線上にある）

で、二極性は「その線の向きが二つある」以上の意味を持たない。**「二極」を「rank-1」と言い換えると、撤回済みの状態レベル二極と読まれる余地が消える。** [[フレーム前の穴]] **後-3**（「二極」の語の書き分け）は、書き分けではなく**語の差し替え**で済む可能性がある。

## 5. [[不偏ウォーク仮説]] との判別

両者は同じ SDE の別の規約であり、物理的には §2-3（τ の分離）が成り立つかどうかに帰着する。

| | [[不偏ウォーク仮説]]（伊藤） | 本ファイル（Stratonovich） |
|---|---|---|
| 平均力 | ゼロ | ゼロ（同じ） |
| 正味ドリフト | 無し（輸送は見かけ） | **有り**（σσ′ ∝、−µ̂ 向き） |
| **コホート平均 cos** | **保存**（任意抽出定理） | **下がる** |
| 中間帯最速 | 説明する | 説明する |
| 準定常密度 | ∝ σ^(−2) | ∝ σ^(−1) |

**判別 = 保存則テスト**（[[不偏ウォーク仮説]] §9 検定 A）。タスク内・固定コホートで、死者を死亡位置で凍結したままの全体平均 cos が一定かを見る。既存 npz で回る。

**規約の直接検定 = `Var(Δcos)` の p̂ 依存**（同 §9 検定 D）。p̂ ≫ 1/τ で σ ∝ p̂、p̂ ≪ 1/τ で σ ∝ √p̂ になるはずで、τ ≈ 5–10 なら交差は p̂ ≈ 0.1–0.2（cos ≈ −0.10）付近。ゲート曲線の測定点がちょうどそこを挟んでいる。**折れ曲がりが見えれば τ の測定値と独立に整合し、見えなければ本ファイルの描像が崩れる。**

> **検定 A・D の導出はいずれも私（Claude）の計算で検算を経ていない。** 回す前に手で確かめること。

## 7. 穴A / 後-1 との関係

**本モデルが正しければ穴A は解消ではなく不要になる。** 偏った駆動を仮定せずに輸送が出るので、後-1（駆動が self か rest か）が中心主張の前提から外れる。

フレームの語も「整流」より「**移動度勾配による捕捉**」の方が正確になる。整流は「対称な撹拌 × 非対称な拘束」で撹拌の名指しを要求するが（[[フレーム前の穴]] §4）、本モデルは拘束の**勾配**そのものが輸送を作ると言うので、撹拌を名指す必要がない。

> **注意**: [[不偏ウォーク仮説]] の側では逆に、不偏性が主仮説なので穴A / 後-1 が**中心に上がる**。two つの仮説はここで要求が正反対になる。

## 8. 弱点・留保

- **規約依存**。Stratonovich を採る根拠は τ の分離だけで、τ ≈ 5–10 step が本当に位置の時間尺度と分離しているかは未確認（churn の起源が未同定。[[論点マップ]] 未カバーの穴 ④）
- **P3 の帰無が符号置換のみ**なので、(i)(ii)(iii) を分ける検定になっていない。→ [[フレーム前の穴]] **前-3**
- **降下速度の 3 行に誤差棒が無い**。主予言の根拠が有意性未確認の 2 点差に乗っている
- **p̂ は cos だけの関数ではない**（§6 最終行）
- **σσ′ の大きさが輸送を説明するのに足りるかを見積もっていない。** 向きが合っているだけで、量の照合は未着手
- **スコープ**: 引用値は condA・w100・T=1e4・batch=1。condB へ外挿しない
