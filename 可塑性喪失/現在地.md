## 混同しない

- **2 層**は重みの層が 2 つ（1 隠れ層＋読み出し）。本稿の三つの箱は 2 隠れ層の 3 層網。文字 GPT の **2 ブロック**はブロック数（本文の箱）で、4 ブロックは付録。
- **RC**＝乱数ラベル CIFAR、**RM**＝乱数ラベル MNIST、**F51**＝実ラベル CIFAR の 5+1。online 精度は学習中の正解率でテスト汎化精度ではない。窓が違う走の絶対値を並べない。
- **装填**＝課題を学ぶことで切替の押しが作られること（読み出しの整列・κ）、**担い手**＝押しを位置へ運ぶ経路（入力平均・bias・動く上流）。語の定義は [[用語と記号]] の 1022 の節。
- 登録走・事後の介入・事後の解析・1 seed の下見を同じ格にしない。「読み」と「決定」を分ける。登録判定は run id と結果ノートで引く。
