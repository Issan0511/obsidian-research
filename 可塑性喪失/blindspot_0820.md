## 3. 2×2 分解（力場の周期表）

**現状**: E[δx] = E[δ]µ + Cov(δ,x)（向きによる分割・理論 v2）と δ = self + rest（作者による分割・ratchet_log E1）を、**一度も交差させていない**。

| | µ 方向 | Cov |
|---|---|---|
| **self** | 税の潮流射影（符号安定率 1.000） | Stein で自分の軸を向く成分。**task_080 の p 符号問題の住人** |
| **rest** | 古典的な潮流（符号は E[δ_rest] 依存） | タスク駆動の回転（aniso_perp の Σa） |

**懸念（これが本体）**: condA は入力が非負なので E[a_i·x] が µ̂ とほぼ平行になり、**「潮流」と「税」が方向として縮退している**。

**注意**: これは「間違っている」ではなく「現状のデータでは区別できていない」。

**8/20 夕の追記**: [[中和と境界窓]] で「駆動は rest」と分かったので、この分解の優先度は上がった。

**8/22 追記**: 「駆動は rest」の根拠だった [[中和と境界窓]] §4 が使用停止になり、さらに x 水準別の分解で **中和率が位置に依らず平坦**（0.990〜0.999）、上へ行くと self も rest もほぼ同率で伸びる（14.68 倍 / 14.26 倍）と判明した（[[xr分解と生存機構_0822]] §4）。**「self か rest か」という二択自体が成立しない。** 効いているのは `|self|/|rest|` が x ≈ −0.1 で 1 を跨ぐこと。§3 の問いは「どちらが駆動か」ではなく「**比が 1 を跨ぐ位置は何が決めるか**」に書き換わる。

**検証案**: 4 セル分解には probe 拡張の再計装リプレイが要る（→ §13）。

**補足**: self が µ̂ 方向しか向いていなければ self×Cov セルは空で実質2分類になる。それはそれで「税は純粋に潮流方向の力である」という発見。

## 4. 停止条件の残り候補（teachw 後）

teachw により「需要が決める」は棄却済み（→ `context_0820.md` §2）。残る候補:

- **(a) 罠の幾何**: 動く罠の共通部分に落ちなかった者だけが残る。生存者数は入力統計と消灯点で決まる定数
- **(b) 低次成分の稼ぎ**: 生存者は稼いでいるが、稼ぎ先は教師複雑度に依存しない成分（µ 方向・定数項まわり）のみ

判別は `spec_surv_hist_0820.md` の T1/T2/E2。**さらに、alive は 1M でも下げ止まっていない**ので、「停止条件」という枠組み自体が正しいかも未確定。

**8/20 夕の追記**: 候補 (b) は Glorot の言葉では「速いチャンネルの住人だけが境界を生き延びる」。

**8/22 追記**: **(a) 側に大きく傾いた。** 生存者は `r`（µ̂ 直交成分）が大きく（4.161 対 死者 2.632）、`|v|` はほぼ同じ、`|x|` はむしろ小さい（[[xr分解と生存機構_0822]] §5・§7）。「稼いでいるから生きている」ではなく「**µ̂ 軸から降りているから生きている**」。ただし `r` の成長には**正のフィードバック**があり（太い個体ほど 7 倍速く太る、同 §6）、単純な「罠の幾何が決める定数」でもない。**寿命は初期値でも需要でもなく、`r` の成長競争で決まる**という第三の候補 (c) を立てる必要がある。

**接続**: (a) が正しければ、生存者は閾値際の滞留者 = 未計測ギャップの「ゾンビ（線形化）ユニット」の正体候補になる。実測の生存者 cos は **−0.076**（消灯線 −0.20 の直上）で、この描像と一致する。

## 5. 動く罠（吸収はタスクごと）

µ̂ は境界で跳ぶので、吸収は「そのタスクの入力統計の下で」しか成立しない。P4-move（凍結区間の 76.5% で ‖w‖ が動く）はその実測。

**8/20 夕の追記**: P4-move の**機構は台帳で説明できた**（[[台帳（実効バイアスの縮退）]] §4）。

**主張候補**: 恒久的に死ねる領域は**全タスク変種の罠の共通部分**という幾何的対象で、タスク間の µ̂ 分散がその大きさを決める。

**予言**: µ̂ の散らばりを増やすと終端 dead_frac は下がり、ゾンビの出入りが増える。

**8/22 追記 — コストが激減した**: condA の死は**閉形式 1 本**で書けることを確認した（10 seed × 100 unit で 32 パターン列挙と厳密一致）:

```
dead(flip) ⟺ flip·w[1:15] + b + Σ_{j∈rnd} max(w_j, 0) ≤ 0
```

各タスク変種は**線形制約 1 本**であり、共通部分は半空間の交わり。**列挙不要で任意の変種集合について判定できる。** → [[命題リスト]] Q11 / [[フレーム前の穴]] 前-4 が安く回る。詳細は [[xr分解と生存機構_0822]] §9。

## 6. 深さ（多層）

層 ℓ の出力が層 ℓ+1 の入力なので、上流の死と整列が下流の µ・Σ を作り変える。「入力は非負」という前提条件は ReLU が自己生成しており、カスケードの前提は揃っているのに、カスケードの力学は誰も書いていない。

論文スコープを 2 層に限定するのは妥当だが、**確認してから限定する**のと確認せずに限定するのでは査読での防御力が違う。2 隠れ層の最小確認。→ 具体形は §10。

## 7. 小さいもの

**一歩踏み越え仮説**: lr=0.01・batch=1 では死の直前の最終ステップが |v_i|·a_i に比例する大きな一跳びになる。堆積帯（−0.325）が消灯点（−0.15）より深い理由の対抗仮説（対 匍匐仮説）。**8/22: 対抗仮説が優勢になった** — 深さは「µ̂ の振れ幅ぶんの余裕」で説明でき、復活に要する flip 数で層別すると cos が −0.266 / −0.341 / −0.434 と単調（[[xr分解と生存機構_0822]] §9）。さらに死の直前 3 タスクで x はむしろ**戻る**ので、大きな一跳びの描像とは合わない（同 §5）。

**瞬時力場のランク**: F_i = −2η·v_i·G より、任意の瞬間に全ユニットが感じる力は共通の1方向（の ±v_i 倍）しかない。教師をどれだけ複雑にしても**瞬時の力場の向きの数は増えない**ので、動員が起きるとすれば G の時間変化を通じてのみ。これが正しければ teachw の非感応は実験結果ではなく構造からの帰結になる。測るべき量は G の向きの実効ランク（ratchet_log に G の時系列あり、H=100 のみ計算可能）。

## 8. 活性化依存性: leaky は上向きの復元力を持つ（§1 から分離・2026-08-20）

**由来**: [[自己項の恒等式]] §3 の反例走査。恒等式は活性化を問わず成立するが、**符号の片側性は σ·σ' ≥ 0 を要求する**。ReLU と sigmoid は満たし、LeakyReLU (α>0) は z<0 で σσ' = α²z < 0 になって満たさない。

**主張候補**: leaky ではゲート下側に入ったユニットに、ReLU には存在しない**上向きの自己復元力**が働く（数値確認: 正符号率 0.212、α=0.1）。

**なぜ blindspot 行きか**: 「それが実際に堆積を止めるか」は未測定。**8/22 追記**: leaky の効果は「税の符号を変える」よりも「**σ の下限を与えて `r` の成長を全域で許す**」側かもしれない。α 単調（`methods_sde_0813`）は後者の読みでも出る。α スイープを回すなら `r` の成長率も同時に測ること。

**検証案**: α スイープ（α ∈ {0, 0.01, 0.1}）。`nets.VecMLP` は `act_alpha` を既に持っているので実装コストはゼロ。**ただし新規学習走が要る。**

**注意**: tanh は σ が負値を取るので σσ' ≥ 0 を満たさない。§1 旧記述の「tanh では出力ゼロ近傍が最も感度が高い」は活性化の感度の話で、符号条件とは別の論点。

## 10. 凍結座標と上流死の対応（8/20 夕・多層への橋）

タスク内で入力が 0 の flip 座標は勾配が恒等 0 で bitwise 凍結する。これは**ユニットの死とは別物**（環境が決める・可逆・他律 vs 自分の重みが決める・不可逆・自律）。

ただし**層をまたぐと厳密な対応になる**: 1 層目のユニットが死ぬと出力が恒等 0 → 2 層目から見てその入力座標は**永久凍結された座標**。

**主張候補**: 上流が死ぬたびに下流は永久凍結座標を 1 本ずつ増やす。これが層を伝播する LoP の機構になる。

**8/22 追記**: §15 の「入力スパンがランクを決める」と直結する。下流の入力スパンが痩せることそのものが、下流の重みの実効ランクを縛る。

**検証案**: 2 隠れ層の最小確認（§6 と共通）。

## 14. µ̂ の跳び幅ダイヤル（2026-08-22・新規）

**由来**: [[xr分解と生存機構_0822]] §9。死者の相互整列（符号付き cos +0.18）が、変種を重ねても**ほとんど増えない**（浅い +0.182 → 深い +0.200）ことの説明。

**機構**: 恒久死は「訪れた全変種で線の下」＝**半空間の交わり**。ところが condA では連続する µ̂ の重なりが **0.9748 ± 0.0017**（約 13°）と大きく、**制約の法線がほぼ平行**。ほぼ平行な半空間をいくら重ねても、交わりは「細い錐」にならず「同じ向きに深い半空間」になる。削られるのは 1 方向の深さだけで、横 19 次元の立体角は据え置き。

**主張候補**: **dead の相互整列度は µ̂ の跳び幅で制御できる。** µ̂ が毎回大きく跳ぶ環境（数ビット同時 flip、あるいは flip 座標の再抽選）なら法線がばらけ、交わりが本当に細い錐になって、深い死者は強く整列するはず。

**なぜ効くか**: 「dead が揃う」という現象が**環境の幾何の関数**であることを示せれば、Joudaki のクローン多様体との線引きが機構レベルで書ける。彼らの整列は等式多様体、こちらは不等式の交わりで、**後者は法線の散らばりで整列度が連続的に変わる**。

**検証案**: 1 タスクあたりの flip ビット数 k ∈ {1, 3, 5} を振り、(i) 連続 µ̂ の重なり、(ii) dead のペア符号付き cos、(iii) 終端 dead_frac を測る。**新規学習走が要る**ので、8/21 の線引きが決まるまで起案しない。

**安い先行確認（再学習不要）**: 既存 checkpoint で、仮想的に k ビット同時反転した変種集合について閉形式（§5）で死判定し、交わりの立体角の縮み方を k 別に計算できる。

## 15. 入力スパンがランクを決める（2026-08-22・新規）

**由来**: [[xr分解と生存機構_0822]] §8。生存者スパンの圧縮（eff_rank 7.53 対 ランダム基準 10.80）が、罠とは**別起源**であることの発見。

**機構**: SGD の更新は毎 step `Δw ∝ x_t` の rank-1 なので、重みは**訪れた入力の張る空間の中でしか動けない**。condA の 1 タスク内の入力は「flip 15 bit 固定 + ランダム 5 bit」なので、**タスク内の入力スパンは高々 6 次元**。

実測（alive、12 本）:

| | flip 側 15 次元 | ランダム側 5 次元 |
|---|---|---|
| 等方基準の配分 | 0.75 | 0.25 |
| **実測配分** | **0.223** | **0.777** |
| ブロック内 eff_rank | 7.76 / 15（基準 10.24） | 4.28 / 5（基準 4.66） |

**完全に逆転している。** 毎 step 叩かれるランダム 5 次元に 8 割のエネルギーが乗り、ほぼ満杯。

**主張候補**: 低ランク化の一部は、力場でも罠でもなく**入力の被覆の粗さ**から出る。continual learning では各タスクの入力スパンが全空間より狭いので、これは LoP に一般的に効く可能性がある。

**なぜ Q0 に効くか**: 「ランク低下は選好ではなく吸収的上限」という現在の論法に、**第三の候補（入力被覆）**が加わる。線引きの文でこれを潰しておかないと、「あなたの低ランクは単に入力が低次元なだけでは」と言われる。逆に、**dead 経由のランク低下と入力被覆によるランク低下を分離できれば、それ自体が主張の強化になる**。

**検証案（再学習不要）**: (i) 初期化時の重み行列で同じブロック分解を計算し、逆転が学習の産物であることを確認、(ii) dead 群でも同じ分解を出して群間差を見る、(iii) `eff_rank_W`（全ユニット）が 18.7 → 15.2 とほぼ動かないこと（[[フレーム前の穴]] §7）との整合を確認。

**留保**: 上の数値は 1 スナップショット（`posreset_0819` の `A_w100_cont`、step 500k）・alive 平均 12 本・**事後計算で未事前登録**。**condA の入力幾何に固有**なので condB へ外挿しない。「ランダム側が flip 側より育つ」機構（flip 側は µ̂ 経由で復元力を受け、ランダム側は受けない）は**私の推測で未検証**。
