## 3. 2×2 分解（力場の周期表）

**現状**: E[δx] = E[δ]µ + Cov(δ,x)（向きによる分割・理論 v2）と δ = self + rest（作者による分割・ratchet_log E1）を、**一度も交差させていない**。

| | µ 方向 | Cov |
|---|---|---|
| **self** | 税の潮流射影（符号安定率 1.000） | Stein で自分の軸を向く成分。**task_080 の p 符号問題の住人** |
| **rest** | 古典的な潮流（符号は E[δ_rest] 依存） | タスク駆動の回転（aniso_perp の Σa） |

**懸念（これが本体）**: condA は入力が非負なので E[a_i·x] が µ̂ とほぼ平行になり、**「潮流」と「税」が方向として縮退している**。canvas_0819 の |cos(G, µ̂)| = 0.966–0.995 は両者を混ぜて測っている可能性があり、「µ は増幅因子」という命題の証拠の一部が実は税の証拠かもしれない。

**注意**: これは「間違っている」ではなく「現状のデータでは区別できていない」。

**8/20 夕の追記**: [[中和と境界窓]] で「駆動は rest」と分かったので、この分解の優先度は上がった。**rest×µ セルが輸送の主役**という仮説を直接測ることになる。

**検証案**: (i) 4 セル分解の時系列は ratchet_log の保存データ（G, F_self, F_rest, flip_state）から追加実験なしで計算可能、(ii) 方向の縮退を解くには Σ の異方性でユニット方向と µ を引き剥がす（aniso 系の資産が使える）。

**補足**: self が µ̂ 方向しか向いていなければ self×Cov セルは空で実質2分類になる。それはそれで「税は純粋に潮流方向の力である」という発見。

## 4. 停止条件の残り候補（teachw 後）

teachw により「需要が決める」は棄却済み（→ `context_0820.md` §2）。残る候補:

- **(a) 罠の幾何**: 動く罠の共通部分に落ちなかった者だけが残る。生存者数は入力統計と消灯点で決まる定数
- **(b) 低次成分の稼ぎ**: 生存者は稼いでいるが、稼ぎ先は教師複雑度に依存しない成分（µ 方向・定数項まわり）のみ。これなら「稼ぎ説なのに H 非感応」が両立する

判別は `spec_surv_hist_0820.md` の T1/T2/E2。**さらに、alive は 1M でも下げ止まっていない**（context §5-1）ので、「停止条件」という枠組み自体が正しいかも未確定。T2（持続性）がこれを兼ねる。

**8/20 夕の追記**: 候補 (b) は Glorot の言葉では「**速いチャンネルの住人だけが境界を生き延びる**」（[[台帳（実効バイアスの縮退）]] §3）。速いチャンネル＝台帳＝実効バイアス 1 自由度は教師複雑度に依存しないので、teachw の H 非感応とも整合する。**別方向から同じ実験を指してきた**ことになり、(b) の優先度が上がった。

**接続**: (a) が正しければ、生存者は閾値際の滞留者 = 未計測ギャップの「ゾンビ（線形化）ユニット」の正体候補になり、探すべき場所（閾値近傍の p̂ 分布）が先に決まる。

## 5. 動く罠（吸収はタスクごと）

µ̂ は境界で跳ぶので、吸収は「そのタスクの入力統計の下で」しか成立しない。P4-move（凍結区間の 76.5% で ‖w‖ が動く）はその実測。

**8/20 夕の追記**: P4-move の**機構は台帳で説明できた**（[[台帳（実効バイアスの縮退）]] §4）。再露出とは、凍結座標の記帳 ±w_ik が実効バイアスに復帰することそのもの。スモークで dead の 16.5%/境界 が再点灯。

**主張候補**: 恒久的に死ねる領域は**全タスク変種の罠の共通部分**という幾何的対象で、タスク間の µ̂ 分散がその大きさを決める。

**予言**: µ̂ の散らばりを増やすと終端 dead_frac は下がり、ゾンビの出入りが増える。

**位置づけ**: PB-5 の但し書き「固定入力統計の下で」を、制約から**正の理論対象**へ反転させる。condA なら 32 パターン × タスク変種でゲート集合を厳密計算できる。

## 6. 深さ（多層）

層 ℓ の出力が層 ℓ+1 の入力なので、上流の死と整列が下流の µ・Σ を作り変える。「入力は非負」という前提条件は ReLU が自己生成しており、カスケードの前提は揃っているのに、カスケードの力学は誰も書いていない。

論文スコープを 2 層に限定するのは妥当だが、**確認してから限定する**のと確認せずに限定するのでは査読での防御力が違う。2 隠れ層の最小確認。→ 具体形は §10。

## 7. 小さいもの

**一歩踏み越え仮説**: lr=0.01・batch=1 では死の直前の最終ステップが |v_i|·a_i に比例する大きな一跳びになる。堆積帯（−0.325）が消灯点（−0.15）より深い理由の対抗仮説（対 匍匐仮説）。最終ステップ幅と終端深度の相関で既存ログから判別できる。**8/20 夕: 死の二経路（Q16）の分離がこれの前提になる。**

**瞬時力場のランク**: F_i = −2η·v_i·G より、任意の瞬間に全ユニットが感じる力は共通の1方向（の ±v_i 倍）しかない。教師をどれだけ複雑にしても**瞬時の力場の向きの数は増えない**ので、動員が起きるとすれば G の時間変化を通じてのみ。これが正しければ teachw の非感応は実験結果ではなく構造からの帰結になる。測るべき量は G の向きの実効ランク（ratchet_log に G の時系列あり、H=100 のみ計算可能）。

## 8. 活性化依存性: leaky は上向きの復元力を持つ（§1 から分離・2026-08-20）

**由来**: [[自己項の恒等式]] §3 の反例走査。恒等式は活性化を問わず成立するが、**符号の片側性は σ·σ' ≥ 0 を要求する**。ReLU と sigmoid は満たし、LeakyReLU (α>0) は z<0 で σσ' = α²z < 0 になって満たさない。

**主張候補**: leaky ではゲート下側に入ったユニットに、ReLU には存在しない**上向き（出力を大きくする向き）の自己復元力**が働く。condA でも F_self > 0 が実在する（数値確認: 正符号率 0.212、α=0.1）。leaky が dying ReLU を緩和する既知の事実に、恒等式からの独立な機構説明を与える。

**なぜ blindspot 行きか**: 符号が壊れることの数値確認は済んでいるが、「それが実際に堆積を止めるか」は未測定。復元力があっても rest 由来の輸送が勝てば死ぬ。**8/20 夕にこの懸念は強まった**（[[中和と境界窓]]: そもそも輸送の主役が rest なので、税側の符号を変えても効かない可能性がある）。

**検証案**: α スイープ（α ∈ {0, 0.01, 0.1}）で dead_frac と F_self の符号分布を同時に測る。`nets.VecMLP` は `act_alpha` を既に持っているので実装コストはゼロ。**ただし新規学習走が要る**ので、[[命題リスト]] の穴を閉じるかを先に判断すること。

**注意**: tanh は σ が負値を取るので σσ' ≥ 0 を満たさない（§1 旧記述の「tanh では出力ゼロ近傍が最も感度が高い」は活性化の感度の話で、符号条件とは別の論点）。両者を混ぜないこと。

## 9. Glorot 再演仮説（8/20 夕・一部棄却済み）

**由来**: Glorot & Bengio 2010 §3 の「出力層は最初、上位の隠れ活性 h より（速く学習される）バイアス b に頼る」「h が予測に役立たないうちは誤差勾配は Wh を 0 へ押す」という記述。

**残った実測**: 二時定数が実在する。残差を平均成分（バイアスで直せる）と構造成分（W, v が要る）に分けると、半減時間が **35 step vs 1200 step**。初期フィットでも境界回復でも同じ形。→ [[台帳（実効バイアスの縮退）]] §3

**棄却された読み**: 「Glorot の抑制（＝税）が崩壊を進めている」。[[中和と境界窓]] §4 の台帳テストで否定された。

**残った位置づけ**: Q0 の関連研究として引ける。ただし「同じ機構」ではなく「**同じ過渡現象の器。ただし駆動の中身は未同定で、彼らの抑制説はこの系では棄却**」という形で。線引きは「過渡 vs 吸収」「単発 vs 毎境界の再演」。sigmoid では税の符号が保たれる（[[自己項の恒等式]] §3 の C2b）ことが、飽和 vs 吸収の対比の数値側になる。

**未監査の導出スケッチ**（外部に出さないこと）: 速いチャンネルが仕事を終えると E[r_i] ≈ 0。ユニット i の特徴が新しい標的と無相関なら E[r_i·gate_i·(x·µ̂)] ≈ E[r_i]E[gate_i(x·µ̂)] ≈ 0 で、残るのは F_self だけ。**この積の分解が近似で、しかも上の台帳テストと整合しない**（実際には rest が主犯）。無相関の仮定が成り立っていない可能性が高い。

## 10. 凍結座標と上流死の対応（8/20 夕・多層への橋）

タスク内で入力が 0 の flip 座標は勾配が恒等 0 で bitwise 凍結する（[[台帳（実効バイアスの縮退）]] §1）。これは**ユニットの死とは別物**（環境が決める・可逆・他律 vs 自分の重みが決める・不可逆・自律）。

ただし**層をまたぐと厳密な対応になる**: 1 層目のユニットが死ぬと出力が恒等 0 → 2 層目から見てその入力座標は**永久凍結された座標**。環境による凍結は境界で解除されるが、上流の死による凍結は解除されない。

**主張候補**: 上流が死ぬたびに下流は永久凍結座標を 1 本ずつ増やす。下流から見れば入力次元が減っていくのと同じで、これが層を伝播する LoP の機構になる。

**検証案**: 2 隠れ層の最小確認（§6 と共通）。1 層目の dead_frac と 2 層目の実効入力次元の対応を測る。

## 11. 教師の粗さダイヤル（8/20 夕・新規）

**由来**: [[中和と境界窓]] §3。境界での残差の跳びは、学習器のずれ（台帳の組み替え）ではなく**標的の移動**が主因（寄与 2/3）で、corr(y旧, y新) = 0.17–0.48 だった。

**主張候補**: 境界衝撃の大きさは教師の**超立方体上での粗さ**が決める。滑らかな教師（1 ビット反転で出力が大きく変わらない教師）なら残差の跳びが小さく、中和が壊れず、崩壊も弱まる。

**なぜ効くか**: teachw（教師 LTU 幅）とは**独立なダイヤル**になる。teachw は「需要」を振ったが、これは「タスク間の連続性」を振る。LoP 文献の「gradual vs abrupt」（Liu & Mou 2026）と直接つながる軸でもある。

**検証案**: 教師を LTU から、1 ビット反転に対する感度を制御できる族（例: 低次フーリエ／低次多項式閾値）に差し替え、corr(y旧, y新) を測りながら dead_frac を追う。**新規学習走が要る**。

**留保**: corr 0.17–0.48 という値自体が LTU 幅 100・β=0.7 固定のスモークで、教師パラメータ依存。まず既存の teachw アーム（H_T ∈ {1,2,4,8,32,100}）で corr を事後計算するのが安い（**再学習不要**）。H が小さいほど滑らかなはずで、T4 傍証（H=1,2 で alive が高い）の別説明になりうる。

## 13. §3 のコスト表示の訂正（2026-08-21b）

**§3 の検証案 (i)「4 セル分解の時系列は ratchet_log の保存データ（G, F_self, F_rest, flip_state）から追加実験なしで計算可能」は誤り。**

`results/ratchet_log_0819/logs/*.npz` を確認した結果:

| 保存されているもの | 対象 |
|---|---|
| `G`（20 次元）・`E_delta`・`flip_state`（→ µ） | **列**の分割（µ vs Cov）。ただし**ゲート抜き・全ユニット共通の G** について |
| `F_self` / `F_rest`（**スカラー**） | **行**の分割（self vs rest）。ただし**ゲート後・ユニット別の力の µ̂ 射影** |

行と列はどちらも手元にあるが、**別々の対象についての行と列**なので掛け合わせられない。4 セルに必要な per-unit の `E[a_i]`・`E[a_i·x]`（ベクトル）は記録されておらず、重みスナップショットも保存されていない（csv/json/md/npz/png/yaml のみ）ので後から作り直すこともできない。

**必要なのは probe を拡張した再計装リプレイ。** 新規アームではなく、同じ seed・同じ config で同じ軌道を録り直すだけ（元走行の S2 が probe 追加の非侵襲性を保証済み、学習 363 秒）。→ `specs/spec_cell4_0821.md`、[[命題リスト]] Q12。

**§3 の問いの立て方も 8/20 夕の撤回に合わせて言い直す**: 聞くべきは「税が潮流か」ではなく **駆動である rest が µ̂ 方向を向いているか**。中和（Q2b）が示すとおり「大きく寄与しているのに正味ゼロ」は両立するので、和の向きを測った数字（|cos(G, µ̂)| = 0.97）は内訳を割らないかぎりどちらにも帰属できない。

**FAIL 時の処置も先に確定済み**: condA の中では µ 列の 2 セルは定義上コリニアで、self 行は非負性で µ̂ に張り付くため原理的に分離できない。異方 Σ（新規アーム）は 8/21 の線引きの外なので、処置は現論文への限定文の追加のみとする。
