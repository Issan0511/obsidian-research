## 確立したこと

**λ_lock はノルム媒介ではない実在の力である。** ノルムを完全固定した条件下で β の CI がゼロから明確に離れた。

**λ_align > 0 も成立。** α = 1.036 [1.024, 1.042] がランダム基準 1.0101 を CI 下端で上回る。

## 修正が必要だった点

**関数形は線形ではなく飽和**（直線性 R²w = 0.768 で FAIL）。µ 結合は s(u)、p(u) という有界量を経由するため、c が入力 sd と同程度になればゲートが飽和して結合は伸びない。

**γ（奇数項）はアーティファクト。** 負 c アームで invD(−c) = invD(c) を確認。片側データでは基底 {1, c, c²} がほぼ共線で、飽和曲線をこの基底でフィットすれば γ に正値が機械的に流れ込む。直線性 FAIL と奇数項 FAIL は一つの事実の二重計上だった。
