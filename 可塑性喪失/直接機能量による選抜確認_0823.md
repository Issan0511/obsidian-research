# 直接機能量による選抜確認（0823・作業6）

親: [[中心主張v3草案_0823]] 柱3 / 作業: [[中心主張v3作業リスト_0823]] 作業6 / 関連: [[機能盲目性_0823]] / 状態: **独立確認・保存完了 2026-08-23**

> **結論**: 現在タスク32入力上の単独消音損失 `ΔL` が大きいユニットほど、同じ `p̂` と壁マージンを層別した後も同一タスク末尾で `strict_dead` になりにくかった。主判定は **PROTECTIVE**。作業6の操作的定義では、強い「選抜は機能を見ない」仮説は**否定側**である。

## 1. 問いと独立性

作業2の H は機能代理 `r` を使い、any-hit は天井効果、非天井 endpoint は **INCONCLUSIVE** だった。そこで、ユニットが現在の予測へ実際に寄与する量を新規走で直接記録した。

- 条件: condA・w100・T=10,000・std・batch=1・lr=0.01・0〜810,000 step
- confirmation: 20系列、`generator_offset=20260830`
- pilot: 旧軌道 `generator_offset=0` の10系列。設計専用で、confirmationへ合算していない
- seed番号は乱数seedではなくR軸の表示名なので、offsetを変えて初期状態・環境・教師を独立化した
- 起点 `t0=B+1`、終点 `t1=B+10000`、`B=200k,210k,…,800k` の61タスク
- 主リスク集合: t0で `p_hat>=0.05`。主転帰: t1で `strict_dead := p_hat=0`

## 2. 直接機能量と主解析

現タスクの32入力を全列挙し、ユニット `i` の出力寄与を `q_i`、残差を `δ=yhat-y` として

`delta_mse_i = E[(δ-q_i)^2]-E[δ^2] = E[q_i^2-2δq_i]`

`utility_nmse_i = delta_mse_i / Var(y)`

を記録した。正なら、その時点・その現タスクでユニットを単独消音すると損失が増える。

主解析は、t0のリスク曝露をまず **`t0 × p_count`**（`p_count=round(32*p_hat)`）で完全層別し、その中で `pre_max` を五分位化した。各 `t0 × p_count × margin5` セル内で `utility_nmse` を三分位化し、high−low の凍結率差を `min(n_high,n_low)` で重み付けした。CIは20 seedのブロックbootstrap 10,000回（RNG `20260831`）。群とセルはbootstrap前に固定した。

判定境界は±0.05。CI上端が−0.05未満なら **PROTECTIVE** と事前固定した。

## 3. 独立確認の主結果

| 項目 | 結果 |
|---|---:|
| リスク曝露 | 15,582 |
| 全セル / 有効セル | 6,002 / 2,839 |
| 無効セルの除外曝露 | 3,163 |
| low | 5,023件、2,018 event、pooled率 0.4018 |
| high | 4,431件、739 event、pooled率 0.1668 |
| 主調整RD（high−low） | **−0.2353 [−0.2812, −0.2325]** |
| 主判定 | **PROTECTIVE** |

CI全体が意味のある差の境界 −0.05 より負にある。セル内高 `ΔL` 群の同一タスク末尾凍結率は、セル内低 `ΔL` 群より明確に低い。

登録CIが点推定の負側へ非対称なのは、exact層別が疎で、seed再標本化時にlow/highの片側が消えて重み0になるセルが多いため。事前固定した計算法をそのまま再現した値であり、事後的な別CIへ差し替えない。

固定済み副次解析も同方向だった: `dead_0.05` −0.2544、壁マージン十分位 −0.2405、未調整 −0.3171、`utility_raw` −0.2332。3時期別も −0.2116 / −0.2476 / −0.2717。ただし主判定の差し替えには使わない。

## 5. 柱3への含意

**言ってよい**

- この条件・この現在タスク `ΔL`・この層別の範囲では、セル内で相対的に `ΔL` が高いユニットほど凍結しにくい
- 壁の式そのものに機能量が現れないことと、集団としての凍結結果が機能に無関係であることは別。後者は支持されなかった
- 作業2 O の「学習済み W に修復可能な容量が残る」は別の容量診断として維持される

**言わない**

- `ΔL` がユニットの普遍的価値・将来タスク価値・Shapley値である
- 層別で交絡が完全に消えた、または機能が凍結を因果的に防いだ
- condB、他幅、他教師、長期将来へ一般化できる
- Oまで否定された、または逆に O だけで「病理的刈り込み」が確定した

したがって、柱3を「機能盲目性」として売るのは止める。残る事実は、**直接機能量と凍結結果には保護的関連が見える一方、学習済み W 全体にもオラクル修復可能な容量が残る**という二層構造である。v3の「良性刈り込みへの反例」という位置づけは、この分解を踏まえて先生再裁定が必要。
