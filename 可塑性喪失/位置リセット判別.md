## 一行

**新特徴ゼロの座標復元だけで full reinit の便益の 70%（floor 補正後 50%）が出た（H_feat の強い形は棄却）。しかし座標を戻さず方向だけ入れ替える dironly が posonly を有意に上回り、その差は「マージンの引き直し」では説明され尽くさない——座標に還元されない新特徴の固有寄与が実在する（追補 Q1 FAIL・Q2 PASS）。B1「主成分は座標復元」は支持されない。**

## 何をやったか（本走）

t_int=500k で 4 アームに分岐（seed 10本、+500k）。treated = 固定 eval バッチ上の発火率 p̂<0.05 のユニット。

| アーム     | w                             | b    | 読み出し v |
| ------- | ----------------------------- | ---- | ------ |
| none    | 変更なし                          | 変更なし | 変更なし   |
| posonly | ‖g‖·(w/‖w‖)＝**方向保持・ノルムだけ初期化** | 0    | 0      |
| dironly | ‖w‖·(g/‖g‖)＝**新方向・ノルムとbは保持**  | 保持   | 0      |
| full    | g（標準 reinit）                  | 0    | 0      |

レジーム A = condA A_w100（µ経路）、B = µ=0・K=100・w20（b経路）。**`w` は学習器の幅、`K` は condB の教師再サンプル周期**（→ [[用語と記号]] §4）。判定は clean eval_loss のみ（dead_frac は使用禁止）。

## 結果1: レジーム B は死んだ ← 想定外

事前登録のキルラインは B に置いていた（β=b/‖w‖ なので posonly が β を直接 0 に戻す＝座標が完全復元される最強予言場）。しかし**前提ゲート G0（Δ_full>0）が落ちた**:

- Δ_full = 0.013、95%CI [−0.009, 0.034] → **full reinit ですら便益ゼロ**
- treated_frac = 0.945。つまり**95%のユニットを丸ごと初期化しても clean eval が動かない**
- 規約どおり P1/P2/P3 は全て void

これは [[怪文書の検証]] 側の cbp_harm_0815 の PC-4（µ=0 では reset は残差の有無に関わらずコストだけ）と同方向で、独立な再現になっている。**µ=0・b経路の場は「治療の効き」を測る土俵として使えない**、が確定した設計上の教訓。

### ただし機構署名だけは完璧に出た

- ゲート再開率（p̂>0.05 到達 @+100k）: **posonly 0.498 vs dironly 0.011**（差 0.488、CI [0.425, 0.551]）

### 読み解き

1. **floor 補正で B1 はさらに弱まった。** raw 比では posonly/full=0.704・dironly/full=0.936 だったが、共通床 V（=v←0 だけの効果）が full 便益の 40.5% を占めることが判明。floor を引くと **posonly = 0.502、dironly = 0.893**。つまり座標復元だけで買える便益は当初の「7割」ではなく「**5割**」——半分は v←0 という無関係な共通操作で説明され、残り半分だけが posonly 固有の座標復元の寄与。dironly との差はむしろ拡大した。
2. **Q1 FAIL・Q2 PASS は「dironly>posonly の差はマージンでは説明され尽くさない」の直接証拠。** posflip（新特徴ゼロ・マージン反転のみ）は dironly の便益の 90% 水準にすら届かない。→ dironly が posonly を上回る理由は、大部分が「新しい方向そのもの」にあり、「マージンの向き」ではない。
3. **Q7 ≈ 0 は P7 の交絡を一部解消した。** v←0 だけを行う vzero では Δcos(u,µ̂) はほぼゼロ（本走 posonly の −0.033 と対照的）。**v←0 による勾配窒息だけでは P7 の負符号は再現されない**——つまり posonly の Δcos が負に振れたのは「v=0 で信号が届かないから」ではなく、**ノルムを縮めた posonly 固有の何か**が原因である可能性が高い。[[ノルム増大と不可逆性]] の 1/‖w‖ 操舵切断描像に対する反証としての重みは、この追補で（弱まるどころか）やや補強された。

## 二極説（±µ、v符号で極が決まる）の棄却 — 2026-08-19

**状態: 決着**（棄却）。

検定: posreset_0819 の t_int=500k スナップショット（condA w100、10 seed × 100 unit、全ユニット。npz は treated のみだがスナップショットに v が含まれる）。µ = concat(flip_state, 0.5·1) は `posreset.current_mu_A` と同一式。

- **sign(v) は極を予測しない**: sign 一致率 0.527（偶然 0.5）。dead 率は v>0 で 0.898 / v<0 で 0.931 と差なし
- **+µ 極が存在しない**: cos(u,µ̂) > +2SD のユニットは **0/1000**。dead 915 個のうち cos>0 は **0 個**。cos>0 は全体の 1.9%（すべて alive）
- **構造は片側**: dead は cos −1.45 SD（median −0.325、IQR 狭い）、alive は −0.37 SD ≈ ランダム方向。alive 間 pairwise |cos| は 0.260（ランダム期待 0.178）で軽度整列にとどまりクローン帯ではない
- b も判別しない（alive −0.344 / dead −0.442）。‖w‖ は alive 3.30 > dead 2.44（生存側の方が大きい）

**この棄却は新情報ではなく、既知事実（sign_clone_frac ≈ 0、inter-unit ~74°）から演繹できた。** 二極構造は theory v2 §3(c) の予測だが、少なくとも condA・500k では −側だけが実現している。

### 代替候補（**未検証**）: 片側吸収による整流

各ユニットの µ 方向の駆動符号は sign(v_i·E[δ]) で決まり、教師再サンプル（K=10⁴）ごとに反転しうる（8/18 の符号安定率 6.1% ≈ コイン投げ）。駆動が符号反転する一方、**−側だけがゲート閉鎖で吸収的**（力もノイズも O(p) で同時消失）なら、対称な駆動＋片側吸収 = 一方向の堆積になる。これは (i) +極が育たない、(ii) posflip の往復と再死、(iii) sign_clone に到達しない、を同時に説明する。

**位置づけの含意**: 唯一の安定終点が dead であるため Dohare 現象は普遍的に見え、Joudaki のクローン多様体には到達しない——両者の関係は「同じ項の二つの符号」ではなく「**同じ駆動の、吸収端とそれ以外**」。

検証: ①ロギング走で個体ごとの駆動符号がタスク境界で反転するか、②死亡直前軌跡が単調輸送か拡散到着か、③方向凍結アームで安全角のユニットが不死か。スコープ: condA・w100・t=500k・単一スナップショット。

## ゲートなし力場の二極性 — 厳密計算（2026-08-19）

**状態: 決着**（厳密計算）。

condA は全サポート 32 パターン（m=20, f=15 → 変動するのは rnd 5 bit のみ）で**期待値が厳密に計算できる**。t_int=500k スナップショット（10 seed × 100 unit、教師込み）から E[δx] を厳密評価した。

**恒等式**: F_i^ungate = −2η·v_i·G、G = E[δx] は**全ユニット共通の単一ベクトル**。よってゲートを外した力場は定義上 ±G の二極。経験的中身は G の向きと大きさ。

- **G ≈ 潮流**: |cos(G,µ̂)| は E[δ] が有意な 6 seed で **0.966–0.995**。‖E[δ]µ‖/‖Cov(δ,x)‖ = median **4.3**（有意 seed で 3.7–9.6）。**condA では µ 項が Cov 項を一桁近く上回る**（condB 異方の aniso_perp とは別レジーム）
- **二極性の厳密確認**: sign(ċos_ungated) = −sign(v_i)·sign(G·µ̂) の一致率 **0.993**（E[δ]≈0 の seed 6 のみ 0.930）。**恒等式そのものは代数的に厳密で、0.993 はゲート後の実測符号との一致率**（→ [[命題リスト]] Q1）。seed 別に見ると完全に二極
- **極の割り当ては sign(v_i·E[δ]) で決まり、E[δ] の符号は系列で割れる**（10 seed 中 6 正 / 4 負）。同一系列内でも教師再サンプルで反転しうる（→ ロギング走で τ≈5–10 step と確定）

### 整流機構の確定形（機構としては強い、時間発展は未検証）

1. ゲートなし力場は ±µ の厳密な二極（上記）
2. 極の割り当ては sign(v_i·E[δ]) で、E[δ] はタスクごとに反転しうる → **駆動は符号対称に振れる**
3. **移動度**は位置依存: p̂ は cos>0.3 で 1.000、cos<−0.15 で 0.000（経験ゲート曲線）
4. → 対称な駆動 × 片側だけゼロの移動度 = **整流**。−側にのみ堆積し、+極は罠がないので育たない

「力場は二極、状態は片側」は矛盾ではなく整流の帰結。**Path A / Path B は「同じ二極場の、罠のある側とない側」**。
