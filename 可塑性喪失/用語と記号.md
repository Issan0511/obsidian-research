## 1. モデルと損失（出典: [[自己項の恒等式]] §0、`src/nets.py`）

- $\hat y = \sum_j v_j a_j + c$、$a_j = \mathrm{ReLU}(z_j)$、$z_j = w_j\cdot x + b_j$ — **2層 ReLU ＋ 線形読み出し**
- 損失 $\ell = \delta^2$（**½ なし**。実装規約。外部資料では ½ 規約と明示して使い分ける）
- $\delta = \hat y - y$ … **全ユニットが共有する残差スカラー**
- $o_i = v_i a_i$ … ユニット $i$ 自身の出力（**旧 $f_i$。8/20 夕に改名** — `f` が flipping bits の本数と衝突するため）
- $\delta = o_i + \delta_{\mathrm{rest},i}$ … 残差の「自分の分／それ以外」分解
- $u_i = w_i/\lVert w_i\rVert$ … 重みの向き（単位ベクトル）
- $\mu = \mathbb{E}[x]$、$\hat\mu = \mu/\lVert\mu\rVert$ … **必ず単位ベクトル**。$\lVert\mu\rVert$ は境界で跳ぶので生の $\mu$ 内積で引用しない
- $\mathrm{gate}_i = \mathbb{1}[z_i>0]$。**ReLU では $a_i\cdot\mathrm{gate}_i = a_i$** なので式中の gate は化粧
- $\hat p_i$ … ユニット $i$ の発火率（固定 eval バッチ上）。**8/23 以降は次の二層を区別し、修飾なしの `dead` を不可逆性の主張に使わない**
    - **凍結（`strict_dead`）**: $\hat p\equiv0$。condA では当該タスクの全 32 パターンで gate が閉じ、タスク内の勾配が恒等ゼロ。不可逆性・吸収・復活 0 を述べてよいのはこの集合だけ
    - **ほぼ消灯（`near_off`）**: $0<\hat p<0.05$。condA では量子化により $\hat p=1/32$ のみ。1 パターンでは gate が開くので勾配は恒等ゼロでない
    - **旧作業指標（`dead_0.05` / `dead_frac_0.05`）**: $\hat p<0.05$。凍結とほぼ消灯の和で、過去のログ・集計との互換用の代理指標。不可逆性の根拠には使わない。既存ファイルの修飾なし `dead` / `dead_frac` は、明示的に $\hat p=0$ と書かれていない限り原則この旧指標を指す
    - 裁定理由: $1/32=0.03125<0.05$ であり、旧 `t_death` 以降もほぼ消灯群は median $\lvert\Delta b\rvert=0.43$ 動く一方、凍結後は厳密に 0 → [[マージン恒等式と消灯点_0822]] §8(a)
- $\beta$ … **ゲートマージン**。レジーム A では $(w^\top\mu+b)/\lVert w\rVert_\Sigma$、$\mu=0$ のレジーム B では $b/\lVert w\rVert$
- $\eta$ … 学習率。$c$ … 読み出しのバイアス（出力オフセット）

## 2. 力の分解（出典: [[自己項の恒等式]]、[[中和と境界窓]]）

| 記号 | 定義 | 通称 |
|---|---|---|
| $F_{\mathrm{self},i}$ | $-2\eta\, v_i^2\,\mathbb{E}[a_i\,\mathrm{gate}_i\,(x\cdot\hat\mu)]$ | **税** |
| $F_{\mathrm{rest},i}$ | 上式の $o_i \to \delta_{\mathrm{rest},i}$ | **稼ぎ**。**現行フレームではこちらが駆動** |
| $F_{\mathrm{gate},i}$ | $F_{\mathrm{self}} + F_{\mathrm{rest}} \propto \mathbb{E}[\delta\cdots]$ | 正味 |
| $G$ | $\mathbb{E}[\delta x]$。**全ユニット共通の単一ベクトル** | **潮流**（condA では $\hat\mu$ とほぼ平行、$\lvert\cos\rvert$ 0.966–0.995） |

- **「税」= $F_{\mathrm{self}}$、「稼ぎ」= $F_{\mathrm{rest}}$、「潮流」= $G$（≒ $\hat\mu$ 方向）**。全ノートでこの愛称が流通している
- $F_i^{\mathrm{ungate}} = -2\eta\,v_i\,G$ … ゲートを外した力場。$v_i$ に**線形**なので定義上 $\pm G$ の二極
- **中和** … フィット中は $F_{\mathrm{self}}+F_{\mathrm{rest}}\approx 0$（相殺比 0.005）。力の平衡ではなく「共通スカラー $\delta$ が小さいことの言い換え」
- **鏡** … $\mathrm{corr}(-F_{\mathrm{self}}, F_{\mathrm{rest}})$。中和が成立している状態＝鏡が 1.000
- **陣営** … $v_i$ の符号。二極の割り当てが $\mathrm{sign}(v_i\cdot\mathbb{E}[\delta])$ で決まることから来る言い回し

## 3. 入力条件（出典: `src/envs.py`、[[台帳（実効バイアスの縮退）]] §1）

### condA = SCR（Slowly-Changing Regression、Dohare の公式ベンチマーク）

- 入力 $x \in \{0,1\}^m$、**$m=20$、$f=15$**。$x = [\,\mathrm{flip}(15\ \mathrm{bit}) \,\Vert\, \mathrm{rnd}(5\ \mathrm{bit})\,]$
- flip ビットはタスク内で**定数**（周期 $T$ ごとに 1 ビットだけ反転）、rnd ビットは毎 step $U\{0,1\}$
- → **1 タスクのサポートは rnd 5 bit の $2^5 = \mathbf{32}$ パターン**。「$f=15$ なのになぜ 32 か」はここ。$2^{15}$ ではない
- $\mu = \mathbb{E}[x] = [\,\mathrm{flip\_state} \,\Vert\, 0.5\cdot\mathbf 1\,]$（`src/posreset.py: current_mu_A`）。**成分毎に非負** — 税の符号定理はここに乗っている
- **$n_{\mathrm{active}}$** … flip 15 ビットのうち 1 の本数。$\mathrm{Bin}(15,0.5)$ なので典型 6–10。台帳の増幅率 $1+n_{\mathrm{active}}$ に出る
- 教師は **LTU**（Linear Threshold Unit）の和。重み・バイアスは $\pm1$、閾値 $\tau = \beta(m+1)-S$（`src/envs.py: LTUTarget`）

### condB = ガウス入力・教師再サンプル

- $x \sim \mathcal N(0,\Sigma)$。異方版は $\Sigma$ に $\kappa$ スパイクを入れる（`aniso_perp_0812` の $\kappa=16$ 等）
- $\mu=0$ なので税の符号定理は**成立しない**。**台帳も存在しない**（凍結ブロックが無いため）

## 6. 現象の呼び名

- **帯** / **帯深** … dead ユニットが溜まる $\cos(u,\hat\mu)$ の値域（median −0.325）とその深さ
- **消灯点** … $\hat p$ が 0 になる $\cos(u,\hat\mu)$（実測 ≈ −0.15）。**帯深 −0.325 との差が匍匐の動機**
    - **水準の区別（8/22 追加）**: −0.15 は **seed 中央値水準**の消灯点 $\theta_\mathrm{med}$。**全サンプル水準は $\theta_\mathrm{all} = -0.55$** で、崖は $[-0.55, -0.15]$ の内部構造を持つ。**ガウス $\beta$ 近似の −0.46 と比べるときは水準を揃えること**
    - **enc 依存（8/22 追加）**: 消灯点は $\cos_\mathrm{crit} = -(b+M)/(\lVert w\rVert\lVert\mu\rVert)$ で、**分母に $\lVert\mu\rVert$ がいる**。enc=centered では $\lVert\mu\rVert$ が 3.041 → 0.117 に潰れるため $\cos$ の定義域 $[-1,1]$ の外へ出て、**消灯点が存在しなくなる**（`ratchet_centered_0822` の C1「不可比」）。**逆に $\lVert\mu\rVert$ が大きいほど壁は手前に来る**（$b+M>0$ のユニットで。$\lVert\mu\rVert$ は壁の位置と、バイアスが逃げられる割合 $1/(1+\lVert\mu\rVert^2)$ の両方を決めている）→ [[マージン恒等式と消灯点_0822]] §1.5
- **匍匐（ほふく）** … 境界で $\hat\mu$ が跳ぶ → 凍結ユニットが一瞬**再露出** → 一押しされて再凍結、を繰り返して深部へ進む描像
- **再露出率** … 凍結区間のうち $\lVert w\rVert$ が実際に動いた割合（76.5%）
- **安全角** … 力の消灯領域に入らない $\cos(u,\hat\mu)$ の範囲（方向凍結アームの設計用語）
- **新鮮エントロピー** … `dir_angle` ダイヤル実験で一定に保つ統制量（供給する方向の「新しさ」の量）。角度 $\theta$ だけを動かすための設計
- **再分類死 / 輸送死** … 境界の衝撃 $\pm w_{ik}$ 一発でゲートが閉じる死（輸送ゼロ）と、窓の中で力に運ばれて滑落する死（→ [[命題リスト]] Q16）
- **穴A** … 「税が駆動でないなら、なぜ rest が下向きに偏るのか」という未同定の機構（8/20 夕以降の最大の未解決）
- **台帳** … condA で flip 15 座標＋バイアスが 1 自由度に縮退する構造（[[台帳（実効バイアスの縮退）]]）。**次論文の素材**

## 7. 略号・固有名

- **LoP** = Loss of Plasticity（可塑性喪失）
- **LTU** = Linear Threshold Unit（condA の教師の構成単位）
- **SCR** = Slowly-Changing Regression。**Dohare の公式ベンチマーク**（condA はこれ）
- **CBP** = Continual Backprop（Dohare の手法）
- **SDE** = 確率微分方程式。8/12 の先生提案の統一フレーム（Path A / Path B）
- **Path A / Path B** = 旧 SDE フレームでの「diffusion＋吸収壁 → dead」／「drift → 低ランク整列」。現行では「同じ駆動の、吸収端とそれ以外」
- **「怪文書」** = **私的な呼称**。正式には「符号クローン仮説の解析報告文書」。**外部文書には書かない**

## 8. 番号体系の注意（**相互参照の罠**）

**`Q` と `P` は2つの体系で使われている。**

- **グローバル**: [[命題リスト]] の `Q0`–`Q16`（中心主張の足場台帳）
- **ローカル**: 各実験ノート内の事前登録 ID。**そのノート限りの番号で、命題リストとは無関係**

    - [[位置リセット判別]] 本走: `P4`, `P5`, `P7` ／ 追補: `Q1`–`Q8`

## 8/24 追記 — 記号 κ の導入（**§1 へ統合すること**）

運用ルール「新しい記号を導入したら1行足す」に従う追記。**暫定的に末尾に置いてあるので、§1（β の定義の隣）へ移すこと。**

| 記号 | 定義 | 意味 | 出所 |
|---|---|---|---|
| **κ** | `‖w_free‖₁ / ‖w_free‖₂ ∈ [1, √5]` | 消灯の正規化閾値。`κ² = participation ratio` = **実効自由ビット数**（k 本等大なら κ=√k）。無次元・スケール不変 | [[吸収不等式の命題化_0824]] §2・§5 |

**混同注意（重要）**: [[xr分解と生存機構_0822]] の **`r`（µ̂ 直交成分の大きさ＝「背の高さ」、次元は重みと同じ）とは別物**。κ は「背の**使い方**」を測る形状量で、同じ `r` でも κ は 1〜√5 の幅を持つ。[[吸収不等式の命題化_0824]] の初版は本量を `r` と書いており衝突していた（8/24 に κ へ改訂済み）。初版を引用した箇所があれば読み替えること。

関連: `p̂ = 0 ⟺ β ≤ −κ`（condA・タスク内）。一般の平均 0 揺らぎでは `ρ(w) := ess sup(w·δ_x)/σ` に置き換わり、ガウスでは ρ = ∞（吸収域が空 = PB-5）。
