## 位置づけ: 暗黙バイアスの「反例」であって「反証」ではない

- **LoP は暗黙バイアスである。** タスク内で µ ブロックは実効閾値 `b_eff` の 1 自由度に縮退し、残る 14 次元は厳密零空間。零空間の中で SGD がどの方向を選ぶかを µ（潮流）が決めている — 教科書的な暗黙バイアスの構造そのもの
- **ただし単純な良性刈り込みではない。** 落とされた W を固定したままスイッチと bias を修復すると失われた損失の 93.6% が回復する（柱3）。一方、選択則が個々のユニットの学習内容を一切参照しないという強い形は、r を代理にした H では未決着
- 主張の型は「暗黙バイアス理論の反証」では**ない**。本系は補間点に達していない（unfit ≈ 0.14）ので、補間点上の選択則を反証することは論理的に不可能。やるのは「**暗黙バイアス = 良性の単純化・刈り込み**という通念への**反例の供給**」
- 文献接続: 零損失多様体上のドリフト（[[命題リスト]] §3-1 の正典 Blanc+ / Li+）に対し、**病理側の事例**を与える

## 三本柱

### 柱1: µ が壁を作る【機構】

- 死は閉形式 `s + M ≤ 0`。cos 表現で `cos(u,µ̂) ≤ cos_crit = −(b+M)/(‖w‖·‖µ‖)`（[[マージン恒等式と消灯点_0822]] §1）
- ‖µ‖ は壁を **2 経路**で強くする: (i) 位置（cos_crit の分母）、(ii) b の逃走自由度 `1/(1+‖µ‖²)`（同 §1.5）
- µ を除去すると壁は定義域外へ出て、dead 0.947 → 0.324（同 §3）
- 崖の位置 −0.15 は初期化則と入力統計だけのゼロパラメータ MC で予言が当たる（同 §2）
- `β ≤ −r` は PB-5 の有界入力版の解析定理（同 §1.3）

**格**: centered 本走は **commit 済**（`ratchet_centered_0822`）。閉形式の検証・2 経路・MC は事後計算で要昇格。β≤−r は走なしで命題化できる。
**残る穴**: 2 経路の寄与分離（µ タイトレーション未実施、同 §9-6）。

### 柱2: 揺れはほぼ対称、境界が非対称（整流）【動力学】

- 撹拌の符号は 49.7 : 50.1、94.9% の個体が +µ 側を訪問、終端で +側に残るのは 0（[[xr分解と生存機構_0822]] §19）
- 上端 = **可逆な天井**（残差依存・自己参照平衡）、下端 = **不可逆な吸収**（勾配恒等ゼロ、16,475,293 ペアで復活 0、同 §14・§20）
- 境界あたりハザードは一定 0.099–0.186（時間依存なし、下げ止まりなし。[[マージン恒等式と消灯点_0822]] §7）
- 「行きは自由、帰りは無い」だけで、時間とともに全員が下端に堆積する
- 揺れの大きさは残差に比例（|Δx| ∝ eval_loss、窓相関 ≈0.96）— **揺れは学習の副産物であり、方向情報を持たない**

**格**: `ratchet_log_0819` の走は事前登録済だが、上記の解析は 8/22–23 事後計算で**要昇格**。
**前提作業**: `p̂ < 0.05` 作業定義の裁定（[[マージン恒等式と消灯点_0822]] §8a。「勾配恒等ゼロ」は p̂≡0 でのみ正しい）。

### 柱3: 機能盲目性仮説【意義・本論文の売り候補】

良性刈り込み仮説（「LoP は不要なユニットを落としているだけ」）を検討する3点。作業2後の証拠は **O が支持、H は未決着**:

1. **選抜と機能代理 r の関係は未決着**: 300k以内の any-hit は 1.000 / 0.997 / 0.995 で等価判定を通るが天井効果。非天井の300k後 `strict_dead` 占有率は 0.860 / 0.864 / 0.833、high−low = −0.0265 [−0.0894, +0.0378] で **INCONCLUSIVE**。`p̂×x` 調整後も等価判定を通らない。旧 0.837 / 0.839 / 0.850 は再現しなかった
2. **落とされた W には修復可能な容量が残る**: `dead_0.05` を閾値上へ蹴り上げ、W・vを固定して全 bias + c だけ再最適化すると、seed 平均 NMSE は **0.143367 → 0.009148（93.619%回復）**。新しく固定した対照の平均 NMSE は学習済 W 0.1126 < fresh He 0.2354 < 行シャッフル 0.3829 < rnd列ランダム化 0.7794で、学習済 W と各破壊対照の paired CI はすべて0未満。ただし dead unit 単体の有用性や動的な修復持続は示さない
3. **壁は学習内容を見ない**: 壁の位置と強さは ‖µ‖（入力の平均）だけで決まり、そのユニットが何を学んだかと無関係（柱1）

**格**: 1・2 は `function_blind_0823` として spec・実装・結果を commit 済み（結果 commit `4493a14`）。ただし既知の事後概数を見た後の再現で、H-end は初回の天井効果を見た後の追補。旧チャットの3破壊対照値は操作定義を回収できず未再現。詳細は [[機能盲目性_0823]]。3 は柱1 に従属。

## ランク低下の扱い【確定・8/23】

- `rank ≤ alive` は厳密（dead 行は全サポートで恒等ゼロ）。主張は「**dead による上界の低下**」と明記する。力場 → dead → 上界低下、で因果が完結し、追加の防衛が要らない
- 生存者内の余分な圧縮（alive-only eff_rank 7.53 / 12 本、同数ランダム基準 10.80）は**入力スパン由来**（[[blindspot_0820]] §15）で本主張の外。**本文で先に自分で書く**（聞かれてから答えると弱い）
