## 0. 一言で

0923 の主張候補の三本柱のうち、**「幅には固定点がある」と「実効変位は W にほとんど依らない」は不成立**。残るのは、収支の恒等式と、RL に限った「近い相殺」（1 課題の書き換えの 95% を次の課題の削りが打ち消し、残り 5% が積もる）、c_S が課題の非類似度を測ること、CIFAR での最適化器差。幅は RL でも止まらず、MNIST 固定入力では **150 課題まで毎課題ほぼ一定の +100 ずつ**伸びる（V_S ∝ t、R_S ∝ √t）。「√t は死重側で、効く成分は定常へ向かう」（棚卸しノート・追記 2）も撤回。

## 3. 残ること

1. 恒等式 ΔV_S = Q + 2X（自明）。
2. **RL に限った近い相殺**: 1 課題の書き換え ρ_S ≈ 0.4〜0.5 のうち 95% を次の課題の削りが打ち消す。残り 5% が MNIST では一定額（+100/課題、√t）、CIFAR では t^−0.4 で減りながら積もる。頭打ちではない。
3. **c_S は課題の非類似度の物差し**: RL では全遷移で負（−0.19〜−0.35）、CondA k1 では −0.03 で 3 割が正、X0Y0 では正。
4. **CIFAR の最適化器差**: t41–50 の幅は Adam が SGD の 7.5 倍。差を作るのは早期の過渡（t ≤ 15 に V_S が 24 万に達する）と収束後の尾（課題あたり正味の 68%）。CondA では Adam ≈ SGD（学習率違い）なので箱固有。
5. ε の用量反応（CIFAR、D_S 343 → 192）は水準の効果として残る。固定点の効果ではない。

## 4. 親ノートで消すべき文

- §0・§2「幅には固定点がある」「W_S* = D_S/(2|c_S|) に達する」→「RL では ρ_S が 2|c_S| の 5% 上に留まり、幅は √t（MNIST）〜t^0.3（CIFAR）で伸び続ける」。
- §3「実効変位は W にほとんど依らない」→ 長期では弾性 0.6〜0.7。腕をまたぐ W_S ∝ D_S^1.00 は ρ_S が最適化器によらないことの言い換えで、向きは決めない。
- §7「次元を増やせば固定点が上がる」→ 固定点が無いので問い自体を立て直す。Codex の CondA 診断では生次元 m20 → m40 で D 比 0.98（教師も変わるので純粋な介入ではない）。画像複製の走は登録済み・未開始 [[実効変位_画像の次元と分散を分ける_予測_0924]]。
- 棚卸しノート追記 2「幅は定常へ向かい √t は死重側」→ MNIST では効く成分そのものが √t。
- **「幅は実効変位に比例する」（§0 の一言・§2 の 5 腕の比）→ 主張にしない。** 同じ計量で測った R と D の比 ρ_S が定数だという言い換えで、恒等式 R = D/(2|c|) と合わせても「1 課題の正味成長が供給の 5%」以上のことは言っていない（Issa の指摘、0924 朝）。中身があるのは、ρ_S と c_S が尺度に依らない箱の定数であること（RL 0.4〜0.5 と −0.2〜−0.35、CondA 0.06 と ≈0）、尺度を決める側（入力分散 × 偏り × 最適化器）、正味 5% の出どころ、の三つで、D → W の向きは決まっていない。

## 6. 追記（0924 朝、Issa の問い）: MNIST と CIFAR で幅のオーダーが違うのは実効変位の側で、実効ランクではない

走ゼロ（`effdisp_growth_posthoc_0924/mnist_vs_cifar_scale.txt`）。MNIST は Codex の固定入力走（画素 [0,1]、1,200 枚の bank）、CIFAR は元の走の std（画素ごと標準化）。

| | RL-MNIST 固定入力 | RL-CIFAR std |
|---|---:|---:|
| 入力 d / 分散の rank / tr Σ / 平均分散 λ̄ | 784 / 591 / 52.7 / 0.067 | 3,072 / 1,199 / 2,980 / 0.97 |
| 実効ランク PR / 上位 10 の分散の分担 | **29.7** / 49% | **9.8** / 65% |
| 素の変位 ‖D‖_F² / 課題（t41–50） | **27,700** | 4,760 |
| 実効変位 ‖D‖_Σ² / 課題（t41–50） | 1,140 | **175,000** |
| 実効 ÷ 素 | 0.041 | 36.5 |
| （実効 ÷ 素）÷ λ̄ ＝ 等方に対する偏り | 0.6 | 37.6 |
| D の素の分担: 上位 10 / 11–100 / 101–rank | 0.7% / 7.6% / **88.9%** | 15.9% / 48.7% / 35.3% |
| D の実効の分担: 上位 10 | 49% | 83% |
| ‖W1‖_F² の分担 101–rank（t50） | **92%** | 56%（mid2+low） |
| V_S / V_raw（t50） | 0.016 | 9.8 |

t41–50 の幅の比 V_S(CIFAR)/V_S(MNIST) = 134 は、実効変位の比 153 = **素の変位 0.17 × 平均分散 14 × 偏り 62** に分かれる。

- Adam の素の歩幅は MNIST のほうが**大きい**（課題あたり 6 倍、座標あたり 23 倍）。差は歩幅の大きさではなく、歩幅がどの方向に落ちるか。
- MNIST の低分散方向は個々の縁の画素（座標に揃っている）。Adam の座標ごとの正規化はまさにその座標の微小勾配を η の歩幅に拡張するので、素の変位の 89% が分散のほぼ無い方向（PC 101–591）へ行き、死重になる（t150 で ‖W1‖_F² 126 万のうち 92%）。CIFAR std は全画素が単位分散なので、同じ座標ごとの歩幅が分散の上に乗る（実効変位の 83% が上位 10 成分）。
- 実効ランクは逆向き（MNIST 30 > CIFAR 10）で説明にならない。
- 昨日の「入力次元」の問いへの自然実験: 効くのは d でも実効ランクでもなく、変位が乗る分散（λ̄ × 偏り）。
- 整合: Codex の参照走の CIFAR raw（[0,1]、画素ごとの分散差あり）は V_S/V_raw 0.24 で、std の 10 と MNIST の 0.016 の間。Issa の「Adam が微量な成分を拡張する」は MNIST では素のノルムの支配項（ただし幅にはほとんど効かない）。
- 予言（未検定）: ε を上げると MNIST の素のノルムの伸びは CIFAR std より大きく落ちる。幅の伸び（+100/課題）への効き方は別に測る。

## 7. 追記（0924 朝、Issa の問い 2）: 「新しい方向はランク分しか無いのでは」

走ゼロ（`effdisp_growth_posthoc_0924/mnist_direction_reuse.txt`、MNIST 固定入力 150 課題・5 seed、Σ 計量）。

| 量 | 値 |
|---|---|
| 課題 s の変位が k 課題後に残る割合（射影） | k=1: 0.79、2: 0.72、5: 0.64、10: 0.58、20: 0.54、40: **0.51** |
| 変位どうしのラグ cos | lag 1: **−0.215**、2: −0.064、3: −0.036、5: −0.019、10: −0.008、20: −0.001 |
| Σ cos（lag 1〜40） | ≈ −0.475 → 正味 = Q(1 + 2Σcos) = **0.05 Q**（登録の釣り合い比 0.95 と一致） |
| 変位のうち古い変位の方向に沿う二乗の割合 Σ cos² | **≈ 5%**（残り 95% は過去の全変位と直交する新しい方向） |
| 150 課題の変位のグラム行列の参加比（Σ / 素） | **113** / 130（直近 50 課題では 44.5/50） |
| 1 課題の前活性の変化 ΔZ（100 × 1,200）の実効ランク | PR 16、90% が 22 方向 |
| 幅の中身 Z_150 の実効ランク | PR 15、90% が 56 方向 |

読み。

- **150 課題では「毎課題ほぼ新しい方向」がそのまま成立している。** 各課題の変位の 95%（二乗）は過去の全変位と直交し、古い方向に沿うのは 5% で符号は負（削り）。その 5% が交差項 2‖D_old‖‖D_new‖cos として効くので、V の正味は供給の 5% になる。射影で見ると各課題の変位の半分は 40 課題後も残っている（削りは次の課題で 21%、その後 6%・4%・3%…と減り、20 課題を過ぎるとほぼ触られない）。
- **直交な方向の数の上限は「入力のランク」ではなく「ユニット数 × 入力のランク」。** MNIST で 100 × 591 ≈ 59,000、CIFAR で 100 × 1,199 ≈ 120,000。実際に変位が使う範囲はユニット側 16〜22 次元 × 入力側 100 主成分ほど ≈ 2,000 なので、150 課題では余裕があり、**千課題のオーダーで埋まる**。ΔZ と Z の実効ランクは 15〜20 で、ユニット側の方向は使い回されている（Frobenius 直交は同じユニット方向でも入力側が違えば成り立つ）。
- **埋まっても、期待値の伸びは止まらない。** √t に要るのは「直交」ではなく「無相関」で、1 次元のランダムウォークでも ‖W‖² ∝ t。方向が尽きて再利用が起きても、再利用の符号がランダムなら Σ‖D‖² の積み上がりは変わらない。伸びを止められるのは削り（負の相関）が供給に釣り合うことだけで、それは方向の数と無関係。
- したがって問いは「なぜ次の課題は前の変位の 21% しか削らず、残りを二度と触らないか」に移る。候補: 効く成分の大半が現在の下流（W2·W3）が読まない方向に落ち（[[RL-CIFAR第2層の前活性_動きの1割しか第3層に読まれない_事後_0923|l2act: W3 が読むのは 9 方向、変化の 10%]]）、読まれない方向は次の課題の勾配も受けない。検定: 各課題の変位を「現在の下流が読む部分空間」と直交補に分け、次の課題で削られる割合を比べる（走ゼロ、MNIST の state で可能）。
