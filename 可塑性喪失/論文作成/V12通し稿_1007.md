## 要旨

学習を続けると学び直せなくなる可塑性喪失について、前活性が負側へ偏り、訓練に使う応答を失う経路を調べる。入力平均を介して重みの更新が前活性の位置も動かすことに着目し、乱数ラベルを学ぶ一隠れ層の模型で、出力と傾きの積が課題切替時の期待の押しを決め、その釣り合いが強く負側へ偏ることを示す。さらに、負の相対位置をほぼ保ったまま分布幅が増すと沈降が深まることを示し、活性化ごとに異なる応答と非線形性の喪失を整理する。中心化と bias 抑制や重みの成長制限で再学習性能が改善する条件を確かめ、早期と劣化後の応答の交換が成績を両方向に変えることを示す。この分析を踏まえ、分布幅に合わせて曲がりの尺度を変える活性化 kunekune を導入し、適応 Snake とともに乱数ラベル CIFAR で高い再学習性能を得る。実ラベルの 5+1 CIFAR を用いた二隠れ層 MLP でも、両者は追加の正則化やユニットの再初期化を使わず、学習率を固定して少数の候補から調整した Shrink & Perturb・CBP・ReDo を12〜17ポイント上回り、この課題向けに調整した L2 Init と同等だった。

## 1 序論

学習を続けると、なぜ学び直せなくなるのか。本研究は、前活性が負側へ偏り、応答を失う経路を調べる。

入力平均を通じて重みの更新が前活性の位置も動かすことに着目し、乱数ラベルを学ぶ一隠れ層の模型で、課題切替の期待の押しが出力と傾きの積で決まることを示す。その正負の非対称性によって、釣り合い自体が強く負側へ偏る。例えばガウス模型の leaky ReLU（負側の傾き a = 0.1）では、正側に残る入力が約4%になるまで釣り合わない。さらに、その釣り合いより下にも沈める押しが残る条件を整理する。これらは仮定を置いた模型での期待についての結論であり、実際の訓練との対応を実測と介入で調べる。

その偏りによって失われる機能は活性化ごとに異なり、分布幅の増大も応答を左右する。負の相対位置（共通位置 ÷ 分布幅）をほぼ保ったまま幅が伸びると、共通位置はさらに深くなる。ELU・SiLU・GELU では、深い負側で傾きの絶対値がゼロへ近づく。ReLU は負側で応答を失い、leaky ReLU は傾きが残っても全入力が負側に入ると直線化する。

位置や応答への介入で、これらの変化と再学習性能との関係を検証する。乱数ラベル CIFAR の ReLU 網では、入力と中間層の中心化に bias 抑制を加えることで200課題まで高い成績を保った。成長制限は調べた ELU 網を改善したが、実ラベルの ReLU には効かなかった。早期と劣化後の応答の交換は、三つの課題設定で次課題の成績を両方向に変えた。

この分析を踏まえ、Snake [13] を基に、分布幅に合わせて曲がりの尺度を調整する活性化 kunekune を導入する。負側にも傾きを残すだけでなく、入力ごとに異なる傾きを使える領域を保つことを狙う。kunekune は、同じ尺度調整を施した適応 Snake とともに、乱数ラベル CIFAR の未標準化・標準化入力の両方で高い再学習成績を保った。

実ラベルの 5+1 CIFAR を用いた二隠れ層 MLP の比較でも、kunekune・適応 Snake は高い再学習性能を示した。追加の正則化やユニットの再初期化を使わず、ほかの課題と同じ既定値を用いた。学習率を固定した比較で、少数の候補から調整した Shrink & Perturb・CBP・ReDo を上回り、この課題向けに調整した L2 Init [4] と同等だった。

**関連研究。** 入力・中間層の中心化や bias shift の抑制は、最適化を改善する手段として研究されてきた [1–3]。可塑性喪失に対する正規化の効果も報告され [4,7]、Lyle ら [5] は再尺度化と中心化の寄与を調べ、MLP で入力中心化の有効性を示した。活性化による可塑性の違い [9,10] や、Deep Fourier [8]・CReLU [11,12] も調べられている。本稿は、前活性の位置と幅から応答の喪失に至る過程を解析し、中間層の中心化と bias 抑制、応答への介入、幅に適応する活性化を検証する。

## 2 設定

### 2.1 対象と用語

可塑性喪失とは、初回には学べていた条件のもとで、後の課題を学ぶ能力が低下することである。再学習能力は、学習中の各更新前の正解率（online 精度）で測る。この指標は課題内の適応の速さを表し、汎化精度とは区別する。

各層の前活性 $z_i(x)=w_i^\top x+b_i$ を、共通位置 $\bar z_i=w_i^\top\mu+b_i$ と入力ごとの揺らぎ $w_i^\top(x-\mu)$ に分ける。$\mu$ はその層の入力の平均である。共通位置が負側へ動き続けることを輸送と呼び、局所応答は訓練が用いる微分 $\varphi'(z_i(x))$ で測る。機能的な喪失は、各実験で定めた予算・評価窓での online 精度の対照差により判定する。応答指標の閾値と実効数は課題設定ごとに評価する。

### 2.2 課題系列と三つの箱

主実験は正規化層のない二隠れ層 MLP と Adam を用い、乱数ラベル CIFAR、乱数ラベル MNIST、実ラベル 5+1 CIFAR の三つの設定（箱）で行う。weight decay は対照条件以外では用いない。乱数ラベル課題では固定画像のラベルを課題ごとに引き直す。5+1 CIFAR は Kumar ら [4] に従い、5 クラスの hard 課題と1クラスの easy 課題を交互に学び、クラスは再訪しない。評価には hard 課題を用いる。最後の hard 課題を新しく初期化した網にも同じバッチ列で学ばせ、その成績から継続学習した網の成績を引いた値を fresh gap とする。正の fresh gap を、課題の難化から区別した可塑性喪失の証拠とする。手続きは §7、網の構成・訓練予算・評価窓は付録 A.1 に示す。

## 3 入力平均の投影と中心化の効果

入力平均がゼロでない層では、特徴を学ぶ重みの更新が、前活性分布の共通位置も動かす。中心化はこの経路を抑えるが、bias が位置を動かす経路は残る。

### 3.1 重みの更新は、入力平均を通じて共通位置も動かす

ある層の入力を $x$、その平均を $\mu$ とすると、ユニット $i$ の前活性は

$$
z_i(x)=\underbrace{w_i^\top\mu+b_i}_{\text{共通位置 }\bar z_i}
+\underbrace{w_i^\top(x-\mu)}_{\text{入力ごとの揺らぎ}}
$$

と分けられる。特徴を学ぶ重み $w_i$ は、入力ごとの揺らぎを変えると同時に、その入力平均方向の成分を通じて共通位置も動かす。bias は、入力平均を介さずに共通位置を動かす。

層入力を固定し、重みと bias を同じ学習率 $\eta$ で一標本 SGD 更新すると、局所勾配 $\delta_{in}=\partial\ell_n/\partial z_i(x_n)$ に対し、共通位置は

$$
\Delta\bar z_i=-\eta\,\delta_{in}K_n,\qquad
K_n=\mu^\top x_n+1
$$

と動く。この $K_n$ が §4.1 の「明るさ」で、$+1$ は bias の寄与である。raw 画像や中心化前の ReLU 出力は成分ごとに非負なので、各入力で $K_n\ge1$ となり、正の局所勾配は共通位置を下げる。

平均 $\bar K=\|\mu\|^2+1$ は正だが、この正値性は各入力の正値性や §4.1 の「$K$ 一定」を保証せず、std では負の $K_n$ もあり得る（§4.4）。

層入力を厳密に中心化すれば $K_n=1$ となり、共通位置を動かす bias の経路だけが残る。ただし、ReLU は次層に非ゼロの平均を再び生み得るため、中心化は外部入力と中間層の両方に施す。

### 3.2 中心化とbias抑制で、200課題まで高い成績を保った

乱数ラベル CIFAR（raw）を学ぶ二隠れ層 ReLU 網で、入力平均を引く C と、両隠れ層の出力平均を引く H を組み合わせた CH を調べた。H は平均を指数移動平均（EMA）で推定するため、実平均を厳密にゼロにする操作ではない。残る bias の経路も抑える CHB は、CH に第1層 bias の毎更新後のゼロ化と、第2層 bias への decoupled weight decay を課題1から加えた条件である。

C は第1課題を学べたが、課題を重ねると成績が低下し、CH は全10 seed で C を上回った（表1）。C では第2層、H 単独では第1層が死亡し、CH は両層を保った（付録 B.2）。

#### 表 1　中心化条件と50課題の成績

| 条件 | 課題31–50の online 精度 |
|---|---:|
| C：入力のみ | 11.33% |
| CH：入力＋中間層 | 98.67% |
| CHB：CH＋bias 抑制 | 98.54% |

各 seed の窓内平均の10 seed 中央値。層別診断と H・分散正規化・LayerNorm の対照は付録 B.2。

## 4 駆動源の理論と活性化ごとの機能低下

本章では、乱数ラベルを学ぶ一隠れ層網について、課題切替後の最初の更新が前活性の共通位置に与える変化を解析し、幅の成長による応答の変化と介入につなぐ。訓練した網を「実網」と呼び、仮定を置いた模型の結果と区別する。仮定の一覧は付録 C.2、実測との照合は付録 D.2 に示す。

各ユニットの共通位置を m（入力についての平均、§3.1 の z̄_i）、分布幅を s（標準偏差）、相対位置を r = m/s、正の前活性を持つ入力の割合を p とする。正側の入力を「開いた入力」と呼び、これを持つユニットを「生きたユニット」、全入力で前活性が 0 以下の状態を「全閉」と呼ぶ。開閉と区別して、活性化の傾き d = φ′(z) を局所応答として調べる。以下で「ゲート」と呼ぶのもこの傾き d である。

### 4.1 負側へ動く理由

§3.1 の局所勾配と明るさの積を各入力について足し、新ラベルで平均した量を、切替の「押し」と呼ぶ。正の押しは、最初の勾配更新で共通位置を下げる。前の課題を学んだ読み出しへの切替の押しが位置を運ぶ時期を相 1、切替の押しが細り、模型の外の止め役と釣り合った後を相 2 と呼ぶ。以下では、それぞれの時期の押しを異なる模型で調べる。

#### 4.1.1 初期に大きく負側へ偏る理由

<!-- G3 -->
**切替の押しの期待は、出力と傾きの積からなる「自己形」に従う。負側の応答が弱いと、正側の入力が少数になるまで沈める押しが続く。**

新ラベルは網の状態と独立・一様とする。特徴を固定し、独立・一様な旧ラベルを読み出しが勾配学習で自信をもって正しく当てる模型（H1）を考える。新ラベルで平均した押しを S_i とし、初期読み出し項と旧ラベルの相関を 0 と置くと、旧ラベルについても平均した押しは

E_old[S_i] = κ(1 − 1/K)Σ_n K_n d_in φ_in

となる [厳密な極限]（付録 C.3）。φ_in と d_in はユニット i の入力 n に対する出力と傾き、K_n = x̄·x_n + 1 は §3.1 の明るさ（x̄ = μ）、K はクラス数、κ は読み出しが勾配で育った量である。右辺の出力と傾きの積を明るさで重みづけした和が自己形で、正なら共通位置を下げる。この導出は活性化の形によらず、整流型の leaky ReLU・ELU（α ≤ 1）・ReLU（H0）にも、SiLU・GELU にも共通する。

前活性をガウス分布、明るさを正の一定値とする（H3）。**正負の入力が半々でも、自己形の押しは釣り合わない。** 例えば leaky ReLU では、出力と傾きの積は正側で z、負側で a²z となり、同じ絶対値の前活性なら、浮かせる寄与は沈める寄与の a² 倍しかない。a = 0.1 では、自己形の零点で正側に残る入力は約4%にすぎない（p = Φ(r)、Φ は標準正規の分布関数）。このように、負側の応答の弱さが釣り合い自体を大きく負側へ偏らせる。初期位置から向かう自己形の安定な釣り合いを r*₀ と呼ぶ。


**補題 1（負側の釣り合いへ向かう）。** 自己形の釣り合いがある場合、各課題末で H1 と付録 C.3 の条件が保たれると、同じ理想化の下で、r*₀ より上では期待の押しが沈める側に働き、位置を r*₀ へ向ける。r ≥ 0 では押しの大きさに正の下界があり、有限回の切替で p < 1/2 に入る。この領域で残る押しを次節で調べる。ReLU は負側の寄与が 0 のため釣り合いが無く、各入力で K_n > 0 なら、生きている間は沈める押しが残る。証明は付録 C.3 に置く。

釣り合いの有無と幅による違いは §4.2 に示す。以上は切替の期待の押しについての結論であり、課題内の係数変化と H1 の持続時間は扱わない（§8）。実網の初期の沈みとの照合は、付録 D.2 の表 D2 と C.3 にまとめる。

#### 4.1.2 沈んだ後も押しが残る条件

<!-- G4・G9 -->
相 2 の押しを、凍結・線形化した網に二乗誤差とリッジを用い、当てはめを完了した模型（H2）で調べる。この模型の押しは、位置を動かしたときの出力 φ(z) の変化に由来する「読み出しの押し」と、傾き d の変化に由来する「ゲートの押し」に分かれる。ゲートの押しに現れる重み e′ は、ゲートが位置の変化に反応する度合いを表し、整流型では閾値付近で大きい（付録 C.1・C.6）。

**補題 2（負の偏り）。** ガウス分布・明るさ K 一定（H3）の下で、読み出しには付録 C.5 の残差化模型、ゲートには C.6 の並べ替え平均を用い、それぞれの適用条件と符号条件を満たすと、正側の入力が半数未満の生きたユニットでは、期待の押しが沈める側に残る。これらの条件が保たれる範囲では、自己形の釣り合い r*₀ より下にも、押しが釣り合う位置は無い。leaky ReLU・ReLU では、この符号条件は正側の入力が半数未満であること（r < 0）と同じになる。ELU ではゲートの符号条件が、相対位置がある上限 r_g(σ) より下のときに限られ（σ = 1 で −0.65）、幅が小さいと r*₀ のすぐ下の一部が条件の外に出る。証明は付録 C.7 に置く。

<!-- G5・G6 -->
理由は、他のユニットを含めた当てはめでは、自己形の釣り合いを作る成分が変わることにある。自己形は、出力と傾きの共分散と、それぞれの平均の積に分かれる。r*₀ では負の平均積が共分散を打ち消すが、定数成分を他のユニットが引き受ける理想化では、読み出しの押しに共分散が残る。整流型ではこれは r*₀ より下でも非負である。この分解は付録 C.5 に示す。

<!-- G7・H4・G8 -->
整流型の実際の入力の並びへ結び付けるには、ゲートの押しを反転させるだけの重なりが他のユニットに無いという追加仮定 H4 を置く。これは leaky ReLU の実測で支える仮定であり、一般の定理ではない。重なりは、開いた他のユニット（橋）と閉じたユニットの持ち上げの合計で、leaky では閉じたユニットの分が大きい。調べた実状態では、この合計は必要量に届かなかった（最大 0.92 倍）。橋の定義と必要数の下界は付録 C.9、持続性を含む実測は付録 D.2 (c)〜(f) にまとめる。

<!-- G8・G9・SiLU/GELU の条件 -->
SiLU・GELU には傾きが負になる域があるが、ガウス・K 一定に幅とゲート項の重み比の条件を加えると、同様に期待の押しが沈める側に残ることを数値が支持する（付録 C.8）。以上は凍結した模型のラベルと前活性の並びについての期待であり、実際の訓練が必ず r*₀ を越えるという保証ではない。

### 4.2 幅の増大による釣り合いと開いた割合の変化

<!-- G10 -->
**相対位置が負のままほぼ一定なら、幅の成長によって共通位置は深くなる。** m = r·s なので、r が負のまま留まれば（ṙ ≈ 0）、時間微分は ṁ = ṙ·s + r·ṡ ≈ r·ṡ となり、共通位置は幅の伸びに比例して深くなる。この関係は、相対位置が幅によらない leaky ReLU の自己形の釣り合い r*₀ 付近に留まる場合にも成り立つ。相 2 での幅の成長を仮定 H5 とする。幅が伸び続ける理由は未導出であり、幅の収支と条件付きの成長模型は付録 C.13、実測との照合は付録 D.2 (g)・付録 D.3 の表 D5 に置く。

**幅の増大は、自己形の釣り合いで正側に残る入力の割合も変える。** §4.1.1 と同じガウス分布・明るさ K 一定の下で、釣り合いにおける開いた割合を p*₀ = Φ(r*₀) と書く。leaky ReLU では r*₀ が幅によらないため、p*₀ も幅によらない。ReLU には、生きている間の釣り合いが初めから無い。幅が増すと、ELU では自己形の釣り合いが深まり、そこで正側に残る入力はほぼ無くなる。SiLU・GELU では釣り合い自体が消える [ガウス・数値]（付録 C.3）。

ここで小さくなる p*₀ は、自己形の釣り合いでの値であり、実網の開いた割合 p がこの値まで下がるという結論ではない。実網では別の止め役が働きうるため、実際の p と残る応答を次節で調べる。

### 4.3 実網の止まり位置と残る応答
§4.1.2 の模型はミニバッチの揺らぎと Adam の更新を含まず、実網の止まり位置を決めきれない。止め役と停止位置、残る局所応答を、活性化・最適化器ごとに実測と介入で調べる（H6）。

#### 4.3.1 leaky ReLUは応答を残すが片側化する

<!-- G11 -->
a = 0.1 の leaky ReLU の実網は、自己形の釣り合いより深くで止まる。止め役の候補は、ミニバッチ残差の揺らぎと負の平均出力の積から生じる、浮かせる項である [候補]。幅に比例するこの項が止め役なら、停止する相対位置は幅によらない。この項を除くと、止まり位置はさらに深くなった [介入]（付録 D.2、表 D2・(h)）。

leaky は閉じた入力にも傾き a を残すため、死なずに片側化する。ただし全入力が負側に入ると傾きが一様になり、入力ごとに傾きを使い分ける非線形性を失う。

#### 4.3.2 ELUの止まり位置は最適化器で違う

ELU は尺度固定で z → −∞ となると、傾きの絶対値がゼロへ近づく。一隠れ層の ELU × Adam では、出力の下限 −1 と Adam の押し戻しが、開いた入力の数を幅によらず一定に保つ [実測・介入]（付録 D.3 の表 D7）。ELU × SGD は全閉まで下がる [実測]。二隠れ層では、更新の移動量が押し戻しを上回り、層が機能低下に至りうる（付録 D.3 の表 D7・D.2 の表 D3）。

#### 4.3.3 ReLUは負側で応答を失う

<!-- G11 -->
ReLU は z < 0 で傾きがゼロになり、同定済みの各項は 0 または沈める側に働く（付録 C.10）。揺らぎの項も、SGD の 2 歩で導いた式では、平均出力が非負なので沈める側に働く（Adam での符号は確かめていない）。未知の止め役が無く、上端（最大の前活性）の余白が 1 課題の期待値で増えず（S1）、死の近くでも揺らぎが残る（S2）と仮定すれば、有限時間に確率 1 で上端が 0 を切り、死ぬ [確率・仮定つき]（付録 C.10）。

<!-- G11 -->
入力が固定なら、死んだ間の勾配は厳密に 0 であり、Adam の残留運動量で開き直さない限り死は永久である [厳密・条件つき]（付録 C.10）。

#### 4.3.4 SiLU・GELUは深い負側でほとんど閉じる

<!-- G8・G9・SiLU/GELU の実状態 -->
SiLU・GELU も尺度固定で z → −∞ となると、傾きの絶対値がゼロへ近づく。調べた凍結状態では模型の期待と異なり、深くほとんど閉じたユニットでも、谷の壁（傾きの最小点から活性化の最小点まで）の項が橋なしで浮かせる側に働く場合があった。押しは小さく、調べた訓練では半分より多く開いた側へ戻らなかった [実測]。この帯でも r が負のままほぼ一定なら、幅の成長が共通位置を下げる（付録 C.8）。

SiLU・GELU は全閉まで下がる [実測]。出力の平均は 0 へ近づき、止め役は同定されていない。

### 4.4 二隠れ層への適用

<!-- G12 -->
**上流を固定した第 2 層には、一隠れ層と同じ構造が移る。** 第 2 層の位置は z̄₂ = W₂·µ₂ + b₂（µ₂ は平均入力）で、読み出し W₃ は入力によらない。そのため第 2 層は、入力 h1（第 1 隠れ層の出力）・平均入力 µ₂ の一隠れ層の理論と同じ構造を持つ [恒等式]。符号条件 K2 = µ₂·h1 + 1 ≥ 0 は ReLU 以外では別途確認が必要で、上流の項 W₂·Δµ₂ は固定入力の模型の外にある。また、µ₂ の向きは閉じた側の出力（ELU の −1 など）の共通成分が支配する。

<!-- G13 -->
第 1 層の読み出しは、第 2 層のゲートを通って戻る g_in で、入力に依る。そのため、切替の押しの期待が自己形に等しいという §4.1.1 の結果は移らない。第 1 層での期待の形は導出していない。移るのは、他のユニットが定数成分を引き受ける理想化での補題 Cov(φ′, φ) ≥ 0（付録 C.5）で、重み |g_in|²K_n をつけた Cov_w(φ′, φ) ≥ 0 になる [厳密・raw・仮定つき]（付録 C.11）。重みの非負には K ≥ 0 が要り、raw では全入力で成り立つ。std では K < 0 の入力が 36% あり（付録 D.2 (k)）、第 1 層は補題の外にある。

<!-- G14 -->
bias を別に使わず、重みを平均入力の向き x̄ に沿って動かすと、相対位置は −c（c = (mean(K) − 1)/sd(K)）へ近づく [厳密]。z を平均入力の向きの成分に回帰した切片が非負なら、この道の全体で相対位置は −c を下回らない（付録 C.11）。この −c を壁と呼ぶ。第 1 層の壁は raw で −3.83、std で −0.40 である。h1 は中心化されていないので、std でも第 2 層の壁は −2.0 と深い。この違いから、std では第 2 層に理論の機構が現れると解釈する。層の順序は導出していない。壁が深く、止め役が無いか更新の移動量を抑えきれない層が先に低下すると考え、実測で確かめた（付録 D.2 の表 D1）。raw で第 1 層が先に低下するのは最初の切替より前で、切替の押しでは説明しない。

<!-- 旧 4.9 -->
説明は最初の機能低下までとし（判定基準は付録 D.2）、その後は戻らない理由として扱う。ReLU では、死んだユニットの勾配は死んだ間ちょうど 0 である（§4.3.3）。ReLU の g_in は第 2 層の開いたユニットだけを通るので、第 2 層が全部死ぬと第 1 層の勾配も 0 になり [厳密]、Adam の残りの更新が尽きると第 1 層は凍る。入力が動く第 2 層では、死んだ層も上流の項で運ばれる [恒等式 ＋ 実測]。

<!-- G12・G13・G15 -->
調べた CIFAR の leaky ReLU・ELU・ReLU の第2層では、Cov(e′, d) > 0 の下で押しが反転した例は、第1層が先に機能低下した後に限られた [実測]。乱数ラベル MNIST の ELU の第1層では、半分より多く開いた側へ戻る例があり、「戻らない」は全層には移らない（付録 D.2 (i)〜(l)、付録 D.3 の表 D7）。

### 4.5 幅を止める介入による検証

**幅を止める介入の効き方は、活性化によって分かれた。** ELU では成績が大きく改善し、SiLU・GELU にも高い課題末精度を保つ条件があった。実ラベルの ReLU では改善しなかった。

#### 4.5.1 ELUは両層の成長上限で成績が改善する

課題 1 終端の行ノルムを半径として、各 Adam 更新後に重みを射影した。両隠れ層に上限を置く cap12 では、課題 31–50 の平均 online 精度が 85.98%（対照 10.09%）、対応差が +75.9 ポイント［97.5% 信頼区間：75.1–76.6］となり、全 10 seed で床への崩壊を防いだ。第 1 層だけでは 11.91%、第 2 層だけでは 25.10% にとどまり、片方の成長を抑えても他方が沈降を運んだ。‖µ₂‖ は課題 1→50 に対照で 52.6→1157、cap12 で 52.6→40 だった（seed 平均）。乱数ラベル MNIST の ELU 網でも、第 1 層の入力平均方向の成分と第 2 層の行ノルムをともに制限すると、全 10 seed で改善した（online 0.84。相対位置と深さの事後診断は付録 D.2 (p)）。

**SiLU・GELU にも成長上限が効く条件があった。** 1 隠れ層の乱数ラベル MNIST では、行ノルム上限で高い課題末精度を保つ条件が確認された。ただし GELU は介入時期に依存し、学習速度の維持を示す結果ではない（付録 D.2 (q)）。

成長上限の効果には沈降の抑制と実効学習率の保持がともに含まれ得るが、学習率だけを変える同尺度の対照が無く、両者の寄与は分離していない（付録 C.13）。

#### 4.5.2 ReLUは深さを抑えても開閉が変わらない

**実ラベルの ReLU では上限が効かない。** 5+1 CIFAR の ReLU に同じ上限を適用すると、cap12 は後期 online 精度を 3.6 ポイント下げ［97.5% 信頼区間：−6.7〜−0.5］、fresh gap を 4.7 ポイント広げた［0.6–8.8］。cap1 も悪化し、cap2 には明確な効果が無かった（事前登録 `cap_cifar5p1_1007`）。cap12 は第 2 層の共通位置を浅くしたが（対照 −8.5、cap12 −5.6）、幅も同じ比で縮み（5.5、3.7）、相対位置は全 4 条件で −1.5〜−1.6 のままだった。死亡率も下がらなかった（対照 .34、cap12 .40）。重みの成長が深さを増す関係はあっても、深さを止めるだけでは ReLU の開閉は変わらない。

応答への直接介入が再学習成績を変えるかを、次章で調べる。

## 5 応答の回復と保持による再学習性能の改善

第4章では、前活性が負側へ動き、活性化に応じて応答や非線形性を失う過程を調べた。本章では、応答を直接変える介入で再学習成績との関係を確かめ、その分析を踏まえた活性化を導入して比較する。

### 5.1 応答の交換はELUでもReLUでも成績を変える

応答場（各ユニット・入力の傾き φ′(z)）を、同じ軌道の早期と劣化後の間で第2層について交換し、固定した。交換時の重みを保ち、固定補正で特徴と予測を対照に一致させた後、重みと特徴の更新を再開した。

乱数ラベル CIFAR（ELU・std）では、課題10末の網に課題1末の場を戻すと、次課題の online 精度が 10.2% から 57.0% へ上がり、逆向きの交換では 97.1% から 29.2% へ下がった。成績は次の1課題・30,000更新での10 seed平均で、復元は Adam の履歴を継続し、逆向きは対照・介入とも初期化した（区間と図は付録 E.1）。

同じ両方向の効果は、乱数ラベル MNIST の ELU と実ラベル 5+1 CIFAR の ReLU でも得られ、三つの設定とも各10 seedすべてで確認した。ReLU では早期の場を戻すと、次課題の精度が 40.4% から 61.7% へ上がった（付録 E.2・E.3）。

5+1 の ReLU では、開いたゲート数を早期の場にそろえる一様シフトでは、早期の場を戻すより成績が高く、同じ応答値を画像・ユニットの構造を壊して並べ替えると低下した。開いた数と入力に沿った配置が成績に関わるが、検証は次の1課題までである（付録 E.3）。

### 5.2 分布幅に合わせて曲がりを保つ活性化を導入する

負側に傾きを残す leaky ReLU も、全入力が負側に入れば一つの直線になる（§4.3.1）。この分析を踏まえ、分布幅に合わせて曲がりの尺度を調整する活性化 kunekune を導入する。kunekune は Snake の曲がりを有限区間に残し、その外側を直線につないだ関数である。同じ尺度調整を施した適応 Snake も比較する。

尺度は各ユニットの前活性幅の走行統計から決め、その統計には勾配を通さない。分布が曲がる領域に残る限り、入力ごとに異なる傾きを使い続けられる。ただし、幅への追随だけで分布の中心をその領域に保てるわけではない。関数の定義と実装は付録 F.1・A.1、止まり位置と応答の下界の条件は付録 C.12 に示す。

### 5.3 乱数ラベルCIFARで高い成績を保つ

二隠れ層 MLP を50課題学習させると、kunekune・適応 Snake は、未標準化入力（raw）と標準化入力（std）の両方で高い成績を保った（表2）。この50課題では分布の大部分が曲がりを持つ帯内に残った（付録 F.1）。一方、leaky ReLU は傾きが残っていても、早期から後期への成績低下が見られた（付録 F.3）。

課題31–50の平均 online 精度の10 seed中央値。全13種の比較は付録 F.3 に示す。

活性化の置き換えでは出力値と微分がともに変わるため、この成績差を非線形性や尺度調整だけの効果とは切り分けていない。別設定での固定尺度との比較は付録 F.2 に示す。実ラベル課題での既存対策との比較を、次章で調べる。

## 6 実ラベル課題で既存対策に並ぶ再学習性能

kunekune・適応 Snake への置き換えは、正則化もユニットの再初期化も使わずに、実ラベル課題で調整した L2 Init と同程度の再学習成績を示した。Kumar ら [4] の 5+1 CIFAR を二隠れ層 MLP に移し、CIFAR-100 の 5 クラスを学ぶ課題と別の 1 クラスだけを学ぶ課題を交互に、計 30 課題学習させた（各 780 更新。設定は付録 A.1）。

**活性化の置き換えは、ReLU を大きく改善し、標準的な対策 3 手法を上回った。** 後期の 5 クラス課題（課題 21・23・25・27・29）の平均 online 精度は、ReLU の 42.4% に対し、kunekune は 66.7%、適応 Snake は 67.1% だった（10 seed 中央値、図 1）。評価とは別の seed で設定を選んだ Shrink & Perturb・CBP・ReDo は、ReLU を 6〜10 ポイント改善したが、kunekune・適応 Snake には 12〜17 ポイント届かなかった（評価 20 seed の対応差中央値。16 腕の全成績は付録 G.1、較正の条件は付録 A.2）。

**調整した L2 Init と同等だった。** L2 Init は、重みを初期値へ引く正則化である。この課題向けに強さを調整した L2 Init（λ = 10⁻³）とは、追試を加えた計 20 seed で、kunekune・適応 Snake の両方が後期成績の対応差について事前に定めた ±0.5 ポイントの同等性基準を満たした。原典の λ = 10⁻² には 19/20 seed で上回った。活性化側はほかの課題設定と同じ既定値を用い、この課題に合わせた再調整はしていない。0 へ縮める正則化（AdamW、0 へ引く L2）は ReLU を救わなかった（付録 G.1）。

**死んだユニットをほぼなくしても、上位群の成績には届かなかった。** ReDo は、後期の課題終端で測った第 2 層の死亡率を 33.6% から 0.2% へ下げた。それでも、ReLU から適応 Snake までの成績差のうち ReDo が埋めたのは 43% だった。死亡率の改善だけでは、再学習性能が回復したとは判断できない。

kunekune・適応 Snake にも、可塑性喪失は残った。最後の 5 クラス課題を、新しく初期化した同じ構造の網に同じ 780 更新・同じミニバッチ列で学ばせると、課題を重ねてきた網より kunekune で約 3.5 ポイント、適応 Snake で約 3.2 ポイント高い online 精度が得られた（10 seed の対応差中央値）。

## 7 方法

活性化の定義、介入の実装、測定量、判定の手続きは付録 A にまとめる。主な比較は seed 内対応差の符号検定を用い、同等性は順位区間が登録帯に収まるかで判定する。新規の本走は判定規則・閾値・予測を実行前に固定し、既知軌道の登録再解析と事後解釈は区別した。

## 8 限界

主な検証対象は、Adam で学習する二隠れ層 MLP の三つの課題設定である（柱ごとの範囲は付録 I.1 の表 I1）。理論は乱数ラベルの MLP における最初の機能低下までを扱い、CNN で検証したのは現象と介入である（付録 H）。成長上限の救済は ELU の二つの課題設定で得られ、応答場の復元は人工的な関数変更による回復である。S&P・CBP・ReDo との比較は、学習率を 10⁻⁴ に固定した小さい較正格子の範囲に限る（付録 A.2）。理論では、前活性幅が伸びる理由（H5）と、凍結した模型の期待値を実際の訓練の軌道へ移す証明が未解決である。ほかの未解決点と実装依存は付録 I、仮定と実測の対応は付録 C.2・D.3 にまとめる。

## 付録 A　実験設定と統計手順

### A.1 実験と活性化の設定

**乱数ラベル CIFAR。** CIFAR-10 から seed ごとに1200枚を固定し、課題ごとに一様乱数ラベルを引き直す。入力は raw（画素/255）と std（チャネルごとの定数で標準化）。網は bias ありの3072-100-100-10で、中心化の実験は ReLU、成長上限と応答場の交換は ELU、活性化比較は13種を用いる。Adam の学習率は1e−3、β=(0.9, 0.999)、ε=1e−8、batch 16で、moment は課題をまたいで保持し、weight decay は対照以外では用いない。50課題を各30,000更新（400 epoch × 75）学習し、中心化の長期比較は200課題とする。主評価は課題31–50の平均 online 精度で、通常は seed 0–9の中央値を示す（例外は A.4）。

**乱数ラベル MNIST。** 固定した1200枚（画素/255）に課題ごとに一様乱数ラベルを与える。網は784-100-100-10、両隠れ層は ELU(α=1)。Adam の設定と batch は上の CIFAR と同じで、100課題を各6,000更新（80 epoch × 75）学習する。応答場の移植は分岐後2課題を評価する。主指標は課題51–100の online 精度と第2層の訓練微分。seed は0–9で、介入別に10–19・30–39も用いる。

**実ラベル 5+1 CIFAR。** CIFAR-100 の hard 課題（5クラス × 500枚）と easy 課題（1クラス500枚）を交互に学び、クラスは再訪しない。入力は std、網は3072-100-100-100、活性化は16種。Adam の学習率は1e−4、batch 32で、weight decay は対照以外では用いない（L2 Init は対照）。30課題を各780更新（hard 10 epoch・easy 50 epoch）学習する。評価は hard 課題の online 精度、後期窓 hard 21–29、早期窓 hard 1–9、fresh gap とし、seed 0–9と追試10–19を用いる。

**活性化の変種。** leaky ReLU の負側の傾きは 0.01・0.1・0.3（5+1 CIFAR では 0.7 も）とし、Smooth-Leaky と Randomized Smooth-Leaky は Lillo と Cheney [9] の既定値を用いた。KKA は位相 $[-3\pi/2,\pi/2]$ の外を傾き 2 の直線にした変種、KKA23 はその 2/3 倍である。5+1 CIFAR では Concat ReLU と Deep Fourier も加え、等パラメータ（hidden 94）の版を併走させた。

ReLU・leaky ReLU・Smooth-Leaky・Randomized Smooth-Leaky・ELU(1)・SiLU・GELU と、適応 Snake $\phi_\alpha(z)=z+\sin^2(\alpha z)/\alpha$、その一周期を残した kunekune（KKT1）を用いた。kunekune は位相 $\theta=2\alpha z\in[-2\pi,\pi]$ で Snake、左で $z$、右で $z+1/\alpha$ とし、継ぎ目は $C^1$ である。適応尺度は $\alpha_i=\mathrm{clip}(0.6/W_i,\,0.005,\,3)$（$W_i$ は前活性分散の EMA の平方根）で、三つの箱で共通とした。

適応尺度の分散 EMA は $V\leftarrow0.99V+0.01\,\mathrm{Var}_{\rm batch}(z)$、初期値 1、母分散を用い、$W_i=\sqrt{V_i}$ とする。

### A.2 介入と箱ごとの条件

**中心化と対照。** C は訓練画像の平均を学習前に引く。H は両隠れ層の出力から、画像方向のユニット別 EMA 平均（β = 0.01）を引く。EMA には勾配を通さず、訓練・評価で同じ値を用い、分散正規化と affine は加えない。B は第 1 層 bias を除き、第 2 層 bias に decoupled weight decay を掛ける。RL-CIFAR の C は seed ごとの 1200 枚の平均を引き、分散では割らない。H は $a=\varphi(z)$ に適用する。B の第 2 層の λ = 0.1713 は未使用 seed の probe から導出した。CS は H と同じ軸のスケールだけを正規化し、中心化・affine は加えない。LN は線形写像の後、標本ごとに特徴方向へ適用し、γ・β を学習する。5+1 では C に CIFAR-100 訓練集合の平均を使い、B の λ を probe から 0.835 に導出し直した。

**層別キメラ。** 層別キメラは活性化の組合せ以外を揃えた。RL-CIFAR/raw は第 1 層 {leaky 0.1, ELU, GELU} × 第 2 層 {leaky 0.1, ELU} と GELU→GELU の 7 組、RL-MNIST は leaky・ELU の 2×2 とした。

**凍結窓。** 凍結窓では切替直後と課題中央で更新数を揃え、両隠れ層の重み・bias と Adam の m/v を止め、出力層は訓練を続ける。RL-CIFAR/raw × MLP、seed 0–9、50 課題、各 30,000 更新で、LE（leaky 0.1→ELU）と LL（leaky 0.1→leaky 0.1）を比較した。窓は切替直後の 0〜K−1 と、課題中央の ⌊(30000−K)/2⌋ から K 更新。LE は K ∈ {75, 750, 7500}、LL は K=750 とした。主比較は LE・K=750 の ‖µ₂‖(t5) で、seed 対の両側符号検定と「切替腕の中央値が課題内腕の半分未満」の規則を本走前に固定した。無凍結参照は S-A の既存軌道を用いた。

**成長制限。** 成長上限は課題 1 終端の値を半径とし、課題 2 から各 Adam 更新後に重みを射影する。RL-CIFAR の ELU/std では第 1 層・第 2 層の行ノルム上限（cap1・cap2・cap12）と、両層 bias も課題 1 終端へ戻す cap12_bfix を比較した。RL-MNIST では第 1 層を入力平均方向と直交成分に分けた上限と、第 2 層の行ノルム上限を組み合わせた。

**応答場と履歴。** 課題末で分岐し、第 2 層の出力を

$a_i(x)=\varphi(z_i^0(x))+[\varphi(z_i(x)+d_i(x))-\varphi(z_i^0(x)+d_i(x))]$

と置く。$z^0$ は分岐点で凍結した前活性、$d$ は移植元と分岐点の前活性の差である。分岐点の特徴・logit・損失・重みを保って、訓練の微分を $\varphi'(z+d)$ に変える。RL-CIFAR の主 P1 は Adam 履歴継続、主 P2 は両腕履歴初期化とし、一様シフト $d=-\Delta$ を対照に置く。RL-CIFAR の ELU/std は課題 1 末と 10 末の間で両方向に交換した。履歴初期化（r 腕）は重み・bias を保って Adam の全 m/v/tc をゼロへ戻す。5+1 の ReLU/std では課題 2 末と 28 末で分岐し、場は次の課題の画像で定義した。

**移植と予算。** RL-MNIST の ELU→ELU（l2cap の ref の箱）へ C・H・CH を移し、C は seed の 1200 枚の平均、H は両隠れ層の出力 EMA（β = 0.01）を用いた。5+1 の ReLU/std へは両層の行ノルム上限と応答場交換を移した。駆動の測定は RL-MNIST では旧ラベル・Adam の十分条件・自己 S・上流 U を用いる A2 と同じ定義、5+1 では旧ラベルが無いため S・U と画像集合の変更項を課題内 26 更新ごとに記録した。窓は較正 seed 5–9 だけで選び、主 seed を開く前に固定した。5 走とも spec を commit して予測と判定を固定してから本走した。5+1 の増予算は 780 更新を 10 倍にした条件である。

**標準手法との比較。** 5+1 CIFAR の同じ MLP・入力標準化・30課題（各780更新、batch 32）で、全比較腕の Adam 学習率を 10⁻⁴ に固定した。S&P・CBP・ReDo は ReLU 網に適用した。各手法では、seed 100–109 の後期窓（課題21・23・25・27・29の更新前正答率）の算術平均が最大のセルを選んだ。選択を保存してから seed 0–19 で評価した。表の精度は、各 seed の同じ後期窓平均を取った後の20 seed中央値である。

| 手法 | 較正格子 | 選択値 | 後期 online（%） |
|---|---|---|---:|
| S&P | ε ∈ {10⁻⁵,10⁻⁴,10⁻³} × σ ∈ {10⁻⁴,10⁻³,10⁻²} | ε=10⁻⁵、σ=10⁻² | 51.94 |

同じ20 seed・後期窓では ReLU 43.24%、kunekune 66.37%、適応 Snake 66.06%だった。kunekune・適応 Snake と3手法の seed 内対応差の中央値は 12.33〜17.12 pt で、6比較すべてで全20 seedが前者を支持した。3手法とも格子の端で選ばれた。比較はこの格子と固定学習率の範囲に限る。

S&P は Adam 更新後に全重み・bias を θ←(1−ε)θ+σζ とし、ζ は各層の初期化分布 U(±1/√fan_in) から引く。CBP は両隠れ層で contribution utility を用い、成熟したユニットの置換数の端数を繰り越す。ReDo は両隠れ層で直近64枚の平均絶対活性を層平均で割ったスコアが τ 以下のユニットを再初期化する。CBP・ReDo とも入力重みを初期化し出力重みと bias をゼロにする。CBP は該当要素の Adam m/v と更新番号をリセットし、ReDo は該当重みの m/v のみリセットして bias の moment と大域更新番号を保持する。

### A.3 測定の計算

再学習能力は更新前の argmax 正解率の課題平均（online 精度）で測り、課題末の 1200 枚の正解率も併記する。死亡率は全画像で $|\varphi'|$ の最大が $10^{-6}$ 未満の unit の割合、mob は画像平均した $\varphi'$ の unit 中央値、低応答率 Q は全画像×全 unit のうち $|\varphi'|<10^{-6}$ の割合とする。

共通位置の変位分解（A6）と応答介入は autograd の訓練微分を使う。活性化比較の死亡率・mob は解析式 dphi による診断値で、float32 ELU の訓練微分とは異なる場合がある。LN の保存診断は LN 前の z に基づくためゲート比較から除く。機能低下の時刻 T_d・T_f は付録 D.2 に定義する。

共通位置は unit ごとの入力平均 $m_i=\bar z_i$、幅は同じ入力集合での標準偏差 $s_i=\mathrm{sd}_x(z_i)$、相対位置は $r_i=m_i/s_i$ とする。第 2 層では $\bar z_2=W_2\mu_2+b_2$ で、二時点の差を

$$\Delta\bar z_2=\Delta W_2\mu_2+W_2\Delta\mu_2+\Delta W_2\Delta\mu_2+\Delta b_2$$

に分解する。右辺の差分でない $W_2,\mu_2$ は移動前の値。順に自己重み・上流・交差項・bias の寄与である。低応答の先行層は、各層の低応答率 $Q=P_{x,i}(|\varphi'|<10^{-6})$ が初めて $1/2$ を越える課題で判定する。

実効数は unit ごとに $n_{\rm eff}=(\sum_x|g|)^2/(N\sum_xg^2)$（$g$ は逆伝播が掛ける微分）とし、全 g=0 なら 0、層では unit 平均を取る。付録 E.2 の平均実効数は課題中の probe 時点でも時間平均する。実効階数は活性化行列の特異値を $p_i=\sigma_i/\sum_j\sigma_j$ と正規化した $\exp(-\sum_i p_i\log p_i)$ で、Gram 行列から float64 で計算する。共通位置の四項分解も float64 を用いる。T_f の適合率は $(A(t)-1/K)/(A(1)-1/K)$（$A$ は online 精度）とする。

### A.4 集約・判定・検査

## 付録 B　中心化の対照と別設定での検証

### B.1 中心化が変える項

$$
z_i(x)=w_i^\top\mu+b_i+w_i^\top(x-\mu),\qquad
\Delta\bar z_i=(\Delta w_i)^\top\mu_t+w_{i,t+1}^\top\Delta\mu+\Delta b_i .
$$

第 2 式の右辺は、順に自己更新、上流の移動、bias の寄与を表す。一標本 SGD・スカラー出力・二乗損失では $\Delta\bar z_i=-\eta e v_i\varphi'(z_i)(x^\top\mu+1)$ となる。中心化は $x^\top\mu$ を 0 にし、bias の寄与である 1 を残す。raw CIFAR では $x^\top\mu\approx\|\mu\|^2\approx670$ なので、中心化により係数 $(x^\top\mu+1)$ は約 3 桁小さくなる。Adam で座標ごとの歩幅が揃う場合は $\|\mu\|_1$ が目安となる（未登録の近似）。

初期化の時点の配置も入力平均で決まる。入力平均と偏差の比 $\|\bar x\|/\mathrm{rms}\|x-\bar x\|$ は seed 中央値で raw 1.90・std 0.125 で、1,200 枚の 99% 超に同じ符号を返す第 1 層のユニットの割合は raw 0.22（事前登録の予測帯 0.185–0.255）、std と C では 0 だった。入力平均を γ 倍した条件を含む 8 条件のうち帯内は 6 条件で、測った第 1 層の出力に条件付けた第 2 層は 8 条件とも帯より高かった（`initgeom_cifar_0920`、未使用 seed 20–39、訓練なし）。

### C.1 模型

**格。** [厳密] は記した条件下の証明、[恒等式] は代数的な等式、[ガウス] はガウス分布・K 一定での数値評価、[数値] は構成や探索、[実測] は訓練済み状態の測定、[介入] は比較実験を指す。[仮定つき]・[極限] はその制限を明示し、[候補]・[未導出]・[反例] を区別する。「読み」は解釈である。

**模型。** 凍結した網を線形化し、二乗誤差とリッジ（係数 λ）で当てはめる。bias 込みの入力を x̃_n、その平均を x̄、明るさを K_n = x̃_n·x̄、Θ = X̃X̃ᵀ とする。unit j の入力 n のゲート d_nj は傾き φ′(z_nj) で、整流型では d = a + (1 − a)σ(z/τ) と平滑化する。読み出しを v_j、γ_j = ‖v_j‖²、出力を F = (φ_nj) とする。核は 𝒦 = Σ_j(v_jv_jᵀ)⊗(D_jΘD_j) + I⊗(FFᵀ + 11ᵀ)、容量は Φ = ½ log det(λ + 𝒦) である。unit i の位置を w_i → w_i + t x̄ と動かしたときの A_i = ∂Φ/∂t を押しと呼び、正を沈める側とする。押しはゲートの道の分 A^g と読み出しの道の分 A^r に分かれる。unit 単独の核（出力 bias を含む）による押しを自己項、全体との差を残りと呼ぶ。1 出力の核と多クラスの核（クラスの向き K′ = 9）を区別する。「K 一定」は K_n を定数 K̄ と置く理想化である。照合に使う箱と実状態の作り方は付録 D の冒頭に置く。

### C.3 相 1 の押しの期待と補題 1

**命題（自己形）** [厳密な極限・H1]。特徴 φ_im と傾き d_in を固定し、旧ラベル y を入力間で独立・一様とする。読み出しを v_ic = v⁰_ic + κΣ_m(y_mc − 1/K)φ_im と置く。κ は読み出しが旧ラベルから学んだ量で、v⁰ は旧ラベルと無相関とする。予測は自信のある正答（π_n → e_{y_n}）とする。新ラベルについて平均した切替の押し S_i = Σ_nK_nd_in⟨v_i, π_n − 1/K⟩ は、旧ラベルについても平均すると次になる。

E_old[S_i] = κ(1 − 1/K) Σ_n K_n d_in φ_in

右辺の和を自己形と呼ぶ。

証明。CE の局所勾配は δ_in = ⟨v_i, π_n − y^new_n⟩d_in で、全バッチの一歩は位置 m_i を −ηΣ_nδ_inK_n だけ動かす。新ラベルは独立・一様なので E[y^new_n] = 1/K で、−ηS_i が残る。π_n → e_{y_n} では ⟨v_i, e_{y_n} − 1/K⟩ = Σ_cv_ic(y_nc − 1/K) で、読み出し模型を入れると、その学んだ部分は κΣ_mφ_im(1[y_m = y_n] − 1/K) である。独立・一様なら E[1[y_m = y_n]] は m = n で 1、m ≠ n で 1/K なので、期待は κ(1 − 1/K)φ_in になる。v⁰ の項は無相関の仮定で消える。∎

**自己形の符号** [厳密（ガウス・K 一定）]。z ~ N(m, σ²)、r = m/σ とすると、自己形は N K̄ σ G(r) で、G = E[φ′φ]/σ である。

- leaky では G = ϕ(r) + rΦ(r) + a²[rΦ(−r) − ϕ(r)] で、G′ = Φ(r) + a²Φ(−r) > 0、G(0) = (1 − a²)ϕ(0) > 0、r → −∞ で負である。よって零点 r*₀ はただ 1 つの負の値で（a = 0.1・0.3・0.5 で −1.72・−0.94・−0.55）、その上で G > 0 である。
- ReLU では φ′φ = relu z なので、K_n ≥ 0 なら自己形は Σ_{n∈O}K_nz_n ≥ 0 で（O は開いた入力）、生きた unit では正である。どの分布でも零点は無い。
- ELU（α ≤ 1）では、H(m) = E[φ′φ] の零点 m₀ で H′(m₀) = E[φ′(z)φ(z)z]/σ² > 0 である（z ≠ 0 で φ′φz > 0）。よって零点はどれも負から正への横切りで、高々 1 つである。H(0) > 0 で、m → −∞ では H < 0 なので、零点はただ 1 つの負の値である。零点は幅とともに深くなる（σ = 1・4・16 で r*₀ = −0.72・−2.75・−10.7）[ガウス]。
- SiLU・GELU では、零点は σ < 0.7254・0.4249 にだけあり、σ ≥ 0.3 では r ≥ 0 で G ≥ 0.1085・0.1672 である [ガウス]。

**補題 1 の証明** [厳密（ガウス・K 一定）]。課題の中の学習を除き、切替の押しだけを順に当てた列を考える。K 一定なら位置の動きは全入力の z を同じだけずらすので σ は変わらず、k 回目の切替で Δr_k = −ηκ_k(1 − 1/K)N K̄ G(r_k) である。r ≥ 0 では G に正の下限 G_min がある（leaky (1 − a²)ϕ(0)、ReLU ϕ(0)、ELU は σ ≥ σ₀ で G(0, σ₀)、SiLU・GELU は上の値）。各切替で κ_k ≥ κ_min > 0 なら、r ≥ 0 の間は毎回 δ = ηκ_min(1 − 1/K)N K̄ G_min 以上下がる。よって ⌊r₀/δ⌋ + 1 回以内に r < 0、すなわち p < 1/2 に入る。r*₀ より上では G > 0 なので、押しは位置を r*₀ の側へ動かす。∎

**注（鏡像）** [厳密]。活性化を ψ(z) = −φ(−z) に替え、初期値の符号を対応させ（替えた層の重み・bias と、それを読む層の重みの符号を反転）、同じバッチ順で符号反転に同変な最適化器（SGD・運動量・Adam）で回すと、全時刻で z′ = −z となり、押しの符号は全部逆になる。網の関数がこの写像で変わらず、勾配も同じ写像で写るからである。押しの向きは活性化の形に依り、床のある側が沈める側になるのは上の自己形の符号による。

### C.4 容量の傾き

**命題** [厳密・模型]。ラベルを課題の頭の出力からの差で測り、ラベルの振幅の 2 次まで展開する。古い乱数ラベル Y（平均 0、共分散 σ_Y²I）にリッジで当てはめた点から、新しいラベルで一歩進む。この一歩の、新旧のラベルについての期待は、当てはめが済む極限（λ → 0、𝒦 ≻ 0）で −ησ_Y²∇Φ になる [厳密・極限]。したがって押し A = ∂Φ/∂t は、この極限での切替の期待の一歩である。

証明。網の出力を f、ヤコビ行列を J、E = (JJᵀ + λ)⁻¹ とする。当てはめの 1 次は δ₁ = JᵀEY である。新ラベルについての期待の一歩は −η∇U（U = ½‖f‖²）で、これを 2 次まで展開して旧ラベルで平均すると、方向 u について次になる。

E[∇U·u] = σ_Y²[½D_uΨ + λ(Ju)ᵀE(Jt₁ + q/2)]

ここで Ψ = log det(𝒦 + λ) + λ tr(𝒦 + λ)⁻¹、(t₁)_a = tr(∂_aJ·JᵀE²)、q_k = tr(H_kJᵀE²J)（H_k は出力 k の 2 階微分）である。λ → 0 で E𝒦 → I なので第 2 項は消え、½D_uΨ → D_uΦ となる。∎ λ > 0 では、余白 ⟨Y, f⟩ の傾きの期待はどの λ でも σ_Y²∇Φ に一致するが、一歩そのものには勾配の形でない第 2 項が残る（小さい網の数値で一歩の 0.1〜33%）。

### C.5 読み出しの押し（段 1・段 2）

**命題（射影の式）** [厳密]。読み出しだけで当てはめる最小二乗（λ → 0、列は full column rank、旧ラベルは入力ごとに独立・等分散 σ_Y²）では、unit i の押しの旧ラベルについての期待は σ_Y²⟨P⊥u_i, P⊥φ_i⟩/‖P⊥φ_i‖² である。u_i = (K_nφ′(z_in))_n は位置を動かしたときの出力の向き、P⊥ は他の unit が作れる成分の直交補への射影である。

証明。最小二乗の読み出しは v = (F̃ᵀF̃)⁻¹F̃ᵀY（F̃ = [F, 1]）で、新ラベルの勾配の期待は v_i⟨u_i, f⟩ である。旧ラベルで平均すると σ_Y²⟨u_i, ω_i⟩、ω_i = F̃(F̃ᵀF̃)⁻¹e_i になる。ω_i は他の列と 1 に直交し ⟨ω_i, φ_i⟩ = 1 を満たすので、ω_i = P⊥φ_i/‖P⊥φ_i‖² である。∎ 他の unit が作れる成分を、無し（段 0）・定数（段 1）・定数と自分の z の 1 次式（段 2）と置くのが段の理想化である。段 0 は C.3 の自己形である。

**段 1** [厳密・K 一定]。段 1 の分子は N K̄ Cov(φ′, φ) である。φ′ が単調非減少で φ が増加なら（leaky、ELU α ≤ 1、ReLU）、独立な複製 Z′ を使って Cov(φ′(Z), φ(Z)) = ½E[(φ′(Z) − φ′(Z′))(φ(Z) − φ(Z′))] ≥ 0 で、φ′ が台の上で一定でなければ正である。ReLU では値は (1 − p)E[z₊] である。E[φ′φ] = Cov(φ′, φ) + E[φ′]E[φ] なので、段 0 の釣り合い r*₀ では平均項が共分散を打ち消している。定数を他の unit が引き受けると、非負の共分散だけが残る。

**段 2** [恒等式・厳密]。leaky では φ = az + (1 − a)relu z、φ′ = a + (1 − a)1[z > 0] なので、段 2 の分子は ReLU の量の (1 − a)² 倍である。0 < p < 1 で、開いた側と閉じた側の z の平均を z̄_o・z̄_c、分散を v_o・v_c、q = 1 − p とすると、入力 1 個あたりの分子は次に等しい [恒等式]。

(1 − a)² pq[q·z̄_o·v_c + p·z̄_c·v_o]/Var(z)

これは z で回帰した残りの共分散 Cov(g, h) − Cov(g, z)Cov(z, h)/Var(z)（g = 1[z > 0]、h = relu z）を群の平均と分散で書いたものである。任意の分布では p < 1/2 でも負になりうる（z = (1, 2, −1, −1, −1) で (1 − a)² × (−3/40)）。ガウスでは Stein の補題から Cov(z, h) = σ²p、Cov(g, z) = σϕ(r) で、分子は (1 − a)²σJ(r)、J(r) = (1 − 2p)ϕ(r) + rpq となる。J は奇関数で、r < 0 で正である [厳密]。x = −r、Q = 1 − Φ(x) とすると、0 < x ≤ 1 では ϕ の凹性から 1 − 2Q ≥ x[ϕ(0) + ϕ(x)] で J ≥ xΛ(x)、Λ(x) = ϕ(x)[ϕ(0) + ϕ(x)] − Q(1 − Q) は減少で Λ(1) = 0.0216 > 0 である。x ≥ 1 ではミルズ比の上界 Q/ϕ(x) < (x² + 2)/(x³ + 3x) と ϕ(x)/(1 − Q) < x/(x² + 2) から J > 0 である（Codex の報告 C2-A）。ELU の段 2 は r = 0 の直下に負の楔が残り、正なのは r < r_w(σ) である（r_w = −0.68・−0.23 は σ = 1・4、大きい σ で r_w ≈ −1/σ）[ガウス]。

### C.6 ゲートの押し

**定理 1（放物線の恒等式）** [厳密]。unit j の入力 n のゲート g = d_jn だけを動かすと、シューアの補行列から次が成り立つ。

1/E_rr = c₀ + γ_jκ′_jn(g − d̂_jn)²

r は 1 出力の核では n、多クラスの核では unit の読み出しの向きの行 (v̂_j, n) である。c₀ ≥ λ、κ′_jn > 0 で、c₀・κ′・d̂ は g によらない。det の分解から ∂Φ/∂d_jn = γ_jκ′_jnE_rr(d_jn − d̂_jn) なので、

A^g_j = Σ_n c_jn(d_jn − d̂_jn)、c_jn = e′_jnγ_jκ′_jnE_rr、e′_jn = K_n∂d_jn/∂z

である。なめらかなゲートと K_n > 0 で c > 0 である。1 出力の核では、谷底 d̂ は他の unit のゲートと特徴の 1 次式 d̂_jn = Σ_{k≠j}w_kd_kn + Σ_kw^r_kφ_kn + w¹ で、重みは入力 n のゲートに依らない（primal 形）。

**定理 6（並びの期待値）** [恒等式]。正方行列 M とベクトル x, y を同じ一様な並べ替え ψ で並べると、E[x_{ψ(n)}y_{ψ(m)}] は n = m で mean(xy)、n ≠ m で (N x̄ȳ − mean(xy))/(N − 1) である。これを足し合わせて次を得る。

E_ψ[x_ψᵀMy_ψ] = N(μ_d − μ_o)Cov(x, y) + (1ᵀM1)x̄ȳ

μ_d・μ_o は M の対角・非対角の平均、Cov は N で割る共分散である。M ⪰ 0 なら μ_d − μ_o ≥ 0、1ᵀM1 ≥ 0 である。A^g = γe′ᵀMd（M = Θ∘P、P は E の v̂ のブロック）に当て、組 (e′_n, d_n) を並べ替えると、e′ > 0 のとき Cov(e′, d) ≥ 0 なら E_ψ[A^g] > 0 である。これが並べ替えについての確率の文になるのは、M を unit の並びによらない核（unit の両方の道を除いた核）から作るときである。

**命題（ゲートの共分散）** [厳密（ガウス）]。平滑化したゲート d = a + (1 − a)ℓ(z/τ)（ℓ はロジスティック関数）と z ~ N(m, σ²) について、Cov(e′, d) は m < 0 で正、m = 0 で 0、m > 0 で負である。

証明。X = z/τ ~ N(μ, ν²) とすると、Cov(e′, d) は Cov(ℓ′(X), ℓ(X)) の正の定数倍で、後者は E[k(X, X′); X > X′]（X′ は独立な複製、k(x, y) = (ℓ′(x) − ℓ′(y))(ℓ(x) − ℓ(y))）である。ℓ′ は偶関数で |x| について減少するので、x > y の上では k > 0 ⟺ x + y < 0 である。鏡映 (x, y) ↦ (−y, −x) は {x > y, x + y < 0} と {x > y, x + y > 0} を入れ替え、k を −k に写す。よって Cov は ∫_{x>y, x+y<0} k(x, y)[f(x)f(y) − f(−x)f(−y)] dx dy で、f は X の密度である。ガウスでは f(−x)f(−y)/(f(x)f(y)) = exp(−2μ(x + y)/ν²) で、μ < 0・x + y < 0 なら 1 未満なので、被積分関数は正である。∎ ELU の連続なゲートでは、Cov(φ″, φ′) が r ∈ (r_g(σ), 0) で負になる（σ = 1 で r_g = −0.65）[ガウス]。

### C.7 補題 2 の証明

ガウス・K 一定で、押しを読み出しの分（C.5 の段 1 か段 2）とゲートの分（C.6 の並べ替え平均）の和として評価する。leaky・ReLU では、読み出しの分は段 1 なら全ての r で、段 2 なら r < 0 で正である。ゲートの分は第 2 項が非負で、第 1 項の Cov(e′, d) が C.6 の命題により r < 0 で正である。よって r < 0（p < 1/2）の生きた unit で和は正であり、r*₀ < 0 より下にも押しの零点は無い。ELU ではゲートの符号条件が r < r_g(σ) に限られ、σ ≳ 0.93 のときに限り r*₀ より下の全域が条件の範囲に入る。∎ 並べ替え平均から実際の並びへ移すには、C.9 の H4 を使う。

### C.8 SiLU・GELU

φ″ は |z| > z*（SiLU 2.40・GELU √2）で負なので、定理 1 の c_n は符号つきになる。恒等式は残るが、谷の壁 [−z*, −t₀)（−t₀ は φ の最小点）と z > z* の入力は、谷底の持ち上げなしで浮かせる側になりうる。実際、橋の無い単独の unit で A^g < 0 になる構成がある [厳密]。並びの期待値は E_ψ[A^g] = γN(μ_d − μ_o)[Cov(e′, d) + (1 − T̄)ē′ḡ]（1 − T̄ = 1ᵀM1/[N(μ_d − μ_o)]）で、全ての半正定値 M で非負となる必要十分条件は Cov(e′, d) ≥ 0 と ē′ḡ ≥ 0 である。十分性は係数の非負から、必要性は M = I − 11ᵀ/N と M = 11ᵀ を入れて出る [厳密]。ガウス・K 一定では、段 0・段 1・段 2・Cov(e′, d) が r < 0 の全域で非負になる幅の閾値は SiLU 0.73〜0.94・GELU 0.42〜0.57 である。ē′ḡ には負の帯が残るが、幅 ≥ 0.94・0.57 かつ 1 − T̄ ≤ 2.9 なら、段 1 以上の期待の押しは r < 0 で沈める側である [ガウス・数値]。実状態の 1 − T̄ は最大 0.6 である（付録 D.2 (g)）。

### C.9 橋と H4

**必要条件** [厳密]。定理 1 から A^g_i = Σ_nc_in(d_in − d̂_in)、c > 0 なので、ゲートの分が 0 以下になるには、ある入力で d̂_in ≥ d_in が要る。読み出しの分 A^r < 0 が埋める留め置きには、この条件は要らない。

**持ち上げと必要数** [恒等式・1 出力]。1 出力の核では谷底を unit ごとの持ち上げ Δ_k(n) = w_kd_kn + w^r_kφ_kn に分けられ、自分の項を除いた必要量を w*_n と書くと、d̂_in > d_in ⟺ Σ_{k≠i}Δ_k(n) > w*_n である。ゲートの項 w_kd_kn は、G = (λ + 𝒦)_{∖n∖n}⁻¹ の計量で標的の模様と正の内積を持つ unit で正になる。n で開いた unit（橋）だけでなく、閉じた unit も硬いゲートでは a 倍で持ち上げる（ReLU では 0）。必要量 N_i = Σ_nc_inw*_n と供給 L_k = Σ_nc_inΔ_k(n) を置くと A^g_i = N_i − Σ_{k≠i}L_k なので、ゲートの分が 0 以下なら、供給が正の unit の数は N_i/max_kL_k 以上である（鳩の巣）。

**H4.** 各課題末で、どの生きた unit でも、他の unit の供給の合計が必要量に届かないこと（Σ_{k≠i}L_k < N_i）を H4 とする。これは実際の並びでゲートの分が反転しないことの言い換えで、実測で支える仮定である。一般の定理ではなく、設計した状態では破れる（P155・P152c）。硬い ReLU では閉じた unit の供給が 0 なので、開いた他の unit の数が上の下界に届かなければ H4 が成り立つ。実状態の leaky では、供給が正の unit の数は下界を超えるが、供給の合計は必要量の最大 0.61〜0.92 倍にとどまる（付録 D.2 (e)）。

### C.10 ReLU の止め役と死

**止め役の項** [厳密]。ReLU の閉じた入力では φ′ = φ = 0 なので、自己形の閉じた側の寄与は 0 である（leaky では a²ΣKz < 0）。硬いゲートで全入力 K_n > 0 なら、unit i の核の寄与 𝒦_i ⪰ 0 は、位置の線の上の死んだ半直線 t ≤ min_n(−z⁰_n/K_n) で 0 になる。よって容量はそこで一定で、線の上の最小値をとる。ミニバッチの残差の揺らぎと出力の平均の積の項は、SGD の続く 2 歩で F_i = −η²φ̄_iΣ_nK_nd_inΓ_ntr(C_nΣ_ν) となる（Γ_n = 1 + Σ_jφ̄_jφ_jn ≥ 1、C_n は softmax の曲率、Σ_ν はバッチの雑音の共分散）。ReLU では φ̄_i ≥ 0 なので、この項は沈める側である（leaky の相 2 では φ̄ < 0 で浮かせる側）。

**死んだ間の勾配と Adam の残り** [厳密]。入力が固定の層で全入力 z_in ≤ 0 なら、unit i の重み・bias・読み出しの列の勾配は、どの損失・バッチでも 0 である。m₀ = v₀ = 0 で重み減衰の無い Adam（β = (0.9, 0.999)）では、最後の 0 でない勾配の後の更新は、座標ごとに向きが −sign(m) で一定である。その和の大きさは lr·(|m|/√v)·ρ/(1 − ρ)（ρ = β₁/√β₂、ρ/(1 − ρ) = 9.05。偏りの補正の比は 1 以下）以下で、コーシー・シュワルツから |m|/√v ≤ (1 − β₁)/√((1 − β₂)(1 − ρ²)) = 7.27 なので、座標あたり 65.8·lr 以下である。この残りで開き直さなければ、死は永久である。

**有限時間の死** [確率・仮定つき]。生きた unit の上端の余白 Y_t = max_nz_in(t) の増分が有界で、Y_t > 0 の間 (S1) E[ΔY | 𝓕_t] ≤ 0、(S2) P(ΔY ≤ −δ | 𝓕_t) ≥ q > 0 なら、有限時間で Y ≤ 0 に達する確率は 1 である。証明: 到達時刻を τ とすると、Y_{t∧τ} + C は非負の優マルチンゲールなので収束し、{τ = ∞} の上では ΔY ≤ −δ が有限回しか起きない。一方 (S2) と Lévy の条件つき Borel–Cantelli の補題からは、{τ = ∞} の上で無限回起きる。よって P(τ = ∞) = 0 である。∎

**全滅** [厳密]。永久に死んだ unit は網の関数とどの勾配からも消える。全部死ねば出力は出力 bias だけの定数で、正答率はそのクラスのラベルの割合（≈ 1/K）になる。

### C.11 三層への移し

**第 2 層** [恒等式]。第 1 層を固定すると、第 2 層から出力までは入力 h1 の 1 隠れ層の網である。平均位置は z̄₂ = W₂µ₂ + b₂、明るさは K2_n = µ₂·h1_n + 1、読み出しは W₃[:, j] で、C.1 の定義と C.3〜C.6 の式がそのまま移る。第 1 層も動く一歩には、上流の項 W₂Δµ₂ と交差項 ΔW₂Δµ₂ が足される。ReLU では h1 ≥ 0 なので K2 ≥ 1 だが、leaky・ELU では K2 < 0 の入力がありうる。

**第 1 層** [厳密・仮定つき]。読み出し g_in = W₃diag(φ₂′)W₂[:, i] が入力に依るので、C.3 の自己形には帰着しない。重み w_n = |g_in|²K_n ≥ 0 で測る段 1 は Cov_w(φ′, φ) = ½Σ_{n,m}w̃_nw̃_m(φ′_n − φ′_m)(φ_n − φ_m) ≥ 0 である（w̃ は正規化した重み）。これを押しと同一視するのは、引く定数が w の重みつき平均のときである。raw では K ≥ 1 で重みが非負だが、std では K < 0 の入力が約 36% あり、この補題の外にある。

**壁** [恒等式・厳密]。bias を除き、重みの x̄ 方向の係数を q、ρ = q²Var(x̄·x/‖x̄‖)/Var(z)、c = (mean K − 1)/sd K とすると、r = sign(q)·c·√ρ である。重みを x̄ に沿って動かすと r は −c に近づき、x̄ に反平行なら一致する。z を x̄ の向きの成分に回帰した切片が非負なら、この道の全体で r ≥ −c である。値は第 1 層 raw −3.83・std −0.40、第 2 層 std −2.0 である。

**ReLU の全死** [厳密]。第 2 層が全部死ぬと g_in は厳密に 0 で、勾配が残るのは出力 bias b₃ だけである。Adam の残りが尽きると網は凍る。

### C.12 Snake 族

帯の中では φ = z + (1 − cos θ)/(2α)、φ′ = 1 + sin θ（θ = 2αz）である。KKT1・KKA は帯の外を直線でつなぐ。

1. K 一定では、段 0・段 1・段 2 の押しは ½E[φ²]・½Var φ・½Var φ⊥ の位置についての微分で、ゲートの分の 2 項は ½Var φ′・½(Eφ′)² の微分である [恒等式]。z の平行移動で微分するとこうなる（段 2 は包絡線の定理による）。
2. φ_{α/λ}(λz) = λφ_α(z) なので、K 一定では押しの符号は r と分布の形だけで決まる [恒等式]。適応尺度の定常では κ = ασ = 0.6√(B/(B − 1)) = 0.620 である（B はバッチの大きさ）。
3. SNA で z ~ N(m, σ²)、θ̄ = 2κr とすると、E[e^{iθ}] = e^{iθ̄ − 2κ²} と Stein の補題から、段 1 は L1/σ = cos θ̄·[2κe^{−2κ²} + (e^{−4κ²} − e^{−8κ²})sin θ̄/(2κ)]（括弧は正）、段 2 は L2/σ = −e^{−4κ²}[κ − (1 − e^{−4κ²})/(4κ)] sin 2θ̄ である。谷 θ̄ = −π/2（r* = −π/(4κ) = −1.27）は、段 1・段 2・ゲートの分の 2 項に共通の安定な零点である [厳密（ガウス・K 一定）]。帯が谷について対称なので、KKT1・KKA でも谷で 4 量は 0 になる。
4. 定常では θ の標準偏差が 2κ なので、どの unit にも φ′ ≥ min(1, 1 − cos 2κ) = 0.675 の入力がある（KKT1・KKA は無条件、SNA は θ が 1 周期の窓に入るとき）。平均の φ′ は SNA・KKA で 1 − e^{−2κ²} = 0.536 以上である [厳密]。

### C.13 幅の収支

**恒等式** [恒等式]。課題 t の末の第 1 層の重みを W_t、固定した入力の中心化した共分散を Σ とし、⟨U, U′⟩_S = tr(UΣU′ᵀ) と置く。幅の 2 乗の層の和 V_t = ‖W_t‖_S² は、各ユニットの s_i² の和である。1 課題の変位 D_t を、前の重みに沿う縮み −a_tW_{t−1}（a_t = −⟨W_{t−1}, D_t⟩_S/V_{t−1}）と S 直交な書き込み ξ_t に分け、q_t = ‖ξ_t‖_S²、b_t = 1 − (1 − a_t)² とすると、ピタゴラスの等式から V_t = (1 − b_t)V_{t−1} + q_t である。

**補題（伸び続ける条件）** [厳密]。書き込みを q_t = g(V_{t−1})（g は非減少）と置き、0 < b_{t+1} ≤ b_t < 1 とする。ある課題で幅が伸びれば、以後の課題でも毎回伸びる。証明: V_t は V_{t−1} と q_t/b_t の凸結合なので、伸びた課題では V_{t−1} < V_t < q_t/b_t である。次の課題では q_{t+1}/b_{t+1} ≥ g(V_t)/b_t ≥ g(V_{t−1})/b_t = q_t/b_t > V_t なので、また伸びる。あとは帰納法による。∎ 補題は毎回伸びることだけを言い、上に有界でないことは含まない（g と b が一定なら V_t は q/b に収束する）。

**Adam の尺度** [厳密・ε = 0]。leaky ReLU の正の同次性から、第 1 層の重みと bias を 1/γ 倍、第 2 層の重みを γ 倍しても網の関数は変わらない。このとき勾配は (γ, 1/γ) 倍に写り、モーメントも同じく写すと、ε = 0 の Adam では座標ごとの m̂/√v̂ が変わらない。よって、移した状態から共通の学習率で回した軌道は、元の状態から第 1 層の学習率を γ 倍、第 2 層を 1/γ 倍にして回した軌道の像に一致する。関数を変えない尺度の違いは、各層の相対速度（学習率 ÷ 重みの大きさ）の違いと同じである。重みを伸ばすと相対的な歩幅が下がり、成長上限はこの低下も抑える（§4.5.1）。正規化層を持つ網での同様の機構と Normalize-and-Project は既知である [6,14,15]。

## 付録 F　kunekune の裾と活性化の比較

### F.1 変種と裾の比較

比較したのは適応 Snake、KKA、KKA23、KKT1 の 4 種である。KKA は位相 $\theta=2\alpha z$ が $[-3\pi/2,\pi/2]$ の外で傾き 2 の直線となり、継ぎ目は $C^2$ である。KKA23 は KKA の 2/3 倍とする。KKT1 は $[-2\pi,\pi]$ の外で傾き 1 の直線となり、左では $z$、右では $z+1/\alpha$、継ぎ目は $C^1$ である。α の適応則は共通で、走行統計に勾配を通さず、追加の学習可能な倍率・シフトは持たない。

乱数ラベル CIFAR × MLP（seed 0–9・raw/std）では、4 本の後期窓の差は raw 0.6 pt、std 0.1 pt 以内で、5 位との差（raw 9 pt）より小さかった。KKA23 − KKA は raw で `SCALE_MATTERS_DOWN`、std で `SCALE_MATTERS_UP` と符号が反転した。縦スケールの変更は次層の初期重み・学習率の変更にも対応するが、Adam で厳密に対応させるには $\epsilon\to\epsilon/k$ も必要であり、ここでは歩幅単独の効果を同定していない。

適応 α が追うのは分布幅である。EMA が幅に追随し clip が効かなければ $\mathrm{sd}(\theta)\approx1.2$、$\mathbb E[\theta]\approx1.2\bar z/\sigma_z$ となる。このため、共通位置が沈めば、曲がりを持つ有限の帯から出る。今回の 50 課題では分布の大部分が帯内に残ったが、KKA/raw の帯外率は t50 で第 1 層約 4.5%・第 2 層約 2.5%、t1 の第 1 層は約 21.7% だった。

### F.2 尺度の適応と固定

乱数ラベル MNIST の MLP では、固定 α = 0.6 と 3 の後期 online は 0.9497・0.9003、適応 Snake は 0.9859 だった（窓の seed 平均、−3.6・−8.6 pt）。RL-CIFAR ではこの固定 α 比較は行っていない。

5+1 CIFAR の `controls_cifar5p1_1008` では、初期値 α = 0.6 で固定すると、適応する SNA・KKT1 より後期窓の online が 6.1・4.6 pt 低かった（97.5% 区間 [+5.5, +6.8]・[+3.8, +5.4]、10/10、`ADAPTIVITY_MATTERS`）。早期窓には差がなく（0.689 対 0.688）、課題とともに差が開いた。

一方、課題 1 末の α で固定した条件は、継続して適応する条件を後期窓で 0.7・1.1 pt 上回った（95% [+0.1, +1.3]・[+0.5, +1.7]、副比較・報告のみ）。この 30 課題では最初の幅への適合で足りたと読める。

z を幅で割って固定 α の Snake に入れる条件は R と区別できず（後期窓 0.460 対 0.437）、幅による正規化だけでは同じ結果にならなかった。1 隠れ層 MNIST の事後実験では固定 α でも沈降・喪失がなく、適応の必要性は実験設定に依存する（[[V12_§4_詳細版_1015]] 旧 §4.6）。

5+1 CIFAR の KKT1 − 適応 Snake の後期差は +0.0027、20 seed の差の中央値の区間は [−0.0001, +0.0042] で、登録帯 ±0.005 内の `EQUIVALENT_WITHIN_0.005` だった。この同等性を踏まえ、本文では単純な KKT1 を代表腕とする。

## 付録 H　CNN での追加検証

CNN の測定は MLP の主理論の適用範囲を調べる追加実験である。以下の分解は保存した状態での恒等式・実測で、学習履歴の因果を直接示さない。[登録] は走る前の規則による判定、[事後] は結果を見た後の分析を表す。率は seed ごとの割合の 10 seed 平均、区間は t 分布の 95% 区間。

### H.1 設定と現象

Kumar ら [4] の CNN（conv 5×5 3→16、pad 2 → φ → maxpool 2 → conv 5×5 16→16、pad 2 → φ → maxpool 2 → fc 1024→100 → φ → fc 100→100 → φ → fc 100→10、全層 bias あり）を使用した。RL-CIFAR は固定 1,200 枚、入力 [0,1] とし、画像ごとに独立な一様乱数ラベルを課題ごとに更新した。batch 16、400 epoch = 30,000 更新/課題、Adam 1e−3、WD なし、seed 10〜19 とした。入力 conv を c1、次を c2、全結合隠れ層を f1・f2 とする。

leaky 0.1（LR）、適応 Snake SNA（全層 c = 0.6）、SNAc3（全層 c = 3）、CV06FC3（conv c = 0.6・fc c = 3）、CV3FC06（逆）を比較した。SNAc3 の conv の α は上限 3 に張り付くが、fc は適応を続ける。Snake の基本比較は 50 課題、他は 30 課題。

online は LR 0.965→0.889（課題 1→30）、SNA 0.977→0.939、SNAc3 0.972→0.965（課題 1→50）。課題 30 に初期値より沈んだチャネルは c1 で Snake 85%・LR 93%、c2 で 99〜100%。c1 の位置は平均パッチ m による z̄_j = ⟨W1_j,m⟩+b1_j で、LR の Δz̄ の中央値 −2.67 は重み側 −2.53 と bias 側 −0.23 に分かれた [恒等式・実測]。出所: `cnn_drive_verify_1009`・`cnn_center_1010`。

### H.2 中心化

**leaky の入力中心化。** LRc は入力から訓練集合のチャネル平均 (0.491,0.482,0.447) を引く。平均パッチのノルムは 3.76〜3.84→0.015〜0.050、c1 の沈降は −2.70→−0.92（比 0.34、10/10 seed でなお沈降、`C1_PARTIAL`）。残る沈降は bias が運び、c2 は両腕とも全チャネルが沈む。online の早期（課題 1〜5）から後期（26〜30）への低下は 0.077→0.031（`LESS_LOSS`、10/10）、課題 30 は 0.889→0.943 [登録]。中心化は zero padding の意味や初期ゲートも変えるため、成績改善を c1 の沈降だけには帰せない。

**ReLU の中心化（P181）。** C は色チャネル平均を引く。H は pool 後のチャネル平均と fc の unit 平均を EMA（β 0.01、勾配なし、訓練・評価共通）で引き、CH は両方を組み合わせる。主窓 t21–30 の online ≥ 0.5 が 9/10 seed 以上なら `RESCUED`、1/10 以下なら `FAIL` とした。ref・C は `FAIL`（主窓中央値 0.112）。H・CH は登録した記録要件がほぼ全滅の層を扱えず `INAPPLICABLE`。要件を外す事後集計では H 0.112・CH 0.115 でともに `FAIL` だった。CH は T_f の中央値を ref の 3 から 10.5 へ遅らせるが、10/10 seed で残余の低下がある。

ref・C は c2、H は f1 が先に低下した。H が消すのはチャネル平均で、f1 入力の位置ごとの平均は残る。CH でも f1 は平均方向の経路、他層は bias の経路で沈んだ [事後・実測]。

**全特徴の中心化（P183）。** pool 出力をチャネル×位置ごとの EMA 平均で引く H′（c1 後 4,096・c2 後 1,024 特徴）と、色の C を足した CH′ を同じ 10 seed・30 課題で検証した。fc の中心化は H と同じ。入力 c1 は色の中心化であり位置ごとの中心化ではない。ref・C・H・CH は P181 の走を再利用した。EMA の記録要件は本走前に修正し、救済の閾値は同じとした。

| 腕 | 主窓 online の中央値（範囲） | online ≥ 0.5 | T_f 中央値 | 登録判定 |
|---|---|---|---|---|
| H′ | 0.114（0.110〜0.122） | 0/10 | 9 | FAIL_ABOVE_FLOOR |
| CH′ | 0.178（0.111〜0.917） | 1/10 | 16 | FAIL_ABOVE_FLOOR |

要約は `CENTERING_NOT_A_DOOR_IN_CNN`。CH′ の主窓は CH より高い（9/1、対応差中央値 0.047）が、T_f は CH と区別できず（7/3、`NO_TIMING_DIFF`）、10/10 seed で残余の低下があった。CH′ の T_f は ref より遅い（10/0）。中心化の位置を並べ替える対照は 1 seed のみで、H 側の対照は H に近く、CH 側は判別不能だった。

この中心化は f1 入力の平均を偏差比 0.13〜0.14→0.009 へ減らしたが、CH′ では全 4 層で bias の経路による沈降が残った（課題 30 の Δb は −1.04・−10.5・−6.5・−6.0、死亡率 0.77〜0.88）。最初に低下する層は c1（10/10）へ移った [事後・実測]。この箱では全特徴の中心化を加えても 30 課題の喪失を防がない。bias への介入と 50 課題での持続性は未検証。出所: [[入力を中心化したleakyCNN_結果_1010]]、[[ReLUのCNNに中心化の扉_結果_1011]]、[[ReLUのCNNに全特徴の中心化_結果_1011]]、P181・P183。

### H.3 押しの向き

c1 の切替の押しを G_j = E_new⟨∇z̄_j,∇L⟩ とする。一様な新ラベルの期待は厳密で、G_j = Σ_{n,q}γK1H1_j（γ は pool の勝者ゲート、K1 は平均パッチ方向の接線、H1 は pool 後出力への逆伝播）。G > 0 が沈める側である。H1 を自分の出力で置き換えた自己形は、c1 の押しを予測しない。課題 1・2・5・10・20・30 の符号一致は Snake 0.55・LR 0.25、押しが沈める割合は c1 0.51・0.29、c2 0.68・0.88。c2 では Snake の谷の則との AUC が 0.94、c1 は 0.53だった [実測]。

G は下流の余接の平均が接続カーネルを通る定数成分と、中心化した残りへ分かれる [恒等式]。LR の c1（課題 5〜20）では定数成分が 86〜95% で浮かせる側、残りが 93〜99% で沈める側で、全体の符号は前者に 89〜95% 一致する [事後・実測]。現在の µ₂ に沿う接続重みの成分は符号則 −sign(P̄1_j) に従うが全体を支配せず、登録判定は `DRIFT_SIGN_ONLY`。計算前に立てた LRc の予測（c1 は浮く・drift は浮く・c2 は沈む）は、3/3 一致した。c2 の押しの大部分（課題 10 以降の分担中央値 0.96）は上流の変化だった。出所: [[CNN駆動源理論を実軌道で数値検証_結果_1010]]・[[入力層の押しの向き_定数モードと残りの競合_結果_1010]]。

### H.4 課題の中

課題 1・10・20 の末から同じ軌道を再走した。Snake の c1 は切替後 10 更新で 77%・64%・55% が下がってから戻る。LR は逆に上がり（中央値 +0.13・+0.79・+0.59）、課題内の当てはめで沈む。1 課題の正味で沈むチャネルは両活性化とも 50〜56% で、単調でない動きが長期には沈降として積もる [実測]。したがって、切替の押しが沈降を運ぶという MLP の相 1 の記述は CNN の入力層へそのまま移らない。

LR の課題 10→11・20→21 で、平均パッチ方向の重み成分が安定区間の c1 の変位の 0.92〜1.03 を占めた。ただし「結合変化の半分以上が最初の 75 更新に起きる seed が 8/10 以上」という登録判定は 7/10・6/10 で不支持。1 課題の正味の沈降を与える式は未導出。出所: `cnn_drive_verify_1009`・`c1_direction_1010`。

### H.5 Adam と十分条件

保存した Adam 状態から新ラベル・batch の期待を 65,536 標本で評価すると、最初の 1 歩が SGD の期待 −G と有意に反転する割合は通常 c1 0〜1.7%、c2 0〜4.4%（課題 1 の LR は 4.4%・10%）。古い m を消しても変わらず、Snake c2 の反転の 98% は座標倍率に由来する。10 更新の符号一致は、パラメータを固定した参照と実軌道で Snake 0.86 対 0.59、LR 0.94 対 0.87。固定状態からのずれにはパラメータの移動が大きく寄与する [実測]。

CNN 用の画像ごとの CE 十分条件 3 種について、全 1,200 枚で成立する実状態は、調べた 300 状態（Snake 240・LR 60）中に無かった。凍結 CNN・二乗誤差・有限 ridge の線形 head には切替期待の条件つき定理があるが、自己形が沈める側でも他チャネルにより全体が浮く反例もある。特殊な入力・初期化での長期沈降の存在証明は、平均が負になること・死・喪失を示さず、ここでの CE・Adam の実測を覆わない。証明・反例: `analysis/cnn_drive_1009/`、[[CNN駆動源_有限強度の符号保証_1009]]（CE 条件は `ce_trained_state.md` (3)(5)(8)）。

### H.6 適応 Snake の劣化

SNA は SNAc3 より初期成績が高いが課題 13 以降に逆転し、主窓 t31–50 で 0.9457 対 0.9606（10/10 seed）だった [登録]。層別 c の比較の初期判定 `FC_LOCUS` は、fc のみ c = 3 にした腕の尺度暴走に影響されたため、追加介入は t11–20・t21–30 で評価した。これらの窓は事後に選んだ。

### I.2 限界の詳細（§8 の補足）

**介入と比較。** 成長上限の救済は ELU の二つの課題設定で得られ、ReLU の正則化効果は課題設定と正則化の基準値によって異なった。成長制限と実効学習率の効果は分離していない。応答場の復元は人工的な関数変更による回復である。中心化・予算・層別キメラ・凍結窓の対照範囲は付録 B・G.2・F.4・D.2（図 D8）、手法比較の条件は付録 A.2 にまとめる。

S&P・CBP・ReDo との比較は lr = 1e−4 固定・文献の既定値を中心とする小さい較正格子であり、Kumar ら [4] が選んだ lr = 1e−3 や手法別の学習率最適化を含まない。kunekune・適応 Snake は共通の既定値を用い、調整した L2 Init と同等だった。

**理論の条件と未解決点。** 仮定と実測の対応は表 C1・表 D5 にまとめる。

1. **停止位置。** leaky の停止位置と漂い、Snake 族の谷からのずれは未導出である。ReLU で同定済みの止め役が無いことは、全項の不在証明ではない。
2. **読み出しの押し。** 読み出しの分には負になる構成がある。その反転にも橋が必要かは未解決である。
3. **橋と H4。** 必要数の下界は状態から求まるが、留め置きの割合には (B′)・(N*) と時間割合への接続の仮定が要る。被覆の実測は leaky に限り、訓練がその統計を保つ理由は未導出である。
4. **実訓練への接続。** 凍結・線形化・二乗誤差の模型の期待値を、CE・Adam の全訓練軌道へ移す証明はない。ReLU の有限時間の死には未導出の S1・S2、永久の死には Adam の残りで開き直さない条件が要る。
5. **進行と時間。** 前活性幅が伸びる理由（H5）は未解決で、重みノルムの増大とは別である。沈降の速さと層の順序は未導出であり、切替前の課題 1 内の落下は切替の押しでは説明しない。
6. **実ラベル。** 乱数ラベルの導出は 5+1 に一般化しない。固定 α の Snake・大 α の ELU は向きの補題の外にあり、適応 Snake 族には谷の止め役の文を用いる。
7. **第 1 層。** std は向きの補題の外にあり、raw でも実際の切替の押しが常に沈めるとは限らない。定数モードの分担と、第二の箱の戻り・CNN 入力層の押しを運ぶ機構は未解決である。
8. **活性化の条件。** SiLU・GELU の進行はガウス・K 一定・幅 ≥ 0.94・0.57・1 − T̄ ≤ 2.9 の下での文である。実状態の深い帯には浮かせる押しがあり、H4 の橋の縛りも両活性化には移していない（付録 C.8・C.9）。
9. **第 2 層。** 理論は上流を固定して照合する。上流の変化と、第 1 層の機能低下後に現れる押しの反転はその範囲外である。層の順序の場合分けは理論と実測を合わせた解釈である。
10. **時刻。** T_d は課題末、T_f は課題内平均から決めるため、同じ課題内の先後は決められない。z と訓練微分による定義も異なり、leaky の z による開いた割合は代用指標である（表 D1）。

**実装依存。** MNIST 系の float32 ELU（expm1 実装）の微分の零点 −16.64 は F.elu 等とは異なる。float64 と床の無い実装でも崩壊は再現するが、凍結の形は変わりうる（付録 I.3・D.2 (o)）。

### I.3 数値実装と低下時刻

MNIST の当該 float32 実装では、全勾配と残留更新が尽きて凍結することを確認した。一方、float64 の F.elu でも同じ有限予算で崩壊した。したがって、微分が厳密に 0 になることは崩壊の必要条件ではない。個々の入力の微分、全入力の勾配、Adam の残留更新は区別して測る。

低応答率 Q と機能低下の時刻も別の指標である。RL-CIFAR の ELU・std では、第 2 層の Q が過半を越えた課題 2 に、online が 0.983 から 0.920 に下がった。online が 0.5 を割ったのは課題 3 だった。付録 D.2 の T_d（開いた割合の unit 中央値 < 1%）と T_f（適合率 < 1/2）は、この箱の seed 0〜2 ではともに課題 3（T_d は z、訓練微分 d では 3〜4）である（付録 D.2・表 D1）。
