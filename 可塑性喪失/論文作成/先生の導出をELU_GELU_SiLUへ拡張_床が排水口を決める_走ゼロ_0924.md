## 0. 一言で

**Issa の 3 つの問いへの答え（0924 夜、§9 で raw の数値）**: (1) 通用するか — 帳簿・供給側・ラベル平均の勾配は活性化に依らず通用する。leaky 固有なのは排水口で、床 s を入れれば通用し、それが「Leaky より悪化」を出す。(2) 命題 2 が落ちると — 供給の弾性 β が ½ → 0 に落ちる（増えた幅が飽和した対に入り勾配を運ばない。raw の EL で実測 .01 対 LL .53）ので**供給の速度は縮む**が、排水口も同時に閉じる（a → 0・増幅）ので**正味の幅は釣り合いなしに伸び、t50 で leaky の 3〜4 倍**。(3) 谷を越えるほど・勾配が消えるほど幅が増えるか — **言える（§10、訂正あり）**。初期化の unit の sd は raw 0.135・std 0.54 で全対が遷移帯（|z|<3）の中にあり、課題 1 で幅が 30〜100 倍に伸びて負側の対が谷の先へ出る。幅だけ伸ばした反実仮想で約半分が越え、相対位置だけ動かすと 0。伸びる理由は leaky と同じ（Adam の 1 歩は活性化の尺度を知らない、課題 1 の倍率も同じ）で、違うのは越えた先で φ′ が消えるかどうか（leaky は 0.1 のまま）。層が全部死ぬ（p⁺ → 0）には相対位置（①）も要る。


先生の稿で leaky 固有なのは 2 か所。**蛇口側の命題 2（Adam の尺度対称性）** は leaky の正斉次性を使うので ELU・GELU・SiLU では成り立たないが、先生がそこから使っているのは「1 歩の生の大きさは幅に依らない」だけで、それは Adam の座標正規化そのものであり、勾配が ε より十分大きい限り活性化によらない。実測でも **書き込みの係数 A = ‖ξ‖_S / σ₁^½ は生存 9 腕（leaky 0.3/0.1/0.01・Smooth-Leaky・RSL・Snake 族 4 種）で 11.7〜16.1 に揃う**。壊れるのは「幅を変えても関数が変わらない」という部分で、床のない活性化では幅が（相対位置 × 幅 ＝ 絶対の深さを通して）ゲートを決める。これがそのまま本稿の ③（固定尺度は戻れない）になる。

**排水口側（消去）が本当の leaky 固有の環**。消去は Jacobian J = W₃ diag φ′(z₂) W₂ diag φ′(z₁) を通るので、第 2 層の訓練ゲート φ′(z₂) が因子として掛かる。第 2 層は全腕で沈む（z̄₂/σ₂ ≈ −0.8〜−2.0、①）ので p⁺₂ = P(z₂>0) は小さく、平均ゲートは ḡ₂ = p⁺₂ + s(1−p⁺₂) で **床 s に支配される**。消す割合 a はこの ḡ₂ に追随し（9 腕・Spearman .96）、leaky 梯子で s に単調（.185 / .113 / .016）。釣り合う幅 σ* = A²/(a(2−a)) は s → 0 で発散する（s = .01 は t50 で LR の 3.4 倍、まだ釣り合いから離れつつある）。**s = 0 の 4 腕（ReLU・ELU・GELU・SiLU）は崩壊の 2〜3 課題で a < 0（書き込みが既存の蓄えを増幅、LR の 2〜3.5 倍書く）ののち p⁺₂ = 0 で蛇口も排水口も閉じて凍結する**（課題末の W₁ が bit 一致）。ELU だけ 2/10 seed が正の対を数十残して自己膨張を続ける。

→ **Issa の「Leaky より悪化」は先生の変数で成立する。悪化は蛇口ではなく排水口で起き、3 段になる: (1) 床が薄いほど排水口が細く幅が伸びる（梯子・生存）、(2) 床が無いと崩壊局面で排水口が逆流し（増幅）、(3) 直後に蛇口ごと閉じる（凍結、可塑性 0）。**

## 3. 拡張した導出（どこまで言えるか）

**残る（仮定なし）**: 命題 1（恒等式）、Green-Kubo、ラベル平均の勾配、線形回帰の対比、命題 3（代入）。

**命題 2 の置き換え（仮定つき）**: 「勾配の各座標が ε より十分大きい間、Adam の 1 歩の生の大きさは重みの尺度に依らない」。証明は座標正規化そのもの（m と √v が同じ因子で変わる）で、関数を保つ付け替えは要らない。leaky では付け替えが存在するので「同じ関数・同じ 1 歩」まで言えるが、ELU・GELU・SiLU では「同じ 1 歩・違う関数」になる。走ゼロの証拠: A が 9 腕で揃う（§2.3）。β = ½ の導出（持続時間 ∝ σ/η）は尺度崩壊を使うので厳密には失われるが、生存腕で経験的に .35〜.58。

**排水口の因子（構造・厳密）**: 消去の 1 次（支持）も 2 次（曲率）も J_n = W₃ diag φ′(z₂ₙ) W₂ diag φ′(z₁ₙ) を通り、第 2 層の訓練の微分 φ′(z₂ₙ) が (unit, image) 対ごとに因子として掛かる。leaky ではこの因子が全対で ≥ s。床なしでは z₂ < 0 の対で e^{z}・Φ(z)+zφ(z)・σ(z)(1+z(1−σ)) と減り、p⁺₂ = 0 かつ |z₂| が大きければ全対で 0（ReLU・GELU は厳密、ELU・SiLU は float32/ε の下）。**このとき消去も供給も 0（凍結）。** ノルムの下限 a ≥ a_min(s) > 0 のような不等式は、J の中の diag が W₃ の行空間から向きを外しうるので示していない。言えるのは因子の構造と、a が ḡ₂ に追随する実測（Spearman .96）まで。

**命題 3 の帰結**: σ* = A²/(a(2−a))。A が活性化によらず a が床で決まるので、釣り合う幅は床の単調減少関数。s = .3 / .1 / .01 で 471 / 851 / 4,041（t41–50）。s → 0 で発散。

**新しい命題（事後・機構は候補）**: 床なしの活性化で第 2 層が p⁺₂ ≈ 0 に沈む途中（崩壊の 2〜3 課題）、少数の生きた対の勾配が Adam に正規化されて x̄ に揃った全速の一歩になり、既存の蓄え（top 帯）と同じ向きに乗る（a < 0）。leaky ではこの局面でも a > 0。機構の候補は [[第1層の増幅器はAdamか_ε介入_le_eps_cifar_0922_結果]]・[[押しは切替で作られるか_凍結窓_0922]] の「少数対 → ±x̄ の一歩 → 反平行 W₂」で、この走ゼロでは向きと符号だけを確かめた。

## 4. 「Leaky より悪化」の 3 段（Issa の仮説の判定）

1. **床が薄いほど排水口が細く幅が伸びる（生存したまま）**: 梯子で a が s に単調、A は同じ。LK001 は t50 で LR の 3.4 倍の幅、釣り合いから離れつつあり、online −7.4 pt。→ 先生の式で σ* ∝ 1/(a(2−a)) と読める。

### 10.3 leaky と同じ理由か

- **課題 1 で谷を越えるほど伸びる理由は leaky と同じ。** 倍率も書き込みの大きさも同じ（std の t1 の ‖ξ‖: LR 174・ELU 168・GELU 196・SiLU 197。raw: LL 95・EL 157・GL 141）。Adam の 1 歩は勾配の大きさにも活性化の尺度にも依らない（命題 2 の残る部分）ので、初期化の 0.1〜0.5 から数十まで、どの活性化でも伸びる。
- **違うのは伸びた先で何が起きるか。** leaky には固有の尺度が無く（命題 2 の対称性）、z<−3 に入っても φ′ = 0.1 のままで勾配は小さくならない。ELU・GELU・SiLU は尺度 ≈ 1 を持つので、同じ伸びで負側の φ′ が 0 に向かう。**命題 2 が成り立たないことの中身は「幅に意味がある」ことで、それがそのまま「同じ伸びで勾配が消える」になる。**
- **課題 2 以降は理由が分かれる。** leaky は排水口（a ≈ .15）で釣り合い、50 課題で raw ×2・std ×5。床なしは排水口が φ′ を通るので閉じる（raw EL a ≈ 0 で ×3）か、崩壊局面で増幅する（std ELU t1→t5 ×7.8、LR ×2.1）。std GELU・SiLU は t1→t5 で leaky の 50 課題分（×4.8〜5.1）を 4 課題で伸びてから凍る。ここは leaky と違う理由（§2.4・§9.2）。

### 10.4 言えないこと

課題 1 の書き込みが活性化の尺度の何倍になるかの下限（どの層で尺度を稼ぐかは決まらない。実測は 10〜20 倍）。幅だけで層が死ぬこと（半分止まり）。課題 2 以降に伸び続けること（std の床なしは t5–10 で凍って止まる）。
