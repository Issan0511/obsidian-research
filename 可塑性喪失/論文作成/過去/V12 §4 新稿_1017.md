## 3 入力平均の投影と中心化の効果

入力平均がゼロでない層では、特徴を学ぶ重みの更新が、前活性分布の共通位置も動かす。中心化はこの経路を抑えるが、bias が位置を動かす経路は残る。

### 3.1 重みの更新は、入力平均を通じて共通位置も動かす

ある層の入力を $x$、その平均を $\mu$ とすると、ユニット $i$ の前活性は

$$
z_i(x)=\underbrace{w_i^\top\mu+b_i}_{\text{共通位置 }\bar z_i}
+\underbrace{w_i^\top(x-\mu)}_{\text{入力ごとの揺らぎ}}
$$

と分けられる。特徴を学ぶ重み $w_i$ は、入力ごとの揺らぎを変えると同時に、その入力平均方向の成分を通じて共通位置も動かす。bias は、入力平均を介さずに共通位置を動かす。

層入力を固定し、重みと bias を同じ学習率 $\eta$ で一標本 SGD 更新すると、局所勾配 $\delta_{in}=\partial\ell_n/\partial z_i(x_n)$ に対し、共通位置は

$$
\Delta\bar z_i=-\eta\,\delta_{in}K_n,\qquad
K_n=\mu^\top x_n+1
$$

と動く。この $K_n$ が §4.1 の「明るさ」で、$+1$ は bias の寄与である。raw 画像や中心化前の ReLU 出力は成分ごとに非負なので、各入力で $K_n\ge1$ となり、正の局所勾配は共通位置を下げる。

平均の正値性は各入力の正値性や §4.1 の「$K$ 一定」を保証せず、std では負の $K_n$ もあり得る（§4.4）。

層入力を厳密に中心化すれば $K_n=1$ となり、共通位置を動かす bias の経路だけが残る。ただし、ReLU は次層に非ゼロの平均を再び生み得るため、中心化は外部入力と中間層の両方に施す。

### 3.2 中心化とbias抑制で、200課題まで高い成績を保った

乱数ラベル CIFAR（raw）を学ぶ二隠れ層 ReLU 網で、入力平均を引く C と、両隠れ層の出力平均を引く H を組み合わせた CH を調べた。H は平均を指数移動平均（EMA）で推定するため、実平均を厳密にゼロにする操作ではない。残る bias の経路も抑える CHB は、CH に第1層 bias の毎更新後のゼロ化と、第2層 bias への decoupled weight decay を課題1から加えた条件である。

C は第1課題を学べたが、課題を重ねると成績が低下し、CH は全10 seed で C を上回った（表1）。C では第2層、H 単独では第1層が死亡し、CH は両層を保った（付録 E.2）。

#### 表 1　中心化条件と50課題の成績

| 条件 | 課題31–50の online 精度 |
|---|---:|
| C：入力のみ | 11.33% |
| CH：入力＋中間層 | 98.67% |
| CHB：CH＋bias 抑制 | 98.54% |

各 seed の窓内平均の10 seed 中央値。層別診断と H・分散正規化・LayerNorm の対照は付録 E.2。

中心化だけで長期に成績を保てるかを、新たな10 seed（10–19）で200課題まで調べた。課題181–200の online 精度は CH が62.98%、CHB が99.03%だった（seed 間平均）。全10 seed で CH は成績が低下し、CHB は高成績を保った。対応差（CHB − CH）の平均は36.05ポイント［95%信頼区間：20.45–51.65］だった（付録 E.2）。

入力を中心化した第1層の共通位置は bias そのものであり（z̄₁ = b₁）、CH ではこれが負側へ沈んだ。CHB は両層の bias の寄与を小さく保った（付録 E.2）。

## 4 駆動源の理論と活性化ごとの機能低下

本章では、乱数ラベルを学ぶ一隠れ層網について、課題切替後の最初の更新が前活性の共通位置に与える変化を解析し、幅の成長による応答の変化と介入につなぐ。訓練した網を「実網」と呼び、仮定を置いた模型の結果と区別する。仮定の一覧は付録 M、実測との照合は付録 K.4 に示す。

各ユニットの共通位置を m（入力についての平均、§3.1 の z̄_i）、分布幅を s（標準偏差）、相対位置を r = m/s、正の前活性を持つ入力の割合を p とする。正側の入力を「開いた入力」と呼び、これを持つユニットを「生きたユニット」、全入力で前活性が 0 以下の状態を「全閉」と呼ぶ。開閉と区別して、活性化の傾き d = φ′(z) を局所応答として調べる。以下で「ゲート」と呼ぶのもこの傾き d である。

### 4.1 負側へ動く理由

§3.1 の局所勾配と明るさの積を各入力について足し、新ラベルで平均した量を、切替の「押し」と呼ぶ。正の押しは、最初の勾配更新で共通位置を下げる。前の課題を学んだ読み出しへの切替の押しが位置を運ぶ時期を相 1、切替の押しが細り、模型の外の止め役と釣り合った後を相 2 と呼ぶ。以下では、それぞれの時期の押しを異なる模型で調べる。

#### 4.1.1 初期に大きく負側へ偏る理由

<!-- G3 -->
**切替の押しの期待は、出力と傾きの積からなる「自己形」に従う。負側の応答が弱いと、正側の入力が少数になるまで沈める押しが続く。**

新ラベルは網の状態と独立・一様とする。特徴を固定し、独立・一様な旧ラベルを読み出しが勾配学習で自信をもって正しく当てる模型（H1）を考える。新ラベルで平均した押しを S_i とし、初期読み出し項と旧ラベルの相関を 0 と置くと、旧ラベルについても平均した押しは

E_old[S_i] = κ(1 − 1/K)Σ_n K_n d_in φ_in

となる [厳密な極限]（付録 K.2(b)）。φ_in と d_in はユニット i の入力 n に対する出力と傾き、K_n = x̄·x_n + 1 は §3.1 の明るさ（x̄ = μ）、K はクラス数、κ は読み出しが勾配で育った量である。右辺の出力と傾きの積を明るさで重みづけした和が自己形で、正なら共通位置を下げる。この導出は活性化の形によらず、整流型の leaky ReLU・ELU（α ≤ 1）・ReLU（H0）にも、SiLU・GELU にも共通する。

前活性をガウス分布、明るさを正の一定値とする（H3）。**正負の入力が半々でも、自己形の押しは釣り合わない。** 例えば leaky ReLU では、出力と傾きの積は正側で z、負側で a²z となり、同じ絶対値の前活性なら、浮かせる寄与は沈める寄与の a² 倍しかない。a = 0.1 では、自己形の零点で正側に残る入力は約4%にすぎない（p = Φ(r)、Φ は標準正規の分布関数）。このように、負側の応答の弱さが釣り合い自体を大きく負側へ偏らせる。初期位置から向かう自己形の安定な釣り合いを r*₀ と呼ぶ。


**補題 1（負側の釣り合いへ向かう）。** 自己形の釣り合いがある場合、各課題末で H1 と付録 K.2(b) の活性化ごとの幅条件が保たれると、同じ理想化の下で、r*₀ より上では期待の押しが沈める側に働き、位置を r*₀ へ向ける。r ≥ 0 では押しの大きさに正の下界があり、有限回の切替で p < 1/2 に入る。この領域で残る押しを次節で調べる。ReLU は負側の寄与が 0 のため釣り合いが無く、各入力で K_n > 0 なら、生きている間は沈める押しが残る（付録 K.2(p)）。

釣り合いの有無と幅による違いは §4.2 に示す。以上は切替の期待の押しについての結論であり、課題内の係数変化と H1 の持続時間は扱わない（§9）。実網の初期の沈みとの照合は、付録 K.4 の表 8 と K.2(b) にまとめる。

#### 4.1.2 沈んだ後も押しが残る条件

<!-- G4・G9 -->
相 2 の押しを、凍結・線形化した網に二乗誤差とリッジを用い、当てはめを完了した模型（H2）で調べる。この模型の押しは、位置を動かしたときの出力 φ(z) の変化に由来する「読み出しの押し」と、傾き d の変化に由来する「ゲートの押し」に分かれる。ゲートの押しに現れる重み e′ は、ゲートが位置の変化に反応する度合いを表し、整流型では閾値付近で大きい（付録 K.1・K.2 (d)(e)）。

**補題 2（負の偏り）。** ガウス分布・明るさ K 一定（H3）の下で、読み出しには付録 K.2 (g)(h) の残差化模型、ゲートには K.2 (e) の並べ替え平均を用い、それぞれの適用条件と符号条件を満たすと、正側の入力が半数未満の生きたユニットでは、期待の押しが沈める側に残る。これらの条件が保たれる範囲では、自己形の釣り合い r*₀ より下にも、押しが釣り合う位置は無い。

<!-- G5・G6 -->
理由は、他のユニットを含めた当てはめでは、自己形の釣り合いを作る成分が変わることにある。自己形は、出力と傾きの共分散と、それぞれの平均の積に分かれる。r*₀ では負の平均積が共分散を打ち消すが、定数成分を他のユニットが引き受ける理想化では、読み出しの押しに共分散が残る。整流型ではこれは r*₀ より下でも非負である。この分解は付録 K.2 (g) に示す。

<!-- G7・H4・G8 -->
整流型の実際の入力の並びへ結び付けるには、ゲートの押しを反転させるだけの重なりが他のユニットに無いという追加仮定 H4 を置く。これは leaky ReLU の実測で支える仮定であり、一般の定理ではない。重なりを担う「橋」の定義、必要数の下界と持続性は付録 K.2 (i)(l)、実測は付録 K.4 (c)〜(f) にまとめる。

<!-- G8・G9・SiLU/GELU の条件 -->
SiLU・GELU には傾きが負になる域があるが、ガウス・K 一定に幅とゲート項の重み比の条件を加えると、同様に期待の押しが沈める側に残ることを数値が支持する（付録 K.2 (h⁗)）。以上は凍結した模型のラベルと前活性の並びについての期待であり、実際の訓練が必ず r*₀ を越えるという保証ではない。

### 4.2 幅の増大による釣り合いと開いた割合の変化

<!-- G10 -->
**相対位置が負のままほぼ一定なら、幅の成長によって共通位置は深くなる。** m = r·s なので、r が負のまま留まれば（ṙ ≈ 0）、時間微分は ṁ = ṙ·s + r·ṡ ≈ r·ṡ となり、共通位置は幅の伸びに比例して深くなる。この関係は、相対位置が幅によらない leaky ReLU の自己形の釣り合い r*₀ 付近に留まる場合にも成り立つ。相 2 での幅の成長を仮定 H5 とする。幅が伸び続ける理由は未導出であり、幅の収支と条件付きの成長模型は付録 K.5、実測との照合は付録 K.4 (g)・付録 M の表 5a に置く。

**幅の増大は、自己形の釣り合いで正側に残る入力の割合も変える。** §4.1.1 と同じガウス分布・明るさ K 一定の下で、釣り合いにおける開いた割合を p*₀ = Φ(r*₀) と書く。leaky ReLU では r*₀ が幅によらないため、p*₀ も幅によらない。ReLU には、生きている間の釣り合いが初めから無い。幅が増すと、ELU では自己形の釣り合いが深まり、そこで正側に残る入力はほぼ無くなる。SiLU・GELU では釣り合い自体が消える [ガウス・数値]（[[ELU・SiLU・GELUへの拡張_負の偏りと死_1007]] §3、付録 K.2(b)）。

ここで小さくなる p*₀ は、自己形の釣り合いでの値であり、実網の開いた割合 p がこの値まで下がるという結論ではない。実網では別の止め役が働きうるため、実際の p と残る応答を次節で調べる。

### 4.3 実網の止まり位置と残る応答
§4.1.2 の模型はミニバッチの揺らぎと Adam の更新を含まず、実網の止まり位置を決めきれない。止め役と停止位置、残る局所応答を、活性化・最適化器ごとに実測と介入で調べる（H6）。

#### 4.3.1 leaky ReLUは応答を残すが片側化する

<!-- G11 -->
a = 0.1 の leaky ReLU の実網は、自己形の釣り合いより深くで止まる。止め役の候補は、ミニバッチ残差の揺らぎと負の平均出力の積から生じる、浮かせる項である [候補]。幅に比例するこの項が止め役なら、停止する相対位置は幅によらない。この項を除くと、止まり位置はさらに深くなった [介入]（付録 K.4、表 8・(h)）。

leaky は閉じた入力にも傾き a を残すため、死なずに片側化する。ただし全入力が負側に入ると傾きが一様になり、入力ごとに傾きを使い分ける非線形性を失う。

#### 4.3.2 ELUの止まり位置は最適化器で違う

ELU は尺度固定で z → −∞ となると、傾きの絶対値がゼロへ近づく。一隠れ層の ELU × Adam では、出力の下限 −1 と Adam の押し戻しが、開いた入力の数を幅によらず一定に保つ [実測・介入]。ELU × SGD は全閉まで下がる [実測]。二隠れ層では、更新の移動量が押し戻しを上回り、層が機能低下に至りうる（§4.4）。

#### 4.3.3 ReLUは負側で応答を失う

<!-- G11 -->
ReLU は z < 0 で傾きがゼロになり、同定済みの各項は 0 または沈める側に働く（付録 K.2 (r)）。揺らぎの項も、平均出力が非負なので沈める側に働く。未知の止め役が無く、上端（最大の前活性）の余白が 1 課題の期待値で増えず（S1）、死の近くでも揺らぎが残る（S2）と仮定すれば、有限時間に確率 1 で上端が 0 を切り、死ぬ [確率・仮定つき]（付録 K.2 (w)）。

<!-- G11 -->
入力が固定なら、死んだ間の勾配は厳密に 0 であり、Adam の残留運動量で開き直さない限り死は永久である [厳密・条件つき]（付録 K.2 (u)）。

#### 4.3.4 SiLU・GELUは深い負側でほとんど閉じる

<!-- G8・G9・SiLU/GELU の実状態 -->
SiLU・GELU も尺度固定で z → −∞ となると、傾きの絶対値がゼロへ近づく。調べた凍結状態では模型の期待と異なり、深くほとんど閉じたユニットでも、谷の壁（傾きの最小点から活性化の最小点まで）の項が橋なしで浮かせる側に働く場合があった。押しは小さく、調べた訓練では半分より多く開いた側へ戻らなかった [実測]。この帯でも r が負のままほぼ一定なら、幅の成長が共通位置を下げる（付録 K.2 (h⁗)）。

SiLU・GELU は全閉まで下がる [実測]。出力の平均は 0 へ近づき、止め役は同定されていない。

### 4.4 二隠れ層への適用

<!-- G12 -->
**上流を固定した第 2 層には、一隠れ層と同じ構造が移る。** 第 2 層の位置は z̄₂ = W₂·µ₂ + b₂（µ₂ は平均入力）で、読み出し W₃ は入力によらない。そのため第 2 層は、入力 h1（第 1 隠れ層の出力）・平均入力 µ₂ の一隠れ層の理論と同じ構造を持つ [恒等式]。符号条件 K2 = µ₂·h1 + 1 ≥ 0 は ReLU 以外では別途確認が必要で、上流の項 W₂·Δµ₂ は固定入力の模型の外にある。また、µ₂ の向きは閉じた側の出力（ELU の −1 など）の共通成分が支配する。

<!-- G13 -->
第 1 層の読み出しは、第 2 層のゲートを通って戻る g_in で、入力に依る。そのため、切替の押しの期待が自己形に等しいという §4.1.1 の結果は移らない。第 1 層での期待の形は導出していない。移るのは、他のユニットが定数成分を引き受ける理想化での補題 Cov(φ′, φ) ≥ 0（付録 K.2(g)）で、重み |g_in|²K_n をつけた Cov_w(φ′, φ) ≥ 0 になる [厳密・raw・仮定つき]（付録 K.2 (m)）。重みの非負には K ≥ 0 が要り、raw では全入力で成り立つ。std では K < 0 の入力が 36% あり（付録 K.4 (k)）、第 1 層は補題の外にある。

<!-- G14 -->
bias を別に使わず、重みを平均入力の向き x̄ に沿って動かすときの相対位置の下限（壁）は、−mean(K)/sd(K) である [恒等式]。第 1 層の壁は raw で −3.83、std で −0.40 である。h1 は中心化されていないので、std でも第 2 層の壁は −2.0 と深い。この違いから、std では第 2 層に理論の機構が現れると解釈する。層の順序は導出していない。壁が深く、止め役が無いか更新の移動量を抑えきれない層が先に低下すると考え、実測で確かめた（付録 K.4 の表 10）。raw で第 1 層が先に低下するのは最初の切替より前で、切替の押しでは説明しない。

<!-- 旧 4.9 -->
説明は最初の機能低下までとし（判定基準は付録 K.4）、その後は戻らない理由として扱う。ReLU では、死んだユニットの勾配は死んだ間ちょうど 0 である（§4.3.3）。ReLU の g_in は第 2 層の開いたユニットだけを通るので、第 2 層が全部死ぬと第 1 層の勾配も 0 になり、第 1 層は凍る [厳密]。入力が動く第 2 層では、死んだ層も上流の項で運ばれる [恒等式 ＋ 実測]。

<!-- G12・G13・G15 -->
調べた CIFAR の leaky ReLU・ELU・ReLU の第2層では、Cov(e′, d) > 0 の下で押しが反転した例は、第1層が先に機能低下した後に限られた [実測]。乱数ラベル MNIST の ELU の第1層では、半分より多く開いた側へ戻る例があり、「戻らない」は全層には移らない（付録 K.4 (i)〜(l)、付録 M）。

### 4.5 幅を止める介入による検証

**幅を止める介入の効き方は、活性化によって分かれた。** ELU では成績が大きく改善し、SiLU・GELU にも高い課題末精度を保つ条件があった。実ラベルの ReLU では改善しなかった。

#### 4.5.1 ELUは両層の成長上限で成績が改善する

課題 1 終端の行ノルムを半径として、各 Adam 更新後に重みを射影した。両隠れ層に上限を置く cap12 では、課題 31–50 の平均 online 精度が 85.98%（対照 10.09%）、対応差が +75.9 ポイント［97.5% 信頼区間：75.1–76.6］となり、全 10 seed で床への崩壊を防いだ。第 1 層だけでは 11.91%、第 2 層だけでは 25.10% にとどまり、片方の成長を抑えても他方が沈降を運んだ。‖µ₂‖ は課題 1→50 に対照で 52.6→1157、cap12 で 52.6→40 だった（seed 平均）。乱数ラベル MNIST の ELU 網でも、第 1 層の入力平均方向の成分と第 2 層の行ノルムをともに制限すると、全 10 seed で改善した（online 0.84）。

**SiLU・GELU にも成長上限が効く条件があった。** 1 隠れ層の乱数ラベル MNIST では、行ノルム上限で高い課題末精度を保つ条件が確認された。ただし GELU は介入時期に依存し、学習速度の維持を示す結果ではない（各 3 seed・200 課題、[[沈降の根を分ける走_sink_roots_0930_追補とR7_0930]] §3・§6）。

成長上限の効果には沈降の抑制と実効学習率の保持がともに含まれ得るが、学習率だけを変える同尺度の対照が無く、両者の寄与は分離していない（付録 K.5）。

#### 4.5.2 ReLUは深さを抑えても開閉が変わらない

**実ラベルの ReLU では上限が効かない。** 5+1 CIFAR の ReLU に同じ上限を適用すると、cap12 は後期 online 精度を 3.6 ポイント下げ［97.5% 信頼区間：−6.7〜−0.5］、fresh gap を 4.7 ポイント広げた［0.6–8.8］。cap1 も悪化し、cap2 には明確な効果が無かった（事前登録 `cap_cifar5p1_1007`）。cap12 は第 2 層の共通位置を浅くしたが（対照 −8.5、cap12 −5.6）、幅も同じ比で縮み（5.5、3.7）、相対位置は全 4 条件で −1.5〜−1.6 のままだった。死亡率も下がらなかった（対照 .34、cap12 .40）。重みの成長が深さを増す関係はあっても、深さを止めるだけでは ReLU の開閉は変わらない。

応答への直接介入が再学習成績を変えるかを、次章で調べる。

## 5 応答の回復と保持による再学習性能の改善

第4章では、前活性が負側へ動き、活性化に応じて応答や非線形性を失う過程を調べた。本章では、応答を直接変える介入で再学習成績との関係を確かめ、その分析を踏まえた活性化を導入して比較する。

### 5.1 応答の交換はELUでもReLUでも成績を変える

応答場（各ユニット・入力の傾き φ′(z)）を、同じ軌道の早期と劣化後の間で第2層について交換し、固定した。交換時の重みを保ち、固定補正で特徴と予測を対照に一致させた後、重みと特徴の更新を再開した。

乱数ラベル CIFAR（ELU・std）では、課題10末の網に課題1末の場を戻すと、次課題の online 精度が 10.2% から 57.0% へ上がり、逆向きの交換では 97.1% から 29.2% へ下がった。成績は次の1課題・30,000更新での10 seed平均で、復元は Adam の履歴を継続し、逆向きは対照・介入とも初期化した。

同じ両方向の効果は、乱数ラベル MNIST の ELU と実ラベル 5+1 CIFAR の ReLU でも得られ、三つの設定とも各10 seedすべてで確認した。ReLU では早期の場を戻すと、次課題の精度が 40.4% から 61.7% へ上がった（付録 A.1・A.2）。

5+1 の ReLU では、開いたゲート数を早期の場にそろえる一様シフトでは、早期の場を戻すより成績が高く、同じ応答値を画像・ユニットの構造を壊して並べ替えると低下した。開いた数と入力に沿った配置が成績に関わるが、検証は次の1課題までである（付録 A.2）。

### 5.2 分布幅に合わせて曲がりを保つ活性化を導入する

負側に傾きを残す leaky ReLU も、全入力が負側に入れば一つの直線になる（§4.3.1）。この分析を踏まえ、分布幅に合わせて曲がりの尺度を調整する活性化 kunekune を導入する。kunekune は Snake の曲がりを有限区間に残し、その外側を直線につないだ関数である。同じ尺度調整を施した適応 Snake も比較する。

尺度は各ユニットの前活性幅の走行統計から決め、その統計には勾配を通さない。分布が曲がる領域に残る限り、入力ごとに異なる傾きを使い続けられる。ただし、幅への追随だけで分布の中心をその領域に保てるわけではない。関数の定義と実装は付録 F.1・N.1、止まり位置と応答の下界の条件は付録 K.2 (y) に示す。

### 5.3 乱数ラベルCIFARで高い成績を保つ

二隠れ層 MLP を50課題学習させると、kunekune・適応 Snake は、未標準化入力（raw）と標準化入力（std）の両方で高い成績を保った（表2）。この50課題では分布の大部分が曲がりを持つ帯内に残った（付録 F.1）。一方、leaky ReLU は傾きが残っていても、早期から後期への成績低下が見られた（付録 F.3）。

### 通し稿 §1 序論・駆動の主張と仮定の説明の改訂前

出所：[[V12通し稿_1007]] §1 序論。仮定の列挙を整理し、自己形の釣り合いが強く負側へ偏る主張を前面に出した際の変更前の文を保存する。相対位置の定義は、実網の止まり位置を述べる段落へ移した。

**駆動の理論。** 乱数ラベルを学ぶ一隠れ層網では、読み出しの勾配学習を仮定し、相対位置（共通位置 ÷ 分布幅）を動かす期待の押しを解析する。整流型の初期では、特徴を固定した読み出し模型で新旧の乱数ラベルについて平均すると、切替の押しが出力と傾きの積からなる「自己形」で決まる。ガウス分布・位置更新の入力間一様性の下で、leaky ReLU・ELU の釣り合いは初期位置より下にある。その位置へ向かう途中で、正側の入力が半数を割る。ReLU にはこの釣り合いが無い（補題 1）。

他のユニットを含めて当てはめた凍結・線形化模型では、定数成分を分担することで、自己形の釣り合いより下にも期待の押しが残る。読み出しと活性化の傾き（ゲート）に由来する押しの符号条件、および実際の入力の並びについての追加仮定 H4 が必要である（補題 2）。SiLU・GELU の条件付きの拡張を含め、導出と実測の照合は付録 K にまとめる。これは模型平均の結論であり、個々の訓練軌道を保証しない（§4.2）。

**進行と応答の分岐。** 共通位置は相対位置と分布幅の積である。相対位置が負のままほぼ一定に留まっていても、幅が伸びれば共通位置は深くなる。幅の成長を仮定 H5 とし、その応答への影響と成長を止める介入を調べる（§5）。沈降に伴い、ReLU・ELU などは局所応答を失う。leaky ReLU は応答を残すが、全入力が負側に入ると一つの直線となり、入力ごとに傾きを使い分ける働きを失う。kunekune・適応 Snake は分布幅に合わせて曲がりの尺度を変え、分布が曲がる領域にある限り非線形な応答を保つ。この分岐を、重み成長への介入、活性化の比較、応答場の交換によって検証する。

### 通し稿 §1 序論・配置と中心化の説明の短縮前

出所：[[V12通し稿_1007]] §1 序論。数式・機構の補足・成績の詳細を省き、位置変化の経路と200課題の結果の二文へ短縮した際の原文。

**配置。** 各層の前活性は、入力平均 $\mu$ によって、共通位置 $w_i^\top\mu+b_i$ と入力ごとの揺らぎ $w_i^\top(x-\mu)$ に分かれる。特徴を学ぶ重みの更新は、$\mu$ 方向の成分を通じて共通位置も動かす。bias は位置を直接動かすもう一つの経路である。ReLU 型の正負非対称性は、中心化された前活性からも次層に非ゼロの入力平均を生むため、この配置はネットワーク内部で再形成される。

層入力の実平均をゼロに保てば、重みを介する位置の変化は消えるが、bias の経路は残る。乱数ラベル CIFAR の二隠れ層 ReLU 網では、入力と中間層の中心化（CH）で 50 課題まで高成績を保ったものの、200 課題では低下した。新たな 10 seed による追試では、課題 181–200 の平均 online 精度は CH の 62.98% に対し、bias 抑制を加えた CHB は 99.03% だった。対応差は 36.05 ポイント［95% 信頼区間：20.45–51.65］で、全 seed で CHB が上回った（§3）。

### 通し稿 §1 序論・研究の問いからkunekuneの比較へつなぐ改稿前

出所：[[V12通し稿_1007]] §1 序論。研究の問い、負側への偏りと幅の増大、応答への介入、kunekuneの設計と既存手法との比較をつなぐ序論へ書き直す前の全文。本文と重なる文も含む。

本研究は、可塑性喪失のうち、前活性が負側へ偏り、応答を失う経路を対象とする。

**配置。** 入力平均がゼロでない層では、特徴を学ぶ重みの更新が前活性の共通位置も動かす。入力と中間層の中心化に bias 抑制を加えると、乱数ラベル CIFAR の ReLU 網で200課題まで高い再学習成績を保った（§3）。

**駆動の理論。** 乱数ラベルを学ぶ一隠れ層の模型で、課題切替が共通位置を負側へ動かす理由を解析する。新旧ラベルについて平均した押しは、出力と傾きの積からなる「自己形」で決まる。**負側の応答が弱いと、浮かせる寄与も弱く、釣り合い自体が大きく負側へ偏る。** ガウス模型の leaky ReLU（負側の傾き a = 0.1）では、正側に残る入力が約4%になるまで釣り合わない。ReLU には、生きている間の釣り合いが無い。

他のユニットが定数成分を引き受ける凍結・線形化模型では、その釣り合いより下にも沈める押しが残る条件を示す。これらは仮定を置いた模型平均の結論であり、個々の訓練軌道を保証しない。仮定と適用範囲は §4・付録 K にまとめる。

実網の止まる相対位置（共通位置 ÷ 分布幅）は、活性化と最適化器に依存する。leaky ReLU ではミニバッチの揺らぎによる押し戻しが止め役の候補で、ReLU では同定済みの止め役が働かない。二隠れ層では上流を固定した第 2 層に理論を適用し、最初の機能低下までを実測と照合する。

**進行と応答の分岐。** 共通位置は相対位置と分布幅の積である。相対位置が負のままほぼ一定に留まっていても、幅が伸びれば共通位置は深くなる。幅の成長の理由は未導出だが、応答への影響と成長を止める介入を調べる（§5）。沈降に伴い、ReLU・ELU などは局所応答を失う。leaky ReLU は応答を残すが、全入力が負側に入ると一つの直線となり、入力ごとに傾きを使い分ける働きを失う。kunekune・適応 Snake は分布幅に合わせて曲がりの尺度を変え、分布が曲がる領域にある限り非線形な応答を保つ。この分岐を、重み成長への介入、活性化の比較、応答場の交換によって検証する。

本稿の貢献は次の六点である。

1. 入力平均を介する位置変化を整理し、中心化と bias 抑制により ReLU の再学習成績を 200 課題まで保った（§3）。
2. 自己形の釣り合いが強く負側へ偏ることと、その下にも沈める押しが残る条件を模型で示し、二隠れ層への適用範囲を整理した（§4）。
3. 重み成長の上限が乱数ラベルの ELU を改善する一方、実ラベルの ReLU では相対位置を変えず成績を下げることを示した（§5）。
4. 活性化による応答の分岐を比較し、kunekune・適応 Snake が乱数ラベル CIFAR の 50 課題で高成績を保つことを示した（§5）。
5. 三つの課題設定で、早期と劣化後の応答を交換すると再学習成績が両方向に変わることを確かめた（§6）。
6. 実ラベルの 5+1 CIFAR で、kunekune・適応 Snake が調整済み L2 Init と同等の成績を示すことを確かめた（§7）。

### 通し稿 旧§8 関連研究・序論へ統合する前

出所：[[V12通し稿_1007]] 旧§8 関連研究。先行研究との関係を一段落に圧縮して§1末尾へ移した際の原文。後続の方法・限界は§8・§9へ繰り上げた。

入力平均をゼロに寄せる操作は、収束を速める工夫として研究されてきた。LeCun ら [1] は入力と隠れ層出力の中心化、Clevert ら [2] は ELU による bias shift の抑制、Salimans と Kingma [3] は mean-only batch normalization を論じた。本研究はこれを、重みの更新が入力平均への投影を通じて前活性の共通位置を動かすという幾何に置き直し、乱数ラベル CIFAR の ReLU MLP で、入力・中間層の中心化と bias 抑制により 200 課題まで再学習能力を保った。

可塑性喪失に対する正規化の効果は設定に依存する。Kumar ら [4] と Lewandowski ら [7] は Layer Norm が喪失を部分的に抑えることを報告した。Lyle ら [5] は正規化の利得の大半を再尺度化に帰属させる一方、MLP では batch 軸の平均減算が重要で、その利得の大半を入力中心化が再現するとした。本稿では入力中心化だけでは第 2 層が沈み、中間層の中心化が必要だった。学習予算・正則化・入力平均の大きさが異なるため、同一条件での反証ではない。[6] の中心化と飽和の検証は、訓練網ではなく等方ガウスのランダムウォークを対象とする。

Dohare ら [10] は Slowly-Changing Regression で ELU にも喪失が残ることを報告した。Lillo と Cheney [9] は 17 活性化を比較し、負側に実効的な傾きを持つ群の生存と、死んだユニットの割合と精度の相関を示した。本稿は、前活性が負側へ届く過程と応答を失う過程を結び、応答への介入で再学習成績を変える。Snake [13] の曲がる領域を分布幅に追随させ、Deep Fourier [8]、CReLU [12]（可塑性への適用は [11]）と同じ設定で比較した。

L2 Init [4] は初期重みへの正則化によって可塑性を保つ。本稿の 5+1 CIFAR × MLP では、適応 Snake は原典の λ = 10⁻² を用いた L2 Init を上回り、この設定で調整した λ = 10⁻³ とは ±0.5 pt の帯で同等だった。活性化側は三つの課題設定で既定値を共用している。原典の CNN と本稿の MLP の数値は直接比較せず、同じ課題設定での結果を主な比較とする（§7・付録 I）。

### 通し稿 要旨・6文への短縮前

出所：[[V12通し稿_1007]] 要旨。「問い → 負側へ偏る理論 → 幅と応答の変化 → 介入 → kunekuneと既存手法の比較」の流れで一段落・6文にまとめる前の原文。仮定や個別数値の詳細を要旨から外した際の保存用。

可塑性喪失のうち、前活性が負側へ運ばれて応答（訓練が使う微分）を失う経路を扱う。前活性は、入力平均への投影で決まる共通位置と入力ごとの揺らぎに分かれ、特徴を学ぶ重みの更新は共通位置も動かす。

乱数ラベルを学ぶ一隠れ層の整流型網を凍結・線形化し、前活性をガウス分布、入力の明るさ K を一定とする模型で、沈降が進む条件を導いた。特徴を固定し、読み出しが勾配学習で前の課題を自信をもって当てる模型では、新旧の乱数ラベルで平均した切替の押しが出力と傾きの積の和（自己形）に等しく、初期位置を負側へ向ける。相対位置（共通位置 ÷ 分布幅）が負のままほぼ一定に留まれば、分布幅の成長によって共通位置はさらに深くなる。幅の成長は仮定であり、その理由は未導出である。さらに、他のユニットが定数成分を引き受け、読み出しと活性化の傾き（ゲート）に由来する押しの二成分がそれぞれの符号条件を満たす模型では、自己形の釣り合いより下にも期待の押しが残る。実網の止まり位置と応答の変化は活性化と最適化器によって異なり、leaky ReLU は応答を残して直線化し、ReLU はユニットの死に至り、kunekune・適応 Snake は谷の付近に留まる。二隠れ層網では、上流を固定した第 2 層に同じ構造が移る。

事前登録の介入では、乱数ラベル CIFAR の ReLU 網で入力と中間層の中心化が課題 31–50 の online 精度を 11.3% から 98.7% へ上げ、bias の抑制を加えると課題 181–200 でも 99.0% を保った。ELU 網では重みの成長上限が課題 31–50 の精度を 10.1% から 86.0% へ上げたが、実ラベルの 5+1 CIFAR の ReLU には効かなかった。第 2 層の応答場の交換は三つの課題設定で成績を両方向に変えた。5+1 CIFAR では、追加の正則化を用いない kunekune・適応 Snake が、学習率を固定し、少数の候補から調整した Shrink & Perturb・CBP・ReDo を 12〜17 pt 上回り、この課題設定で調整した L2 Init と同等だった。

理論の対象は乱数ラベルの MLP における最初の機能低下までであり、5+1 と CNN は実験的な検証対象である。本研究は、入力平均による位置の変化、沈降の進行、活性化ごとの応答の喪失を結び、再学習能力を保つ介入条件を示す。
