## 0. 結論

**2 ブロックを本文、4 ブロックを付録に置く判断は、条件付きで正当。Fable と Astra で一致した。**
理由の書き方は「機構の最小単位だから」ではなく、「上流 FFN の共通の書き込みが下流ゲートのしきい値を担うという仮説を、両者を別々に介入できる最小の構成で検証するため」とする。本文採用には、下見の 3 条件、独立 seed、介入による因果確認が要る。

本文の一文の案（Astra）:
> 上流 FFN の共通の書き込みが下流ゲートのしきい値を担うという仮説を検証するため、両者を別々に介入できる本構成で最小の 2 ブロック Transformer を用いる。4 ブロックでの対応と、深さに伴う役割移動は付録で評価する。

## 2. 残る留意（Astra が強調し、Fable も受け入れた）

- **構造の対応と因果の同一性は別。** 2 ブロックの L1 の担い手が FFN0 由来だと言うには、LN を経た入力平均のうち FFN0 由来の成分がどれだけ効くかを示す（注意・埋め込み・残差も混ざる）。
- **閾値を既存の数から導いても選択は残る。** SE × 3 は検出可能性の目安で、喪失の実質的な大きさではない。下見の基準は目安に留め、本文採用は独立 seed で効果量と不確実性を評価する。
- **事後の深さ選択と見られないために**、採用基準を下見の前に固定し、2・4 ブロックを同じ課題列で比べ、不一致も報告する。

## 3. 2 ブロックの下見（C3=ReLU・SiLU、seed 1000、100 課題）で落とせない 3 条件

1. **学習成立と喪失の両立。** 課題 1 末の超過損失 ≤ 0.1（段 0 の規則）。同じ学習予算の fresh 対照に比べて再学習が悪化する。fresh gap の符号と評価窓を先に固定する。
2. **沈降・応答喪失・再学習悪化の接続。** 固定評価集合で L1 の負方向の変位が切替ごとに再現し、応答の低下が悪化に先行するか伴う。平均位置や死亡率で代用しない。
3. **分解の閉合と経路の対応。** 交差項を含めて Δμ を再構成でき、負方向の成分が L1 に集中し、その上流寄与が FFN0 の共通成分と対応する。相殺量も示す。

補足: 役割の移動（SiLU の L1 が正側へ出て L0 が沈む）は 100 課題で終わらなくてよい。終わらなければ「未観測」と書き、延長するなら 2・4 ブロックに共通の期限を先に決める。閾値の目安は既存の数から導く（喪失は本走 10 seed の C3 の fresh gap の SE 0.008 の 3 倍、沈みは 4 ブロック seed 1000 の L3 の切替 Δμ/σ −0.33 の半分、集中度は 4 ブロックの分解で L3 が占めた割合の 0.8 倍）。

## 4. Issa の読み（重みの成長が下の層の押しを装填し、上の層が線形化すると押しが下へ移る）

- 1 隠れ層の理論（押し ∝ κ、層 ℓ の自己形の重みは下流経路のノルムの 2 乗に比例）と定性的には整合する。導出済みではない。LN・残差・注意・Adam のある系では、重みのノルムだけから有効な下流経路の強さは読めない。主因が上流の項なら、自己形の増幅だけでは説明が足りない。
- 測る量は 2 つ。(1) 各層の活性から logit への Jacobian と層ごとの κ（有効な下流感度と整列）が、自己形の負方向の更新を予測するか。(2) 同じ checkpoint から上流の表現を固定した短い分岐と通常の更新を比べ、L1 の線形化の前後で L0 への負方向の変位が増すか。
- L3 が正側へ出て線形化する現象は、[[応答が残るのに適応が落ちる_片側化と非線形性喪失_1020]] の「読み出し v が小さいと正側へ片側化する」型（ReDo の v ゼロ化後に p ≥ 0.99 が 88%、非ゼロ v で 28%）と同じ。共通の量は入力間の傾きの分散 Var_x(φ′) で、p → 0（死）でも p → 1（線形化）でも 0 になる。V13 の文 3 は「沈んで応答を失う」と「浮いて折れ目を失う（応答は残る）」の二つの道を持つ。先行は Lyle ら 2025 §3.2・付録 F.8。
