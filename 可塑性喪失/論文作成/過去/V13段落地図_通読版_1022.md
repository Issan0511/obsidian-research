## 全体の流れ

**問いを立てる → 測る量をそろえる → 短い条件付き理論 → MLPで接続を確かめる → CNNで予防と回復の違いを見る → Transformerで動く上流を操作する → kunekuneの設計・比較 → 示した範囲と残る問い**

| 節                 | 読者がここで理解すること                                              |
| ----------------- | --------------------------------------------------------- |
| §1 序論             | 学習が押しを作り、その押しを運ぶ経路と失われる機能を問う論文である。kunekuneも設計上の貢献として予告する。 |
| §2 設定・定義          | 位置・幅・応答・片側化と、学び直しの評価を区別する。                                |
| §3 短い理論           | 装填から切替の押しと位置の符号へ進み、幅が自己形の境界をどう変えるかを示す。                         |
| §4 MLP            | 装填 → 位置経路 → 成長制限の操作と結果 → 機能低下と応答への介入。                      |
| §5 CNN            | MLPで確かめた接続を、予防・全層応答交換・自然B後付け・予算比較で検証する。                 |
| §6 Transformer | 上流経路、capとL0だけのELR救済、L0応答の双方向介入をつなぐ。 |
| §7 kunekuneの設計・比較 | 応答と曲がりの尺度を保つ設計を示し、固定Snake・既存対策と比べる。                       |
| §8 議論             | 共通する接続をまとめ、全層の単調沈降や全性能の単一原因へ広げずに結論する。                     |

- 旧§4は、条件付き理論を§3、実証を§4へ分ける。旧補題1の有限回到達・安定点への収束はコピーしない。
