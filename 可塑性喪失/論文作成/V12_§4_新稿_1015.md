## 4 駆動源の理論 — 最初の機能低下までの道

本章では、乱数ラベルを学ぶ一隠れ層網について、課題切替後の最初の更新が前活性の共通位置に与える変化を解析する。各ユニットの共通位置を m（入力についての平均）、分布幅を s（標準偏差）、相対位置を r = m/s、正の前活性を持つ入力の割合を p とする。

切替の最初の一歩で共通位置が動く量の期待を「押し」と呼び、負側への向きを沈める側とする。期待を取る対象と必要な仮定は各節で明示する。結論は模型内の期待値についてのもので、個々の訓練軌道を保証しない。仮定の一覧は付録 M に、実測との照合は付録 K に置く。文末の角括弧は文の格（根拠の種類）で、凡例は付録 K.1 に置く。

**本章の結論は、沈んだ後の期待の押しには模型の中に釣り合って止まる位置が無く、相対位置は期待では模型の外の止め役まで下る、ということである。** 前提は、整流型の網で読み出しが勾配学習で育つこと（H1）と、分布幅が伸びること（H5）である。初期には、切替の押しがユニットを自己形の釣り合い r*₀（切替の押しだけなら止まる相対位置）へ向ける（4.1）。ReLU には r*₀ が無く、初めから沈める側が続く。正側の入力が半数を割った後は、他のユニットを含めた期待の押しがその沈みを打ち消さず、r*₀ の釣り合いも消える（4.2）。相対位置が負のまま幅が伸びれば、共通位置はさらに深くなる（4.3）。SiLU・GELU でも、4.2 の幅と重みの比の条件の下で同じ結論が立つ。二隠れ層では、上流を固定した第 2 層に同じ構造が移る（4.4）。各文の格は各節に置く。

### 4.1 初期に負側へ動く理由

新しいラベルは網の状態と独立・一様とする（H0）。整流型は、傾き φ′ が前活性とともに減らない leaky ReLU・ELU（α ≤ 1）・ReLU を指す。前の課題を学んだ読み出しへの切替の押しが位置を運ぶ時期を、相 1 と呼ぶ。

<!-- G3 -->
**前の課題を自信をもって当てる読み出しへの切替の押しの期待は、自己形に等しい。整流型ではガウス・K 一定で、自己形の釣り合い r*₀ が出発点より下にあり、その上では押しが沈める側なので、各課題末で H1 が立つ限り、ユニットの期待の位置は切替のたびに r*₀ へ向かう（補題 1）。** ユニット i への切替の押しを S_i = Σ_n K_n d_in⟨v_i, p_n − 1/K⟩ と書く。K_n は入力 n の明るさ（平均入力 x̄ との内積に 1 を足した K_n = x̄·x_n + 1 で、位置の一歩が前活性に効く量）、d_in は活性化の傾き、v_i は読み出し、p_n は softmax の出力（開いた割合 p とは別）、K はクラス数である。S_i が正なら、切替の最初の更新は新しいラベルの期待で共通位置を下げる。仮定 H1 は、読み出しが勾配学習で育ち、課題末に前の課題を自信をもって当てることである。訓練した一隠れ層の網（実網）では、課題末の softmax の最大値の平均が相 1 で 0.96 だった [実測]（付録 K）。H1 の下で新しいラベル y の期待をとると、E_y[S_i] = κ(1 − 1/K)Σ_n K_n d_in φ_in になる [厳密な極限]。この期待には、他のユニットとの打ち消しが出ない。κ は読み出しが勾配で育った量、φ_in はユニットの出力である。

<!-- G3 -->
右辺の和が自己形で、出力と傾きの積を明るさで重みづけして足した量である。整流型では、正側の入力での積は前活性 z で、沈める側に効く。負側の入力での積は leaky ReLU で a²z（a は負側の傾き）と小さく、浮かせる側に効く。前活性をガウス分布とみなし、明るさ K_n を一定と置く（H3）。このとき p = Φ(r)（Φ は標準正規の分布関数）で、leaky と ReLU では自己形の符号は相対位置 r だけで決まる。ELU では幅にもより、釣り合いは幅とともに深くなる [ガウス・数値]。正側が勝つ上の側では沈め、負側が勝つ下の側では浮かせる。その境が釣り合い r*₀ で、半々（r = 0）より下にある。a = 0.1 では r*₀ = −1.72 で、零点はこの 1 つである [ガウス・K 一定]。切替の押しだけなら、各課題末で H1 が立つ限り、期待の位置にとって r*₀ は安定な止まり位置である（ELU では幅を固定したとき）[ガウス・K 一定]。r*₀ の下でも沈み続ける理由は、4.2 で与える。

<!-- G3 -->
補題 1（出発点を離れる）は次の文である。各課題末で H1 が立ち続ける限り、出発点から出たユニットの期待の位置は、切替のたびに r*₀ へ向かう [模型の帰結・仮定つき（各課題末で H1）]。根拠は、同じ理想化の下で二つある。r > r*₀ では押しが沈める側で、r*₀ より上に固定点が無い。r ≥ 0 では押しの大きさに正の下界がある（付録 K.2 (b)）。r*₀ が r = 0 より下にあるので、r*₀ へ向かう途中で正側の入力は半数を割る。出発点がちょうど半々なら最初の切替で割り、課題 1 の学習で位置が上にずれていても有限回で割る [模型の帰結]。半数を割ることは主張ではなく、4.2 の補題 2 が使う継ぎ目である。ReLU では負側の積が 0 で、K > 0 なら釣り合いが無いので、H1 の下で押しは死ぬまで沈める側である（付録 K.2 (p)）。切替の押しだけで死まで運ぶかは [候補] である。

補題 1 が言うのは期待の位置で、個々の軌道ではない。課題の中で押しの係数が動く分は模型の外にあり、相 1 を切替の押しが運ぶ相と定めて相の境に吸収する。半数を割るまでの回数の式と、H1 が保たれる長さは導いていない（§11 の 5）。a = 0.1 の leaky ReLU の実網（seed 0）では、r のユニット中央値が最初の切替一回で +0.18 から −0.81 へ下がり、半数を割った [実測]。SiLU・GELU の実網でも、課題 3 末には生きたユニット（正側の入力を持つユニット）が全部 p < 1/2 の側に入った [実測]（2 seed。付録 K.2 (b)）。

### 4.2 沈んだ後も押しが残る理由

相 1 の切替の押しは、ユニットを自己形の釣り合い r*₀ へ向ける（4.1）。押しが細り、模型の外の止め役と釣り合った後を相 2 と呼ぶ。**相 2 の押しの役は二つある。相 1 の沈みを打ち消す項が無いことと、r*₀ の釣り合いが消えることである。**

<!-- G4 -->
網を凍結・線形化し、二乗誤差とリッジで当てはめきった模型で、重みを平均入力の向きに動かす（H2）。切替の一歩の古いラベルについての期待は、容量 Φ = ½ log det(λ + 𝒦) の傾き A_i = ∂Φ/∂t_i に一致する。𝒦 は両方の層の NTK、λ はリッジの強さ、t_i は位置をずらす量で、A_i > 0 が沈める側である。押しは読み出しの分とゲートの分に分かれる [厳密・模型]（付録 K.2 (c)）。

<!-- G5・G6 -->
**一つ目は、打ち消す項が無いことである。** 読み出しの分は、他のユニットが作れる成分を引いた残りで読む。何も引かないのが段 0（自己形）、定数を引くのが段 1、前活性の一次式を引くのが段 2 で、読み出しだけの最小二乗・λ → 0 の理想化である。K 一定（H3）では、段 1 の押しは Cov(φ′, φ) ≥ 0 となる。整流型では φ′ と φ がともに単調非減少なので、これは分布によらない [厳密]。段 2 は、leaky と ReLU ではガウス・K 一定で p < 1/2 の全域で正である [厳密]。ELU は r ≤ −1.5 または幅 ≥ 4 の範囲で数値確認した [数値]。任意の分布では段 2 が負になる反例もある（付録 K.2 (h)）。

ゲートの分は、前活性の値を入力間で一様に並べ替えて平均すると、他のユニットの形によらず、Cov(e′, d) の正の倍数と非負項の和になる（定理 6）。d = φ′(z) はゲート、e′ は閾値付近で大きい重みである。閾値付近の開き具合が全体を上回る条件 Cov(e′, d) > 0 の下で沈める側となる。この条件は、密度が平らな理想化では p < 1/2 と同値である。確率の文として厳密なのは、ユニット自身の両方の道を除いた核の版である [厳密・条件つき]（付録 K.2 (e)）。

<!-- G7・H4・G8 -->
実際の並びでゲートの分を反転させるには、標的の閾値の入力と開いた入力をまたいで開く他のユニット（橋）が必要で、要る数には状態から計算できる下界がある [厳密]。各課題末で、どの生きたユニットでも、その閾値の入力で開く他のユニットの数がこの下界に届かないことを H4 とする。位置の流れ（容量の勾配降下）の下では、橋は作られず、押しは 0 へ向かい、逆向きの符号は続かない [厳密]。しかし実際の訓練は位置の流れではなく、橋を設計して入れれば押しが打ち消し合って止まる状態（位置の流れの停留点）を作れるので、H4 は一般の定理ではない。leaky ReLU の相 2 の保存状態では下界に届いた例が無く、訓練中の橋も多くは一課題で消えた [実測]。反転の式・下界・実測値は付録 K に置く（K.2 (i)(l)）。

<!-- G6・G11 -->
**二つ目は、r*₀ の釣り合いが消えることである。** K 一定では、段 0 の自己形は E[φ′φ] に比例し、段 1 との差は平均項 E[φ′]E[φ] である。ここで E は入力についての平均で、
E[φ′φ] = Cov(φ′, φ) + E[φ′]E[φ]
が成り立つ [恒等式]。段 0 の釣り合いでは平均項が −Cov(φ′, φ) ≤ 0 となり、沈める側の共分散項を打ち消す。E[φ′] > 0 なので、この位置では出力の平均 E[φ] ≤ 0 である。出力 bias を含む当てはめの極限で、定数成分を他のユニットが引き受けると置けば、この平均項が除かれる。段 1 に残る共分散項は r*₀ の下でも非負である [厳密・K 一定]。ReLU は、生きたユニットで E[φ′φ] = E[z⁺] > 0 なので、もともと段 0 の釣り合いが無い。

<!-- G9 -->
以上が補題 2（負の偏り）である。整流型の網で、正側の入力が半数未満の生きたユニットでは、段 1 以上の期待の押しの全項が沈める側に残り、読み出しとゲートの分は打ち消し合わない。条件は、読み出しの分が K 一定・ガウスの理想化、ゲートの分が並びの期待で Cov(e′, d) > 0 であることである。位置で符号の条件が変わるのは段 2 とゲートの分の Cov(e′, d) で、境はどちらも p = 1/2 である。段 1 は位置によらない。そのため p = 1/2 は到達点ではなく、証明の継ぎ目である。補題 2 の押しが釣り合って止まる位置は模型の中に無く、止まる位置は模型の外の止め役が決める（4.3）。これが本稿の主張である [厳密・ガウス（K 一定）＋ 実測]。全項が同じ向きなので、項どうしの大きさを比べる必要は無い。大きさの比較が要るのは模型の外の止め役との釣り合いで、H6 として実測・介入で扱う（4.3）。

<!-- G8・G9・SiLU/GELU の条件 -->
SiLU・GELU には傾きが負になる域があり、上の単調性の証明は使えない。ただし、ガウス・K 一定で幅が SiLU 0.94・GELU 0.57 以上なら、読み出しの分は r < 0 の全域で沈める側になる。ゲートの分は共分散項と平均の積の項の重みつきの和で、後者が浮かせる帯でも、重みの比 1 − T̄ ≤ 2.9 なら前者が勝つ。この二条件の下では、同じ全域で段 1 以上の期待の押しが沈める側となり、模型の中に釣り合いは無い [ガウス・数値]（付録 K.2 (h⁗)）。比の上限は定理から出ず、実測で支える仮定である。実網の幅は課題 2 以降 1.35 以上、比は最大 0.6 で、両条件を満たす [実測]。幅が伸びるだけでは任意の分布に対しては成り立たない [反例]。K 一定での状態ごとの十分条件 SC1・SC2 は付録 K.2 (h′) に置く。

結論は凍結した網のラベルと前活性の並びについての期待であり、実際の訓練軌道へのつなぎは未導出である。

### 4.3 沈降の進行と止まる理由

<!-- G10 -->
**相対位置が負のままほぼ一定なら、幅の伸び（H5）によって共通位置は深くなる。止まる相対位置は、活性化と最適化器によって異なる。** 共通位置 m は、定義により相対位置 r と幅 s の積 m = r·s である。r が負のまま留まれば（ṙ ≈ 0）、時間微分は ṁ = ṙ·s + r·ṡ ≈ r·ṡ となり、共通位置は幅の伸びに比例して深くなる（§5）。相 2（押しが細り止め役と釣り合った後）でも幅が伸び続けることを、理由は未解決のまま仮定 H5 とする。leaky a0.1 の実網の相 2 では、幅が 3.4 から 5.5 へ伸びる間に、共通位置は −7.8 から −11.3 へ深くなった [実測]（付録 K）。

<!-- G8・G9・SiLU/GELU の実状態 -->
SiLU・GELU では、模型の期待と実際の状態ごとの押しの符号が異なることがある。調べた凍結状態（課題 3〜41 の 14 状態）では、r < −1.75 の深くほとんど閉じたユニットで、主に谷の壁（傾きの最小点から活性化の最小点まで）の項が、橋なしでも浮かせる側に働くことがあった。その押しは小さく、調べた訓練で半分より多く開いた側へ戻ったユニットは無かった [実測]。この帯でも r が負のままほぼ一定なら、幅の伸びが共通位置を下げる（付録 K.2 (h⁗)）。

<!-- G11 -->
4.2 の模型内の押しには、そこで述べた条件の下で安定な釣り合いが無い。a0.1 では、切替の押しの期待（段 0）が相対位置 −1.72 で釣り合う [ガウス・K 一定]（4.1）。実網はそれより深い所で止まる [実測]（付録 K）。模型の押しは凍結した網での期待値で、ミニバッチの揺らぎも Adam の更新も含まない。止め役（模型の外で沈みを止める項）の有無は、実網で確かめた仮定 H6 として扱う。

<!-- G11 -->
leaky の止め役は、ミニバッチの残差の揺らぎと出力の平均の積に比例する項である [候補]。沈んだ leaky では出力の平均が負なので、この項は浮かせる側に働く。この項が止め役なら、項が幅に比例するので、止まる相対位置は幅によらない。この項を抜くと、a0.1 の止まる位置は −2.19 から −2.91 へ深くなった [介入]（付録 K）。閉じた入力にも傾き a が残るので、leaky は死なずに片側化する。一隠れ層の ELU × Adam では、−1 の床と Adam の守りが、開いた入力の数を幅によらず一定に保つ [実測・介入]。二隠れ層では、この守りが歩幅に負けて層が機能低下に至りうる（4.4）。

<!-- G11 -->
ReLU では、同定済みの止め役の項がどれも 0 か沈める側だと、項ごとに示せる（付録 K.2 (r)）。揺らぎの項も、出力の平均が 0 以上なので沈める側に働く。ただし、全ての項で止め役が無いことは導いていない。止め役が無く、上端（全入力のうち最大の前活性）の余白の 1 課題の期待の変化が正でないこと（S1）と、死の近くでも揺らぎが消えないこと（S2）を仮定すれば、ユニットは有限の時間に確率 1 で上端が 0 を切って死ぬ [確率・仮定つき]（付録 K.2 (w)）。(S1)(S2) は導いていない。

<!-- G11 -->
入力が固定の層では、死んだ間の勾配はちょうど 0 なので、死は Adam の運動量の残りが開き直さない限り永久である [厳密・条件つき]（付録 K.2 (u)）。ELU × SGD と SiLU・GELU は全閉（全入力で前活性が 0 以下）まで下がる [実測]。SiLU・GELU では出力の平均が 0 へ近づき、同定された止め役が無い。

<!-- G11 -->
Snake 族（適応 Snake・kunekune など）は傾き φ′ が単調でなく、仮定 H0 の外にある。尺度 α が幅に追随する定常（K 一定）では、φ′ の谷（φ′ が極小の位置）が押しの安定な零点で、そのまわりで上は沈める側、下は浮かせる側である。したがって止め役は、活性化の谷として模型の中にある [ガウス]。同じ定常では φ′ が 0.675 以上の入力が残るので、ユニットは死なない（適応 Snake は位相 θ が 1 周期の窓に入るとき）[厳密・条件つき]（付録 K.2 (y)）。示したのは凍結した状態の符号と座る位置の一致までで、ユニットを谷へ運ぶ動きは導いていない。谷で止まることと可塑性の喪失の弱さの関係は、どちらとも言わない。

### 4.4 二隠れ層への適用

<!-- G12 -->
**上流を固定した第 2 層には同じ構造が移り、条件の内側で押しの向きが反転した例は、第 1 層が先に機能低下した後の層を除いて無い。第 1 層には raw で重みつきの補題として移るが、押しそのものは入力の条件で揃い方が変わり、上流の変化は模型の外に残る。先に落ちる層は壁と止め役から読み、実測で確かめた。** 第 2 層の位置は z̄₂ = W₂·µ₂ + b₂（µ₂ は平均入力）で、読み出し W₃ は入力によらない。そのため第 2 層は、入力 h1（第 1 隠れ層の出力）・平均入力 µ₂ の一隠れ層の理論と同じ構造を持つ [恒等式]。但し書きは 3 つある。第一に、定理と補題の符号に要る明るさ K2 = µ₂·h1 + 1 ≥ 0 は、h1 ≥ 0 の ReLU 以外では保証されない。第二に、位置の変化には上流の項 W₂·Δµ₂ が加わり、h1 を固定した模型はこれを含まない。第三に、µ₂ の向きは閉じた側の出力（ELU の −1 など）の共通成分が支配する。

<!-- G13 -->
第 1 層の読み出しは、第 2 層のゲートを通って戻る g_in で、入力に依る。そのため、切替の押しの期待が自己形に等しいという 4.1 の結果は移らない。第 1 層での期待の形は導出していない。移るのは段 1 の補題 Cov(φ′, φ) ≥ 0（4.2）で、重み |g_in|²K_n をつけた Cov_w(φ′, φ) ≥ 0 になる [厳密・raw・仮定つき]（付録 K.2 (m)）。重みの非負には K ≥ 0 が要り、raw では全入力で成り立つ。std では K < 0 の入力が 36% あり、第 1 層は補題の外にある。

<!-- G14 -->
bias を別に使わず、重みを平均入力の向き x̄ に沿って動かす道で届く相対位置の下限（壁）は、−mean(K)/sd(K) である [恒等式]。第 1 層の壁は raw で −3.83、std で −0.40 である。h1 は中心化されていないので、std でも第 2 層の壁は −2.0 と深い。そのため std で理論の中身が現れるのは第 2 層である（読み）。層の順序は導出していない。壁が深く、止め役が無いか歩幅に負ける層が先に落ちると読み、実測で確かめた（付録 K）。raw で第 1 層が先に落ちるのは最初の切替より前で、切替の押しの道の外にある。

<!-- 旧 4.9 -->
説明は最初の機能低下までとし（判定基準は付録 K）、その後は戻らない理由として扱う。ReLU では、死んだユニットの勾配は死んだ間ちょうど 0 である（4.3）。ReLU の g_in は第 2 層の開いたユニットだけを通るので、第 2 層が全部死ぬと第 1 層の勾配も 0 になり、第 1 層は凍る [厳密]。入力が動く第 2 層では、死んだ層も上流の項で運ばれる [恒等式 ＋ 実測]。

<!-- G12・G13・G15 -->
CIFAR の網の第 2 層では、4.2 の条件 Cov(e′, d) > 0 の内側で押しの向きが反転した例は、調べた leaky ReLU・ELU・ReLU のうち、第 1 層が先に機能低下した後の層にしか無かった。第 1 層で押しそのもの（実際の切替の一歩）が沈める側だったユニットの割合は、raw で学べている間 84〜97%、std で 37〜67% である [実測]（付録 K）。乱数ラベル MNIST の二隠れ層 ELU 網の第 1 層では、半分より多く開いた側へ戻るユニットと課題の組が 17〜19% あり、「戻らない」は第 1 層には移らない場合がある [実測]（付録 K）。移植の辞書と登録結果 #1〜#7 との照合も付録 K に置く。
