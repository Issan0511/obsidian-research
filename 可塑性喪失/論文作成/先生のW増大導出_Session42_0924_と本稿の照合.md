## 0. 一言で

先生の toy は本稿の背骨の箱そのもの（乱数ラベル CIFAR 固定 1,200 枚・3072-100-100-10・leaky 0.1・std・Adam 1e−3・batch 16・30,000 更新/課題）で、幅・書き込み・消す割合・滞在時間が本稿の A 腕と 1〜3% で一致する。先生の稿が埋めるのは②の **G4–G5（なぜ 5% 残るか＝消去が年齢とともに弱まり、供給が幅に跳ね返る）** と、本稿で未同定だった **「幅 → 遅れ」の担い手（層の相対速度 η/σ）**。本稿が持っていて先生に無いのは、供給源の介入（当てはめ後 SGD／凍結・状態リセット・交差 fork・CE 一致）、全部 SGD、隠れ幅、MNIST 固定入力、ε、そして ELU/std の下流（μ₂・cap・応答）。先生の箱は生き残る leaky で、崩壊（本流）には触れない。役割分担がそのまま接続面になる。

## 3. 本稿の結果が先生の稿に足すもの・絞るもの

- **供給源の介入（G3）**: 先生は静穏局面の形を導出したが、止めるとどうなるかは無い。本稿は当てはめ後だけ凍結／SGD で伸びの 7〜9 割・遅れの全部が消える（登録）。先生の「幅 → 相対速度 → 遅れ」と合わせると「当てはめ後の Adam → 幅 → 相対速度 → 遅れ」が両側から閉じる。
- **全部 SGD でも書き込みの弾性は .54–.57（時系列・事後・1 腕）**: 先生の弾性 ½ の導出は Adam の 1 歩が幅に依らないこと（尺度対称性）を使う。SGD ではこの前提が無いのに同じ値。導出の前提が広すぎるか、別の理由で同じ値になるか。先生に問う。
- **隠れ幅（h スイープ・登録）**: 先生の「幅が積もるのは低ランクの出力（10 ≪ 100）の帰結」のうち、ランクの余裕の側は本稿の h = 8（読み出しが全部を読む）でも残留が半分で不成立（LOSS_SET）。残るのは「支持を失った書き込みは弱い 2 次の力しか受けない」の側。先生の (ii) を支持し (i) を絞る。
- **読まれる／読まれない部分空間の残留（0924 走ゼロ）**: 1 課題後 .65 対 .85、10 課題で両方 .5–.6。先生の支持（読まれる側）／曲率（両方）の 2 項と同型。
- **消去の年齢依存（MNIST 固定入力・別箱）**: 射影の残留 f_k = .79, .72, .64, .58, .54, .51（k = 1, 2, 5, 10, 20, 40）から危険率は .21 → .09 → .04 → .02 → .007 → .003 で、先生の背景 .035 に落ち着かず更に減る。背景 h_bg が CIFAR 固有か、箱で違うか。
- **MNIST 固定入力の +100/課題（一定）**: 先生の CIFAR は増分が減る（t^0.6）。先生の式（τ_res と A の時間変化）を MNIST に当てると何が出るか。
- **ε の用量反応**: 実効変位 343 → 192（e8 → e3）。先生の「静穏の変位は η に依らない」と、当てはめ側の ε 依存を分ける材料。
- **ELU/std の下流（G6–G8・③）**: 先生の稿は生き残る箱の「遅れ」で、崩壊の箱には触れない。

## 4. 言い方の衝突（本稿側で直すもの）

- 「固定点は無い」（3 文の文 1・訂正ノート §0）→ **「固定点があるとしても観測地平の外で、釣り合いの高さ自体が上がり続ける」**。先生の命題 3–4 と同じ内容になる。
- 「なぜ 5% 残るかは未導出」→「本稿では未導出。機構の候補は先生の稿（支持の消去の年齢依存＋供給の跳ね返り）」。先生の確認と参照の形が決まるまでは②の G5 は「未導出」のまま。
- 「書き換えの大きさが幅の 0.7 乗」は MNIST の値。CIFAR では本稿も .49–.57 で先生の .57 と一致。
- 「Adam と SGD の差は尺度と尾」は変わらない。

## 5. 決定 9b への含意
