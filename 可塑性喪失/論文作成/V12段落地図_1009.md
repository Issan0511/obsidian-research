## 要旨

- **学習を続けると学び直せなくなる可塑性喪失について、** — 一段落・6文で、問い、自己形による負の偏り、幅と応答、介入、kunekune の導入、既存対策との比較をつなぐ。

## 1 序論

- **学習を続けると、なぜ学び直せなくなるのか。** — 前活性が負側へ偏り、応答を失う経路を本稿の問いにする。
- **入力平均を通じて重みの更新が** — 自己形の釣り合いが強く負側へ偏る理論を、leaky ReLU の正側約4%という例で示す。模型の条件と実訓練を区別する。
- **その偏りによって失われる機能は** — 負の相対位置と幅の増大が深さを増す関係、活性化ごとの応答・非線形性の喪失を示す。
- **位置や応答への介入で、** — 中心化と bias 抑制、成長制限、応答交換を実験的な接続として示す。
- **この分析を踏まえ、Snake** — 分布幅に曲がりの尺度を合わせる kunekune を導入し、適応 Snake とともに乱数ラベル CIFAR の高成績へつなぐ。
- **実ラベルの 5+1 CIFAR を用いた** — 活性化の既定値と、固定学習率・少数候補の較正という比較条件を保ち、既存3手法を上回り調整済み L2 Init と同等だった結果を述べる。
- **関連研究。** — 中心化・正規化・活性化と可塑性に関する先行研究、本稿の位置と幅から応答への接続を一段落にまとめる。独立した関連研究章は置かない。

## 4 駆動源の理論と活性化ごとの機能低下

- **本章では、乱数ラベルを学ぶ一隠れ層網について、** — 切替の最初の更新から幅・応答・介入へつなぐ。模型と実網、仮定と実測の所在を示す。
- **各ユニットの共通位置を** — m・s・r・p、開いた入力・生きたユニット・全閉、局所応答 d を定義する。

### 4.1 負側へ動く理由

- **§3.1 の局所勾配と明るさの積を** — 切替の「押し」と相1・相2を定義し、時期ごとに異なる模型を用いる。

#### 4.1.1 初期に大きく負側へ偏る理由

- **切替の押しの期待は、** — 出力と傾きの積からなる自己形と、負側の応答の弱さを核にする。
- **新ラベルは網の状態と独立・一様とする。** — H1 の固定特徴・学習済み読み出し模型で、新旧ラベル平均の自己形の式を示す。導出と有限回到達の幅条件は C.3(b)。
- **前活性をガウス分布、明るさを正の一定値とする** — 正負が半々でも釣り合わず、leaky 0.1 は正側が約4%まで減るという例で強い偏りを示し、安定な釣り合い r*₀ を定義する。
- **補題 1（負側の釣り合いへ向かう）。** — 活性化ごとの幅条件と H1 の持続の下で負側へ向かう。有限回の越えの条件は付録 C.3(b) に置く。ReLU は生存中に釣り合いを持たない。証明は C.5。
- **釣り合いの有無と幅による違いは** — §4.2、限界 §8、実測 D.2 の表 D2・C.3(b) へつなぐ。

#### 4.1.2 沈んだ後も押しが残る条件

- **相 2 の押しを、凍結・線形化した網に** — H2 と読み出し・ゲートの二成分、ゲートの位置変化への反応 e′ を定義する。
- **補題 2（負の偏り）。** — 残差化模型と並べ替え平均の適用条件・符号条件の下で、自己形の釣り合いより下にも期待の押しが残る。leaky・ReLU では符号条件が r < 0 と同じになり、ELU では r < r_g(σ) に限られる。証明は C.5。
- **理由は、他のユニットを含めた当てはめでは、** — 自己形の共分散と平均積の分解、定数成分の分担によって共分散が残る直観を示す。
- **整流型の実際の入力の並びへ結び付けるには、** — 追加仮定 H4 を置き、重なりが橋と閉じたユニットの持ち上げの合計で、実状態では必要量に届かないことを示す。橋・必要数・持続性・実測の所在を示す。
- **SiLU・GELU には傾きが負になる域があるが、** — 幅と重み比の条件付き拡張を C.3(h⁗) へ送る。実訓練の保証とは区別する。

### 4.2 幅の増大による釣り合いと開いた割合の変化

- **相対位置が負のままほぼ一定なら、** — m = rs により幅の成長が共通位置を深くする。H5 は仮定であり、成長理由は未導出。
- **幅の増大は、自己形の釣り合いで正側に残る入力の割合も変える。** — leaky は幅によらず、ReLU は釣り合いが無い。ELU は釣り合いが深まり p*₀ が減り、SiLU・GELU は釣り合いが消える。数値の根拠は C.3(b)。
- **ここで小さくなる p*₀ は、** — 自己形の釣り合いの値と実網の開いた割合 p を区別し、別の止め役を次節で調べる。

### 4.3 実網の止まり位置と残る応答

- **§4.1.2 の模型は** — ミニバッチの揺らぎと Adam を含まない模型の限界を示し、止め役と残る応答を実測・介入で調べる（H6）。

#### 4.3.1 leaky ReLUは応答を残すが片側化する

- **a = 0.1 の leaky ReLU の実網は、** — 自己形より深い停止、揺らぎ×負の平均出力の止め役候補、除去介入を述べる（D.2 の表 D2・(h)）。
- **leaky は閉じた入力にも傾き a を残すため、** — 傾きが残っても全入力が負側なら一つの直線となることを示す。

#### 4.3.2 ELUの止まり位置は最適化器で違う

- **ELU は尺度固定で z → −∞ となると、** — 1層 Adam の押し戻しと SGD の全閉を付録 D.3 の表 D7 へ、2隠れ層で保持が破れる条件を表 D7・D.2 の表 D3 へ結ぶ。

#### 4.3.3 ReLUは負側で応答を失う

- **ReLU は z < 0 で傾きがゼロになり、** — 同定済みの止め役の不在（揺らぎの項は SGD の 2 歩の式で、Adam での符号は未確認）と、S1・S2 等を仮定した有限時間死亡を区別する。
- **入力が固定なら、** — 死亡中の勾配零化と、Adam の残留運動量で再開しない場合の永久性を述べる。

#### 4.3.4 SiLU・GELUは深い負側でほとんど閉じる

- **SiLU・GELU も尺度固定で z → −∞ となると、** — 深い帯の瞬間的な浮上項と、半分より多く開いた側への戻りが観測されなかったことを述べる。負の r と幅成長の接続は保つ（C.3(h⁗)）。
- **SiLU・GELU は全閉まで下がる** — 全閉の実測と、止め役の未同定を示す。

### 4.4 二隠れ層への適用

- **上流を固定した第 2 層には、一隠れ層と同じ構造が移る。** — 読み出しの入力非依存性、K2 の符号条件、模型外の上流変化を示す。
- **第 1 層の読み出しは、** — 入力依存のため自己形の等式は移らず、非負重みつき共分散の補題だけが移る。std の符号条件外を明示する。
- **bias を別に使わず、** — 平均方向の移動で相対位置が近づく壁 −c と、それが下限になる条件（回帰の切片が非負）、層の順序の解釈・実測を示す。
- **説明は最初の機能低下までとし** — 低下後は回復制約として扱い、ReLU の全死・勾配遮断（勾配 0 は厳密、凍結は Adam の残りが尽きた後）と上流輸送を説明する。
- **調べた CIFAR の leaky ReLU・ELU・ReLU の第2層では、** — 押しの反転と先行層低下、MNIST 第1層の戻りを照合し、全層への一般化を避ける（D.2 (i)〜(l)・D.3 の表 D7）。

### 4.5 幅を止める介入による検証

- **幅を止める介入の効き方は、活性化によって分かれた。** — ELU・SiLU・GELU の改善条件と、実ラベル ReLU の不改善を対比する。

#### 4.5.1 ELUは両層の成長上限で成績が改善する

- **課題 1 終端の行ノルムを半径として、** — cap12 と片層上限、入力平均の変化、MNIST の改善を示す。相対位置と深さの事後診断は D.2(p)。

- **成長上限の効果には沈降の抑制と実効学習率の保持が** — 二つの寄与が未分離であることを述べる（C.4）。

#### 4.5.2 ReLUは深さを抑えても開閉が変わらない
