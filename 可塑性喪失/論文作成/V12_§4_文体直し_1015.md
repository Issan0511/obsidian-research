**語。本章の語と記号は、次のとおりである。**

位置・幅・ゲート:
- **位置** m = w·x̄ + b。平均入力の向きの成分で、§2.1 の共通位置 z̄ と同じ量。
- **幅** s = sd_n(z)。データの上の散らばり。
- **相対位置** r = m/s。付録 C の入力の平均／偏差の比 r とは別の量で、そちらは「付録 C の r」と書く。
- **開いた割合** p。ガウスでは p = Φ(r) で、付録 J の p⁺ を unit ごとに取った同じ量。
- **明るさ** K_n = x̄·x_n + 1。bias 込みで、付録 E の旧 §3.1 の x^⊤µ + 1 に当たる。位置の一歩で z_n が t K_n ずれる。raw は K ≥ 0、std は 36% が負である。
- **ゲート** d = φ′(z)。
- **e′_n** = K_n ∂d_n/∂z > 0。e′ の大きい入力が、閾値の近くの入力である。
- **p_max**：課題末の softmax の最大の平均。押しの源の指標。

押しとその項:
- **押し** A_i：切替の最初の一歩で位置が動く量の期待。模型では容量の押し ∂Φ/∂t_i で、A > 0 が沈める側。
- **切替の押し** S_i = Σ_n K_n d_in⟨v_i, p_n − 1/K⟩。相 1 の量で、新しいラベルについての期待。古い関数は実際の softmax である。K はクラス数、v_i は unit i の読み出し。p_n は入力 n の softmax の出力で、開いた割合 p とは別。
- **押しそのもの**：当て残しの項を含む実際の一歩。3 層では実際の S_i。
- **当て残し**：課題の終わりに網が当てられていないラベルの部分。模型ではリッジ λ。
- **自己項**：unit 単独の核で測った押し。閉じた側の a 倍の分と、自分の読み出しの道の分の和。後者が浮かせる側のとき、浮力と呼ぶ。
- **残り** = 全体 − 自己項。
- **自己形**：段 0 の量 Σ_n K_n φ′(z_n)φ(z_n)。切替の押しの自己の部分で、自己項とは別の量。相 2 では、自己形は浮かせる側、自己項は沈める側である。
- **自己項の形** = Cov(e′, d)。

段・谷底・橋など:
- **段 0〜3**：他の unit が作れるものの段。段 0 から順に、なし、定数、自分の z の 1 次式、入力の 1 次式と写し。
- **谷底** d̂_in：unit i の入力 n のゲートだけを動かしたとき、容量が最小になる値。
- **橋**：標的の閾値の入力と開いた入力をまたいで開く unit。部分的な写し。
- **留め置き**（逆向きの押しが続く状態）：自己項 > 0 なのに A_i ≤ 0 であること。
- **被覆**：unit が標的の開いた集合を覆う割合。
- **釘付け**：沈む unit が最上位の入力を開いたまま、底の近くで止まる状態。

相・止め役・壁:
- **相 1**：切替の押しが運ぶ相。初期の広い相で、1 隠れ層の箱では課題 < 10。
- **相 2**：押しが細って止め役との釣り合いに入った後の相。狭い相で、課題 ≥ 10・r ≈ r*。r* は止まる位置。
- **止め役**：模型の外で沈みを止める項。
- **壁**：相対位置の下限 −mean(K)/sd(K)。

条件・補題・主張・版:
- **(A)**：半分より多く開いていない（p < 1/2）。
- **(B)**：複製が無い。
- **補題 1**：対称な出発点（p ≈ 1/2）を離れること（4.2）。
- **補題 2**：p < 1/2 で、段 1 以上の期待の押しの全項が沈める側（負の偏り。4.5）。
- **主張**：押しが初期も沈んだ後も沈める側で、模型の中に釣り合って止まる位置が無く、沈降が進むこと（4.5・4.6）。
- **版**：版 (α)・(β)・(δ) は、1 隠れ層の定理 2 の重みの割り方。版 (A)・版 (B) は、3 層の第 1 層の重みの割り方。どちらも必ず「版」を付ける（付録 K）。

開閉・死・凍結:
- **O・k**：O は開いた入力の集合（z > 0）、k は開いた入力の数。
- **全閉**：unit の前活性が全入力で z ≤ 0 の状態。
- **生きた unit**：全閉でない unit。z > 0 の入力が 1 個以上あり、死の反対ではない。
- **死**：unit の訓練の微分が全入力で厳密に 0 の状態。ReLU では全閉と一致する（z = 0 ちょうどは訓練中に 0 回）。ELU では expm1 の実装の箱で全入力 z < −16.64 のとき起き、F.elu の箱では起きない。leaky は全閉でも傾き a が残るので死なない。
- **層の機能低下 T_d**：P173・P175 の層の死の基準（p の unit 中央値 < 1%）で数える。付録 K.1 の gate 平均 < 1%（P169）とは別の数え方である。
- **全滅（全死）**：層の全 unit が全閉の状態。
- **吸収**：入力が固定の層で、死んだ unit が開き直らないこと。ReLU で、Adam の残りが開き直さないときに限る（4.9）。
- **死を待たない機能低下**：全画像で訓練の微分が 0 の unit が出る前に、応答が細って成績が落ちること（§5。ELU）。
- **凍結**：第 2 層の死で第 1 層の読み出し g_in がほぼ 0 になり、第 1 層が動けないこと（4.9）。bit で止まるのは、訓練の微分が厳密に 0 になる場合である。それは、CIFAR の訓練では ReLU と GELU std、第二の箱では expm1 の ELU である。

Snake 族:
- **Snake 族**：適応 Snake（SNA）・kunekune（KKT1）・KKA（付録 F）。帯の中の微分は φ′ = 1 + sin θ、θ = 2α_i z で、α_i は付録 F の適応尺度。
- **位相** θ̄ = 2α_i z̄。
- **φ′ の谷**：φ′ が極小になる位置。Snake 族は θ ≡ −π/2 で φ′ = 0、SiLU・GELU は φ′ < 0 の域。谷底 d̂ とは別である。
