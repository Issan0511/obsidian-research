**語。本章の語と記号は、次のとおりである。**

位置・幅・ゲート:
- **位置** m = w·x̄ + b。平均入力の向きの成分で、§2.1 の共通位置 z̄ と同じ量。
- **幅** s = sd_n(z)。データの上の散らばり。
- **相対位置** r = m/s。付録 C の入力の平均／偏差の比 r とは別の量で、そちらは「付録 C の r」と書く。
- **開いた割合** p。ガウスでは p = Φ(r) で、付録 J の p⁺ を unit ごとに取った同じ量。
- **明るさ** K_n = x̄·x_n + 1。bias 込みで、付録 E の旧 §3.1 の x^⊤µ + 1 に当たる。位置の一歩で z_n が t K_n ずれる。raw は K ≥ 0、std は 36% が負である。
- **ゲート** d = φ′(z)。
- **e′_n** = K_n ∂d_n/∂z > 0。e′ の大きい入力が、閾値の近くの入力である。
- **p_max**：課題末の softmax の最大の平均。押しの源の指標。

押しとその項:
- **押し** A_i：切替の最初の一歩で位置が動く量の期待。模型では容量の押し ∂Φ/∂t_i で、A > 0 が沈める側。
- **切替の押し** S_i = Σ_n K_n d_in⟨v_i, p_n − 1/K⟩。相 1 の量で、新しいラベルについての期待。古い関数は実際の softmax である。K はクラス数、v_i は unit i の読み出し。p_n は入力 n の softmax の出力で、開いた割合 p とは別。
- **押しそのもの**：当て残しの項を含む実際の一歩。3 層では実際の S_i。
- **当て残し**：課題の終わりに網が当てられていないラベルの部分。模型ではリッジ λ。
- **自己項**：unit 単独の核で測った押し。閉じた側の a 倍の分と、自分の読み出しの道の分の和。後者が浮かせる側のとき、浮力と呼ぶ。
- **残り** = 全体 − 自己項。
- **自己形**：段 0 の量 Σ_n K_n φ′(z_n)φ(z_n)。切替の押しの自己の部分で、自己項とは別の量。相 2 では、自己形は浮かせる側、自己項は沈める側である。
- **自己項の形** = Cov(e′, d)。

段・谷底・橋など:
- **段 0〜3**：他の unit が作れるものの段。段 0 から順に、なし、定数、自分の z の 1 次式、入力の 1 次式と写し。
- **谷底** d̂_in：unit i の入力 n のゲートだけを動かしたとき、容量が最小になる値。
- **橋**：標的の閾値の入力と開いた入力をまたいで開く unit。部分的な写し。
- **留め置き**（逆向きの押しが続く状態）：自己項 > 0 なのに A_i ≤ 0 であること。
- **被覆**：unit が標的の開いた集合を覆う割合。
- **釘付け**：沈む unit が最上位の入力を開いたまま、底の近くで止まる状態。

相・止め役・壁:
- **相 1**：切替の押しが運ぶ相。初期の広い相で、1 隠れ層の箱では課題 < 10。
- **相 2**：押しが細って止め役との釣り合いに入った後の相。狭い相で、課題 ≥ 10・r ≈ r*。r* は止まる位置。
- **止め役**：模型の外で沈みを止める項。
- **壁**：相対位置の下限 −mean(K)/sd(K)。

条件・補題・主張・版:
- **(A)**：半分より多く開いていない（p < 1/2）。
- **(B)**：複製が無い。
- **補題 1**：対称な出発点（p ≈ 1/2）を離れること（4.2）。
- **補題 2**：p < 1/2 で、段 1 以上の期待の押しの全項が沈める側（負の偏り。4.5）。
- **主張**：押しが初期も沈んだ後も沈める側で、模型の中に釣り合って止まる位置が無く、沈降が進むこと（4.5・4.6）。
- **版**：版 (α)・(β)・(δ) は、1 隠れ層の定理 2 の重みの割り方。版 (A)・版 (B) は、3 層の第 1 層の重みの割り方。どちらも必ず「版」を付ける（付録 K）。

開閉・死・凍結:
- **O・k**：O は開いた入力の集合（z > 0）、k は開いた入力の数。
- **全閉**：unit の前活性が全入力で z ≤ 0 の状態。
- **生きた unit**：全閉でない unit。z > 0 の入力が 1 個以上あり、死の反対ではない。
- **死**：unit の訓練の微分が全入力で厳密に 0 の状態。ReLU では全閉と一致する（z = 0 ちょうどは訓練中に 0 回）。ELU では expm1 の実装の箱で全入力 z < −16.64 のとき起き、F.elu の箱では起きない。leaky は全閉でも傾き a が残るので死なない。
- **層の機能低下 T_d**：P173・P175 の層の死の基準（p の unit 中央値 < 1%）で数える。付録 K.1 の gate 平均 < 1%（P169）とは別の数え方である。
- **全滅（全死）**：層の全 unit が全閉の状態。
- **吸収**：入力が固定の層で、死んだ unit が開き直らないこと。ReLU で、Adam の残りが開き直さないときに限る（4.9）。
- **死を待たない機能低下**：全画像で訓練の微分が 0 の unit が出る前に、応答が細って成績が落ちること（§5。ELU）。
- **凍結**：第 2 層の死で第 1 層の読み出し g_in がほぼ 0 になり、第 1 層が動けないこと（4.9）。bit で止まるのは、訓練の微分が厳密に 0 になる場合である。それは、CIFAR の訓練では ReLU と GELU std、第二の箱では expm1 の ELU である。

Snake 族:
- **Snake 族**：適応 Snake（SNA）・kunekune（KKT1）・KKA（付録 F）。帯の中の微分は φ′ = 1 + sin θ、θ = 2α_i z で、α_i は付録 F の適応尺度。
- **位相** θ̄ = 2α_i z̄。
- **φ′ の谷**：φ′ が極小になる位置。Snake 族は θ ≡ −π/2 で φ′ = 0、SiLU・GELU は φ′ < 0 の域。谷底 d̂ とは別である。

**止め役の働きは、上端の余白の変化 ΔY/s の符号に出る。** 上端の余白は Y = max_n z_in である。ΔY は、課題末から次の課題末への Y の変化である。s は課題末の幅である。ReLU × Adam では、開いた入力の数 k の 5 区分 × 3 seed の全部で、ΔY/s の平均が負である。死の近く（k ≤ 3）でも、揺らぎは k ≥ 11 の 0.82〜1.23 倍残る。SGD では 0.37〜0.50 倍に縮む [実測]。leaky a0.1 と ELU では、同じ量が死の境の近くで戻す側である [実測]。k ごとの値は表 4.6-C に置く。1 隠れ層の箱の ReLU では、同定済みの止め役が無いことに加えて、戻す漂流も実測で見えない [実測]。

**ELU の閉じた unit は動ける。** 1 隠れ層の箱で課題末に全画像で閉じていた ELU の unit は、次の課題の後半に自分の重みで動く。その量は、開いた unit の 1.41 倍である（中央値の比）。全画像で訓練の微分が 0 になる深さ（z < −16.64）に入る unit は無い [実測]（P172。seed 0）。1 隠れ層の箱の ELU は d では死なず、機能は課題 12〜14 に半分を割る（表 11）。ELU × SGD・SiLU・GELU は、全閉まで下がる [実測]。

**ReLU では、前活性が 0 を下回った入力で、訓練の勾配が深さによらず止まる（§5）。** 入力が固定の層では、全入力で閉じた ReLU unit の勾配は、死んだ間は厳密に 0 である。重み・bias・読み出しのどの勾配も、どの損失・バッチ・ラベルでも 0 である [厳密]。死んだ unit が戻らないこと（吸収）と、全部死んだ網は 4.9 に置く。学べる向きの数は、rank 𝒦 ≤ Σ_{生きた j} min(k_j, rank X̃) + K′(|A| + 1) で押さえられる [厳密・模型]。k_j は unit j の開いた入力の数、|A| は生きた unit の数、K′ は出力の数である。狭さ、つまり開いた入力の少なさは、leaky では階数を減らさず、固有値を a² 倍に縮めるだけである。ReLU では、狭さそのものが階数の天井になる [厳密・模型]。死の数だけでは、容量の順序は決まらない（生きた unit の重みの伸びが核を増やす）[反例]。

**生きた unit が実際の訓練で死に着くことは、2 つの仮定の下で、有限の時間に確率 1 で起きる** [確率・仮定つき]。仮定 (S1) は、上端の余白 Y = max_n z_in の 1 課題の期待の変化が正でないことである。仮定 (S2) は、死の近くでも揺らぎが消えないことである。(S1) は [未導出] である。模型が与えるのは、幅を止めた押しの符号である。実際の 1 課題の漂流には、幅の伸び（H5）と課題の中の揃い直しが入る。(S2) も導出は無い。Adam の正規化で歩幅が勾配の大きさによらないことからの見込みである。SGD では、歩幅が開いた側の質量に比例して、死の近くで縮む。

**1 隠れ層の箱の ReLU × Adam では、死の 93〜95% を運動量の残りが閉じる。** これらの unit は、最後の勾配を受けた時点ではまだ開いていた。最後の勾配は、死んだ課題の更新 176〜187（中央値）にあり、切替の直後である [実測]（P172）。SGD では、全部が勾配の一歩で閉じる [実測]。1 隠れ層の箱の実網では、(S1) と (S2)（Adam）が成り立つ。根拠は、上の止め役の段落の ΔY/s である [実測]。課題 1〜20 では、正答率との順位相関が 3 つの量で 0.87〜0.94 である。3 つの量は、生きた unit の数（= 100 − 死の数）、階数の上界の割合、硬い版の容量である。どれが主かは、3 seed では分けられない [実測]。機能が半分を割る T_f（課題 3〜4）は、層の T_d（課題 4〜5）の 1 課題前か同じ課題である（表 11）。

**Snake 族では φ′ が単調でないので、段 1 の補題の前提が外れる（H0 の外）。** H0 は、乱数ラベルの課題列と、φ′ が単調非減少な整流型の活性化という設定である。Snake 族では φ′ = 1 + sin θ である（θ = 2α_i z、α_i は適応尺度）。K 一定では、段 0・段 1・段 2 の押しは、それぞれ ½E[φ²]・½Var φ・½Var φ⊥ の位置についての微分である [恒等式]。φ⊥ は、自分の z の最良の直線を引いた残りである。切替の一歩は Δm = −η × 押し なので、unit は各段の量を下る。段 1 なら、下る量は自分の出力の分散である [恒等式]。H0 の下では Var φ は位置について単調非減少で、段 1 に安定に止まる点は無い [恒等式 ＋ チェビシェフ]。

**ガウスの下では、押しの符号は φ′ の谷を境に分かれる。** 適応尺度の定常では、θ の幅は 2c√(B/(B − 1)) = 1.24 に固定される（c = 0.6、バッチ B = 16）。押しの符号は、相対位置 r と z の分布の形だけで決まり、幅によらない [恒等式 ＋ 仮定つき（定常・clip なし）]。1 層の箱では、ασ（尺度と幅の積）の中央値は 0.622 で、clip は 0 である [実測]。θ̄ を θ の平均とする。θ ~ N(θ̄, 1.24²)・K 一定では、SNA の段 1 の符号は sign(cos θ̄) である。段 2 の符号は −sin 2θ̄ の符号である [厳密]。閉じた式は付録 K.2 (y) にある。帯の外が直線の KKT1・KKA には、この式は当たらない。谷を含む盆地の中で符号が変わるのは、谷だけである [ガウス]（数値の根）。盆地の範囲は表 4.6-D に置く。同じ仮定で、φ′ の谷は θ̄ = −π/2（r = −1.27）にある。谷は、3 腕とも段 1・段 2・ゲートの分の 2 項の共通の安定な零点である。そのまわりで、上は沈める側、下は浮かせる側である [厳密（SNA）・ガウス（KKT1・KKA は数値）]。谷での零は、K 一定で z の分布が平均について対称なら厳密である [厳密・K 一定]。段 0 の零点は、θ̄ −1.19（r −0.96）にある。相 1 の切替の押しの期待（4.2）は、この零点より上で沈める側である [厳密な極限 ＋ ガウス]。

**この節は、最初の機能低下の後の動きを書く。** 最初の機能低下は、層の機能低下の時刻 T_d と、網の機能が半分を割る時刻 T_f の早いほうである（表 11）。ここに置く動きは喪失の機構ではなく、喪失が戻らない理由の記述である。箱（実験設定）ごとの値は表 12 に置く。1 隠れ層の箱は、乱数ラベル MNIST の 1 隠れ層網である。背骨は乱数ラベル CIFAR の二隠れ層網で、入力は raw か標準化した std である。第二の箱は、乱数ラベル MNIST の ELU 二隠れ層網である。

**入力が固定の層では、ReLU unit の死が永久になるのは、Adam の運動量の残りが開き直さないときである [厳密・条件つき]。** これを死の吸収と呼ぶ。この層では、全入力で閉じた ReLU unit の勾配は死んだ間は厳密に 0 である（4.6）[厳密]。死後に残る動きは、運動量の残りだけである。β (0.9, 0.999) では、その大きさは座標あたり 65.8·lr（lr は学習率）以下で、向きは最後の一歩と同じである [厳密]。残りで開き直った実例がある [反例]。開き直すかは、状態ごとに判定できる。Adam の ε → 0 で最後の勾配の歩 t₀ が大きいとき、残りの合計は最後の更新の 9.05 倍になる。この倍率は ρ/(1 − ρ)、ρ = β₁/√β₂ である。前活性 z_in（unit i・入力 n）の行き着く値は、z_in(∞) ≈ z_in(t₀) + 9.05·Δz_in(t₀) である。全入力で z_in(∞) ≤ 0 なら、永久に閉じる [厳密・極限]。状態によらない最悪の場合の余白（lr 1e−3 の MNIST で 16.7〜22.8）は保守的で、実用にならない。float32 では、最後の勾配から 70〜190 更新で重みの行が bit 不変になる [数値（見積もり）]。なめらかなゲートの模型は向きを再現するが、この吸収は再現しない [厳密]。

**1 隠れ層の箱の ReLU では、課題末に死んでいた unit は、次の課題末にも 5 課題後にも開かない。** 同じ解析で、leaky a0.1（a は閉じた側の傾き）と ELU には次の課題末に開く unit がある。死んだ unit の重みは、課題末どうしで bit 一致する [実測]（P172）。課題末に閉じていた unit が次の課題の後半に自分の重みで動く量も、厳密に 0 である [実測]。残りによる変化は、最後の更新の 9.05 倍である（傾きの中央値）。予測した max z(∞) と実際の値の差は、中央値で 0.0004 である。永久の判定は、課題の中で死んだ 299 個のうち 295 個で実際と一致する。外れた 4 個は課題 1 の死で、t₀ が小さく近似の外にある [実測]。SGD では、残りは厳密に 0 である [実測]。

**第 2 層が先に機能低下した箱では、その後に第 1 層が凍る。** 凍るとは、第 2 層の死で第 1 層の読み出しがほぼ 0 になり、動けないことである。ReLU の第 1 層 unit i の入力 n での読み出し g_in は、第 2 層の開いた unit だけを通る。i の開いた入力の全部で、i と結ばれた第 2 層の unit が閉じているとする。このとき、i の勾配はその時点で厳密に 0 である（機能的な死）[厳密]。この凍結が続くかは第 2 層の模様しだいで、言えない。全閉（全入力で閉じた）の第 1 層 unit が動かないのは、活性化の微分が φ₁′ ≡ 0 だからである。g_in は、第 2 層が生きている間は 0 でない。ReLU raw の課題 1 では、|g_in|² は 0.42〜0.96 である [実測]（P173）。段 1 は、他の unit が定数を作れるとした段である。第 2 層が死ぬと、g_in ≈ 0 となる。第 1 層は、段 1 の押し（重みつき補題 Cov_w(φ′, φ)）の向きを保ったまま、測度を失って凍る。

**背骨 std の ELU・GELU・SiLU・ReLU では、第 2 層の死で第 1 層が凍る。** 凍る位置は、相対位置 r（位置 ÷ 幅）で −0.09〜−0.11 である [実測]（P169・P173）。CIFAR の訓練で第 2 層が全死した後に第 1 層の重み W1 が bit 不変になるのは、ReLU と GELU std だけである。ELU std・SiLU std は、bit では止まらない [実測]（P173）。ReLU では、第 2 層が全部死ぬと g_in = 0 が float64 でも厳密に成り立つ [厳密]。std の 3 seed とも、全死の課題（表 12）から W1・b1・W2・b2・W3 が bit 不変になる。動くのは b3 だけである [実測]（P173）。全死の前は、生き残った第 2 層 unit が第 1 層を動かし続ける。第 2 層の開いた割合 p₂（前活性が正になる入力の割合）の中央値が 1% を切ってから、全死まで 3〜5 課題かかる [実測]。

**leaky→R・LE と第二の箱でも、第 1 層は凍る。** leaky→R は、第 1 層 leaky・第 2 層 ReLU の層別キメラである。LE は、第 1 層 leaky・第 2 層 ELU の層別キメラである。leaky→R では、第 2 層が課題 2〜3 に全死した課題から W1・b1 が bit 不変になる [実測]（P173）。その第 1 層は沈んでから凍る（沈み方は seed ごとに表 4.9-A）。3 seed とも、課題 2〜3 に r −3.2〜−3.6 で凍る [実測]。LE の第 1 層は、第 2 層のゲートが閉じていく課題 2〜5 に沈んでから凍る（付録 J）。第二の箱の第 1 層は、第 2 層の最後の unit の死の後（T_d の 30〜60 課題後）に凍る。それまでは、生き残った第 2 層の unit（課題 12 で 16〜42 個）が第 1 層を動かし続ける [実測]（P175）。

**死んだ層は、壁に座るとは限らない。** 壁は x̄ の道（重みを平均入力 x̄ の向きに動かす道）で届く相対位置の下限で、それより下へ行けない床ではない [恒等式]。ReLU の層は、死んだ時点の r で止まる。raw の第 1 層では、r の中央値が seed ごとの壁の 0.02〜0.17 上にある。unit の 27〜45% は、壁の下にある [実測]（P173）。1 隠れ層の箱の ReLU の unit も、死んだ時の r で止まる。その中央値は −2.73〜−2.77 で、壁 −3.48〜−3.56 まで行かない [実測]（P172）。

**std の止め役の無い活性化では、第 2 層は壁で T_d に至り、その後も壁に座る。** 止め役は、模型の外で沈みを止める項である。課題 3 の r₂ − 壁₂（第 2 層の相対位置と壁の差）は、seed 平均で ReLU −0.02、ELU +0.14 である（P173）。ELU は seed で −0.05〜+0.30 である（P175）。ReLU の第 2 層は、全死した後も壁 −mean(K2)/sd(K2) に座る [実測]（P173）。K2 は第 2 層の明るさである。全死の課題と、壁からの差は表 12 に置く。

**背骨の ELU std の第 2 層は、相対位置を保ったまま幅だけが伸びる。** 層集約の相対位置 z̄₂/σ₂ は −1.85〜−1.95 に保たれる。その間に、幅は課題 5 → 50 で 299 → 461 に伸びる。課題 3 では、z̄₂/σ₂ は −1.53、幅は 152 である。値は `rlcifar_mlp_battle_0918` の 10 seed の層集約の中央値で、登録列の読みである。S5（成長上限の実験）の ref では、幅は 326 → 460 である（表 6a）。相対位置がほぼ動かず幅だけ伸びるこの形は、絶対位置 m = r·s（相対位置 × 幅）の形である。これは生きた unit の負の偏り（4.5）ではなく、死んだ層を上流（前の層の変化）が運ぶ形と読む（読み）。r の台地（r が平らに留まること）は、止め役の印ではない。ELU std の第 2 層の −2.0 は、壁で死んでいる。

**第二の箱の第 2 層は、T_d では壁より浅く、その後に上流で壁へ運ばれる。** T_d での r₂ は、壁₂ より 0.59〜1.19 浅い。課題 50 では、r₂ − 壁₂ = +0.02 になる [実測]（P175）。3 層 std の「壁に座って死ぬ」とは、順序が逆である。

**入力が動く層では、死んだ unit も上流で動く。** ReLU では、死んだ第 2 層 unit の自分の重みの勾配は、死んだ間は厳密に 0 である。Adam の残りが尽きた後は、位置は上流の項 W₂·Δµ₂ でだけ動く [厳密]。Δµ₂ は、第 2 層の平均入力 µ₂ の変化である。Adam の残りを足した値で b₂_j < 0（unit j の bias）とする。さらに、第 1 層の出力 h1_c が今後正になりうる全ての c で W₂_jc ≤ 0 とする。このとき、その unit は永久に死ぬ [厳密]。背骨の ELU raw の第 2 層では、死後に ‖µ₂‖ が ×22 に伸びる。この伸びは、常時点灯（全入力で開いた）unit か、開いた入力を持つ unit の z1 の尺度が運ぶ [実測]（図 K6）。z1 は第 1 層の前活性である。

**登録 #4（課題の間は上流が運ぶ）のうち、上流が自己を上回って運ぶ部分は、死んだ層を上流が運ぶこの局面の文である。** C 腕（入力を中心化した背骨の ReLU）の第 2 層では、上流移動 U が 5/5 で負で、課題を追うごとに増える。U の負は課題 2 から出る。C 腕の第 2 層は、課題 3〜4 に T_d に至る（表 11）。U が自己移動 S を上回る seed が 4/5 になるのは、T_d の後の課題 5 である（付録 D）。A6（ELU/std の帳簿）の報告のみの固定窓 t10→50 では、第 2 層で上流が 99% である。この窓も、第 2 層が課題 3〜4 に T_d に至った後の窓である（§5・表 11）。ただし、#4（C 腕 ReLU）と A6（ELU/std）は活性化・入力条件の違う走で、単一軌道の機構としては連結しない。

**第二の箱では、T_d の後も上流が第 2 層を壁へ運び、層は戻らない。** T_d の後に ‖µ₂‖ はさらに ×3 伸び、層ごと壁へ運ぶ [実測]（P175）。ELU の死は吸収ではない。第二の箱の ELU では、float32 の訓練の微分が z < −16.64 で 0 になる。全入力でこの深さに入った第 2 層 unit も、35〜45% が上流（h1 の変化）で一度は戻る [実測]（P175）。それでも、第 2 層の生きた unit は課題 50 までに 1 個に減り、層は戻らない [実測]（P175）。unit の数は、課題 12 までは 10 seed、以降は seed 0〜2 の平均である。

**第 2 層の入力 h1 の中心化した参加比は、第 2 層の T_d と同時かその後に落ちる [実測]（P178）。** 参加比は、h1 の散らばりが実質いくつの方向に広がるかを表す。std の ELU・ReLU では課題 3 に、ELU raw では課題 4〜5 に落ちる。第二の箱では T_d で落ち、課題 20 以降はさらに落ちる。開いた集合の入れ子（unit の開いた入力の集合が互いに含み合う度合い）は、参加比の落ちより先に上がる。ELU raw では課題 1 → 3 に、第二の箱では課題 4〜5 に上がる [実測]（P178）。したがって、参加比が落ちて橋ができるのではない。参加比の落ちは、死に向かう層の第 1 層の出力が少数の方向（第二の箱では常時点灯の unit）に縮むことの記述と読む（読み）。生きた LR（leaky ReLU）raw の参加比は、逆に 9.2 → 27 と上がる（4.7 (iii)）。

**押しの源（学べていること）が無くなった後は、押しの向きは揃わない。** 学べない状態は、課題末の softmax の最大の平均が p_max ≈ 1/K の状態である。この状態で、背骨の第 1 層の実際の押し S_i は、沈める側と浮かせる側が半々である [実測]（P169）。3 層の層別キメラ EL・GE・GG の第 2 層でも、押しの源が無い状態では符号は半々である（表 7 の #3）。第二の箱の第 1 層の S_i は、凍結の後に 0.43〜0.55 である [実測]（P175）。

**1 隠れ層の箱の leaky a ≤ 0.1 と ELU は、d では死なずに、課題 8〜14 に T_f に至る（表 11）。** d は訓練の微分である。その後の相 2（押しが細って止め役と釣り合った後の相）では、相対位置は負に留まる。r は leaky a0.1 で −2.1〜−2.3、ELU で −2.1〜−2.4 である。開いた割合が 1/2 を上回る生きた unit-task は、leaky a0.1 では 0 個である。a0.03 では seed あたり 1 個、ELU では戻りが 0〜1 個である（4.5 の負の偏り。分母は表 12）[実測]（P172・P175・P177）。幅は伸び続け、絶対位置 m = r·s は深くなる（4.1・4.6）。これらは、死なない層で機能が戻らない理由の記述として読む（読み）。leaky の機能の低下は本稿の死の経路の外にあり、その機構は扱わない（§6・付録 F・§11）。

**本稿は恒久的な救済を主張しない。** 最初の機能低下の後、ReLU では死んだ unit の自分の勾配が厳密に 0 である。第 2 層が全部死ぬと、第 1 層も凍る [厳密]。背骨 std では、b₃ 以外の全ての重みが bit 不変になる [実測]。画像の集合が固定の箱では、ReLU の死んだ unit が自然な学習則のまま戻る道は、上流の変化と Adam の残りの他に無い [厳密]。ELU では閉じた unit は動けるが、第二の箱の第 2 層は T_d の後に戻らなかった [実測]。

**本稿の介入（中心化・成長上限・凍結窓）は、最初の機能低下の前に働く予防である（§11）。** 人工的な応答場の復元（§7）は 1 課題の学習を戻すが、戻った状態が続くことは示していない。死を取り除く ReDo（§8）では、死は課題ごとに作り直され、差の 43% しか戻らない。予防も、有限の課題数の文である。CH（入力と中間層の中心化）は、200 課題で登録 COLLAPSE 7/10 である（付録 E。追試は §3.3）。cap12（両層の成長上限）は、初回から 12.3 pt 低い（§5）。
