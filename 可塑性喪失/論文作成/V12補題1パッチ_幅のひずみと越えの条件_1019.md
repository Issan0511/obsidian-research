## 0. 要約

補題 1 の証明の一歩「K 一定なら σ は変わらない」は偽である。切替の一歩は、位置だけを動かす「沈み」と、形を変える「ひずみ」に厳密に割れる。旧証明はひずみを 0 と置いていた。ひずみの大きさは入力の幾何の比 q = λ_max(Σ) / (‖x̄‖² + 1) で抑えられる。この比が出発点の分布から決まる閾値以下なら、有限回の切替で m < 0 に入る [厳密・条件つき]。ガウス分布は定理のどこにも要らない。幅は仮定ではなく、出発点の分布を通して閾値に入る。乱数ラベル MNIST の 1 隠れ層では q = 0.14〜0.16 で、課題 2 末の生きた unit の 83〜95%（整流型）がこの条件を満たす。向きまで見た比を使えば整流型は 99〜100% になる。SiLU・GELU は余白が薄く出発点が高いので 23〜49%（向き込みで 53〜84%）に留まるが、模型の列ではすべての unit が越える [数値]。

## 1. 何が壊れたか

付録 C.3「補題 1 の証明」の一歩は次である。「K 一定なら位置の動きは全入力の z を同じだけずらすので σ は変わらず」。これは位置方向の流れ w → w + t x̄（付録 C.1 の模型）では正しい。しかし補題は実際の切替の一歩の列について言っている。実際の一歩は Δz_n = −η Σ_m δ_m (x_m·x_n + 1) で、明るさ K_n = x̄·x_n + 1 が縛るのは行列の行平均だけである。

反例（Codex、10/18）。x₁ = (1, 1)、x₂ = (1, −1)、w = (0, 1)、b = 0。K₁ = K₂ = 2 で一定だが、学習の行列は [[3, 1], [1, 3]] である。δ = (1, 0) で一歩進めると z は (1, −1) から (1 − 3η, −1 − η) に動き、幅は 1 から 1 − η に縮む [厳密]。自己形の重み δ_n ∝ φ′φ でも幅は動く（§6 の検算）。

経緯。v6.0.0（10/15・Fable）で「有限回の切替で p < 1/2 に入る」を書き、K.2 (b) に「下界が幅 σ に依らない」と書いた。このとき σ が一歩で動かないことを暗黙に使った。v6.7.0（10/17・Opus の書き起こし）で上の一歩を明文化し、v6.8.0 の圧縮でも C.3 に残った。

残るもの。一歩の期待式 E_old[S_i] = κ(1 − 1/K) Σ_n K_n d_in φ_in [厳密な極限]。ある状態での自己形の符号。落ちるもの。反復の単調性、有限回の到達の旧証明、「r*₀ へ安定に向かう」。このパッチは、有限回の到達を新しい条件で復元し、r*₀ を符号の境に格下げする。

## 3. 新しい文：§4.1.1 の補題 1

**補題 1（位置が正の側を離れる）。** 課題の中の学習を除き、切替の押しだけを順に当てた列を考える。整流型（H0）では、位置が正の状態（m ≥ 0。ガウスの読みでは正側の入力が半分以上）で、期待の押しは必ず沈める側に働く。これは前活性の分布によらない。SiLU・GELU では、閉じた入力の平均の深さが 0.20・0.12 を超えれば同じである。切替の一歩は、位置を動かす沈みと、形を変えるひずみに厳密に割れる。ひずみの大きさは、入力の幾何の比 q = λ_max(Σ) / (‖x̄‖² + 1) で抑えられる。この比が出発点の分布から決まる閾値以下なら（付録 C.3 の条件 (Q)）、有限回の切替で m < 0 に入る。ガウスの読みでは p < 1/2 である。歩数の上界も付録 C.3 に与える。r*₀ は自己形の符号が変わる境であり、安定な釣り合いとは言わない。ReLU は負側の寄与が 0 のため境が無く、各入力で K_n > 0 なら、生きている間は沈める押しが残る。証明は付録 C.3 に置く。

補題の直後の段落（「釣り合いの有無と幅による違いは §4.2 に示す…」）はそのまま残す。

## 4. 新しい文：付録 C.3

### (a) 一歩の分解 [厳密]

K_n ≡ K̄（H3）とする。これは x̄·x̃_n = 0（x̃_n = x_n − x̄）と同じである。切替の押しの期待の一歩は、g = φ′φ、c = ηκ(1 − 1/K) として

Δz_n = −c Σ_j g_j (x_j·x_n + 1) = −c K̄ Σ_j g_j − c Σ_j g_j (x̃_j·x̃_n)

に割れる。第 1 項は全入力に同じで、位置を Δm = −c N K̄ ḡ だけ動かす（ḡ は g の入力平均）。第 2 項 u_n は入力平均が 0 で、幅と形を変える。旧証明は u ≡ 0 と置いていた。位置方向の流れ w → w + t x̄（C.1）では第 2 項が無いので、旧証明はその流れについては正しい。

### (b) ひずみの大きさ [厳密]

G̃ = X̃X̃ᵀ とすると u = −c G̃ (g − ḡ1) で、rms(u) ≤ c N λ_max(Σ) sd(g) である。沈み D = c N K̄ ḡ と比べると

rms(u) / D ≤ (λ_max(Σ) / K̄) · (sd(g) / ḡ).

unit の向きで見た版。Cov(x, g) = γ Σw + v、γ = Cov(z, g)/σ² と分けると rms(u) ≤ c N sd(g) (λ̃_w + ε_w) である。λ̃_w = √(wᵀΣ³w / wᵀΣw) は unit の向きで測った Σ の尺度で、λ̃_w ≤ λ_max。ε_w = √(vᵀΣv) / sd(g) は入力雲がその向きから見てガウスから外れる分で、ガウスの雲では 0。以下、q = λ_max(Σ)/K̄（幾何だけ）と q_w = (λ̃_w + ε_w)/K̄（向き込み）を使う。幾何だけの q は状態によらない。q_w は状態の量で、模型の列に沿って 4% 以内しか動かなかった [数値]。

### (c) 自己形の符号

整流型。g(z) = z + h(z₋)（z₋ = max(−z, 0)）と書け、h ≥ 0 は非減少である。leaky は h(t) = (1 − a²)t、ReLU は h(t) = t、ELU（α ≤ 1）は h(t) = t − α² e^{−t}(1 − e^{−t})。よって ḡ = m + E[h(z₋)] ≥ m で、m ≥ 0 なら自己形は沈める側である [厳密・分布によらない]。等号は z ≡ 0 のときだけである。ガウス・K 一定の零点 r*₀（leaky a0.1・0.3・0.5 で −1.72・−0.94・−0.55、ELU は幅とともに深くなる）は、負側で符号が変わる境としてそのまま残す [ガウス]。

SiLU・GELU。正側では g ≥ z/4 [数値]。負側の谷は g ≥ −M_B で、M_B は SiLU 0.0495・GELU 0.0308 [数値]。よって ḡ ≥ (m + E[z₋])/4 − M_B·P(z < 0) で、

m + E[z₋] > 4 M_B · P(z < 0)

なら沈める側である [厳密・定数は数値]。閉じた入力の平均の深さが 0.20（SiLU）・0.12（GELU）を超えれば足りる。ガウスで書くと、旧 C.3 の σ ≥ 0.3 の条件に当たる。ガウス・K 一定の零点の記述（σ < 0.7254・0.4249 にだけ零点がある）はそのまま残す [ガウス]。

### (d) 補題 1 の証明 [厳密・条件 (Q)]

対象は、課題の中の学習を除き、切替の押しだけを順に当てた列 z^{(k+1)} = z^{(k)} − D_k·1 + u_k である。歩幅 c_k > 0 は任意。記号を置く。S_k = Σ_{j<k} D_j = m₀ − m_k（厳密）。T_k = Σ_{j<k} rms(u_j)。B_g(S) = (1/N) Σ_n g(z^{(0)}_n − S) は、出発点を一様に S 下げたときの自己形。B̂_g(S) = min_{0 ≤ s ≤ S} B_g(s)。L_g = sup|g′| で、leaky・ReLU・ELU は 1、SiLU は 1.30、GELU は 1.38 [数値]。

帳簿は 3 行である。
(i) z^{(k)} = z^{(0)} − S_k·1 + U_k、U_k = Σ_{j<k} u_j、rms(U_k) ≤ T_k。
(ii) ḡ_k ≥ B_g(S_k) − L_g T_k ≥ B̂_g(S_k) − L_g T_k。g が L_g-Lipschitz で、E|U| ≤ rms(U) だからである。
(iii) σ_k ≤ σ₀ + T_k、sd(g_k) ≤ L_g σ_k。

(b) と合わせると、分母が正のとき rms(u_k) ≤ R(S_k, T_k) D_k、R(S, T) = q L_g (σ₀ + T) / (B̂_g(S) − L_g T) である。R は S と T について非減少である。

比較 ODE を T̂′(S) = R(S, T̂(S))、T̂(0) = 0 と置く。

**条件 (Q)**: この解が [0, m₀] で存在し、β_* = min_{S ∈ [0, m₀]} (B̂_g(S) − L_g T̂(S)) > 0。

主張。(Q) のとき、任意の歩幅で T_k ≤ T̂(S_k) である。帰納法で、T_{k+1} ≤ T_k + R(S_k, T_k) D_k ≤ T̂(S_k) + ∫_{S_k}^{S_{k+1}} R(s, T̂(s)) ds = T̂(S_{k+1})。R の単調性を使った。したがって m_k ≥ 0 の間は ḡ_k ≥ β_* > 0 で、D_k ≥ c_k N K̄ β_* である。Σ_{j<k} c_j が m₀ / (N K̄ β_*) を超える前に m < 0 に入る。c_k ≥ c_min なら歩数は ⌈m₀ / (c_min N K̄ β_*)⌉ 以内である。その時点で σ_k ≥ σ₀ − T̂(m₀) > 0 なら r_k < 0 である。∎

符号の条件は (Q) に含まれる。整流型では B_g(S) ≥ m₀ − S ≥ 0 で、(c) の分布によらない符号がそのまま効く。SiLU・GELU では (c) の十分条件を、一様に下げた分布で確かめる。結論は m < 0 で、p < 1/2 と読むのは H3 のガウスの読み（p = Φ(r)）である。

### (e) 注（旧証明の正しい範囲）[厳密]

位置方向の流れでは u ≡ 0、T ≡ 0 なので、R ≡ 0 で (Q) は自明に成り立ち、旧証明の歩数の式 ⌊r₀/δ⌋ + 1 がそのまま出る。旧証明が間違えたのは、この流れの性質を実際の一歩の列に移した点である。

## 7. 幾何の比の意味

学習の核 M = XXᵀ + 11ᵀ は、K 一定のとき G̃ + K̄ 11ᵀ である。平均モード 1 の固有値は N K̄、中心化モードの最大は N λ_max(Σ) で、q はその比である。raw の画像では画素が非負で全画像が共通の明るい領域を持つので、平均のエネルギー ‖x̄‖² がどの変動方向の分散より一桁大きく、q が小さい。反例は K̄ = 2・λ = 1 で q = 0.5 と、平均と変動が同じ桁の配置である。

中心化した入力では K̄ ≈ 1 で q が大きい。自己形の押しは位置を下げる前に幅を縮め、m > 0 なら r は上がり得る。そこでは補題は成り立たない側で、§3 の「中心化で沈降が消える」と同じ側にある。条件 (Q) は技術的な但し書きではなく、沈降を運ぶのが入力平均の経路だという機構の定量形である。

## 8. 限界・未対応

- 実 K。明るさのばらつき sd(K)/K̄ = 0.28・0.29（seed 0・1）は、Gram 由来のひずみ（比 0.07）より大きい別のひずみを作る。これは K 一定（H3）の近似の問題で、今回の穴とは別である。leaky では Σ K_n g_n の符号が分布によらずには出ない。実 K の成り立ちは従来どおり実測の格（付録 D）。
- SiLU・GELU の保証率は 23〜84% に留まる。原因は余白の薄さ（L_g 1.3〜1.4、自己形の値が小さい）と出発点の高さである。上界を詰めれば上がる。
- 向き込みの q_w は状態の量で、列に沿って一定であることは測っただけである（2 unit で 4% 以内）。幾何だけの q は状態によらない。
- 結論は m < 0。p < 1/2 は H3 のガウスの読み。中央値についての文は作っていない。
- 課題の中の学習は模型の外（補題の直後の段落のまま）。
- 検算は乱数ラベル MNIST の 1 隠れ層・2 seed・課題 2 末だけ。第二の箱・背骨の q は未計算（std 入力は K の 36% が負で、H3 自体が粗い）。
- V13 の P8（[[V13背骨と段落地図_1018]]）には、条件 (Q) の一文と「幾何の比が閾値以下なら有限回で越える」を足す必要がある。
- 別セッションの Fable による独立再計算は、閾値・被覆率・実状態の数まで一致した（§10 の 5）。
