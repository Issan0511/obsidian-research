## 0. 一段で

1. **二つは別の問い。** 駆動源問題は「なぜ共通位置が沈むか」（向き・時間の形・担い手）。W 増大問題は「なぜ重みが伸び、伸びると何が壊れるか」。本稿の柱で言えば前者が「駆動」、後者が「W 増大 → 進行」。
2. **整合面の中心は箱のずれ。** 先生の理論が決着しているのは**箱 A**（CondA・1 隠れ層 100 unit・leaky 0.03・通常 SGD・batch 1・10⁴ 更新/課題・500 課題）で、そこでは **W は伸びない**（V-b: ‖w‖ 中央値の変化 <1%、σ 中央値 1.5–3.3%）。本稿の 3 箱は全部 **Adam・2 隠れ層**で、W は √t で伸びる。先生自身が「LoP は少なくとも 2 機構（箱 A = SGD の φ′ 帯選別、箱 B = Adam の ‖W₁‖ 蓄積）」と書いている（現在地 v3 §13）。本稿の箱は先生の分類で全部 B 側。
3. **だから「先生の理論が本稿の登録結果を再現する」は、理論を箱 B に移す作業（[[W_Problem]] の 5 段階）の完成が要る。それは未着手。** teacher ブランチの最終 commit は 9/19（bee7f3f）で、起票済みの `Landing_B_Step0_spec` の中身は着地点 A の精度確認（Chat container の script 復元・他 seed 検算・1000 課題の定常性）であって、√t の導出ではない。段階 1 の起票ノート `50_source/w-growth-sqrt-t-derivation-with-k-spectrum-0918` は共有 vault に無い。
4. **本稿の側で「わかっている」（登録）**: 向き（SCR の鏡像・本稿の箱の外）、時間の形（切替の衝撃・課題間の常時押しは不成立）、課題間の担い手（上流・交差項）、伸びること（MNIST）、成長を止めると崩壊が止まること（両箱）、片方の層では足りないこと（両箱）。
5. **本稿の側で「わかっていない」**: 速度（なぜ正味が往復の数%か・飽和値）、なぜ堆積が ‖W‖ とともに増えるか、直交の理由、活性化 → 指数の定量、W → σ → 崩壊の CIFAR 版（事後のみ）、多層・Adam の理論。
6. **先生の側で「わかっている」（箱 A・決着）**: 5 項式 → 実質 4 項式（per-event R² > 0.9）、Y = bias mode の cancellation（ratio 1.008）、Term I/II 分解と 3 レジーム、V-a 有界・V-b 不動、K spectrum。**先生自身が「わかっていない」と書いているもの**（現在地 v3 §10-2・着地点 A 13 §2）: 5 項式の η 依存の量的当てはめ、260 課題の累積分布（500 課題で peak η が動く）、段階 6 の必要十分条件、CondA 以外での再現、W_Problem の 5 段階すべて。
