## 査読: Asymmetric Activations Keep Sinking Preactivations（v0.4）

### 1. 主張の要約
- 課題を学ぶと読み出しが現課題へ整列（κ>0）し、次の切替で前活性を負側へ押す。この押しは、入力平均・bias・動く上流の経路を通って共通位置に届く。
- 非対称な活性化では、幅が伸びるほど沈みが深くなる。沈んだユニットが応答を失うことが、学び直しの低下の一因になる。
- MLP・CNN・2 ブロック GPT の 3 構造で、この機構の各環を介入または事後解析で支持している。そこから幅に合わせた活性化 kunekune を設計している。

### 2. 強み
- 応答場の交換（§4.4）は、分岐時の活動・logit・重みを一致させたまま微分だけを変えている。10 seed で双方向の効果が出ており、学習率を合わせた対照（全 6 比較）も付いている。設計として優れている。
- κ の下界（§3.1）と位置の厳密な分解（§3.2）が、実験の測る量（自分の重みの経路の取り分、上流 w⊤Δȳ）に直接つながっている。
- 不利な結果も本文に書いている。実ラベルの ELU で cap12 が −2.0（§4.3、登録した予測が外れた）、自己形が押しの量の 13〜60% しか運ばない（§4.1）、後付けの B は治療にならない（§5.4）。

### 3. 弱み（重要な順）
1. **§8「各環を相関ではなく介入で確かめた」**
   - なぜ刺されるか: 装填の段は介入で確かめていない（§5.1・§6.1 は事後解析、GPT の κ は 1 seed）。§8 の適用範囲や要旨の「介入または保存状態の解析」とも矛盾する。
   - 直すなら: 「各環を介入または保存状態の解析で」に揃え、装填の段が記述であることを明記する。
2. **§8「経路を塞げば保たれ（…GPTのFFN0固定）」**
   - なぜ刺されるか: §6.2 の FFN0 固定は、課題 2–10 で沈みを 53% 減らしただけで、学び直しは測っていない。課題 41–50 では浮く向きに反転している。
   - 直すなら: GPT を括弧から外す。または実験 A（下記）を入れる。
3. **要旨・§8「幅を抑えれば崩れず（ELUのcap）」**
   - なぜ刺されるか: 実ラベル 5+1 では ELU の cap12 が 2.0 ポイント悪化している（§4.3）。また CNN の幅の段（§5.3）は、本文自身が書くとおり予算延長であって幅だけへの介入ではない。
   - 直すなら: 要旨を「乱数ラベル課題では」に限定する。§5 の見出し「同じ四段を確かめる」を、幅の段については弱める。
4. **GPT の応答の段（§6.3〜6.4）**
   - なぜ刺されるか: 回復比は 0.37〜0.68、cap 網の L0 を 77% 閉じても悪化は小さく、逆向きの悪化は 0.015 にとどまる。§6.3 は幅の害を「回転の凍結」としており、④の応答の段が GPT で主因だとは言えない。要旨の「三構造で双方向」は強すぎる。
   - 直すなら: GPT では応答の寄与が部分的だと要旨に書く。
5. **kunekune（§7）**
   - なぜ刺されるか: CNN の kunekune は 78.9 で、ELU 84.0・課題 1 末固定 Snake 80.8・適応 Snake 80.0 を下回る。要旨の「上位を保つ」は弱い。適応尺度が要るという主張も、課題 1 末固定で足りた（§7）ことで弱まる。
   - 直すなら: 要旨では MLP の結果だけを主張する。CNN は「784 更新では ELU に届かず、7,800 更新では並ぶ」と書く。
