## 0. 何を合わせるのか

駆動源問題は「**なぜ前活性の共通位置が下向きに残るのか**」。向き・時間の形・担い手の三つに分かれる。本稿は三つとも登録で書いてあり、**符号の導出と時間の形の理由は「本稿の範囲外」と書いてある**。理論が埋めるのはそこ。

**箱のずれを先に置く（最重要）**: 先生の決着（着地点 A）は **CondA・1 隠れ層 100 unit・leaky 0.03・通常 SGD・batch 1・10⁴ 更新/課題** の箱。本稿の 3 箱は全部 **Adam・2 隠れ層**。先生自身が「LoP は少なくとも 2 機構（箱 A = SGD の φ′ 帯選別、箱 B = Adam の ‖W₁‖ 蓄積）」と書いている（現在地 v3 §13）ので、**本稿の箱は先生の分類で全部 B 側**である。§2 の照合はこの移送が済んで初めて意味を持つ。

### 0.1 主張Bとの接続と当面の保留（2026-09-23・Issa）

Issaの中心仮説は「既存の応答を抑える学習要求が繰り返されるために沈む」。ここでの応答は既存の予測・活性の寄与を指し、活性化の微分そのものと区別する。検証対象は、抑制要求の反復が、入力平均を通じた共有更新と微分の非対称性のもとで、なぜ回復を上回る正味の沈降を生むのかである。

**この駆動源の理論は、先生の担当との接続待ちとして当面保留する。** [[V11主張Bの検証_0923]] の無条件の「平均が非ゼロなら不可避」への反例は、著者の上記機構仮説全体を棄却した判定ではない。乱数ラベルは抑制要求を繰り返し作る実験設定として位置づける案を保持し、論文の中心を乱数ラベル限定へ狭める判断は今はしない。

再開時には、先生の理論の対象条件と、本ノート§2の登録結果・§3の事後観測を区別して照合する。特にCondA/SGDから本稿のAdam・二隠れ層への移送、下向き条件の頻度と積算変位の違い、切替直後と課題後半の収支を見る。成立・棄却・本文への採用は今回確定しない。W増大の理論（決定9b）やkunekuneの尺度の性質とは別の保留である。

## 3. 理論を縛る事後の観測（登録ではない）

理論がこれと矛盾する形を取るなら、先に走で決めるべき箇所。

- **押し下げの中身は誤答へのヘッジ。** まだ間違えている標本で活性化しているユニットへの「減らせ」（+13,293）が、合っている標本への「増やせ」（−12,781）とほぼ相殺し、誤答が 11% しかないのに勾配が 10 倍大きい分だけ勝つ（差 +776 が沈下）。MNIST・事後（[[駆動源問題_0909]] §8 追記 0910 夜）。**速度（なぜ正味が片側の 5% か）は未導出のまま。**
- **切替の瞬間に「下げろ」が揃い、課題末は逆を向く。** 開いた対の |δ₂| 重みつき符号は切替（t−1 の状態に t のラベル）で +0.12〜+0.25 → +0.6〜+0.99、課題末（t の状態に t のラベル）では −0.2〜−1.0（上げろ）。W₂ の降下方向の µ̂₂ 成分は切替で負（−0.30〜−0.43）、課題末で 0.000（[[第1層の増幅器はAdamか_ε介入_0922]] 追補・raw 1 箱・事後）。A2 の `BOUNDARY_ENRICHED` と同じ向き。
- **一つの要求・二つの径路（事後・raw 1 箱）。** 切替の「下げろ」が (i) W₂ の µ̂₂ への反平行（w·µ̂₂ −0.45 → −0.91）と (ii) 上流 ‖µ₂‖ の伸びの両方に化ける。床のある層は課題内で戻せず、切替ごとの押しが積もる。**駆動源から W 増大への橋がここ** → [[W増大の接続面_理論が合わせる登録結果_0922]] §3。
- **要求の伝達は Adam の産物ではない。** ε を 1e−8 → 1e−3 に上げても骨格（少数の (unit, 画像) 対の要求 → ±x̄ に揃う一歩 → 反平行の W₂ 経由で残りが沈む）は変わらず、√v ≪ ε の SGD 域でも同じ形（`le_eps_cifar_0922`・Q1 `REDUCED`・`MONOTONE`）。**Adam は速さで存在ではない。**
- **$T_5$（標本雑音）は本稿の箱で測っていない。** 箱 B ではミニバッチ標本雑音は沈下の必要条件ではない（[[駆動源問題_0909]] §2.1）。さらに $T_5$ の因子 $(1-a)$ は a=0.1 を大きくする向きだが、折れ目 unit の ± 蹴りの対平均が負になったのは a=0.7 でだけで、**a 依存が逆**（[[三理論の統合_駆動源5項式とV10とφ′射影_0918]] §3.5）。同じ観測量ではないので矛盾とは言わないが、判別走で並べる。
- **ELU の訓練の微分は実装で 3 系統。** autograd の expm1 は z ≤ −16.64（CPU）／−16.98（CUDA）で厳密 0、手書きの e^z は −103.97 まで 0 にならない。「ε が止めた」は撤回済みで、止めたのは厳密 0。float64＋F.elu でも同じ予算で崩壊するので、厳密 0 は崩壊の必要条件ではない。理論が「凍結」を使うなら、どの系統の話かを明記する（[[εの再判定_float32の床を入れて読み直す_結果_0917]]）。

## 4. 先生に確認する 3 か所

2. **Adam と φ′**（同上）。現在地 v3 §8「座標正規化で φ′ が消える」と W_Problem 弱点 2「$\overline{\varphi'^2}$ の依存は残る」が逆を言っている。こちらの導出（0918・訂正済み）は「実更新の差分写像から消えるのは一つ分で、$|v\varphi'|$ が残る」。§2 の #5（M2）は「大きさでなく符号の一貫性が指数差を作る」の読みと整合し、$\overline{\varphi'^2}$ そのものではない。
