> **何のための表か。** V13 の④「沈んだ unit は応答を失い、学び直しが削れる」は、ViT で前提の外に出た（残差が迂回路になる。J F5 RESPONSE_BYPASSED）。MLP の head 0 対照では「体の側」が二つに割れた（φ′ ≈ 0 の切り落としと、optimizer の記憶）。V14 では④を G2〜G5 に割り、主語を「応答」から「切り落とされた残りの網の容量」へ移す。題名（Asymmetric Activations Keep Sinking Preactivations）・①〜③・kunekune は変えない。本文の案はこの表が通ってから。

**一言で。** 学んだ読み出しの整列が切替の押しを作り、入力平均・bias・上流の経路が運び、非対称な活性化が深く沈める（①〜③、変わらず）。沈みは押しが続く限り保たれる。φ′ ≈ 0 に入った部分は自分の勾配では戻らず、網から切り落とされる。学び直しが削れるのは、切り落とされた残りの容量が課題を下回ったときで、迂回路の無い層では unit 単位で層が止まり、残差網では枝単位で網が浅くなる。構造で変わるのは切り落としの単位だけ。

**V13 からの差分。** ④ → G2〜G5。他は不変。Transformer は境界の箱から正式な箱へ。

**格の凡例。** 【厳密】＝定義か構造から導ける。【登録】＝判定規則と予測を走る前に登録した走。【事後介入】＝保存状態から始めた介入で、定義・判定・予測は走る前に commit した。【事後記述】＝保存状態の分解・診断で、因果ではない。【読み】＝観測に整合する解釈で、検証していない。

## 3 本文への置き方（案、表が通ってから）

- §3 の④を G2〜G5 の 4 文に。「経路を塞ぐか応答を保てば保たれる」は G6 側へ。
- §4 MLP: head 0 対照を §4.4（応答場の交換）の隣に。
- §6 Transformer: ViT を正式な箱に。§6.4 後半は、切れ目 2 が閉じれば「課題 30 までは head の装填費用、課題 60 以降は枝が迂回路に落ちて浅くなった網の容量」に。閉じなければ 1105 の文（担い手は同定しない）のまま。
- 例外 1 文: leaky と浅い ELU は切り落としを起こさないので、沈みは押しが続く限り保たれるが可逆。
- 題名は変えない。副題を付けるなら「切り落とされた残りの容量」が入る形。
