> **何のための表か。** V13 の④「沈んだ unit は応答を失い、学び直しが削れる」は、ViT で前提の外に出た（残差が迂回路になる。J F5 RESPONSE_BYPASSED）。MLP の head 0 対照では「体の側」が二つに割れた（φ′ ≈ 0 の切り落としと、optimizer の記憶）。V14 では④を G2〜G5 に割り、主語を「応答」から「切り落とされた残りの網の容量」へ移す。題名（Asymmetric Activations Keep Sinking Preactivations）・①〜③・kunekune は変えない。本文の案はこの表が通ってから。

**一言で。** 学んだ読み出しの整列が切替の押しを作り、入力平均・bias・上流の経路が運び、非対称な活性化が深く沈める（①〜③、変わらず）。沈みは押しが続く限り保たれる。φ′ ≈ 0 に入った部分は自分の勾配では戻らず、網から切り落とされる。学び直しが削れるのは、切り落とされた残りの容量が課題を下回ったときで、迂回路の無い層では unit 単位で層が止まる。これは MLP・CNN の主張で、残差網では切り落としの単位が枝に変わり、測った 2 ブロック ViT では学び直しの削れは容量の問題でなかった（範囲の境、追補 H）。

**V13 からの差分。** ④ → G2〜G5。他は不変。Transformer は V13 と同じく範囲の境のまま（1109 Issa。追補 H で容量の読みが ViT t60 に当たらなかった。1108 の「正式な箱へ」は取り下げ）。

**格の凡例。** 【厳密】＝定義か構造から導ける。【登録】＝判定規則と予測を走る前に登録した走。【事後介入】＝保存状態から始めた介入で、定義・判定・予測は走る前に commit した。【事後記述】＝保存状態の分解・診断で、因果ではない。【読み】＝観測に整合する解釈で、検証していない。

**G3 の書き方。** 「勾配 0 → 入力重み不変 → 入力の分布がずれない限り永久」は Dohare 2024 と Lyle 2024 を引く。本稿の主張はその上の 2 点に絞る: (i) 迂回路の無い層では入力が固定のデータなので永久、残差網では上流が入力を動かす経路があるので戻り得る、という構造での分け方。(ii) 死んだ部分を「切り落とされた部分構造」として網に写す見方。

**G4 の書き方。** 「容量が減る」は Kumar 2021（srank）と Dohare 2024（総容量）を引く。「skip 付きの網は浅い経路の和」は Dong 2021 注釈 2 と Veit 2016 を引く。本稿の新しさは、残りの容量と課題の大きさを比べる条件（閾値）と、学習の途中でサブ層が一つずつ迂回路へ落ちていく動態と、それを継続学習の学び直しの削れに結ぶこと。切れ目 1・2 が閉じるまでは【読み】。

**G7 の書き方（和解済み、1108 夜・追補 C）。** Lyle 2023・Lyle 2024 付録 E・Dohare 2024 Methods の「古い v が小さく歩幅が過大」と、本稿の「古い v が大きく歩幅が過小」は、同じ式 lr·m̂/√v̂ の両側。和解の文（Neokunekune セッションの案、置き方は Issa）: 「Adam の歩幅は lr·m̂/√v̂ で、v は前の約 1,000 更新の勾配の尺度を覚えている。切替で新しい勾配が記憶より大きいとき（文献の箱。本箱の S は 2〜8 倍、ViT は 20 倍）に歩幅が lr を超えるのは勾配の向きが更新をまたいで揃うときに限られ（ViT 2.1 lr、全滅前の ReLU 1.7 lr、他は 0.4〜1.0 lr）、新しい勾配が記憶より小さいとき（head を 0 にした網: 0.001〜0.06 倍）は同じ記憶が歩幅を 0.02〜0.19 lr に抑えて開き直しを遅らせる。二つは同じ式の両側で、向きは新しい勾配と記憶の比が、大きさは勾配の向きの揃いが決める。」 置き場所は関連研究か付録で、機構の段には入れない。向きの揃いは記録していないので、揃いの算術（5 更新が揃えば 0.41R、揃わなければ 0.19R）は読み。
