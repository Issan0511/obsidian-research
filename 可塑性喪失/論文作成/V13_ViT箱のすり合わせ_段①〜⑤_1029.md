## 段の番号の対応

ViT の解析では ①装填 ②切替の押し ③上流の共通成分 ④幅の伸び ⑤応答の喪失 の 5 段で呼んだ。本稿 §3 の 4 段とは次の対応になる。

| ViT の段    | 本稿の節                   | 本稿の文                              |
| --------- | ---------------------- | --------------------------------- |
| ① 装填      | §3.1 前半（κ の装填）         | 切替前の学習が特徴と読み出しを現課題に整列させ、切替の押しを作る  |
| ② 切替の押し   | §3.1 後半（押しの符号 S_i、自己形） | 押しの向きは活性化の値と傾きの積で決まり、大きさは κ に比例する |
| ③ 上流の共通成分 | §3.2（経路の第 2 項 wᵀΔμ）    | 上流が学習で動く層では、上流の変化の経路が加わる          |
| ④ 幅の伸び    | §3.3（m = r·s）          | 幅の成長が絶対の深さを増す。ReLU の自己形に零点は無い     |
| ⑤ 応答の喪失   | §3.4                   | 沈んだ unit は応答を失い、学び直しを削る           |

§6（Transformer）は 6.1 押し・6.2 経路・6.3 幅・6.4 応答で §3 と 1 対 1。①② → 6.1、③ → 6.2、④ → 6.3、⑤ → 6.4。

## 結論の見込み（走る前）

- ①〜④ は S で機構どおりに走っている。担い手は unit 自身の重みや bias（≈ −0.01 で動かない）でなく、上流 FFN の共通の書き込み。GPT の §6.2 と同じ形で、CNN の「学習で動く上流」の延長。
- ⑤ は死が実在するのに学び直しを削っていない印が 1 seed で出ている。追補 F の SN（尺度だけ固定）と SC（入口の中心化だけ）で分ける。`RESPONSE_BYPASSED` なら本稿の 6.4 は「応答の喪失は起きるが残差が迂回し、削るのは尺度と装填費用で LN が閉じる」になる。`RESPONSE_CARRIES` なら GPT と同じ 1 文で閉じる。
- 本文に入れないもの: S の共通成分の長期の成長則、R0 の崩れの窓の形成、SL の接核の形成、6 ブロックの死（付録）。
