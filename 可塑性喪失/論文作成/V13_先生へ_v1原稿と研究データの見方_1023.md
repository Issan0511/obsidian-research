## 2 研究データの開き方

研究データは https://research-data.issan.dev/ の下にあります。URL は秘密の文字列を含む長いもので、別にお送りします。

- 読み取り専用です。URL を知っている人だけが開けます。
- URL は他の方へ転送しないでください。漏れたときは URL を替えて、お送りし直します。
- 開いた記録（時刻・IP・開いたパス）をサーバに残しています。秘密の文字列は記録していません。

### 中身

開くと、フォルダの一覧が出ます。フォルダ名は実験名で、`<実験名>_<MMDD>` の形です。MMDD は 2026 年の実験の開始日です。実験名は付録の各節の末尾にある「出典」と同じです。

多くのフォルダは `results/<実験名>/` の下に、条件ごとのフォルダ・ログ・集計を持っています。条件の名前は実験ごとの略号です。よく出るものは次のとおりです。

| 略号 | 意味 |
|---|---|
| KKT1 | kunekune |
| SNA | 適応 Snake |
| R | ReLU |
| LR | leaky ReLU（負側の傾き 0.1） |
| ref | 対照 |

ほかの略号は、各実験の spec（§3）に定義があります。

2026-10-23 に、論文で使わない実験の大きなデータを消しました。消したフォルダには `_THINNED_1023.md` を置き、ファイルの一覧は `_cleanup_1023/` にあります。v1 が引く実験のデータは残しています。

### 見る・落とす

テキスト（.md・.json・.csv・.log・.py など）と画像・PDF は、ブラウザで表示されます。.npz と .pt はダウンロードになります。

.npz と .pt は Python で開けます。

```python
import numpy as np
import torch

z = np.load("units_ELU_s0.npz")
print(z.files)

s = torch.load("state.pt", map_location="cpu")
# 上で開けない .pt は、次で開けます（このデータに限ってください）
s = torch.load("reference.pt", map_location="cpu", weights_only=False)
```

大きなファイルは、途中で切れても続きから落とせます。下の `<URL>` は、お送りする URL（末尾の `/` まで）に置き換えてください。

```bash
curl -C - -O "<URL>cifar5p1_cnn_budget_1019/results/cifar5p1_cnn_budget_1019/smoke/b2340/state.pt"
```

フォルダを丸ごと落とすときは wget を使います。サーバは検索ロボットを断る設定なので、`-e robots=off` が要ります。

```bash
wget -r -np -nH --cut-dirs=1 -e robots=off -R "index.html*" "<URL>kappa_reload_1020/"
```

数十 GB あるフォルダもあります（大きさは §4 の表）。

## 3 数の正本

本文と付録の数は、各実験の集計と判定から引いています。集計・判定・事前登録の spec は、GitHub の lop_analysis にあります。

- 集計と判定: https://github.com/Issan0511/lop_analysis の `results/<実験名>/`
- spec: 同じ repo の `specs/spec_<実験名>.md`

research-data にあるのは、その元の生データです（走ごとの記録・保存状態・ログ）。
