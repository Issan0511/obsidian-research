## 作業1: `p̂ < 0.05` 定義の裁定 【完了 2026-08-23】

**参照**: [[マージン恒等式と消灯点_0822]] §8(a) ／ [[用語と記号]] §1 ／ [[フレーム前の穴]] §6 冒頭の注記

**何が問題か**

「dead」の作業定義が `p̂ < 0.05` になっている。ところが condA は 1 タスクのサポートが 32 パターンなので `p̂ ∈ {0, 1/32, 2/32, …}`。**`1/32 = 0.03125 < 0.05`** なので、**32 通りのうち 1 つでゲートが開くユニットが「dead」に分類される**。

そのユニットは勾配が恒等ゼロでは**ない**。実測で `t_death` 以降も `median |Δb| = 0.43` 動いている。真に凍るのは `p̂ ≡ 0` 以降で、そこからの `|Δb|` は厳密に 0。

**なぜ柱2 の前提なのか**

柱2 の核が「下端は**不可逆**（勾配恒等ゼロ、16,475,293 ペアで復活 0）」だから。この不可逆性は **`p̂ ≡ 0` でのみ成立する**。`p̂ < 0.05` のまま書くと、柱の一番強い部分が定義のズレで崩れる。

**やること**

定義を `p̂ ≡ 0` に直すか、`p̂ ≡ 0`（凍結）と `p̂ < 0.05`（ほぼ消灯）を**別の語**にするかを決める。

**裁定（8/23）**

- **凍結（`strict_dead`）**: `p̂ = 0`。不可逆性・吸収・勾配恒等ゼロを述べる対象
- **ほぼ消灯（`near_off`）**: `0 < p̂ < 0.05`。condA では `p̂ = 1/32` で、まだ勾配がありうる
- **旧作業指標（`dead_0.05` / `dead_frac_0.05`）**: `p̂ < 0.05`。過去のログ・数値との互換用で、不可逆性は含意しない
- 波及先 6 ファイルへ反映済み。修飾なしの `dead` を新しい機構主張では使わない

**波及先（定義を直す場合に書き換えが要るファイル）**

[[用語と記号]] §1（定義の本体・現在は注記のみ追加済）／[[命題リスト]] Q3 主張文／[[整流モデル]] 部品2 の 3 区分／[[死の二経路]] §5／[[停止条件]] の dead_frac 定義／[[移動度勾配モデル]] §1 表

**無傷**（既に `p̂ = 0` を明示している）: [[xr分解と生存機構_0822]] §14 ／ [[不偏ウォーク仮説]] §1(3) ／ [[自己項の恒等式]] §2

**コスト**: 書き物のみ。走なし・解析なし。

- 方法: 起点 t₀ ∈ {200k…600k} で alive な個体を r 三分位に分け、その後 300k 以内の死亡率を比較。`p̂` と `x` で統制した 3×3 も

- チャットでの結果: 周辺死亡率 0.837 / 0.839 / 0.850（**平坦**）、統制セル内も勾配なし
- 要注意: 同一個体が複数起点に重複して入るので SE が過小。転帰が「一時死」を含む（境界復活 11.5%）

**やること (b): オラクル bias 修復 + 対照 4 本**

- 問い: 「死んだユニットの重みは壊れているのか、スイッチが切れているだけか」

- チャットでの結果: unfit 現状 0.143 → 修復後 0.009。対照の中央値は ① 0.0001 ／ ③ 0.070 ／ ④ 0.081 ／ ② 0.196
- 要注意: **オラクルであって手法ではない**。蹴り上げ幅 0.5 は恣意（感度未確認）。単一スナップショット
- 関連: [[台帳（実効バイアスの縮退）]]（b と w の勾配が同じ因子を共有する構造）／`cbp_harm_0815`（CBP は重みを取り替えるが eval を改善しない ＝ この結果と整合）

## 作業3: `β ≤ −r` の命題化 ＋ step-0 MC の昇格 【走なしで格が上がる】

**参照**: [[マージン恒等式と消灯点_0822]] §1.3・§2・§9-1・§9-2 ／ [[用語と記号]] §5 の `PB-5` ／ [[自己項の恒等式]] §2

**(a) `β ≤ −r` の命題化**

消灯条件が正規化形で `β ≤ −r`（`r := ‖w_free‖₁/‖w_free‖₂ ∈ [1, √5]`）と書ける、という**解析的に閉じた定理**。走も事前登録も要らず、書けばそのまま命題になる。

価値: [[用語と記号]] §5 の `PB-5`「ガウス入力では `Φ(β) > 0` なので絶対吸収は起きない」に対する、**有界入力版の厳密な対応物**。「condA では文字通りの吸収が存在する」という定性的な言い方を、初めて式にする。

おまけ: Q8（Feller 分類、task_080）に予言が立つ。**µ → 0 の極限で吸収境界でなくなるはず**。ならなければ理論と `ratchet_centered_0822` の間に矛盾が立つ。

**(b) step-0 MC の事前登録昇格**

「ゲート曲線の崖の位置 −0.15 は、初期化則（`w_j ~ U(±√(6/20))`, `b=0`）と入力統計（flip ~ Bern(1/2)¹⁵）だけから予言できる」。**フィットゼロ・パラメータ 0 個**の MC で θ_med = −0.15 が的中（θ_all は予測 −0.50 / 観測 −0.55 で 1 ビン差）。

現状は**事後計算**なので、事前登録して回し直せば正式な結果になる。柱1 の「壁の位置まで説明できる」を支える。

## 作業5: µ タイトレーション 【柱1 の本丸・唯一の新規走】

**参照**: [[マージン恒等式と消灯点_0822]] §1.5・§3・§9-6

**問い**

`cos_crit = −(b+M)/(‖w‖·‖µ‖)` の分母に ‖µ‖ がいる。では **壁の強さは ‖µ‖ でどうスケールするのか**。

**現状の何が足りないか**

いま持っているのは `std`（‖µ‖ = 3.041）と `centered`（0.117）の **2 点だけ**。しかも比が 26 倍あるので、centered では崖が cos の定義域外へ飛んでしまい（88.1% のユニットで `|cos_crit| > 1`）、**「動いた」ではなく「盤から落ちた」**としか言えない。中間点が無い。

**やること**

`center_alpha`（部分センタリングの強さ）を振って ‖µ‖ を連続的に変え、θ(‖µ‖) のスケーリングを直接測る。

**それで何が言えるようになるか**

1. 「µ が壁を作る」が **2 点比較 → 用量反応曲線**になる。柱1 が一段強くなる
2. §1.5 の **2 経路の分離**ができる。現在「(i) 壁の位置を手前に引く」と「(ii) b の逃走自由度 `1/(1+‖µ‖²)` を奪う」の寄与を分けられていない
3. 「µ は制御ノブである」と言えるようになる ＝ v3 の一行（「µ が作った壁」）が主張から**測定**になる

**コスト**: **新規の学習走**。v3 の作業で唯一。
