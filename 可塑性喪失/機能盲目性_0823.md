> **結論**: オラクル修復 O は「スイッチを開けば利用可能な学習済み W が残る」を支持した。機能代理 r の H は未決着だったが、作業6の直接 `ΔL` 独立確認は **PROTECTIVE** で、セル内高 `ΔL` 群ほど凍結しにくかった。したがって柱3を「機能盲目性」とは書かない。

## 1. 位置づけ

8/23 チャットの使い捨て事後計算を、既存ログ・既存スナップショットだけで再現可能な解析へ固定した。既知の概数を見た後の再現解析であり、盲検事前登録・独立確認ではない。新規の学習走は行っていない。

- H: `results/ratchet_log_0819/logs/seed*.npz`
- O: `results/posreset_0819/snapshots/A_w100_cont_step500000.pt`
- 対象: condA・w100・10 seed

死の用語は8/23裁定に従い、`strict_dead := p̂=0`、`near_off := 0<p̂<0.05`、旧互換指標 `dead_0.05 := p̂<0.05` を分離した。

## 2. H: r 三分位と消灯

### H-any（初回 spec）

起点 `t₀ ∈ {200k,300k,400k,500k,600k}` で `p̂≥0.05` の個体を、各 t₀ 内の r 三分位へ分け、保存記録点上で300k以内に一度でも消灯したかを測った。CI は同一個体の反復曝露をばらさず、seed ブロック bootstrap で計算した。

| 転帰 | low / mid / high（seed等重み） | RD high−low [95% CI] | 判定 |
|---|---:|---:|---|
| `dead_0.05` any-hit | 1.000 / 0.997 / 0.995 | −0.0045 [−0.0136, 0.0000] | EQUIV |
| `strict_dead` any-hit | 0.997 / 0.997 / 0.995 | −0.0015 [−0.0136, +0.0091] | EQUIV |

95% CI 全体が事前に固定した等価幅 ±0.05 に入る。しかし率がほぼ1で、**天井効果の下での等価**である。旧チャット値 0.837 / 0.839 / 0.850 は再現しなかった。

### H-end（初回結果後の追補）

天井効果を切り分けるため、bulk の401起点それぞれについて「300k後の一点で消灯状態か」を別 spec で追加した。これは初回結果を見た後の事後追補であり、H-any の主判定を置換しない。

| 転帰 | low / mid / high（seed等重み） | RD high−low [95% CI] | `p̂×x` 調整 RD [95% CI] | 判定 |
|---|---:|---:|---:|---|
| `strict_dead` endpoint | 0.860 / 0.864 / 0.833 | −0.0265 [−0.0894, +0.0378] | +0.0089 [−0.0443, +0.0582] | INCONCLUSIVE |
| `dead_0.05` endpoint | 0.905 / 0.919 / 0.898 | −0.0068 [−0.0564, +0.0386] | +0.0132 [−0.0388, +0.0580] | INCONCLUSIVE |

点推定は小さいが、CI 全体が ±0.05 に収まらない。よって「r 三分位で平坦」「`p̂×x` 統制後も勾配なし」は確定結果として使わない。r 自体も入力応答重みの大きさの代理で、教師への因果的寄与そのものではない。

## 3. O: オラクル bias 修復

32入力を全列挙し、スナップショットの W・v を固定した。`dead_0.05` の bias を最良入力で preactivation 0.5 となる位置へ蹴り上げた後、全 hidden bias と出力 offset c だけを最適化した。

- 旧見出しと同じ seed 平均 NMSE: **0.143367 → 0.009148**
- 回復率: **93.619%**、seed bootstrap 95% CI [89.706%, 97.672%]
- spec の点推定90%基準は PASS。ただし CI 下端は90%をわずかに下回る

固定済みの対照定義による結果:

| arm | mean NMSE | median unfit |
|---|---:|---:|
| current | 0.143367 | 0.109259 |
| repair `dead_0.05`, k=0.5 | 0.009148 | 0.000000 |
| learned W | 0.112614 | 0.068269 |
| fresh He | 0.235382 | 0.171076 |
| row shuffle | 0.382892 | 0.340128 |
| rnd 5列 randomize | 0.779437 | 0.695399 |

学習済み W と各破壊対照の paired seed bootstrap 差（learned−control）は、fresh He −0.1112 [−0.1748, −0.0308]、row shuffle −0.2168 [−0.4765, −0.0792]、rnd randomize −0.5731 [−0.9135, −0.4437]。すべて CI 上端が0未満で、学習済み W に利用可能な構造が残るという容量診断を支持する。

ただし元の使い捨てコードが残っておらず、旧チャットの対照値 0.0001 / 0.070 / 0.081 / 0.196 は操作定義を回収できないため未再現。上表は今回新しく固定した操作の結果である。

## 4. 作業6: 直接 `ΔL` の独立確認

作業2の代理指標と天井効果を避けるため、新規20系列（`generator_offset=20260830`）で現在タスク32入力の単独消音損失を直接計測した。t0の `p_count` を完全層別し、`pre_max` 五分位セル内で `utility_nmse` を三分位化した。

- 主調整RD（high−low）: **−0.2353 [−0.2812, −0.2325]**
- low/high pooled凍結率: 0.4018 / 0.1668
- 判定: **PROTECTIVE**（CI上端 < −0.05）
- C-S1〜C-S8: 全PASS。CLI再実行byte一致、別実装の主解析再計算も完全一致

この結果は「壁の式に機能量がない」と「凍結結果が機能と無関係」を分離する。前者から後者は導けず、後者は作業6の操作的定義で否定された。詳細・制限・provenanceは [[直接機能量による選抜確認_0823]]。

## 5. 言ってよいこと・言わないこと

**言ってよい**

- W・v を固定したオラクル容量診断では、スイッチと bias を開くと損失の大半を回復できる
- 学習済み W は3種類の破壊対照より有意に良い
- H-any は固定済み定義で EQUIV だが天井効果がある
- 非天井の H-end では r 勾配の有無・等価性は未決着
- 直接 `utility_nmse` の独立確認では、セル内高 `ΔL` 群の同一タスク末尾凍結率が明確に低い

**言わない**

- dead unit 単体が教師に有用
- 選抜は機能を一切見ない、と H が確定した
- 作業6の観察的関連を、機能が凍結を防ぐ因果効果と呼ぶ
- オラクル修復が学習手法として有効、または再開後も効果が持続する
- condB・他幅・他時刻へ一般化する
- 新しい対照値が旧使い捨て解析の再現である
