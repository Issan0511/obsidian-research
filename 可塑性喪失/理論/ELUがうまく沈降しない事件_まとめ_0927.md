## 0. 一言で

1 層の ELU は、絶対の深さでは沈み続けていた。沈まなかったのは相対位置と p⁺ で、切替の押しを課題内の当てはめが unit ごと持ち上げて取り戻すから。上端が登るのは ‖w‖ が伸びるだけの恒等式。ELU が死ぬのは、切替の押し（2 層なら上流の共通モード）が unit を数値の床まで運ぶときだけ。RL-CIFAR の EL が「明確に沈む」のはこれで、生 CIFAR の ‖x‖₁ が MNIST の 14 倍なので Adam の 1 歩が z で 14 倍大きかった。

| 課題 30 → 200（2 seed の範囲） | 上端（生存 unit の中央値） | 生存 unit の開いた入力 | 全閉 unit | p⁺（t200） |
|---|---|---|---|---|
| ELU | 10〜11 → **35〜36** | 19〜20 → 15〜16（t50 の底）→ **20〜24** | 6〜16% → **0〜1%** | 1.7〜2.0% |

GELU/SiLU は上端が有界のまま unit が閉じて死んだ。ELU は上端が幅と一緒に登り、開いた入力は t50 で底を打って戻り、全閉 unit は 0 に戻って、p⁺ は 2% で張り付いた。ELU の上端の予測は Claude（対数で 13）も Issa（指数で収束して 11）も外れ。続けて Issa が「RL-CIFAR の EL（第 1 層 ELU・第 2 層 leaky）は明確に沈むのに、なぜこれは沈まないのか」と問い、0927 まで調べた。

## 2. わかったこと

**2.1 沈んでいるのは絶対の深さ、止まっているのは相対位置 [実測・α = 1 を 2,000 課題]**
平均 m は課題 30 の −21 から課題 2000 の −148 まで幅に比例して沈み続け、最も深い入力は −390 に達する。一方、相対位置 ρ = m/s は −2.1、p⁺ と平均ゲートは 0.02 で張り付いたまま（課題 50 の最小 0.011 から微増）。上端は 10 → 99 と登るが、上端/s は 1.1〜1.4 で一定。Issa の「勾配が死なない限り無限に沈下」は絶対の平均では成り立ち、p⁺ → 0・mob → 0 は 1 層の ELU では成り立たない。（α 梯子 §8.7）

**2.2 上端の登りは恒等式、張り付きは押しと払い戻しの釣り合い [恒等式は厳密・釣り合いは実測]**
z_n = ‖w‖(ŵ·x_n) + b なので、向きの統計（ρ・上端/s）が固定されたまま ‖w‖ が伸びれば、上端も平均も幅も比例して動く。張り付きの中身は課題ごとの正味 0 で、切替直後 200 更新の押し（上端で −4〜−5、z の単位で一定）を課題内の払い戻しが取り戻す。払い戻しの比は 0.75 から 1.0 へ上がり、完全になるのは生存 unit の開いた入力が 21〜25 に減ってから。（α 梯子 §8.8）
払い戻しの実体は、当てはめが unit 全体を持ち上げ、押し下げられた入力を z ≈ −5 から拾い直す動き。e^z の帯（折れ目のすぐ下）から来るのは 0〜27% だけ。GELU/SiLU ではこの払い戻しが後半ほぼ 0 なので、開いた入力が 1〜2 個に減り、上端は 2〜4 に留まって unit が閉じる。（α 梯子 §3.3）

**2.3 ELU が死ぬのは数値の床に届くときだけ [再パラメータ化は厳密・床は実測]**
ELU を α·ELU(z/α) に縮めても、生き残りは全 α で ELU 型（上端 ∝ 幅）。死ぬ割合（t200・expm1 経路）は α = 1 で 0.5%、1/4 で 9%、1/8 で 52%、1/16 で 89%。決めているのは切替の押し（z で 3〜4、α によらない）と数値の床の比。床は、expm1 の自動微分なら z/α < −16.64 で学習微分が厳密に 0、厳密な微分でも Adam の ε と重みの float32 丸めで z/α ≈ −26。全閉 unit の再開確率は u = z/α だけの関数で、α を 16 倍変えても重なる（命題 E: 全閉 unit を δ 深くすることは Adam の ε を e^{δ/α} 倍することと同じ）。（α 梯子 §2.2・§3.1・§3.4）
縮小は「第 1 層の学習率を 1/α 倍にした標準 ELU」と同値で、写した腕はビット一致した。α = 1 のまま学習率だけ 16 倍にすると死に（72〜81%）、初期値だけ 16 倍にしても死なない。バイアスは押しの 1.5% で、凍結しても同じく死ぬ。幅の増大は床を動かさないので殺さない。（α 梯子 §8.1〜8.5）

**2.4 幅は α = 1 を殺さず、守る [実測]**
2,000 課題で幅が約 70 まで育っても、床の下の unit は 0、閉じた unit も課題 400 以降は 0。閉じるのは開いた入力が 1 個で上端が +2〜3 の unit だけで、幅が育つと生存 unit は開いた入力を 23〜25 個持ち、上端が 1.2〜1.3 s になって押し 3〜4 では閉じなくなる。（α 梯子 §8.6〜8.7）

**2.5 EL が「明確に沈む」のは歩幅の尺度 [実測・Issa の説が的中]**
生 CIFAR の ‖x‖₁ は 1,440 で、MNIST（101）の 14 倍。Adam の 1 歩は z で 14 倍になるので、EL の第 1 層は MNIST 梯子の α ≈ 1/14 にいたことになる。同じ箱で第 1 層の学習率を 1/16 にするか α₁ = 16 にすると、第 1 層の死は 74〜87% から 5〜12% に減り、ρ −2.1・p⁺ 0.02 で MNIST の α = 1 と同じ張り付きに落ち着く。MNIST の ELU と EL の ELU は同じ法則で動いていて、違いは床が押しの届く深さにあるかどうかだけ。（α 梯子 §10.1〜10.2）

**2.6 張り付いても喪失は残り、正体は「第 1 層が学べないこと」[実測]**
尺度を直した EL の online は課題 50 で 0.36（LL は 0.73）。課題 5 の健全な第 1 層を凍結しても 0.40 で、沈んだ層と変わらない。床 0.1 を足すと 0.61、同じ疎さの leaky（ρ −2.2・p⁺ 2%）は 0.66、中心化は 0.72。沈む深さは leaky でも同じで、ELU に固有なのは閉じた入力の勾配が 0 になることだけ。深さの数字そのものは健全さの指標にならない（張り付いた MNIST の α = 1 でも、（入力, unit）の対の 97% が z < −5）。（α 梯子 §10.3）

**2.7 大きい α は沈まないが、線形に近づく [実測]**
α ≥ 8 では閉じた入力のゲートが折れ目付近で 1 に近く、leaky の床と同じように押しの符号を打ち消すので、沈下も幅の伸びも止まる。課題 200 の当てはめは 0.35 → 0.74 に上がるが、課題 1 は 0.96 → 0.80〜0.82 に落ちる。（α 梯子 §9）

**範囲**: 2.1〜2.7 は 1 層（と RL-CIFAR の第 1 層）の話。2 層では上流の共通モード（µ₂）が上端ごと運ぶので、ELU の第 2 層は床まで沈んで死ぬ（[[第2層のµ₂壁_崩壊層の釘付けと切替衝撃_事後_0916]]・[[第2層にも上限を置いてELU→ELUの崩壊を防ぐ_結果_0917]] で登録済み）。

## 3. Issa の元の命題の行き先

| 命題 | GELU/SiLU | ELU |
|---|---|---|
| 幅が非有界なら、勾配が死なない限り平均は幅に比例して沈む | 成立（実測） | 成立（実測・2,000 課題） |
| 上端は活性化だけの定数で抑えられる | 成立（実測・上端 2〜4） | 不成立（どの α でも上端 ∝ 幅） |
| p⁺ → 0・mob → 0 | 成立（実測・1 層でも閉じて死ぬ） | 1 層では不成立。床に届くとき（小さい α・大きい歩幅・2 層の共通モード）だけ |

どの行も定理にはなっていない。沈む向き（切替の押しの符号）は、生きている unit の 95〜99% で成り立つ実測。

## 4. 理論の格

- [厳密] 尺度の恒等式。α の再パラメータ化。切替一歩目の期待値式 E[Δ(w_i·µ̂)] = −(η/N)S_i。ḡ − p⁺ = (1/N)Σ_{z<0} e^{z/α} ≤ (1 − p⁺)e^{−d/α}（d は折れ目に最も近い閉じた入力の深さ）。
- [条件付き] 命題 E（全閉で、Adam の β₂ の記憶が抜けた後）。
- [実測のみ] 押しの向き。ELU の張り付き（ρ −2.1・p⁺ 2%）。払い戻しが完全になる開いた入力の数。GELU/SiLU で開いた入力が 1〜2 個に減ること。
- [未導出] 開いた入力の下限 21〜25。谷が集団の払い戻しを止める理由。幅 ‖w‖ の伸び（W 増大の側）。第 2・3 層だけの当てはめが 0.4 に留まる理由。
- 書けない文: 「床なしの活性化は 1 層で p⁺ → 0・mob → 0」（ELU で偽）。「上端が有界なら p⁺ → 0」（p⁺ = k/N なので代数的に偽）。「幅 → ∞ なら ḡ → p⁺」（閉じた入力が折れ目の直下に残らない条件が要る）。

## 5. Claude の説明で外れたもの

- 「ELU も上端は有界で収束する」（0925 夜・親ノート §1.6-7）。200 課題の走で棄却。
- 「e^z の帯が閉じた入力を引き戻す」（親ノート §3.6）。拾い直しは帯の外の z ≈ −5 から来ていて、帯の幅は死にも拾い直しにも効かない。
- 「EL と MNIST を分けるのは r（入力の平均と散らばりの比、生 CIFAR 1.91・MNIST 0.81）」（0925 夜の会話）。歩幅を直すと r = 1.91 のまま MNIST と同じ張り付きになったので、r は要らなかった。効いていたのは ‖x‖₁ で決まる歩幅。
- 「上端が有界なら p⁺ → 0」。Codex の指摘で代数的に偽。
- 「α = 1 も 10³ 課題の桁で数 % が床に届く」（α 梯子 §8.6）。幅が育つと閉じる候補が消えることを入れていなかった。
