## 0. 一言で

- **縮めた ELU の生き残りには、どの α でも ELU と同じことが言える。GELU/SiLU で言えたこと（上端が有界・開いた入力が 1 個前後）は、どの α でも言えない。** 生存 unit の上端／幅は α = 1〜1/16 で 1.1〜1.5（GELU 0.1〜0.4、SiLU 0.1〜0.2）。課題内の払い戻し比は後半で 0.5〜0.9（GELU −0.1〜0、SiLU 0 前後）。α で縮むのは、張り付く p⁺ の高さ（0.019 → 0.0002〜0.0005）と生存 unit の開いた入力数（24 → 2）。
- **死ぬかどうかを分けるのは負側の帯の幅ではなく、数値の床（u = z/α ≈ −16.6）が切替の押しの届く深さに来るかどうか。** 全閉 unit が次の課題で開く確率は u だけの関数で、α を 16 倍変えても重なる。上端の入力が「出力を増やしたい」なら u ≥ −8 で 0.8〜0.9、u < −16.64 で expm1 経路は厳密に 0、厳密微分でも 0.01〜0.03。死ぬ割合（t200）は α ≥ 1/4 で 0〜12%、1/8 で 52%（expm1）／22%（厳密）、1/16 で 89%／70%、ReLU 100%。
- **理論**: (1) 再パラメータ化は厳密（Codex 同意）。(2) 命題 E: 指数の尾では、全閉 unit を δ 深くすることは Adam の ε を e^{δ/α} 倍することと同じ。深さは u = z/α でしか効かない。再開確率が u で重なるのはその実測。(3) 帯の幅（2.5α）の説は、死にも拾い直しにも効かない。拾い直す入力は全 α で z ≈ −5 の深さから来て、帯の中からは 0〜27%。(4) Codex が前回ノートの誤り 3 つを指摘し、前回ノートに注記した（「上端有界 ⇒ p⁺ → 0」は代数的に誤り、「s → ∞ ⇒ ḡ → p⁺」は条件付き、§1.6-1 の力の式は SGD 限定）。
- **なぜ縮めると死ぬか（§8・Issa「幅のスケールアップと同じでは？ バイアス由来？」）**: 関数としては同じだが、Adam の歩幅は重みの単位で η のままなので、縮小 ≡ 第 1 層の学習率 ×1/α（ε ×α）の標準 ELU（完全に写した腕はビット一致）。死を決めるのは切替の押し（z で 3〜4・α によらない）と数値の床（z で 16.64α）の比で、幅の増大は床を動かさない。α = 1 で第 1 層の学習率だけ 16 倍にすると 1/16 と同じく死に（全閉 0.72〜0.81）、初期値だけ 16 倍にしても死なず（0〜0.01）、α = 1/16 で学習率だけ 1/16 にすると死なない（0〜0.02）。バイアスは押しの 1.4〜1.8% で、凍結しても死ぬ（0.82〜0.91）。
- **前回の答え（MNIST で GELU/SiLU の上端が一定の理由）の訂正**: 「ELU は e^z 帯で引き戻せる、谷は引き戻せない」の帯の部分は外れ。ELU 型は、当てはめが unit 全体を持ち上げて、押し下げられた入力を深さ D から拾い直す（集団の払い戻し）。GELU/SiLU はこれがほぼ 0 で、拾い直しは帯 (z_c, 0) の中からだけ。谷がなぜ集団の払い戻しを止めるかは未導出。

## 1. 問いと設計

**読み**: 負側を α(e^{z/α} − 1) とした（= α·ELU(z/α)、CELU(α)）。ELU のグラフを原点のまわりに α 倍へ縮めたもので、φ′ = e^{z/α} は折れ目で 1 に連続、漸近値 −α、α → 0 で ReLU。書かれた e^{αz} だと帯は逆に 1/α 倍へ広がり、折れ目の傾きが α² に跳ぶ（縮小ではない）ので採らなかった。

**「同じこと」**: 親ノート §3.2〜3.6 の項目（切替の押しの符号、p⁺ の層平均、ゲートの階段化、上端の有界性、開いた入力数 k、全閉 unit の蓄積、mob → 0）を α ごとに測り直す。

**Codex が見つけた前回ノートの誤り**（前回ノートの §1.5-3・§1.6・§4 に注記済み）:
1. 「上端有界 ⇒ p⁺ → 0」は代数的に誤り。p⁺ = k/N で、上端が有界でも k は減らない（一つの z を 1 に保ち残りを −∞ へ送れば、上端は有界・幅は発散・p⁺ = 1/N のまま）。
2. 「s → ∞ ⇒ ḡ → p⁺（床なし）」は条件付き。閉じた入力が折れ目の直下に留まらない（d → ∞）ことが要る。厳密な形は ḡ − p⁺ ≤ (1 − p⁺)e^{−d/α}。
3. §1.6-1 の入力ごとの力の式は SGD の式。Adam では自己項と交差項に厳密には分かれない。

**二説を分ける観測（Codex の提案）**: 生存 unit の k の推移と、全閉 unit の上端の深さ別の再開率。全閉率だけでは分けられない。

### 2.2 命題 E（深さ = ε の倍率）

**[条件付き: 全閉・β₂ の記憶が抜けた後・深い unit]** ELU-α の全閉 unit で全入力の z を δ だけ下げると、φ′(z − δ) = e^{−δ/α}φ′(z) なので、その unit の勾配は（出力の変化 O(α e^{z_top/α}|v_i|) を除いて）ちょうど e^{−δ/α} 倍になる。Adam は勾配の履歴を一様に c 倍すると ε を ε/c に置き換えたのと同じ更新になる（代数的に厳密、ε = 0 なら不変）。**よって「δ だけ深い」は「ε を e^{δ/α} 倍する」と同じで、深さは u = z/α でしか効かない。** 動けるのは ε e^{δ/α} < |g₀|、つまり δ < α ln(|g₀|/ε) の間で、この箱では ≈ 14〜16α。m1 の厳密 0（16.64α）とほぼ同じ深さなので、m1 と ex の差は壁が硬いか柔らかいかだけになる。
- **含意**: Adam の下で全閉 unit に効くのは φ′ の**符号**（谷は逆向き）と**数値的に 0 かどうか**（厳密 0・ε・重みの float32 分解能）で、φ′ の**大きさ**（帯の幅）は効かない。吸収の深さは ReLU 0、GELU z_c = −0.75（符号）、SiLU −1.28（符号）、ELU-α ≈ −16.6α（数値）。
- **β₂ の記憶（Codex）**: 閉じた直後は開いていた頃の v̂ が残るので、目が覚めるまで約 (2δ/α + ln 75)/(1 − β₂) 更新かかる（δ/α = 5 で 3〜4 課題、15 で 8〜9 課題）。この間は沈みもしない。
- **検証（§3.4）**: 再開確率は u のビンごとに α = 1〜1/16 で重なる。勾配ノルムで見ると、全バッチ勾配ノルム 10⁻¹⁰ を下回ると再開が 0 になる（ε = 10⁻⁸ は座標ごとのバッチ勾配に対する値で、全バッチのノルムとは 1〜2 桁ずれる）。
- **ex の床の中身**: ex でも α = 1/16 の 27% の unit は 1 課題の変位が厳密に 0（t200）。ε で更新が η|g|/ε まで縮み、それが重み（座標あたり 0.3〜0.8）の float32 の半 ulp（~2×10⁻⁸）を下回ると重みが丸めで動かなくなる。|g| ≈ 0.03e^{u} で見積もると u ≲ −25.7。実測でも、動かない unit の上端は u = −66〜−25.7（中央値 −32〜−34）、動いている全閉 unit は −30〜−2（中央値 −21〜−23）で、境は u ≈ −26〜−30。m1 の動かない unit は u ≤ −16.6 で、厳密 0 の閾値どおり。

## 5. 何が言えるか（Issa への答え・格つき）

1. **[厳密]** 縮めた ELU の網は、層ごとに学習率・ε・初期値を変えた標準 ELU の網と同値（T0）。φ′ > 0 なので谷の吸収の補題は使えない（T1）。ḡ − p⁺ = (1/N)Σ_{z<0} e^{z/α}（T2）。
2. **[条件付き・実測で支持]** 全閉 unit では深さは u = z/α でしか効かず、Adam の下では「深さ = ε の倍率」（命題 E）。再開確率は u だけの関数で、α = 1〜1/16 で重なる。
3. **[実測]** 生き残りについては、どの α でも ELU と同じことが言える。上端は幅と伸び（上端/s ≈ 1.1〜1.5）、全閉 unit は跳ね返り、p⁺ は張り付く。張り付きの高さと開いた入力数は α にほぼ比例して下がる。**上端 ≤ 活性化の定数（GELU/SiLU で言えたこと）は、どの α でも言えない。**
4. **[実測]** 死ぬのは数値の床（u ≈ −16.6：m1 の厳密 0、ex の ε と重みの丸め）が押しの届く深さ（2.5〜4.6）に来たときだけ。z で 16.64α なので、α = 1/4（4.2）と 1/8（2.1）の間で転移する（ex は 1/8 と 1/16 の間）。**1 層で ELU-α の mob → 0 が起きるのは、この死を通してだけ。** 実数演算で ε → 0 なら床は −∞ へ退くので、どの α でも ELU と同じになるはず（条件付きの予測・未検証）。
5. **[実測・機構は未導出]** ELU 型と谷型を分けるのは課題内の集団の払い戻し（ELU-α 0.5〜0.9、GELU/SiLU 0 前後）。谷は閉じた入力の勾配の符号を逆にし、|φ′| が小さくない（〜0.1〜0.17）入力が多いので、当てはめが unit 全体を持ち上げる動きに逆らう、という読み。帯の幅は死にも拾い直しにも効かない。

## 8. なぜ縮めると死ぬのか — 幅の増大とは何が違うか・バイアス由来か（Issa の問い・0925 深夜）

**問い**: 「縮めたら死んだ理由は？ 幅が大きくなってスケールアップしたのと別に変わらないのでは？ もしかしてバイアス由来？」

### 8.1 答え（格つき）

1. **[厳密] 関数としては同じ、力学としては違う。** α 網 (W1, b1) は標準 ELU の (W1/α, b1/α) と同じ関数（T0）。だが Adam の歩幅は重みの単位で η のままなので、同値な標準 ELU では第 1 層の学習率が η/α になる。**α の梯子は、標準 ELU で見れば「第 1 層の学習率の梯子」であって「幅の梯子」ではない。** 幅が育った α = 1 の網は、学習率 η のままの標準 ELU にすぎない。
2. **[実測] 死を決めるのは、折れ目付近の力学の尺度（z の単位で α によらない）と数値の床（z の単位で 16.64α）の比。** 切替の押しは z で 2.9〜4.3、閉じたばかりの unit の上端は z で −0.1〜−1.2、閉じた unit の目覚め後の動きも z の尺度。これらは α を 16 倍変えても変わらない（§8.2）。床だけが z = −16.64α と上がってくる。幅の増大は床を z = −16.64 に置いたままなので死なない。
3. **[実測] バイアス由来ではない。** バイアスの寄与は、切替の押し（上端の 200 更新の落ち）の 1.4〜1.8%、平均モードの沈み全体の 2〜9%（全 α・GELU/SiLU も同じ）。Adam ではバイアス 1 座標の歩幅が η、w·x は 784 座標で η‖x‖₁ ≈ 0.1 なので、比は最初から 1% 程度。バイアスを凍結した腕 C も同じように死ぬ（§8.4）。
4. **[実測・読み] α が小さいほど閉じた unit の運命が一方向になる。** 閉じた unit の勾配のゲート質量のうち上端 1 入力が担う割合は α = 1 で 71%、1/2 で 96%、≤ 1/4 で 100%。小さい α では unit はその 1 入力の需要どおりに動き（増やしたい → 上・減らしたい → 下）、α = 1 では他の閉じた入力の需要が混ざって「減らしたい」でも半分は戻る（§3.4 の減らしたい行: α = 1 で 0.5、1/16 で 0.02）。床が無ければこれだけでは死なない（需要は次の課題で引き直される）が、床があると一方向の沈みが不可逆になる。

### 8.6 α = 1 でも幅が十分育てば落ちるか（Issa の問い・0926 朝）

**問い**: 「α = 1 でも幅がもっと大きくなると閉じた unit は落ちて死ぬのでは？ 浅いところは勾配が確保できているが、深くなると死にそう」。

**答え（格つき）**: 半分そのとおり。
1. **[実測] 閉じる深さは幅で変わらない。** α = 1 の閉じた unit の上端は、幅 10（課題 2〜60）でも 22（課題 140〜199）でも z = −2.5〜−3.0（p10/50/90: −4.7/−2.6/−0.8 → −5.5/−3.0/−1.1）。閉じるのは開いた入力 1 個の unit で、上端 +2〜3 から押し 2〜3 で落ちる。押しは η‖x‖₁ の尺度で、幅の尺度ではない。上端は折れ目で閉じるのであって、平均（−2.1 s）の深さで閉じるのではない。
2. **[実測] 幅が育つと「減らしたい」閉じた unit が戻らなくなる（Issa の直感どおり）。** 再開率（課題末まで）は α = 1 で 幅 10 → 15 → 22 のとき、増やしたい 0.93 → 0.91 → 0.89、**減らしたい 0.63 → 0.56 → 0.26**（n 216/171/23）。α = 1/2 でも 減らしたい 0.35 → 0.20 → 0.12（n 634/470/128）。読み: 幅が育つと閉じた unit のゲート質量が上端 1 入力に集中し（α = 1 で 71%、p10 43%）、動く向きがその入力の需要で決まる。集中度で分けると、α = 1/2 で集中 < 0.8 の「減らしたい」は 0.57、≥ 0.95 は 0.10〜0.17、α = 1/4 で ≥ 0.999 は 0.00（56 件）。**集中度が再開を止め、集中度は幅で上がる。**
3. **[条件付き・見積もり] それでも α = 1 が死ぬには床（z = −16.64）に届く必要があり、この箱の時間尺度では届かない。** 「減らしたい」の課題で閉じた unit が沈むのは z で 1〜3（課題 140〜199 の中央値 −1.4）で、需要は毎課題引き直される（増やしたい 50% → 0.9 で再開）。床までの 12〜14 単位を連続の「減らしたい」で沈むのは (1/2)^5〜(1/2)^12。速い経路は「5 課題ほど閉じ続けて Adam の v̂ が抜け、そのとき減らしたいを引いて一気に沈む」で、閉じ続ける確率は集中度が 1 に近づくほど上がる（1 課題あたり 0.45 → 0.63、5 課題で 2% → 10%）。この経路の死は 1 閉鎖あたり 1〜5%、幅は ln t でしか育たないので、**200 課題では 0（807 閉鎖で床 0）、10³ 課題の桁で数% の見込み**。
4. **[条件付き] 2 層では別。** 上流の共通モード（µ₂ 経路）は unit 全体を上端ごと運ぶので、折れ目で閉じる 1 の制約が外れ、上端が −16.64 を越えて凍る（l2_wall・cap の登録）。Issa の「深くなると死ぬ」はこちらでは既に成立している。

**走（0926 朝に起動・予測は `PREDICTIONS_long.md` に固定）**: α = 1 m1 を 2,000 課題、α = 1/2 m1 を 1,000 課題（seed 0–1・CPU）。賭け: α = 1 の t2000 で凍結 2〜15%（t300 以降に初出）、減らしたいの再開 < 0.3、閉じる深さ不変。凍結 < 1% なら「この時間尺度では幅は殺さない」、> 30% なら見落とした速い経路がある。

### 8.7 長い走の採点（α = 1 を 2,000 課題・α = 1/2 を 1,000 課題・seed 0–1・0926 朝）

| 腕 | 幅 s（初め → 終わり） | 凍結 unit（床の下） | 閉じた区間の結末 | 閉じた unit（非凍結）の割合 | 生存 unit の上端/s・開いた入力 |
|---|---|---|---|---|---|
| α = 1、2,000 課題 | 16 → **68** | **0 / 0**（両 seed） | 837 区間すべて再開 | 課題 1〜200 で 2.6%、201〜400 で 0.1%、**401 以降は 0** | 1.2〜1.3・23〜25 |
| α = 1/2、1,000 課題 | 11 → 40 | seed 0 で 2 unit（課題 110・263、閉じてから 8 課題後）、seed 1 で 0 | 2,008 区間のうち再開 2,006・凍結 2 | 12% → 3% → 1%（1% は凍結分） | 1.1〜1.3・15〜19 |

- **Issa の仮説「α = 1 でも幅が十分育てば落ちる」は、この箱・この時間尺度では不成立。** 幅が 68 まで育っても閉じた unit は 0、床の下も 0。**私の賭け（t2000 で凍結 2〜15%）も外れ**（判定の下限 < 1% に落ちた）。
- **理由は「幅が守る」**: 閉じるのは開いた入力 1 個で上端が +2〜3 の unit だけ（§8.2）。幅が育つと生存 unit は開いた入力を 23〜25 個持ち、上端は 1.2〜1.3 s（s = 68 で 80 以上）になるので、押し 3〜4 では閉じられない。閉じる候補が無くなるので、§8.6-2 の「減らしたい unit が戻らなくなる」効果は働く相手を失う。深くなるのは閉じた入力（z = −50〜−100・ゲートは個別に厳密 0）であって上端ではない。
- α = 1/2 の凍結 2 件は §8.3 の遅い経路（閉じてから 8 課題後の一気の沈み）で、幅 19〜25 の早い時期に起きた。その後 700 課題（幅 25 → 40）で追加は 0。
- 死は全 α で早い局面の現象（上端が低く、閉じる候補が多い課題 5〜50）。α が小さいほどその局面で床が近いので死ぬ。小さい α の生存 unit も上端 ∝ s なので、後期には安全になる（α = 1/16 の死亡は t50 → t200 で 0.75 → 0.89 と増えたが、これは上端がまだ 9〜11 と低い区間）。
- 見積もり §8.6-3 の誤り: 「1 閉鎖あたり 1〜5%」は閉鎖が起き続ける前提で、幅が育つと閉鎖率そのものが 0 になることを入れていなかった。

**まとめ（Issa の問いへの最終の答え）**: 1 層・固定入力では、幅は α = 1 を殺さない。閉じる深さは幅で変わらず（η‖x‖₁ の尺度）、幅が育つと閉じる候補が消える。幅が育つと死ぬのは 2 層の共通モードが上端ごと運ぶときで、それは別の経路（[[第2層のµ₂壁_l2_wall_0916]]・[[第2層にも上限_l2cap_ee_0917]]）。

**沈下は止まるのか（Issa・0926 昼）**: 意味で分かれる。α = 1・2,000 課題で、**絶対の平均 m は沈み続ける**（−21 → −148、s に比例、s は ln t あたり 23〜24）。**相対位置 ρ = m/s は −2.1 で張り付き**（t ≥ 500 の傾き +0.015/ln t）、**p⁺ と平均ゲートも 0.02 で張り付き**（0.019 → 0.021、+0.002/ln t）、**上端は 10 → 99 と上がり続ける**（1.1〜1.4 s、先生の規格化した上端 h ∝ top/s は一定）。α = 1/2 も同型（ρ −2.2、p⁺ 0.014、+0.002/ln t）。つまり止まるのは相対位置と mob、沈むのは絶対の平均と閉じた入力。版 B「勾配が死なない限り無限に沈下」は絶対の平均では成り立ち、mob → 0 は成り立たない（1 層 ELU は「幅 → ∞ かつ p⁺ → 0」の後半が落ちる）。
