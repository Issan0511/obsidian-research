## 0. 一言で

- **定理にならない。** 「切替で平均モードが下がる」の期待値式は厳密だが、その符号（整列 S_i > 0）は当てはめから導けない（1 unit の反例）。「p⁺ の単調減少」「平均ゲート → 0」は前提を置いた条件付きの文で、前提は測るしかない。
- **測ると前提は成り立っている。** 1 層の走で、切替時に生きている unit の **95〜99%（ELU/GELU/SiLU）・69〜75%（leaky）で S_i < 0**、200 更新後の実際の変位は 85〜96% で下向き。leaky だけ 3 割が「上向き予測」で、床が押しの符号にも入っている。
- **p⁺ は層平均では単調に減り、unit 単位では 2〜4 割の課題で微増する。** 平均ゲートは崩壊層で 0 へ（RL-CIFAR は課題 50 で厳密 0 のゲートが 100%）。
- **活性化の差は払い戻し比に出る**: 課題内の払い戻し／切替の押し = leaky(SGD) 0.95・leaky(Adam) 0.8・ELU 0.66・SiLU 0.32・GELU 0.2。この順に崩壊が速い（GELU 課題 5・SiLU 10・ELU 30 で 0.015・leaky は 0.01〜0.03 で張り付き）。
- 理論で書けるのは §1.5 の 4 文。「向き」は前提として明示する。

## 1. 理論の検証

### 1.1 検証にかけた主張（[[先生の箱A理論_Session43_0925_と本稿の照合]] のスケッチ＋当日の会話）

- **A** 切替直後の平均モードの期待変化 E[Δ(w_i·µ̂)] = −(η/N)Σₙ(v_{i,y_old(n)} − v̄_i)φ′(z_{i,n})(xₙ·µ̂)。前提 (i) xₙ·µ̂ > 0、(ii) 当てはめが作った整列で和が正、(iii) 新ラベルは旧と独立で一様。⇒ 開いた入力のある全 unit で下向き。Adam なら一歩 −η‖µ‖₁/‖µ‖₂。
- **B** 1 課題の Δρ ≈ −α p⁺ + β(p⁺)。払い戻し容量 ∝ Σ φ′ r。leaky は床で正の固定点、ELU は p⁺ = 0 が吸収点で α > β なら単調、GELU/SiLU は谷で α によらず単調。
- **C** φ′ → 0 の活性化で ρ → −∞ ⇒ ḡ → 0。ELU の ḡ は単調。
- **D** SGD は dρ/dt ∝ ḡ で対数則、Adam は線形で有限時間に厳密 0。

### 1.3 整列仮定なしで言えること

- **切替一歩目の期待損失は一様化の損失**（Codex）: E_{y_new}L = log K + (1/N)Σₙ KL(u‖pₙ)。期待勾配は「予測を一様にする」勾配そのもので、隠れ unit を負側へ動かすことはその必須の方法ではない。
- **出力層のノルムは一次で縮む**（Codex）: Σ_i v_iᵀ∇_{v_i}EL + cᵀ∇_c EL = (1/N)Σₙ ℓₙᵀ(pₙ − u) ≥ 0。
- **斉次な活性化なら隠れ層も縮む**（私の追加）: leaky/ReLU で φ′z = φ なので Euler の関係から Σ_i(w_i·∇_{w_i}F + b_i∂_{b_i}F) = (1/N)Σₙ(pₙ−u)ᵀ(ℓₙ − c) = (1/N)Σₙ ℓₙᵀ(pₙ−u) − (p̄−u)ᵀc。第 1 項 ≥ 0。予測の平均 p̄ ≈ u なら Σ(‖w_i‖² + b_i²) の一次変化は非正。切替の期待一歩は「縮める」で、平均モードの向きはこの中に入っていない。

### 1.4 反例の読み方（うちの箱への含意）

反例の unit は「活動が平均方向の射影 r と逆相関」している。w·µ̂ < 0 の unit（沈んだ unit）は開いた入力が r の小さい入力なので、押し Σ q_y g r は開いた入力からは弱く、閉じた入力（q < 0・r 大）からは g の分だけ上向きに入る。**leaky は g = a > 0 なのでこの上向きが残り、ELU は g = e^z で消える。** 床が課題内の払い戻しだけでなく**切替の押しの符号にも**入る、という読み。1 層の走の v2（§3.5）で確かめた。

### 1.5 定理として書ける文と、前提として置く文

1. [厳密] 切替一歩目の期待変化 E[Δ(w_i·µ̂)] = −(η/N)S_i、S_i = Σₙ(v_iᵀpₙ − v̄_i)φ′_{in}(xₙ·µ̂)（任意の活性化・E[y_new \| 状態] = u だけ）。
2. [厳密] 切替一歩目の期待勾配は一様化の勾配で、出力層 Σ‖v_i‖² + ‖c‖² の一次変化は非正。斉次なら隠れ層の Σ(‖w_i‖² + b_i²) も（(p̄−u)ᵀc を除いて）非正。
3. [厳密] max_n z_{i,n} → −∞ ⇒ ḡ_i → 0（φ′ → 0 の活性化）。ρ → −∞ だけでは不十分。
4. [条件付き] 縮約 ODE dρ/dt = −κḡ(ρ)（ELU 型の尾・固定尺度）で ρ ~ −(1/s)ln t。
5. **[前提として置く]** S_i > 0（向き）。当てはめから導けない。測る（§3.2）。
6. **[前提として置く]** 課題内の払い戻しが切替の押しを下回る（α > β）。上界しか無い。測る（§3.4）。

### 3.4 払い戻し比（α 対 β の実測）

払い戻し（200 更新 → 課題末）／切替の押し（0 → 200）の中央値: **leaky SGD 0.95・leaky Adam 0.80・ELU Adam 0.66・SiLU 0.32・GELU 0.20**。崩壊の速さ（GELU 課題 5・SiLU 10・ELU 30 で 0.015・leaky は張り付き）と同じ順。α > β は前提として置く量で、この比がその実測値。谷のある GELU/SiLU で比が小さいのは §1.2 の「谷の払い戻し」の読みと合うが、導出はない。

### 3.5 開いた入力／閉じた入力の分解（v2・Adam 4 腕 × 3 seed・切替 t ≥ 4 と seed の中央値）

S_i = S_open + S_closed（開いた入力 z > 0 と閉じた入力の寄与）。

| 腕 | S_i < 0 | S_open < 0 | S_closed > 0（床が上向きに効く） | \|S_closed\|/\|S_open\| | 上向き予測の unit 数（/生存） | そのうち「開いた分は下・閉じた分が勝つ」 | 上向き予測 unit の実変位@200 が下向き |
|---|---|---|---|---|---|---|---|
| ELU | 0.98 | **1.00** | 0.75 | 0.11 | 2 / 97 | 0.88 | 0.50 |
| GELU | 0.97 | 0.98 | 0.53 | 0.09 | 2 / 65 | 0.33 | 0.50 |
| SiLU | 0.96 | 0.97 | 0.41 | 0.14 | 3 / 77 | 0.50 | 0.67 |
| leaky 0.1 | **0.69** | 0.92 | 0.54 | **1.44** | **26 / 89** | **0.89** | 0.76 |

- 開いた入力からの押しは全活性化で下向き（92〜100%）。§1.2 の反例の型（開いた入力で逆相関）は、この箱では起きていない。
- **leaky の 3 割の上向き予測は床が作る**: 閉じた入力の寄与（g = a = 0.1 × 反整列 × 大きい r）が開いた入力の寄与の 1.4 倍あり、上向き予測 unit の 89% は「開いた分は下、閉じた分が勝つ」。ELU/GELU/SiLU では閉じた入力の寄与が 1 割で消える。§1.4 の読みのとおり、**床は課題内の払い戻しだけでなく切替の押しの符号にも入る**。
- ただし leaky の上向き予測 unit も実際には 76% が 200 更新で下がる。一歩目の期待値は課題内の力学の一部でしかなく（Adam のモーメント・課題内の再整列）、leaky の予測一致が 0.7 に留まる理由はここ。

## 4. Issa の 2 主張への答え

1. **「ELU/GELU/SiLU で p⁺ が単調減少」**: 定理ではない。前提 S_i > 0（向き・§1.5-5）と α > β（§1.5-6）を置けば「各切替で期待値として下がり、課題内で下回る分だけ戻る」まで。数値は層平均では単調（RL-CIFAR 崩壊層で GELU/SiLU/ReLU が 10/10 seed 一度も上がらず 0、ELU は微小復活つき）、unit 単位では 2〜4 割の課題で微増。**単調は「層平均・課題平均・崩壊層」で書く。** 谷の GELU/SiLU が厳密単調で ELU に復活があるのは α > β の構造どおりだが、谷の必然性は導出されていない（反例あり）。
2. **「平均勾配・mob → 0」**: 定理は「上端 max_n z_{i,n} → −∞ ⇒ ḡ → 0」（§1.5-3）。ρ → −∞ では足りない。上端が −∞ へ行くのは「幅 → ∞ ＋ 上端の相対位置が負に留まる」（版 B の議論）で、後半は実測（1 層で ρ → −2.2〜−2.9・上端は m + 3.2s > 0 のまま。層が全部死ぬのは 2 層の箱で上流の幅が運ぶとき）。数値は崩壊層で 0（RL-CIFAR 課題 50 で厳密 0 が 100%）。GELU/SiLU の ḡ は谷で負を通るので \|φ′\| で書く。
