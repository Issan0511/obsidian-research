## 0. 一言で

- **定理にならない。** 「切替で平均モードが下がる」の期待値式は厳密だが、その符号（整列 S_i > 0）は当てはめから導けない（1 unit の反例）。「p⁺ の単調減少」「平均ゲート → 0」は前提を置いた条件付きの文で、前提は測るしかない。
- **測ると前提は成り立っている。** 1 層の走で、切替時に生きている unit の **95〜99%（ELU/GELU/SiLU）・69〜75%（leaky）で S_i < 0**、200 更新後の実際の変位は 85〜96% で下向き。leaky だけ 3 割が「上向き予測」で、床が押しの符号にも入っている。
- **p⁺ は層平均では単調に減り、unit 単位では 2〜4 割の課題で微増する。** 平均ゲートは崩壊層で 0 へ（RL-CIFAR は課題 50 で厳密 0 のゲートが 100%）。
- **活性化の差は払い戻し比に出る**: 課題内の払い戻し／切替の押し = leaky(SGD) 0.95・leaky(Adam) 0.8・ELU 0.66・SiLU 0.32・GELU 0.2。この順に崩壊が速い（GELU 課題 5・SiLU 10・ELU 30 で 0.015・leaky は 0.01〜0.03 で張り付き）。
- 理論で書けるのは §1.5 の 4 文。「向き」は前提として明示する。
- **0925 深夜の追記**: ELU を α·ELU(z/α) に縮めた梯子（α = 1〜1/16）は [[ELUを縮める_α梯子_1層200課題と理論_0925]]。生き残りはどの α でも ELU 型（上端 ∝ 幅）、死ぬのは数値の床 u = z/α ≈ −16.6 が押しの届く深さに来たときだけ。§3.6 の「e^z 帯で引き戻せる」の読みは外れ（拾い直しは帯の外の z ≈ −5 からの集団の払い戻し）。Codex の指摘で §1.5-3・§1.6 に訂正の注記を入れた。

## 1. 理論の検証

### 1.1 検証にかけた主張（[[先生の箱A理論_Session43_0925_と本稿の照合]] のスケッチ＋当日の会話）

- **A** 切替直後の平均モードの期待変化 E[Δ(w_i·µ̂)] = −(η/N)Σₙ(v_{i,y_old(n)} − v̄_i)φ′(z_{i,n})(xₙ·µ̂)。前提 (i) xₙ·µ̂ > 0、(ii) 当てはめが作った整列で和が正、(iii) 新ラベルは旧と独立で一様。⇒ 開いた入力のある全 unit で下向き。Adam なら一歩 −η‖µ‖₁/‖µ‖₂。
- **B** 1 課題の Δρ ≈ −α p⁺ + β(p⁺)。払い戻し容量 ∝ Σ φ′ r。leaky は床で正の固定点、ELU は p⁺ = 0 が吸収点で α > β なら単調、GELU/SiLU は谷で α によらず単調。
- **C** φ′ → 0 の活性化で ρ → −∞ ⇒ ḡ → 0。ELU の ḡ は単調。
- **D** SGD は dρ/dt ∝ ḡ で対数則、Adam は線形で有限時間に厳密 0。

### 1.3 整列仮定なしで言えること

- **切替一歩目の期待損失は一様化の損失**（Codex）: E_{y_new}L = log K + (1/N)Σₙ KL(u‖pₙ)。期待勾配は「予測を一様にする」勾配そのもので、隠れ unit を負側へ動かすことはその必須の方法ではない。
- **出力層のノルムは一次で縮む**（Codex）: Σ_i v_iᵀ∇_{v_i}EL + cᵀ∇_c EL = (1/N)Σₙ ℓₙᵀ(pₙ − u) ≥ 0。
- **斉次な活性化なら隠れ層も縮む**（私の追加）: leaky/ReLU で φ′z = φ なので Euler の関係から Σ_i(w_i·∇_{w_i}F + b_i∂_{b_i}F) = (1/N)Σₙ(pₙ−u)ᵀ(ℓₙ − c) = (1/N)Σₙ ℓₙᵀ(pₙ−u) − (p̄−u)ᵀc。第 1 項 ≥ 0。予測の平均 p̄ ≈ u なら Σ(‖w_i‖² + b_i²) の一次変化は非正。切替の期待一歩は「縮める」で、平均モードの向きはこの中に入っていない。

### 1.4 反例の読み方（うちの箱への含意）

反例の unit は「活動が平均方向の射影 r と逆相関」している。w·µ̂ < 0 の unit（沈んだ unit）は開いた入力が r の小さい入力なので、押し Σ q_y g r は開いた入力からは弱く、閉じた入力（q < 0・r 大）からは g の分だけ上向きに入る。**leaky は g = a > 0 なのでこの上向きが残り、ELU は g = e^z で消える。** 床が課題内の払い戻しだけでなく**切替の押しの符号にも**入る、という読み。1 層の走の v2（§3.5）で確かめた。

### 1.5 定理として書ける文と、前提として置く文

1. [厳密] 切替一歩目の期待変化 E[Δ(w_i·µ̂)] = −(η/N)S_i、S_i = Σₙ(v_iᵀpₙ − v̄_i)φ′_{in}(xₙ·µ̂)（任意の活性化・E[y_new \| 状態] = u だけ）。
2. [厳密] 切替一歩目の期待勾配は一様化の勾配で、出力層 Σ‖v_i‖² + ‖c‖² の一次変化は非正。斉次なら隠れ層の Σ(‖w_i‖² + b_i²) も（(p̄−u)ᵀc を除いて）非正。
3. [厳密] max_n z_{i,n} → −∞ ⇒ ḡ_i → 0（φ′ → 0 の活性化）。ρ → −∞ だけでは不十分。**幅 → ∞ を前提に置くなら上端の行き先は要らない（Issa の指摘・0925 夜）**: z_{i,n} = s(ρ + u_n) で s → ∞ なら各 n で φ′ → 1 か 0 に落ちるので、有限和で ḡ_i → p⁺_i（床なし）／p⁺_i + a(1 − p⁺_i)（leaky）。**幅 → ∞ かつ p⁺ → 0 ⇒ mob → 0**。**［0925 深夜の訂正・Codex の α 梯子レビュー］床なしの「s → ∞ ⇒ ḡ → p⁺」は、標準化した位置 ρ + u_n が 0 から離れたままという条件つき（[条件付き]）。s → ∞ だけでは足りない（少数の入力が −∞ へ行って幅を広げ、残りが折れ目の直下に留まる反例）。厳密な形は ELU で ḡ − p⁺ = (1/N)Σ_{z<0} e^{z} ≤ (1 − p⁺)e^{−d}（d = 折れ目に最も近い閉じた入力までの距離）で、ḡ → p⁺ ⇔ d → ∞。leaky の ḡ = p⁺ + a(1 − p⁺) は条件なしで厳密。N 固定では p⁺ = k/N なので「p⁺ → 0」は最終的に k = 0（全閉）の意味になる。詳細は [[ELUを縮める_α梯子_1層200課題と理論_0925]]。**上端が折れ目に張り付いていれば p⁺ ≤ 1/N でそれだけで足りる。データ: 1 層 ELU で ḡ − p⁺ は課題 1 の 0.25（s = 1.1）→ 課題 30 の 0.005（s = 9.5）。mob → 0 は「勾配が死ぬ」ではない（上端の入力ではゲート 1 のまま学べる。③の担い手減少はこちら。凍結は上端が閾値の下に落ちるときで、2 層で上流の幅が共通モードで運ぶ場合）。
4. [条件付き] 縮約 ODE dρ/dt = −κḡ(ρ)（ELU 型の尾・固定尺度）で ρ ~ −(1/s)ln t。
5. **[前提として置く]** S_i > 0（向き）。当てはめから導けない。測る（§3.2）。
6. **[前提として置く]** 課題内の払い戻しが切替の押しを下回る（α > β）。上界しか無い。測る（§3.4）。

### 1.6 上端 ≤ C の理論（Issa「理論的に詰めて」・0925 夜）

**目標**: 幅 s → ∞ の下で unit の上端 z_top = max_n z_{i,n} が幅に依らない定数で抑えられれば p⁺ ≤ k/N → 0（§1.5-3）。**［0925 深夜の訂正・Codex］この含意は代数的に誤り。p⁺ = k/N なので、上端が有界でも k は減らない（一つの z を 1 に保ち残りを −∞ へ送れば、上端は有界・幅は発散・p⁺ = 1/N のまま）。上端の有界性とは別に k が減ることが要る。GELU/SiLU の k → 0.2〜1 は実測で、谷の吸収性はその読みであって導出ではない。**

1. **入力ごとの力 [厳密]**: Δz_{i,n} = −(η/B)Σ_m δ_{i,m}(x_m·x_n + 1)、δ = (v_iᵀe_m)φ′(z_m)。自己力 F_n = −(v_iᵀe_n)φ′(z_n)(‖x_n‖² + 1)（v_iᵀe_n < 0 は「出力を増やしたい」）と交差項に分かれる。**［0925 深夜の訂正・Codex］これは SGD の式。この箱は Adam なので、座標ごとの一次・二次モーメントを通した更新になり、自己項と交差項への厳密な分解は無い。次の 2. の吸収性も自己力の符号の話で、Adam の全更新での吸収を示したものではない（一つの入力が勾配を支配するときは Adam でも符号は保たれる）。**
2. **谷は自己力で吸収的 [厳密]**: GELU/SiLU は z_c（−0.752 / −1.278）で φ′ = 0、下で φ′ < 0。z < z_c の入力は「増やしたい」なら F < 0 で逃走、「減らしたい」なら z_c へ向かい z_c で止まる。自己力では z_c の上へ戻れない。ELU は φ′ = e^z > 0 で戻れる。吸収領域の有無は活性化だけで決まる。
3. **補充帯 (z_c, 0) [条件付き]**: 切替の交差項は整列（S_i > 0・実測 95〜99%）なら共通モードで下向き。課題内の交差項の符号は出せていない。これを除くと、開いた集合 O_i は帯 (z_c, 0) に留まった入力だけが当てはめで戻り、z_c より下は失われる。帯の幅 |z_c| は活性化だけの定数。ELU の帯は e^z が 1 と張り合える 2〜3 単位（Adam の正規化下）、leaky は ∞。
4. **押し D > |z_c| なら |O_i| → O(1) [条件付き]**: 上端への切替の押し D ≈ η T_s ‖x‖₁ coh ≈ 2〜2.5（実測 GELU −2.1・SiLU −2.4）> |z_c| なので、折れ目のすぐ上の入力は一回の切替で z_c の下へ落ちる。実測 GELU 1.2・SiLU 2.4 入力/unit。
5. **1 入力 unit の上端は logit の余裕で決まる [条件付き・箱依存]**: 必要な logit 差 M（信頼度 1−ε で log((K−1)(1−ε)/ε)、ε=0.1 で 4.4）を寄与 Δv_i·φ(z_top) で出すので、当てはめ後の上端は z_top ≈ M/Δv_i =: C。前の高さに依らず毎課題この高さに戻る。幅 s に依らない。実測の GELU/SiLU の上端 3〜6。生き残る条件 C − D > z_c は Adam で Δv が育つと割れ、全閉 unit が増え続ける（GELU 25% → 50%）。
6. **ELU に上界が無い理由**: 吸収領域が無く補充されるので多入力のまま（18 入力/unit）、読み出しが薄まり上端を高くして効かせる。上端は幅と伸びる（3 → 11）。ELU の p⁺ → 0 は相対位置 ρ → −3.4 の経路で、向きと α > β（§1.5-5・6）に戻る。

7. **ELU でも上端は有界で収束する [条件付き]（Issa との問答・0925 夜）**: (a) 当てはめは「量」でなく「水準」まで持ち上げる [厳密]: CE の勾配は logit 差 M で消えるので、課題末の上端は max(切替後の上端, M/Δv_eff) で幅に依らない。(b) 閉じた入力の予算は有限 [厳密]: 速さ c 以上で沈む入力の累積ゲートは (φ(0) − φ(−∞))/c（ELU 1/c、GELU/SiLU は |φ′| で 2|φ_min|/c）、leaky は ∞。閉じた側からの力は深さで幾何的に尽きる（Issa の「φ′ の負の積分は収束する」）。(c) Δv_eff は開いた入力の数 k が減ると上がり Adam で育つ [条件付き]。⇒ 上端 ≤ M/Δv_eff(k_max) で、k → 1 なら 1 入力の高さ（GELU/SiLU の 3〜6）へ下がって落ち着く。ELU の 11 は希釈の一時的な高さ。収束の速さは k(t) の形（この箱で p⁺ ≈ 0.5/t）で決まり代数的、指数ではない。残る前提: k が長期で非増加（切替の押しが補充を上回る＝整列）、Δv_eff が下から離れる。これで「幅 → ∞ ＋ 整列 ⇒ 上端有界 ⇒ p⁺ → 0 ⇒ 沈下・mob → 0」が前提 2 つの条件付き命題になる。**→ 200 課題の走で ELU について棄却（§3.6）**: 前提 (c)「k が長期で非増加」が落ちる。切替の押しは消えないが、可視方向の幅の伸びが平均の沈みを追い越し、吸収領域が無い ELU では広がった分の入力が再び開く（k 14 → 24〜29、上端 11 → 35、p⁺ 2% で張り付き）。有界性の議論は**谷のある活性化（GELU/SiLU）にだけ**通る。ELU の死は 1 層の切替の押しでは起きず、上流の共通モード（2 層・µ₂ 経路）に運ばれるときに起きる。

格: 活性化だけの定数は |z_c| と吸収領域の有無。上端の定数 C = M/Δv は箱の量だが幅に依らない。足りないもの: 課題内の交差項の符号、D > |z_c| の導出（今は実測）、Δv の時間発展、Adam での「入力ごとの力」の近似性。**200 課題の走への予測（走の前に固定・0925 夜）**: GELU/SiLU の生き残り unit の上端は 3〜6 のまま・全閉 unit は増え続ける、ELU の上端は幅とともに伸び続ける（対数的）。**Issa の予測（同時刻）**: ELU の上端の伸びは指数的に鈍ってある値に収束する。30 課題の当てはめでは対数（R² 0.82/0.92）と飽和指数（0.83/0.91）が区別できず、t200 の予測は対数 13.4〜13.6、飽和 10.7（seed 1・τ = 13）。判別は 200 課題の走で。理論の側では、§1.6-5 の C = M/Δv が多入力 unit では入力数 k の希釈で上がり、k = p⁺N ≈ 0.5N/t で減り Δv は Adam で育つので、上端が収束すること自体は枠組みと矛盾しない。収束の速さは k(t) と Δv(t) の形で決まり、k ∝ 1/t なら代数的で指数ではない。

- 含意: **1 層・固定入力では ELU は死なない（leaky 型に張り付く）。ELU が死ぬのは上流の共通モード（第 2 層・µ₂ 経路・l2_wall / cap の登録）に運ばれるとき。** 既存の箱と整合: RL-CIFAR std は第 1 層の ELU p⁺ 不変・第 2 層が死ぬ、raw は第 1 層 ELU 0.084 → 0.032 で止まる、RL-MNIST 2 層は第 1 層 ELU が t150 でゲート 0.29 で生存し第 2 層だけ死ぬ。GELU/SiLU は第 1 層でも死ぬ（谷）。

## 4. Issa の 2 主張への答え

1. **「ELU/GELU/SiLU で p⁺ が単調減少」**: 定理ではない。前提 S_i > 0（向き・§1.5-5）と α > β（§1.5-6）を置けば「各切替で期待値として下がり、課題内で下回る分だけ戻る」まで。数値は層平均では単調（RL-CIFAR 崩壊層で GELU/SiLU/ReLU が 10/10 seed 一度も上がらず 0、ELU は微小復活つき）、unit 単位では 2〜4 割の課題で微増。**単調は「層平均・課題平均・崩壊層」で書く。** 谷の GELU/SiLU が厳密単調で ELU に復活があるのは α > β の構造どおりだが、谷の必然性は導出されていない（反例あり）。
2. **「平均勾配・mob → 0」**: 幅 → ∞ を前提に置けば定理は「p⁺ → 0 ⇒ mob → 0（床なし）／→ a（leaky）」（§1.5-3・ゲートが階段関数になり平均ゲートは折れ目の上の割合に落ちる）。**［0925 深夜の訂正］床なしでは「閉じた入力が折れ目の直下に留まらない（d → ∞）」も前提に要る（§1.5-3 の注記）。**上端 → −∞ は幅の前提なしの版（Codex の縮む反例を潰す条件）で、幅 → ∞ の下では要らない。ρ → −∞ だけでは足りない。上端が −∞ へ行くのは「幅 → ∞ ＋ 上端の相対位置が負に留まる」（版 B の議論）で、後半は実測（1 層で ρ → −2.2〜−2.9・上端は m + 3.2s > 0 のまま。層が全部死ぬのは 2 層の箱で上流の幅が運ぶとき）。数値は崩壊層で 0（RL-CIFAR 課題 50 で厳密 0 が 100%）。GELU/SiLU の ḡ は谷で負を通るので \|φ′\| で書く。
