# ELUのQとノルム比 — 保存状態による検証

2026-09-29 JST / Codex。会話での「Qが分からなければ比を予測できない」「Qへの分解に意味があるのか」という問いへの事後検証。先生の理論の追加主張ではない。

関連: [[ELUを縮める_α梯子_1層200課題と理論_0925]]

## 結論

Qには、入力側を縮め読み出しを増やす操作の損失勾配という意味がある。ただし「比を1へ戻す力」と解釈する根拠はない。保存された1層ELU・Adamの課題末では、Qの大半が出力バイアスの平均誤差と結びついていた。実測ノルム比も、観測期間では1へ単調に近づいていない。

## 操作としてのQ

隠れunitごとに u=(w,b), R=||u||², V=||v||², e=p−y, D=vᵀe。同じ学習率ηのEuclidean勾配流では

$$Q=\dot V-\dot R=2\eta\langle D(z\phi'(z)-\phi(z))\rangle.$$

v(s)=exp(s)v, u(s)=exp(−s)u という積を保つ操作について、dL/ds=−Q/(2η)。Q>0なら、この経路ではvを増やしuを縮める側で損失が下がる。自然なAdam更新がこの経路をたどるという意味ではない。

標準ELUの深い負側は出力−vなので、この操作は共通の出力ずれを作る。出力バイアスcも c(s)=c+(exp(s)−1)v と動かして補償すると、

$$Q^{\mathrm{comp}}=Q-2\eta v^\top\nabla_cL.$$

従ってQを「出力バイアス勾配との重なり」と「補償経路の損失勾配」に分けられる。補償経路は比較のための別操作であり、元の勾配流の定義Qを置き換えない。

## 保存状態で確かめたこと

Qの検証は2 seed、課題10/20/30/40、全100 unit。以下の数値は課題末。

| 指標                          | seed 0 | seed 1 |
| --------------------------- | -----: | -----: |
| Q>0の割合                      |  48.0% | 45.25% |
| Qと2ηvᵀ∇cLの符号一致              | 99.25% | 97.25% |
| sum(abs(Qcomp))/sum(abs(Q)) |  4.43% |  4.48% |

4.4%は差のL1比であり、分散説明率や因果媒介率ではない。

さらにw,vを固定し、出力バイアスだけを最適化すると、8状態のsum(abs(Q))は92〜99%減少し、41〜56%のunitで符号が反転した。z、上端、R、V、V/Rは変えていない。同じw,vでもQは他のparameterが平均誤差を解消するだけで大きく変わるので、R,Vだけで閉じた力にはならない。バイアス最適化後のQと、最適化前のQcompは残差eが変わるため同一ではない。

各unitの二乗ノルム比V/Rの中央値は以下。別の保存記録との軌道一致を確認して接続した。

| 課題  |    seed 0 |    seed 1 |
| --- | --------: | --------: |
| 10  |   0.02100 |   0.02129 |
| 50  |  0.003085 |  0.003239 |
| 100 | 0.0005337 | 0.0005479 |
| 200 |  0.001864 |  0.001970 |

Rは増大、Vは途中まで減少し後半に再増大。比は1へ単調接近していない。将来の極限を反証したわけではない。

## 検算と限界

ELUの尺度操作とバイアス補償操作の損失有限差分は、Qの予測と最大相対L1誤差6.95e−8で一致。leaky ReLUの負の対照も確認。確率は保存DとW2から復元し、復元残差は約1e−7以下。Adam momentは保存されていないので実更新の再演はしていない。数学的ELUの微分を使う診断であり、float32 expm1経路の深部の微分0やAdamの実変位とは区別する。2 seedの事後解析、新規訓練なし。
