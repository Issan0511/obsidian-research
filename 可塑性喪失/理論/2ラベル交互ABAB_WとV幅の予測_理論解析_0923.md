## 0. 問い（Issa、0922 夜）

「RL-CIFAR で 2 ラベルを交互にやらせまくったときの W と前活性の幅の挙動を詳しく解析させてください」。走はまだ無い。IID（毎課題 fresh な乱数ラベル）の 50 課題 × 10 seed の帳簿（[[RL-CIFAR第1層の帯別帳簿_事後_0922]]・[[RL-CIFAR第1層の漏れ検査_Adamの三つの歩幅_事後_0922]]・[[RL-CIFAR第1層の幅を広げる者_消し残りと収束後の増幅_事後_0922]]・[[Snakeの幅はなぜ小さいところで止まるか_切替で古い解を捨てる_事後_0922]]・[[残滓は溶接されている_当てはめの前なら外せる_事後_0923]]・[[PC別帳簿_消し込みの目盛りは順位に線形で緩和ではない_事後_0923]]）と PMNIST の置換循環（[[置換循環_幅成長の反実仮想_結果_0909]]）を事実として渡し、4 つの候補模型（M-OU・M-LAG1・M-ADAM・M-CE）で ABAB を予測させた。

## 3. 骨格: 戻るのか、大きくなり続けるのか

課題終端の重みを W_t = M_t + s_t D_t（s_t = +1 が A、−1 が B）と書く。M_t が中心、D_t が 2 解の隔たり。ABAB で起き得るのは
- M, D とも一定 → 有界な 2 周期
- M が伸び D は有界 → 共通の自信・特徴の成長（M-CE）
- D が伸びる → 振幅の増す振動
- 両方動く → 不完全な再利用

**主要評価量は「周期の中心と直径」を局面（衝撃・当てはめ・静穏・一撃）ごとに分けた変位。** 累積比 r_M = ‖ΣΔ_t‖²/Σ‖Δ_t‖² が小さいことは有界の証拠にならない: W_t = R_t u_{A/B}, R_t ∝ t^β なら C₁ → −1・C₂ → +1 で r = O(1/T) だが N ∝ t^{2β} で伸び続ける。

## 4. top 帯（Q1）

- **厳密に戻る場合:** 増分は D, −D, D, … なので C₁ = −1・C₂ = +1、r_M = 0（M 偶数）/ 1/M（M 奇数）。t6–50 なら 0.0222。
- **OU（fresh な革新）:** W_t = aW_{t−1} + ξ_t, a = 1−f で C_k = −(f/2) a^{k−1}（検算済み）。top の f = 728/(2·2,533) = 0.144 → C₁ = −0.072・C₂ = −0.062。**IID の実測 C₁ = −0.16 に既に届かない**: スカラー OU はエネルギー収支は合わせられても時間の過程は合わない。
- **再利用か書き直しか:** 事実 (e)（溶接・当てはめ前なら無料）と (f)（W1 凍結で 2/5・5/5 が覚える。Wilson 区間 0.12–0.77・0.57–1 で広い）はどちらも「古い A の解を取り出す」ことを示さない。Codex は leaky/Snake どちらにも決めず、登録可能な境界だけ出した:
  - 強い節約: 2 回目以降の A で acc 0.999 到達 **≤ 1,800 更新**（fresh 網 1,767 の次の評価点）
  - IID 並み: 3,400–5,300（中心 5,000）
- A→A の top コサイン: 厳密再利用 1、AR(1) で連続コサインを係数にすると leaky 0.62² = 0.38・Snake 0.41² = 0.17、1−f_V を使うと 0.44/0.18。模型の目盛りで、単一測定からの演繹ではない。

## 5. 遅い帯 mid2・low・comp（Q2）— ここが一番効く

- **OU-F（後期 f を固定、fresh な革新）:** N_t = N* + (N₁ − N*)(1−f)^{2(t−1)}。ABAB/IID の成長比は **1**（「革新は fresh のまま」という追加仮定の帰結で、OU の復元力の帰結ではない）。中心化した周期強制 ξ = ±δ なら定常比は f/(2−f) = mid2 0.005・low 0.002 だが、A/B の平均 μ ≠ 0 なら逆に非常に大きくなる。
- **LAG-P 純:** Δ_t = H(y_t − y_{t−1})。IID で C₁ = −1/2・C_{k≥2} = 0、ABAB で C_k = (−1)^k、ラベル駆動の変位は有界（比 0）。しかし実測の ρ は −0.08/−0.06/−0.02 で −1/2 に遠い。
- **LAG-P 混合:** Δ_t = H(y_t − y_{t−1}) + ε_t（ε は fresh）。ラベル差成分のエネルギー割合 α = 2ρ（mid2 0.16・low 0.12・comp 0.04）。ABAB で C₁ = −α・C₂ = +α、残りの成長 (1−α)d = mid2 1,123・low 211・comp 4.03/課題。**ラベル差成分は IID でも既に伸び縮み（telescoping）しているので、ABAB でも比は 1。**

> **私の読み違い（ノート PC別帳簿 §7 の「ラグ 1 の取り消しなら交互で二乗の足し算が消えるはず」）はこの形では成り立たない。** ラグ 1 の取り消しは「前の課題のラベル差の分を消す」だけで、IID でも同じだけ消えている。積もっているのはラベル差でない部分で、それが (i) fresh なら ABAB でも IID と同じ速さ、(ii) 現在のラベル y_t だけの関数 G(y_t) なら ABAB では G(A), G(B), G(A), … が足し算になって **IID より速く伸びる（弾道、N ∝ t²）**、(iii) 差の形 G(y_t) − G(y_{t−1}) なら有界。ABAB が分けるのはこの 3 つで、「交互にすれば成長が止まる」は (iii) だけ。

- **comp:** 入力が固定なので W_comp だけ動かしても出力も生の勾配も変わらない → **因果的な復元力は厳密に 0**（当てはめた f_comp > 0 は相関統計）。Adam の座標ごとの正規化が comp に書く。予測は「一撃の向きが反復する」なら有界で交互、「fresh に漏れる」なら N_comp ≈ 20.3 + 4.2t（t25 で 125・t50 で 230）、混合で 121/222。
- **PMNIST の CYCLE2 = 0.66** は競合する経験的目安であって、入力の張る空間が固定でも低い比が導かれるわけではない（固定が保証するのは comp が永久に見えないことだけ）。

## 6. 幅（Q3）

- IID の λ 重み帳簿 ΔV = A V^0.44 − B V^0.61 の平衡は V* = (A/B)^{1/0.17}。ABAB が堆積・侵食の係数を k_D・k_E 倍するなら **σ*_AB = 92 (k_D/k_E)^{1/0.34}**: 0.5 → 12・0.66 → 27・0.8 → 48・0.9 → 68・1.0 → 92・1.1 → 122。急峻で、堆積の減少だけでは水準が決まらない。
- 「課題 1 の大きさの解に毎回戻り、収束後に 1.65 倍」なら σ ≈ 12.3 × 1.65 = **20.3** で止まる（増幅は戻った解に掛け直す。前の課題の端点に複利で掛けると 12.3 × 1.65^t で t50 に 9×10¹¹ になり定常の読みと両立しない）。ただし 12.3 は層全体の中央値で top だけの値ではない。mid1（IID 分散の 40%）が後期水準のままなら σ₅₀ ≈ √(0.55·20.3² + 0.45·82.5²) = **57.4**。**mid1 を top と同じ丁寧さで測る。**

## 7. 切替の衝撃（Q4）: 逆向きの衝撃は逆符号の ΔN を意味しない

A→B の衝撃を δ、B→A を −δ とすると ΔN_{A→B} + ΔN_{B→A} = 2‖δ‖² − 2⟨B − A, δ⟩ で打ち消す理由が無い。等ノルムの端点で δ = h(B − A) なら **両方の切替で ΔN = −h(1−h)‖B − A‖²**（0<h<1 で両方侵食、h>1 で両方増）。h は与えた事実から決まらないので、「+8,098 と −8,098」も「−2,800 と +2,800」も交互から導けない。判別は A→A の端点変位と、同じ checkpoint からの A 対 fresh C の fork。

## 9. Snake（Q6）

IID の top コサイン 0.41 は「別ラベル間の置換」で、A 再訪のコサインを予言しない。W1 凍結で 5/5 は「再利用できる特徴地図」の可能性を支持する。3 本を分けて置く: (1) IID 並みの書き直しなら幅は平衡 **≈36** のまま、(2) 固定サイズの解を再利用なら 12.2/0.59 = **20.7**、(3) 部分再利用なら決まらない。mid2 の経験則 ΔN = A − BN^1.16 は安定固定点を持つ（線形 OU ではなく非線形）。**leaky の則 ΔN = AN^0.19 − BN^0.48 にも形式的な固定点があり**、後期 mid2 で N* = 30,847(1337/645)^{1/0.29} ≈ **381,000**・局所緩和 ≈ 609 課題。言えるのは「Snake の平衡は近く強い、leaky の平衡は 50 課題の窓の遥か外」で、「leaky には定常が無い」ではない。

3 列が食い違う → **1 個のスカラー置換率ではない**（[[PC別帳簿_消し込みの目盛りは順位に線形で緩和ではない_事後_0923]] と同じ結論を別経路で）。ラグ 1 だけの消去 2ρd は実測 |e| を各帯で約 3 倍過小（top 239 対 728・mid1 397 対 1,749・mid2 214 対 645・low 29 対 53）、r_{6:50} のラグ 1 予測 (0.69, 0.82, 0.84, 0.88) 対 実測 (0.105, 0.363, 0.623, 0.812) で、欠けている高次ラグの和は (−0.29, −0.23, −0.11, −0.04)。ただし f_t = c/t・S 一定でも dN/dt = S − (2c/t)N から N ~ S t/(1+2c) と線形になるので、**「平坦化が無い」は fresh 堆積と時間依存の復元を区別しない。** 先の線形化定理 E⟨θ, δθ⟩ = −η‖Jθ‖² は二乗損失の話で、CE では期待勾配が J^T(p − 1/10) になり Adam の前処理も乗るので、−1/2 は自動には従わない。

## 11. 走の設計（Q8、Codex 案）

1. leaky ABAB-full 50 課題 × 3 paired seed（既存 IID と seed・初期化・入力・第 1 ラベルを揃える。ミニバッチ乱数は継続）
2. 同 ABAB-stop × 3 seed（full の約 1/10 の更新。静穏・一撃が本当に無いことを確認する）

## 12. 私の読み（Codex の外）

1. **IID から ABAB は演繹できない**、が答えの形。理由は 3 つの機関（ラベル差の伸び縮み・fresh な書き込み・Adam の動径成分）が IID では同じ足跡（負のラグ 1・線形の N）を残すから。
2. **遅い帯の成長について ABAB が分けるのは 3 択**（§5 の枠）: 有界（増分がラベルの差の形）／IID と同じ（fresh）／IID より速い（増分が現ラベルの関数で足し算になる）。私が §7 で書いた「交互にすれば二乗の足し算が消える」は 3 択の 1 つを決め打ちしていた。PMNIST の 0.66 は 2 番目と 1 番目の間で、入力の張る空間が回る箱の値。
3. **Adam だけの帰無（83k–124k）が IID の端点（76k）に届く**のは、切替と当てはめの侵食（−2,060/課題 at t50）を落としたから。この帰無は N ∝ t² で線形則を出せないので、線形則にはラベル駆動の侵食が要る。ABAB で侵食が減れば、Adam の drift ∝ ‖W‖ が剥き出しになって IID より速く伸びる枝があり、これは M-ADAM の予測として走で見える（静穏期 ΔN が √N 則で 2.2–3.7k/課題）。
4. 走るなら Codex の段階案の 1（ABAB-full × 3 seed）と fork（A 対 fresh C）だけで枝は決まる。stop 版と Snake は枝が決まってから。
