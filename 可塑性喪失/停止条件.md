## 論点

下向きの力は condA では常に働いており（[[ロギング走の結果]] E1: self 成分は 10 seed × 20,901 記録点で一度も正にならない、符号安定率 1.000）、その上 −側だけがゲート閉鎖で吸収的なので、素朴には堆積が止まらず全滅するはずだが、実測の dead_frac は 0.87–0.99 で止まる。**「なぜ死ぬか」は機構があるが「なぜ止まるか」には理論が無い。** 8/20 の blindspot pass で顕在化した穴（盲点4）。

> **8/20 夕の訂正（枠組みの前提）**: 本ファイルはもともと「税（自己項）が全ユニットに課され片側しか向かないから素朴には全滅する」という形で問いを立てていたが、**税＝駆動という前提は撤回された**（[[中和と境界窓]]、[[命題リスト]] Q2b）。税はフィット中 99.5% 中和され正味を運ばない。
> **問い自体は消えない**が、正しい形は「**駆動（rest）が下向きに偏り続け、罠が片側だけ吸収的なのに、なぜ堆積が止まるのか**」。税はむしろ**罠の吸収性そのもの**（死領域で勾配が開集合上で恒等ゼロ）を担う側にいるので、「税の普遍性から全滅が出る」という論法は使えない。
> 下記 teachw_0820 の判定はこの訂正に影響されない（教師複雑度に対する生存者数の感応を測っただけなので）。

## 確定したこと（teachw_0820）

教師 LTU 幅 H_T ∈ {1,2,4,8,32,100} × seed 10、入力ストリームは全アームでビット同一（S2 PASS）、H_T=100 は ratchet_log と厳密一致（S3 PASS）。**`H_T` は教師 LTU の幅（config の `target_hidden`）で、学習器の幅 `w100` とは別物** → [[用語と記号]] §4。

- **事前登録 P1 FAIL**（キルライン発火）: 傾き −5.755 [−7.615, −3.930]、per-seed Spearman ρ 中央値 −0.629。予言は正の単調増加なので符号が逆
- → **「生存者数＝タスクを表現するのに必要なユニット数」（役立ち説の複雑度予言）は棄却**
- **事後層別（判定外・ラベル必須）**: 低 H に損失スケール交絡（S4' の flip 平均 Var 比 H1 0.327 / H2 0.509 / H4–100 0.913–1.150）。スケール整合層 H∈{4,8,32,100} に限ると **傾き −0.0181 [−0.379, +0.309] のタイトな null**
- 同区間で**未フィット率（残差/信号分散、無次元）は中央値 0.0038 → 0.211（約56倍）**、傾き +0.0389 [+0.019, +0.060]。alive の paired 差は −0.20 [−2.40, +1.60]

→ 対立側（罠幾何説 / H_marg 系）の予言「入力統計が固定なら生存者数は教師複雑度に非感応」が、棄却ではなく**積極的に支持**された。**需要が増えても動員は起きない。**

### 予算不足説の排除（事後・本チャットで確認）

1. condA は教師関数が 1M step 通じて固定。1タスク内サポートは 32 パターンで各約312回提示。到達しうる入力は全体で高々3千点に対し 1M サンプル
2. t=100k では全レベルが高精度フィット（未フィット率 H4 0.0027 / H100 0.0005）。**一度は解けており、その後で失われている**
3. 未フィット率は時間とともに**上昇**（H100: 0.0005 → 0.255）。予算不足なら下降するはず

### T4 傍証（別枠・交絡つき）

H_T ∈ {1,2} は alive 中央値 46 / 42 と高く、損失 plateau がほぼ 0（4.7e-05 / 3.2e-05 ＝ ほぼ完全フィット）。「堆積には未フィット残差の持続が必要」と整合。ただし損失スケール交絡を持つので P1 の判定には混ぜない。

## 残る候補（未判別）

- **(a) 罠幾何説**: 動く罠の共通部分に落ちなかった者だけが残る。生存者数は入力統計と消灯点で決まる定数 → [[整流モデル]] の吸収帯、`blindspot_0820.md` §5
- **(b) 低次成分の稼ぎ説**: 生存者は稼いでいるが、稼ぎ先は教師複雑度に依存しない成分（µ 方向・定数項まわり）のみ。これなら「稼ぎ説なのに H 非感応」が両立する（役立ち説の弱い変種として生き残っている）

判別は `spec_surv_hist_0820.md` の T1（alive の p̂ 中央値）× T2（窓 [700k,1M] の持続性）の2票決定行列。**再学習なし**（ratchet_log の保存 npz のみ）。

## 訂正（8/20）

**「生存者は 8.5% で止まる」は誤り。** alive の時系列は 1M でも下げ止まっていない（700k→1M の中央値変化: H1 −9、H2 −13、H4 −6、H8/H32/H100 は −1〜−2 でほぼ横ばい）。正しくは「1M 時点のスナップショット」。**「停止条件」という枠組み自体が正しいかも未確定**で、surv_hist の T2 がこれを兼ねる。
