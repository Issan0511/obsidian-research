## 0. 一行

**今日の 4 箱で「mobility が 0.55〜0.82 の帯にある Snake だけが leaky に勝つ」が一貫したが、その帯に入る α は箱で 5 倍動く（SGD 1.0・Adam 0.2）。** α を人が選ぶ代わりに **α_i = c / W_i**（W_i = ユニット i の前活性の走行 sd）で走行中に決めると、(Q1) 箱を替えても帯に落ちるか、(Q2) 帯に落ちた腕は勝ち・落ちない腕は負けるか（＝帯は原因か）、(Q3) leaky に勝つか、(Q4) 重み空間の既存介入に対してどこに立つか — を 1 走で判定する。

**動機**: Issa の裁定（9/5）「α の選定が余りにも難しいのが致命的な難点。それが解けたら優良ではないか」。今日の相関は「α は自由パラメータではなく W の従属変数」と読める。**その読みが正しければ α は測って決められ、難点は消える。** 正しくなければ、帯は結果であって原因ではない。

### 1.1 先に書いておく危険

1. **W_i の推定が batch 16 では粗い。** EMA で平滑化しても α_i がジッタし、ゲート構造が滲む可能性。→ β を登録し、α_i の時系列を記録する
2. **W は α に依存する**ので α_i = c/W_i は不動点問題。α↓ → W↑ → α↓↓ と暴走するか、収束するか。→ clip を置き、clip に当たった割合を記録する。α↓ で W↑ は負帰還ではなく正帰還なので暴走の可能性は実在する
3. **c の値が箱に依存したら Q1 の答えは否。** c は 1 つだけ登録し（0.6）、感度は REPORT_ONLY
4. **適応 α は「純粋な活性化」ではない**（§2.1 の階級 B）。Issa の「既存手法は内部をいじっていてずるい」に対して、これも走行統計を持つ点で BatchNorm 相当の機械である。**階級を跨ぐ比較には必ず階級を併記する**

## 2. 何を測るか

### 2.1 介入の階級（登録・Issa の指摘を制度化する）

| 階級 | 中身 | 腕 | 触るもの |
|---|---|---|---|
| **A** 活性化のみ | φ を差し替えるだけ。状態なし | `R` `LR` `LIN` `SN1` `SN02` `SN3` | 何も |
| **B** 活性化＋走行統計 | φ が前活性の走行統計を参照する。BatchNorm と同じ階級の機械 | **`SNA`** | 前活性の統計（勾配は流さない） |

### 2.2 `SNA`（適応 α Snake・登録）

各隠れユニット i について:
- 走行分散 `V_i ← (1−β)·V_i + β·var_batch(z_i)`、**β = 0.01**（時定数 100 step ≈ タスクの 1/6）。初期値 `V_i = 1`
- `W_i = sqrt(V_i)`、**`α_i = clip(c / W_i, 0.05, 3.0)`**、**c = 0.6**（勝った腕の 2αW が 0.57〜1.9 に散っていたので中央 1.2 → c = 0.6）
- `φ(z_i) = z_i + sin²(α_i z_i) / α_i`。**α_i は detach**（BN の running stats と同じ扱い）。評価時も走行値を使う
- 記録: タスクごとに `α_i` の中央値・min・max・clip に当たった割合、`2 α_i W_i` の中央値

### 2.3 箱（2 つ・両方で回す。箱非依存性が Q1 の本体）

| 箱 | 最適化器 | lr | epoch/タスク | step/タスク | 由来 |
|---|---|---|---|---|---|
| **A** | Adam(0.9, 0.999, 1e-8)・moment はタスク跨ぎで保持 | 0.001 | 1 | 625 | Lillo & Cheney と同一・先生の「低 lr が実世界」 |
| **B** | 素の SGD | 0.02 | 4 | 2,500 | 非線形性のレンジが開く箱（1 epoch は半分に潰す） |

共通: 784–100–100–10・batch 16・1 タスク 10,000 例・200 タスク・seed 0–9・重み/moment はリセットしない。**lr は箱内で全腕共通**（腕別較正はしない。今日の交絡の教訓）。

## 3. 登録判定

評価窓 = タスク 151–200 の平均 test 精度。seed 対応・符号検定（n=10・両側）＋対応差の平均±SE を併記。**mobility は第 1 層・窓 151–200 の 10 seed 中央値。「帯」= [0.50, 0.85]。**

### 3.1 Q1 — α は自分で決まるか

| 条件 | ラベル |
|---|---|
| `SNA` の mobility が**両箱で**帯内、かつ clip に当たった割合が両箱で 5% 未満 | **`ALPHA_SELF_SETS`** |
| 片方の箱だけ帯内 | `ALPHA_BOX_DEPENDENT` |
| どちらも帯外、または clip 率 ≥ 5% | `ALPHA_NOT_SELF_SETTING`（暴走か推定不良。§1.1-2） |

### 3.2 Q2 — 帯は原因か（主判定・機構）

各箱で、`SNA` 対「帯外の固定 α」（箱 A: `SN1`・箱 B: `SN3`）と、`SNA` 対「帯内の固定 α」（箱 A: `SN02`・箱 B: `SN1`）:

| 条件 | ラベル |
|---|---|
| 両箱で `SNA` > 帯外固定（9/10・p<0.05）**かつ** `SNA` と帯内固定に有意差なし | **`GATE_BAND_CAUSAL_SUPPORTED`**（帯に入れれば α の値は問わない） |
| 両箱で `SNA` > 帯外固定、だが片箱以上で `SNA` < 帯内固定（有意） | `ADAPTIVE_COSTS`（帯は効くが追随に代償がある） |
| 片箱以上で `SNA` ≤ 帯外固定 | `GATE_BAND_NOT_CAUSAL`（帯は結果であって原因ではない） |

### 3.3 Q3 — leaky に勝つか（Issa の元の予測の再判定）

| 条件 | ラベル |
|---|---|
| 両箱で `SNA` > `LR`（9/10・p<0.05） | **`SNAKE_RETAINS_BETTER_BOTH`** |
| 片箱のみ | `SNAKE_RETAINS_BETTER_ONE`（どの箱かを併記） |
| どちらも有意でない／負け | `SNAKE_NOT_BETTER` |

### 3.4 Q4 — 重み空間介入に対する位置（階級 B 対 C）

各箱で `SNA` 対 `R+l2init`・`R+cbp`:

| 条件 | ラベル |
|---|---|
| 両手法に 9/10 で勝つ | `B_ABOVE_C` |
| 少なくとも 1 手法と有意差なし、負けなし | `B_WITHIN_C` |
| 少なくとも 1 手法に 9/10 で負ける | `B_BELOW_C` |

**書き方**: 「`SNA` は l2init に並んだ」は可、「活性化だけで l2init に並んだ」は不可（`SNA` は階級 B）。

### 3.5 REPORT_ONLY

## 4. 検査

- **S-ema-off**: `SNA` を β=0・V_i=1 で回すと、固定 α=0.6 の Snake と `per_task.csv` が **bit 一致**（適応機構を切ると通常の Snake に退化することの確認）
- **S-act**: ユニット別 α_i を持つ φ の φ′ を autograd と照合（相対 `allclose(atol=0)` は \|φ′\|>1e−9 で、絶対は 4·eps。零点は格子に明示的に入れる）
- **S-detach**: α_i に勾配が流れていないことを `requires_grad` と grad の None で確認
- **S-clip**: α_i の min/max がタスクごとに [0.05, 3.0] 内。clip 率を記録
- **S-repro**: 既知の 6 腕（`R` `LR` `LIN` `SN1` `SN02` `SN3`）の箱 A・seed 0 が `_diag_adam_0905` / `_diag_alpha_adam_0905` の同 seed と **bit 一致**（宿主の版が変わっていないこと）
- **S-init / S-perm / S-data**: [[PermutedMNIST_spec_0905]] §7 を継承
- **S-div**: 非有限で腕を落とす。step・seed を記録
- **S-cost**: 箱 A ≈ 80 run × 60 s、箱 B ≈ 80 run × 190 s。3 並列で合計 2 時間前後（見積もり・実測を §8 に）
