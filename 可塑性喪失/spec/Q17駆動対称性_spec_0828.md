## 0. 生成式から先に固定する

`src/ratchet_log.py` の生成式は

```python
pref   = -2.0 * lr[:, None] * v
F_rest = pref * (d_rest * gate * xdm).mean(dim=0)
```

である。ここで

\[
h_i:=E[\delta_{rest,i}\,gate_i\,(x\cdot\hat\mu)]
\]

とおけば

\[
F_{rest,i}=-2\eta v_i h_i
\]

が恒等的に成立する。`v_i≠0`、`F_rest≠0` では

\[
\operatorname{sign}(h_i)
=-\operatorname{sign}(v_i)\operatorname{sign}(F_{rest,i})
\]

なので、`h` の符号は除算せず保存列 `v,F_rest` だけから厳密に復元できる。

`q_c:=P(F_rest<0 | camp=c,F_rest≠0)`、`p_c:=P(h>0 | camp=c,F_rest≠0)` とすると

\[
q_+=p_+,\qquad q_-=1-p_-.
\]

したがって

\[
q_+-q_-=p_++p_--1
\]

は**両陣営に共通する `h` の符号偏り**であり、

\[
p_+-p_-=q_++q_--1
\]

が**`h` の真の陣営差**である。初稿はこの二つを取り違えていた。

さらに `d_rest=δ-v_i a_i` なので

\[
h_i=E[\delta\,gate_i\,(x\cdot\hat\mu)]
-v_iE[a_i\,gate_i\,(x\cdot\hat\mu)].
\]

condA std では `x·mu_hat>=0`。第二項は camp ごとに逆向きへずれうるため、共通偏りだけでは陣営差を判定できない。二つを別測度にする。

## 1. 問いと三つの主測度

### 1.1 問い

condA・w100・T=10,000・batch=1 の `ratchet_log_0819` において、ゲート後ユニット別 `rest` 駆動は

1. 潜在符号 `sign(h)` が各陣営内で 50:50 に近いか
2. `sign(h)` の分布が陣営間で同じか
3. 大きさ込みの `h` 空間正味比が各陣営でゼロに近く、陣営間でも同じか

を判定する。死亡個体・alive 個体には限定せず、全ユニット・全該当記録点を対象にする。

### 1.2 Q17-W — `h` の陣営内方向バランス

時間領域 `D`、seed `s`、陣営 `c` ごとに

\[
p_{s,c,D}
=P(h>0\mid camp=c,F_{rest}\ne0)
\]

を作る。実装は

```text
h_sign = -sign(v_current) * sign(F_rest_current)
```

で行い、`h` を数値除算で復元しない。

各陣営で `p=0.5` が対称点である。

### 1.3 Q17-B — `h` の真の陣営間差

seed 内対応差を

\[
B_{s,D}=p_{s,+,D}-p_{s,-,D}
=q_{s,+,D}+q_{s,-,D}-1
\]

とする。**差を seed 内で先に作る。** 別々の欠測集合から二つの全体平均を引かない。

初稿の

\[
C_{s,D}:=q_{s,+,D}-q_{s,-,D}
=p_{s,+,D}+p_{s,-,D}-1
\]

は「共通 `h` 符号偏り」と改名し、登録副次量として残す。Q17-B とは呼ばない。

### 1.4 Q17-N — 大きさ込み `h` 正味比

まず seed・陣営・領域ごとに、生の物理方向の正味比

\[
N_{s,c,D}
=
\frac{\sum F_{rest}}{\sum |F_{rest}|}
\in[-1,1]
\]

を作る。`N=0` が x 方向の正味ゼロ、負が下向き、正が上向きである。

ただし `F_rest=-2ηv h` なので、生の `N_c` を陣営間でそのまま引いてはならない。`c=sign(v)∈{+1,-1}` として

\[
M_{s,c,D}:=-cN_{s,c,D}
=
\frac{\sum 2\eta |v|h}{\sum 2\eta |v||h|}
\in[-1,1]
\]

を定義する。`M_c` は保存列だけで作れる、`2η|v|` 重み付きの `h` 空間正味比である。符号頻度が 50:50 のまま一方向だけ大きい場合を検出する。

真の陣営差は同じ seed 内で

\[
B^M_{s,D}:=M_{s,+,D}-M_{s,-,D}
=-(N_{s,+,D}+N_{s,-,D})
\]

とする。一方、旧案の

\[
\Delta N_{s,D}:=N_{s,+,D}-N_{s,-,D}
=-2A^M_{s,D},
\qquad
A^M_{s,D}:=\frac{M_{s,+,D}+M_{s,-,D}}{2}
\]

は陣営差ではなく、両陣営に共通する `h` の大きさ込みコヒーレンスである。`N_+`,`N_-`,`ΔN`,`A^M` は登録記述量として残すが、Q17-N の主対象は `M_+`,`M_-`,`B^M` とする。差は seed 内で先に作る。

### 1.5 zero は判定から外す

\[
z_{s,c,D}=P(F_{rest}=0\mid camp=c)
\]

は報告するが、総合判定に使わない。`p_hat=0` では `F_rest=0` が恒等的であり、strict-off 後は `v` も凍結するため、`z_c` は主として陣営別の死の累積を測る。これは非対称な拘束側の予言であって、駆動非対称の反証にしてはならない。

## 2. 等価域

### 2.1 符号確率

確率と確率差の意味幅を 5 percentage point に固定する。

- Q17-W: 各陣営の `p` の等価域 `[0.45,0.55]`
- Q17-B: `B=p_+-p_-` の等価域 `[-0.05,+0.05]`
- 副次 `C`: 記述だけ。同じ `[-0.05,+0.05]` を図示するが総合判定には追加しない

初稿の `q_+` / `q_-` に同じ帯を置く方法は採らない。生成式による符号反転を戻した `p_+` / `p_-` を同一尺度で判定する。

### 2.2 大きさ側の校正（未凍結・実行ブロッカー）

改訂1の

\[
\epsilon_{net}=0.10\times PE_{transport}=0.0375432
\]

は採用しない。D2 の `PE_transport` は `Δcos_u_mu`、輸送死・降下窓・`mu_hat` 固定ペアという結果選抜母集団、窓ごとの ratio の中央値である。一方 Q17-N は `F_rest`、全ユニット無条件、seed×陣営×領域の ratio of sums である。座標・推定量・母集団が違う。

より根本的に、コヒーレンス比は輸送効率であって輸送量ではない。`M=0.10×参照効率` だけでは、長い走行時間を積分した残差駆動が壁まで届かないことを保証しない。したがって、既報 D2 の10%を防衛命題の意味幅にする論拠はない。D3/E1 の力空間符号安定率も近い記述ではあるが、Q17 の答えに近い既知結果を見て帯を校正することになるため、本稿では許容幅に使わない。

#### 同次元比較案の識別可能性

候補量

\[
D_{rest,W}:=\sum_{t\in W}F_{rest}(t)
\]

は窓内の x 変位単位を持つ。しかし、これと比較すべきユニット別の「現在状態から strict-off 壁までの x 距離」は、現行 `ratchet_log_0819` npz から一意に復元できない。保存された `x,p_hat,w_norm,b,flip_state` だけでは full `W`、32パターンの preactivation、または直接計算した `d_off_x` がない。`p_hat` は発火パターン数であって距離ではない。

`pre_max` を追加しても、それ単独は preactivation 単位の余白であり一般には x 距離ではない。`w→w-d\hat\mu` の並進で各パターンの preactivation が変わる係数 `x_pattern·mu_hat` は同一でなく、bias と直交成分も実走行中に動く。したがって、比較するなら「何を固定した静的壁距離か」を先に定義し、full state から `d_off_x` を直接保存または再計算する必要がある。

観測された初回 `p_hat=0` の `x` を事後的な壁位置にする方法も主判定には使わない。これは消灯した個体だけを未来結果で選ぶため、全ユニット無条件という Q17 の母集団を壊し、粗い窓外グリッドでは初回消灯時刻も区間打切りになる。

さらに npz は境界窓外が gap 900/1000 なので、走行全体の `ΣF_rest` も直接は積分できない。窓内平均力×走行長はオーダー外挿であり、独立の厳密判定にはしない。

以上から改訂2では `epsilon_M` を数値化しない。Q17-N の推定量 `M_+`,`M_-`,`B^M` は先に登録するが、等価判定は停止する。凍結には次のどちらかを別レビューで選ぶ必要がある。

1. 現行 npz のまま、走行長と輸送時間から導いた外部的な `epsilon_M` を事前登録し、コヒーレンスについてだけ限定主張する。
2. deterministic replay / 再計測で、操作的に定義した `d_off_x` と十分な時間解像度の `D_rest` を保存し、同次元の輸送量判定へ置換する。

いずれの場合も Q17 の値を見てから帯を決めない。現段階では Q17-N および総合判定は **`DESIGN_BLOCKED_NET_MARGIN`** とする。

## 4. 局所判定と総合判定

領域ごとの各測度を次で分類する。

|---|---|---|---|
| Q17-W | `p_+` と `p_-` の 95% CI がともに `[0.45,0.55]` 内 | いずれかの CI 全体が `<0.45` または `>0.55` | `INCONCLUSIVE` |

改訂2では `epsilon_M` が未凍結なので、この表の Q17-N 行と以下の総合判定はまだ発火させない。現状ラベルは `DESIGN_BLOCKED_NET_MARGIN` であり、sanity-only を含め解析を走らせない。

`epsilon_M` または同次元基準を凍結した後の総合判定の優先順位:

1. sanity・標本ガード落ち → **`INCONCLUSIVE_GUARD`**
2. CI 精度ガード落ち → **`INCONCLUSIVE_PRECISION`**
3. FULL・PRE・POST のどこか一つでも `MATERIAL` → **`MATERIAL_REST_ASYMMETRY`**
4. 3領域×3測度族がすべて `EQUIV` → **`SYMMETRIC_REST_DRIVE`**
5. それ以外 → **`INCONCLUSIVE_REST_SYMMETRY`**

FULL だけが EQUIV で PRE/POST が未解像なら SYMMETRIC にしない。

## 7. Sanity gate

以下のいずれかが落ちたら主判定を出さない。

### S1. 入力とグリッド

- 10 seed、各20,901点
- 必須列・shape・dtype・有限性が一致
- gap分布が確定構造と一致

### S2. 境界

- `(diff(flip_state)!=0).any(axis=1)` で各seed 99境界
- 左端 `B` が `(B%10000==0)&(gap==1)&(B>0)` と完全一致
- FULL/PRE/POST/EDGE の行数が§5と一致
- PRE、POST、EDGEが排他的で、その和がFULL

### S3. 行キー

- `(seed,B,r,unit)` が領域内で一意
- `r`集合が定義どおり
- 全unitが `0..99`

### S4. 力の分解

保存列をfloat64へ上げ、全対象行で

```python
rtol = 8 * np.finfo(np.float32).eps
atol = 8 * np.finfo(np.float32).tiny
abs(F_gate-F_self-F_rest) <= (
    atol + rtol*(abs(F_gate)+abs(F_self)+abs(F_rest))
)
```

を要求する。

### S5. 恒等式の保存確認

- campのpositive/negative/zeroが全行を排他的に分割
- `F_rest`のup/down/zeroが全行を排他的に分割
- `v==0 => F_rest==0`
- `p_hat==0 => F_gate==F_self==F_rest==0`

S5 は生成式の恒等式であり、ファイル破損・配列ずれ検出だけに使う。科学的証拠に数えない。

### S6. 代数の実装確認

非ゼロ行で

```text
h_sign == -sign(v)*sign(F_rest)
p_plus == q_plus
p_minus == 1-q_minus
B == q_plus+q_minus-1
C == q_plus-q_minus
M_plus == -N_plus
M_minus == +N_minus
B_M == M_plus-M_minus == -(N_plus+N_minus)
A_M == (M_plus+M_minus)/2 == -(N_plus-N_minus)/2
```

を機械照合する。浮動小数の比については同じ集約済み分子・分母から両辺を作り、S4 と同じ相対・絶対 tolerance で照合する。

### S7. スコープ検査

主判定に `delta_x`、alive/dead、死亡経路、ゲート抜き `G` を含めていないことを列名で検査する。Q17-N の対象は常に `F_rest`。`F_gate/F_self` は provenance、S4、フレーム帳簿の記述にのみ許可する。

## 8. 登録副次量

判定を増やさず次を報告する。

- `C=(p_++p_-)-1=q_+-q_-`: 共通`h`符号偏り
- `A^M=(M_++M_-)/2=-ΔN/2`: 共通`h`大きさ込みコヒーレンス
- 生の `N_+`,`N_-`,`ΔN`: 物理的 x 方向の記述。`ΔN` を陣営差とは呼ばない
- seed・領域・陣営ごとの `N_up/N_down/N_zero/N_vzero`
- `z_c` と `Δz`（判定なし）
- zeroに占める `p_hat==0` の割合
- 境界index四分位 `1–25/26–50/51–75/76–99` ごとの `z_c`（死の累積確認、判定なし）
- camp構成割合
- 窓内 `D_rest,W=ΣF_rest` と `mean(F_rest)`（走行全体へ外挿しない）
- EDGE単独の符号割合・`N`・`M`（CI・判定なし）

`|F_rest|` の分位点は Q17-N の補助として報告してよいが、結果を見て新しい閾値や群を作らない。

## 9. フレーム上の割り当てと解釈上限

### 9.1 三項の割り当て

\[
F_{gate}=F_{self}+F_{rest}.
\]

本 spec では

- `F_rest`: 撹拌／駆動の候補
- `F_self<=0`: 系統的な自己減衰（税）。**撹拌には入れず、拘束・減衰側の帳簿に置く**
- `p_hat=0` の片側消灯: 非対称な移動度拘束

と割り当てる。

したがって実際のフレームは厳密な二要素ではなく

> ほぼ対称な rest 駆動 ＋ 系統的な自己減衰 × 非対称な移動度拘束

の三項である。短縮して「対称な撹拌×非対称な拘束」と呼ぶ場合も、self税を拘束側へ含めた略記だと明記する。

Q17 は `F_rest` の対称性だけを判定する。self税が輸送に必要か、罠だけが非対称の原因か、という因果的必要性は Q2b/Q3 の証拠と合わせても本 spec 単独では確定しない。

### 9.2 `SYMMETRIC_REST_DRIVE` のとき言えること

このラベルは§2.2の大きさ基準を別レビューで凍結した後にだけ使用する。

> condA・w100の境界前後窓では、`h` の符号頻度は各陣営で50:50の5pt等価域に入り、陣営差も5pt以内だった。`h` 空間の大きさ込み正味比 `M` も、各陣営と陣営差 `B^M` の全てで登録した意味幅以内だった。

これは符号だけでなく、**凍結後の大きさ基準が支える範囲に限って** rest の正味駆動が小さいことを防衛する。コヒーレンス基準を選んだ場合は輸送量や到達不能性までは主張しない。

### 9.3 `MATERIAL_REST_ASYMMETRY` のとき

「対称なrest駆動」とは書かない。どの領域・どの測度が外れたかを明記し、結果を見て `epsilon_M` や確率帯を広げない。

### 9.4 常に言えないこと

- `F_rest` の全分布・分散が完全に対称
- `F_gate` や `Δx` が対称
- 正味の非対称の原因が罠だけであるという排他的因果帰属
- Q3 と本結果だけで状態分布の非対称が全て導けること
- bulk、condB、centered、別width/T/optimizerへの外挿
- Q17-N と変位PEが同一の物理量であること
- 現行npzだけからユニット別の strict-off 壁までの x 距離が復元できること
- 境界窓の平均力を10^6 stepへ外挿した値が実走行積分と等しいこと
