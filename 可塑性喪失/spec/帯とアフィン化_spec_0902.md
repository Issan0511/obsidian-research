### 0-2. 記号

[[到達と離脱_統合主張_0903]] §0 に従う。3 分類は $\hat p$ だけで尽きる: **沈下** $\hat p=0$（$\max_x z\le0$ と同値）／**帯** $0<\hat p<1$（`near_off` $=1/32$ は帯の内側）／**浮上** $\hat p=1$（$\min_x z>0$ と同値）。「浮上」「帯」は新語で、採用されるなら [[用語と記号]] に足す（P1 の後・同 §0-3）。

### 0-3. 実装で確定したこと（`src/elu_swamp.py` の `exact_layer_record_elu`）

```python
X = full_support_ro(st["env"])          # 32 点の厳密サポート
z = einsum(W, cur) + b                  # cur は centered_layers なら中心化後
p_hat = (z > 0).double().mean(dim=0)    # パターン軸の平均
submerged_unit = z.amax(dim=0) <= 0
submerge_mismatch = int((submerged_unit != (p_hat == 0)).sum())
```

- $\hat p$ は 32 点の厳密サポート上の開口頻度。**`p_hat` は `LOG_UNIT_KEYS`（`src/mlp2_phase0.py`）に入っており、8 月以降の全走・全腕・全記録点にある**（§10-5 の「要確認」への答え）
- 「沈下 $\iff\hat p=0$」は `elu_swamp` の登録サニティ（`submerge_mismatch`）と `gate_dial_0902` の `submerged_equals_strict_dead` の 2 経路で検査済み。同じ経路から浮上 $\hat p=1\iff\min_x z>0$ も厳密に出る
- `centered_layers` が立つ層では中心化後の $z$。`gate_dial_0902` は全腕 `centered_layers: [1]` なので `layer1_zmax`・`layer1_zmean` と同じ座標系

## 1. 代数（→ [[到達と離脱_統合主張_0903]] §2-1・§2-5）

補題（1 層・線形読み出し・二乗損失: サポート上でアフィンなユニットは非線形残差 $\delta_{\rm nl}$ に応答しない）と、その 3 つの帰結（死と線形化は同じ種類の容量喪失／ELU の沈下だけ $O(e^{\max_x z})$ で応答／浮上の力学は活性化非依存）は統合主張ノートに置いた。本 spec で使う当てはめだけを再掲する。

| 状態              | ReLU                         | leaky（$a$）                       | ELU（$\alpha$）                   | SiLU・GELU                         |
| --------------- | ---------------------------- | -------------------------------- | ------------------------------- | --------------------------------- |
| 浮上（$\hat p=1$）  | アフィン（$\gamma=1$）             | 同                                | 同                               | 厳密にはアフィンでない（深い正側で $\varphi\to z$） |
| 帯（$0<\hat p<1$） | アフィンでない                      | 同                                | 同                               | 同                                 |
| 沈下（$\hat p=0$）  | $\varphi=0$・アフィン（$\gamma=0$） | $\varphi=az$・厳密にアフィン（$\gamma=a$） | $\varphi=\alpha(e^z-1)$・アフィンでない | アフィンでない（谷の向こうで漸近的に 0）             |

**アフィン＝無害ではない**（$\delta$ 全体は動かせる）し、瞬時の主張である。**補題は 1 層限定で、多層では成り立たない。** 本 spec の対象走はすべて 1 層。

## 2. 動機（既存の committed 値・事後・未登録）

- **沈下率は族をまたいで水準を並べない**（[[現象3主張v1_0902]] §2-5）。帯率で並び直すかが問い。
- **$a$ を 4 桁振っても水準が動かない**（`results/gate_dial_0902/dial_table.csv`・`e94bf48`・2026-09-03 正本照合済み）: `R_1216` 沈下 0.9855・$\log_{10}U$ −0.275／`LR_a0p01` 0.9815・−0.406／`LR_a0p001` **0.9955**・**−0.071**／`LR_a0p0001` 0.9805・−0.247／`LR_a0p00001` 0.9865・−0.234。**$a$ には並ばず、最も沈下率が高い腕が最も悪い。** 4 点・事後・CI なし。
- **谷埋めは静的な読みでは説明できない**: GELU ダイヤル 1 の谷底は $z_c=-0.752$ で、`gelu_clamp` は深さ 0.75 より下のすべてをアフィンにする。静的には容量が減るはずが $U$ 1.0→0.30 と良くなった。逃げ道は clamp 腕の帯率が上がっていること。走なしで確かめられる（§4 の D。**ただし §5-0 の白状を参照**）。

## 6. これが決まると何が動くか

- **P1 が語彙を決める**（[[到達と離脱_統合主張_0903]] §1-3）: 当たれば 3 状態（浮上 E・帯 S・沈下 D）へ、外れれば 2 軸のまま。**なお 2 層・中心化での浮上は [[現象2主張v1_0901]] C3 に既にある**（alive のゲートマージン中央値 +11.40・常時発火 68%）。P1 が問うのは無介入・1 層の本線。
- `BAND_IS_THE_ORDER_PARAMETER` なら §10-1 に代数と測定の両方が付き、§9.1 の「死なずに悪化した現象が手元に無い」に「浮上ユニットがその候補」と答えられる。新規性は「現象の発見」ではなく (a) 両側の統一 (b) 介入・厳密列挙による測定に置く。
- `BAND_IS_NOT_IT` なら §10-1 を閉じる。離脱の 4 型は状態量では説明できず、逃走のような動的過程が主。
- `SURFACED_UNITS_ABSENT` でも残る価値: (a) 死と線形化の統一（可動度と容量の分離）、(b) G の肩の人口、(c) F の $N_{\rm mask}$。
- **どちらでも [[ELU可動度の深さ座標_spec_0902]] の帰趨は変わらない。**

## 7. 引用上の注意

- 走ゼロ・新規ロガーゼロ。A〜E・G は `layer1_p_hat`（と `layer1_zmax`）のみ。F は ckpt。**H は本 spec でやらない**
- **`submerged_frac` を verdict に使わない規則（[[用語と記号]] §1）は帯率にも適用する。** 判定は順序と介入前後の差。$U$ は既存の committed 値
- 帯は二値だが容量は連続。$\hat p=1/32$ はランク 1 程度の容量。B（分布）を必ず併記
- §1 の補題は 1 層限定。§2 の数値はすべて事後・未登録。$\hat p$ は生の量（[[引用禁止]]「正規化量で力学を書かない」に抵触しない）
