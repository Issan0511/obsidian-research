## 2. 代数（→ [[到達と離脱_統合主張_0903]] §2-2）

**(a) 可動度の恒等式**（統合主張ノートに置いた）: ELU の沈下ユニットで
$$\max_x z_i-3.466\ \le\ \ln\frac{\mathbb E_x[\varphi'(z_i)]}{\alpha}\ \le\ \max_x z_i .$$
近似も仮定もない。$\max_x z_i$ は沈下の判定に既に使われている量。

**(b) 現行の定義には座標の不整合がある。** [[用語と記号]] §1 は沈下の判定を $\max_x z$ で、深さを $\bar z$ で測ると定めている。しかし ELU で勾配がどれだけ流れるかを決めるのは (a) のとおり $\max_x z$ の側。**判定と深さで別の座標を使っているのが指数の食い違いの源ではないか、というのが本 spec の問い。**（同じ区別は [[負に押す力の正体_0902]] §4 の「churn の再露出は $\max_x z$ ＝パターン水準の話で別」に既にある。）

**(c) 深さ依存が分解に依らないこと。** [[自己項の実在_力場_0902]] §3 のとおり $g_{b_i}=2v_i\,\varphi'(z_i)\,\bigl(v_i\varphi(z_i)+\delta_{{\rm rest},i}\bigr)$ で、$\varphi'$ は括弧の外にある。$w_i$ 側も同じ $\varphi'$ で重み付けされる。深い ELU では $\varphi\to-\alpha$（定数）なので括弧の中は深さに依らなくなる。**したがってタスク内増分の深さ依存はまるごと $\varphi'$ が担い、自己項と残差項の分け方に依らない。**

**(d) ただし (c) は測られていない。** §10-4 は「$v^2$ 比例は不成立」と報告しており、中和後に残る括弧の中身が深さに依らない保証は無い。**だから本 spec は「増分の指数が 1 か」を直接問わず、「増分の指数と可動度の対数の指数が同じ帯で一致するか」を問う**（§5 の P2）。一致すれば括弧の中は深さ非依存、ずれればその差が括弧の深さ依存になる。

## 3. 動機（committed 値からの事後計算・Kubo・未登録）

`results/gate_dial_0902/dial_table.csv` の `m_minus` と `depth_hist.csv` の `depth_median`（seed 中央値）から $\ln(m^-/\alpha)+$深さ を計算した。§2(a) によりこれは $\bar z$ 座標で測ったときのずれにあたる（出所: どちらも `provenance.json` の `git_hash` **`e94bf48`**。`E_1216` の `m_minus` 7.829e−3 と深さ 8.837 は 2026-09-03 に `p3_extend_0902/summary.md` の `depth_q50_5M` 8.837 とも整合）。

| 腕               | $\alpha$ | `m_minus` | 深さ中央値 | $\ln(m^-/\alpha)$ |       ずれ |
| --------------- | -------: | --------: | ----: | ----------------: | -------: |
| `E_1216`        |        1 |  7.829e−3 | 8.837 |            −4.850 | **3.99** |
| `E_a0p1_1216`   |      0.1 |  7.403e−4 | 6.872 |            −4.906 | **1.97** |
| `E_a0p01_1216`  |     0.01 |  1.142e−4 | 6.103 |            −4.472 | **1.63** |
| `E_a0p001_1216` |    0.001 |  1.859e−5 | 5.222 |            −3.985 | **1.24** |

**ずれは 1.2〜4.0 nat。実際の可動度は $\bar z$ の絵が予言する値の 3.4〜54 倍。** §2(a) の上界 3.466 とも整合する。4 腕で $\ln(m^-/\alpha)$ を $\bar z$ に回帰すると傾き **0.22**（最小二乗・$n$=4・腕をまたぐので $\alpha$ が交絡）。

**★ 増分の指数は走と窓を替えると大きく振れる。** 同じ `E_1216` の深さ帯を中点で割ると、[[現象3主張v1_0902]] C2（5M）では 2→4.5 で **0.37**・4.5→8 で 0.46、[[現象3_非ReLU戻り道の対応づけ_0902]] §10-4（15M プール）では **0.98**・0.50・0.66（8→12）。**同じ量が 0.37〜0.98 に振れる。** これが §5 の許容帯 0.3 の根拠。

**ここまではすべて事後・未登録で、判定には使わない。**

## 4. 測ること（走なし・再集計）

必要な列はすべて既存ログにある（`src/gate_dial_0902.py` の `unit_extra_record`: `layer1_zmax`・`layer1_zmean`・`layer1_mob`・`layer1_v_unit`・`layer1_p_hat`・`flip_state`・`step`）。

沈下ユニット（`zmax` ≤ 0）を拾い、**タスク内**（同一タスクかつ `flip_state` 不変）の $\bar z$ 増分を 1000 step あたりで取る —— ここまでは [[現象3_非ReLU戻り道の対応づけ_0902]] §10-4 の集計を逐語継承する。切る座標だけを替える。

| ID    | 出すもの                                                                           |
| ----- | ------------------------------------------------------------------------------ |
| **A** | `zmax` の帯で切った**増分**の中央値と、帯の中点での局所指数                                            |
| **B** | **同じ帯**で切った **$\ln(\text{可動度}/\alpha)$** の中央値と、その局所指数                          |
| **C** | $\bar z$ の帯で切った同じ 2 つ（§3 の再現）                                                  |
| **D** | 全記録・全沈下ユニットで $\ln(\text{可動度}/\alpha)-\mathrm{zmax}$（§2(a) の帯 $[-3.466,0]$ の検査） |
| **E** | 副次: 沈下ユニットの $\lvert v_i\rvert$ と深さの Spearman（**符号のみ**）                         |

**腕**: ELU 4 腕（`E_1216`・`E_a0p1_1216`・`E_a0p01_1216`・`E_a0p001_1216`）。**対照に leaky 3 腕**（`LR_1216`・`LR_a0p01_1216`・`LR_a0p001_1216`）を同じ配管に通す —— leaky の沈下ユニットは可動度が定数 $a$ なので、**同じ配管が B で指数 0 を返さなければ配管の側が壊れている**（S 検査）。

**窓**: 既存の集計と同じ。`E_1216`・`LR_1216` は `p3_extend_0902` の 15M があればそちらも。**§3 のとおり走と窓で指数が振れるので、A・B・C は必ず同一の走・同一の窓・同一の帯で取ること。**

## 5. 事前予測と判定（**Kubo 単独・再集計の前に固定**）

| #          | 予測                                                                                          |
| ---------- | ------------------------------------------------------------------------------------------- |
| **P1**     | **D**: $\ln(\text{可動度}/\alpha)-\mathrm{zmax}$ が**全記録で** $[-3.466,\ 0]$ に入る（恒等式なので外れたら配管か実装） |
| **P2**     | **A と B**: `zmax` 座標で、各帯において**増分の局所指数と可動度の局所指数が同符号**であり、かつ**点推定の差が 0.3 以内**                 |
| **P3**     | **C**: $\bar z$ 座標でも同じ 2 条件が成り立つ                                                            |
| **P4**     | **S 検査**: leaky 3 腕で B の指数が $\lvert\cdot\rvert\le0.1$                                       |
| **P5**（副次） | **E**: $\lvert v_i\rvert$ と深さの Spearman が正（**向きだけ**。大きさは主張しない）                              |

**★ P2 が主判定である。** 「増分の指数が 1 か」ではなく「増分の指数が**可動度の指数と一致するか**」を問う —— $\max_x z$ から可動度への $\ln32$ 幅のずれも、深さ座標の取り違えも、両辺に等しく乗るので落ちる。残るのは括弧の中（$\delta$）の深さ依存だけ。許容帯 0.3 の根拠は §3 の振れ幅。

| 条件（P1・P4 が通っている下で） | ラベル                            | 読み                                                                                                                            |
| ------------------ | ------------------------------ | ----------------------------------------------------------------------------------------------------------------------------- |
| P2 ∧ P3            | **`GAIN_CARRIES_DEPTH`**       | 増分の深さ依存は**まるごと可動度**が担っている。§2(c) が支持され、「指数が 1 でない」は座標と $\ln32$ 幅の見かけに帰する。C2 の格欄の「どちらも引かない」を、**座標を明記したうえで**解除できる                |
| P2 ∧ ¬P3           | **`COORDINATE_ONLY`**          | `zmax` 座標でだけ一致する。座標の取り違えは実在するが、$\bar z$ 座標には別の歪み（深い帯の生存者バイアス等）が残る                                                             |
| ¬P2                | **`BRACKET_DEPENDS_ON_DEPTH`** | 括弧の中（$\delta$）が深さに依存している。§2(c) の前提が落ち、**増分から活性化の形を読むこと自体ができなくなる**。§10-4 の「$v^2$ 比例は不成立」と同じ向きの結果。**C2 の格欄の制限は据え置き**。可動度の絵は打ち切り |
| ¬P1                | **`LOGGER_FAULT`**             | 恒等式が外れる。`zmax` と `mob` が同じ $z$ から作られているかを `unit_extra_record` で確認する                                                           |
| ¬P4                | `PIPELINE_FAULT`               | 配管の側。他のラベルを読まない                                                                                                               |

**外れたときに第一に疑うもの**（順に）: (1) 沈下判定が `zmax`≤0 でなく `p_hat`==0 になっていないか（ELU では両者が一致するはずだが float32 の丸めで境界が割れうる）、(2) 増分がタスク境界をまたいでいないか、(3) 帯が等頻度分位か等幅か（`increments.csv` は等頻度）。

## 6. これが決まると何が動くか

- **`GAIN_CARRIES_DEPTH` なら**: [[現象3主張v1_0902]] C2 の 4 型と代数の対応づけ（Kubo に回された項目）に答えが出る。**対応は $\varphi'$ ではなく $\varphi^2$ の負側の形で書く**（[[到達と離脱_統合主張_0903]] §2-5 の第 4 列）。
- **`BRACKET_DEPENDS_ON_DEPTH` なら**: [[帯拘束ゲートとELU実効吸収_0902]] §2 の代数は「$\varphi$ の形の話」としては生き残るが、増分の測定からそれを読むことはできないことが確定する。同ノート §14-6 の表題見直しへ。
- **どちらでも $u_{\rm esc}=\ln(\eta AT)$ と「短い視野で ELU と leaky が割れる」の帰趨は変わらない**（同ノート §11-2・§13・§14 で格を落としてある）。短い視野の話は [[現象3主張v1_0902]] §7-C の担当。
