## 0. 一行

Phase 0 が `LOP_ABSENT` を返したのは (i) 判定の脚が「late 未フィット率 < 0.05」1 本だったこと、(ii) 深さ2 が補間点に入りスコープ外だったこと、(iii) 1M step では死が 0.65 までしか進まなかったこと、の合成だった。**ホライズンを 5M step に伸ばし、深さと容量を分離する幅整合の深さ1 腕を足し、判定を分布ベースに書き換えて、もう一度回す。**

## 1. Phase 0 から何を直すか

| # | Phase 0 の欠陥 | 本 spec での修正 |
|---|---|---|
| 1 | トレンドを符号つき $M$ で登録（$M$ は負で、壁は $M$ が深まるほど強い） | **壁深さ $D := -\,\mathrm{median}_i M_i$** で登録。予測は「$D$ が増える」 |
| 2 | studentized bootstrap が補間 regime で退化（CI 上端 91.9、トレンド ±10¹³） | 統計量を **$\log_{10}$ 未フィット率**に移し、床でクリップ。退化検出と fallback を登録（§5.5） |
| 3 | regime の入口チェックが無い | **G-pre** を前段ゲートに置き、腕ごとに regime ラベルを付ける（§5.1） |
| 4 | 判定が seed 平均に依存（late 未フィット率が seed 間 14 桁、committed 値はほぼ seed4 単独） | **発症 seed 数**を主 endpoint にする（§5.2） |
| 5 | 深さと容量が交絡（深さ2 は補間、深さ1 w100 は非補間） | **幅整合の深さ1 腕 `L1wide`** を足す（§3.1） |
| 6 | ホライズンが足りない（L2 は死 0.65 で頭打ちしていない） | **5M step = 500 タスク** |

## 3. 設計

### 3.1 腕（3 本・介入なし）

| 腕 | 学習器 | 役割 |
|---|---|---|
| `L1w100` | 隠れ 1 層 × 100 | 既知の基準。Phase 0 の L1 を 5M へ延長した対応物（**ただし別走・非ペア**） |
| `L1wide` | 隠れ 1 層 × W\* | **深さと容量の分離**。深さ1 のまま補間点に届く幅 |
| `L2` | 隠れ 2 層 × 100 → 100 | 本命。Phase 0 の L2 の延長 |

共通: m=20, f=15, target_hidden=100, β=0.7, T=10⁴, enc=std, batch=1, lr_main=0.01, seed 0–9, **total_steps = 5e6（500 タスク）**, device=cpu。

**腕の間はペアにならない**（幅・深さで generator の消費が変わる）。**腕間の paired bootstrap は禁止**。

### 3.2 `W*` の較正（本走前・結果を見る前に凍結）

`L1wide` の幅 `W*` は、**early 窓の未フィット率が `L2` と同じ桁に入る**最小の幅として決める。

- 手続き: `W ∈ {150, 200, 300, 450, 600}` を seed 0–2 × 200k step の短走で回し、タスク 2–11 の未フィット率中央値を出す
- 採用規則: `L2` の early 未フィット率（Phase 0 committed で 8.596e-12 / 事後の seed 中央値 3.0e-13）に対し、**$\log_{10}$ で差が 2 以内**に入る最小の `W`
- どの幅も入らなければ `W* = 600` を採用し、**未達である旨を verdict に記録する**
- **較正走では未フィット率以外の量を見ない。** dead・M・eff_rank は本走まで開けない

> 較正の型は作業5（µ タイトレーション）の phase 0 で `center_alpha` を実現 ‖µ‖ に合わせて選んだのと同じ。

## 5. 集計（事前登録）

### 5.1 G-pre — regime ラベル【前段ゲート】

各腕について、early 窓（タスク 2–11）の未フィット率の seed 中央値 `U_early` を出し、ラベルを付ける。

| 条件 | ラベル |
|---|---|
| `U_early ≥ 0.01` | `IN_SCOPE`（v4 の宣言 regime。深さ1 w100 は unfit ≈ 0.14 側） |
| `U_early < 0.01` | `INTERPOLATING`（**v4 の主張の適用外**） |

**`INTERPOLATING` の腕で `LOP_ABSENT` が出ても「v4 の反証」とは読まない。** ラベルは verdict.csv に列として持ち、以後の引用で必ず一緒に運ぶ。

### 5.2 G0 — 発症 seed 数【主 endpoint】

各 seed について late 窓（タスク 491–500）の未フィット率の窓平均 `U_k` を出す。**床**: `U_k := max(U_k, 1e-12)`。

- **発症**: `U_k ≥ 0.05`（Phase 0 と同じ閾値を引き継ぎ、変更しない）
- 統計量 `n_onset = #{k : U_k ≥ 0.05}`（0–10）
- **併記必須**: `U_k` の中央値・最小・最大、および全 10 値のリスト（seed 分布を潰さない）

| 条件 | verdict |
|---|---|
| `n_onset ≥ 5` | `LOP_PRESENT` |
| `n_onset = 0` | `LOP_ABSENT` |
| `1 ≤ n_onset ≤ 4` | `LOP_PARTIAL` — **これも結果**。発症 seed と非発症 seed で §5.4 の量を比べる |

**Phase 0 の L2 は本規則では `n_onset = 1` すなわち `LOP_PARTIAL` に相当した**（seed4 が 0.0572）。平均ベースの `LOP_ABSENT` とは異なる読みになる点を、後継の設計理由として記録しておく。

### 5.3 時間推移【副 endpoint】

`ΔU_log = median_k [ log10(U_k, late) − log10(U_k, early) ]`。

- 床でクリップした後の $\log_{10}$ 上で取る（Phase 0 の CI 退化の直接の対策）
- CI: studentized bootstrap、B=10,000、`rng = np.random.default_rng(20260829)`。**§5.5 の退化検出を通す**

### 5.4 alive ↔ 未フィット率の関係が腕に依存しないか【事前登録・新規】

[[多層Phase0結果_0829]] §3.3 の事後観察を、検定可能な形に格上げする。

- 全腕・全 seed・全タスク末尾記録点をプールし、`log10(U)` を `log10(alive)` に回帰する（腕を要因に入れる）
- **H0**: `log10(alive)` で条件付けたとき、腕の主効果は 0
- 推定は seed クラスタ bootstrap、B=10,000、同 rng。判定は腕の主効果の CI が 0 を含むか
- `alive` の代わりに `eff_rank` を説明変数にした版も同時に出す（**どちらを主にするかを実行前に §8-5 で選ぶ**）

**H0 が棄却されなければ**「深さ・幅が変えているのは死の進行速度であって、生存容量と性能の関係ではない」という読みが支持される。**棄却されれば**深さ自体が関係を変えていることになる。

### 5.5 CI の退化検出と fallback【新規・必須】

studentized bootstrap の各 resample で seed 間 SE を計算し、

- SE が `1e-15` 未満になる resample の割合が **1% を超えたら `CI_DEGENERATE`** を立てる
- `CI_DEGENERATE` のとき: studentized CI を**報告するが判定に使わない**。代わりに (i) percentile CI、(ii) 符号検定（H0: median = 0）の p を併記し、**判定は点推定と seed 分布の記述に留める**
- CI 幅が点推定の絶対値の 100 倍を超えた場合も同じ扱い

**Phase 0 の `dU` CI `[-0.00149, 91.94]` とトレンド CI ±10¹³ は、本規則なら `CI_DEGENERATE` として判定から外れていた。**

### 5.6 壁座標【Phase 0 から符号を修正】

$\boldsymbol\mu^{(\ell)}$・$\Sigma^{(\ell)}$・$M_i$・$B_i$ の定義と 32 パターン厳密計算、退化ガード（`1e-8`）、位相揃え（タスク末尾のみ）は Phase 0 §5.2 をそのまま継承。**変更は 1 点だけ**:

$$D^{(\ell)} := -\,\mathrm{median}_i\, M_i^{(\ell)}\qquad(\text{壁深さ。大きいほど壁が強い})$$

- トレンドは `Spearman(task, D)`。**増加 = CI が 0 を上に外す**（§5.5 の退化検出を通す）
- 副次スカラー dose $\|\boldsymbol\mu^{(\ell)}\|/\sqrt{\operatorname{tr}\Sigma^{(\ell)}/d_\ell}$ も継続。**verdict には使わない**
- Phase 0 で見えた「early は第2層が上、late で逆転」は事後観察なので、**本走では early / late 両窓での層間比較を事前登録項目にする**

### 5.7 併記（REPORT_ONLY）

層別に `‖w‖`・`eff_rank`・`eff_rank_W`・`strict_dead`・`alive`・`eff_rank / alive`。`‖w‖` は主要共変量として事前登録（Phase 0 から継続）。`strict_dead` は verdict に使わない。
