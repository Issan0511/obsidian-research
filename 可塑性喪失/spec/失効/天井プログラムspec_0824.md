## 0. 先生向けサマリ（1枚）

**問い**: 上側の弱い天井（8/22d、[[xr分解と生存機構_0822]] §19–§20）の正体。仮説 H:「天井は独立の壁ではなく、**中和の平衡**（|F_self|/|F_rest| が 1 を跨ぐ位置）である」。

**なぜ今か**: r 差し替え解析（8/24）で、凍結の機能保護（作業6、RD −0.2353）の候補機構が**需要側 F_rest ただ一つ**に絞られた。H が立てば、(i) 機能保護（下から見た平衡）、(ii) 停止条件（上に留まれない理由 = 上の壁は残差とともに消える）、(iii) 天井そのもの、の**3 観測が 1 機構に統合**される。立たなくても現論文は記述で成立する — 「やらないと崩れる」ではなく「やれると一段上がる」投資。

**費用**: T0–T1 は**新規学習走ゼロ**（`ratchet_log_0819` の既存 npz の再解析のみ）。真の介入（T2: 再計装・v クランプ等）は T0–T1 の結果を見てから別途提案。

**撤退基準**: 明文 3 本（§7）。T0 で土台が崩れれば全体を畳む設計なので、**数日で「掘る価値の有無」自体に答えが出る**。

**8/21 合意との関係**: 機構の深掘りに当たるため、事前に承認を求める（勝手に回さない）。T0 のみは符号監査として防衛側であり、単独先行の可否も併せて確認したい。

## 3. T0 — 力と変位の帳簿監査（最初に実施・防衛）

**目的**: 保存されている力量のうち、どれが実際の変位 E[Δx] を予測するかを確定する。敵 3 の解消。H の土台審査。

**T0-0（定義監査・実施前に必須）**: ログ生成コードを読み、`F_self / F_rest / F_gate` が**何であるか**（ユニット別か共通 G の分割か・ゲート前か後か・µ̂ 射影か）を summary に明記する。Q12 の教訓（保存量が「ゲート抜き共通 G の列分割」と「ゲート後ユニット別 µ̂ 射影の行分割」で**別対象**だった）をここで繰り返さない。

**T0-1（符号一致）**: 候補予測子 P ∈ {F_gate, F_self+F_rest, F_self, F_rest}（ペア始点の値）について、**帯 × seed（7 × seed 数）**のセルごとに sign(mean P) と sign(mean Δx) の一致を取る。ペア数 < 50 のセルは除外。

| 結果 | 判定 |
|---|---|
| いずれかの P で一致率 **≥ 0.90** | **帳簿確定 PASS**。以後その P のみを使う |
| すべての P で一致率 **< 0.75** | **帳簿破綻 FAIL → プログラム全体を中止**（撤退 1）。§20 は「力の帳簿と変位の対応が未確立」の但し書き付きの記述に格下げ |
| 中間 | PARTIAL。一致した帯に限定して T1 を続行し、不一致帯を明記 |

**T0-2（ヤコビアン分解・記述）**: 厳密分解 `Δx = w_t·Δcos + cos_{t+1}·Δw_norm` の 2 項の寄与シェアを帯別に報告。Δcos 単独集計に対する ‖w‖ 交絡（Q3 の反論欄）の大きさをここで定量化する。

## 4. T1a — 水準別プロファイルの CI 化と P1×P2 の分離

**推定**: E[Δx | 帯] を seed クラスタ bootstrap（B = 10,000、`bootstrap_seed = 20260825`、`OMP_NUM_THREADS=1`）で。

**A1（天井の存在を CI 付きで確定）**: 最上位帯 [+0.6,∞) の E[Δx] の CI が、最下位帯 (−∞,−0.6) の CI と**非重複で、より負**。8/22c の 66 倍（−0.02585 対 −0.00039、CI なし）の正式版。

**A2（P1×P2 同時層別）**: |v|（ペア始点・全ペア母集団の中央値で二分）× 残差（ペア始点の `eval_loss_exact`・同中央値で二分）の 2×2。判定対象帯は [+0.3,+0.6) と [+0.6,∞) の 2 帯のみ。

- **残差主効果**（|v| 半分内のコントラストの平均）の CI が 0 を含まず負 → **P2 が P1 と分離して支持**
- |v| 主効果（残差半分内）の CI が 0 を含む → P1 は P2 の影だった、と記録
- 両方 CI が 0 を外す → 同時依存。どちらも 0 を跨ぐ → **天井の残差依存が再現せず**（撤退 3 の材料）
- ガード: 帯 × セルのペア数 < 300 の帯は判定対象外（記述のみ）

## 5. T1b — 境界ショックの時定数（主判別・自然実験）

**設計**: 境界（flip 切替）を残差ショックとして使う。中和は境界で 1 step で壊れ **1–2k step で回復**する（[[中和と境界窓]]・現論文で測定値として扱う量）。H が正しければ、**天井も同じ時計で動くはず**。

記録間隔 1000 step の制約下で、ペア始点のタスク内相対位置 τ₀ を 4 ビンに割る:

| ビン | τ₀ | 意味 |
|---|---|---|
| b1 | {0} | ショック直後（崩壊＋回復前半を含む） |
| b2 | {1000} | 回復後半 |
| b3 | {2000, 3000} | 回復完了直後 |
| b4 | {4000,…,8000} | 定常 |

**予言の割れの判別（§1）**: 上位 2 帯（[+0.3,+0.6) と [+0.6,∞)、別々に集計）の E[Δx | τ ビン] について、

| 観測 | 帰結 |
|---|---|
| b1 が b4 より**有意に負**（CI 非重複）で、負のドリフトが b1→b4 で単調に緩む | **P2 の断面方向が時間構造でも成立**。「残差 → 天井強化」が支持され、H は「天井 = 中和の裏面」の形で生存 |
| b1 が b4 より**有意に正または浅い** | **比の力学読み**（残差↑ → 天井が上がる）を支持。P2 断面は交絡だったと記録し、H の定式化を比ベースへ修正 |
| τ 依存が出ない（b1 vs b4 の CI 重複） | **「天井 = 中和」を棄却**（撤退 2）。天井は残差の時計と無関係な別物として記述へ |

**B2（交絡対照・必須）**: 中央帯 [−0.1,+0.1) と下位帯 [−0.6,−0.3) で同じ τ プロファイルを出す。境界窓には一般的な大変位（Q6: 変位の 31.5% が時間の 2.01% に集中）と台帳の記帳復帰が集中するため、**b1 の異常が全帯で同じ形なら天井固有と言えず INCONCLUSIVE**。天井の予言は「上位帯だけが符号付きで沈み、中央・下位帯は E[Δx] の CI が 0 近傍」。帯別・ビン別の SD(Δx) も併記し、「揺れの増加」と「ドリフトの発生」を区別する。

**B3（時定数の突き合わせ・記述）**: 上位帯の |E[Δx]| の緩和が概ね b3 までに完了するか（= 1–2k step と整合するか）を記述。ビンが粗いため点推定の時定数は出さない（過剰主張禁止）。

## 6. T1c-0 の結論 — vzero は使えない（実施済み・メタデータのみ）

[[命題リスト]] の判別案「vzero アームで、介入後に残った個体の天井が上がるかを既存データで見られる**可能性**」を確認した。**答えは否**。

- `results/posreset_0819_add/unit_traj_A_*_vzero.npz` の保存対象は **`unit_idx`（処置ユニット = 介入時 dead 側、例: seed0 で 85 本）のみ**。座標系列（`p_hat, w_norm, beta, cos_u_mu`）も処置ユニット分しかない
- 天井の検定に必要なのは**非処置の alive 個体**の x 軌跡であり、保存されていない
- 介入は `t_int = 500000`、処置は v←0（bit 一致サニティ済み）。集団レベル CSV（`lop_metrics_*`）はあるがユニット別 x が要るため代用不可

**帰結**: 真の介入判別（残差を外から動かして天井の応答を見る）は **T2（再計装または新規介入走）に送る**。T2 の設計要件はここで確定した: 「介入後の**非処置** alive ユニットの (cos, w_norm) 系列を保存すること」。T2 の提案は T0–T1 の結果が撤退基準を生き延びた場合のみ行う。

## 8. H が生き延びた場合に論文へ入る統合文の候補（採否は先生判断）

> 上側の天井は独立の力ではなく、フィットの中和そのものである。ユニットは残差に必要とされる間だけ支えられ、不要になった瞬間、入力分布に無条件の税だけが残る。凍結順序が ΔL で層別される（作業6）のはこの平衡を下から見た姿であり、集団が上に留まれない（停止しない）のは、上の壁が残差とともに消えるからである。

## 11. 追補（2026-08-27）— 「力 vs 変位」枠組みによる改訂

**格**: 本 spec は**未実行**（先生ゲート前）。よって本追補は事後追補ではなく、**事前登録のままの改訂**。起草時に新しい統計量は一切計算していない。枠組みの出所は [[論点マップ]] §14。チャット `lop-作業4-xr-recheck-spec`。

### 改訂1（最重要）— 撤退基準 1 を反転する

**現行**: T0-1 で全予測子の符号一致率 < 0.75 なら「帳簿破綻 FAIL → **プログラム全体を中止**」（§7 撤退 1）。

**問題**: この系では、力と変位の符号がずれることは**帳簿の誤りではなく系の設計から出る帰結**である。

1. **ゲート**: 力は開いている間しか働かないが、変位は閉じている時間も 0 として積む
2. **吸収**: 落ちた個体が抜けるので母集団の条件付けが場所依存になる
3. **積分の打ち消し**: 変位は力の積分。同じ大きさの力でも、向きの揃い方で 1000 歩ぶんにも √1000 ≈ 32 歩ぶんにもなる（30 倍）
4. **比例定数の時間変化**: 1 歩の変位は誤差 × 脚力（`v_i` と発火率）で、脚力が学習中に 10 倍動く（`xr_recheck_0827` A5-a、committed `window_metrics.csv`）

力の曲線 `E[F_gate | x]` と変位の曲線 `E[Δx | x]` のゼロ点が別の場所にあるなら、**その二点に挟まれた帯では符号が必ず逆になる**。一致率の低下は、そこに情報があることの指標であって破綻ではない。

**この改訂がなければ起きたこと**: [[xr分解と生存機構_0822]] §4 の符号不一致は**既に観測されている**。現行の撤退 1 は、それを再現した時点でプログラムを止める設計になっていた。

**改訂後の T0-1 判定表**:

| 結果 | 判定 |
|---|---|
| いずれかの P で一致率 **≥ 0.90** | **帳簿確定 PASS**。以後その P のみを使う（現行どおり） |
| 一致率 < 0.75 で、**不一致が連続した帯に集中** | **分離 DETECTED**。中止しない。不一致帯の位置を主結果として報告し、T1 は一致帯・不一致帯を分けて続行 |
| 一致率 < 0.75 で、**不一致が帯にも seed にも構造なくばらつく** | **帳簿破綻 FAIL**（現行の撤退 1。実装またはメタデータの誤りを疑う） |
| 中間（0.75–0.90） | PARTIAL（現行どおり） |

**「帯に集中」の操作的定義（結果を見る前に凍結）**: 不一致セルの帯インデックスの分散が、同数セルを帯にランダム配置した帰無分布の **5 パーセンタイル未満**。B = 10,000、`bootstrap_seed = 20260827`、`OMP_NUM_THREADS=1`。

### 改訂2 — 母集団定義を `p̂ > 0` に直す

**現行 §2**: 「alive はペア始点で `p̂ ≥ 0.05`」。

**問題**: 作業1 の裁定（[[中心主張v3作業リスト_0823]]）により `p̂ < 0.05` は旧作業指標 `dead_0.05` であり、condA では `p̂ = 1/32 = 0.03125` の個体を dead 側へ落とす。この個体は**勾配が恒等ゼロではない**（実測 `median|Δb| = 0.43`）。力と変位の対応を測る研究で、力が実在する個体を母集団から外すのは定義の誤り。

さらに `xr_recheck_0827` の追補で同じ理由から母集団が訂正され、照合により `p̂ > 0` は **149,492 ペア**（[[xr分解と生存機構_0822]] §19 と厳密一致）、`p̂ ≥ 0.05` は **119,046 ペア**で **30,446 件ずれる**ことが確定している。

**改訂後**: alive はペア始点で **`p̂ > 0`**。`p̂ ≥ 0.05` 版は感度チェックとして併記のみで、判定には使わない。

### 改訂3 — アームを 2 本足す（T0-3 / T0-4）

改訂1 で「分離 DETECTED」が出た場合、原因は**論理的に 2 つしかない**。同じ場所・同じ条件付けなら `E[Δx] ≈ (ゲート開放率) × (力)` で、開放率は非負なので符号を反転できない。よって候補は

1. **選抜** — `|alive` の条件付けが場所依存
2. **道のり** — 1000 step の間に個体の `x` 自体が動く

の 2 つに尽きる。以下の 2 アームでこれを割る。**どちらも新規走ゼロ。**

**T0-3（道のりの分離）**: `ratchet_log_0819` の記録 20,901 点は、粗グリッド 1000 step 刻み（1,001 点）と**境界窓 [−100,+100] の毎 step 記録**（99 境界 × 201 点）の合成である（[[中和と境界窓]] §8）。よって境界窓内では **Δstep = 1** のペアが取れる。

**同一窓・同一個体**で Δstep = 1 と Δstep = 1000 の符号一致率を比較する。

- Δstep = 1 で一致率が回復（≥ 0.90）→ **道のり効果が犯人**
- Δstep = 1 でも一致しない → 道のりでは説明できない。選抜へ

**ガード**: 境界窓内のペアには残差ショックが乗っており、粗グリッドのバルクとは条件が違う。よって T0-3 は T0-1 との直接比較ではなく、**境界窓の内側で完結する Δstep=1 対 Δstep=1000 の対比**として設計する（同一窓・同一個体で両方取れるので交絡しない）。

**T0-4（選抜の分離）**: 同一ペア集合について、条件付けを 2 通りで引き直す。

- **始点のみ alive**（区間内で消灯した個体も残す）
- **両端 alive**（区間を生き延びた個体のみ）

両者の `E[Δx | 帯]` の差が、選抜の寄与そのもの。8/22c の `E[Δx | alive]` がどちらの定義だったかは**再現できないので、本 spec の定義を正とし両方報告する**。

### T1b への波及（先取りしない）

T1b の τ₀ ビンは粗グリッド 1000 step 刻みで切ってある。T0-3 で境界窓を開けるなら、b1 ビン（τ₀ = 0）は毎 step 記録で置き換えられ、「1 step で壊れ 1–2k step で回復」の時定数を**ビンの粗さに縛られず**測れる可能性がある。**ただし T0 の結果を見てから判断する。** 本追補では T1b の判定基準を変更しない。

### Q17 との関係が変わった

[[論点マップ]] §14 により **Q17 は未検証に戻った**（8/22c・8/22d の判定はどちらも変位の測定で、Q17 の主張文は力の命題）。本 spec 冒頭の分類「T0 は防衛、T1a/T1b は深掘り」への影響:

- Q17 が未検証である以上、**駆動の対称性はフレーム選択（整流を名乗るか）の分岐条件のまま**
- T0 は力の帳簿を確定する作業なので、**Q17 の前提整備そのもの**にあたる
- したがって T0 の防衛性は 8/24 時点より強い。**§10 の「T0 単独先行の可否」を先生に確認する根拠が一つ増えた**

**ただし Q17 本体（陣営 sign(v_i) 別の `F_gate` 符号分布）は本 spec に含まれていない。** 同じ npz で同時に取れるが、相乗りさせるかは別途判断（本追補では起票しない）。

### 変更していないもの

§3 T0-0・T0-2、§4 T1a、§5 T1b の判定基準、§6 T1c-0 の結論、§7 撤退基準 **2・3**、§8 統合文、§9 スコープ — すべて現行のまま。**改訂したのは撤退基準 1・母集団定義・アーム追加の 3 点のみ。**
