## 2. 段 1: 走 A `valley_off_0903`（約 16 分・15 分級）

### 2-1. 設計

`gate_dose_0830` の `_off` 腕（`target_dose: null`・オラクルなし・自然な condA）の機構に、`gate_dial_0902` の GELU・SiLU（ダイヤル $\beta$=1）を載せる。腕は **`G_off`（GELU ダイヤル 1）・`S_off`（SiLU ダイヤル 1）** の 2 本。1 層・幅 100・5M・seed 0–9・batch 1・lr 0.01。対照は committed の `R_off`・`E_off`・`LR_off`（`gate_dose_0830`）。S-pair（init・入力列が `R_off` と bit 一致）。ロガーは `gate_dial` の `unit_extra_record`（`zmax`・`mob`・`v_unit`）を継承。**`gate_dial_0902` の `validate_config` は用量 12.16 を強制するので、新 run id で起こす。**

### 2-2. 既知の対照値（`gate_dose_0830` の `dose_response.csv`・`summary.md`・`verdict.csv`、`c4fe8ed`。2026-09-03 に正本で照合）

`R_off` は **5M** で発症 **10/10**・`strict_dead` 0.9915・median $\log_{10}U$ **−0.0930**、**1M** で発症 **9/10**・median $\log_{10}U$ **−0.6748**（seed 中央値 $U$ 0.212）。

**★ 5M では ReLU が天井（$U$ 0.81）にいるので、「ReLU より悪い」は 5M では検定できない。1M 窓で検定する。**

### 2-3. 事前予測（Kubo・走の前に固定）

| #          | 予測（Kubo）                                                                                          | 自信  |
| ---------- | ------------------------------------------------------------------------------------------------- | --- |
| **A1**     | `G_off` は 5M で **10/10**、1M で **≥8/10**                                                           | 高   |
| **A2**     | **1M 窓**の paired $\Delta\log_{10}U$（`G_off` − `R_off`）が **≥ +0.2 dex**、符号 **≥ 8:2**。5M は天井のため報告のみ | 中   |
| **A3**     | `G_off` の 5M 末尾窓: 沈下率 **≥ 0.99**、深さ中央値 **≥ 8**（`R_off` より深い・paired 10:0）、凍結率 **≥ 0.9**            | 高   |
| **A4**     | `S_off` は 5M で **≥ 5/10**、深さ中央値 ≥ 5、沈下率 ≥ 0.95（SiLU ダイヤル 1 は 12.16 でも遅かったので低め）                    | 低   |
| **A5**（副次） | `G_off` でも谷の向こうからの同一タスク内脱出が起きる（[[ゲート硬さダイヤル結果_0902]] §4b と同型・率 $10^{-3}$ 台/記録）                     | 中   |

**★ A1 の 1M 側（≥8/10）は `R_off` 自身が 1M で 9/10 なので、ReLU との差を含意しない。** A1 は「`G_off` 自身が逃げるか」の予測であり、ReLU との差は A2（paired 差）だけが検定する。**A3 の凍結率は本走のロガー（`layer1_mob`・閾値 $10^{-6}$）で定義し、出所を添えて報告する**（凍結率は走・窓で定義が違う。[[到達と離脱_統合主張_0903]] §0-1）。

### 2-4. 判定ラベル

| 条件                     | ラベル                           | 読み                                                      |
| ---------------------- | ----------------------------- | ------------------------------------------------------- |
| A1 ∧ A3                | **`FLIGHT_WITHOUT_ORACLE`**   | 自然な condA でも逃走する。**目玉は用量 12.16 限定ではない**                 |
| `G_off` の 5M 発症 ≤ 2/10 | **`FLIGHT_NEEDS_OFFSET`**     | 谷まで押し込む圧力はオラクル由来。**目玉は「強い平均シフトの下で」に限定**                 |
| A3 ∧ 5M 発症 3–7/10      | **`FLIGHT_SLOW`**             | 沈んでいるが遅い（S_b1 型）。15M 延長で再判定                             |
| A1 ∧ A3 ∧ ¬A2          | `WORSE_UNTESTABLE_AT_CEILING` | 逃走はあるが「ReLU より悪い」は 1M でも分離できない。**H1 は 12.16 の結果だけで立てる** |

**外れたときに第一に疑うもの**（順に）: (1) 自然な condA の用量が谷底に届く圧力を持たない（`R_off` の 5M `dose` と深さ分布を先に見る）、(2) S-pair が `R_off` と切れている、(3) ロガーの `zmax` が中心化前後で座標が違う（`_off` は `centered_layers` を持たないので生の $z$）。

## 3. 段 2: 走 B `G2_b1`・`S2_b1`（約 1 時間・M 級・[[9月運用_0901]] §0-2 の Issa 例外扱いが要る）

### 3-1. 設計

`elu_swamp_0830` の 2 層（隠れ [100,100]）の機構に GELU・SiLU を載せる（`set_activation` の経路。GELU・SiLU が `elu_swamp` の活性化表に無ければ追加が要る）。用量 12.16・5M・seed 0–9。対照は 2 層 ReLU（`mlp2_phase1` の `L2_none` 相当・committed 値）。**なぜ要るか**: 当方の補題（[[到達と離脱_統合主張_0903]] §2-1）は 1 層限定なので、**2 層で逃走が残るかは純粋に実測の問題**。

### 3-2. 事前予測（Kubo・走の前に固定）

| #      | 予測（Kubo）                                               | 自信  |
| ------ | ------------------------------------------------------ | --- |
| **B1** | 2 層 GELU ダイヤル 1 は第 1 層で 10/10、第 1 層の深さ中央値 ≥ 8          | 中   |
| **B2** | 第 2 層でも沈下率 ≥ 0.9（性質 A: 隠れ層が用量を作り直す）                    | 低   |
| **B3** | 2 層 ReLU 対 2 層 GELU の 5M 対比は同符号（GELU が悪い）だが、1 層より差が小さい | 低   |

ラベル: **`FLIGHT_SURVIVES_DEPTH`**（B1）／**`FLIGHT_1LAYER_ONLY`**（第 1 層発症 ≤ 2/10）。

**外れたときに第一に疑うもの**: (1) 第 2 層入力の用量が 12.16 の意味を持つか（第 2 層は隠れ層出力を受けるので「用量」は第 1 層にしか掛からない。第 2 層入力の $\mu/\Sigma$ 比を窓つきで報告する・[[運用ルール]] §5 教訓⑫）、(2) `elu_swamp` の 2 層 ELU で第 2 層沈下が 1.5% だった（`LOP_REDUCED`）ことと同じ理由で GELU でも第 2 層が空になる可能性。
