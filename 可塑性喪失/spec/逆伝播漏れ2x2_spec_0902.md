## 0. 一行

`gate_dose_0830` は「片道性が load-bearing」を示したが、片道を外す手段は **forward も変える**活性化（ELU・leaky）だった。本走は **forward を厳密 ReLU に固定したまま backward の勾配だけを負側へ漏らす**（forward ReLU / backward leaky、以下 **逆伝播漏れ**）。これで「ゲートが開くだけで足りるか、forward の非ゼロ出力（self 復元力・$v_i$ の学習）まで要るか」を切り分ける。b-WD を掛け合わせるのは、forward が 0 のときに消える self 復元力の**明示的な代替**になるかを同時に見るため。

## 1. なぜ回すか

| 材料                                                                                                                                           | 出所                                          | 格                                                  |
| -------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------- | -------------------------------------------------- |
| 帯内用量で ReLU 10/10、ELU・leaky 0/10。滑らかさは不要、片道でないことだけが効く                                                                                         | `results/gate_dose_0830/verdict.csv`        | **commit 済み出力**                                    |
| 沈下は死ではない（ELU 0.36–0.45・leaky 0.63–0.67 でも LoP なし）                                                                                            | 同                                           | commit 済み出力                                        |
| self 項の恒等式: 負側の上向き復元力は $\sigma\sigma' = a^2 z < 0$ から出る。**forward が厳密 0 なら $\sigma = 0$ で消える。** 同じ理由で $v_i$ への勾配 $\delta\cdot a_i$ も 0       | [[selfterm_identity]] §3（leaky の副次予言）       | 定理＋未検証予言                                           |
| b-WD（λ=1e-3）は centered で dead・機能劣化・b 暴走を同時に止めた                                                                                               | `results/bias_wd_0901/`（`BIAS_WD_PROTECTS`） | commit 済み出力（**2 層・centered 系**。1 層・std 系への移植は本走が初） |
| 先行: forward ReLU / backward 代替勾配は **SUGAR**（Horuz et al., arXiv:2505.22074, 2025-05）が提案済み。i.i.d. 単一タスクで LeakyReLU 代替は改善小、減衰型（NeLU・B-SiLU）が有効 | alphaxiv 要約（**原典未精読・数値は引かない**）              | 外部・記憶級                                             |

**動機**: (i) 柱2「片道が病理を作る」を **backward 単独の介入**で再現できれば、病理の所在を「力場」に絞れる（[[運用ルール]] 登録原則「力 ≠ 変位」の直接検証）。(ii) 外れれば「ゲートが開くだけでは足りず forward の非ゼロ出力が要る」＝ self 復元力または $v_i$ 学習が必要、という機構情報になる。(iii) SUGAR に対し「LoP 文脈での機構分解」が当方の差分になる。

## 2. 何を分けるか（未登録の Claude の推論）

逆伝播漏れで負側ユニットに戻る力を恒等式で分けると:

| 経路                                                      | forward-leaky（`LR`）   | 逆伝播漏れ（`BL`）          |
| ------------------------------------------------------- | --------------------- | -------------------- |
| rest 経路（共通場 $G$ との結合、$-2\eta v_i\,\mathrm{gate}\,G$、双極） | $a$ 倍で戻る              | $a$ 倍で戻る             |
| self 復元力（$-\eta\nabla\tfrac12\mathbb{E}[f_i^2]$、負側で上向き） | 戻る（$\sigma\sigma'<0$） | **戻らない**（$\sigma=0$） |
| $v_i$（出力重み）の勾配 $\delta\cdot a_i$                        | 戻る                    | **0（凍結）**            |

`BL` で発症しなければ、rest 経路だけで壁から逃げられる（脱出に必要なのはゲートの開放のみ）。`BL` で発症し `BLW`（`BL` + b-WD）で発症しなければ、失われた self 復元力を b への外的復元力が代替している。どちらでも発症すれば forward の非ゼロ出力（$v_i$ の学習を含む）が要る。

**本走が答えないこと**: $a$ の掃引・帯型（NeLU 型）代替勾配・Adam・多層・幅。無限時間の主張（0/10 は「5M までに観測しなかった」）。

## 3. スコープと前提

`gate_dose_0830` §3 を逐語継承: condA・幅 100・隠れ 1 層・$T=10^4$・batch=1・素の SGD・lr 0.01・seed 0–9・`total_steps=5e6`・device=cpu・オラクル用量固定・`eval_loss_exact` 併記・1M `state_hash`。床 **1e-16**（1 層系・再較正しない）。bootstrap seed **`20260905`**（既用: 20260829 / 20260902 / 20260904）。

## 4. 設計

### 4.1 腕（新規 6 本 ＋ 対照 4 本は committed）

2×2（backward 漏れ × b-WD）× 帯内 2 用量。

| 腕                      | forward       | backward（$z\le0$） | b-WD   | 用量           | 出所                              |
| ---------------------- | ------------- | ----------------- | ------ | ------------ | ------------------------------- |
| `R_933` / `R_1216`     | ReLU          | 0                 | なし     | 9.33 / 12.16 | **committed**（`gate_dose_0830`） |
| `LR_933` / `LR_1216`   | leaky $a=0.1$ | 0.1               | なし     | 同            | **committed**（同）                |
| `RW_933` / `RW_1216`   | ReLU          | 0                 | λ=1e-3 | 同            | **新規**（b-WD 単独の対照）              |
| `BL_933` / `BL_1216`   | ReLU          | **0.1（代替勾配）**     | なし     | 同            | **新規・主対象**                      |
| `BLW_933` / `BLW_1216` | ReLU          | 0.1（代替勾配）         | λ=1e-3 | 同            | **新規・折衷案**                      |

- `*_off`（用量固定なし）は省く（`gate_dose` の verdict も帯内 2 腕でのみ判定）
- $a=0.1$ は `gate_dose` の leaky と同値。**`BL` と `LR` の差が「forward の非ゼロ出力」だけになる**ようにするため
- λ=1e-3 は `bias_wd_0901` の C4 値を継承。**1 層・std 系での較正はしない**（外れたときは §7.3 で疑う）

### 4.2 対応づけ

代替勾配・b-WD・活性化はいずれも乱数を消費しないので、新規 6 腕は `gate_dose_0830` の各腕と init・教師・入力列・flip 軌道が bit 一致する（S-pair）。**step 1 以降は軌道が分岐する**（`gate_dose` §4.2 と同じ）。paired 対比は `results/gate_dose_0830/verdict.csv` の seed 別 $U_k$（10 値）を相手に取る。引用時に「対照は別走の committed 値」と書く。

### 4.3 実装

- `VecMLPL` に `act='bwd_leaky'` を追加: 前向き `where(pre>0, pre, 0)`、後ろ向き `where(pre>0, 1, a)`。閉形式のまま（autograd に切り替えない）。**ReLU 経路・leaky 経路は 1 行も触らない**
- b-WD は `VecMLPL.set_weight_decay_b(1e-3)`（`bias_wd_0901` と同じ差し込み。b のみ・w と v には掛けない）
- 用量固定は `dose_const_5m_0830` のオラクルモードそのまま（入力側の変換・活性化非依存）

### 4.4 用語

`BL` / `BLW` / `RW` は forward が ReLU なので `strict_dead`（$\hat p_i\equiv0$）がそのまま定義できる。ただし `BL` / `BLW` では**吸収でない**（負側に勾配があるので復活しうる）。§5.3 で復活数を数える。verdict には使わない。

## 5. 集計（事前登録）

窓・床・発症定義・CI は `gate_dose` §5 を逐語継承: 5M 末尾窓 = タスク 491–500、1M 窓 = 91–100、$U_k$ = 窓平均未フィット率、**発症 = $U_k\ge0.05$**、$n_{\rm onset}$ は Clopper–Pearson、差は seed クラスタ paired bootstrap B=10000・percentile 主。

### 5.1 主 endpoint — 発症数（帯内 2 用量とも、5M）

「0」は 2 用量とも $n_{\rm onset}(5\mathrm{M})=0$、「≥5」はいずれかの用量で $\ge5$。**上から順に最初に当たった行を verdict とする。**

| 順   | `BL`           | `BLW` | `RW` | verdict                                                                         |
| --- | -------------- | ----- | ---- | ------------------------------------------------------------------------------- |
| 1   | 0              | —     | —    | **`BACKWARD_GATE_SUFFICIENT`**（ゲートが開くだけで足りる。self 復元力・$v_i$ 学習は不要。`RW` は REPORT） |
| 2   | ≥5             | 0     | ≥5   | **`RESTORING_FORCE_REQUIRED`**（漏れ単独は不足、漏れ＋外的復元力で足りる、復元力単独では不足 ＝ 折衷案の成立）         |
| 3   | —              | —     | 0    | **`WD_B_SUFFICIENT_ALONE`**（b-WD 単独で 1 層・std でも止まる。漏れの寄与は §5.2 の水準で読む）          |
| 4   | ≥5             | ≥5    | —    | **`FORWARD_LEAK_REQUIRED`**（forward の非ゼロ出力が要る。折衷案は不成立）                          |
| 5   | 上記以外（1–4 が混じる） |       |      | **`PARTIAL`** — §5.2 で読む                                                        |

前提: committed の `R_*` は 10/10・`LR_*` は 0/10（既知）。**飽和ガード**: 二値が 0 に揃った場合は §5.2 を同格で報告する。

### 5.2 水準（主判定と同格）

各腕の seed 中央値 $\log_{10}U(5\mathrm{M})$・$\log_{10}U(1\mathrm{M})$。paired Δ $\log_{10}U(5\mathrm{M})$（用量ごと）:

- **P3'**: `BL`−`R`、`BLW`−`R`、`RW`−`R`（各介入の効果）
- **P5（本走の要）**: `BL`−`LR`。**等価限界 $\Delta=0.15$ dex**（[[チャネル遮断2x2_spec_0901]] D4 を継承・Issa 上書き可）。CI が $[-0.15,+0.15]$ に収まれば **`BWD_EQUIV_FWD`**（forward の非ゼロ出力は水準にも効かない）、CI が 0 を上に外せば **`FWD_ADVANTAGE`**（self 復元力／$v_i$ 学習の寄与が水準に残る）、どちらでもなければ **`INCONCLUSIVE_WIDE`**
- **P6（交互作用）**: (`BLW`−`BL`) − (`RW`−`R`)。符号規約: 負 = 漏れと b-WD が水準で相補的。**機構の証拠には使わない**（[[チャネル遮断2x2_spec_0901]] の教訓: 符号規約の齟齬）

### 5.3 副次（REPORT_ONLY）

- **復活数**: `BL` / `BLW` で $\hat p_i$ が 0 → 正へ戻ったユニット・イベント数（`gate_dose` の ReLU 腕は 0 が既知）。**双方向ゲートの直接の署名**
- **$v_i$ 凍結率**: `BL` で末尾窓中 $\Delta v_i = 0$ のユニット割合。§2 の表の「$v_i$ 凍結」が実装どおりかの確認（`strict_dead` 集合と一致するはず）
- `strict_dead` / `submerged_frac` / `alive` / `eff_rank` / `‖w‖` / `b_median` / `median_M` / `median_B` / `preact_sd_median` の時系列、`eval_loss_exact`。**`‖w‖` は主要共変量**（継続）
- 数値発散は `gate_dose` §5.6 を逐語継承（`NUMERIC_DIVERGENCE` でセルを空にし、verdict が空セルを要求すれば `INCONCLUSIVE_DIVERGENCE`）

### 5.4 副次 P7 — ユニット別 $s_i = M_i + B_i$ の分布（登録・verdict 不使用・9/2 追加）

先生案（[[kubo_review_v4.2_0831]] §2.3）の壁座標 $s_i = M_i + B_i$（$M_i = w_i\cdot\mu/\mathrm{denom}_i$：µ チャネル、$B_i = b_i/\mathrm{denom}_i$：b チャネル、$\mathrm{denom}_i = \sqrt{w_i^\top\Sigma w_i}$。`exact_layer_record` が $\mathbb E[z_i]/\mathrm{sd}(z_i)$ との一致を照合済み）を**用量の代替ではなく読み出し**として載せる。用量は操作変数、$s_i$ は各腕でユニットがどこに居るか・どのチャネルで動いたかの記述。本走で特に効く理由: 3 腕とも forward が ReLU なので `strict_dead` と位置が同じ座標で比べられ、**b-WD が $B_i$ を係留し $M_i$ に触らない**（[[現象2主張v1_0901]] C5）ことと、**漏れがどちらのチャネルを戻すか**が分離できる。

- 記録: 5M 末尾窓・1M 窓の各記録点でユニット別 `s` / `M` / `B` / `denom` を `s_distribution.csv` に保存（`lr_a1_0901` の相乗り列を継承。**要確認: `gate_dose` の宿主ロガーにユニット別列があるか。無ければ追加し、既存列は触らない**）
- 集約順（凍結）: ユニット → **seed 内中央値**（全ユニット／alive のみ の 2 系列）→ seed 中央値。`median_s` と `median_M + median_B` は別物として両方出す（[[引用禁止]] の縮退 (ii)）。`denom` の中央値を併記（縮退 (iii)）。中心化腕は無いので縮退 (i) は非該当
- **P7a**: 各腕の `median_s` / `median_M` / `median_B`（全ユニット・alive）
- **P7b（漏れが戻すチャネル）**: paired Δ（`BL` − `R`）の `median_M`・`median_B`（全ユニット）。CI が 0 を上に外したチャネルを「戻したチャネル」と読む。両方なら両方。**ラベル化はしない**（F_self / F_rest 分解の教訓: 役割の割り当ては失敗しやすい。ここは記述にとどめる）
- **P7c（b-WD の係留）**: `RW` − `R`、`BLW` − `BL` の `median_B` と `median_M`。C5 の再現なら $B$ のみ動き $M$ は等価限界 0.15 内
- $s_i$ は「位置」であって「病理」ではない（[[現象3指標再定義_P3_0901]]）。`BL` の位置が `R` と同じ深さでも復活数（§5.3）が正なら、差は位置ではなく可動度にある — この読みを P7 と §5.3 の併記で固定する

## 6. 前段チェック・出力・コスト

- **S-pair（必須）**: 新規 6 腕の step 0 で init・教師・入力列・flip が `gate_dose_0830` の `logs/` と bit 一致（30k 短走）
- **S-limit（必須）**: `bwd_leaky` で $a=0$ が ReLU 経路と **30k 短走で bit 一致**（forward・backward とも）。`set_weight_decay_b(0)` が無介入と bit 一致
- **S-dose（必須）**: 実測 ‖µ‖ が目標と相対誤差 $10^{-10}$ 以内（6 腕すべて）
- **S-bwd（必須）**: 代替勾配は損失の勾配ではないので有限差分照合は**不可**。代わりに負側ユニット 1 個を手で置き、1 step の $\Delta w,\Delta b$ が $a\cdot(\text{leaky 腕の負側更新})$ と一致・$\Delta v = 0$ であることを単体テストで確認
- **S-wd（必須）**: step 1 で `RW` と `R` の差が b のみ、かつ $\Delta b = -\eta\lambda b$ に一致（`bias_wd_0901` の差し込み規約を再確認）
- **S-taut**: 判定指標（未フィット率）が介入で定義上恒真になっていない
- S1: `OMP_NUM_THREADS=1`。S6: 床は継承。**本走前に §5 の集計はしない**

出力: `results/bwd_leak_0902/` に `verdict.csv`（腕・用量・$n_{\rm onset}$ 1M/5M・CP95・$U_k$ 10 値・P3'・P5・P6・復活数・`NUMERIC_DIVERGENCE`）、`summary.md`、`layer_stats.csv`、`provenance.json`（`gate_dose_0830` の commit SHA を記録）、`logs/`、`arm_status/`。**数値は `verdict.csv` と `summary.md` からのみ転記。**

コスト: `gate_dose_0830` 9 腕 ≈ 100 分 → 6 腕・ReLU 系のみ（exp なし）で **約 55–65 分**。腕ごとの独立プロセス並列は可。
