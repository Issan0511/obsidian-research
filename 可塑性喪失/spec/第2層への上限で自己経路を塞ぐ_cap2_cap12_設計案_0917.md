## 0. 決めたいこと

**崩壊する箱（RL・ELU→ELU）で、第2層自身の重みの成長に上限を置くと、第2層の負側への輸送と応答の喪失が止まるか。** 止まったら、その網に応答の移植を当てて「W の成長 → 輸送 → 応答 → 再学習」を 1 箱で一本につなぐ。

## 1. なぜ第2層か

- 第1層の成分上限（cap_par・cap_perp・cap_both）は ELU→leaky では輸送を止めた（`BOTH_HELD`）が、ELU→ELU では崩壊を 3.5〜7.5 タスク遅らせるだけだった（`COLLAPSED`・T½ 7 → 10.5/14/14.5）。
- cap_both は ‖µ₂‖ を t20 まで 12 以下に抑えたのに t14.5 で崩れ、その間に第2層の重みが全腕で最も育った（平均 ‖w‖ t10 5.2・t20 6.7、ref 3.9・4.1）。**上流を塞ぐと第2層の自己経路が運ぶ。**
- 帳簿（事後）では ref の沈みの 7 割以上が上流の ‖µ₂‖ の伸びだが、これは ref の分解であって、上流を止めたときに自己経路が残らないことを意味しない。
- affine なしの入力 LN は ‖µ₂‖ ≈ 10 で `RESCUED`（50 タスク・3 seed）。cap_both（‖µ₂‖ ≤ 12）との差は ‖µ₂‖ の大きさでは説明できず、壁の距離 c₂（LN 8–12・cap_both 2.5–2.9）が疑われている（未検証）。

## 2. 箱と腕

箱は mucap_ee_0917 と同じ（RL・1200 枚固定・784–100–100–10・両層 ELU・Adam lr 1e−3・6000 更新/タスク・100 タスク・seed 0–9・`flush_denormal`）。上限の方式も同じ: 行ごとに $w=qe+v$ と分け、半径はその run の task 1 終端値、task 2 から射影で戻す。第2層では $e_2=\hat\mu_2$（1200 枚の平均 $a_1$ の方向）を各タスク開始時に引き直す。

| 腕 | 上限 | 役割 |
|---|---|---|
| ref | なし | mucap_ee の ref と bit 一致（S0） |
| cap_both | 第1層の q と ‖v‖ | mucap_ee の腕を bit 再利用 |
| **cap2** | 第2層の q₂ と ‖v₂‖ だけ | 自己経路だけを塞ぐ。上流は自由 |
| **cap12** | 第1層 cap_both ＋ 第2層 cap2 | **主**。上流と自己の両方を塞ぐ |
| cap12b | cap12 ＋ b₂ を task 1 終端の範囲に留める | bias への逃げ（0916 の cap_par で −7）を塞ぐ |
| inLN | affine なしの入力 LN | l2_wall の `RESCUED` を同じ箱に並べる対照（上流の伸びを止める） |

## 3. 主判定と読み分け

主 endpoint は mucap_ee と同じ E1（主窓 task 51–100 の online 精度・床の規則は親と同じ）。**E2 は解析的な平均 φ′ から、訓練の微分で数えた「厳密 0 の (ユニット, 画像) の割合」と $n_{\rm eff}$ に替える**（[[第2層の応答の場を移植して再学習を比べる_結果_0917]] §5: 平均 φ′ は optimizer が受け取った量ではない）。主判定は cap12 − ref（97.5%）、崩壊時刻 T½ の符号検定を併記。

| ラベル | 条件 | 読み |
|---|---|---|
| **RESCUED** | cap12 が主窓で床の上・第2層の 0 の割合が ref より小さい | 第2層の自己成長が崩壊の担い手。§5 へ進む |
| COLLAPSED・LATER | 床に落ちるが遅い | 上限が輸送を遅らせるだけ。bias・c₂・他の経路を疑う（cap12b・inLN と比べる） |
| COLLAPSED・SAME | 遅れもしない | 第2層の重みの成長は原因でなく補償。V10 §1.2 の「W 増大が引き起こす」を層で限定し直す |
| IMPAIRED | task 2–10 で ref より学べない | 介入として判別不能。経路の反証にしない |

cap2 単独・cap12b・inLN は副（95%・報告）。

## 5. 救えたら: 上流と下流を一本につなぐ（A4 → A5）

cap12（または cap12b）が RESCUED なら、resp_ee の移植をその網に当てる。

- **沈める**: cap12 の t10 の網に ref の t10 の場を渡す → E が落ちれば、上限が保った応答が再学習を担っていた。
- **戻す**: ref の t10 の網に cap12 の t10 の場を渡す → E が上がれば、上限が守ったのは応答の場そのもの。
- これで [[中心主張v10作業リスト_0916]] §4 の読み分け「成長抑制 → 輸送減少 → 応答維持 → 再学習改善」を、同じ箱・同じ seed で 4 つの矢印すべて介入で押さえられる。
- 動く場（[[動く場の移植_応答低下からLoPへ_設計案_0917]]）と組むなら、cap12 の網を並走網にして「輸送が止まった場」を ref に渡す腕も置ける。

## 7. 言えるようになること・ならないこと

- 言える: 崩壊する箱で、第2層の自己成長が輸送と応答喪失の担い手か。RESCUED なら §5 で V10 の鎖を 1 箱で一本に。
- 言えない: なぜ W₂ が育つか（H1・A2 の側）。他の箱・活性化への一般化。c₂（壁の距離）が何で決まるか（inLN との差の説明は別途）。
