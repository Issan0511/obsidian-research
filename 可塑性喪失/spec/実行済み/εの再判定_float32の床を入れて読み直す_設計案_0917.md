## 0. 決めたいこと

**崩壊した ELU の層で更新が止まったのは、勾配が Adam の ε（1e−8）を下回ったからか、訓練の微分が厳密に 0 で勾配そのものが無かったからか。**

この箱の ELU（expm1 実装）は float32 で $z<-16.64$ のとき訓練の微分が厳密に 0。過去の読みは解析的な $e^z$（6e−34 など）で「float32 の下限より 11 桁上だから ε が止めた」と推論したが、optimizer が受け取った量は 0 だった可能性がある。

## 1. 区別の仕方

ε が止めた（EPS）と、0 が止めた（ZERO）は、既存データで分けられる。

| 量 | EPS なら | ZERO なら |
|---|---|---|
| 訓練の微分が 0 の (ユニット, 画像) の割合 | 小さい（勾配は小さいが有る） | ほぼ 1 |
| W₂ の座標ごとの勾配 rms | 0 < rms < ε | 厳密に 0 |
| Adam の v̂ | 小さい値で釣り合う | 勾配 0 のまま β₂ で指数減衰（1/e ≈ 1000 更新） |
| ε を 1e−30 にしたとき | 動き出す | 動かない（l2_wall の `MIXED` はこちらと整合） |
| 第1層（下流が 0 のとき） | — | 上から来る勾配も 0 に近く、「√v̂ < ε」は ε のブレーキでなく履歴の減衰 |

## 2. 材料（すべて既存）

- `resp_ee_0917`: 自然軌道の分岐点（t2・5・7・10・15・20）の状態 `branch_states.pt` と (ユニット, 画像) ごとの z（`units.npz`・退避済み）。訓練の微分の 0 の割合は t10 で 91〜96% と既に数えてある。
- `layer_chimera_rl_0914` / `relu_gelu_silu_rl_ext150_0914`: タスク終端の `tinygate`$=P_x(|\varphi'|<10^{-8})$。解析値で $z<-18.4$ に当たるので、厳密 0（$z<-16.64$）の割合の下界として使える。
- `l2_wall_0916` Part B: ε = 1e−6 / 1e−8 / 1e−30 の 3 腕の d₂/c₂ と帳簿。
- `mucap_ee_0917`: t100 の第1層・第2層の √v̂ と勾配 rms（units.npz）。

## 3. 手順

1. 分岐点の状態で 1 ミニバッチ（と 1200 枚全体）の逆伝播を取り、層ごとに **訓練の微分が 0 の割合**、**座標ごとの勾配 rms の分布**（0 / (0, ε) / ≥ ε の 3 区分）、**√v̂ と ε の比**を表にする。
2. `tinygate` の時系列を厳密 0 の下界として読み直し、「ゲートが ε を横切る t10」と「厳密 0 が過半になる時刻」を並べる。
3. l2_wall Part B の 3 腕で、ε を変えても動かなかった座標の勾配が 0 だったか (0, ε) だったかを帳簿から分ける。
4. 第1層について、上から来る勾配の大きさを第2層の 0 の割合と併記し、「√v̂ < ε」が履歴の減衰で説明できるかを見る。

## 4. ラベルと読み直し

| ラベル | 条件 | 書き換え |
|---|---|---|
| **ZERO_NOT_EPS** | 凍結した座標の勾配が厳密 0 で、(0, ε) の区分がほぼ空 | 0914 §5 の「止めたのは ε」を「止めたのは float32 の床」に。到達深さは optimizer の定数でなく実装の床で決まる |
| EPS_REAL | (0, ε) の区分が主で、ε を下げると動く | 0914 の読みは保つ。l2_wall の `MIXED` は別の理由 |
| BOTH | 層・時期で分かれる | 時期を分けて書く（床に届く前は ε、届いた後は 0） |

予測（Claude）: 第2層は ZERO_NOT_EPS 75%。第1層の「√v̂ < ε」は履歴の減衰で説明できる 60%。
