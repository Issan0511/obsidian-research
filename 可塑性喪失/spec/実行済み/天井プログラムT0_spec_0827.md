## 0. 結論を何で決めるか

### 0.1 問い

同じ開始状態のコホートから出発したとき、始点で予測される 1-step の力

\[
F := F_{\mathrm{gate,start}}
\]

と、実現した k-step 変位率

\[
D_k := \frac{x_{t+k}-x_t}{k}, \qquad x=w\cdot\hat\mu
\]

のゼロ点はどれだけ離れるか。k を伸ばすとその差がどちら向きに変わるか。区間中に strict off へ落ちた個体が帯内の差をどれだけ担っているか。

### 0.2 主推定量

母集団 A（始点 `p_hat > 0`）について、帯平均曲線の下降根を

\[
z_F(k),\quad z_D(k)
\]

とし、位置差を

\[
g_A(k):=z_D(k)-z_F(k)
\]

とする。

- **主ホライズン**: `k = 40`
- **1-step 基準**: `k = 1`
- **主判定**: `g_A(40)`
- **道のり判定**: `P_g := g_A(40)-g_A(1)`
- `k ∈ {2,5,10,20}` は、方向と発生位置を示す事前登録済みプロファイルであり、結果を見て主ホライズンを差し替えない

`k=40` は、全 k で共通の 60 起点を保ったまま取れる最大の登録ホライズンである。`k=99` や、結果を見て選んだ k は主判定に使わない。

### 0.3 主判定表

判定は sanity gate をすべて通過した場合だけ行う。CI は §10 の seed cluster bootstrap による 95% percentile CI。

| 条件 | `T0_root` |
|---|---|
| 元標本で `z_F(40)` または `z_D(40)` がない | `INCONCLUSIVE_NO_ROOT` |
| `g_A(40)` の同時根存在率 `< 0.95` | `INCONCLUSIVE_UNSTABLE_ROOT` |
| 95% CI 全体が 0 より大きい | `SEPARATION_POSITIVE` |
| 95% CI 全体が 0 より小さい | `SEPARATION_NEGATIVE` |
| 95% CI が 0 を含む | `NO_RESOLVED_SEPARATION` |

ここで `POSITIVE` は変位の下降根が力の下降根より上側、`NEGATIVE` は下側にあることを意味する。`NO_RESOLVED_SEPARATION` は等価性の確定ではない。「差がない」とは書かない。

道のり判定 `T0_horizon` は次のとおり。

| 条件 | `T0_horizon` |
|---|---|
| 元標本で `k=1,40` に必要な 4 根のいずれかがない | `INCONCLUSIVE_NO_ROOT` |
| 4 根の同時存在率 `< 0.95` | `INCONCLUSIVE_UNSTABLE_ROOT` |
| `P_g` の 95% CI 全体が 0 より大きい | `GAP_MOVES_POSITIVE_WITH_HORIZON` |
| `P_g` の 95% CI 全体が 0 より小さい | `GAP_MOVES_NEGATIVE_WITH_HORIZON` |
| 95% CI が 0 を含む | `NO_RESOLVED_HORIZON_SHIFT` |

`T0_root` と `T0_horizon` は別々に出す。たとえば `k=40` で位置差があっても、`k=1` からの変化が解像できなければ、道のり起源は確定しない。

### 0.4 選抜について言える範囲

終点 alive は未来の転帰による post-treatment 条件である。したがって、本 spec は「選抜か道のりか」を加法的・因果的に二分したとは主張しない。

- 主結果: 固定開始コホート A の `g_A(k)` と `P_g`
- 選抜の主記述: §8 の帯内混合恒等式 `H_A=C_S+C_L`
- 生存者条件付けコントラスト `C_surv=g_S-g_A` は副次記述
- `C_L` や `C_surv` を「選抜の因果寄与」「全ギャップの何%」とは呼ばない

## 1. 確定前提 A1–A12

### A1. 記録グリッド

`record_steps(total=1e6, period=10000, half_window=100, bulk_every=1000)`、すなわち bulk 1000 刻みと各境界 ±100 の毎 step 記録の和集合。対象は `seed0`–`seed9` の 10 seed、各 20,901 点。各 seed の gap 分布は `{1: 19900, 900: 199, 1000: 801}`。

### A2. Δstep=1 ペア

unit・seed あたり Δ1 総数 19,900。本当に flip を跨ぐペアは 99。本 spec の非跨ぎ候補は 19,801。99 個の実境界窓に 19,800 本、終端半窓 `999900→1000000` に 100 本ある。

### A3. Δstep=1000 ペア

タスク内 bulk の開始位相は `τ0 ∈ {1000,…,8000}` の 8 本/タスク。これとは別に初期化ペア `0→1000` が 1 本だけある。unit・seed あたり合計 801。本 spec の bulk 参考値では初期化ペアを除外する。

### A4. 時間領域の排他性

Δ1 と Δ1000 は時間領域が排他的で、同一時間領域・同一窓の対応比較はできない。両者を並べる場合は「刻み幅」と「境界近傍性」が交絡する。Δ1000 は主判定に使わない。

### A5. 力の定義

生成コード `src/ratchet_log.py` の定義は

```python
pref   = -2 * lr * v
xdm    = x_in @ mu_hat
F_gate = pref * (delta  * gate * xdm).mean(dim=0)
F_self = pref * (d_self * gate * xdm).mean(dim=0)
F_rest = pref * (d_rest * gate * xdm).mean(dim=0)
```

である。`d_self=v_i*a_i`、`d_rest=delta-d_self`。`F_gate` はユニット別・ゲート込み・単位 `mu_hat` 射影・full-support で期待した 1 SGD step の `Δ(w·mu_hat)`。ゲート開放率を外から再度掛けない。

### A6. 分解の厳密性

`delta=d_self+d_rest` により `F_gate=F_self+F_rest` は代数的に厳密。生成時は float64 で直接計算し、保存列は float32。保存後照合は byte 一致ではなく §9.3 の機械精度由来の混合許容差を使う。

### A7. 1-step の力と変位

std・同一タスク・境界非跨ぎ・batch=1・現在状態で条件付けた 1-step 期待値について

\[
E[\Delta x\mid state]=F_{gate}
\]

は厳密。centered、境界跨ぎ、`k>1`、未来の生存で条件付けた S/L、状態で条件付けない個別観測へは持ち出さない。

記録フックは `train_group` のループ先頭、`env.step()` より前に呼ばれる。したがって非境界の記録点 t に保存された `F_gate[t]` は遷移 `t→t+1` の始点力であり、1 行ずらして使わない。

### A8. 設計上の含意

Δ1 の一致は発見ではなく統計的 sanity。開始状態分布・条件付け・時間領域を揃えずに k を比べると、位相と領域の構成差が第三の見かけ上の原因になる。本 spec は §4 の固定開始コホートでこれを防ぐ。

### A9. 境界前窓

各実境界 B の `[B-100,B-1]` は同一タスク・毎 step 記録で、`k=1…99` を作れる。ただし k ごとに可能な起点集合が異なるため、自動的に交絡なしにはならない。

### A10. 保存列

`x=cos_u_mu*w_norm`、`p_hat`、`v`、`F_gate`、`F_self`、`F_rest`、`b`、`w_norm`、`mu_norm`、`G`、`flip_state`、`E_delta`、`eval_loss_exact` を利用できる。

### A11. 境界の定義

境界ペアは `diff(flip_state)!=0` から機械的に定義する。補助照合として左端 `s=step[:-1]` に対する

```python
(s % T == 0) & (gap == 1) & (s > 0)
```

が全 seed で 99 本と一致しなければ sanity FAIL。右端 `step[1:]` を `s` として使わない。

### A12. 使用禁止

- 「中和の回復は 1–2k step」を時定数の前提にしない
- 天井を `|F_self|/|F_rest|=1` と定義しない
- 複数の力量から結果を見て予測子を選ばない
- `F_gate` にゲート開放率を二重掛けしない
- `posreset_0819_add` の vzero を非処置 alive の準介入に使わない
- Δ1 と Δ1000 を同一窓の対応比較と呼ばない

### A13. 座標軸回転の適用範囲（2026-08-28 追加）

std の condA では `mu_T=(flip_T,0.5·1_5)` で、`flip_T` はタスク内で固定される。本 spec の主ペアと bulk Δ1000 参考ペアはすべて同一タスク内なので

```text
mu_hat_end = mu_hat_start
```

が構造的に成立する。したがって主 T0 の `delta_x` に座標軸回転項は入らず、旧 `E[F_gate]=+2.98e-7` 対 `E[Δx]=-1.75e-3` の符号不一致も回転では説明できない。境界での回転と死の対応は [[タスク方向回転M1_spec_0828]] へ分離する。

## 3. 行テーブルと座標

### 3.1 行キー

1 行は `(seed, unit, s_start, s_end, k)`。最低限、次を保持する。

```text
seed, unit, s_start, s_end, k,
task_id, tau_start, tau_end,
x_start, x_end, delta_x, delta_x_per_step,
F_gate_start, F_self_start, F_rest_start,
p_hat_start, p_hat_end, on_start, on_end, near_off_start,
v_start, v_sign_start, w_norm_start, eval_loss_exact_start,
flip_cross
```

境界時刻 B の状態は flip 前なので、一般形は

```python
task_id = 0 if s_start == 0 else (s_start - 1) // T
tau_start = s_start - task_id * T
```

とする。`s_start//T` を無条件に使わない。

### 3.2 横軸と変位率

```python
x_start = cos_u_mu_start * w_norm_start
x_end   = cos_u_mu_end   * w_norm_end
delta_x = x_end - x_start
D_k     = delta_x / k
```

力と変位は、母集団ごとに必ず同一行集合から計算する。力だけ全記録点へ広げない。

一般に座標軸も変わる有限差分は、旧軸を基準にすれば

\[
x_1-x_0=(w_1-w_0)\cdot\hat\mu_0+w_1\cdot(\hat\mu_1-\hat\mu_0)
\]

と厳密に分けられる。第2項で `w_0` を使うなら交差項 `Δw·Δmu_hat` が別途必要であり、`Δw·mu_hat+w·Δmu_hat` とだけ書くと端点規約が曖昧になる。

本 spec では A13 により `mu_hat_1=mu_hat_0` なので第2項は厳密に 0、

\[
\Delta x=(w_1-w_0)\cdot\hat\mu_T
\]

である。したがって先生提案の「力による移動 (A)」は本 spec の `delta_x` そのものであり、別の主判定列へ差し替えない。

### 3.3 主格子

全条件共通の固定幅 0.1 格子

\[
[0.1j,\,0.1(j+1)),\qquad j\in\mathbb Z
\]

を使い、帯は `x_start` で割り当てる。端の疎な帯を結合しない。境界上の値は左閉右開に従う。帯代表点は `0.1(j+0.5)`。

既存 8/22c/d の 7 帯は再現接続用の副次出力だけに使い、根・主判定・ガード調整には使わない。

## 4. 主ペア — 固定開始コホート

### 4.1 実境界

各 seed で `diff(flip_state)!=0` となる 99 本の左端を実境界 B とする。

### 4.2 起点と k

各 B について

```text
s_start ∈ {B-100, B-99, …, B-41}  # 60 点
k ∈ {1, 2, 5, 10, 20, 40}
s_end = s_start + k
```

を使う。全 k で `(seed,unit,s_start)` が同一で、最大終点は `B-1`。境界直前まで含め、恣意的な終端バッファを置かない。学習系には境界を予知する機構がないため、k とともに終点が先へ進むことは除去対象ではなくホライズンそのものである。

w100 の全ユニットを使う U の期待行数は、各 k・各 seed で `99×60×100=594,000`、10 seed 合計 `5,940,000`。A はこの固定 U から始点条件だけで作る。

### 4.3 Δ1000 の別枠参考値

bulk の `k=1000` は、開始位相 `τ0∈{1000,…,8000}` のタスク内ペアだけを使う。`0→1000` は除外する。

したがって U の期待行数は各 seed・unit で 800 本、w100 では各 seed 80,000 本。

- 主 T0 と同じ図・判定表へ混ぜない
- `g_A(40)`、`P_g`、選抜分解の判定に使わない
- 「Δ1000 の符号逆転を T0 が直接説明した」と書かない
- 出す場合は常に `REFERENCE_CONFOUNDED_DOMAIN` と表示し、A4 を併記する

## 5. 母集団

各 k について次の 4 集合を作る。

| 記号 | 定義 | 用途 |
|---|---|---|
| A | `p_hat_start > 0` | 主母集団・固定開始コホート |
| S_k | A かつ `p_hat_end > 0` | 終点生存者 |
| L_k | A かつ `p_hat_end == 0` | 区間中に strict off へ落ちた個体 |
| U | 始点条件なし | 占有構成の記述 |

`A=S_k ⊔ L_k`。A と U は全 k で同じ開始行集合。S/L は未来条件なので k に依存する。

区間中に off へ落ちても `delta_x` を観測どおり使う。補完、右打ち切り、生存時間による再正規化はしない。

## 6. 曲線の集約

母集団 `M∈{A,S,L,U}`、seed s、帯 j、k ごとに、同じ行から

\[
F_{M,s,j,k}=\operatorname{mean}(F_{gate,start}),
\]

\[
D_{M,s,j,k}=\operatorname{mean}(D_k),
\]

\[
H_{M,s,j,k}=D_{M,s,j,k}-F_{M,s,j,k}
\]

を作る。その後、寄与する seed を等重みで平均する。全行を seed を無視してプールしない。seed ごとの標準化もしない。

### 6.1 区間平均力（副次）

主窓では各 step が記録されているため

\[
\bar F_{path}:=\frac{1}{k}\sum_{u=0}^{k-1}F_{gate,t+u}
\]

を副次出力する。遷移 `t+u→t+u+1` に対応する左端の力を k 本使う。主予測子は始点 `F_gate_start` のままで、結果を見て区間平均力へ差し替えない。bulk `k=1000` には中間記録がないため計算しない。

## 7. 根と位置差

### 7.1 曲線

seed 等重み集約後の帯平均を帯中心で結ぶ折れ線とする。平滑化・パラメトリック当てはめ・結果依存の帯結合をしない。

### 7.2 ガードと連結

§10.1 の主ガードを満たす帯だけを根の候補に使う。ガード落ちの帯は欠測として飛ばさず、そこで折れ線を切る。

さらに、根候補となる隣接 2 帯は**寄与 seed id の集合が完全一致**していなければ連結しない。8/10 と 8/10 でも顔ぶれが異なる 2 点を結ぶと、x の変化ではなく seed 構成差で偽の根が生じうるためである。結果を見て共通部分へ組み替えず、不一致ならその辺を切る。

### 7.3 天井根

- x の増加に対して **正→負**へ切る根だけを天井候補とする
- 複数あれば最も x が大きい根を主根とする
- 負→正の根とその他の根は個数・位置を別に報告する
- 非ゼロの隣接帯で正→負なら、帯中心間を線形内挿する
- 単独ゼロ帯で左が正・右が負なら、その帯中心を下降根とする
- 単独ゼロでも方向が決まらなければ主根にしない
- 連続ゼロ帯はゼロ区間として報告し、点根は `NaN`
- 外挿で根を作らない

### 7.4 位置差

各母集団・k について

\[
g_M(k)=z_{D,M}(k)-z_{F,M}(k)
\]

を作る。元標本でどちらかの根がなければ `g_M(k)=NaN`。

生存者条件付けコントラスト

\[
C_{surv}(k)=g_S(k)-g_A(k)
\]

は副次記述とする。A/S の必要な 4 根が同じ bootstrap 標本で存在するときだけ値を持つ。

## 8. 選抜の帯内混合分解

終点条件による顔ぶれの変化を、根ではなく ordinate の帳簿で先に分解する。`Y∈{F,D,H}` について、各 `seed×帯×k` で

```text
n_A       = A の行数
C_S^Y     = sum(Y rows in S) / n_A
C_L^Y     = sum(Y rows in L) / n_A
Y_A       = C_S^Y + C_L^Y
```

を計算し、その後 seed 等重みで平均する。分母の粒度を `seed×帯×k` より粗くしない。S または L が空なら対応する和は 0 とする。

各 `seed×帯×k` で

\[
off\_rate_s=1-\frac{n_{S,s}}{n_{A,s}}
\]

を作り、その後 seed 等重みで平均する。全行の比を直接取らない。

この分解が示すのは「固定開始コホートの差を、最終的な S/L のどちらの行が担ったか」である。未来の生存状態を操作した効果ではない。

## 9. Sanity gate

以下の structural sanity のいずれかが落ちたら `SANITY_FAIL` とし、主判定・CI を出さない。

### 9.1 構造

1. 10 seed、各 20,901 点、gap 分布が A1 と一致
2. 各 seed の実境界が 99 本で、A11 の補助マスクと完全一致
3. 主ペアの `(seed,unit,s_start)` 集合が全 k で完全一致
4. U の行数が各 k・各 seed 594,000、全 seed 5,940,000
5. `x_start`、`p_hat_start`、`F_gate_start` が同じ開始キーで全 k 完全一致
6. `tau_start` は全 k で同一集合、`tau_end=tau_start+k`、全終点が `B-1` 以下
7. `flip_cross.sum()==0`
8. §3.1 の必須元列と構成後の `x_start/x_end/delta_x` が全行で有限
9. 主ペアと bulk 参考ペアの全行で `flip_state_start==flip_state_end` が byte 一致。同じ flip から float64 で再構成した `axis_rotation_cos` は `|1-cos|<=64*eps(float64)` で照合し、`sanity.csv` に出す

### 9.2 母集団と吸収

1. `S_k⊆A`、`L_k⊆A`、`S_k∩L_k=∅`、`S_k∪L_k=A`
2. A と U の行数・キーが k に依らない
3. 各開始キーについて S の所属は k とともに単調非増加
4. U のうち `p_hat_start==0` の行は、全 k で `p_hat_end==0`、`F_gate_start=F_self_start=F_rest_start=0`、`delta_x=0`

### 9.3 力の分解

保存列を float64 へ変換してから全要素で

```python
rtol = 8 * np.finfo(np.float32).eps
atol = 8 * np.finfo(np.float32).tiny
abs(F_gate - F_self - F_rest) <= (
    atol + rtol * (abs(F_gate) + abs(F_self) + abs(F_rest))
)
```

を要求する。

### 9.4 混合恒等式

§8 の F・D・H の各恒等式を float64 で再照合する。許容差は

```python
rtol_mix = 64 * np.finfo(np.float64).eps
atol_mix = 64 * np.finfo(np.float64).tiny
```

を同じ混合形で使う。

### 9.5 1-step 統計 sanity

A について seed 等重みの pooled

\[
S_{one}=E[D_1-F_{gate,start}]
\]

を bootstrap する。95% CI が 0 を含まなければ `STAT_SANITY_FAIL_ONE_STEP` とし、主判定を抑止する。帯別 `H_A(1)` も出すが、個別帯の有意性だけでは gate を落とさない。

S/L は未来の生存で条件付けているため、この sanity の対象にしない。

## 10. ガードと bootstrap

### 10.1 元標本の帯ガード

`帯×k×母集団` ごとに次を固定する。

| 用途 | 最小寄与 seed | 最小総ペア数 |
|---|---:|---:|
| 主判定・根 | 8/10 | 300 |
| 記述 | 6/10 | 300 |

ガードは元標本で一度だけ決め、bootstrap 標本ごとに変更しない。S/L の寄与数を見て閾値を調整しない。ガード落ちの帯も図には表示できるが、明示的にマークし、根をまたいで連結しない。

根に使う隣接辺については §7.2 の seed 集合一致も元標本で固定する。

### 10.2 seed cluster bootstrap

- cluster は seed のみ
- 10 seed を復元抽出
- `B=10000`
- `bootstrap_seed=20260828`
- `OMP_NUM_THREADS=1`
- 95% percentile CI は有限な登録標本の 2.5/97.5 percentile
- A/S/L/U、全登録 k、F/D/H、混合分解を同一 resample index で回す

重複抽出された seed は `draw_id` の異なる別 cluster として 10 枠の平均に重複して入れる。元の seed id で再集約して重複を消さない。

ある帯の seed 内平均が存在しない draw 枠は、その帯の平均から外す。10 枠すべてが欠測なら当該 replicate は非有限とする。S/L の根では §10.3、根そのものでは §10.4 の規則に従う。

### 10.3 非有限値

根以外の推定量で bootstrap replicate に非有限値が 1 件でも出た場合、その推定量の CI を出さず `SANITY_FAIL_NONFINITE`。有限 replicate だけを選んで CI を作らない。

### 10.4 根の特例

根の `NaN` は「その標本では根が存在しない」という結果として扱う。

- `g_M(k)` の存在は、同じ replicate で F と D の根が両方有限であること
- `C_surv(k)` は、同じ replicate で A/S の F/D 4 根がすべて有限であること
- `P_g` は、同じ replicate で A の `k=1,40` の F/D 4 根がすべて有限であること
- 元標本で必要根がなければ CI を出さない
- 同時存在率 `>=0.95` の場合だけ、同時存在した replicate の有限値から percentile CI を作る
- 0.95 未満は `INCONCLUSIVE_UNSTABLE_ROOT`

## 13. 解釈の上限

### 言えること

- condA・w100・T=10^4・batch=1・std・境界前窓での、力と変位率の下降根の位置差
- 同じ開始コホートで k を 1 から 40 へ伸ばしたときの位置差の変化
- 終点 S/L が帯内の F・D・H を担う割合と生存者条件付けコントラスト

### 言えないこと

- Δ1000 の既知の符号逆転を T0 が直接説明した
- 選抜と道のりの因果寄与を完全に二分した
- 天井が `|F_self|/|F_rest|=1` である
- Q17 の `F_rest` 対称性
- centered、他の w、他の T、他の batch、他のデータセットへの一般化
- 真の介入効果
- 境界での `mu_hat` 回転が再分類死を増やすか（[[タスク方向回転M1_spec_0828]] の問い）
