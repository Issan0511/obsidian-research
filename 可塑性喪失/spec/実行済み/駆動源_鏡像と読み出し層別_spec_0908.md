## 1. 問いと予測

自然軌道に、殻極・角検出項の候補が予測する次の特徴があるかを調べる。

| 条件                     | 殻極の候補 | 角検出項の候補 | 復元力との関係       |
| ---------------------- | ----- | ------- | ------------- |
| K1（1 点だけ z>0）          | 負向き   | 負向き     | 復元力は反対向きになりうる |
| K31（1 点だけ z≤0）         | 正向き   | 弱い負向き   | 復元力は反対向きになりうる |
| small_v（読み出しの絶対値≤0.05） | 残りうる  | 弱まる     | 復元力も残りうる      |

**問いは観測的な整合性。合力の符号だけで各項の有無や支配率を決めない。** 問い合わせ §1 の「K1 では三つとも下」という文は、同じ節の定数極の表と矛盾するため採用しない。

## 3. 時刻・母集団・集約

T=10,000。t は完了したタスク数とし、tT が対応するタスク終端行であることをロガーの実装・タスク ID で確認する。

- 主窓: t=200,…,499。応答は N_i,t=zbar_i((t+1)T)−zbar_i(tT)。
- 状態の条件付けは (t−2)T の K、v、幅・端点を用いる。未来の情報は使わない。
- **これは「2 タスク前に K31 だった群の、その後の 1 タスク変位」。現在 K31 のユニットに働く瞬時力とは呼ばない。** 2 タスク遅らせても平均回帰・状態依存・未観測交絡が消える保証はない。
- gate 数は round(32 p_hat)、整数からの誤差≤10^-5 を検査。mob から復元する場合は p_hat=(mob−a)/(1−a) とする。a=1 では復元不能。
- K1/K31/K2、small_v / large_v を初期の規則で分類する。v は signed 列から |v| を取る。|v| 列しかなければ符号の補助解析を省略する。
- 開始時の過渡、同じタスクの重複記録、タスクが欠けた差分を除く。正しいイベント集合の個数を保存する。終端間 N のマスクを gap=1 の境界マスクと混同しない。
- N は支持変更と学習を含む。**tT+1 行を更新前の純粋な入力ジャンプとして扱わない。** この spec は J の純幾何分解をしない。

seed ごとに該当する unit×task の N の算術平均を取り、seed 間を等重みで平均する。長く滞在する個体ほど寄与する「該当イベントあたりの平均」である。総和を平均に代用しない。

各 seed・群について event 数、ユニーク unit 数、ユニーク task 数、滞在長、K((t−2)T)→K(tT) の遷移表を必ず出す。

## 4. 主 endpoint と判定

主 endpoint D31 = K31 群（small_v / large_v を合わせた群）の seed 等重み平均 N。

- 判定に使える seed: K31 がユニーク 5 units 以上、10 tasks 以上、50 events 以上ある seed。
- 有効 seed≥8 を要求。満たさなければ NOT_DETERMINED_OCCUPANCY。閾値は起草側の最低反復基準であり、検出力を保証しない。
- seed bootstrap 10,000 回、rng(20260908)、95% percentile CI。
- 生 z 変位の判定幅 δ_A=10^-4 / task。測りたい最小変位として事前に固定した運用値であり、理論予測ではない。

| ラベル             | 条件                   | 読めること                 |
| --------------- | -------------------- | --------------------- |
| K31_UP          | CI の下限>δ_A           | K31 過去状態群の正向き変位が解像された |
| K31_DOWN        | CI の上限<−δ_A          | 同群の負向き変位が解像された        |
| K31_WITHIN_BAND | CI 全体が [−δ_A,+δ_A] 内 | この窓・この精度では小さい         |
| NOT_DETERMINED  | 上記以外、在庫/品質/反復数不足     | 方向または大きさを判定できない       |

K31_UP を「殻極が主」、K31_DOWN を「殻極なし」、WITHIN_BAND を「角検出項が主」と読み替えない。

## 5. 副解析 — 主判定を差し替えない

1. D1、D2、K1/K31 の small_v / large_v 別 N。同じ反復数基準・95% CI・δ_A を使い、CI が 0 を含むだけでは「消えた」としない。
2. 幅 W=(zmax−zmin)/2、少数側の侵入量 d（K1 は zmax、K31 は −zmin）、|v|、κ、タスク時期の分布を並べる。K1/K31 の平均位置そのものを揃えることは要求しない（比較したい鏡像配置を消してしまう）。
3. 状態を揃えた感度解析: seed 内で K1/K31 を同じ 50-task 区間から、W、d/W、|v| の各順位の差≤0.1 の範囲で一対一対応させる。順位は両群を合わせた seed 内 ECDF。候補距離は順位差の二乗和、同距離は task→unit ID 順、置換なしの決定的 greedy 法。小さい群を task→unit 順で走査する。入力が足りなければ NO_COMMON_SUPPORT。正規化は対応付けにだけ使用し、応答は生の N のまま。
4. 元 B1 に対応する回帰は REPORT_ONLY: 各 seed・各 K 群で N=β0+βd d+βW W+βv |v|+βt(t−350)/100+誤差。説明変数は全て t−2、切片あり。説明変数を seed 内標準化して解き、βd を生の単位へ戻す。分散 0 または設計行列の条件数>10^8 は REGRESSION_UNIDENTIFIED。回帰係数の符号と平均運動の符号を混同しない。
5. 条件時刻を t に置いた版は平均回帰に対する感度表示。こちらだけで有意でも主判定を変更しない。
6. a 掃引の指数比較は今回は実施しない。別々に育った腕では幅・v・残差も変わり、(1−a)^2 と (1−a) の適合だけでは機構を分離できない。

## 6. 必須の健全性確認

- 必須列の seed/unit/step 軸が一致。先頭数件は元データの個別行と照合する。
- 解析窓の終端ペアは重複せず、正しいタスク差を持つ。欠測がなければ t の候補は 300 本/seed。
- zmin≤zbar≤zmax、p_hat の支持数整合、w_free がある場合は 5 次元であること。
- 再集計のコードと元 run の設定を保存する。既存 verdict と同定義の量があれば同じ窓・集約順で照合するが、別の量を一致検査に使わない。
- データ欠損・層別による標本不足と、数値的ゼロを区別する。

## 7. checkpoint で確認できる誤差成分（補助・学習なし）

元の 1M checkpoint の 32 点で残差 δ=f−y を再計算し、
m=mean δ、p=mean(δ q)、r=δ−m−p q を作る。エネルギーは E0=m²、EP=p²、ER=mean r²。

独立計算で mean δ²=E0+EP+ER を検算し、可能なら 32 個の Walsh 成分も出す。初期の mean(φ_i q) はユニットが parity 成分を表現しているかの指標であり、殻極の力そのものではない。

教師の状態まで復元できる場合は、元の状態から可能な flip bit 15 個を一つずつ仮想反転し、同じ自由 raw bit ID 上で教師応答 y_after−y_before を計算する。教師出力の成分と、生徒を更新せず入力変換まで反映した切替後残差の成分を**別々に**保存する。環境・乱数・checkpoint 本体は変更しない。

「教師の parity エネルギーが平均成分と同じ」は検査対象であり、前提に固定しない。平均成分のエネルギーが 0 の場合は比を定義せず、各エネルギーを出す。成分が大きいことは、その成分が変位を多く生むことを意味しない。
