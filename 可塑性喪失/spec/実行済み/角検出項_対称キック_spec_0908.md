# 角検出項 — 対称な蹴りとゲート切替を許さない対照（corner_kick_0908）

## 1. 問いと、測る介入効果

同じ状態に +h と −h の前活性の蹴りを与えたとき、再適応後に残る平均変位が、対象ユニットのゲート切替を許すかで変わるか。

角検出項の候補は、折れ目で傾きが変わるため正負の蹴りからの戻りが非対称になり、下向きの変位が残るというもの。本実験はその候補に対応する**ゲート切替の介入効果**を測る。

単なる「蹴りの後に沈んだ」は判定に使わない。固定ゲート対照にもパラメータ結合による非線形な応答がありうるため、対照との差を取る。

## 2. 初期状態と蹴り

親 §4 と B と同じ target ID・K1/K31 の初期世界を使う。各世界の介入前の出力 f0(X) を固定教師 y=f0(X) とする。X は全実験を通じて固定。

各対象ユニットの初期 z の絶対値から、0 より大きい相異なるマージン d1<d2<… を求める。10^-10 以内の値は同じマージンとしてまとめる。d1>10^-6 を適格条件とする。

振幅は初期の幾何だけから決める。

| 振幅      | 定義                 | 用途                            |
| ------- | ------------------ | ----------------------------- |
| h_below | 0.5 d1             | 蹴りの瞬間は横断なし                    |
| h_cross | [d1+min(d2,2d1)]/2 | 最初のマージンを越え、次の異なるマージンは越えない。主振幅 |
| h_multi | [d2+min(d3,2d2)]/2 | 2 番目のマージンも越える。REPORT_ONLY     |

d2 がない場合は h_cross=1.5d1、h_multi は NOT_AVAILABLE。d2 はあるが d3 がなければ h_multi=1.5d2。同じマージンに複数点がある場合、h_cross でも複数点が同時に横断しうる。**振幅名から横断点数を決めつけず実数を記録する。** 横断後ちょうど z=0 に一致する数値事故は検出し、丸めて都合のよい側へ入れない。

各振幅について、対象ユニットの b のみに +h / −h を加える。W、v、他ユニット、出力バイアスは蹴りの瞬間には変更しない。

これは前活性の並進だけを指定する診断であり、自然な flip bit 切替を再現する操作ではない。実際の flip は入力平均・入力変換・教師出力・全ユニットを同時に変えうる。

## 3. 比較する二つのモデル

### LIVE — 元の leaky

全ユニットで通常の φ(z)=max(z,az) を使用する。対象ユニットも、蹴り・学習による横断に応じて傾きが切り替わる。

### PRE_GATE — 対象ユニットだけ、支持点ごとに元の枝を延長

**蹴る前**の対象ユニットの 32 個の z_ref,r と傾き s_ref,r=φ'(z_ref,r) を固定し、同じ支持点 ID r に対して

φ_fixed,i(r;θ)=φ(z_ref,r)+s_ref,r [z_i(X_r;θ)−z_ref,r]

を使う。他ユニットは LIVE と同じ leaky のまま。

- 順伝播は上式、対象の z についての逆伝播の傾きは s_ref,r、v の勾配には上式の活性値を使う。**逆伝播だけを改変しない。**
- 初期には LIVE と PRE_GATE の出力・全パラメータが一致する。
- 初期に点ごとに違う傾きのパターンは保たれる。対象ユニットを支持全体で一つのアフィン関数に置換する実験ではない。
- 学習中も s_ref は更新しない。これは固定された 32 点の診断用モデルであり、新しい入力に一般化する活性化関数の提案ではない。
- 実装は支持点 ID を明示的に扱い、ミニバッチ順序によって別の傾きを割り当てない。

この対照は、**蹴りの瞬間とその後の再適応の両方で、対象のゲート切替を除く**。差が出ても「全てが境界瞬間の角検出」とは断定しない。対象の切替が残差を変え、他ユニットの再適応を変える経路も含めた効果を測る。

## 4. 腕と更新

各世界について、2 モデル×3 振幅×2 signs=12 枝と、両モデルの h=0 対照 2 枝、最大 14 枝を作る。h_multi が欠けても主比較は可能。全枝は独立に元の世界から開始する。

- y=f0 は両モデル・全 signs で同じ。蹴った後の出力を教師にして誤差を消さない。
- 教師を調整して正負の初期 MSE を揃えることはしない。正負の同じ前活性蹴りが、折れ目により異なる出力誤差を生むこと自体が検査対象だからである。
- 初期 MSE、残差の平均/parity/残りの成分、初期勾配ノルムを必ず比較する。
- 学習率 0.001、全 32 点、全パラメータ同時更新、1000 更新。PRE_GATE でも v を更新する。

## 5. 変位・主 endpoint

各枝で時刻 pre（蹴る前）、0+（蹴った直後、**更新 0 回**）、τ（τ 回更新後）を分ける。

対象 unit i の学習による変位:
R_(model,sign,i)(h,τ)=zbar_(model,sign,i)(τ)−zbar_(model,sign,i)(0+)。

h=0 の同じモデルの変位を R_(model,0,i)(τ) として、正負平均
D_model,i(h,τ)=[R_(model,+,i)+R_(model,−,i)]/2−R_(model,0,i)
を作る。

ゲート切替の介入差:
G_i(h,τ)=D_LIVE,i(h,τ)−D_PRE_GATE,i(h,τ)。

**主 endpoint** は、鏡像側を等重みで平均した、横断する蹴りと横断しない蹴りの介入差の差:
C_i = mean_(side∈{K1,K31}) [G_i(h_cross,1000)−G_i(h_below,1000)]。

親 §5 の target→seed 集約、97.5% CI、δ_z=10^-5 で判定する。

| ラベル                    | 条件                   | 読めること                  |
| ---------------------- | -------------------- | ---------------------- |
| CROSSING_DOWN_CONTRAST | C の CI 上限<−δ_z       | 横断振幅でゲート切替の介入差が相対的に負向き |
| CROSSING_UP_CONTRAST   | C の CI 下限>δ_z        | 同じ比較で正向き               |
| CROSSING_WITHIN_BAND   | CI 全体が [−δ_z,+δ_z] 内 | この精度で小さい               |
| NOT_DETERMINED         | 帯を跨ぐ、反復数・数値品質不足      | 判別不能                   |

C は振幅間の差なので、C<0 だけでは G(h_cross)<0 を意味しない。**G(h_cross)、G(h_below)、LIVE/PRE_GATE の各 D、K1/K31 別の符号を必ず併記する。** 一方の鏡像側だけが支配していても「両側とも下」とは書かない。

K1/K31 の平均は殻極を厳密に消す操作ではない。こちらで測った C を、B の P と足し引きして自然な変位の寄与率にしない。

## 6. 横断と適応量の記録

- 蹴りの瞬間: sign ごとの各 support ID の前後 z、横断方向、横断点数、gate の変化。
- 学習中: 対象ユニットの横断数、初めて横断した更新、support ID、他ユニットの横断数。PRE_GATE では z の符号変化と実際の傾き固定を別列にする。
- h_below でも学習中には横断しうる。G(h_below) が非ゼロならその可能性も調べる。横断した枝を後から除くことはしない。
- 各枝で MSE(τ)/MSE(0+) を出す。MSE(0+)≤10^-20 なら NO_FIT_SIGNAL とし比は NaN、変位そのものは保存する。v=0 等で蹴りが出力に効かない例を「戻りが対称」とは判定しない。
- 主比較の全 2 models×2 signs×2 amplitudes×2 sides について MSE 比≤0.1 を満たす target の割合を出す。元 seed の 80%以上で target の過半数がこの条件を満たさなければ FIT_LIMITED を付記する。主サンプルは事後選別しない。
- 学習による b、w_flip、w_free の寄与と幅の変化を保存する。蹴り自身の Δb=±h は R に混ぜない。

FIT_LIMITED / NO_FIT_SIGNAL が多い場合、小さい C を「十分に戻した後も角検出がない」という否定には使えない。

## 7. 1 更新目の独立検算 — 機構の発見には数えない

固定支持の平均を μ_X とする。対象だけに b の蹴りを与え、教師は蹴る前の出力なので、LIVE の初期残差は
δ_r = v_i [φ(z_ref,r+sign h)−φ(z_ref,r)]。

従って最初の更新による対象の平均前活性変位は
R_LIVE,sign,i(h,1)
=−2η v_i² mean_r{[φ(z_ref,r+sign h)−φ(z_ref,r)] φ'(z_ref,r+sign h) [1+X_r·μ_X]}。

PRE_GATE は同式の活性差を s_ref,r sign h、微分を s_ref,r に置き換える。これを、実装が返した新旧 W/b から計算した変位と突き合わせる。

- **この 1 更新式の v² は代数的に決まる。観測しても v² 機構が発見されたとは言わない。**
- 正負平均で残る leaky の局所効果と、長い再適応後の C は別の測定。
- 1000 更新では v と全ネットワークも動くため、同じ指数をそのまま仮定しない。
- 固定された離散支持では |h|<d1 は横断ゼロ。「蹴りの 1 乗」を h→0 の全域に当てはめない。今回の 3 振幅から普遍的なべき指数を主張しない。

## 8. 必須の検査と図

共通前検査に加えて:
1. pre で LIVE と PRE_GATE が一致、0+ の zbar 変化が正確に ±h、蹴りによる W の変化は 0。
2. φ(z_ref+sign h)−φ(z_ref)−s_ref sign h を 32 点で計算し、横断しない点では 0。LIVE/PRE_GATE の 0+ 出力差が v_i×この余りに一致。
3. h=0 の状態は不変。
4. 対象が一度も横断しないように構成した遠い支持の人工例では、LIVE/PRE_GATE の短時間の全パラメータ軌道が一致。横断を与えた例では少なくとも forward/gradient の差を検出できる。
5. a=1 の人工例では全振幅で LIVE/PRE_GATE が同じモデルになり、G=0。**D_LIVE 自体を 0 と要求しない**（v と w がともに更新される因子化モデルの非線形な応答は残りうる）。
6. PRE_GATE の支持点を並べ替えても対応を保てば結果が同じ。backward だけの改変は有限差分検査で落ちること。
7. 1 更新式の数値検算（許容は共通 §6）。

## 9. 予測・出力・帰結

候補予測は CROSSING_DOWN_CONTRAST。ただし自然な入力 flip の仮説を、バイアスだけの蹴りへ移植した診断である。元の角検出式がこの初期状態・1000 更新にも必ず適用できるという導出はまだない。大きさと確率は未指定、Issa の予測は任意。

出力: results/corner_kick_0908/。共通ファイルに kick_geometry.csv、gate_events.csv、first_step_check.csv、fit_diagnostics.csv を追加。初期の gate テーブルと教師を保存し、全枝の生変位から D/G/C を再計算できるようにする。

正の証拠は「対象のゲート切替を許すと、対称な蹴りへの有限時間応答が変わる」。これは自然なタスク境界の沈下を全て説明したことでも、殻極が存在しないことでもない。差の発生が 1 更新目か後続の再適応かを時系列で記述し、元の教師・自然な入力切替への接続を次の未解決点として残す。
