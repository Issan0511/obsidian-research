# 殻極 — parity の誤差への再適応で跨ぎを解く運動が出るか（shell_parity_0908）

親: [[殻極と角検出項_検証計画_0908]] / 状態: **未着手** / 作成・更新: 2026-09-08 / 起草: Issan/Codex
背景: [[駆動源_Kuboからの問い合わせ_0906]] §1 / 関連: [[駆動源_鏡像と読み出し層別_spec_0908]]／[[角検出項_対称キック_spec_0908]]
**共通の checkpoint 選択・鏡像構成・更新・統計・前検査・保存は親ノート §3–§7 を本 spec の一部とする。実装・実験・事前登録 commit は未実施。**

## 1. 問いと仮説

入力支持を動かさず、parity 成分の出力誤差への再適応だけで、K1 を負側へ・K31 を正側へ動かす応答が生じるか。

殻極の候補は「parity の誤差を消すときの v と w の連動が、跨ぎを解く向きの平均変位を生む」。この仮説から制御された課題への方向予測を立てる。ただし元の教師・タスク切替からこの診断課題へ移したときの厳密な係数・適用条件は未導出。**否定結果を元の殻極候補全体の無条件な反証とはしない。**

主実験は全ネットワークを更新する。v_freeze、単一ユニットだけの更新、出力バイアス固定は主腕に含めない。これらは誤差を誰が担うかと v-w の連動を変える。

## 2. 初期世界と診断教師

親 §4 に従い、元 1M checkpoint の同じ対象ユニットから K1/K31 の 2 世界を作る。入力 X は 32 点で固定し、各世界の初期全ネットワーク出力 f0 を保持する。

元のバイアスを変更する前の checkpoint 出力を f_orig とし、seed ごとに
Y=max(1, sqrt(mean_r f_orig(X_r)^2))
を定める。Y は出力単位の介入振幅を決める固定尺度で、全 target・鏡像側・誤差モードに同じ値を使う。学習中には更新しない。

誤差モード:
- u_mean(r)=1。
- u_parity(r)=q_r=(-1)^(自由 raw bit 5 個の和)。
- u_bit(r)=(-1)^(最初の自由 raw bit)。raw 添字 15 の bit を使う。

いずれも mean u²=1、互いに直交する。各世界で次の**固定教師**を作る。

y_(mode,sign)(X_r)=f0(X_r)+sign × ε × u_mode(r), sign∈{−1,+1}。

教師の f0 は detach して保存し、現在の出力に追随させない。これは初期残差の成分を指定する実験であり、毎更新の残差を parity 空間に射影し続ける実験ではない。他成分の残差は途中で生じうるので測る。

## 3. 腕（1 初期世界あたり 11 枝）

| 腕                          | ε/Y  | 符号    | 用途                 |
| -------------------------- | ---- | ----- | ------------------ |
| ZERO                       | 0    | —     | 新たな誤差なし。基準変位       |
| MEAN_PLUS / MEAN_MINUS     | 0.03 | + / − | 平均成分、初期誤差エネルギーを揃える |
| PARITY_PLUS / PARITY_MINUS | 0.03 | + / − | **主比較**            |
| BIT_PLUS / BIT_MINUS       | 0.03 | + / − | 低次数の入力依存成分との比較     |
| PARITY_SMALL_PLUS / MINUS  | 0.01 | + / − | 振幅感度、REPORT_ONLY   |
| PARITY_LARGE_PLUS / MINUS  | 0.10 | + / − | 振幅感度、REPORT_ONLY   |

初期 MSE は非 ZERO 腕で ε²。**同じ初期誤差エネルギーでも、学習しやすさ・勾配ノルム・必要なパラメータ変化は同じにならない。** その違いを消すための事後的 lr/ε 調整はしない。差を記録して解釈する。

全枝は同じ初期世界から独立に開始。正の教師を学習した後に負の教師を与える連続実験ではない。学習率 0.001、1000 full-support 更新、全パラメータ更新という共通設定を使う。

## 4. 測定量と主 endpoint

同じ世界・対象 unit i の各枝で
d_(mode,sign,i)(τ)=zbar_(mode,sign,i)(τ)−zbar_i(pre)
とする。ZERO の変位を d_ZERO,i(τ) として、符号について偶な応答を

D_mode,i(τ)=[d_(mode,+,i)(τ)+d_(mode,−,i)(τ)]/2−d_ZERO,i(τ)

と定義する。符号について奇な応答 [d_+−d_-]/2 も別列で保存する。

**主 endpoint は同一対象ユニットの鏡像差**
P_i=[D_parity,i,K31(1000)−D_parity,i,K1(1000)]/2。
ε=0.03Y のみを使い、親 §5 の集約・97.5% CI・δ_z=10^-5 で判定する。

| ラベル                     | 条件                   |
| ----------------------- | -------------------- |
| PARITY_OUTWARD_CONTRAST | P の CI 下限>δ_z        |
| PARITY_INWARD_CONTRAST  | P の CI 上限<−δ_z       |
| PARITY_WITHIN_BAND      | CI 全体が [−δ_z,+δ_z] 内 |
| NOT_DETERMINED          | 帯を跨ぐ、反復数・数値品質不足      |

この P>0 は「parity 条件で K31 側の応答が K1 側より正向き」を意味する。**P>0 だけでは K1 が負・K31 が正の両方を満たすとは限らない。** D_parity,K1 と D_parity,K31 を生の符号・95% CI 付きで必ず並べ、どちらか片側だけの寄与を隠さない。

この主判定は平均成分の応答を「復元力」として差し引いたものではない。異なるモードへの有限時間応答の差を、自然な学習の独立な力の和と解釈しない。

## 5. 適応量と、結果の解釈を制限する条件

各非 ZERO 枝で MSE(τ)/ε² と、投与したモードの残差係数 mean[(f−y)u_mode]/ε を記録する。教師の平均成分が変わる MEAN 腕でも、信号分散を分母にしてゼロ除算しない。

- 適応量の記述: MSE(1000)/ε²≤0.1 を「90%以上の誤差エネルギー減少」、≤0.01 を「99%以上」とする。全枝の割合を報告する。
- target 単位の適応成立フラグ: parity の 2 signs×2 sides の全てが 0.1 以下なら FIT90_ALL_BRANCHES。これは残差比の診断フラグであり、主サンプルをその条件で選抜しない。
- 元 seed の 80%以上で target の過半数が FIT90_ALL_BRANCHES を満たさなければ、結果には FIT_LIMITED を付記する。P が小さい/逆向きでも「十分な refit 後の殻極は存在しない」とは言えない。
- 学習後に都合のよい時刻を選ばない。1000 更新の主 endpoint を保ち、未収束なら未収束として示す。長い refit への変更は実行前の追補で別 protocol にする。

ゲート切替は初期介入では 0（入力・前活性を教師設定時に動かさない）。学習による横断は毎更新数える。途中横断のある specimen だけを除いた解析を主判定にしない。横断が多ければ「入力ジャンプなしの効果」であって、「角を一切使わない効果」とは書けない。

## 6. 補助 endpoint と図（全て REPORT_ONLY）

1. D_mean、D_bit、および P_mean、P_bit。P_parity−P_mean、P_parity−P_bit の paired 差も出す。parity と他モードで同じ応答なら「parity 固有」の証拠は弱い。
2. 振幅別の生 D と P。ε を変えたときの偶応答の形を示す。P/ε² は振幅応答の診断としてのみ使い、物理的な生の力の代わりにしない。
3. b と w の寄与: 固定支持なので、d=Δb+Δw·mean(X) を毎点検算して表示。自由 5 bit と flip 15 bit の寄与も分ける。
4. 中心と幅の同時変化、少数側端点の変化。初期の端点を与えた固定 support ID の z と、現在の min/max を別々に保存する。
5. 対象の v、平均活性 mean φ、parity 活性 mean(φq)、残差の平均/parity/残りのエネルギー、他ユニットの gate 切替。
6. 自然な初期 |v|≤0.05 の target が十分ある場合の層別。元 seed≥8 がなければ単なる記述。**層別比較から v^0 や v² を因果的な指数として推定しない。**
7. 図: 初期 K1/K31 の 32 点配置、D_mode(τ)、1000 更新の鏡像 paired 図、残差比の時系列、P の振幅応答。誤差棒は seed 単位。

## 7. 実装検査

共通前検査に加えて以下を行う。

- mean q=0、mean q²=1、3 モードの Gram 行列が単位行列（許容 10^-12）。raw bit ID を並べ替えたら X・教師・q も同じ並びになること。
- sign 枝の初期パラメータ・X が一致し、f0 が更新中不変。
- 最初の更新の d_+ と d_- は反対符号、D_mode(1)=0（許容 10^-10）。**これは初期残差に対する勾配の線形性による検算であり、殻極の不存在の証拠ではない。**
- 実装の full-support 勾配と、32 個の単点勾配の平均が一致する。
- 独立の記述検査として、初期状態で対象の支持が単一アフィン枝に全て収まる人工例では mean(φq)=0 を確認する。対象が parity を表現できない場合に、係数がないことを正しく検出できること。
- a=1 の小さな検査モデルでは全ネットワークがアフィンなので pure parity 誤差に対する full-support 勾配が 0。これは表現容量の検査であり、「三つの力が全てゼロ」という実験的発見には数えない。

## 8. 予測、出力、主張の上限

候補予測: D_parity,K1<0、D_parity,K31>0、従って P>0。mean/bit との大きさの順位や、定量的な係数は予言しない。Codex はこの制御課題への移植を検査すべき候補として提案しており、確率は未指定。Issa の予測は任意欄。

出力: results/shell_parity_0908/。共通ファイルに mode_targets.npz、initial_worlds.csv、mode_energy.csv、fit_diagnostics.csv を追加する。初期世界・出力尺度 Y・ε・target ID・生の枝別変位・偶/奇応答を再計算できる形で保存する。

正の主判定で言えるのは「指定した診断条件で parity 再適応が鏡像間の外向き応答差を生んだ」まで。両側の方向、他モード対照、適応量、横断回数を合わせて機構との整合性を記述する。**自然な沈下のうち殻極が何%を担うか、LoP の原因か、v に無依存かはこの主実験だけでは決まらない。**
