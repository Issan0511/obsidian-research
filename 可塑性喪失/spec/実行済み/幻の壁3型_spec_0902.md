## 0. 一行

`BL` は「幻の残差項」で、µ の壁の力（パターン平均 $\bar g$ の µ 成分）が壁の向こうでも同じ向きに続くため発散した。壁の力を止める幻の作り方は 3 つある: 負側ゲートの**符号を反転**する（`BLR`）、反転を**深さ比例**にする（`BLQ`）、幻の勾配から **µ 射影だけ抜く**（`BLP`）。恒等式（[[自己項の実在_力場_0902]] §3）は「反転 2 型は壁の力と一緒に呼び戻し信号も消す（聞こえない）、射影型だけ信号が残る」と予言する。**幻はどれも $\lVert w\rVert$ のバネを持たない**ので、w-WD を掛けた対を置き、幻とバネのどちらが何を担うかを分ける。

**動機**: (i) 恒等式の「反転は聞こえない／射影は聞こえる」を発症数で判別する。(ii) 幻の 3 型のどれも $\lVert w\rVert$ にバネが無い（射影型は $\sqrt t$ で伸びる予想）ので、w-WD がバネの代替になるかを同時に見る。(iii) 「幻の壁は弊害しかない」を、型ごとに「発散」「聞こえない」「効く」のどれかに割り振る。

## 2. 何を分けるか（未登録の Claude の推論）

沈下パターン（$z_p\le0$）での幻ゲート $\gamma_p$ と、それが $\bar g$（壁＋呼び戻し）・$a_p$（揺らぎ）に掛ける係数:

| 腕 | 負側ゲート $\gamma(z)$ | $\bar g$ の係数（釣り合い時） | 揺らぎの係数 | $\lVert w\rVert$ のバネ | 予言される型 |
|---|---|---|---|---|---|
| `BL`（済） | $+a$ | $|F|+a|S|>0$：壁の力が続く | $1-a$ | なし | **発散**（実測） |
| `BLR` | $-a$ | $|F|-a|S|=0$：壁も呼び戻しも消える | $1+a$ | なし | **反射壁・聞こえない** |
| `BLQ` | $a_Q z$（$z<0$ で負・深さ比例・$a_Q=0.01$） | 深さ加重で 0 になる点あり | 深さ加重 | なし | **硬い反射壁・聞こえない** |
| `BLP` | $+a$、ただし $w$ の幻勾配から $\hat\mu$ 射影を抜き、$b$ の幻勾配は 0 | µ 成分 0・呼び戻し成分は残る | $1-a$（$\hat\mu$ 直交） | なし（$\sqrt t$） | **信号は残る・ノルムは伸びる** |
| `*w`（各型 + w-WD） | 同上 | 同上 | 同上 | $\lambda_w$ | バネの代替 |
| `RWw`（ReLU + w-WD） | $0$ | — | — | $\lambda_w$ | **w-WD 単独の対照** |

- `BLR`・`BLQ` は壁の力を止める代償に呼び戻しも止める。発症するなら「聞こえない」の直接の証拠。発症しないなら §3 の恒等式が間違っている
- `BLP` は $s=(w\!\cdot\!\mu+b)/\mathrm{denom}$ が幻では動かない（$w$ の µ 成分と $b$ を幻が触らない）。復帰は $w$ の直交成分が $z_p$ の広がりを変えることでのみ起きる。信号は正しい符号で残る
- w-WD は alive ユニットにも掛かる。**`RWw` が無いと w-WD 自体の LoP 抑制（既知の L2 効果）と幻の効果が分けられない**

**本走が答えないこと**: $a$・$\lambda_w$ の掃引、b-WD との組合せ、多層、Adam。

### 4.1 腕（新規 7 本 ＋ 対照 3 本は committed）

| `RW_1216`   | 0                | 0                                 | なし（b-WD 1e-3） | committed（`bwd_leak_0902`）・参考 |
| `BLR_1216`  | 0                | $-a$                              | なし            | **新規**                        |
| `BLQ_1216`  | 0                | $a_Q z$（$a_Q=0.01$）               | なし            | **新規**                        |

| `BLRw_1216` | 0                | $-a$                              | $\lambda_w$   | **新規**                        |

- $a=0.1$（`gate_dose`・`bwd_leak` と同値）。**ただし `BLQ` のみ $a=0.01$**（§下記）
- **`BLQ` のスケール（9/2・Issa 裁定）**: 負側ゲートは **生の $z$ を使い $\gamma(z) = a_Q\,z$、$a_Q = 0.01$**。sd 正規化は採らない（sd の推定方法という実装自由度が増え、事前登録が甘くなるため）。生 $z$ で $a_Q=0.1$ だと `bwd_leak` の診断走で見えた深さ（$\bar z \sim -30$）で $|\gamma|=3$ となり発火ユニットより強い勾配が掛かるので、$a_Q=0.01$ に下げて $|\gamma|\le0.3$ に収める。**したがって `BLR`（$a=0.1$）と `BLQ`（$a_Q=0.01$）は係数が異なり、両者の対比は「反転の有無」ではなく「深さ依存の有無」としてのみ読む**（§8）
- **$\lambda_w = 1\times10^{-4}$（9/2・Issa 裁定）**。隠れ層の $W$ のみ（$v$・$b$・$c$ には掛けない）。b-WD の 1e-3 と揃えなかったのは、**対照 `RWw` が「効かない」側にいてくれないと Xw の 0/10 を幻に帰属できない**ため。1e-3 で `RWw` が 0/10 になると全腕の効果が w-WD で説明され、本走の問いに答えられない
- **`BL`・`BLW` は再走しない**（発散が既知）

### 4.2 対応づけ

幻ゲート・射影・w-WD はいずれも乱数を消費しないので、新規腕は `gate_dose_0830` の各腕と init・教師・入力列・flip が bit 一致する（S-pair）。paired 対比は committed の seed 別 $U_k$ を相手に取る。

### 4.3 実装

- `VecMLPL` に `act='bwd_reflect'`（`BLR`）: 前向き `relu`、後ろ向き `where(pre>0, 1, -a)`
- `act='bwd_quad'`（`BLQ`）: 前向き `relu`、後ろ向き `where(pre>0, 1, a_Q*pre)`、`a_Q=0.01`
- `act='bwd_leaky_proj'`（`BLP`）: 前向き `relu`、後ろ向き `where(pre>0, 1, a)` で $w$・$b$ の勾配を計算したあと、**沈下パターン由来の寄与だけ**に (i) $w$: $g \mapsto g - (g\!\cdot\!\hat\mu)\hat\mu$、(ii) $b$: $g_b \mapsto 0$ を適用。$\hat\mu$ は用量固定で実際に加えたオラクル µ の単位ベクトル（`dose_const_5m_0830` から取る）。batch=1 なので「沈下パターン由来」は「そのステップで $z_i\le0$ のユニット $i$ の勾配」と等価
- w-WD は `VecMLPL.set_weight_decay_w(λ)` を新設（$W$ のみ。$\Delta W = -\eta\lambda W$ を各ステップ加算。`set_weight_decay_b` と同じ差し込み位置）
- **ReLU・leaky・`bwd_leaky`・`fwd_leaky` の経路は触らない**

### 4.4 用語

全腕 forward が ReLU なので `strict_dead`（$\hat p_i\equiv0$）はそのまま。`BLR`・`BLQ`・`BLP` は**吸収でない**（負側に幻の勾配がある）。`BLP` は $s$ が幻では動かない（**µ 方向には吸収・直交方向には可動**）。

- **`BLR`: `PHANTOM_DEAF`**（発散せず 10/10）。$\hat p$ が 0.09 付近に山、沈下率 ≈0。理由: §3 の恒等式で $\bar g$ が消える
- **`BLQ`: `PHANTOM_DEAF`**。ただし深さ比例の反転は $\lVert w\rVert$ の直交ランダムウォークに対して弱い側の抑えしか持たないので、`BLR` より水準が悪いか、5M 前に発散する可能性を 3 割見る。**$a_Q=0.01$ に下げた分、浅い側での抑えは `BLR` より弱い**（$|z|<10$ で $|\gamma|<0.1$）
- **`BLP`: `PHANTOM_NEEDS_SPRING`**（単独は ≥5・`BLPw` は 0）。理由: 信号は残るが $s$ が µ 方向に凍っており、復帰が直交成分の広がり頼みで遅い。$\lVert w\rVert$ 成長指数 ≈0.5。w-WD を掛けると広がりが保たれて復帰できる
- **`RWw`: ≥5**（w-WD 1e-4 単独では止まらない）。1e-3 なら止まる側に寄る
- w-WD が壁座標に及ぼす作用: `RWw`−`R` で `median_M` が 0 側へ動き `median_B` は動かない（b-WD の鏡像・P7）

### 7.3 外れたときに第一に疑うもの（Claude）

(i) `BLP` の射影実装（S-proj）。(ii) $\lambda_w=1\text{e-}4$ の較正不足（`RWw` が 0 なら w-WD が強すぎ、全腕が w-WD で説明される）。(iii) `BLQ` の $a_Q=0.01$ が弱すぎて `BL` と同型に発散する（発散ならまずここ。`bwd_leak` の診断走の深さ $\bar z\sim-30$ でも $|\gamma|\le0.3$ に収まる設計だが、より深くまで行けば $|\gamma|>1$ はあり得る）。(iv) `BLR` が 0/10 なら §3 の恒等式のどこかが誤りで、まず「$\bar g$ に呼び戻しが含まれる」という同定を疑う
