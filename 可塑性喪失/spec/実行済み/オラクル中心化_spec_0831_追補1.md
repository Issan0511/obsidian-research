# オラクル中心化 spec 追補1 — 境界マスクから初期過渡を外す

親: [[オラクル中心化_spec_0831]] / 出所: [[centered死因分解_posthoc_spec_0831]] の実行結果（`centered_death_posthoc_0831` / `d38a391`）
状態: **実行済み追補（オラクル走の endpoint 計算前に事前凍結）** / 作成 2026-08-31 / 実行 2026-08-31

> **本追補は `center_oracle_0831` の結果を見る前に commit する。** 親 spec の P1 は endpoint の**定義**を [[centered死因分解_posthoc_spec_0831]] §2 E3 から継承しており、その定義に欠陥が見つかったので継承先を差し替える。**判定閾値（0.2 / 0.8）は変更しない。**

---

## 1. 直す欠陥

E3 の境界窓マスクは `step % 10000 == 1000` で定義されており、**500 個**の遷移を拾う。しかし `flip_state` の変化は seed あたり **499 回**しかない。差の 1 個は **step 0 → 1000 の遷移**で、これはタスク切替ではなく **EMA の初期収束過渡**である（`running_mean` が初期値から第1タスクの平均へ動く窓）。

実装側の S3 はこの不一致を検出して note に「499 changes / boundary mask contains 500 transitions」と書いているが、**マスクはそのまま使われている。**

### 影響の実測（`mlp2_phase1_0829` ログからの独立再計算・事後）

| 腕 | 登録定義（500） | 真の切替のみ（499） | step0→1000 単独 |
|---|---:|---:|---:|
| `L1w100_A1` L1 | −4.297 | **−4.199** | −0.279 |
| `L2_A1` L1 | −2.190 | **−2.127** | −0.310 |
| `L2_none` L1 | −4.666 | **−4.322** | −0.155 |

**E3・E4 の判定は変わらない**（符号も大小関係も保存。`BOUNDARY_CARRIES_DESCENT` / `CENTERING_REDUCES_BUT_NOT_REMOVES` はそのまま）。したがって `centered_death_posthoc_0831` の登録判定は**書き換えない**。

### なぜオラクル走では効くのか

親 spec の P1 は**比** $R=\lvert\Delta\beta^{\rm bnd}(\text{Aexact})\rvert / \lvert\Delta\beta^{\rm bnd}(\text{A1})\rvert$ である。オラクル腕は支持平均を step 0 から厳密に引くので、**EMA の初期収束過渡が構成上存在しない**。すなわち step0→1000 の項は

- 分母（A1）には $-0.28$ 程度が入る
- 分子（Aexact）には EMA 由来の寄与が入らない

という**非対称な混入**になる。分母への影響は 6.5% で小さいが、**分子は B1 が正しいときに小さくなる量**であり、そこに 0.28 の非対称項が乗ると `EMA_LAG_IS_THE_CAUSE`（$R<0.2$、すなわち $\lvert\Delta\beta^{\rm bnd}(\text{Aexact})\rvert\lesssim 0.86$）の判定を **30% 規模で押し下げる**。**判定が最も面白い regime でだけ効く artifact** なので、閾値を動かさず定義を直す。

これは [[運用ルール]] §5 教訓②（指標が測定対象の一部で恒真になっていないか）の変種で、**マスクの要素数と、それが表す物理イベントの回数が一致するかの検算**が抜けていた事例である。

## 2. 差し替える定義

親 spec §3 の $\Delta\beta^{\rm bnd}$・$\Delta\beta^{\rm int}$ を次で置き換える。

- **境界窓** := `step % 10000 == 1000` **かつ** 当該遷移で `flip_state` が実際に変化した遷移。**499 個**
- **内部** := `step % 10000 != 1000` の遷移。**4500 個**
- **初期過渡** := step 0 → 1000 の遷移。**1 個。どちらにも入れず、単独の行として報告する**

サニティを 1 本足す。

| id | 内容 | 基準 |
|---|---|---|
| **S9** | 境界窓マスクの要素数が `flip_state` の変化回数と一致 | 499 = 499（seed ごと）。**不一致なら走を破棄しない代わりに endpoint を出さない** |

## 3. 報告の形

`verdict.csv` に次の 3 行を腕ごとに出す。

1. `dbeta_boundary_499`（**P1 の判定に使う**）
2. `dbeta_internal_4500`
3. `dbeta_startup_0to1000`（REPORT_ONLY。オラクル腕と EMA 腕でこの値がどう違うかは、EMA 初期収束の大きさそのものの記述統計になる）

併せて、**登録定義（500）版の $R$ も REPORT_ONLY で併記**する。両者で判定が割れた場合は「割れた」ことを結果として記録し、**P1 は 499 版を採る**。
