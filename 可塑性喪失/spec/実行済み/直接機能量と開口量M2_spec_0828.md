## 0. 定義と問い

現タスクの32入力に対し、unit i の preactivation と開口量を

\[
z_i(x,t)=W_i(t)x_{in}+b_i(t),\qquad
S_i(t)=\frac1{32}\sum_{x=1}^{32}\max(z_i(x,t),0)
\]

と定義する。主転帰は

\[
\Delta S_i=S_i(t_1)-S_i(t_0)
\]

である。`delta_S` が大きいとは、区間中に開口量がより増えた、またはより小さく減ったことを意味する。

比較は作業6で固定された同一幾何セル内の `utility_nmse_group=high` 対 `low`。`mid` も分布記述するが主判定に使わない。

### 2.2 必須一致検査

1. リプレイ最終時の `net/env/teacher/running_mean/eval_fixed/全generator/cbp` hash 辞書が元 `instrumentation_meta.json.final_state_hashes` とキー・値とも完全一致

### 2.3 S の計算とサニティ

`_forward_context(st)` が作る float64 `activation=relu(pre)` を使い、

```python
S = activation.mean(dim=0)  # [run, unit], denominator is always 32
```

を保存する。全記録で次を必須にする。

- support size = 32
- `S` は有限かつ `S>=0`
- `S==0` と `p_hat==0` が完全一致
- 決定論的に選ん20例で、32パターンを loop した scalar 平均と vectorized S の最大絶対誤差 `<1e-12`

## 4. 主推定量—セル内優越確率

各有効セル c で、`Y=delta_S` に対し

\[
PS_c(Y)=\frac{1}{n_{H,c}n_{L,c}}
\sum_{h\in H_c}\sum_{l\in L_c}
\left[1(Y_h>Y_l)+\frac12 1(Y_h=Y_l)\right]
\]

\[
A_c(Y)=PS_c(Y)-0.5,\qquad w_c=\min(n_{H,c},n_{L,c})
\]

\[
A_{\Delta S}=\frac{\sum_c w_c A_c(\Delta S)}{\sum_c w_c}
\]

とする。`A_deltaS>0` は、同じ幾何セル内で high の `delta_S` が low より大きい確率が高い、すなわち high がより開いた/押し下げられにくい方向を意味する。

優越確率を主にする理由は、先生の問いが「分布の違い」であり、S の実測スケールを見ずに意味のある raw 平均差の等価幅を置けないため。

同じ式を `Y=S0` に適用した `A_S0` を「起点が遠いか」の副判定に使う。

## 5. 主判定

20 seed block bootstrap の95% percentile CIを使う。等価域は優越確率の差 `+-0.05`（`PS=0.45..0.55`）。作業6/r-swap で使った5 percentage point と同じ有意幅を、尺度非依存の確率差に適用する。

### 5.1 動的差 `M2_dynamics`

| `A_deltaS` の95% CI | 判定 |
|---|---|
| CI 全体が `[-0.05,+0.05]` 内 | `EQUIV_DYNAMICS` |
| CI 下端 `>+0.05` | `HIGH_LESS_PUSHED` |
| CI 上端 `<-0.05` | `HIGH_MORE_PUSHED` |
| それ以外 | `INCONCLUSIVE` |

上から順に排他的に適用する。`INCONCLUSIVE` を「押し下げ方は同じ」と書かない。

### 5.2 起点差 `M2_baseline`

| `A_S0` の95% CI | 判定 |
|---|---|
| CI 下端 `>+0.05` | `HIGH_STARTS_MORE_OPEN` |
| CI 上端 `<-0.05` | `HIGH_STARTS_LESS_OPEN` |
| CI 全体が `[-0.05,+0.05]` 内 | `EQUIV_BASELINE` |
| それ以外 | `INCONCLUSIVE_BASELINE` |

### 5.3 組み合わせの読み

- `EQUIV_DYNAMICS` + `HIGH_STARTS_MORE_OPEN`: 「起点がより開いていただけ」という説明を **M2 の操作的範囲で支持**
- `HIGH_LESS_PUSHED`: 起点差と別に、high 群の動的変化が異なる。`delta_L` 固有の関連が残る方向
- `HIGH_MORE_PUSHED`: 動的差は予言と逆方向
- それ以外: 起点だけ/動的差を二分するには不十分

ここでの「ΔL 固有」は、既存幾何セル内の観察的関連のみ。ΔL を介入した因果効果とは呼ばない。

## 7. bootstrap

- cluster = seed のみ。20 seed を復元抽出し、選ばれた seed の全unit・全task曝露をブロックで複製
- `B=10000`
- `bootstrap_seed=20260901`
- `OMP_NUM_THREADS=1`
- `S0,S1,delta_S`、優越確率、raw 平均差を全て同一 resample index で回す
- セルと群ラベルは元標本で固定。bootstrap で low/high のどちらかが0になったセルはその replicate の `w_c=0`
- 対の優越確率では、seed が m 回抽出されたらその seed の行重みを m とし、high/low のペア重みは行重みの積
- 95% percentile CI
- 一つでも非有限 replicate があれば CI を出さず `SANITY_FAIL_NONFINITE`

## 10. 解釈禁止

- 観察的な群間差を、ΔL が押し下げを因果的に防ぐ効果と呼ばない
- `EQUIV_DYNAMICS` だけで「起点だけ」と断定しない。`HIGH_STARTS_MORE_OPEN` との組み合わせが必要
- `INCONCLUSIVE` を差なしと書かない
- 作業6の PROTECTIVE、r-swap の SPECIFIC 判定を M2 で事後的に差し替えない
- condB、他幅、他教師、長期将来、因果介入へ外挿しない
- 同じ軌道の再計装を「独立 replication」と呼ばない
