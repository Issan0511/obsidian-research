## 0. 一行

`gate_dose_0830` は「片道性が load-bearing」を示したが、片道を外す手段は **forward と backward を同時に変える**活性化（ELU・leaky）だった。沈んだ leaky ユニットは出力 $az$ を読み出し層に供給し続けるので、LoP が消えたのが「勾配で脱出できるから」なのか「沈んでも使えるから」なのかは現在の証拠では言えない（★穴 1）。本走は forward と backward の片道性を**別々に**外す: **順 ReLU／逆 leaky（`BL`）** は出力 0 のまま勾配だけ通し、**順 leaky／逆 ReLU（`FL`）** は出力 $az$ を供給するが勾配は通さない。これで担い手を決める（V1）。さらに `BL` に b-WD を掛けて、forward が 0 のときに消える self 復元力の**明示的な代替**になるかを見る（V2・折衷案）。

## 2. 何を分けるか（未登録の Claude の推論）

forward × backward の 2×2 で、沈んだユニットに残る経路を恒等式で分ける（$a=0.1$）:

| 経路                                                                          | `R`（順 ReLU／逆 ReLU） | `LR`（順 leaky／逆 leaky） | `BL`（順 ReLU／逆 leaky） | `FL`（順 leaky／逆 ReLU） |
| --------------------------------------------------------------------------- | ------------------ | --------------------- | -------------------- | -------------------- |
| rest 経路（共通場 $G$ との結合、$-2\eta v_i\,\mathrm{gate}\,G$、双極。$w,b$ を動かす）          | 0                  | $a$ 倍                 | $a$ 倍                | **0**                |
| self 復元力（$-\eta\nabla\tfrac12\mathbb{E}[f_i^2]$、負側で上向き。$\sigma\sigma'$ に比例） | 0                  | 戻る（$\sigma\sigma'<0$） | **0**（$\sigma=0$）    | **0**（$\sigma'=0$）   |
| $v_i$（出力重み）の勾配 $\delta\cdot a_i$                                            | 0                  | 戻る                    | **0（凍結）**            | 戻る（$a_i=az$）         |
| 読み出し層への供給                                                                   | 0                  | $az$                  | **0**                | $az$                 |

- `BL` が持つのは**勾配のみ**（rest 経路）。`FL` が持つのは**出力のみ**（$az$ の供給と $v_i$ の学習。$w,b$ は吸収）
- **V1（担い手）**: `BL` 0／`FL` 発症 → 勾配が担い手。`BL` 発症／`FL` 0 → 出力が担い手（沈んだユニットは固定特徴として使えれば足りる）。両方 0 → どちらでも足りる。両方発症 → 両方要る（self 復元力を含む forward-backward の結合が要る）
- **V2（折衷）**: `BL` で発症し `BLW`（`BL` + b-WD）で発症しなければ、失われた self 復元力を b への外的復元力が代替している

**本走が答えないこと**: $a$ の掃引・帯型（NeLU 型）代替勾配・Adam・多層・幅。無限時間の主張（0/10 は「5M までに観測しなかった」）。

- $a=0.1$ は `gate_dose` の leaky と同値。**`BL`・`FL` と `LR` の差がそれぞれ「出力」「勾配」だけになる**ようにするため
- λ=1e-3 は `bias_wd_0901` の C4 値を継承。**1 層・std 系での較正はしない**（外れたときは §7.3 で疑う）

### 4.2 対応づけ

代替勾配・順逆の分離・b-WD はいずれも乱数を消費しないので、新規腕は `gate_dose_0830` の各腕と init・教師・入力列・flip 軌道が bit 一致する（S-pair）。**step 1 以降は軌道が分岐する**（`gate_dose` §4.2 と同じ）。paired 対比は `results/gate_dose_0830/verdict.csv` の seed 別 $U_k$（10 値）を相手に取る。引用時に「対照は別走の committed 値」と書く。

### 4.3 実装

- `VecMLPL` に 2 つの活性化を追加。閉形式のまま（autograd に切り替えない）。**ReLU 経路・leaky 経路は 1 行も触らない**
  - `act='bwd_leaky'`（`BL`）: 前向き `where(pre>0, pre, 0)`、後ろ向き `where(pre>0, 1, a)`
  - `act='fwd_leaky'`（`FL`）: 前向き `where(pre>0, pre, a*pre)`、後ろ向き `where(pre>0, 1, 0)`
  - どちらも既存の `relu` / `leaky` の前向き・後ろ向き関数を**組み合わせるだけ**にし、新しい算術を書かない（S-limit・S-cross で検証）
- b-WD は `VecMLPL.set_weight_decay_b(1e-3)`（`bias_wd_0901` と同じ差し込み。b のみ・w と v には掛けない）
- 用量固定は `dose_const_5m_0830` のオラクルモードそのまま（入力側の変換・活性化非依存）

### 4.4 用語

- `BL` / `BLW` / `RW`: forward が ReLU なので `strict_dead`（$\hat p_i\equiv0$）がそのまま定義できる。`BL` / `BLW` は**吸収でない**（負側に勾配があるので復活しうる）
- `FL`: $\hat p_i$ は backward ゲートの開口率（$=\mathbb 1[z>0]$ の平均）で定義し、`strict_dead` は $w_i,b_i$ が**吸収された**ユニット（更新経路が切れている）を指す。**ただし出力は $az$ で非ゼロ・$v_i$ は学習を続ける。** `submerged`（$\max_x z_i\le0$）と一致する（[[引用禁止]] の恒真性）
- どちらも verdict には使わない。§5.3 で復活数と凍結率を数える

### 5.2 水準（主判定と同格）

各腕の seed 中央値 $\log_{10}U(5\mathrm{M})$・$\log_{10}U(1\mathrm{M})$。paired Δ $\log_{10}U(5\mathrm{M})$（用量ごと）:

- **P3'**: `BL`−`R`、`FL`−`R`、`BLW`−`R`、`RW`−`R`（各介入の効果）
- **P5（V1 の水準側）**: `BL`−`LR` と `FL`−`LR`。**等価限界 $\Delta=0.15$ dex**（[[チャネル遮断2x2_spec_0901]] D4 を継承・Issa 上書き可）。CI が $[-0.15,+0.15]$ に収まれば **`*_EQUIV_FWD`**（その経路だけで leaky と同水準）、CI が 0 を上に外せば **`*_SHORT_OF_LR`**（もう一方の経路の寄与が水準に残る）、どちらでもなければ **`INCONCLUSIVE_WIDE`**。`BL` と `FL` の両方で報告する

### 5.3 副次（REPORT_ONLY）

- **復活数**: `BL` / `BLW` で $\hat p_i$ が 0 → 正へ戻ったユニット・イベント数（`gate_dose` の ReLU 腕は 0 が既知）。**双方向ゲートの直接の署名**。`FL` は 0 のはず（backward が片道）— 0 でなければ実装を疑う
- **凍結率**: `BL` で末尾窓中 $\Delta v_i = 0$ のユニット割合（`strict_dead` 集合と一致するはず）。`FL` で末尾窓中 $\Delta w_i = \Delta b_i = 0$ のユニット割合（同じく一致するはず）。§2 の表が実装どおりかの確認
- **`FL` の固定特徴の使われ方**: 沈んだユニットの $|v_i|$ の末尾窓中央値（`R` の dead ユニットの $|v_i|$ と比較）。`OUTPUT_CARRIES` が出たとき「固定特徴として使われている」の傍証になる
- `strict_dead` / `submerged_frac` / `alive` / `eff_rank` / `‖w‖` / `b_median` / `median_M` / `median_B` / `preact_sd_median` の時系列、`eval_loss_exact`。**`‖w‖` は主要共変量**（継続）
- 数値発散は `gate_dose` §5.6 を逐語継承（`NUMERIC_DIVERGENCE` でセルを空にし、verdict が空セルを要求すれば `INCONCLUSIVE_DIVERGENCE`）

### 5.4 副次 P7 — ユニット別 $s_i = M_i + B_i$ の分布（登録・verdict 不使用・9/2 追加）

先生案（[[kubo_review_v4.2_0831]] §2.3）の壁座標 $s_i = M_i + B_i$（$M_i = w_i\cdot\mu/\mathrm{denom}_i$：µ チャネル、$B_i = b_i/\mathrm{denom}_i$：b チャネル、$\mathrm{denom}_i = \sqrt{w_i^\top\Sigma w_i}$。`exact_layer_record` が $\mathbb E[z_i]/\mathrm{sd}(z_i)$ との一致を照合済み）を**用量の代替ではなく読み出し**として載せる。用量は操作変数、$s_i$ は各腕でユニットがどこに居るか・どのチャネルで動いたかの記述。本走で特に効く理由: `BL`・`BLW`・`RW`・`FL` はいずれも `strict_dead` と位置が同じ座標で比べられ、**b-WD が $B_i$ を係留し $M_i$ に触らない**（[[現象2主張v1_0901]] C5）ことと、**漏れがどちらのチャネルを戻すか**が分離できる。

- **記録の実現可能性は未確認。分岐を事前登録する**（§6 の **S-log**）。ユニット別 `s` / `M` / `B` / `denom` が取れるかは宿主のロガー次第で、本 spec の起草時点で確認していない。`gate_dose` §5.5 に載っているのは**腕水準の** `median_M` / `median_B` であり、**ユニット別列があるとは書かれていない**。分岐は §6 S-log で決め、選んだ分岐と理由を `provenance.json` に記録する
- **対照 `R` / `LR` にも同じ列が要る点に注意。** P7b・P7c は committed 腕との paired 対比なので、新規腕だけにロガーを付けても計算できない。分岐 B ではここが効く
- 集約順（凍結）: ユニット → **seed 内中央値**（全ユニット／alive のみ の 2 系列）→ seed 中央値。`median_s` と `median_M + median_B` は別物として両方出す（[[引用禁止]] の縮退 (ii)）。`denom` の中央値を併記（縮退 (iii)）。中心化腕は無いので縮退 (i) は非該当
- **P7a**: 各腕の `median_s` / `median_M` / `median_B`（全ユニット・alive）
- **P7b（漏れが戻すチャネル）**: paired Δ（`BL` − `R`）の `median_M`・`median_B`（全ユニット）。CI が 0 を上に外したチャネルを「戻したチャネル」と読む。両方なら両方。**ラベル化はしない**（F_self / F_rest 分解の教訓: 役割の割り当ては失敗しやすい。ここは記述にとどめる）
- **P7c（b-WD の係留）**: `RW` − `R`、`BLW` − `BL` の `median_B` と `median_M`。C5 の再現なら $B$ のみ動き $M$ は等価限界 0.15 内
- **P7d（分岐 C 用の退避先・新規腕内のみ）**: `BLW` − `BL`、`BLW` − `RW`、`FL` − `BL`。committed 腕を使わないので、新規腕にロガーが付きさえすれば必ず計算できる
- $s_i$ は「位置」であって「病理」ではない（[[現象3指標再定義_P3_0901]]）。`BL` の位置が `R` と同じ深さでも復活数（§5.3）が正なら、差は位置ではなく可動度にある — この読みを P7 と §5.3 の併記で固定する
