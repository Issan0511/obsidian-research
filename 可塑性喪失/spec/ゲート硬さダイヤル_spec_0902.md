## 2. 何を測るか — 分解を使わない設計原理

総勾配は $\partial L/\partial b_i = v_i\,\mathbb E[\varphi'(z_i)\,\varepsilon]$、$\partial L/\partial w_i = v_i\,\mathbb E[\varphi'(z_i)\,\varepsilon\,x]$（$\varepsilon$ は**総残差**）。$\varepsilon$ を自己項と rest に割らなければ、ゲート $\varphi'$ は総力の乗法因子である。ここから分解なしで出るのは次の 3 つだけで、**向き**は出ない。

- **(a) 大きさの上界。** 1 step の $|\Delta b_i|\le\eta|v_i||\varphi'||\varepsilon|$ なので、$T$ step の変位は $\eta T\sup|\varphi'|\cdot K$ で抑えられる（$K:=|v_i|\,\mathbb E|\varepsilon|$ の上界）。**設計上は $K=1$ を約束事にする**（保証ではない。§5.4 で実測 $|v_i|$・残差水準と併記する）。5M では $\eta T=5\times10^4$ なので、$|\varphi'|<10^{-6}$ の深さでは 5M かけても変位の上界が 0.05 を割る。これを**凍結深さ $u_{\rm fr}$**（$u=-z$）と呼ぶ。「それより深いユニットは 5M の間に表層まで戻れない」という保証であって、「届く範囲のユニットは戻る」とは言わない（後者が Q2b で否定された側）
- **(b) 零点（障壁）。** SiLU・GELU は負側に $\varphi'=0$ の点（谷底）を持ち、そこでは向きに関係なく速度が 0 になる。谷より深いユニットが勾配だけで表層へ戻る経路は無く、越えるのは境界での $w\cdot\Delta\mu$ の跳びだけ。谷底の位置は視野 $T$ に依らない
- **(c) 符号反転。** 谷より深いと $\varphi'<0$ なので残差への応答の向きが反転するが、残差の向きに定符号は無い。書けるのは「反転して、かつ消えていく」まで。**「押し下げ」とは書かない**

| 族            | 負側 $\varphi'(u)$                                 | 負側 $\varphi(u)$                  | 谷底 $u^\ast$（$\varphi'=0$） | 凍結深さ $u_{\rm fr}$（$K$=1・5M）                                    | ダイヤルの効き方                     |
| ------------ | ------------------------------------------------ | -------------------------------- | ------------------------- | -------------------------------------------------------------- | ---------------------------- |
| leaky$_a$    | $a$（定数）                                          | $-au$（線形・情報あり）                   | なし                        | **なし**（$a>0$ なら有限時間で任意の深さへ届く）                                  | 上界は $a$ に線形（冪）               |
| ELU$_\alpha$ | $\alpha e^{-u}$                                  | $\alpha(e^{-u}-1)\to-\alpha$（定数） | なし                        | $\ln(10^6\alpha)$ ＝ 13.8 / 11.5 / 9.2（$\alpha$=1 / 0.1 / 0.01） | **対数**（10 分の 1 で 2.3 浅くなるだけ） |
| SiLU$_\beta$ | $\sigma(-\beta u)\,[1-\beta u\,\sigma(\beta u)]$ | $-u\,\sigma(-\beta u)\to0^-$     | $1.278/\beta$             | ≈ $16.5/\beta$                                                 | $1/\beta$                    |
| GELU$_\beta$ | $\Phi(-\beta u)-\beta u\,\phi(\beta u)$          | $-u\,\Phi(-\beta u)\to0^-$       | $0.752/\beta$             | ≈ $5.5/\beta$                                                  | $1/\beta$                    |

（$\sigma$ はロジスティック、$\Phi$・$\phi$ は標準正規の分布関数・密度。谷底は $c\,\sigma(c)=1$・$\Phi(-c)=c\,\phi(c)$ の根。**表の数値は閉形式と $K$=1 の代入で、実験出力ではない。引用不可。**）

**同じ「標準点」で硬さの 2 つの候補が食い違う例**: $\beta$=1 の SiLU は $u_{\rm fr}$=16.5 で ELU（13.8）より**深部の裾は軟らかい**が、谷底 1.28 より深いと勾配では戻れないので**復帰の意味では硬い**。どちらの「硬さ」が発症を決めるかは本走が答える。

**「いつ」の作業仮説（登録しない・設計の見当）**: 発症は「凍結域（$u>u_{\rm fr}$、または谷より深い）に到達したユニット時間の割合」が容量を割る点で起きる。**到達側（どの深さまで、どの率で沈むか）の理論は持たない。測る。**

**本走が答えないこと**: 視野 $T$ のダイヤル（先生の U1 probe 2000 step・U3 $T$ 短縮 — ELU の $u_{\rm fr}$ は $T$ で動き SiLU/GELU の谷底は動かないので、次の判別軸）、谷を埋める活性化（先生の T5）、順伝播と逆伝播の分離（`bwd_leak_0902`）、用量 9.33、多層、Adam、幅、無限時間の主張。

### 4.3 実装

- `VecMLPL.ACTIVATIONS` に `silu`・`gelu` を追加。閉形式のまま（autograd に切り替えない）。**ReLU・leaky・ELU の経路は 1 行も触らない**。ダイヤルは既存の `act_alpha` に載せる（$a$・$\alpha$・$\beta$ を同じ引数で運ぶ既存契約）。`act_grad_form` は ELU 用のまま
  - `silu`: 前向き $z\,\sigma(\beta z)$、後ろ向き $\sigma(\beta z)\,[1+\beta z\,(1-\sigma(\beta z))]$。`torch.sigmoid` の安定形で書く（$\exp(-\beta z)$ を裸で書かない）
  - `gelu`: **exact（erf）**。tanh 近似は使わない。前向き $z\,\Phi(\beta z)$、$\Phi(x)=\tfrac12(1+\mathrm{erf}(x/\sqrt2))$。後ろ向き $\Phi(\beta z)+\beta z\,\phi(\beta z)$、$\phi(x)=e^{-x^2/2}/\sqrt{2\pi}$
  - leaky $a\in\{10^{-2},10^{-3},10^{-4}\}$・ELU $\alpha\in\{0.1,0.01\}$ は既存分岐のパラメータ変更のみ
- 用量固定は `dose_const_5m_0830` のオラクルモードそのまま（入力側・活性化非依存）
- **新規ロガー（軌道中立・追加のみ・既存列は変えない）**。記録点ごと・ユニット別 `(5001, 100)` float32、既存の `layer1_M` / `layer1_B` / `layer1_denom` / `layer1_p_hat` と同じ形:
  - `layer1_mob` $=\mathbb E_x[\varphi'(z_i(x))]$（32 サポート点の平均）。ReLU では `p_hat` と、leaky では $a+(1-a)\hat p$ と恒等に一致するはず（S-mob）。**独立な量になるのは ELU・SiLU・GELU 腕だけ**（[[引用禁止]] の可動度の項・P-3 の新規ロガー 1 件目）
  - `layer1_absmob` $=\mathbb E_x|\varphi'|$（SiLU・GELU は符号が混じるので別に持つ）
  - `layer1_zmax` $=\max_x z_i(x)$、`layer1_zmean` $=\mathbb E_x z_i(x)$（生の深さ。$(M+B)\cdot\mathrm{denom}$ と一致するはず — 照合に使う）
  - `layer1_v` $=v_i$（読み出し重み・ユニット別）。§5.4 の $|v_i|$ 中央値（$K$=1 の事後確認）に要るほか、**先生の U4 で `INSUFFICIENT_DATA` になった「$|v_i|$ と沈下深さの相関」**（[[帯拘束ゲートとELU実効吸収_0902]] §10-6）が新規腕について取れるようになる。宿主の 8 出力にユニット別 $v_i$ の列が無いのは確認済み
- **float32 の飽和（設計上の注意）**: GELU は erf が float32 で飽和するため $\beta z<-5.5$ で前向き・後ろ向きとも**厳密 0**になる。数学的な $|\varphi'|$ はその領域で $6\times10^{-7}$ 以下＝5M の変位上界 0.03 未満なので、**力学上の差は無い**（$u_{\rm fr}\approx5.5/\beta$ と同じ位置）。SiLU は $\beta z<-104$ まで非零。**飽和深さは S-num で測って `provenance.json` に書く。** float64 化はしない（宿主と実装を揃える）

### 4.4 用語

- `submerged` := $\max_x z_i\le0$（$\hat p_i=0$ と恒真同値・[[引用禁止]]）。全腕で定義
- `beyond_valley` := $\max_x z_i\le-u^\ast$（SiLU・GELU のみ。ReLU の `strict_dead` に対応する**位置**の概念。leaky・ELU は空欄）
- `frozen` := $\bar z_i\le-u_{\rm fr}$（$K$=1 の約束事つき。leaky は常に偽）
- **$m^-$**（v6 §4 の硬さ候補）:= seed 内で `submerged` ユニットの `layer1_mob` の中央値（末尾窓）。**新しい指標ではなく既存軸の制限**
- **復活** := `submerged` → 非 `submerged` の遷移（境界／非境界で別に数える）。ReLU は非境界 0 が既知（Q3）
- いずれも verdict には使わない（§5.4・§5.5）

## 5. 集計（事前登録）

窓・床・発症定義・CI は `gate_dose` §5 を逐語継承: 5M 末尾窓 = タスク 491–500、1M 窓 = 91–100、$U_k$ = 窓平均未フィット率（記録点 1000 step 間隔・タスク内 10 点の平均）、**発症 = $U_k\ge0.05$**、$n_{\rm onset}$ は Clopper–Pearson、差は seed クラスタ paired percentile bootstrap B=10000・studentized 併算＋退化ガード（教訓⑬）・percentile 主。

### 5.2 E2 — 水準（主判定と同格）

各腕の seed 中央値 $\log_{10}U(5\mathrm{M})$・$\log_{10}U(1\mathrm{M})$。paired $\Delta\log_{10}U(5\mathrm{M})$:

- **P5'（軟らかい端との距離）**: leaky 系は − `LR_1216`、ELU 系は − `E_1216`、SiLU・GELU 系は − `E_1216` と − `LR_1216` の両方。**等価限界 $\Delta=0.15$ dex**（[[逆伝播漏れ2x2_spec_0902]] §7.1 の Issa 裁定を継承。同じ理由で `EQUIV` は $n=10$ ではほぼ到達不能であり、較正定数の要らない **seed 別符号検定を REPORT_ONLY で併記**する）。CI が $[-\Delta,+\Delta]$ に収まれば **`*_EQUIV_SOFT`**、0 を上に外せば **`*_SHORT_OF_SOFT`**、どちらでもなければ **`INCONCLUSIVE_WIDE`**

### 5.3 E3 — 発症時刻（v6 (ii)「速度」の endpoint）

$U^{(10)}_k$ := タスク $k-9$〜$k$ の記録点の `unfit` 平均（宿主の `_window` と同じ集約。$U^{(10)}_{100}$・$U^{(10)}_{500}$ が 1M・5M の $U_k$ に一致することを S-mask で検算）。**$k^\ast:=\min\{k\ge10: U^{(10)}_k\ge0.05\}$**、無ければ **500 で打ち切り**（`censored=1`）。seed 別に出し、腕ごとに中央値・範囲・打ち切り数を書く。「未発症＝生存」の Kaplan–Meier 曲線（**率**）を $n_{\rm onset}$（**総和**）と並べる（教訓⑰）。

**V2（族ごとの単調性・v6 (ii) の判定）**: 族内で軟らかい側から硬い側へ並べる（committed の両端を含む）:

- leaky: `LR_1216`（0.1）→ 0.01 → 0.001 → 10⁻⁴ → `R_1216`（0）
- ELU: `E_1216`（1）→ 0.1 → 0.01 → `R_1216`（0。ELU は $\alpha=0$ で ReLU に厳密一致）
- SiLU: 0.3 → 1 → 3 → `R_1216`（$\beta\to\infty$ の極限。厳密一致ではない）

- 0/10 は「5M までに観測しなかった」（片側 95% 上限 $p\le0.2589$）。「起きない」と書かない
- 対照 `R_1216`・`LR_1216`・`E_1216` は**別走の committed 値**（§4.2）。同一走の腕ではない
- **用量 1 点（12.16）の主張である。** `GATE_LOAD_BEARING` が帯内 2 点で立っているのに対し、本走の判定はすべて 12.16 に限る。引くときは用量を添える
- **§2 の $u_{\rm fr}$・谷底の数値は閉形式＋$K$=1 の代入で、実験出力ではない。** 「凍結深さは 13.8」と測定値のように書かない
- §1 の「ELU の 25% が既に凍結域」は**事後・未登録・チャット内再集計**。設計の見当にだけ使い、結果ノートに引かない
- `layer1_mob` は ReLU・leaky では $\hat p$ の一次関数（[[引用禁止]]）。「可動度を測った」と書けるのは ELU・SiLU・GELU 腕だけ
- `beyond_valley`・`frozen` は**位置**であって病理ではない（[[現象3指標再定義_P3_0901]]）

- 先生の 3 分類は §7.2 に転記した予言であり、本走が支持しても「自己項が駆動している」とは書かない（分解の帰属は Q2b・Q12 で失敗している）
- SiLU・GELU の $\beta\to\infty$ は数学的極限であって、`R_1216` は SiLU・GELU 族の腕ではない
