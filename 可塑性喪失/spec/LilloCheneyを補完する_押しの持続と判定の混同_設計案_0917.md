## 0. 決めたいこと

Lillo & Cheney（ICLR 2026）は、負側の微分が裾で消える活性化の群が可塑性を失いやすいことを示したが、(1) 死を出力値で数え、(2) 押し込みを 1 epoch で戻す人工の衝撃で与え、(3) 活性化ごとに学習率を変えて比べた。それぞれが「飽和 → LoP」の読みをどう変えるかを、私たちの箱で決める。

| 部 | 問い | 種類 | 費用 |
|---|---|---|---|
| C1 | 出力で数える dead unit は、裾にいる入力と 0 のそばの入力を混ぜているか。再学習と並ぶのはどちらの判定か | 再解析・走ゼロ | 1 時間以内 |
| C2 | 同じ γ 倍の衝撃でも、戻すか続けるか、いつ当てるかで学習能力の失い方が変わるか | 新しい腕（resp_ee の runner） | 30 分程度 |
| C3 | 彼らの ELU(α = 3.6) が生き残るのは、0 のすぐ下の傾きのためか、負側の出力の漸近値のためか（lr だけでは救われないことは公開表から分かる） | 新しい走（彼らのプロトコル） | CPU 4 並列で約 7 時間／GPU 一括なら約 1.5 時間 |
| C4 | 一回きりの押しからの回復に、時間の上界はどれだけ効くか | 算術・導出 | 走ゼロ |

## 1. C1 判定の混同（再解析）

**材料**: resp_ee の分岐状態（t2・5・7・10・15・20 × 10 seed、`~/Projects/obsidian-research-data/resp_ee_0917/`）と 26 腕の継続、neff_pred の GPU エンジン（RL・PM の GELU・SiLU・ELU→leaky を記録と bit 一致で再生できる）。

**2 つの判定を同じ (ユニット, 入力) に当てる**:

- **LC**（彼らのコードの現行版）: GELU・SiLU は \|a\| < 0.05σ、ELU は a < −α + 0.02 または \|a\| < 0.05σ（σ はそのバッチの出力の標準偏差）。
- **TR**（私たち）: 訓練で使われる微分 g について \|g\| < 1e−3（彼らの衝撃実験の閾値に合わせる）と、厳密な 0。ユニットごとの $n_{\rm eff}$ も並べる。

**量**:

- 混同率 $A$ = LC で dead とされた入力のうち \|g\| ≥ 0.1 のものの割合（元気なのに dead と数えられた分）。
- 見落とし率 $B$ = TR で死んでいる入力のうち LC で dead とされなかった割合。
- 26 腕をまたいで、E と「LC の割合」「TR の割合」「$n_{\rm eff}$」の順位相関。
- 分岐点での移植腕と自然腕の LC の割合（前向きが bit 一致なので同じになるはず。E は 0.14 と 0.90 で違う）。

**予測（Claude）**:

| 項目 | 予測 | 確信 |
|---|---|---|
| RL GELU の第2層（t50、z̄₂ ≈ 0）で $A$ ≥ 0.3 | 0 のそばの入力が dead に数えられる | 60% |
| 崩壊した RL ELU の第2層（t10）で $A$ < 0.05 | 裾が深く、0 のそばは空 | 85% |
| 26 腕で \|ρ(E, LC)\| < \|ρ(E, $n_{\rm eff}$)\| | 出力の判定は移植腕を区別できない | 75% |
| 分岐点の LC の割合が R2_10 と N10 で一致 | 構成上 | 95% |

## 2. C2 押しの持続（彼らの衝撃を私たちの箱へ）

**箱**: resp_ee と同じ（RL・1200 枚・784–100–100–10・両層 ELU・Adam 1e−3・6000 更新/タスク・seed 0–9・float32・white-san CPU）。自然軌道は resp_ee の記録と bit 一致で再現する。

**操作**: 彼らと同じく、全隠れ層の前活性を非線形の直前で γ 倍する（1 epoch = 75 更新）。

| 腕 | γ のかけ方 | 役割 |
|---|---|---|
| N | なし（自然な継続） | 対照（既存腕を再利用） |
| **K_rev** | 10 epoch ごとに 1 epoch、γ を 1.5 → 0.5 → 0.25 → 2.0 と巡回して戻す | 彼らのプロトコルの再現 |
| **K_mid2** | タスクの途中（3000〜3075 更新）に 1 epoch だけ γ = 2 | 一回きり・切替と無関係 |
| **K_sw2** | 切替直後の 1 epoch（0〜75 更新）だけ γ = 2 | 一回きり・自然な押しと同時 |
| **K_hold2** | タスクを通して γ = 2 | 押しが続く |
| K_hold2_L2 | 第2層だけ γ = 2 を続ける | 報告のみ |

**分岐点**: t2（健康・E 0.78）と t5（崩壊途中・E 0.56・z̄₂ ≈ −8）。t5 で γ = 2 を続けると、平均がちょうど float32 の床（−16.64）付近に来る。継続は 2 タスク（2 タスク目は γ なし）で、後遺症も見る。

**主判定**（t5・95%・seed 内の差）: $D_{\rm hold}$ = K_hold2 − K_rev、$D_{\rm time}$ = K_sw2 − K_mid2。

| ラベル | 条件 | 読み |
|---|---|---|
| **PERSISTENCE_MATTERS** | K_rev − N の区間が 0 を含み、$D_{\rm hold}$ < 0 | 彼らの D.4（戻る）を再現し、同じ衝撃を続けると学べなくなる |
| TIMING_MATTERS | $D_{\rm time}$ < 0 | 同じ一回きりでも、自然な押しと重なると傷が深い |
| SHOCK_HARMS | K_rev − N < 0 | 一回きりでも戻れない（D.4 と逆） |

**予測（Claude）**: t5 で PERSISTENCE_MATTERS 65%（K_hold2 は N10 並みの 0.2 以下へ 60%）、TIMING_MATTERS 45%、t2 では全腕が N2 から 0.05 以内 55%。2 タスク目に K_sw2 の傷が残る 40%。

## 3. C3 α の効き方 — 0 のすぐ下の傾きか、負側の漸近値か（彼らのプロトコル）

**走らせずに分かったこと（09/17 夜・公開表の読み直し）**:

- CELU(α = 1) は ELU(α = 1) と同じ関数（PyTorch で値も微分も bit 一致）。彼らの ELU・CELU の掃引は同じ α の格子（1.0 を含む）× lr 2 値。CELU の最良が 37.2 なので、**ELU(1) は lr 1e−3 でも 1e−4 でも 37.2 以下**（選ぶ基準が表 2 と同じなら）。**lr を下げるだけでは救われない。** 初版のこの節の問い（「lr が小さく輸送が届かなかったのか」）は、公開表でほぼ否定された。
- $\mathrm{CELU}_\alpha(z)=\alpha\,\mathrm{ELU}_1(z/\alpha)$。CELU(3.6) は ELU(1) の網を座標変換したもので、裾が太いわけではない。違いは Adam の層ごとの実効学習率と初期値。
- ELU(3.6) の裾の減衰の速さは ELU(1) と同じ（深さで 1.3 ずれるだけ）。§1.3a から、裾では生き残りを説明できない。

**負側を $\varphi(z)=c\,(e^{kz}-1)$ と書くと、0 のすぐ下の傾きは $ck$、負側の漸近値は $-c$、裾の減衰の速さは $k$ で、3 つのうち 2 つを選べば残りが決まる。** 傾きと漸近値の 2×2 を組む。

| 腕 | 形 | 0 のすぐ下の傾き | 負側の漸近値 | 裾の減衰の速さ $k$ |
|---|---|---|---|---|
| E1 | ELU(1) | 1 | −1 | 1 |
| **S36** | $e^{3.6z}-1$（新しい関数） | **3.6** | −1 | **3.6**（裾は最も細い） |
| C36 | CELU(3.6) | 1 | **−3.6** | 0.28 |
| **E36** | ELU(3.6)（彼らの最良設定） | **3.6** | **−3.6** | 1 |

- lr は 1e−4（彼らの ELU の設定）に揃え、E1 だけ lr 1e−3 も置く（公開表からの推論「ELU(1) は救われない」を確かめる。act_chimera の親走と同じ設定なので崩壊は既知）。
- 箱: 784–100–100–10・1200 枚・Adam・batch 16・**400 epoch = 30,000 更新 × 50 タスク**。実装は私たちのエンジン。seed 3 つ。
- 各タスクで online 精度・適合率 F・崩壊の時刻 T½・$\bar z_2$・$\|\mu_2\|$・訓練の微分の 0 の割合・$n_{\rm eff}$ を記録する。
- **主量**: 後半窓（t41–50）の F と T½。彼らの主量（全 50 タスクの online 平均）も並べる。

**予測（Claude）**:

| 項目 | 予測 | 確信 |
|---|---|---|
| E1（lr 1e−4）の全タスク平均が 40% 以下 | 公開表からの推論の確認 | 70% |
| E36 の全タスク平均が 75% 以上 | 彼らの 84.2 の再現 | 55% |
| C36 の全タスク平均が 45% 以下 | 彼らの 37.2 の再現（ELU(1) の座標違い） | 65% |
| **S36 が後半窓 F ≥ 0.5 で生き残る**（裾が最も細いのに） | 0 のすぐ下の傾きが輸送を止める | 50% |
| 傾きの主効果（S36・E36 対 E1・C36）が漸近値の主効果より大きい | 同じ | 55% |

**読み分け**: S36 が生き残れば、「裾の太さではなく、沈みかけた入力への押し戻しの強さが輸送を止める」になり、V10 §1.3a（裾は必ず負ける）と両立する形で、クラスの中でも生き残る条件を書ける。C36 だけが生き残るなら漸近値の側で、[[GELUとSiLU_s2は150タスクで死ぬか_結果_0915]] §3b の「負側の漸近値がどの層から死ぬかを決める」とつながる。E36 だけが生き残るなら両方が要る。どれも死ぬなら、彼らの 84.2 は私たちのエンジンで再現しない（実装差）ことになり、そこから調べ直す。

## 4. C4 回復時間の上界（算術・導出の候補）

Adam の一歩は座標ごとに $|\Delta\theta_j|\le\eta\,(1-\beta_1)/\sqrt{1-\beta_2}$ で抑えられる（Kingma & Ba 2015 §2.1、$(1-\beta_1)>\sqrt{1-\beta_2}$ のとき）。β = (0.9, 0.999) では約 $3.16\eta$。μ を固定すると、ユニットの平均前活性の 1 更新の変化は

$$
|\Delta\bar z_i|\le 3.16\,\eta\,(\|\mu\|_1+1).
$$

第1層では $\|\mu\|_1\approx\bar S\approx104$（段階0 の値）なので、lr 1e−3 で 1 更新あたり最大 0.33。深さ 16 から登り直すのに要る更新数の下限は 50 程度で、1 タスク 6000 更新（彼らは 30,000）に比べて小さい。

- **含み**: 一回きりの押しからの回復は、勾配が残っていれば時間では律速されない。D.4 の「1〜2 epoch で戻る」はこれと合う。戻れないのは (i) 全入力で訓練の微分が実質 0（実効数が尽きた）か、(ii) 押しが続いて登りを打ち消すとき。
- **導出したいもの**: 実効数が尽きかけた状態で、押しの速さと登りの速さが釣り合う条件。§1.3a の減衰の定理と組み合わせると、「押しが続く限り戻れない」の定量版になる。未導出。
- 上界は最悪の場合で、実際の一歩は小さい。第2層では $\|\mu_2\|_1$ が崩壊とともに伸びる（ref で ‖µ₂‖ は 200 超）ので、上界はむしろ緩む。
