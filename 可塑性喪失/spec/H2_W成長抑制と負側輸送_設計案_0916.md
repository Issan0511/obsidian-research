## 0. 決めたいこと

**Random Label MNIST・ELUの同じ学習条件で、隠れ層の中心化重みの成長を止める介入が、第2層の負側への輸送と応答消失を減らすか。**

これはH2の一条件を検証する設計。H1の駆動源の導出完了や、H4の応答を介した性能改善の完全な因果同定までは要求しない。H3の変位分解を同時に記録して、「第2層自身の更新」と「上流に運ばれた」を区別する。

以下を推奨案として固定する。実行を決めた場合は、実験repoへのspec登録、実装検査、費用確認を別途行う。この文書の保存・commitは、本走の事前登録や起動を意味しない。

## 1. 対象と既存研究からの選択

- 対象は二層ともELU(α=1)のMLP。[[層別キメラでELU崩壊の所在を決める_結果_0914]] と同じ80 epoch箱を採る。同結果は第2層を調べる根拠だが、W増大が原因だったことはまだ示していない。
- [[ELUの沈下と学習余力を分ける_結果_0913]] の環境比較では、W1介入がtask 10後。今回はtask 1後に分岐し、第2層の成長も操作する。
- [[Wの蓄積を止めれば時間劣化は消えるか_結果_0914]]・[[Lの分解で救命の出どころを分ける_結果_0914]] の400 epoch箱と混ぜない。既存のleaky/ReLUの救命率を本設計のELUの予測値に転用しない。
- 主操作は**中心化行ノルムの上限**。成長が止まったかを直接検査でき、λの調整を要しない。硬い上限には副作用があるため、task 1は共通で学習し、介入開始時には重みを変えない。以後の学習への影響は残るので記録する。
- 「WDで収束した後」そのものを調べる実験ではない。結合型L2・AdamW・上限射影は異なる操作。softな減衰との再現性確認は、本設計の結果を踏まえて別途決める。

- 10 seedはばらつきを記述する実務的な固定数で、検出力を保証する数ではない。結果を見てseedや窓を追加・交換しない。

## 3. 介入の定義

行ごとに $m_i=\mathrm{mean}_j w_{ij}$、$\widetilde w_i=w_i-m_i\mathbf1$ と置く。
task 1終了時の $r_i^*=\|\widetilde w_i\|_2$ を保存する。

各Adam更新後の行を $w_i^{pre}$ とし、その行平均 $m_i^{pre}$ と中心化成分を計算する。対象層では、

$$
w_i^{post}
=m_i^{pre}\mathbf1+
\widetilde w_i^{pre}
\min\left(1,\frac{r_i^*}{\|\widetilde w_i^{pre}\|_2}\right).
$$

- ゼロノルムはそのまま、目標ゼロで現在非ゼロなら中心化成分をゼロへ射影する。
- **上限であり、ノルムの等式固定ではない。** 小さくなった行を膨らませない。
- 射影時の行平均と中心化成分の向きは保存。bias、W3、Adamのmomentは変更しない。
- 自然更新pre、射影補正post−pre、実際の更新post−oldを区別する。
- row meanは入力平均μではない。また中心化Wはμへの直交成分でもない。
- 対象は中心化Wだけ。行平均・bias・W3の成長や上流表現の変化は残り得る。失敗を「W全体を止めても沈む」と一般化しない。

## 4. 評価対象と保存点

全評価をseedごとの固定1200画像上で行い、画像を再抽出しない。全100ユニットを固定母集団とし、後から生存者だけを選ばない。画像・ユニット・タスクを独立seedとして数えない。

- task 1終了・分岐直前の全パラメータ、moment、step、各stream状態を保存。
- task 2–10は更新数0, 75, 375, 1500, 3000, 6000で診断。
- task 11–50は各タスク開始と終了で診断。開始点は新ラベルでの性能も評価し、ラベル変更だけでは前活性が変わらないことを確認。
- 全診断点でパラメータと、固定画像の第1層出力・各層の前活性・ゲートを保存または再構成可能にする。
- 射影の発動割合、補正ノルム、自然更新ノルム、累積射影量を毎タスク集約する。診断点直前の1更新ではpre/postを別保存。
- 自然なAdam更新と射影補正の収支を論じる場合は、該当量を毎更新で集約する。疎な診断点だけから「毎更新の駆動の内訳」を推定しない。

### 必須測定

| 対象    | 測定                                                |
| ----- | ------------------------------------------------- |
| 操作    | W1/W2のユニット別中心化ノルム、全行ノルム、行平均、上限違反、射影量              |
| 輸送    | ユニット別の生の平均前活性、標準偏差、経験的分位点0.01/0.5/0.99、最大値、正側入力割合 |
| 応答    | ユニット別の平均φ′・RMS φ′、φ′<0.05の入力割合                    |
| 上流・迂回 | μ2=平均a1、a1のRMS・共分散、W3ノルム、全bias                    |
| 学習    | 更新前バッチの平均精度・CE、診断点の全1200枚の精度・CE、実更新量              |

「平均+3標準偏差」を実際の上端と呼ばず、経験的な裾を直接測る。ELUの低ゲート割合は $z<\log(0.05)$ の割合と同値なので、同じ変化を独立な二つの証拠として数えない。ゲートは局所応答であり、ネットワークの再学習能力そのものではない。

## 5. 主endpointと集約

主窓は**task 2–10の各タスク終端**。介入後の崩壊過程を対象にする。持続はtask 11–20・41–50で副報告する。窓は結果を見て切り替えない。

seedごとに先に「画像平均→全100ユニットの算術平均→9タスクの算術平均」を取り、その後seed間を集約する。中央値による感度分析は副報告とする。

1. **輸送の主endpoint**: 第2層の平均前活性についてtask 1終端からの変化を主窓で平均する。cap12−refが正なら負側への正味輸送が小さい。
2. **応答の主endpoint**: 第2層の平均φ′について同様にtask 1終端からの変化を主窓で平均する。cap12−refが正なら局所応答が多く残る。
3. **操作のendpoint**: 各層の中心化行ノルム平均を同じ主窓で評価。上限違反の最大値と、refとの差を別々に示す。「上限を守った」ことだけでは有効な腕間差の証拠にならない。

全10 seedの対応差、平均、SDを提示する。主2endpointには各97.5%の対応差t区間（df=9）を用い、同時被覆をBonferroniで扱う。通常95%区間も併記する。これは小標本の近似区間なので全seed点と分布を併記し、分布の強い歪みも開示する。分散ゼロなら実測の同一差と退化を表示し、t値を作らない。

比や「除去率」は主判定にしない。**区間がゼロを跨ぐ場合は未決で、効果なし・同等とは呼ばない。** 正の区間だけでも効果の大きさは必ず併記し、実用上十分な救済とは区別する。副比較・副窓は探索的な区間とし、主判定の代用にしない。

### 主判定の適用条件

以下もseedごとの値を全件示し、都合のよいseedだけに絞らない。

- 共通task 1状態の一致、stream一致、有限値、全窓の完走、射影の数値精度が成立する。不成立なら主判定は検証不能。
- refの主窓ではtask 1より前活性と平均φ′が減ることを、各seedの変化と95% t区間で確認。区間で負を確認できない量があれば、対象現象の再現は未決。
- refの対象層に成長余地があるか確認する。主窓の中心化行ノルム平均がtask 1比で1.10以上かを層ごとに示し、cap12がref比で10%以上小さいことを両層で確認する（いずれもseed内で比を取りseed算術平均）。10%は操作差の実務上の最低幅で、既存研究から導いた機構定数ではない。満たさない場合は操作差不足とし、生の効果を残す。
- task 1ですでに第2層の全入力・ユニット平均低ゲート割合が0.95以上のseedは「介入が遅い可能性」を表示する。除外せず、主張をtask 1後の残りの輸送に限定する。

## 6. 第2層の変位を分ける帳簿

同じ画像集合を使い、連続する診断点の旧状態を $w,\mu,b$、変化をΔとする。

$$
\Delta\bar z_i
=(\Delta w_i)^\top\mu
+w_i^\top\Delta\mu
+(\Delta w_i)^\top\Delta\mu
+\Delta b_i.
$$

「自身のW更新」「上流入力の変化」「交差」「bias」を別列で保存し、和が直接測定した変位を再構成するか確認する。交差項を後から都合よくどちらかへ配らない。

自己更新項はさらに
$(\Delta\widetilde w_i)^\top\mu+\Delta m_i\,\mathbf1^\top\mu$
へ分ける。中心化成分の長さと向きの変化も区別するため、両端ノルムが正なら $\widetilde w=r u$ として

$$
\Delta\widetilde w
=(r'-r)\frac{u'+u}{2}
+\frac{r'+r}{2}(u'-u)
$$

の対称な有限差分分解を使い、それぞれ旧μと内積を取る。ゼロノルムを含む区間は直接差分だけを報告し、方向を作らない。

これは有限区間の代数的帳簿であり、各項を独立に除去した因果効果でも、自然更新が全時刻で同じ向きだった証明でもない。第1層は画像固定なのでΔμ1=0であり、実装検査にも使える。

## 7. 結果の読み分け

| 成長抑制後の結果                  | 結論                                            |
| ------------------------- | --------------------------------------------- |
| 主2endpointがともに正の区間、適用条件成立 | この条件で中心化W成長抑制が輸送と低応答化を減らす、というH2の介入証拠          |
| 輸送だけ改善                    | H2の輸送部分を支持。応答が残ることへの接続は未決または反対                |
| 応答だけ改善                    | 分布の裾・幅の変化を調べる。平均沈下を通る説明は未成立                   |
| 性能だけ改善                    | 飽和経路の証拠にせず、回転など別経路の候補                         |
| 抑制が効いても輸送が継続              | μ・向き・行平均・biasの帳簿を読む。対象成分の成長を止めれば輸送が止まる、とは言えない |
| 操作差不足、非有限、欠測、初期段階で既に低応答   | 判別不能・範囲限定。H2全体を棄却しない                          |
| 輸送・応答が改善し、性能も改善           | H2と機能との整合は強まるが、応答が性能改善を媒介した割合までは決まらない         |

task 2の初期75更新とtask 2全体のCE・精度を必ず報告し、介入が適合を妨げて輸送を小さくした可能性を調べる。task 2–10のonline精度がrefより5ポイント以上悪い場合は、学習阻害の注意フラグを付ける（設計上の実務的閾値）。それ未満でも交絡が消えた証明にはならない。悪化腕の小さい輸送を「可塑性を保護した」と呼ばない。

cap1/cap2の片方が効けばその層への介入が十分だった証拠になる。両方だけ効いても、統計的未決を「両層が必要」と言い換えない。上流/自己更新の帰属には§6を添え、時間順序だけで原因を断定しない。

## 8. 将来実装するときの検証・成果物

- 宿主の無介入再現、単独/バッチモデルの勾配とAdam更新の一致、ELU微分の照合。

## 9. H2を閉じたと書ける範囲

期待される成果は「**このELU・乱数ラベル・更新予算・介入開始点では、指定した中心化Wの成長を抑えると深い輸送と低応答化が減る**」という限定した因果主張。

Wの大きさだけを他の状態から独立に操作した普遍法則、全活性化の不可避性、自然なLoPの媒介割合までは主張しない。H4へ進む場合には同じ箱で応答への独立介入を接続する。H1のマージン候補との照合は別作業として残る。
