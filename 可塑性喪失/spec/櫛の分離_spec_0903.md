## 0. 一行

**動機**: ゲート族（ReLU・leaky・ELU・GELU）は片側で φ' を下げることで非線形性を作るので、**非線形性と可動度の損失が同じつまみ**である（leaky は φ' を 0.9 削った分だけ非線形）。周期族（Snake・櫛）は振動から非線形性を作り、φ' を削らない。もし `CB_a1` の 0/10 がこの違いで出ているなら、主張候補は「**LoP はゲートで非線形性を買うことの代償であり、振動で買えば代償を払わない**」になる。しかし現状は表現力（厳密補間）と切り分けられていないので、**表現力を落として井戸だけ残す**腕で割る。

## 2. 何を測るか — 関数の定義

すべて $z\ge0$ で恒等（`SN` を除く）。$\alpha$=1 固定（`act_alpha`）。葉の端 $-\pi/\alpha=-\pi$。$a$=0.1 は `LR_1216` に揃える。

| 族               | 記号       | $\varphi(z)$（$z<0$）                             | $\varphi'(z)$（$z<0$） | 一言                                                                                            |
| --------------- | -------- | ----------------------------------------------- | -------------------- | --------------------------------------------------------------------------------------------- |
| 1 葉＋平坦          | `CB1f`   | $-\sin^2 z$（$-\pi\le z<0$）／$0$（$z<-\pi$）        | $-\sin 2z$／$0$       | 井戸 1 個（$z=-\pi$ で $\varphi=\varphi'=0$）、その先は ReLU の壁。**壁の硬さ（$\varphi'(0^-)=0$）は `CB_a1` と同じ** |
| 1 葉＋leaky       | `CB1l`   | $-\sin^2 z$（$-\pi\le z<0$）／$a(z+\pi)$（$z<-\pi$） | $-\sin 2z$／$a$       | 井戸 1 個の先に戻り道。$[-\pi,0)$ は `CB_a1` と bit 一致                                                    |
| 段付き leaky       | `RB_dpi` | $0$（$-\pi\le z<0$）／$a(z+\pi)$（$z<-\pi$）         | $0$／$a$              | `CB1l` の葉を平坦に置き換えた対照。`RB_d2`（1/10）と `RB_d4`（0/10）の間                                           |
| Snake（錨）        | `SN`     | 全域 $z+\sin^2 z$                                 | $1+\sin 2z\in[0,2]$  | **ゲートなし**。単調・負側の可動度平均 1。表現力は櫛と同じ周期基底                                                          |
| 櫛（対照・committed） | `CB_a1`  | $-\sin^2 z$                                     | $-\sin 2z$           | `weird_act_0903`・再走しない                                                                        |

閉形式の幾何（代入値・引用不可。S-dial で数値照合）: `CB1f`・`CB1l` の分水嶺 $u$=1.571、井戸 3.142。`SN` の $\varphi'=0$ は $u=3\pi/4+k\pi$ の孤立点（測度 0）。leaky の沈下深さ中央値 ≈4（事後）は井戸 3.142 より深いので、**沈下ユニットの過半が葉を越えて先の領域（平坦／leaky）に入るはず**（`CB_a1` の沈下深さ中央値 4.09 と整合）。

### 2.1 2×2 の読み

|                    | 先が平坦                     | 先が leaky |
| ------------------ | ------------------------ | -------- |
| **$[-\pi,0)$ が葉**  | `CB1f`                   | `CB1l`   |
| **$[-\pi,0)$ が平坦** | `R_1216`（ReLU・committed） | `RB_dpi` |

行の差 = 井戸（葉）の効果、列の差 = 戻り道の効果。**`CB_a1` と `CB1l` の差 = 2 葉目以降（多葉の表現力）の効果。**

### 2.2 本走が答えないこと

包絡（$\beta<\infty$・発散域）・$\alpha\ne1$・Adam・実ベンチ（§4.3）・「Snake が良い活性化か」（処方箋ではない）。

### 4.4 実装

- `VecMLPL.ACTIVATIONS` に `comb1_flat`・`comb1_leaky`・`band_leaky_dpi`・`snake` を足す（閉形式・autograd なし・乱数消費なし・**既存分岐は 1 行も触らない**・`weird_act_0903` の追記様式に倣う）
  - `comb1_flat`: forward `where(z>0, z, where(z>-LOBE, -sin(alpha*z)**2, zeros_like(z)))`、backward `where(z>0, 1, where(z>-LOBE, -alpha*sin(2*alpha*z), 0))`、`LOBE = pi/alpha`
  - `comb1_leaky`: 同上で $z<-\pi$ を `a*(z+LOBE)`／`a`。$a$=0.1 はクラス定数 `COMB1_LEAK = {"comb1_leaky": 0.1}`（`act_alpha` は $\alpha$ に使う）
  - `band_leaky_dpi`: `BAND_WIDTH["band_leaky_dpi"] = pi`
  - `snake`: forward `z + sin(alpha*z)**2 / alpha`、backward `1 + sin(2*alpha*z)`。`0.0 - a` の規約は不要（符号反転なし）
- 段 A は `weird_act_0903` の runner を写して腕表を差し替える（宿主 `gate_dial_0902._run_arm` を直接呼ぶ・`WeirdRecorder` の 6 列を継承）。段 B は `lr_a1_0901` の runner を写す
- **★ 新規ガード `EXACT_FIT`**（本 spec の新設・全腕）: 1M 窓の $U$ seed 中央値 ≤ **1e−8** なら `EXACT_FIT` を立てる（float32 厳密補間の床 ≈1e−13 と leaky の 1e−3 の中間で、桁が 5 以上離れた値）。**`EXACT_FIT` の腕は水準（log₁₀U の差）に基づくラベルを付けない**（機構の帰属に使えない）。$n_{\rm onset}$ に基づくラベルは残す。`eval_loss_exact` を併記する
- 発散: `gate_dose_0830` §5.6 逐語継承。`SN` は正側も非線形なので発散を許容する腕（錨）。段 B の `CB_A1` が発散したら `NUMERIC_DIVERGENCE` で V7 を空にする
