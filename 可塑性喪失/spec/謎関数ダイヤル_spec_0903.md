## 0. 一行

負側の形を**設計した** 5 族（鏡・折り返し・段付き・滑り出し・櫛）を用量 12.16 の同一ハーネスで回し、**(V1) 「反転」の定義は $\varphi'<0$ か $\varphi\varphi'>0$ か**、**(V2) 吸収域の幅は支持幅（$\max_x z-\min_x z$）を越える必要があるか**、**(V3) 可動度を一定に保ったまま分水嶺を置くと罠になるか**、**(V4) 逃走の先を非アフィンな井戸で止めると救われるか**、を判定する。4 つとも「介入の効果」型の予測（[[到達と離脱_統合主張_0903]] §7 の基準率で当たりやすい側）だが、V3・V4 は機構の帰属を含むので自信は下げてある。

## 2. 何を測るか — 5 族の定義と 3 列での位置

すべて $z\ge0$ で恒等（ReLU・leaky と同じ正側）。負側だけを設計する。$u:=-z>0$ を深さとする。母数 $a$ は既存の `act_alpha` に載せる（§4.3）。

### 2.3 [[負に押す力の正体_0902]] からの読み（各腕で何が起きるはずか）

- **到達（押し下げ）は共通。** flip の平均回帰 $-\tfrac{2}{15}(w\cdot s-\tfrac12\sum w_k)$ は活性化に依らない（厳密）。$b$ 分担 $1/(1+(\mathrm{dose}/4)^2)$=0.098 も共通（[[現象3主張v1_0902]] 補題 1(b)）。**初回沈下までの降下量・深さ・所要 step が C1 の帯（$\Delta(w\cdot\mu)$ −1.18〜−1.31・深さ 1.1–1.3・30k–50k step）に入るか**を全腕で報告する（§5.5）。`LRm` だけは壁の直下で $\varphi'$ の符号が逆なので refit のループが違いうる —— C1 の帯から外れるならそれ自体が §1b 補題 2-3 への情報になる
- **適応剥がしを下向きの正味にするのは片道の壁**（同 §1 帰結・[[現象3主張v1_0902]] 補題 2-3）。壁が**区間**として存在するのは `RB` だけ（幅 $d$）。`LRq` は点、`CB` は可算個の点、`LRm`・`LRv` は無い。したがって「壁で戻しが消える」型の下向き正味は `RB` にしか無く、`RB` では死帯の幅が支持幅を越えたユニットが ReLU と同じ $\rho=2/15$ レジーム（同 §2 表）に入るはず
- **バネ（$\rho>2/15$）**は $(\varphi^2)'<0$ で帯へ向かう腕に立つ: `LRm`・`LRq`（全域）・`LRv`（$[-d,0)$ のみ）・`RB`（$z<-d$ で $-d$ へ）・`CB`（葉の浅い半分）
- **逃走は `LRv` の $(-2d,-d)$ と `CB` の葉の深い半分にある。** SiLU・GELU と違い**減衰せず**（`LRv` は可動度 $a$ 一定、`CB` は $O(\alpha e^{u/\beta})$）、**有限で止まる**（`LRv` は $-2d$、`CB` は井戸）。「逃走が止まらない」（`FLIGHT_STALLS`＝減速するが停止しない）が SiLU・GELU の $\lvert\varphi'\rvert\to0$ に由来するなら、これらは止まる

### 2.4 本走が答えないこと

2 層・用量 9.33・オラクルなし（`_off`）・lr・$T$・Adam・幅・無限時間。谷埋めとの直接比較は `Gc_b1`／`Sc_b3` の committed 値で水準だけ添える（§4.2）。`CB` の包絡 $\beta<5$（発散域・§4.1）。

  - `band_leaky_d0p5`／`_d1`／`_d2`／`_d4`: forward `where(z>0, z, where(z>-d, zeros_like(z), a*(z+d)))`、backward `where(z>0, 1, where(z>-d, 0, a))`。`BAND_WIDTH = {...}`。$d$=0 で `leaky_relu` の式に退化することを S-limit で見る
  - `ramp_leaky_d1`: forward `where(z>0, z, where(z>-d, -kappa*z*z, a*z + a*d/2))`、backward `where(z>0, 1, where(z>-d, -2*kappa*z, a))`、`kappa = a/(2d)` を `set_activation` 内で 1 回だけ計算。`RAMP_DEPTH = {"ramp_leaky_d1": 1.0}`
  - `comb_binf`／`comb_b5`: forward `where(z>0, z, -env*sin(alpha*z)**2)`、backward `where(z>0, 1, env*(sin(alpha*z)**2/beta - alpha*sin(2*alpha*z)))`、`env = exp(-z/beta)`（`comb_binf` は `env = 1.0`・`1/beta = 0.0` を**定数で**書き、`exp` を呼ばない）。`COMB_ENVELOPE = {"comb_binf": inf, "comb_b5": 5.0}`。$\beta$=5 では $z<-200$ で `exp` が float32 で溢れるので、S-num の範囲 $[-200,200]$ は `comb_b5` だけ $[-100,100]$ にし、溢れる深さを `provenance.json` に書く
- **すべて自分の forward の真の導関数**（折れ目は測度 0）。S-fd は折れ目 $\{0,-d,-2d\}$ の $\pm10^{-3}$ を除いた格子で照合する。SiLU・GELU と同じ扱い（`bwd_leak` の代替勾配とは違う）
- 用量固定は宿主のオラクルモードそのまま（入力側・活性化非依存）
- **ロガー（軌道中立・追加のみ）**: `gate_dial_0902.unit_extra_record` の 5 列（`layer1_mob`・`layer1_absmob`・`layer1_zmax`・`layer1_zmean`・`layer1_v`）を継承し、**`layer1_zmin`** $=\min_x z_i(x)$ を 1 列足す（支持幅 `zmax − zmin` のため。V2 の §5.4 で要る）。S-log-b で bit 一致を見る
- **可動度の符号混在（設計上の注意）**: `LRv`・`CB` は支持が折れ目・井戸を跨ぐと $\varphi'$ の符号が混じり、`layer1_mob` が打ち消しで小さくなる。**`frozen`（$\lvert\mathbb E\varphi'\rvert<10^{-6}$）はこの 2 族では凍結の指標にならない**。並べて `frozen_abs` $:=\mathbb E_x\lvert\varphi'\rvert<10^{-6}$ を持つ（`layer1_absmob` から）。判定式には入れない
