## 4. 引き継がないもの（8/22 に撤回・弱化したもの）

| 項目 | 状態 |
|---|---|
| **L1（`∫F_self / ∫F_gate` の中央値）** | **指標として使えない**。`g = s + r` なので分母に分子が入り、`S = 1/(1+r/s)`。**完全中和（`r = −s`）に極があり、それは系が最も長く過ごす状態**。実測の比の最大は 1602.9。さらに `s ≤ 0` 固定で `r` が両符号なので非負分解にならず、S=1 は中間ではなく枝の境界。**群間差（輸送死 0.9903 / 全群 0.8705 / 再分類死 0.4314）は下枝比率（51.1% / 54.2% / 66.2%）の再エンコードで、大きさを測っていない** |
| **「見出しを全群で読むか輸送死で読むかで結論の向きが変わる」** | **言い過ぎ。撤回**。どちらで読んでも大きさが出ないので、向きが変わるほどの情報がない |
| **「スモークの 24.5% が本番で再現しなかった」** | **弱める**。0.245 と 0.87 は極を持つ同じ統計量の 2 標本なので、値の差は再現失敗の証拠にならない。ただし**スモークの成果物が repo に存在しない**のは別途事実（[[中和と境界窓]] 訂正記録） |
| **L8** | **同じ病気**。分子・分母とも近中和の正味なので符号が飛ぶ。CI が **[−0.2457, +1.6865]** と負をまたいで 1 を超えているのが徴候。**(A) でフレームを落としても、引用するなら注記が要る** |
| 影響を受けないもの | **L2 / L4 / L5 / L7**（符号割合）と **L3**（s・r・g を別々に出している） |

**測れる形にするなら**: `s / (|s| + |r|)` のように分母から分子を外す（P3 の `PE = |ΣΔ| / Σ|Δ|` と同じ作法）か、`|s| > |r|` の割合のような順位統計。**いずれも新規指標なので別 spec の事前登録事項。**

## 5. Q3 の詳細（3-1）

**主張**: 移動度は片側消灯（p̂ < 0.05 で滑落 ≈ 0）。ゲート曲線で cos < −0.15 → p̂ = 0.000。ガウス β 近似の −0.46 より遥かに急峻で、condA は有界入力なので**文字通りの吸収が実在**。三本柱のうち「なぜ止まるか」を担う。

### (a) 誤差棒 → 既存データで付く【解析】

`ratchet_log_0819` の npz は `cos_u_mu` / `p_hat` / `w_norm` / `b` を 10 seed × 20,901 記録点 × 100 unit で持つ。seed 束ねブートストラップの結果（**事後計算・未事前登録**）:

| cos 区間 | p̂ 中央値 | 95% CI |
|---|---|---|
| [−0.35, −0.25) | 0.0000 | [0.0000, 0.0000] |
| [−0.25, −0.20) | 0.0000 | [0.0000, 0.0000] |
| [−0.20, −0.15) | 0.0031 | [0.0000, 0.0094] |
| [−0.15, −0.10) | 0.0625 | [0.0625, 0.0625] |
| [−0.05, +0.00) | 0.3313 | [0.3219, 0.3406] |
| [+0.15, +0.30) | 0.9125 | [0.8969, 0.9281] |

**−0.20 より下は 10 seed 全部で厳密ゼロ**（CI が退化して幅ゼロ）。再学習不要で格を一段上げられる。

### (b) ‖w‖ 交絡 → 既存データで見え、実在する【解析】

（**事後計算・未事前登録**）

| ‖w‖ 四分位 | p̂ = 0 になる cos の上端 |
|---|---|
| [0.87, 1.70] | −0.15 |
| [1.70, 2.30] | −0.15 |
| [2.30, 3.07] | **−0.20** |
| [3.07, 7.72] | **−0.20** |

**ノルムが大きいほど消灯点が µ̂ 側へ寄る。** 交絡は実在するが、向きは主張に有利（ノルムが育つほど浅い負 cos で消える）。[[ノルム増大と不可逆性]] とも同方向。層別ゲート曲線として書ける。

### (c) 消灯点のスケーリング → ここだけ新規走【走】

−0.15 が入力統計から予言できるのか、この設定固有の値かが未確認。

**閉じる作業の記述に問題がある。** [[命題リスト]] Q3 行は「c スイープ」と書いているが、`c` は **condB 専用**の入力平均パラメータ（µ = c/√d · 1、`src/envs.py:176`。condA の run は `c=None`、`src/common.py:73`）。**Q3 の主張は condA スコープで、condB への外挿は禁止**（[[論点マップ]] 未カバーの穴 ②）。字義どおりやると対象が違う。

condA 側で入力平均を動かすレバーは `enc`（`std` / `centered`）。centering の効果自体は既測（dead 0.964 → 0.294）だが、**`ratchet_log_0819` は `std` のみで、centered アームに p̂ / cos のプローブログが付いていない**。やるならプローブ付き centered アームの新規走。

**→ [[命題リスト]] Q3 行の「閉じる作業」列を書き換える必要がある。**

## 6. 死 → ランクの事後確認（3-5）

`results/teachw_0820/H100/lop_metrics_A_w100.csv`（commit 済み）から。**すべて事後計算・未事前登録。引用するには事前登録つきの昇格が要る。**

| step | eval_loss | alive | eff_rank | eff_rank_W |
|---|---|---|---|---|
| 100k | 0.0032 | 38.7 | 14.94 | 18.73 |
| 300k | 0.6855 | 12.0 | 8.86 | 16.92 |
| 500k | 0.2903 | 8.5 | 6.61 | 16.09 |
| 1M | 0.3684 | 5.3 | **4.66** | 15.22 |

- `eff_rank` は `alive` に追随（相関 **0.961**）、1M で **eff_rank 4.66 ≈ alive 5.3**
- `eff_rank / alive` は 0.39 → 0.88 と**上がる**。生存者あたりの冗長性はむしろ減っており、ランク低下は **m_alive 側で説明される向き**
- `eff_rank_W`（死んだ重みを含む行列側）は 18.7 → 15.2 とほぼ動かない。**落ちるのは表現側だけ**

Q0 の骨格（100k でフィット達成 → その後喪失、95 ユニットが遊んだまま未フィット）も同じ表から**単一アームで**出る。H スイープを引く必要がない。
